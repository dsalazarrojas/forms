# Winter Illumination Voting Survey - Help Guide
## Purpose

This survey is intended to gather feedback and ratings about the Winter Illumination event. It will help event organizers to understand attendee opinions on the display quality, attendee demographics, and potential suggestions for improvement.

## How To Complete This Form

1. Please answer the questions truthfully and thoroughly.
2. Make sure to select all relevant options for the best representation of your experience.
3. For open-ended fields, provide as much detail as possible.
4. If you're unsure about any question, feel free to ask for clarification.

## Field-by-Field Explanation

* **Will you be attending the Winter Illumination event?** (id: 2, type: select_one, required: true)
  Please select 'True' if you plan to attend the event, and 'False' otherwise.
* **Do you have a photo credit for the event?** (id: 3, type: select_one, required: false)
  Select 'True' if you have a photo credit, 'False' if you don't.
* **How would you rate the event's display quality (good)?** (id: 4, type: select_multiple, required: false)
  Choose all that apply: Good, Fair.
* **Feedback** (id: 5, type: text, required: false)
  Share your thoughts and suggestions about the event.
* **Suggestion** (id: 6, type: text, required: false)
  Provide any additional ideas or suggestions for improvement.
* **Will you be displaying your name at the event?** (id: 7, type: select_one, required: false)
  Select 'True' if you plan to display your name, 'False' otherwise.
* **Event name** (id: 8, type: text, required: false)
  Provide the name of the event (if not already provided).
* **Event date** (id: 9, type: date, required: false)
  Enter the date of the event.
* **Event time** (id: 10, type: time, required: false)
  Enter the time of the event.
* **Where will the event be held?** (id: 11, type: select_one, required: false)
  Select where the event will take place (e.g., venue, location).
* **Other** (id: 12, type: text, required: false)
  Provide any other relevant information not covered by the previous fields.
