# Lakeside Equipment Survey Template - Help Guide
## Purpose
The Lakeside Equipment Survey Template is a form designed to gather information about equipment used at lakesides, which can include equipment such as boats, canoes, or other gear used by park rangers or staff for lake activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the general information section with details about the equipment, including its type, description, and any other relevant information.
2. Take a photo of the equipment and provide a description of it in the photo description field.
3. Select the equipment's condition and assess its maintenance needs.
4. Provide details about any maintenance required for the equipment.
5. Enter the repair cost for the equipment, if applicable.
6. Record the purchase date and last service date.
7. Specify the cost of services performed on the equipment.
8. Enter any notes or comments about the equipment.
9. Choose the assigned tool or equipment category.
10. Report the number of equipment pieces.
11. Enter the serial number and model number of the equipment.
12. Describe the equipment in more detail.
13. Select the equipment's condition and assign a category (e.g., A, B, C).
14. Choose the method of purchase (e.g., lease, own, other).
15. Record the purchase date range.
16. Enter the warranty start and end dates.
17. Specify the warranty period.

## Field-by-Field Explanation

* **title**: This is the name of the form and is not editable.
* **general_info**: This field is a text field where you can enter general information about the equipment, such as its name, description, and other relevant details.
* **equipment_type**: This field is a dropdown menu where you can select the type of equipment (e.g., boat, canoe, kayak).
* **photo_description**: This field is a text field where you can enter a description of the equipment's photo.
* **photo_file**: This field is not used in this template, but you can upload a photo of the equipment if desired.
* **condition_assessment**: This field is a text field where you can assess the equipment's condition (e.g., good, fair, poor).
* **maintenance_needed**: This field is a dropdown menu where you can select the maintenance needs of the equipment (e.g., none, low, high).
* **repair_cost**: This field is a numerical field where you can enter the cost of repairs performed on the equipment.
* **purchase_date**: This field is a date field where you can record the purchase date of the equipment.
* **last_service**: This field is a date field where you can record the last service date of the equipment.
* **service_cost**: This field is a numerical field where you can enter the cost of services performed on the equipment.
* **notes**: This field is a text field where you can enter any additional comments or notes about the equipment.
* **assigned_tool**: This field is a dropdown menu where you can select the assigned tool or equipment category.
* **category**: This field is a dropdown menu where you can select a category for the equipment (e.g., A, B, C).
* **equipment_count**: This field is a numerical field where you can report the number of equipment pieces.
* **serial_number**: This field is a text field where you can enter the equipment's serial number.
* **model_number**: This field is a text field where you can enter the equipment's model number.
* **description**: This field is a text field where you can describe the equipment in more detail.
* **equipment_condition**: This field is a dropdown menu where you can select the equipment's condition (e.g., good, fair, poor).
* **purchase_method**: This field is a dropdown menu where you can select the method of purchase (e.g., lease, own, other).
* **purchase_date_range**: This field is a date field where you can record the purchase date range.
* **warranty_start_date**: This field is a date field where you can record the start date of the warranty.
* **warranty_end_date**: This field is a date field where you can record the end date of the warranty.
* **warranty_period**: This field is a text field where you can specify the warranty period.
* **comments**: This field is a text field where you can enter any additional comments or notes about the equipment.
* **uploaded_file**: This field is not used in this template, but you can upload a file related to the equipment if desired.
