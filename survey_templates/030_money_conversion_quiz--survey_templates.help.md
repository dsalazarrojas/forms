# Money Conversion Quiz - Help Guide
## Purpose

The Money Conversion Quiz form is designed to help users convert a base amount in one currency to its equivalent value in another currency. This form is a quick and easy way to perform currency conversions.

## How To Complete This Form

1. Select the **Base Currency** from the list of available options.
2. Enter the **Base Amount** to be converted.
3. Enter the **Base Exchange Rate** (optional).
4. Select the **Target Currency** from the list of available options.
5. Enter the **Target Amount** to see the converted amount.
6. Optionally, enter the **Actual Exchange Rate** to override the default exchange rate.
7. Click **Submit** to view the converted amount.

## Field-by-Field Explanation

* **Base Information**: This is a note field for entering any relevant information about the base currency. (Required: false)
* **Base Currency**: Choose the currency of the base amount you want to convert (e.g., USD, EUR, JPY, CNY). (Required: true)
* **Base Amount**: Enter the amount you want to convert from the base currency. (Required: false)
* **Base Exchange Rate**: Enter the exchange rate for the base currency (optional). If not provided, the default rate will be used. (Required: false)
* **Target Currency**: Choose the currency to which you want to convert the base amount (e.g., USD, EUR, JPY, CNY). (Required: true)
* **Target Amount**: This field displays the converted amount in the target currency. (Required: false)
* **Actual Exchange Rate**: Enter the actual exchange rate for the conversion (optional). This will override the default exchange rate. (Required: false)
* **Converted Amount**: This field displays the converted amount in the target currency. (Required: false)
* **Submit**: Click this button to view the converted amount. (Required: false)
