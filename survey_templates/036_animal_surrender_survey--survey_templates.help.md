# Animal Surrender Survey - Help Guide
## Purpose
This form is designed to gather information from individuals surrendering animals to our shelter, to understand their reasons for surrendering and gather feedback for improvement.

## How To Complete This Form

To complete this form, please follow these steps:

*   Read each question carefully and answer all the questions to the best of your ability.
*   Select the correct answer options for each question. If you are unsure about an option, please select "Unsure".
*   If you have any additional feedback or comments, please use the "Any Additional Feedback or Comments" section at the end of the form.
*   Please note that some questions are required fields and must be answered before proceeding.

## Field-by-Field Explanation

*   **Your Name**: This is the name of the person surrendering the animal.
    *   Please enter your name.
*   **Email Address**: This is the email address where we can contact you for follow-up if needed.
    *   Please enter your email address.
*   **Survey Date**: This is the date of the survey.
    *   This field is automatically populated based on the date the form is submitted.
*   **Animal Name**: This is the name of the animal being surrendered.
    *   Please enter the name of the animal.
*   **Species**: Select the species of the animal being surrendered.
    *   Please select the correct species from the options provided.
*   **Animal Age**: This is the age of the animal in years.
    *   Please enter the age of the animal.
*   **How Long Did You Own This Animal**: This is the length of time you have owned the animal.
    *   Please enter the length of time.
*   **Primary Reason for Surrender**: Select the primary reason for surrendering the animal.
    *   Please select the reason that best describes your situation.
*   **Housing Related Reasons**: Select all the housing related reasons that apply to your situation.
    *   If none apply, select "Not Applicable".
*   **Financial Challenges**: Select all the financial related reasons that apply to your situation.
    *   If none apply, select "Not Applicable".
*   **Behavior Issues**: Select all the behavior issues experienced by the animal.
    *   If none apply, select "None".
*   **Did You Receive Any Support Before Surrender**: Select if you received any support before surrendering the animal.
    *   Please select "Yes" if you received any support.
*   **Would Additional Support Have Helped You Keep Your Pet**: Select if additional support would have helped you keep your pet.
    *   Please select "Yes" if you think additional support would have helped.
*   **Did You Attempt to Rehome the Animal**: Select if you attempted to rehome the animal.
    *   Please select "Yes" if you attempted to rehome the animal.
*   **Barriers in Rehoming**: Select all the barriers you faced while rehoming the animal.
    *   If none apply, select "Did Not Try".
*   **How Difficult Was This Decision**: Select how difficult this decision was for you.
    *   Please select the option that best describes your experience.
*   **How Was Your Experience with Our Shelter**: Select your experience with our shelter.
    *   Please select the option that best describes your experience.
*   **How Helpful Was Our Staff**: Select how helpful our staff was.
    *   Please select the option that best describes your experience.
*   **Would You Consider Adopting from Us in the Future**: Select if you would consider adopting from our shelter in the future.
    *   Please select "Yes" if you would consider adopting.
*   **What Support Services Would Have Helped You**: Select all the support services that would have helped you.
    *   If none apply, select "None".
*   **May We Contact You for Follow-Up**: Select if you are okay with us contacting you for follow-up.
    *   Please select "True" if you are okay with contact.
*   **Any Additional Feedback or Comments**: Please use this section to provide any additional feedback or comments.
    *   Your input helps us improve our services.
