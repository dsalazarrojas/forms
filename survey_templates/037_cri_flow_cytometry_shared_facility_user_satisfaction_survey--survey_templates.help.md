# cri_flow_cytometry_shared_facility_user_satisfaction_survey - Help Guide
## Purpose
This form is designed to collect user feedback and satisfaction data from users who have interacted with a shared facility, likely in an academic or research setting.

## How To Complete This Form
1. Review each question carefully and answer them based on your experience at the facility.
2. For questions with a select_multiple type, select all options that apply.
3. For questions with a select_one type, choose only one option that best describes your experience.
4. For text fields, provide a brief answer in as much detail as possible.

## Field-by-Field Explanation
* **Facility experience a priority (1)**:
	+ This question asks whether facility experience is a priority for you. Select 'True' if it is, or 'False' if it is not.
* **Facility experience priority (2)**:
	+ Please describe how important facility experience is for you.
* **Facilities equipment quality (3)**:
	+ This question asks about your perception of the facility's equipment quality. Select all options that apply: Excellent, Good, or Poor.
* **Facility staff knowledge (4)**:
	+ This question is not required, but if you answer it, please describe how knowledgeable you find the facility staff to be.
* **Facility staff helpfulness (5)**:
	+ This question is not required, but if you answer it, please describe how helpful you found the facility staff to be.
* **Facility staff communication (6)**:
	+ This question is not required, but if you answer it, please describe how good you found the communication from the facility staff to be.
* **Facility staff friendliness (7)**:
	+ This question is not required, but if you answer it, please describe how friendly you found the facility staff to be.
* **Facility accessibility (8)**:
	+ This question is not required, but if you answer it, please describe how accessible you found the facility to be.
* **Facility cleanliness (9)**:
	+ This question is not required, but if you answer it, please describe how clean you found the facility to be.
* **Facility environment (10)**:
	+ This question is not required, but if you answer it, please describe the facility's environment.
* **Facility services (11)**:
	+ This question is not required, but if you answer it, please describe any services you used at the facility.
* **Facility safety (12)**:
	+ This question is not required, but if you answer it, please describe the safety of the facility.
* **Facility evaluate (13)**:
	+ This question is not required, but if you answer it, please describe your evaluation of the facility.
* **Facility comments (14)**:
	+ This is an open-ended text field for you to provide any additional comments about your experience at the facility.

## Tips
- Please answer all the required questions (marked as "required").
- For questions that are not required, you can skip them if you don't have an opinion or experience.
- If you have any comments or suggestions for the facility, please use the "Facility comments" field.
- Thank you for taking the time to complete this form!
