# Feedback Form Requisition Tool - Help Guide
## Purpose
The Feedback Form Requisition Tool is used to collect feedback on events from users. This form helps event organizers to gather information on various aspects of events, including the event's details and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Organizer field with the name of the person or organization responsible for the event.
2. Provide the Event Name and Event Location fields with accurate and descriptive information.
3. Enter the Event Date and Event Time fields with the correct date and time of the event.
4. Select the Event Category from the options provided.
5. Choose the Feedback Type from the options provided.
6. Enter any additional Notes if necessary.
7. Review and confirm the accuracy of the information provided.

## Field-by-Field Explanation

* **Event Organizer**: Enter the name or organization responsible for the event.
* **Event Name**: Enter a short description of the event, such as a title or name.
* **Event Description**: Enter a brief description of the event.
* **Event Location**: Enter the physical location where the event will take place.
* **Event Date**: Enter the date of the event in the format of MM/DD/YYYY.
* **Event Time**: Enter the start time of the event in the format of HH:MM AM/PM.
* **Event Category**: Select the category of the event from the options provided.
* **Feedback Type**: Select the type of feedback from the options provided.
* **Notes**: Enter any additional comments or feedback on the event.
* **Event Status**: Select the status of the event from the options provided.
* **Event Submitted By**: Select whether the event was submitted by the event organizer.
* **Event Submitted On**: Select whether the event was submitted on the current date.
* **Event Last Update On**: Select whether the event was last updated on the current date.
* **Assigned To**: Select whether the event is assigned to someone.
* **Assigned By**: Select whether the event is assigned by someone.
* **Assigned Status**: Select the status of assignment from the options provided.
* **Assigned Date**: Select the date the event was assigned.
* **Last Update By**: Select whether the last update was made by someone.
