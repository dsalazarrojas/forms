# Project Management Survey - Help Guide
## Purpose
This form is a simple survey designed to gather contact information and basic details about project managers.

## How To Complete This Form
To complete this form, please follow these steps:

1. Click on the "Submit" button to start filling out the form.
2. Fill out each of the following fields with the corresponding information:
	* **Project Management Survey**: A title for the project.
	* **Project Manager**: The name of the project manager.
	* **Project Manager Title**: The title of the project manager.
	* **Project Manager Email**: The email address of the project manager.
	* **Project Manager Phone**: The phone number of the project manager.

## Field-by-Field Explanation
* **Project Management Survey** (`project_management_survey_1`, text, required): Enter a brief title for the project.
* **Project Manager** (`project_management_survey_2`, text, optional): Enter the name of the project manager.
* **Project Manager Title** (`project_management_survey_3`, text, optional): Enter the title of the project manager (e.g., "Team Lead", "Senior Project Manager", etc.).
* **Project Manager Email** (`project_management_survey_4`, email, optional): Enter the email address of the project manager.
* **Project Manager Phone** (`project_management_survey_5`, text, optional): Enter the phone number of the project manager.

## Tips
* Please make sure to enter accurate and up-to-date information for each field.
* If you are unsure about any of the fields, please consult with your project team or supervisor for guidance.
* You can save your progress and come back later to complete the form if needed.
