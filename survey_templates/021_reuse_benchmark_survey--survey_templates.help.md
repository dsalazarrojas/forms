# reuse_benchmark_survey - Help Guide
## Purpose
This form is designed to collect feedback on the progress and challenges of a project or process. It helps us understand where users may be facing difficulties and where we can improve.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the "Form questions" section, which asks about your general experience with the project or process.
2. Choose the "Survey progress" option that best describes your current status.
3. Identify any barriers you are facing, such as lack of resources, knowledge, or support.
4. Select the types of support you need, such as technical, training, or process support.
5. Add any comments or feedback in the "Form comments" section.

## Field-by-Field Explanation

* **Progress** (`survey_progress`, select_one, optional): Choose the option that best describes your current progress in the project or process.
* **Lack of resources** (`barriers`, select_multiple, optional): Select this option if you are facing challenges due to lack of resources.
* **Lack of knowledge** (`barriers`, select_multiple, optional): Select this option if you are facing challenges due to lack of knowledge.
* **Lack of support** (`barriers`, select_multiple, optional): Select this option if you are facing challenges due to lack of support.
* **Other** (`barriers`, select_multiple, optional): Select this option if you are facing other challenges not listed above.
* **Technical support** (`support_needs`, select_multiple, optional): Select this option if you need technical support.
* **Training support** (`support_needs`, select_multiple, optional): Select this option if you need training or instruction support.
* **Process support** (`support_needs`, select_multiple, optional): Select this option if you need process or procedure support.
* **Other support** (`support_needs`, select_multiple, optional): Select this option if you need other types of support not listed above.
* **Form comments** (`form_comments`, note, optional): Add any additional comments or feedback you have about the project or process.
