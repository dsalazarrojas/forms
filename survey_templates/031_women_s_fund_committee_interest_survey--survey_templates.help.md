# women's_fund_committee_interest_survey - Help Guide
## Purpose
This form is used by the Women's Fund Committee to collect information about their interests and preferences. The form helps to gather data on their volunteer interests, candidate information, and follow-up details.

## How To Complete This Form
1. Start by reviewing each field carefully and answering each question to the best of your ability.
2. Make sure to provide as much detail as possible in your responses.
3. If you have any questions or concerns, don't hesitate to ask for clarification.

## Field-by-Field Explanation
* **Introduction** (`Introduction`, note, optional): This section is an overview of the form and is intended to introduce the committee's background and purpose. Please provide a brief overview of the committee's mission and goals.
* **Contact Information** (`Contact Information`, text, optional): This field is used to collect the committee's contact information, including their name, title, and department. Please provide the committee's name, title, and department.
* **Email** (`Email`, email, optional): This field is used to collect the committee's email address. Please provide the email address of the committee's main contact person.
* **Phone** (`Phone`, text, optional): This field is used to collect the committee's phone number. Please provide the committee's main phone number.
* **Volunteer Interest** (`Volunteer Interest`, select multiple, optional): This field is used to indicate the committee's volunteer interests. Please select all that apply from the options provided:
	+ Volunteer
	+ Other (please specify)
* **Candidate Info** (`Candidate Info`, select one, optional): This field is used to indicate if the committee has any candidate information. Please select one of the options provided:
	+ Yes
	+ No
* **Candidate Interest** (`Candidate Interest`, select multiple, optional): This field is used to collect the committee's candidate interests. Please select all that apply from the options provided:
	+ Volunteer
	+ Other (please specify)
* **Follow-up** (`Follow-up`, select one, optional): This field is used to indicate if the committee would like to be followed up on. Please select one of the options provided:
	+ True
	+ False
* **Follow-up Time** (`Follow-up Time`, date, optional): This field is used to collect the date for the follow-up. Please provide the date for the follow-up.
* **Follow-up Date** (`Follow-up Date`, time, optional): This field is used to collect the time for the follow-up. Please provide the time for the follow-up.
* **Next Steps** (`Next Steps`, text, optional): This field is used to collect the committee's next steps. Please provide the next steps the committee would like to take.
* **Additional Comments** (`Additional Comments`, text, optional): This field is used to collect any additional comments from the committee. Please provide any additional comments or thoughts.
* **Nonprofit** (`Nonprofit`, select one, optional): This field is used to indicate if the committee is a nonprofit organization. Please select one of the options provided:
	+ Nonprofit
	+ Other
