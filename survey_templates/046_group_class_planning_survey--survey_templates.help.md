# Group Class Planning Survey - Help Guide
## Purpose
The Group Class Planning Survey is a form used to collect information for planning and creating group classes in a system. It collects data such as class title, category, description, start and end time, questions, and more, to create and manage classes in the system.


## How To Complete This Form

1. **Fill out the form**: Carefully complete each field as instructed below.
2. **Review and edit carefully**: Before submitting, review the form to ensure all required fields are completed accurately and correctly.
3. **Submit the form**: Once satisfied that the form is complete and accurate, submit it to proceed with creating the class.

## Field-by-Field Explanation

* **Class Title** (`class_title`, `text`, Required): Enter a brief and descriptive name for the class.
* **Category** (`class_category`, `select_one`, Required): Select the category for the class, which can be General, Advanced, or Intermediate.
* **Tags** (`class_tags`, `text`, Optional): Add relevant tags or keywords for the class (e.g., programming languages, topics).
* **Description** (`class_description`, `text`, Required): Provide a detailed description of the class, including its content and scope.
* **Start Time** (`class_start_time`, `time`, Required): Enter the start time of the class in 24-hour format (e.g., 14:00).
* **End Time** (`class_end_time`, `time`, Required): Enter the end time of the class in 24-hour format (e.g., 16:00).
* **Questions** (`class_questions`, `select_multiple`, Required): Select the questions that will be covered in the class.
* **Questions Type** (`class_questions_type`, `select_one`, Required): Select the type of questions, which can be Theory, Practical, or Both.
* **Sort Questions** (`class_questions_sort`, `select_multiple`, Required): Select the sort order for the questions, which can be Ascending or Descending.
* **Sort Order** (`class_questions_sort_order`, `select_multiple`, Required): Select whether to sort the questions in true or false order.
* **Sort Option** (`class_questions_sort_option`, `select_multiple`, Required): Select whether to sort the questions with Yes or No.
* **Confirm Sort Order** (`class_questions_sort_order_confirmation`, `checkbox`, Required): Confirm the sort order selection to ensure accuracy.

Note: This guide is intended to be used as a reference for end-users to understand the purpose and requirements of each field in the form.
