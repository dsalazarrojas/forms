# Number Decoding Quiz - Help Guide
## Purpose
This form is designed to assess an individual's ability to decode numbers, a crucial skill in mathematics and problem-solving. It helps to evaluate how well they can identify patterns and sequences within a given set of numbers.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first number response in the "First number response" field.
2. Select the correct response for the given number pattern in the "Correct response" field.
3. Choose the number patterns that match the given sequence from the "Number patterns" field.
4. Confirm whether your first number response is correct or not by selecting one of the options in the "First number response is correct" field.
5. Enter your second number response in the "Second number response" field.
6. Optionally, enter your total score in the "Total score" field.
7. Add any comments or explanations for your responses in the "Comments" field.

## Field-by-Field Explanation
* **First number response** (`first_number_response`, text, required): This field is where you enter your first number response. Please enter the number you think is part of the sequence.
* **Correct response** (`first_number_response_correct`, text, required): This field shows the correct response for the given number pattern.
* **Number patterns** (`number_patterns`, select_multiple, required): Select all the number patterns that match the sequence given in the "First number response" field. Note that you can select multiple patterns if they both apply.
* **First number response is correct** (`first_number_response_is_correct`, select_one, required): Confirm whether your first number response is correct or not.
* **Second number response** (`second_number_response`, text, optional): If provided with a second number, enter your response in this field.
* **Number decoding score** (`number_decoding_score`, number, optional): Optionally, enter your total score after attempting all questions.
* **Second number response correct** (`second_number_response_correct`, text, optional): If provided with a second number, confirm whether your second number response is correct or not.
* **Total score** (`total_score`, number, optional): Optionally, enter your total score after attempting all questions.
* **Comments** (`comments`, note, optional): Add any comments or explanations for your responses in this field.
