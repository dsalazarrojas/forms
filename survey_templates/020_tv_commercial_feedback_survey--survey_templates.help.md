# tv_commercial_feedback_survey - Help Guide
## Purpose
The tv_commercial_feedback_survey form is designed to collect feedback on TV commercials from users. It helps us evaluate and improve the effectiveness and quality of commercials.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the commercial ID number.
2. Choose the channel the commercial was shown on.
3. Select one or more categories for the commercial.
4. Rate the commercial's effectiveness on a scale of 1-10.
5. Provide a short message about the commercial.
6. If necessary, enter your email address and phone number for follow-up contact.
7. Choose the time and date of the commercial.
8. Select one or more feedback options.

## Field-by-Field Explanation

* **Survey**: (Page 1, Text): Enter a brief title or description for the survey.
* **Commercial**: (id: 2, Number): Enter the ID number of the commercial you are providing feedback on.
* **Channel**: (id: 3, Select One): Choose the channel the commercial was shown on. 
* **Category**: (id: 4, Select Multiple): Select one or more categories that the commercial falls under.
* **Commercial Effectiveness**: (id: 5, Number): Rate the commercial's effectiveness on a scale of 1-10.
* **Message**: (id: 6, Note): Provide a short message about the commercial, any issues you noticed, or any suggestions for improvement.
* **Email**: (id: 7, Email, optional): Enter your email address if you would like to be contacted for follow-up.
* **Phone**: (id: 8, Text, optional): Enter your phone number if you would like to be contacted for follow-up.
* **Date**: (id: 9, Date): Enter the date the commercial was shown.
* **Time**: (id: 10, Time): Enter the time the commercial was shown.
* **Feedback**: (id: 11, Select Multiple): Select one or more feedback options to provide additional comments.
* **Assigned Tool**: (id: 12, Text): Enter the name of the tool that was used to create the commercial.
* **Created By**: (id: 13, Select One): Choose who created the commercial.

Note: Fields marked as optional are not required to be filled out, but can be filled out if you have this information available.
