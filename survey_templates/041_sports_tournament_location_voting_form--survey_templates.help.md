# Sports Tournament Location Voting Form - Help Guide
## Purpose
The Sports Tournament Location Voting Form is designed to collect feedback on potential locations for a sports tournament from users.

## How To Complete This Form
1. Please ensure you have a genuine interest in voting for a location for a sports tournament.
2. Select a location by choosing one of the options provided.
3. Enter your preferred date and time if you wish (though not mandatory).
4. If you have any additional information, please include it in the "Additional Information" field.
5. Provide a valid email address if you wish to be contacted.

## Field-by-Field Explanation
* **Sports Tournament Location** (`sports_tournament_location`, select_one, required): Choose one of the provided locations as your preferred location for the sports tournament.
* **Tournament Date** (`tournament_date`, date, optional): Select a date for the sports tournament, though this field is not mandatory.
* **Tournament Time** (`tournament_time`, time, optional): Choose a time for the sports tournament, though this field is not mandatory.
* **Additional Information** (`additional_info`, note, optional): If you have any extra information you'd like to share with us, please enter it here.
* **Contact E-mail** (`contact_email`, email, optional): Enter a valid email address if you'd like to be contacted about this sports tournament.
