# Media Project Planning Survey - Help Guide
## Purpose
This form is designed to collect information about media projects, including objectives, timeline, resources, contacts, budget, location, and any additional notes.

## How To Complete This Form

To complete this form, follow these steps:

1. **Project Objectives**
   (`project_objectives`, `text`, required: false): Write a brief summary of the project's objectives.
2. **Project Timeline**
   (`project_timeline`, `date`, required: false): Enter the start and end dates for the project.
3. **Project Resources**
   (`project_resources`, `select_multiple`, required: false): Select the resources required for the project, such as Video Editor, Director, Producer, Designer, and Cinematographer.
4. **Project Contacts**
   (`project_contacts`, `text`, required: false): List all project contacts.
5. **Project Budget**
   (`project_budget`, `number`, required: false): Enter a budget for the project.
6. **Project Location**
   (`project_location`, `text`, required: false): Enter the location of the project.
7. **Project Notes**
   (`project_notes`, `note`, required: false): Add any additional notes about the project.
8. **Timeline Dates**
   (`project_timeline_dates`, `time`, required: false): This field is not explicitly defined in the provided YAML, but it's likely meant to complement the `project_timeline` field.
9. **Timeline Start Date**
   (`project_timeline_start_date`, `date`, required: false): Enter the start date of the project.
10. **Timeline End Date**
    (`project_timeline_end_date`, `date`, required: false): Enter the end date of the project.
11. **Project Contacts Email**
    (`project_contacts_email`, `email`, required: false): Enter the contact email for the project.
12. **Project Contacts Phone**
    (`project_contacts_phone`, `text`, required: false): Enter the contact phone number for the project.
13. **Project Budget Notes**
    (`project_budget_notes`, `note`, required: false): Add any additional notes about the project budget.
14. **Project Location Notes**
    (`project_location_notes`, `note`, required: false): Add any additional notes about the project location.
15. **Project Resources Notes**
    (`project_resources_notes`, `note`, required: false): Add any additional notes about the project resources.

## Tips

- Be as accurate and detailed as possible when filling out this form, as it's intended to gather crucial information for project planning and tracking.
- If a field is marked as optional, it's not required for the project, but it can still be beneficial for additional context.
- Ensure that you're filling out the correct form for the project at hand, considering its category and purpose.
