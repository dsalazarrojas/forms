## Most Active Member Voting Form - Help Guide
## Purpose
The Most Active Member Voting Form is used to recognize outstanding members within an organization by facilitating a streamlined voting process.

## How To Complete This Form

1.  To start, select the assigned tool that you are using for this voting process. Please select "chatjimmy" if you're using the chatjimmy tool.
2.  Next, enter a description of the member(s) you're voting for, or choose "Other" if it's not listed.
3.  Select the category for this voting form, such as "Survey Templates" or "Event Registration Forms."
4.  Choose the ID of the form you're using for this voting process, such as "1198" or "24087."
5.  Enter the name of the file that will be generated as output.
6.  Select the format for the output file, such as "yaml."
7.  To prevent overwriting an existing file, you can select "Other" as the format.
8.  Finally, enter the path where you want the output file to be saved.

## Field-by-Field Explanation

* **Assigned Tool** (`assigned_tool`, `select_one`, required): Select the tool you are using for this voting process. This is the tool that will be assigned to handle the voting process.
* **Description** (`description`, `text`, optional): Enter a description of the member(s) you're voting for. This will provide context for the voting process.
* **Category** (`category`, `select_multiple`, required): Select the category for this voting form, such as "Survey Templates" or "Event Registration Forms."
* **Form IDs** (`form_ids`, `select_multiple`, required): Choose the ID of the form you're using for this voting process, such as "1198" or "24087."
* **Output File** (`output_file`, `text`, optional): Enter the name of the file that will be generated as output.
* **Output File Name** (`output_file_name`, `text`, optional): Enter the name of the file that will be generated as output.
* **Output File Format** (`output_file_format`, `select_one`, required): Select the format for the output file, such as "yaml."
* **Output File Path** (`output_file_path`, `text`, optional): Enter the path where you want the output file to be saved.
* **Overwrite Existing File** (`output_file_overwrite`, `text`, optional): To prevent overwriting an existing file, you can select "Other" as the format.
* **Remove Existing File** (`output_file_remove`, `text`, optional): Select to remove an existing file, if present.

**Tips:** Ensure that you enter accurate information for the assigned tool, category, and form ID to prevent errors in the voting process.
