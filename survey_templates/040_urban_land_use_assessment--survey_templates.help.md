# Urban Land Use Assessment - Help Guide

## Purpose
The Urban Land Use Assessment form is designed to collect data on land use, zoning status, and project status of each parcel of land in a given area. This data will be used by land use and zoning officials to make informed decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on each page to access the corresponding section of the form.
2. Enter the required information for each section.
3. Click "Submit" to save your answers.

## Field-by-Field Explanation

* **Parcel Details** (`parcel_details`, `note`, optional): This section is a brief description of the parcel of land being assessed. Enter any relevant information about the parcel, such as its size, location, or any notable features.
* **Land Use** (`land_use`, `select_one`, required): This field asks whether the land is currently being used for a specific purpose, such as residential, commercial, or industrial. Select the option that best describes the current land use.
* **Zoning Status** (`zoning_status`, `select_one`, required): This field asks about the current zoning status of the land. Select the option that best describes the current zoning status.
* **Parcel Observations** (`parcel_observations`, `note`, optional): This section is for any additional observations or notes about the parcel. Enter any relevant information that does not fit into any of the other fields.
* **Land Use and Zoning** (`land_use_zoning`, `note`, optional): This section is for any additional information about land use and zoning that does not fit into any of the other fields.
* **Parcel Use** (`parcel_use`, `select_multiple`, required): This field asks about the current use of the parcel. Select all the options that apply.
* **Project Status** (`project_status`, `select_one`, required): This field asks about the current project status. Select the option that best describes the current status.
* **Project Notes** (`project_notes`, `note`, optional): This section is for any additional information about the project. Enter any relevant notes or observations.
* **Zoning Regulations** (`zoning_regulations`, `select_multiple`, optional): This field asks about the current zoning regulations applicable to the parcel. Select all the options that apply.
* **Zoning Variances** (`zoning_variances`, `select_multiple`, optional): This field asks about any zoning variances granted to the parcel. Select all the options that apply.
* **Land Use Restrictions** (`land_use_restrictions`, `select_multiple`, optional): This field asks about any land use restrictions applicable to the parcel. Select all the options that apply.
* **Parcel Boundaries** (`parcel_boundaries`, `select_multiple`, optional): This field asks about the parcel boundaries. Select all the options that apply.
* **Adjacent Parcel Use** (`adjacent_parcel_use`, `select_multiple`, optional): This field asks about the use of adjacent parcels. Select all the options that apply.
* **Project Contacts** (`project_contacts`, `select_multiple`, optional): This field asks about the project contacts. Select all the options that apply.
* **Project Contacts Email** (`project_contacts_email`, `email`, required): Enter the email address of the project contacts.
* **Project Contacts Phone** (`project_contacts_phone`, `text`, required): Enter the phone number of the project contacts.
* **Project Contacts Address** (`project_contacts_address`, `select_one`, optional): This field asks about the project contacts' address. Select the option that best describes the location.
* **Project Contacts Notes** (`project_contacts_notes`, `note`, optional): This section is for any additional information about the project contacts. Enter any relevant notes or observations.
* **Parcel Owner** (`parcel_owner`, `select_one`, optional): This field asks about the parcel owner. Select the option that best describes the ownership status.
* **Parcel Owner Notes** (`parcel_owner_notes`, `note`, optional): This section is for any additional information about the parcel owner. Enter any relevant notes or observations.
* **Zoning Notes** (`zoning_notes`, `note`, optional): This section is for any additional information about zoning. Enter any relevant notes or observations.
* **Project Status Date** (`project_status_date`, `date`, required): Enter the date of the current project status.
* **Project Status Time** (`project_status_time`, `time`, optional): Enter the time of the current project status.
* **Project Status Notes** (`project_status_notes`, `note`, optional): This section is for any additional information about the project status. Enter any relevant notes or observations.
* **Other Project Status Notes** (`project_status_other`, `note`, optional): This section is for any additional information about the project status that does not fit into any of the other fields. Enter any relevant notes or observations.

## Tips
* Enter accurate and complete information for each field to ensure the most accurate assessment of land use and zoning in the area.
* If a field does not apply to the parcel, select "No" or enter "N/A" if there is no information available.
* Use the provided examples to help guide your answers.
* Review the completed form for any errors or inconsistencies before submitting.
