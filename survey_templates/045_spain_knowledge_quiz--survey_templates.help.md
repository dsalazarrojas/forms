# spain_knowledge_quiz - Help Guide
## Purpose
The "spain_knowledge_quiz" form is designed to collect user responses for a quiz related to Spain.

## How To Complete This Form
To complete this form, follow these steps:
1. Answer each question on the provided page as accurately as possible.
2. Use the available options for select-type fields (e.g., select one, select multiple) to choose the most suitable answer.
3. For date and time fields, enter the correct date and time in the requested format (e.g., YYYY-MM-DD, HH:MM AM/PM).
4. For the note field, provide any additional information or comments that you want to associate with your response.
5. Once you have answered all questions, submit the form to save your responses.

## Field-by-Field Explanation
- **test_1** (number, optional): Enter a test-related number value.
- **select_1** (select one, optional): Choose one option from the available choices: barcelona, madrid.
- **select_2** (select multiple, optional): Select multiple options from the available choices: málaga, valencia, girona.
- **date_1** (date, optional): Enter a date in the YYYY-MM-DD format.
- **time_1** (time, optional): Enter a time in the 12-hour clock format (HH:MM AM/PM).
- **note_1** (note, optional): Enter any additional information or comments.
- **email_1** (email, optional): Enter a valid email address.
- **phone_1** (text, optional): Enter a phone number or any other text value.

## Tips
- Make sure to fill out all required fields (if any).
- If unsure about any question, try to answer it to the best of your ability.
- Double-check your responses for accuracy before submitting the form.
