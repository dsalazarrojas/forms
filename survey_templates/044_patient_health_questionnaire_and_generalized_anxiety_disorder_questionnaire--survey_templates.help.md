# Patient Health Questionnaire And Generalized Anxiety Disorder Questionnaire - Help Guide
## Purpose
This form is a patient health questionnaire and generalized anxiety disorder questionnaire used to gather information about a patient's health and symptoms of generalized anxiety disorder.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title of the form as requested.
2. Select the category of the form from the dropdown options.
3. Enter a description of the form as needed.
4. Select the assigned tool from the dropdown options.
5. If you want to save the form to a file, enter the file name.
6. Enter the form ID as requested.
7. Enter the form version as requested.
8. Enter the name of the person who created the form.

## Field-by-Field Explanation
* **Patient Health Questionnaire And Generalized Anxiety Disorder Questionnaire** (`form_title`, text, required: no): Enter the title of the questionnaire that will be used to identify the form.
* **Category** (`form_category`, select_one, required: no): Select the category of the questionnaire from the dropdown options. This will help identify where the form will be stored and used.
* **Description** (`form_description`, text, required: no): Enter a brief description of the questionnaire. This can include any additional information that will help identify the form.
* **Assigned Tool** (`form_assigned_tool`, select_multiple, required: no): Select the tool that will be used to administer the questionnaire. This can be a chatbot, other, or any other tool that will be used.
* **Output File** (`output_file`, text, required: no): If you want to save the form to a file, enter the file name here.
* **Form ID** (`form_id`, text, required: no): Enter a unique ID for the form as requested.
* **Form Version** (`form_version`, text, required: no): Enter the version of the form as requested.
* **Created By** (`form_created_by`, text, required: no): Enter the name of the person who created the form.

Please note that all fields are optional unless specified as required.
