# Halloween Trunk or Treat Event Interest Survey - Help Guide

## Purpose
This survey is designed to gather information about the Halloween trunk or treat event. It will help us understand who is interested in attending, what you are looking for in the event, and other important details.

## How To Complete This Form

1. Review the form carefully to ensure you answer each question accurately.
2. Fill out the form with as much detail as possible.
3. If you're unsure about any of the questions or fields, please ask the event organizer for clarification.

## Field-by-Field Explanation

* **Event Name** (`event_name`, `text`, required): This is the name of the event. Please enter the name of the event you are interested in.
* **Contact Email** (`contact_email`, `email`, optional): This is the email address of the person who is organizing the event. If you are the event organizer, please enter your email address.
* **Event Details** (`event_details`, `text`, required): Please provide any additional details about the event, such as its purpose, activities, or any other relevant information.
* **Event Organizer** (`event_organizer_name`, `text`, required): Please enter the name of the person or group organizing the event.
* **Parent Name** (`parent_name`, `text`, required): This is the name of the parent or guardian of the child participating in the event.
* **Child Names** (`child_names`, `select_multiple`, optional): Please select all the children participating in the event, or enter "Other" if they are not listed.
* **Event Date** (`event_date`, `date`, optional): This is the date of the event. If unsure, please check with the event organizer.
* **Start Time** (`event_start_time`, `time`, optional): This is the start time of the event. If unsure, please check with the event organizer.
* **End Time** (`event_ending_time`, `time`, optional): This is the end time of the event. If unsure, please check with the event organizer.
* **Event Location** (`event_location`, `text`, required): This is the location of the event. Please enter the address or venue name.
* **Event Description** (`event_description`, `text`, optional): This is a brief description of the event.
* **Event Notes** (`event_notes`, `text`, optional): Please enter any additional notes about the event.
* **Event Status** (`event_status`, `select_one`, required): Please select the status of the event, such as "Yes" or "No".
* **Event Comments** (`event_comments`, `text`, optional): This is a place to enter any additional comments about the event.
* **Parent Comments** (`parent_comments`, `text`, optional): This is a place to enter any comments from parents about the event.
* **Other Comments** (`other_comments`, `select_multiple`, optional): Please select all that apply from the list of comments.
* **Event Participants** (`event_participants`, `select_multiple`, optional): Please select all participants, or enter "Other" if they are not listed.
* **Event Participation** (`event_participation`, `select_multiple`, optional): Please select all participation methods, or enter "Other" if they are not listed.
* **Event Treats** (`event_treats`, `select_multiple`, required): Please select all treats that will be provided, or enter "Other" if they are not listed.
* **Public Parking** (`event_parking`, `select_one`, optional): Please select if public parking is available.
* **Parking Info** (`event_parking_info`, `text`, optional): Please enter any additional parking information.
* **Event Cost** (`event_cost`, `select_one`, required): Please select if the event is free, or "Other" if it's not.
* **Event Cost Notes** (`event_cost_notes`, `text`, optional): This is a place to enter any additional cost information.
* **Do Not Send Info** (`event_dont_send`, `select_one`, optional): Please select if you do not want to receive information.
* **Additional Info** (`event_additional_info`, `text`, optional): This is a place to enter any other information about the event.
