# Post Event Networking Feedback Questionnaire - Help Guide
## Purpose
This form is designed to gather feedback from event attendees about their post-event networking experience. The feedback gathered will help event planners improve their event planning and networking strategies.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Please select the correct options for each question.
2. If a question is not applicable to your experience, you can leave it blank.
3. If you have any additional comments or suggestions, please use the "Suggestions" field.
4. Please answer the questions based on your honest feedback.

## Field-by-Field Explanation
* **Event Planner**: Please select "Yes" if you were the event planner for this event.
* **Attended Event**: Please select all the days you attended this event.
* **Networking Opportunities**: Please rate the quality of networking opportunities you experienced at this event.
* **Feedback Score**: Please rate the overall feedback score for this event on a scale of 1-5.
* **Suggestions**: Please use this field to provide any additional comments or suggestions for improvement.
* **Comments**: Please use this field to provide any additional comments or feedback about the event.
* **Email**: Please enter your email address if you'd like to receive follow-up questions for future events.
* **Phone**: Please enter your phone number if you'd like to receive follow-up calls or messages.
* **How would you rate this event?**: Please rate the overall quality of the event on a scale of 1-5.
* **How would you rate the event planner?**: Please rate the quality of the event planner's performance on a scale of 1-5.
* **Comments about Event Planner**: Please provide any additional comments or feedback about the event planner.
* **Would you like to receive follow-up questions for future events?**: Please select "Yes" if you'd like to receive follow-up questions.
