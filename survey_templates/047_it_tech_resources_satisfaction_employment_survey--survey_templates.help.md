# IT Tech Resources Satisfaction Employment Survey - Help Guide
## Purpose
This form is designed to collect feedback on IT tech resources, including satisfaction, tool usage, and support.

## How To Complete This Form

To complete this form, follow these steps:

1. Select how satisfied you are with the IT tech resources provided.
2. Choose the category that best describes your role or team.
3. Indicate if you are currently using the assigned tool.
4. If using the tool, select the duration of time you have been using it.
5. Select the frequency at which you use the tool.
6. Rate your overall satisfaction with the tool and the support you receive.
7. Enter any additional comments or notes about your experience.

## Field-by-Field Explanation
* **IT Tech Resources** (`it_tech_resources`): This field allows you to rate your satisfaction with the IT tech resources provided. Choose one of the following options:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neither Satisfied Nor Dissatisfied
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Category** (`category`): This field allows you to select the category that best describes your role or team. Choose one or more of the following options:
	+ Category 1
	+ Category 2
	+ Category 3
* **Assigned Tool** (`assigned_tool`): This field indicates if you are currently using the assigned tool. Choose one of the following options:
	+ True
	+ False
* **Tool Used** (`tool_used`): This field allows you to select the tool you are currently using. Choose one of the following options:
	+ Tool 1
	+ Tool 2
	+ Tool 3
* **Tool Used Duration** (`tool_used_duration`): This field allows you to enter the duration in months you have been using the tool.
* **Tool Used Frequency** (`tool_used_frequency`): This field allows you to select how often you use the tool. Choose one of the following options:
	+ Daily
	+ Weekly
	+ Monthly
	+ Rarely
* **Satisfaction** (`satisfaction`): This field allows you to rate your overall satisfaction with the tool and support. Choose one of the following options:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neither Satisfied Nor Dissatisfied
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Team Members** (`team_members`): This field allows you to enter the number of team members who use the tool.
* **Support Frequency** (`support_frequency`): This field allows you to select how often you receive support. Choose one of the following options:
	+ Daily
	+ Weekly
	+ Monthly
	+ Rarely
* **Support Duration** (`support_duration`): This field allows you to enter the duration in months you receive support.
* **Overall Satisfaction** (`overall_satisfaction`): This field allows you to rate your overall satisfaction with the tool and support. Choose one of the following options:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neither Satisfied Nor Dissatisfied
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Notes** (`notes`): This field allows you to enter any additional comments or notes about your experience.
