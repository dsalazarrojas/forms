# structural_model_evaluation_survey - Help Guide
## Purpose
The "structural_model_evaluation_survey" form is designed to collect evaluations of structural models, assessing their suitability, quality, and characteristics.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you are familiar with the questions and fields.
2. For each field, provide clear and concise answers based on your evaluation of the structural model.
3. Use the provided fields to rate or score the model's suitability and characteristics.
4. Provide any additional comments or descriptions if necessary.

## Field-by-Field Explanation
### 1. Introduction
* **1. Introduction**: This field is not required, but it's a good place to provide any introductory information about the structural model being evaluated.

### 2. Structural Model Name
* **2. Structural Model Name**: Enter the name of the structural model being evaluated.

### 3. Structural Systems
* **3. Structural Systems**: Select all the structural systems that the model includes. This field is not required, but it helps the evaluator understand the model's scope.
* Options:
	+ True
	+ False

### 4. Model Rating
* **4. Model Rating**: Rate the model's suitability on a scale (not specified). This field is not required.
* Type: Number

### 5. Design Complexity
* **5. Design Complexity**: Rate the model's design complexity on a scale (not specified). This field is not required.
* Type: Number

### 6. Structural Model Suitability
* **6. Structural Model Suitability**: Describe the model's suitability. This field is not required.
* Type: Text

### 7. Structural Model Suitability Scale
* **7. Structural Model Suitability Scale**: Describe the model's suitability scale. This field is not required.
* Type: Text

### 8. Structural Model Suitability Scale Score
* **8. Structural Model Suitability Scale Score**: Describe the score for the model's suitability scale. This field is not required.
* Type: Text

### 9. Model Suitability
* **9. Model Suitability**: Describe the model's suitability. This field is not required.
* Type: Text

### 10. Model Suitability Score
* **10. Model Suitability Score**: Describe the score for the model's suitability. This field is not required.
* Type: Text

### 11. Model Suitability Description
* **11. Model Suitability Description**: Describe the model's suitability in detail. This field is not required.
* Type: Text

### 12. Structural Systems Score
* **12. Structural Systems Score**: Describe the score for the structural systems. This field is not required.
* Type: Text

### 13. Structural Systems Scale
* **13. Structural Systems Scale**: Describe the scale for the structural systems. This field is not required.
* Type: Text

### 14. Structural Systems Scale Score
* **14. Structural Systems Scale Score**: Describe the score for the structural systems scale. This field is not required.
* Type: Text

### 15. Comments
* **15. Comments**: Provide any additional comments or feedback about the structural model.
* Type: Text

## Tips
- Ensure you have a clear understanding of the structural model before completing this form.
- Use clear and concise language when providing answers and descriptions.
- Review the form carefully before submitting it.
