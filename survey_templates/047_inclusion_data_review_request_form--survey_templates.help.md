# Inclusion Data Review Request Form - Help Guide
## Purpose
This form is used to request and track reviews of inclusion data processes. It helps stakeholders gather necessary information for evaluation and decision-making purposes.

## How To Complete This Form
1. **Review Request**: 
	* Fill in the "Review Request" field with a brief description of the review request.
2. **Organization**: 
	* Enter the organization involved in the review process.
3. **Evaluation Needs**: 
	* Provide a list of specific evaluation needs for the review.
4. **Review Outcome**: 
	* Select "Yes" if the review is approved, "No" otherwise.
5. **Notes**: 
	* Add any additional comments or explanations about the review request.
6. **Internal Review Process**: 
	* Describe the internal review process for the inclusion data process.
7. **External Review Process**: 
	* Describe the external review process for the inclusion data process.
8. **Review Cycle**: 
	* Select a date for the review cycle.
9. **Review Due Date**: 
	* Set a deadline for the review completion.
10. **Internal Reviewer**: 
	* Enter the internal reviewer responsible for the review.
11. **External Reviewer**: 
	* Enter the external reviewer involved in the review process.
12. **Approval Status**: 
	* Select "Active" if the review is approved, "Inactive" otherwise.
13. **Approval Date**: 
	* Select a date for approval.
14. **Approved By**: 
	* Enter the person or department that approved the review.

## Field-by-Field Explanation

* **Review Request** (1, text, required): A brief description of the review request.
* **Organization** (2, text, required): The organization involved in the review process.
* **Evaluation Needs** (3, text, required): A list of specific evaluation needs for the review.
* **Review Outcome** (4, select_one, required): Select "Yes" if the review is approved, "No" otherwise.
* **Notes** (5, text, required): Additional comments or explanations about the review request.
* **Internal Review Process** (6, text, required): Describe the internal review process for the inclusion data process.
* **External Review Process** (7, text, required): Describe the external review process for the inclusion data process.
* **Review Cycle** (8, date, required): Select a date for the review cycle.
* **Review Due Date** (9, date, required): Set a deadline for the review completion.
* **Internal Reviewer** (10, text, required): Enter the internal reviewer responsible for the review.
* **External Reviewer** (11, text, required): Enter the external reviewer involved in the review process.
* **Approval Status** (12, select_one, required): Select "Active" if the review is approved, "Inactive" otherwise.
* **Approval Date** (13, date, required): Select a date for approval.
* **Approved By** (14, text, required): Enter the person or department that approved the review.

## Tips
* Ensure that you have necessary permissions and access controls to complete this form.
* Double-check the review cycle and due date for accuracy.
* If you need help or clarification, don't hesitate to reach out to the review team.
