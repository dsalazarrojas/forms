# Report Types Assessment - Help Guide
## Purpose
The Report Types Assessment form is used to categorize and prioritize reports based on their urgency and importance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of report you are assessing from the `report_types` field. This field is optional but helps to quickly categorize the report.
2. In the `report_categories` field, enter a brief description or keywords related to the report.
3. In the `report_priority` field, enter a numerical value indicating the priority of the report, with higher values indicating higher priority.
4. In the `assessment_date` field, select the date when the report was assessed.
5. In the `report_notes` field, enter any additional comments or information about the report.
6. In the `report_time_required` field, enter the estimated time required to complete the report.
7. In the `report_urgency` field, select if the report is urgent or not.
8. In the `report_frequency` field, select the frequency of the report, indicating how often it is produced.
9. In the `assigned_tool` field, select if a tool is required to complete the report.

## Field-by-Field Explanation
### report_types
* Label: `report_types` (select_one): *Select the type of report you are assessing from the dropdown menu.*
### report_categories
* Label: `report_categories` (text): *Enter a brief description or keywords related to the report.*
### report_priority
* Label: `report_priority` (number): *Enter a numerical value indicating the priority of the report, with higher values indicating higher priority.*
### assessment_date
* Label: `assessment_date` (date): *Select the date when the report was assessed.*
### report_notes
* Label: `report_notes` (text): *Enter any additional comments or information about the report.*
### report_time_required
* Label: `report_time_required` (time): *Enter the estimated time required to complete the report in hours.*
### report_urgency
* Label: `report_urgency` (select_one): *Select if the report is urgent or not.*
### report_frequency
* Label: `report_frequency` (select_multiple): *Select the frequency of the report, indicating how often it is produced.*
### assigned_tool
* Label: `assigned_tool` (select_one): *Select if a tool is required to complete the report.*
