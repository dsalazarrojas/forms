# post-update-satisfaction-check-in - Help Guide
## Purpose
This form is used to collect feedback from players on the satisfaction of a recent update for a game.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question honestly and thoroughly.
2. Provide clear and concise answers to each field.
3. Ensure that you are filling out this form for the correct update.

## Field-by-Field Explanation
### Player Feedback
* **Player Feedback** (`player_feedback`, text, optional): Share your general thoughts and feelings about the update.
### Satisfaction Rating
* **Satisfaction Rating** (`satisfaction_rating`, select_one, optional): Rate your satisfaction with the update on a scale of "Likely to recommend" to "Not likely to recommend".
### Favorite Feature
* **Favorite Feature** (`favorite_feature`, select_multiple, optional): Select all the features that you particularly enjoyed or found useful in the update.
### Least Favorite Feature
* **Least Favorite Feature** (`least_favorite_feature`, select_multiple, optional): Select all the features that you did not enjoy or found least useful in the update.
### Fix Priority
* **Fix Priority** (`fix_priority`, select_one, optional): Rate the priority of the bugs or issues that you experienced in the update, on a scale of "High" to "Low".
### Fix Plan
* **Fix Plan** (`fix_plan`, text, optional): Provide any suggestions or ideas for how you would fix the issues that you experienced in the update.
### Release Date
* **Release Date** (`release_date`, date, optional): Enter the release date of the update, if known.
### Update Date
* **Update Date** (`update_date`, date, optional): Enter the date of the latest update, if known.
### Update Duration
* **Update Duration** (`update_duration`, number, optional): Enter the length of time it took to complete the update, if known.
### Game Version
* **Game Version** (`game_version`, text, optional): Enter the version number of the game or update, if known.
### Player Questions
* **Player Questions** (`player_questions`, select_multiple, optional): Select all the questions that you found most relevant or useful in the update.

Tips: If you have any further feedback or questions, please feel free to include them in the "Player Feedback" field.
