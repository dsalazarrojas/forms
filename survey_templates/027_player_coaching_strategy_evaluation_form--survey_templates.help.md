# Player Coaching Strategy Evaluation Form - Help Guide
## Purpose
This form is used to collect feedback and evaluate the coaching strategy used during a coaching session with a player.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **Session Date** in the first field. This is the date on which the coaching session took place.
2. Enter the **Session Time** in the second field. This is the time on which the coaching session took place.
3. In the **Player Feedback** field, provide your feedback about the player's performance during the session.
4. In the **Coaching Strategy** field, describe the coaching strategy used during the session.
5. In the **Session Focus Areas**, select all areas that were focused on during the session (e.g., Focus Area 1, Focus Area 2, Focus Area 3).
6. In the **Player Coaching Style** field, select the player's coaching style used during the session (e.g., Style 1, Style 2, Style 3).
7. In the **Coaching Tactics** field, describe any coaching tactics used during the session.
8. In the **Additional Comments** field, provide any additional feedback or comments about the session.
9. In the **Player Coaching Strategy Implementation**, select all implementations of the coaching strategy used during the session (e.g., Implementation 1, Implementation 2, Implementation 3).
10. In the **Evaluation Form Completed By** field, enter the date on which this form was completed.
11. In the **Evaluation Form Completed At** field, enter the time on which this form was completed.

## Field-by-Field Explanation
* **Session Date** (id: 1, type: date): Enter the date on which the coaching session took place.
* **Session Time** (id: 2, type: time): Enter the time on which the coaching session took place.
* **Player Feedback** (id: 3, type: text): Provide feedback about the player's performance during the session.
* **Coaching Strategy** (id: 4, type: text): Describe the coaching strategy used during the session.
* **Session Focus Areas** (id: 5, type: select_multiple): Select all areas that were focused on during the session (e.g., Focus Area 1, Focus Area 2, Focus Area 3).
* **Player Coaching Style** (id: 6, type: select_one): Select the player's coaching style used during the session (e.g., Style 1, Style 2, Style 3).
* **Coaching Tactics** (id: 7, type: text): Describe any coaching tactics used during the session.
* **Additional Comments** (id: 8, type: text): Provide any additional feedback or comments about the session.
* **Player Coaching Strategy Implementation** (id: 9, type: select_multiple): Select all implementations of the coaching strategy used during the session (e.g., Implementation 1, Implementation 2, Implementation 3).
* **Evaluation Form Completed By** (id: 10, type: date): Enter the date on which this form was completed.
* **Evaluation Form Completed At** (id: 11, type: time): Enter the time on which this form was completed.
