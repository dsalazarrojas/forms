# file_extension_knowledge_survey - Help Guide
## Purpose
This form is designed to assess your level of knowledge about file extensions, including types, associations, levels of knowledge, common uses, confidence levels, and management skills.

## How To Complete This Form
1. Read the form carefully and ensure you understand each question.
2. Answer each question according to your experience and knowledge.
3. Be honest in your responses, as your input will help improve file management practices.

## Field-by-Field Explanation

* **file_types** (`select_one`): Choose the file type(s) you are most familiar with from the available options:
	+ ID3
	+ ID2
	+ ID1
* **file_extensions** (`select_multiple`): Select all file extensions you are familiar with:
	+ txt
	+ pdf
	+ docx
* **file_association** (`select_multiple`): Indicate your level of association with file extensions:
	+ True (highly associated)
	+ False (not associated)
	+ maybe (partially associated)
* **knowledge_level** (`select_one`): Rate your level of knowledge about file extensions:
	+ beginner
	+ intermediate
	+ advanced
* **file_management** (`text`): Describe your current practices and habits when handling files.
* **common_use** (`select_multiple`): Indicate where you use file extensions:
	+ personal
	+ work
	+ school
* **file_confidence** (`select_multiple`): Rate your confidence level in handling files:
	+ high
	+ medium
	+ low
* **filemanagement_skills** (`select_multiple`): Indicate whether you possess the following skills:
	+ True (yes)
	+ False (no)
* **filemanagement_confidence** (`select_one`): Rate your confidence level in handling files:
	+ high
	+ medium
	+ low

## Tips
- Be honest and thorough in your responses.
- If you are unsure about any question, choose the option that best represents your situation.
- If you have any questions or need help, contact form@gic.mx.
