# Science Fair Organization Feedback Questionnaire - Help Guide
## Purpose
This form is used to collect feedback on science fair events. Please provide your honest feedback to help us improve future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (\*).
2. Select the correct event type from the options provided.
3. Enter the event name, location, start and end dates and times, and duration.
4. Provide contact information for the event organizer.
5. Add any additional comments or feedback.

## Field-by-Field Explanation

* **Science Fair Event Name (\*)**: Enter the name of the event you are providing feedback on.
* **School Name (\*)**: Enter the name of the school hosting the event.
* **Event Type (\*)**: Select the type of event (High School, Middle School, College, or University).
* **Overall Satisfaction (\*)**: Rate your overall satisfaction with the event on a scale of 1-5.
* **Event Organization**: Describe how well the event was organized.
* **Event Location**: Enter the location of the event.
* **Event Start Date (\*)**: Enter the date and time the event started.
* **Event Start Time (\*)**: Enter the time of day the event started.
* **Event End Date (\*)**: Enter the date and time the event ended.
* **Event End Time (\*)**: Enter the time of day the event ended.
* **Event Duration (\*)**: Enter the length of the event in hours and minutes.
* **Feedback**: Provide any additional feedback or comments about the event.
* **Additional Comments**: Add any additional comments or notes about the event.
* **Contact Information (\*)**: Provide the name, phone number, and email address of the event organizer.
* **Email**: Enter a second email address for the event organizer (optional).
* **Phone**: Enter a second phone number for the event organizer (optional).
* **Comments 2**: Add any additional comments or notes about the event from the second contact person.
* **Event Organizer**: Enter the name of the event organizer.
* **Event Organizer Phone**: Enter the phone number of the event organizer.
* **Event Organizer Email**: Enter the email address of the event organizer.
* **Event Organizer Notes**: Add any additional notes or comments about the event from the event organizer.
* **Event Organizer Comments**: Add any additional comments or notes from the event organizer.
* **Comments**: Add any additional comments or notes about the event.
* **Phone 2**: Enter a second phone number for the event organizer (optional).
* **Email 2**: Enter a second email address for the event organizer (optional).
* **Comments 2**: Add any additional comments or notes about the event.
* **Event Organizer Phone 2**: Enter a second phone number for the event organizer (optional).
* **Event Organizer Email 2**: Enter a second email address for the event organizer (optional).
* **Event Organizer Comments 2**: Add any additional comments or notes from the event organizer.
