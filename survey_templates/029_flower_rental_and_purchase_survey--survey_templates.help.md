# ประก prophets And Purchase survey - Help Guide
## Purpose
This survey aims to understand how you usually buy and rent flowers for different occasions and preferences.

## How To Complete This Form
1. Select the way you usually buy flowers from the options provided in the first question.
2. Choose the occasion for which you are buying/renting flowers from the available options.
3. Select the type of flower you prefer from the provided options.
4. If you are renting flowers, indicate the maximum price you would be willing to pay.
5. If you are buying flowers, indicate the maximum price you would be willing to pay.
6. For both rental and purchase options, specify the number of flowers you would like to have.
7. For both rental and purchase options, specify the duration for which you would like to have the flowers.
8. For rental options, check all services you would like to have with your rental (e.g., delivery, pickup, in-store).
9. For purchase options, check all services you would like to have with your purchase.
10. Finally, add any additional notes you have about your preferences.

## Field-by-Field Explanation
* **How do you usually buy flowers**:
	+ Select One: Rent (if you rent flowers), Buy (if you buy flowers), or Other (if you don't buy or rent flowers)
* **What is the occasion**:
	+ Select Multiple: Choose all that apply (Wedding, Birthday, Funeral, Other)
* **What type of flower do you like**:
	+ Select One: Rose, Liliu, Carnation (Note: Please be aware that "Carnation" might be misspelled as "Carnation goals" but it seems to be a legitimate option)
* **How much would you pay for renting flowers**:
	+ Number: Enter a number that represents the maximum price you would pay for renting flowers.
* **How much would you pay for buying flowers**:
	+ Number: Enter a number that represents the maximum price you would pay for buying flowers.
* **How many flowers would you like to rent**:
	+ Number: Enter a number that represents the number of flowers you would like to rent.
* **How many flowers would you like to buy**:
	+ Number: Enter a number that represents the number of flowers you would like to buy.
* **How long would you like to rent flowers for**:
	+ Date: Enter a date that represents the duration for which you would like to rent flowers.
* **How long would you like to buy flowers for**:
	+ Date: Enter a date that represents the duration for which you would like to buy flowers.
* **Would you like any services with your rental**:
	+ Select Multiple: Check all that apply (Delivery, Pickup, In-store, Other)
* **Do you like any services with your purchase**:
	+ Select Multiple: Check all that apply (Delivery, Pickup, In-store, Other)
* **Additional notes**:
	+ Note: Enter any additional comments or preferences you have about your flower-buying and renting habits.

Note: Please be precise and honest with your answers, as this will help us better understand your preferences.
