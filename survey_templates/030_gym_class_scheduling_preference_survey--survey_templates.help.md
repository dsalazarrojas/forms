# Gym Class Scheduling Preference Survey - Help Guide

## Purpose
The Gym Class Scheduling Preference Survey is designed to collect your preferences for scheduling gym classes. Your responses will help create a plan that best suits your needs and preferences.

## How To Complete This Form

1. Read each question carefully and select the most suitable option for your preferences.
2. Make sure to provide as much information as possible, as it will help us create a more accurate scheduling plan for you.
3. If a question does not apply to you, please select the "Not Applicable" option.
4. Use the "Additional Comments" field to provide any further information that you think is relevant to your preferences.

## Field-by-Field Explanation

* **Class Type** (`class_type`, select_one): This question asks about the type of classes you usually attend. Please select one of the options:
	+ Yoga
	+ Strength Training
	+ Cardio
* **Class Frequency** (`class_frequency`, select_multiple): This question asks about the frequency of classes you prefer. Please select as many options as apply to you:
	+ Monday
	+ Tuesday
	+ Wednesday
	+ Thursday
	+ Friday
	+ Saturday
	+ Sunday
* **Class Time** (`class_time`, select_one): This question asks about the time of day you prefer for classes. Please select one of the options:
	+ Morning
	+ Afternoon
	+ Evening
* **Preferred Time** (`preferred_time`, time): This question asks about your preferred time for classes. Please enter a time in 24-hour format (e.g., 09:00, 13:00, etc.).
* **Start Time** (`start_time`, time): This question asks about your preferred start time for classes. Please enter a time in 24-hour format (e.g., 09:00, 13:00, etc.).
* **End Time** (`end_time`, time): This question asks about your preferred end time for classes. Please enter a time in 24-hour format (e.g., 09:00, 13:00, etc.).
* **Preferred Days** (`preferred_days`, select_multiple): This question asks about the days of the week you prefer for classes. Please select as many options as apply to you:
	+ Monday
	+ Tuesday
	+ Wednesday
	+ Thursday
	+ Friday
	+ Saturday
	+ Sunday
* **Class Duration** (`class_duration`, number): This question asks about the duration of classes you prefer. Please enter a number in minutes.
* **Availability** (`availability`, select_one): This question asks about your availability for classes. Please select one of the options:
	+ Always
	+ Mostly
	+ Rarely
	+ Never
* **Morning Availability** (`morning_availability`, select_one): This question asks about your availability for morning classes. Please select one of the options:
	+ Always
	+ Mostly
	+ Rarely
	+ Never
* **Afternoon Availability** (`afternoon_availability`, select_one): This question asks about your availability for afternoon classes. Please select one of the options:
	+ Always
	+ Mostly

	+ Never
* **Evening Availability** (`evening_availability`, select_one): This question asks about your availability for evening classes. Please select one of the options:
	+ Always
	+ Mostly

	+ Never
* **Available Days** (`available_days`, select_multiple): This question asks about the days of the week you are available for classes. Please select as many options as apply to you:
	+ Monday
	+ Tuesday
	+ Wednesday
	+ Thursday
	+ Friday
	+ Saturday

* **Class Limit** (`class_limit`, number): This question asks about the maximum number of classes you prefer per week. Please enter a number.
* **Morning Limit** (`morning_limit`, number): This question asks about the maximum number of morning classes you prefer per week. Please enter a number.
