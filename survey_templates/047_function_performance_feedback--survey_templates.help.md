# Function Performance Feedback - Help Guide
## Purpose
## How To Complete This Form
You can complete this form in a few steps:

1.  Fill in the title of the function or feature you are providing feedback on.
2.  Select the type of event you are providing feedback on (e.g. Meeting, Training, Other).
3.  Provide the date when the event took place.
4.  Rate the overall performance of the function or feature (from 1 to 5).
5.  Add any additional comments or feedback you have on the performance.
6.  Specify if you attended the event or not.
7.  Choose how you would like to be followed up on (if at all).
8.  Provide an expected time frame when you would like to be followed up.
9.  Add a follow-up message (if any).
10.  Add any comments about the event.

## Field-by-Field Explanation
*   **Form Title** (`form_title`, text, optional): This is the title of the function or feature you are providing feedback on.
*   **Event Type** (`event_type`, select_one, required): This is the type of event you are providing feedback on. Choose from Meeting, Training, or Other.
*   **Date** (`date`, date, required): Provide the date when the event took place.
*   **Overall Rating** (`overall_rating`, number, required): Rate the overall performance of the function or feature (from 1 to 5).
*   **Additional Feedback** (`additional_feedback`, text, optional): Add any additional comments or suggestions on how to improve the performance.
*   **Attended** (`attended`, select_multiple, required): Specify if you attended the event or not.
*   **Follow Up** (`follow_up`, select_one, required): Choose how you would like to be followed up on (if at all). Options include Follow up via phone, Follow up via email, Follow up in person, or No follow up.
*   **Follow Up Timeframe** (`follow_up_timeframe`, date, optional): Provide an expected time frame when you would like to be followed up.
*   **Follow Up Message** (`follow_up_message`, text, optional): Add a follow-up message (if any).
*   **Comments for Event** (`comments_for_event`, text, optional): Add any comments about the event.
*   **Other** (`other`, text, optional): If you selected Other in Event Type, provide a brief description of the event.
*   **Meeting** (`meeting`, text, optional): If you selected Meeting in Event Type, provide a brief description of the meeting.
*   **Training** (`training`, text, optional): If you selected Training in Event Type, provide a brief description of the training.
*   **Follow Up Method** (`follow_up_method`, select_multiple, optional): Select the method you prefer for follow-up (if at all). Options include Follow up via email, Follow up via phone, Follow up in person.
*   **Follow Up Message** (`follow_up_message`, text, optional): Add a follow-up message (if any).
