# Startup Mentorship Program Impact Evaluation Form - Help Guide
## Purpose
The Startup Mentorship Program Impact Evaluation Form is used to collect information about the startup mentorship program. This information will help evaluate the program's impact, outcomes, and effectiveness.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by reading the introduction page, which provides background information about the program.
2. Answer the questions about the program's goals, type, duration, and number of participants.
3. Describe the program's outcomes and impact.
4. Choose the criteria for evaluation and the frequency of submission and evaluation.
5. Select the method of evaluation (if applicable).

## Field-by-Field Explanation

* **Mentorship Goals** (`mentorship_goals`, text, required): Please describe the goals of the mentorship program.
* **Program Type** (`program_type`, select_one, required): Please select the type of program (Accelerator, Incubator, Co-working space).
* **Program Duration** (`program_duration`, number, required): Please enter the duration of the program.
* **Number of Participants** (`number_of_participants`, number, required): Please enter the number of participants in the program.
* **Program Outcomes** (`program_outcomes`, text, required): Please describe the outcomes of the program.
* **Program Impact** (`program_impact`, text, optional): Please describe the impact of the program (if any).
* **Evaluation Criteria** (`evaluation_criteria`, select_multiple, optional): Please select the criteria for evaluation (Communication, Quality of Support, Quality of Feedback, Effectiveness, Others).
* **Submission Frequency** (`submission_frequency`, select_one, required): Please select the frequency of submission (Daily, Weekly, Bi-weekly, Monthly).
* **Evaluation Frequency** (`evaluation_frequency`, select_one, required): Please select the frequency of evaluation (Daily, Weekly, Bi-weekly, Monthly).
* **Evaluation Method** (`evaluation_method`, select_multiple, optional): Please select the method of evaluation (Self, Peer, Both).
