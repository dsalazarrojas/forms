# Game Feature Specification Survey - Help Guide
## Purpose
The Game Feature Specification Survey is a form used by game developers and team members to gather information about game features and their priorities. This form helps the team to better understand what features are important to players and how teams perform.

## How To Complete This Form
1. Please select "Team A" or "Team B" from the dropdown menu for "Game Teams".
2. For "Players", select all the options that apply to you (e.g., "Yes" for players you have interacted with recently, "No" for players you have not).
3. Select one of the options for "Player Experience" that best describes your experience with the game.
4. For "Feature Priorities", select all the options that apply to you (e.g., "Yes" for features you think are high priority).
5. Please enter your feedback in the "Feedback" field. This is an open-ended question, so feel free to provide as much detail as you'd like.
6. For "Game Updates", please enter any updates you think are needed for the game.
7. For "Product Decisions", please enter any product decisions or changes you think are needed.
8. In the "Feature Specifications" field, please provide a brief description of the game feature in question.
9. For "Player Pain Points", "Team Pain Points", "Game Performance", and "Product Performance" fields, please enter any issues or areas for improvement you've noticed.
10. For "JAT" and "JAT2" fields, please enter the relevant dates and times (if applicable).

## Field-by-Field Explanation

* **Game Teams** (Team A/ Team B): Select the team you are part of (e.g., Team A or Team B).
* **Players** (Yes/No): Select all the options that apply to you (e.g., "Yes" for players you have interacted with recently, "No" for players you have not).
* **Player Experience** (Excellent/Good/Fair): Select the option that best describes your experience with the game.
* **Feature Priorities** (Yes/No): Select all the options that apply to you (e.g., "Yes" for features you think are high priority).
* **Feedback**: Enter any feedback or comments you have about the game.
* **Game Updates**: Enter any updates you think are needed for the game.
* **Product Decisions**: Enter any product decisions or changes you think are needed.
* **Feature Specifications**: A brief description of the game feature in question.
* **Player Pain Points**, **Team Pain Points**, **Game Performance**, **Product Performance**: Enter any issues or areas for improvement you've noticed.
* **JAT** (Date): Enter the relevant dates (if applicable).
* **JAT2** (Time): Enter the relevant times (if applicable).
