# Supermarkets Cabinet Survey - Help Guide
## Purpose
This form is designed for supermarket employees to report on the availability and condition of various products, as well as gather some demographic information about the person filling out the survey. This data will help the supermarket management team make informed decisions about inventory management and customer service.

## How To Complete This Form

1. Read each question carefully and answer accordingly.
2. Select the correct option for each question, or type in your answer if it's a text field.
3. Make sure to fill out all required fields, as indicated by the "required" label in each field.
4. Use the "Submit" field to submit your completed survey.

## Field-by-Field Explanation
* **Layout Questions**: Answer this question with a brief description of the store layout, including the number of sections or departments, and any notable features.
* **product-1**: Please select "Yes" if you have product 1 available, "No" otherwise.
* **product-2**: Please select "Yes" if you have product 2 available, "No" otherwise.
* **product-3**: Please select "Yes" if you have product 3 available, "No" otherwise.
* **product-4**: Please select "Yes" if you have product 4 available, "No" otherwise.
* **Comments**: Use this field to provide any additional comments or notes about the store's current state.
* **Date/Time of Visit**: Enter the date and time of your visit to the store.
* **Employee ID**: Enter your employee ID number for identification purposes.
* **E-mail**: Enter your work email address for contact purposes.
* **Phone**: Enter your work phone number for contact purposes.
* **Submit**: Select "Yes" if you are submitting the survey, "No" if you are not.
