# Cutover Day Feedback Survey - Help Guide
## Purpose
The Cutover Day Feedback Survey is a form designed to gather information from end users on their experience with a cutover day. This form helps the project team to understand what went well and what didn't, and to identify areas for improvement for future cutover days.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question thoroughly and honestly.
2. If a question does not apply to you, answer "Not Applicable" in the field provided.
3. For questions with multiple options, select all that apply.
4. Provide as much detail as possible in the text fields.

## Field-by-Field Explanation

* **Experience** (1):
	+ This field is a text input where you can describe your overall experience with the cutover day.
* **Communication** (2):
	+ This question has two options, "Yes" and "No". If you felt the communication from the project team was adequate, select "Yes". If you felt it was not, select "No".
* **Issues** (3):
	+ This field is a text input where you can describe any issues you encountered during the cutover day.
* **Improvements** (4):
	+ This question has two options, "Yes" and "No". If you think there are improvements that need to be made for future cutover days, select "Yes". If you do not, select "No".
* **Issues Details** (5):
	+ This field is a text input where you can provide more details about any issues you encountered.
* **Communication Details** (6):
	+ This field is a text input where you can provide more details about your experience with communication from the project team.

## Tips
* Please answer all questions thoroughly and honestly.
* If you have any further comments or suggestions, please provide them in the text fields.
* If you need help or have any questions, do not hesitate to contact the project team.
