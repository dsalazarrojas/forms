# Manifestation Journey Survey - Help Guide

## Purpose
The Manifestation Journey Survey is a tool used to gather information about a client's goals, progress, and experiences with a program or project. This data will help us identify areas where they need support, guidance, or resources to achieve their objectives.

## How To Complete This Form

To complete this form, please follow these steps:

1. Answer each question carefully and honestly, providing as much detail as possible.
2. For select_multiple questions (e.g., Next Steps Plans), choose all the relevant options that apply to you.
3. For open-ended questions (e.g., Challenges Faced), provide as much context as you can.

## Field-by-Field Explanation

* **Client Goals** (`client_goals`): Describe your goals for this program or project.
* **Manifestation Journey Start** (`manifestation_journey_start`): Explain how you started this program or project.
* **Manifestation Journey End** (`manifestation_journey_end`): Describe where you are at the end of the program or project.
* **Progress Checkins** (`progress_checkins`): Enter the number of progress checkins you've completed during this program or project.
* **Challenges Faced** (`challenges_faced`): Share any challenges you've faced while working on this program or project.
* **Wins Celebrated** (`wins_celebrated`): List any wins or accomplishments you've celebrated during this program or project.
* **Program Support** (`program_support`): Select the type of support you've received from the program (e.g., Regular Checkins, Private Chat, Phone Call, Video Call).
* **Additional Comments** (`additional_comments`): Add any additional comments or thoughts about your experience with the program or project.
* **Email Follow-up** (`email_follow_up`): Enter the email follow-up you'd like to schedule.
* **Phone Follow-up** (`phone_follow_up`): Enter the phone follow-up you'd like to schedule.
* **Other Follow-up** (`other_follow_up`): If other follow-up options are required, please specify them here.
* **Next Steps Plans** (`next_steps_plans`): Describe your next steps plans for this program or project.
* **Program Commitment** (`program_commitment`): Describe your level of commitment to the program or project.
* **Program Commitment Level** (`program_commitment_level`): Rate your level of commitment to the program or project on a scale of 1-5.
* **Program Commitment Level Other** (`program_commitment_level_other`): If your commitment level is not listed, please describe it here.
* **Coaching Support** (`coaching_support`): Describe any coaching support you've received.
* **Additional Resources** (`additional_resources`): List any additional resources you've used or would like to use.
* **Additional Resources Other** (`additional_resources_other`): If additional resources are required, please specify them here.
* **Next Steps Plans Details** (`next_steps_plans_details`): Describe any other details about your next steps plans.
* **Program Commitment Level Other Details** (`program_commitment_level_other_details`): If you've chosen "Other" as your commitment level, please provide more details here.
* **Coaching Support Other** (`coaching_support_other`): If you've received coaching support, but it's not listed, please describe it here.
* **Additional Resources Other 2** (`additional_resources_other_2`): If you've used additional resources, but they're not listed, please specify them here.
* **Form Completion** (`form_completion`): Enter the date and time you completed this form.
* **Form Completion Time** (`form_completion_time`): Enter the time you spent completing this form.
* **Form Completion Time Other** (`form_completion_time_other`): If the time you spent on this form is not typical, please describe it here.
