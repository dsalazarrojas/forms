# Video Game Survey - Help Guide

## Purpose
The Video Game Survey is a data collection form designed to gather information about your gaming preferences and habits.

## How To Complete This Form

To complete this form, follow the steps below:

1. Enter your User Name, a name to identify you in the "User Name" field.
2. Select your Gamer Type in the "Gamer Type" field. This will help us understand your identity as a gamer.
3. Indicate your favorite game genres, platforms, and qualities by selecting all that apply in their respective fields.
4. For fields that allow free-text responses (Favorite Game Notes, Other Game Preferences), enter a brief description of your preferences.
5. If you have a preferred game platform or console, select "Yes" in the respective field.
6. Enter your favorite game release date and time in their respective fields.

## Field-by-Field Explanation
* **User Name**: Enter your name to identify yourself in our records.
* **Gamer Type**: Select one option that best describes your identity as a gamer: Casual, Hardcore, or Social.
* **Favorite Game Genre**: Select all that apply. For example, Adventure, Action, Role-Playing.
* **Favorite Game Platform**: Select "Yes" if you have a preferred platform.
* **Favorite Game Console**: Select "Yes" if you have a preferred console.
* **Favorite Game Quality**:
	+ **Video Quality**: Select one: High, Medium, Low.
	+ **Music Quality**: Select one: High, Medium, Low.
	+ **Favorite Story Quality**: Select one: High, Medium, Low.
	+ **Favorite Graphic Quality**: Select one: High, Medium, Low.
	+ **Favorite Sound Quality**: Select one: High, Medium, Low.
	+ **Favorite Game Duration**: Select one: Short, Medium, Long.
* **Preferred Game Speed**: Select one: Fast, Average, Slow.
* **Favorite Game Difficulty**: Select one: Easy, Medium, Hard.
* **Favorite Game Price**: Enter a number (optional).
* **Favorite Game Language**: Select all that apply. For example, English, Spanish, French.
* **Favorite Game Rating**: Select all that apply. For example, Good, Fair, Bad.
* **Favorite Game Release Date**: Enter a date in the format MM/DD/YYYY.
* **Favorite Game Time**: Enter a time in the format HH:MM.
* **Favorite Game Notes**: Enter a brief description of your preferences.
* **Other Game Preferences**: Enter any other preferences not listed above.
* **Game Preferences**: Enter a brief description of your game preferences.
* **Other**: Enter any other game preferences.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
