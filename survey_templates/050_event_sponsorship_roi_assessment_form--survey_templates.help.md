# Event Sponsorship ROI Assessment Form - Help Guide
## Purpose
This form is designed to help event organizers or sponsors assess the effectiveness of an event sponsorship. It gathers information about the main sponsorship outcome, ROI category, sponsor return on investment, event sponsorship ROI, and sponsor feedback.

## How To Complete This Form

To complete this form, follow these steps:

1.  Read through each field carefully and answer accordingly.
2.  Answer the questions based on your personal experience or knowledge about the event sponsorship.
3.  Ensure you answer all required fields (indicated by \*).

## Field-by-Field Explanation

*   **What's the main sponsorship outcome?** (`event_sponsorship_assessment`, `text`, \*): This field asks you to briefly describe the main outcome of the sponsorship. This could be, for example, increased visibility, brand awareness, or sales generated.
*   **Main Sponsorship Outcome** (`main_sponsorship_outcome`, `select_one`, \*): Please select the main outcome of the sponsorship. Choose the option that best describes the outcome.
    *   'Yes': This option means the main outcome was positive.
    *   'No': This option means the main outcome was not positive.
*   **ROI Category** (`roi_category`, `select_multiple`, \*): Select all that apply for the ROI category. This field is used to categorize the ROI into different areas. For example, 'Yes' for increased sales and 'No' for increased awareness.
    *   'Yes': This option means the ROI was positive in this category.
    *   'No': This option means the ROI was not positive in this category.
*   **Sponsor Return On Investment** (`sponsor_return_on_investment`, `number`, \*): This field is used to estimate the sponsor's return on investment. Enter the monetary value of the ROI.
*   **Event Sponsorship ROI** (`event_sponsorship_roi`, `number`, \*): This field is used to estimate the total ROI of the event sponsorship. Enter the monetary value of the ROI.
*   **Sponsor Feedback** (`sponsor_feedback`, `text`, \*): This field is used to gather any feedback or comments about the sponsor. This could include positive or negative feedback about the sponsorship experience.
