# Project Success Feedback Survey Form - Help Guide
## Purpose
The **Project Success Feedback Survey Form** is a tool to collect feedback from project team members on the success of a project. This form is designed to gather information about the project's goals, project manager's responsibilities, and overall project experience. The feedback collected through this form will help us to identify areas of improvement and make informed decisions for future projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project title in the **project** field.
2. Answer the question "What was the project goal?" in the **answer 1** field.
3. Answer the question "What was the project manager's responsibilities?" in the **answer 2** field.
4. Provide any additional comments about the project in the **comments** field.
5. Enter your email address in the **email** field.
6. Provide your phone number in the **phone** field.
7. Add any additional comments about the project in the **project comments** field.

## Field-by-Field Explanation
* **project**: Enter the title of the project you are providing feedback on.
* **answer 1**: Describe the project goal.
* **answer 2**: Describe the project manager's responsibilities.
* **comments**: Provide any additional comments about the project.
* **email**: Enter your email address so we can contact you if needed.
* **phone**: Enter your phone number for further contact.
* **project comments**: Add any additional comments about the project experience.
* **project_manager**: Enter the name of the project manager.
* **what was the project goal**: Describe the project goal.
* **what was the project manager responsibilities**: Describe the project manager's responsibilities.
* **project_success_feedback_survey_form**: This field is not required and not visible to the user, it's part of the form's internal identification.
* **answer_1**: This field is meant to capture a descriptive answer about the project goal.
* **answer_2**: This field is meant to capture a descriptive answer about the project manager's responsibilities.

## Tips
* Please answer all the required fields to help us collect accurate and complete feedback.
* If you have any concerns or questions about the form, feel free to contact us.
* If you are providing feedback on a confidential project, please keep the answers and comments confidential.

Note: This form is designed to be simple and easy to use. If you have any questions or need further clarification on any field, please don't hesitate to reach out.
