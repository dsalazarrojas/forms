# Bar Build Project Survey - Help Guide
## Purpose
This survey is designed to gather feedback about the performance of a bar build project. It collects information on project details, progress, and contractor performance.

## How To Complete This Form

1. **Survey Date**: Select the date this survey was conducted.
2. **Project Name**: Enter the name of the bar build project.
3. **Establishment Name**: Enter the name of the bar or restaurant.
4. **Project Location**: Enter the address of the project.
5. **Your Name**: Enter your full name.
6. **Your Role**: Choose the role you have in the project (e.g., Owner, Manager, Project Manager, Contractor, Architect, Designer, or Other).
7. **Email Address**: Enter your contact email address.
8. **Project Start Date**: Select the date the project began.
9. **Project Completion Date**: Select the date the project was completed.
10. **Was Project Completed On Schedule?**: Answer whether the project was completed on schedule.
11. **Was Project Completed On Budget?**: Answer whether the project was completed on budget.
12. **Were There Scope Changes?**: Choose whether there were changes made to the project's scope.
13. **Overall Contractor Performance**: Rate the contractor's performance.
14. **Quality of Workmanship**: Rate the quality of work done.
15. **Communication and Responsiveness**: Rate the contractor's communication and responsiveness.
16. **Timeliness and Punctuality**: Rate the contractor's timeliness.
17. **Safety Compliance**: Rate the contractor's safety compliance.
18. **Problem Resolution**: Rate how well issues were resolved by the contractor.
19. **Any Issues or Problems Encountered?**: Describe any problems you faced during the project.
20. **Would You Recommend This Contractor?**: Choose whether you would recommend the contractor.
21. **Areas for Improvement**: Suggest areas where the contractor could improve.
22. **Additional Comments**: Enter any other feedback or comments.

## Field-by-Field Explanation
* **Survey Date** (`survey_date`, date, required): Select the date this survey was conducted.
* **Project Name** (`project_name`, text, required): Enter the name of the bar build project.
* **Establishment Name** (`establishment_name`, text, required): Enter the name of the bar or restaurant.
* **Project Location** (`location`, text, required): Enter the address of the project.
* **Your Name** (`respondent_name`, text, required): Enter your full name.
* **Your Role** (`respondent_role`, select_one, required): Choose the role you have in the project (e.g., Owner, Manager, Project Manager, Contractor, Architect, Designer, or Other).
* **Email Address** (`respondent_email`, email, required): Enter your contact email address.
* **Project Start Date** (`project_start_date`, date, required): Select the date the project began.
* **Project Completion Date** (`project_completion_date`, date, required): Select the date the project was completed.
* **Was Project Completed On Schedule?** (`on_schedule`, select_one, required): Answer whether the project was completed on schedule.
* **Was Project Completed On Budget?** (`on_budget`, select_one, required): Answer whether the project was completed on budget.
* **Were There Scope Changes?** (`scope_changes`, select_one, required): Choose whether there were changes made to the project's scope.
* **Overall Contractor Performance** (`contractor_performance`, select_one, required): Rate the contractor's performance.
* **Quality of Workmanship** (`workmanship_quality`, select_one, required): Rate the quality of work done.
* **Communication and Responsiveness** (`communication_quality`, select_one, required): Rate the contractor's communication and responsiveness.
* **Timeliness and Punctuality** (`timeliness`, select_one, required): Rate the contractor's timeliness.
* **Safety Compliance** (`safety_compliance`, select_one, required): Rate the contractor's safety compliance.
* **Problem Resolution** (`problem_resolution`, select_one, required): Rate how well issues were resolved by the contractor.
* **Any Issues or Problems Encountered?** (`issues_encountered`, text, required): Describe any problems you faced during the project.
* **Would You Recommend This Contractor?** (`recommendation_likelihood`, select_one, required): Choose whether you would recommend the contractor.
* **Areas for Improvement** (`improvement_suggestions`, text, required): Suggest areas where the contractor could improve.
* **Additional Comments** (`additional_comments`, text, required): Enter any other feedback or comments.

## Tips
- Please answer all required questions.
- Rate questions that allow for selection-based feedback (1-5 scale).
- Use specific dates (mm/dd/yyyy) for date fields.
- Describe problems in the text field for "Any Issues or Problems Encountered?"
- Enter your actual email address for "Email Address".
