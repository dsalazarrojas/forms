# Startup Beta Product Feedback Survey - Help Guide

## Purpose
This form is designed to gather feedback from beta product users to help us improve the product's performance and user experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form by providing your feedback on your experience with the beta product.
2. Be as thorough as possible in answering all the questions.
3. If you have any suggestions or comments, please include them in the "User Comments" field.
4. If you have any personal contact information, you can provide it if you feel comfortable doing so.

## Field-by-Field Explanation

* **Start Date** (`start`, date, required/optional): This field is for the user to provide the date they started using the beta product.
* **User Information** (`user_information`, text, optional): This field is for the user to provide any additional information about themselves that they feel is relevant to their feedback.
* **Product Experience** (`product_experience`, text, optional): This field is for the user to describe their experience with the beta product, including any issues they encountered and how they overcame them.
* **Rating** (`rating`, number, optional): This field is for the user to rate their experience with the beta product, with higher numbers indicating a more positive experience.
* **Product Improvement** (`product_improvement`, select_one, optional): This field is for the user to select one or more areas where they feel the beta product could be improved, including:
	+ Option 1: Feature Addition
	+ Option 2: User Interface Improvements
	+ Option 3: Performance Enhancements
* **Product Features** (`product_features`, select_multiple, optional): This field is for the user to select one or more features that they would like to see added to the beta product.
* **Product Issues** (`product_issues`, select_multiple, optional): This field is for the user to select one or more issues they encountered with the beta product.
* **User Comments** (`user_comments`, note, optional): This field is for the user to provide any additional comments or suggestions for improving the beta product.
* **Email** (`email`, email, optional): This field is for the user to provide their email address if they would like to be contacted for further feedback or updates.
* **Phone** (`phone`, text, optional): This field is for the user to provide their phone number if they would like to be contacted for further feedback or updates.

Note: Some fields are optional, but providing as much information as possible will help us gather more valuable feedback.
