# hazardous_tree_report_form - Help Guide
## Purpose
The hazardous tree report form is used to report any hazardous conditions found in trees within a specific area. This form helps gather accurate and reliable data to ensure the safety and well-being of the community.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **hazardous_tree_report** field with a brief description of the hazardous condition found in the tree.
2. Enter the **hazardous_tree_location** where the hazardous tree is located.
3. Select the date of the **report_date** when the hazard was noticed.
4. Choose whether the tree was **assigned_to** a specific individual or group.
5. Indicate if the tree was **assigned_by** someone, and if so, specify that person's name.
6. Select whether the tree is **tree_type**, which is typically a yes or no answer.
7. Choose the **tree_status**, which can be Active or Inactive.
8. Provide a brief description of the tree's **tree_location**.
9. Enter any **tree_notes** about the tree or its condition.
10. Select any **tree_hazards** that exist, which can be yes or no answers.

## Field-by-Field Explanation
* **hazardous_tree_report**: Enter a brief description of the hazardous condition found in the tree.
* **hazardous_tree_location**: Enter the exact location of the hazardous tree.
* **report_date**: Select the date you noticed the hazardous condition in the tree.
* **assigned_to**: Choose "Yes" if the tree is assigned to a specific individual or group.
* **assigned_by**: Choose "Yes" if the tree is assigned by someone, and specify their name.
* **tree_type**: Select "Yes" if the tree is of a specific type.
* **tree_status**: Choose "Active" or "Inactive" depending on the tree's status.
* **tree_location**: Enter a brief description of the tree's location.
* **tree_notes**: Enter any additional comments or notes about the tree.
* **tree_hazards**: Select "Yes" for any hazards that exist on the tree.
