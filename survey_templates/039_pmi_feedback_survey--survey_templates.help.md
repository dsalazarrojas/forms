# PMI Feedback Survey - Help Guide
## Purpose
The PMI Feedback Survey is a tool used to collect feedback from participants and project managers on the overall project process. It aims to gather insights on project outcomes, participant satisfaction, and areas for improvement. This form is intended for regular assessment and improvement of project management practices within the organization.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields marked with an asterisk (\*) as they are necessary for the form to be considered complete.
2. Enter the project title and description as accurately as possible.
3. Select the current status of the project from the options provided.
4. Provide the start date of the project if known.
5. Enter your name and email address for contact purposes.
6. Select your response to the feedback categories.
7. Provide any additional comments or feedback.

## Field-by-Field Explanation

* **Project Title** (`project_title`, text, *): This field is where you enter the title of the project being assessed. It's essential to enter a clear and concise title that accurately represents the project.
* **Project Description** (`project_description`, text, *): Please enter a brief description of the project, including its objectives and scope.
* **Project Status** (`project_status`, select_one, *): Select the current status of the project from the options provided: Active or Inactive.
* **Project Start Date** (`project_start_date`, date, ): If the project start date is known, enter it in the format YYYY-MM-DD.
* **Participant Name** (`participant_name`, text, ): This is the name of the participant who is providing feedback.
* **Participant Email** (`participant_email`, email, ): Enter the participant's email address for contact purposes.
* **Participant Phone** (`participant_phone`, text, ): Enter the participant's phone number for easy contact.
* **Feedback Category** (`feedback_category`, select_multiple, ): Select all categories that apply to your feedback:
	+ Yes
	+ No
* **PMI Initiative** (`pmi_initiative_score`, number, ): Enter a score out of 100 for the PMI initiative, where 100 indicates a perfect implementation.
* **Overall Satisfaction** (`overall_satisfaction`, select_one, *): Select your overall satisfaction level with the project:
	+ Satisfied
	+ Dissatisfied
* **Feedback Comments** (`feedback_comments`, text, ): Provide any additional comments or feedback on the project.
* **Project Outcomes** (`project_outcomes`, select_multiple, ): Select all outcomes that apply to your feedback:
	+ Yes
	+ No
* **Participant Satisfaction** (`participant_satisfaction`, select_one, ): Select your participant satisfaction level with the project:
	+ Satisfied
	+ Dissatisfied
* **Participant Improvement** (`participant_improvement`, select_one, ): Select if you have any improvement suggestions for the project:
	+ Yes
	+ No
* **Project Manager Name** (`project_manager_name`, text, ): Enter the name of the project manager.
* **Manager Comments** (`manager_comments`, text, ): Provide any comments or feedback for the project manager.
* **Participant Improvement Action** (`participant_improvement_action`, select_multiple, ): Select all improvement actions that apply to your feedback:
	+ Yes
	+ No
* **Manager Improvement Action** (`manager_improvement_action`, select_multiple, ): Select all improvement actions that apply to your feedback:
	+ Yes
	+ No
* **Overall Project Value** (`overall_project_value`, number, ): Enter a numerical value for the project's overall value.
* **Participant Suggestions** (`participant_suggestions`, select_multiple, ): Select all suggestions you have for the project:
	+ Yes
	+ No
* **Manager Suggestions** (`manager_suggestions`, select_multiple, ): Select all suggestions you have for the project:
	+ Yes
	+ No
* **Participant Concerns** (`participant_concerns`, select_multiple, ): Select all concerns you have for the project:
	+ Yes
	+ No
* **Manager Concerns** (`manager_concerns`, select_multiple, ): Select all concerns you have for the project:
	+ Yes
	+ No
* **Participant Agreement** (`participant_agreement`, select_one, ): Select if you agree with the project:
	+ Yes
	+ No
* **Manager Agreement** (`manager_agreement`, select_one, ): Select if you agree with the project:
	+ Yes
	+ No

Note: The asterisk (\*) indicates required fields. Ensure to fill these fields in to complete the form.
