# Network And Camera Deployment Survey - Help Guide
## Purpose
This form is used to document and track site-specific information for network and camera deployments.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary permissions and approvals before filling out this form.
2. Select the site details and address.
3. Answer the questions about camera type, network type, and other relevant information.
4. Provide any necessary contact details for the site and camera administrator.

## Field-by-Field Explanation
* **Site Details** (site_details, text, not required): Enter a brief description of the site.
* **Site Address** (site_address, text, not required): Enter the address of the site.
* **Camera Location** (camera_location, select_one, not required): Choose 'Yes' if cameras are deployed at this site.
* **Camera Type** (camera_type, select_multiple, not required): Select multiple types of cameras deployed at the site.
* **Network Type** (network_type, select_multiple, not required): Select multiple types of networks connected at the site.
* **Network Speed** (network_speed, select_one, not required): Choose the type of network speed at the site.
* **Cable Type** (cable_type, select_multiple, not required): Select multiple types of cables used at the site.
* **Cable Length** (cable_length, number, not required): Enter the length of the cable used at the site.
* **Install Time** (install_time, time, not required): Enter the estimated time for installation.
* **Install Date** (install_date, date, not required): Enter the date of installation.
* **Notes** (notes, note, not required): Enter any additional comments or notes about the site.
* **Contact Email** (email_contact, email, not required): Enter the contact email for the site.
* **Contact Phone** (phone_contact, text, not required): Enter the contact phone number for the site.
* **Site Contact** (site_contact, text, not required): Enter the contact name and email for the site.
* **Site Manager** (site_manager, select_one, not required): Choose 'Yes' if a site manager is available.
* **Facility Manager** (facility_manager, select_multiple, not required): Select multiple facility managers for the site.
* **Network Admin** (network_admin, select_multiple, not required): Select multiple network administrators for the site.
* **Cable Admin** (cable_admin, select_multiple, not required): Select multiple cable administrators for the site.
* **Install Status** (install_status, select_multiple, not required): Select the installation status of the site.
* **Comments** (comments, note, not required): Enter any comments about the site.
* **Site Notes** (site_notes, note, not required): Enter any additional notes about the site.
* **Camera Notes** (camera_notes, note, not required): Enter any additional notes about the cameras.
* **Notes** (notes, note, not required): Enter any additional comments about the site.
* **Comments** (comments, note, not required): Enter any comments about the site.
* **Site Status** (site_status, select_multiple, not required): Select the status of the site.
