# Passive Voice Proficiency Quiz - Help Guide
## Purpose
This form is designed to assess the proficiency of users in using passive voice in their writing.

## How To Complete This Form

To complete this form, follow the instructions on each page. Please select the correct option that uses passive voice for each sentence. You can review the sentences carefully and choose the option that best fits the correct usage of passive voice.

## Field-by-Field Explanation

* **Survey Template Quizzes** (`survey_templates_quizs`, select_multiple, required: false): Select all the options that you are familiar with.
* **Survey Template Quiz** (`survey_templates_quiz`, select_one, required: false): Select the correct option that uses passive voice.
* **Passive Voice Proficiency Quiz** (`passive_voice_proficiency_quiz`, select_one, required: false): Select the correct option that uses passive voice.
* **Students Names** (`students_names_quizs`, text, required: false): Enter the names of the students you are assessing.
* **Student Name Emails** (`student_name_emails_quizs`, select_multiple, required: false): Select the emails of the students you are assessing.
* **Manage Data** (`manage_data_quizs`, select_multiple, required: false): Select the options that you are familiar with.
* **Drag And Drop Interfaces** (`drag_and_drop_interfaces_quizs`, text, required: false): Enter your thoughts on drag and drop interfaces. This field is optional.
* **Drag And Drop Interfaces** ( duplicate of `drag_and_drop_interfaces_quizs`, text, required: false): Enter your thoughts on drag and drop interfaces. This field is optional and is not necessary to fill.
