# Network Cost Assessment Survey - Help Guide

## Purpose
The Network Cost Assessment Survey is designed to gather information about network costs for a specific period. This form is intended for authorized personnel to evaluate and report on network expenses.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the correct frequency of cost assessment (Cost 1, Cost 2, or Cost 3) from the dropdown menu in the "Frequency" field.
2. Choose the costs associated with the selected frequency by selecting multiple options in the "Cost 1" field.
3. Enter the time frame for each cost in the "Frequency 1" field for each selected cost.
4. Enter the actual costs for each selected cost in the "Cost 1" field.
5. Enter the total cost and monthly cost for the assessment period in the "Total Cost" and "Monthly Cost" fields, respectively.
6. Enter the annualized cost for the assessment period in the "Annualized Cost" field.
7. Select the date for the assessment period in the "Date 1" field.

## Field-by-Field Explanation
* **Network Cost Assessment Survey** (text, text, required): A brief description of the form purpose.
* **Total Cost** (number, number, not required): The total cost for the assessment period.
* **Monthly Cost** (number, number, not required): The monthly cost for the assessment period.
* **Yearly Cost** (number, number, not required): The yearly cost for the assessment period.
* **Annualized Cost** (number, number, not required): The annualized cost for the assessment period.
* **Frequency** (select one, select one, not required): The frequency of cost assessment (Cost 1, Cost 2, or Cost 3).
* **Cost 1** (select multiple, select multiple, not required): The costs associated with the selected frequency.
* **Frequency 1** (time, time, not required): The time frame for each cost.
* **Cost 1** (number, number, not required): The actual cost for each selected cost.
* **Date 1** (date, date, not required): The date for the assessment period.
