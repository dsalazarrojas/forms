# Virtual Event Quality Questionnaire - Help Guide
## Purpose
The Virtual Event Quality Questionnaire is a tool used to collect feedback on virtual events. It helps event organizers to assess the quality and effectiveness of their events by gathering information on various aspects of the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the virtual event.
2. Provide a title for the event.
3. Choose the type of event (e.g. Webinar, Conference, Workshop).
4. Choose the format of the event (e.g. Video, Live, Recording).
5. Enter the name of the speaker (if applicable).
6. Enter the time of the event.
7. Select the location of the event (if applicable).
8. Rate the event on a scale of 1-10.

## Field-by-Field Explanation

* **Event Date**: Enter the date of the virtual event in the format `YYYY-MM-DD`. This field is not required.
* **Event Title**: Enter a descriptive title for the event. This field is not required.
* **Event Type**: Select the type of event you attended (e.g. Webinar, Conference, Workshop). This field is not required.
* **Event Format**: Select the format of the event (e.g. Video, Live, Recording). This field is not required.
* **Speaker Name**: If the event had a speaker, enter their name. This field is not required.
* **Event Time**: Enter the time of the virtual event. This field is not required.
* **Event Location**: If the event had a physical location, select from the available options. This field is not required.
* **Event Rating**: Rate the event on a scale of 1-10. This field is not required.

Note: All fields are not required, but providing accurate information will help event organizers get a better understanding of the event.
