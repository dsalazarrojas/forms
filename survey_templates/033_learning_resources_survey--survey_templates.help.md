# learning_resources_survey - Help Guide
## Purpose
The "learning_resources_survey" form is designed to collect data on learning resources used for educational purposes. This form helps to gather information about the resource's title, institution, resource type, and user ratings (effectiveness, accessibility, relevance, and utility).

## How To Complete This Form
To complete this form, follow these steps:

1.  Scroll to the "intro" page to read the form's purpose.
2.  Proceed to the "institution" page to enter the title of the institution related to the resource.
3.  On the next page, enter the name of the resource.
4.  Select the type of resource by choosing one of the provided options.
5.  For resources not listed, describe their type in the "other" field.
6.  Rate the resource's effectiveness, accessibility, relevance, and utility using numbers.
7.  Enter any additional comments or suggestions about the resource.

## Field-by-Field Explanation

* **Institution** (text, required): Enter the title of the institution related to the resource.
* **Resource** (text, required): Enter the name of the resource.
* **Resource Type** (select_one, required): Select one of the provided options for the resource type.
* **Other (Resource Type)** (text, optional): Provide an alternative description of the resource type if not listed.
* **Effectiveness** (number, required): Rate the resource's effectiveness on a scale (e.g., 1-5).
* **Accessibility** (number, required): Rate the resource's accessibility on a scale (e.g., 1-5).
* **Relevance** (number, required): Rate the resource's relevance on a scale (e.g., 1-5).
* **Utility** (text, optional): Enter any additional comments or suggestions about the resource.
* **Worth** (number, required): Rate the resource's worth on a scale (e.g., 1-5).
* **Suggestions** (text, required): Enter any additional comments or suggestions about the resource.
* **Institution Suggestions** (text, optional): Provide any suggestions related to the institution.
* **Resource Suggestions** (text, optional): Provide any suggestions related to the resource.
* **Comments** (text, optional): Enter any additional comments about the resource.

## Tips
When filling out this form, please ensure that you are rating the resources accurately and honestly. If a resource's effectiveness, accessibility, relevance, or utility are unclear, it's okay to seek clarification from others before submitting your rating.
