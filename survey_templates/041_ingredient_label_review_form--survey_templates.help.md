# ingredient_label_review_form - Help Guide
## Purpose
The ingredient label review form is used to validate the presence and correctness of ingredients in a product label.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the product name from the "product_name" field. This field is required and should be filled in with the exact name of the product being reviewed.
2. In the "list_of_ingredients" field, select the list of ingredients found on the product label. If the ingredient is not present, select "No" from the dropdown.
3. Enter the name of the ingredient in the "ingredient_name" field.
4. Select the type of ingredient from the "ingredient_type" dropdown. This field is required and should be filled in with the correct type of ingredient.
5. Enter any comments or observations about the product label in the "comments" field.
6. If you are the person submitting the review, select "Yes" from the "submitted_by" field.

## Field-by-Field Explanation

* **product_name** (required): Enter the exact name of the product being reviewed.
* **list_of_ingredients** (required, select multiple): Select the list of ingredients found on the product label. If an ingredient is not present, select "No".
* **ingredient_name** (required): Enter the name of the ingredient being reviewed.
* **ingredient_type** (required, select one): Select the type of ingredient from the dropdown options.
* **product_label** (optional): Enter any additional comments or information about the product label.
* **comments** (optional): Enter any comments or observations about the product label.
* **submitted_by** (required, select one): Select "Yes" if you are the person submitting the review.
* **submitted_at** (optional): The date the review was submitted.
* **submitted_at_time** (optional): The time the review was submitted.

## Tips
* Make sure to fill in the product name exactly as it appears on the label.
* Be accurate when selecting the list of ingredients.
* Enter the ingredient name carefully to ensure it matches the product label.
* Double-check the type of ingredient to ensure accuracy.
* If you are the person submitting the review, select "Yes" to confirm.
* The date and time fields are optional, but can be helpful for tracking and record-keeping purposes.
