# Literary Involvement Interest Form - Help Guide
## Purpose
This form is designed to help us understand your interests and involvement in literary events and programs. Your input will help us tailor our offerings to better meet your needs and interests.

## How To Complete This Form
To complete this form, simply select the fields that apply to you and provide any additional information as requested.

## Field-by-Field Explanation
* **Title**: (1) - Please enter your name as you would like to be addressed.
* **Email**: (3) - Enter your email address so we can contact you. Please ensure it is accurate and up-to-date.
* **Phone**: (4) - If you would like to be contacted by phone, enter your phone number here. (Optional)
* **Contact Method**: (5) - Select how you would like to be contacted: email, phone, or other (please specify).
* **Organization**: (6) - If you are associated with an organization, please enter its name.
* **Role in Community**: (7) - Check all the roles that apply to you: library staff, community member, author, reader, or other (please specify).
* **Program Ideas**: (8) - If you have ideas for programs, events, or activities, please describe them here.
* **Events of Interest**: (11) - Select all the events you are interested in: poetry reading, book club, reading series, workshop, or other (please specify).
* **Interested in Programs**: (10) - Check all the programs you are interested in: literary events, writing workshops, book talks, reading events, or other (please specify).
* **Preferred Contact Frequency**: (12) - Select how often you would like to be contacted: as needed, weekly, bi-weekly, monthly, or quarterly.
* **Notes**: (13) - Add any additional comments or thoughts you would like to share.
* **Date**: (14) - Please enter a date if you have a specific event or program in mind.
* **Time**: (15) - If you have a specific time in mind for the event or program, please enter it here.
* **Location**: (16) - If you are interested in hosting an event or program at a specific location, please enter it here.
* **Event Details**: (17) - If you have specific ideas for an event or program, please describe them here.
* **Outreach Method**: (18) - If you have specific methods for outreach, please describe them here.
* **Outreach Frequency**: (19) - Select how often you would like to be contacted for outreach purposes: as needed, weekly, bi-weekly, monthly, or quarterly.
* **Follow-up Method**: (20) - Select how you would like to be followed up with: in-person, phone, email, or mail.
* **Follow-up Frequency**: (22) - Select how often you would like to be followed up with: as needed, weekly, bi-weekly, monthly, or quarterly.
* **Follow-up Email**: (24) - Enter your email address if you would like to be followed up with by email.
* **Follow-up Phone**: (25) - Enter your phone number if you would like to be followed up with by phone.
* **Notes**: (23) - Add any additional comments or thoughts you would like to share.
* **Follow-up Note**: (21) - Add any additional comments or thoughts about follow-up communication.
* **Follow-up Email**: (24) - Enter your email address if you would like to be followed up with by email.
* **Follow-up Phone**: (25) - Enter your phone number if you would like to be followed up with by phone.
