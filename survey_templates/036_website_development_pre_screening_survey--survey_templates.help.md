# Website Development Pre Screening Survey - Help Guide
## Purpose
The Website Development Pre Screening Survey is a crucial tool for evaluating and prioritizing projects. This form is used to gather essential information about projects, including their goals, budget, timeline, and other relevant details. By providing accurate and complete information, project stakeholders can make informed decisions about project progression and resource allocation.

## How To Complete This Form

1.  Fill in the project goals, describing the objectives and expected outcomes of the project.
2.  Enter the project budget, indicating the allocated funds for the project.
3.  Select the project timeline, specifying the expected start and completion dates.
4.  Choose the project priority level, indicating its urgency and importance.
5.  Provide a brief description of the project, including any additional details or context.
6.  Select the type of website to be developed (e-commerce, blog, brochure, portfolio, or other).
7.  Choose the methods of lead capture (email, phone, social media).
8.  Indicate the project status (started, not started, postponed).
9.  Enter the project status notes, if any.
10.  Specify the lead source (agency, referral, online ad).
11.  Enter project notes, if required.
12.  Enter the developer's name and email, if you are a developer.
13.  Enter the agency's name and email, if you are working with an agency.
14.  Enter the agency's phone number and notes, if necessary.
15.  Enter the budgeted hours, if applicable.
16.  Enter the expected launch date, if known.
17.  Enter the project URL, if available.
18.  Enter any project status updates, if needed.
19.  Enter project update notes, if required.

## Field-by-Field Explanation

* **Project Goals** (`project_goals`, text, required): This field is for describing the objectives and expected outcomes of the project. Please provide a brief and clear statement of what the project aims to achieve.
*   **Project Budget** (`project_budget`, number, required): Enter the allocated funds for the project.
*   **Project Timeline** (`project_timeline`, time, required): Choose the expected start and completion dates of the project.
*   **Project Priority** (`project_priority`, select_one, required): Indicate the project's level of urgency and importance, with options High, Medium, or Low.
*   **Project Description** (`project_description`, text, required): Give a brief overview of the project, including any additional details or context.
*   **Website Type** (`website_type`, select_multiple, required): Select the type of website to be developed, from E-commerce, Blog, Brochure, Portfolio, or Other.
*   **Lead Capture** (`lead_capture`, select_multiple, required): Choose the methods of lead capture, including Email, Phone, Social Media.
*   **Project Status** (`project_status`, select_one, required): Indicate the project status, with options Started, Not Started, Postponed.
*   **Project Status Notes** (`project_status_notes`, text, optional): Enter any additional notes about the project status.
*   **Lead Source** (`lead_source`, select_multiple, required): Specify the source of the lead, including Agency, Referral, Online Ad.
*   **Project Notes** (`project_notes`, text, optional): Enter any additional notes about the project.
*   **Developer Name** (`developer_name`, text, optional): Enter your name as the developer.
*   **Developer Email** (`developer_email`, email, optional): Enter your email as the developer.
*   **Developer Phone** (`developer_phone`, text, optional): Enter your phone number as the developer.
*   **Developer Notes** (`developer_notes`, text, optional): Enter any additional notes as the developer.
*   **Agency Name** (`agency_name`, text, optional): Enter the name of the agency you are working with.
*   **Agency Email** (`agency_email`, email, optional): Enter the agency's email address.
*   **Agency Phone** (`agency_phone`, text, optional): Enter the agency's phone number.
*   **Agency Notes** (`agency_notes`, text, optional): Enter any additional notes about the agency.
*   **Budgeted Hours** (`budgeted_hours`, number, optional): Enter the budgeted hours for the project.
*   **Expected Launch Date** (`expected_launch_date`, date, optional): Enter the expected launch date of the project.
*   **Project URL** (`project_url`, text, optional): Enter the project URL, if available.
*   **Project Status Update** (`project_status_update`, text, optional): Enter any additional project status updates.
*   **Project Update Notes** (`project_update_notes`, text, optional): Enter any additional notes about the project status.
