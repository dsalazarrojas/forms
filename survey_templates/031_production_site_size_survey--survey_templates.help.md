# Production Site Size Survey - Help Guide
## Purpose
This form is used to collect information about the production site size and status. The data collected will help the facilities team to make informed decisions about the production process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately.
2. Ensure you have all necessary information about the production site, including its size, type, capacity, location, and status.
3. Select the correct facility ID and production site type from the options provided.
4. Enter the correct production site size and capacity.
5. Enter the production site description.
6. Select the correct production site status.
7. Enter the facility manager's name and title.

## Field-by-Field Explanation

* **Facility ID** (`facility_id`, `text`, required): Enter the unique identifier for the production facility.
* **Production Site Size** (`production_site_size`, `number`, required): Enter the production site size.
* **Production Site Type** (`production_site_type`, `select_one`, required): Choose the correct type of production site (small, medium, or large).
* **Production Site Capacity** (`production_site_capacity`, `number`, required): Enter the production site capacity.
* **Production Site Location** (`production_site_location`, `text`, required): Enter the location of the production site.
* **Production Site Description** (`production_site_description`, `text`, required): Enter a brief description of the production site.
* **Production Site Status** (`production_site_status`, `select_one`, required): Choose the correct status of the production site (active or inactive).
* **Facility Manager** (`facility_manager`, `text`, required): Enter the facility manager's name and title.
* **Other (please specify)** (`production_site_size_other`, `text`, optional): Enter any additional information about the production site size, if not listed above.
* **Other Other** (`production_site_size_other`, `text`, optional): Enter any additional information about the production site, if not listed above.
* **Production Site Size** (no label, `number`, required): Enter any additional information about the production site size that does not fit the above categories. 

Note: The fields marked as "optional" can be filled out if you have additional information that doesn't fit the above categories.
