# restoration_project_voting_form - Help Guide
## Purpose
The restoration_project_voting_form is used to collect information about restoration projects for voting purposes. It ensures that each project has all the necessary data to be properly represented in the voting process.

## How To Complete This Form
Before starting, please ensure you have all the required information about the restoration project. This form has 14 fields that need to be filled out. Each field is described below.

## Field-by-Field Explanation

* **restoration_project** (`restoration_project_name`, `text`, required): Enter the name of the restoration project. This is the primary identifier for the project.
* **how_will_you_vote** (`restoration_project_voting`, `select_one`, required: false): Select how you will vote for this project. You can choose one of the provided options.
* **contact_email** (`contact_email`, `email`, required): Enter the contact email address for the project.
* **contact_phone** (`contact_phone`, `text`, required): Enter the contact phone number for the project.
* **restoration_project_description** (`restoration_project_description`, `note`, required): Provide a detailed description of the restoration project.
* **voting_how** (`restoration_project_voting_how`, `select_multiple`, required: false): Select the methods you will use to vote for this project. You can choose multiple options.
* **voting_what** (`restoration_project_voting_what`, `select_one`, required: false): Select what you will vote for. You can choose one of the provided options.
* **voting_why** (`restoration_project_voting_why`, `select_multiple`, required: false): Select why you will vote for this project. You can choose multiple options.
* **voting_when** (`restoration_project_voting_when`, `date`, required: false): Enter the date when you will vote for this project.
* **voting_time** (`restoration_project_voting_time`, `time`, required: false): Enter the time when you will vote for this project.
* **voting_note** (`restoration_project_voting_note`, `note`, required: false): Add any additional notes about your voting decision.
* **contact_address** (`contact_address`, `text`, required): Enter the contact address for the project.
* **voting_who** (`restoration_project_voting_who`, `select_one`, required: false): Select who you will vote for. You can choose one of the provided options.
* **voting_whatelse** (`restoration_project_voting_whatelse`, `select_multiple`, required: false): Select any additional options you will vote for. You can choose multiple options.
