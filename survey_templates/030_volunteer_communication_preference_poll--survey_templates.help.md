# Volunteer Communication Preference Poll - Help Guide
## Purpose
This form helps us understand your communication preferences as a volunteer. Your input will enable us to tailor our communication with you effectively.

## How To Complete This Form
1. Please select the options that best describe your preferred contact methods:
	* Fill out the form as thoroughly as possible.
	* You can choose from the following options for each question.
2. When finished, click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Volunteer Communication Preference Poll** (Volunteer Communication Preference Poll, Text, Optional): 
    This is the title of the form, it's a placeholder, and you can ignore it.
* **Preferred Contact Method** (preferred_contact_method, Select One, Optional):
    Please select the communication method you are most comfortable with. You can choose "Yes" if you prefer email, phone, in-person, or online communication, or "No" if you don't prefer any of these methods.
* **Volunteer Communication Frequency** (volunteer_communication_frequency, Select Multiple, Optional):
    Select all the communication frequencies you are comfortable with. You can choose from the following options:
	+ Yes (daily/weekly/monthly)
	+ No (none of the above)
* **Volunteer Communication Method** (volunteer_communication_method, Select Multiple, Optional):
    Please select all the communication methods you are comfortable with. You can choose from the following options:
	+ Yes (email/phone/in-person/online)
	+ No (none of the above)
* **Volunteer Email** (volunteer_email, Text, Optional): 
    Enter your email address if you prefer to use email as a communication method.
* **Volunteer Phone** (volunteer_phone, Text, Optional): 
    Enter your phone number if you prefer to use phone as a communication method.
* **Volunteer SMS** (volunteer_sms, Text, Optional): 
    Enter your phone number if you prefer to use SMS as a communication method.
* **Volunteer In-Person** (volunteer_inperson, Select One, Optional): 
    Please select "Yes" if you are comfortable with in-person communication, or "No" if you are not.
* **Volunteer Online** (volunteer_online, Select One, Optional): 
    Please select "Yes" if you are comfortable with online communication, or "No" if you are not.
* **Volunteer Both** (volunteer_both, Select One, Optional): 
    Please select "Yes" if you are comfortable with both in-person and online communication, or "No" if you are not.

## Tips
* Please answer honestly, and we will use your input to tailor our communication with you effectively.
* If you have any questions or need clarification on any of the fields, feel free to ask.
