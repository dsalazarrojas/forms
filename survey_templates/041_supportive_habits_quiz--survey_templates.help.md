# Supportive Habits Quiz - Help Guide
## Purpose
The Supportive Habits Quiz form is designed to collect information about supportive habits, which is used to categorize and describe the form's purpose.

## How To Complete This Form
To complete this form, simply fill out the required fields and select the relevant information as instructed below.

## Field-by-Field Explanation
* **Supportive Habits Quiz** (`supportive_habits_quiz_form`, text, required/optional): This is the title of the quiz form. Enter a brief description of the quiz.
* **Category** (`category`, select_one, required/optional): Select the category that best fits the quiz, such as "Survey Templates" or "Other Templates".
* **Description** (`description`, text, required/optional): Provide a detailed description of the quiz.
* **Form ID** (`form_id`, number, required/optional): Enter a unique ID for the quiz form.
* **Assigned Tool** (`assigned_tool`, select_one, required/optional): Select the tool assigned to the quiz form, such as "chatjimmy" or "other tool".
* **Output File** (`output_file`, text, required/optional): Enter the output file name for the quiz form.

## Tips
* Make sure to fill out all fields accurately and thoroughly.
* If you're unsure about any field, refer to the form's purpose and the provided instructions.
* Double-check your entries before submitting the form.
