# Post Project Assessment Survey - Help Guide
## Purpose
This form is used to collect information about a project that has been completed.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter a title for the project in the "project_title" field.
2. Enter the project ID number in the "project_id" field.
3. Enter the name of the lead or team member in charge of the project in the "lead" field.
4. Enter the start date of the project in the "start_date" field. Please enter the date in a standard date format, e.g., 2022-01-01.
5. Select the current status of the project from the "status" dropdown menu.
6. Select all team members who were involved in the project from the "team_members" dropdown menu.
7. Enter a brief description of the project in the "description" field.
8. Enter an estimated budget for the project in the "budget" field.
9. Add any additional notes about the project in the "notes" field.
10. Enter the contact email of the project lead or manager in the "email" field.
11. Enter the contact phone number of the project lead or manager in the "phone" field.
12. Add any final comments about the project in the "comments" field.

## Field-by-Field Explanation

* **project_title** (text): Enter a title for the project that summarizes its objectives and goals.
* **project_id** (number): Enter the project ID number assigned to the project.
* **lead** (text): Enter the name of the project lead or team member in charge of the project.
* **start_date** (date): Enter the date when the project started. Use a standard date format, e.g., 2022-01-01.
* **status** (select_one): Select the current status of the project from the dropdown menu:
	+ Active: The project is currently ongoing.
	+ In Progress: The project is in the middle of its lifecycle.
	+ On Hold: The project has been paused or postponed.
	+ Completed: The project has been successfully completed.
* **team_members** (select_multiple): Select all team members involved in the project from the dropdown menu.
* **description** (text): Enter a brief description of the project, including its main objectives and goals.
* **budget** (number): Enter an estimated budget for the project.
* **notes** (note): Enter any additional notes about the project.
* **email** (email): Enter the contact email of the project lead or manager.
* **phone** (text): Enter the contact phone number of the project lead or manager.
* **comments** (text): Enter any final comments about the project.
