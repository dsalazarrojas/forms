# Early Warning System Monitoring Form - Help Guide
## Purpose
This form is designed to collect information about the Early Warning System Monitoring Form, which is a tool used to monitor and track the status of early warning systems. This information will be used to ensure that the systems are properly configured and functioning as expected.

## How To Complete This Form
To complete this form, follow the steps below:

1. Ensure you have the necessary permissions and access rights to input information for the relevant organizations and systems.
2. Fill out all required fields, as indicated by the asterisks (*).
3. Review the field-by-field explanations below to understand the purpose and requirements for each field.

## Field-by-Field Explanation
* **Organization Name** (`organization_name`, text, *): Enter the name of the organization that owns or operates the early warning system.
* **Location** (`location`, text, *): Enter the location where the early warning system is deployed or operational.
* **Contact Person** (`contact_person`, text, *): Enter the name of the person responsible for the early warning system at the organization.
* **Early Warning System** (`warning_system`, select_one, *): Select the type of early warning system being monitored (e.g., System 1, System 2, System 3).
* **Risk Level** (`risk_level`, select_one, *): Select the risk level associated with the early warning system (e.g., Low, Medium, High).
* **Frequency of Warnings** (`frequency_of_warnings`, select_multiple, *): Select the frequency at which the early warning system sends out warnings (e.g., Daily, Weekly, Monthly, Quarterly, Annually).
* **Warning Threshold** (`warning_threshold`, number, *): Enter the threshold value for the early warning system to trigger a warning.
* **Intervention Time** (`intervention_time`, date, *): Enter the date and time when the early warning system is scheduled for intervention or maintenance.
* **System Status** (`system_status`, select_one, *): Select the current status of the early warning system (e.g., Active, Inactive).
* **Notes** (`notes`, note, optional): Enter any additional comments or notes about the early warning system.
* **Email Address** (`email_address`, email, *): Enter the email address of the person responsible for the early warning system.
* **Phone Number** (`phone_number`, text, *): Enter the phone number of the person responsible for the early warning system.
