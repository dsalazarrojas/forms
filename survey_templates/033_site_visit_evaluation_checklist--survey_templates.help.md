# Site Visit Evaluation Checklist - Help Guide
## Purpose
This form is used to evaluate site visits, providing a structured way to assess the outcomes, logistics, and overall experience of site visits. 

## How To Complete This Form
To complete this form, please answer the questions honestly and thoroughly, providing as much detail as possible. For select_multiple and select_one fields, choose the best option from the list. 

## Field-by-Field Explanation
* **Title** (`title`, text, required): This field is the name of the form, which is self-explanatory.
* **Introduction** (`introduction`, text, required=false): A brief introduction to the site visit, please describe the purpose of the visit and any notable circumstances.
* **Stakeholders Met** (`site_visit_goals`, select_multiple, required=false): 
  - Select 'Yes' if all the intended stakeholders were met.
  - Select 'No' if no stakeholders were met.
  - Select 'Some' if some stakeholders were met, but not all.
* **Engagement with site visit** (`engagement_with_site_visit`, select_one, required=false): 
  - Choose 'Excellent' if the visit was highly engaging and productive.
  - Choose 'Good' if the visit was fairly engaging and productive.
  - Choose 'Fair' if the visit was somewhat engaging and productive.
  - Choose 'Poor' if the visit was not engaging at all.
* **Logistics** (`logistics`, select_multiple, required=false): 
  - Select 'Vehicle' if vehicle transportation was provided and used.
  - Select 'Accomodation' if accommodation was provided for site visitors.
* **Time Management** (`time_management`, time, required=false): 
  - Enter the total time spent on site visit in hours and minutes (e.g., 2:30).
* **Overall Outcomes** (`overall_outcomes`, select_multiple, required=false): 
  - Select 'Good' if the site visit outcomes were satisfactory.
  - Select 'Fair' if the site visit outcomes were mediocre.
  - Select 'Poor' if the site visit outcomes were unsatisfactory.
* **Site Visit Suggestions** (`site_visit_suggestions`, text, required=false): 
  - Enter any suggestions for improving future site visits.
* **Additional Comments** (`additional_comments`, text, required=false): 
  - Enter any additional comments or observations about the site visit.
* **Site Visit Evaluation** (`site_visit_evaluation`, select_one, required=false): 
  - Choose 'Excellent' if the site visit evaluation was satisfactory.
  - Choose 'Good' if the site visit evaluation was fairly satisfactory.
  - Choose 'Fair' if the site visit evaluation was somewhat satisfactory.
  - Choose 'Poor' if the site visit evaluation was not satisfactory.
* **Date** (`date`, date, required=false): 
  - Enter the date of the site visit in the format MM/DD/YYYY.
* **Time** (`time`, time, required=false): 
  - Enter the time of the site visit in the format HH:MM.
* **Email** (`email`, email, required=false): 
  - Enter your email address for contact purposes.
* **Phone** (`phone`, text, required=false): 
  - Enter your phone number for contact purposes.

Note: The fields with required=false are optional and can be skipped if not applicable.
