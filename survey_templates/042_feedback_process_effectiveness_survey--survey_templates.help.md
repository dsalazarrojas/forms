# Feedback Process Effectiveness Survey - Help Guide
## Purpose
This form is designed to gather information about your experience with the feedback process in your organization, including your current feedback channels, response times, and feedback frequencies. This will help us understand how effective our feedback process is and identify areas for improvement.

## How To Complete This Form
1. Please select all the feedback channels you currently use, as shown in the list below:
	* Email
	* In-app
	* Phone
	* In-person
2. If you have any other feedback channels not listed above, please specify in the text field.
3. Choose how quickly you usually receive feedback, as shown in the options below:
	* Less than a week
	* 1-2 weeks
	* 2-4 weeks
	* More than a week
4. If other options are not listed, please specify in the text field.
5. Please select how frequently you receive feedback, as shown in the options below:
	* Daily
	* Weekly
	* Monthly
	* Quarterly
	* Never
6. If other options are not listed, please specify in the text field.
7. Choose how valuable you find feedback, as shown in the options below:
	* Very valuable
	* Somewhat valuable
	* Not very valuable
	* Not at all valuable
8. Choose how useful you find feedback in your role, as shown in the options below:
	* Very useful
	* Somewhat useful
	* Not very useful
	* Not at all useful
9. Choose how immediate feedback is, as shown in the options below:
	* Immediate
	* A few days
	* A week
	* More than a week
10. Choose how frequently feedback is given on actions taken, as shown in the options below:
	* Daily
	* Weekly
	* Monthly
	* Rarely
11. If other options are not listed, please specify in the text field.

## Field-by-Field Explanation
* **Feedback Channels**: This is where you select all the channels through which you currently receive feedback. For example, you might select "Email", "In-app", and "Phone" if you receive feedback through these channels.
* **Other Feedback Channels**: If you have any other feedback channels not listed above, please describe them in the text field. For example, if you receive feedback through a shared drive or a specific app.
* **Response Time**: This is how quickly you usually receive feedback. Select the option that best describes your experience. For example, if you usually receive feedback within a week, select "Less than a week".
* **Response Time (If Other)**: If the options above do not fit your experience, please specify the response time in the text field. For example, "Usually within 2-3 days".
* **Feedback Frequency**: This is how often you receive feedback. Select all the options that apply to your experience. For example, if you receive feedback daily and weekly, select both "Daily" and "Weekly".
* **Feedback Value**: This is how valuable you find feedback. Select the option that best describes your experience. For example, if you find feedback very valuable, select "Very valuable".
* **Feedback Usefulness**: This is how useful you find feedback in your role. Select the option that best describes your experience. For example, if you find feedback very useful, select "Very useful".
* **Feedback Immediacy**: This is how immediate feedback is. Select the option that best describes your experience. For example, if you receive immediate feedback, select "Immediate".
* **Feedback Frequency of Action**: This is how frequently feedback is given on actions taken. Select the option that best describes your experience. For example, if feedback on actions taken is given daily, select "Daily".
* **Feedback Frequency of Action (If Other)**: If the options above do not fit your experience, please specify the frequency in the text field. For example, "Feedback on actions taken is given weekly".
