# Vote For Favorite Coaches - Help Guide
## Purpose
This form is designed to collect your honest opinions on your favorite coaches. Your responses will be used to gather valuable feedback for internal purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form carefully, as it contains multiple questions.
2. For each question, select the answer that best reflects your opinion.
3. You can select multiple options for questions that allow multiple selections.
4. Be honest and sincere in your responses.
5. Once you've completed all questions, submit the form.

## Field-by-Field Explanation
* **Coach1** (`coach1`, select_one, required/optional): Select "Yes" if you have a favorite coach, "No" otherwise.
* **Coach2** (`coach2`, select_one, required/optional): Select "Yes" if you have another favorite coach, "No" otherwise.
* **Vote1** (`vote1`, select_multiple, required/optional): Select all coaches you consider your favorite by choosing "Yes" for each one you like. You can select multiple coaches.
* **Vote2** (`vote2`, select_multiple, required/optional): Select all coaches you consider your favorite by choosing "Yes" for each one you like. You can select multiple coaches.
* **Note1** (`note1`, note, required/optional): Write a brief note about your favorite coaches. This is an optional field for any additional comments or thoughts you'd like to share.

## Tips
* Be honest and sincere in your responses.
* Select only one option for questions that are marked as "select_one".
* Select multiple options for questions that are marked as "select_multiple".
