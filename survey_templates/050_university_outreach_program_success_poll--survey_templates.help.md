# University Outreach Program Success Poll - Help Guide
## Purpose
This form is designed to collect data about the success of university outreach programs. It's intended to be used by program participants, organizers, or staff to provide feedback on specific events.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the Event ID field with the ID of the event you're providing feedback on.
2. Enter your Name and Email for identification purposes.
3. Select the Department that best fits your affiliation with the event.
4. Choose your Role in the event (e.g., Team Member, Program Lead, Guest).
5. Enter a brief description of the event (optional).
6. Rate your satisfaction with the event on a scale from Very Satisfied to Very Dissatisfied.

## Field-by-Field Explanation

* **Event ID** (Event ID, Number, Required: False): Enter the unique ID of the event for which you're providing feedback.
* **Name** (Name, Text, Required: False): Enter your name for identification purposes.
* **Email** (Email, Email, Required: False): Enter your email for identification purposes.
* **Department** (Department, Select Multiple, Required: False): Select the department you belong to or are affiliated with.
* **Role** (Role, Select One, Required: False): Choose your role in the event (e.g., Team Member, Program Lead, Guest).
* **Event Name** (Event Name, Text, Required: False): Briefly describe the event (optional).
* **Event Description** (Event Description, Text, Required: False): Provide a more detailed description of the event (optional).
* **Date** (Date, Date, Required: False): Enter the date of the event.
* **Time** (Time, Time, Required: False): Enter the time of the event.
* **Rating** (Rating, Select One, Required: False): Rate your satisfaction with the event on a scale from Very Satisfied to Very Dissatisfied.

## Tips
* Please fill this form only once per event.
* Ensure that you're entering accurate information about the event and your role.
* If you have any difficulties or questions, please contact us for assistance.
