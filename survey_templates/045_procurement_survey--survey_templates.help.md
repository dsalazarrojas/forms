# Procurement Survey - Help Guide
## Purpose
This form is used to gather information for procurement purposes, including planning and budgeting for a potential purchase or acquisition. It's intended for use by procurement teams within an organization.

## How To Complete This Form
1. Fill in the form with the requested information as accurately as possible.
2. Answer each question to the best of your ability, using the options provided or typing in a free text response.
3. Make sure to complete all required fields, as indicated by the asterisk (\*) symbol.

## Field-by-Field Explanation

* **Survey Header** (`survey_header`, note, not required): This is a note field for any additional information you'd like to add to your response.
* **What would you like to order?** (`what_would_you_like_to_order`, text, not required): Describe the item or service you're interested in procuring.
* **What would you like to order description?** (`what_would_you_like_to_order_description`, text, not required): Provide a brief description of the item or service you're interested in.
* **What would you like to order options?** (`what_would_you_like_to_order_options`, select_one, not required):
	+ Select "Yes" if you'd like to order this item or service.
	+ Select "No" if you're not interested in ordering this item or service.
* **When is this a business opportunity?** (`when_is_this_a_business_opportunity`, select_one, not required):
	+ Select "Yes" if this is a business opportunity.
	+ Select "No" if it's not a business opportunity.
* **What are the key factors to consider?** (`what_are_the_key_factors_to_consider`, date, not required): Enter the date for this opportunity.
* **When would you like to start?** (`when_would_you_like_to_start`, time, not required): Enter the desired start date for this procurement.
* **What is the expected timeframe?** (`what_is_the_expected_timeframe`, number, not required): Enter the expected timeframe for this procurement.
* **What is the expected budget?** (`what_is_the_expected_budget`, number, not required): Enter the expected budget for this procurement.
