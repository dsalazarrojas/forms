# Patient Task Observation Survey - Help Guide
## Purpose
The Patient Task Observation Survey form is a crucial tool for healthcare professionals to document and track patient data in a structured manner. It helps to improve the quality of care provided to patients and enhances communication between healthcare workers.

## How To Complete This Form
To complete this form, follow these steps:
* Ensure you are authorized to access and fill out this form.
* Select the patient's name and the therapist's name from the corresponding fields.
* Choose the date of the visit when you observed the patient's task progress.
* Document the patient's task observation, which is a description of the tasks they were able to complete during the visit.
* Choose the observation scale to indicate the level of completion of the tasks observed.
* Provide any additional comments if necessary.
* Select the status of the task, which can be Complete, Partially Complete, or Not Complete.
* Choose the type of therapy provided, which can be Inpatient, Home Care, or Other.
* Document the details of the therapy session, which includes the date and time of the session.
* Schedule the follow-up visit and document any follow-up notes if necessary.
* Record the discharge status and date, if applicable.
* Document any discharge notes if necessary.
* Schedule and document next visit dates and notes if necessary.
* Document any review date and comments from the reviewer.
* Complete the review by documenting any final comments and observations.

## Field-by-Field Explanation

* **Patient Name (<name>)**: This is the patient's name. Please ensure that you enter the correct and accurate name of the patient.
* **Therapist Name (<name>)**: This is the name of the healthcare professional who interacted with the patient. Enter the correct and accurate name of the therapist.
* **Visit Date (<name>)**: This is the date of the visit when the patient's tasks were observed. Enter the correct date in the correct format (YYYY-MM-DD).
* **Task Observation (<name>)**: This is a description of the tasks the patient was able to complete during the visit. Enter a detailed description of the tasks observed.
* **Observation Scale (<name>)**: This is a scale to indicate the level of completion of the tasks observed. Choose from the options: 1, 2, 3.
* **Additional Comments (<name>)**: This is an optional field for you to provide any additional comments or information related to the visit.
* **Task Status (<name>)**: This is the status of the task, which can be Complete, Partially Complete, or Not Complete. Choose the correct status based on the observation.
* **Therapy Type (<name>)**: This is the type of therapy provided to the patient. Choose from the options: Inpatient, Home Care, Other.
* **Therapy Session (<name>)**: This is a description of the therapy session, which includes the date and time of the session.
* **Follow-up Scheduled (<name>)**: This is the date scheduled for the follow-up visit. Enter the correct date in the correct format (YYYY-MM-DD). If no follow-up is scheduled, leave this field empty.
* **Follow-up Completed (<name>)**: This is the date when the follow-up visit was completed. Enter the correct date in the correct format (YYYY-MM-DD). If no follow-up is completed, leave this field empty.
* **Follow-up Notes (<name>)**: This is an optional field for you to provide any follow-up notes or comments.
* **Next Visit Scheduled (<name>)**: This is the date scheduled for the next visit. Enter the correct date in the correct format (YYYY-MM-DD). If no next visit is scheduled, leave this field empty.
* **Next Visit Completed (<name>)**: This is the date when the next visit was completed. Enter the correct date in the correct format (YYYY-MM-DD). If no next visit is completed, leave this field empty.
* **Next Visit Notes (<name>)**: This is an optional field for you to provide any next visit notes or comments.
* **Discharge Status (<name>)**: This is the discharge status of the patient, which can be Discharged, Discharged to Other, or Not Discharged. Choose the correct status based on the patient's condition.
* **Discharge Date (<name>)**: This is the date of discharge, if applicable. Enter the correct date in the correct format (YYYY-MM-DD). If no discharge date is applicable, leave this field empty.
* **Discharge Notes (<name>)**: This is an optional field for you to provide any discharge notes or comments.
* **Review Date (<name>)**: This is the date when the reviewer reviewed the patient's data. Enter the correct date in the correct format (YYYY-MM-DD). If no review is completed, leave this field empty.
* **Reviewer (<name>)**: This is the name of the reviewer who reviewed the patient's data. Enter the correct and accurate name of the reviewer.
* **Review Comments (<name>)**: This is an optional field for you to provide any review comments or observations.
* **Review by (<name>)**: This is a field to document the reviewer's name.
* **Review Notes (<name>)**: This is an optional field for you to provide any review notes or comments.
* **Task Status Review (<name>)**: This is the status of the task after review, which can be Complete, Partially Complete, or Not Complete. Choose the correct status based on the review.
* **Review Comments (<name>)**: This is an optional field for you to provide any final review comments or observations.
*   **Review by (<name>)**:  This is a field to document the reviewer's name.
*   **Review Notes (<name>)**:  This is an optional field for you to provide any review notes or comments.
*   **Review Comments (<name>)**:  This is an optional field for you to provide any final review comments or observations.
