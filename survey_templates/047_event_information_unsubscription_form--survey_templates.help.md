# event_information_unsubscription_form - Help Guide
## Purpose
This form is used to collect event information for handling event unsubscription or cancellations.

## How To Complete This Form
1. **Unsubscribe/Cancel Event**: Choose "Yes" if you wish to unsubscribe or cancel the event.
2. **Event Type**: Select "Yes" if you would like to provide more information about the type of event.
3. **Event Date**: Enter the date of the event.
4. **Event Time**: Enter the time of the event.
5. **Event Location**: Enter the location of the event (optional).
6. **Organizers Information**: This section collects email addresses of event organizers. You can add up to 18 email addresses for multiple organizers.
7. **Submit**: Once all fields are filled, click "Submit" to proceed with event unsubscription or cancellation.

## Field-by-Field Explanation

* **event_information_unsubscription_form_first_page**: This is the first page with two options: "Yes" or "No".
* **event_type**: This field is used to provide more information about the type of event.
* **event_date**: Enter the date of the event in the format MM/DD/YYYY.
* **event_time**: Enter the time of the event in the 24-hour format (HH:MM).
* **event_location**: This field is optional and can be used to provide more details about the event location.
* **event_organizers**: This section requires up to 18 email addresses of event organizers.

Note that the last 17 fields are all "event_organizers_email_*" fields, which seem to be intended for capturing multiple email addresses of event organizers. However, since they all have the same label and description, only the first field **event_organizers_email_1** is actually used, and the others can be disregarded.
