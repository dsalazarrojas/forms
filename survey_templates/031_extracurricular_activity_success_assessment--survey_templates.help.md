# Extracurricular Activity Success Assessment - Help Guide

## Purpose

The Extracurricular Activity Success Assessment form is designed to collect information about a particular extracurricular activity or program being evaluated. This form helps to gather details about the activity's name, type, frequency, student and participant engagement, location, duration, and other relevant aspects.

## How To Complete This Form

To complete this form, follow these steps:

1. **Enter the Club Name**: This is the name of the extracurricular activity or club being evaluated.
2. **Enter the Program Name**: This is the name of the specific program or activity within the club.
3. **Select the Program Type**: Choose the type of program (Clubs, Sports, or Enrichment).
4. **Enter the Student Count**: Enter the number of students participating in the program (optional).
5. **Enter the Participant Count**: Enter the number of participants in the program (optional).
6. **Select the Program Frequency**: Choose the frequency of the program (Daily, Weekly, or Monthly).
7. **Enter the Participant Engagement**: Enter the time spent engaged with the program.
8. **Enter the Program Location**: This is the location where the program takes place (optional).
9. **Enter the Program Start Date**: Enter the date the program started (optional).
10. **Enter the Program End Date**: Enter the date the program ended (optional).
11. **Enter Program Notes**: Add any additional notes about the program.
12. **Enter Email Addresses**: Enter any email addresses associated with the program (optional).
13. **Enter Phone Numbers**: Enter any phone numbers associated with the program (optional).
14. **Enter Website**: Enter the website associated with the program (optional).
15. **Enter Social Media Links**: Enter any social media links associated with the program (optional).
16. **Enter Club Coordinators**: Enter any club coordinators associated with the program (optional).
17. **Enter Program Coordinators**: Enter any program coordinators associated with the program (optional).
18. **Enter Program Coordinator Title**: Enter the title of the program coordinator (optional).
19. **Enter Program Coordinator Email**: Enter the email of the program coordinator (optional).
20. **Enter Program Coordinator Phone**: Enter the phone number of the program coordinator (optional).
21. **Enter Program Coordinator Website**: Enter the website of the program coordinator (optional).
22. **Enter Parent Permission**: Check if parent permission is given or not (optional).
23. **Enter Participant Conferences**: Choose the conferences attended by participants (Pre-Registration and/or Mid-Season).
24. **Enter Student Conferences**: Choose the conferences attended by students (Pre-Registration and/or Mid-Season).
25. **Enter Program Evaluation**: Check if the program evaluation is True or False (optional).
