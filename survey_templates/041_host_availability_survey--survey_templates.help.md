# Host Availability Survey - Help Guide

## Purpose

The Host Availability Survey is a form designed to collect information about a host's availability for an event or service.

## How To Complete This Form

1. Fill out the form with your availability information.
2. Select a specific date for the event or service.
3. Select the start and end time for the event or service.
4. Choose the days you are unavailable.
5. Select your morning and evening availability time slots.
6. Provide any additional notes about your availability.
7. Enter your email address.
8. Enter your phone number.
9. Select your preferred language.

## Field-by-Field Explanation

* **Host Availability Survey (Availability Survey)**: A text field where you can provide a brief description of your availability.
* **Event Date (Event Date)**: A date field where you select a specific date for the event or service.
* **Start Time (Start Time)**: A time field where you select the start time for the event or service.
* **End Time (End Time)**: A time field where you select the end time for the event or service.
* **Availability Start (Availability Start)**: A date field where you select the start date of your availability.
* **Availability End (Availability End)**: A date field where you select the end date of your availability.
* **Days Off (Days Off)**: A multiple select field where you select the days you are unavailable.
* **Morning Availability (Morning Availability)**: A multiple select field where you select the morning time slots you are available.
* **Evening Availability (Evening Availability)**: A multiple select field where you select the evening time slots you are available.
* **Notes (Notes)**: A text field where you can provide any additional notes about your availability.
* **Email (Email)**: A text field where you enter your email address.
* **Phone (Phone)**: A text field where you enter your phone number.
* **Preferred Language (Preferred Language)**: A text field where you select your preferred language.

## Tips

* Be as specific as possible when filling out the form.
* If you have any conflicts or exceptions, please mention them in the notes field.
* Please select all applicable options in the multiple select fields.
* Make sure to select a specific date and time for the event or service.
* Enter your email and phone number correctly.
* If you have any language preference, please select it from the list.
