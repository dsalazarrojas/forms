# Hot And Cold Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback on your experience with a particular issue or product.

## How To Complete This Form
1. Select one of the three options for the Hot Feedback field and provide a brief description in the How Hot was it? field.
2. Select one or more options for the Cold Feedback field and provide a description in the How Cold was it? field.
3. Choose one of the three options for the Action field and provide a description in the Action Description field.
4. Select one of the five rating options and provide a description in the Rating Description field.
5. Enter any additional comments or feedback in the Comments field.
6. If you have any follow-up comments, enter them in the Follow-up Comments field.
7. Enter the next steps for the issue in the Next Steps field.
8. If you have any open comments, enter them in the Open Comments field and provide a description in the Open Comments Description field.
9. If you have any closed comments, enter them in the Closed Comments field and provide a description in the Closed Comments Description field.

## Field-by-Field Explanation

* **Introduction**
	+ Label: Introduction
	+ Description: Briefly introduce the issue or experience you're providing feedback on.
* **Hot Feedback**
	+ Label: Hot Feedback
	+ Description: Select one of the following options:
		- Positive: I was extremely satisfied with the experience.
		- Negative: I was extremely dissatisfied with the experience.
		- Neutral: I had a neutral experience.
* **How Hot was it?**
	+ Label: How Hot was it?
	+ Description: Provide a brief description of how hot the issue was.
* **Cold Feedback**
	+ Label: Cold Feedback
	+ Description: Select one or more of the following options:
		- Positive: The issue was resolved quickly.
		- Negative: The issue took too long to resolve.
		- Neutral: The issue was resolved within a reasonable timeframe.
* **How Cold was it?**
	+ Label: How Cold was it?
	+ Description: Provide a description of how cold the issue was (i.e., how quickly it was resolved).
* **Action**
	+ Label: Action
	+ Description: Choose one of the following options:
		- Positive: The support team took action immediately.
		- Negative: The support team took a long time to take action.
		- Neutral: The support team took action within a reasonable timeframe.
* **Action Description**
	+ Label: Action Description
	+ Description: Provide a description of the action taken.
* **Rating**
	+ Label: Rating
	+ Description: Select one of the following options:
		- Excellent: The issue was handled extremely well.
		- Good: The issue was handled well.
		- Fair: The issue was handled adequately.
		- Bad: The issue was handled poorly.
		- Not Rated: No rating provided.
* **Rating Description**
