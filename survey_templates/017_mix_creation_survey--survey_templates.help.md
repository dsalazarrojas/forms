# Mix Creation Survey - Help Guide

## Purpose
This survey is designed to gather information from DJs about their habits, preferences, and experiences related to creating mixes. It will help us understand the demographics and behavior of DJs, which will inform decisions on how to improve our platform and provide better services for you.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question truthfully and in the best way possible.
2. Make sure to fill in all required fields. Required fields are marked with an asterisk (\*).
3. You can select multiple options for select_multiple type fields by holding down the Ctrl (or Command key on Mac) key while selecting.

## Field-by-Field Explanation

* **How often do you DJ?** (`mix_creation_survey_1`, `number`, required): This field asks about your frequency of creating mixes. Please enter a number that indicates how often you create mixes.
* **Do you use any music software?** (`mix_creation_survey_2`, `select_one`, required): This field asks if you use any software for creating and editing mixes. Please select 'Yes' if you use such software, and 'No' otherwise.
* **What is your level of satisfaction?** (`mix_creation_survey_3`, `select_multiple`, required): This field asks about your level of satisfaction with creating mixes. Please select all options that apply.
* **Do you have a favorite music software?** (`mix_creation_survey_4`, `select_one`, required): This field asks if you have a favorite software for creating mixes. Please select 'Yes' if you have one, and 'No' otherwise.
* **What software do you use?** (`mix_creation_survey_5`, `text`, required): This field asks for the name of your favorite software. Please enter the name of your preferred software.
* **What do you use to create your mixes?** (`mix_creation_survey_6`, `text`, optional): This field is for any other tools or methods you use to create your mixes.
* **Do you use any music streaming services?** (`mix_creation_survey_7`, `select_multiple`, required): This field asks if you use any music streaming services. Please select 'Yes' if you use such services, and 'No' otherwise.
* **Which services do you use?** (`mix_creation_survey_8`, `text`, required): This field asks for the names of music streaming services you use.
* **Do you use social media?** (`mix_creation_survey_9`, `select_one`, required): This field asks if you use social media for promoting your mixes. Please select 'Yes' if you use it, and 'No' otherwise.
* **What platform do you use?** (`mix_creation_survey_10`, `text`, required): This field asks for the name of the social media platform you use.
* **Do you share your mixes on platforms?** (`mix_creation_survey_11`, `select_one`, required): This field asks if you share your mixes on any platforms. Please select 'Yes' if you share, and 'No' otherwise.
* **Which platforms do you share on?** (`mix_creation_survey_12`, `text`, required): This field asks for the names of the platforms where you share your mixes.
* **Do you get paid for your mixes?** (`mix_creation_survey_13`, `select_one`, required): This field asks if you get paid for creating mixes. Please select 'Yes' if you get paid, and 'No' otherwise.
* **What is your income source?** (`mix_creation_survey_14`, `select_one`, required): This field asks for the source of your income from mixes. Please select one option.
* **Do you work with artists?** (`mix_creation_survey_15`, `select_one`, required): This field asks if you collaborate with artists on mixes. Please select 'Yes' if you work with artists, and 'No' otherwise.
* **What is your work type?** (`mix_creation_survey_16`, `text`, optional): This field is for any other work you do related to mix creation.
* **Do you have any collaborators?** (`mix_creation_survey_17`, `select_one`, required): This field asks if you work with others on mixes. Please select 'Yes' if you collaborate, and 'No' otherwise.
* **What is your collaboration type?** (`mix_creation_survey_18`, `text`, required): This field asks for the type of collaboration you do.
* **How many tracks do you create?** (`mix_creation_survey_19`, `number`, required): This field asks for the number of mixes you create in a typical month.
* **How many tracks per week do you create?** (`mix_creation_survey_20`, `number`, required): This field asks for the average number of mixes you create per week.
* **Do you have a regular schedule?** (`mix_creation_survey_21`, `select_one`, required): This field asks if you create mixes on a regular schedule. Please select 'Yes' if you have a schedule, and 'No' otherwise.
* **What is your schedule type?** (`mix_creation_survey_22`, `text`, optional): This field is for any details about your schedule.
* **Do you have any mentors?** (`mix_creation_survey_23`, `select_one`, required): This field asks if you have someone who guides you in mix creation. Please select 'Yes' if you have a mentor, and 'No' otherwise.
* **What is your mentorship status?** (`mix_creation_survey_24`, `text`, optional): This field is for any details about your mentorship.
* **Do you have any role models?** (`mix_creation_survey_25`, `select_one`, optional): This field asks if you have people you look up to for inspiration or guidance. Please select 'Yes' if you have role models, and 'No' otherwise.

## Tips
* Make sure to answer truthfully and accurately.
* If you are unsure about any question, please ask for clarification.
* You can ask us if you need help or have any questions about the survey.
