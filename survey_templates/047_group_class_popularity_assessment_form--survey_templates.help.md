# Group Class Popularity Assessment Form - Help Guide
## Purpose
This form is used to collect user input on the popularity of group classes, including schedule demand, class length, class frequency, and class type.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Answer the questions on each page, selecting the most relevant options for your preferences.
2. Make sure to fill out all the required fields (indicated by an asterisk*) as they are necessary to process your response.
3. If a field does not apply to you, please select "Other" and provide a brief explanation in the corresponding text box.
