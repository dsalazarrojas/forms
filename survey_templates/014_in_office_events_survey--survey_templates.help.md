# In Office Events Survey - Help Guide

## Purpose
The "In Office Events Survey" form is designed to collect information about office events. It is intended for internal use and should only be completed by authorized personnel.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Name** in the text field provided.
2. Select the **Event Date** and **Event Time** using the respective date and time fields.
3. Provide a brief description of the event in the **Event Description** field.
4. List the **Attendees** in the text field.
5. Add any **Comments** related to the event.
6. Select the **Event Suggestions** using the text field.
7. Choose whether the event had a **Yes** or **No** for the **Event Priorities** question.
8. Select the **Likert Scale** for the **Event Likert Scale** question.
9. Provide additional details for the **Likert Scale Label** question.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required: false): Enter the name of the event in this field.
* **Event Date** (`event_date`, date, required: false): Select the date of the event from the calendar or enter the date manually.
* **Event Time** (`event_time`, time, required: false): Select the time of the event from the clock or enter the time manually.
* **Event Description** (`event_description`, text, required: false): Provide a brief description of the event.
* **Attendees** (`attendees`, text, required: false): List the names of the attendees of the event.
* **Comments** (`comments`, text, required: false): Add any comments or observations related to the event.
* **Event Suggestions** (`event_suggestions`, text, required: false): Enter any suggestions for future events.
* **Event Priorities** (`event_priorities`, select_multiple, required: false): Select all that apply for event priorities.
* **Event Likert Scale** (`event_likert`, select_one, required: false): Select the Likert scale for the event.
* **Likert Scale Label** (`event_likert_label`, text, required: false): Provide additional details for the Likert scale.
* **Likert Scale Label 1** (`event_likert_label_1`, text, required: false): Enter the label for the first Likert scale option.
* **Likert Scale Label 2** (`event_likert_label_2`, text, required: false): Enter the label for the second Likert scale option.
* **Likert Scale Label 3** (`event_likert_label_3`, text, required: false): Enter the label for the third Likert scale option.

**Tips**

* Ensure that all fields are filled in completely and accurately.
* Review the form carefully before submitting to ensure that all information is correct.
* If you need to add or remove questions, contact the form administrator.
* If you have any issues with the form, contact the help desk.
