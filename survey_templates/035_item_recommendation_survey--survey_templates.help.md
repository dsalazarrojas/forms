# Item Recommendation Survey - Help Guide
## Purpose
This form is used to collect information about items and their respective users. It is a tool to help you get to know users better and improve our services.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out each section carefully and accurately.
2. Make sure to provide all required information for the item and user.
3. If a field is marked as required, it is necessary to fill out this field.
4. If you are unsure about any of the fields, please refer to the Field-by-Field Explanation section.

## Field-by-Field Explanation

* **Item Name** (`item_name`, text, optional): Enter the name of the item being recommended.
* **item id** (`item_id`, number, optional): Enter the unique identifier for the item.
* **User Id** (`user_id`, number, optional): Enter the unique identifier for the user.
* **item status** (`item_status`, text, optional): Enter the current status of the item (e.g., pending, approved, etc.).
* **item category** (`item_category`, text, optional): Enter the category of the item (e.g., electronics, clothing, etc.).
* **User Status** (`user_status`, text, optional): Enter the current status of the user (e.g., active, inactive, etc.).
* **item description** (`item_description`, text, optional): Enter a short description of the item.
* **user description** (`user_description`, text, optional): Enter a short description of the user.
*   Please note that all fields are optional except for "Item Name", which is only required if the item exists. If the item does not exist, do not fill this field and proceed with the rest of the form.
*   If you need help with anything, do not hesitate to ask your supervisor or colleague.
