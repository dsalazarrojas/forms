# Public Art Installation Voting Form - Help Guide
## Purpose
This form is used to gather opinions and feedback about a public art installation. It will help the organizers of the public art installation to better understand the community's interest and preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read the information about the public art installation and review the questions.
2. Answer each question carefully and accurately.
3. Make sure to complete all required fields, marked as "required".
4. You can also add comments to provide more information about your opinion.
5. Once you have finished, click the submit button to send your feedback to the organizers.

## Field-by-Field Explanation

* **Introduction**: This is a short description of the public art installation and its purpose.
* **Public Art Installation Name**: This is the name of the public art installation. Please enter the actual name of the installation.
* **Location**: This is the location where the public art installation is or will be situated. Please enter the address or name of the location.
* **Artist**: This is the name of the artist who created the public art installation. Please enter the actual name of the artist.
* **Image**: This is a brief description of what the public art installation looks like. Please enter a brief description of the installation's image.
* **Description**: This is a more detailed description of the public art installation. Please enter a brief description of the installation.
* **Vote**: This is your opinion about the public art installation. You can choose more than one option by selecting multiple items from the list.
	+ **Yes**: You are interested in installing this public art installation in your city.
	+ **No**: You are not interested in installing this public art installation in your city.
* **Comments**: This is a space for you to add any additional comments or thoughts about the public art installation.
* **Name**: This is your name, which will be used to identify you as the person who submitted the feedback. Please enter your actual name.
