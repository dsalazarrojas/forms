# Top Fail Voting Survey - Help Guide
## Purpose
This form is intended to collect feedback from stakeholders on events, campaigns, or content that failed in some way. This feedback will help identify areas of improvement for future projects.

## How To Complete This Form
To complete this form, follow these steps:

* Select the correct event type from the dropdown menu.
* Input a severity rating from 1-10 to indicate how severe the failure was.
* Provide a description of the event in the text field.
* If desired, input additional explanations or comments in the explanations field.
* Specify if you have any audience feedback or comments in the audience feedback field.
* Choose the correct output type for the form results.
* If desired, input a file name or path in the output file field.
* If desired, select additional options in the votes field.
* Specify which tool was used during the event in the assigned tool field.
* Finally, input the form ID if it's available.

## Field-by-Field Explanation
- **Event Type** (`event_type`, select-one): Select the type of event, campaign, or content that failed.
  * Event: For standard event failures.
  * Campaign: For failures during a campaign.
  * Content: For failures of content.
  * Other: For any other type of event.
- **Severity Rating** (`severity_rating`, number): Input a rating from 1-10 to indicate how severe the failure was.
- **Description** (`description`, text): Provide a brief description of the event.
- **Votes** (`votes`, select_multiple): Select any additional options for your vote. 
  * None: No vote.
  * Other: Select an other option.
- **Rating** (`rating`, number): Input a rating from 1-10 to indicate how severe the failure was.
- **Explanations** (`explanations`, text): Provide any additional explanations or comments.
- **Audience Feedback** (`audience_feedback`, text): Provide any additional feedback or comments from the audience.
- **Output Type** (`output_type`, select-one): Choose the correct output type for the form results.
  * Output for Event: For event specific outputs.
  * Output for Campaign: For campaign specific outputs.
  * Output for Content: For content specific outputs.
  * Other: For other outputs.
- **Output** (`output`, select_multiple): Select any additional options for your output.
  * None: No output.
  * Other: Select an other option.
- **Output File** (`output_file`, text): Input a file name or path.
- **Assigned Tool** (`assigned_tool`, text): Specify which tool was used during the event.
- **Form ID** (`form_id`, text): Input the form ID if it's available.
