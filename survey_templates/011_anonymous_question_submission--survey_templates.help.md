# Anonymous Question Submission - Help Guide
## Purpose
This form is used to submit anonymous questions and feedback related to events or meetings. It collects relevant information such as the event name, category of the question, and priority level of the question, along with other details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event or Meeting Name** in the first field.
2. Select the **Category** of the question from the provided options.
3. Type your **Question** clearly and concisely in the second field.
4. Provide any additional **Background or Context** that may help answer your question (optional).
5. Select the **Priority Level** of your question from the available options.
6. Specify who you think should answer your question.
7. Decide whether you would like the question to be answered publicly or via a general update.
8. Lastly, rate how easy it was to submit this question.

## Field-by-Field Explanation
- **Event or Meeting Name**: Enter the name of the event or meeting this question is related to.
    * Type: text
    * Required: false
    * Hint: Which session is this question for?
- **Question Category**: Select the category that best fits your question from the provided options.
    * Type: select_one
    * Options: Human Resources, Project Operations, Strategy, Finance, General Inquiry
    * Required: true
- **Your Question**: Type your question clearly and concisely.
    * Type: text
    * Required: true
    * Hint: Please be clear and concise
- **Background or Context (Optional)**: Provide any additional details that may help answer your question.
    * Type: text
    * Required: false
    * Hint: Provide detail to help us answer better
- **Priority Level**: Select the priority level of your question from the available options.
    * Type: select_one
    * Options: Low, Medium, High, Critical
    * Required: true
- **Who Should Answer**: Specify who you think should answer your question.
    * Type: text
    * Required: false
    * Hint: e.g. CEO, Dept Manager
- **Would you like this question answered publicly or via general update?**: Decide how you would like your question to be answered.
    * Type: select_one
    * Options: Yes, publicly, No, via general update
    * Required: true
- **How easy was it to submit this question?**: Rate how easy it was to submit this question.
    * Type: number
    * Required: false
