# Airbnb Guest Check Out Form - Help Guide
## Purpose

The Airbnb Guest Check Out Form is a crucial tool for guests to report their departure experience, providing valuable insights for hosts to improve their properties and services.

## How To Complete This Form

1. Please answer each field carefully, providing as much detail as possible.
2. Ensure all required fields are filled in accurately and completely.
3. Use the provided options for select_one fields to choose the best fit for your experience.
4. For text fields, provide a clear and concise explanation.

## Field-by-Field Explanation

* **Guest name** (`guest_name`, text, optional): This field is for you to input your name for contact and reference purposes.
* **Check out date** (`check_out_date`, date, required): Enter the date you departed the property to ensure accurate tracking and follow-up.
* **Condition of property at check out** (`condition_of_property`, select_one, required):
	+ Choose Good if everything was in order upon departure.
	+ Select Minor issues if there were some minor damages or issues that don't require further action.
	+ Choose Major issues if there were significant damages or issues that need host attention.
* **Feedback on stay experience** (`feedback_on_stay`, text, optional): Share your thoughts on your stay, including any positive experiences or suggestions for improvement.
* **Additional charges reported** (`additional_charges`, number, optional): If you incurred any extra fees or charges during your stay, enter them here.
* **Would you recommend this property** (`recommend_to_others`, select_one, optional):
	+ Choose True if you would recommend the property to others.
	+ Select Maybe if you're unsure or need more time to decide.
	+ Choose False if you wouldn't recommend the property.
* **Host response needed** (`host_response_needed`, select_one, optional):
	+ Choose True if you require the host to follow up on any issues or concerns.
	+ Select False if the host doesn't need to respond.
* **Final comments from guest** (`final_comments`, text, optional): Add any additional comments or details that might be helpful for the host to know.

## Tips

* Be honest and thorough in your answers, as this form helps hosts improve their services and properties.
* If you have any concerns or issues, use the space provided to explain them in detail.
* Ensure all required fields are completed to enable hosts to follow up and address any concerns.
