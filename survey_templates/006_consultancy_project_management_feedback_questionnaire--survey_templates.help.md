# Consultancy Project Management Feedback Questionnaire - Help Guide
## Purpose
This form is designed to gather feedback from clients on their experience with a consultancy project. The goal is to understand how well the project met its objectives, the consultant's performance, and the overall satisfaction with the project's outcome.

## How To Complete This Form
1. Fill out the form completely and truthfully.
2. Provide your name and email address so that we can follow up with you.
3. Answer each question in a way that reflects your genuine experience with the project.

## Field-by-Field Explanation
* **Client Name** (`client_name`, `text`, required): This is the name of the client or organization that you represented or worked with.
* **Client Email Address** (`client_email`, `email`, required): This is the email address where we can follow up with you for further questions or clarification.
* **Project Name** (`project_name`, `text`, required): This is the name or title of the project that we worked on.
* **Project Start Date** (`project_start_date`, `date`, required): This is the date when the project began.
* **Project End Date** (`project_end_date`, `date`, required): This is the date when the project was completed.
* **Consultant Name** (`consultant_name`, `text`, required): This is the name of the consultant assigned to your project.
* **Overall Satisfaction Rating** (`overall_satisfaction`, `select_one`, required): Rate your overall satisfaction with the project's outcome using the provided scale.
* **Were Project Objectives Met** (`project_objectives_met`, `select_one`, required): Select how well the project achieved its objectives using the provided scale.
* **Communication Rating** (`communication_rating`, `select_one`, required): Rate the consultant's communication using the provided scale.
* **Professionalism Rating** (`professionalism_rating`, `select_one`, required): Rate the consultant's professionalism using the provided scale.
* **Technical Expertise Rating** (`expertise_rating`, `select_one`, required): Rate the consultant's technical expertise using the provided scale.
* **Timeline Adherence** (`timeline_adherence`, `select_one`, required): Select how well the project stayed on schedule using the provided scale.
* **Budget Adherence** (`budget_adherence`, `select_one`, required): Select how well the project stayed within budget using the provided scale.
* **Quality of Deliverables** (`deliverable_quality`, `select_one`, required): Rate the quality of project deliverables using the provided scale.
* **Problem Solving Effectiveness** (`problem_solving`, `select_one`, required): Rate how well issues were resolved using the provided scale.
* **Project Strengths** (`strengths`, `text`, required): Describe what went well during this project.
* **Areas for Improvement** (`areas_for_improvement`, `text`, required): Describe what could be improved in future projects.
* **Challenges Faced** (`challenges_faced`, `text`, optional): Describe any challenges encountered during the project (optional).
* **Would You Recommend Our Services** (`would_recommend`, `select_one`, required): Select if you would recommend our services to others using the provided scale.
* **Interest in Future Collaboration** (`future_collaboration`, `select_one`, required): Select if you would work with us again using the provided scale.
* **Additional Services of Interest** (`additional_services_needed`, `select_multiple`, optional): Select any other services you might need in the future.
* **Additional Comments** (`additional_comments`, `text`, optional): Any other feedback or suggestions you might have.
