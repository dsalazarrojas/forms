# Flashcard Creation Survey - Help Guide
## Purpose
This survey is designed to gather information about your habits and preferences related to flashcards.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select all applicable platforms from the list for "Platforms used".
2. Choose the content types that you use flashcards for from the list.
3. Select your preferred frequency of use for each question (e.g., Daily, Weekly, Monthly, Yearly).
4. Specify any other platforms or content types not listed if applicable.

## Field-by-Field Explanation

* **Platforms used** (`platform_used`, select_multiple, not required): Please select all platforms you use for flashcards, such as Anki, Quizlet, AnkiDroid, or None.
* **How often do you use flashcards?** (`frequency_use`, select_one, not required): Choose how often you use flashcards, from Daily, Weekly, Monthly, or Yearly.
* **Content Types** (`content_types`, select_multiple, not required): Select the types of content you use flashcards for, such as Vocab, Grammar, Idioms, Formula, or None.
* **Other Content Types** (`content_other`, text, not required): If you have a different type of content not listed, specify it in this field.
* **How often do you create flashcards?** (`frequency_create`, select_one, not required): Choose how often you create flashcards, from Daily, Weekly, Monthly, or Yearly.
* **Desired Features** (`desired_features`, select_multiple, not required): Select any desired features you have for flashcards, such as 'Yes' or 'No'.
* **How often do you share flashcards?** (`frequency_share`, select_one, not required): Choose how often you share flashcards, from Daily, Weekly, Monthly, or Yearly.
* **How often do you learn from flashcards?** (`frequency_learn`, select_one, not required): Choose how often you learn from flashcards, from Daily, Weekly, Monthly, or Yearly.
* **Anki** (`platforms_anki`, select_multiple, not required): Select if you use Anki, 'Yes' or 'No'.
* **AnkiDroid** (`platforms_anki_droid`, select_multiple, not required): Select if you use AnkiDroid, 'Yes' or 'No'.
* **Quizlet** (`platforms_quizlet`, select_multiple, not required): Select if you use Quizlet, 'Yes' or 'No'.
* **Email** (`email`, email, not required): If you have an email address associated with flashcards, please enter it here.
* **Phone** (`phone`, text, not required): If you have a phone number associated with flashcards, please enter it here.
* **Other Platforms** (`platforms_other`, text, not required): If you use other platforms not listed, specify them here.
* **Frequency Use Other** (`frequency_use_other`, text, not required): If you use other platforms, specify how often you use them.
* **Other Content Types** (`content_other`, text, not required): If you use other content types not listed, specify them here.
