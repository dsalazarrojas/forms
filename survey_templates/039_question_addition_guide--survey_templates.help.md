# Question Addition Guide - Help Guide

## Purpose
<thinking>
This form is designed to add new questions to a survey template. The purpose of this form is to provide a structured way to create and manage questions for surveys, quizzes, and assessments. To ensure that each question is relevant and accurately categorized, we recommend carefully reviewing the form's fields before submitting.

Before proceeding, please make sure you have a good understanding of the question you want to add, as well as the survey template you are using.
</thinking>

## How To Complete This Form
1. Fill in the title of the question in the **question-addition-guide** field.
2. Provide a description of the question in the **form-description** field.
3. Select the relevant category for the question from the **category** field.
4. Ensure that the category is consistent across all fields for the same question.
5. You can add additional descriptions for the question in the **description-2**, **description-3**, and so on fields, if necessary.
6. Review your answers and submit the form when complete.

## Field-by-Field Explanation
* **question-addition-guide** (`form_title`, text, required/optional): Enter a concise and descriptive title for the question.
* **form-description** (`form_description`, text, required/optional): Describe the question in detail, including any necessary context or background information.
* **category** (`category`, select_multiple, required): Select the category that best fits the question from the options provided. This will help in organizing and filtering questions in the future.
* **category** (`form_category`, select_one, required): Confirm the category for the question. This ensures consistency and accuracy in categorization.
* **category** (`form_category_2`, select_one, required): Confirm the category for the question again. This further ensures consistency and accuracy in categorization.
* **category** (`form_category_3`, select_one, optional): Select the category for the question if not previously selected.
* **category** (`form_category_4`, select_one, optional): Select the category for the question if not previously selected.
