# Tajweed Rules Knowledge Quiz - Help Guide
## Purpose
This form is designed to test your knowledge of Tajweed rules, a set of principles used in the Islamic tradition of reciting the Quran. You will be asked to select all the applicable options for each of the 25 questions.

## How To Complete This Form
1. Read each question carefully.
2. Select all the applicable options for each question using the select_multiple type of question.
3. Answer all questions before submitting the form.

## Field-by-Field Explanation
* **First Question** (`First Question`, text, optional): This is the first question of the quiz. Please answer it as accurately as possible.
* **Tajweed Rule 1** (`Tajweed Rule 1`, select_multiple, optional): This question asks about the nature of Tajweed rules. Select all that apply.
	+ What is a Tajweed rule?
	+ A set of principles
	+ A set of rules
* **Tajweed Rule 2** (`Tajweed Rule 2`, select_multiple, optional): This question is similar to the previous one and asks about the same nature of Tajweed rules.
* **Tajweed Rule 3** (`Tajweed Rule 3`, select_multiple, optional): This question asks about the specific rules of the Quran. Please select all that apply.
	+ Rules for the Quran
	+ Rulings for Tajweed
* ... (repeat for each question, with each question having two options: "Rules for the Quran" and "Rulings for Tajweed")

## Tips
