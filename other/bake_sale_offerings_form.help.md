# Untitled Form - Help Guide

## Purpose
The "Untitled Form" is a survey template designed to gather information about bake sale offerings. This form is intended to collect data on various aspects of bake sales, including offerings, pages, and other relevant details.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Select the correct page for each question by clicking on the corresponding "Next" button.
2. For each field, enter the requested information in the provided format (e.g., text, date, time, etc.).
3. Make sure to fill out all required fields as they are marked with an asterisk (\*).
4. If a field is not required, you can leave it blank or enter a placeholder value if desired.
5. Once you have completed all pages, click "Submit" to submit your responses.
