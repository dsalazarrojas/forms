# Baking Class Signup Form - Help Guide
## Purpose
The Baking Class Signup Form is designed to collect information from students who want to enroll in a baking class. The form is intended for instructors or administrators to manage class capacity and student records.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name in the **First Name** field.
2. Enter your last name in the **Last Name** field.
3. Enter a valid email address in the **Email** field.
4. Enter your phone number in the **Phone** field.
5. Select your preferred baking class time slot from the **Baking Class** dropdown menu.
6. Choose a date for the **Session Date** field. Use the format MM/DD/YYYY.
7. Select the time for the **Session Time** field. The format is 12:00 AM.
8. If you are signing up with a group, enter the number of participants in the **Participant Count** field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter your first name. Please keep in mind that this field is optional.
* **Last Name** (`last_name`, text, optional): Enter your last name. This field is also optional.
* **Email** (`email`, email, optional): Enter a valid email address. This will help us contact you with class information and updates.
* **Phone** (`phone`, text, optional): Enter your phone number. This is not a required field, but it can help us reach you if we need to.
* **Baking Class** (`baking_class`, select_one, optional): Select your preferred baking class time slot. This will help us schedule the class accordingly.
* **Session Date** (`session_date`, date, optional): Choose a date for the baking class. Use the format MM/DD/YYYY.
* **Session Time** (`session_time`, time, optional): Select the time for the baking class. The format is 12:00 AM.
* **Participant Count** (`participant_count`, number, optional): If you are signing up with a group, enter the number of participants. This will help us plan for class capacity.

## Tips
- Ensure that you are signing up for the correct baking class.
- Double-check your email address and phone number for accuracy.
- Be mindful of the date and time you select, as these will be used to schedule the class.
- If you are signing up with a group, enter the correct participant count to help us plan for class capacity.
