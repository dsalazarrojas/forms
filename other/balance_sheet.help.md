# Balance Sheet - Help Guide
## Purpose
This guide explains how to complete the Balance Sheet form, a tool used for creating or updating account information.

## How To Complete This Form
To start, follow these steps:

1. Enter the balance sheet title to describe the current state of your account.
2. Select the date of the balance sheet, if applicable.
3. Enter the account balance amount and select the currency used for the balance.
4. Choose the type of account from the options provided: Checking, Savings, Credit, or Other.
5. If you selected Other, provide additional details in the Other Details field.
6. Fill in any other required fields as needed, such as Bank Name, Account Number, Branch Location, and Account Balance Other and Account Balance Currency Other.

## Field-by-Field Explanation
* **Balance Sheet** (`balance_sheet`): Enter a descriptive title for the balance sheet.
* **Date** (`date`): Select the date of the balance sheet.
* **Account Balance** (`account_balance`): Enter the account balance amount.
* **Account Balance Currency** (`account_balance_currency`): Select the currency used for the balance.
* **Account Type** (`account_type`): Choose the type of account from the options: Checking, Savings, Credit, or Other.
* **Other** (`account_type_other`): If you selected Other, provide additional details about the account type in this field.
* **Bank Name** (`bank_name`): Enter the name of the bank associated with the account.
* **Account Number** (`account_number`): Enter the account number.
* **Branch Location** (`branch_location`): Enter the branch location.
* **Account Balance Other** (`account_balance_other`): If you need to add extra information about the account balance, use this field.
* **Account Balance Currency Other** (`account_balance_currency_other`): If you need to add extra information about the account balance currency, use this field.
* **Other Details** (`account_type_other_details`): If you selected Other as the Account Type, provide additional details about the account in this field.
* **Account Details** (`account_type_details`): Enter any other details about the account, if needed.
