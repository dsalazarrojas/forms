# untitled_form - Help Guide
## Purpose
The untitled_form is a basic order information template. It is intended to collect order details and customer contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the order information in the Order Info field. This field is a text box where you can type in any relevant order details.
2. Select the type of order being placed in the Order Type dropdown menu. You can choose between "Yes" or "No".
3. Enter the date of the order in the Order Date field. This field is a date picker that will allow you to select a date.
4. Enter the time of the order in the Order Time field. This field is a time picker that will allow you to select a time.
5. Select additional contact information for the customer in the Contact Info dropdown menu. You can choose between "Yes" or "No".
6. Add any additional notes about the customer in the Customer Notes field. This field is a free text area where you can type in any relevant details.
7. Enter the customer's email address in the Customer Email field.
8. Enter the customer's phone number in the Customer Phone field.

## Field-by-Field Explanation
- **Order Info** (text): Enter any relevant order information. This field is used to collect any additional details about the order.
  - **Order Type** (select_one): Select the type of order being placed. Choose between "Yes" or "No".
  - **Order Date** (date): Enter the date of the order.
  - **Order Time** (time): Enter the time of the order.
  - **Contact Info** (select_multiple): Select additional contact information for the customer. Choose between "Yes" or "No".
  - **Customer Notes** (note): Add any additional notes about the customer.
  - **Customer Email** (email): Enter the customer's email address.
  - **Customer Phone** (phone): Enter the customer's phone number.
