# covid_daily_health_screening_form - Help Guide
## Purpose
This form is used for conducting a daily health screening of COVID-19 patients.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the "Patient Name" field.
2. Fill in the patient's contact number in the "Contact Number" field.
3. Enter the patient's email address in the "email" field.
4. Select all the symptoms that the patient is currently experiencing from the options under "Temperature Check", "cough", "Shortness of Breath", "Sore Throat", and other fields.
5. Indicate whether the patient has recently traveled or had recent contact with a confirmed COVID-19 case in the respective fields.

## Field-by-Field Explanation

* **Patient Name** (text): Enter the patient's full name.
* **Contact Number** (text): Enter the patient's contact number.
* **email** (email): Enter the patient's email address.
* **Temperature Check** (select multiple): Select all the symptoms related to temperature checks that the patient is experiencing.
*   - **Fever**: Select if the patient has a fever.
*   - **Chills**: Select if the patient is experiencing chills.
*   - **Cough**: Select if the patient has a cough.
*   - **Shortness of Breath**: Select if the patient has difficulty breathing.
*   - **Sore Throat**: Select if the patient has a sore throat.
* **cough** (select multiple): Select the severity of the patient's cough.
*   - **Mild Cough**: Select if the patient has a mild cough.
*   - **Severe Cough**: Select if the patient has a severe cough.
* **Shortness of Breath** (select multiple): Select the severity of the patient's shortness of breath.
*   - **Mild**: Select if the patient has mild shortness of breath.
*   - **Severe**: Select if the patient has severe shortness of breath.
* **Sore Throat** (select multiple): Select the severity of the patient's sore throat.
*   - **Mild**: Select if the patient has a mild sore throat.
*   - **Severe**: Select if the patient has a severe sore throat.
* **Chest Pain** (select multiple): Select the severity of the patient's chest pain.
*   - **Mild**: Select if the patient has mild chest pain.
*   - **Severe**: Select if the patient has severe chest pain.
* **Fatigue** (select multiple): Select the severity of the patient's fatigue.
*   - **Mild**: Select if the patient has mild fatigue.
*   - **Severe**: Select if the patient has severe fatigue.
* **Recent Travel** (select multiple): Select if the patient has recently traveled.
*   - **True**: Select if the patient has recently traveled.
*   - **False**: Select if the patient has not recently traveled.
* **Recent Contact** (select multiple): Select if the patient has had recent contact with a confirmed COVID-19 case.
*   - **True**: Select if the patient has recently had contact.
*   - **False**: Select if the patient has not recently had contact.
* **Symptoms Start** (date): Enter the date when the patient's symptoms started.
* **Symptoms End** (date): Enter the date when the patient's symptoms ended.
* **Last Contact Date** (date): Enter the date of the patient's last contact with a confirmed COVID-19 case.
* **Last Test Date** (date): Enter the date of the patient's last test for COVID-19.
* **Vaccination Status** (select multiple): Select the patient's vaccination status.
*   - **Vax 1**: Select if the patient has received the first dose of the vaccine.
*   - **Vax 2**: Select if the patient has received the second dose of the vaccine.
*   - **Vax 3**: Select if the patient has received the third dose of the vaccine.
*   - **False**: Select if the patient has not been vaccinated.
*   - **Unknown**: Select if the patient's vaccination status is unknown.
* **Medical Condition** (text): Enter any other medical conditions the patient may have.
* **Allergy** (text): Enter any allergies the patient may have.
* **Medical History** (text): Enter the patient's medical history.
* **Notes** (note): Enter any additional notes about the patient's condition.

## Tips
* Ensure that you have access to authorized personnel and follow all confidentiality and data security guidelines when using this form.
* Be thorough and accurate when filling out the form to ensure accurate diagnosis and treatment.
* If you are unsure about any information, seek advice from a medical professional.
