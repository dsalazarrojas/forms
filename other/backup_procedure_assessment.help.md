# Untitled Form - Help Guide
## Purpose
The purpose of this form is to collect information about the current state of backup and recovery processes in your organization.

## How To Complete This Form
To complete this form, follow these steps:
1. Answer the questions on each page carefully, providing accurate information about the current backup procedure and associated risks.
2. Be sure to answer all applicable questions, as indicated by the required field marker next to each question.
3. If you are unsure about the purpose or content of a question, contact the relevant department for clarification.

## Field-by-Field Explanation
### What is the current backup procedure?
* **What is the current backup procedure?** (`backup_procedure_assessment`, text, required): This question is asking you to describe the current backup procedure being used in your organization. Please provide a detailed answer in the text field.

### What are the backup risks identified?
* **What are the backup risks identified?** (`backup_risks`, text, required): This question is asking you to list and describe the risks associated with the current backup procedure. Please provide a detailed answer in the text field.

### What are the recovery risks identified?
* **What are the recovery risks identified?** (`recovery_risks`, text, required): This question is asking you to list and describe the risks associated with the current recovery process. Please provide a detailed answer in the text field.

### Is the backup procedure standardized across departments?
* **Is the backup procedure standardized across departments?** (`standardization`, select_one, required): This question is asking you to indicate whether the backup procedure is standardized across all departments in your organization. Please select 'Yes' or 'No' from the dropdown menu.

### Are recovery risks identified?
* **Are recovery risks identified?** (`recovery_risks_identified`, select_multiple, required): This question is asking you to select all applicable recovery risks that have been identified. Please select all relevant options from the dropdown menu.

## Tips
* Please provide accurate and detailed information about the backup procedure and associated risks.
* If you are unsure about any question, contact the relevant department for clarification.
* Make sure to answer all required fields, as indicated by the required marker next to each question.
