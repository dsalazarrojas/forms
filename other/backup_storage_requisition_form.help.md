# Backup Storage Requisition Form - Help Guide
## Purpose
The Backup Storage Requisition Form is a tool used to request backup storage for important files or data to prevent data loss or corruption. Please fill out this form to submit your backup storage request.

## How To Complete This Form
To complete this form, follow these steps:
1. Provide a title for your request in the "Form Title" field.
2. Describe the files or data you want to be backed up in the "description" field.
3. Choose the storage location from the dropdown menu in the "Storage Location" field.
4. Specify the size of storage needed in the "Storage Size" field.
5. Select the type of storage required in the "Storage Type" field.
6. Choose the duration for which you need storage in the "Storage Duration" field.
7. Review and submit your request in the "Form Submit" field.
8. Optionally, cancel your request and start over in the "Form Cancel" field.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, optional): A title for your request.
* **Description** (`form_description`, text, optional): A brief description of the files or data you want to be backed up.
* **Storage Location** (`storage_location`, select_one, optional): The location where you want the backup storage to be stored. Options: Option 1, Option 2, Option 3.
* **Storage Size** (`storage_size`, number, optional): The size of storage needed. Please ensure you enter a valid number.
* **Storage Type** (`storage_type`, select_one, optional): The type of storage required. Options: Option 1, Option 2, Option 3.
* **Storage Duration** (`storage_duration`, date, optional): The duration for which you need storage. Please enter a valid date.
* **Form Submit** (`form_submit_button`, note, optional): Review and submit your request.
* **Form Cancel** (`form_cancel_button`, note, optional): Cancel your request and start over.

Tips:
* Only request backup storage for files or data that are not currently backed up by the organization.
* Double-check that the storage size and duration are accurate to ensure you get the right amount of storage.
* If you are unsure about any field, please ask for assistance from the IT department.
