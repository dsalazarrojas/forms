# Untitled Form - Help Guide
## Purpose
This form is designed to collect details about Baggage Handling Incidents or issues. It helps gather information to categorize incident types and aid in resolving these matters efficiently.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the Baggage Handling Incident Report Form Type (Select one of the options provided)
2. Enter the Incident Date (in the date format)
3. Select the relevant Airport where the incident occurred (from the list of options)
4. Select the Flight Number (as it appears on the flight ticket)
5. Enter the Baggage Tag Number (if available)
6. Fill out the form according to the selected form type's instructions

## Field-by-Field Explanation
- **Baggage Handling Incident Report Form Type** (`baggage_handling_incident_report_form_type`, select_one, required: false): Choose the type of form you are submitting (e.g., Airline, Airport).
- **Incident Date** (`incident_date`, date, required: false): Enter the date on which the incident occurred. This should be in a standard date format (e.g., MM/DD/YYYY).
- **Airport** (`airport`, select_multiple, required: false): Select the airport where the incident happened (e.g., Option 1, Option 2, Option 3). This will help identify the location of the incident.
- **Flight Number** (`flight_number`, text, required: false): Enter the flight number as it appears on the ticket. This will aid in tracking the specific flight associated with the incident.
- **Baggage Tag Number** (`baggage_tag_number`, text, required: false): If possible, enter the baggage tag number for the affected baggage. This might be required for some form types.
 

**Tips:**
- Ensure you select the correct form type according to the incident.
- Be accurate when filling out the date and flight number.
- If required, enter the Baggage Tag Number to help track the affected item.
- Double-check your selections before submitting the form to ensure accuracy.
