# bagel_order_form - Help Guide
## Purpose
The "bagel_order_form" form is a template for customers to place an order for bags. It is used to collect information about the customer's bagel preferences and shipping details.

## How To Complete This Form
To complete this form, follow these steps:
1. **Go to the first page** and enter the desired **Bagel Name** (e.g., "Everything Bagel") in the text field.
2. On the same page, enter the desired **Quantity** of bags you would like to purchase.
3. On the same page, enter the **Price** of the bagel (e.g., if you're using a price calculator or estimate).
4. Move on to the second page and select a **Payment Method** (e.g., Credit Card, PayPal, or Cash).
5. Complete the **Shipping Address**, **Shipping City**, **Shipping State**, and **Shipping Zip** fields with the necessary information for delivery.

## Field-by-Field Explanation
* **Bagel Name** (`bagel_name`, `text`, required/optional): Enter the name of the bagel you would like to order.
* **Quantity** (`quantity`, `number`, required/optional): Enter the number of bags you would like to purchase.
* **Price** (`price`, `number`, required/optional): Enter the price of the bagel (e.g., if you're using a price calculator or estimate).
* **Payment Method** (`payment_method`, `select_one`, required/optional): Select the payment method you would like to use (e.g., Credit Card, PayPal, or Cash).
* **Shipping Address** (`shipping_address`, `text`, required/optional): Enter the shipping address where you would like to receive the bagel.
* **Shipping City** (`shipping_city`, `text`, required/optional): Enter the city where you would like to receive the bagel.
* **Shipping State** (`shipping_state`, `text`, required/optional): Enter the state where you would like to receive the bagel.
* **Shipping Zip** (`shipping_zip`, `text`, required/optional): Enter the zip code where you would like to receive the bagel.
