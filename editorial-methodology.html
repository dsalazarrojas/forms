Editorial Methodology

GIC Forms includes a very large template corpus, but not every record should be treated as an equally strong landing page. The curated guide and category pages are intended to give the site a higher-quality editorial layer.

Selection Principles

  • Prefer templates that already have usable help content.
  • Prefer readable titles over raw slugs, lowercase titles, or underscore-heavy names.
  • Limit the number of pages selected from any single category so the indexed surface is more balanced.
  • Use guide pages to add context, review notes, and links instead of exposing only a generic preview shell.

What Still Requires Review

Even curated pages can contain generic or programmatic source text. Visitors should treat templates as drafts that need domain review before production use.

Ongoing Improvement

The next improvement cycle should focus on title normalization, help content cleanup, richer category intros, and stronger static metadata for the best-performing categories.
