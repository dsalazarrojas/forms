# Travel Agent Offboarding Form - Help Guide
## Purpose
This form is designed to help travel agents offboard their accounts with the company. It will guide them in providing necessary information to ensure a smooth transition of their travel-related responsibilities.

## How To Complete This Form
1. Please answer each question carefully, providing as much detail as possible.
2. Select the correct options for each question, and make sure to select all that apply.
3. If a question is not applicable to your situation, please mark it as "No" or "Not Applicable".
4. Once you have completed all questions, review your answers to ensure they are accurate.

## Field-by-Field Explanation
* **What is your current role**: This field is used to identify your current position or role within the company. Please provide a brief description of your role, including any specific responsibilities or tasks you are currently handling.
* **Travel Agent**: This field is used to confirm that you are a travel agent.
* **Do you have an active travel agent contract**: Please select "True" if you have an active contract, and "False" otherwise.
* **What is the expected date of departure**: This field is used to record your expected departure date. Please enter the date in the format MM/DD/YYYY.
* **What time of day will you be departing**: This field is used to record your expected departure time. Please enter the time in the format HH:MM AM/PM.
* **Will you be returning to your office**: Please select "True" if you plan to return to the office, and "False" otherwise.
* **What is your expected return date**: This field is used to record your expected return date. Please enter the date in the format MM/DD/YYYY.
* **Do you have any outstanding work items**: Please select all that apply to your outstanding work items.
* **What type of support do you require**: Please select the type of support you need (Phone, Email, or In Person).
* **What time of day will you be returning**: This field is used to record your expected return time. Please enter the time in the format HH:MM AM/PM.
