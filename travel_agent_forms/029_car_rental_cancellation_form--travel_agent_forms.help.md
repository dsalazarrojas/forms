# Car Rental Cancellation Form - Help Guide

## Purpose

This form is for customers to cancel their car rental reservations. Please provide the necessary information to complete the cancellation process.

## How To Complete This Form

1. Fill out the form completely, making sure to enter all required fields.
2. Review and confirm your request by checking the boxes for each field.
3. Click "Submit" to finalize your cancellation request.

## Field-by-Field Explanation

* **Customer Information** (`Customer Information`, note, not required):
	+ A section for providing your contact details.
* **First Name** (`First Name`, text, required):
	+ Your first name.
* **Last Name** (`Last Name`, text, required):
	+ Your last name.
* **Email Address** (`Email Address`, email, required):
	+ The email address you used to make the reservation, for confirmation purposes.
* **Phone Number** (`Phone Number`, text, required):
	+ Your contact number.
* **Street Address** (`Street Address`, text, not required):
	+ Your address.
* **City** (`City`, text, not required):
	+ Your city.
* **State** (`State`, text, not required):
	+ Your state.
* **ZIP Code** (`ZIP Code`, text, not required):
	+ Your ZIP code.
* **Reservation Information** (`Reservation Information`, note, not required):
	+ Details of your reservation.
* **Reservation Number** (`Reservation Number`, text, required):
	+ Confirmation number for your reservation.
* **Rental Start Date** (`Rental Start Date`, date, required):
	+ Original pickup date.
* **Rental End Date** (`Rental End Date`, date, required):
	+ Original return date.
* **Pickup Location** (`Pickup Location`, text, required):
	+ Where you were to pick up the vehicle.
* **Vehicle Category** (`Vehicle Category`, text, not required):
	+ Class of vehicle reserved (e.g. Economy, Compact, SUV).
* **Cancellation Details** (`Cancellation Details`, note, not required):
	+ Information about your cancellation.
* **Cancellation Date** (`Cancellation Date`, date, required):
	+ Today's date for cancellation request.
* **Cancellation Time** (`Cancellation Time`, time, not required):
	+ Time of cancellation request.
* **Cancellation Reason** (`Cancellation Reason`, select_one, required):
	+ Select the reason for cancellation:
		+ Change of plans
		+ Found alternative transportation
		+ Price too high
		+ Vehicle not available
		+ Schedule conflict
		+ Emergency
		+ Illness
		+ Weather conditions
		+ Travel cancelled
		+ Other
* **Cancellation Reason Details** (`Cancellation Reason Details`, text, not required):
	+ Elaborate on your cancellation reason.
* **Cancellation Type** (`Cancellation Type`, select_one, required):
	+ Select the type of cancellation:
		+ Full cancellation
		+ Partial cancellation
		+ Modify reservation
		+ Postpone rental
* **Rebooking Interest** (`Rebooking Interest`, select_one, required):
	+ Select your rebooking interest:
		+ Yes - will rebook soon
		+ Maybe - considering
		+ No - not planning to
* **Preferred Rebooking Date** (`Preferred Rebooking Date`, date, not required):
	+ If you are planning to rebook, enter the date you prefer.
* **Refund Information** (`Refund Information`, note, not required):
	+ Refund details.
* **Was Payment Made?** (`Was Payment Made?`, select_one, required):
	+ Select if you have already paid for the reservation:
		+ Yes - full payment
		+ Yes - deposit only
		+ No - not yet
* **Payment Amount** (`Payment Amount`, number, not required):
	+ Amount paid.
* **Payment Method** (`Payment Method`, select_one, not required):
	+ Select the method of payment:
		+ Credit Card
		+ Debit Card
		+ PayPal
		+ Bank Transfer
		+ Cash
		+ Not applicable
* **Refund Requested** (`Refund Requested`, select_one, required):
	+ Select if you are requesting a refund:
		+ True
		+ False
		+ Unsure
* **Refund Amount Expected** (`Refund Amount Expected`, number, not required):
	+ Expected amount of refund.
* **Refund Method** (`Refund Method`, select_one, not required):
	+ Select the method of refund:
		+ Same as original payment
		+ Credit for future rental
		+ Check by mail
		+ Not applicable
* **Cancellation Fee Acknowledgment** (`Cancellation Fee Acknowledgment`, select_one, required):
	+ Confirm you understand the cancellation fees:
		+ Yes - I understand
		+ No - please explain
* **Feedback** (`Feedback`, note, not required):
	+ Your feedback about our service.
* **Overall Satisfaction** (`Overall Satisfaction`, select_one, not required):
	+ Select your satisfaction level:
		+ Very satisfied
		+ Satisfied
		+ Neutral
		+ Dissatisfied
		+ Very dissatisfied
* **Booking Experience** (`Booking Experience`, select_one, not required):
	+ Select your experience with our booking process:
		+ Excellent
		+ Very good
		+ Good
		+ Fair
		+ Poor
* **Reason Not Satisfied** (`Reason Not Satisfied`, text, not required):
	+ If applicable, explain why you are not satisfied.
* **Would You Recommend Us?** (`Would You Recommend Us?`, select_one, not required):
	+ Select if you would recommend us:
		+ Definitely yes
		+ Probably yes
		+ Maybe
		+ Probably not
		+ Definitely not
* **How Did You Hear About Us?** (`How Did You Hear About Us?`, select_one, not required):
	+ Select your source of referral:
		+ Website
		+ Mobile app
		+ Search engine
		+ Social media
		+ Travel agent
		+ Friend/Family
		+ Advertisement
		+ Previous rental
		+ Other
* **Additional Comments** (`Additional Comments`, text, not required):
	+ Any other information.
* **Contact Preference** (`Contact Preference`, select_one, required):
	+ Select how you would like us to contact you:
		+ Email
		+ Phone call
		+ Text message
		+ No contact needed
* **Cancellation Confirmation** (`Cancellation Confirmation`, select_one, required):
	+ Confirm you want to cancel your reservation:
		+ Yes - please cancel my reservation
* **Signature Confirmation** (`Signature Confirmation`, select_one, required):
	+ Confirm your cancellation request:
		+ I hereby confirm this cancellation request
* **Submission Date** (`Submission Date`, date, required):
	+ Today's date of submission.

### Tips

* Please answer all required fields.
* If you have any additional comments or feedback, please use the "Feedback" field.
* If you are unsure about any field, please contact us.
* Review your answers carefully before submission.
