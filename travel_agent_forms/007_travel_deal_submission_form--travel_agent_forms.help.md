# Travel Deal Submission Form - Help Guide
## Purpose
The Travel Deal Submission Form is designed to collect information about travel deals, which can be used for various purposes, such as promotion, marketing, or internal reference. This form is meant to be completed by travel agents to provide detailed information about the deals they are offering.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate travel category for your submission (Travel Agent Forms)
2. Provide a detailed description of the travel deal in the Description field
3. Enter the title of the travel deal
4. Choose the start and end dates for the travel deal (optional)
5. Enter the duration of the travel deal (optional)
6. Enter the price of the travel deal (optional)
7. Select the currency of the travel deal (optional)
8. Upload any relevant images
9. Enter a short description of the travel deal content
10. Add any relevant tags to the travel deal
11. Review and submit the form

## Field-by-Field Explanation
* **Travel Agent Forms** (`form_category`, select_multiple, required/optional): Select the travel category that this submission belongs to. This field is used to group submissions based on their category.
* **Description** (`form_description`, text, required): Provide a detailed description of the travel deal. This field is mandatory and should be filled in with a clear and concise description.
* **Title** (`form_title`, text, required): Enter a title for the travel deal. This field is mandatory and should be a short and descriptive title.
* **Date** (`form_date`, date, optional): Choose the start and end dates for the travel deal. This field is optional, but it's recommended to be filled in for accurate scheduling.
* **Time** (`form_time`, time, optional): Choose the time for the travel deal. This field is optional and should be filled in only if the start and end dates are selected.
* **Deal Type** (`form_deal_type`, select_one, optional): Select the type of travel deal. This field is optional and should be filled in if the deal type is known.
* **Duration** (`form_duration`, text, optional): Enter the duration of the travel deal. This field is optional and should be filled in if the duration is known.
* **Start Date** (`form_start_date`, date, optional): Choose the start date for the travel deal. This field is optional and should be filled in if the start date is known.
* **End Date** (`form_end_date`, date, optional): Choose the end date for the travel deal. This field is optional and should be filled in if the end date is known.
* **Price** (`form_price`, number, optional): Enter the price of the travel deal. This field is optional and should be filled in if the price is known.
* **Currency** (`form_currency`, select_one, optional): Select the currency of the travel deal. This field is optional and should be filled in if the currency is known.
* **Images** (`form_images`, text, optional): Upload any relevant images for the travel deal. This field is optional and should be filled in if images are provided.
* **Content** (`form_content`, text, required): Enter a short description of the travel deal content. This field is mandatory and should be filled in with a clear and concise description.
* **Tags** (`form_tags`, text, optional): Add any relevant tags to the travel deal. This field is optional and should be filled in if tags are known.
* **Submit** (`form_submit`, note, not applicable): This field is not a form field but rather a submit button to submit the form.
* **Category Tags** (`form_category_tags`, select_multiple, optional): Select any relevant category tags for the travel deal. This field is optional and should be filled in if category tags are known.

Note: Remember to review your submission before submitting to ensure it meets the required fields and is accurate and complete.
