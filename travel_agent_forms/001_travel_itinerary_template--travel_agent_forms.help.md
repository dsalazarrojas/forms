# Travel Itinerary Template - Help Guide

This form is designed to help travel agents create travel itineraries for their clients. It includes fields for collecting essential travel information, making it a valuable tool for planning and organizing trips.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the `travel_agent_info` field, which is a text field where you can enter your name and any other relevant details about yourself as a travel agent.
2. Choose the correct option for `travel_dates`, which is a select field that asks for the travel dates.
3. Enter the travel details in the `travel_details` field, a text field for free-form description of the trip.
4. Add any additional notes in the `travel_notes` field, also a text field.
5. Select the travel destination from the `travel_destination` field, which offers three options.

* **travel_dates** (travel_dates, select_one, optional): Choose the travel dates from the available options.

* **travel_notes** (travel_notes, text, optional): Add any additional notes about the trip.
* **travel_destination** (travel_destination, select_one, optional): Select the travel destination from the available options.
* **travel_duration** (travel_duration, number, optional): Enter the duration of the trip in units (e.g., days).
