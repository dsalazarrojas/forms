# Travel Agent Booking Form - Help Guide

## Purpose

The Travel Agent Booking Form is a document designed to gather information from travel agents for booking purposes.

## How To Complete This Form

To use this form, follow these steps:

1. **Enter Client Name**: Type the client's name into this field.
2. **Select travel_date**: Choose the date of the travel using the calendar.
3. **Enter flight_number**: Type the flight number in this field.
4. **Enter travel_agent_id**: Type the travel agent's ID.
5. **Enter travel_agency_id**: Type the travel agency's ID.
6. **Add Booking Details**: Use this field to add any additional information about the booking.
7. **Add Travel Agency Notes**: Use this field to add any notes or comments about the travel agency.

## Field-by-Field Explanation

* **Client Name** (`client_name`, `text`, required: false): Type the client's name in this field.
* **Travel Date** (`travel_date`, `date`, required: false): Select the date of the travel using the calendar.
* **Flight Number** (`flight_number`, `text`, required: false): Type the flight number in this field.
* **Travel Agent ID** (`travel_agent_id`, `number`, required: false): Type the travel agent's ID.
* **Travel Agency ID** (`travel_agency_id`, `number`, required: false): Type the travel agency's ID.
* **Booking Details** (`booking_details`, `note`, required: false): Use this field to add any additional information about the booking.
* **Travel Agency Notes** (`travel_agency_notes`, `text`, required: false): Use this field to add any notes or comments about the travel agency.
