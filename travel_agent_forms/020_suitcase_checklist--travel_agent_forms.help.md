# Suitcase Checklist - Help Guide

## Purpose
The Suitcase Checklist form is used by travel agents to quickly scan and assess the contents of a traveler's suitcase. This helps ensure that all necessary documents and items are present, and allows agents to provide assistance if anything is missing or incorrect.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each category of the form, which includes:
	* Contents (Page 1)
	* Travel Documents (Page 2)
	* Clothing (Page 3)
	* Accessories (Page 4)
	* Toiletries (Page 5)
2. Select the correct response for each category:
	* For "Travel Documents", select "Yes" if you have a Passport, ID card, or other relevant documents.
	* For "Clothing", select "Yes" if you have clothing and "No" if you do not.
	* For "Accessories" and "Toiletries", select "Yes" if you have the item and "No" if you do not.
3. Make sure to review each page carefully to ensure accuracy.

## Field-by-Field Explanation

* **Contents** (`Contents`, `note`, not required): This page is used to record any notes or comments about the contents of the suitcase. Please provide any relevant information about the items packed or any issues noticed.
* **Travel Documents** (`Travel Documents`, `select_multiple`, not required): This page asks you to confirm whether you have all necessary travel documents, such as a Passport, ID card, or other relevant documents. Select "Yes" if you have all the required documents, or "No" if you do not.
* **Clothing** (`Clothing`, `select_one`, not required): This page asks you to confirm whether you have clothing packed in the suitcase. Select "Yes" if you have clothing, or "No" if you do not.
* **Accessories** (`Accessories`, `select_multiple`, not required): This page asks you to confirm whether you have any accessories packed in the suitcase, such as chargers, adapters, etc. Select "Yes" for each item you have, or "No" for each item you do not.
* **Toiletries** (`Toiletries`, `select_one`, not required): This page asks you to confirm whether you have any toiletries packed in the suitcase, such as toiletries, etc. Select "Yes" if you have toiletries, or "No" if you do not.

## Tips
* Make sure to carefully review each page to ensure accuracy.
* If you need assistance, select "No" for any items you are unsure about.
* If you have any issues or concerns, please contact the travel agent for help.
