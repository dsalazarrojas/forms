# Prophets - Help Guide
## Purpose
This form is designed for travel agents to input information about tours and travel services. It captures details such as tour name, location, dates, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the travel agent information, including the travel agent's name, email, phone number, and address.
2. Select the start and end dates for the tour.
3. Choose the location services and transportation options, including whether you will be offering services such as tours, transportation, and pickup.
4. Input any additional tour details, including the tour name, transportation type, and pickup type.
5. Provide a description of the tour and its services.
6. Set the tour duration and price.
7. Select any suggested areas of interest for the tour.
8. Input any notes or comments about the tour.

## Field-by-Field Explanation

* **Travel Agent** (1, text, required: false): Enter the name of the travel agent responsible for the tour.
* **Name** (2, text, required: false): Enter the name of the tour.
* **Email** (3, text, required: false): Enter the email address of the travel agent.
* **Phone** (4, text, required: false): Enter the phone number of the travel agent.
* **Address** (5, text, required: false): Enter the address of the travel agent.
* **Start Date** (6, date, required: false): Enter the start date of the tour.
* **End Date** (7, date, required: false): Enter the end date of the tour.
* **Location Services** (8, select_one, required: false): Select whether the tour offers location services such as transportation, parking, and other amenities.
* **Transport Type** (10, select_one, required: false): Select the type of transportation offered for the tour.
* **Pickup Type** (11, select_one, required: false): Select the type of pickup services offered.
* **Pickup Time** (12, time, required: false): Enter the time of pickup for the tour.
* **Pickup Location** (13, text, required: false): Enter the location of pickup for the tour.
* **Tour Duration** (14, number, required: false): Enter the duration of the tour.
* **Tour Description** (15, text, required: false): Enter a description of the tour and its services.
* **Tour Price** (16, number, required: false): Enter the price of the tour.
* **Suggestion Areas** (17, select_multiple, required: false): Select any suggested areas of interest for the tour.
* **Tour Details** (18, text, required: false): Enter any additional details about the tour.
* **Booking Date** (19, date, required: false): Enter the date the tour was booked.
* **Booking Time** (20, time, required: false): Enter the time the tour was booked.
* **Booking Note** (21, text, required: false): Enter any notes about the booking.
* **Pickup Note** (22, text, required: false): Enter any notes about the pickup.
* **Pickup Instructions** (23, text, required: false): Enter any pickup instructions for the tour.
* **Transport Price** (24, number, required: false): Enter the price of transportation for the tour.
* **Notes** (25, note, required: false): Enter any additional notes about the tour.
