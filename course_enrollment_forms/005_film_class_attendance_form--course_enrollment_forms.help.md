# Film Class Attendance Form - Help Guide
## Purpose
The Film Class Attendance Form is used to record and track student attendance in film classes. It helps to maintain up-to-date records of student attendance, which is crucial for instructors to assess the effectiveness of their classes and make necessary adjustments.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Session Id** to identify the class session.
2.  Enter the **Student Id** of the student who attended the session.
3.  Enter the **Student Name** of the student who attended the session.
4.  Select the **Session Date** of the session.
5.  Enter the **Session Time** of the session.
6.  Enter the **Session Start Time** of the session.
7.  Enter the **Session End Time** of the session.
8.  In the **Attended** field, select the number of sessions attended.
9.  In the **Attended All** field, select "Yes" if the student attended all sessions, otherwise select "No".
10. In the **Attended Partially** field, select the number of sessions attended if the student did not attend all sessions.
11. In the **Attended None** field, select "None" if the student did not attend any sessions.
12. Select the **Feedback** level of the session:
    *   "Excellent"
    *   "Good"
    *   "Fair"
    *   "Poor"
13. In the **Did You Attend All Sessions?** field, select "Yes" if you attended all sessions, otherwise select "No".
14. In the **Session Notes** field, enter any notes about the session.
15. In the **Film Notes** field, enter any notes about the film being shown.
16. In the **Session Comments** field, select the level of agreement:
    *   "Agreed"
    *   "Disagreed"
    *   "Neutral"

## Field-by-Field Explanation

*   **Session Id**: Enter the unique identifier for the session.
*   **Student Id**: Enter the unique identifier for the student who attended the session.
*   **Student Name**: Enter the name of the student who attended the session.
*   **Session Date**: Select the date of the session.
*   **Session Time**: Enter the time of the session.
*   **Session Start Time**: Enter the start time of the session.
*   **Session End Time**: Enter the end time of the session.
*   **Attended**: Select the number of sessions attended.
*   **Attended All**: Select "Yes" if attended all sessions, otherwise select "No".
*   **Attended Partially**: Select the number of sessions attended if not all sessions were attended.
*   **Attended None**: Select "None" if no sessions were attended.
*   **Feedback**: Select the level of satisfaction with the session:
    *   "Excellent"
    *   "Good"
    *   "Fair"
    *   "Poor"
*   **Did You Attend All Sessions?**: Select "Yes" if all sessions were attended, otherwise select "No".
*   **Session Notes**: Enter any notes about the session.
*   **Film Notes**: Enter any notes about the film being shown.
*   **Session Comments**: Select the level of agreement with the session:
    *   "Agreed"
    *   "Disagreed"
    *   "Neutral"
