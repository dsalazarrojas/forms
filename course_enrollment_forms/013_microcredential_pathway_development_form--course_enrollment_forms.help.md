# Microcredential Pathway Development Form - Help Guide
## Purpose
The Microcredential Pathway Development Form is a tool used to create and manage microcredential pathways for educational purposes. This form is designed to help users develop and manage pathways for microcredentials, which are a collection of skills, knowledge, or competencies that can be used to demonstrate a specific level of proficiency.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the Form Overview page to understand the purpose and scope of the microcredential pathway.
2. Select the Microcredential Title that best describes the pathway.
3. Choose the Microcredential Category that best fits the pathway.
4. Provide a brief description of the microcredential in the Microcredential Description field.
5. Select the Microcredential Pathway that corresponds to the pathway's requirements.
6. Indicate the level of proficiency required for the microcredential in the Microcredential Level field.
7. Select the current Status of the microcredential in the Microcredential Status field.
8. Enter the start and end dates of the microcredential in the Microcredential Start Date and Microcredential End Date fields.
9. Add contact information for the microcredential in the Microcredential Contact field.
10. Enter the microcredential's email in the Microcredential Email field.
11. Add any additional comments or information about the microcredential in the Microcredential Comments field.

## Field-by-Field Explanation
* **Form Overview**: This page provides a brief overview of the microcredential pathway.
* **Microcredential Title**: Enter the title of the microcredential pathway that best describes it.
* **Microcredential Category**: Select the category that best fits the microcredential pathway.
* **Microcredential Description**: Provide a brief description of the microcredential pathway.
* **Microcredential Pathway**: Select the pathway that corresponds to the microcredential's requirements.
* **Microcredential Level**: Indicate the level of proficiency required for the microcredential.
* **Microcredential Status**: Select the current status of the microcredential.
* **Microcredential Start Date**: Enter the start date of the microcredential.
* **Microcredential End Date**: Enter the end date of the microcredential.
* **Microcredential Contact**: Add contact information for the microcredential.
* **Microcredential Email**: Enter the email address of the microcredential.
* **Microcredential Comments**: Add any additional comments or information about the microcredential.

## Tips
* Make sure to review and update existing microcredential pathways before creating a new one.
* Use the correct categories and pathways to accurately reflect the requirements and scope of the microcredential.
* Enter accurate start and end dates for the microcredential.
* Use the email address associated with the microcredential to ensure proper communication.
* Use the comments field to add any additional information or context about the microcredential.
