# Festival Stage Barrier Booking Form - Help Guide
## Purpose
The Festival Stage Barrier Booking Form is a digital form used by event organizers to book a stage barrier for their event. This form gathers essential details to process and fulfill the barrier booking request.

## How To Complete This Form
To book a stage barrier, please follow these steps:

1. Fill in the required information in each field.
2. Ensure all required fields are filled in before submitting the form.
3. Review and submit the form.

## Field-by-Field Explanation
- **Event Organizer** (`event_organizer`, Text, Required): Enter the name of the event organizer.
- **Barrier Details** (`barrier_details`, Text, Required): Provide a brief description of the barrier.
- **Quantity** (`quantity`, Number, Required): Specify the number of barriers needed.
- **Location** (`location`, Text, Optional): If necessary, provide the location where the barrier will be delivered.
- **Delivery Date** (`delivery_date`, Date, Optional): Select the date for delivery.
- **Delivery Time** (`delivery_time`, Time, Optional): Choose the time for delivery.
- **Barrier Type** (`barrier_type`, Select One, Required): Choose the type of barrier (Stage, Platform, or Fence).
- **Barrier Size** (`barrier_size`, Select Multiple, Required): Select the size of the barrier (Small, Medium, or Large).
- **Contact Person** (`contact_person`, Text, Optional): If you'd like to be contacted for any updates, enter the name of your contact person.
- **Contact Number** (`contact_number`, Text, Optional): Enter the contact number for your contact person.
- **Note** (`note`, Text, Optional): Add any additional notes for the barrier booking.
- **Email** (`email`, Email, Optional): Enter your email address.
- **Email Hint** (`email_hint`, Text, Optional): A hint for your email address.
- **Delivery Timing** (`delivery_timing`, Time, Required): Choose the delivery timing.
- **Delivery Location** (`delivery_location`, Text, Optional): If necessary, specify the delivery location.
- **Delivery Person** (`delivery_person`, Text, Optional): If necessary, provide the name of the person delivering the barrier.
- **Confirmation** (`confirmation`, Select One, Required): Confirm the status of your barrier request (Confirmed, Not Confirmed, or On Hold).
- **Event Date** (`event_date`, Date, Required): Select the date of your event.
- **Event Time** (`event_time`, Time, Optional): Choose the time of your event.
- **Event Location** (`event_location`, Text, Optional): If necessary, specify the location of your event.
- **Event Type** (`event_type`, Select One, Required): Choose the type of event (Festival, Conference, or Trade Show).
- **Event Size** (`event_size`, Select Multiple, Required): Select the size of your event (Small, Medium, Large, Extra Large, or Huge).
- **Event Setup** (`event_setup`, Text, Optional): Add any additional event setup details.
- **Event Setup Note** (`event_setup_note`, Text, Optional): Add any additional event setup notes.
- **Event Notes** (`event_notes`, Text, Optional): Add any additional event notes.

## Tips
- Please ensure all required fields are filled before submitting the form.
- If you have any questions, do not hesitate to contact us for assistance.
