# heated_patio_event_rsvp - Help Guide
## Purpose
The "heated_patio_event_rsvp" form is designed to gather event information from attendees for a heated patio event.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the "Heated Patio Event RSVP" field with a simple "yes" or "no" response indicating your intention to attend the event.
2. In the "Confirmation" field, confirm your response to the first field.
3. If you have any additional comments or notes about the event, type them in the "Comments" field.

## Field-by-Field Explanation
* **Heated Patio Event RSVP** (text, required): This is the main field where you can indicate your intention to attend the event by typing "yes" or "no". 
* **Confirmation** (text, required): Confirm your response to the first field. This helps us ensure that we have accurate information about your event attendance.
* **Comments** (text, optional): If you have any additional comments or notes about the event, this is the place to type them in.
