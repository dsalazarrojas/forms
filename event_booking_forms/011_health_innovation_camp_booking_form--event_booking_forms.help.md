# Health Innovation Camp Booking Form - Help Guide
## Purpose
This form is designed to collect information for the Health Innovation Camp, allowing users to provide their booking details and preferences.

## How To Complete This Form
1. Review the form carefully and fill out the required fields (those marked as "required" in the form schema).
2. For each field, refer to the "Field-by-Field Explanation" section for more information on what each field means.
3. Once you have filled out all the required fields, click the "Submit" button to complete your booking.

## Field-by-Field Explanation
### 1. **Booking Details** (1)
* This field is not explicitly used in the form, but it may be used internally for organizational purposes.

### 2. **Name** (2)
* This field is for the user's first name.

### 3. **Surname** (3)
* This field is for the user's last name.

### 4. **Email** (4)
* This field is for the user's email address, which will be used as the primary contact method.

### 5. **Phone** (5)
* This field is for the user's phone number.

### 6. **Date of Arrival** (6)
* This field is for the date the user plans to arrive at the event.

### 7. **Date of Departure** (7)
* This field is for the date the user plans to depart from the event.

### 8. **Room Type** (8)
* This field is for selecting the type of room the user would like to book. Please choose one or more of the available options.

### 9. **Room Number** (9)
* This field is for selecting a specific room number for the user's booking. Please choose one of the available options.

### 10. **Message** (10)
* This field is for any additional information or special requests the user may have.

### 11. **Accept terms of service** (11)
* This field is for the user to accept the terms of service of the event. Please select the appropriate option.

### 12. **Submit** (12)
* This button submits the form once all required fields have been filled out.
Note: As the form schema has a lot of options, ensure you are using the correct ones for your booking purpose. If unsure, please contact your event organizer.
