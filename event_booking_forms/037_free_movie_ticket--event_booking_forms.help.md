> This help guide is for the "Free Movie Ticket" form, which allows users to create and manage movie-related events. The form is used by event organizers to provide free movie tickets to attendees. The purpose of this form is to gather information about the movie event, including the event details, ticket availability, and other relevant information.

Before proceeding, please ensure that you are using this form for its intended purpose and that you have not already created a similar event. Duplicate events may cause confusion among attendees and event organizers.

# Free Movie Ticket - Help Guide
## Purpose
The Free Movie Ticket form is designed to create and manage movie-related events for ticket giveaways. This form helps event organizers collect necessary information about the event, including the movie title, event date and time, ticket count, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

*   Select the movie house owner (yes or no)
*   Enter the event date
*   Enter the movie start time
*   Enter the ticket count
*   Choose the ticket type
*   Enter the ticket price
*   Select the event end time
*   Choose the event organizer
*   Enter the movie name
*   Enter a brief description of the event
*   Enter the movie theatre name
*   Enter the event start date
*   Enter the event end date
*   Enter the number of free tickets
*   Select the second ticket type
*   Enter the ticket price 2
*   Enter the event start time 2
*   Select the second event end time
*   Choose the second event organizer
*   Enter the ticket count 2

## Field-by-Field Explanation

*   **Movie House Owner** (`movie_house_owner`, select_multiple, required: false): This field is used to indicate if the movie house owner is involved in the event.
*   **Event Date** (`event_date`, date, required: false): Enter the date of the event.
*   **Movie Start Time** (`movie_start_time`, time, required: false): Enter the time the movie starts.
*   **Ticket Count** (`ticket_count`, number, required: false): Enter the number of tickets available for the event.
*   **Ticket Type** (`ticket_type`, select_one, required: false): Choose the type of ticket available for the event.
*   **Ticket Price** (`ticket_price`, number, required: false): Enter the price of each ticket.
*   **Event End Time** (`event_end_time`, time, required: false): Enter the time the event ends.
*   **Event Organizer** (`event_organizer`, select_multiple, required: false): Choose the organizer of the event.
*   **Movie Name** (`movie_name`, text, required: false): Enter the name of the movie.
*   **Event Description** (`event_description`, text, required: false): Enter a brief description of the event.
*   **Movie Theatre** (`movie_theatre`, text, required: false): Enter the name of the movie theatre.
*   **Event Start Date** (`event_date_start`, date, required: false): Enter the date the event starts.
*   **Event End Date** (`event_end_date`, date, required: false): Enter the date the event ends.
*   **Free Tickets** (`free_tickets`, text, required: false): Enter the number of free tickets available.
*   **Ticket Type 2** (`ticket_type_2`, select_one, required: false): Choose the type of ticket 2 available for the event.
*   **Ticket Price 2** (`ticket_price_2`, number, required: false): Enter the price of each ticket 2.
*   **Event Start Time 2** (`event_start_time_2`, time, required: false): Enter the time the event 2 starts.
*   **Event End Time 2** (`event_end_time_2`, time, required: false): Enter the time the event 2 ends.
*   **Event Organizer 2** (`event_organizer_2`, select_multiple, required: false): Choose the organizer of the event 2.
*   **Ticket Count 2** (`ticket_count_2`, number, required: false): Enter the number of tickets 2 available for the event.
