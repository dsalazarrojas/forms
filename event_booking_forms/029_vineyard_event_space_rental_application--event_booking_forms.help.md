# Vineyard Event Space Rental Application - Help Guide
## Purpose
The Vineyard Event Space Rental Application form is designed to collect essential information about events to be held at the vineyard. This form helps us understand your event needs, preferences, and requirements, ensuring a smooth and efficient planning process.

## How To Complete This Form
1. Fill out the form in one sitting to ensure all necessary information is captured.
2. Answer each field accurately and thoroughly, as it will help us understand your event requirements.
3. Make sure to submit the form once you have completed all fields.
4. If you need help or have any questions, feel free to contact us.

## Field-by-Field Explanation
* **Form Data** (`form_data`, text, optional): Enter a brief description of your event.
* **Event Name** (`event_name`, text, optional): Enter the name of the event.
* **Event Type** (`event_type`, select multiple, optional): Select the type of event (Private, Corporate, Wedding).
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Event Time** (`event_time`, time, optional): Enter the start time of the event.
* **Event Start Time** (`event_start_time`, time, optional): Enter the end time of the event. **Note:** This field is optional and should not be filled out if you only select a time.
* **Event End Time** (`event_end_time`, time, optional): Enter the end time of the event. **Note:** This field is optional and should not be filled out if you select a time for Event Time or Event Start Time.
* **Guest Count** (`event_guest_count`, number, optional): Enter the expected number of guests.
* **Space Requirements** (`event_space_requirements`, text, optional): Specify any specific space requirements for your event.
* **Contact Name** (`contact_name`, text, optional): Enter the full name of the contact person.
* **Contact Email** (`contact_email`, email, optional): Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the contact person (in the format: 10 digits, e.g 1234567890).
* **Event Space** (`event_space`, text, optional): Enter any specific details about the event space (e.g., room number, location).
* **Space Description** (`event_space_description`, text, optional): Provide a brief description of the event space.
* **Event Space Type** (`event_space_type`, select one, optional): Select the type of event space (Indoor, Outdoor, Mixed).
* **Additional Requirements** (`event_additional_requirements`, text, optional): Specify any additional requirements for your event.
* **Approval Status** (`approval_status`, select one, optional): Select the current status of your application (Awaiting Approval, Approved, Rejected).
* **Approval Comments** (`approval_comments`, text, optional): Enter any comments regarding the approval process.
* **Event Status** (`event_status`, select one, optional): Select the current status of your event (Awaiting Approval, Approved, Rejected).
* **Event Status Change Reason** (`event_status_change_reason`, text, optional): Enter the reason for any status changes.
* **Form Submitted** (`form_submitted`, select one, optional): Select whether the form has been submitted (Yes, No).
* **Form Submitted Date** (`form_submitted_date`, date, optional): Enter the date the form was submitted.
* **Form Updated** (`form_updated`, select one, optional): Select whether the form has been updated (Yes, No).
* **Form Updated Date** (`form_updated_date`, date, optional): Enter the date the form was last updated.
* **Submitted By** (`submitted_by`, text, optional): Enter the name of the person who submitted the form.
