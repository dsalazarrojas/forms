# Drone Light Show Booking Form - Help Guide

## Purpose
This form is designed to facilitate the booking of events for drone light shows. It helps event organizers to provide essential details about the event and drone-related information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the required fields, marked with a red asterisk (\*). You can leave the optional fields blank or provide information as necessary.
2.  Choose the correct options for drone type, event status, and assigned tool.
3.  Ensure that the event date and time are in the correct format (date: YYYY-MM-DD, time: 24-hour format, e.g., 12:00).
4.  Provide accurate details for event name, location, and description.
5.  Enter a valid email address for the event organizer.

## Field-by-Field Explanation
###  Event Booking Form
*   **Event Booking Form** (`event_booking_form`, text, optional): A description of the form's purpose is not provided. Please fill in any additional details about the event.

###  Event Date
*   **Event Date** (`event_date`, date, optional): Enter the date of the event in the format YYYY-MM-DD.

###  Event Time
*   **Event Time** (`event_time`, time, optional): Enter the time of the event in 24-hour format, e.g., 12:00.

###  Event Duration
*   **Event Duration** (`event_duration`, text, optional): Describe the duration of the event.

###  Number of People
*   **Number of People** (`number_of_people`, number, optional): Enter the expected number of people attending the event.

###  Phone Number
*   **Phone Number** (`phone_number`, text, optional): Enter the event organizer's phone number.

###  Email
*   **Email** (`email`, email, optional): Enter the event organizer's email address.

###  Event Name
*   **Event Name** (`event_name`, text, optional): Enter the name of the event.

###  Event Location
*   **Event Location** (`event_location`, text, optional): Enter the location of the event.

###  Event Description
*   **Event Description** (`event_description`, text, optional): Provide a detailed description of the event.

###  Event Organizer
*   **Event Organizer** (`event_organizer`, text, optional): Enter the name of the event organizer.

###  Event Organizer Email
*   **Event Organizer Email** (`event_organizer_email`, email, optional): Enter the email address of the event organizer.

###  Event Organizer Phone Number
*   **Event Organizer Phone Number** (`event_organizer_phone`, text, optional): Enter the phone number of the event organizer.

###  Drone Type
*   **Drone Type** (`drone_type`, select_one, optional): Choose 'Yes' if the event uses drones and 'No' otherwise.

###  Drone Model
*   **Drone Model** (`drone_model`, select_one, optional): Choose 'Yes' if the event is using a model and 'No' otherwise.

###  Event Status
*   **Event Status** (`event_status`, select_multiple, optional): Choose one or more status options for the event, e.g., Active and Inactive.

###  Event Notes
*   **Event Notes** (`event_notes`, note, optional): Add any additional information about the event.

###  Assigned Tool
*   **Assigned Tool** (`assigned_tool`, text, optional): Enter the tool that is assigned to the event.
