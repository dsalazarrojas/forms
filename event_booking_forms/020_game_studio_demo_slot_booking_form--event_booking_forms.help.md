# Game Studio Demo Slot Booking Form - Help Guide
## Purpose

This form is used to schedule and book demo slots for game development demonstrations. It's meant to be completed by game developers or studios showcasing their work to potential partners or clients.

## How To Complete This Form

1. Select the start time for the demo from the available options.
2. Select the end time for the demo from the available options.
3. Input your name as the representative of the game studio.
4. Enter your email address for contact purposes.
5. Select the partner or client you will be demonstrating to.
6. Choose the booking slot for the demo from the available options.
7. Add any additional notes or comments about the demo.

## Field-by-Field Explanation

* **Start Time** (`start_time`, select_one, required: false): Choose the start time for the demo from 10, 15, 20, or 25 minutes.
* **End Time** (`end_time`, select_one, required: false): Choose the end time for the demo from 10, 15, 20, or 25 minutes.
* **Name** (`name`, text, required: false): Input your name as the representative of the game studio.
* **Email** (`email`, email, required: false): Enter your email address for contact purposes.
* **Partner** (`partner`, select_one, required: false): Select the partner or client you will be demonstrating to.
* **Booking Slot** (`booking_slot`, select_one, required: false): Choose the booking slot for the demo from Slot 1, Slot 2, or Slot 3.
* **Note** (`note`, note, required: false): Add any additional notes or comments about the demo.
* **Created At** (`created_at`, date, required: false): This field is automatically populated and not editable.

## Tips

* Make sure to fill out all required fields.
* Double-check the accuracy of the information you input.
* If you're having trouble with the form, contact form@gic.mx.
