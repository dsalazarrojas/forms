# Ticket Counter Operation Booking Form - Help Guide
## Purpose
The Ticket Counter Operation Booking Form is used to book and manage operations for ticket counters. This form is designed to help administrators or staff members schedule and track ticket counter operations.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the required fields:
    *   **event_title**: Enter the title of the event or operation.
    *   **event_description**: Provide a brief description of the event or operation.
    *   **start_date_time**: Enter the start date and time of the operation.
    *   **end_date_time**: Enter the end date and time of the operation.
    *   **event_type**: Select the type of event or operation (e.g., Event Type 1 or Event Type 2).
    *   **event_status**: Select the status of the event or operation (e.g., Active or Inactive).
    *   **ticket_counter**: Enter the ticket counter number.
    *   **ticket_type**: Select the type of ticket (e.g., Ticket Type 1 or Ticket Type 2).
    *   **ticket_counter_status**: Select the status of the ticket counter (e.g., Status 1 or Status 2).
    *   **ticket_counter_operation**: Enter the operation to be performed on the ticket counter.
    *   **ticket_counter_operation_status**: Select the status of the ticket counter operation (e.g., Status 1 or Status 2).
2.  Fill out the optional fields as necessary:
    *   **event_location**: Enter the location of the event or operation.
    *   **assigned_to**: Select the staff members or users assigned to the operation.
    *   **ticket_counter_note**: Enter any additional notes about the ticket counter.
    *   **ticket_counter_status_notes**: Enter any additional notes about the ticket counter status.
    *   **ticket_counter_operation_note**: Enter any additional notes about the ticket counter operation.
    *   **ticket_counter_operation_booking_form_note**: Enter any additional notes about the ticket counter operation booking form.
    *   **ticket_counter_operation_booking_form_status**: Select the status of the ticket counter operation booking form (e.g., Status 1 or Status 2).

## Field-by-Field Explanation

*   **event_title** (`event_title`, text, required): Enter the title of the event or operation.
*   **event_description** (`event_description`, text, required): Provide a brief description of the event or operation.
*   **start_date_time** (`start_date_time`, date, required): Enter the start date and time of the operation.
*   **end_date_time** (`end_date_time`, date, required): Enter the end date and time of the operation.
*   **event_location** (`event_location`, text, optional): Enter the location of the event or operation.
*   **event_type** (`event_type`, select_one, required): Select the type of event or operation (e.g., Event Type 1 or Event Type 2).
*   **event_status** (`event_status`, select_one, required): Select the status of the event or operation (e.g., Active or Inactive).
*   **assigned_to** (`assigned_to`, select_multiple, optional): Select the staff members or users assigned to the operation.
*   **ticket_counter** (`ticket_counter`, number, required): Enter the ticket counter number.
*   **ticket_type** (`ticket_type`, select_one, required): Select the type of ticket (e.g., Ticket Type 1 or Ticket Type 2).
*   **ticket_counter_status** (`ticket_counter_status`, select_one, required): Select the status of the ticket counter (e.g., Status 1 or Status 2).
*   **ticket_counter_operation** (`ticket_counter_operation`, text, required): Enter the operation to be performed on the ticket counter.
*   **ticket_counter_operation_status** (`ticket_counter_operation_status`, select_one, required): Select the status of the ticket counter operation (e.g., Status 1 or Status 2).
*   **ticket_counter_note** (`ticket_counter_note`, text, optional): Enter any additional notes about the ticket counter.
*   **ticket_counter_status_notes** (`ticket_counter_status_notes`, text, optional): Enter any additional notes about the ticket counter status.
*   **ticket_counter_operation_note** (`ticket_counter_operation_note`, text, optional): Enter any additional notes about the ticket counter operation.
*   **ticket_counter_operation_booking_form** (`ticket_counter_operation_booking_form`, text, required): Enter the ticket counter operation booking form details.
*   **ticket_counter_operation_booking_form_note** (`ticket_counter_operation_booking_form_note`, text, optional): Enter any additional notes about the ticket counter operation booking form.
*   **ticket_counter_operation_booking_form_status** (`ticket_counter_operation_booking_form_status`, select_one, required): Select the status of the ticket counter operation booking form (e.g., Status 1 or Status 2).

## Tips
