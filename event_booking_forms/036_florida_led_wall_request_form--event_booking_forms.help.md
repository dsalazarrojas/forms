# florida_led_wall_request_form - Help Guide
## Purpose
This form is for event organizers to submit requests for LED wall displays for their events.

## How To Complete This Form
1. Fill in the event details such as event type, date and time, number of guests, location, contact name, email, phone number, and any additional event description.
2. Choose the desired color scheme and screen resolution for the LED wall display.
3. Specify any special requests for the event.
4. Select the assigned staff member to handle the event.
5. Finally, submit the form.

## Field-by-Field Explanation
* **Form Submission**: Enter a brief description of the event (e.g. "Concert for 1,000 guests at the Miami Beach Theater").
* **Event Type**: Select the type of event you are hosting (e.g. Corporate, Concert, Party, etc.).
* **Event Date**: Enter the date of the event in the required date format (YYYY-MM-DD).
* **Event Time**: Enter the time of the event in the required time format (HH:MM).
* **Number of Guests**: Enter the number of guests expected for the event.
* **Location**: Enter the location of the event (e.g. address, city, state).
* **Contact Name**: Enter the name of the person in charge of the event.
* **Email**: Enter the email address of the person in charge of the event.
* **Phone**: Enter the phone number of the person in charge of the event.
* **Event Description**: Enter a detailed description of the event (e.g. "We are hosting a corporate event for our company's annual meeting").
* **LED Wall Details**: Enter any additional details about the LED wall display (e.g. "We need a large screen to display our company logo").
* **Color Scheme**: Select the desired color scheme for the LED wall display (e.g. Monochrome, Multicolor, etc.).
* **Screen Resolution**: Select the desired screen resolution for the LED wall display (e.g. 720P, 1080P, etc.).
* **Screen Size**: Enter the size of the screen in feet (e.g. 10 ft).
* **Special Requests**: Enter any additional requests or instructions for the event.
* **Assigned Staff**: Select the staff member assigned to handle the event.
* **Form Submission Date**: This field will be automatically filled out with the current date.
* **Form Submission Time**: This field will be automatically filled out with the current time.
* **Assigned Staff**: Select the staff member assigned to handle the event.

Note: The fields marked as "required" will be mandatory to fill out, while the others can be left blank if not applicable.
