# Public Performance Stage Booking Form - Help Guide

## Purpose
This form is designed to gather necessary information from event organizers to book a public performance stage for their events. To use this form, please follow the instructions below.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the necessary information.
2. Provide a brief description of the event in the "Event Description" field.
3. Enter the contact email and phone number of the event organizer in the "Contact Email" and "Contact Phone" fields respectively.

## Field-by-Field Explanation
- **Event Venue Name** (`event_venue_name`, text, optional): Enter the name of the venue where the event will take place.
- **Event Start Date** (`event_start_date`, date, optional): Enter the date when the event starts.
- **Event Start Time** (`event_start_time`, time, optional): Enter the time when the event starts.
- **Event End Date** (`event_end_date`, date, optional): Enter the date when the event ends.
- **Event End Time** (`event_end_time`, time, optional): Enter the time when the event ends.
- **Event Description** (`event_description`, text, optional): Provide a brief description of the event.
- **Contact Email** (`contact_email`, email, optional): Enter the email address of the event organizer.
- **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the event organizer.

## Tips
* Make sure to fill in all the required fields.
* Use the correct format for dates (DD/MM/YY) and times (HH:MM AM/PM) when filling in the "Event Start Date" and "Event Start Time" fields respectively.
* Be concise and clear in the "Event Description" field.
* Double-check the "Contact Email" and "Contact Phone" fields for accuracy.
* If you have any questions or concerns, contact the event coordinator.
