# Sow A Seed Form - Help Guide
## Purpose
The Sow A Seed form is a tool for event booking purposes, specifically for events related to seeds, plants, or animals.

## How To Complete This Form
To complete this form, follow the steps below:
1. Enter the event name in the "Event Name" field.
2. Enter the seed name in the "Seed Name" field.
3. Enter a brief description of the seed in the "Seed Description" field.
4. Enter the seed price in the "Seed Price" field.
5. Enter the donation amount in the "Donation Amount" field.
6. Enter your email address and phone number in the "Email" and "Phone" fields, respectively.
7. Select a date and time for the event using the "Date" and "Time" fields.
8. (Optional) Specify the time zone using the "Time Zone" field.
9. Select the type of seed from the list provided in the "Seed Type" field.
10. If the seed type is not listed, enter the type in the "Other Seed Type" field.
11. Enter the quantity of seeds needed in the "Quantity" field.

## Field-by-Field Explanation

* **Event Name** (Event Name, text, required)
  The event name is the title of the event being booked.
* **Seed Name** (Seed Name, text, required)
  The seed name is the name of the seed being booked.
* **Seed Description** (Seed Description, text, required)
  A brief description of the seed being booked.
* **Seed Price** (Seed Price, number, required)
  The price of the seed being booked.
* **Donation Amount** (Donation Amount, number, optional)
  The amount donated towards the seed.
* **Email** (Email, email, optional)
  The email address of the user.
* **Phone** (Phone, text, optional)
  The phone number of the user.
* **Date** (Date, date, optional)
  The date of the event.
* **Time** (Time, time, optional)
  The time of the event.
* **Time Zone** (Time Zone, text, optional)
  The time zone of the event.
* **Seed Type** (Seed Type, select_one, required)
  The type of seed being booked (seeds, plants, animals).
* **Other Seed Type** (Other Seed Type, text, optional)
  If the seed type is not listed, enter the type here.
* **Quantity** (Quantity, number, required)
  The number of seeds needed.
