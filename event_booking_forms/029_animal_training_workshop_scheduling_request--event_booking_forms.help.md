# Animal Training Workshop Scheduling Request - Help Guide
## Purpose
This form is for requesting a workshop for animal training. It is used to gather information from organizations or individuals interested in scheduling a workshop, such as the type of workshop, target audience, and preferred date and time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the organization or individual name requesting the workshop.
2. Provide the contact email address for the person requesting the workshop.
3. Select the type of workshop that is being requested.
4. Choose the target audience for the workshop.
5. Enter the estimated number of participants.
6. Select the preferred start date for the workshop.
7. Select the preferred start time for the workshop.
8. Provide a description of the facility and location where the workshop will take place.
9. Select any equipment and amenities that will be provided for the workshop.
10. Summarize the training goals and objectives of the workshop.

## Field-by-Field Explanation
* **Organization or Individual Name** (`organization_requester_name`, text, required): Enter the name of the organization or individual requesting the workshop.
* **Contact Email Address** (`contact_email_address`, email, required): Enter the email address of the person requesting the workshop.
* **Workshop Type** (`workshop_type_choice`, select_one, required): Select the type of workshop that is being requested. Options include:
	+ Basic Obedience Fundamentals
	+ Agility and Sport Training
	+ Therapy Animal Preparation
	+ Aggression and Reactivity Management
	+ Puppy Socialization Clinic
* **Target Audience** (`target_audience_type`, select_one, required): Choose the target audience for the workshop. Options include:
	+ General Pet Owners
	+ Shelter and Rescue Staff
	+ Professional Trainers
	+ Veterinary Technicians
* **Estimated Number of Participants** (`estimated_attendee_count`, number, required): Enter the estimated number of participants for the workshop.
* **Preferred Start Date** (`preferred_workshop_date`, date, required): Select the preferred start date for the workshop.
* **Preferred Start Time** (`preferred_workshop_time`, time, required): Select the preferred start time for the workshop.
* **Facility and Location Details** (`facility_description`, text, required): Provide a description of the facility and location where the workshop will take place.
* **Equipment and Amenities Provided** (`provided_equipment_list`, select_multiple, optional): Select any equipment and amenities that will be provided for the workshop. Options include:
	+ Training Mats or Flooring
	+ Agility Obstacles and Tools
	+ Sound System and Microphones
	+ Projector and Screen
	+ Water and Snacks for Participants
* **Workshop Training Goals and Objectives** (`training_goals_summary`, text, required): Summarize the training goals and objectives of the workshop.
