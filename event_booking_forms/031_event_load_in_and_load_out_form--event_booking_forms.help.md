# Event Load In And Load Out Form - Help Guide
## Purpose
This form is designed to gather information about event load in and load out details to facilitate effective event management.

## How To Complete This Form
1. Review the form sections and identify the required and optional fields.
2. Complete the required fields, which include:
	* Load In Info (Section 1)
	* Equipment List (Section 2)
	* Load Out Info (Section 3)
	* Notes (Section 4)
3. Optional fields can be completed as needed, depending on the event specifics.
4. Ensure that all fields are completed accurately and thoroughly.

## Field-by-Field Explanation

* **Load In Info** (`load_in_info`, select_multiple, required): Select one or more options from the provided list to indicate whether the load-in information is required or not.
* **Equipment List** (`equipment_list`, text, optional): Enter any equipment that needs to be loaded in or out. This field is not required, but can be helpful for detailed notes about the equipment.
* **Load Out Info** (`load_out_info`, select_multiple, required): Similar to Load In Info, select one or more options from the provided list to indicate whether the load-out information is required or not.
* **Notes** (`notes`, note, optional): Provide any additional comments or remarks about the event.
* **Date** (`date`, date, optional): Enter the date of the event if it is relevant.
* **Time** (`time`, time, optional): Enter the time of the event if it is relevant.
* **Event Details** (`event_details`, select_one, required): Select one option from the provided list to confirm the event details.
* **Equipment Details** (`equipment_details`, select_multiple, optional): Select one or more options from the provided list to confirm equipment details.
* **Load In Staff** (`load_in_staff`, select_one, optional): Select one option from the provided list to confirm load-in staff.
* **Load Out Staff** (`load_out_staff`, select_one, optional): Select one option from the provided list to confirm load-out staff.
* **Contact Person** (`contact_person`, select_one, optional): Select one option from the provided list to confirm the contact person.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact person's phone number if it is relevant.
* **Event Location** (`event_location`, select_one, required): Select one option from the provided list to confirm the event location.
* **Comments** (`comments`, text, optional): Enter any additional comments or remarks about the event.
* **Email** (`email`, email, optional): Enter the email contact information if it is relevant.
* **Load Out Notes** (`load_out_notes`, note, optional): Provide any additional notes about the load-out.
* **Equipment Count** (`equipment_count`, number, optional): Enter the count of equipment if it is relevant.
* **Total Count** (`total_count`, number, optional): Enter the total count of equipment if it is relevant.
* **Event Name** (`event_name`, select_one, optional): Select one option from the provided list to confirm the event name.
* **Event Date** (`event_date`, date, optional): Enter the date of the event if it is relevant.
* **Event Time** (`event_time`, time, optional): Enter the time of the event if it is relevant.
* **Load Out Location** (`load_out_location`, select_one, optional): Select one option from the provided list to confirm the load-out location.
* **Remarks** (`remarks`, note, optional): Enter any additional remarks about the event.
* **Event Details** (`event_details`, select_one, optional): Select one option from the provided list to confirm event details.
