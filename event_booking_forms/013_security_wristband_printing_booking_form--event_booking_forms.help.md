# Security Wristband Printing Booking Form - Help Guide
## Purpose
This form is used for booking security wristbands for events. Please fill out the form with event details and customer information to book your wristbands.

## How To Complete This Form
1. Start by filling in the required fields:
	* Event Organizer
	* Event Name
	* Event Date
	* Event Start Date
	* Event End Date
	* Event Type
	* Event Size
	* Wristband Quantity
	* Customer Name
	* Customer Email
2. Fill in the optional fields as needed:
	* Event Description
	* Event Location
	* Event Time
	* Event Design
	* Wristband Color
	* Customer Phone
	* Customer Note
	* Customer Message

## Field-by-Field Explanation
### 1. Event Organizer
* **Event Organizer (Required)**: Please enter the name of the person responsible for the event.
*   Type: Text
*   Required: Yes

### 2. Event Name
* **Event Name (Required)**: Enter a brief name for your event.
*   Type: Text
*   Required: Yes

### 3. Event Date
* **Event Date (Required)**: Enter the date of your event in the format YYYY-MM-DD.
*   Type: Date
*   Required: Yes

### 4. Event Time
* **Event Time**: Enter the time of your event in 24-hour format (HH:MM).
*   Type: Time
*   Required: No

### 5. Event Location
* **Event Location**: Enter the location of your event.
*   Type: Text
*   Required: No

### 6. Event Start Date
* **Event Start Date (Required)**: Enter the date of the start of your event in the format YYYY-MM-DD.
*   Type: Date
*   Required: Yes

### 7. Event End Date
* **Event End Date (Required)**: Enter the date of the end of your event in the format YYYY-MM-DD.
*   Type: Date
*   Required: Yes

### 8. Event Description
* **Event Description**: Enter a brief description of your event.
*   Type: Text
*   Required: No

### 9. Event Type
* **Event Type (Required)**: Select the type of event (Event type or Other).
*   Type: Select One
*   Required: Yes

### 10. Event Size
* **Event Size (Required)**: Select the size of your event (Size or Other).
*   Type: Select Multiple
*   Required: Yes

### 11. Event Design
* **Event Design**: Enter any custom design requirements for the wristbands.
*   Type: Text
*   Required: No

### 12. Event Wristband Color
* **Event Wristband Color**: Select the color of the wristbands.
*   Type: Select One
*   Required: No

### 13. Event Wristband Quantity
* **Event Wristband Quantity (Required)**: Enter the number of wristbands required.
*   Type: Number
*   Required: Yes

### 14. Customer Name
* **Customer Name (Required)**: Enter the name of the person booking the event.
*   Type: Text
*   Required: Yes

### 15. Customer Email
* **Customer Email (Required)**: Enter the email of the person booking the event.
*   Type: Email
*   Required: Yes

### 16. Customer Phone
* **Customer Phone**: Enter the phone number of the person booking the event.
*   Type: Text
*   Required: No

### 17. Customer Note
* **Customer Note**: Enter any additional notes for the event.
*   Type: Note
*   Required: No

### 18. Customer Message
* **Customer Message**: Enter a message to the event organizer.
*   Type: Text
*   Required: No

## Tips
* Please ensure that all required fields are completed before submitting the form.
* Double-check the accuracy of the event details before submitting the form.
* If you have any questions or concerns, please contact the event organizer or support team.
