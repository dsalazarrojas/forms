# On Site First Aid Team Booking Form - Help Guide
## Purpose
This form is used for event planners to book a first aid team for on-site events, ensuring that the medical team is adequately prepared for your event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event planner's name and contact information.
2. Select the type of first aid team required (large, medium, or small event).
3. Choose the dates and time of the event.
4. Specify the event location.
5. Indicate the staffing needs for your event (number of personnel required).
6. Provide any additional event details (optional).
7. Select the schedule dates and times for the first aid team.
8. Choose the submit option (Submit or Other).

## Field-by-Field Explanation

* **Event Planner**:
	+ A text field for the event planner's name.
* **Site Manager**:
	+ A text field for the site manager's name (optional).
* **On-site First Aid Team**:
	+ Select one of three options: First Aid Team - Large Event, First Aid Team - Medium Event, or First Aid Team - Small Event, depending on the size of your event.
* **Date and Time**:
	+ A date field to select the dates of the event. The format is YYYY-MM-DD.
* **Event Location**:
	+ A text field for the event location.
* **Staffing Needs**:
	+ Select multiple options from 1 to 5 to indicate the number of personnel required for the event.
* **Event Details**:
	+ A text field for any additional event details (optional).
* **Schedule Dates**:
	+ Select multiple dates from the options provided. Note that the format is YYYY-MM-DD.
* **Schedule Start Time**:
	+ A time field to select the start time of the event in 24-hour format (HH:MM).
* **Schedule End Time**:
	+ A time field to select the end time of the event in 24-hour format (HH:MM).
* **Contact Info**:
	+ A text field for the contact information (phone number, email, etc.).
* **Email**:
	+ An email field for the event planner's email address.
* **Notes**:
	+ A text field for any additional notes or comments (optional).
* **Assigned Tool**:
	+ A text field for the assigned tool or equipment (optional).
* **Submit**:
	+ Select one of two options: Submit or Other.

Note: Please ensure that all required fields are completed accurately to ensure that the on-site first aid team is adequately prepared for your event.
