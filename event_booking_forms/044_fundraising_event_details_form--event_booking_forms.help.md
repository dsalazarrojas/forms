# Fundraising Event Details Form - Help Guide
## Purpose
This form is designed to collect essential information about a fundraising event. It helps event organizers gather details such as event name, date, location, type, and other relevant information to make the event a success.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the "Event Name" field.
2. Select the event date in the "Event Date" field using the date picker.
3. Choose the event time in the "Event Time" field using the time picker.
4. Enter the event location in the "Event Location" field.
5. Select the event type in the "Event Type" field.
6. Enter the event description in the "Event Description" field.
7. Enter the event organizer's name in the "Event Organizer" field.
8. Enter the event target audience in the "Event Target" field.
9. Select the correct target value for the event in the "Event Target Value" field.
10. Enter the event goal in the "Event Goal" field.

## Field-by-Field Explanation
### Event Name (id: 1)
* **Event Name** (`event_name`, text, required: false): Enter the name of the event, for example, "Fundraising Gala" or "Charity Run".

### Event Date (id: 2)
* **Event Date** (`event_date`, date, required: false): Select the date of the event using the date picker. Make sure to choose a date that is in the future and is not earlier than today.

### Event Time (id: 3)
* **Event Time** (`event_time`, time, required: false): Choose the time of the event using the time picker. Be accurate with the time to avoid confusion.

### Event Location (id: 4)
* **Event Location** (`event_location`, text, required: false): Enter the location of the event, such as "City Hall" or "Park".

### Event Type (id: 5)
* **Event Type** (`event_type`, select_one, required: false): Select the type of event, such as "Yes" or "No". For most events, it will be "Yes".

### Event Type Options (id: 6)
* **Options** (`event_type_options`, text, required: false): Enter any additional information about the event type, for example, "Charity Run" or "Benefit Dinner".

### Event Description (id: 7)
* **Event Description** (`event_description`, text, required: false): Enter a short description of the event, such as "Join us for a night of fundraising and fun".

### Event Organizer (id: 8)
* **Event Organizer** (`event_organizer`, text, required: false): Enter the name of the event organizer.

### Event Target (id: 9)
* **Event Target** (`event_target`, text, required: false): Enter the target audience of the event, such as "Local Community" or "School Children".

### Event Target Options (id: 10)
* **Options** (`event_target_options`, text, required: false): Enter any additional information about the event target, for example, "Age group: 10-15".

### Event Target Value (id: 11)
* **Event Target Value** (`event_target_value`, select_one, required: false): Select the correct target value for the event, such as "Yes" or "No".

### Event Target Value Options (id: 12)
* **Options** (`event_target_value_options`, text, required: false): Enter any additional information about the event target value, for example, "Donations: 1000".

### Event Goal (id: 13)
* **Event Goal** (`event_goal`, text, required: false): Enter the goal of the event, such as "Raising $1000 for charity".


## Tips
* Ensure that all fields are filled out accurately and completely.
* Double-check that the date and time are correct.
* Enter a short but descriptive event description.
* Choose the correct event type and target value.
* Be creative and detailed when filling out the event target options and goal fields.
