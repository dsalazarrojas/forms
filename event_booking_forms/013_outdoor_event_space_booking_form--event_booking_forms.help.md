# Outdoor Event Space Booking Form - Help Guide

## Purpose
The Outdoor Event Space Booking Form is designed to collect information about outdoor or indoor events, enabling users to book and manage events in a structured and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of event (outdoor, indoor, or hybrid).
2.  Enter the event date in the required format (dd/mm/yyyy).
3.  Enter the start and end times for the event.
4.  Specify the duration of the event.
5.  Provide a title for the event.
6.  Describe the event in a few sentences.
7.  Enter the location where the event will take place.
8.  Specify the number of people that can attend the event at the location.
9.  Enter the name, contact email, and contact phone number of the person or organization responsible for the event.

## Field-by-Field Explanation

*   **Event Type** (`Event Type`, `select_one`, required: false): Select the type of event you are booking. Options are: Outdoor, Indoor, Hybrid.
    *   If your event is a mix of both outdoor and indoor, choose the "Hybrid" option.
*   **Event Date** (`event_date`, `date`, required: false): Enter the date for the event in the format dd/mm/yyyy.
    *   Please use the correct date format to ensure accurate calculations and processing.
*   **Start Time** (`start_time`, `time`, required: false): Enter the start time of the event.
    *   Use 24-hour clock format (HH:MM).
*   **End Time** (`end_time`, `time`, required: false): Enter the end time of the event.
    *   Use 24-hour clock format (HH:MM).
*   **Duration** (`duration`, `number`, required: false): Specify the duration of the event in hours.
    *   This field is optional, but it helps to calculate the total event duration.
*   **Event Name** (`event_name`, `text`, required: false): Give your event a descriptive name.
    *   This helps identify the event and communicate with attendees.
*   **Event Description** (`event_description`, `text`, required: false): Briefly describe your event.
    *   This is optional but helps in event promotion and planning.
*   **Venue Location** (`venue_location`, `text`, required: false): Specify the location where the event will take place.
    *   This could be a physical address or a descriptive location name.
*   **Venue Capacity** (`venue_capacity`, `number`, required: false): Enter the maximum number of attendees for the event.
    *   This helps in planning for resources and seating arrangements.
*   **Contact Name** (`contact_name`, `text`, required: false): Enter the name of the person or organization responsible for the event.
    *   This ensures that relevant communication and follow-up can be done with the right person.
*   **Contact Email** (`contact_email`, `email`, required: false): Enter the email address of the person or organization responsible for the event.
    *   This helps in communicating about event details and updates.
*   **Contact Phone** (`contact_phone`, `text`, required: false): Enter the phone number of the person or organization responsible for the event.
    *   This provides a contact method for last-minute updates and questions.

## Tips
*   Double-check all entered information before submitting the form to avoid errors.
*   Be as detailed as possible for better event planning.
*   Ensure you have the necessary permissions and approvals for the event before submitting this form.
