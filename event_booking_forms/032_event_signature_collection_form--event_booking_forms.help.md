# event-signature-collection-form - Help Guide
## Purpose
The event-signature-collection-form is used to collect event booking information from attendees. It is essential for event organizers to gather details about the event and its attendees.
## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the `event id` field with the relevant ID number.
2. Enter your `attendee-name` in the `attendee-name` field.
3. Enter your `email` address in the `email` field.
4. Write your signature in the `signature` field.
5. Fill in the `event-date` field with the date of the event.
6. Select the correct time of the event in the `time` field.
7. Choose whether the event starts with 'Yes' or 'No' in the `event-start` field.
8. Choose whether the event ends with 'Yes' or 'No' in the `event-end` field.
9. Select the relevant event type in the `event-type` field.
10. Choose the consent type(s) you agree to in the `attendee-consent` field.
11. Select the payment method(s) you will use in the `payment-method` field.
12. Choose whether the payment amount is 'Yes' or 'No' in the `payment-amount` field (if required by the event).
13. Write any additional notes about the event in the `notes` field.
14. Add any additional notes about the event in the `additional-notes` field.
15. Enter the contact number of the event organizer in the `contact-number` field.
16. Write a brief description of the event in the `event-description` field (if required).
17. Enter the event address in the `event-address` field (if required).
18. Enter the event website in the `event-website` field (if required).

## Field-by-Field Explanation
* **Event ID (1)**: Enter the ID number of the event.
* **Attendee Name (2)**: Enter your name as the attendee of the event.
* **Email (3)**: Enter your email address.
* **Signature (4)**: Sign your name to confirm your attendance.
* **Event Date (5)**: Enter the date of the event.
* **Time (6)**: Select the time of the event.
* **Event Start (7)**: Choose whether the event starts with 'Yes' or 'No'.
* **Event End (8)**: Choose whether the event ends with 'Yes' or 'No'.
* **Event Type (9)**: Select the type of event (e.g., 'Yes', 'No').
* **Attendee Consent (10)**: Choose the consent type(s) you agree to.
* **Payment Method (11)**: Select the payment method(s) you will use.
* **Payment Amount (12)**: Choose whether the payment amount is 'Yes' or 'No'.
* **Notes (13)**: Write any additional notes about the event.
* **Additional Notes (14)**: Write any additional notes about the event.
* **Contact Number (15)**: Enter the contact number of the event organizer.
* **Event Description (16)**: Write a brief description of the event (if required).
* **Event Address (17)**: Enter the event address (if required).
* **Event Website (18)**: Enter the event website (if required).
