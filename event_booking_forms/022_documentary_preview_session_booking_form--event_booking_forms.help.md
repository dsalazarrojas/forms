# Documentary Preview Session Booking Form - Help Guide
## Purpose
The Documentary Preview Session Booking Form is a tool for end-users to book a documentary preview session for an event.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the desired screening date from the calendar input field.
2. Enter your name and email address in the corresponding input fields.
3. Provide your phone number in the phone input field.
4. Choose the screening time from the time input field.
5. Enter the screening location in the text input field.
6. Describe the event details in the text input fields (Event Details 1-5).
7. Specify the event goals in the text input field.
8. List the event owners in the text input fields (Event Owners 1-3).
9. Confirm your booking by selecting 'True' or 'False' from the confirm select input field.

## Field-by-Field Explanation
- **Screening Date**: Select the date you would like to book the documentary preview session.
  * Type: date
  * Required: false
- **Name**: Enter your name for the event booking.
  * Type: text
  * Required: false
- **Email**: Provide your email address for communication purposes.
  * Type: email
  * Required: false
- **Phone**: Enter your phone number for further communication.
  * Type: text
  * Required: false
- **Screening Time**: Choose the time you would like to book the documentary preview session.
  * Type: time
  * Required: false
- **Screening Location**: Enter the location where the documentary preview session will take place.
  * Type: text
  * Required: false
- **Event Details 1-5**: Provide a brief description of the event you are booking.
  * Type: text
  * Required: false
- **Event Goals**: Specify the goals of the event you are booking.
  * Type: text
  * Required: false
- **Event Owners 1-3**: List the owners of the event you are booking.
  * Type: text
  * Required: false
- **Confirm**: Confirm your booking by selecting 'True' or 'False'.
  * Type: select_one
  * Required: false

## Tips
* Please ensure that the information provided is accurate and complete to avoid any confusion or miscommunication.
* You can enter any additional information or details that you feel are essential for the documentary preview session.
* The event owners and event details are optional fields and can be left blank if not applicable.
* Confirming your booking does not necessarily mean you are committed to the booking. If changes are needed, please let us know as soon as possible.
