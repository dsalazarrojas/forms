# F1 Grand Prix Ticket Booking - Help Guide
## Purpose

The F1 Grand Prix Ticket Booking form is designed to collect essential information for booking tickets for the event. This form will guide you through the process of providing accurate and complete information to ensure a smooth booking experience.

## How To Complete This Form

1.  Go through the form carefully, and make sure to fill in all the required fields.
2.  Provide accurate information for each field, taking into account the specific requirements of the event and the booking process.
3.  If you're unsure about any particular field, refer to the field-by-field explanations below.

## Field-by-Field Explanation

*   **Ticket Type** (`ticket_type`, select_one, required: false): This field requires choosing the type of ticket you want to book (if you want to book tickets, select "Yes" and choose the ticket type).
*   **Ticket Price** (`ticket_price`, number, required: false): Enter the price of the ticket you want to book.
*   **Ticket Quantity** (`ticket_quantity`, number, required: false): Enter the number of tickets you want to book.
*   **Attendee Details** (`attendee_details`, text, required: false): Provide a brief description of the attendee (if you want to book tickets for yourself, this field can be left blank).
*   **Accessibility Needs** (`accessibility_needs`, select_multiple, required: false): Select any accessibility needs you or your attendee may require.
*   **Payment Method** (`payment_method`, select_multiple, required: false): Choose your preferred payment method.
*   **Payment Terms** (`payment_terms`, select_one, required: false): Confirm the payment terms.
*   **Payment Amount** (`payment_amount`, number, required: false): Enter the payment amount.
*   **Attendee Name** (`attendee_name`, select_one, required: false): Choose the name of the attendee (if you want to book tickets for yourself, this field can be left blank).
*   **Attendee Email** (`attendee_email`, email, required: false): Enter the email address of the attendee.
*   **Attendee Phone** (`attendee_phone`, text, required: false): Enter the phone number of the attendee.
*   **Event Date** (`event_date`, date, required: false): Select the date of the event.
*   **Event Time** (`event_time`, time, required: false): Choose the event time.
*   **Event Location** (`event_location`, select_one, required: false): Select the event location.
*   **Event Description** (`event_description`, text, required: false): Provide a brief description of the event.
*   **Event Terms** (`event_terms`, select_one, required: false): Confirm the event terms.
*   **Event Conditions** (`event_conditions`, select_multiple, required: false): Select any event conditions.
*   **Ticket Conditions** (`ticket_conditions`, select_multiple, required: false): Choose any ticket conditions.
*   **Form Submit** (`form_submit`, text, required: false): Confirm that you have read and agree to the form terms.
*   **Form Comments** (`form_comments`, text, required: false): Add any comments about the booking process.
*   **Accessibility Notes** (`accessibility_notes`, text, required: false): Provide any accessibility notes.
*   **Payment Notes** (`payment_notes`, text, required: false): Add any payment notes.
*   **Attendee Notes** (`attendee_notes`, text, required: false): Enter any notes about the attendee.
*   **Event Notes** (`event_notes`, text, required: false): Provide any event notes.
*   **Form Owner** (`form_owner`, select_one, required: false): Confirm the form owner.

Note: Please ensure that you've filled in all the required fields accurately for a smooth and efficient booking process.
