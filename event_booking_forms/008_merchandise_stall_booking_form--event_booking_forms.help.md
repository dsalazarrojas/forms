# Merchandise Stall Booking Form - Help Guide
## Purpose
The Merchandise Stall Booking Form is designed for vendors or event organizers to book and manage merchandise stalls for specific events. This form helps gather essential details about the event, stall, and payment information in a structured and organized manner.

## How To Complete This Form
To complete this form successfully, follow these steps:

1. Fill in the required fields marked as `required` in the form.
2. Select the relevant options for each field according to your needs.
3. Ensure you enter accurate and up-to-date information for all the fields.

## Field-by-Field Explanation

* **Event Details** (`event_details`): Enter a brief description of the event.
* **Stall Booking** (`stall_booking`): Choose the type of stall booking you require (Option 1, Option 2, or Option 3).
* **Vendor Details** (`vendor_details`): Provide a brief description of the vendor's details.
* **Payment Info** (`payment_info`): Enter the payment information for the stall booking.
* **Event Date** (`event_date`): Select the date of the event.
* **Event Time** (`event_time`): Select the time of the event.
* **Contact Phone** (`contact_phone`): Enter the contact phone number of the vendor or event organizer.
* **Contact Email** (`contact_email`): Enter the contact email of the vendor or event organizer.
* **Message** (`message`): Enter any additional message or notes for the event organizer.
* **Payment Method** (`payment_method`): Select the payment method (Option 1, Option 2, or Option 3).
* **Payment Amount** (`payment_amount`): Enter the payment amount for the stall booking.
* **Event Type** (`event_type`): Choose the type of event (Option 1, Option 2, or Option 3).
* **Event Status** (`event_status`): Select the status of the event (Option 1, Option 2, or Option 3).

## Tips
* Double-check all fields for accuracy and completeness before submitting the form.
* If you are unsure about any field, refer to the event organizer or vendor for clarification.
* This form is designed to be completed by authorized vendors or event organizers only.
