# Rehearsal Studio Lighting Booking Form - Help Guide
## Purpose
The Rehearsal Studio Lighting Booking Form is designed to provide the necessary information for the lighting team to prepare for events such as rehearsals, performances, or meetings that require specific lighting configurations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and email address in the `First Name` and `Email` fields, respectively.
2. Provide your phone number in the `Phone` field.
3. Enter your address in the `Address` field.
4. Select the type of event from the `Event Type` dropdown menu.
5. Enter the date and start and end times for the event in the `Event Date`, `Event Start Time`, and `Event End Time` fields, respectively.
6. Choose the number of rooms required for the event in the `Room` field.
7. Enter a description of the event in the `Description` field.
8. List the attendees for the event in the `Attendees` field.
9. Enter the date and start time for the second stage of the event (if applicable) in the `Event Date Time 2`, `Event Start Time 2`, and `Event End Time 2` fields, respectively.
10. Indicate whether you need a room for the second stage of the event in the `Room 2` field.
11. Enter any additional notes for the second stage of the event in the `Notes 2` field.
12. List the attendees for the second stage of the event in the `Attendees 2` field.
13. Enter the date and start time for the third stage of the event (if applicable) in the `Event Date Time 3`, `Event Start Time 3`, and `Event End Time 3` fields, respectively.
14. Indicate whether you need a room for the third stage of the event in the `Room 3` field.
15. Enter any additional notes for the third stage of the event in the `Notes 3` field.
16. Finally, click the `Submit` button to send the form.

## Field-by-Field Explanation

* **First Name** (`page_1`, text, required): Enter your first name.
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`contact_phone`, text, required): Enter your phone number.
* **Address** (`contact_address`, text, required): Enter your address.
* **Event Type** (`event_type`, select_one, required): Select the type of event (e.g., rehearsal, performance, meeting).
* **Event Date** (`event_date`, date, required): Enter the date for the event.
* **Event Start Time** (`event_start_time`, time, required): Enter the start time for the event.
* **Event End Time** (`event_end_time`, time, required): Enter the end time for the event.
* **Duration** (`event_duration`, text, optional): Enter the duration of the event (if applicable).
* **Room** (`event_rooms`, select_multiple, required): Choose the number of rooms required for the event.
* **Description** (`event_description`, text, optional): Enter a description of the event.
* **Attendees** (`event_attendees`, text, optional): List the attendees for the event.
* **Notes** (`event_notes`, note, optional): Enter any additional notes for the event.
* **Event Date Time 2** (`event_date_time_2`, date, required): Enter the date and start time for the second stage of the event (if applicable).
* **Start Time 2** (`event_start_time_2`, time, required): Enter the start time for the second stage of the event.
* **End Time 2** (`event_end_time_2`, time, required): Enter the end time for the second stage of the event.
* **Room 2** (`event_rooms_2`, select_multiple, required): Indicate whether you need a room for the second stage of the event (if applicable).
* **Notes 2** (`event_notes_2`, note, optional): Enter any additional notes for the second stage of the event.
* **Attendees 2** (`event_attendees_2`, text, optional): List the attendees for the second stage of the event.
* **Event Date Time 3** (`event_date_time_3`, date, required): Enter the date and start time for the third stage of the event (if applicable).
* **Start Time 3** (`event_start_time_3`, time, required): Enter the start time for the third stage of the event.
* **End Time 3** (`event_end_time_3`, time, required): Enter the end time for the third stage of the event.
* **Room 3** (`event_rooms_3`, select_multiple, required): Indicate whether you need a room for the third stage of the event (if applicable).
* **Notes 3** (`event_notes_3`, note, optional): Enter any additional notes for the third stage of the event.
* **Submit** (`submit`, text, optional): Click the submit button to send the form.

## Tips
- Make sure to fill out all required fields.
- Double-check the event date and time fields to ensure accuracy.
- If you have any questions or concerns, contact the event coordinator or lighting team.
