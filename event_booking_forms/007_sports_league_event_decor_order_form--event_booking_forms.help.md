# sports_league_event_decor_order_form - Help Guide
## Purpose
The sports_league_event_decor_order_form is used by event organizers or coordinators to collect information about an event's decorations, dates, venues, and payment options. This form helps to plan and prepare for an event's logistics.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form pages to understand the sections and fields you need to fill out.
2. Select the decor items you want for the event on the "Select Decor Items" page.
3. Enter the event date on the "Event Date" page.
4. Provide the event venue on the "Event Venue" page.
5. Specify the delivery instructions on the "Delivery Instructions" page.
6. Select payment options on the "Set Payment" page.
7. Review and repeat the same process for additional event pages (2-4).
