# Remote Artist Camp Booking Form - Help Guide
## Purpose
This form is a tool for artists to book and manage their bookings for remote art camps. It captures essential information about artist bookings, including dates, locations, and payment statuses.

## How To Complete This Form
1. Select the artist's discipline from the options provided.
2. Choose the dates for the remote camp using the date fields.
3. Enter the location for the camp.
4. Fill in the artist's name and contact information.
5. Add any additional notes or comments.
6. Select the accommodation option for the artist.
7. If the artist has any other discipline or preferences, add them in the respective fields.
8. Choose the booking status and payment status from the options provided.
9. Review and submit the form.

## Field-by-Field Explanation
* **Artist Booking Form** (`artist_booking_form`, select_multiple, Required): Select the type of event you are booking the artist for (e.g. Option 1, Option 2, Option 3).
* **Discipline** (`discipline`, select_one, Required): Choose the artist's discipline (e.g. Option 1, Option 2, Option 3).
* **Dates** (`dates`, date, Required): Enter the dates for the remote camp.
* **Start Date** (`start_date`, date, Required): Enter the start date of the event.
* **End Date** (`end_date`, date, Required): Enter the end date of the event.
* **Location** (`location`, text, Required): Enter the location of the remote camp.
* **Name** (`name`, text, Required): Enter the artist's name.
* **Email** (`email`, email, Required): Enter the artist's email address.
* **Phone** (`phone`, text, Required): Enter the artist's phone number.
* **Notes** (`notes`, note, Optional): Add any additional comments or notes about the booking.
* **Chat Form** (`chat_form`, text, Optional): Add any additional information for the artist.
* **Discipline Preferences** (`discipline_preferences`, text, Optional): Enter any other discipline the artist is interested in.
* **Accommodation** (`accommodation`, select_one, Optional): Choose the accommodation option for the artist.
* **Accommodation Details** (`accommodation_details`, text, Optional): Enter any details about the accommodation.
* **Other Discipline** (`other_discipline`, text, Optional): Enter any other discipline the artist is interested in.
* **Other Discipline Preferences** (`other_discipline_preferences`, text, Optional): Enter any other discipline preferences the artist has.
* **Participant Preferences** (`participant_preferences`, text, Optional): Enter any participant preferences the artist has.
* **Additional Info** (`additional_info`, text, Optional): Enter any additional information.
* **Booking Form** (`booking_form`, select_multiple, Optional): Select the type of booking form the artist is booking for (e.g. Option 1, Option 2, Option 3).
* **Booking Details** (`booking_details`, text, Optional): Enter any additional information about the booking.
* **Participant** (`participant`, select_multiple, Optional): Choose the participants involved in the booking.
* **Payment** (`payment`, text, Optional): Enter any payment information.
* **Booking Status** (`booking_status`, select_one, Required): Choose the status of the booking (e.g. Option 1, Option 2, Option 3).
* **Artist Booking Status** (`artist_booking_status`, select_one, Required): Choose the status of the artist's booking (e.g. Option 1, Option 2, Option 3).
* **Payment Status** (`payment_status`, select_one, Required): Choose the payment status (e.g. Option 1, Option 2, Option 3).
