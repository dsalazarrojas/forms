# Sound Test Window Booking Form - Help Guide
## Purpose
The Sound Test Window Booking Form is used to book a sound test window for a specific event. It is essential to fill out the required fields accurately and completely to ensure efficient booking and proper communication with the facility.

## How To Complete This Form
- Click on the "Submit" button once you've filled out all required fields to confirm your booking request.

## Field-by-Field Explanation
- **Studio** (`1`, `select_one`, required): Select 'Yes' or 'No' to confirm whether you're booking a studio or not. This field is mandatory.
- **Start Date** (`2`, `date`, required): Choose the date for the event. Select a date in the required format (yyyy-mm-dd).
- **Test Start Time** (`3`, `select_one`, required): Select 'Yes' or 'No' to confirm whether you want to start the test on time or not.
- **Test Duration** (`4`, `number`, required): Enter the duration of the test. This field is only required if you selected 'Yes' for 'Test Start Time'.
- **Event End Time** (`5`, `time`, optional): Enter the expected end time of the event. This field is optional.
- **Required Equipment** (`6`, `select_multiple`, optional): Select the required equipment for the test. This field is only required if you selected 'Yes' for 'Studio'.
- **Comments** (`7`, `note`, optional): Enter any additional comments about the event or test. This field is optional.
- **Assigned Tool** (`8`, `text`, required): Enter the tool assigned to the event. This field is mandatory.
- **Booking Comments** (`9`, `text`, optional): Enter any additional comments about the booking. This field is optional.
- **Booking Status** (`10`, `select_one`, required): Select 'Active' or 'Inactive' to confirm the booking status.
- **User** (`11`, `email`, required): Enter your email address. This field is mandatory.
- **Contact Person** (`12`, `text`, required): Enter the contact person's name. This field is mandatory.
- **Contact Email** (`13`, `email`, required): Enter the contact person's email address. This field is mandatory.
- **Contact Phone** (`14`, `text`, optional): Enter the contact person's phone number. This field is optional.
- **Facility Name** (`15`, `text`, required): Enter the facility name. This field is mandatory.
- **Facility Address** (`16`, `text`, required): Enter the facility address. This field is mandatory.
- **Facility Notes** (`17`, `text`, optional): Enter any additional comments about the facility. This field is optional.
- **Event Date** (`18`, `date`, optional): Choose the event date. This field is optional.
- **Event Time** (`19`, `time`, optional): Choose the event time. This field is optional.
- **Facility** (`20`, `select_one`, required): Select 'Yes' or 'No' to confirm whether you're booking a facility or not.
- **Booking Notes** (`21`, `text`, optional): Enter any additional comments about the booking. This field is optional.
- **Facility Type** (`22`, `select_one`, required): Select 'Yes' or 'No' to confirm the facility type. This field is mandatory.
- **Booking Type** (`23`, `select_one`, required): Select 'Yes' or 'No' to confirm the booking type. This field is mandatory.
- **Sound Test Notes** (`24`, `note`, optional): Enter any additional comments about the sound test. This field is optional.
- **Facility Phone** (`25`, `text`, optional): Enter the facility phone number. This field is optional.
