# Sponsorship Activation Slot Booking Form - Help Guide
## Purpose
The purpose of this form is to enable event organizers to book activation slots for their events and provide relevant information about the event and the sponsor.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your name as the event organizer in the "Event Organizer" field.
2. Enter the sponsor's information in the "Sponsor Info" field.
3. Select the desired activation slots for the event from the "Activation Slot" dropdown menu.
4. Choose the time slots available for the event from the "Time Selection" dropdown menu.
5. Provide a brief description of the event in the "Event Info" field.
6. Add any additional information or comments in the "Note" field.
7. (Optional) Enter the sponsor's email and phone number in the "Sponsor Email" and "Sponsor Phone" fields.

## Field-by-Field Explanation

* **Event Organizer**: The name of the person booking the activation slot.
* **Sponsor Info**: The name of the sponsor for whom the activation slot is being booked.
* **Activation Slot**: Choose "Yes" if you want to book an activation slot for the event, or "No" if you do not want to book one.
* **Time Selection**: Choose the time slot(s) for the event from the available options.
* **Event Info**: A brief description of the event.
* **Note**: Any additional information or comments about the event or activation slot.
* **Email**: The sponsor's email address (optional).
* **Phone**: The sponsor's phone number (optional).
* **Sponsor Email**: The sponsor's email address (optional).
* **Sponsor Phone**: The sponsor's phone number (optional).

## Tips
- Make sure to fill out all required fields.
- Double-check the information before submitting the form.
- If you have any questions or need further assistance, contact the event team.
