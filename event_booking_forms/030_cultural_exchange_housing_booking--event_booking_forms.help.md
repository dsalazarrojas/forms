# cultural_exchange_housing_booking - Help Guide
## Purpose
This form is used to book cultural exchange housing accommodations for a specific program or event.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields, indicated by an asterisk (\*).
2. Choose the correct accommodation type from the list.
3. Enter the start and end dates of the reservation.
4. Enter the address of the accommodation.
5. Enter the contact information for the accommodation (name, email, and phone number).
6. Optionally, add any additional notes about the accommodation.
7. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

- **User**: This field is a unique identifier number for the user.
*   **Program**: Please enter the name of the program for which you are booking the accommodation.
    *   **Start Date**: The start date of the reservation.
    *   **End Date**: The end date of the reservation.
    *   **Duration**: The duration of the stay in hours or days.
*   **Accommodation Type**: Choose the type of accommodation you are booking (e.g., Yes or No).
    *   **Accommodation Name**: The name of the accommodation.
    *   **Address**: The address of the accommodation.
    *   **Email**: The email address of the accommodation contact person.
    *   **Phone**: The phone number of the accommodation contact person.
    *   **Notes**: Any additional notes about the accommodation.
    *   **Submitter**: The name of the person submitting the booking.
    *   **Email**: The email address of the person submitting the booking.
    *   **Phone**: The phone number of the person submitting the booking.
    *   **Notes**: Any additional notes about the submission.
