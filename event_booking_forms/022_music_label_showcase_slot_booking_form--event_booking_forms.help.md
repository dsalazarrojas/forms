# Music Label Showcase Slot Booking Form - Help Guide
## Purpose
The Music Label Showcase Slot Booking Form is a tool used by event organizers to collect information from artists about their music events. This form helps event organizers track and manage events more efficiently.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the main page status from the drop-down menu.
2. If applicable, list the artists performing at the event.
3. Fill out the artist's name, email, and phone number as required.
4. Choose your preferred time slot for the event.
5. Select any technical requirements for the event.
6. Enter the venue and event details, including date, time, location, and description.
7. Specify event tags and any additional requirements.
8. Add any event and artist notes.
9. Choose the event status and type.

## Field-by-Field Explanation

* **Main Page Status**: Select "Yes" or "No" to confirm the status of this event.
* **Artists List**: List the names of all artists performing at this event, one per line. If no artists are performing, select "Yes" to indicate that there are no artists.
* **Artist Name**: Enter the name of the main artist or lead performer.
* **Artist Email**: Enter the email address of the artist.
* **Artist Phone**: Enter the phone number of the artist.
* **Time Slot**: Choose your preferred time slot for the event from the drop-down menu.
* **Technical Requirements**: Select any technical requirements for the event, such as sound and lighting.
* **Technical Requirements 1-5**: These fields are similar to "Technical Requirements" and may be used to capture additional or specific technical requirements.
* **Venue**: Enter the name of the venue hosting the event.
* **Promoter**: Enter the name of the promoter or organizer.
* **Event Date**: Select the date of the event.
* **Event Time**: Select the time of the event.
* **Event Location**: Enter the location of the event.
* **Event Description**: Enter a brief description of the event.
* **Event Tags**: Select any additional tags or descriptions for the event.
* **Event Requirements**: This field is similar to "Technical Requirements" and captures any additional requirements for the event.
* **Notes**: Enter any additional notes or details about the event or artist.
* **Artist Notes**: Enter any additional notes or details about the artist.
* **Event Status**: Enter the current status of the event, such as "confirmed" or "cancelled".
* **Event Type**: Select the type of event, such as "concert" or "fest".
* **Assigned To**: Enter the person or team responsible for the event.
