# stage_rigging_crew_booking_form - Help Guide
## Purpose
The stage rigging crew booking form is a crucial tool for event planners to collect and store information about events, crew sizes, and other essential details.

## How To Complete This Form
1. Ensure that the form is complete and accurate before submission.
2. Review each field carefully to avoid errors.
3. Fill out the required fields marked as mandatory.

## Field-by-Field Explanation

* **EventDetails**: Enter a brief description of the event, highlighting its unique aspects and requirements.
* **EventType**: Select the type of event from the provided options to ensure correct categorization and planning.
* **EventDuration**: Enter the expected duration of the event in numbers (e.g., 1, 2, 3 hours).
* **LaborHours**: Enter the number of labor hours required for the event.
* **EquipmentCount**: Enter the number of equipment pieces needed for the event.
* **DateOfEvent**: Enter the date of the event in the format MM/DD/YYYY.
* **EventStartTime**: Enter the start time of the event in 24-hour format (HH:MM).
* **EventFinishTime**: Enter the finish time of the event in 24-hour format (HH:MM).
* **EventFinishDate**: Enter the date of the event finish in the format MM/DD/YYYY.
* **Venue**: Enter the location of the event.
* **ContactPerson**: Enter the name of the contact person responsible for the event.
* **ContactEmail**: Enter the email address of the contact person.
* **ContactPhone**: Enter the phone number of the contact person.
* **AdditionalEquipment**: Enter any additional equipment or special requirements for the event.
* **CrewSize**: Enter the number of crew members expected for the event.
* **CrewType**: Select the type of crew from the provided options.
* **LaborCost**: Enter the expected labor cost for the event.
* **EventNotes**: Enter any additional comments or notes about the event.
* **Submit**: Select the submission status from the provided options.
* **Event Type 1**: Confirm if the event has a specific type 1 feature.
* **Event Type 2**: Confirm if the event has a specific type 2 feature.
* **Event Type 3**: Confirm if the event has a specific type 3 feature.
* **Crew Size 1**: Confirm if the event requires a specific crew size 1 feature.
* **Crew Size 2**: Confirm if the event requires a specific crew size 2 feature.
