# Comedy Show Performance Booking Form - Help Guide

## Purpose

This form is designed to help us book and prepare for a comedy show performance. Please fill out the form accurately to ensure a smooth and enjoyable experience for both you and the event organizers.

## How To Complete This Form

1. Read through the form carefully and answer each question truthfully.
2. Fill out the required fields, marked with an asterisk (\*).
3. Select relevant options for the fields with multiple choices.
4. Double-check your answers for accuracy before submission.

## Field-by-Field Explanation

* **Performer Name** (1, Text, \*: Stage name or legal name): This is your professional name that will be used for booking and payment purposes.
* **Legal Name** (2, Text, \*: For contract and payment purposes): This is your full name as per your identification documents.
* **Email Address** (3, Email, \*: Primary contact email for booking inquiries): Enter your email address for us to contact you about the booking.
* **Phone Number** (4, Text, \*: Contact number for booking inquiries): Provide your phone number for us to reach you about the booking.
* **Management Contact** (5, Text, Optional): If you have a manager or agent, enter their name and email address.
* **Comedy Style** (7, Select Multiple, \*: What type of comedy you perform): Select one or more of the following options: Stand-Up, Improv, Sketch Comedy, Musical Comedy, Observational, Dark Comedy, Clean Comedy, Political Satire.
* **Performance Duration** (8, Select One, \*: How long is your set): Choose your set duration from the following options: 5-10 minutes, 15-20 minutes, 30 minutes, 45 minutes, 60 minutes, 90 minutes or more.
* **Preferred Performance Dates** (9, Text, \*: Select your available dates): Enter your preferred dates for the performance.
* **Venue Preference** (10, Select One, \*: What type of venue do you prefer): Select one of the following options: Comedy Club, Theater, Bar or Lounge, Corporate Event, Private Party, Festival, Any Venue.
* **Preferred Audience Size** (11, Select One, \*: What size crowd do you prefer): Choose your preferred audience size from the following options: Intimate (under 50), Small (50-100), Medium (100-300), Large (300-500), Arena (500+), No Preference.
* **Technical Requirements** (12, Note, \*: Special technical needs): If you have any specific technical requirements, please describe them here.
* **Microphone Preference** (13, Select One, \*: Do you have specific mic requirements): Select one of the following options: Handheld Wireless, Handheld Wired, Lapel Mic, Headset Mic, No Preference.
* **Lighting Requirements** (14, Text, Optional): If you have any specific lighting requirements, please describe them here.
* **Sound Requirements** (15, Text, Optional): If you have any specific sound requirements, please describe them here.
* **Stage Setup** (16, Text, Optional): Describe your ideal stage setup.
* **Performance Fee Expectation** (18, Number, \*: Your expected compensation): Enter your expected fee for the performance.
* **Is Fee Negotiable** (19, Select One, \*: Are you open to negotiation): Select one of the following options: Yes Flexible, Somewhat, No Fixed Rate.
* **Travel Expenses Required** (20, Select One, \*: Do you require travel expense coverage): Select one of the following options: Yes Required, Negotiable, No I Cover My Own.
* **Accommodation Needed** (21, Select One, \*: Do you need hotel accommodation): Select one of the following options: Yes Required, Negotiable, No I Cover My Own.
* **Video Sample URL** (23, Text, Optional): Provide a link to your performance video.
* **Social Media Handles** (24, Text, Optional): Enter your social media profiles.
* **Press Kit Available** (25, Select One, \*: Do you have a press kit): Select one of the following options: Yes Available, Working On It, False.
* **Additional Notes** (26, Text, Optional): Enter any additional information we should know about you or your performance.
