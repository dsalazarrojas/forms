# Event Programming Form - Help Guide
## Purpose
This form is designed to collect information about events for event programming purposes. It is essential to ensure that the form is completed accurately and in its entirety to collect the necessary information.

## How To Complete This Form
1. Ensure that you have all the necessary information about the event before proceeding.
2. Review the form carefully and complete each field accurately.
3. Fill in the required fields, which are marked as "required" in this guide.
4. Be aware that some fields are optional and only required if specified by the event organizer or type.

## Field-by-Field Explanation

* **Event Programming Form Label** (`event_programming_form_label`, Text, Required: false): This field is for users to enter a brief label for the event.
* **Event Organizer** (`event_organizer`, Text, Required: false): Enter the name of the event organizer or the person responsible for the event.
* **Attendee Name** (`attendee_name`, Text, Required: false): Enter the name of the attendees for the event.
* **Contact Details** (`contact_details`, Text, Required: false): Enter any contact details related to the event.
* **Email** (`email`, Email, Required: false): Enter the email address of the event organizer or contact person.
* **Phone Number** (`phone_number`, Text, Required: false): Enter the phone number of the event organizer or contact person.
* **Event Date** (`event_date`, Date, Required: false): Enter the date of the event.
* **Event Time** (`event_time`, Time, Required: false): Enter the time of the event.
* **Event Type** (`event_type`, Select, Required: false):
	+ Choose from the options: Yes, No
* **Event Type Option** (`event_type_option`, Text, Required: false): Enter any additional information about the event type.
* **Event Organizer Option** (`event_organizer_option`, Select Multiple, Required: false):
	+ Choose from the options: Yes, No
* **Event Attendees** (`event_attendees`, Select Multiple, Required: false):
	+ Choose from the options: Yes, No
* **Event Attendees Option** (`event_attendees_option`, Text, Required: false): Enter any additional information about the event attendees.
* **Event Details** (`event_details`, Text, Required: false): Enter any additional information about the event.
* **Event Details Option** (`event_details_option`, Text, Required: false): Enter any additional information about the event details.
* **Event Comments** (`event_comments`, Text, Required: false): Enter any comments or feedback about the event.
* **Event Comments Option** (`event_comments_option`, Text, Required: false): Enter any additional information about the event comments.
* **Form Submissions** (`form_submissions`, Select, Required: false):
	+ Choose from the options: Yes, No
* **Form Submissions Option** (`form_submissions_option`, Text, Required: false): Enter any additional information about form submissions.
* **Form Submissions Date** (`form_submissions_date`, Date, Required: false): Enter the date of the form submissions.
* **Form Submissions Time** (`form_submissions_time`, Time, Required: false): Enter the time of the form submissions.
* **Form Submissions Comments** (`form_submissions_comments`, Text, Required: false): Enter any comments or feedback about form submissions.
* **Form Submissions Notes** (`form_submissions_notes`, Text, Required: false): Enter any additional information about form submissions.

## Tips
- Please ensure that you complete the form accurately and thoroughly.
- Be aware that some fields are optional and only required if specified by the event organizer or type.
- Please review the form carefully before submitting it to avoid any errors or omissions.
