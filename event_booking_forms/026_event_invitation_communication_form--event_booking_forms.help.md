# Event Invitation Communication Form - Help Guide
## Purpose
This form is designed to help event organizers gather information from guests about their event invitations. It is meant to be a simple and straightforward way to collect details like guest names, phone numbers, and event specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the guest's name in the "guest_name" field.
2. Provide the guest's phone number in the "guest_phone" field.
3. Add any necessary event details in the "event_details" field.
4. If applicable, select the guest's dietary preference(s) from the "dietary_preferences" dropdown list.
5. Indicate the guest's RSVP status by choosing from the "rsvp_status" dropdown list.
6. Enter any special requests the guest may have in the "special_requests" field.
7. Review and submit the form once all fields are filled.

## Field-by-Field Explanation

* **guest_name** (text, required): This field is for entering the guest's name.
* **guest_phone** (text, required): This field is for providing the guest's phone number.
* **event_details** (text, required): Enter any necessary information about the event, such as date, time, and location.
* **rsvp_status** (select_one, required): Choose from the dropdown list to indicate whether the guest is attending ("Attending"), declining ("Declining"), or unable to attend ("Unable to Attend").
* **dietary_preferences** (select_multiple, optional): Select any dietary preferences the guest has, such as Vegetarian or Vegan.
* **special_requests** (text, optional): Enter any special requests or notes the guest may have.
* **event_details** (text, optional): This field is a duplicate of the event details field, intended for redundancy.

## Tips

* Make sure to fill out the form once for each guest to prevent duplication.
* Use the collected information responsibly and securely.
* If you have any questions or concerns about the form, contact the event organizer.
