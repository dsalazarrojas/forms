# Cultural Program Scheduling Request Form - Help Guide
## Purpose
The Cultural Program Scheduling Request Form is designed to collect information about cultural programs that users would like to schedule. This form helps us understand user's needs and preferences for such programs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with your requested program information.
2. Provide accurate details in each field to help us better understand your request.
3. If you have any additional questions or concerns, you can include them in the "Event Details" field.

## Field-by-Field Explanation
### **Program Name** (`program_name`, text, optional)
Program Name is the title of the cultural program you're interested in scheduling. Please enter the name of the program as it appears on promotional materials or the program's website.

### **Program Date** (`program_date`, date, optional)
Program Date is the date you would like to schedule the program. Please use the calendar format (YYYY-MM-DD) to ensure accurate date entry.

### **Program Start Time** (`program_start_time`, time, optional)
Program Start Time is the time you would like the program to start. Please use the 12-hour clock format (HH:MM AM/PM) to ensure accurate time entry.

### **Program End Time** (`program_end_time`, time, optional)
Program End Time is the time you would like the program to end. Please use the 12-hour clock format (HH:MM AM/PM) to ensure accurate time entry.

### **Location** (`location`, text, optional)
Location is the venue or space where you would like to schedule the program. Please provide the exact address or a brief description of the location.

### **Description** (`description`, text, optional)
Description is an optional field where you can provide additional information about the program, such as the target audience or specific requirements.

### **Event Type** (`event_type`, select_one, optional)
Event Type is the type of cultural program you're interested in scheduling. Please select one of the available options (Event 1, Event 2, Event 3).

### **Event Details** (`event_details`, text, optional)
Event Details is an optional field where you can provide any additional information about the program, such as specific requirements or preferences.

## Tips
- Be accurate and clear when filling out the form to ensure we can efficiently process your request.
- If you have any questions or concerns, contact us at form@gic.mx. 
- We may contact you for further clarification or details about your submitted form. 
- Duplicate submissions might be deleted or ignored, so please do not submit the same form multiple times.
