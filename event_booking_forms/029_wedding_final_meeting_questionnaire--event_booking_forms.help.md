# Wedding Final Meeting Questionnaire - Help Guide
## Purpose
This form is used to gather final meeting questionnaire information for a wedding event. It is essential to have all necessary details collected before proceeding with the event.

## How To Complete This Form
1. Fill in the required fields with accurate information.
2. Review all fields carefully to ensure completeness.
3. Use the provided options for fields with multiple options.

## Field-by-Field Explanation

* **Wedding Location** (`wedding_location`, text, required: false): Enter the venue or location where the wedding will take place.
* **Wedding Date** (`wedding_date`, date, required: false): Enter the date of the wedding event.
* **Wedding Time** (`wedding_time`, time, required: false): Enter the time of the wedding event.
* **Wedding Venue** (`wedding_venue`, text, required: false): Enter a description or details about the wedding venue.
* **Wedding Type** (`wedding_type`, select_one, required: false): Select the type of wedding event (ceremony, reception, or both).
* **Guests List** (`guests_list`, select_multiple, required: false): Select the list of guests attending the wedding (guests or Other).
* **Wedding Details** (`wedding_details`, text, required: false): Enter any additional details about the wedding event.
* **Wedding Guests** (`wedding_guests`, select_multiple, required: false): Select the number of guests attending the wedding (guests or Other).
* **Contact Name** (`contact_name`, text, required: false): Enter the name of the person responsible for contact.
* **Contact Email** (`contact_email`, email, required: false): Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`, text, required: false): Enter the phone number of the contact person.
* **Note** (`note`, note, required: false): Enter any additional notes or comments about the wedding event.
* **Wedding Planner** (`wedding_planner`, text, required: false): Enter the name of the wedding planner or coordinator.

Note: All fields are optional, but filling them accurately and completely is necessary for a successful event. Make sure to review the form carefully before submission.
