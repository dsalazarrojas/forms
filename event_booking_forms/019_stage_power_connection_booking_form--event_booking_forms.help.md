# Stage Power Connection Booking Form - Help Guide
## Purpose
The Stage Power Connection Booking Form is a vital tool for event organizers to book and manage power requirements for stage events. It helps to ensure that all necessary power resources are reserved and allocated efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out each section carefully, providing accurate information for each field.
2. Make sure to review the field explanations below for a clear understanding of each field's purpose.

## Field-by-Field Explanation
* **Venue Name** (`venue_name`, text, optional): Please enter the name of the venue where the event will take place.
* **Event Date** (`event_date`, date, optional): Provide the date of the event in the format YYYY-MM-DD.
* **Event Start Time** (`event_start_time`, time, optional): Enter the time the event is scheduled to begin.
* **Event End Time** (`event_end_time`, time, optional): Enter the time the event is scheduled to end.
* **Number of People** (`number_of_people`, number, optional): Estimate the expected number of attendees for the event.
* **Power Requirements** (`power_requirements`, select_multiple, optional): Indicate whether power drops are required for the event. Please select 'Yes' if they are needed.
* **Instructions** (`instructions`, text, optional): Provide any specific instructions or requirements for the event.
* **Power Drops** (`power_drops`, select_multiple, optional): Indicate whether power drops are required for the stage. Please select 'Yes' if they are needed.
* **Stage Layout** (`stage_layout`, select_multiple, optional): Indicate whether the stage layout is complex or simple. Please select 'No' if it's a straightforward layout.
* **Contact Person** (`contact_person`, text, optional): Enter the name and contact information of the person responsible for the event.

Note: The optional fields are not required, but filling out all the fields will help ensure that your event is properly managed and that all necessary resources are reserved.
