# Event Planning Quote Form Template - Help Guide
## Purpose
The Event Planning Quote Form Template is a guide for event planners to provide accurate quotes to their clients. It captures essential information about the event, payment terms, and event planner's contact details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the company name and event details as required by the client.
2. Select the correct event location from the list of options.
3. Enter the event date in the format MM/DD/YYYY.
4. Select the start and end times of the event.
5. Enter the duration of the event.
6. Provide the event planner's contact information, including their name, phone number, and email.
7. Enter any additional event notes.
8. Select the payment terms that apply to the event.
9. Fill in any other additional information required by the client.
