# rural_regeneration_residency_booking_form - Help Guide
## Purpose
This form is used to book a residency for an event in a rural regeneration context. It collects necessary information from artists to process their booking.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project name and project type in the corresponding fields.
2. Select the preferred date for the residency.
3. Provide your contact email and phone number in case we need to reach you.
4. Add any additional project details if required.
5. Indicate if you have any artist-specific requirements.
6. Select the residency period and event requirements accordingly.
7. Choose the status of your project.
8. Fill in your contact name.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, optional): A brief name for your project.
* **Project Type** (`project_type`, select_one, optional): Select 'Yes' if your project is related to rural regeneration, 'No' otherwise.
* **Preferred Date** (`preferred_date`, date, optional): Select the date you prefer for the residency.
* **Project Details** (`project_details`, note, optional): Additional details about your project, if required.
* **Contact Email** (`contact_email`, email, optional): Your email address where we can reach you.
* **Contact Phone** (`contact_phone`, text, optional): Your phone number for any further contact.
* **Artist Details** (`artist_details`, note, optional): Any additional information about you as an artist.
* **Residency Period** (`residency_period`, select_multiple, optional): Select the duration of your residency, typically 'Yes' or 'No'.
* **Artist Requirements** (`artist_requirements`, note, optional): Any requirements you have for the residency.
* **Event Requirements** (`event_requirements`, select_one, optional): Select 'Yes' if you have specific requirements for the event, 'No' otherwise.
* **Project Status** (`project_status`, select_one, optional): Select 'Active' if your project is currently active, 'Inactive' otherwise.
* **Contact Name** (`contact_name`, text, optional): Your name for contact purposes.
