# Fan Club Event Appearance Request Form - Help Guide

## Purpose
This form is used to book events with the fan club and communicate event details.

## How To Complete This Form

1. Fill out the required fields (Event Booking Date, Event Booking Time, Fan Club Name, Fan Club Email, and Fan Club Phone).
2. Provide a clear description of the event in the Request Details field.
3. Enter the number of attendees in the Event Attendees field.
4. Optionally, add any additional information in the Event Booking Note field.
5. Fill out the Requested Date field with the date you would like to book the event.
6. Click on the "Submit" button to send the request.

## Field-by-Field Explanation

* **Event Booking Date** (`event_booking_date`, date, required): Enter the date of the event.
* **Event Booking Time** (`event_booking_time`, time, required): Enter the time of the event.
* **Event Booking Venue** (`event_booking_venue`, text, optional): Enter the venue of the event if different from the default venue.
* **Fan Club Name** (`fan_club_name`, text, required): Enter the name of the fan club.
* **Fan Club Email** (`fan_club_email`, email, required): Enter the email of the fan club.
* **Fan Club Phone** (`fan_club_phone`, text, optional): Enter the phone number of the fan club.
* **Event Attendees** (`event_attendees`, text, required): Enter the number of attendees for the event.
* **Request Details** (`request_details`, text, optional): Enter a clear description of the event.
* **Requested Date** (`requested_date`, date, optional): Enter the date you would like to book the event.
* **Event Booking Note** (`event_booking_note`, note, optional): Enter any additional information about the event booking.
