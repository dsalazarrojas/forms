# Guest Transport Change Request Form - Help Guide
## Purpose
The Guest Transport Change Request Form is used to update information about the transport details of a guest during an event.

## How To Complete This Form

1. Enter the **Event ID** (`1. Event ID`, required: false) - This field is not required for the form to submit, but it is a useful identifier for the event. If you know the Event ID, please enter it to ensure that your request is associated with the correct event.
2. Select the **Transport Type** (`2. Transport Type`, required: false) - Choose the new transport type from the dropdown list: Bus, Train, or Flight.
3. Enter the **New Event ID** (`3. New Event ID`, required: false) - If you want to change the event ID, enter the new ID here.
4. Provide a **Reason for Change** (`4. Reason for change`, required: false) - Briefly describe the reason for the transport change.
5. Select the **New Transport Type** (`5. New Transport Type`, required: false) - Choose the new transport type for the guest from the dropdown list: Bus, Train, or Flight.
6. Enter the **New Event Date** (`6. New Event Date`, required: false) - If the event date needs to be changed, enter the new date here. Please use the date format MM/DD/YYYY.
7. Enter the **New Event Time** (`7. New Event Time`, required: false) - If the event time needs to be changed, enter the new time here. Please use the 12-hour clock format (e.g., 12:00 PM).
8. Add a **Note** (`8. Note`, required: false) - Include any relevant details or comments about the transport change request.
9. Enter the **Email** (`9. Email`, required: false) - If you would like to be notified of the update, enter your email address here.
10. Enter the **Phone** (`10. Phone`, required: false) - Enter your phone number if you want to be notified by phone.
11. Enter your **User Name** (`11. User Name`, required: false) - Enter your name so we can associate the update with you.
12. Enter your **User Email** (`12. User Email`, required: false) - Enter your email address so we can contact you.
13. Enter your **User Phone** (`13. User Phone`, required: false) - Enter your phone number so we can contact you.
14. Enter the **Event Date** (`14. Event Date`, required: false) - Enter the date of the event if the transport change is related to an upcoming event.

* **Event ID** (`1. Event ID`): Enter the ID of the event you want to associate this transport change request with. This will help us identify the correct event.
