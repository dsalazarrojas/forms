# wedding_rehearsal_slot_booking_form - Help Guide
## Purpose
The wedding_rehearsal_slot_booking_form is used to book a time slot for a wedding rehearsal. It collects information about the couple and their guests, ensuring all necessary details are captured accurately.

## How To Complete This Form
1. Fill in the form carefully, ensuring all required fields are completed.
2. Enter the couple's name in the "Couple Name" field.
3. Enter the couple's email address in the "Couple Email" field.
4. Select a date for the event in the "Event Date" field.
5. Choose a start time for the event in the "Event Start Time" field.
6. Specify the duration of the event in the "Event Duration" field.
7. Provide venue information in the "Venue Information" field (optional).
8. Select the guests attending from the list in the "Guest List" field.
9. Indicate the attendance status for each guest in the "Guest Attendance" field.
10. Enter any message or note for each guest in the "Guest Message" field (optional).
11. Select a date for the booking in the "Booking Date" field.
12. Choose the start time for the booking in the "Booking Start Time" field.
13. Specify the duration of the booking in the "Booking Duration" field.
14. Confirm the booking status in the "Booking Status" field.

## Field-by-Field Explanation
* **Couple Name** (required): Enter the name of the couple getting married.
* **Couple Email** (required): Enter the email address of the couple.
* **Event Date** (required): Select the date for the wedding rehearsal.
* **Event Start Time** (required): Choose the start time for the wedding rehearsal.
* **Event Duration** (required): Specify the length of the wedding rehearsal in hours.
* **Venue Information** (optional): Provide any additional information about the venue, such as address or contact details.
* **Guest List** (required): Select all guests attending the wedding rehearsal.
* **Guest Attendance** (required): Mark each guest as "Attending", "Not Attending", or "Not Invited".
* **Guest Message** (optional): Enter any message or note for each guest.
* **Booking Date** (required): Select the date for the booking.
* **Booking Start Time** (required): Choose the start time for the booking.
* **Booking Duration** (required): Specify the length of the booking in hours.
* **Booking Status** (required): Confirm the booking status as "Confirmed", "Pending", or "Cancelled".
* **Notes** (optional): Provide any additional notes about the booking.
