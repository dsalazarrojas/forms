# Live Show Visual Effects Booking Form - Help Guide
## Purpose

This form is used to book and organize live shows, providing event organizers with a structured way to submit information about the event details.

## How To Complete This Form

1.  Start by filling out the form sections in order from top to bottom. This will help ensure that you provide all necessary information for a successful event booking.
2.  Ensure that you fill out all required fields. Required fields are marked with a \* symbol.
3.  If you're unsure about any field, review the explanations below for further guidance.

## Field-by-Field Explanation

*   **event_name (text)**: \* Enter the name of the event you wish to book.
*   **Event Date (date)**: Enter the date of the event you wish to book.
*   **Production Equipment (text)**: List any available equipment for the production (e.g., sound, lighting, special effects).
*   **Special Effects (text)**: List any special effects you have available for the production (e.g., pyrotechnics, lasers, drones).
*   **Stage Layout (text)**: Describe the stage layout for the production.
*   **Name (text)**: Enter your name.
*   **Email (email)**: Enter your email address.
*   **Phone (text)**: Enter your phone number.
*   **Venue (select_one)**: Select the venue for the event from the list provided. Options are:
    \* Venue 1
    \* Venue 2
    \* Other
*   **Notes (note)**: Add any additional notes about the event or booking.

## Tips

*   Ensure all required fields are filled out thoroughly.
*   Be as detailed as possible with event and production information.
*   If you have any questions or concerns, please reach out to the event booking team.
