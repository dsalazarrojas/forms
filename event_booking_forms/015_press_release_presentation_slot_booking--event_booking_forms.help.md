# Press-Release-Presentation-Booking - Help Guide
## Purpose
This form is used for booking and managing press releases and presentations. It is a crucial tool for event organizers and coordinators to track and update event information in real-time.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the Event Identifier and Press Release Title to identify the event.
2. Enter the Press Release Date and Time to schedule the event.
3. Enter the Media Contact information if necessary.
4. Specify any Special Requests.
5. Set the PR Booking Status.
6. Enter the Event Organizer's details.
7. Enter the Event Identifier 2.
8. Enter Event Notes.
9. Enter PR Notes (optional).
10. Enter Email and Phone numbers for contact purposes.
11. Enter Event Date and Time.
12. Enter Event Duration.
13. Enter Event Location.
14. Enter Event Type.
15. Set the Event Status.
16. Select the Event Reminder (optional).
17. Add any Event Remarks (optional).
18. Enter Press Release ID and PR Booking ID (optional).

## Field-by-Field Explanation
### 1. **Event Identifier** (Required) 
* This is the unique identifier for the event.
* Enter a unique and descriptive name for the event.

### 2. **Press Release Title** (Required)
* This is the title of the press release related to the event.
* Enter a brief and descriptive title for the press release.

### 3. **Press Release Date** (Required)
* This is the date of the press release.
* Enter the date in the correct format (DD/MM/YY).

### 4. **Press Release Time** (Required)
* This is the time of the press release.
* Enter the time in the correct format (HH:MM).

### 5. **Media Contact** (Optional)
* This is the contact information for media inquiries.
* Enter the media contact's name and contact details.

### 6. **Special Requests** (Optional)
* This is for any special requests or instructions.
* Enter any special requests or instructions related to the event.

### 7. **PR Booking Status** (Required)
* This is the status of the press release booking.
* Select the booking status from the available options: Booked, Unavailable, or Cancelled.

### 8. **Event Organizer** (Required)
* This is the person organizing the event.
* Enter the event organizer's name and contact details.

### 9. **Event Identifier 2** (Required)
* This is the secondary event identifier.
* Enter a unique and descriptive name for the event.

### 10. **Event Notes** (Required)
* This is for any additional event information.
* Enter any notes or comments related to the event.

### 11. **PR Notes** (Optional)
* This is for any additional press release information.
* Enter any notes or comments related to the press release.

### 12. **Email** (Required)
* This is the email address for contact purposes.
* Enter the email address of the event organizer or contact person.

### 13. **Phone** (Required)
* This is the phone number for contact purposes.
* Enter the phone number of the event organizer or contact person.

### 14. **Event Date** (Required)
* This is the date of the event.
* Enter the date in the correct format (DD/MM/YY).

### 15. **Event Time** (Required)
* This is the time of the event.
* Enter the time in the correct format (HH:MM).

### 16. **Event Duration** (Required)
* This is the duration of the event.
* Enter the duration in minutes or hours as required.

### 17. **Event Location** (Required)
* This is the location of the event.
* Enter the location address of the event.

### 18. **Event Type** (Required)
* This is the type of event.
* Enter the type of event, e.g., Conference, Workshop, etc.

### 19. **Event Status** (Required)
* This is the status of the event.
* Select the status from the available options: Confirmed, Cancelled, or Pending.

### 20. **Event Reminder** (Optional)
* This is the reminder for the event.
* Select the reminder option from the available options: 1 day before, 1 week before, 1 week after.

### 21. **Event Remark** (Optional)
* This is any additional remark or comment.
* Enter any additional remark or comment related to the event.

### 22. **PR Booking ID** (Optional)
* This is the ID of the press release booking.
* Enter the ID of the press release booking.

### 23. **Press Release ID** (Optional)
* This is the ID of the press release.
* Enter the ID of the press release.

### 24. **Event Booking Created By** (Optional)
* This is the person who created the event booking.
* Enter the name of the person who created the booking.

### 25. **Event Booking Created Time** (Optional)
* This is the time the event booking was created.
* Enter the time the booking was created.
