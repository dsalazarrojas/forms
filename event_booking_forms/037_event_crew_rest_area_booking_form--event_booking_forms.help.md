# Event Crew Rest Area Booking Form - Help Guide
## Purpose
The Event Crew Rest Area Booking Form is designed to book rest area resources for events. This form helps event managers and staff to efficiently allocate resources and manage crew rest area bookings.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the required fields (marked as "required" in the form).
2. Select the desired options for each field.
3. Review your submission before submitting.

## Field-by-Field Explanation
- **Event Name** (`event_crew_rest_area_booking_form`): Type in the name of the event you are booking the rest area for.
- **Event Location** (`event_location`): Enter the location of the event where the rest area is needed.
- **Team Name** (`team_name`): Enter the name of the team or group booking the rest area.
- **Start Time** (`start_time`): Select the start time of the event.
- **End Time** (`end_time`): Select the end time of the event.
- **Rest Area** (`rest_area_name`): Choose the rest area where the crew will take a break.
  - Select one of the options: Area 1, Area 2, Area 3.
- **Crew Size** (`crew_size`): Choose the approximate size of the crew:
  - Select one or multiple options: Small, Medium, Large.
- **Assigned Date** (`assigned_date`): Enter the date the rest area is assigned (not necessarily the event date).
- **Assigned Time** (`assigned_time`): Select the time the rest area is assigned.
- **Event Status** (`event_status`): Choose the status of the event:
  - Select one of the options: Active, Inactive, Pending.
- **Notes** (`notes`): Add any additional comments or requests about the booking.
