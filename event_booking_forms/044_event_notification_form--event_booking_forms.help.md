# Event Notification Form - Help Guide
## Purpose
The "Event Notification Form" is a simple form designed to allow users to notify others about upcoming events. It collects basic information about the event, including its name, dates, location, and contact details for the organizer.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Name** field with the title of the event you wish to notify others about.
2. Enter the **Event Start Date** and **Event End Date** to define the event's duration.
3. Provide a brief description of the event in the **Event Description** field.
4. Enter the name of the event organizer in the **Event Organizer** field.
5. Enter the event location in the **Event Location** field.
6. Enter the event organizer's contact phone number in the **Event Organizer Phone** field.

## Field-by-Field Explanation
* **Event Name**: A text field to enter the title of the event.
* **Event Start Date**: A date field to enter the start date of the event.
* **Event End Date**: A date field to enter the end date of the event.
* **Event Description**: A text field to provide a brief description of the event.
* **Event Organizer**: A text field to enter the name of the event's organizer.
* **Event Location**: A text field to enter the location of the event.
* **Event Organizer Phone**: A text field to enter the event organizer's phone number.

## Tips
- Double-check that you're providing accurate and relevant event information to ensure that the notification is effective.
- Ensure that you're using the correct format for dates (MM/DD/YYYY).
- If you're unsure about any of the form fields or have questions, please reach out to the event organizer or relevant personnel for clarification.
