# submit_your_location_for_holiday_carols - Help Guide
## Purpose
This form is designed to collect information about a location that users would like to submit for a holiday carols event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Location Details field with the name and address of your location.
2. If you have a preferred time for the event, please enter it in the Preferred Time field.
3. If your location has accessibility features, please provide information about them in the Accessibility Info field.
4. Finally, provide your contact details in the Contact Details field.

## Field-by-Field Explanation
* **Location Details** (Text Field): Enter the name and address of your location, so that the event organizers can find it easily.
* **Preferred Time** (Time Field): If you have a specific time in mind for the event, please enter it here. This will help the event organizers plan the event accordingly.
* **Accessibility Info** (Text Field): If your location has features like wheelchair accessibility, audio equipment, or sign language support, please provide information about them. This will help event organizers plan the event for attendees with disabilities.
* **Contact Details** (Text Field): Please enter your name, email, and phone number so that the event organizers can contact you with any questions or updates about the event.

## Tips
* Make sure to double-check your location's name and address for accuracy.
* If you have any additional information about your location, feel free to add it in the Accessibility Info field.
* If you have any questions or need clarification about the form, please contact us at form@gic.mx.
