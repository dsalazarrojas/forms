# esports_event_stream_slot_booking - Help Guide
## Purpose
This form is used to book slots for esports events. The form is used by event staff to coordinate and manage the schedule of streamers and games across different platforms.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event slot booking details in the `Slot Booking` field at the top of the page.
2. Select a game name from the `game_name` field.
3. Enter the name of the streamer(s) who will be participating in the event.
4. Select the platform(s) on which the event will be streamed.
5. Enter the date and time of the booking in the `booking_date` and `booking_time` fields.
6. Specify the duration of the event slot.
7. Answer the following questions:
* Select whether the event will have streamers (`Streamers`) or not.
* Select whether the event will be available on platforms (`Platforms`) or not.
* Select whether the event will be part of a schedule (`Event Schedule`) or not.
* Answer whether the event will be available on game platforms (`Game Platforms`) or not.
* Answer whether the event will feature game streamers (`Game Streamers`) or not.
8. Add any additional notes about the event in the `notes` field.
9. Enter the email and phone number of the event staff or team.
## Field-by-Field Explanation
### 1. **Slot Booking** (`Slot Booking`, `text`, required)
Enter the event slot booking details in this field.

### 2. **game_name** (`game_name`, `text`, required)
Enter the name of the game being featured in the event.

### 3. **Streamer(s)** (`Streamer(s)`, `select_multiple`, required)
Select the names of the streamer(s) participating in the event.

### 4. **Platforms** (`Platforms`, `select_multiple`, required)
Select the platform(s) on which the event will be streamed.

### 5. **Booking Date** (`booking_date`, `date`, required)
Enter the date of the event booking.

### 6. **Booking Time** (`booking_time`, `time`, required)
Enter the time of the event booking.

### 7. **Slot Duration** (`Slot Duration`, `text`, required)
Specify the duration of the event slot.

### 8. **Streamers** (`Streamers`, `select_multiple`, required)
Answer whether the event will have streamers.

### 9. **Platforms** (`Platforms`, `select_multiple`, required)
Answer whether the event will be available on platforms.

### 10. **Event Schedule** (`Event Schedule`, `select_multiple`, required)
Answer whether the event will be part of a schedule.

### 11. **Game Platforms** (`Game Platforms`, `select_multiple`, required)
Answer whether the event will be available on game platforms.

### 12. **Game Streamers** (`Game Streamers`, `select_multiple`, required)
Answer whether the event will feature game streamers.

### 13. **Notes** (`notes`, `note`, required)
Add any additional notes about the event.

### 14. **Email** (`Email`, `email`, required)
Enter the email of the event staff or team.

### 15. **Phone** (`Phone`, `text`, required)
Enter the phone number of the event staff or team.

## Tips
* Make sure to fill out all required fields accurately and thoroughly.
* Double-check the information before submitting the form.
* If you're unsure about any field, consult with event staff or team members.
