# Sports Tournament Security Pass Order Form - Help Guide
## Purpose
This form is used to collect information from event organizers, staff, vendors, media, and guests for security purposes. It is used to ensure that all relevant parties have authorized access to the event premises.

## How To Complete This Form
- Please fill in the form completely and accurately.
- Select "Yes" or "No" for event organizers, staff, vendors, and media.
- Enter the name and role of staff members, the name and type of vendors and media, and the number of guests.
- Enter the date and time of pass application submission.
- Enter the form submission details, including IP address and browser type (if applicable).
