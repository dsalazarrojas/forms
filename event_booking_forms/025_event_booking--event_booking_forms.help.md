# event_booking - Help Guide
## Purpose
This form is used to create, manage, and schedule events on an events management system or website.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event title and a brief description to give a clear understanding of the event.
2. Choose the event date and time in the required format (YYYY-MM-DD and HH-MM AM/PM respectively).
3. Enter the event location, including the venue or address.
4. Enter the event description, providing more details about the event.
5. Enter the email and phone number of the event organizers for easy contact.
6. Set the event capacity to limit the number of attendees.
7. Choose the start and end dates and times of the event.
8. Add the event organizers' details, including their name or name and contact information.

## Field-by-Field Explanation
* **Event Title (Event Title)** (`event_name`, text, required): Enter the title of the event, which will be displayed on the event schedule and other related pages.
* **Event Date (Event Date)** (`event_date`, date, required): Enter the date of the event in the format YYYY-MM-DD.
* **Event Time (Event Time)** (`event_time`, time, required): Enter the time of the event in the format HH-MM AM/PM.
* **Event Location (Event Location)** (`event_location`, text, required): Enter the location of the event, including the venue or address.
* **Event Description (Event Description)** (`event_description`, note, required): Enter a brief description of the event, providing more details to the audience.
* **Event Organizers Email (Event Organizers Email)** (`event_organizers_email`, email, required): Enter the email address of the event organizers for easy contact.
* **Event Capacity (Event Capacity)** (`event_capacity`, number, required): Enter the maximum capacity of attendees the event can hold.
* **Event Organizers Phone (Event Organizers Phone)** (`event_organizers_phone`, text, optional): Enter the phone number of the event organizers, which is not required but can be useful for direct contact.
* **Start Date (Start Date)** (`event_start_date`, date, required): Enter the start date of the event in the format YYYY-MM-DD.
* **Start Time (Start Time)** (`event_start_time`, time, required): Enter the start time of the event in the format HH-MM AM/PM.
* **End Date (End Date)** (`event_end_date`, date, required): Enter the end date of the event in the format YYYY-MM-DD.
* **End Time (End Time)** (`event_end_time`, time, required): Enter the end time of the event in the format HH-MM AM/PM.
* **Organizers (Organizers)** (`event_organizers`, text, required): Enter the name and contact information of the event organizers.

## Tips
* Please ensure the date and time formats are in the correct format to avoid errors.
* Use a clear and concise title and description to make the event easily identifiable.
* Enter accurate contact information for the event organizers to facilitate communication.
