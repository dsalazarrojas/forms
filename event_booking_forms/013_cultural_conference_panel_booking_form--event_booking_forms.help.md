# Cultural Conference Panel Booking Form - Help Guide

## Purpose
This form is used to book a cultural conference panel and gather necessary details from attendees. Please fill in the required fields accurately to ensure a successful event.

## How To Complete This Form
1. Fill in the conference name in the "conference_name" field.
2. Select the relevant panel type from the "select_panel" options.
3. Provide details about the attendees in the "attendee_details" field.
4. Specify any accessibility needs in the "accessibility_needs" field.
5. Add any comments or notes in the "comments" field.
6. Choose the output type (PDF, email, or both) and address or email in the corresponding fields.

## Field-by-Field Explanation

* **conference_name** (Text, Required: No): Enter the name of the conference.
* **select_panel** (Select, Required: No): Select the type of panel you want to book. Options: Cultural, Art, Music, Film.
* **attendee_details** (Text, Required: No): Please provide details about the attendees.
* **accessibility_needs** (Select Multiple, Required: No): Specify any accessibility needs. Options: Wheelchair, Audio Description, Sign Language, Visual.
* **comments** (Text, Required: No): Add any comments or notes about the event.
* **output** (Select, Required: No): Choose the output type. Options: PDF, email, both.
* **email_address** (Text, Required: No): Select the output address.
* **output_email** (Text, Required: No): Select the output email.

## Tips
* Please fill in the form accurately and completely to ensure a successful event.
* If you have any specific requests or requirements, please mention them in the "comments" field.
* If you need assistance with filling out this form, contact us at form@gic.mx.
