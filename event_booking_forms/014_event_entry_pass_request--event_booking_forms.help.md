# Event Entry Pass Request - Help Guide
## Purpose
The Event Entry Pass Request form is designed to collect necessary information from event attendees to verify their entry to events with restricted access. This form helps event organizers to manage access levels and ensure that only authorized individuals can enter events with limited access.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Event Details** page with the event's title and any other relevant information.
2. Move on to the **Attendee Details** page and fill in the attendee's information, including their name and any other relevant details.
3. On the **Access Levels** page, select the correct access level for the attendee (All Access, VIP Access, or General Access).
4. Add any additional **Notes** about the attendee's entry if necessary.
5. Fill in the **Event Dates** page with the event's start and end dates.
6. Fill in the **Event Start Date** page with the start date of the event.
7. Fill in the **Event Start Time** page with the start time of the event.
8. If applicable, provide the **Event Location** of the event.

## Field-by-Field Explanation

* **Event Details** (`event_entry_pass_request`, text, required): Enter the event's title and any other details that might be relevant for the attendee's entry.
* **Attendee Details** (`attendee_details`, text, required): Enter the attendee's name and any other relevant details for their entry.
* **Access Levels** (`access_levels`, select_multiple, required): Select the correct access level for the attendee's entry (All Access, VIP Access, or General Access).
* **Notes** (`notes`, note, optional): Add any additional notes about the attendee's entry if necessary.
* **Event Dates** (`event_dates`, date, required): Enter the event's start and end dates.
* **Event Start Date** (`event_start_date`, date, required): Enter the start date of the event.
* **Event Start Time** (`event_start_time`, time, optional): Enter the start time of the event.
* **Event Location** (`event_location`, text, optional): Enter the event's location, if applicable.

## Tips
* Make sure to fill in all required fields to ensure the event entry is processed correctly.
* If you're unsure about the access level, please contact event organizers for clarification.
* Please note that this form is for internal use only and the information collected will be used to manage event access levels.
