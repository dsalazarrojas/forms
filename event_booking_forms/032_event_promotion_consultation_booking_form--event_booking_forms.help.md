# Event Promotion Consultation Booking Form - Help Guide
## Purpose
This form is used by event organizers to request consultations with event agencies for promotional purposes.

## How To Complete This Form
To complete this form, please follow the steps outlined above.

## Field-by-Field Explanation

* **Event Date**: Select the date of the event you are promoting.
*  **Event Time**: Enter the time of the event you are promoting.
* **Event Location**: Provide the location where the event will take place.
* **Event Start Time**: Enter the start time of the event.
* **Event End Time**: Enter the end time of the event.
* **Event Organizer**: Provide the name of the event organizer.
* **Event Agencies**: Select the agencies involved in the event.
* **Event Agency Manager**: Select the manager at the agency responsible for the event.
* **Event Booking Status**: Select the status of the event booking.
* **Event Booking Date**: Enter the date of the event booking.
* **Event Booking Time**: Enter the time of the event booking.
* **Event Description**: Provide a brief description of the event.
* **Event Promotion Channels**: Select the channels to be used for promoting the event.
* **Event Booking Notes**: Enter any additional booking notes.
* **Event Agency Notes**: Enter any notes from the agency.
* **Event Organizer Phone**: Enter the phone number of the event organizer.
* **Event Organizer Email**: Enter the email address of the event organizer.
* **Event Agency Phone**: Enter the phone number of the event agency.
* **Event Agency Email**: Enter the email address of the event agency.
* **Event Agency Address**: Enter the address of the event agency.
