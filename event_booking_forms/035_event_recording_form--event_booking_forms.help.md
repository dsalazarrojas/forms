# Event Recording Form - Help Guide
## Purpose
The Event Recording Form is a tool designed to collect essential details about an event. This form serves as a centralized platform to capture and store information regarding events, making it easier to plan, execute, and follow up on event-related activities.

## How To Complete This Form
To complete this form effectively, follow these steps:

1.  Enter the event date in the designated "Event Date" field. This field is a date picker type, allowing you to select the date of the event.
2.  Provide a title for the event in the "Event Name" field. This is a text field where you can enter a brief yet descriptive title for the event.
3.  If applicable, choose the method(s) of recording (audio, video, or both) for the event in the "Recording Method" field. This field is a multiple-choice type, so select all applicable options.
4.  Enter the location of the event in the "Event Location" field. This is a text field where you can provide the address or venue details of the event location.
5.  Add a brief description of the event in the "Event Description" field. This is a note field, allowing you to provide more extensive details about the event.
6.  Provide the name of the contact person associated with the event in the "Contact Name" field. This is a text field where you can enter the name of the person responsible for the event.
7.  Enter the email of the contact person in the "Email" field. This is an email type field, where you can provide the contact person's email address.
8.  Select the organizer's name for the event from the "Event Organizer" field. This is a single-select type field, where you can choose one name from the provided options.
9.  List the attendees of the event in the "Attendees" field. This is a text field where you can provide a list of names of the people who attended the event.
10.  Set the status of the event from the "Event Status" field. This is a single-select type field, where you can choose one status from the provided options.
11.  Enter the start time of the event in the "Start Time" field. This is a time type field, allowing you to select the start time of the event.

## Field-by-Field Explanation

*   **Event Date**: A date field where you can select the date of the event. 
*   **Event Name**: A text field to provide a brief yet descriptive title for the event. 
*   **Recording Method**: A multiple-choice field to select the method of recording (audio, video, or both) if applicable. 
*   **Event Location**: A text field to provide the address or venue details of the event location. 
*   **Event Description**: A note field to provide more extensive details about the event. 
*   **Contact Name**: A text field to enter the name of the contact person associated with the event. 
*   **Email**: An email type field to provide the contact person's email address. 
*   **Event Organizer**: A single-select field to select the organizer's name for the event. 
*   **Attendees**: A text field to list the names of the people who attended the event. 
*   **Event Status**: A single-select field to set the status of the event. 
*   **Start Time**: A time type field to select the start time of the event. 

## Tips

*   Make sure to fill in all required fields to ensure accurate event documentation.
*   Use the event description field to add more details about the event if needed.
*   Verify the email address of the contact person to ensure proper contactability.
*   Be accurate when selecting the event status to reflect the current state of the event.
*   Use the start time field to record the correct start time of the event.
