# Menu Selection Upload Form - Help Guide

## Purpose
The Menu Selection Upload Form is designed to collect information about menu selections and uploads related to an event. This form is intended to be a helpful tool for event organizers to collect and review relevant information.

## How To Complete This Form
1. Click on the "Menu Selection Upload Form" link to access the form.
2. Review the form pages to ensure that you have all the necessary information.
3. Enter your answers in the text boxes and select your options.
4. Upload your files using the file uploaders.
5. Review your answers and make any necessary corrections before submitting the form.

## Field-by-Field Explanation

* **Menu Selection 1** (`Menu Selection 1`, `select_one`, not required): Select an option from the list to provide information about the menu selection 1.
* **Menu Submissions 1** (`Menu Submissions 1`, `text`, not required): Enter a text description for menu submissions 1.
* **File Uploader 1** (`File Uploader 1`, `text`, not required): Upload a file to provide supporting information.
* **File Uploader 2** (`File Uploader 2`, `text`, not required): Upload another file to provide additional supporting information.
* **Menu Submissions 2** (`Menu Submissions 2`, `text`, not required): Enter a text description for menu submissions 2.
* **Notes** (`Notes`, `note`, not required): Enter any additional notes about the menu selection.
* **Menu Selection 2** (`Menu Selection 2`, `text`, not required): Enter a text description for menu selection 2.
* **Menu Selection 3** (`Menu Selection 3`, `text`, not required): Enter a text description for menu selection 3.
