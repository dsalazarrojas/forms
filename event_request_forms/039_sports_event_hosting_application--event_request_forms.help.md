# Sports Event Hosting Application - Help Guide
## Purpose
This form is for users to submit applications to host sports events. Fill out this form to provide details about your event, the venue, and your requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "User Info" section with your name and contact details.
2. Provide details about the venue where the event will take place in the "Venue Details" field.
3. Enter information about the event itself, such as the type, date, and time, in the "Event Info" field.
4. If you have any special requirements or requests for hosting the event, enter them in the "Host Requirements" field.

## Field-by-Field Explanation
* **User Info** (`user_info`, text, not required): Enter your name and contact information so we can get in touch with you about your event application.
* **Venue Details** (`venue_details`, text, not required): Provide details about the venue where you plan to host the event, such as its name, address, or description.
* **Event Info** (`event_info`, text, not required): Enter information about the event, like the type, date, and time it will take place.
* **Host Requirements** (`host_requirements`, text, not required): If you have any specific requirements or requests for hosting the event, such as equipment or staff needs, enter them here.
