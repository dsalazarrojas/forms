> # Food Brand Sampling Booth Order Form - Help Guide
## Purpose
This form is used to request information for an event where a company or brand wants to set up a sampling booth. It will help us understand your event requirements and preferences for the sampling booth setup.

## How To Complete This Form
1. Ensure that you have all the necessary information and details ready before starting.
2. Fill out the form accurately and thoroughly.
3. Submit the form to initiate the event request process.

## Field-by-Field Explanation

* **Title** (`event_request_form_1`, text, required): Enter a descriptive title for your event request.
* **Contact Information** (`contact_name`, text, required): Provide the name of the contact person for this event request.
* **Contact Phone** (`contact_phone`, text, required): Enter the contact phone number for the person submitting this request.
* **Event Date** (`event_date`, date, required): Select the date of the event where the sampling booth will be set up.
* **Sampling Location** (`sampling_location`, text, required): Specify the location of the event where the sampling booth will be set up.
* **Sampling Event** (`sampling_event`, select_one, required): Indicate if the event is for sampling or not.
* **Sampling Date and Time** (`sampling_date_and_time`, date, required): Select the date and time of the event where the sampling will take place.
* **Product Information 1** (`product_information_1`, text, required): Provide details about the product to be sampled.
* **Product Information 2** (`product_information_2`, text, required): Enter additional details about the product to be sampled.
* **Product Information 3** (`product_information_3`, text, required): Provide further details about the product to be sampled.
* **Event Setup Requirements** (`event_setup_requirements`, text, optional): Specify any additional setup requirements for the event.
* **Product Sample Size** (`product_sample_size`, text, optional): Indicate the size of the product sample to be offered.
* **Product Sample Weight** (`product_sample_weight`, text, optional): Specify the weight of the product sample to be offered.
* **Event Setup Cost** (`event_setup_cost`, text, optional): Enter any costs associated with setting up the event.
* **Other Event Setup Cost** (`other_event_setup_cost`, text, optional): Provide any additional costs associated with setting up the event.
* **Booth Setup Date** (`booth_setup_date`, date, optional): Indicate the date of the event setup.
* **Booth Dismantle Date** (`booth_dismantle_date`, date, optional): Specify the date of the event disassembly.
* **Sampling Duration** (`sampling_duration`, text, optional): Indicate the duration of the sampling event.
* **Sampling Type** (`sampling_type`, text, optional): Specify the type of sampling event.
* **Product Sample Type** (`product_sample_type`, text, optional): Indicate the type of product sample to be offered.
* **Event Request Form Confirmation** (`event_request_form_confirmation`, text, required): Confirm that the submitted event request is accurate and complete.

Note: Please review all fields carefully and ensure accuracy before submitting the form.
