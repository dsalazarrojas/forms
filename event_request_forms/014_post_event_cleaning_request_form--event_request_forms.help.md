# Post Event Cleaning Request Form - Help Guide
## Purpose
This form is used to collect information from users about the cleaning requirements for an event that has taken place. It helps event organizers to efficiently schedule and prepare for the cleaning services requested.

## How To Complete This Form
1. Fill in the required information, including Event Date, Event Time, and Preferred Cleaning Time.
2. Select the Service Needs that apply to your event (Basic, Premium, or Custom).
3. Enter the Event Location, Number of People, Number of Rooms, First Name, Last Name, Company Name, Email, and Phone number if required.
4. Submit the form to request the cleaning services.

## Field-by-Field Explanation

* **Event Date** (`event_date`, date, required): Enter the date of the event that has taken place.
* **Event Time** (`event_time`, time, required): Enter the time of the event that has taken place.
* **Preferred Cleaning Time** (`preferred_cleaning_time`, time, optional): Enter the preferred time for the cleaning service. If left blank, the system will schedule the cleaning at the earliest possible time.
* **Service Needs** (`service_needs`, select_multiple, required): Select the services you need for your event, such as Basic, Premium, or Custom. This will help us to provide the best services for your event.
* **Event Location** (`event_location`, text, required): Enter the location of the event. This will help us to send the cleaning crew to the correct location.
* **Number of People** (`number_of_people`, number, required): Enter the number of people attending the event.
* **Number of Rooms** (`number_of_rooms`, number, required): Enter the number of rooms that need to be cleaned.
* **First Name** (`first_name`, text, optional): Enter your first name.
* **Last Name** (`last_name`, text, optional): Enter your last name.
* **Company Name** (`company_name`, text, optional): Enter the name of your company.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
