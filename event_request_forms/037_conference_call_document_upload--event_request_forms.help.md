# Conference Call Document Upload - Help Guide
## Purpose
This form is used for uploading conference call documents. It is a crucial part of the conference call process, allowing team members to easily share and track conference call information.

## How To Complete This Form
1. Fill out all required fields marked as *required* on every page. These fields include:
	* Meeting date
	* Uploader name
	* Document purpose
	* Access permissions
	* Submission reference (generated automatically after upload)
2. For fields not marked as *required*, you can choose to fill them out or leave them blank, depending on your needs.
3. Review your filled-out form carefully before submitting it.

## Field-by-Field Explanation

* **Uploader name**: The person uploading the document. Please enter your name or team name to identify yourself.
* **Meeting date**: The date of the conference call. Enter the date in the format `YYYY-MM-DD` (e.g., 2022-07-25).
* **Document purpose**: Choose the type of document being uploaded from the list:
	+ Agenda
	+ Minutes
	+ Presentation
	+ Supporting document
* **Access permissions**: Choose who can view this document:
	+ Public
	+ Internal only
	+ Restricted
* **Upload reference**: A text field for referencing the uploaded file or attachment.
* **Access permissions**: This field determines who can view the document. Please select the desired option.
* **Notes for participants**: Additional instructions or information for viewers. You can enter any relevant comments or explanations here.
* **Contact email**: If you want to provide an email address for document-related questions or concerns, enter it here. This is optional.
* **Confidentiality notice**: A field for including read-only guidance on handling sensitive documents. Please use this field for any additional information on document handling.
* **Version number**: Enter a version number for tracking document changes. This is optional.
* **Submission reference**: A system-generated ID for reference after document upload. You will not need to fill this out.
