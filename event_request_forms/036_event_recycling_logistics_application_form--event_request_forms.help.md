# event_recycling_logistics_application_form - Help Guide
## Purpose
This form is used to gather event details and logistics information for recycling purposes, including the type of recycling service needed, schedule of collection, and any additional services required.

## How To Complete This Form
1. Fill in the required information for each field.
2. Review the information before submitting the form.

## Field-by-Field Explanation
* **Event Details (1)**: Enter a brief description of the event.
* **Recycling Needs (2)**: Select all recycling needs for this event (e.g. "Yes" for a specific service).
* **Venue Address (3)**: Enter the address of the event location.
* **City Selection (4)**: Select the city for this event.
* **Waste Hauler (5)**: Select the primary waste hauler for this event (or "Yes" if you don't have a specific hauler).
* **Collection Date (6)**: Enter the date of collection for this event.
* **Collection Time (7)**: Enter the time of collection for this event.
* **Bin Selection (8)**: Select all bin types that will be used for this event (e.g. "Yes" for a specific bin type).
* **Services Request (9)**: Select any additional services you need for this event (e.g. "Yes" for a specific service).
* **Submit (10)**: Confirm that you have completed the form correctly and submit it for review.

## Tips
* Double-check your information before submitting the form to ensure accuracy and completeness.
* If you need assistance or have questions, please contact us.
