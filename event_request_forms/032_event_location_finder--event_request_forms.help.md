# Event Location Finder - Help Guide
## Purpose
The Event Location Finder form is designed to collect information about an event location. This form is used by event planners and coordinators to provide a comprehensive overview of the event location, including date, budget, guest count, venue type, event size, parking availability, and contact information of the planner and agency involved.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date for the event in the "event_date" field.
2. Enter the budget for the event in the "event_budget" field.
3. Select the estimated number of guests attending the event in the "guest_count" field.
4. Choose the type of venue from the options provided in the "venue_type" field.
5. Select the size of the event from the options provided in the "event_size" field.
6. Indicate whether parking is available at the venue in the "parking_available" field.
7. Enter the contact information of the event planner in the "planner_name", "planner_phone", "planner_email", and "planner_note" fields.
8. Enter the contact information of the agency involved in the "agency_name", "agency_phone", "agency_email", and "agency_note" fields.

## Field-by-Field Explanation
* **event_date** (date): Select the date for the event.
* **event_budget** (number): Enter the budget for the event.
* **guest_count** (number): Select the estimated number of guests attending the event.
* **venue_type** (select_one): Choose the type of venue for the event (e.g. ballroom, bistro, catering space, etc.).
* **event_size** (select_multiple): Select the size of the event (e.g. small, medium, large, extra large).
* **parking_available** (select_one): Indicate whether parking is available at the venue.
* **planner_name** (text): Enter the name of the event planner.
* **planner_phone** (text): Enter the phone number of the event planner.
* **planner_email** (email): Enter the email address of the event planner.
* **planner_note** (note): Enter any additional notes about the event planner.
* **agency_name** (text): Enter the name of the agency involved.
* **agency_phone** (text): Enter the phone number of the agency.
* **agency_email** (email): Enter the email address of the agency.
* **agency_note** (note): Enter any additional notes about the agency.
