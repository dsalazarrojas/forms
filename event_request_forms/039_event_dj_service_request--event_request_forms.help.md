# Event DJ Service Request - Help Guide
## Purpose
This form is used to request a DJ service for an event. The information collected will be used to determine the type of event, number of guests, and other specific details to provide the best possible service.

## How To Complete This Form
To complete this form, simply fill in the required fields with the necessary information. Please note that the form is divided into several sections, each with its own specific purpose.

## Field-by-Field Explanation
* **Event Details** (`event_dj_service_request`, Text, Optional): This field is a general description of the event. Please provide a brief description of the event, including its purpose and any notable details.
* **Event Date** (`event_dj_service_date`, Date, Optional): Enter the date of the event. Please use the standard date format (MM/DD/YYYY).
* **Event Start Time** (`event_dj_service_time`, Time, Optional): Enter the start time of the event. Please use the 12-hour clock format (HH:MM AM/PM).
* **Event Duration** (`event_dj_service_duration`, Number, Optional): Enter the duration of the event in minutes. This will help us determine how many hours the DJ will need to perform.
* **Location** (`event_location`, Text, Optional): Enter the location where the event will take place. This includes the physical address, such as a house or a venue.
* **Event Type** (`event_type`, Select One, Optional): Choose the type of event this is:
	+ Wedding
	+ Party
	+ Corporate
* **Expected Number of Guests** (`event_guests`, Number, Optional): Enter the estimated number of guests attending the event.
* **Event Description** (`event_dj_service_description`, Text, Optional): Provide a detailed description of the event, including any specific requirements or needs.
* **Special Requests** (`event_dj_service_special_requests`, Text, Optional): If there are any special requests or requirements for the event, please list them here.
* **DJ Details** (`event_dj_service_dj_details`, Text, Optional): If the client has specific requests for the DJ's performance, such as music genre or specific equipment requirements, please list them here.
