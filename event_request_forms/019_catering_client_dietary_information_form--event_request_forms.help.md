# Catering Client Dietary Information Form - Help Guide
## Purpose
The Catering Client Dietary Information Form is used to provide us with information about your event and your guests' dietary restrictions. This information will help us prepare and provide suitable meals for all guests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your contact information: Provide your full name, email address, and phone number.
2. Enter event details: Enter the name of the event and the date it will take place.
3. Specify the number of guests: Enter the total number of guests attending the event.
4. Indicate dietary restrictions: Answer the question about whether any guests have dietary restrictions.
5. Provide detail about guests with dietary restrictions: If some guests have dietary restrictions, please specify the number and type of restrictions.
6. Specify any additional information: If you have any other important information to share with us, please provide it in the additional notes field.

## Field-by-Field Explanation

* **Client Name**: Enter your full name.
* **Email Address**: Enter your email address.
* **Phone Number**: Enter your contact phone number.
* **Event Name**: Enter the name of the event.
* **Event Date**: Enter the date of the event.
* **Total Number of Guests**: Enter the total number of guests.
* **Are There Dietary Restrictions**: If any guests have dietary restrictions, select "True".
* **Vegetarian Guests**: If some guests have vegetarian dietary restrictions, enter the number.
* **Vegan Guests**: If some guests have vegan dietary restrictions, enter the number.
* **Gluten-Free Guests**: If some guests have gluten-free dietary restrictions, enter the number.
* **Dairy-Free Guests**: If some guests have dairy-free dietary restrictions, enter the number.
* **Nut Allergy Guests**: If some guests have nut-free dietary restrictions, enter the number.
* **Shellfish Allergy Guests**: If some guests have shellfish-free dietary restrictions, enter the number.
* **Religious Dietary Requirements**: If some guests have religious dietary restrictions, enter the number.
* **Religious Dietary Details**: If you have any specific details about religious dietary restrictions, provide them here.
* **Medical Dietary Requirements**: If some guests have medical dietary restrictions, enter the number.
* **Medical Dietary Details**: If you have any specific details about medical dietary restrictions, provide them here.
* **Other Dietary Requirements**: If some guests have other dietary restrictions, enter the number.
* **Other Dietary Details**: If you have any other specific details about other dietary restrictions, provide them here.
* **Guest List with Dietary Info Provided**: If you will provide a detailed guest list with dietary information, select "Yes - Attached". If not, select "Yes - Will Send Later" or "False".
* **Buffet Labels Needed**: If you need allergen labels for the buffet, select "True".
* **Separate Preparation Required**: If some guests have severe allergies, select "True".
* **Additional Notes**: If you have any other important information to share, provide it here.

Note: This form is an essential part of our process for preparing and delivering meals for your event. Please ensure that you complete it accurately and thoroughly to ensure that we can provide the best possible service for your guests.
