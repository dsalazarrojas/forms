# Jewelry Display Requisition Form - Help Guide
## Purpose
The Jewelry Display Requisition Form is used to create a new event or display request for jewelry items in a mall or store. This form gathers essential information about the event or display, including details about the event itself, the type of display requested, and the location where it should take place.

## How To Complete This Form
1. Click on "Submit" to begin filling out the form.
2. Fill out each field as instructed below.

## Field-by-Field Explanation

* **Event Request Form** (`event_request_form`, text, false): This field is optional and can be used for any additional comments or requests.
* **Event Details** (`event_details`, text, false): Provide a brief description of the event or display.
* **Event Date** (`event_date`, date, false): Enter the date when the event or display should take place.
* **Event Start Time** (`event_start_time`, time, false): Enter the start time of the event or display.
* **Event End Time** (`event_end_time`, time, false): Enter the end time of the event or display.
* **Event Duration** (`event_duration`, number, false): Enter the duration of the event or display in minutes.
* **Display Request Type** (`display_request_type`, select_one, false): Choose the type of display you're requesting (Event, Promotional, or Display).
* **Display Request Location** (`display_request_location`, select_one, false): Choose the location where the display should take place (Mall, Store, or Online).
* **Jewelry Description** (`jewelry_description`, text, false): Describe the jewelry items you'd like to display.
* **Jewelry Image** (`jewelry_image`, text, false): Upload an image of the jewelry items or a reference to an image URL.
* **Jewelry Video** (`jewelry_video`, text, false): Upload a video of the jewelry items or a reference to a video URL.

## Tips
- Please fill out as many fields as necessary for your request.
- If you have any attachments (images or videos), make sure they're relevant to your request.
- If you have any further questions, feel free to contact us.
