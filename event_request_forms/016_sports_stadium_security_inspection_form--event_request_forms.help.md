# Sports Stadium Security Inspection Form - Help Guide
## Purpose
This form is designed for security inspectors to conduct thorough evaluations of sports stadiums. It collects information about upcoming events, venue details, and security protocols to ensure a safe and secure environment for attendees.

## How To Complete This Form

1.  Fill in the **Event Date** field with the actual date of the event.
2.  Select the **Event Type** from the provided options (Sports, Event, or Other).
3.  Enter the **Venue Name** of the sports stadium.
4.  Fill in the **Venue Address** of the sports stadium.
5.  Select the **Venue Security Personnel** responsible for the event, such as Security Guard or Event Manager.
6.  Select the **Safety Equipment** that will be available during the event (Fire Extinguishers, First Aid Kit, or Other).
7.  Describe the **Safety Procedures** that will be in place during the event.
8.  Check the **Security Clearance** status (True or False).
9.  Add any **Comments** regarding the event or inspection.
10.  Assign the form to the person responsible for the event by selecting **Assigned To** from the provided options (chatjimmy, John, or Jane).

## Field-by-Field Explanation

*   **Event Date**: The date on which the event is scheduled to take place.
*   **Event Type**: The type of event being held at the sports stadium (Sports, Event, or Other).
*   **Venue Name**: The name of the sports stadium where the event will be held.
*   **Venue Address**: The address of the sports stadium.
*   **Venue Security Personnel**: The personnel responsible for ensuring the event's security (Security Guard or Event Manager).
*   **Safety Equipment**: The equipment available for safety and security during the event (Fire Extinguishers, First Aid Kit, or Other).
*   **Safety Procedures**: A detailed description of the procedures in place for safety during the event.
*   **Security Clearance**: A status indicating whether the sports stadium has security clearance (True or False).
*   **Comments**: Any additional comments or observations regarding the event or inspection.
*   **Assigned To**: The person or team responsible for the event and the form submission (chatjimmy, John, or Jane).
