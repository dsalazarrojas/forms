# Event Request Form - Help Guide
## Purpose
The Event Request Form is designed to collect information for event requests. To use this form, fill out the fields accurately and thoroughly.


## How To Complete This Form
1.  Enter your name and email address in the "Name" and "Event Requester Email" fields respectively.
2.  Enter the contact number for both the event requester and the event organizer in the "Contact Number" and "Organizer Contact Number" fields respectively.
3.  Choose the event type from the dropdown menu in the "Event Type" field.
4.  Enter the start and end dates of the event in the "Start Date" and "End Date" fields respectively.
5.  Enter a detailed description of the event in the "Event Description" field.
6.  Enter the location of the event in the "Location" field.
7.  Indicate if the event requester is the one requesting the event in the "Event Requester" field.
8.  Indicate if the event organizer is the one requesting the event in the "Event Organizer" field.
9.  Enter the number of attendees expected in the "Number of Attendees" field.


## Field-by-Field Explanation
*   **Event Request Form** (`text`, required/optional): Enter a title for the event.
*   **Name** (`text`, required/optional): Enter the name of the event requester.
*   **Email Address** (`email`, required/optional): Enter the email address of the event requester.
*   **Contact Number** (`text`, required/optional): Enter the contact number of the event requester.
*   **Start Date** (`date`, required/optional): Enter the start date of the event.
*   **End Date** (`date`, required/optional): Enter the end date of the event.
*   **Event Type** (`select_one`, required/optional): Choose the type of event (Conference, Seminar, Fair, Charity Event).
*   **Event Description** (`text`, required/optional): Enter a detailed description of the event.
*   **Location** (`text`, required/optional): Enter the location of the event.
*   **Event Requester** (`select_multiple`, required/optional): Indicate if the event requester is the one requesting the event ("Yes" or "No").
*   **Event Requester** (`text`, required/optional): Enter the contact number of the event requester.
*   **Event Organizer** (`select_one`, required/optional): Indicate if the event organizer is the one requesting the event ("Yes" or "No").
*   **Organizer Contact Number** (`text`, required/optional): Enter the contact number of the event organizer.
*   **Number of Attendees** (`number`, required/optional): Enter the number of attendees expected.
*   **Event Requester Email** (`email`, required/optional): Enter the email address of the event requester.

## Tips
- Double-check your contact and email fields for accuracy.
- Ensure that you've filled out all required fields.
- Submit the form once you've completed all the fields accurately.
