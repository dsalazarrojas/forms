# Event Photography Coverage Request - Help Guide
## Purpose
This form is used to request event photography coverage. It is essential to provide accurate and detailed information about your event to ensure the right photographer is assigned.

## How To Complete This Form
- Fill out the form completely and accurately based on your event.
- Select the correct event type, schedule, and location.
- Choose the correct coverage needs and event format.
- Enter the necessary contact information for the event planner or organizer.
- Add any additional comments or details about the event.
- Review your submission carefully before submitting.

## Field-by-Field Explanation
- **Event Type**: Select the type of event you are requesting photography coverage for (Event, Wedding, or Party).
- **Schedule**: Enter the date of your event. Please use the date format (YYYY-MM-DD).
- **Location**: Enter the venue or location of your event.
- **Duration**: Enter the duration of your event (in hours).
- **Coverage Needs**: Select the number of photographers needed for your event (Single, Double, or Triple).
- **Contact Person**: Enter the name of the person handling the event organization.
- **Contact Email**: Enter the email address of the person handling the event organization.
- **Contact Phone**: Enter the phone number of the person handling the event organization.
- **Additional Comments**: Add any additional details or information about your event.
- **Event Venue**: Select the venue type of your event (Outdoor or Indoor).
- **Event Format**: Select the format of your event (Formal, Casual, or Casual + Formal).
- **Event Size**: Select the expected size of your event (Small, Medium, or Large).
- **Event Type**: Select the type of event (Public Event or Private Event).
- **Coverage Requirements**: Enter any specific requirements you have for the photography coverage.
- **Event Status**: Select the status of your event (Confirmed, Scheduled, or Not Started).
- **Event Details**: Add any additional details about your event.
- **Payment Terms**: Select the payment method for your event (Bank Transfer, Cash, or Check).
- **Contact Address**: Enter the address of the person handling the event organization.
- **Photographer Name**: Enter the name of the photographer assigned to your event.
- **Photographer Contact**: Enter the contact information for the assigned photographer.
- **Photographer Email**: Enter the email address of the assigned photographer.
- **Photographer Phone**: Enter the phone number of the assigned photographer.
- **Assigned Tool**: Select the tool or equipment used for photography coverage.
- **Comments**: Add any additional comments or feedback about your event.

Note: Please make sure to review your submission carefully before submitting the form to ensure accuracy and relevance. If you have any questions or concerns, please contact us for assistance.
