# Annual Party Logistics Request Form - Help Guide

## Purpose
This form is designed to help event planners gather essential information for annual company parties. It ensures that all necessary details are collected to make the party planning process smoother and more efficient.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name, email address, and phone number to ensure we can contact you for coordination and updates.
2. Select the department or team hosting the party.
3. Provide the event name or theme.
4. Enter the proposed date and time for the party.
5. Indicate any alternate dates if the primary date is not available.
6. Choose the expected duration of the party.
7. Enter the estimated number of attendees.
8. Select the preferred venue type (onsite, offsite, hybrid, or virtual).
9. If known, enter the specific venue location or address.
10. Indicate if catering is needed and provide any special requests.
11. Choose whether beverages will be served (alcoholic, non-alcoholic, or undecided).
12. Select the desired level of decoration.
13. Indicate if entertainment or activities are needed.
14. If applicable, provide details about the entertainment preferences.
15. Enter any audio-visual or technology needs.
16. Indicate if parking is needed and if it's limited.
17. If necessary, specify any accessibility requirements.
18. Enter the estimated budget range for the party.
19. Finally, include any special requests or considerations.

## Field-by-Field Explanation

* **Requester Name** (`requester_name`): Enter your full name to ensure we can contact you for coordination and updates.
* **Email Address** (`requester_email`): Enter your company email address for us to communicate with you about the party.
* **Phone Number** (`requester_phone`): Provide your contact number for the event planner.
* **Department or Team Name** (`department_or_team`): Select the department or team hosting the party to help with coordination.
* **Event Name or Party Theme** (`event_name`): Enter the name or theme of the party to help with planning.
* **Proposed Event Date** (`event_date`): Enter the preferred date for the party.
* **Alternate Dates** (`alternate_dates`): If the primary date is not available, provide one or two backup dates.
* **Preferred Event Time** (`event_time`): Enter the start time for the party.
* **Expected Duration** (`duration`): Choose the expected length of the party (1-2 hours, 2-3 hours, etc.).
* **Expected Number of Attendees** (`expected_attendance`): Enter the total headcount for the party.
* **Venue Preference** (`venue_preference`): Select the preferred venue type (onsite, offsite, hybrid, or virtual).
* **Specific Venue Location or Address** (`venue_location`): If known, provide the specific venue address.
* **Catering is Needed** (`catering_needed`): Indicate if catering is required for the party.
* **Catering Preferences** (`catering_preferences`): If needed, provide any dietary restrictions or special preferences.
* **Beverage Service Needed** (`beverage_service`): Choose if you'll be serving alcoholic or non-alcoholic beverages.
* **Decoration Level Desired** (`decoration_level`): Select the desired level of decoration (Minimal, Simple, Moderate, Elaborate, Professional event design).
* **Entertainment or Activities Needed** (`entertainment_needed`): Indicate if entertainment or activities are required for the party.
* **Entertainment Preferences** (`entertainment_details`): If needed, provide details about the entertainment preferences (music, games, activities, etc.).
* **Audio-Visual or Technology Needs** (`audio_visual_needs`): If required, enter any audio-visual or technology needs (microphone, projector, etc.).
* **Parking Availability Needed** (`parking_requirements`): Indicate if parking is needed and if it's limited.
* **Accessibility Requirements** (`accessibility_requirements`): If necessary, specify any accessibility requirements (wheelchair access, etc.).
* **Estimated Budget Range** (`budget_estimate`): Enter the estimated budget range for the party.
* **Special Requests or Considerations** (`special_requests`): Finally, include any special requests or considerations for the event planner.
