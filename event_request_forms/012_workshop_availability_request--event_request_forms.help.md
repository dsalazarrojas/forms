# Workshop Availability Request - Help Guide
## Purpose
This form is used to request a workshop or event availability. You will need to provide basic information to ensure that we can schedule your workshop or event correctly.

## How To Complete This Form
To fill out this form, simply provide the following information and submit it to us.

## Field-by-Field Explanation
### First name 
* **First name** (first_name, text, optional): This is the first name of the person requesting the workshop or event.

### Last name 
* **Last name** (last_name, text, optional): This is the last name of the person requesting the workshop or event.

### Email 
* **Email** (email, email, optional): This is the email address of the person requesting the workshop or event.

### Date 
* **Date** (date, date, optional): This is the date you would like to schedule the workshop or event on. Please use the format MM/DD/YYYY.

### Group size 
* **Group size** (group_size, number, optional): This is the number of people in your group that plan on attending the workshop or event.

### Preferred date 
* **Preferred date** (preferred_date, date, optional): This is the date you would prefer to schedule the workshop or event on. Please use the format MM/DD/YYYY.

### Preferred time 
* **Preferred time** (preferred_time, time, optional): This is the time you would prefer to schedule the workshop or event on. Please use the format HH:MM.

### Phone 
* **Phone** (phone, text, optional): This is a contact number for the person requesting the workshop or event.

### Contact details 
* **Contact details** (contact_details, text, optional): This is any additional information you would like to provide about yourself or your group.
