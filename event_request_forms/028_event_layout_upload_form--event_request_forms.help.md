# Event Layout Upload Form - Help Guide
## Purpose
This form is designed to collect detailed information about an event, including venue details, event description, event schedule, and other relevant details to facilitate efficient event planning and management.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill in all required fields (marked as required).
*   Select all applicable files for upload.
*   Double-check your entries for accuracy and completeness.

## Field-by-Field Explanation
*   **Venue Information**: Enter the venue's name and details where the event will take place.
*   **Upload Layout Files**: Select the files that describe the event layout, including floor plans, seating charts, and other relevant documents.
*   **Event Planning Details**: Enter any additional notes or comments about the event planning process.
*   **Event Date**: Enter the date of the event.
*   **Event Time**: Enter the time of the event.
*   **Venue Capacity**: Enter the maximum capacity of the venue.
*   **Event Description**: Enter a brief description of the event.
*   **Event Location**: Enter the location of the event.
*   **Event Organizer**: Enter the name of the event organizer.
*   **Event Status**: Choose the status of the event (Pending, Confirmed, Canceled).
*   **Contact Number**: Enter the contact number for the event.
*   **Email**: Enter the email address of the event organizer.
*   **Venue Address**: Enter the address of the venue.
*   **Upload Additional Files**: Select additional files that are relevant to the event.
*   **Event Layout Notes**: Enter any additional notes about the event layout.

Note: The fields marked as "required" must be filled in to submit the form.
