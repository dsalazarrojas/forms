# event_listing_support_request - Help Guide
## Purpose
This form is used to request support for events that are not displaying properly. Fill out this form to report any issues you've encountered with an event in the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the name of the event experiencing the issue.
2. Enter the date of the event, including the month, day, and year (e.g., 2022-07-26).
3. Enter the time of the event.
4. Enter the name of the contact person or representative.
5. Describe the support needs you have regarding the event.
6. Enter the contact email address, which will be used to contact you about your issue.
7. Enter the contact phone number, which will be used to contact you about your issue.
8. Enter a brief description of the issue or concern you have with the event.

## Field-by-Field Explanation

* **Event Name**: <label> Event Name</label> (`event_name`, `text`, required: false): Enter the name of the event that is experiencing the issue.
* **Event Date**: <label> Event Date</label> (`event_date`, `date`, required: false): Enter the date of the event using the format mm/dd/yyyy.
* **Event Time**: <label> Event Time</label> (`event_time`, `time`, required: false): Enter the time of the event.
* **Contact Name**: <label> Contact Name</label> (`contact_name`, `text`, required: false): Enter the name of the contact person or representative.
* **Support Needs**: <label> Support Needs</label> (`support_needs`, `text`, required: false): Describe the support needs you have regarding the event.
* **Email**: <label> Email</label> (`email`, `email`, required: false): Enter the contact email address, which will be used to contact you about your issue.
* **Phone**: <label> Phone</label> (`phone`, `text`, required: false): Enter the contact phone number, which will be used to contact you about your issue.
* **Description**: <label> Description</label> (`description`, `text`, required: false): Enter a brief description of the issue or concern you have with the event.

## Tips
* Make sure to enter accurate information in each field to ensure that your issue can be properly addressed.
* If you have any further information or details about the issue, include them in the description field.
* If you need to report multiple events, please submit each event separately.
* If you have any questions or concerns, feel free to contact us directly.
