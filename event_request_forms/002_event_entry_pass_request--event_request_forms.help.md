# Event Entry Pass Request - Help Guide
## Purpose
This form is used to request an event entry pass for access to specific areas of the event site.

## How To Complete This Form
1. Scroll through the form to each page and fill out the corresponding section.
2. Enter your information in the required fields.
3. Select the desired access level(s) from the dropdown menu(s).
4. Fill out the event details and dates.
5. Once you have completed all sections, review your form before submitting.

## Field-by-Field Explanation

* **Event Entry Request**: A text field for the event you wish to attend.
* **Attendee Details**: A text field for providing any additional details about yourself as an attendee.
* **Event Details**: A text field for providing event specific details.
* **Access Levels**: A dropdown menu to select the level of access you desire for the event, options are High and Low.
* **Event Dates**: A text field for providing the event dates.
* **Event Dates 1**, **Event Dates 2**, **Event Dates 3**, **Event Dates 4**: Text fields for providing the dates of the event, if applicable.
* **Access Levels 1**: A dropdown menu to select the level of access you desire for the event, options are High and Low.

## Tips
- Ensure that you are not submitting duplicate requests for the same event.
- Fill out the form completely and accurately to increase the chances of your request being approved.
- If you are unsure about any information, please contact the event organizer for clarification.
