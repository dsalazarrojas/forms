# Sports Event Media Interview Request Form - Help Guide
## Purpose
This form is designed to collect information about media requests for sports events. It is used to gather details about the event, the individual requesting media access, and the interview details.

## How To Complete This Form
To complete this form, follow these steps:
- Fill in the required fields with accurate and up-to-date information.
- Review the submission status for each request.
- Make sure to add any additional notes if necessary.

## Field-by-Field Explanation

* **Request Details** (`request_details`): 
  This field is used to enter a brief description of the media request.
  - Required: No
* **Event Date** (`event_date`): 
  Enter the date of the sports event.
  - Required: No
* **Interview Requester** (`interview_requester`): 
  Enter your name and contact information.
  - Required: No
* **Email** (`email`): 
  Enter your email address.
  - Required: No
* **Contact Information** (`contact_info`): 
  Enter any additional contact information if needed.
  - Required: No
* **Interview Details** (`interview_details`): 
  Enter a brief description of the interview details.
  - Required: No
* **Media Type** (`media_type`): 
  Choose whether you are requesting media access for this event.
  - Options: Yes/No
  - Required: No
* **Interview Location** (`interview_location`): 
  Enter the location of the interview.
  - Required: No
* **Interviewers** (`interviewers`): 
  Choose who will be conducting the interview.
  - Options: Yes/No
  - Required: No
* **Submission Status** (`submission_status`): 
  Track the status of your submission.
  - Options: Active/Inactive
  - Required: No
* **Notes** (`notes`): 
  Add any additional notes or comments about your request.
  - Required: No
* **Submit** (`submit`): 
  Review and submit your request for review.
  - Required: No

## Tips
- Make sure to enter accurate and up-to-date information to ensure efficient processing of your media request.
- If you are unsure about any of the fields, please contact event organizers or coordinators for clarification.
- This form is used to manage media requests for sports events, please be respectful of other requestors and event staff.
