# Volunteer Badge Printing Request - Help Guide
## Purpose
The "Volunteer Badge Printing Request" form is used to request the printing of volunteer badges for events. Authorized personnel can use this form to gather necessary information for volunteer badge printing.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Enter the Event Name where the volunteer will be working.
2. Select the date of the event from the calendar or enter it manually.
3. Enter the name of the volunteer who will be receiving the badge.
4. Enter the volunteer's photo (if available).
5. Enter the name of the organization or department the volunteer belongs to.
6. Enter the shift start and end times if applicable.
7. Select the role of the volunteer (if applicable).
8. Select the volunteer level (1, 2, 3, 4, or 5).
9. Enter the name and contact phone number of the person to be contacted for further details.
10. Enter the contact email of the person to be contacted for further details.
11. Enter the event ID (if applicable).
12. Select the access level of the volunteer (1, 2, 3, 4, or 5) (if applicable).
13. Add any relevant notes about the volunteer.
14. Click "Submit" to complete the form.

## Field-by-Field Explanation
- **Event Name** (Event Name, text, required): Enter the name of the event where the volunteer will be working.
  • This is the name of the event for which the volunteer will be receiving a badge.
  • Ensure it is accurate and spelled correctly.
- **Event Date** (Event Date, date, required): Select the date of the event or enter it manually.
  • This is the date of the event for which the volunteer will be receiving a badge.
  • Ensure the date is accurate and in the correct format.
- **Volunteer Name** (Volunteer Name, text, required): Enter the name of the volunteer.
  • This is the name of the person who will be receiving the badge.
  • Ensure it is spelled correctly and accurate.
- **Volunteer Photo** (Volunteer Photo, text, required): Enter the volunteer's photo.
  • This is an optional field; if not provided, the volunteer will still be printed a badge.
  • If available, please attach a recent, clear photo of the volunteer.
- **Organization/Department** (Organization, text, required): Enter the name of the organization or department the volunteer belongs to.
  • This is where the volunteer will be working and receiving their badge from.
  • Ensure it is accurate and spelled correctly.
- **Shift Start** (Shift Start, time, required): Enter the start time of the volunteer's shift if applicable.
  • This field is optional, but if applicable, enter the time the volunteer starts their shift.
  • Use the correct format (HH:MM) and ensure it is accurate.
- **Shift End** (Shift End, time, required): Enter the end time of the volunteer's shift if applicable.
  • This field is optional, but if applicable, enter the time the volunteer ends their shift.
  • Use the correct format (HH:MM) and ensure it is accurate.
- **Role** (Role, text, required): Select the role of the volunteer if applicable.
  • This is the position or title the volunteer holds within the organization or department.
  • If not applicable, leave this field blank.
- **Volunteer Level** (Volunteer Level, select_one, required): Select the level of the volunteer.
  • This determines the level of access or privileges the volunteer has within the organization or department.
  • Choose one of the available options: Level 1, 2, 3, 4, or 5.
- **Contact Name** (Contact Name, text, required): Enter the name of the person to be contacted for further details.
  • This is the person responsible for the volunteer's badge printing.
  • Ensure it is spelled correctly and accurate.
- **Contact Phone** (Contact Phone, text, required): Enter the contact phone number of the person to be contacted for further details.
  • This is the phone number of the person responsible for the volunteer's badge printing.
  • Ensure it is accurate and in the correct format.
- **Contact Email** (Contact Email, email, required): Enter the contact email of the person to be contacted for further details.
  • This is the email of the person responsible for the volunteer's badge printing.
  • Ensure it is accurate and in the correct format.
- **Event ID** (Event ID, text, required): Enter the event ID if applicable.
  • This is a unique identifier for the event for which the volunteer will be receiving a badge.
  • If not applicable, leave this field blank.
- **Access Level** (Access Level, select_multiple, required): Select the access level of the volunteer if applicable.
  • This determines the level of access or privileges the volunteer has within the organization or department.
  • If not applicable, leave this field blank.
  • Choose from the available options: Level 1, 2, 3, 4, or 5.
- **Notes** (Notes, note, required): Add any relevant notes about the volunteer.
  • This is an optional field for any additional comments or information about the volunteer.
  • Ensure it is clear and concise.
- **Submit** (Submit, text, required): Click this button to complete the form.
  • This is the final step to submit the volunteer badge printing request.
  • Ensure all fields are filled out accurately before clicking "Submit".
