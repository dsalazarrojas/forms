# Virtual Screening Replay Request Form - Help Guide
## Purpose
This form is used to request a replay of a virtual screening that was missed or experienced technical issues during the event.

## How To Complete This Form
To complete this form, follow these steps:

* Select the type of screening you want to replay ('Yes' or 'No')
* Enter your email address where you would like to receive updates and follow-up information
* Provide the date of the original event
* Enter the name of the festival where the screening took place
* Enter the name of the screening you are interested in replaying
* Leave any additional comments or questions about the screening you want to replay
* If applicable, provide the name of the distributor involved with the screening
* If applicable, provide the name and contact information of the event organizer

## Field-by-Field Explanation
### Screening Type (Screening Type)
* **Screening Type** (select_one): Choose 'Yes' if you want to request a replay of the screening, 'No' if you do not require a replay.

### Viewer Email (Viewer Email)
* **Viewer Email** (email): Enter your email address where you want to receive updates and follow-up information.

### Date of Event (Date of Event)
* **Date of Event** (date): Enter the date of the original event.

### Name of Festival (Name of Festival)
* **Name of Festival** (text): Enter the name of the festival where the screening took place.

### Name of Screening (Name of Screening)
* **Name of Screening** (text): Enter the name of the screening you are interested in replaying.

### Viewer Comments (Viewer Comments)
* **Viewer Comments** (text): Leave any additional comments or questions about the screening you want to replay.

### Name of Distributor (Name of Distributor)
* **Name of Distributor** (text): If applicable, enter the name of the distributor involved with the screening.

### Name of Event Organiser (Name of Event Organiser)
* **Name of Event Organiser** (text): If applicable, enter the name of the event organizer.

### Event Organiser Email (Event Organiser Email)
* **Event Organiser Email** (email): If applicable, enter the email address of the event organizer.

### Event Organiser Phone (Event Organiser Phone)
* **Event Organiser Phone** (text): If applicable, enter the phone number of the event organizer.
