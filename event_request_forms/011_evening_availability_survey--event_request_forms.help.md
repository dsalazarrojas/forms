# Evening Availability Survey - Help Guide

## Purpose

The Evening Availability Survey is designed to gather information about your evening work schedule. It's used to determine when you are available to work on evenings and to what extent. Please only fill out this form if you are an employee or have a specific reason to complete it (e.g., work-related event). If you've already completed this form, please do not fill it out again.

## How To Complete This Form

1. To begin, enter your group name in the text field.
2. Select 'Yes' or 'No' to confirm if you are or are not available on the evening.
3. If you select 'Yes', you will be asked to enter your work start and end times using the time input fields.
4. Select the days of the week you are available on evenings by entering a number (1-7) corresponding to each day of the week.

## Field-by-Field Explanation

* **Enter Group Name**: Enter your group name to identify yourself in the system. This field is not required.
* **Group Type**: Select 'Yes' if you are available to work on evenings, 'No' otherwise. This field is not required.
* **What time do you start work on evenings?**: If you selected 'Yes' for Group Type, enter the start time of your work schedule using 24-hour format (e.g., 17:00 for 5:00 PM). This field is not required.
* **What time do you end work on evenings?**: If you selected 'Yes' for Group Type, enter the end time of your work schedule using 24-hour format (e.g., 20:00 for 8:00 PM). This field is not required.
* **Monday**: Enter 1 if you are available on Monday, 0 if you are not. This field is not required.
* **Tuesday**: Enter 1 if you are available on Tuesday, 0 if you are not. This field is not required.
* **Wednesday**: Enter 1 if you are available on Wednesday, 0 if you are not. This field is not required.
* **Thursday**: Enter 1 if you are available on Thursday, 0 if you are not. This field is not required.
* **Friday**: Enter 1 if you are available on Friday, 0 if you are not. This field is not required.

## Tips

* Please use 24-hour format for start and end times.
* If you're unsure about your availability, select 'No' for Group Type.
* If you need help, contact your supervisor or the IT department.
