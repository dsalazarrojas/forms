# Event Production Scheduling Survey - Help Guide
## Purpose
The Event Production Scheduling Survey is a crucial tool for event organizers to provide accurate and comprehensive information about their productions. This form ensures that all necessary details are captured, facilitating efficient planning and execution.

## How To Complete This Form
To complete the form, follow these steps:

1.  Determine whether you will be holding an event at a venue or not. Select "Yes" or "No" for the "Venue" field.
2.  Enter the date of your event using the date picker or manually input it in the correct format.
3.  Enter the start time of your event using the time picker or manually input it in the correct format.
4.  Enter the end time of your event using the time picker or manually input it in the correct format.
5.  Specify whether you will be working with a production team ("Yes" or "No").
6.  Choose the resources needed for your event from the available options.
7.  Provide any additional venue-specific requirements in the text field.
8.  Indicate the type of event you will be hosting, such as a concert or performance ("Yes" or "No").
9.  Select the expected event size from the provided options.
10.  Specify the format of your event, such as live or digital ("Yes" or "No").
11.  Choose the duration of your event from the provided options.
12.  Enter any additional event details in the text area.
13.  Enter any notes about your event in the text area.

## Field-by-Field Explanation

*   **Venue** (`venue_id`, `select_multiple`, required/optional): Select "Yes" or "No" to indicate whether your event will be held at a venue.
*   **Event Date** (`event_date`, `date`, required/optional): Enter the date of your event using the date picker or manually input it in the correct format.
*   **Start Time** (`start_time`, `time`, required/optional): Enter the start time of your event using the time picker or manually input it in the correct format.
*   **End Time** (`end_time`, `time`, required/optional): Enter the end time of your event using the time picker or manually input it in the correct format.
*   **Production Team** (`production_team`, `select_multiple`, required/optional): Choose "Yes" or "No" to indicate whether a production team will be involved.
*   **Resources** (`resources`, `select_multiple`, required/optional): Select the resources required for your event from the available options.
*   **Venue Requirements** (`venue_requirements`, `text`, required/optional): Enter any specific venue requirements in this text field.
*   **Event Type** (`event_type`, `select_multiple`, required/optional): Choose "Yes" or "No" to indicate the type of event.
*   **Event Size** (`event_size`, `select_one`, required/optional): Select the expected event size from the provided options.
*   **Event Format** (`event_format`, `select_multiple`, required/optional): Choose "Yes" or "No" to indicate the format of your event.
*   **Event Duration** (`event_duration`, `select_one`, required/optional): Choose the duration of your event from the provided options.
*   **Event Details** (`event_details`, `note`, required/optional): Enter any additional event details in this text area.
*   **Event Notes** (`event_notes`, `note`, required/optional): Enter any notes about your event in this text area.
*   **Venue ID** (`venue_id_2`, `select_one`, required/optional): This field is currently not used in this form, and we recommend skipping it.

Note: The fields marked as required/optional are not actually required, as per the YAML configuration.
