# Stage Performance Slot Extension Request Form - Help Guide

## Purpose
This form allows users to submit extension requests for stage performance slots.

## How To Complete This Form
To complete this form, follow the steps below:

1. Ensure you have reviewed the original performance slot schedule and understand the context.
2. Fill out each field in the form with accurate information.
3. Submit the form for internal review and approval.

## Field-by-Field Explanation

* **Stage Performance Slot Extension Request Form** (`stage_performance_slot_extension_request_form`, text, optional): This field is not a form field in the sense that it's the form's title, not a field to be filled. It's here to let you know that this is the form's title.
* **Stage Performance Slot Date** (`stage_performance_slot_date`, date, optional): Enter the date for which the slot extension is requested.
* **Stage Performance Slot Duraton** (`stage_performance_slot_duraton`, number, optional): Enter the duration of the slot extension, in hours or minutes.
* **Stage Performance Slot Duration Reasons** (`stage_performance_slot_duration_reasons`, text, optional): Explain the reasons for the slot extension request, including any relevant context or supporting information.

## Tips
* Be as specific as possible when filling out the form to ensure accurate review and approval.
* If you're unsure about any field, please don't hesitate to reach out to relevant stakeholders for clarification.
* This form is intended for internal extension requests, not for creating new performance slots. Review the original schedule and check with stakeholders before submitting the form.
