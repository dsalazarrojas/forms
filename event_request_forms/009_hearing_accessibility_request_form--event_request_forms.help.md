# Hearing Accessibility Request Form - Help Guide

## Purpose
The Hearing Accessibility Request Form is a tool designed to collect information about events that require accessibility accommodations. This form helps event organizers and attendees submit requests for accommodations that can make events more accessible and inclusive for everyone.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Event Details**: Enter a brief description of the event, including the name of the event, location, and date.
2. **Requestor Details**: Provide your personal information, including your name, email address, and contact number.
3. **Accessibility Requirements**: Specify any accessibility needs or requirements you have for the event, such as wheelchair accessibility, sign language interpretation, or other accommodations.
4. **Event Scheduling**: Select a date for the event if it is not already scheduled.
5. **Session Details**: Provide any additional information about the session or event that may be helpful for our team to consider.
6. **Request Status**: Select the current status of your request from the options provided.
7. **Follow up**: If applicable, choose a follow-up date for the event, if you would like to be updated on the status of your request.

## Field-by-Field Explanation
* **Event Details** (Event Details, text, required): Enter the name, location, and date of the event for which you are requesting accommodations.
* **Requestor Details** (Requestor Details, text, required): Provide your name, email address, and contact number so that we can reach out to you about your request.
* **Accessibility Requirements** (Accessibility Requirements, text, required): Specify any accessibility needs or requirements you have for the event, such as wheelchair accessibility, sign language interpretation, or other accommodations.
* **Event Scheduling** (Event Scheduling, date, required): Select a date for the event if it is not already scheduled.
* **Session Details** (Session Details, text, required): Provide any additional information about the session or event that may be helpful for our team to consider.
* **Request Status** (Request Status, select_one, required): Choose the current status of your request from the options provided.
* **Follow up** (Follow up, date, required): If applicable, choose a follow-up date for the event, if you would like to be updated on the status of your request.

## Tips
* Please make sure to provide accurate and complete information to ensure that your request is processed correctly.
* If you have any additional questions or concerns, please don't hesitate to reach out to us.
* We will do our best to accommodate your request, but please note that we cannot guarantee that all requests can be fulfilled.
