# Live Entertainment Coverage Request Form - Help Guide
## Purpose
The Live Entertainment Coverage Request Form is a tool used to gather information from users regarding their requests for live entertainment coverage. This form is intended to collect details about the user's event and their preferred media coverage options. It's essential to complete this form accurately to ensure that your live event coverage needs are met.

## How To Complete This Form
To get started, simply select the relevant information for each field and submit the form. You can fill in as much or as little information as you need, and don't worry if some fields are not applicable. However, be aware that not providing required information may impact the processing of your request.

## Field-by-Field Explanation
### 1. User Information
* **User Information (user_info)** (`User Information`, optional, `text`): This field is for you to provide any additional information about yourself. You can type in as much or as little text as you need.

### 2. Event Information
* **Event Information (event_info)** (`Event Information`, optional, `text`): Please enter any additional details about the event you'd like to get live coverage for. This could be the name, date, time, location, etc.

### 3. Coverage Preference
* **Coverage Preference (coverage_preference)** (`Coverage Preference`, optional, `select_multiple`): Select all that apply:
	+ Option 1: This is your preferred coverage option.
	+ Option 2: This is your secondary preferred option.
	+ Option 3: This is your tertiary preferred option.

### 4. Media Contact Info
* **Media Contact Info (media_contact_info)** (`Media Contact Info`, optional, `text`): If you have any additional contact details for the media you'd like to contact, feel free to provide them here.

## Tips
If you're unsure about any field, you can always reach out to our support team for further assistance. We're here to help ensure that you get the live entertainment coverage you need.
