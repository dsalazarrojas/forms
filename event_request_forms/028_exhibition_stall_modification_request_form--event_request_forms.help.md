# Exhibition Stall Modification Request Form - Help Guide
## Purpose
This form is used to modify an exhibition stall in a specific event. You can use it to request changes, replacements, or removals of exhibition stalls.

## How To Complete This Form

To complete this form, follow these steps:

* Select the "Event Organizer" from the options provided, as it is required to identify the owner of the exhibition.
* Enter the "Event Data" in the space provided. This field is not required, but it's useful to provide additional context about the event.
* If necessary, upload file(s) by using the "Form Files" option.
* Set "Preferred Dates" for the modified stall. If left empty, the default date of the event will be assumed.
* Choose whether the stall is "prioritized" or not.
* Enter the date the request was submitted.
* Select the time of day when the request was submitted.
* Choose who the request was submitted by.
* If the request requires a modification, select the type of modification required. For the "Modified" field, enter the number of modifications made.
* Enter the "Event ID" number of the event.
* Enter the "Request ID" number of the request.
* If a change is required, choose the "Status" of the request as "New", "Approved", "Rejected", or "Pending".
* Finally, select the "Modification Type" as "Change", "Replace", or "Remove".

## Field-by-Field Explanation
* **Exhibition Stall Modification Request Form**: This is the title of the form.
* **File Uploads**: This field is not currently used, but you can upload files if necessary.
* **Preferred Dates**: This field allows you to select the preferred dates for the modified stall. If left blank, the default date of the event will be assumed.
* **Prioritized Stalls**: Select whether the stall is prioritized or not.
* **Event Data**: This field is for additional context about the event. It is not required but can be useful for further information.
* **Event Organizer**: Choose the event organizer from the options provided. This is a required field to identify the event owner.
* **Event Organizer Phone**: Currently, this field is not used. It may be used in the future, but for now, it's a placeholder.
* **Event Organizer Email**: This field is also currently not used. It may be used in the future, but for now, it's a placeholder.
* **Form Files**: This field is for uploading files if necessary. Currently, it's not used.
* **Event Details**: This field is used to provide additional details about the event. It is not required but can be useful for further information.
* **Event Dates**: This field allows you to select the date for the modified stall. If left blank, the default date of the event will be assumed.
* **Stall Number**: This field is for the number of the stall being modified.
* **Request Description**: This field is for a description of the request.
* **Status**: Choose the status of the request as "New", "Approved", "Rejected", or "Pending".
* **Assigned Tool**: Choose the tool assigned for the request from the options provided.
* **Submitted Date**: This field is for the date the request was submitted.
* **Submission Time**: This field is for the time of day the request was submitted.
* **Submitted By**: This field is for the person who submitted the request.
* **Modified By**: This field is for the person who modified the request.
* **Modified Date**: This field is for the date the request was modified.
* **Submitted**: Currently not used; a placeholder.
* **Modification Type**: Choose the type of modification required as "Change", "Replace", or "Remove".
* **Modified**: This field is for the number of modifications made.
* **Event ID**: This field is for the ID number of the event.
* **Request ID**: This field is for the ID number of the request.
* **Modification Type**: Choose the type of modification required as "Change", "Replace", or "Remove".
