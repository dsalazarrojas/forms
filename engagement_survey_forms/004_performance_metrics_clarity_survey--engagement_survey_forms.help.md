# Performance Metrics Clarity Survey - Help Guide
## Purpose
This survey is designed to gather information on how employees perceive the clarity of performance metrics and identify areas for improvement.

## How To Complete This Form
- Read each section carefully and answer the questions truthfully.
- Answer the questions according to your understanding and experience with performance metrics.
- Take as much time as you need to complete the form, but please try to finish it in one sitting.

## Field-by-Field Explanation

* **Employee Understanding** (`page_3`, number, optional): This question asks about your understanding of performance metrics. Please select a number between 1 and 5, where 1 is "Poor" and 5 is "Excellent".
* **Metrics Clarity** (`page_4`, select_one, required): This question asks how clear you think performance metrics are. Please select one of the following options: "Excellent", "Good", "Fair", or "Poor".
* **Target Achievement** (`page_5`, select_multiple, required): This question asks about the alignment between performance metrics and target goals. Select all that apply:
	+ Met
	+ Partially Met
	+ Not Met
	+ No target set
* **Metrics Alignment Improvement Plan** (`page_6`, select_one, required): This question asks about your agreement with improvement plans for metrics alignment. Please select one of the following options: "Agree", "Neutral", or "Disagree".
* **Action Plan** (`page_7`, select_one, required): This question asks about the current action plan for metrics alignment improvement. Please select one of the following options: "Action Plan", "No action plan".
* **Improvement Plan Progress** (`page_8`, select_one, required): This question asks about the progress of the improvement plan. Please select one of the following options: "In progress", "Not in progress".
* **Effectiveness of Improvement Plan** (`page_9`, select_one, required): This question asks about the effectiveness of the improvement plan. Please select one of the following options: "Effectiveness", "Neutral", or "Not effective".
* **Comments** (`page_10`, select_multiple, required): This is an open-ended question where you can provide any additional comments or feedback about performance metrics clarity.
	+ Select all that apply: "Excellent", "Good", "Fair", or "Poor". 
Note: Please take this form as a starting point for improvement, your comments can help us better understand the current state and identify potential areas for improvement.
