# Project Execution Readiness Survey - Help Guide
## Purpose
This form is designed to assess the readiness of a project for execution. It is used to collect information about the project's current status, suitable questions, title, description, execution readiness score, and submission status.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the title of the project in the "Title" field.
* Describe the project in the "Description" field.
* Choose the suitable questions that apply to the project from the "Suitable Questions" field.
* Enter a score out of 10 to indicate the project's execution readiness in the "Project Execution Readiness Score" field.
* Select the current submission status of the project from the "Submission Status" field.

## Field-by-Field Explanation
* **Title** (`project_title`, text, required): Enter the title of the project.
* **Description** (`project_description`, text, required): Enter a brief description of the project.
* **Suitable Questions** (`suitable_questions`, select_multiple, optional): Select the questions that apply to the project. These questions help to identify specific challenges or needs that the project may face.
* **Project Execution Readiness Score** (`project_execution_readiness_score`, number, required): Enter a score out of 10 to indicate the project's execution readiness.
* **Submission Status** (`submission_status`, select_one, required): Select the current status of the project's submission.

## Tips

* Make sure to provide accurate and complete information about the project in the "Title" and "Description" fields.
* Choose all applicable questions from the "Suitable Questions" field to ensure that they are taken into account when assessing the project's execution readiness.
* The "Project Execution Readiness Score" is a subjective measure, so be objective and fair when assigning a score.
* The "Submission Status" field should reflect the actual status of the project's submission, and not the desired status.
