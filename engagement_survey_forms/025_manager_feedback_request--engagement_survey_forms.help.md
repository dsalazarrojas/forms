# Manager Feedback Request - Help Guide
## Purpose
This form is used to collect feedback from team members about their manager's performance, allowing for honest and constructive input to help improve the manager's skills and the team's overall well-being.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the manager's name in the "Manager Name" field.
2. Select the category where the manager excels or needs improvement from the "Feedback For Manager" field.
3. In the "Manager Strengths" field, choose any number of skills or traits where the manager excels.
4. In the "Areas For Improvement" field, type any specific areas where the manager needs improvement.
5. In the "Manager Feedback" field, select one or more areas where the feedback is positive, negative, or neutral.
6. In the "Anonymous Feedback" field, provide any additional comments or feedback about the manager.

## Field-by-Field Explanation
* **Feedback Request** (`feedback_request`, text, **required**): This is a free-text field for team members to provide feedback about their manager. This field should contain a clear and concise description of the feedback.
* **Manager Name** (`manager_name`, text, **required**): Enter the manager's name who is being feedback on.
* **Feedback For Manager** (`feedback_for_manager`, select_one, **required**): Select the category where the manager excels or needs improvement, such as "Manager" or "Team Members".
* **Manager Strengths** (`manager_strengths`, select_multiple, **required**): Choose any number of skills or traits where the manager excels, such as "Communication", "Leadership", etc.
* **Areas For Improvement** (`areas_for_improvement`, text, **required**): Type any specific areas where the manager needs improvement.
* **Manager Feedback** (`manager_feedback`, select_multiple, **required**): Select one or more areas where the feedback is positive, negative, or neutral, such as "Positive", "Negative", etc.
* **Anonymous Feedback** (`anonymous_feedback`, text, **required**): Provide any additional comments or feedback about the manager.
* **Submit** (`submit`, note, **optional**): Click the "Submit" button to submit the feedback form.
