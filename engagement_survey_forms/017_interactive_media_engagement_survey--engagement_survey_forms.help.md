# Interactive Media Engagement Survey - Help Guide
## Purpose
The Interactive Media Engagement Survey form is used to collect data on engagement levels of media content.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the media content in the "Form Title" field.
2. Select the category of the media content in the "Category" field.
3. Provide a description of the media content in the "Description" field.
4. Enter the title of the media content in the "Media Title" field.
5. Enter the URL of the media content in the "Media URL" field.
6. Select the engagement level of the media content in the "Engagement Level" field.
7. Enter the engagement level description in the "Engagement Description" field.
8. Enter any additional comments about the engagement level in the "Engagement Comment" field.
9. Select whether the form is a description of the media content in the "Form Description" field.
10. Enter the URL of the form in the "Form URL" field.
11. Enter the version number of the form in the "Form Version" field.
12. Enter the number of submissions received in the "Submission Count" field.
13. Enter the name of the user who submitted the form in the "Submitted By" field.
14. Enter the date and time the form was submitted in the "Submitted At" field.
15. Enter the username or email of the user who submitted the form in the "Submitted By User" field.
16. Enter the time of submission in the "Submission Time" field.
17. Select the version history of the form in the "Form Version History" field.
18. Enter the ID of the user who submitted the form in the "Submitted By User ID" field.
19. Enter a timestamp for the submitted date in the "Submitted At Timestamp" field.
20. Enter the version number of the form in the "Form Version Number" field.
21. Select whether the submission is public or private in the "Form Submissions" field.
22. Enter any comments about the submission in the "Submission Comments" field.
23. Select the status of the submission in the "Submission Status" field.

## Field-by-Field Explanation
* **Form Title** (`form_title`, `text`, required: false): This is the title of the form, which will be displayed at the top of the form.
* **Category** (`category`, `select_one`, required: false): This is the category of the media content, which can be Engagement Survey Forms, Feedback Forms, or Media Forms.
* **Description** (`description`, `note`, required: false): This is a description of the media content, which can be any text.
* **Media Title** (`media_title`, `text`, required: false): This is the title of the media content.
* **Media URL** (`media_url`, `text`, required: false): This is the URL of the media content.
* **Rating** (`rating`, `number`, required: false): This is a rating of the media content, which can be a number.
* **Engagement Level** (`engagement_level`, `select_one`, required: false): This is the level of engagement of the media content, which can be High, Medium, or Low.
* **Engagement Description** (`engagement_description`, `text`, required: false): This is a description of the engagement level.
* **Engagement Comment** (`engagement_comment`, `text`, required: false): This is any additional comment about the engagement level.
* **Form Description** (`form_description`, `select_one`, required: false): This is a description of the form, which can be Yes or No.
* **Form URL** (`form_url`, `text`, required: false): This is the URL of the form.
* **Form Version** (`form_version`, `number`, required: false): This is the version number of the form.
* **Submission Count** (`submission_count`, `number`, required: false): This is the number of submissions received.
* **Submitted By** (`submitted_by`, `text`, required: false): This is the name or username of the user who submitted the form.
* **Submitted At** (`submitted_at`, `date`, required: false): This is the date and time the form was submitted.
* **Submitted By User** (`submitted_by_user`, `email`, required: false): This is the username or email of the user who submitted the form.
* **Submission Time** (`submission_time`, `time`, required: false): This is the time of submission.
* **Form Version History** (`form_version_history`, `select_multiple`, required: false): This is a history of the form versions.
* **Submitted By User ID** (`submitted_by_user_id`, `number`, required: false): This is the ID of the user who submitted the form.
* **Submitted At Timestamp** (`submitted_at_timestamp`, `number`, required: false): This is a timestamp for the submitted date.
* **Form Version Number** (`form_version_number`, `number`, required: false): This is the version number of the form.
* **Submission Time** (`submission_time`, `time`, required: false): This is the submission time.
* **Form Submissions** (`form_submissions`, `select_one`, required: false): This is the submission status, which can be Public or Private.
* **Submission Comments** (`submission_comments`, `text`, required: false): This is any comments about the submission.
* **Submission Status** (`submission_status`, `select_one`, required: false): This is the status of the submission, which can be Approved, Declined, or Pending.

## Tips
* Please fill out all the required fields.
* Be as accurate as possible when filling out the fields.
* If you have any questions or need help, contact the support team.
