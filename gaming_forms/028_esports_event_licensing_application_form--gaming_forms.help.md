# Esports Event Licensing Application Form - Help Guide
## Purpose
The Esports Event Licensing Application Form is a critical document used to apply for event licensing in the esports industry.

## How To Complete This Form
1. Ensure you have all required documents and information ready before starting.
2. Select the event title and enter the event date and time.
3. Provide the event organizer's name, email, and contact details.
4. Answer the questions regarding event licensing status, fees, and other relevant details.
5. Specify the event staff and their qualifications.
6. Outline the event safety and emergency plans.
7. Confirm your understanding of the event licensing process and terms.

## Field-by-Field Explanation

* **Event Title** (`event_title`, text, required): Enter the title of the event as it will be known to the public.
* **Event Date** (`event_date`, date, required): Enter the date of the event in the format YYYY-MM-DD.
* **Event Time** (`event_time`, time, required): Enter the time of the event in 24-hour format (HH:MM).
* **Event Organizer** (`event_organizer`, text, required): Enter the name of the event organizer or company.
* **Event Details** (`event_details`, text, required): Provide a brief description of the event, including the type and duration of the event.
* **Event Venue** (`event_venue`, text, optional): If the event has a venue, enter the address or name of the venue.
* **Event Licensing Fee** (`event_licensing_fee`, number, optional): If applicable, enter the licensing fee for the event.
* **Event License Type** (`event_license_type`, select_one, required): Select 'Yes' if the event requires a license.
* **Event License Status** (`event_license_status`, select_one, required): Select the status of the event license, either 'Active' or 'Inactive'.
* **Event License Start Date** (`event_license_start_date`, date, required): Enter the start date of the event license.
* **Event License End Date** (`event_license_end_date`, date, required): Enter the end date of the event license.
* **Event License Number** (`event_license_number`, number, optional): If applicable, enter the event license number.
* **Event License Status Description** (`event_license_status_description`, select_one, required): Select the status description of the event license, either 'Active' or 'Inactive'.
* **Event License Organizer Name** (`event_license_organizer_name`, text, required): Enter the name of the event license organizer.
* **Event License Organizer Email** (`event_license_organizer_email`, email, required): Enter the email address of the event license organizer.
* **Event License Organizer Phone** (`event_license_organizer_phone`, text, optional): Enter the phone number of the event license organizer.
* **Event License Organizer Address** (`event_license_organizer_address`, text, optional): Enter the address of the event license organizer.
* **Event License Notes** (`event_license_notes`, text, optional): Enter any additional notes or comments about the event license.
* **Event Prophets** (`event_prophets`, select_one, required): Select 'Yes' if the event has prophets or streamers attending.
* **Event Streamer** (`event_streamer`, select_one, required): Select 'Yes' if the event has streamers attending.
* **Event Staff** (`event_staff`, select_multiple, required): Select all applicable event staff types that will be present during the event.
* **Event Safety Plan** (`event_safety_plan`, text, required): Outline the safety measures in place during the event.
* **Event Medical Plan** (`event_medical_plan`, text, required): Provide the medical plan for the event.
* **Event Emergencies** (`event_emergencies`, select_multiple, required): Select all the potential emergencies that may occur during the event.
* **Event Venue Capacity** (`event_venue_capacity`, number, optional): If applicable, enter the capacity of the event venue.
