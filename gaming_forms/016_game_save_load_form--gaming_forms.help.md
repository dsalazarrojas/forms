# Game Save Load Form - Help Guide

## Purpose
The Game Save Load Form is used to record and track game save and load requests from players. This form is used to collect information about the game, platform, and player details associated with the save or load request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant game title and platform for the save or load request.
2. Enter the game version and any version notes, if applicable.
3. Enter the player name and player ID, if applicable.
4. Select the save and load status (e.g., Load, Save, or Both).
5. Enter any additional request details and notes, if applicable.
6. Enter the assignee name and ID, if applicable.
7. Select the request date and time, if applicable.
8. Update the form status and add any comments, if applicable.
9. Add any attachments, if applicable.
10. Add any tags, if applicable.
11. Add custom form fields, if applicable.
12. Enter the game and version details, if applicable.
13. Enter the player name 2 and platform 2 details, if applicable.

## Field-by-Field Explanation

* **Game Save Load Form**: This is the title of the form, which cannot be edited.
* **Game Title**: Enter the title of the game you are requesting to save or load. (Text, optional)
* **Platform**: Select the platform on which the game was saved or loaded. (Select One, optional)
* **Game Version**: Enter the version of the game you are requesting to save or load. (Number, optional)
* **Version Notes**: Enter any additional notes about the game version, if applicable. (Text, optional)
* **Player Name**: Enter the name of the player who saved or loaded the game. (Text, optional)
* **Player ID**: Enter the ID of the player who saved or loaded the game. (Text, optional)
* **Platform Notes**: Enter any additional notes about the platform, if applicable. (Text, optional)
* **Save Load Status**: Select the status of the save or load request (e.g., Load, Save, or Both). (Select Multiple, optional)
* **Request Details**: Enter any additional details about the request, if applicable. (Text, optional)
* **Request Notes**: Enter any additional notes about the request, if applicable. (Text, optional)
* **Assignee Name**: Enter the name of the person or team assigned to handle the request. (Text, optional)
* **Assignee ID**: Enter the ID of the person or team assigned to handle the request. (Text, optional)
* **Request Date**: Select the date of the request, if applicable. (Date, optional)
* **Request Time**: Select the time of the request, if applicable. (Time, optional)
* **Form Status**: Select the current status of the form (e.g., Pending, Completed, or In Progress). (Select One, optional)
* **Comments**: Add any comments about the form, if applicable. (Text, optional)
* **Attachments**: Add any attachments related to the request, if applicable. (Text, optional)
* **Tags**: Add any tags related to the request, if applicable. (Text, optional)
* **Custom Form Fields**: Add any custom fields, if applicable. (Text, optional)
* **Game**: Enter the game details, if applicable. (Text, optional)
* **Version**: Enter the version details, if applicable. (Text, optional)
* **Player Name 2**: Enter the name of player 2, if applicable. (Text, optional)
* **Platform 2**: Enter the platform 2 details, if applicable. (Text, optional)

Note: All fields are optional unless marked as required.
