# tabletop_game_feedback_form - Help Guide
## Purpose
This form is designed to collect detailed feedback from players about their tabletop game experiences. Your input will help game developers understand what players like or dislike about the game, which can lead to improvements and a better gaming experience for everyone.

## How To Complete This Form
1. **Gameplay**: Select one of the provided options to describe your gameplay experience (Option 1, Option 2, or Option 3).
2. **Ratings**: Enter a numerical rating (1-10) for your overall experience.
3. **Suggestions**: Type any suggestions you have for improving the game.
4. **Game Improvements**: Select multiple options to describe areas where the game can be improved (Option 1, Option 2, or Option 3).
5. **Submit Date**: Enter the date you submitted this feedback (automatically populated).
6. **Game ID**: Enter the game's unique ID number.
7. **Player Rating**: Enter a numerical rating (1-10) for your overall experience.
8. **Player Comments**: Type any additional comments about your experience.
9. **Email**: Enter your player email address.
10. **Phone**: Enter your phone number (optional).
11. **Player Name**: Enter your name as the player.
12. **Game Name**: Enter the game's name.
13. **Game Version**: Enter the game's version number.
14. **Player Type**: Select one of the provided options to describe your player type (Option 1, Option 2, or Option 3).
15. **Player Experience**: Enter a brief description of your gaming experience with the game.
16. **Platform**: Select one of the provided options to describe the platform you played on (Option 1, Option 2, or Option 3).
17. **Devices**: Enter any devices you used to play the game.
18. **Frequency**: Enter how often you play the game (optional).
19. **More Comments**: Type any additional comments about your experience.
20. **Form ID**: This field is not required and can be left blank.
21. **Assigned Tool**: Enter the tool used to submit this feedback (automatically populated).
22. **Submitted By**: Enter the person submitting the feedback.
23. **Submission Date**: Enter the date this feedback was submitted (automatically populated).
24. **Game Developer**: Enter the game developer's name (optional).
25. **Game Developer Email**: Enter the game developer's email address (optional).

Note: Some fields are marked as not required, but it's still essential to fill them out for the form to be complete and submitted successfully.
