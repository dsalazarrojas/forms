# Gaming Tournament Registration Form - Help Guide
## Purpose
This form is for teams to register for a gaming tournament. It collects necessary information to verify team eligibility and settings.

## How To Complete This Form
1. Fill out the form with accurate and complete information.
2. Ensure all required fields are completed.
3. Review your answers for accuracy before submission.

## Field-by-Field Explanation
* **Player Name (<player_name>):** Enter the name of the player who is filling out the form.
* **Email (<email>):** Enter a valid email address that can be used for communication.
* **Discord ID (<discord_id>):** Enter the Discord username or ID of the team member.
* **Tournament Name (<tournament_name>):** Enter the name of the tournament you are registering for.
* **Game Name (<game_name>):** Enter the name of the game being played.
* **Game System (<game_system>):** Enter the platform or system on which the game is being played (e.g., PC, console, etc.).
* **Game Version (<game_version>):** Enter the version of the game being played (if applicable).
* **Game Server (<game_server>):** Enter the server on which the game is being played (if applicable).
* **Game Port (<game_port>):** Enter the port number or settings for the game (if applicable).
* **Game Password (<game_password>):** Enter any password required for the game (if applicable).
* **Team Size (<team_size>):** Enter the size of your team (optional but recommended).
* **Discord Role (<discord_role>):** Enter your Discord role or position within the team (optional).
* **Discord Channel (<discord_channel>):** Enter the Discord channel where you can be reached (optional).
* **Discord Message (<discord_message>):** Enter a message for the tournament organizers (optional).
* **Discord Server (<discord_server>):** Enter the name of the Discord server where the team resides (optional).
* **Discord Tag (<discord_tag>):** Enter a custom tag for your team (optional).
* **Discord Rank (<discord_rank>):** Enter your rank or position within the team (optional).
* **Discord Role ID (<discord_role_id>):** Enter your Discord role ID (optional).
* **Discord Channel ID (<discord_channel_id>):** Enter your Discord channel ID (optional).

Note: All fields with a label that contains an asterisk (\*) are optional.
