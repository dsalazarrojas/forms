# Character Search And Filter Form - Help Guide
## Purpose
The Character Search And Filter Form allows users to search and filter characters based on various criteria, including role, alignment, or level. This form is designed for quick browsing and filtering of characters.

## How To Complete This Form
To use the Character Search And Filter Form, follow these steps:

1. Click on the "Character Search and Filter" form link.
2. Fill out the form fields as desired, selecting any or all of the available filters.
3. Submit the form to view the filtered list of characters.

## Field-by-Field Explanation

* **Role (`role`, `select_one`, required: false):** Select one or more primary roles or classes from the dropdown menu.
* **Alignment (`alignment`, `select_one`, required: false):** Choose a moral or faction alignment from the options provided.
* **Level Minimum (`level_min`, `number`, required: false):** Enter a minimum character level to filter results.
* **Level Maximum (`level_max`, `number`, required: false):** Enter a maximum character level to filter results.
* **Trait Keywords (`trait_keywords`, `text`, required: false):** Enter any keywords associated with a character's traits, separated by commas.
* **Availability Status (`availability_status`, `select_one`, required: false):** Select whether the character is Active, Inactive, or Retired.
* **Sort By (`sort_by`, `select_one`, required: false):** Choose how the results should be sorted (Name, Level, Role).
* **Include NPCs (`include_npcs`, `select_one`, required: false):** Choose whether to include Non-Player Characters in the search results.
* **Results Limit (`results_limit`, `number`, required: false):** Set the maximum number of results to return.

## Tips
- You can filter by one or more criteria to narrow down your search results.
- You can leave any field blank if you don't want to apply that filter.
- Results will be displayed based on the selected filters.
