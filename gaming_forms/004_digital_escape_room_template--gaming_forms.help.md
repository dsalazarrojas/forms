# digital_escape_room_template - Help Guide
## Purpose
This form is designed to collect user input for digital escape room game settings and puzzle lists.

## How To Complete This Form
1. Select the game settings page to input your game settings.
2. Select the puzzle list page to input your puzzle lists.
3. Fill in the relevant fields with the required information for each page.
4. Review and submit your form.
