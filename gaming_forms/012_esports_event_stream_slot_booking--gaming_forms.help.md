# esports_event_stream_slot_booking - Help Guide
## Purpose
The `esports_event_stream_slot_booking` form is used to book and schedule stream slots for esports events. This form helps event organizers collect information from streamers about their availability and preferences for streaming events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required and optional fields as needed.
2. For the `Platform` field, select the platforms where the streamer is available (e.g., Twitch, YouTube, Facebook).
3. Choose the start and end times for the stream slot.
4. Select the type of game being played (Team, Solo, Mixed).
5. Choose the duration of the stream slot (1 hour, 2 hours, 3 hours).
6. Enter the event schedule date.
7. Enter the streamer's name and contact information (email, phone number).
8. Add any additional event notes.
9. Set the status of the event (Open, Closed, Pending).

## Field-by-Field Explanation
### Stream Slot Booking
* **Book Stream Slot**: This is the main field for booking a stream slot. Please fill in the details as required.

* **Team Name**: Enter the team's name as they will be participating in the stream.

* **Platform**: Select the platforms where the streamer is available to stream (e.g., Twitch, YouTube, Facebook).

* **Start Time**: Enter the start time of the stream slot.

* **End Time**: Enter the end time of the stream slot.

* **Game Type**: Choose the type of game being played (Team, Solo, Mixed).

* **Slot Duration**: Choose the duration of the stream slot (1 hour, 2 hours, 3 hours).

* **Event Schedule**: Enter the event schedule date.

* **Streamer Name**: Enter the streamer's name who will be streaming.

* **Streamer Email**: Enter the streamer's email address.

* **Streamer Phone**: Enter the streamer's phone number.

* **Event Notes**: Add any additional event notes or details.

* **Event Status**: Set the status of the event (Open, Closed, Pending).

* **Stream Status**: Set the status of the stream (Online, Offline, Pending).
