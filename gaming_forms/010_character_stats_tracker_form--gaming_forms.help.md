# Character Stats Tracker Form - Help Guide
## Purpose

This form is designed to track and update character information in a tabletop RPG or similar context. It collects details about the character's current state, such as level, stats, and other relevant data.

## How To Complete This Form

1. Fill in the required fields marked as "required" in the form. These include:
	* Player Name
	* Character Name
	* Campaign Name
	* Tracking Date
	* Current Level
	* Strength Stat
	* Dexterity Stat
	* Constitution Stat
	* Intelligence Stat
	* Wisdom Stat
	* Charisma Stat
	* Current Hit Points
	* Maximum Hit Points
	* Armor Class
	* Speed
	* Proficiency Bonus
2. If applicable, fill in the optional fields:
	* Saving Throw Proficiencies
	* Skill Proficiencies
	* Current Gold
	* Inventory Changes
	* Progress to Next Level
	* Any Stat Changes This Session

## Field-by-Field Explanation

* **Player Name** (`player_name`, `text`, `required`):
	+ Enter your name as the player.
* **Character Name** (`character_name`, `text`, `required`):
	+ Enter the name of the character being tracked.
* **Campaign Name** (`campaign_name`, `text`, `required`):
	+ Enter the name of the current campaign or adventure.
* **Tracking Date** (`tracking_date`, `date`, `required`):
	+ Enter the date of the update or tracking.
* **Current Level** (`current_level`, `number`, `required`):
	+ Enter the character's current level.
* **Strength** (`strength_stat`, `number`, `required`):
	+ Enter the character's Strength stat value.
* **Dexterity** (`dexterity_stat`, `number`, `required`):
	+ Enter the character's Dexterity stat value.
* **Constitution** (`constitution_stat`, `number`, `required`):
	+ Enter the character's Constitution stat value.
* **Intelligence** (`intelligence_stat`, `number`, `required`):
	+ Enter the character's Intelligence stat value.
* **Wisdom** (`wisdom_stat`, `number`, `required`):
	+ Enter the character's Wisdom stat value.
* **Charisma** (`charisma_stat`, `number`, `required`):
	+ Enter the character's Charisma stat value.
* **Current Hit Points** (`current_hp`, `number`, `required`):
	+ Enter the character's current hit points.
* **Maximum Hit Points** (`max_hp`, `number`, `required`):
	+ Enter the character's maximum hit points.
* **Armor Class** (`armor_class`, `number`, `required`):
	+ Enter the character's Armor Class value.
* **Speed** (`speed`, `number`, `required`):
	+ Enter the character's movement speed.
* **Proficiency Bonus** (`proficiency_bonus`, `number`, `required`):
	+ Enter the character's proficiency bonus value.
* **Saving Throw Proficiencies** (`saving_throws`, `text`, `optional`):
	+ List any saving throw proficiencies the character has.
* **Skill Proficiencies** (`skill_proficiencies`, `text`, `optional`):
	+ List any skill proficiencies the character has.
* **Current Gold** (`current_gold`, `number`, `optional`):
	+ Enter the character's current gold amount.
* **Inventory Changes** (`inventory_changes`, `text`, `optional`):
	+ Describe any changes to the character's inventory.
* **Progress to Next Level** (`level_progress`, `text`, `optional`):
	+ Enter the progress towards the next level, such as a percentage or amount.
* **Any Stat Changes This Session** (`stat_changes`, `text`, `optional`):
	+ Describe any stat changes the character has had this session.
