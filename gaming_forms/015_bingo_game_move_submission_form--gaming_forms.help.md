# Bingo Game Move Submission Form - Help Guide

## Purpose

This form is used to submit details of a bingo game move, including player information, game details, and verification status. The form ensures that all required fields are completed accurately to facilitate efficient and transparent win verification and prize distribution processes.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your player details, including first name, last name, and player ID (required fields).
2. Enter your email address and phone number (optional fields).
3. Specify the game session details, including date and time of the game (required fields).
4. Select the game type and number (required fields).
5. Provide details about your winning move, including the last number called and the winning pattern (required fields).
6. Enter the ID number of your winning card (required field).
7. Describe the pattern achieved for this win (optional field).
8. Enter the number of numbers called when bingo was achieved (required field).
9. Indicate the verification status of this move (required field).
10. If verified, enter the name of the person who verified this move (optional field).
11. Enter any prize information, including dollar amount and prize type (optional fields).
12. Specify if this was a progressive jackpot win (required field).
13. Indicate if there were any witnesses to this win (optional field).
14. Enter the number of witnesses (optional field).
15. Enter the names of witnesses (optional field).
16. Add any special comments about this move (optional field).
17. Flag any dispute about this move (required field).
18. Finally, indicate when this move was submitted (required field).

## Field-by-Field Explanation

* **First Name** (`player_first_name`): Enter your first name.
* **Last Name** (`player_last_name`): Enter your last name.
* **Player ID** (`player_id`): Enter your player card or membership number.
* **Email Address** (`player_email`): Enter your contact email (optional).
* **Phone Number** (`player_phone`): Enter your contact number (optional).
* **Game Session** (`game_session`): Enter game session details.
* **Game Date** (`game_date`): Enter the date of the bingo game.
* **Game Time** (`game_time`): Enter the time of the game session.
* **Game Number** (`game_number`): Select the game number in the session.
* **Game Type** (`game_type`): Select the type of bingo game being played.
* **Caller Name** (`caller_name`): Enter the name of the bingo caller.
* **Move Details** (`move_details`): Report your bingo move.
* **Move Type** (`move_type`): Select the type of winning move.
* **Last Number Called** (`winning_number`): Enter the number that completed your win.
* **Bingo Card Number** (`card_number`): Enter the ID number on your winning card.
* **Winning Pattern** (`winning_pattern`): Describe the pattern achieved for this win.
* **Numbers Called** (`numbers_called_count`): Enter the total numbers called when bingo was achieved.
* **Verification Status** (`verification_status`): Indicate the verification status of this move.
* **Verifier Name** (`verifier_name`): Enter the name of the person who verified this move (if applicable).
* **Prize Information** (`prize_information`): Enter any prize details for this win (optional).
* **Prize Amount** (`prize_amount`): Enter the dollar amount of the prize (optional).
* **Prize Type** (`prize_type`): Select the type of prize awarded (optional).
* **Progressive Jackpot** (`progressive_jackpot`): Specify if this was a progressive jackpot win.
* **Witness Information** (`witness_information`): Report any witness information about this win (optional).
* **Witnesses Present** (`witnesses_present`): Enter the number of witnesses (optional).
* **Witness Names** (`witness_names`): Enter the names of witnesses (if applicable).
* **Special Notes** (`special_notes`): Add any additional comments about this move (optional).
* **Dispute Flag** (`dispute_flag`): Indicate if there is any dispute about this move.
* **Submission Time** (`submission_timestamp`): Enter when this move was submitted.
