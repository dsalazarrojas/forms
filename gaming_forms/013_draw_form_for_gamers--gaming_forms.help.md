# Draw Form For Gamers - Help Guide
## Purpose
This form is designed to collect information from gamers about their experiences and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title and description fields with the relevant information.
2. Choose whether or not to output a file for the form data.
3. Select the category and category 2 relevant to your gaming experience.
4. Answer whether or not you have been assigned a tool for the gaming session.
5. Answer whether or not the category and category 2 you selected is correct.
6. Provide a brief description of your gaming session in the description field.
7. Enter a title for your gaming session.
8. Enter a detailed description of your gaming session in the description long field.
9. If necessary, select an output file 2 for your gaming session.

## Field-by-Field Explanation

* **Draw Form For Gamers (1)** (`text`, required/optional): Enter a brief title for your gaming session.
* **Output File (2)** (`select_one`, required/optional): Choose whether or not to output a file for your form data. If yes, a file will be generated and available for download.
* **Form IDs (3)** (`number`, required/optional): Enter a unique number related to the form, usually an ID provided by a supervisor.
* **Assigned Tool (4)** (`select_one`, required/optional): Answer whether or not you have been assigned a tool for the gaming session.
* **Category (5)** (`select_one`, required/optional): Select the category that best describes your gaming experience.
* **Description (6)** (`text`, required/optional): Provide a brief description of your gaming session.
* **Title (7)** (`text`, required/optional): Enter a title for your gaming session.
* **Description Long (8)** (`text`, required/optional): Enter a detailed description of your gaming session.
* **Output File 2 (9)** (`text`, required/optional): Enter a file name for your gaming session, if needed.
* **Category 2 (10)** (`select_one`, required/optional): Select the category 2 that best describes your gaming experience.

## Tips
* Please ensure that you complete the form accurately and honestly.
* If you have any issues or concerns, contact your supervisor for assistance.
* The form data will be used to improve gaming-related services and features.
