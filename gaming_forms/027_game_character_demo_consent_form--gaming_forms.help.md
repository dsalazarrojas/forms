# Game Character Demo Consent Form - Help Guide
## Purpose
The Game Character Demo Consent Form is used to obtain consent from game character creators or organizations to display or distribute their game characters for demo or showcase purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you are the game character's creator or organization.
2. Read the form carefully and ensure you understand the purpose and requirements of the form.
3. Fill out the form completely and accurately with the required information.
4. Review your answers for accuracy before submitting.

## Field-by-Field Explanation

* **Creator Details** (id: 1): This field is for the game character's creator or organization to provide their name and contact information.
* **Name** (id: 2): Enter the name of the game character.
* **Email** (id: 3): Enter the email address of the game character's creator or organization.
* **Phone** (id: 4): Enter the phone number of the game character's creator or organization.
* **Game Character** (id: 5): Enter a brief description of the game character.
* **Demo Use** (id: 6): Describe how you would like to use the game character in the demo or showcase event.
* **Demo Display** (id: 7): Select how you would like the game character to be displayed in the demo or showcase event:
	+ demo display event
	+ demo display showcase
	+ demo display development
* **Demo Distribute** (id: 8): Select how you would like the game character to be distributed in the demo or showcase event:
	+ demo distribute event
	+ demo distribute showcase
	+ demo distribute development
* **Permission** (id: 9): Provide any additional comments or permissions related to the use of the game character.
* **Notes** (id: 10): Add any additional notes or comments related to the use of the game character.

## Tips

* Ensure you are the game character's creator or organization before filling out this form.
* Double-check your answers for accuracy before submitting.
* If you have any questions or concerns, contact the event organizer directly.
