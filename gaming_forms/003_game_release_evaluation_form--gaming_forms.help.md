# Game Release Evaluation Form - Help Guide
## Purpose
The Game Release Evaluation Form is used to collect feedback and information about a game's release.

## How To Complete This Form

1. Please answer the questions honestly and to the best of your ability.
2. Select one of the options for each field, or enter your answer in the text fields.
3. Be as detailed as possible when providing feedback in the text fields.

## Field-by-Field Explanation

* **Game Version** (`1`, `select_one`, required: false): Choose the game's version status.
* **Game Name** (`2`, `text`, required: false): Enter the name of the game.
* **Platform** (`3`, `select_one`, required: false): Choose the platform(s) the game is released on.
* **Overall Rating** (`4`, `number`, required: false): Rate the game from 1 to 10.
* **Feedback** (`5`, `text`, required: false): Provide any feedback or comments about the game.
* **Game Type** (`6`, `select_one`, required: false): Indicate if the game is for a specific type (e.g., adventure, sports, etc.).
* **System Requirements** (`7`, `text`, required: false): List the system requirements for the game.
* **Release Date** (`8`, `date`, required: false): Enter the release date of the game.
* **Player Level** (`9`, `number`, required: false): Indicate the recommended player level (e.g., beginner, intermediate, advanced).
* **Playtime** (`10`, `time`, required: false): Enter the estimated playtime for the game.
* **Game Servers** (`11`, `text`, required: false): List the game's server status.
* **Player Experience** (`12`, `text`, required: false): Describe your experience playing the game.
* **Developer Comment** (`13`, `text`, required: false): Enter any comments from the developer about the game.
* **Player Comment** (`14`, `text`, required: false): Enter any comments from players about the game.
* **Game Servers 2** (`15`, `text`, required: false): List any additional game servers or services.
* **Operating System** (`16`, `select_one`, required: false): Rate the game's compatibility with different operating systems.
* **Game Version Comment** (`17`, `text`, required: false): Provide any comments about the game's version.
* **Game Language** (`18`, `select_one`, required: false): Indicate if the game's language is in the default language or not.
* **Player Language** (`19`, `select_one`, required: false): Indicate if the player's language is in the default language or not.
* **Platform Language** (`20`, `select_one`, required: false): Indicate if the game's platform language is in the default language or not.
* **Game Type Comment** (`21`, `text`, required: false): Provide any comments about the game type.
* **Player Level Comment** (`22`, `text`, required: false): Provide any comments about the player level.
* **Game Release Version** (`23`, `select_one`, required: false): Indicate if the game's release version is up-to-date or not.
* **Release Date 2** (`24`, `date`, required: false): Enter the release date of the game, if different from the original release date.
* **Player Level 2** (`25`, `number`, required: false): Indicate the player level 2 (e.g., beginner, intermediate, advanced).
