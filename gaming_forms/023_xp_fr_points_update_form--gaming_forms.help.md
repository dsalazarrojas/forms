# XP/FR Points Update Form - Help Guide
## Purpose
This form is used to update user balances of XP (Experience Points) and FR (Friendship Points) within a gaming context. It allows game administrators or moderators to track changes to user balances, including reasons for the change, dates, and additional details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter any relevant information in the "User Input" field, which can be used to identify the user and provide context for the balance update.
2. Provide a brief description of the reason for the balance update in the "Reason" field.
3. Enter the date of the update in the "Reason Date" field.
4. Enter any additional details about the reason for the balance update in the "Reason Details" field.
5. If applicable, provide any supporting information or details in the "Support Details" field.
6. Confirm who requested the balance update in the "Requested By" field.
7. Enter any relevant contact information in the "Contact Info" field.
8. Click the "Submit" button to complete the form and submit the request for processing.

## Field-by-Field Explanation

* **User Input** (`user_input`, text, optional): Enter any relevant information to identify the user and provide context for the balance update.
* **Reason** (`reason`, text, optional): Provide a brief description of the reason for the balance update.
* **Reason Date** (`reason_date`, date, optional): Enter the date of the update.
* **Reason Details** (`reason_details`, text, optional): Enter any additional details about the reason for the balance update.
* **Support Details** (`support_details`, text, optional): If applicable, provide any supporting information or details.
* **Requested By** (`request_by`, text, optional): Confirm who requested the balance update.
* **Contact Info** (`contact_info`, text, optional): Enter any relevant contact information.
* **Submit** (`submit_button`, text, optional): Click to complete and submit the form.

## Tips
* Ensure the information provided is accurate and clear, as it will be used to track changes to user balances.
* If you're unsure about any field, please ask a game administrator or moderator for guidance.
* Double-check that this form is not a duplicate before creating a new instance.
