# Gaming Streaming Platform Referral Form - Help Guide
## Purpose
The form is used to collect information about a gaming streaming platform referral. This includes details such as the creator's information, referral type, streaming platform, follow-up frequency, and notes. The form is likely used for internal or external use cases.

## How To Complete This Form
- Start by filling out the "Creator Information" page, which includes the creator's name.
- Then, choose the "Referral Type" option by selecting one or more of the provided options (Yes/No).
- Next, select the "Streaming Platform" option from the available choices (Yes/No).
- If the platform is a referral, enter the platform's "Referral Link".
- In the "Description" field, you can add any additional information about the referral.
- Choose the follow-up frequency for the referral from the options provided (Yes/No).
- Finally, enter any relevant "Notes" in the "Notes" field.

## Field-by-Field Explanation
* **Creator Information (Creator Name)**: Enter the name of the creator in full.
* **Referral Type**: Choose one or more options if this is a referral. Otherwise select "No".
* **Streaming Platform**: Select the type of streaming platform, or "No" if this platform is not a referral.
* **Referral Link**: If this platform is a referral, enter the platform link.
* **Description**: Add any additional information about the referral.
* **Follow Up Frequency**: Choose when to follow up with the creator, or "No" if no follow-up is needed.
* **Notes**: Enter any relevant notes or comments for the referral.
* **Referral Status**: Select the status of the referral, which can be either Active or Inactive.
