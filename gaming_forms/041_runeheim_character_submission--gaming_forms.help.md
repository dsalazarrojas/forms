# Runeheim Character Submission - Help Guide

## Purpose

The Runeheim Character Submission form is designed to collect information about characters from the Runeheim universe. This form is used to create new characters and add them to our database.

## How To Complete This Form

1. Fill out each page of the form, making sure to provide accurate information for each field.
2. For character name, please use the character's real name.
3. Select the character's race and class from the provided options.
4. Provide a brief character description and image URL (if applicable).
5. Choose the character's background and proficiency from the provided options.
6. Enter the character's equipment, language, note (if applicable), and location information.
7. Add any additional notes or comments for the character.
8. Finally, provide the character's image, author, and contact information (if applicable).

## Field-by-Field Explanation

* **Character Name** (`character_name`, **required**): Enter the character's real name.
* **Character Race** (`character_race`, **required**): Select the character's race from the provided options.
* **Character Class** (`character_class`, **required**): Select the character's class from the provided options.
* **Character Description** (`character_description`, **required**): Provide a brief description of the character.
* **Character Image URL** (`character_image_url`, **required**): Enter the URL of the character's image (if applicable).
* **Character Background** (`character_background`, **required**): Select the character's background from the provided options.
* **Character Alignment** (`character_alignment`, **required**): Enter the character's alignment.
* **Character Race Type** (`character_race_type`, **required**, **select_one**): Select the character's race type from the provided options.
* **Character Class Type** (`character_class_type`, **required**, **select_one**): Select the character's class type from the provided options.
* **Character Background Type** (`character_background_type`, **required**, **select_one**): Select the character's background type from the provided options.
* **Character Proficiency** (`character_proficiency`, **required**, **select_multiple**): Choose the character's proficiency from the provided options.
* **Character Equipment** (`character_equipment`, **required**, **text**): Enter the character's equipment information.
* **Character Language** (`character_language`, **required**, **text**): Enter the character's language information.
* **Character Note** (`character_note`, **required**, **note**): Enter any additional notes or comments for the character.
* **Character Image** (`character_image`, **optional**, **text**): Enter the URL of the character's image (if applicable).
* **Character Author** (`character_author`, **required**, **text**): Enter your name or the name of the character's author.
* **Character Email** (`character_email`, **optional**, **email**): Enter the character's email (if applicable).
* **Character Phone** (`character_phone`, **optional**, **text**): Enter the character's phone number (if applicable).
* **Character Location** (`character_location`, **required**, **select_multiple**): Select the character's location from the provided options.
* **Character Time** (`character_time`, **required**, **time**): Enter the character's time of creation.
* **Character Date** (`character_date`, **required**, **date**): Enter the character's date of creation.
* **Character Gender** (`character_gender`, **optional**, **text**): Enter the character's gender.
* **Character Race Gender** (`character_race_gender`, **optional**, **text**): Enter the character's race's gender.
* **Character Note 2** (`character_note2`, **optional**, **note**): Enter any additional notes or comments for the character.
* **Character Image 2** (`character_image`, **optional**, **text**): Enter any additional image information (if applicable).
