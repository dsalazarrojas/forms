# Gaming Server Rule Voting Form - Help Guide
## Purpose
The Gaming Server Rule Voting Form is a tool for the community to provide feedback on proposed rule changes to the server. It helps moderators understand the community's opinion on the changes, ensuring that the server rules are fair and acceptable to the players.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the proposed rule change and understand the change itself.
2.  Select the "Yes" or "No" option for the rule change. If you have an opinion, select "Yes" to agree with the change or "No" to disagree.
3.  Provide a brief reason for your vote if you choose "No" to help the moderators understand your concern.
4.  Fill in any other fields as requested, such as server IP and region, if required for the specific rule change.

## Field-by-Field Explanation

*   **server_rule_id**: This field is to identify the specific rule being changed. Please leave it as it is, as it is not editable.
*   **moderator**: If you are a server moderator, please indicate yourself. You can fill this field with your moderator nickname or ID.
*   **rule_change**: Describe the proposed change in detail. This field is optional, but it helps us understand the proposed rule change.
*   **rule_type**: Please choose one of the options to select the type of rule change (e.g., "Ban," "Allow", etc.).
*   **votes**: Leave this field as is. It shows the total number of votes.
*   **vote_type**: Select "Yes" or "No" to cast your vote. If you choose "No", you can optionally provide a reason below.
*   **vote_date**: This field shows the date you voted. Please leave it as is.
*   **vote_time**: This field shows the time you voted. Please leave it as is.
*   **rule_change_description**: Describe the change if you choose "No" and want to provide a reason.
*   **rule_change_date**: This field shows the date the rule change was proposed. Please leave it as is.
*   **rule_change_time**: This field shows the time the rule change was proposed. Please leave it as is.
*   **rule_change_type**: Please select one of the options to select the type of rule change.
*   **reason**: If you choose "No", you can provide a brief reason for your vote here.
*   **server_ip**: If required, please enter the IP address of your server.
*   **server_port**: If required, please enter the port number of your server.
*   **server_region**: If required, please enter your server region.
*   **server_name**: If required, please enter your server name.
*   **rule_voting_form_submitters**: This field shows the number of users who submitted this form. Please leave it as is.
*   **rule_voting_form_comments**: This field is for any comments about the rule change. If you have any additional thoughts or comments, you can fill this in.
*   **rule_voting_form_votes**: This field is not editable and shows the total number of votes for the rule change.
*   **rule_voting_form_votes_count**: This field shows the number of votes. Please leave it as is.
*   **rule_voting_form_submitted_at**: This field shows the date and time when the form was submitted. Please leave it as is.
*   **rule_voting_form_submit_time**: This field shows the time when the form was submitted. Please leave it as is.
*   **rule_voting_form_ip_address**: This field is not editable and shows the IP address of the submitter. Please leave it as is.
*   **form_submitter**: If you are the form submitter, please fill in your name or ID. It is optional and only for internal use.
