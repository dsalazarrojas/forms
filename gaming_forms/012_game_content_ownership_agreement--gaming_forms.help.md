# Game Content Ownership Agreement - Help Guide
## Purpose
This form is used to establish the ownership and creation details of a game, including the creator's and studio's names, emails, content type, and content description.

## How To Complete This Form

To complete this form, please follow these steps:

1. **Fill out each field as instructed**:
	* Enter the game creator's name in the "Creator Name" field.
	* Provide the game creator's email in the "Creator Email" field.
	* Enter the studio's name in the "Studio Name" field (if applicable).
	* Enter the studio's email in the "Studio Email" field (if applicable).
	* Select the type of game content in the "Content Type" field.
	* Briefly describe the game content in the "Content Description" field.
	* If applicable, select the date the agreement was made in the "Agreement Date" field.
2. **Sign the form**:
	* The game creator should sign their name in the "Creator Signature" field.
	* The studio should sign their name in the "Studio Signature" field (if applicable).

## Field-by-Field Explanation

* **Creator Name**: Enter the name of the person or entity creating the game content.
* **Creator Email**: Enter the email address associated with the game content creator.
* **Studio Name**: Enter the name of the studio or entity responsible for producing the game (if applicable).
* **Studio Email**: Enter the email address associated with the studio or entity (if applicable).
* **Content Type**: Select the type of game content being created (e.g., game, asset, etc.).
* **Content Description**: Briefly describe the game content being created.
* **Agreement Date**: Select the date the agreement was made (if applicable).
* **Creator Signature**: Sign your name as the game content creator.
* **Studio Signature**: Sign your name as the studio or entity responsible for producing the game (if applicable).

## Tips

* Please ensure you enter accurate information in each field to avoid any confusion or discrepancies.
* If you have any questions or need further clarification, please contact [form@gic.mx](mailto:form@gic.mx).
