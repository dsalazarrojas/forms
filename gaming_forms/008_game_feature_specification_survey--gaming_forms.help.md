# Game Feature Specification Survey - Help Guide

## Purpose
This form is designed to gather information from users about the features they would like to see in a game. It helps us understand what users value and prioritize when it comes to game development.

## How To Complete This Form
To complete this form, follow the instructions below:

* Start by selecting one of the options on each page, or if no options are available, provide a text response.
* Make sure to fill out all required fields. Fields with an asterisk (\*) are required.
* Use the select multiple field to choose multiple options for a single question.
* Use the select one field to choose only one option for a question.
* Answer each question as accurately and honestly as possible to ensure we get valuable feedback.
