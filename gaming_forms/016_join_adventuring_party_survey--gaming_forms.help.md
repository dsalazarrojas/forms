# join_adventuring_party_survey - Help Guide
## Purpose

This form is designed to help you register for or sign up with an adventuring party. Please fill out the form to provide necessary information for the party leader and other participants.

## How To Complete This Form

1. Read through each section carefully to ensure you've answered all required fields.
2. Enter your party name and select the correct party leader.
3. Indicate your adventure preferences (e.g., Yes or No).
4. Choose the type of party you're joining (e.g., Adventurer, Party, Guild, Alliance, or Company).
5. Select how frequently you'll be adventuring (e.g., 1, 2, 3, 4, or 5).
6. Enter the start and end dates (if applicable) and start and end times (if applicable) for the adventure.
7. Add any player notes (if applicable).
8. Enter your email address and phone number (if applicable).
9. Provide the contact person and contact information (if applicable).
10. Click "Submit" to finalize your registration.

## Field-by-Field Explanation

* **Party Name**: Enter the name of the party you're joining or registering with.
	+ Type: text
	+ Required: true
* **Party Leader**: Select the leader of the party.
	+ Type: text
	+ Required: true
* **Adventure Preferences**: Indicate your preferences for the adventure (Yes or No).
	+ Type: select_multiple
	+ Required: false
* **Party Type**: Choose the type of party you're joining (e.g., Adventurer, Party, Guild, Alliance, or Company).
	+ Type: select_one
	+ Required: true
* **Adventure Frequency**: Select how frequently you'll be adventuring (e.g., 1, 2, 3, 4, or 5).
	+ Type: select_one
	+ Required: true
* **Adventure Length**: Enter the length of the adventure (optional).
	+ Type: number
	+ Required: false
* **Start Date**: Enter the start date of the adventure (if applicable).
	+ Type: date
	+ Required: false
* **End Date**: Enter the end date of the adventure (if applicable).
	+ Type: date
	+ Required: false
* **Start Time**: Enter the start time of the adventure (if applicable).
	+ Type: time
	+ Required: false
* **End Time**: Enter the end time of the adventure (if applicable).
	+ Type: time
	+ Required: false
* **Player Notes**: Add any additional notes about yourself as a player (if applicable).
	+ Type: note
	+ Required: false
* **Email**: Enter your email address (if applicable).
	+ Type: email
	+ Required: false
* **Phone**: Enter your phone number (if applicable).
	+ Type: text
	+ Required: false
* **Contact Person**: Provide the contact person for the party (if applicable).
	+ Type: text
	+ Required: false

	+ Type: text
	+ Required: false
