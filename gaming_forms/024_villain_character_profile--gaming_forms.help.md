# Villain Character Profile - Help Guide

## Purpose
This form is designed to help you create a detailed profile for a villain character in a role-playing or game development context. It gathers information about the character's details, motivation, goals, method of operation, and powers/weaknesses.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the character's name in the "villain_character" field.
2. Provide a brief description of the character in the "villain_description" field.
3. Choose one or more goals for the character from the "villain_goals" field.
4. Select the motivation behind the character's actions from the "villain_motivation" field.
5. Choose the character's method of operation from the "villain_method" field.
6. Provide a brief backstory for the character in the "villain_backstory" field.
7. Select any powers the character possesses from the "villain_powers" field.
8. Select any weaknesses the character has from the "villain_weaknesses" field.

## Field-by-Field Explanation

* **Villain Character** (`villain_character`, text, required): Enter the character's name.
* **Villain Description** (`villain_description`, text, required): Provide a brief description of the character.
* **Villain Goals** (`villain_goals`, select multiple, required): Choose one or more goals for the character. Options: `Yes` and `No`.
* **Villain Motivation** (`villain_motivation`, select one, required): Select the motivation behind the character's actions. Options: `Financial Gain`, `Power`, `Revenge`, `Control`, `Mutilation`.
* **Villain Method** (`villain_method`, select one, required): Choose the character's method of operation. Options: `Physical`, `Psychological`, `Magical`, `Social`, `Cyber`.
* **Villain Backstory** (`villain_backstory`, text, required): Provide a brief backstory for the character.
* **Villain Powers** (`villain_powers`, select multiple, required): Select any powers the character possesses. Options: `Yes` and `No`.
* **Villain Weaknesses** (`villain_weaknesses`, select multiple, required): Select any weaknesses the character has. Options: `Yes` and `No`.
