# Virtual Game Night Registration Form - Help Guide
## Purpose
The Virtual Game Night Registration Form is designed to collect relevant details from participants to organize and execute the virtual game night event successfully.

## How To Complete This Form
To complete this form, follow the steps below:
1. Fill in the required information accurately.
2. Review the form for any errors or incomplete fields before submission.

## Field-by-Field Explanation

### Participant Name
*   **Participant Name** (`participant_name`, Text, Required: false):
    *   Enter the name of the participant in the text field. This field is not mandatory.

### Participant Email
*   **Participant Email** (`participant_email`, Email, Required: false):
    *   Enter a valid email address for the participant. This field is not mandatory.

### Participant Phone
*   **Participant Phone** (`participant_phone`, Text, Required: false):
    *   Enter the participant's phone number in the text field. This is not a required field.

### Game Title
*   **Game Title** (`game_title`, Text, Required: false):
    *   Enter the title of the game being played on that night. This field is not required.

### Game Start Time
*   **Game Start Time** (`game_start_time`, Date, Required: false):
    *   Select the start time of the game in date format. This field is not necessary.

### Game Duration
*   **Game Duration** (`game_duration`, Text, Required: false):
    *   Enter the duration of the game. This field is not required.

### Game Description
*   **Game Description** (`game_description`, Text, Required: false):
    *   Provide a brief description of the game being played. This field is not required.

### Game Tags
*   **Game Tags** (`game_tags`, Select Multiple, Required: false):
    *   Choose the game tags as 'Yes' or 'No'. This field is not mandatory.

### Event Date
*   **Event Date** (`event_date`, Date, Required: false):
    *   Select the date of the event. This field is not required.

### Event Start Time
*   **Event Start Time** (`event_start_time`, Time, Required: false):
    *   Choose the start time of the event in 24-hour format. This field is not necessary.

## Tips
*   Ensure all required fields are filled accurately to avoid any issues with the submission.
*   Review the form for any errors or missing fields before submitting.
*   Double-check the game tags as 'Yes' or 'No' for accurate representation.
