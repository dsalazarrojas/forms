# Game Concept Upload Form - Help Guide

## Purpose
This form is used to collect game concept information for review and feedback purposes.

## How To Complete This Form
1. Fill in all required fields with accurate and relevant information.
2. Use the "Game Type" field to select the type of game (2D or 3D).
3. Select the tags that best describe the game concept.
4. Provide the game developer's and publisher's details.
5. Choose the development status (e.g., In Development, In Review, etc.).
6. Optionally, provide a reviewer rating and notes.
7. Fill in the reviewer's details (name, email, and phone).
8. Choose the submit date and time.
9. Repeat the process for the second game concept section.

## Field-by-Field Explanation

* **Game Title**: Enter the title of the game being uploaded. 
* **Game Description**: Enter a brief description of the game concept.
* **Game Type**: Select the type of game (2D or 3D).
* **Game Tags**: Choose the tags that best describe the game concept.
* **Game Developer**: Enter the game developer's name.
* **Game Publisher**: Enter the game publisher's name.
* **Game Development Status**: Choose the current development status (e.g., In Development, In Review, etc.).
* **Reviewer Rating**: Optionally, provide a rating on a scale of 1-10.
* **Reviewer Notes**: Optionally, provide notes for the reviewer.
* **Reviewer Name**: Enter the reviewer's name.
* **Reviewer Email**: Enter the reviewer's email.
* **Reviewer Phone**: Enter the reviewer's phone number.
* **Game Developer Notes**: Optionally, provide additional notes for the game developer.
* **Game Developer Comment**: Optionally, provide comments for the game developer.
* **Submit Date**: Choose the date the form is submitted.
* **Submit Time**: Choose the time the form is submitted.
* **Game Developer 2**: Select the type of game for the second game concept (2D or 3D).
* **Game Concept Upload Form Upload File 2**: Upload a file for the second game concept.
* **Game Concept Upload Form Upload File 3**: Upload an additional file for the second game concept.
* **Reviewer Name 2**: Enter the name of the reviewer for the second game concept.
* **Reviewer Email 2**: Enter the email of the reviewer for the second game concept.
* **Reviewer Phone 2**: Enter the phone number of the reviewer for the second game concept.
* **Game Development Status 2**: Choose the development status for the second game concept (e.g., In Development, In Review, etc.).
