# one_shot_game_application - Help Guide
## Purpose

This form is used to collect information about one-shot games, including player details, game metadata, and submission status.

## How To Complete This Form

1. Fill in the required fields (if any) and provide accurate information where applicable.
2. Ensure you have the necessary permissions or approvals to access and submit this form.
3. Review and verify the entered data before submitting.

## Field-by-Field Explanation

* **player_name** (`player_name`, text, optional): Enter the name of the player involved in the one-shot game.
* **Email** (`Email`, email, optional): Input the player's email address for contact or communication purposes.
* **Game Name** (`Game Name`, text, optional): Enter the name of the one-shot game being applied for.
* **Game System** (`Game System`, text, optional): Provide the system or platform associated with the game (e.g., console, OS, etc.).
* **Game Version** (`Game Version`, number, optional): Enter the version number of the game being played.
* **Players** (`Players`, select multiple, optional): Confirm if the game involves multiple players. Select 'Yes' if it does, and 'No' otherwise.
* **Start Date** (`Start Date`, date, optional): Record the date when the one-shot game started.
* **End Date** (`End Date`, date, optional): Enter the date when the one-shot game ended.
* **Submission Time** (`Submission Time`, time, optional): Note the time of day when you submitted this form.
* **Submission Date** (`Submission Date`, date, optional): Record the date you submitted this form.
* **Submission Status** (`Submission Status`, select one, optional): Choose the status of your submission: Active or Inactive.
