# pc_game_library_checklist - Help Guide
## Purpose
The pc_game_library_checklist form is a tool for tracking and documenting PC games within a library. This form allows you to gather information about each game, including its platform, title, developer, release date, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the platform on which the game is played (Steam, GOG, or Origin).
2. Enter the title of the game.
3. (Optional) Enter the developer of the game.
4. (Optional) Enter the publisher of the game.
5. Enter the release date of the game.
6. (Optional) Enter the number of hours played.
7. Check if you own the game, with options to select "True", "False", or "Partial".
8. Check the progress of the game, with options to select "Not Started", "In Progress", or "Completed".
9. (Optional) Enter any additional notes about the game.

## Field-by-Field Explanation
* **Platform** (Select One): Choose the platform on which the game is played (Steam, GOG, or Origin).
* **Game Title** (Text): Enter the title of the game.
* **Developer** (Text, Optional): Enter the name of the game's developer.
* **Publisher** (Text, Optional): Enter the name of the game's publisher.
* **Release Date** (Date): Enter the release date of the game.
* **Playtime** (Number, Optional): Enter the number of hours played, if applicable.
* **Hours Played** (Number, Optional): Enter the estimated hours played, if applicable.
* **Owned** (Select Multiple): Check if you own the game, with options to select "True", "False", or "Partial".
* **Progress** (Select Multiple): Check the progress of the game, with options to select "Not Started", "In Progress", or "Completed".
* **Notes** (Text, Optional): Enter any additional notes or comments about the game.
