# Game Character Design Upload Form - Help Guide
## Purpose
The Game Character Design Upload Form is used to upload character designs for a game. It is a critical component of the game development process, allowing designers to provide essential information about each character in a structured and organized manner.

## How To Complete This Form
To complete this form successfully, follow these steps:

1.  Provide details about the character, including its name and any other relevant information.
2.  Enter a brief description of the character, highlighting its key features and roles in the game.
3.  Upload or provide the URL of the character's image, so it can be referenced later.
4.  Specify the name of the game the character belongs to.
5.  Enter the name of the character designer.
6.  Identify the type of game this character belongs to.
7.  Indicate the type of character, such as protagonist or antagonist.
8.  Specify the genre of the game the character belongs to.
9.  Upload the character design file or provide its URL.

## Field-by-Field Explanation

* **Character Details** (`character_details`):
	+ This field is for providing the details about the character, including its name and other attributes.
	+ Enter relevant information about the character that is not covered in the description field.
* **Description** (`character_description`):
	+ A brief text that describes the character, including its role and any notable features.
* **Character Image URL** (`character_image_url`):
	+ Enter the URL of the character's image, if available.
* **Game Name** (`game_name`):
	+ Enter the name of the game that the character belongs to.
* **Designer Name** (`designer_name`):
	+ Enter the name of the character's designer.
* **Game Type** (`game_type`):
	+ Select the type of game this character belongs to, such as adventure or puzzle.
* **Character Type** (`character_type`):
	+ Indicate the character's role in the game, such as protagonist or antagonist.
* **Game Genre** (`game_genre`):
	+ Identify the genre of the game that this character belongs to.
* **Character Design File** (`character_design_file`):
	+ Upload the character's design file or provide its URL.

## Tips
- Be as detailed as possible when providing character information.
- Ensure that the character's image URL is accurate and up-to-date.
- Verify that the game and character details are correct to avoid errors in the database.
- Use the select options for game and character types to help with data organization and filtering.
