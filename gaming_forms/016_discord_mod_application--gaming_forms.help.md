# Discord Mod Application - Help Guide
## Purpose
The purpose of this form is to submit an application to become a moderator on our server. Please make sure you are genuinely interested in this role before proceeding.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the form and ensure you understand the questions before answering.
2. Select "Yes" or "No" for "I'm applying for mod" if you wish to apply for moderator position.
3. Enter your valid Discord username in the "username" field.
4. Enter a valid email address in the "email" field.
5. Provide a clear explanation for why you're applying to be a moderator in the "Reason for applying" field.
6. Enter the ID of the server you're applying for in the "Server ID" field.

## Field-by-Field Explanation

* **I'm applying for mod** (`discord_mod_application`, select_multiple, required): Please select "Yes" if you wish to apply for moderator position, and "No" if you are not.
* **username** (`username`, text, required): Enter your valid Discord username.
* **email** (`email`, email, required): Enter a valid email address.
* **Reason for applying** (`reason_for_applying`, text, required): Provide a clear explanation for why you're applying to be a moderator. This will help us understand your motivations and ensure you're a good fit for the role.
* **Server ID** (`server_id`, text, required): Enter the ID of the server you're applying for.
