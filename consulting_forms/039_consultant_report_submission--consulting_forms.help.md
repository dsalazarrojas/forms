# Consultant Report Submission - Help Guide

## Purpose
This form is used to submit reports from consultants to clients. It is essential to complete this form accurately and thoroughly to ensure that the report is properly recorded and reviewed.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your consultant name in the "Consultant name" field. This is the person submitting the report.
2. Enter the client's name in the "Client name" field. This is the organization receiving the report.
3. Provide a short descriptive title for the report in the "Report title" field.
4. Select the date you are submitting the report in the "Submission date" field.
5. Write a brief summary of the report's key findings in the "Executive summary" field.
6. Offer actionable recommendations from the report in the "Recommendations" field.
7. Indicate if any supporting files are attached in the "Attachments included" field.

## Field-by-Field Explanation
* **Consultant name** (`consultant_name`, required): Enter your name as the person submitting the report.
* **Client name** (`client_name`, required): Enter the name of the organization receiving the report.
* **Report title** (`report_title`, required): Provide a short title for the report.
* **Submission date** (`submission_date`, required): Enter the date you are submitting the report.
* **Executive summary** (`executive_summary`, required): Write a concise summary of the report's key findings.
* **Recommendations** (`recommendations`, required): Offer actionable recommendations from the report.
* **Attachments included** (`attachments_included`, optional): Check the box if you have attached supporting files to the report.

## Tips
* Ensure you have all necessary information and supporting files before filling out this form.
* Double-check your report metadata and attachments to ensure accuracy.
* If you have already submitted a report with the same client and title, review it before resubmitting to avoid duplication.
