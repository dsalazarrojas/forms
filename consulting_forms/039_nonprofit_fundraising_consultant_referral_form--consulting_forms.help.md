# Nonprofit Fundraising Consultant Referral Form - Help Guide
## Purpose
This form is used to refer a nonprofit organization to a consultant who can provide fundraising services. The information collected will help identify potential consultants that can assist with a nonprofit's fundraising goals.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the following information about the nonprofit organization:
	* **Nonprofit Name**: The name of the nonprofit organization you are referring to the consultant.
	* **Nonprofit Website**: The website of the nonprofit organization (optional).
2. Fill in the following information about the consultant:
	* **Consultant Name**: The name of the consultant you are referring.
3. Fill in the following fields about the consultant's services:
	* **Consultant Services**: The services offered by the consultant (e.g., Consulting Services, Fundraising Strategy, Grant Writing, etc.). Select one or more services that apply.
	* **Consultant Fees**: The fee structure of the consultant (note: this can be a one-time fee or a recurring fee).
4. If you have a personal recommendation about the consultant, please feel free to leave it in the **Consultant Recommendation** field.

## Field-by-Field Explanation
- **Nonprofit Name** (Nonprofit Name): This is the name of the nonprofit organization you are referring to the consultant.
	+ Type: `text`
	+ Required: No
	+ Description: Enter the name of the nonprofit organization.
- **Nonprofit Website** (Nonprofit Website): This is the website of the nonprofit organization.
	+ Type: `text`
	+ Required: No
	+ Description: Enter the website of the nonprofit organization (if applicable).
- **Consultant Name** (Consultant Name): This is the name of the consultant you are referring.
	+ Type: `text`
	+ Required: No
	+ Description: Enter the name of the consultant you are referring to.
- **Email** (email): This is the email address of the nonprofit organization or the person completing the form.
	+ Type: `email`
	+ Required: No
	+ Description: Enter a valid email address.
- **Phone** (phone): This is the phone number of the nonprofit organization or the person completing the form.
	+ Type: `text`
	+ Required: No
	+ Description: Enter a valid phone number.
- **Consultant Recommendation** (consultant_recommendation): This is a personal recommendation about the consultant.
	+ Type: `text`
	+ Required: No
	+ Description: Share your personal experience or impression about the consultant.
- **Nonprofit Fundraising Goals** (nonprofit_fundraising_goals): This is a description of the nonprofit organization's fundraising goals.
	+ Type: `text`
	+ Required: No
	+ Description: Enter a brief description of the nonprofit organization's fundraising goals.
- **Consultant Services** (consultant_services): This is the services offered by the consultant.
	+ Type: `select_one`
	+ Required: No
	+ Description: Select one or more services offered by the consultant (e.g., Consulting Services, Fundraising Strategy, Grant Writing, etc.).
- **Consultant Fees** (consultant_fees): This is the fee structure of the consultant.
	+ Type: `number`
	+ Required: No
	+ Description: Enter the fee structure of the consultant (e.g., a one-time fee or a recurring fee).

## Tips

- Be as specific as possible when describing the nonprofit organization and the consultant's services.
