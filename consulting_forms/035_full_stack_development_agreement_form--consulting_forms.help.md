# full_stack_development_agreement_form - Help Guide
## Purpose
This form is used to collect and record project details, payment terms, and payment status for full-stack development projects.

## How To Complete This Form

1. Start by filling out the Form Details section.
2. Provide a clear and concise description of the project in the Project Description field.
3. Determine whether the project is a Yes/No type by selecting the appropriate option in the Project Type field.
4. Enter the start date of the project in the Start Date field.
5. Enter the end date of the project in the End Date field.
6. If applicable, provide payment terms in the Payment Terms field.
7. Indicate whether the project requires agency approval by selecting Yes/No in the Approval field.
8. Provide agency details, if necessary, in the Agency Details field.
9. Specify the payment method in the Payment Method field.
10. Select the current payment status (Active/Inactive) in the Payment Status field.
11. Confirm whether the payment terms are agreed upon by selecting Yes/No in the Payment Terms Agreed field.
12. If the payment terms are signed, enter the date in the Payment Terms Signed field.
13. Confirm whether the payment terms are signed by selecting Yes/No in the Payment Terms Signed field.

## Field-by-Field Explanation

* **Form Details** (1, text, required): Enter a brief description of the form and its purpose.
* **Project Description** (2, text, required): Provide a clear and concise description of the project.
* **Project Type** (3, select_one, required): Select Yes for a project that requires full-stack development, No otherwise.
* **Start Date** (4, date, required): Enter the start date of the project.
* **End Date** (5, date, required): Enter the end date of the project.
* **Payment Terms** (6, text, optional): Provide any additional payment terms or conditions specific to the project.
* **Approval** (7, select_one, required): Indicate whether agency approval is required for the project (Yes/No).
* **Agency Details** (8, text, optional): Enter any agency-specific details, if necessary.
* **Agency Terms** (9, text, optional): Enter any agency-specific terms or conditions.
* **Payment Method** (10, select_one, optional): Specify the payment method for the project (Yes/No).
* **Payment Status** (11, select_one, required): Select the current payment status (Active/Inactive).
* **Payment Terms Agreed** (12, select_one, required): Confirm whether the payment terms are agreed upon (Yes/No).
* **Payment Terms Signed** (13, date, optional): If the payment terms are signed, enter the date.
* **Payment Terms Signed** (13, select_one, required): Confirm whether the payment terms are signed (Yes/No).

## Tips

* Review the form carefully to ensure that all necessary information is provided accurately and consistently.
* Double-check the payment terms and status to avoid any discrepancies.
* If you are unsure about any field, consult with the project manager or the relevant team members before proceeding.
