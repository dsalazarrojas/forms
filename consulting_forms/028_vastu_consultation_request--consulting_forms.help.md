# Vastu Consultation Request - Help Guide
## Purpose
This form collects information for a property-related consultation request from users seeking the services of a professional, likely a property owner or stakeholder.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the required and optional fields as necessary.
2. Ensure you provide accurate contact information, including first name, last name, email address, and phone number.
3. Select a preferred time and date for the consultation.
4. Choose a suitable consultant from the available options.
5. If applicable, select additional professionals, such as architects or wellness professionals, that you would like to include in the consultation.
6. Provide a note about your consultation needs or concerns.
7. Confirm whether you would like follow-up interactions and select the preferred method.
8. Enter any follow-up notes if applicable.
