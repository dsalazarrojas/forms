# RIA Registration Support Request Form - Help Guide
## Purpose
This form is designed to gather information from users to facilitate support requests related to RIA registrations. Users can input their details, status, and other relevant information to aid our support team in resolving their queries.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the required fields with accurate and relevant information.
2. Choose the correct options for each field, such as status and jurisdictions.
3. Add any additional notes if necessary to provide further context.
4. Submit the form to submit your request.

## Field-by-Field Explanation

* **User Input**: A text field for users to input any information they feel is relevant to their request.
* **RIA Registration Support Request**: A text field for users to describe their support request in detail.
* **Status**: A dropdown field to select the current status of the RIA registration. Please choose from the following options:
	+ Active
	+ Inactive
	+ Pending
	+ Other
* **Jurisdiction**: A text field to select the relevant jurisdiction for the RIA registration.
* **Other Status**: A text field to provide any additional status information not covered by the "Status" field.
* **Date of Issue**: A date field to input the date when the issue arose.
* **Request Details**: A note field to provide a detailed description of the issue or request.
* **File Upload**: A text field to attach any relevant files or documents.
* **Assignee**: A dropdown field to select the person or team responsible for this request.
* **RIA Registration Number**: A text field to input the relevant RIA registration number.
* **Route Status by Status**: A multi-select field to select relevant routes or paths based on the status of the RIA registration. Please choose from the following options:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
* **Route Jurisdiction by Jurisdiction**: A multi-select field to select relevant routes or paths based on the jurisdiction of the RIA registration. Please choose from the following options:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
* **RIA Registration Number Notes**: A note field to input any additional notes or comments about the RIA registration number.
* **RIA Registration Status Notes**: A note field to input any additional notes or comments about the status of the RIA registration.
* **RIA Registration Notes**: A note field to input any additional notes or comments about the RIA registration.
* **Submit**: A text field to submit the completed form and request support.
