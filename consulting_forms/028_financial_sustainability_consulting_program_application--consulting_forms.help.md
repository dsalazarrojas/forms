# Financial Sustainability Consulting Program Application - Help Guide

## Purpose
The Financial Sustainability Consulting Program Application is designed to provide financial support to organizations that are applying for consulting services related to financial sustainability. This application is intended for organizations that are interested in exploring sustainable financial practices and seeking guidance to improve their financial management and planning.

## How To Complete This Form
To complete this form, follow these steps:
1. Click on the "Apply for Financial Consulting Support" page.
2. Review the application form, which is divided into multiple pages.
3. On each page, fill out the required and optional fields as instructed.

## Field-by-Field Explanation

* **Apply for Financial Consulting Support** (`application_form`, text, required: false): This is the main page of the application form. Enter a brief description of your organization and the reason for your interest in the Financial Sustainability Consulting Program.
* **Organization Type** (`organization_type`, select_one, required: false): Select the type of organization you represent, which can be:
	+ Non-profit Organization
	+ Business
	+ Social Enterprise
* **Organization Name** (`organization_name`, text, required: false): Enter the name of your organization, including any applicable acronyms or abbreviations.
* **Contact Name** (`contact_name`, text, required: false): Enter the name of the person submitting the application.
* **Contact Email** (`email`, email, required: false): Enter a valid email address for the contact person.
* **Contact Phone** (`phone`, text, required: false): Enter a phone number for the contact person.

## Tips
* Make sure to provide accurate and clear information in each field to ensure a smooth review process.
* If you have any questions or need assistance, contact the program administrator for support.
* This application form is designed to be completed by one person per organization. If multiple applications are submitted by the same organization, only the first application will be reviewed.
