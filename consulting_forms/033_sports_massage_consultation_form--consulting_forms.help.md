# Sports Massage Consultation Form - Help Guide
## Purpose
This form is used to gather information from clients before a sports massage consultation. Please fill out this form thoroughly and accurately to ensure that the massage therapist is prepared to provide the best possible service.

## How To Complete This Form
1. Answer each question to the best of your ability.
2. Be as detailed as possible when answering questions that have a text box.
3. If you have any medical conditions, please answer "Yes" to the relevant questions.

## Field-by-Field Explanation
* **General Information** (`general_info`, text, required: false): This is a text field where you can provide any general information about yourself that may be relevant to your massage consultation.
* **Health History** (`health_history`, number, required: false): Select "Yes" if you have any health concerns or conditions that you would like the massage therapist to be aware of.
* **Massage Needs** (`massage_needs`, select_multiple, required: false):
	+ "Yes" if you are interested in receiving a massage.
* **Physical Condition** (`physical_condition`, select_one, required: false):
	+ Excellent: You are physically fit and have no concerns.
	+ Good: You have some physical limitations, but are generally healthy.
	+ Fair: You have significant physical limitations.
* **Specific Needs** (`specific_needs`, text, required: false): This is a text field where you can provide any specific needs or concerns you may have.
* **Medical History** (`medical_history`, select_multiple, required: false):
	+ "Yes" if you have any medical conditions that you would like the massage therapist to be aware of.
* **Medical History Details** (`medical_history_details`, text, required: false): This is a text field where you can provide more information about your medical history.
* **Allergies** (`allergies`, select_multiple, required: false):
	+ "Yes" if you have any allergies that the massage therapist should be aware of.
* **Medications** (`medications`, text, required: false): This is a text field where you can list any medications you are currently taking.
* **Emergency Contact** (`emergency_contact`, select_one, required: false):
	+ "Yes" if you have an emergency contact person that the massage therapist can contact in case of an emergency.
* **Emergency Contact Relationship** (`emergency_contact_relationship`, text, required: false): This is a text field where you can provide more information about your emergency contact relationship.
* **Insurance** (`insurance`, select_one, required: false):
	+ "Yes" if you have insurance that covers massage therapy.
* **Medical Provider** (`medical_provider`, text, required: false): This is a text field where you can provide the name of your medical provider.
* **Medical Condition Details** (`medical_condition_details`, text, required: false): This is a text field where you can provide more information about your medical conditions.
* **Massage Frequency** (`massage_frequency`, number, required: false): This is a field where you can select how often you would like to receive massages.
* **Massage Duration** (`massage_duration`, number, required: false): This is a field where you can select how long each massage session should be.
* **Massage Intensity** (`massage_intensity`, number, required: false): This is a field where you can select how intense you would like each massage session to be.
* **Goals** (`goals`, text, required: false): This is a text field where you can provide any goals you have for your massage therapy.
* **Notes** (`notes`, text, required: false): This is a text field where you can provide any additional notes or comments.
* **Consent** (`consent`, select_one, required: false):
	+ "Yes" if you consent to the massage therapist performing the massage.

## Tips
* Please answer each question as accurately as possible.
* If you are unsure about any question, please ask the massage therapist for clarification.
* This form is not a substitute for medical diagnosis or treatment.
