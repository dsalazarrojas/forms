# governance_audit_consulting_request_form - Help Guide
## Purpose
This form is used to collect information from end-users requesting governance audit consulting services. It is meant to categorize, describe, and specify the requirements for the audit.

## How To Complete This Form
To complete this form, follow the steps below:

1. Provide a title for the request.
2. Select the relevant category for your request.
3. Enter a detailed description of the services you need.
4. Enter your company's or client's form ID, if applicable.
5. Select the category for your request again (this field seems to be a duplicate, please ignore).
6. Provide a detailed description of the services you need (this field seems to be a duplicate, please ignore).
7. Select whether to assign a specific tool for the audit.
8. Enter the name and email of the client, if applicable.
9. Enter the client's phone number, if applicable.
10. Click the "Submit" button when you have completed all the steps above.

## Field-by-Field Explanation

* **Title** (`title`, text, required: false): Enter a concise title that describes your request.
* **Category** (`category`, select_one, required: false): Select the category that best describes your request.
* **Description** (`description`, text, required: false): Provide a detailed description of the services you need.
* **Form ID** (`form_id`, text, required: false): Enter your company's or client's form ID, if applicable.
* **Assigned Tool** (`assigned_tool`, select_one, required: false): Select whether to assign a specific tool for the audit.
* **Client Name** (`client_name`, text, required: false): Enter the name of the client, if applicable.
* **Client Email** (`client_email`, email, required: false): Enter the email of the client, if applicable.
* **Client Phone** (`client_phone`, text, required: false): Enter the phone number of the client, if applicable.
* **Submit** (`submit`, text, required: false): Click this button to submit your request.

Note: Please ensure that you complete all the fields accurately to facilitate efficient processing of your request.
