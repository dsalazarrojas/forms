# editorial_consultation_appointment_form - Help Guide

## Purpose
This form is designed to schedule an editorial consultation appointment. It captures essential information for both the editor and the client, such as the appointment title, date, time, duration, and location. The form ensures that all necessary details are documented for a smooth and organized consultation process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title for the editorial consultation appointment in the "Form Title" field.
2. Provide your name as the "Editor Name" in the required field.
3. Select the "Project Title" and enter a brief "Project Description" if necessary.
4. Choose the "Start Date" and "Start Time" for the consultation appointment. Note that these fields are required.
5. Set the "Session Duration" in minutes.
6. Provide the "Meeting Link" (if applicable) and "Meeting Location" (if different from the office location).
7. Enter any relevant "Client Info" for the consultation.
8. Add any "Additional Comments" about the appointment.
9. Click the "Submit" button to save the form.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, optional): Enter a brief title for the editorial consultation appointment.
* **Editor Name** (`editor_name`, text, required): Provide your name as the editor for the consultation.
* **Project Title** (`project_title`, text, optional): Select or enter the title of the project related to the consultation.
* **Project Description** (`project_description`, text, optional): Enter a brief description of the project if necessary.
* **Start Date** (`start_date`, date, required): Select the date for the consultation appointment.
* **Start Time** (`start_time`, time, required): Choose the start time for the consultation appointment.
* **End Time** (`end_time`, time, required): Set the end time for the consultation appointment.
* **Session Duration** (`session_duration`, number, required): Define the length of the consultation in minutes.
* **Meeting Link** (`meeting_link`, text, optional): Enter any relevant link related to the meeting (e.g., a shared Google Doc).
* **Meeting Location** (`meeting_location`, text, optional): Provide the location for the meeting if different from the office location.
* **Client Info** (`client_info`, text, optional): Enter any relevant information about the client for the consultation.
* **Additional Comments** (`additional_comments`, text, optional): Add any additional comments or instructions about the consultation.
* **Submit** (`submit`, text, required): Click to save the form after completing all required fields.
