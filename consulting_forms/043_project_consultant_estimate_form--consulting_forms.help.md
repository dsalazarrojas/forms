# Project Consultant Estimate Form - Help Guide
## Purpose
This form is used to create and manage project estimates for project consultants.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the form details in the **Form Details** field.
2. Provide a brief description of the project scope in the **Project Scope** field.
3. Select the proposed services to be provided in the **Proposed Services** field.
4. Enter the anticipated costs associated with the project in the **Anticipated Costs** field.
5. Enter the consultant's details in the **Consultant Details** field.
6. Provide the client's information in the **Client Information** field.
7. Enter the contact information for the project in the **Contact Information** field.
8. Select the tool assigned to the project in the **Assigned Tool** field.
9. Choose the current project status in the **Project Status** field.
10. Enter the due date for the project in the **Due Date** field.
11. Enter the start date for the project in the **Start Date** field.
12. Enter the end date for the project in the **End Date** field.
13. Enter a unique form ID in the **Form ID** field.
14. Select whether the project falls under a specific category in the **Category** field.
15. Enter a description of the project in the **Description** field.

## Field-by-Field Explanation

* **Form Details (id: 1)**: Enter the title and any additional information about the form.
	+ Type: `text`
	+ Required: No
* **Project Scope (id: 2)**: Briefly describe the project scope to help project managers understand project goals.
	+ Type: `text`
	+ Required: No
* **Proposed Services (id: 3)**: Select the services that will be provided for the project.
	+ Type: `select_multiple`
	+ Required: No
* **Anticipated Costs (id: 4)**: Enter the costs expected for the project.
	+ Type: `number`
	+ Required: No
* **Consultant Details (id: 5)**: Enter the consultant's name, email, and any additional information.
	+ Type: `note`
	+ Required: No
* **Client Information (id: 6)**: Enter the client's name, email, and any additional information.
	+ Type: `text`
	+ Required: No
* **Contact Information (id: 7)**: Enter the contact information for the project, including name, email, and phone number.
	+ Type: `text`
	+ Required: No
* **Assigned Tool (id: 8)**: Select the tool used for the project.
	+ Type: `select_one`
	+ Required: No
* **Project Status (id: 9)**: Choose the current project status.
	+ Type: `select_one`
	+ Required: No
* **Due Date (id: 10)**: Enter the date by which the project is due.
	+ Type: `date`
	+ Required: No
* **Start Date (id: 11)**: Enter the start date of the project.
	+ Type: `date`
	+ Required: No
* **End Date (id: 12)**: Enter the end date of the project.
	+ Type: `date`
	+ Required: No
* **Form ID (id: 13)**: Enter a unique ID for the form.
	+ Type: `number`
	+ Required: No
* **Category (id: 14)**: Select whether the project falls under a specific category.
	+ Type: `select_one`
	+ Required: No
* **Description (id: 15)**: Enter a description of the project.
	+ Type: `text`
	+ Required: No
