# Menu Popularity Report Form - Help Guide

## Purpose
This form is used to generate a menu popularity report for restaurants and multi-location teams. The report can be customized based on the user's selection, providing insights on menu performance, trend analysis, or other relevant data.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of report you need using the `restaurant_manager_forms` field.
2. Enter a brief description of the data collection process using the `data_collection` field.
3. Provide an email address for staff insights using the `staff_insights` field (optional).
4. Enter a number for monthly dish performance using the `monthly_dish_performance` field (optional).
5. Select one option for compare menu trends using the `compare_menu_trends` field (optional).

## Field-by-Field Explanation

* **Restaurant Manager Forms** (`restaurant_manager_forms`): Select the type of report you need:
	+ Form 1: Menu Performance
	+ Form 2: Menu Trend
	+ Form 3: Menu Analysis
* **Description of Data Collection** (`data_collection`): Briefly describe the data collection process.
* **Staff Insights** (`staff_insights`): Enter an email address for staff insights (optional).
* **Monthly Dish Performance** (`monthly_dish_performance`): Enter a number indicating the dish's performance (optional).
* **Compare Menu Trends** (`compare_menu_trends`): Select one option to compare menu trends:
	+ Form 1
	+ Form 2
	+ Form 3
* **Data Collection** (`data_collection`): Enter a brief description of the data collection process.
* **Staff Insights** (`staff_insights`): Enter an email address for staff insights (this field may be skipped if not required).
* **Note** (`data_collection`): Enter a brief description of the data collection process (this field is optional but recommended for accurate results).

## Tips
* Make sure to select the correct type of report and provide accurate data for each field to ensure the report is generated correctly.
* If you're unsure about any field, refer to the field's label for clarification.
* The form is designed to be self-explanatory, but if you need further assistance, contact the support team.
