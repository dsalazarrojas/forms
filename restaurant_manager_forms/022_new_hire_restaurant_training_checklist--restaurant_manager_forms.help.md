# new_hire_restaurant_training_checklist - Help Guide
## Purpose
The new_hire_restaurant_training_checklist form is used to record the training status of new restaurant staff on key areas such as restaurant operations, emergency procedures, food safety, and safety protocols.

## How To Complete This Form

1. To complete this form, please answer the questions based on your training status for each of the listed areas. Select "Yes" if you have completed the required training, or "No" if you have not.
2. For select multiple fields, you can choose multiple options that apply to you.

## Field-by-Field Explanation

* **Restaurant Training Program** (`restaurant_training_program`, number, required/optional): This field asks about your completion status for the restaurant's training program. Please select "1" if you have completed the program, and "0" otherwise.
* **Emergency Procedures** (`emergency_procedures`, text, required/optional): This field is used to note any emergency procedures you have received training on. Please provide a brief description of the procedures you have learned.
* **Food Safety Handling** (`food_safety_handling`, text, required/optional): This field is for noting any food safety handling procedures you have received training on. Please provide a brief description of the procedures you have learned.
* **Food Safety Certification** (`food_safety_certification`, select multiple, required/optional): If you have obtained food safety certification, please select "Yes". Otherwise, select "No".
* **Fire Suppression** (`fire_suppression`, select multiple, required/optional): If you have received fire suppression training, please select "Yes" for each relevant category. Otherwise, select "No".
* **First Aid** (`first_aid`, text, required/optional): This field is for noting any first aid training you have received. Please provide a brief description of the procedures you have learned.
* **Restaurant Security** (`restaurant_security`, select multiple, required/optional): If you have received restaurant security training, please select "Yes" for each relevant category. Otherwise, select "No".
* **Employee Policies** (`employee_policies`, select multiple, required/optional): If you have received training on employee policies, please select "Yes" for each relevant category. Otherwise, select "No".
* **Food Borne Illnesses** (`food_borne_illnesses`, select multiple, required/optional): If you have received training on food borne illnesses, please select "Yes" for each relevant category. Otherwise, select "No".

## Tips

* Please answer honestly and accurately based on your actual training status.
* If you are unsure about any of the fields, please consult with your supervisor or training officer.
* This form is meant to be a quick reference guide for your training status. Please take the time to thoroughly review and complete each field accurately.
