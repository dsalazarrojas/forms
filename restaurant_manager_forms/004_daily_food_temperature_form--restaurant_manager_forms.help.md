# Daily Food Temperature Form - Help Guide
## Purpose
This form is used to record the daily food and storage temperatures for quality and safety control.

## How To Complete This Form
To fill out this form, follow these steps:
1. Select the correct temperature value for each food item from the provided fields.
2. Enter the correct storage temperature value for each storage unit from the provided fields.
3. Make sure all required fields are filled in, indicated by an asterisk (\*).
