# easter_treats_order_form - Help Guide
## Purpose
The Easter Treats Order Form is used by restaurant managers to order Easter treats for their establishment. It is intended to collect information about the order details, such as the type of Easter treat, quantity, price, and description.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the Easter Egg field to indicate if the order is for an Easter egg or not.
* Enter the quantity of the Easter treats ordered.
* Select the desired Easter treat flavors.
* Enter the price of the Easter treats.
* Add a description of the Easter treats.
* If necessary, upload an image of the Easter treats.
* Calculate the subtotal of the Easter treat price.

## Field-by-Field Explanation
* **Easter Egg** (Yes/No, required: No)
	+ This field indicates if the order is for an Easter egg or not. Select "Yes" if the order is for an Easter egg, otherwise select "No".
* **Quantity** (number, required: No)
	+ Enter the number of Easter treats ordered.
* **Easter Treat Flavors** (multiselect, required: No)
	+ Select all the desired flavors for the Easter treats.
* **Easter Treat Price** (number, required: No)
	+ Enter the price of the Easter treats.
* **Easter Treat Description** (text, required: No)
	+ Add a brief description of the Easter treats, such as a product name or a special note.
* **Easter Treat Image** (date/time, required: No)
	+ If required, upload an image of the Easter treats.
* **Easter Treat Price Subtotal** (text, required: No)
	+ Calculate the total price of the Easter treats by multiplying the price per unit by the quantity.
