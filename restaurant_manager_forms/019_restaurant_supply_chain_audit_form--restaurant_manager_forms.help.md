# Restaurant Supply Chain Audit Form - Help Guide
## Purpose
This form is designed to collect information about a restaurant's supply chain, specifically their suppliers. The purpose of this form is to conduct an audit of the supply chain, which is a critical process for ensuring that restaurants are sourcing ingredients and materials from reliable and trustworthy suppliers.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each section completely and accurately, as much as possible.
2. If a field does not apply to your supplier or supply chain situation, you may skip it or leave it blank.
3. Be as specific as possible when providing information, especially when answering questions about dates and frequencies.

## Field-by-Field Explanation
- **Supplier Name** (`supplier_name`, text, optional): This field is for entering the name of the supplier.
	* Please type the name of the supplier in this field.
- **Supplier Phone** (`supplier_phone`, text, optional): This field is for entering the phone number of the supplier.
	* Please type the phone number of the supplier in this field.
- **Supplier Address** (`supplier_address`, text, optional): This field is for entering the address of the supplier.
	* Please type the address of the supplier in this field.
- **Date Last Order** (`date_last_order`, date, optional): This field is for entering the date of the last order from the supplier.
	* Please type the date of the last order in the format MM/DD/YYYY.
- **Order Frequency** (`order_frequency`, number, optional): This field is for entering the frequency of orders from the supplier.
	* Please type a number to indicate how often you receive orders from this supplier (e.g. 1 = once a month, 2 = twice a month, etc.).
- **Order Frequency Type** (`order_frequency_type`, select one, optional): This field is for selecting the type of frequency.
	* Please select one of the following options: Frequent, Infrequent, Rare.
- **Receiving Location** (`receiving_location`, select multiple, optional): This field is for selecting the locations where you receive shipments from this supplier.
	* Please select all locations where you receive shipments from this supplier (e.g. Receiving Location 1, Receiving Location 2, etc.).
- **Receiving Time** (`receiving_time`, time, optional): This field is for entering the time of day when you receive shipments from this supplier.
	* Please type the time of day when you receive shipments in the format HH:MM.
- **Receiving Frequency** (`receiving_frequency`, number, optional): This field is for entering the frequency of receiving shipments from this supplier.
	* Please type a number to indicate how often you receive shipments from this supplier (e.g. 1 = once a week, 2 = twice a week, etc.).
- **Receiving Frequency Type** (`receiving_frequency_type`, select one, optional): This field is for selecting the type of frequency.
	* Please select one of the following options: Frequent, Infrequent, Rare.
- **Quality Control** (`quality_control`, select multiple, optional): This field is for selecting the level of quality control performed by this supplier.
	* Please select all methods of quality control that apply to this supplier (e.g. 'Yes', 'No', Unknown).
- **Follow-up Required** (`followup_required`, select multiple, optional): This field is for selecting whether follow-up is required for this supplier.
	* Please select all options that apply (e.g. 'Yes', 'No', Unknown).

## Tips
- Please answer each question as accurately and completely as possible.
- If a field does not apply to your supplier or supply chain situation, you may skip it or leave it blank.
- If you are unsure about any question, please reach out to your procurement staff or manager for guidance.
