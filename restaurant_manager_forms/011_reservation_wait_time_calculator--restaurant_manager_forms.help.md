# Reservation Wait Time Calculator - Help Guide
## Purpose
The Reservation Wait Time Calculator form is a tool designed to help restaurant managers estimate the wait time for a reservation based on several factors.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Wait Time" field to input the wait time for the reservation.
2. Enter the "Table Capacity" to input the capacity of the table.
3. Enter the "Number of Guests" to input the number of guests for the reservation.
4. Select the "Reservation Start Time" field to input the start time of the reservation.
5. Enter the "Expected Reservation Duration" to input the expected duration of the reservation.
6. Enter the "Actual Reservation Duration" to input the actual duration of the reservation.
7. Click the "Submit" button to calculate the estimated wait time.

## Field-by-Field Explanation
* **Wait Time**: Enter the estimated wait time for the reservation.
* **Table Capacity**: The number of guests that the table can accommodate.
* **Number of Guests**: The number of guests for the reservation.
* **Reservation Start Time**: The start time of the reservation.
* **Expected Reservation Duration**: The expected duration of the reservation.
* **Actual Reservation Duration**: The actual duration of the reservation.

## Tips
- Make sure to enter accurate information to get an accurate estimate of the wait time.
- If you're unsure about any of the fields, consult with the reservation staff or manager.
- You can use this form to adjust your wait time estimates based on various factors such as time of day and day of the week.
