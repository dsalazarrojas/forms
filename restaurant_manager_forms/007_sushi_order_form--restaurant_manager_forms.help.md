# sushi_order_form - Help Guide
## Purpose
The sushi_order_form is a tool used to gather pickup order information for customers. Please use this guide to ensure accurate and efficient completion of the form.
## How To Complete This Form
1.  To start, select a pickup location.
2.  Enter the pickup time and date for the order.
3.  Choose the order type (Sushi, Sushi and drinks, or Drinks only).
4.  Enter the customer's name and contact phone number.
5.  Provide any additional order details.
6.  Enter the total number of items in the order.
7.  Enter an order ID (if known) or leave it blank.
8.  Enter the customer's address.

## Field-by-Field Explanation
*   **Pickup location** (1, text, required/optional): Enter the address where you would like to pick up the order. This field is optional, but it is recommended if you want to select a specific location.
*   **Pickup time** (2, time, required/optional): Enter the time at which you would like to pick up the order. This field is optional, but it is recommended for accurate pickup scheduling.
*   **Pickup date** (3, date, required/optional): Enter the date of the pickup order. This field is optional, but it is recommended for accurate order tracking.
*   **Report type** (4, select_one, required/optional): Choose from the options Sushi, Sushi and drinks, or Drinks only to select the type of order you are placing.
*   **Customer name** (5, text, required/optional): Enter the name of the customer who placed the order. This field is optional, but it is recommended for accurate customer information.
*   **Contact phone** (6, text, required/optional): Enter the phone number of the customer who placed the order. This field is optional, but it is recommended for communication purposes.
*   **Order details** (7, text, required/optional): Enter any additional information about the order, such as special requests or modifications. This field is optional, but it is recommended for clear order understanding.
*   **Total items** (8, number, required/optional): Enter the total number of items in the order.
*   **Order ID** (9, number, required/optional): Enter the ID of the order (if known). This field is optional, but it is recommended for order tracking.
*   **Customer address** (10, text, required/optional): Enter the address of the customer who placed the order. This field is optional, but it is recommended for accurate shipping or delivery purposes.

## Tips
*   Be sure to fill in all required fields to ensure accurate order completion.
*   If you are unsure about any field, refer to the form's purpose and the field-by-field explanation above for guidance.
*   Double-check all fields before submitting the form to avoid errors.
