# Menu Addition Support Request - Help Guide
## Purpose
The Menu Addition Support Request form is used by staff to submit requests for adding, modifying, or removing menu items in the restaurant.

## How To Complete This Form
To complete this form, follow these steps:

1. **Menu Item Name**: Enter the name of the new or updated menu item in the text field provided.
2. **Menu Item Details**: Provide a detailed description of the menu item in the text field.
3. **Menu Item Type**: Select the type of menu item from the dropdown menu. This can be "New Menu Item", "Menu Update", or "Menu Removal".
4. **Item Status**: Indicate the status of the menu item as "Available" or "Not Available".
5. **Category ID**: This is a numerical ID for the category under which the menu item will be listed. Please ensure you know the correct ID for this field.
6. **Category**: Enter the name of the category under which the menu item will be listed.
7. **Urgency**: Select the level of urgency for the request, which can be "High", "Medium", or "Low".
8. **Attachments**: If necessary, attach any relevant images or files to support the request.
9. **Menu Item Image URL**: If you have a URL for an image of the menu item, enter it here.
10. **Menu Item Price**: Enter the price of the menu item, ensuring it is a numerical value.
11. **Submit**: Click the "Submit" button to submit the request.
