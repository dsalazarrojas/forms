# Bartender Opening Checklist - Help Guide
## Purpose

The "Bartender Opening Checklist" form is used to document the daily opening and setup of a bar, ensuring that all essential items are present, accounted for, and functioning correctly before service begins.

## How To Complete This Form

1.  **Opening Date**: Enter the date of the current shift using the date field. This field is required to track and reference future dates.
2.  **Bartender Name**: Enter your name as the bartender responsible for the current shift. This field is required to track accountability and responsibility.
3.  **Opening Time**: Enter the start time of the current shift using the time field. This field is required to track shift timing and duration.
4.  **Bar Set Up and Organization**: Confirm if the bar is properly set up and organized. Select "True" if the bar is ready for service, "False" otherwise.
5.  **Ice Machine**: Confirm if the ice machine is stocked and functioning correctly. Select "True" if ready, "False" otherwise.
6.  **Glassware**: Confirm if the glassware is clean and ready for service. Select "True" if clean, "False" otherwise, or "Partial" for any issues.
7.  **Inventory Verification**:
    *   **Liquor Check**: Confirm if all liquor bottles are present and accounted for. Select "True" if all bottles are present, "False" otherwise.
    *   **Discrepancies**: If there are any discrepancies or missing bottles, describe them in the text field.
8.  **Mixers and Juices**:
    *   **Mixers and Juices**: Confirm if mixers and juices are properly stocked. Select "True" if stocked, "False" otherwise, or "Low Stock" for any issues.
9.  **Garnishes**:
    *   **Fresh Garnishes**: Confirm if garnishes (e.g., limes, lemons, olives) are prepared and fresh. Select "True" if fresh, "False" otherwise, or "Needs Refresh" for any issues.
10. **Supplies and Tools**:
    *   **Bar Tools**: Confirm if all bar tools (e.g., shakers, jiggers, strainers) are present and clean. Select "True" if all tools are present, "False" otherwise, or "Missing Items" for any issues.
    *   **Bar Towels**: Confirm if clean bar towels are available. Select "True" if available, "False" otherwise, or "Low Supply" for any issues.
11. **Registration and Systems**:
    *   **POS System**: Confirm if the POS system is tested and functional. Select "True" if functional, "False" otherwise.
    *   **Register Opened**: Confirm if the cash register is opened with the starting amount. Select "True" if opened, "False" otherwise.
    *   **Starting Cash**: (Optional) Enter the starting cash amount.
12. **Manager Communication**:
    *   **Notes**: If there are any issues or notes from the previous shift, provide them in this text field.
13.  **Checklist Verification**: Confirm all opening items have been completed by selecting "I Confirm" if true, "Needs Review" if there are discrepancies or issues.

Remember, accuracy and attention to detail are crucial when completing this form. Please ensure all fields are filled in correctly to maintain a smooth operation and minimize errors.
