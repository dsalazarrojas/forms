# Pet Information Form - Help Guide
## Purpose
The Pet Information Form is a crucial tool for shelters to collect accurate and complete information about pets and their owners to facilitate the adoption process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the pet's name in the "Pet Name" field.
2. Select the pet's type (e.g., Dog, Cat, Other) in the "Pet Type" field.
3. Enter the pet's age in years in the "Pet Age" field.
4. Select the pet's breed(s) from the provided options, if applicable.
5. Enter the pet's weight in the "Pet Weight" field.
6. Enter the owner's email address in the "Owner Email" field.
7. Enter the owner's phone number in the "Owner Phone" field.
8. Enter any additional notes in the "Notes" field, if necessary.
9. Select the pet's date of birth (if known).
10. Select the pet's gender.
11. Choose the unit of weight measurement (e.g., lbs, kg).
12. Enter the name and phone number of the veterinarian.
13. Enter the name and phone number of the shelter.
14. Enter the shelter's address.
15. Select the adoption date.
16. Select the vaccination status.
17. Select the adoption status.
18. Select the adoption date, if applicable.
19. Select whether the owner has provided information.
20. Select whether the owner has provided additional information.
21. Select whether the owner has provided further information.
22. Select whether the owner has provided more information.

## Field-by-Field Explanation
* **Pet Name**: A required field to enter the pet's name.
* **Pet Type**: A required field to select the type of pet (e.g., Dog, Cat, Other).
* **Pet Age**: A required field to enter the pet's age in years.
* **Pet Breed**: An optional field to select the pet's breed(s), if applicable.
* **Pet Weight**: A required field to enter the pet's weight.
* **Owner Email**: A required field to enter the owner's email address.
* **Owner Phone**: A required field to enter the owner's phone number.
* **Notes**: An optional field to enter any additional notes, if necessary.
* **Pet DOB**: A field to select the pet's date of birth (if known).
* **Pet Gender**: A required field to select the pet's gender.
* **Pet Weight Unit**: A required field to choose the unit of weight measurement.
* **Veterinarian**: An optional field to enter the name and phone number of the veterinarian.
* **Shelter Name**: A required field to enter the name of the shelter.
* **Shelter Phone**: A required field to enter the shelter's phone number.
* **Shelter Address**: A required field to enter the shelter's address.
* **Adoption Date**: A required field to select the adoption date.
* **Vaccination Status**: A required field to select the vaccination status.
* **Adoption Status**: A required field to select the adoption status.
* **Adopted Date**: A required field to select the adopted date, if applicable.
* **Owner Info 1-5**: Required fields to select whether the owner has provided information on these aspects.
