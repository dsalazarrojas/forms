### E Commerce Payment Integration Registration - Help Guide

## Purpose
This form is used to register e-commerce payment integration details. Please fill out the form with the required information to complete the registration process.

## How To Complete This Form
To complete this form, simply fill out each field with the requested information. The required fields are marked as "Required/Optional" next to each field label.

## Field-by-Field Explanation

### 1. Merchant Info
* **Merchant Info** (`merchant_info`, text, required: false): This field is for the name of your merchant.
### 2. Contact Info
* **Contact Info** (`contact_info`, text, required: false): This field is for the contact information of your merchant.
### 3. Payment Details
* **Payment Details** (`payment_details`, text, required: false): This field is for additional payment details.
### 4. Shipping Cost
* **Shipping Cost** (`shipping_cost`, number, required: false): This field is for the shipping cost of your products.
### 5. Tax Rate
* **Tax Rate** (`tax_rate`, number, required: false): This field is for the tax rate of your products.
### 6. Integration Type
* **Integration Type** (`integration_type`, select_one, required: false): This field is for whether you want to integrate your payment information.
### 7. API Key
* **API Key** (`api_key`, text, required: false): This field is for entering your API key.
### 8. API Secret
* **API Secret** (`api_secret`, text, required: false): This field is for entering your API secret.
### 9. Callback URL
* **Callback URL** (`callback_url`, text, required: false): This field is for entering the callback URL.
### 10. Merchant ID
* **Merchant ID** (`merchant_id`, number, required: false): This field is for the merchant ID.
### 11. Payment Gateway
* **Payment Gateway** (`payment_gateway`, text, required: false): This field is for the payment gateway.
### 12. Payment Status
* **Payment Status** (`payment_status`, select_multiple, required: false): This field is for the payment status.
### 13. Payment Currency
* **Payment Currency** (`payment_currency`, select_one, required: false): This field is for the payment currency.
### 14. Integration Status
* **Integration Status** (`integration_status`, select_one, required: false): This field is for the integration status.

Note: Please ensure that all fields are filled out accurately and completely to avoid any issues with the payment integration process.
