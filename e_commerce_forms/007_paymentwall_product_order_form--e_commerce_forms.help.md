# Paymentwall Product Order Form - Help Guide
## Purpose
The Paymentwall Product Order Form is designed to collect essential information for payment processing and order management. This form is intended for both customers and internal staff to input order details and product information.

## How To Complete This Form
To fill out this form, follow these steps:
1. Review the form fields carefully to ensure you are inputting the correct information for each field.
2. Enter the product ID to associate the order with the correct product.
3. Enter the user ID to connect the order with the customer's profile.
4. Input the order ID to track order status and updates.
5. Enter the product price to ensure accurate payment processing.
6. Select the order status from the options provided to reflect the current state of the order.
7. Input the customer's email address for communication and order tracking.
8. Enter the customer's phone number for additional contact information.
9. Select the order date and time to record the order's creation timestamp.
10. Add any relevant notes for the order.
11. Choose the payment method from the available options.

## Field-by-Field Explanation
- **Form Data** (Form Data, text, optional): Enter any additional information related to the order not covered by other fields.
- **Product Id** (Product Id, number, optional): Enter the product ID associated with the order.
- **User Id** (User Id, number, optional): Enter the user ID linked to the customer's profile.
- **Order Id** (Order Id, number, optional): Enter the unique ID for the order.
- **Product Price** (Product Price, number, optional): Input the product price for accurate payment processing.
- **Order Status** (Order Status, select_one, optional): Select the current order status from the options provided.
  - **Pending**: The order is pending and has not been fulfilled yet.
  - **Shipped**: The order has been shipped and is no longer pending.
  - **Cancelled**: The order has been cancelled.
- **User Email** (User Email, email, optional): Enter the customer's email address for communication and order tracking.
- **User Phone** (User Phone, text, optional): Enter the customer's phone number for additional contact information.
- **Order Date** (Order Date, date, optional): Input the order creation date.
- **Order Time** (Order Time, time, optional): Input the order creation time.
- **Notes** (Notes, note, optional): Add any relevant notes for the order.
- **Payment Method** (Payment Method, select_one, optional):
  - **Credit card**: Use credit card payment method.
  - **PayPal**: Use PayPal payment method.
  - **Bank Transfer**: Use bank transfer payment method.
- **Form Notes** (Form Notes, note, optional): Add any additional information or comments regarding the order.
