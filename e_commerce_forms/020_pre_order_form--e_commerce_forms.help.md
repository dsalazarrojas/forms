# Pre Order Form - Help Guide
## Purpose
This form is used to gather information from customers for processing pre-orders. Please fill out this form to ensure that your order is processed correctly and on time.

## How To Complete This Form
To complete this form, follow these steps:
* Fill in all required fields, which are marked as required.
* For the 'shipping_address' field, please provide your shipping address in the format 'Street Address Line 1', 'Street Address Line 2', City, State/Province, ZIP/Postal Code' (e.g., '123 Main St, Anytown, CA 12345').
* For the 'email' field, please enter a valid email address that you check frequently.
* For the 'phone' field, please enter your phone number in the format 'XXX-XXX-XXXX' (e.g., '123-456-7890').
* For the 'name' field, please enter your name as you would like it to appear on the order.
* For the 'product_details' field, please provide any additional information about the product you are ordering (e.g., 'Product Name - Size 8 - Color Red').
* For the 'shipping_method' field, please select 'Yes' if you would like to ship the order immediately, and 'No' if you would like to schedule shipping at a later date.
* For the 'payment_method' field, please select all the payment methods you are interested in using (e.g., 'Yes' for credit card, 'Yes' for bank transfer, 'No' for other methods).
* For the 'shipping_date' field, please select the date you would like to ship the order.
* You can leave the other fields blank if not applicable or if you are unsure of the information.

## Field-by-Field Explanation
* **Shipping Address**: Please provide your shipping address to ensure that your order is delivered to the correct location.
* **Email**: Please enter a valid email address that you check frequently, so we can contact you with order updates.
* **Phone**: Please enter your phone number for contact purposes.
* **Name**: Please enter your name as you would like it to appear on the order.
* **Product Details**: Please provide any additional information about the product you are ordering.
* **Shipping Method**: Please select 'Yes' if you would like to ship the order immediately, or 'No' if you would like to schedule shipping at a later date.
* **Payment Method**: Please select all the payment methods you are interested in using.
* **Shipping Date**: Please select the date you would like to ship the order.
