# File Attachment Form - Help Guide
## Purpose
The File Attachment Form is a data collection tool designed to gather personal and attachment details. It is intended for users to provide information and attach files to a specific context, such as a support request or an order.

## How To Complete This Form
1. Fill in your First Name and Last Name in the corresponding fields. These fields are required.
2. If you have a file to attach, select it from the attachment type dropdown menu.
3. If you wish to provide an email address, enter it in the Email field.
4. If you have a phone number, enter it in the Phone field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Fill in your first name as it appears on your identity documents.
* **Last Name** (`last_name`, text, required): Fill in your last name as it appears on your identity documents.
* **File** (`file`, text, optional): If you have a file to attach, select it from the attachment type dropdown menu to associate it with the correct type.
* **Attachment Type** (`attachment_type`, select_one, required): Select the type of attachment from the provided options (Attachment 1, Attachment 2, Attachment 3, Attachment 4).
* **Email** (`email`, email, optional): If you wish to provide an email address for contact, enter it here.
* **Phone** (`phone`, text, optional): If you have a phone number, enter it here.

## Tips
* Make sure to select the correct attachment type to ensure accurate association with your file.
* If you are unable to select a attachment type from the options, please contact the support team to inquire about additional options.
* Ensure that the information you enter is accurate and up-to-date to ensure smooth processing and follow-up.
