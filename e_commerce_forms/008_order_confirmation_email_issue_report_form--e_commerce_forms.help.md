# Order Confirmation Email Issue Report Form - Help Guide
## Purpose
The Order Confirmation Email Issue Report Form is used to report issues with order confirmation emails that have not been delivered to customers or have been delivered in an unexpected way.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Order ID of the order that has an issue with its confirmation email.
2. Select the current Order Status of the order from the list provided.
3. Describe the problem in detail, including any error messages or unexpected behavior you have observed.
4. Enter your name and role as the support agent who is reporting the issue.

## Field-by-Field Explanation

* **Order ID** (`order_confirmation_email_issue_report_form_order_id`, number, required): Enter the unique identifier for the order that has an issue with its confirmation email. This is usually a series of numbers that is provided to you when you access the order in the system.
* **Customer Email** (`order_confirmation_email_issue_report_form_customer_email`, email, optional): Enter the email address that the confirmation email was supposed to be sent to, if available. If the email address is not available, you can leave this field blank.
* **Order Status** (`order_confirmation_email_issue_report_form_order_status`, select one, optional): Select the current status of the order from the list provided. This will help us understand the context of the issue.
* **Description** (`order_confirmation_email_issue_report_form_description`, note, optional): Describe the problem with the confirmation email in detail. Be as specific as possible about any error messages or unexpected behavior you have observed.
* **Support Agent** (`order_confirmation_email_issue_report_form_support_agent`, text, optional): Enter your name and role as the support agent who is reporting the issue. This helps us know who to contact for more information.
