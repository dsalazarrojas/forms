# Used Book Listing Form - Help Guide
## Purpose
This form is used for listing used books on our platform. Please fill it out with accurate and complete information to help buyers and sellers connect.

## How To Complete This Form

To complete this form, follow these steps:

* Fill out all required fields with accurate information.
* For fields with multiple options, select the most relevant option from the list.
* You can leave optional fields blank if not applicable or if you're unsure about the information.

## Field-by-Field Explanation

* **Book Title** (`book_title`, text, required): Enter the title of the book you are listing.
* **ISBN** (`isbn`, text, required): Enter the 10 or 13-digit ISBN number of the book.
* **Condition** (`condition`, text, required): Describe the condition of the book (e.g., "Good", "Fair", "Poor").
* **Edition** (`edition`, text, optional): Specify the edition of the book (e.g., "First Edition", "Second Edition").
* **Author** (`author`, text, optional): Enter the name of the book's author.
* **Publisher** (`publisher`, text, optional): Enter the name of the book's publisher.
* **Pages** (`pages`, text, optional): Enter the number of pages in the book.
* **Price** (`price`, number, optional): Set a price for the book.
* **Image Url** (`image_url`, text, optional): Enter the URL of the book's cover image.
* **Category** (`category`, select_one, optional): Select the category of the book (e.g., "Book", "Textbook", "Novel").
* **Tags** (`tags`, select_multiple, optional): Select relevant tags for the book (e.g., "Book", "Text", "Novel", "Non-Fiction", "Fiction").
* **Date Listed** (`date_listed`, date, optional): Set the date you listed the book.
* **Quantity** (`quantity`, number, optional): Enter the quantity of the book available for sale.
* **Used Condition** (`used_condition`, text, optional): Describe the used condition of the book.
* **Description** (`description`, note, optional): Enter a detailed description of the book and its condition.

## Tips

* Make sure to double-check your entries for accuracy to avoid any confusion or errors.
* If you're unsure about any information, leave the field blank and provide a note in the "Description" field.
* If you have any additional questions or concerns, contact our support team.
