# Print & Design Order Form - Help Guide
## Purpose
The Print & Design Order Form is a simple form designed to collect information from clients for their print order. The form is intended for clients who need to place an order for customized print materials.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Select the desired font for your print order from the options provided in the "Lettering" field.
2. Choose the numbering style for your print order from the options provided in the "Numbering" field. If you don't want numbering, select "None".
3. Select the desired color scheme for your print order from the options provided in the "Coloring" field.
4. Provide a detailed description of your design order in the "Design Order Form" field.

## Field-by-Field Explanation
- **Lettering** (`Lettering`, select one, optional): Choose the font style for your print order. Select from the options: Arial, Calibri, or Times New Roman.
- **Numbering** (`Numbering`, select multiple, optional): Select the numbering style for your print order. Choose from the options: None, Arabic, Roman, Uppercase, or Lowercase.
- **Coloring** (`Coloring`, select one, optional): Select the color scheme for your print order. Choose from the options: Colorless, Monochrome, Color, or Grayscale.
- **Design Order Form** (`Design Order Form`, text, optional): Provide a detailed description of your design order.
