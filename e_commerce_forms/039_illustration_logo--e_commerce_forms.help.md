# Illustration Logo - Help Guide
## Purpose

This form is used to create or update metadata for ecommerce illustration logos. It includes fields for title, description, category, ID, version, output file, assigned tool, file name, file type, date, time, note, email, and phone number. Please fill out the form carefully to ensure accurate logo metadata.

## How To Complete This Form

1. Fill out the **form_title** field with a brief title describing the illustration logo.
2. Provide a detailed description of the illustration logo in the **form_description** field.
3. Select the category of the illustration logo from the **form_category** dropdown menu. (Choose from "E-commerce Forms" or "Other")
4. Enter a unique ID for the illustration logo in the **form_id** field.
5. Enter the version of the illustration logo in the **form_version** field (if applicable).
6. If necessary, upload an output file for the illustration logo in the **form_output_file** field.
7. Select the tool assigned to the illustration logo from the **form_assigned_tool** dropdown menu. (Choose from "chatjimmy" or "Other")
8. Enter the name of the file for the illustration logo in the **form_file_name** field.
9. Select the file type of the illustration logo from the **form_file_type** dropdown menu. (Choose from "png" or "Other")
10. Enter the date the illustration logo was created in the **form_date** field.
11. Enter the time the illustration logo was created in the **form_time** field.
12. Provide any additional notes about the illustration logo in the **form_note** field.
13. Enter a contact email for the illustration logo in the **form_email** field (if applicable).
14. Enter a phone number for the illustration logo in the **form_phone** field (if applicable).

## Field-by-Field Explanation

* **form_title** (text, required): Enter a brief title describing the illustration logo.
* **form_description** (text, required): Provide a detailed description of the illustration logo.
* **form_category** (select_multiple, required): Select the category of the illustration logo (E-commerce Forms or Other).
* **form_id** (number, required): Enter a unique ID for the illustration logo.
* **form_version** (number, optional): Enter the version of the illustration logo (if applicable).
* **form_output_file** (text, optional): If necessary, upload an output file for the illustration logo.
* **form_assigned_tool** (select_one, optional): Select the tool assigned to the illustration logo (chatjimmy or Other).
* **form_file_name** (text, required): Enter the name of the file for the illustration logo.
* **form_file_type** (select_one, required): Select the file type of the illustration logo (png or Other).
* **form_date** (date, required): Enter the date the illustration logo was created.
* **form_time** (time, required): Enter the time the illustration logo was created.
* **form_note** (note, optional): Provide any additional notes about the illustration logo.
* **form_email** (email, optional): Enter a contact email for the illustration logo (if applicable).
* **form_phone** (text, optional): Enter a phone number for the illustration logo (if applicable).
