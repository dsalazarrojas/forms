# Ticket Purchase Form With Skrill - Help Guide
## Purpose
The Ticket Purchase Form With Skrill is designed to facilitate secure online ticket purchases through the Skrill payment gateway. This form guides users through the entire ticket purchasing process, ensuring a seamless and secure transaction experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each page of the form, which includes:
	* Page 1: Select the ticket options (ticket_purchase_form_with_skrill_1).
	* Page 2: Enter the event ID and ticket price (event_id, ticket_price).
	* Page 3: Choose the quantity of tickets to purchase (quantity).
	* Page 4: Review and confirm your purchase before submitting.

## Field-by-Field Explanation

* **Ticket Options (ticket_purchase_form_with_skrill_1)** (`ticket_purchase_form_with_skrill_1`, Number, Not Required)
	+ This field allows you to select the ticket options you'd like to purchase.
* **Event ID (event_id, Select Multiple, Not Required)** 
	+ Enter the ID of the event for which you'd like to purchase tickets.
* **Ticket Price (ticket_price, Number, Not Required)** 
	+ Enter the price of the tickets you'd like to purchase.
* **Quantity (quantity, Number, Not Required)** 
	+ Select the number of tickets you'd like to purchase.
* **Purchase Button (purchase_button, Note, Not Required)** 
	+ This is a non-editable field to confirm that you have read and understood the terms.
* **Success Message (success_message, Text, Not Required)** 
	+ This field will display a success message after a successful purchase.
* **Error Message (error_message, Text, Not Required)** 
	+ This field will display an error message in case of a failed purchase.

## Tips

* Make sure to fill out each page of the form accurately to avoid errors in the purchasing process.
* If you encounter any errors during the purchase process, check the error message field for more information.
* After a successful purchase, review the success message to confirm the transaction details.
