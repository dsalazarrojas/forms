# E Commerce SEO Change Request Form - Help Guide
## Purpose
This form is intended for E Commerce SEO change requests. It's designed to help authorized personnel track and manage these requests effectively.

## How To Complete This Form
1.  Select "Submit Request" to indicate the number of requests you wish to submit.
2.  Enter a brief description of the change request in the "Description" field.
3.  Provide relevant keywords related to the change request in the "Keyword" field.
4.  Enter the URL(s) affected by the change in the "URL" field.
5.  Specify the category of the change request in the "Category" field.
6.  Assign a priority level to the request in the "Priority" field (if applicable).
7.  Select the status of the request in the "Status" field.

## Field-by-Field Explanation

*   **Submit Request**: This field allows you to select how many requests you want to submit. You can choose from "Yes", "No" options.
*   **Description**: Enter a clear and concise description of the change request. This field is optional, but providing a description helps in understanding the request accurately.
*   **Keyword**: In this field, provide relevant keywords related to the change request. This helps in efficiently searching for the request.
*   **URL**: Enter the URL(s) affected by the change request. This field is crucial for identifying the specific URL(s) that need to be modified.
*   **Category**: Choose the category of the change request from the available options. This helps in filtering and prioritizing requests based on category.
*   **Priority**: Assign a priority level to the request from 1-5, with 1 being the highest priority. This helps in deciding the order and urgency of the requests.
*   **Status**: Select the status of the request as "Active" or "Inactive". This field is optional and helps in tracking the progress of the requests.

## Tips
*   Be as specific as possible when describing the change request in the "Description" field.
*   Ensure that the "URL" field is accurate to identify the correct URL(s) affected.
*   Assign the correct "Priority" level based on the request's urgency.
*   Clearly select the "Status" of the request to avoid confusion and facilitate tracking.
*   If submitting multiple requests, make sure to fill out each field accordingly for each request.
