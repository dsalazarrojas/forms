# e_commerce_platform_integration_order_form - Help Guide
## Purpose
This form is designed to collect information for e-commerce platform integration. It helps our development team understand the requirements and preferences of the users.

## How To Complete This Form
To complete this form, follow these steps:
1. Provide the necessary details about the e-commerce platform you want to integrate with our system.
2. Choose the integration method you prefer (API, SDK, Custom Code, or API and SDK).
3. Enter the Platform ID and Platform Name for the selected platform.
4. Enter the Platform URL.
5. Add any integration notes that may be helpful for our development team.
6. Enter the API Key and API Key Type (Public, Private, or Server-to-Server).
7. Enter additional information about the API Key.
8. Select the integration status (Completed, Pending, or Failed).
9. Choose the Time Zone.
10. Enter the Time Zone Offset.
11. Optionally, enter a custom Time Zone Name.

## Field-by-Field Explanation

* **Platform Details** (`platform_details`, text, optional): Enter a brief description of the e-commerce platform you want to integrate with our system.
* **Integration Method** (`integration_method`, select_one, optional):
	+ API: Select this option if you want to integrate using the API.
	+ SDK: Select this option if you want to integrate using the SDK.
	+ Custom Code: Select this option if you want to integrate using custom code.
	+ API and SDK: Select this option if you want to integrate using both API and SDK.
* **Platform ID** (`platform_id`, text, optional): Enter the unique ID of the e-commerce platform.
* **Platform Name** (`platform_name`, text, optional): Enter the name of the e-commerce platform.
* **Platform URL** (`platform_url`, text, optional): Enter the URL of the e-commerce platform.
* **Integration Notes** (`integration_notes`, text, optional): Add any additional notes about the integration.
* **API Key** (`api_key`, text, optional): Enter the API key for the e-commerce platform.
* **API Key Type** (`api_key_type`, select_one, optional):
	+ Public: Select this option if the API key is public.
	+ Private: Select this option if the API key is private.
	+ Server-to-Server: Select this option if the API key is server-to-server.
* **API Key Info** (`api_key_info`, text, optional): Enter additional information about the API key.
* **Integration Status** (`integration_status`, select_one, optional):
	+ Completed: Select this option if the integration is completed.
	+ Pending: Select this option if the integration is pending.
	+ Failed: Select this option if the integration failed.
* **Integration Date** (`integration_date`, date, optional): Enter the date of the integration.
* **Time Zone** (`time_zone`, select_one, optional):
	+ UTC: Select this option if the time zone is UTC.
	+ EST: Select this option if the time zone is EST.
	+ EST5EDT: Select this option if the time zone is EST5EDT.
	+ CST: Select this option if the time zone is CST.
	+ PST: Select this option if the time zone is PST.
* **Time Zone Offset** (`timezone_offset`, text, optional): Enter the offset for the time zone.
* **Time Zone Name** (`timezone_name`, text, optional): Enter a custom name for the time zone.

## Tips
- Be sure to double-check your entries for accuracy and consistency.
- If you're unsure about any field, please ask our support team for clarification.
- You can always reach out to us if you have further questions or need assistance.
