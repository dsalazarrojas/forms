# online_purchase_information_collection_form - Help Guide
## Purpose
This form is for collecting additional information required to fulfill an online purchase. Fill this form only if we don't have all the necessary information in our records for the customer.

## How To Complete This Form
To fill this form, please follow these steps:
- Fill out the form completely.
- Be truthful and accurate in your entries.

## Field-by-Field Explanation
- **Customer Details** (Customer Details, text, required): Enter the customer's name and any other identifying information we don't have.
- **Contact Info** (Contact Info, text, required): Enter the customer's email address and phone number so we can contact them.
- **Shipping Details** (Shipping Details, text, required): Enter the customer's shipping address so we can send the order.
- **Order Info** (Order Info, text, required): Enter details about the order, such as the product or products purchased.
- **Delivery Preferences** (Delivery Preferences, text, required): Choose the desired delivery date and time for the order.
- **Customer Notes** (Customer Notes, text, required): Enter any additional information about the customer or order that we should know.
- **Shipping Notes** (Shipping Notes, text, required): Enter any additional information about the shipment or delivery.
- **Order Notes** (Order Notes, text, required): Enter any additional information about the order that we should know.
- **Customer Email** (Customer Email, email, required): Enter the customer's email address so we can contact them.
- **Customer Phone** (Customer Phone, text, required): Enter the customer's phone number so we can contact them for any issues with the order.

## Tips
- Double check your entries for accuracy before submitting the form.
- If you're unsure about any information, please contact us for clarification.
- This form is for collecting information only, and we will not be able to fulfill the order until we receive all required information.
