# Image Order Form - Help Guide
## Purpose
The Image Order Form is used to collect information about an image order, including order date, customer details, photo specifics, and delivery options.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have reviewed and understood the order details provided by the customer.
2. Select the correct options for each field as required, taking into account the specifications of the ordered image product.
3. Fill in the customer's details accurately and completely.
4. Select the desired delivery options for the image product.
5. Enter any additional order notes if necessary.
