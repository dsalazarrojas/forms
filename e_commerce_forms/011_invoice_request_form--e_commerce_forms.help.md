# Invoice Request Form - Help Guide
## Purpose
The Invoice Request Form is used to submit a request for an invoice, ensuring that you receive accurate and timely payment. To fill out this form correctly, please follow the instructions below.

## How To Complete This Form
1. Ensure you are authorized to request an invoice.
2. Gather all necessary information required for the form.
3. Complete each section as instructed below:

## Field-by-Field Explanation

* **User Info**: This field is used to identify you as the user requesting the invoice.
* **Contact Information**: Enter your contact information so that we can reach out to you if needed.
* **Order Details**: Provide details about the order you wish to invoice, including any relevant dates and times.
* **Payment Details**: Enter payment information to help us process your payment efficiently.
* **Delivery Option**: Select the desired delivery option from the drop-down menu.
* **Payment Method**: Choose the payment method you prefer from the drop-down menu.
* **Delivery Time**: Enter the desired delivery time.
* **Delivery Date**: Enter the desired delivery date.
* **Note**: This field is optional and can be used to add any additional comments or notes about the order.
* **Email**: Enter your email address so that we can contact you via email.
* **Phone**: Enter your phone number so that we can contact you via phone.
* **File**: Upload any relevant files related to the order.
* **Upload File**: Upload any files required for the order.
* **Date**: Enter the date for the order.
* **Time**: Enter the time for the order.
* **Time Period**: Select the time period for the order.
* **Select One**: Select one option from the drop-down menu.
* **Select Multiple**: Select multiple options from the drop-down menu.
* **Email Client**: Enter the email address of the client.
* **Phone Client**: Enter the phone number of the client.
* **File Client**: Upload any files related to the client.
* **Upload File Client**: Upload any files required for the client.
* **Select Multiple Client**: Select multiple options from the drop-down menu for the client.
* **Decimal**: Enter a decimal value (e.g., a price or percentage).
* **Integer**: Enter an integer value (e.g., a quantity).

## Tips
* Double-check all fields for accuracy before submitting the form.
* Make sure to upload any required files before submitting the form.
* If you are unsure about any field, contact us and we will be happy to assist.
