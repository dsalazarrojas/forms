# Landing Page Build Request Form Template - Help Guide
## Purpose
This form is used to request a landing page build from our team. It is essential to provide accurate and complete information to ensure that the project requirements are met.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project title and details in the "Build Request" field.
2. Provide client details in the "Client Details" field.
3. Enter project details, including the target audience, build deadline, and build budget, in the "Project Details" field.
4. Select the project type, status, and priority in the "Project Type", "Project Status", and "Project Priority" fields, respectively.
5. Provide client feedback and any additional comments in the "Client Feedback" and "Project Comments" fields, respectively.
6. Finally, submit the form to request the landing page build.

## Field-by-Field Explanation
* **Build Request** (`build_request`, text, **required**): Enter a brief description of the project.
* **Client Details** (`client_details`, text, **required**): Enter the client's name, contact information, and any other relevant details.
* **Project Details** (`project_details`, text, **required**): Enter a detailed description of the project, including the target audience and build deadline.
* **Project Description** (`project_description`, text, **required**): Enter a detailed description of the project.
* **Target Audience** (`target_audience`, text, **required**): Enter the target audience for the project.
* **Build Deadline** (`build_deadline`, number, **required**): Enter the build deadline in the format `YYYY-MM-DD`.
* **Build Budget** (`build_budget`, number, **required**): Enter the build budget.
* **Project Manager** (`project_manager`, text, **required**): Enter the project manager's name and contact information.
* **Client Manager** (`client_manager`, text, **required**): Enter the client manager's name and contact information.
* **Project Team** (`project_team`, text, **required**): Enter the project team members.
* **Project Type** (`project_type`, select_one, **required**): Select the project type from the options provided.
* **Project Status** (`project_status`, select_one, **required**): Select the project status from the options provided.
* **Project Priority** (`project_priority`, select_one, **required**): Select the project priority from the options provided.
* **Client Feedback** (`client_feedback`, text, **required**): Enter any feedback or comments from the client.
* **Project Comments** (`project_comments`, text, **optional**): Enter any additional comments or notes about the project.
* **Technical Requirements** (`technical_requirements`, text, **optional**): Enter any technical requirements or notes about the project.
* **Build Request Comments** (`build_request_comments`, text, **optional**): Enter any comments or notes about the build request.
* **Build Request Additional Comments** (`build_request_additional_comments`, text, **optional**): Enter any additional comments or notes about the build request.
* **Date Completed** (`date_completed`, date, **optional**): Enter the date the project was completed.
* **Build Completed Status** (`build_completed_status`, select_one, **optional**): Select the build completed status from the options provided.
* **Build Status** (`build_status`, select_one, **optional**): Select the build status from the options provided.
* **Build Comments** (`build_comments`, text, **optional**): Enter any build comments or notes.
* **Technical Comments** (`technical_comments`, text, **optional**): Enter any technical comments or notes.
* **Project Status Comments** (`project_status_comments`, text, **optional**): Enter any project status comments or notes.
* **Build Request Status** (`build_request_status`, select_one, **optional**): Select the build request status from the options provided.

## Tips
* Please make sure to fill in all the required fields accurately and thoroughly.
* If you have any additional comments or notes, please use the relevant fields to provide them.
* If you are unsure about any field, please contact the project manager or client manager for clarification.
* Before submitting the form, review it carefully to ensure that all the information is accurate and complete.
* If you have already submitted this form for the same project, please do not submit again to avoid duplicate entries.
