# hospital_playlist_form - Help Guide
## Purpose
The hospital_playlist_form is designed to be used in a hospital setting to create a playlist for a hospital's music program.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the playlist in the "Hospital Playlist" field.
2. Select one or more songs from the "Song" field.
3. Enter any relevant information for the selected artist(s) in the "Artist" field.

## Field-by-Field Explanation
* **Hospital Playlist** (`hospital_playlist`, text, **optional**):
	+ Enter a title for the playlist.
* **Song** (`song`, select_one, **optional**):
	+ Select one or more songs from the available options.
* **Artist** (`artist`, text, **optional**):
	+ Enter any relevant information for the selected artist(s).

## Tips
* Make sure to enter a descriptive title for the playlist.
* Choose a song that is relevant to the playlist's purpose.
* Be as specific as possible when entering information for the selected artist(s).
