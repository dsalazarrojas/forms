# ec_opp - Help Guide
## Purpose
This form is used to record details about electronic commerce opportunities, including title, name, description, date, time, categorization, status, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the electronic commerce opportunity in the `ec_opp_form` field.
2. Provide a brief description of the opportunity in the `ec_opp_name` field.
3. If applicable, select the `ec_opp_date` and `ec_opp_time` fields to indicate when the opportunity was or will be available.
4. Choose the relevant category for the opportunity using the `ec_opp_category` field.
5. Select any additional categories that apply using the `ec_opp_category_options` field.
6. Choose the current status of the opportunity using the `ec_opp_status` field.
7. Select any additional statuses that apply using the `ec_opp_status_options` field.
8. Enter any relevant notes about the opportunity in the `ec_opp_note` field.
9. Provide contact information, including email address in the `ec_opp_email` field, and phone number in the `ec_opp_phone` field.

## Field-by-Field Explanation
* **ec_opp_form** (`ec_opp_form`, text, optional): Enter a brief title for the electronic commerce opportunity.
* **ec_opp_name** (`ec_opp_name`, text, optional): Provide a brief description of the opportunity.
* **ec_opp_description** (`ec_opp_description`, text, optional): Enter a detailed description of the opportunity.
* **ec_opp_date** (`ec_opp_date`, date, optional): If applicable, select the date when the opportunity was or will be available.
* **ec_opp_time** (`ec_opp_time`, time, optional): If applicable, select the time when the opportunity was or will be available.
* **ec_opp_category** (`ec_opp_category`, select_one, optional): Choose the main category for the opportunity.
* **ec_opp_category_options** (`ec_opp_category_options`, select_multiple, optional): Select any additional categories that apply.
* **ec_opp_status** (`ec_opp_status`, select_one, optional): Choose the current status of the opportunity.
* **ec_opp_status_options** (`ec_opp_status_options`, select_multiple, optional): Select any additional statuses that apply.
* **ec_opp_note** (`ec_opp_note`, note, optional): Enter any relevant notes about the opportunity.
* **ec_opp_email** (`ec_opp_email`, email, optional): Enter the contact email address.
* **ec_opp_phone** (`ec_opp_phone`, text, optional): Enter the contact phone number.
