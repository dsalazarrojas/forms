# Holiday Furniture Offer Form - Help Guide
## Purpose
This form is used to create and manage holiday-specific offers for furniture products.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your customer ID (customer id).
2. Provide the name of the person or team member responsible for this offer.
3. Indicate if this offer is a holiday offer (yes/no).
4. Enter a brief description of the offer.
5. Select the ID of the item you want to offer a discount on.
6. Specify the quantity of the item you want to offer at the discounted price.
7. Enter the unit price of the item.
8. Enter the discount percentage for this offer.
9. Define the start date of the offer.
10. Define the end date of the offer.
11. Provide the name of the item to be offered.
11. Enter the description of the item to be offered.

## Field-by-Field Explanation
* **Customer ID (customer id)**: Enter your customer ID to associate this offer with your account.
* **Name (name)**: Enter the name of the person or team member responsible for this offer.
* **Offer Type (offer type)**: Select 'Yes' if this is a holiday offer, 'No' otherwise.
* **Offer Details (offer details)**: Enter a brief description of the offer.
* **Item ID (item id)**: Select the ID of the item you want to offer a discount on.
* **Quantity (quantity)**: Enter the quantity of the item you want to offer at the discounted price.
* **Unit Price (unit price)**: Enter the price of the item at which you want to offer it.
* **Discount Percentage (discount percentage)**: Enter the discount percentage for this offer.
* **Start Date (start date)**: Enter the start date of the offer.
* **End Date (end date)**: Enter the end date of the offer.
* **Item Name (item name)**: Enter the name of the item to be offered.
* **Item Description (item description)**: Enter a description of the item to be offered.

## Tips
* Make sure to enter accurate and up-to-date information for a successful offer.
* Double-check the item ID to ensure the correct item is selected.
* The start and end dates should be in a format that can be easily parsed by the system.
