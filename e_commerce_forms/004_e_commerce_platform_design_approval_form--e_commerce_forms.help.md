# E Commerce Platform Design Approval Form - Help Guide
## Purpose
This form is used to review and approve E Commerce Platform designs. It is used to gather information about the platform's features, platform URL, designer's name and contact details, and platform status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field as requested. The form is divided into two pages, so make sure to complete both pages.
2. For the platform features, select one or more features from the dropdown menu that apply to the platform.
3. Enter the platform's URL and designer's name, email, and phone number in the respective fields.
4. Add any additional feedback or comments about the platform in the "Feedback" field.
5. Select the status of the platform from the dropdown menu.
6. Finally, select the desired action for the form submission: "Submit", "Save as Draft", or "Cancel".

## Field-by-Field Explanation
* **Platform Design** (`platform_design`, text, optional): This field is used to describe the platform's design.
* **Description of E Commerce Platform** (`description_of_e_commerce_platform`, text, optional): This field is used to provide a brief description of the platform.
* **Features of Platform** (`platform_features`, select_one, optional): This field is used to select one or more features that apply to the platform. Features include:
	+ Feature A
	+ Feature B
	+ Feature C
* **URL of E Commerce Platform** (`platform_url`, text, optional): This field is used to enter the platform's URL.
* **Name** (`name`, text, optional): This field is used to enter the designer's name.
* **Email** (`email`, email, optional): This field is used to enter the designer's email address.
* **Phone** (`phone`, text, optional): This field is used to enter the designer's phone number.
* **Feedback** (`feedback`, note, optional): This field is used to add any additional feedback or comments about the platform.
* **Status of Platform** (`platform_status`, select_one, optional): This field is used to select the platform's status. Options include:
	+ Approved
	+ Rejected
	+ In Progress
* **Submit** (`submit`, select_multiple, optional): This field is used to select the desired action for the form submission. Options include:
	+ Submit
	+ Save as Draft
	+ Cancel
* **Comments** (`comments`, text, optional): This field is used to add any additional comments about the platform.
