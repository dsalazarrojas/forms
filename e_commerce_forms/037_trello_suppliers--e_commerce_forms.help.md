# Trello Suppliers - Help Guide
## Purpose
This form is used to collect information about Trello suppliers, likely for purchasing or inventory management purposes. The form helps users gather and organize data about Trello suppliers.

## How To Complete This Form
1. Click on "Submit" to begin.
2. Fill in the required field "Name".
3. Enter the supplier's "Email" for contact purposes.
4. Optionally, provide the "Address" of the supplier.
5. Select whether the supplier is of "Supplier type" or not.
6. If applicable, input the "Supplier name" for reference.
7. If the supplier has a website, input the "Supplier website".
8. Review and submit the form.

## Field-by-Field Explanation
* **Name** (required): This is the name of the supplier. Please input their name here.
* **Email** (required): Enter the supplier's email address here. This will be useful for contact purposes.
* **Address**: This field is for optional use. If the supplier has an address, please input it here.
* **Supplier type**: This field determines whether the supplier is of the type that we work with or not. Please select "Yes" or "No" accordingly.
* **Supplier name**: If you have a reference or specific name for this supplier, please input it here.
* **Supplier website**: If the supplier has a website, please input the URL here.
* **Supplier website**: This field is not actually used in the form.
