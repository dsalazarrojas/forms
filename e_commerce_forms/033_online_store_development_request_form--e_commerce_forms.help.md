# online_store_development_request_form - Help Guide
## Purpose
This form is designed to collect information from customers or clients who are interested in online store development.

## How To Complete This Form
To complete this form, please provide the following information:

1. Fill in your **Business Name**, which should be the name of your company or business.
2. Enter your **Contact Name**, which should be the name of the person we will be contacting for further discussion.
3. Provide your **Email** address for us to contact you.
4. Describe your project in **Description** field, providing a brief summary of the project.
5. If you have a **Website**, please provide it.
6. Answer **Yes/No** to whether you would like to use **Ecommerce Platform**.
7. Answer **Yes/No** to the **Business Type** question.
8. Answer **Yes/No** to the **Project Type** question.
9. If you have a specific **Project Goal**, provide it.
10. If you have a **Project Deadline**, provide it.
11. If you have any **Additional Info**, please provide it.
12. If you have a **Business Location**, provide it.
13. Answer **Active/Inactive** to the **Project Status** question.
14. If you would like to assign your project to a specific person, provide their name in the **Assigned To** field.
15. If you have any **Chat Log**, provide it.
16. If you have information about who created this project, provide it in the **Created By** field.
17. If you have a **Created At** timestamp, provide it.
18. If you have an **Updated At** timestamp, provide it.
19. If you have information about who updated this project, provide their name in the **Updated By** field.
20. If you have any **Notes**, provide it.
21. If you have any **Comments**, provide them.
22. If you have any **Tags**, provide them.
23. If you have a timestamp of when this project was created, provide it.
24. If you have a timestamp of when this project was last updated, provide it.
25. If you know when this project was **Submitted At**, provide it.

## Field-by-Field Explanation

* **Business Name** (1, Text, Required): This field is where you should enter the name of your business or company.
* **Contact Name** (2, Text, Required): This field is where you should enter the name of the person we will contact for further discussion.
* **Email** (3, Email, Required): This field is where you should enter your email address.
* **Description** (4, Text, Required): This field is where you should provide a brief description of your project.
* **Website** (5, Text, Optional): This field is where you should enter your website address.
* **Ecommerce Platform** (6, Select One, Required): This field is where you should answer Yes or No to whether you would like to use an ecommerce platform.
* **Business Type** (7, Select Multiple, Required): This field is where you should answer Yes or No to the question of what type of business you are.
* **Project Type** (8, Select One, Required): This field is where you should answer Yes or No to the question of what type of project you have in mind.
* **Project Goal** (9, Text, Optional): This field is where you can provide a specific project goal.
* **Project Deadline** (10, Date, Optional): This field is where you can provide a deadline for the project.
* **Additional Info** (11, Text, Optional): This field is where you can provide any additional information that might be helpful.
* **Business Location** (12, Text, Optional): This field is where you can provide the location of your business.
* **Project Status** (13, Select One, Optional): This field is where you can answer Active or Inactive to the project status.
* **Assigned To** (14, Text, Optional): This field is where you can assign your project to a specific person.
* **Chat Log** (15, Text, Optional): This field is where you can provide any chat log related to your project.
* **Created By** (16, Text, Optional): This field is where you can provide information about who created this project.
* **Created At** (17, Date, Optional): This field is where you can provide a timestamp of when this project was created.
* **Updated At** (18, Date, Optional): This field is where you can provide a timestamp of when this project was last updated.
* **Updated By** (19, Text, Optional): This field is where you can provide information about who updated this project.
* **Notes** (20, Text, Optional): This field is where you can provide any notes about your project.
* **Comments** (21, Text, Optional): This field is where you can provide any comments about your project.
* **Tags** (22, Text, Optional): This field is where you can provide any tags related to your project.
* **Created At Timestamp** (23, Date, Optional): This field is where you can provide a timestamp of when this project was created.
* **Updated At Timestamp** (24, Date, Optional): This field is where you can provide a timestamp of when this project was last updated.
* **Submitted At** (25, Date, Optional): This field is where you can provide a timestamp of when this project was submitted.

## Tips
Please make sure to fill out all the required fields (indicated by *) to ensure a successful submission. If you have any questions or concerns, please don't hesitate to contact us.
