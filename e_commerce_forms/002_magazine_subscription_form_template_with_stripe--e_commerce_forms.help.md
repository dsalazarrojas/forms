# Magazine Subscription Form Template With Stripe - Help Guide
## Purpose
This form is designed for users who wish to subscribe to a magazine using Stripe. It collects necessary information to process a successful subscription and payment.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired subscription plan from the options provided.
2. Choose whether or not to subscribe for one or more periods (if applicable).
3. Enter the payment amount (if applicable).
4. Choose whether or not to select a payment type (if applicable).
5. Choose whether or not to select a payment method (if applicable).
6. Select the current payment status (if applicable).
7. Enter the Stripe token (if provided).
8. Enter a payment message (if required).
9. Enter a payment refund amount (if applicable).

## Field-by-Field Explanation

* **subscription_plan**: This field allows you to select the desired subscription plan. Choose from options like Free, Basic, and Premium.
* **subscription_period**: Select whether or not to subscribe for one or more periods. If you select 'Yes', you can choose from a list of periods.
* **payment_amount**: Enter the amount of payment if you've chosen to pay. Please ensure you enter the amount correctly.
* **payment_type**: Choose whether or not to select a payment type. If you select 'Yes', you'll have to select a payment type from the options provided.
* **payment_method**: Choose whether or not to select a payment method. If you select 'Yes', you'll have to choose a payment method from the options provided.
* **payment_status**: Select the current payment status, which can be Active or Inactive.
* **stripe_token**: This field is for the Stripe token. Only enter this if you've been provided with one.
* **payment_message**: Enter a message related to the payment if required.
* **payment_refund**: Enter the refund amount if necessary. Please enter it correctly.
* **payment_date**: This field is currently not used. Please don't fill it in for now.

Note: If you encounter any issues while filling in the form, please contact your subscription administrator for assistance.
