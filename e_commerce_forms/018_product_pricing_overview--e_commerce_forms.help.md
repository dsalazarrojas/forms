# Product Pricing Overview - Help Guide
## Purpose
The Product Pricing Overview form is used to collect and display information about a product's pricing details. This includes its name, price, promotional dates, and other attributes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Product Name** (Field 7) - This field is used to enter the product's name.
2. Enter the **Price Cents** (Field 2) - This field is used to enter the product's price in cents.
3. Select the **Price Currency** (Field 3) - This field is used to select the price currency.
4. Enter the **Promo Start Date** (Field 4) - This field is used to enter the start date of the promotion.
5. Enter the **Promo End Date** (Field 5) - This field is used to enter the end date of the promotion.
6. Enter the **Competitive Price** (Field 6) - This field is used to enter the competitive price.
7. Enter the **Product Description** (Field 7) - This field is used to enter a brief description of the product.
8. Upload a **Product Image** (Field 8) - This field is used to upload an image of the product.
9. Enter the **Product URL** (Field 9) - This field is used to enter the product's URL.
10. Enter the **Product Tags** (Field 10) - This field is used to enter tags or keywords related to the product.
11. Select the **Competitive Price Tier** (Field 11) - This field is used to select whether the product has a competitive price.
12. Select the **Price Update Frequency** (Field 12) - This field is used to select how often the price is updated.
13. Select the **Product Status** (Field 13) - This field is used to select the product's status.
14. Select whether the product has **Price Tiers** (Field 14) - This field is used to select whether the product has price tiers.
15. Select the **Competitive Price Tiers** (Field 15) - This field is used to select whether the product has competitive price tiers.
16. Select the **Price Currency Tiers** (Field 16) - This field is used to select whether the product has price currency tiers.
17. Select the **Product Tags Tier** (Field 17) - This field is used to select whether the product has product tags tier.

* **Competitive Price** (`competitive_price`): Enter the competitive price of the product.
* **Product Description** (`product_description`): Enter a brief description of the product.
* **Product Image** (`product_image`): Upload an image of the product.
* **Product URL** (`product_url`): Enter the URL of the product.
* **Product Tags** (`product_tags`): Enter tags or keywords related to the product.
* **Competitive Price Tier** (`competitive_price_tier`): Select whether the product has a competitive price.
* **Price Update Frequency** (`price_update_frequency`): Select how often the price is updated.
* **Product Status** (`product_status`): Select the product's status.
* **Price Tiers** (`price_tiers`): Select whether the product has price tiers.
* **Competitive Price Tiers** (`competitive_price_tiers`): Select whether the product has competitive price tiers.
* **Price Currency Tiers** (`price_currency_tiers`): Select whether the product has price currency tiers.
