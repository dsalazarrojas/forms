# export_batch_order_form - Help Guide
## Purpose

The export_batch_order_form is used to create a new export batch, which is a collection of orders that will be exported to the customer.

## How To Complete This Form

1. Select the `Business Unit` to which the export batch will belong.
   - Please select the relevant business unit from the available options.

2. Select the `Order Type`.
   - Choose whether the export batch is a Batch or One-off.

3. Enter the `Batch Size`.
   - Enter the number of orders included in the export batch.

4. Select the `Product Type`.
   - Choose the type of product being exported.

5. Enter the `Customer Name` (optional).
   - If this is not required, you can skip this field.

6. Enter the `Customer Email` (optional).
   - If this is not required, you can skip this field.

7. Enter the `Product Specifications` (optional).
   - If this is not required, you can skip this field.

8. Enter the `Product Details` (optional).
   - If this is not required, you can skip this field.

9. Enter the `Customer Phone` (optional).
   - If this is not required, you can skip this field.

10. Enter the `Customer Address` (optional).
    - If this is not required, you can skip this field.

11. Enter the `Shipping Info` (optional).
    - If this is not required, you can skip this field.

12. Enter the `Special Instructions` (optional).
    - If this is not required, you can skip this field.

13. Enter the `Order Notes` (optional).
    - If this is not required, you can skip this field.

14. Select the `Business Unit 2` (optional).
    - If this is not required, you can skip this field.

15. Select the `Order Type 2`.
    - Choose whether the export batch is a Batch or One-off.

16. Select the `Product Type 2`.
    - Choose the type of product being exported.

17. Enter the `Customer Name 2` (optional).
    - If this is not required, you can skip this field.

18. Enter the `Customer Phone 2` (optional).
    - If this is not required, you can skip this field.

19. Enter the `Shipping Info 2` (optional).
    - If this is not required, you can skip this field.

20. Enter the `Special Instructions 2` (optional).
    - If this is not required, you can skip this field.

21. Enter the `Order Notes 2` (optional).
    - If this is not required, you can skip this field.

22. Select the `Business Unit 3` (optional).
    - If this is not required, you can skip this field.

23. Select the `Order Type 3`.
    - Choose whether the export batch is a Batch or One-off.

24. Select the `Product Type 3`.
    - Choose the type of product being exported.

25. Enter the `Customer Name 3` (optional).
