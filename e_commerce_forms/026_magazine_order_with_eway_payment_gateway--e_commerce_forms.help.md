# Magazine Order With Eway Payment Gateway - Help Guide
## Purpose
The Magazine Order With Eway Payment Gateway form is designed to enable users to easily place a magazine order using the Eway Payment Gateway. This form simplifies the ordering process, providing a user-friendly interface for users to input their details and complete the transaction.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Magazine Order Form" section.
2. Fill in the "Payment Details" field, making sure to provide the required information.
3. Review your input before clicking the "Submit" button.

## Field-by-Field Explanation
* **Magazine Order Form** (magazine_order, text, optional):
	+ This field is where you can input your magazine order information.
	+ Please provide a clear and concise description of your order.
* **Payment Details** (payment_details, text, required):
	+ This field is where you input the payment details for your order.
	+ Please make sure to include the required payment information to complete the transaction.
* **Submit** (submit, text, optional):
	+ This field is the final step to submit your order.
	+ Clicking this button will complete the ordering process.
