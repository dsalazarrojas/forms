# Order Replacement Coordination Contact Form - Help Guide
## Purpose
The purpose of this form is to allow customers to contact the customer support team for order replacement coordination. This form is used to gather necessary information for the support team to assist with the replacement process.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your first name in the field provided.
2. Enter your email address in the field provided. Please ensure it is a valid email address.
3. If you wish to be contacted, please enter your phone number in the field provided.
4. Select the status of the order you are inquiring about from the options provided.
5. Enter the order ID if known, or leave it blank if you do not have it.

## Field-by-Field Explanation
* **First Name** (`name`, `text`, **required**): Please enter your first name in this field.
* **Email** (`email`, `email`, **required**): Enter your email address in this format: `username@domain.com`. Ensure you can receive emails at this address.
* **Phone** (`phone`, `text`, **optional**): If you would like to be contacted via phone, please enter your phone number in this field.
* **Order Status** (`order_status`, `select_multiple`, **required**): Choose from the following options:
	+ Pending: Order has not been processed or delivered yet.
	+ Processing: Order is in progress and expected to be delivered soon.
	+ Cancelled: Order has been cancelled and is no longer active.
	+ Delivered: Order has been successfully delivered to the customer.
* **Order ID** (`order_id`, `text`, **optional**): If you know your order number, please enter it here. If not, you can leave it blank and provide it separately.
