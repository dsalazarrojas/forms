# pod_submission_form - Help Guide
## Purpose
This form is used to collect product information for production purposes.

## How To Complete This Form
1. Ensure that you have all the required information about the product before starting the form.
2. Fill out the form with accurate and complete information.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Product name** (`product_name`, `text`, required: false): Enter the name of the product being submitted for production.
* **Product description** (`product_description`, `text`, required: false): Provide a brief description of the product.
* **Product image** (`product_image`, `text`, required: false): Enter a URL or file link to a product image.
* **Quantity** (`quantity`, `number`, required: false): Enter the quantity of the product being submitted.
* **Usage confirmation** (`usage_confirmation`, `select_one`, required: false): Confirm if the product is for usage or not.
* **File 1** (`file_1`, `text`, required: false): Enter any additional file information about the product.
* **File 2** (`file_2`, `text`, required: false): Enter any additional file information about the product.
* **File 3** (`file_3`, `text`, required: false): Enter any additional file information about the product.
* **File 4** (`file_4`, `text`, required: false): Enter any additional file information about the product.
* **Usage confirmation 2** (`usage_confirmation_2`, `select_one`, required: false): Confirm if the product is for usage or not.
* **Quantity 2** (`quantity_2`, `number`, required: false): Enter the quantity of the product being submitted.
* **Product price** (`product_price`, `number`, required: false): Enter the price of the product.
* **Design type** (`design_type`, `select_multiple`, required: false): Select the type of design for the product.
* **Product type** (`product_type`, `select_multiple`, required: false): Select the type of product being submitted.
* **Production date** (`production_date`, `date`, required: false): Enter the date of production.
* **Production time** (`production_time`, `time`, required: false): Enter the time of production.
* **Production time zone** (`production_time_zone`, `select_one`, required: false): Select the time zone of production.
* **Notes** (`notes`, `note`, required: false): Enter any additional notes about the product.
* **Email** (`email`, `email`, required: false): Enter the email address of the person submitting the product.
* **Phone** (`phone`, `text`, required: false): Enter the phone number of the person submitting the product.
* **Product category** (`product_category`, `select_multiple`, required: false): Select the category of the product.
* **Production method** (`production_method`, `select_multiple`, required: false): Select the method of production.
* **Product status** (`product_status`, `select_multiple`, required: false): Select the status of the product.
* **Usage status** (`usage_status`, `select_multiple`, required: false): Select the usage status of the product.
* **File 5** (`file_5`, `text`, required: false): Enter any additional file information about the product.

## Tips
1. Make sure to review the form carefully before submitting.
2. Ensure that all required fields are filled out.
3. Enter accurate and complete information about the product.
