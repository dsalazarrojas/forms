# Clothing Item Search Form - Help Guide
## Purpose
The Clothing Item Search Form is designed to help customers quickly and easily provide us with their preferences for a specific clothing item search.

## How To Complete This Form
1. **Fill out the form completely and accurately**. This will help us serve you better.
2. **Make sure to provide your real email address** so that we can contact you to confirm your search details.
3. **Select your preferred clothing category, item type, style, and size** from the provided options.
4. **Choose your budget range and occasion** for the clothing item you are looking for.
5. **Don't forget to add any additional notes or special requirements**.

## Field-by-Field Explanation
* **Your Name** (`customer_name`, text, required): Please enter your name as you would like to be addressed.
* **Email Address** (`email_address`, email, required): This is the email address we will use to contact you about your search details.
* **Phone Number** (`phone_number`, text, optional): If you would like to provide your phone number for recommendations, you can do so here.
* **Clothing Category** (`item_category`, select_one, required): Please select a category that best fits the clothing item you are searching for (e.g., Tops, Bottoms, Dresses, etc.).
* **Specific Item Type** (`specific_item`, text, required): Please provide a specific item type you are looking for (e.g., t-shirt, jeans, blazer, etc.).
* **Style Preference** (`style_preference`, select_multiple, required): Select one or more styles that you prefer for the clothing item (e.g., casual, business, athletic, etc.).
* **Size Needed** (`size`, select_one, required): Please select the size you need for the clothing item.
* **Fit Preference** (`fit_preference`, select_one, optional): If you have a preferred fit, please select it here (e.g., slim fit, regular fit, oversized fit, etc.).
* **Color Preference** (`color_preference`, text, optional): If you have a specific color or colors in mind, please separate them with commas (e.g., red, blue, black, etc.).
* **Pattern Preference** (`pattern_preference`, select_one, optional): Select a pattern or design you prefer for the clothing item (e.g., solid, stripes, plaid, etc.).
* **Material Preference** (`material_preference`, select_multiple, optional): If you have a preferred material or materials, please select them here (e.g., cotton, polyester, wool, etc.).
* **Sleeve Length** (`sleeve_length`, select_one, optional): If you have a preferred sleeve length, please select it here (e.g., sleeveless, short sleeve, long sleeve, etc.).
* **Budget Range - USD** (`budget_range`, select_one, required): Please select a budget range for the clothing item you are looking for.
* **Brand Preference** (`brand_preference`, text, optional): If you have a preferred brand or designer, please enter it here.
* **What is this for?** (`occasion`, select_multiple, required): Please select one or more occasions or uses for the clothing item (e.g., everyday wear, work, special event, etc.).
* **Any special requirements or preferences?** (`special_requirements`, text, optional): If you have any allergen-free, sustainable, or other special requirements, please enter them here.
 
## Tips
* Please fill out the form completely and accurately to help us serve you better.
* If you need to make multiple searches, you can simply fill out the form again.
