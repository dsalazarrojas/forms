# thrivers_society_digital_consultation_template - Help Guide
## Purpose
The **Thrivers Society Digital Consultation Template** is a form designed to collect information from clients for evaluation purposes. This form is intended for internal use by Thrivers Society staff members only.

## How To Complete This Form
- Read the form carefully before starting.
- Ensure you are an authorized staff member of Thrivers Society before using this form.
- Fill out the form with the required information for each field.
- Submit the form after completing it.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `text`, required: false): A brief introduction to the client's salon. This field is optional, but it's recommended to provide a brief description of the salon.
* **Salons Visited** (`salons_visited`, `select_one`, required: false): Check if you visited the salon during your evaluation. If you have not visited, please select "False".
* **Name** (`salons_name`, `text`, required: false): The name of the salon.
* **Address** (`salons_address`, `text`, required: false): The address of the salon.
* **Phone** (`salons_phone`, `text`, required: false): The phone number of the salon.
* **Email** (`salons_email`, `email`, required: false): The email address of the salon.
* **Hours** (`salons_hours`, `time`, required: false): The operating hours of the salon.
* **Rating** (`salons_rating`, `number`, required: false): The rating of the salon, on a scale of 1-5.
* **Comment** (`salons_comment`, `note`, required: false): Any comments or feedback about the salon.
* **Recommend** (`salons_recommendation`, `select_multiple`, required: false): Select "True" if you recommend the salon, and "False" otherwise.
* **Image** (`salons_image`, `text`, required: false): The URL of an image related to the salon.
* **Alt Image** (`salons_image_alt`, `text`, required: false): The alt text for the image.
* **Alt Image 2** (`salons_image_alt_2`, `text`, required: false): Another alt text for the image.

Please note that the fields marked as "required: false" are optional, but it's highly recommended to fill them out for accurate evaluation. 

Also, remember that the "Salons Visited" field should be selected as "True" only if you have physically visited the salon. 

The "Recommend" field should be selected as "True" only if you truly recommend the salon.
