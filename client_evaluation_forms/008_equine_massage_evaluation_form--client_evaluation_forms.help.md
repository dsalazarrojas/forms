# Equine Massagesession Notes - Help Guide
## Purpose
This form is used to record notes and evaluation outcomes of an equine massage session. It is designed to help therapists and practitioners collect feedback from clients and assess the effectiveness of the massage session. The form is not required, but it is recommended to fill it out for future reference and to help improve the equine massage service.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by writing a brief summary of the equine massage session, including any relevant notes or observations.
2. Check the "Owner Consent" box to indicate that the client has given consent to the massage session.
3. For each evaluation outcome, select all that apply from the options listed.
4. Provide any additional details about the evaluation outcomes in the "Evaluation Outcome Details" field.

## Field-by-Field Explanation

* **Equine Massage Session Notes** (Text, Optional):
	+ This is a text field where you can write a brief summary of the equine massage session, including any relevant notes or observations.
* **Owner Consent** (Text, Required):
	+ This field requires the client to give consent to the massage session. Please ensure that the client signs or initials this field to confirm their consent.
* **Evaluation Outcomes** (Select Multiple, Optional):
	+ This field allows you to select all applicable evaluation outcomes from the options listed.
* **Evaluation Outcome Details** (Text, Optional):
	+ This field is for providing additional details about the evaluation outcomes. Please use this field to provide any specific information or comments about the client's response.
