# Cleaning Staff Feedback Request Form - Help Guide
## Purpose

This form is designed to gather feedback and evaluation from clients about the cleaning staff that provided services to their property.

## How To Complete This Form

- Read the form instructions carefully before starting.
- Make sure to answer all required fields.
- Be as specific as possible when providing feedback.
- Use the provided options as a guide, but feel free to provide additional information if necessary.

## Field-by-Field Explanation

* **Service Date** (id: 2, type: date, required: true): The date the cleaning service was provided.
* **Property Address** (id: 3, type: text, required: true): The address of the property that was cleaned.
* **Type of Cleaning Service** (id: 4, type: select_one, required: true): Select the type of service that was provided (e.g., Regular Cleaning, Deep Cleaning, etc.).
* **Your Name** (id: 6, type: text, required: true): Your name as the person providing feedback.
* **Email Address** (id: 7, type: email, required: true): Your email address for follow-up communication.
* **Your Role** (id: 9, type: select_one, required: true): Your role in relation to the property (e.g., Property Owner, Manager, Supervisor, etc.).
* **Staff Professionalism** (id: 13, type: select_one, required: true): Rate the staff's level of professionalism from Excellent to Poor.
* **Staff Courtesy and Respect** (id: 14, type: select_one, required: true): Rate the staff's level of courtesy and respect from Excellent to Poor.
* **Communication Skills** (id: 15, type: select_one, required: true): Rate the staff's communication skills from Excellent to Poor.
* **Work Ethic and Diligence** (id: 16, type: select_one, required: true): Rate the staff's work ethic from Excellent to Poor.
* **Attention to Detail** (id: 17, type: select_one, required: true): Rate the staff's attention to detail from Excellent to Poor.
* **Time Management** (id: 18, type: select_one, required: true): Rate the staff's time management from Excellent to Poor.
* **Cleanliness Quality Achieved** (id: 20, type: select_one, required: true): Rate the cleanliness quality achieved from Excellent to Poor.
* **Satisfaction with Specific Areas** (id: 21, type: text, required: false): Rate your satisfaction with different areas of the property (e.g., kitchen, bathroom, etc.).
* **Safety and Compliance** (id: 22, type: select_one, required: false): Rate whether the staff followed safety protocols (e.g., Yes, Fully Compliant, Mostly Compliant, etc.).
* **Were There Any Problems?** (id: 24, type: select_one, required: true): Select if there were any problems with the service provided.
* **Describe the Issues** (id: 25, type: text, required: false): Describe any problems that occurred.
* **Any Property Damage?** (id: 26, type: select_one, required: true): Select if any property damage occurred.
* **Damage Description** (id: 27, type: text, required: false): Describe any property damage that occurred.
* **Cleaning Staff Strengths** (id: 29, type: text, required: false): Describe the strengths of the cleaning staff.
* **Areas for Improvement** (id: 30, type: text, required: false): Suggest areas where the cleaning staff could improve.
* **Would You Request the Same Crew Again?** (id: 31, type: select_one, required: true): Select if you would request the same crew again (e.g., Yes, Definitely, Not Sure, etc.).
* **Overall Satisfaction with Cleaning Staff** (id: 32, type: select_one, required: true): Rate your overall satisfaction with the cleaning staff from Very Satisfied to Very Dissatisfied.
* **Additional Comments** (id: 33, type: text, required: false): Provide any additional feedback or suggestions.
