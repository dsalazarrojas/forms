# Building Design Release Client Feedback Form - Help Guide
## Purpose
The Building Design Release Client Feedback Form is designed to collect client feedback on a building design project, providing valuable input on the quality of the design, functionality, and other aspects. This form helps identify areas of improvement and serves as a basis for future development.

## How To Complete This Form
1. Fill in your name and company name (if applicable).
2. Enter your contact email address and contact number.
3. Specify the date of the feedback.
4. Provide the name of the project.
5. Classify the project type (e.g., New Construction, Renovation, etc.).
6. Select the design phase that was reviewed (e.g., Conceptual Design, Schematic Design, etc.).
7. Enter the release date of the design documents.
8. Rate your overall satisfaction with the design.
9. Rate the design quality, functionality, and aesthetics.
10. Assess the sustainability features, code compliance, budget alignment, and timeline feasibility.
11. Evaluate the communication quality and deliverable quality.
12. Check if any changes were needed and describe them.
13. Mention any concerns or issues.
14. Specify the current approval status.
15. Describe the next steps.
16. State whether you would recommend our services to others.

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, required): Fill in your full name.
* **Company Name** (`company`, text, optional): Enter your company name if applicable.
* **Email Address** (`email`, email, required): Provide your contact email address.
* **Phone Number** (`phone`, text, required): Enter your contact number.
* **Feedback Date** (`feedback_date`, date, required): Specify the date of the feedback.
* **Project Name** (`project_name`, text, required): Provide the name of the project.
* **Project Type** (`project_type`, select_one, required): Classify the project type (e.g., New Construction, Renovation, etc.).
* **Design Phase Released** (`design_phase`, select_one, required): Select the design phase that was reviewed (e.g., Conceptual Design, Schematic Design, etc.).
* **Release Date** (`release_date`, date, required): Enter the release date of the design documents.
* **Overall Satisfaction** (`overall_satisfaction`, select_one, required): Rate your overall satisfaction with the design (e.g., Very Satisfied, Satisfied, etc.).
* **Design Quality** (`design_quality`, select_one, required): Rate the design quality (e.g., Excellent, Good, Average, etc.).
* **Functionality Rating** (`functionality_rating`, select_one, required): Assess the functionality of the design (e.g., Exceeds Expectations, Meets Expectations, etc.).
* **Aesthetics Rating** (`aesthetics_rating`, select_one, required): Evaluate the visual appeal of the design (e.g., Excellent, Good, Average, etc.).
* **Sustainability Features** (`sustainability_features`, select_one, required): Rate the sustainability features (e.g., Excellent, Good, Average, etc.).
* **Code Compliance Confidence** (`code_compliance`, select_one, required): Assess your confidence in code compliance (e.g., Very Confident, Confident, etc.).
* **Budget Alignment** (`budget_alignment`, select_one, required): Check if the design is well within your budget (e.g., Well Within Budget, Within Budget, etc.).
* **Timeline Feasibility** (`timeline_feasibility`, select_one, required): Evaluate the project's feasibility on the timeline (e.g., Very Feasible, Feasible, etc.).
* **Communication Rating** (`communication_rating`, select_one, required): Rate the communication quality (e.g., Excellent, Good, Average, etc.).
* **Deliverable Quality** (`deliverable_quality`, select_one, required): Assess the quality of deliverables (e.g., Excellent, Good, etc.).
* **Changes Requested** (`changes_requested`, select_one, required): Check if any changes were needed and describe them.
* **Concerns or Issues** (`concerns`, text, optional): Mention any concerns or issues.
* **Approval Status** (`approval_status`, select_one, required): Specify the current approval status (e.g., Approved as Is, Approved with Minor Revisions, etc.).
* **Next Steps** (`next_steps`, text, optional): Describe the next steps.
* **Would Recommend** (`would_recommend`, select_one, required): State whether you would recommend our services to others (e.g., Definitely Yes, Probably Yes, etc.).
* **Additional Comments** (`additional_comments`, text, optional): Provide any additional comments or feedback.
