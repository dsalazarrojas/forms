# Sales Client Relationship Assessment Form - Help Guide
## Purpose
This form is designed to gather information about a client's sales performance and the performance of their sales manager. The data collected will help the sales team assess the client's sales performance, identify areas for improvement, and provide insights for future sales strategies.

## How To Complete This Form

1. The form is divided into several sections, each with its own set of questions.
2. You will need to answer questions about the client's sales performance, including their overall satisfaction with the sales process.
3. You will also be asked questions about the sales manager's performance, including their sales numbers, commission, and other relevant metrics.
4. Please answer all questions as accurately and completely as possible.

## Field-by-Field Explanation

* **What is the client's sales performance?** (1, number): This question asks you to rate the client's sales performance on a scale of 1-10.
* **Sales Manager** (2, select_one, required/optional): Please select the sales manager's performance level (Good, Fair, Poor).
* **What is the client's sales performance?** (3, select_multiple, required/optional): This question asks you to select multiple options that describe the client's sales performance (High, Medium, Low).
* **Sales Manager Comment** (4, note, required/optional): Please provide any additional comments about the sales manager's performance.
* **Sales Manager Phone** (5, text, required/optional): Please provide the sales manager's phone number.
* **Client Feedback** (6, text, required/optional): Please provide any feedback from the client.
* **Overall Satisfaction** (7, number, required/optional): This question asks you to rate the client's overall satisfaction with the sales process on a scale of 1-10.
* **Sales Manager Email** (8, email, required/optional): Please provide the sales manager's email address.
* **Client Email** (9, email, required/optional): Please provide the client's email address.
* **Client Phone** (10, text, required/optional): Please provide the client's phone number.
* **Sales Manager Title** (11, text, required/optional): Please provide the sales manager's title.
* **Sales Manager Name** (12, text, required/optional): Please provide the sales manager's name.
* **Sales Manager Company** (13, text, required/optional): Please provide the sales manager's company name.
* **Sales Manager Department** (14, text, required/optional): Please provide the sales manager's department name.
* **Sales Manager Job Title** (15, text, required/optional): Please provide the sales manager's job title.
* **Sales Manager Reported Hours** (16, number, required/optional): This question asks you to report the sales manager's hours worked.
* **Sales Manager Reported Days** (17, number, required/optional): This question asks you to report the sales manager's days worked.
* **Sales Manager Sales** (18, number, required/optional): This question asks you to report the sales manager's sales numbers.
* **Sales Manager Last Quarter** (19, number, required/optional): This question asks you to report the sales manager's sales numbers for the last quarter.
* **Sales Manager Last Year** (20, number, required/optional): This question asks you to report the sales manager's sales numbers for the last year.
* **Sales Manager Last 6 Months** (21, number, required/optional): This question asks you to report the sales manager's sales numbers for the last 6 months.
* **Sales Manager Average Sales per Month** (22, number, required/optional): This question asks you to report the sales manager's average sales per month.
* **Sales Manager Total Sales** (23, number, required/optional): This question asks you to report the sales manager's total sales.
* **Sales Manager Sales per Quarter** (24, number, required/optional): This question asks you to report the sales manager's sales per quarter.
* **Sales Manager Commission** (25, number, required/optional): This question asks you to report the sales manager's commission.

Note: Some fields are marked as required/optional, please only answer required fields if they are relevant to your assessment.
