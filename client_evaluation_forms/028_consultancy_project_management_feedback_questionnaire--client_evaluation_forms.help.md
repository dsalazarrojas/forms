# Consultancy Project Management Feedback Questionnaire - Help Guide
## Purpose
This form is designed to gather feedback from clients about their recent consultancy project. The feedback will help our team to improve our services and deliver better results in future projects.

## How To Complete This Form
1. Fill out your details in the following pages:
	* Client information (page 2)
	* Project details (page 3)
	* Project assessment (pages 4-6)
	* Improvement suggestions (page 7)
2. Answer the questions honestly, and provide any additional comments or suggestions.

## Field-by-Field Explanation

* **Client name** (`client_name`, Text, **Required**): Please enter the name of your organization or individual. If you are an individual, enter your name as it appears on official documents.
* **Project name** (`project_name`, Text, **Required**): Enter the name of the consultancy engagement, as it appears in your records.
* **Engagement duration months** (`engagement_duration_months`, Number, Optional): If you wish to provide more information about the length of the consultancy engagement, please enter the number of months it lasted.
* **Satisfaction with deliverables** (`satisfaction_with_deliverables`, Select One, **Required**): Rate your satisfaction with the final deliverables of the project. Choose from the following options:
	+ Very satisfied
	+ Satisfied
	+ Neutral
	+ Dissatisfied
	+ Very dissatisfied
* **Communication quality** (`communication_quality`, Select One, **Required**): Rate the clarity and timeliness of communication during the project. Choose from the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Value for money** (`value_for_money`, Select One, **Required**): Rate the perceived value for fees paid for the project. Choose from the following options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Improvement suggestions** (`improvement_suggestions`, Text, Optional): If you have any suggestions for improvement, please enter them here. This is an optional field, but your feedback is valuable to us.

## Tips
* Please answer the questions honestly and provide detailed explanations where necessary.
* If you have already completed a project with us, please do not submit duplicate feedback.
* If you have any concerns or suggestions that are not addressed in this form, please contact us directly.
