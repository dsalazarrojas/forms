# Pet History Form - Help Guide
## Purpose
This form is designed to collect vital information about a pet's history to provide the best possible care for the pet.

## How To Complete This Form
To complete this form, simply fill out each field with the corresponding information about the pet you are providing care for. Be as accurate as possible, and if you are unsure about any information, please contact the relevant authority or party for clarification.

## Field-by-Field Explanation
- **Pet Type** (`pet_type`, text, optional): This field is used to identify the type of pet you are providing care for (e.g., dog, cat, etc.). Select the most suitable option or type in the text field.
- **Breed** (`breed_id`, select_one, optional): This field is used to select the breed of the pet from the available options (e.g., Labrador, German Shepherd, Poodle, etc.).
- **Name** (`name`, text, optional): Enter the pet's name here.
- **Age** (`age`, number, optional): Enter the pet's age here.
- **Weight** (`weight`, number, optional): Enter the pet's weight here.
- **Owner Name** (`owner_name`, text, optional): If you are not the owner of the pet, please enter the owner's name here.
- **Shelter ID** (`shelter_id`, text, optional): If this pet is currently in a shelter, please enter the shelter's ID here.
- **Vaccination Status** (`vaccination_status`, select_one, optional): Indicate whether the pet is vaccinated or not.
- **Medical History** (`medical_history`, text, optional): Enter any known medical history or conditions for this pet.
- **Microchip Status** (`microchip_status`, select_one, optional): Check if the pet has a microchip, and select the correct status.
- **Microchip Number** (`microchip_number`, text, optional): Enter the microchip number here if applicable.
- **Adoption Date** (`adoption_date`, date, optional): If the pet is not new, enter the adoption date here.
- **Spayed/Neutered** (`spayed_neutered`, select_one, optional): Check if the pet is spayed/neutered.
- **Microchip Provider** (`microchip_provider`, text, optional): Enter the microchip provider's name here if applicable.
- **Microchip Provider Phone** (`microchip_provider_phone`, text, optional): Enter the microchip provider's phone number here if applicable.
- **Microchip Provider Email** (`microchip_provider_email`, text, optional): Enter the microchip provider's email here if applicable.
- **Microchip Provider Address** (`microchip_provider_address`, text, optional): Enter the microchip provider's address here if applicable.
- **Microchip Provider City** (`microchip_provider_city`, text, optional): Enter the microchip provider's city here if applicable.
- **Microchip Provider State** (`microchip_provider_state`, text, optional): Enter the microchip provider's state here if applicable.
- **Microchip Provider Zip** (`microchip_provider_zip`, text, optional): Enter the microchip provider's zip here if applicable.
- **Microchip Provider Country** (`microchip_provider_country`, text, optional): Enter the microchip provider's country here if applicable.
- **Microchip Provider Notes** (`microchip_provider_notes`, text, optional): Enter any additional notes about the microchip provider here.
- **Microchip Provider Notes 2** (`microchip_provider_notes_2`, text, optional): Enter any additional notes about the microchip provider here.
- **Microchip Provider Notes 3** (`microchip_provider_notes_3`, text, optional): Enter any additional notes about the microchip provider here.
- **Microchip Provider Notes 4** (`microchip_provider_notes_4`, text, optional): Enter any additional notes about the microchip provider here.
