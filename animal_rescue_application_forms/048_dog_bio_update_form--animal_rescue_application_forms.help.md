# Dog Bio Update Form - Help Guide
## Purpose
The Dog Bio Update Form is used to collect and update a dog's biological information, such as name, breed, age, size, and update frequency. This form is essential for ensuring the accuracy and consistency of a dog's profile in the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you have a valid reason to update a dog's bio, such as a new adoption or a significant change in the dog's condition.
2. Enter the dog's name in the "Dog Name" field. This field is not required, but it's crucial for identifying the dog.
3. Select the correct breed of the dog from the options provided in the "Dog Breed" field.
4. Enter the dog's age in the "Dog Age" field. Please use a numerical value for accurate calculation.
5. Indicate whether the dog's size is "Yes" or "No" in the "Dog Size" field. This field is for indicating whether the dog's size is currently correct.
6. Enter the date of the last bio update in the "Bio Update Date" field, if applicable.
7. Select the frequency of bio updates for the dog from the options provided in the "Bio Update Frequency" field.

## Field-by-Field Explanation
* **Dog Name (Dog Name)** (`text`, required: false): Enter the dog's name as it is known in the system.
* **Dog Breed (Dog Breed)** (`select_one`, required: false): Select the breed of the dog from the list of available options.
* **Dog Age (Dog Age)** (`number`, required: false): Enter the current age of the dog.
* **Dog Size (Dog Size)** (`select_one`, required: false): Indicate whether the dog's size is accurate or needs update.
* **Bio Update Date (Bio Update Date)** (`date`, required: false): Enter the date of the last bio update, if applicable.
* **Bio Update Frequency (Bio Update Frequency)** (`select_one`, required: false): Select the frequency of bio updates for the dog.
