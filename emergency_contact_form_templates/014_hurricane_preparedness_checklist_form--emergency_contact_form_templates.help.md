# Hurricane Preparedness Checklist Form - Help Guide
## Purpose
The Hurricane Preparedness Checklist Form is designed to help individuals and families prepare for hurricanes. It is a self-assessment tool that will help you identify areas where you need to take action to be prepared.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Review each page and select the correct response for each field.
2. Answer each field as accurately and thoroughly as possible.
3. If you are unsure about any field, use the available options as guidance.

## Field-by-Field Explanation
### **Emergency Plans** (`hurricane_preparedness_checklist_form`)
* This page allows you to indicate if you have emergency plans in place. Choose 'Yes' if you have a plan, such as a family emergency plan, that you can refer to during a hurricane. Choose 'No' if you don't have a plan.
### **Inventory Supplies** (`supplies`)
* This page allows you to indicate if you have the necessary supplies in your home in case of a hurricane. Choose 'Yes' if you have the required supplies, such as food, water, and first aid kit. Choose 'No' if you don't have the necessary supplies.
### **Emergency Contact** (`emergency_contact`)
* This page is where you provide emergency contact information. Choose the contact type that best fits the contact you are listing. For example, if you are listing a family member, choose 'Name'. If you are listing a neighbor, choose 'Phone'. If you are listing a friend, choose 'Email'.
