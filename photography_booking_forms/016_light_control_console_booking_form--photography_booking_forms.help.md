# Light Control Console Booking Form - Help Guide
## Purpose
This form is used to book a console for a specific time period. Please provide the required information to complete the booking process.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in your **First Name**, **Last Name**, and **Email** fields with the required information.
2. Enter your **Phone** number for contact purposes.
3. Select a **Date** for your booking.
4. Choose a **Start Time** and an **End Time** for your console usage.
5. Enter the **Duration** of your console usage in minutes.
6. Select the **Console Type** you would like to book (Console 1, Console 2, or Console 3).
7. Enter any additional **Notes** about your booking.
8. Select the tools you would like to **Assign to the Console** (chatjimmy, user123, user456).
9. Confirm if you would like to **Assign Tool 2** and **Assign Tool 3** to the console.
10. Finally, select the **Console Booking Status** (Active or Inactive).

## Field-by-Field Explanation
### First Name (first-name)
* The field for your first name is a text input field.
* Please enter your first name to complete this field.

### Last Name (last-name)
* This field is for your last name.
* Enter your last name to complete this field.

### Email
* Enter your email address in this field.
* This will help us contact you if needed.

### Phone
* Enter your phone number for contact purposes.
* This will be used to reach out to you if needed.

### Date
* Select a date for your console usage.
* Please use the correct date format (YYYY-MM-DD).

### Start Time
* Choose a start time for your console usage.
* This field is in 24-hour format (HH:MM).

### End Time
* Select an end time for your console usage.
* Enter the end time in 24-hour format (HH:MM).

### Duration
* Enter the duration of your console usage in minutes.
* This will help us estimate the required resources.

### Console Type
* Select the type of console you would like to book (Console 1, Console 2, or Console 3).
* Please choose the correct console type for your needs.

### Notes
* Add any additional comments or notes about your booking.
* This will help us understand your requirements better.

### Assigned Tool
* Select the tools you would like to assign to the console (chatjimmy, user123, user456).
* Please choose the tools that you need for your console usage.

### Assigned Tool 2
* Confirm if you would like to assign Tool 2 to the console.
* This will help us prepare the required resources.

### Assigned Tool 3
* Confirm if you would like to assign Tool 3 to the console.
* This will help us prepare the required resources.

### Console Booking Status
* Select the status of your console booking (Active or Inactive).
* Please choose the correct status for your booking.

### Tips
* Please ensure that you provide accurate information to avoid any errors in the booking process.
* If you have any questions or concerns, please contact us.
