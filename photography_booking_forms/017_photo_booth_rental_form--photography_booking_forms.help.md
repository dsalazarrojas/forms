# Photo Booth Rental Form - Help Guide
## Purpose
This form is used to collect information from users who want to rent a photo booth for an event.

## How To Complete This Form
1. Please select the type of event you are booking the photo booth for:
	* Wedding
	* Birthday
	* Graduation
	* Other
2. Choose the services you would like to include with your rental:
	* Photography Services
	* Event Photography
	* Photo Editing
3. Select the number of hours you would like to rent the photo booth for:
	* 2 hours
	* 4 hours
	* 6 hours
	* 8 hours
4. Add any additional notes or messages in the "Message" field.
5. Review and agree to the User Agreement, Photo Booth Terms of Service, and Photo Booth Rental Terms.

## Field-by-Field Explanation
* **User Name**: Enter your name as the person booking the photo booth.
* **Contact E-mail**: Enter your email address so we can contact you with any updates or questions.
* **Contact Phone**: Enter your phone number so we can reach you if needed.
* **Date**: Select the date of the event.
* **Time**: Select the start time of the event.
* **Rental Duration**: Choose the duration of the rental from 2-8 hours.
* **Number of Guests**: Enter the number of guests attending the event.
* **Message**: Add any additional information or requests you have.
* **What type of event?**: This is a dropdown menu where you select the type of event (e.g., Wedding, Birthday, Graduation).
* **What services would you like?**: This is a dropdown menu where you select the services you want (e.g., Photography Services, Event Photography, Photo Editing).
* **How many hours would you like to rent?**: This is a dropdown menu where you select the duration of the rental (e.g., 2-8 hours).
* **Note**: This is an open-ended field where you can add any additional information.
* **User Agreement**: This is a read-only field that displays the terms of use for the photo booth rental.
* **Agreement Terms**: This is a read-only field that displays the terms of service for the photo booth rental.
* **Photo Booth Information**: This is a read-only field that displays information about the photo booth.
* **Terms of Service**: This is a text field where you can review the terms of service.
* **Privacy Policy**: This is a text field where you can review the privacy policy.
* **Photo Booth Rental Terms**: This is a text field where you can review the photo booth rental terms.
* **Photo Booth Rental Fees**: This is a text field where you can review the rental fees.
* **Photo Booth Return Policy**: This is a text field where you can review the return policy.
* **Photo Booth Terms of Service**: This is a read-only field that displays the terms of service for the photo booth rental.
* **Photo Booth Warranty**: This is a read-only field that displays information about the warranty.
* **Photo Booth Return Policy Terms**: This is a read-only field that displays the return policy terms.
* **Photo Booth Cancellation Policy**: This is a text field where you can review the cancellation policy.
* **Photo Booth Payment Terms**: This is a text field where you can review the payment terms.

## Tips
* Please make sure to fill out all required fields (marked as required) to ensure a smooth rental process.
* If you have any questions or concerns, please don't hesitate to contact us.

Note: This help guide is designed to be as comprehensive and user-friendly as possible, but if you have any specific questions or need further clarification, please don't hesitate to ask.
