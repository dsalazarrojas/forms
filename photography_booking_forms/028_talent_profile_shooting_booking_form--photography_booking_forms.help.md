# Talent Profile Shooting Booking Form - Help Guide
## Purpose
This form is designed to collect necessary information for a photography shoot, including date, time, location, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

* Enter the date for the shoot.
* Select the start and end times for the shoot.
* Enter the location for the shoot.
* Enter the name of the photographer in charge.
* Enter any relevant notes for the shoot.
* Enter the name of the talent performing at the shoot.
* Choose the type of shoot (e.g., Option 1, Option 2, or Option 3).
* Select the current status of the shoot (e.g., Option 1, Option 2, or Option 3).
* Optionally, assign a tool for the shoot.
* Enter the date the form was created, updated, or deleted.
* Optionally, enter the date the form was submitted.
* Optionally, enter the name of the person submitting the form.

## Field-by-Field Explanation
* **Shooting Date**: Enter the date of the photography shoot. (Type: date)
* **Start Time**: Select the start time of the shoot. (Type: time)
* **End Time**: Select the end time of the shoot. (Type: time)
* **Location**: Enter the location where the shoot will take place. (Type: text)
* **Photographer**: Enter the name of the photographer in charge. (Type: text)
* **Agency**: Enter the name of the agency managing the shoot. (Type: text)
* **Shoot Notes**: Enter any relevant notes or details about the shoot. (Type: note)
* **Talent**: Enter the name of the talent performing at the shoot. (Type: text)
* **Shoot Type**: Choose the type of shoot (e.g., Option 1, Option 2, or Option 3). (Type: select_one)
* **Shoot Status**: Select the current status of the shoot (e.g., Option 1, Option 2, or Option 3). (Type: select_multiple)
* **Assigned Tool**: Optionally, assign a tool for the shoot. (Type: text)
* **Created At**: Display the date the form was created. (Type: date)
* **Updated At**: Display the date the form was last updated. (Type: date)
* **Deleted At**: Display the date the form was deleted. (Type: date)
* **Submitted At**: Optionally, enter the date the form was submitted. (Type: date)
* **Submitted By**: Optionally, enter the name of the person submitting the form. (Type: text)
* **Shoot Image 1-8**: Enter any relevant images for the shoot. (Type: text)

Note: The fields marked as "required: false" are not compulsory and can be left empty if not applicable to the shoot.
