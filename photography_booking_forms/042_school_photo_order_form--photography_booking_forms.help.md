# School Photo Order Form - Help Guide
## Purpose
The School Photo Order Form is designed to collect information about a school photo shoot, including student details, event specifics, and order status.

## How To Complete This Form
1. Fill out all the required fields (student name, student photo year, school name, and photo shoot date) accurately and completely.
2. For optional fields (student photo year, photo shoot location, number of students, packages, photo products, photo print size, student photos, school year, payment status, payment method), select the relevant options according to your needs.
3. If you have any additional comments or notes, fill out the "order_comments" and "photo_comments" fields.
4. Finally, review the form carefully before submitting it.

## Field-by-Field Explanation

* **Student Name** (`student_name`, text, required): Please enter the student's name accurately.
* **Student Photo Year** (`student_photo_year`, text, optional): If applicable, enter the student's photo year.
* **School Name** (`school_name`, select_one, required): Select the school's name from the provided options.
* **Photo Shoot Date** (`photo_shoot_date`, date, required): Enter the date of the photo shoot.
* **Photo Shoot Location** (`photo_shoot_location`, select_multiple, optional): If applicable, select the location of the photo shoot.
* **Number of Students** (`number_of_students`, select_one, optional): Select the number of students participating in the photo shoot.
* **Package** (`package`, select_one, optional): Select the package you are interested in.
* **Photo Products** (`photo_products`, select_multiple, optional): Select the photo products you require.
* **Photo Print Size** (`photo_print_size`, select_multiple, optional): Select the photo print size you need.
* **Student Photos** (`student_photos`, select_multiple, optional): Select the student photos you need.
* **School Year** (`school_year`, select_one, optional): Select the school year.
* **Payment Status** (`payment_status`, select_multiple, optional): Select the payment status.
* **Payment Method** (`payment_method`, select_multiple, optional): Select the payment method.
* **Notes** (`notes`, note, optional): Add any additional comments or notes regarding the photo shoot or order.
* **Email** (`email`, email, optional): Enter the email address for communication.
* **Phone** (`phone`, text, optional): Enter the phone number for communication.
* **Order Comments** (`order_comments`, text, optional): Add any additional comments regarding the order.
* **Photo Comments** (`photo_comments`, text, optional): Add any additional comments regarding the photo shoot.
* **Order Status** (`order_status`, select_multiple, optional): Select the order status.
* **Student ID** (`student_id`, select_one, optional): Select the student ID.
* **Student Class** (`student_class`, select_one, optional): Select the student class.
* **Student Gender** (`student_gender`, select_one, optional): Select the student gender.
* **School Grade** (`school_grade`, select_one, optional): Select the school grade.
* **Student Age** (`student_age`, select_one, optional): Select the student age.

## Tips
- Review the form carefully before submitting it to ensure all required fields are filled in accurately.
- Be precise and clear when filling out the form to avoid any errors or miscommunication.
- If you're unsure about any field, consult with the relevant authorities or contacts for clarification.
