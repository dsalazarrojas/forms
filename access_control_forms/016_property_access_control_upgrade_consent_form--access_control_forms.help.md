# Property Access Control Upgrade Consent Form - Help Guide

## Purpose
The Property Access Control Upgrade Consent Form is used to grant permission for users to access specific properties. This form is a critical component of the property access control upgrade process, ensuring that users have the necessary permissions to access properties securely.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to initiate the upgrade request.
2. Select "property_access_control_upgrade_form" from the available options.
3. Enter your consent in the text fields "resident_consent" and "owner_consent".

## Field-by-Field Explanation
* **property_access_control_upgrade_form** (`property_access_control_upgrade_form`, number, required): Select the property access control upgrade form from the available options.
* **resident_consent** (`resident_consent`, text, optional): Enter your consent as the resident or occupant of the property.
* **owner_consent** (`owner_consent`, text, optional): Enter your consent as the property owner or administrator.
