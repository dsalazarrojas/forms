# Referral Service Login Assistance Request - Help Guide

## Purpose
This form is designed to collect information for referral service login assistance requests. Please use it to report issues with accessing a login service.

## How To Complete This Form

1.  Click on the "Login Request" page.
2.  Fill out the "Prophets Name", "User ID", "Email", "Description", "Referral Platform", "Assigned Team", "User Type", and "User Level" fields.
3.  If applicable, provide the "Login URL" and "Login URL Link".
4.  Enter the "Prophets Note" field to describe the issue you're experiencing.
5.  Click "Submit" to send the request.

## Field-by-Field Explanation

*   **Login Request (text, required)**: Please provide a brief description of the issue you're experiencing.
*   **Prophets Name (text, required)**: Enter the name of the prophet associated with the login issue.
*   **User ID (number, optional)**: If you know the User ID associated with the issue, please enter it. This will help the assigned team to quickly identify the problem.
*   **Email (email, required)**: Enter a valid email address in the standard format (e.g., user@example.com).
*   **Phone (text, optional)**: If you have a phone number where you can be reached for follow-up, please enter it.
*   **Description (text, optional)**: Provide a more detailed description of the issue you're experiencing.
*   **Referral Platform (select_one, required)**: Select the referral platform associated with the issue (e.g., Platform 1, Platform 2, Platform 3).
*   **Assigned Team (select_multiple, required)**: Select the team you'd like to be assigned to this issue.
*   **Submitted by (note, optional)**: Enter a note explaining who submitted the request.
*   **Submitted Date (date, optional)**: Enter the date the request was submitted.
*   **Prophets Note (text, required)**: Describe the issue you're experiencing in detail.
*   **Login URL (text, required)**: Enter the URL associated with the login service.
*   **Login URL Link (text, optional)**: Enter a link to the login URL if possible.
*   **User Type (select_multiple, required)**: Select the user type associated with the issue (e.g., User Type 1, User Type 2, User Type 3).
*   **User Level (select_one, required)**: Select the user level associated with the issue (e.g., Level 1, Level 2, Level 3).
