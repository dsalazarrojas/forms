# university_library_resource_access_check_in - Help Guide
## Purpose
The purpose of this form is to facilitate the check-in process for university library resources. To complete this form, you will need to provide information about the resource and yourself.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the User Name field with your name.
2. Enter the Item Name of the resource being checked in.
3. Provide the Item Number of the resource (if available).
4. Enter the Date the resource is being returned.
5. Enter the Time the resource is being returned.
6. Select the Department that is responsible for the resource.

## Field-by-Field Explanation
* **User Name** (`user_name`, text, required): Enter your name for identification purposes.
* **Item Name** (`item_name`, text, required): The name of the resource being checked in.
* **Item Number** (`item_number`, number, optional): The unique identifier of the resource (if available).
* **Date** (`date`, date, required): The date the resource is being returned.
* **Time** (`time`, time, required): The time the resource is being returned.
* **Department** (`department`, text, optional): The department responsible for the resource.

## Tips
* Ensure you have permission to use the resource before checking it in.
* Make sure to return all required fields.
* If you're unsure about a particular field, check with library staff for assistance.
