# Key Issuance Log - Help Guide
## Purpose
The Key Issuance Log is a form used to record the issuance and return of keys within an organization. This form is used to provide a historical record of key movements and can be used for reference or audit purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the form title.
* Enter the name of the person issuing the key.
* Enter the contact number for the person issuing the key.
* Select the date the key was issued.
* Select the date the key was returned.
* Add any additional notes about the key issuance or return.
* Choose the type of person responsible for the key issuance (Manager, Maintenance Crew, or Other).
* Enter the name of the manager responsible for the key.
* Enter the email address of the manager responsible for the key.
* Enter the contact number of the manager responsible for the key.
* Enter the employee ID of the manager responsible for the key.

## Field-by-Field Explanation
* **form_title** (1, text, required: false): Enter a brief title for the key issuance log entry.
* **name** (2, text, required: false): Enter the name of the person issuing the key.
* **employee_name** (3, text, required: false): Enter the name of the employee to whom the key was issued.
* **contact_number** (4, text, required: false): Enter the contact number of the person issuing the key.
* **key_issue_date** (5, date, required: false): Select the date the key was issued.
* **key_return_date** (6, date, required: false): Select the date the key was returned.
* **notes** (7, note, required: false): Add any additional notes about the key issuance or return.
* **employee_signature** (8, select_multiple, required: false): Choose the type of person responsible for the key issuance (Manager, Maintenance Crew, or Other).
* **manager_name** (9, text, required: false): Enter the name of the manager responsible for the key.
* **manager_email** (10, email, required: false): Enter the email address of the manager responsible for the key.
* **manager_contact_number** (11, text, required: false): Enter the contact number of the manager responsible for the key.
* **manager_employee_id** (12, number, required: false): Enter the employee ID of the manager responsible for the key.

## Tips
* Make sure to fill in all required fields before submitting the form.
* Use the date fields to accurately track the timing of key issuance and return.
* The notes field can be used to add any additional information that is not captured by the other fields.
* The employee_signature field is used to indicate who is responsible for the key issuance, so choose the correct option for the person who actually issued the key.
