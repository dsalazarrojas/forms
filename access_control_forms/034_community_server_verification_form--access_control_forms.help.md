# Community Server Verification Form - Help Guide
## Purpose
This form is designed to verify your identity and intentions as a potential member of the community server. It's essential to fill it out carefully and accurately to ensure a smooth verification process.

## How To Complete This Form
1.  Fill out each section completely and accurately.
2.  Be honest in your responses, especially when it comes to verification questions.
3.  Review each field carefully before submitting the form.
4.  If you're unsure about any question, don't hesitate to ask for clarification.

## Field-by-Field Explanation
- **Applicant Information**: This section is for your basic details.
  * **Desired Username**: Choose a username you'd like to have in the server.
  * **Email Address**: Enter a valid email address for verification purposes.
  * **Discord ID**: If you have a Discord ID, please enter it.
  * **Age**: Please enter your age.
  * **General Location**: Enter your country or region.
- **How Did You Find This Server?**: Choose how you found the server.
  * **Friend Referral**: If a friend referred you, select "Friend Referral."
  * **Social Media**: If you found the server through social media, select "Social Media."
  * **Server Listing**: If you found the server through a listing, select "Server Listing."
  * **Search Engine**: If you found the server through a search engine, select "Search Engine."
  * **Other Community**: If you found the server through another community, select "Other Community."
  * **Advertisement**: If you saw an ad, select "Advertisement."
  * **Other**: If none of the above apply, select "Other."
- **Why Do You Want to Join This Server?**: Tell us your motivation for joining the server.
- **What Are Your Interests?**: Select all your interests that apply.
  * **Gaming**: If you're interested in gaming.
  * **Technology**: If you're interested in technology.
  * **Art and Design**: If you're interested in art and design.
  * **Music**: If you're interested in music.
  * **Education**: If you're interested in education.
  * **Community Discussion**: If you're interested in community discussion.
  * **Professional Networking**: If you're interested in professional networking.
  * **Hobbies**: If you have hobbies.
  * **Support Groups**: If you're interested in support groups.
  * **Other**: If none of the above apply, select "Other."
- **Have You Been in Similar Communities Before?**: Choose how much experience you have with similar communities.
  * **Yes - Extensive Experience**: If you have extensive experience with similar communities.
  * **Yes - Some Experience**: If you have some experience with similar communities.
  * **No - First Time**: If you're new to similar communities.
- **Have You Read the Community Rules?**: Choose if you have read the community rules.
  * **Yes - I Have Read and Agree**: If you have read and agree with the rules.
  * **No - I Need to Read Them**: If you haven't read the rules yet.
- **Do You Agree to Follow the Rules?**: Choose your stance on the community rules.
  * **Yes - I Agree**: If you agree to follow the rules.
  * **No - I Do Not Agree**: If you don't agree to follow the rules.
- **Are You a Real Person?**: Choose your true nature.
  * **Yes - I Am Human**: If you're a real person.
  * **No - I Am a Bot**: If you're not a human.
- **What Is 5 Plus 3?**: Answer a simple math question to verify your humanity.
- **Social Media Accounts**: If you have social media accounts, you can enter them.
- **Personal Website or Portfolio**: If you have a website, you can enter it.
- **What Skills Can You Contribute?**: Select all your skills that apply.
  * **Moderation**: If you can moderate discussions.
  * **Content Creation**: If you can create content.
  * **Event Planning**: If you can plan events.
  * **Technical Support**: If you can provide technical support.
  * **Art and Design**: If you can do art and design.
  * **Writing**: If you can write.
  * **Mentoring**: If you can mentor others.
  * **Community Building**: If you can build communities.
  * **None Currently**: If you don't have any skills.
- **How Often Do You Plan to Participate?**: Choose how often you plan to participate in the community.
  * **Daily**: If you plan to participate daily.
  * **Several Times a Week**: If you plan to participate several times a week.
  * **Once a Week**: If you plan to participate once a week.
  * **Few Times a Month**: If you plan to participate a few times a month.
  * **Occasionally**: If you plan to participate occasionally.
- **Your Timezone**: Choose your time zone.
  * **Pacific Time (PT)**: If you're in the Pacific Time zone.
  * **Mountain Time (MT)**: If you're in the Mountain Time zone.
  * **Central Time (CT)**: If you're in the Central Time zone.
  * **Eastern Time (ET)**: If you're in the Eastern Time zone.
  * **Europe**: If you're in the Europe Time zone.
  * **Asia**: If you're in the Asia Time zone.
  * **Australia**: If you're in the Australia Time zone.
  * **Other**: If none of the above apply.
- **Pronouns**: Choose your pronouns.
  * **He/Him**: If you prefer he/him pronouns.
  * **She/Her**: If you prefer she/her pronouns.
  * **They/Them**: If you prefer they/them pronouns.
  * **Other**: If none of the above apply.
  * **Prefer Not to Say**: If you don't want to disclose your pronouns.
- **Are You Willing to Mark Spoilers?**: Choose your stance on spoilers.
  * **Yes - Always**: If you're always willing to mark spoilers.
  * **Yes - When Reminded**: If you're willing to mark spoilers when reminded.
  * **False**: If you're not willing to mark spoilers.
- **Do You Want Access to NSFW Channels?**: Choose if you're 18+ and want access to NSFW channels.
  * **Yes - I Am 18+**: If you're 18+ and want access.
  * **No - Keep Restricted**: If you don't want access to NSFW channels.
- **Have You Been Banned from Similar Servers?**: Choose if you've been banned from similar servers.
  * **True**: If you've been banned from similar servers.
  * **False**: If you haven't been banned.
  * **Prefer Not to Say**: If you don't want to disclose this information.
- **Details of Previous Bans**: If you've been banned, enter details of previous bans.
- **Anything Else You Want to Share?**: If you have anything else you'd like to share, enter it.
- **Verification Complete**: Confirm that you've filled out the form accurately and are ready for review.
