# Ballot Box Security Log - Help Guide
## Purpose
The Ballot Box Security Log is used to track the security of ballot boxes during the voting process. It is a key document for ensuring the integrity of the election process.

## How To Complete This Form
1.  **Location and Shift Details**: This section provides an overview of the ballot box's location and the shift details. This is not a required field, but it sets the context for the rest of the form.
2.  **Polling Location Name**: Enter the official name of the polling location.
3.  **Ballot Box Identifier**: Enter the unique identifier or serial number of the ballot box.
4.  **Date of Security Check**: Enter the date of the security check or handover.
5.  **Time of Security Check**: Enter the local time of the security check.
6.  **Officer or Staff on Duty**: Enter the name of the person performing the security check.
7.  **Seal Number (optional)**: If applicable, enter the security seal identifier on the ballot box. This field is optional.
8.  **Seal Status**: Indicate if the seal on the ballot box is intact or broken.
9.  **Incident Reported**: If any issue was observed, check yes, otherwise, check no.
10.  **Incident Notes (optional)**: Provide a description of any incident or irregularity observed.
11.  **Next Handover Time (optional)**: Enter the scheduled time for the next shift handover. This field is optional.
12.  **Reviewer Name (optional)**: Enter the name of the supervisor who reviewed the log. This field is optional.
