This form is used by applicants to request assistance with logging into the applicant portal. The purpose of the form is to provide support staff with the necessary information to troubleshoot and assist the applicant with their login issues. Before filling out this form, ensure that you are not duplicating an existing support request and that the issue is not a simple password reset.

To complete this form, please follow the instructions below:

## Purpose
This form is used to request assistance with logging into the applicant portal. Please provide as much detail as possible to help support staff resolve the issue efficiently.

## How To Complete This Form

1. Fill in the request date when you are experiencing the login issue.
2. Enter your full name as it appears on your account.
3. Enter the email address associated with your account.
4. If you have a contact phone number, please enter it. If not, you can leave this field blank.
5. If you have an application reference or ID number, enter it. If not, you can leave this field blank.
6. Select the type of portal you are trying to access.
7. Choose the type of login issue you are experiencing.
8. Provide a detailed description of the issue.
9. If an error message is displayed, enter the exact message.
10. Select the web browser you are using to access the portal.
11. Choose the type of device you are using.
12. If you know, select the operating system of the device.
13. If you have a last successful login, enter the date. If not, you can leave this field blank.
14. If you have tried resetting your password, select your attempt status.
15. If you can, approximate the date when your account was created.
16. If you applied for a job position, enter it. If not, you can leave this field blank.
17. Select the urgency level of your assistance request.
18. Choose your preferred contact method.
19. Select the best time of day for support staff to contact you.
20. If you have any additional comments that may help resolve the issue, enter them here.
21. Finally, consent to be contacted by support staff to discuss this request.

## Field-by-Field Explanation

* **Request Date** (`request_date`, date, required): The date when you are requesting assistance with your login.
* **Applicant Name** (`applicant_name`, text, required): Enter your full name as it appears on your account.
* **Applicant Email** (`applicant_email`, email, required): Enter the email address associated with your account.
* **Applicant Phone** (`applicant_phone`, text, optional): If you have a contact phone number, enter it. If not, you can leave this field blank.
* **Applicant ID** (`applicant_id`, text, optional): If you have an application reference or ID number, enter it. If not, you can leave this field blank.
* **Portal Type** (`portal_type`, select_one, required): Select the type of portal you are trying to access.
* **Issue Type** (`issue_type`, select_one, required): Choose the type of login issue you are experiencing.
* **Issue Description** (`issue_description`, text, required): Provide a detailed description of the issue.
* **Error Message** (`error_message`, text, optional): If an error message is displayed, enter the exact message.
* **Browser Used** (`browser_used`, select_one, optional): Select the web browser you are using to access the portal.
* **Device Type** (`device_type`, select_one, optional): Choose the type of device you are using.
* **Operating System** (`operating_system`, select_one, optional): If you know, select the operating system of the device.
* **Last Successful Login** (`last_successful_login`, date, optional): If you have a last successful login, enter the date. If not, you can leave this field blank.
* **Password Reset Attempted** (`password_reset_attempted`, select_one, required): If you have tried resetting your password, select your attempt status.
* **Account Creation Date** (`account_creation_date`, date, optional): If you can, approximate the date when your account was created.
* **Position Applied** (`position_applied`, text, optional): If you applied for a job position, enter it. If not, you can leave this field blank.
* **Urgency Level** (`urgency_level`, select_one, required): Select the urgency level of your assistance request.
* **Preferred Contact Method** (`preferred_contact_method`, select_one, required): Choose your preferred contact method.
* **Best Contact Time** (`best_contact_time`, select_one, optional): Select the best time of day for support staff to contact you.
* **Additional Comments** (`additional_comments`, text, optional): If you have any additional comments that may help resolve the issue, enter them here.
* **Consent to Contact** (`consent_to_contact`, select_one, required): Finally, consent to be contacted by support staff to discuss this request.

## Tips

* Please provide as much detail as possible to help support staff assist you efficiently.
* If you have any questions or concerns, do not hesitate to ask.
* Support staff will review your request and contact you according to your preferred contact method and time.
* If you have any additional comments or information, please include them in the "Additional Comments" field.
