# Blockchain RPC Provider Access Request Form - Help Guide
## Purpose
This form is used to request access to the blockchain RPC services for a specific organization. The purpose of this form is to gather information about the organization and their expected use of the services. This information will be used to assess the request and ensure that the organization meets the necessary criteria for access.

## How To Complete This Form
1. Fill out the required fields accurately and thoroughly.
2. Select the correct options for each field based on your organization's information.
3. If you are unsure about any of the questions, please reach out to the technical contact for clarification.

## Field-by-Field Explanation

* **Organization Name** (`organization_name`, text, required): Please enter your organization's name.
* **Organization Type** (`organization_type`, select_one, required): Select the type of organization you are representing. This will help us understand your organization's needs and assess your request.
* **Requester Name** (`requester_name`, text, required): Please enter your name, which will be used as the primary contact for communication.
* **Email Address** (`requester_email`, email, required): Enter your email address, which will be used for communication and confirmation of your request.
* **Phone Number** (`requester_phone`, text, optional): If you have a phone number, please enter it. This will allow us to contact you more easily.
* **Company Website or GitHub Profile** (`company_website`, text, optional): If you have a website or GitHub profile, please enter the URL.
* **Blockchain Networks Required** (`rpc_networks`, select_multiple, required): Select the blockchain networks that your organization will be using.
* **Primary Use Case** (`use_case`, text, required): Describe the primary use case for your request. This will help us understand your organization's needs.
* **Estimated Daily RPC Requests** (`estimated_requests_daily`, select_one, required): Estimate the number of daily RPC requests your organization will be making.
* **Estimated Peak Requests Per Second** (`peak_requests_per_second`, number, optional): If you have an estimate of the peak requests per second, please enter it.
* **Requested Access Tier** (`access_tier`, select_one, required): Select the access tier that you believe your organization will need.
* **Does your system support API key rotation?** (`has_key_rotation`, select_one, optional): If your system supports API key rotation, please select "Yes".
* **Describe your security practices** (`security_practices`, text, required): Please describe your security practices and how you will ensure the integrity of our services.
* **Technical Contact Name** (`technical_contact`, text, optional): If you have a technical contact, please enter their name.
* **Technical Contact Email** (`technical_contact_email`, email, optional): If you have a technical contact, please enter their email address.
* **Expected Launch Date** (`expected_launch_date`, date, optional): If you have an expected launch date, please enter it.
* **I accept the terms of service and privacy policy** (`terms_accepted`, select_one, required): Please select "I agree" to confirm that you have read and understood the terms of service and privacy policy.
* **Request Submission Date** (`request_timestamp`, date, required): The date you are submitting this request.
