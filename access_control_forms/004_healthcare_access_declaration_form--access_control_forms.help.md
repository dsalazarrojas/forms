# healthcare_access_declaration_form - Help Guide

## Purpose
This form is used by patients to declare their access needs, insurance information, and payment terms for healthcare services.

## How To Complete This Form

1. Start by filling out the **Patient Info** section, which includes basic information about the patient.
2. If necessary, provide more detailed medical history in the **Medical History** section.
3. Specify your access needs in the **Access Needs** section by selecting one or more of the following: Allergy, Medication, or Condition.
4. In the **Insurance Info** section, select your insurance provider and coverage plan.
5. Provide additional contact information in the **Contact Info** section if required.
6. Add healthcare provider information if assigned to you.
7. Select your medical facility if necessary.
8. Add emergency contact information if required.
9. Add next of contact information if required.
10. Add healthcare coordinator information if required.
11. Provide medical record details if required.
12. Add medical record number if required.
13. Select your insurance plan if necessary.
14. Select your insurance group if necessary.
15. Add coverage start and end dates if required.
16. Select your payment terms, which is mandatory.
17. Add payment status if required.
18. Add payment amount if required.
19. Add payment frequency if required.
20. Set your payment date, which is mandatory.
21. Select your payment method if required.
22. Add any additional notes if required.
23. Add your email address if required.
24. Add your phone number if required.
