# Physical Access Security Request Form - Help Guide
## Purpose
The Physical Access Security Request Form is used to submit requests for physical access to a facility. This form helps employees to request access to a facility for work-related purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields with accurate information.
2. Select the correct options for the facility location and approval requester/approver.
3. Enter the start and end dates of the access period.
4. Specify the duration of the access period.
5. Enter the reason for the access request.

## Field-by-Field Explanation
* **Facility Access Request**:
	+ Type: Text
	+ Purpose: Briefly describe the access request.
* **Access Dates**:
	+ Type: Date
	+ Purpose: Select the start and end dates of the access period.
* **Access Time**:
	+ Type: Time
	+ Purpose: Enter the time of access.
* **Employee Name**:
	+ Type: Text
	+ Purpose: Enter your name for identification purposes.
* **Job Title**:
	+ Type: Text
	+ Purpose: Enter your job title for reference.
* **Facility Location**:
	+ Type: Select One
	+ Purpose: Select the location of the facility you need access to.
* **Approval Requester**:
	+ Type: Select Multiple
	+ Purpose: Select who is requesting your approval.
* **Approval Approver**:
	+ Type: Select Multiple
	+ Purpose: Select who will approve your access request.
* **Access Duration**:
	+ Type: Number
	+ Purpose: Enter the number of hours or days you need access.
* **Reason for Access**:
	+ Type: Text
	+ Purpose: Briefly describe the reason for your access request.

Note: This form is for planned access requests only. If you need emergency or urgent access, please contact your supervisor or facility manager directly.
