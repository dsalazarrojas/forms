# Agent Removal Request Form - Help Guide
## Purpose
The Agent Removal Request Form is used to formally request the removal of an agent within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the required information for the requestor, including their name, position, email, and the date of submission.
2. Enter the details about the agent to be removed, including their full name, unique identifier, position, and department/team.
3. Select the primary reason for the agent's removal from the provided options.
4. Enter a detailed explanation for the removal.
5. Specify the effective date for the removal.
6. Indicate the access that needs to be revoked, including selecting all applicable systems, accounts, or access points.
7. If 'Other' is selected, provide any additional access points.
8. List any assets that need to be returned.
9. Approvals from both an HR manager and department head are required to complete this form.

## Field-by-Field Explanation

* **Requestor Name** (`requestor_name`, text, required): Enter the name of the person submitting the request.
* **Requestor Position** (`requestor_position`, text, required): Enter the position/title of the person submitting the request.
* **Requestor Email** (`requestor_email`, email, required): Enter the email address of the person submitting the request.
* **Request Date** (`request_date`, date, required): Enter the date when this request is submitted.
* **Agent Full Name** (`agent_full_name`, text, required): Enter the full name of the agent to be removed.
* **Agent ID** (`agent_id`, text, required): Enter the unique identifier for the agent.
* **Agent Position** (`agent_position`, text, required): Enter the position/title of the agent.
* **Department/Team** (`department_team`, text, required): Enter the department or team the agent belongs to.
* **Reason for Removal** (`reason_for_removal`, select_one, required): Select the primary reason for the agent's removal from the provided options.
* **Detailed Reason** (`detailed_reason`, text, required): Provide a detailed explanation for the removal.
* **Effective Date** (`effective_date`, date, required): Enter the date when the removal should take effect.
* **Systems Access to be Revoked** (`systems_access_to_be_revoked`, select_multiple, required): List the systems, accounts, or access that needs to be revoked.
* **Additional Access Points** (`additional_access_points`, text, optional): If 'Other' was selected, specify any additional access points.
* **Asset Return Obligations** (`asset_return_obligations`, text, optional): List any assets that need to be returned.
* **HR Manager Approval** (`hr_manager_approval`, select_one, required): HR manager approval is required before the removal can be processed.
* **HR Manager Name** (`hr_manager_name`, text, optional): Enter the name of the HR manager approving this request.
* **Department Head Approval** (`department_head_approval`, select_one, required): Department head approval is required before the removal can be processed.
* **Department Head Name** (`department_head_name`, text, optional): Enter the name of the department head approving this request.
* **Additional Approvals Needed** (`additional_approvals_needed`, text, optional): If other approvals are needed, indicate them here.
* **Follow-up Actions** (`follow_up_actions`, text, optional): What follow-up actions need to be taken after removal?
