# Customer ID Upload Form - Help Guide
## Purpose
This form is for uploading customer identification documents, such as IDs, for verification and authentication purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the category of the document you are uploading (e.g. category1, category2).
2. Provide a brief description of the document (e.g. "ID card issued by XYZ Authority").
3. Choose the type of document you are uploading (e.g. "upload file", "Other").
4. If you selected "upload file", choose the correct type of document (e.g. "type1", "type2", "type3").
5. Select a date for the document (this is an optional field and will not be required unless you need to specify a specific date).
6. Select a time for the document (this is an optional field and will not be required unless you need to specify a specific time).
7. Enter a valid email address associated with the document (this is an optional field and will not be required unless you need to provide contact information).
8. Upload the actual document file.

## Field-by-Field Explanation

* **customer_id** (Text, Required): Enter your customer ID number as per your identification document.
* **category** (Select One, Optional): Select the category of your document from the list provided.
* **description** (Text, Optional): Provide a brief description of the document you are uploading.
* **file** (Select One, Optional): Choose the type of document you are uploading (e.g. "upload file", "Other").
*   **file_type** (Select One, Optional): If you selected "upload file", choose the correct type of document you are uploading.
* **date** (Date, Optional): Enter the date of the document you are uploading.
* **time** (Time, Optional): Enter the time of the document you are uploading.
* **email** (Email, Optional): Enter a valid email address associated with the document.

## Tips
Please ensure that the uploaded document is in a valid format and is not corrupted or damaged. Also, make sure to follow the format guidelines for the document type you selected to ensure it's properly authenticated.
