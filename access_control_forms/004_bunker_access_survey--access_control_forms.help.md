# Bunker Access Survey - Help Guide
## Purpose
The Bunker Access Survey is designed to gather information about your experiences and perceptions of the bunker. Your feedback will help the management team identify areas for improvement and make informed decisions to enhance access and safety.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the form completely and honestly.
2. Answer all questions that apply to you.
3. If you have any additional comments or suggestions, use the "Additional Comments" field at the end of the form.

## Field-by-Field Explanation
### 1. **Respondent Information** (`1`)
Respondent Information is a note field for you to provide any additional details about yourself.

*   **Full Name** (`2`): Enter your full name.
*   **Employee ID** (`3`): Enter your employee identification number.
*   **Department** (`4`): Select the department or division you belong to:
    + Security
    + Operations
    + Maintenance
    + Administration
    + IT
    + Management
    + Other
*   **Access Frequency** (`5`): Rate how often you access the bunker:
    + Note field for your response.
*   **Visit Frequency** (`6`): Rate how often you enter the bunker:
    + Multiple Times Daily
    + Once Daily
    + Several Times Weekly
    + Once Weekly
    + Several Times Monthly
    + Once Monthly
    + Rarely
*   **Typical Purpose of Visit** (`7`): Select all that apply:
    + Equipment Monitoring
    + Maintenance Work
    + Security Checks
    + Data Collection
    + Emergency Response
    + Inspections
    + Storage Retrieval
    + Other
*   **Primary Access Method** (`8`): Select your primary method for accessing the bunker:
    + Key Card
    + Biometric Scanner
    + PIN Code
    + Physical Key
    + Security Escort
    + Remote Access
*   **Safety Assessment** (`9`): Enter your perception of the bunker's safety.
*   **Overall Safety Rating** (`10`): Rate how safe you feel in the bunker:
    + Very Safe
    + Safe
    + Neutral
    + Unsafe
    + Very Unsafe
*   **Ventilation Quality** (`11`): Rate the air quality and ventilation:
    + Excellent
    + Good
    + Acceptable
    + Poor
    + Very Poor
*   **Lighting Adequacy** (`12`): Rate if the lighting is sufficient:
    + Excellent
    + Good
    + Acceptable
    + Poor
    + Very Poor
*   **Emergency Exit Accessibility** (`13`): Confirm if emergency exits are clearly marked and accessible:
    + Yes - Very Clear
    + Yes - Adequate
    + Somewhat
    + No - Needs Improvement
    + No - Major Issues
*   **Safety Concerns** (`14`): Enter any safety concerns you have noticed.
*   **Access Issues** (`15`): Rate how often you experience access problems:
    + Never
    + Rarely
    + Sometimes
    + Often
    + Always
*   **Common Access Problems** (`16`): Select any issues you have encountered:
    + Card Reader Malfunction
    + System Downtime
    + Authorization Delays
    + Equipment Failure
    + Communication Issues
    + None
*   **Improvement Suggestions** (`17`): Enter any suggestions for improving bunker access.
*   **Additional Training Needed** (`18`): Confirm if you need more training for bunker access:
    + No - Fully Trained
    + Minor Refresher
    + Yes - Safety Procedures
    + Yes - Equipment Operation
    + Yes - Emergency Protocols
*   **Overall Satisfaction** (`19`): Rate your overall satisfaction with current bunker access:
    + Very Satisfied
    + Satisfied
    + Neutral
    + Dissatisfied
    + Very Dissatisfied
*   **Additional Comments** (`20`): Enter any other feedback or comments.

## Tips
*   Please answer all questions that apply to you.
*   If you have any additional comments or suggestions, use the "Additional Comments" field.
*   Your feedback is anonymous and will help the management team make informed decisions to improve access and safety.
