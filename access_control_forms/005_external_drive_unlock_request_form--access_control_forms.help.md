# External Drive Unlock Request Form - Help Guide

## Purpose
This form is used to request the unlock of an external drive, which is typically a device that is not managed by the organization's internal systems. The form is used to track the status of unlock requests and to ensure that they are properly managed.

Before submitting this form, please ensure that you have not already submitted a duplicate request for the same external drive. If you are unsure, please review the current status of your previous requests and ensure that this new request is for a different drive. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Category of the external drive (e.g. Security, IT).
2. Provide a brief Description of the external drive and its purpose.
3. Choose the Urgency of the request (e.g. High, Medium, Low).
4. Select the person who should be assigned to the task (e.g. John, Jane, Joe).
5. Enter the Drive Details, such as the model and serial number of the drive.
6. Enter the Date Requested if the request is for a specific date.
7. Enter the Due Date if the request is for a specific date.
8. Enter your Submitter information, including your Email and Department.
9. Check the Drive Status of the external drive (e.g. Locked, Unlocked, Disabled).
10. Add any additional Notes if necessary.
11. Select the Route to which the request should be sent.
12. Enter a Route Description if necessary.
13. Select any Comments regarding the route (e.g. Approved, Declined, Rejected).
14. Enter the Route To Email and Phone number (if applicable).
15. Select the Department to which the request should be sent.
16. Select the Route To Status (e.g. Pending, In Progress, Completed).
17. Enter any Comments regarding the route.
18. Select whether the external drive was Unlocked or not.
19. Select whether the Form was submitted via Phone, Email, or Form.

## Field-by-Field Explanation
* **Category** (`Security`, `IT`): Select the Category of the external drive.
* **Description** (text): A brief description of the external drive and its purpose.
* **Urgency** (High, Medium, Low): Select the urgency level of the request.
* **Assigned To** (`John`, `Jane`, `Joe`): The person assigned to the task.
* **Drive Details** (text): Enter the model and serial number of the external drive.
* **Date Requested** (date): Enter the date when the drive is requested to be unlocked.
* **Due Date** (date): Enter the date when the drive should be unlocked.
* **Submitted By** (text): Enter your name and title.
* **Submitter Email** (email): Enter your email.
* **Submitter Department** (`Sales`, `Marketing`, `IT`): Select your department.
* **Drive Status** (Locked, Unlocked, Disabled): Check the current status of the external drive.
* **Notes** (text): Add any additional details or comments.
* **Route to** (text): Select the route to which the request should be sent.
* **Route Description** (text): Enter a brief description of the route.
* **Comments** (Approved, Declined, Rejected): Select any comments regarding the route.
* **Route To Email** (email): Enter the email of the person who should receive the route.
* **Route To Phone** (text): Enter the phone number of the person who should receive the route.
* **Route To Department** (`Sales`, `Marketing`, `IT`): Select the department to which the request should be sent.
* **Route To Status** (Pending, In Progress, Completed): Select the status of the route.
* **Route To Comments** (text): Enter any comments regarding the route.
* **Route To Notes** (text): Add any additional details or comments.
* **Submitted Via** (Phone, Email, Form): Select how the form was submitted.
* **External Drive Unlocked** (`True`, `False`): Check whether the external drive was unlocked or not.
* **Form Submitted** (`True`, `False`): Check whether the form was submitted correctly.

## Tips
- Please ensure that you select the correct category and drive status.
- If the drive is already unlocked, please select "External Drive Unlocked" accordingly.
- If you are submitting the form via email, please include your email in the "Submitted By" field.
- If you are submitting the form via phone, please provide the phone number in the "Route To Phone" field.
- Please review the form carefully before submitting it to ensure that all fields are filled correctly.
