# Unmute Permission Request Form - Help Guide
## Purpose
This form is used for moderators to request that a user's account be allowed to unmute a channel.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are a moderator with permission to complete this form.
2. Fill out the form completely, including all required fields.

## Field-by-Field Explanation
### 1. **Unmute Permission Request Form** (`unmute_permission_request_form`, text, required)
The title of this form is informational and should not be changed.

### 2. **Moderator Name** (`moderator_name`, text, optional)
This field is used to record the name of the moderator who is requesting the unmute. If you are a moderator, you must enter your name.

### 3. **Reason** (`reason`, text, required)
Enter the reason for the unmute request. This helps the reviewer understand the context and make an informed decision.

### 4. **Channel ID** (`channel_id`, select one, required)
Select `Yes` if the user's channel is currently muted.

### 5. **Channel Name** (`channel_name`, text, optional)
Enter the name of the channel associated with the unmute request.

### 6. **Moderator ID** (`moderator_id`, text, required)
Enter the ID of the moderator who is requesting the unmute.

### 7. **User ID** (`user_id`, text, required)
Enter the ID of the user whose account is being requested to be unmuted.

### 8. **Date** (`date`, date, required)
Enter the date when the unmute should take effect.

### 9. **Time** (`time`, time, required)
Enter the time when the unmute should take effect.

### 10. **Unmute Duration** (`unmute_duration`, time, required)
Enter the duration of time for which the user's account should be unmuted.

### 11. **Unmute Until** (`unmute_until`, date, required)
Enter the date until which the user's account should be unmuted.

### 12. **Reason Selected** (`reason_selected`, select multiple, optional)
Select all reasons why the user's account should be unmuted. Note: This field is optional but can be used to provide additional context.

### 13. **Submit** (`submit`, select one, required)
Select `Yes` to submit the unmute request for review.

## Tips
- Make sure to fill out all required fields completely.
- Be as clear and concise as possible when entering the reason for the unmute request.
- Review the form carefully before submitting it for review.
