# Digital Access Key Reset Request - Help Guide

## Purpose
The purpose of this form is to reset the digital access key for a user. This form is used to cancel or revoke access to a digital resource for a user, typically when the user is no longer authorized to access it.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **User ID** of the account you want to reset access for.
2. Provide a **Reason** for the access reset request.
3. Choose a **Reset Date** for when the access will be reset.

## Field-by-Field Explanation

* **User ID**: This field is used to identify the user's account. Enter the exact User ID as it appears on their account profile.
* **Reason**: Please provide a brief description of why you are requesting to reset access for this user. This information will be used to understand the context of the request.
* **Reset Date**: This field is used to select the date when the access will be reset for the user. Choose a specific date in the format MM/DD/YYYY.

## Tips
* Make sure to enter the correct User ID to ensure the access request is directed to the correct user.
* The Reset Date should reflect when you want the access to be revoked for the user.
* This form should only be used for legitimate reasons. Abuse of this form may result in disciplinary action.
