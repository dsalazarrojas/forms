# Bluetooth Speaker Access Request Form - Help Guide
## Purpose
The Bluetooth Speaker Access Request Form is used to request access to a Bluetooth speaker for events or meetings.

## How To Complete This Form
1. Please fill out the form completely and accurately.
2. Ensure that you have not already submitted a request for the same event or purpose.
3. Be sure to select the correct department and equipment type needed.
4. Enter the correct event or purpose and details.
5. Choose the correct approval status and approve the terms of use.

## Field-by-Field Explanation

* **Requester Name**: <label> (1): Full name of person requesting equipment
	+ Please enter your full name as it appears on your official university ID or business card.
* **Requester Email**: <label> (2): Contact email address
	+ Enter your official email address.
* **Requester Phone**: <label> (3): Contact phone number
	+ Enter your phone number as it appears on your official university ID or business card.
* **Department**: <label> (4): Department or organization
	+ Select your department or organization from the list provided.
* **Equipment Type Needed**: <label> (5): Type of speaker needed
	+ Choose the type of speaker required for your event or meeting.
* **Specific Model Preference**: <label> (6): If you have a preference
	+ If you have a preference for a specific speaker model, enter it here.
* **Quantity Needed**: <label> (7): How many units?
	+ Enter the number of speakers you need.
* **Event or Purpose**: <label> (8): What is this equipment for?
	+ Briefly describe the event or purpose of the request.
* **Event Location**: <label> (9): Where will the equipment be used?
	+ Enter the location where the equipment will be used.
* **Pickup Date**: <label> (10): When do you need the equipment?
	+ Enter the date you need the equipment.
* **Pickup Time**: <label> (11): Preferred pickup time
	+ Enter the preferred time for pickup.
* **Return Date**: <label> (12): When will you return the equipment?
	+ Enter the date you expect to return the equipment.
* **Return Time**: <label> (13): Expected return time
	+ Enter the expected return time.
* **Additional Accessories Needed**: <label> (14): Select any accessories required
	+ Choose from the options provided if you need any additional accessories.
* **Special Requirements**: <label> (15): Any specific setup needs
	+ Briefly describe any specific setup needs.
* **Estimated Number of Attendees**: <label> (16): How many people will be present?
	+ Enter the estimated number of attendees.
* **Event Location Type**: <label> (17): Where will the event be held?
	+ Choose from the options provided.
* **Approval Status**: <label> (18): Current approval status
	+ Choose from the options provided.
* **Approver Name**: <label> (19): Name of approving authority
	+ Enter the name of the person or authority that approved the request.
* **Equipment Use Agreement**: <label> (20): I agree to handle equipment responsibly and return on time
	+ Choose from the options provided.

Please note that this form is subject to change, and new fields may be added or removed as necessary.
