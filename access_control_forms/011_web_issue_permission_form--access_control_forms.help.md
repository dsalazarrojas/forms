# Web Issue Permission Form - Help Guide

## Purpose
This form is used to request access to a web resource or feature that is necessary for you to perform your job duties. By completing this form, you will be able to report issues or request assistance from IT staff, who will work to resolve the problem as soon as possible.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide a brief summary of the issue in the "Issue Summary" field.
2. Describe the issue in more detail in the "Issue Description" field.
3. Indicate whether your supervisor has approved the issue (select "Yes" or "No" in the "Supervisor Approval" field).
4. Select all relevant IT staff members who need to be notified (e.g., IT Support, Web Developers, System Administrators) from the "IT Staff" field.
5. Report the date and time the issue was reported in the "Date and Time" field.
6. If you wish to receive email notifications about the issue, enter your email address in the "Email Notification" field.

## Field-by-Field Explanation
* **Issue Summary** (Text, Optional):
	+ Briefly describe the issue, e.g., "Issue with login credentials not working."
* **Issue Description** (Text, Optional):
	+ Provide more details about the issue, e.g., "Cannot log in after password reset."
* **Supervisor Approval** (Select One, Optional):
	+ Indicates whether your supervisor has approved the issue, e.g., "Yes, supervisor has approved."
* **IT Staff** (Select Multiple, Optional):
	+ Select all relevant IT staff members who need to be notified, e.g., "IT Support, Web Developers."
* **Date and Time** (Date, Optional):
	+ Report the date and time the issue was reported, e.g., "2022-02-20 14:30."
* **Email Notification** (Email, Optional):
	+ Enter your email address if you want to receive email notifications about the issue, e.g., "john.doe@example.com."
