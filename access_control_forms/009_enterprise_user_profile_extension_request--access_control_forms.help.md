# Enterprise User Profile Extension Request - Help Guide
## Purpose
This form is designed to be used by enterprise users to request an extension to their user profile.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your request in the text field on Page 1.
2. Provide your manager's email address in the "Manager Email" field.
3. Select the status of your request ("Approved", "Declined", or "Pending") from the dropdown list in the "Manager Approvals" field.
4. Enter your reason for requesting an extension in the text field "Reason for Request".

## Field-by-Field Explanation

### Page 1 - User Request
* **User Request** (`user_request`, text, required: false): Enter a brief description of your request for a user profile extension.
### Page 1 - Manager Email
* **Manager Email** (`manager_email`, email, required: false): Enter the email address of your manager who will be responsible for approving or denying your request.
### Page 1 - Manager Approvals
* **Manager Approvals** (`manager_approvals`, select_one, required: false): Select the status of your request. Options are:
	+ Approved
	+ Declined
	+ Pending
### Page 1 - Reason for Request
* **Reason for Request** (`reason_for_request`, text, required: false): Enter a brief explanation for why you are requesting an extension to your user profile.
