# IPTV Playlist Management Form - Help Guide
## Purpose
This form is used to create and manage IPTV playlists for customers.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "IPTV" option for the playlist type, as this form is specifically for IPTV playlists.
2. Choose the appropriate permission level for the update, either "Admin," "Reseller," or "Support."
3. Fill out the customer information section, including the customer's name, email, phone number, country, state, and zip code.
4. Attach any relevant documents or files to the request by using the "IPTV Playlist Request Attachment" fields.
5. Provide any additional comments or notes in the "IPTV Playlist Request Comments" field.

## Field-by-Field Explanation

* **IPTV Playlist Request** (`1`, text, required): Enter a brief description of the IPTV playlist request.
* **Request Date** (`2`, date, optional): Enter the date of the request.
* **Request Time** (`3`, time, optional): Enter the time of the request.
* **Customer Name** (`4`, text, optional): Enter the customer's name.
* **Customer Email** (`5`, email, optional): Enter the customer's email address.
* **Customer Phone** (`6`, text, optional): Enter the customer's phone number.
* **Playlist Type** (`7`, select_multiple, required): Select the type of playlist being requested, which should be "IPTV."
* **Channel List** (`8`, text, optional): Enter any additional channel information.
* **Update Reason** (`9`, text, optional): Enter a reason for the update request.
* **Update Permission** (`10`, select_one, required): Select the permission level for the update, which should be either "Admin," "Reseller," or "Support."
* **Ongoing Maintenance** (`11`, text, optional): Enter any ongoing maintenance details.
* **Notes** (`12`, text, optional): Enter any additional notes or comments.
* **IPTV Playlist Request Details** (`13`, text, optional): Enter any additional details about the request.
* **IPTV Playlist Request Notes** (`14`, text, optional): Enter any additional notes about the request.
* **IPTV Playlist Request Comments** (`15`, text, optional): Enter any additional comments about the request.
* **Customer IP** (`16`, text, optional): Enter the customer's IP address.
* **Customer Country** (`17`, select_one, required): Select the customer's country.
* **Customer State** (`18`, text, optional): Enter the customer's state.
* **Customer Zip** (`19`, text, optional): Enter the customer's zip code.
* **IPTV Playlist Request Attachment** (`20`, text, optional): Attach any relevant documents or files to the request.
* **IPTV Playlist Request Attachment 2** (`21`, text, optional): Attach any additional documents or files.
* **IPTV Playlist Request Attachment 3** (`22`, text, optional): Attach any further documents or files.
* **IPTV Playlist Request Attachment 4** (`23`, text, optional): Attach any additional documents or files.
* **IPTV Playlist Request Attachment 5** (`24`, text, optional): Attach any further documents or files.
* **IPTV Playlist Request Attachment 6** (`25`, text, optional): Attach any additional documents or files.

## Tips
* Double-check the customer's contact information to ensure accuracy.
* Attach any relevant attachments to provide a clear and detailed request.
* Use the "Notes" field for any additional comments or questions.
* Review the request carefully before submission to ensure completeness and accuracy.
