# Railcar Access Request Form - Help Guide
## Purpose
The Railcar Access Request Form is designed to request access to railcars for various purposes, such as maintenance, inspections, or operational needs.

## How To Complete This Form
To complete this form correctly, follow these steps:
1. Ensure you have a clear understanding of your request and that it's not a duplicate submission.
2. Fill out all required fields, marked as 'required'.
3. For select_one and select_multiple fields, select the most relevant option from the provided list.
4. Submit the form once you've filled out all required fields.

## Field-by-Field Explanation
* **Railcar Access Request** (`railcar_access_request`, `text`, optional): Enter a brief description of the railcar you're requesting access to, including its location and purpose of access.
* **Date** (`date`, `date`, optional): Select the date you need access to the railcar.
* **Supervisor Review** (`supervisor_review`, `select_one`, optional): Check the box to indicate if you need supervisor approval for your request. If yes, the request will be reviewed and approved by a supervisor before access is granted.
* **Rail Yards** (`rail_yards`, `select_multiple`, optional): Select all the rail yards you need access to, if applicable.
* **Maintenance Teams** (`maintenance_teams`, `select_multiple`, optional): Select all the maintenance teams you need access to, if applicable.
* **Contractors** (`contractors`, `select_multiple`, optional): Select all the contractors you need access to, if applicable.

## Tips
- Be as specific as possible when filling out the Railcar Access Request field to ensure your request is accurately evaluated.
- If you're unsure about any field, contact the relevant team or supervisor for guidance.
- If you've filled out the form and need to make changes, you can submit updates through the same form.
