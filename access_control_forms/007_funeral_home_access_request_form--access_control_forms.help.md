# Funeral Home Access Request Form - Help Guide
## Purpose
The Funeral Home Access Request Form is used to request access to a funeral home during specific time periods.

## How To Complete This Form
To complete this form, follow the steps below:
1. Select the time period for which you need access to the funeral home from the dropdown menu on page 1 of the form.
2. On page 2 of the form, enter any additional information that you'd like to share with the staff.
3. If you need to specify which groups you need access for (e.g. family members, staff, etc.), select them on page 3.
4. On page 4, if you'd like to request any special notes about your request, you can add them here.
5. On page 5, enter the date you'd like to request access for, if applicable.
6. On page 6, enter the time you'd like to request access for, if applicable.
7. On page 7, enter your email address so that we can contact you with updates about your request.
8. Finally, on page 8, enter any additional information you'd like to share with the staff.

## Field-by-Field Explanation
* **9 to 5** (`funeral_home_access_request_form_page_1`, select_one, required/optional): Select the time period you need access for. The options are: 9 to 5, 6 to 12, 13 to 17, 18 to 20, 21 to 24, or 25 to 27.
* **Funeral Home Access Request** (`funeral_home_access_request_form_page_2`, text, required/optional): Enter any additional information that you'd like to share with the staff.
* **Access Group** (`funeral_home_access_request_form_page_3`, select_multiple, required/optional): Select which groups you need access for. Options are: Family members, Staff, Other.
* **Special Notes** (`funeral_home_access_request_form_page_4`, note, required/optional): If you'd like to add any special notes or requests, enter them here.
* **Date of Access** (`funeral_home_access_request_form_page_5`, date, required/optional): Enter the date you'd like to request access for.
* **Time of Access** (`funeral_home_access_request_form_page_6`, time, required/optional): Enter the time you'd like to request access for.
* **Email** (`funeral_home_access_request_form_page_7`, email, required/optional): Enter your email address so that we can contact you with updates about your request.
* **Additional Information** (`funeral_home_access_request_form_page_8`, text, required/optional): Enter any additional information you'd like to share with the staff.
