# Workspace Creation Form - Help Guide

## Purpose
The Workspace Creation Form is a tool for administrators to create new workspaces for various teams, departments, and projects. It collects information such as team members, access preferences, and workspace details to enable efficient workspace management.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the team members to be included in the new workspace from the provided list.
2. Choose the access preferences for the new workspace (Public, Private, or Protected).
3. Enter the department where the new workspace falls under (IT, Development, Marketing, or Finance).
4. Type in the URL of the new workspace, which will be used to access it directly.
5. Select the type of the new workspace (Team, Project, Community, or Event).
6. Enter a short description of the new workspace.
7. Provide the name of the new workspace.
8. (Optional) Set a launch date for the new workspace, which is not required.

## Field-by-Field Explanation

* **Team Members** (`team_members`, select_multiple, optional): Select team members to be included in the new workspace. Choose from the provided list of names.
* **Access Preferences** (`access_preferences`, select_one, optional): Choose the access preferences for the new workspace (Public, Private, or Protected).
* **Team Invite** (`team_invite`, text, optional): Enter the invite link for the new workspace, which will be generated automatically once a workspace is created.
* **Department** (`department`, select_one, optional): Select the department where the new workspace falls under (IT, Development, Marketing, or Finance).
* **Workspace URL** (`workspace_url`, text, optional): Enter the URL of the new workspace, which will be used to access it directly.
* **Workspace Type** (`workspace_type`, select_one, optional): Select the type of the new workspace (Team, Project, Community, or Event).
* **Workspace Description** (`workspace_description`, text, optional): Enter a short description of the new workspace.
* **Workspace Name** (`workspace_name`, text, optional): Provide the name of the new workspace.
* **Launch Date** (`launch_date`, date, optional): Set a launch date for the new workspace, which is not required.
* **Form ID** (`form_id`, number, optional): This field is currently not used in the form and can be ignored.

Note: This form is designed for administrators to create new workspaces. If you are not an administrator, please do not attempt to complete this form.
