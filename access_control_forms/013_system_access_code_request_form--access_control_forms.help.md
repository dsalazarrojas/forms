# System Access Code Request Form - Help Guide

## Purpose

The System Access Code Request Form is used to submit requests for access codes to access a system. 

## How To Complete This Form

1. Fill out the form completely and accurately to avoid delays in processing your request.
2. Make sure you are filling out the correct form for your access request.
3. Check that you are not duplicating an existing access code request.

## Field-by-Field Explanation

* **Request Details (page 1)** (`system_access_code_request_form`, text, optional): 
  This field is used to provide a brief description of the system access code request.
* **Request Date (page 1)** (`request_date`, date, optional): 
  Enter the date of the request in the correct format (mm/dd/yyyy).
* **Request Time (page 1)** (`request_time`, time, optional): 
  Enter the time of the request in the correct format (HH:MM).
* **Request Description (page 1)** (`request_description`, text, optional): 
  Enter a short description of why the system access code is needed.
* **Access Code (page 2)** (`access_code`, select_one, optional): 
  Choose the correct access code to be granted for the system access.
* **Requestor Name (page 2)** (`requestor_name`, text, optional): 
  Enter your name as the person requesting the access code.
* **Department (page 2)** (`department`, select_one, optional): 
  Choose the department associated with the access request.
* **Employee ID (page 2)** (`employee_id`, text, optional): 
  Enter your employee ID to ensure accurate tracking of your access request.
* **Requestor Email (page 2)** (`requestor_email`, email, optional): 
  Enter your email to ensure you can be reached for further information.

## Tips

* Please ensure that the information entered is accurate and complete.
* If you are unsure about the access code request, do not hesitate to ask your supervisor or department head for guidance.
* Please be patient and do not resubmit the request multiple times, as this can cause delays in processing the request.
