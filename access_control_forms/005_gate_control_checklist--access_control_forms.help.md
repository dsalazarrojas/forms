# Gate Control Checklist - Help Guide
## Purpose
The Gate Control Checklist is a form designed to help maintain accurate and up-to-date records of access points and their security levels. It is intended to provide a structured way to collect information about access points and their current security status.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Access Point Inspection" field to enter a description or details about the access point.
2. For "Inspection Date", select the date when the inspection was performed.
3. In "Gate Number", enter the unique identification number of the access point.
4. For "Security Level", select one of the three options: High, Medium, or Low, to classify the access point's security level.
5. In "Notes", enter any additional comments or observations about the access point.
6. For "Email" and "Phone", enter contact information for the person responsible for the access point's security level.
7. Finally, enter the name of the "Assigned User" who is responsible for the access point.

* **Access Point Inspection** (Required)
	+ This field is used to describe the access point.
* **Inspection Date** (Required)
	+ This field is used to record the date when the inspection was performed.
* **Gate Number** (Required)
	+ This field is used to track the unique identification number of the access point.
* **Security Level** (Optional)
	+ This field is used to classify the access point's security level as High, Medium, or Low.
* **Notes** (Optional)
	+ This field is used to capture any additional comments or observations about the access point.
* **Email** (Optional)
	+ This field is used to enter contact information for the person responsible for the access point's security level.
* **Phone** (Optional)
	+ This field is used to enter contact information for the person responsible for the access point's security level.
* **Assigned User** (Optional)
	+ This field is used to track the person assigned to the access point.
