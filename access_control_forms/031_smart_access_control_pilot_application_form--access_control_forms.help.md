# Smart Access Control Pilot Application Form - Help Guide
## Purpose
The Smart Access Control Pilot Application Form is designed to collect user information for access control pilot applications, including applicant details, contact information, and scheduling information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all the required fields. The form is submitted when you select the "Submit" option.
2. Review the "Field-by-Field Explanation" section for specific guidance on each field.

## Field-by-Field Explanation
* **Smart Access Control Pilot Application Form** (`first_page`, text, optional): This is the title of the form. You can leave this field blank if you don't want to change the default title.
* **applicant_details** (`applicant_details`, select_multiple, optional): Select one or more of the provided options for applicant details.
* **Contact Details** (`contact_details`, text, optional): Enter the contact details for the pilot application.
* **email** (`email`, email, optional): Enter the email address for the pilot application.
* **phone** (`phone`, text, optional): Enter the phone number for the pilot application.
* **date** (`date`, date, optional): Select the date for the pilot application.
* **time** (`time`, time, optional): Select the time for the pilot application.
* **note** (`note`, note, optional): Enter any additional information for the pilot application.
* **Submit**/**Save for later** (`submit`, select_one, required): Choose between submitting the application and saving it for later.
