# Access Control Unit Setup Form - Help Guide
## Purpose
The Access Control Unit Setup Form is used to collect information about the access control unit during installation. This form ensures that all necessary details are captured accurately and consistently for record-keeping and future reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the installer's name, company, and installation date and time.
2. Provide the unit's model number and serial number.
3. Specify the installation location, access point type, and power source.
4. Select the unit's connectivity type and supported access methods.
5. Enter the firmware version and network configuration (if applicable).
6. Specify the default access permissions and integration requirements.
7. Provide the supervisor's approval and any additional notes.

## Field-by-Field Explanation

* **Installer Name** (`installer_name`): Enter the full name of the technician performing the installation.
* **Installer Company** (`installer_company`): Enter the company name of the installing party.
* **Installation Date** (`installation_date`): Enter the date of the unit installation.
* **Installation Time** (`installation_time`): Enter the time when the installation was completed.
* **Unit Model** (`unit_model`): Enter the model number of the access control unit.
* **Unit Serial Number** (`unit_serial_number`): Enter the serial number of the access control unit.
* **Installation Location** (`installation_location`): Enter the building, floor, and specific location of the unit.
* **Access Point Type** (`access_point_type`): Select the type of access point being controlled (e.g., Main Entrance, Side Door, etc.).
* **Power Source** (`power_source`): Select the power source of the unit (e.g., Hardwired, Battery Operated, etc.).
* **Connectivity Type** (`connectivity_type`): Select the type of connectivity the unit uses (e.g., Ethernet, WiFi, etc.).
* **Supported Access Methods** (`access_methods_supported`): Select all the access methods the unit supports (e.g., Card Reader, Biometric Scanner, etc.).
* **Firmware Version** (`firmware_version`): Enter the current firmware version installed on the unit.
* **Network Configuration** (`network_configuration`): Enter the IP address, subnet, gateway, etc. of the unit (optional).
* **Default Access Permissions** (`default_access_permissions`): Enter the default access permissions granted by the unit.
* **Integration Requirements** (`integration_requirements`): Select if the unit needs to integrate with other systems (e.g., HR System, Time Tracking, etc.).
* **Maintenance Schedule** (`maintenance_schedule`): Enter the recommended maintenance schedule for the unit (optional).
* **Supervisor Approval** (`supervisor_approval`): Enter the name of the approving supervisor.
* **Additional Notes** (`additional_notes`): Enter any other information about the installation.

## Tips

* Make sure to fill out the form accurately and completely.
* Review each field carefully before submitting the form.
* If you are unsure about any field, refer to the provided hints or contact the relevant team for clarification.
* Ensure that all required fields are filled out before submitting the form.
