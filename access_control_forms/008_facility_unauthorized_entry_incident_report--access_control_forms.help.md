# Facility Unauthorized Entry Incident Report - Help Guide
## Purpose
The Facility Unauthorized Entry Incident Report form is used to document and report incidents that occur within a facility. This form helps to gather detailed information about the incident, including the facility involved, the type of incident, and any supporting documentation.

## How To Complete This Form
1. Choose the correct facility name from the list of options.
2. If the incident occurred on a specific date, enter the date in the format MM/DD/YYYY.
3. Enter a brief description of the incident.
4. Select the type of incident that occurred from the options provided (e.g., Trespasser, Security Breach, Property Damage, Theft, or Fire).
5. Enter the location where the incident occurred.
6. Select the individual who reported the incident from the options provided (e.g., Security Officer, Maintenance, or Visitor).
7. Enter a brief summary of the incident.
8. If applicable, provide any supporting documentation related to the incident.
9. Enter the email address of the person submitting the report.
10. Enter the date and time the report was submitted.

## Field-by-Field Explanation

* **Facility Name** (`facility_name`, select_one): Choose the correct facility name from the list of options. This field is required.
* **Incident Date** (`incident_date`, date): Enter the date on which the incident occurred, in the format MM/DD/YYYY. This field is optional.
* **Time of Incident** (`time_of_inincident`, time): Enter the time the incident occurred. This field is optional.
* **Description** (`description`, text): Enter a brief description of the incident. This field is optional.
* **Incident Type** (`incident_type`, select_one): Select the type of incident that occurred from the options provided (e.g., Trespasser, Security Breach, Property Damage, Theft, or Fire). This field is required.
* **Location** (`location`, text): Enter the location where the incident occurred. This field is optional.
* **Incident Reporter** (`incident_reporter`, select_one): Select the individual who reported the incident from the options provided (e.g., Security Officer, Maintenance, or Visitor). This field is required.
* **Incident Summary** (`incident_summary`, text): Enter a brief summary of the incident. This field is optional.
* **Supporting Documents** (`supporting_documents`, text): If applicable, provide any supporting documentation related to the incident. This field is optional.
* **Submitted by** (`submitted_by`, email): Enter the email address of the person submitting the report. This field is optional.
* **Submitted on** (`submitted_on`, date): Enter the date and time the report was submitted. This field is optional.
* **Updated by** (`updated_by`, email): Enter the email address of the person who last updated the report. This field is optional.

## Tips
* Make sure to complete all required fields (Facility Name, Incident Type, Incident Reporter, and Incident Summary).
* Enter all relevant information to help investigators and facility management teams understand the incident.
* If you are unsure about any field, do not hesitate to reach out to facility management for clarification.
* Supporting documentation, if provided, will be attached to the report, if available.
