# Virtual Desktop Access License Request Form - Help Guide
## Purpose
This form is used to request access to a virtual desktop for work purposes. It collects information from both the submitting user and the approver to facilitate the approval process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Submitter User: Enter your name and username.
	* Submitter Department: Select your department from the list.
	* Submitter Job Title: Enter your job title.
	* Approver: Select the approver from the list.
	* Approval Date: Enter the date you want the access to be approved.
	* Submitter Email: Enter your email address.
	* Approver Email: Enter the approver's email address.
2. Fill in the optional fields as needed:
	* Submitter Location: Select your location from the list.
	* Approver Department: Select the approver's department from the list.
	* Approver Location: Select the approver's location from the list.
	* Submitter Note: Add any additional notes about your request.
	* Approver Note: Add any additional comments about the approval.
	* Supporting Document 1, 2, 3: Attach any supporting documents as needed.
	* Submitter Phone: Enter your phone number.
	* Approver Phone: Enter the approver's phone number.
	* Approver Job Title: Enter the approver's job title.
	* Approver Comment: Add any additional comments about the approval.
