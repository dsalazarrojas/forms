# Network Access Restrictions Survey - Help Guide
## Purpose
This survey aims to gather information about network access restrictions that may be impacting employee productivity and satisfaction. Please answer these questions to help us understand your access restrictions and provide suggestions for improvement.

## How To Complete This Form

1. Select the "Yes" or "No" options for each question regarding access restrictions and employee suggestions.
2. Enter your employee ID in the "Employee ID" field.
3. For "Attachment Upload", please upload a file to support your suggestions or comments.
4. Enter your email address in the "Email" field.
5. If you have any additional comments or suggestions, enter them in the "Comments" field.
6. For "Upload Status" and other fields related to file upload, please follow the guidance provided.

## Field-by-Field Explanation

* **Network Access Restrictions (Page 1)** (`network_access_restrictions_survey_page_1`, Select One, Required): Answer "Yes" if you have network access restrictions that impact your productivity, "No" otherwise.
* **Employee ID** (`employee_id`, Text, Required): Enter your employee ID to associate your survey responses with your identity.
* **Department** (`department`, Select One, Required): Select "Yes" if your department has access restrictions that impact your productivity, "No" otherwise.
* **Restricted Areas** (`restricted_areas`, Select Multiple, Optional): List areas where access restrictions are in place.
* **Access Restrictions Type** (`access_restrictions_type`, Select One, Required): Answer "Yes" if you have access restrictions on the type of data you can access.
* **Access Restrictions Level** (`access_restrictions_level`, Select One, Optional): Choose "High" or "Low" to indicate the level of access restrictions.
* **Productivity Impact** (`productivity_impact`, Select One, Optional): Answer "Yes" if access restrictions affect your productivity.
* **Satisfaction** (`satisfaction`, Number, Required): Rate your satisfaction with the current access restrictions (1-10).
* **Comments** (`comments`, Note, Optional): Enter any comments or suggestions you have regarding access restrictions.
* **Email** (`email`, Email, Required): Enter your email address to facilitate communication.
* **Phone** (`phone`, Text, Optional): Enter your phone number for follow-up communication.
* **Employee Suggestions** (`employee_suggestions`, Select Multiple, Optional): List any employee suggestions for improvement.
* **Management Suggestions** (`management_suggestions`, Select Multiple, Optional): List any management suggestions for improvement.
* **Technical Suggestions** (`technical_suggestions`, Select Multiple, Optional): List any technical suggestions for improvement.
* **Additional Comments** (`additional_comments`, Note, Optional): Enter any additional comments or suggestions.
* **Attachment Upload** (`attachment_upload`, Text, Optional): Upload a file to support your suggestions or comments.
* **File Name** (`file_name`, Text, Optional): Enter a name for the uploaded file.
* **File Size** (`file_size`, Text, Optional): Enter the size of the uploaded file.
* **File Type** (`file_type`, Select One, Optional): Answer "Yes" if the uploaded file is of the correct type.
* **Upload Error Message** (`upload_error_message`, Select One, Optional): Check this field to see if there were any errors with the upload.
* **Upload Status** (`upload_status`, Select One, Optional): Check the status of your uploaded file.
* **Attachment Upload** (`attachment_upload`, Text, Optional): Upload another attachment to support your suggestions or comments.
* **Attachment Name** (`attachment_name`, Text, Optional): Enter a name for the uploaded attachment.
* **Attachment Description** (`attachment_description`, Text, Optional): Enter a description for the uploaded attachment.
* **Attachment URL** (`attachment_url`, Text, Optional): Enter the URL of the uploaded attachment.
