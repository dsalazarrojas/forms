# industrial_site_access_control_request - Help Guide
## Purpose
The "Industrial Site Access Control Request" form is designed to collect information necessary for granting access to an industrial site. This form gathers details about visitors, their contact and access requests, and associated processes.

## How To Complete This Form
To fill out this form, follow these steps:

1. **Visitor Information**:
	* Fill in the visitor's name.
	* Enter the visitor's company or organization, if applicable.
2. **Contact Information**:
	* Provide the visitor's contact name.
	* Enter the visitor's contact number.
3. **Access Request**:
	* Describe the purpose of the visit or the requested access type.
4. **Submission Information**:
	* Add any additional comments or information about the visit.
5. **Submitter**:
	* Enter your name and title, if you're submitting the request on behalf of the visitor.
6. **Visitor Entry/Exit Information**:
	* Specify the entry and exit methods and times.
7. **Facility Access Request Information**:
	* Provide any additional details about the access request.
8. **Approval Status**:
	* Select the approval status as either "Approved" or "Rejected".
9. **Comments**:
	* Add any additional comments or remarks about the request.
10. **Approval Date/Time**:
	* Enter the date and time the request was approved or rejected.
11. **Approved**:
	* Select whether the request was approved or rejected.
12. **Facility ID/Code**:
	* Enter the facility ID or code, if applicable.
13. **Site ID/Code**:
	* Enter the site ID or code, if applicable.
14. **User ID**:
	* Enter the user ID, if applicable.
15. **Request Date/Time**:
	* Enter the date and time the request was made.
16. **Entry/Exit Time**:
	* Enter the entry and exit times, if applicable.
17. **Access Type**:
	* Select the access type from the available options.
18. **Site Code**:
	* Enter any additional site-specific code, if applicable.
19. **Entry Method**:
	* Select the entry method from the available options.
20. **Exit Method**:
	* Select the exit method from the available options.
21. **Notes**:
	* Add any additional notes or information about the request.

## Tips

* Ensure you've filled in all required fields accurately.
* Review your submission for completeness and consistency before submitting.
* Follow up with the visitor to confirm their information and request details.
* Verify the status of the request with the visitor after submission.
* Keep a record of the approved or rejected requests for future reference.
