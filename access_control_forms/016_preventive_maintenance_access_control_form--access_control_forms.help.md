# Preventive Maintenance Access Control Form - Help Guide

## Purpose
This form is used to control and manage access to preventive maintenance activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form carefully to understand the purpose of each section.
2. Fill out each field accurately and correctly, making sure to select the correct options for each field.
3. Ensure that all required fields are filled out before submitting the form.
4. Review the form for completeness and accuracy before submitting it.

## Field-by-Field Explanation

* **Scheduled Maintenance** (`scheduled_maintenance`, text, optional): Enter a brief description of the scheduled maintenance activity.
* **Access Type** (`access_type`, select_one, optional): Select the type of access required for the maintenance activity, such as Maintenance Worker, Maintenance Manager, or Maintenance Supervisor.
* **Maintenance Area** (`maintenance_area`, text, optional): Enter the area where the maintenance activity will take place.
* **Start Date** (`access_start_date`, date, optional): Enter the start date of the maintenance activity.
* **End Date** (`access_end_date`, date, optional): Enter the end date of the maintenance activity.
* **Reason for Access** (`reason_for_access`, text, optional): Enter a brief reason for granting access to the maintenance activity.
* **Maintenance Status** (`maintenance_status`, select_one, optional): Select the current status of the maintenance activity, such as Pending, In Progress, or Completed.
* **Maintenance Type** (`maintenance_type`, select_multiple, optional): Select the type of maintenance activity, such as Scheduled, Unscheduled, or Emergency.
* **Access Level** (`access_level`, select_one, optional): Select the level of access required for the maintenance activity, such as Supervisor, Manager, or Employee.
* **Assigned To** (`assigned_tool`, select_one, optional): Select whether a tool has been assigned for the maintenance activity, such as Yes or No.
