# Security PIN Registration Request - Help Guide
## Purpose
The Security PIN Registration Request form is designed for users to register a security PIN for access control purposes. This form allows users to provide essential information to improve access control and security. It is recommended to fill out this form to have a unique six-digit security PIN.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the User Details field with your information.
2. Select the Access Reasons that apply to you from the dropdown list.
3. Read and acknowledge the Policy Acknowledgments field.
4. Choose a date for the Access Request Date field.
5. Enter a six-digit Security PIN in the Security PIN field.

## Field-by-Field Explanation
* **User Details** (`user_details`, text, required/optional): Enter your name and other relevant information.
* **Access Reasons** (`access_reasons`, select_multiple, required/optional): Select all the reasons that apply to you to justify your access request.
* **Policy Acknowledgments** (`policy_acknowledgments`, note, required/optional): Read and acknowledge the policy information provided.
* **Access Request Date** (`access_request_date`, date, required/optional): Choose the date of your access request.
* **Security PIN** (`security_pin`, number, required/optional): Enter a unique six-digit security PIN to secure your access requests.
