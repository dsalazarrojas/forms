# Smart Monitoring Access Request Form - Help Guide
## Purpose

This form is used to request access to monitoring systems for various purposes, such as troubleshooting, maintenance, or testing. 

## How To Complete This Form

1. Please fill out the form with the required information to ensure your request is processed efficiently.
2. Review each field carefully and answer according to your specific situation.
3. If you need to request access for an organization or team, please provide their information.
4. Make sure to provide a clear reason for requesting access.
5. If you are requesting access for a recurring reason (e.g., for maintenance), specify the duration of access.

## Field-by-Field Explanation

* **Requester Information**:
	+ This field is used to capture the person or organization requesting access.
* **Monitor Type**:
	+ This field allows you to specify the type of monitoring system you are requesting access to (e.g., Monitoring System, Smart Monitoring System).
* **System Information**:
	+ This field is used to provide details about the system you are requesting access to.
* **Access Level**:
	+ This field allows you to specify the level of access you need (e.g., Read-Only, Read/Write).
* **Access Reason**:
	+ Please provide a clear reason for requesting access.
* **Duration**:
	+ If you are requesting access for a recurring reason, specify the duration of access in days.
* **Frequency**:
	+ This field allows you to specify if the access is one-off or recurring.
* **Frequency Unit**:
	+ This field allows you to specify the unit of time for recurring access (e.g., Days, Weeks).
* **Frequency Date**:
	+ If you are requesting recurring access, please specify the date when the access starts.
* **Access Start**:
	+ This field is used to specify when you want access to start.
* **End Date**:
	+ This field is used to specify when you want access to end.
* **End of Access**:
	+ This field is used to specify when access will end.
* **Reviewer Comments**:
	+ This field is for the reviewer to add any additional comments about the request.
