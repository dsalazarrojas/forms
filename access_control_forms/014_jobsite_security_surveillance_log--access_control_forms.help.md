# jobsite-security-surveillance-log - Help Guide
## Purpose
This form is used to log and document various aspects of a jobsite's security and surveillance activities.

## How To Complete This Form
1. Fill out the form completely and accurately for each shift.
2. Ensure you have permission to access and complete the form.
3. Use the provided options for each field to select the correct information.

## Field-by-Field Explanation
* **Patrol Activity** (`1`, `date`, required): Record the date of the patrol activity.
* **Incident Report** (`7`, `select_one`, required): Select one of the following options: No Incident, Incident Reported, Incident Under Investigation, or Incident Closed.
* **Officer Remarks** (`3`, `text`, optional): Record any additional officer remarks or comments regarding the shift.
* **Shift Notes** (`4`, `text`, optional): Record any notes about the shift, including any relevant information or observations.
* **Notes** (`5`, `text`, optional): Record any additional notes or comments.
* **Incident Photos** (`6`, `note`, optional): Attach photos related to the incident, if applicable.
* **Incident Date** (`8`, `date`, optional): Record the date of the incident, if applicable.
* **Incident Time** (`9`, `time`, required): Record the time of the incident.
* **Incident Description** (`10`, `text`, optional): Record a brief description of the incident, if applicable.
* **Security Vehicles Present** (`11`, `select_multiple`, optional): Select all security vehicles present during the incident, including Police Vehicle, Fire Truck, Ambulance, or Other.
* **Security Personnel Present** (`12`, `select_multiple`, required): Select all security personnel present during the incident, including Officer A, Officer B, or Other.
* **Incident Investigation Status** (`13`, `select_one`, required): Select one of the following options: Not Started, In Progress, or Closed.
* **Notes on Investigation** (`14`, `text`, required): Record any notes on the investigation, if applicable.
* **Investigation Duration** (`15`, `number`, required): Record the duration of the investigation.
* **Incident Resolution Status** (`16`, `select_one`, required): Select one of the following options: Not Resolved, Resolved.
* **Notes on Resolution** (`17`, `text`, required): Record any notes on the resolution, if applicable.
* **Shift Duration** (`18`, `number`, required): Record the duration of the shift.
* **Start Date and Time** (`19`, `date`, required): Record the start date and time of the shift.
* **Finish Date and Time** (`20`, `date`, required): Record the finish date and time of the shift.
* **Officer Safety Briefing** (`21`, `text`, optional): Record any information regarding the officer safety briefing, if applicable.
* **Officer Briefing Notes** (`22`, `text`, optional): Record any notes about the officer briefing, if applicable.
* **Incident Safety Plan** (`23`, `text`, optional): Record any safety plan related to the incident, if applicable.
* **Weather Conditions** (`24`, `text`, optional): Record any notable weather conditions, if applicable.
* **Additional Remarks** (`25`, `text`, optional): Record any additional information or comments.
