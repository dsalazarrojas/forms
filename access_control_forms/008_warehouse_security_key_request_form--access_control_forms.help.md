# Warehouse Security Key Request Form - Help Guide

## Purpose
This form is used to request a warehouse security key for access to a specific facility, purpose, or manager.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and date of access request in the "user" and "date" fields.
2. Provide a brief description of the reason you need to access the warehouse security key in the "purpose" field.
3. Select the facility you need access to from the dropdown list of facilities.
4. If applicable, select the manager(s) you are requesting access through.
5. Provide the manager's name and title (if applicable) for their acknowledgment.
6. Acknowledge the policy by selecting one or more of the options in the "policy acknowledgement" field.
7. If your request is approved or denied, enter the name and title of the approving or denying authority in the "approved by" and "declined by" fields.
8. If your request is approved, enter the date of approval in the "approved on" field.
9. If your request is denied, enter the date of denial in the "declined on" field.

## Field-by-Field Explanation

* **user** (text): Enter your name as it should be displayed on the security key.
* **date** (date): Enter the date you need access to the warehouse security key.
* **purpose** (text): Provide a brief description of the reason you need to access the warehouse security key.
* **facility** (text): Select the facility you need access to from the dropdown list.
* **manager** (text): If you are requesting access through a manager, enter their name and title (if applicable).
* **signature** (text): Enter the manager's acknowledgment of your request.
* **policy_acknowledgement** (select multiple): Acknowledge that you understand and agree to the security policy. Select all that apply.
* **approved_by** (text): If your request is approved, enter the name and title of the approving authority.
* **approved_on** (date): If your request is approved, enter the date of approval.
* **declined_by** (text): If your request is denied, enter the name and title of the denying authority.
* **declined_on** (date): If your request is denied, enter the date of denial.
