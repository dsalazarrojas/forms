# Factory Access Control System Order Form - Help Guide
## Purpose
This form is used to request an installation of the factory access control system. Please complete the form carefully to provide all necessary information for the installation process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately.
2. Review the form for any errors or missing information before submitting.
3. Submit the form to the designated authority.

## Field-by-Field Explanation
### Factory Access Control System Form
* **Factory Access Control System Form** (`factory_access_control_system_form`, text, required): This field is the main title of the form, which you should not need to fill out as it is already filled out for you.
### Install Request
* **Install Request** (`install_request`, text, required): Please provide a brief description of the installation request, including any specific requirements or requests you have.
### Install Date
* **Install Date** (`install_date`, date, required): Enter the date you would like the installation to take place.
### Install Time
* **Install Time** (`install_time`, time, required): Enter the time you would like the installation to take place.
### Centralize Data
* **Centralize Data** (`centralize_data`, text, optional): This field is used to provide any additional data you would like to centralize with the system.
### Facility Teams
* **Facility Teams** (`facility_teams`, select_one, optional): Please select "Yes" if you have multiple teams at your factory that need access to the system.
### Security Teams
* **Security Teams** (`security_teams`, select_multiple, optional): Please select "Yes" if you have security teams at your factory that need access to the system, and select as many teams as necessary.
### Comments
* **Comments** (`comments`, note, optional): Please use this field to provide any additional comments or information about your order.
### Facility Name
* **Facility Name** (`facility_name`, text, required): Enter the name of your facility.

## Tips
* Make sure to review the form carefully before submission to avoid errors.
* If you have any questions or concerns, please contact the designated authority.
* This form is for factory access control system installations only.
