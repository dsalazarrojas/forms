# Building Access Security Assessment Form - Help Guide
## Purpose
This form is used to assess the security of a building by evaluating various aspects of the physical security measures in place.

## How To Complete This Form

1.  Review each section of the form carefully, as it is divided into several key areas of assessment.
2.  Answer each question based on your observation of the building's security measures, including any documentation or evidence you may have.
3.  Select the most accurate options for each question, based on your evaluation.
4.  Complete all required fields before proceeding to the next section.
5.  If you are unsure about any question, please indicate this in the notes section.

## Field-by-Field Explanation

### Assessment date

*   **Assessment date** (1): Date of the assessment.
    *   Record the date you completed the assessment.

### Assessor name and title

*   **Assessor name** (2): Name of the person conducting the assessment.
    *   Enter your name as it appears on your business card or ID badge.
*   **Assessor title** (3): Title of the person conducting the assessment.
    *   Enter your job title or position.

### Building information

*   **Building name and address** (4): Name and address of the building.
    *   Record the building's name and physical address.

### Building type

*   **Building type** (6): Type of building (e.g., Office building, Residential, Medical facility, etc.).
    *   Select the type of building from the list of options.

### Perimeter Security

*   **Fence condition and integrity** (8): Condition and integrity of the fence surrounding the building.
    *   Select the condition of the fence from the options (Excellent - Intact and secure, Good - Minor wear, etc.).
*   **Gate security and operation** (9): Security and operation of the gates surrounding the building.
    *   Select the status of the gates from the options (Fully functional, Mostly functional, Partially functional, etc.).
*   **Perimeter lighting** (10): Lighting around the perimeter of the building.
    *   Select the coverage of perimeter lighting from the options (Adequate throughout, Adequate in most areas, etc.).
*   **Number of monitored entry points** (11): Number of entry points that are monitored.
    *   Record the number of monitored entry points.
*   **Entry point access control** (12): Type of control in place at entry points.
    *   Select the type of control from the options (Controlled at all entry points, Controlled at main entrance only, etc.).

### Access Control System

*   **Primary access control system type** (14): Type of access control system used in the building.
    *   Select the type of system from the options (Keycard/badge, Biometric, Code/PIN, etc.).
*   **System age** (15): Age of the access control system.
    *   Select the age of the system from the options (Less than 2 years old, 2-5 years old, etc.).
*   **System maintenance status** (16): Status of the access control system's maintenance.
    *   Select the maintenance status from the options (Current with maintenance plan, Current but no formal plan, etc.).
*   **Credential management procedures** (17): Procedures for managing access credentials.
    *   Select the type of procedures from the options (Well-established and documented, Established but informal, etc.).

### Visitor and Contractor Management

*   **Visitor check-in protocol** (19): Protocol for checking in visitors.
    *   Select the type of protocol from the options (Formal process with badges, Sign-in required, etc.).
*   **Contractor access procedures** (20): Procedures for accessing the building as a contractor.
    *   Select the type of procedures from the options (Formal vetting and monitoring, Logged and monitored, etc.).

### Surveillance and Monitoring

*   **CCTV coverage** (22): Coverage of the building by CCTV cameras.
    *   Select the coverage from the options (Comprehensive, Good coverage of main areas, etc.).
*   **Recording system status** (23): Status of the recording system.
    *   Select the status from the options (Operational and backed up, Operational but limited backup, etc.).
*   **Access logs maintained** (24): Type of access logs maintained.
    *   Select the type of logs from the options (Yes, comprehensive logging, Yes, partial logging, etc.).

### Overall Assessment

*   **Overall security rating** (26): Overall security rating of the building.
    *   Select the rating from the options (Excellent - Comprehensive controls, Good - Most areas covered, etc.).
*   **Identified vulnerabilities** (27): List key security weaknesses.
    *   Record any identified security weaknesses.
*   **Recommendations for improvement** (28): Priority actions needed to improve security.
    *   Record any recommended actions to improve security.

## Tips

*   Be thorough and accurate when completing the form.
*   Use any relevant documentation or evidence to support your answers.
*   Select the most accurate options for each question.
*   Complete all required fields before proceeding.
*   If unsure, indicate this in the notes section.

Note: This help guide is intended to be used as a general reference for completing the form. Review the form carefully and use your best judgment when completing it.
