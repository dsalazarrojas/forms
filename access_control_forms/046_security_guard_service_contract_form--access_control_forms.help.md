# Security Guard Service Contract Form - Help Guide
## Purpose
This form is designed to collect information about security guard services. It's used to provide essential details about the service, including its duration, provider, and coverage.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of service you require: Choose between "Security Guard Service" or "Other" services.
2. Specify the guard coverage: Select all the days the security guard service is required.
3. Enter the contract duration: Enter the number of days or weeks for the contract duration.
4. Select the contract start and end dates: Enter the start and end dates of the contract.
5. Provide the service provider's information: Enter the name of the service provider.
6. Enter the property manager's name (if applicable): If you're providing a property manager's name, enter it here.
7. Enter the venue location: Enter the location of where the security guard service will be provided.
8. Add submission notes (if any): You may add any additional notes regarding the submission.
9. Confirm guard coverage: Confirm if the security guard service covers all the required days.
10. Confirm service provider: Confirm if you're confirming the service provider.

## Field-by-Field Explanation

* **Service Details** (`service_details`): Enter a brief description of the security guard service required.
* **Service Type** (`service_type`): Choose between "Security Guard Service" or "Other" services.
* **Guard Coverage** (`guard_coverage`): Select all the days the security guard service is required.
	+ Select "Yes" if the service covers all required days.
	+ Select "No" if the service doesn't cover any required days.
	+ Select "Unsure" if you're unsure about the coverage.
* **Contract Duration** (`contract_duration`): Enter the number of days or weeks for the contract duration.
* **Contract Start Date** (`contract_start_date`): Enter the start date of the contract.
* **Contract End Date** (`contract_end_date`): Enter the end date of the contract.
* **Service Provider** (`service_provider`): Enter the name of the service provider.
* **Property Manager** (`property_manager`): If you're providing a property manager's name, enter it here.
* **Venue** (`venue`): Enter the location of where the security guard service will be provided.
* **Submission Notes** (`submission_notes`): You may add any additional notes regarding the submission.
* **Confirm Guard Coverage** (`confirm_guard_coverage`): Confirm if the security guard service covers all the required days.
* **Confirm Service Provider** (`confirm_service_provider`): Confirm if you're confirming the service provider.
