# Entertainment Studio Sponsorship Application - Help Guide
## Purpose
The Entertainment Studio Sponsorship Application form is a critical tool for gathering information about events, projects, and partners that are seeking sponsorship from our organization. This guide will walk you through each section of the form to ensure you complete it accurately and effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have been invited to apply for sponsorship before submitting this form.
2. Fill out all required fields marked with an asterisk (\*).
3. Enter the name of the event you are applying for sponsorship.
4. Choose whether or not the project is sponsored by the partner.
5. Enter your contact information, including email address and phone number (if applicable).
6. Provide a detailed description of the project and event.
7. Select the dates and times for the event.
8. Specify the event venues and type.
9. Indicate whether the project has budget constraints.
10. Enter the project budget and duration.
11. Choose the project status and start and end dates.
12. Enter the project location.
13. Provide a description of the partner.
14. Specify the partner type (if applicable).
15. Indicate the partner's ownership status.
16. Review the application status.

## Field-by-Field Explanation

* **event_name**: Enter the name of the event you are applying for sponsorship. This field is required.
* **project_name**: Enter the name of the project associated with the event. This field is not required but recommended for clarity.
* **sponsor_name**: Select "Yes" if the project is sponsored by the partner. If not, select "No". This field is required.
* **partner_name**: Select "Yes" if the partner is involved with the project. If not, select "No". This field is required.
* **contact_name**: Enter your name as the contact person for the event or project. This field is required.
* **email**: Enter your email address for communication purposes. This field is required.
* **phone**: Enter your phone number for additional contact information (optional).
* **address**: Enter the address of the location where the event will take place. This field is required.
* **project_description**: Provide a detailed description of the project and its goals. This field is required.
* **event_description**: Enter a detailed description of the event. This field is required.
* **event_dates**: Select the dates of the event. This field is required.
* **event_times**: Select the times for the event. This field is required.
* **event_venues**: Select the venues for the event. This field is required.
* **event_type**: Select the type of event (optional).
* **project_budgtes**: Select "Yes" if the project has budget constraints. If not, select "No". This field is required.
* **project_budget**: Enter the budget for the project. This field is required.
* **project_duration**: Enter the duration of the project. This field is required.
* **project_status**: Select the project status (Active or Inactive). This field is required.
* **project_start**: Enter the start date of the project. This field is required.
* **project_end**: Enter the end date of the project. This field is required.
* **project_location**: Enter the location of the project. This field is required.
* **partner_description**: Enter a detailed description of the partner. This field is required.
* **partner_type**: Enter the type of partner (if applicable). This field is not required.
* **partner_ownership**: Select the ownership status of the partner. This field is required.
* **review_status**: Select the review status of the application (Active or Inactive). This field is required.
