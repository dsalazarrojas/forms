# Project Charter Form - Help Guide
## Purpose
The Project Charter Form is a document that outlines the project's objectives, goals, and key performance indicators (KPIs). It is used to ensure that all project stakeholders are on the same page and that the project is well-structured and well-managed.

## How To Complete This Form
To complete this form, simply fill out the required fields with the relevant information about your project. Each field is described in more detail below.

## Field-by-Field Explanation
* **Project Information** (`project_info`, text, optional): This field is where you can provide a brief description of your project.
* **Project Name** (`project_name`, text, optional): Enter the name of your project, which should be unique and descriptive.
* **Targeted KPI** (`project_targeted_kpi`, text, optional): This field is used to outline the project's key performance indicators, or metrics that will be used to measure progress and success.
* **Budget** (`project_budget`, number, optional): Enter the budget for your project.
* **Milestones** (`project_milestones`, select_multiple, optional): Select the major milestones that your project aims to achieve.
* **Risks** (`project_risks`, text, optional): Identify potential risks or challenges that your project may face.
* **Impact Details** (`project_impact_details`, text, optional): Explain the potential impact of your project on the organization or stakeholders.
* **Financial Details** (`project_financial_details`, text, optional): Provide any additional financial information related to your project.

## Tips
* Please fill out all the fields that are relevant to your project.
* If a field is not required, you can leave it blank or fill it out if you feel it's necessary.
* If you're unsure about any of the fields, please contact the project manager or team lead for guidance.
