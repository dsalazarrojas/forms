# Race Sponsorship Form Template - Help Guide
## Purpose
The Race Sponsorship Form Template is used to collect information for race sponsorship applications.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the sponsor's name in the "Sponsor Name" field.
2. Enter the sponsorship amount in the "Sponsorship Amount" field.
3. Select the sponsorship duration in the "Sponsorship Duration" field.
4. Enter the name of the event organizer in the "Event Organizer Name" field.
5. Enter the name of the event in the "Event Name" field.
6. Select the date of the event in the "Event Date" field.
7. Select the start time of the event in the "Event Time" field.
8. Choose the type of sponsorship from the "Sponsorship Type" field.
9. Provide the sponsor's contact information in the "Sponsor Contact Info" field.
10. Enter the location of the event in the "Event Location" field.
11. Enter the reason for the sponsorship in the "Sponsorship Reason" field.
12. Enter any additional notes about the sponsorship in the "Sponsorship Notes" field.

## Field-by-Field Explanation
* **Sponsor Name** (text, optional): This field is for the sponsor's name.
* **Sponsorship Amount** (number, optional): This field is for the sponsorship amount.
* **Sponsorship Duration** (number, optional): This field is for the sponsorship duration.
* **Event Organizer Name** (text, optional): This field is for the event organizer's name.
* **Event Name** (text, optional): This field is for the event name.
* **Event Date** (date, optional): This field is for the event date.
* **Event Time** (time, optional): This field is for the event time.
* **Sponsorship Type** (select_one, optional): This field is for the type of sponsorship. Options include Sponsor, Supporter, and Vendor.
* **Sponsor Contact Info** (text, optional): This field is for the sponsor's contact information.
* **Event Location** (text, optional): This field is for the event location.
* **Sponsorship Reason** (text, optional): This field is for the reason for the sponsorship.
* **Sponsorship Notes** (text, optional): This field is for any additional notes about the sponsorship.

## Tips
* Make sure to double-check the form for accuracy before submission.
* Review the form carefully to ensure that all required fields are completed.
* If you are unsure about any field, refer to the field's label or contact the form owner for clarification.
