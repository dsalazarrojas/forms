# supplies_order_form - Help Guide
## Purpose
The supplies order form is a tool used to collect and track supplies orders in the workplace, helping to ensure timely and accurate management of supplies.

## How To Complete This Form

To complete this form, simply follow the instructions below:

1. Select the correct options for each field based on your needs and circumstances.
2. Fill in all required fields.
3. Review and update the form as necessary.

## Field-by-Field Explanation

* **Workplace** (`1`, `text`, required: false): Enter the name of the workplace associated with this supplies order.
* **Employee** (`2`, `select_one`, required: false): Select whether the employee is involved in this order.
* **Supplies Needed** (`3`, `text`, required: false): Describe the supplies required for this order.
* **Order Date** (`4`, `date`, required: false): Enter the date the order is needed by.
* **Order Time** (`5`, `time`, required: false): Enter the time the order is needed by.
* **Order Notes** (`6`, `note`, required: false): Add any additional notes or comments regarding the order.
* **Email** (`7`, `email`, required: false): Enter the email address associated with this order.
* **Phone** (`8`, `text`, required: false): Enter the phone number associated with this order.
* **Assigned Tool** (`9`, `select_one`, required: false): Select whether a tool has been assigned to this order.
* **Submitted By** (`10`, `select_multiple`, required: false): Select the individuals who have submitted this order.
* **Submitted To** (`11`, `select_one`, required: false): Select the person this order is submitted to.
* **Approved By** (`12`, `select_one`, required: false): Select the person who approved this order.
* **Approved Date** (`13`, `date`, required: false): Enter the date this order was approved.
* **Approved Time** (`14`, `time`, required: false): Enter the time this order was approved.
* **Rejected By** (`15`, `select_one`, required: false): Select the person who rejected this order.
* **Rejection Reason** (`16`, `note`, required: false): Enter the reason this order was rejected.
* **Comments** (`17`, `note`, required: false): Add any additional comments or updates regarding this order.
* **Status** (`18`, `select_one`, required: false): Select the current status of this order.
