# Purchase Request Form - Help Guide
## Purpose
The Purchase Request Form is used to submit a request for an item or service needed for work purposes.

## How To Complete This Form
- Fill out the form completely and accurately to ensure your request is processed quickly and efficiently.
- Ensure all required fields are filled, which are indicated by an asterisk (\*) in the labels.
- If a field is marked as optional, you can skip it if it's not relevant to your request.
- Submit the form to your manager for review and approval.

## Field-by-Field Explanation

* **Purchase Request Form**: This is the form name, which is already filled out for you. You cannot change this field.
* **Manager Name**: This field is where you enter your manager's name or ID number for their records.
* **Item Number**: Enter the internal item number or code associated with the item or service you are requesting.
* **Item Description**: Provide a brief description of the item or service you are requesting.
* **Item Cost**: Enter the cost of the item or service you are requesting, including any applicable taxes or fees.
* **Purchase Request Date**: Enter the date you need the item or service by.
* **Purchase Request Time**: Enter the specific time you need the item or service by.
* **Comments**: Add any additional information or context about your request here.
* **Assigned Tool**: Enter the tool or equipment ID number associated with the item or service you are requesting.
* **Form ID**: This is a unique identifier for the form, which is already filled out for you. You cannot change this field.
* **Form Category**: This field is reserved for future use and is not applicable at this time.
