# Project Completion Form - Help Guide
## Purpose
The Project Completion Form is designed to capture essential information about project completion, enabling project managers and stakeholders to track progress and evaluate project status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name in the `project_name` field.
2. Select the current project status from the `project_status` dropdown menu (active, pending, completed, or canceled).
3. Enter the completion date in the `completion_date` field.
4. Enter the evaluation date in the `evaluation_date` field.
5. Add any comments from the project manager in the `project_manager_comments` field.
6. Provide project outcomes and recommendations in the `project_outcomes` and `project_recommendations` fields, respectively.
7. (Optional) Add project status comments in the `project_status_comments` field.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project being completed.
* **Project Manager Name** (`project_manager_name`, text, optional): Enter the name of the project manager responsible for the project.
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project (active, pending, completed, or canceled).
* **Completion Date** (`completion_date`, date, optional): Enter the date the project was completed.
* **Evaluation Date** (`evaluation_date`, date, optional): Enter the date the project was evaluated.
* **Project Manager Comments** (`project_manager_comments`, text, optional): Add any comments from the project manager.
* **Project Status Comments** (`project_status_comments`, text, optional): Enter any additional comments about the project status.
* **Project Outcomes** (`project_outcomes`, text, optional): Describe the outcomes of the project.
* **Project Recommendations** (`project_recommendations`, text, optional): Provide recommendations for future projects or improvements.

Note: Fields marked as `optional` can be skipped if not applicable.
