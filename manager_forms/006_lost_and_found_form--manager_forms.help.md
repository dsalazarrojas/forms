# lost_and_found_form - Help Guide
## Purpose
This form is used to track items that have been found and are waiting to be reunited with their original owners.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the question "item_found" to let us know if the item has been found.
2. Provide a brief description of the item in the "item_description" field.
3. If you are the owner or know the owner, provide your name in the "owner_name" field.
4. If available, provide the value of the item in the "item_value" field.
5. If you know the location where the item was found, provide this information in the "item_location" field.
6. If you have the owner's phone number, provide it in the "owner_phone" field.
7. If you have the owner's email, provide it in the "owner_email" field.
8. Enter the date and time the item was submitted in the "submit_date" and "submit_time" fields.
9. Enter your name in the "submitter" field, so we can contact you if needed.
10. Add any additional notes in the "notes" field.
11. Select the "assigned_to" option to indicate whether the item has been assigned to someone or not.

## Field-by-Field Explanation
* **item_found** (select_one, required): Choose "Yes" if the item has been found.
* **item_description** (text, required): Enter a brief description of the item.
* **owner_name** (text, optional): If you are the owner or know the owner, enter your name here.
* **item_value** (number, optional): If you know the value of the item, enter it here.
* **item_location** (text, optional): If you know the location where the item was found, enter it here.
* **owner_phone** (text, optional): If you have the owner's phone number, enter it here.
* **owner_email** (email, optional): If you have the owner's email, enter it here.
* **submit_date** (date, required): Enter the date the item was submitted.
* **submit_time** (time, required): Enter the time the item was submitted.
* **submitter** (text, required): Enter your name so we can contact you if needed.
* **notes** (note, optional): Add any additional notes about the item.
* **assigned_to** (select_one, optional): Indicate whether the item has been assigned to someone or not.
