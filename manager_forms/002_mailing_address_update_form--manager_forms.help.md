# mailing_address_update_form - Help Guide
## Purpose
This form is used to update the mailing address of a user.

## How To Complete This Form
1. Fill out this form when you need to update a user's mailing address.
2. Ensure you have the necessary permissions to access and modify user information.
3. Fill out each field accurately and thoroughly.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter the user's first name.
* **Last Name** (`last_name`, text, optional): Enter the user's last name.
* **Email** (`email`, email, optional): Enter the user's email address.
* **Address 1** (`address_line_1`, text, optional): Enter the first line of the user's mailing address.
* **Address 2** (`address_line_2`, text, optional): Enter the second line of the user's mailing address.
* **City** (`city`, text, optional): Enter the city of the user's mailing address.
* **State** (`state`, text, optional): Enter the state of the user's mailing address.
* **Zip** (`zip`, text, optional): Enter the zip code of the user's mailing address.
* **Phone Number** (`phone_number`, text, optional): Enter the user's phone number.

## Tips
1. Fill out this form accurately and thoroughly to avoid errors.
2. Use a phone number that is in the correct format for your system. 

Please note that all fields are optional, but it is recommended to fill out as much information as possible to ensure the most up-to-date and complete address is stored.
