# Job Requisition Form - Help Guide
## Purpose
The **Job Requisition Form** is used to collect information about job openings, enabling the organization to manage job requisitions efficiently. Please fill out this form to provide necessary details about the job you are requesting.

## How To Complete This Form
To complete the form, follow these steps:

1. Click on the "Next" button to proceed to the first page of the form.
2. Review and fill out the fields on each page according to the field explanations below.

## Field-by-Field Explanation
* **Title** (`title`, text, required): Enter the title of the job requisition, a brief description that will serve as a summary of the job.
* **First Page** (`job_requisition_form_first_page`, note, optional): This page is currently empty and doesn't contain any fields. You can add your notes or comments about the job requisition here if needed.
* **Second Page** (`job_requisition_form_second_page`, number, optional): If applicable, provide a numerical value for this field.
* **Third Page** (`job_requisition_form_third_page`, text, optional): Enter any additional text information about the job requisition.

## Tips
* Be sure to fill out the required fields (Title).
* If you need to add more details, use the First Page for notes.
* For numerical values, use the Second Page.
* If you have additional text to share, use the Third Page.
* Review your submission carefully before submitting the form.
