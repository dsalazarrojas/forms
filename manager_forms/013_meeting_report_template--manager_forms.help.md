# Meeting Report Template - Help Guide
## Purpose
This form is designed for managers to document the details of their meetings, including the topic, location, date and time, notes, and any additional attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the topic of the meeting in the "Meeting Topic" field.
2. Select the date and time of the meeting in the "Meeting Date" and "Meeting Time" fields, respectively.
3. Enter the location of the meeting in the "Meeting Location" field.
4. Type any notes from the meeting in the "Meeting Notes" field.
5. If applicable, indicate if there were any additional attendees by typing their names in the "First name (other)" field. If there were additional attendees, select "Yes" in the "Attendees (other)" field.
6. If the meeting used a tool, select the tool from the "Assigned Tool" dropdown menu.

## Field-by-Field Explanation
* **Meeting Topic**: A brief description of the meeting's topic.
* **Meeting Date**: The date the meeting took place.
* **Meeting Time**: The time the meeting took place.
* **Meeting Location**: The location where the meeting took place.
* **Meeting Notes**: A brief summary of what was discussed during the meeting.
* **First name (other)**: Enter the names of any attendees not listed in the main section (e.g., guests).
* **Attendees (other)**: Select "Yes" if there were additional attendees not listed in the main section.
* **Assigned Tool**: Select the tool used during the meeting (e.g., chatjimmy).
