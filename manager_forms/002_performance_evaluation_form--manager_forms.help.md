# Performance Evaluation Form - Help Guide
## Purpose
This form is designed to gather information about employee performance evaluations. It is used by managers to assess employee performance, provide feedback, and track employee progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the employee being evaluated.
2. Select the date of the performance evaluation.
3. Rate the employee's performance (choose a number from 1-10).
4. Add any comments about the evaluation.
5. Choose the evaluation status (Active, Not Active, On probation, or Terminated).
6. Enter the employee ID (if applicable).
7. Enter the job title of the employee.

## Field-by-Field Explanation
* **employee_name** (text): Enter the name of the employee being evaluated.
* **evaluation_date** (date): Select the date of the performance evaluation.
* **rating** (number): Rate the employee's performance on a scale of 1-10.
* **comments** (text): Add any comments about the evaluation.
* **evaluation_status** (select one): Choose the evaluation status (Active, Not Active, On probation, or Terminated).
* **employee_id** (number): Enter the employee ID (if applicable).
* **job_title** (text): Enter the job title of the employee.
