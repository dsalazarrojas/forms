8. Enter the start time for the poll using the "Poll Start Time" field.
9. Enter the start date for the poll using the "Poll Start Date" field.
10. Enter the end time for the poll using the "Poll End Time" field.
11. Enter the end date for the poll using the "Poll End Date" field.
12. Select the duration of the poll using the "Poll Duration" field.
13. Select the unit of time for the poll duration using the "Poll Duration Unit" field.
