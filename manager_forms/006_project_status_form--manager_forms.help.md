# Project Status Form - Help Guide
## Purpose
The "Project Status Form" is used to track and update project status information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the project name or title in the "project status form project" field.
2.  Enter the start date of the project in the "project start date" field.
3.  Enter the end date of the project in the "project end date" field.
4.  Select the current status of the project from the options provided in the "project status" field.
5.  Enter any additional notes or comments about the project in the "project notes" field.
6.  Select the category of the project from the options provided in the "project category" field.
7.  Enter the priority of the project in the "project priority" field.
8.  Enter the person or team responsible for the project in the "responsible" field.
9.  Enter the start time of the project in the "project start time" field.
10. Enter the end time of the project in the "project end time" field.
11. Enter the date when the project status was last changed in the "project status change date" field.
12. Enter a note about the status change in the "project status change note" field.
