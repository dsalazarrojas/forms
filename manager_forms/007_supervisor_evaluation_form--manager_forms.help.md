# supervisor_evaluation_form - Help Guide
## Purpose
The supervisor evaluation form is a tool used by supervisors to provide feedback and ratings to employees on their performance. It helps identify areas of improvement and development opportunities for the employee.

## How To Complete This Form
1. Start by reading the introduction page and understanding the context of the evaluation.
2. Enter the Employee Name in the designated field, if required.
3. Select a rating for the employee's performance from 1 to 5.
4. Provide feedback on the employee's performance in the Feedback field.
5. List any specific Action Items the employee should work on to improve performance in the Action Items field.
6. Describe the Development Plan the employee will follow to improve performance in the Development Plan field.
7. Choose a date for the evaluation in the Evaluation Date field.
8. Add any Reviewer Notes to discuss additional comments or suggestions.

## Field-by-Field Explanation

* **Introduction**: This section serves as an introduction to the evaluation form.
* **Employee Name**: Enter the employee's name being evaluated.
* **Rating**: This field allows you to select a rating from 1 to 5 to reflect your overall assessment of the employee's performance.
	+ 1: Poor
	+ 2: Below Average
	+ 3: Average
	+ 4: Above Average
	+ 5: Exceptional
* **Feedback**: Provide written feedback on the employee's performance, highlighting strengths and areas for improvement.
* **Action Items**: List specific actions the employee should take to improve their performance.
* **Development Plan**: Describe the steps the employee will take to improve their performance, based on the feedback and rating provided.
* **Evaluation Date**: Select a date for the evaluation, to document when the assessment took place.
* **Reviewer Notes**: Add any additional comments or suggestions for the employee's development.
