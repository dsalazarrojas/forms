# Self Evaluation Template - Help Guide
## Purpose
The Self Evaluation Template is a tool for managers to evaluate the performance of their team members. It helps managers provide feedback and assess progress in a structured and consistent way.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the employee's name.
2. Answer the self-evaluation questions for each of the four questions.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, required/optional): This field is meant to capture the employee's name. Please fill in the name as it should be displayed in the evaluation.
* **Self Evaluation Question 1** (`self_evaluation_question1`, text, required/optional): This field is meant for the manager to pose the first question for the self-evaluation. Please type in the question that you would like to ask the team member.
* **Self Evaluation Answer 1** (`self_evaluation_answer1`, text, required/optional): This field is for the team member to answer the first question. Please type in the answer to the question posed in the previous field.
* **Self Evaluation Question 2** (`self_evaluation_question2`, text, required/optional): This field is meant for the manager to pose the second question for the self-evaluation. Please type in the question that you would like to ask the team member.
* **Self Evaluation Answer 2** (`self_evaluation_answer2`, text, required/optional): This field is for the team member to answer the second question. Please type in the answer to the question posed in the previous field.
* **Self Evaluation Question 3** (`self_evaluation_question3`, text, required/optional): This field is meant for the manager to pose the third question for the self-evaluation. Please type in the question that you would like to ask the team member.
* **Self Evaluation Answer 3** (`self_evaluation_answer3`, text, required/optional): This field is for the team member to answer the third question. Please type in the answer to the question posed in the previous field.
* **Self Evaluation Question 4** (`self_evaluation_question4`, text, required/optional): This field is meant for the manager to pose the fourth question for the self-evaluation. Please type in the question that you would like to ask the team member.
* **Self Evaluation Answer 4** (`self_evaluation_answer4`, text, required/optional): This field is for the team member to answer the fourth question. Please type in the answer to the question posed in the previous field.
