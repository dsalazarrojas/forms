# General Incident Report Form - Help Guide
## Purpose
This form is used to collect information about incidents that occur within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct incident type from the options provided.
2. Enter the date and time the incident occurred.
3. Provide a detailed description of the incident.
4. If applicable, include witness details and witness signature.
5. If you are reporting the incident, provide your name, email, and phone number.

## Field-by-Field Explanation
### Incident Type (1)
• **Incident Type**: Select the type of incident that occurred (Fire, Accident, or Other).

### Incident Date (2)
• **Incident Date**: Enter the date the incident occurred (MM/DD/YY).

### Incident Time (3)
• **Incident Time**: Enter the time the incident occurred (HH:MM AM/PM).

### Incident Location (4)
• **Incident Location**: Enter a detailed description of the location where the incident occurred.

### Incident Description (5)
• **Incident Description**: Provide a detailed description of the incident.

### Witness Details (6)
• **Witness Details**: If you are not reporting the incident, please provide witness details.

### Witness Name (7)
• **Witness Name**: If you are not reporting the incident, enter the witness name.

### Witness Relation (8)
• **Witness Relation**: Select the relation of the witness (Employee, Customer, Supplier, or Other).

### Incident Image (9)
• **Incident Image**: If you have an image related to the incident, you can upload it here.

### Incident Image URL (10)
• **Incident Image URL**: If you have an image related to the incident, you can provide the URL.

### Witness Signature (11)
• **Witness Signature**: If you are not reporting the incident, provide witness signature.

### Incident Reporter Name (12)
• **Incident Reporter Name**: If you are reporting the incident, enter your name.

### Incident Reporter Email (13)
• **Incident Reporter Email**: If you are reporting the incident, enter your email.

### Incident Reporter Phone (14)
• **Incident Reporter Phone**: If you are reporting the incident, enter your phone number.
