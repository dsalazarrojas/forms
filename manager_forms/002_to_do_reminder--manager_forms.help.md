# To Do Reminder - Help Guide
## Purpose
The "To Do Reminder" form is designed to help you manage and track tasks and deadlines. It's meant to be a simple and easy-to-use tool for keeping track of important tasks and reminders.

## How To Complete This Form
1. Select the page where you'd like to fill out the form.
2. For each page, follow the instructions below.

## Field-by-Field Explanation

* **Deadline Date** (`deadline_date`, date, required/optional): Enter the deadline date for the task, if applicable.
* **To Do List** (`to_do_list`, select multiple, required/optional): Select the tasks you'd like to remind yourself about. You can choose multiple tasks.
* **Personal Notes** (`notes_textarea`, text area, required/optional): Write any personal notes related to the task, if necessary.

## Tips
* Make sure to enter accurate and relevant information in the "Deadline Date" field, if you're setting a deadline.
* Use the "To Do List" field to select all relevant tasks that require attention.
* Keep your "Personal Notes" field concise and to the point, it's for personal use only.
