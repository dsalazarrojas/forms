# hao_proxy_form - Help Guide
## Purpose
The hao_proxy_form is a user-facing form designed to collect information for creating or managing proxy relationships. This form gathers relevant details such as title, name, contact information, category, description, assigned tool, event, and notes.

## How To Complete This Form
1. Ensure you have a clear understanding of the purpose of the form and that you are not duplicating an existing proxy relationship.
2. Follow the steps below to complete the form:

## Field-by-Field Explanation
* **hoa_proxy_form** (`hoa_proxy_form`, text, optional): Enter a brief title or description of the proxy relationship.
* **title** (`title`, text, optional): Enter the title of the proxy relationship.
* **name** (`name`, text, optional): Enter the name of the proxy relationship.
* **email** (`email`, email, optional): Enter the email address of the contact person or organization.
* **phone** (`phone`, text, optional): Enter the phone number of the contact person or organization.
* **category** (`category`, select multiple, optional): Select one or more categories relevant to the proxy relationship (e.g., Homeowners, Manager).
* **description** (`description`, text, optional): Enter a detailed description of the proxy relationship.
* **assigned_tool** (`assigned_tool`, select one, optional): Select the tool assigned to the proxy relationship (e.g., chatjimmy, other, other other).
* **event** (`event`, select multiple, optional): Select one or more events relevant to the proxy relationship (e.g., hoa proxy, hoa proxy 2, hoa proxy 3).
* **date** (`date`, date, optional): Enter the date of the proxy relationship.
* **note** (`note`, note, optional): Enter any additional notes or comments about the proxy relationship.
 
## Tips
* Make sure to enter accurate and up-to-date information to ensure the proxy relationship is correctly established.
* If you are unsure about any field, refer to the form's purpose or consult with the relevant stakeholders.
* This form is intended for internal use; please do not share sensitive information unnecessarily.
