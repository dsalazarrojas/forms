# Document Handover Form - Help Guide

## Purpose
The "Document Handover Form" is used to document the handover of a document to a client, including details about the document and the client. This form helps to ensure that all necessary information is captured and that the handover process is completed accurately and efficiently.

## How To Complete This Form

1. Fill in the required information:
	* **Document Handover**: Enter the title of the document being handover.
	* **Client Name**: Enter the name of the client receiving the document.
	* **Document Details**: Enter any relevant details about the document.
	* **Client Email**: Enter the email address of the client.
	* **Manager Name**: Enter the name of the manager involved in the handover process.
	* **Manager Email**: Enter the email address of the manager.
	* **Date**: Select the date of the handover.
	* **Time**: Select the time of the handover.
	* **Handover Method**: Select how the handover was done (Yes or No).
	* **Other (please specify)**: If the handover method is "Other", enter the method used.
	* **Manager Phone**: Enter the phone number of the manager.
2. If applicable, upload the document to be handover.

## Field-by-Field Explanation
* **Document Handover**: A short description of the document being handover.
* **Client Name**: The name of the client receiving the document.
* **Document Details**: Any additional details about the document, such as its version or location.
* **Document Upload**: An optional field for uploading the document.
* **Client Email**: The email address of the client for future communication.
* **Manager Name**: The name of the manager involved in the handover process.
* **Manager Email**: The email address of the manager for future communication.
* **Date**: The date of the handover.
* **Time**: The time of the handover.
* **Handover Method**: How the handover was done (Yes or No).
* **Other (please specify)**: If the handover method is "Other", enter the specific method used.
* **Manager Phone**: The phone number of the manager for future communication.

## Tips
* Make sure to enter all required information accurately and completely.
* If uploading a document, ensure it is the correct version and is complete.
* If using the "Other" handover method, provide a clear description of the handover process.
* If the handover involves communication with the client, ensure to use the client's email address for future reference.
