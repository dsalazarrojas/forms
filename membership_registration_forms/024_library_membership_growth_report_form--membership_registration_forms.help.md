# Library Membership Growth Report Form - Help Guide
## Purpose
The Library Membership Growth Report Form is used to collect data for the library's membership growth report, which can inform the library's marketing and outreach efforts.

## How To Complete This Form
To complete the form, select the report period, enter the number of members, choose the membership status, and enter the date joined for each member.

## Field-by-Field Explanation
* **Select a Date**: Choose the date for which you want to report the membership growth. This will help the library track membership growth over time.
* **Number of Members**: Enter the total number of library members as of the selected date. This will help the library understand the current membership size.
* **Membership Status**: Select the status of the library's members. This will help the library understand which members are actively using its services.
* **Date Joined**: Enter the date when each member joined the library. This will help the library track member retention and identify when members joined the library.

## Tips
* Make sure to select the correct report period to ensure accurate data.
* Enter the correct number of members to avoid inaccuracies in the report.
* Be consistent in selecting the membership status to ensure reliable data.
* Enter the correct date joined to track member retention and identify trends.
