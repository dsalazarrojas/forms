# Business Membership Application Form - Help Guide
## Purpose
This form is designed to collect information for businesses applying for membership to the chamber of commerce. It will help us understand your business needs and preferences.

## How To Complete This Form
- Please fill out all required fields to ensure a smooth application process.
- Double-check your email and phone number for accuracy.
- Select the correct membership category that suits your business needs.
- Choose the payment method that works best for you.

## Field-by-Field Explanation

* **Applicant Name**: This is the full legal name of the applicant.
	+ Type: Text
	+ Required: True
* **Email Address**: This is the primary email address for the applicant.
	+ Type: Email
	+ Required: True
* **Phone Number**: This is the contact phone number for the applicant.
	+ Type: Text
	+ Required: True
* **Business Name**: This is the legal name of the business.
	+ Type: Text
	+ Required: True
* **Business Address**: This is the full business address.
	+ Type: Text
	+ Required: True
* **City**: This is the city location of the business.
	+ Type: Text
	+ Required: True
* **State**: This is the state or province of the business.
	+ Type: Text
	+ Required: True
* **ZIP Code**: This is the ZIP or postal code of the business.
	+ Type: Text
	+ Required: True
* **Business Website**: This is the full website URL of the business.
	+ Type: Text
	+ Required: False
* **Business Phone**: This is the main business phone number.
	+ Type: Text
	+ Required: True
* **Industry**: This is the primary business category.
	+ Type: Select One
	+ Required: True
* **Years in Business**: This is the number of years the business has been operating.
	+ Type: Number
	+ Required: True
* **Number of Employees**: This is the total number of employees in the business.
	+ Type: Number
	+ Required: True
* **Membership Category**: This is the type of membership the applicant is applying for.
	+ Type: Select One
	+ Required: True
* **Benefits of Interest**: Select the membership benefits most important to you.
	+ Type: Select Multiple
	+ Required: True
* **How Did You Hear About Us**: This is the source of awareness for the membership.
	+ Type: Select One
	+ Required: True
* **Referrer Name**: This is the name of the person who referred you.
	+ Type: Text
	+ Required: False
* **Previous Membership**: This is your membership status in the past.
	+ Type: Select One
	+ Required: True
* **Business Description**: This is a brief description of your business.
	+ Type: Text
	+ Required: True
* **Networking Goals**: This is what you hope to achieve through membership.
	+ Type: Text
	+ Required: True
* **Volunteer Interest**: This is your interest in volunteering for committees.
	+ Type: Select One
	+ Required: False
* **Payment Method**: This is the method you will use to pay membership dues.
	+ Type: Select One
	+ Required: True
* **Terms and Conditions**: This is your agreement to the terms and conditions of membership.
	+ Type: Select One
	+ Required: True
