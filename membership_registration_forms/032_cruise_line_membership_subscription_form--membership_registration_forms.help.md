# cruise_line_membership_subscription_form - Help Guide
## Purpose
This form is used to help users subscribe to a cruise line membership. It collects user and contact information, payment details, and membership preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your user info and contact information.
2. Choose your payment method and date.
3. Input your payment amount and email address.
4. Select your membership level, cruise line, ship, cabin, and membership status.
5. Choose the start and end dates of your membership.
6. If you have any notes, input them in the notes field.

## Field-by-Field Explanation
- **User Info**: This is the first page of the form where you can input your user info and contact information.
  * **Contact Info**: This field is optional but can be useful for the membership team to get in touch with you in case of any issues or promotions.
- **Contact Info**: This is a field where you can input your contact information.
  * **Phone**: This is a field where you can input your phone number.
- **Payment Info**: This is the second page of the form where you can input your payment details.
  * **Payment Method**: This field is a dropdown list where you can choose whether you want to be charged or not.
  * **Select Payment Method**: This field is a dropdown list where you can choose whether you want to be charged or not.
  * **Payment Date**: This is a date field where you can select a date when you want to be charged.
  * **Payment Amount**: This is a numeric field where you can input the amount you want to pay.
  * **Email**: This is a field where you can input your email address.
- **Membership Preferences**: This is the third page of the form where you can input your membership preferences.
  * **Membership Level**: This field is a dropdown list where you can choose the level of membership you want.
  * **Select Membership Level**: This field is a dropdown list where you can choose the level of membership you want.
  * **Cruise Line**: This field is a dropdown list where you can choose whether you want to be part of a cruise line or not.
  * **Select Cruise Line**: This field is a dropdown list where you can choose whether you want to be part of a cruise line or not.
  * **Ship**: This field is a dropdown list where you can choose whether you want to be part of a specific ship or not.
  * **Select Ship**: This field is a dropdown list where you can choose whether you want to be part of a specific ship or not.
  * **Cabin**: This field is a dropdown list where you can choose whether you want to be part of a specific cabin or not.
  * **Select Cabin**: This field is a dropdown list where you can choose whether you want to be part of a specific cabin or not.
  * **Membership Status**: This field is a dropdown list where you can choose whether you want to be active or inactive.
  * **Select Membership Status**: This field is a dropdown list where you can choose whether you want to be active or inactive.
  * **Membership Start Date**: This is a date field where you can select the start date of your membership.
  * **Select Membership Start Date**: This field is a date field where you can select the start date of your membership.
  * **Membership End Date**: This is a date field where you can select the end date of your membership.
- **Note**: This is an optional field where you can input any notes you want to provide.
  * **Select Note**: This is an optional field where you can input any notes you want to provide.

## Tips
* Make sure to input accurate information to avoid any issues with your membership.
* Choose your membership level and preferences carefully as they will affect your benefits and responsibilities.
* If you have any questions or concerns, contact the membership team.
