# Short Stay Property Alliance Registration Form - Help Guide
## Purpose
The Short Stay Property Alliance Registration Form is a tool used for property registration. It is used by hosts to provide their contact information, property details, and other relevant details for short stay properties. This form is essential in ensuring accurate and up-to-date information for potential short stay guests.

## How To Complete This Form

1. Start by navigating to the first page, where you will be required to provide basic information about yourself and your property.
2. Fill out the form fields as prompted. Make sure to enter accurate and relevant information for each field.
3. On the second page, you will be required to provide more detailed information about your property, including its license, tax ID, and IBAN number.

## Field-by-Field Explanation

### Page 1

* **First Page Host Info**: Enter your name and any additional information about yourself that you feel is relevant to your property.
* **First Page Property Type**: Select all types that apply to your property. Options include:
	+ Option 1

	+ Option 3
* **First Page Additional Services**: Select all services that apply to your property. Options include:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
* **First Page Manager Info**: Enter the name and contact information of the property manager (if applicable).
* **First Page Manager Phone**: Enter the phone number of the property manager (if applicable).
* **First Page Manager Email**: Enter the email address of the property manager (if applicable).
* **First Page Manager Manager Title**: Select the title of the property manager (if applicable). Options include:
	+ Option 1
	+ Option 2
	+ Option 3
* **First Page Host Info**: Enter any additional information about yourself and your property.
* **First Page Host Phone**: Enter your phone number.
* **First Page Host Email**: Enter your email address.

	+ Option 1
	+ Option 2

### Page 2

* **Second Page Host License**: Select your license number. Options include:
	+ Option 1

	+ Option 3
	+ Option 4
* **Second Page Host License Other**: Enter any other information about your license (if not listed in the options).
* **Second Page Host Tax ID**: Enter your tax ID number.
* **Second Page Host Tax ID Number**: Enter your tax ID number (if not already entered).
* **Second Page Host Tax ID Exp**: Select your tax ID expiration. Options include:
	+ Option 1
	+ Option 2

	+ Option 4
* **Second Page Host IBAN**: Enter your IBAN number.

## Tips

* Ensure that you provide accurate and up-to-date information about yourself and your property.
* Double-check your entries for any errors before submitting the form.
* If you are unsure about any field, feel free to ask for clarification or guidance.
