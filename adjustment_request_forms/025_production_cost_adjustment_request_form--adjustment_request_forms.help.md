# Production Cost Adjustment Request Form - Help Guide
## Purpose
This form is used by Production team members to request adjustments to production costs for specific items. It is intended for internal use only and should not be used for external requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Item** field with the relevant item code or description.
2. Select the **Item Type** from the dropdown menu to indicate the type of item being adjusted.
3. Enter the **Current Cost** of the item.
4. Provide a brief explanation for the **Change Reason** field.
5. Enter your justification for the cost adjustment in the **Justification** field.
6. If you are requesting a new cost, enter the **Proposed Cost** for the item.
7. Select the **Date** for the adjustment.
8. If applicable, specify the **Time** for the adjustment.

## Field-by-Field Explanation
* **Item**: The name or code of the item being adjusted.
	+ Please enter the item name or code.
* **Item Type**: The type of item being adjusted.
	+ Select from the dropdown menu: Raw Material, Component, or Service.
* **Current Cost**: The current cost of the item.
	+ Enter the current cost of the item.
* **Change Reason**: A brief explanation for the cost adjustment request.
	+ This is a free text field, use it to explain the reason for the cost change.
* **Justification**: A detailed explanation for the cost adjustment request.
	+ This is a free text field, use it to justify the cost change.
* **Proposed Cost**: The new proposed cost for the item.
	+ If applicable, enter the proposed cost.
* **Date**: The date of the adjustment.
	+ Enter the date of the adjustment.
* **Time**: The time of the adjustment.
	+ If applicable, specify the time of the adjustment.
* **Justification**: 
	+ This field is empty.
