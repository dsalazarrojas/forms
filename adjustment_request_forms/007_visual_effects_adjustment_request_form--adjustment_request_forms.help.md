# visual_effects_adjustment_request_form - Help Guide
## Purpose
The visual effects adjustment request form is used to collect information from users when requesting adjustments to visual effects in a project.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the form title to access the form.
* Fill in the following fields:
	+ Request Date: The date you are submitting this request.
	+ Artist Name: The name of the artist responsible for the affected visual effect.
	+ Project Code: The unique identifier for your project.
	+ Notes: A brief description or explanation for your request.
	+ Contact Name: The name of the person requesting the adjustment.
	+ Email: The contact email for the person requesting the adjustment.
	+ Phone: The contact phone number for the person requesting the adjustment.
	+ Adjustment Type: Select "Yes" if you are requesting changes to the visual effects, "No" otherwise.
	+ Reason for Adjustment: A description of why you are requesting this adjustment.
	+ Description of Adjustment: A detailed description of the change you are requesting.

## Field-by-Field Explanation

* **Request Date**:
	+ A date field to select when you are submitting this request.
	+ Required: No
* **Artist Name**:
	+ A text field to enter the name of the artist responsible for the affected visual effect.
	+ Required: No
* **Project Code**:
	+ A text field to enter the unique identifier for your project.
	+ Required: No
* **Notes**:
	+ A text field for brief descriptions or explanations.
	+ Required: No
* **Contact Name**:
	+ A text field to enter the name of the person requesting the adjustment.
	+ Required: No
* **Email**:
	+ An email field to enter the contact email for the person requesting the adjustment.
	+ Required: No
* **Phone**:
	+ A text field to enter the contact phone number for the person requesting the adjustment.
	+ Required: No
* **Adjustment Type**:
	+ A select_one field with options "Yes" and "No".
	+ Required: No
* **Reason for Adjustment**:
	+ A text field for describing why this adjustment is being requested.
	+ Required: No
* **Description of Adjustment**:
	+ A text field for a detailed description of the change being requested.
	+ Required: No

## Tips
* Please ensure that you have reviewed up-to-date guidelines, standards, and processes regarding visual effects in your project before submitting this form.
* If you are unsure about any field, please check with your supervisor or project lead.
