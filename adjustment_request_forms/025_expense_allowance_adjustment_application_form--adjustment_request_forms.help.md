# Expense Allowance Adjustment Application Form - Help Guide
## Purpose
This form is used by employees to apply for an adjustment to their existing expense allowance.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your name as an employee in the "Employee Name" field.
2. Enter your manager's name in the "Manager Name" field.
3. Briefly explain the reason for the adjustment request in the "Adjustment Reason" field.
4. Select the date of the request in the "Request Date" field.

## Field-by-Field Explanation
* **Employee Name** (`employee_name`, Text, Required/Optional: Optional): Enter your name as an employee.
* **Manager Name** (`manager_name`, Text, Required/Optional: Optional): Enter the name of your manager.
* **Adjustment Reason** (`adjustment_reason`, Text, Required/Optional: Optional): Briefly explain the reason for the adjustment request.
* **Request Date** (`request_date`, Date, Required/Optional: Required): Select the date of the request.

## Tips
* Please ensure that you have an existing expense allowance before submitting this form.
* If you are unsure about your expense allowance, please contact your HR department for guidance.
* Please be as specific as possible when providing the adjustment reason to ensure that your request is reviewed and approved promptly.
