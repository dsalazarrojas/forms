# Reimbursement Timing Adjustment Consent Form - Help Guide
## Purpose
This form is designed to request a timing adjustment for reimbursement, which can be used to adjust the dates of a reimbursement payment. The form is used to gather information regarding the employee's request, such as the date of adjustment, the type of adjustment, and any necessary approval status. It is intended for employees and approvers to communicate and record the request and its approval.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide your employee's details:
	* Enter the employee's name, department, and job title in the corresponding fields.
2. Specify the adjustment request details:
	* Enter the date of the adjustment request.
	* Select the type of adjustment (Pay Period, Reimbursement Period, or Other).
3. Update the adjustment effective date:
	* Select the date when the adjustment should take effect.
4. Check the approval status:
	* Select the current approval status (Approved, Denied, or Pending).
5. Add comments (optional):
	* Enter any comments or explanations for the denial or adjustment.
6. Provide consent:
	* Select whether the employee consents to the timing adjustment.
7. Enter the approver's name and comments (optional):
	* Enter the name of the employee who approved or denied the request.
	* Add comments or explanations for the approval or denial.

## Field-by-Field Explanation
* **Employee Name** (`employee_name`, text, required): Enter the employee's name to identify them in the request.
* **Department** (`department`, text, optional): Enter the employee's department to provide context for the request.
* **Job Title** (`job_title`, text, optional): Enter the employee's job title to provide further context.
* **Adjustment Request Date** (`adjustment_request_date`, date, required): Enter the date of the request for a timing adjustment.
* **Change Request Type** (`change_request_type`, select_one, optional):
	+ Pay Period: Select this option if the timing adjustment is related to a pay period.
	+ Reimbursement Period: Select this option if the timing adjustment is related to a reimbursement period.
	+ Other: Select this option for any other reason for the timing adjustment.
* **Adjustment Effective Date** (`adjustment_effective_date`, date, required): Select the date when the adjustment should take effect.
* **Approval Status** (`approval_status`, select_one, optional):
	+ Approved: Select this option if the request is approved.
	+ Denied: Select this option if the request is denied.
	+ Pending: Select this option if the request is still being reviewed.
* **Reason for Denial** (`reason_for_denial`, text, optional): Enter the reason for denying the request if applicable.
* **Reimbursement Timing Adjustment Consent** (`reimbursement_timing_adjustment_consent`, select_one, required): Select 'Yes' to indicate consent to the timing adjustment.
* **Comments** (`comments`, text, optional): Enter any comments or explanations for the request or approval.
* **Approvers Name** (`approver_name`, text, optional): Enter the name of the employee who approved or denied the request.
* **Comments** (`comments`, text, optional): Enter any comments or explanations for the approval or denial.

## Tips
* Please ensure that the employee has given their consent before making any adjustments.
* Review the form carefully before submitting it.
* Make sure to provide clear and concise information in each field.
* If you are unsure about any field, you can always reach out to the relevant personnel for guidance.
