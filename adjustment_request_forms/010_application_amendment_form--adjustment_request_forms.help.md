# Application Amendment Form - Help Guide
## Purpose
The Application Amendment Form is used to request modifications to original submissions. Fill out this form to provide details about the changes you'd like to make and any supporting documents.

## How To Complete This Form
1. Fill in the Requester name field with the person requesting the amendment.
2. Enter the Original application ID, which is the reference number of the original submission.
3. Select the type of amendment you're requesting (Personal details, Documents, Course selection, or Other).
4. Describe the Details of change requested in the text field.
5. If applicable, upload any supporting documents and indicate their filenames in the Supporting documents field.
6. If desired, choose an Effective date for the amendment.
7. Select the Approval status of the amendment (Pending, Approved, or Denied).
8. Optionally, add approver comments in the Approver comments field.
9. Enter the Contact email for follow-up.
10. Leave the Final notes field blank, as it is for administrative use only.

## Field-by-Field Explanation

* **Requester name**: Enter the name of the person requesting the amendment. This is the person responsible for the original submission and needs to be identified.
* **Original application ID**: Enter the reference number of the original submission. This helps track the amendment to the correct application.
* **Amendment type**: Choose the type of amendment you're requesting. Options include:
	+ Personal details: Updates to personal information or identity.
	+ Documents: Changes to documents submitted with the original application.
	+ Course selection: Changes to course selection or academic programs.
	+ Other: Any other type of amendment not listed above.
* **Details of change requested**: Describe the specific changes you're requesting in the text field. Be clear and concise about the reasons for the amendment.
* **Supporting documents filename**: If you're uploading supporting documents, indicate their filenames in this field.
* **Effective date**: If you want the amendment to take effect on a specific date, enter it here.
* **Approval status**: Select the status of the amendment (Pending, Approved, or Denied) to track its progress.
* **Approver comments**: Add any comments or feedback from the reviewer or approver.
* **Contact email**: Enter your email address for follow-up or communication about the amendment.
* **Final notes**: This field is for administrative use only; you don't need to fill it out.

Note: The form is designed to be completed by the person requesting the amendment, and all fields are required unless specified otherwise.
