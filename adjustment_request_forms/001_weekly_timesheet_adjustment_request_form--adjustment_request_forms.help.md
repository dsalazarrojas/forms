# Weekly Timesheet Adjustment Request Form - Help Guide
## Purpose
The Weekly Timesheet Adjustment Request Form is used to make adjustments to an employee's weekly timesheet. This form is typically filled out by authorized users to correct errors or make changes to an employee's timesheet.

## How To Complete This Form

1. Enter the Week Start Date of the employee's timesheet you want to make adjustments to.
2. Enter the Week End Date of the employee's timesheet you want to make adjustments to.
3. Select the Date of the timesheet you want to make adjustments to.
4. Enter the Hours Adjusted, or the number of hours you are adjusting the employee's timesheet for.
5. Enter a brief Reason for making this adjustment.
6. If you need to change the Week Start Time, enter the correct time.
7. If you need to change the Week End Time, enter the correct time.
8. If you need to change the number of Hours Worked, enter the new total.
9. Select Yes or No for the Employee ID, depending on whether the adjustment is for the employee listed.
10. Select the Employee Name from the list of employees.
11. Select the Department associated with the employee's timesheet.
12. Select the Project associated with the employee's timesheet.
13. Select the Manager associated with the employee's timesheet.
14. Select the Team Leader associated with the employee's timesheet.
15. Select the Location associated with the employee's timesheet.
16. Select the Job Title associated with the employee's timesheet.
17. Enter the Job Title if it's not already listed.
18. Enter the Work Hours for the adjustment.
19. Select the Pay Period for the adjustment.
20. Enter the Pay Period Name if it's not already listed.
21. Select the Pay Period ID if it's not already listed.
22. Select Yes or No for the Manager, depending on whether the adjustment is for the manager listed.
23. Select the Team for the adjustment.
24. Enter the Work Date of the timesheet you want to make adjustments to.
25. Select Yes or No for who Submitted the form.

## Field-by-Field Explanation

* **Week Start Date (1)** (`week_start_date`, date, optional): Enter the start date of the week the timesheet you want to make adjustments to.
* **Week End Date (2)** (`week_end_date`, date, optional): Enter the end date of the week the timesheet you want to make adjustments to.
* **Date (3)** (`week_date`, date, optional): Enter the date of the timesheet you want to make adjustments to.
* **Hours Adjusted (4)** (`hours_adjusted`, number, optional): Enter the number of hours to adjust the employee's timesheet for.
* **Reason (5)** (`hours_reason`, text, optional): Enter a brief reason for making this adjustment.
* **Week Start Time (6)** (`week_start_time`, time, optional): If you need to change the Week Start Time, enter the correct time.
* **Week End Time (7)** (`week_end_time`, time, optional): If you need to change the Week End Time, enter the correct time.
* **Hours Worked (8)** (`hours_worked`, number, optional): Enter the new total number of hours worked.
* **Employee ID (9)** (`employee_id`, select_one, optional): Select Yes if the adjustment is for the employee listed.
* **Employee Name (10)** (`employee_name`, select_multiple, optional): Select the Employee Name from the list of employees.
* **Department (11)** (`department_id`, select_one, optional): Select the Department associated with the employee's timesheet.
* **Project (12)** (`project_id`, select_one, optional): Select the Project associated with the employee's timesheet.
* **Manager (13)** (`manager_id`, select_one, optional): Select the Manager associated with the employee's timesheet.
* **Team Leader (14)** (`team_leader_id`, select_one, optional): Select the Team Leader associated with the employee's timesheet.
* **Location (15)** (`location_id`, select_one, optional): Select the Location associated with the employee's timesheet.
* **Job Title (16)** (`job_title_id`, select_one, optional): Select the Job Title associated with the employee's timesheet.
* **Job Title (2)** (`job_title`, text, optional): Enter the Job Title if it's not already listed.
* **Work Hours (17)** (`work_hours`, number, optional): Enter the Work Hours for the adjustment.
* **Pay Period (18)** (`pay_period_id`, select_one, optional): Select the Pay Period for the adjustment.
* **Pay Period Name (19)** (`pay_period_name`, text, optional): Enter the Pay Period Name if it's not already listed.
* **Pay Period ID (20)** (`pay_period_id`, select_one, optional): Select the Pay Period ID if it's not already listed.
* **Manager (2)** (`manager_id`, select_one, optional): Select Yes or No for the Manager associated with the employee's timesheet.
* **Team (21)** (`team_id`, select_one, optional): Select the Team associated with the employee's timesheet.
* **Work Date (22)** (`work_date`, date, optional): Enter the date of the timesheet you want to make adjustments to.
* **Submitted By (23)** (`submitted_by`, select_one, optional): Select Yes or No for who submitted the form.
