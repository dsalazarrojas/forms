# Purchase Order Amendment Request Form - Help Guide
## Purpose

This form is designed to be used by authorized users to request amendments to a purchase order. It allows users to select the type of change, provide a description of the change, and attach supporting files. The form also requires the user to select the name and department of the approver who will review the request, as well as the approver's email address (optional).

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Purchase Order Number, which is the reference number for the purchase order that you wish to amend.
2. Select the type of change you wish to make using the "Change Type" dropdown:
	* Amendment: Used to make changes to an existing purchase order.
	* Cancellation: Used to cancel an existing purchase order.
	* Return: Used to return items from an existing purchase order.
3. Provide a clear and concise description of the reason for the change in the "Reason for Change" text field.
4. Provide a detailed description of the change in the "Description of Change" text field.
5. Enter the new total cost for the change in the "New Total Cost" number field.
6. Attach any supporting files, if necessary, in the "Supporting Files" field.
7. Select the name and department of the approver who will review the request.
8. Enter the approver's email address (optional).
9. Click "Submit" to complete the form.

## Field-by-Field Explanation

* **Purchase Order Number**: Enter the reference number for the purchase order that you wish to amend. This is a required field.
* **Change Type**: Select the type of change you wish to make:
	+ Amendment: Used to make changes to an existing purchase order.
	+ Cancellation: Used to cancel an existing purchase order.
	+ Return: Used to return items from an existing purchase order.
* **Reason for Change**: Provide a clear and concise description of the reason for the change. This is a required field.
* **Description of Change**: Provide a detailed description of the change. This is a required field.
* **New Total Cost**: Enter the new total cost for the change. This is a required field.
* **Supporting Files**: Attach any supporting files, if necessary. This field is not required.
* **Approver Name**: Select the name of the approver who will review the request. This is a required field.
* **Approver Department**: Select the department of the approver who will review the request. This is a required field.
* **Approver Email**: Enter the approver's email address (optional). This field is not required.
* **Approver Phone**: Enter the approver's phone number (optional). This field is not required.
* **Approver Note**: Add any additional comments or notes for the approver, if necessary. This field is not required.
