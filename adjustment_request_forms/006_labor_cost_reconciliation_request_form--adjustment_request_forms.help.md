# Labor Cost Reconciliation Request Form - Help Guide
## Purpose
The Labor Cost Reconciliation Request Form is used to request a labor cost reconciliation when there is a discrepancy between the actual costs incurred by a project and the estimated costs recorded in the project management system.

## How To Complete This Form
1. Enter the project title and project code to identify the project for which the labor cost reconciliation is being requested.
2. Enter the labor code to identify the specific labor category for which the cost discrepancy exists.
3. Select the date range to specify the period for which the labor cost reconciliation is being requested.
4. Enter the start and end dates to further specify the period for which the cost discrepancy exists.
5. Describe the discrepancy and amount of the cost discrepancy.
6. Specify the percent of the total cost that is disputed.
7. Enter the total cost of the project.
8. Provide a brief description of the reason for the cost discrepancy.
9. Select the approver for the request.
10. Enter any additional comments or notes.
11. Select the project status to indicate whether the project is active or inactive.
12. Enter your name as the submitter.
## Field-by-Field Explanation

* **Project Title** (`project_title`, text, required): Enter a brief title of the project for which the labor cost reconciliation is being requested.
* **Project Code** (`project_code`, number, optional): Enter the project code to identify the project for which the labor cost reconciliation is being requested. If not applicable, leave this field blank.
* **Labor Code** (`labor_code`, text, optional): Enter the labor code to identify the specific labor category for which the cost discrepancy exists. If not applicable, leave this field blank.
* **Date Range** (`date_range`, date, required): Select the date range to specify the period for which the labor cost reconciliation is being requested.
* **Start Date** (`start_date`, date, required): Enter the start date of the period for which the cost discrepancy exists.
* **End Date** (`end_date`, date, required): Enter the end date of the period for which the cost discrepancy exists.
* **Discrepancy Description** (`discrepancy_desc`, text, required): Provide a brief description of the discrepancy and the reason for the cost request.
* **Discrepancy Amount** (`discrepancy_amount`, number, required): Enter the amount of the cost discrepancy.
* **Discrepancy Percent** (`discrepancy_percent`, number, required): Specify the percent of the total cost that is disputed.
* **Total Cost** (`total_cost`, number, required): Enter the total cost of the project.
* **Discrepancy Reason** (`discrepancy_reason`, text, required): Provide a brief description of the reason for the cost discrepancy.
* **Submitter** (`submitter`, select_one, optional): Select the person submitting the request (Finance or Project Team).
* **Approver** (`approver`, select_one, required): Select the person who will approve the request (Finance or Project Manager).
* **Notes** (`notes`, text, optional): Enter any additional comments or notes related to the request.
* **Project Leader** (`project_leader`, email, optional): Enter the email of the project leader.
* **Finance Contact** (`finance_contact`, text, optional): Enter the name of the finance contact person.
* **Project Contact** (`project_contact`, text, optional): Enter the name of the project contact person.
* **Submit Date** (`submit_date`, time, optional): Enter the date and time when the request was submitted.
* **Review Date** (`review_date`, time, optional): Enter the date and time when the request was reviewed.
* **Approval Date** (`approval_date`, time, optional): Enter the date and time when the request was approved.
* **Approved By** (`approved_by`, select_multiple, optional): Select the person who approved the request (Finance or Project Manager).
* **Rejected By** (`rejected_by`, select_multiple, optional): Select the person who rejected the request (Finance or Project Manager).
* **Comments** (`comments`, text, optional): Enter any additional comments or notes related to the request.
* **Project Status** (`project_status`, select_one, required): Select the project status (Active or Inactive).
* **Submitter Name** (`submitter_name`, text, required): Enter your name as the submitter.
* **Approver Name** (`approver_name`, text, required): Enter the name of the approver.
* **Approval Date** (`approval_date`, time, optional): Enter the date and time when the request was approved.
* **Comments** (`comments`, text, optional): Enter any additional comments or notes related to the request.
