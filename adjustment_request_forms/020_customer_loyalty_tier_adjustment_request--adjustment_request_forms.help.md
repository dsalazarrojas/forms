# Customer Loyalty Tier Adjustment Request - Help Guide
## Purpose
This form is used to request adjustments to a customer's loyalty tier status. It's a way for customers or representatives to notify us of changes that need to be made to a customer's loyalty tier level.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if the request is valid. If the request is invalid, do not proceed.
2. Select whether the request is for a "Yes" or "No" outcome.
3. Enter the customer's ID.
4. Enter the date of the change.
5. Provide a description of the reason for the request.
6. Enter the submitter's name and contact information (optional).
7. Select the current loyalty tier status and the desired status.
8. Select the status of the adjustment request.

## Field-by-Field Explanation
* **Customer Loyalty Tier Adjustment Request**: Select whether the request is for a "Yes" or "No" outcome.
* **Customer ID**: Enter the ID of the customer whose loyalty tier status is being adjusted.
* **Date of Change**: Enter the date the change took place.
* **Change Request Details**: Provide a description of the reason for the request.
* **Submitter Name**: Enter your name if you are submitting the request.
* **Submitter Phone**: Enter your phone number if you are submitting the request.
* **Submitter Email**: Enter your email address if you are submitting the request.
* **Submitter Notes**: Provide any additional information that may be helpful for the review process.
* **Customer Loyalty Tier ID**: Select whether the request is for a "Yes" or "No" outcome for the customer's loyalty tier ID.
* **Customer Loyalty Tier**: Select the current loyalty tier status and the desired status.
* **Adjustment Reason**: Select the reason for the request.
* **Adjustment Request Status**: Select the status of the adjustment request (Active or Inactive).
* **Submitter Phone**: Enter your phone number if you are submitting the request.
* **Submitter Email**: Enter your email address if you are submitting the request.
* **Submitter Notes**: Provide any additional information that may be helpful for the review process.

Note: The submitter name, phone, and email are optional fields, but providing this information can help the review process.
