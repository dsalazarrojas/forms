# Financial Forecast Revision Request Form - Help Guide
## Purpose
The Financial Forecast Revision Request Form is a tool used to request revisions to a previously submitted financial forecast. This form helps ensure that the revision process is thorough and accurate by gathering necessary information from the user.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form submission details, including any relevant information about the original forecast being revised.
2. Select the date when the revision is required.
3. Choose the type of revision needed (Adjust or Review).
4. Select the specific financials that require revision (Revenue, Expense, or Other).
5. If necessary, attach a supporting document to provide additional context.
6. Add any comments or notes about the revision request.
7. Review and submit the form to initiate the revision process.

## Field-by-Field Explanation
* **Form Submission**: This is where you can provide a brief description of the forecast being revised and any relevant details.
* **Date Requested**: This is the date when you would like the revision to be completed by. Please enter a date in the format MM/DD/YYYY.
* **Reason Requested**: This is an optional field to provide a brief explanation of why the revision is needed.
* **Forecast Revision Request Type**: This field determines the type of revision required. You can select either "Adjust" or "Review".
	+ "Adjust" is for making changes to the original forecast, such as updating revenue or expense figures.
	+ "Review" is for reviewing and providing feedback on the original forecast.
* **Financials**: Select the specific financials that require revision, such as Revenue, Expense, or Other.
* **Supporting Document**: If you have any additional context or information to support your revision request, you can attach a document here.
* **Comments**: This is an optional field for providing any additional comments or notes about the revision request.
