# Banking Error Correction Request Form - Help Guide
## Purpose
This form is used to report errors or discrepancies in your bank account, such as incorrect transaction amounts, missing or duplicate transactions, and incorrect fees. By filling out this form accurately, you'll help the bank investigate and correct your account issues promptly.

## How To Complete This Form

1. Select the type of error you're reporting (e.g., incorrect transaction amount, duplicate transaction, etc.)
2. Enter the date you discovered the error (request_date)
3. Enter the date of the transaction in question (transaction_date)
4. Enter the amount of the transaction (transaction_amount)
5. Enter the name of the merchant or payee involved (merchant_name)
6. Enter a detailed description of the error (error_details)
7. If you've reported this error before, provide the reference number of the previous report (previous_reports)
8. Select the resolution you desire (e.g., credit to account, reverse transaction, etc.)
9. Confirm that you authorize the bank to investigate this error (authorization_confirmation)

## Field-by-Field Explanation

* **Request Date** (`request_date`, required): The date you're submitting this report.
* **Customer Name** (`customer_name`, required): Your full name as registered with the bank.
* **Email Address** (`customer_email`, required): Your email for contact and updates.
* **Phone Number** (`customer_phone`, required): Your best contact phone number.
* **Account Number** (`account_number`, required): The last 4 digits of your account number.
* **Type of Error** (`error_type`, required): The type of error you're reporting (e.g., incorrect transaction amount, duplicate transaction).
* **When Did You Discover This Error?** (`error_discovery_date`, required): The date you first noticed the issue.
* **Transaction Date** (`transaction_date`, required): The date of the transaction in question.
* **Transaction Amount** (`transaction_amount`, required): The amount of the transaction in question.
* **Merchant or Payee Name** (`merchant_name`, required): The name of the business or person involved in the transaction.
* **Transaction Description** (`transaction_description`, optional): A description of what the transaction was for.
* **Detailed Description of Error** (`error_details`, required): A clear explanation of the issue.
* **Expected Transaction Amount** (`expected_amount`, optional): The correct amount of the transaction.
* **How Has This Error Affected Your Account?** (`impact_on_balance`, optional): Describe the impact on your account.
* **Documentation Attached** (`documentation_attached`, optional): What supporting documents you're providing (e.g., bank statement, email confirmation).
* **Desired Resolution** (`desired_resolution`, required): The resolution you desire (e.g., credit to account, reverse transaction).
* **Error Urgency Level** (`error_priority`, optional): The urgency level of the issue.
* **Have You Reported This Error Before?** (`previous_reports`, required): If you've reported this error before, select 'Yes'.
* **Previous Report Reference Number** (`previous_reference_number`, optional): If yes, provide the reference number of the previous report.
* **I Authorize Investigation** (`authorization_confirmation`, required): Confirm that you authorize the bank to investigate this error.
