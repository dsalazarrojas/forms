# Music Royalty Adjustment Request Form - Help Guide

## Purpose
This form is used to submit requests for adjustments to music royalty payments. It is intended for artists, publishers, and other industry professionals to submit adjustments to their music royalty payments.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in all required fields, marked as "required" in the form.
2. Make sure to upload any supporting documents required for your request.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Submit Form**: (`music_royalty_adjustment_request_form`, text, required)
	+ This is the main text area where you can type your request for adjustment.
	+ Please provide a clear and concise description of the adjustment you are requesting.
* **Upload Documents**: (`supporting_documents`, text, required)
	+ This is where you can upload any supporting documents related to your request.
	+ Make sure to upload any relevant documents that support your adjustment request.
* **Artist Label Publisher**: (`select_artist_label_publisher`, select_one, required)
	+ Select "Yes" if the label or publisher is involved in the adjustment request.
	+ Select "No" if the label or publisher is not involved.
* **Discrepancy Claim**: (`discrepancy_claim`, text, required)
	+ Describe the discrepancy or issue you are claiming as part of your adjustment request.
* **Adjustment Request**: (`adjustment_request`, text, required)
	+ Describe the specific adjustment you are requesting.
* **Upload Supporting Documents**: (`upload_supporting_documents`, text, required)
	+ This is where you can upload any additional supporting documents.
* **Central Review Date**: (`centralize_review`, date, optional)
	+ If you want to schedule a review of your request, select a date.
* **Music License Number**: (`music_license_number`, number, required)
	+ Enter the music license number related to your request.
* **Music License Holder**: (`music_license_holder`, select_one, required)
	+ Select "Yes" if you are the music license holder.
	+ Select "No" if you are not the music license holder.
* **Artist Contact Email**: (`artist_contact_email`, email, required)
	+ Enter the email address of the artist or their representative.
* **Publisher Contact Email**: (`publisher_contact_email`, email, required)
	+ Enter the email address of the publisher or their representative.
* **Artist Contact Phone**: (`artist_contact_phone`, text, optional)
	+ If you have a phone number to contact the artist, enter it here.
* **Publisher Contact Phone**: (`publisher_contact_phone`, text, optional)
	+ If you have a phone number to contact the publisher, enter it here.
* **Artist**: (`artist`, text, required)
	+ Enter the name of the artist related to your request.
* **Labels**: (`labels`, select_multiple, required)
	+ Select "Yes" if the labels are involved in the adjustment request.
	+ Select "No" if the labels are not involved.
* **Publishers**: (`publishers`, select_multiple, required)
	+ Select "Yes" if the publishers are involved in the adjustment request.
	+ Select "No" if the publishers are not involved.
* **Date Submitted**: (`date_submitted`, date, required)
	+ Enter the date you are submitting this request.
* **Adjustment Status**: (`adjustment_status`, select_one, required)
	+ Select the current status of your adjustment request.
	+ Select "Active" if the request is active.
	+ Select "Inactive" if the request is inactive.
* **Adjustment Date**: (`adjustment_date`, date, required)
	+ Enter the date of the adjustment.
* **Reason**: (`reason`, text, required)
	+ Describe the reason for your adjustment request.
* **Additional Comments**: (`additional_comments`, text, optional)
	+ If you have any additional comments, enter them here.
* **Uploaded Files**: (`uploaded_files`, text, required)
	+ This is where you can upload any additional files.
* **Upload Date**: (`upload_date`, date, optional)
	+ If you want to schedule a upload of files, select a date.
* **File Name**: (`file_name`, text, required)
	+ Enter the name of the file you are uploading.
* **Submit**: (`submit`, text, required)
	+ Click the "Submit" button to submit your request.

**Tips**

* Make sure to fill in all required fields.
* Upload any relevant supporting documents.
* Review the form carefully before submitting it to ensure everything is accurate and complete.
* If you have any questions or need help with the form, contact [support email or phone number].
