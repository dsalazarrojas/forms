# Cost Allocation Change Request Form - Help Guide
## Purpose
The Cost Allocation Change Request Form is designed to facilitate the request to make adjustments to existing cost allocations. It is essential to ensure that changes are accurately and clearly documented to avoid confusion and ensure smooth financial management. Please use this form to request updates to existing cost allocations and ensure your changes are correctly processed.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Project ID of the project that requires a cost allocation change.
2. Choose the type of change you need to request (Type 1, Type 2, or Type 3).
3. Provide a clear description of the change you are requesting.
4. Enter the new value for the cost allocation.
5. If necessary, provide a reason for the change.
6. Optionally, describe the impact on the cost and enter the date and time of the change.
7. Enter your email address and phone number so we can contact you with any questions or updates.

## Field-by-Field Explanation

* **Cost Allocation Change Request** (`cost_allocation_change_request_form`, text, optional): This field is for providing a brief description of the change you are requesting. Please be clear and concise in your explanation.
* **Project ID** (`project_id`, number, optional): Enter the ID of the project that needs a cost allocation change. This will help us to locate the project and apply the change correctly.
* **Change Type** (`change_type`, select_one, optional): Choose one of the three change types (Type 1, Type 2, or Type 3) to indicate the nature of the change you are requesting.
* **Description** (`description`, text, optional): Enter a clear and detailed description of the reason for the change.
* **New Value** (`new_value`, number, optional): Enter the new value for the cost allocation.
* **Reason** (`reason`, text, optional): If you need to provide additional context or explanation for the change, enter it here.
* **Impact on Cost** (`impact_on_cost`, note, optional): Describe the impact of the change on the cost, if any.
* **Date** (`date`, date, optional): Enter the date of the change.
* **Time** (`time`, time, optional): Enter the time of the change.
* **Email** (`email`, email, optional): Enter your email address so we can contact you with any questions or updates.
* **Phone** (`phone`, text, optional): Enter your phone number for any additional contact.
