# marketing_campaign_adjustment_request_form - Help Guide
## Purpose
This form is used to collect information about adjustments users would like to make to marketing campaigns. Please use this form to submit your adjustment requests in a structured and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form fields and ensure you have all the necessary information.
2. Enter your request in the "base_info" field.
3. Provide the name of the marketing campaign in the "campaign_name" field.
4. Select "Yes" or "No" to indicate whether you would like to make a change to the campaign in the "change_type" field.
5. Enter the details of the changes you would like to make in the "change_details" field.
6. Select a date for the changes to be effective from the "campaign_date" field.
7. Indicate whether the marketing manager is involved in the "marketing_manager" field.
8. Indicate whether the sales manager is involved in the "sales_manager" field.
9. Indicate whether customer service is involved in the "customer_service" field.
10. If your request is for a change in type, please select a date for the change to be effective in the "change_type_date" field.

## Field-by-Field Explanation

* **base_info**: Enter a brief description of your request.
* **campaign_name**: Enter the name of the marketing campaign you are requesting adjustments to.
* **change_type**: Select "Yes" if you are requesting to make changes to the campaign, "No" otherwise.
* **change_details**: Describe the specific changes you would like to make to the campaign.
* **campaign_date**: Select a date for the changes to be effective.
* **marketing_manager**: Indicate whether the marketing manager is involved in the request.
* **sales_manager**: Indicate whether the sales manager is involved in the request.
* **customer_service**: Indicate whether customer service is involved in the request.
* **change_type_date**: If your request is for a change in type, select a date for the change to be effective.
