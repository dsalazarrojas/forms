# Tone Frequency Adjustment Form - Help Guide

## Purpose
The Tone Frequency Adjustment Form is a tool used to collect data for tone frequency adjustments. This form helps users provide essential information for calibration purposes, ensuring accurate tone frequencies are maintained in a given submission. It is crucial to fill out this form accurately to ensure correct tone frequency adjustments are made.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Provide submission details.
2.  If required, upload any relevant files.
3.  Add any notes if necessary.
4.  Select the tone frequency.
5.  Choose a calibration method (uploading a file, sending to a service, or using an existing file).
6.  Specify whether you will upload files or not.
7.  Select the submission type (calibration or adjustment).

## Field-by-Field Explanation

* **Submission Details** (`submission_details`, text, optional): This field is used to enter additional information about the submission.
* **File Uploads** (`file_uploads`, text, optional): This field is used to upload files that are relevant to the submission.
* **Notes** (`notes`, note, optional): This field is used to add any extra comments or notes about the submission.
* **Tone Frequency** (`tone_frequency`, select_one, required): This field requires you to select the correct tone frequency for the submission.
* **Upload File** (`upload_file`, text, required): This field requires you to upload a file related to the tone frequency adjustment.
* **Calibration Method** (`calibration_method`, select_one, required): This field asks you to choose a method to calibrate the tone frequency (upload, send, or use existing).
* **Upload Files** (`upload_files`, select_multiple, required): This field allows you to choose whether you will upload files for this submission.
* **Submission Type** (`submission_type`, select_one, required): This field requires you to select the type of submission (calibration or adjustment).

## Tips
* Please ensure that all required fields are filled out accurately to avoid any errors in the tone frequency adjustment process.
* If uploading files, please make sure to follow the file format and size requirements specified in the form.
* If sending to a service, please ensure that you have the necessary permissions and follow the service's requirements.
