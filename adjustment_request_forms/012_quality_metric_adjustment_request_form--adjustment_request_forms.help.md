# Quality Metric Adjustment Request Form - Help Guide
## Purpose
The Quality Metric Adjustment Request Form is designed to facilitate the process of requesting adjustments to quality metrics. This form is intended for internal use only and should only be used for legitimate requests for adjustments.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Submit the form to the reviewer for review.
3. Wait for the reviewer to review and provide feedback on your request.
4. Respond to any feedback or requests for additional information from the reviewer.
5. Once approved, review and verify the adjustments made.

## Field-by-Field Explanation

* **Submit Request**: This field is used to describe the request being made for adjustment.
* **Date of Request**: This field is used to record the date of when the request was made.
* **Metric to Adjust**: This field is a dropdown list of available metrics that can be adjusted.
* **Old Metric Value**: This field is used to record the current metric value before the adjustment.
* **New Metric Value**: This field is used to record the new metric value after the adjustment.
* **Reason for Adjustment**: This field is used to provide a brief explanation for why the adjustment is being made.
* **Review Status**: This field is used to record the reviewer's status of the request.
* **Review Status Comments**: This field is used to record any comments from the reviewer.
* **Submitter**: This field is used to indicate whether the request is made by the submittor or not.
* **Submitter Comments**: This field is used to record any comments from the submittor.
* **Approver**: This field is used to indicate whether the approver has approved the request or not.
* **Approver Comments**: This field is used to record any comments from the approver.
* **Department**: This field is used to record the department or team making the request.
* **Team**: This field is used to record the team or individual making the request.
* **Reviewers Signature**: This field is used to capture the reviewer's signature.
* **Submitter Signature**: This field is used to capture the submittor's signature.
* **Approver Signature**: This field is used to capture the approver's signature.
* **Date**: This field is used to record the date of when the request was made.
* **Time**: This field is used to record the time of when the request was made.
* **Submitter Date**: This field is used to record the date of when the request was submitted.
* **Submitter Time**: This field is used to record the time of when the request was submitted.
