# Cold Transport Audit Registration Form - Help Guide
## Purpose
This form is designed to collect information related to cold transport audits conducted on vehicles. It helps track and monitor compliance with standards for maintaining the safety and integrity of perishable goods during transportation.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide your name, contact email and phone number as the auditor conducting the audit.
2. Enter the name of the organization conducting the audit.
3. Select the date the audit was conducted.
4. Choose the type of audit being conducted (e.g. Routine Scheduled, Random Spot Check, etc.).
5. Enter the name of the carrier or transport company being audited.
6. Enter the contact information for the carrier or transport company (name, email, and phone number).
7. Enter the vehicle's ID or number.
8. Select the type of vehicle being audited (e.g. refrigerated van, refrigerated box truck, etc.).
9. Enter the vehicle's manufacturer and year of manufacture (if applicable).
10. Select the type of refrigeration unit used in the vehicle (e.g. diesel-powered, electric, etc.).
11. Select the temperature range capability of the vehicle's refrigeration unit.
12. Select the type(s) of cargo being transported (e.g. fresh produce, frozen foods, etc.).
13. Select the type(s) of temperature monitoring device used in the vehicle.
14. Check the status of the temperature monitoring device (e.g. calibrated, expired, etc.).
15. Enter the date of the last calibration of the temperature monitoring device.
16. Check if the pre-trip inspection was completed.
17. Check if the temperature logs were reviewed.
18. Select if any temperature deviations were found.
19. Enter any deviation details if deviations were found.
20. Rate the vehicle's cleanliness (e.g. excellent, good, etc.).
21. Check if unusual odors were present.
22. Check the condition of the door seals.
23. Check if any airflow obstructions were found.
24. Select the cargo loading pattern (e.g. proper with air channels, etc.).
25. Check if driver cold chain training was verified.
26. Check if emergency procedures were documented.
27. Check if any compliance issues were found.
28. Enter any corrective actions required.
29. Select the overall audit result (e.g. pass, pass with minor issues, etc.).
30. Enter any additional comments from the auditor.
31. Check if a follow-up audit is required.
32. Enter the date of the follow-up audit if required.

## Field-by-Field Explanation
* **Auditor Full Name (1)**: Enter your full name as the auditor conducting the audit.
* **Auditor Email (2)**: Enter your email address where you can be contacted.
* **Auditor Phone (3)**: Enter your phone number where you can be contacted.
* **Organization Name (4)**: Enter the name of the organization conducting the audit.
* **Audit Date (5)**: Select the date the audit was conducted.
* **Audit Type (6)**: Select the type of audit being conducted (e.g. routine, random spot check, etc.).
* **Carrier or Transport Company Name (7)**: Enter the name of the carrier or transport company.
* **Carrier Contact Person (8)**: Enter the main contact person for the carrier.
* **Carrier Contact Email (9)**: Enter the email address of the carrier or transport company's contact person.
* **Carrier Contact Phone (10)**: Enter the phone number of the carrier or transport company's contact person.
* **Vehicle ID or Number (11)**: Enter the vehicle's ID or number.
* **Vehicle Type (12)**: Select the type of vehicle being audited (e.g. refrigerated van, etc.).
* **Vehicle Manufacturer (13)**: Enter the vehicle's manufacturer (if applicable).
* **Vehicle Year (14)**: Enter the year the vehicle was manufactured (if applicable).
* **Refrigeration Unit Type (15)**: Select the type of refrigeration unit used in the vehicle (e.g. diesel-powered, etc.).
* **Refrigeration Unit Model (16)**: Enter the model number of the vehicle's refrigeration unit (if applicable).
* **Temperature Range Capability (17)**: Select the temperature range capability of the vehicle's refrigeration unit.
* **Type of Cargo Transported (18)**: Select the type(s) of cargo being transported (e.g. fresh produce, etc.).
* **Temperature Monitoring Device (19)**: Select the type of temperature monitoring device used in the vehicle.
* **Monitoring Device Calibration Status (20)**: Check the status of the temperature monitoring device (e.g. calibrated, expired, etc.).
* **Last Calibration Date (21)**: Enter the date of the last calibration of the temperature monitoring device.
* **Pre-Trip Inspection Completed (22)**: Check if the pre-trip inspection was completed.
* **Temperature Logs Reviewed (23)**: Check if the temperature logs were reviewed.
* **Temperature Deviations Found (24)**: Select if any temperature deviations were found.
* **Deviation Details (25)**: Enter any deviation details if found.
* **Vehicle Cleanliness Rating (26)**: Rate the vehicle's cleanliness.
* **Unusual Odors Present (27)**: Check if any unusual odors were present.
* **Door Seals Condition (28)**: Check the condition of the vehicle's door seals.
* **Airflow Obstructions (29)**: Check if any airflow obstructions were found.
* **Cargo Loading Pattern (30)**: Select the cargo loading pattern (e.g. proper with air channels, etc.).
* **Driver Cold Chain Training Verified (31)**: Check if driver cold chain training was verified.
* **Emergency Procedures Documented (32)**: Check if emergency procedures were documented.
* **Compliance Issues Found (33)**: Enter any compliance issues found.
* **Corrective Actions Required (34)**: Enter any corrective actions required.
* **Overall Audit Result (35)**: Select the overall audit result (e.g. pass, pass with minor issues, etc.).
* **Auditor Comments (36)**: Enter any additional comments from the auditor.
* **Follow-Up Audit Required (37)**: Check if a follow-up audit is required.
* **Follow-Up Date (38)**: Enter the date of the follow-up audit if required.
