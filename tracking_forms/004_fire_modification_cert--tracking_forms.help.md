# Fire Modification Cert - Help Guide

## Purpose
The Fire Modification Cert form is used to document modifications made to a fire, such as changes to the fire's intensity, size, or status. This form helps keep track of these modifications and provides valuable information for management and decision-making.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the fire modification status from the options provided.
2. Enter a brief description of the modification reason.
3. Select the date the modification was made.
4. Submit the form to record the modification.

## Field-by-Field Explanation
* **Fire Modification Details** (`fire_modification_cert_form`, Text, Optional): Enter a brief description of the modification, if applicable.
* **Status** (`fire_modification_status`, Select One, Optional): Select the current status of the modification, which can be either Active or Inactive.
* **Reason** (`fire_modification_reason`, Text, Optional): Enter a brief description of the reason for the modification.
* **Date** (`fire_modification_date`, Date, Optional): Select the date the modification was made.

## Tips
* Make sure to select the correct status for the modification.
* Enter a clear and concise description of the modification reason.
* Date selection should match the actual date the modification was made.
* This form is optional, but it is recommended to fill it out for all modifications to track changes accurately.
