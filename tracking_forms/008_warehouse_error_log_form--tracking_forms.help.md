# Warehouse Error Log Form - Help Guide
## Purpose
The Warehouse Error Log Form is a tool used to document errors that occur in the warehouse. It helps track and manage errors, allowing staff to identify trends and areas for improvement.

## How To Complete This Form

* To complete this form, please follow these steps:
  1. Enter a detailed description of the error that occurred.
  2. Provide the date the error occurred.
  3. Select the type of error that occurred.
  4. Choose the category of the error.
  5. Indicate the status of the error.
  6. Select the impact of the error on the user.
  7. Choose the warehouse where the error occurred.
  8. Select the item affected by the error.
  9. Choose the priority of the error.
  10. Add any additional comments about the error.
  11. Enter the name of the user who assigned the error.

## Field-by-Field Explanation

* **User Error Description** (`user_error_description`, text, required): A detailed description of the error that occurred.
* **Date Occurred** (`date_occurred`, date, required): The date the error occurred.
* **Error Type** (`error_type`, select_one, required): The type of error that occurred. Choose from the options provided.
* **Error Category** (`error_category`, select_multiple, required): The category of the error. Choose from the options provided.
* **Error Status** (`error_status`, select_one, required): The status of the error. Choose from the options provided.
* **User Error Impact** (`user_error_impact`, select_one, required): The impact of the error on the user. Choose from the options provided.
* **Warehouse** (`warehouse`, select_one, required): The warehouse where the error occurred. Choose from the options provided.
* **Item** (`item`, select_multiple, required): The item affected by the error. Choose from the options provided.
* **User Error Priority** (`user_error_priority`, select_one, required): The priority of the error. Choose from the options provided.
* **Comments** (`comments`, text, optional): Additional comments about the error. Optional.
* **User Assigned By** (`user_assigned_by`, text, required): The name of the user who assigned the error.

## Tips
* Make sure to complete all required fields.
* Double-check your selections before submitting the form.
* If you're unsure about any field, contact your supervisor or the help desk for assistance.
