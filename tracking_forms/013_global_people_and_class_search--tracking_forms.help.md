# Global People And Class Search - Help Guide

## Purpose
The Global People And Class Search form is used to collect structured search requests for people and classes from organizations using the Jotform Form Builder. This form is essential for gathering specific information about individuals and classes, which can be used to improve data accuracy and efficiency in various business processes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Click on the "Search Request" field and type the name you are looking for.
2. Enter the surname of the person you want to search for in the "Surname" field.
3. If you are searching for a class, click on the "Class" field and enter the class name or type in the "Class Name" field.
4. If you want to search by email, enter the email address of the person or class you are looking for in the "Class Email" field.
5. If you want to search by phone, enter the phone number of the person or class you are looking for in the "Phone" and "Class Phone" fields.
6. Select "Yes" for "Search By" and "Search By Class Email" if you want to search based on the information provided.
7. In the "Notes" field, provide any additional information that may aid in the search process.
8. If you are searching for a specific class, click on the "Class Description" field and enter the class description.
9. Finally, click on the "Search Request Notes" and "Search Request Notes 2" fields to provide further details about the search request.

## Field-by-Field Explanation
### 1. Search Request (<id: 2, name: search_request)
* **Search Request**: Enter the name of the person you are looking for.

### 2. Surname (<id: 4, name: surname)
* **Surname**: Enter the surname of the person you want to search for.

### 3. Class (<id: 6, name: class_type)
* **Class**: Select "Yes" to indicate that you are searching for a class.

### 4. Class Name (<id: 7, name: class_name)
* **Class Name**: Enter the name of the class you are looking for.

### 5. Class Email (<id: 9, name: class_email)
* **Class Email**: Enter the email address of the class you are looking for.

### 6. Phone (<id: 10, name: phone)
* **Phone**: Enter the phone number of the person you are looking for.

### 7. Fax (<id: 11, name: fax)
* **Fax**: Not a required field, used for additional contact information.

### 8. Email (<id: 12, name: email)
* **Email**: Not a required field, used for additional contact information.

### 9. Search By (<id: 13, name: search_by)
* **Search By**: Select "Yes" to indicate that you want to search based on the provided information.

### 10. Search By Class Email (<id: 16, name: search_by_class_email)
* **Search By Class Email**: Select "Yes" to indicate that you want to search based on the class email.

### 11. Search By Phone (<id: 15, name: search_by_phone)
* **Search By Phone**: Not a required field, used for additional search criteria.

### 12. Class Phone (<id: 17, name: search_by_class_phone)
* **Class Phone**: Not a required field, used for additional search criteria.

### 13. Class Email (<id: 9, name: class_email)
* **Class Email**: Enter the email address of the class you are looking for.

### 14. Class Description (<id: 8, name: class_description)
* **Class Description**: Enter the description of the class you are looking for.

### 15. Search By Notes (<id: 21, name: search_by_notes)
* **Search By Notes**: Select "Yes" to indicate that you want to search based on the notes provided.

### 16. Search By Search Request Type (<id: 22, name: search_by_search_request_type)
* **Search By Search Request Type**: Select "Yes" to indicate that you want to search based on the search request type.

### 17. Search Request Notes (<id: 23, name: search_request_notes)
* **Search Request Notes**: Enter any additional information about the search request.

### 18. Search Request Notes 2 (<id: 24, name: search_request_notes_2)
* **Search Request Notes 2**: Enter any additional information about the search request.

### 19. Search By Surname (<id: 25, name: search_by_surname)
* **Search By Surname**: Select "Yes" to indicate that you want to search based on the surname.
