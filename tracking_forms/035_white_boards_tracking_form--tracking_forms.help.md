# white_boards_tracking_form - Help Guide
## Purpose
The white_boards_tracking_form is a tool for tracking and managing Whiteboards. It allows administrators and team members to quickly identify and manage the status of Whiteboards.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Whiteboard's ID (`whiteboard_id` field) - This is a unique identifier for the Whiteboard.
2. Enter the date and time when the Whiteboard was created (`created_at` field) - This is the date and time when the Whiteboard was first created.
3. Enter the date and time when the Whiteboard was last updated (`updated_at` field) - This is the date and time when the Whiteboard's status or details were last changed.
4. Enter the User ID of the person assigned to the Whiteboard (`user_id` field) - This is the ID of the user responsible for the Whiteboard.
5. Select the current status of the Whiteboard (`status` field) - Choose from the options "Active" or "Inactive" to indicate the current status of the Whiteboard.
6. Enter any comments or notes about the Whiteboard (`comments` field) - This is a text field for additional information about the Whiteboard.
7. Enter a brief description of the Whiteboard (`description` field) - This is a text field for a brief summary of the Whiteboard.

## Field-by-Field Explanation
* **Whiteboard ID** (`whiteboard_id`, number, required: false): Enter the unique identifier for the Whiteboard.
* **Created At** (`created_at`, date, required: false): Enter the date and time when the Whiteboard was first created.
* **Updated At** (`updated_at`, date, required: false): Enter the date and time when the Whiteboard's status or details were last changed.
* **User ID** (`user_id`, number, required: false): Enter the ID of the user responsible for the Whiteboard.
* **Status** (`status`, select_one, required: false): Select from "Active" or "Inactive" to indicate the current status of the Whiteboard.
* **Comments** (`comments`, text, required: false): Enter any comments or notes about the Whiteboard.
* **Description** (`description`, text, required: false): Enter a brief summary of the Whiteboard.

## Tips
- Double-check the Whiteboard ID to ensure it matches the correct Whiteboard.
- Use the correct date and time format for the `created_at` and `updated_at` fields.
- Select the correct status for the Whiteboard based on its current state.
- Keep the comments and description fields concise and relevant to the Whiteboard.
- If you are unsure about any field, consult with the relevant team member or administrator.
