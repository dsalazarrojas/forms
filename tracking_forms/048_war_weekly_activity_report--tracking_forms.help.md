# WAR Weekly Activity Report - Help Guide

## Purpose
The WAR Weekly Activity Report is used to track progress towards weekly targets and report on activities, such as sales, appointments, and recruiting. This form helps management monitor and adjust targets as needed.

## How To Complete This Form

To complete the form, follow these steps:

1. **Provide a Report Title**: Enter a brief title for this week's report.
2. **Enter Weekly Activity Metrics**:
	* **Sales**: Enter the number of sales made this week.
	* **Appointments**: Enter the number of appointments scheduled.
	* **Recruiting**: Enter the number of recruits added this week.
3. **Set Targets**:
	* **Sales Target**: Enter the target number of sales for this week.
	* **Appointments Target**: Enter the target number of appointments for this week.
	* **Recruiting Target**: Enter the target number of recruits for this week.
4. **Select Week Dates**:
	* **Week Start Date**: Select the start date of this week.
	* **Week End Date**: Select the end date of this week.
5. **Add Comments** (optional): If you have any comments or notes related to this week's activities, add them here.

## Field-by-Field Explanation

* **Report Title**: Enter a brief title for this week's report.
* **Sales**: Enter the total number of sales made this week.
	+ If you are unsure, you can use a calculator or check your sales records.
* **Appointments**: Enter the total number of appointments scheduled this week.
* **Recruiting**: Enter the total number of recruits added this week.
* **Sales Target**: Enter the target number of sales for this week.
* **Appointments Target**: Enter the target number of appointments for this week.
* **Recruiting Target**: Enter the target number of recruits for this week.
* **Week Start Date**: Select the start date of this week.
* **Week End Date**: Select the end date of this week.
* **Comments**: Add any comments or notes related to this week's activities.

## Tips

* Double-check your numbers for accuracy.
* Make sure to update targets and dates as needed.
* If you have questions or concerns, contact your manager or HR representative.
