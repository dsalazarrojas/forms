# Non Produce Inventory Survey - Help Guide

## Purpose

This form is designed to help track and manage non-produce items in stock. It's used to gather information about stock levels, restocking needs, and reordering points to ensure timely and accurate inventory control.

## How To Complete This Form

1. Fill out each field with the required information.
2. Start from the first page, which is "Item Details."
3. Fill out "Item Details" with the item name, description, or any other relevant information.
4. Move to the next page, "Stock Levels," and enter the current stock level of the item.
5. Proceed to the "Resticock Needs" page and select the restocking needs from the options provided.
6. On the "Resticock Needs Frequency" page, choose the frequency of restocking needs from the options.
7. Enter the quantity and unit required for restocking on the "Resticock Needs Quantity" page.
8. On the "Reorder Point" page, enter the point at which the item should be reordered.
9. Select the reordering frequency from the options on the "Reorder Frequency" page.
10. Enter the quantity required for reordering on the "Reorder Point Quantity" page.
11. Add any relevant survey note on the "Survey Note" page.
12. Provide your email address on the "Email" page.
13. Enter your phone number on the "Phone" page.

## Field-by-Field Explanation

* **Item Details** (Text): Enter a brief description or name of the item being surveyed.
* **Stock Levels** (Number): Enter the current stock level of the item.
* **Resticock Needs** (Select One): Choose the restocking needs for the item from the options provided.
	+ Item: Restocking needs for the item.
	+ Non-Item: Restocking needs for a non-item.
* **Resticock Needs Frequency** (Select One): Choose the frequency of restocking needs.
	+ Daily: Restocking needs to be done daily.
	+ Weekly: Restocking needs to be done weekly.
	+ Bi-Weekly: Restocking needs to be done bi-weekly.
	+ Monthly: Restocking needs to be done monthly.
* **Resticock Needs Quantity** (Number): Enter the quantity required for restocking.
* **Resticock Needs Unit** (Select One): Choose the unit for restocking quantity.
	+ Each: Each unit is used for restocking quantity.
	+ Eaches: Eaches unit is used for restocking quantity.
	+ Case: Case unit is used for restocking quantity.
	+ Cases: Cases unit is used for restocking quantity.
* **Reorder Point** (Number): Enter the point at which the item should be reordered.
* **Reorder Frequency** (Select One): Choose the reordering frequency.
	+ Daily: Reorder needs to be done daily.
	+ Weekly: Reorder needs to be done weekly.
	+ Bi-Weekly: Reorder needs to be done bi-weekly.
	+ Monthly: Reorder needs to be done monthly.
* **Reorder Point Quantity** (Number): Enter the quantity required for reordering.
* **Survey Note** (Note): Add any relevant survey notes.
* **Email** (Email): Enter your email address for contact.
* **Phone** (Text): Enter your phone number for contact.
