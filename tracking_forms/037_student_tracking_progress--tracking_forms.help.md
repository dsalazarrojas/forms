# Student Tracking Progress - Help Guide
## Purpose
This form is used to track student progress in a school setting. It is intended to be filled out by teachers or administrators to record updates on students' performance, behavior, or other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (indicated by a *) with accurate and complete information.
2. Enter the student's name in the **Student Name** field.
3. Enter the class name in the **Class Name** field.
4. Enter the school name in the **School Name** field.
5. Select the student's current class level (e.g., freshman, sophomore, junior, senior).
6. Enter notes or comments about the student's progress in the **Student Progress 1** and **Student Progress 2** fields.
7. Enter the teacher's name in the **Teacher Name** field.

## Field-by-Field Explanation

* **Student Name** (Student Name, text, required): Enter the student's name as it appears on their records.
* **Class Name** (Class Name, text, required): Enter the name of the class the student is currently in.
* **School Name** (School Name, text, required): Enter the name of the school the student attends.
* **Class Level** (Class Level, number, optional): Select the student's current class level (e.g., 9th, 10th, etc.).
* **Student Progress 1** (Student Progress 1, text, optional): Enter notes or comments about the student's progress.
* **Student Progress 2** (Student Progress 2, text, optional): Enter additional notes or comments about the student's progress.
* **Teacher Name** (Teacher Name, text, optional): Enter the name of the teacher providing feedback or updates.

## Tips

* Make sure to enter accurate and complete information to ensure that student progress is tracked effectively.
* If a field is marked as optional, you can skip it if it's not relevant to the student's progress.
* If you're unsure about any of the fields, consult with the student's teacher or administrator for guidance.
