# Sports Game Referee Attendance Form - Help Guide
## Purpose
This form is used to track referee attendance for sports games.

## How To Complete This Form
1. Fill in the required fields, which are marked with an asterisk (\*) in the field labels.
2. Select the correct options for fields with multiple options.
3. Enter any additional notes or comments as needed.

## Field-by-Field Explanation

* **Game ID** (1, number, required): Enter the unique ID of the game.
* **Referee Name** (2, text, required): Enter the name of the referee who attended the game.
* **Game Date** (3, date, required): Enter the date of the game.
* **Game Time** (4, time, required): Enter the start time of the game.
* **Attendance Status** (5, select_one, required): Select 'Yes' or 'No' to indicate whether the referee attended the game.
* **Notes** (6, note, optional): Enter any additional notes or comments about the game.
* **Game Referee Comments** (7, text, optional): Enter any additional comments about the game from the referee.
* **Game Official Comments** (8, text, optional): Enter any additional comments from the game official.
* **Game Score** (9, text, optional): Enter the score of the game.
* **Referee ID** (10, text, optional): Enter the referee's ID number.
* **Team Name** (11, text, optional): Enter the name of the team playing in the game.
* **Referee Name** (12, text, optional): Enter the name of the referee again.
* **Opponent Name** (13, text, optional): Enter the name of the opponent team.
* **Game Location** (14, text, optional): Enter the location of the game.
* **Level** (15, select_one, optional): Select 'High' or 'Low' to indicate the level of the game.
* **Type** (16, select_multiple, optional): Select 'Yes' or 'No' to indicate whether the game is of a certain type.
* **Duration** (17, select_one, optional): Select 'Yes' or 'No' to indicate whether the game was of a certain duration.
* **Start Time** (18, time, optional): Enter the start time of the game.
* **End Time** (19, time, optional): Enter the end time of the game.
* **Game Status** (20, select_one, optional): Select 'Active' or 'Inactive' to indicate the status of the game.
* **Notes** (21, note, optional): Enter any additional notes or comments about the game.
* **Referee Comments** (22, text, optional): Enter any additional comments from the referee.
* **Official Comments** (23, text, optional): Enter any additional comments from the game official.
* **Score 2** (24, text, optional): Enter the score of the game again.
* **Referee ID 2** (25, text, optional): Enter the referee's ID number again.

## Tips
* Please make sure to double-check the game ID to ensure you're filling out the correct game.
* If you're unsure about any field, please don't hesitate to reach out to the administrator for clarification.
* If you have any additional questions or need further assistance, please contact the administrator.
