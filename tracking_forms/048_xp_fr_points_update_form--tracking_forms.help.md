# XP/FR Points Update Form - Help Guide

## Purpose
This form is used to update the XP (Experience Points) and FR (Friendship Points) of a user. Please ensure that you are authorized to make updates and that the changes you wish to make are legitimate. If you are unsure about your authority or the reason for the update, please reach out to the relevant team member for guidance.

## How To Complete This Form
To update the XP/FR points of a user, please follow the steps below:
- Fill in the First Name, Last Name, and Date fields with accurate information.
- In the Reason For Adjustment field, provide a clear and concise explanation for the adjustment.
- Enter the User Points and Points fields with the new values you wish to update to.
- Select the Adjustment Reason and Adjustment Type options that best suit your update.
- Enter any additional contact details if necessary.
- Finally, select the Submit option to finalize the update.

## Field-by-Field Explanation

* **First Name** (`First Name`, `text`, **required**): Enter the user's first name.
* **Last Name** (`Last Name`, `text`, **required**): Enter the user's last name.
* **Reason For Adjustment** (`Reason For Adjustment`, `text`, **required**): Provide a clear and concise reason for the adjustment.
* **Date** (`Date`, `date`, **required**): Enter the date of the adjustment.
* **Contact Details** (`Contact Details`, `text`, **required**): Enter any additional contact details, if necessary.
* **Reason Details** (`Reason Details`, `text`, **required**): Enter more details about the reason for adjustment.
* **Adjustment Reason** (`Adjustment Reason`, `select_one`, **required**): Select a suitable reason for the adjustment (e.g., Reason For Adjustment).
* **Adjustment Type** (`Adjustment Type`, `select_multiple`, **required**): Select multiple adjustment types that apply (e.g., Adjustment Type 1, Adjustment Type 2, Adjustment Type 3).
* **User Points** (`User Points`, `text`, **required**): Enter the new user points value.
* **Points** (`Points`, `number`, **required**): Enter the new points value.
* **Submit** (`Submit`, `select_one`, **required**): Select this option to finalize the update.

## Tips
Please ensure that all required fields are filled in accurately and completely before submitting the form. If you need assistance or clarification on any field, please don't hesitate to reach out to the relevant team member.
