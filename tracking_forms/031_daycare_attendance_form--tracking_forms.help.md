# Daycare Attendance Form - Help Guide
## Purpose
This form is used to track attendance data for childcare or daycare sessions, ensuring that all relevant information is collected and documented accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the child's first and last name in the "First Name" and "Last Name" fields respectively.
2. Enter the child's date of birth in the "Date of Birth" field.
3. Select the child's current status (Active, Inactive, or Absent) from the "Child Status" dropdown menu.
4. Enter the caregiver's name, email, and phone number in the corresponding fields.
5. Select the session type (Regular or Emergency) from the "Session Type" dropdown menu.
6. Choose the session start and end dates in the "Session Start Date" and "Session End Date" fields respectively.
7. Enter the session start and end times in the "Session Start Time" and "Session End Time" fields respectively.
8. Enter the session duration (in minutes) in the "Session Duration" field.
9. Enter any additional notes for the parent in the "Notes for Parent" field.
10. Enter any additional notes for the caregiver in the "Notes to Caregiver" field.

## Field-by-Field Explanation

* **First Name** (1, text, required): Enter the child's first name.
* **Last Name** (2, text, required): Enter the child's last name.
* **Email** (3, email, required): Enter the caregiver's email address.
* **Phone** (4, text, optional): Enter the caregiver's phone number.
* **Date of Birth** (5, date, required): Enter the child's date of birth.
* **Arrival Time** (6, time, optional): Enter the child's arrival time.
* **Departure Time** (7, time, optional): Enter the child's departure time.
* **Notes** (8, note, optional): Enter any additional notes.
* **Caregiver Name** (9, text, optional): Enter the caregiver's name.
* **Caregiver Email** (10, email, required): Enter the caregiver's email address.
* **Caregiver Phone** (11, text, optional): Enter the caregiver's phone number.
* **Child Number** (12, number, required): Enter the child's ID number.
* **Child Name** (13, text, required): Enter the child's full name.
* **Session Duration** (14, number, required): Enter the session duration in minutes.
* **Session Start Time** (15, time, required): Enter the session start time.
* **Session End Time** (16, time, required): Enter the session end time.
* **Session Notes** (17, note, optional): Enter any additional session notes.
* **Child Status** (18, select_one, required): Select the child's current status.
* **Session Number** (19, number, optional): Enter the session number.
* **Session Type** (20, select_multiple, required): Select the session type (Regular or Emergency).
* **Notes for Parent** (21, note, optional): Enter any additional notes for the parent.
* **Session Date** (22, date, required): Enter the session date.
* **Session Start Date** (23, date, required): Enter the session start date.
* **Session End Date** (24, date, required): Enter the session end date.
* **Notes to Caregiver** (25, note, optional): Enter any additional notes for the caregiver.

## Tips

* Ensure that all required fields are filled out accurately to avoid incomplete session records.
* Double-check the session dates and times for consistency.
* Enter any additional notes for the parent and caregiver for better communication.
* Select the correct session type for accurate session tracking.
