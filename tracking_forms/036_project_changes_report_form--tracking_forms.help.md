Project Changes Report Form - Help Guide
=====================================

## Purpose

The Project Changes Report Form is designed to track changes made to a project. This form allows you to report changes to the project team and document the history of changes made to the project.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the project details on **Project Changes Report** page (page 1).
2. Select the type of change that occurred on **Change Type** page (page 2).
3. Enter a brief description of the change on **Description** page (page 3).
4. Enter the date and time of the change on **Date** and **Time** pages (pages 4 and 5).

## Field-by-Field Explanation

### Project Changes Report (Page 1)
* **Project Changes Report** (required: false): On this page, please enter a brief report of what changed. This can include text or any other project information that is relevant to the change.

### Change Type (Page 2)
* **Change Type** (required: false, options: 'Yes', 'No'): On this page, indicate whether the change was a yes or no change. If the change was a yes change, it is recommended to mark it as yes and provide more information in the description field.

### Description (Page 3)
* **Description** (required: false): Enter a brief description of the change. This field is optional, but providing a description helps to clarify the change and its context.

### Date (Page 4)
* **Date** (required: false): Enter the date of the change. Please use the standard date format.

### Time (Page 5)
* **Time** (required: false): Enter the time of the change. Please use 24-hour format.
