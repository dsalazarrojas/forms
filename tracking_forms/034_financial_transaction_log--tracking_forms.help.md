# Financial Transaction Log - Help Guide
## Purpose

This form is used to record and track financial transactions, providing detailed information about each transaction. It's essential to fill out this form accurately for maintaining precise financial records.

## How To Complete This Form

1. Select the correct transaction type from the available options.
2. Enter the date of the transaction using the date picker.
3. Enter the amount of the transaction.
4. Provide a brief description of the transaction.
5. Choose the transaction's currency from the available options.
6. If relevant, enter a reference for the transaction.
7. Provide any additional notes about the transaction.

## Field-by-Field Explanation

* **Transaction Date** (`transaction_date`, required: false): Date of the transaction. This is the date when the financial transaction occurred.
* **Transaction Type** (`transaction_type`, required: true): The type of transaction, which can be Income, Expense, or Transfer.
* **Transaction Amount** (`transaction_amount`, required: false): The monetary value of the transaction.
* **Transaction Description** (`transaction_description`, required: false): A brief description of the transaction, providing context or details about the transaction.
* **Transaction Currency** (`transaction_currency`, required: true): The currency used in the transaction, which can be USD or CAD.
* **Transaction Reference** (`transaction_reference`, required: false): A reference for the transaction, if applicable.
* **Transaction Note** (`transaction_note`, required: false): Any additional notes or comments about the transaction.
* **Transaction User** (`transaction_user`, required: false): The user associated with the transaction.
* **Transaction Company** (`transaction_company`, required: false): The company associated with the transaction.
* **Transaction Date 2** (`transaction_date_2`, required: false): Date of the second transaction.
* **Transaction Type 2** (`transaction_type_2`, required: false): The type of second transaction.
* **Transaction Amount 2** (`transaction_amount_2`, required: false): The amount of the second transaction.
* **Transaction Description 2** (`transaction_description_2`, required: false): A description of the second transaction.
* **Transaction Currency 2** (`transaction_currency_2`, required: false): The currency used for the second transaction.
* **Transaction Reference 2** (`transaction_reference_2`, required: false): A reference for the second transaction.
* **Transaction Note 2** (`transaction_note_2`, required: false): Any notes about the second transaction.
* **Transaction User 2** (`transaction_user_2`, required: false): The user associated with the second transaction.
* **Transaction Company 2** (`transaction_company_2`, required: false): The company associated with the second transaction.

## Tips

* Always enter accurate and up-to-date information to ensure correct financial records.
* If a field is not relevant, leave it blank.
* For repeated transactions (e.g., transaction 2, 3, etc.), fill out the corresponding fields accurately.
