# Project Task Assignment Form - Help Guide

## Purpose
The Project Task Assignment Form is used to assign tasks to team members and track project progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the team members to whom you want to assign the task.
2. Enter the assigned date when the task is assigned to the team member.
3. Enter the due date when the task is due to be completed.
4. Describe the task in the task description field.
5. Select the project status (in progress, completed, or pending).
6. If a specific tool is assigned to the task, enter it in the assigned tool field.
7. Add any additional notes about the task in the notes field.

## Field-by-Field Explanation
* **Select Team Members** (`team_members`, `select_multiple`, optional):
    + Select one or more team members to whom you want to assign the task.
* **Assigned Date** (`assigned_date`, `date`, optional):
    + Enter the date when the task is assigned to the team member.
* **Due Date** (`due_date`, `date`, optional):
    + Enter the date when the task is due to be completed.
* **Task Description** (`task_description`, `text`, optional):
    + Describe the task in a few sentences or short paragraphs.
* **Project Status** (`project_status`, `select_one`, optional):
    + Select the current status of the project (in progress, completed, or pending).
* **Assigned Tool** (`assigned_tool`, `text`, optional):
    + If a specific tool is assigned to the task, enter it here.
* **Notes** (`notes`, `note`, optional):
    + Add any additional notes about the task, such as reminders or follow-ups.

## Tips
* Make sure to select team members who are capable of completing the task.
* Set realistic due dates to ensure tasks are completed on time.
* Regularly update the project status to track progress.
* Use the notes field to keep track of task-related discussions or reminders.
