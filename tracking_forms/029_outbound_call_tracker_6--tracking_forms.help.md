# outbound_call_tracker_6 - Help Guide
## Purpose
The Outbound Call Tracker 6 form is used to track information about calls made to customers. This form helps keep track of important details such as contact information, call type, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the first name of the person being called.
2. Enter the last name of the person being called.
3. Enter the phone number of the person being called.
4. Select whether the call was successful (Yes/No).
5. Select the date of the call.
6. Select the time of the call.
7. Add any notes about the call.
8. If necessary, enter the email of the person being called.
9. If necessary, re-enter the phone number of the person being called.
10. Select whether the call was assigned to someone (Yes/No).
11. Select whether the call was assigned by someone (Yes/No).
12. Select the status of the call (Active/Inactive).
13. Add any tags relevant to the call.

## Field-by-Field Explanation

* **First Name** (user_first_name, text, required): Enter the first name of the person being called.
* **Last Name** (user_last_name, text, required): Enter the last name of the person being called.
* **Phone** (phone_number, number, required): Enter the phone number of the person being called.
* **Call Type** (call_type, select_one, required): Select whether the call was successful (Yes/No).
* **Date of Call** (date, date, required): Select the date of the call.
* **Time of Call** (time, time, required): Select the time of the call.
* **Notes** (note, note, required): Add any notes about the call.
* **Email** (email, email, required): If necessary, enter the email of the person being called.
* **Phone** (phone, text, required): If necessary, re-enter the phone number of the person being called.
* **Assigned to** (assigned_to, select_multiple, required): Select whether the call was assigned to someone (Yes/No).
* **Assigned by** (assigned_by, select_multiple, required): Select whether the call was assigned by someone (Yes/No).
* **Status** (status, select_one, required): Select the status of the call (Active/Inactive).
* **Tags** (tags, text, required): Add any relevant tags to the call.
