# Medical Supplies Usage Report Form - Help Guide

## Purpose
This form is used to report the usage of medical supplies in the facility.

## How To Complete This Form

1. Select the products that were used by choosing the options that apply. Please choose all products that were used during the reported time period.
2. Choose the specific products that were used from the options provided.
3. Enter the truck number associated with the delivery of the used medical supplies.
4. Enter your name, the person submitting the form.
5. If you have any additional comments or notes, please include them in the text box below.

## Field-by-Field Explanation
* **Stock Products**: This is a multiple selection field where you can choose all the products that were used. This will help track which products were used during the reported time period.
* **Products Used**: This field allows you to choose the specific products that were used from the options provided.
* **Truck Number**: This is the number associated with the delivery of the used medical supplies. Enter the exact number to help track the source of the supplies.
* **Submitter Name**: This is the name of the person submitting the form. This is an optional field, but please use your official name and title if you have access.
* **Notes & Comments**: This is an optional field where you can enter any additional comments or notes about the usage of the medical supplies. This can be a good place to report any discrepancies or issues with the supplies.

## Tips
* If you are unsure about any of the fields, please contact the facility administration for clarification.
* If you have any additional questions or concerns, please ask your supervisor or facility administration.
