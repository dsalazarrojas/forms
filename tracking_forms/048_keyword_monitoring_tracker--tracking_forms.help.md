# Keyword Monitoring Tracker - Help Guide
## Purpose
The Keyword Monitoring Tracker form is used to track a keyword or phrase across multiple search engines and platforms. It allows users to input their keyword, select the search engines and frequency at which to monitor, and provide additional details to receive alerts.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the keyword you want to monitor in the **Keyword Input** field.
2. Select the **Platform** on which you want to monitor the keyword (e.g., Google, Bing, Other).
3. Choose how often you want to receive **Alerts** on changes to the keyword (e.g., daily, weekly, monthly).
4. Select the **Search Engine(s)** where you want to monitor the keyword (e.g., Google, Bing, Yahoo).
5. If you want to receive alerts on your phone, enter a valid **Phone Number**.
6. Enter any additional **Notes** about the keyword or the project.
7. Fill in your **Tracker ID** to identify the tracking project.

## Field-by-Field Explanation

* **Form Title**: This is the title of your tracking project, which will appear in the project list.
	+ Type: **text**
	+ Required: No
* **Keyword Input**: Enter the keyword or phrase you want to monitor.
	+ Type: **text**
	+ Required: Yes
* **Platform**: Select the platform(s) on which you want to monitor the keyword (e.g., Google, Bing, Other).
	+ Type: **select_one**
	+ Options: Google, Bing, Other
	+ Required: No
* **Search Engine**: Select the search engine(s) where you want to monitor the keyword (e.g., Google, Bing, Yahoo).
	+ Type: **select_multiple**
	+ Options: Google, Bing, Yahoo, Other
	+ Required: No
* **Monitor Frequency**: Choose how often you want to receive alerts on changes to the keyword (e.g., daily, weekly, monthly).
	+ Type: **select_one**
	+ Options: daily, weekly, monthly
	+ Required: No
* **Alert Frequency**: Choose how often you want to receive alerts on changes to the keyword (e.g., never, daily, weekly, monthly).
	+ Type: **select_one**
	+ Options: never, daily, weekly, monthly
	+ Required: No
* **Email**: Enter a valid email address to receive alerts on changes to the keyword.
	+ Type: **email**
	+ Required: No
* **Phone**: Enter a valid phone number to receive alerts on changes to the keyword.
	+ Type: **text**
	+ Required: No
* **Date**: Enter the date you want to monitor the keyword from.
	+ Type: **date**
	+ Required: No
* **Time**: Enter the time you want to monitor the keyword from.
	+ Type: **time**
	+ Required: No
* **Note**: Enter any additional notes about the keyword or the project.
	+ Type: **note**
	+ Required: No
* **Tracker ID**: Enter a unique ID to identify the tracking project.
	+ Type: **text**
	+ Required: No
