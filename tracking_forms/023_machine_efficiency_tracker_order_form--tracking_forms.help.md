# Machine Efficiency Tracker Order Form - Help Guide
## Purpose
The Machine Efficiency Tracker Order Form is used to capture information about orders of machine monitoring tools. This form is designed to help you track the details of the tools being ordered, including the tool's ID, name, and model.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the Machine Monitoring Tool ID.
2. Enter the Name of the person or department ordering the machine monitoring tool.
3. Enter the Email of the person or department responsible for the order.
4. Enter the Phone number of the person or department responsible for the order.
5. Provide a brief Description of the order.
6. Select the Machine Monitoring Tool Type from the options provided.
7. Select the Machine Monitoring Tool Model from the options provided.
8. Enter the Machine Monitoring Tool Serial Number, if applicable.
9. Select the Order Date from the calendar.
10. Select the Order Time from the clock.

## Field-by-Field Explanation
* **Machine Monitoring Tool ID** (`machine_monitoring_tool_id`, `text`, required: false): Enter a unique identifier for the machine monitoring tool.
* **Name** (`name`, `text`, required: false): Enter the name of the person or department ordering the machine monitoring tool.
* **Email** (`email`, `email`, required: false): Enter the email of the person or department responsible for the order.
* **Phone** (`phone`, `text`, required: false): Enter the phone number of the person or department responsible for the order.
* **Description** (`description`, `text`, required: false): Enter a brief description of the order.
* **Machine Monitoring Tool Type** (`machine_monitoring_tool_type`, `select_one`, required: false): Select the type of machine monitoring tool being ordered.
* **Machine Monitoring Tool Model** (`machine_monitoring_tool_model`, `select_one`, required: false): Select the model of the machine monitoring tool being ordered.
* **Machine Monitoring Tool Serial Number** (`machine_monitoring_tool_serial_number`, `text`, required: false): Enter the serial number of the machine monitoring tool, if applicable.
* **Order Date** (`order_date`, `date`, required: false): Select the date the order was placed.
* **Order Time** (`order_time`, `time`, required: false): Select the time the order was placed.
