# cumulative_record_collection_form_template - Help Guide
## Purpose
This form is designed to collect data for tracking performance and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the "Tracking Performance" section, which is required.
2. If necessary, complete the "Attendance" section by selecting one or multiple options.
3. In the "Behavior" section, provide a note about the subject's behavior.
4. Finally, input your signature in the "Signature" section.

## Field-by-Field Explanation

* **Tracking Performance** (`tracking_performance`, `text`, required): This field is used to record the subject's performance data. Please provide a text description of the performance being tracked.
* **Attendance** (`attendance`, `select_multiple`, optional): Select one or multiple options to indicate the subject's attendance. This field is optional but required if any options are selected.
* **Behavior** (`behavior`, `note`, required): Please provide a note about the subject's behavior. This field is required.
* **Signature** (`signature`, `text`, required): Input your signature in this field. This field is required.

## Tips
* Make sure to complete all required fields.
* For the "Attendance" field, select only the options that apply.
* For the "Behavior" field, provide a clear and concise note about the subject's behavior.
* For the "Signature" field, input your name or any other type of text as required.
