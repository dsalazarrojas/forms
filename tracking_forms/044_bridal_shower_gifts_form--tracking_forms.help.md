# Bridal Shower Gifts Form - Help Guide

## Purpose
The Bridal Shower Gifts Form is a tool designed to track gifts given to a bride at a bridal shower. It helps keep track of the gifts' details, including the giver's information, gift value, and gift status. This form is essential for sending thank you notes and ensuring the bride feels appreciated and valued by her loved ones.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **Bride's Name** in the field provided. This is the primary field and is required.
2. Select the **Bridal Shower Date** when the shower took place. This helps in matching the gifts with the corresponding event.
3. Enter the **Gift Number** which is a sequential number for tracking purposes.
4. Fill in the **Donor's Name** and **Donor Email** fields if applicable.
5. Specify the **Gift Description** in as much detail as possible.
6. Choose the correct **Gift Category** from the provided options. This helps in categorizing and grouping gifts for easier reference.
7. Enter the approximate or actual **Gift Value**.
8. Select **From Registry** to indicate if the gift was from the bridal registry.
9. If the gift was from a registry, specify the **Registry Store**.
10. Enter the **Quantity of the Item** if applicable.
11. If applicable, enter the **Gift Color**.
12. Add any **Special Details or Personalization** for the gift.
13. Indicate if a **Receipt Was Included** with the gift.
14. Select the **Gift Condition Upon Receipt** if applicable.
15. Indicate if a **Thank You Note Was Sent** to the donor.
16. If a thank you note was sent, select the **Date it Was Sent**.
17. Choose the method used to send the thank you **Note**.
18. Specify the current **Gift Status**.
19. Add any **Exchange or Return Details** if applicable.
20. Finally, include any **Additional Notes** about the gift or donor.

## Field-by-Field Explanation

* **Bride Name** (`bride_name`, text, required): Enter the name of the bride who received the gift.
* **Bridal Shower Date** (`shower_date`, date, required): Select the date the bridal shower took place.
* **Gift Number** (`gift_number`, number, required): A sequential number for tracking gifts.
* **Donor or Giver Name** (`donor_name`, text, required): Enter the name of the person who gave the gift.
* **Donor Email** (`donor_email`, email, optional): Enter the email of the person who gave the gift, if applicable.
* **Donor Phone Number** (`donor_phone`, text, optional): Enter the phone number of the person who gave the gift, if applicable.
* **Gift Description** (`gift_description`, text, required): Describe the gift in detail.
* **Gift Category** (`gift_category`, select_one, required): Select the category of the gift from the options provided.
* **Gift Value** (`gift_value`, number, optional): Enter the approximate or actual value of the gift.
* **From Registry** (`gift_from_registry`, select_one, optional): Indicate if the gift was from the bridal registry.
* **Registry Store** (`registry_store`, text, optional): If the gift was from a registry, specify the store.
* **Quantity of Item** (`quantity`, number, optional): If applicable, enter the quantity of the item.
* **Gift Color** (`gift_color`, text, optional): If applicable, enter the color of the gift.
* **Special Details or Personalization** (`special_details`, text, optional): Enter any special details or personalization for the gift.
* **Receipt Included** (`receipt_included`, select_one, optional): Indicate if a receipt was included with the gift.
* **Gift Condition Upon Receipt** (`gift_condition`, select_one, optional): Select the condition of the gift upon receipt.
* **Thank You Note Sent** (`thank_you_sent`, select_one, required): Indicate if a thank you note was sent to the donor.
* **Thank You Note Date Sent** (`thank_you_date`, date, optional): If a thank you note was sent, select the date it was sent.
* **Thank You Method** (`thank_you_method`, select_one, optional): Choose the method used to send the thank you note.
* **Gift Status** (`gift_used_exchanged`, select_one, optional): Select the current status of the gift.
* **Exchange or Return Details** (`exchange_details`, text, optional): If the gift was exchanged or returned, enter the details.
* **Additional Notes** (`notes`, text, optional): Add any other information about the gift or donor.
