# Security Officer Daily Shift Form - Help Guide
## Purpose
The Security Officer Daily Shift Form is used to track and report the security officer's daily activities, including incidents that occurred during the shift, officer's equipment used, and other relevant details.

## How To Complete This Form
1. Ensure that you have a clear understanding of your incident summary.
2. Select whether you encountered any incidents during the shift.
3. Enter your officer ID, officer name, and start and end times.
4. Report any incidents that occurred during the shift.
5. Indicate if you used any officer vehicles during the shift.
6. Select the officer and incident status.
7. Report your officer attendance status and attendance.
8. Indicate the location status.
9. Enter any comments or notes.

* **Incident Location**: Enter the location where the incident occurred.
* **Incident Comments**: Enter any comments or notes about the incident.
* **Officer Comments**: Enter any comments or notes about the shift.
