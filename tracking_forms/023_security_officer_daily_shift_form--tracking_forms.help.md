# Security Officer Daily Shift Form - Help Guide
## Purpose
The Security Officer Daily Shift Form is used to track and report the security officer's daily activities, including incidents that occurred during the shift, officer's equipment used, and other relevant details.

## How To Complete This Form
1. Ensure that you have a clear understanding of your incident summary.
2. Select whether you encountered any incidents during the shift.
3. Enter your officer ID, officer name, and start and end times.
4. Report any incidents that occurred during the shift.
5. Indicate if you used any officer vehicles during the shift.
6. Select the officer and incident status.
7. Report your officer attendance status and attendance.
8. Indicate the location status.
9. Enter any comments or notes.

## Field-by-Field Explanation

* **Incident Summary**: Enter a brief summary of the incidents that occurred during the shift.
* **Incidents**: Indicate whether any incidents occurred during the shift (Yes/No).
* **Officer ID**: Enter your officer ID number.
* **Officer Name**: Enter your name.
* **Date Shift**: Enter the date of the shift.
* **Start Time**: Enter the start time of the shift.
* **End Time**: Enter the end time of the shift.
* **Incident Details**: Enter any additional details about the incidents that occurred during the shift.
* **Incident Location**: Enter the location where the incident occurred.
* **Incident Comments**: Enter any comments or notes about the incident.
* **Officer Comments**: Enter any comments or notes about the shift.
* **Weather Conditions**: Enter any weather conditions that may have impacted the shift.
* **Officer Vehicles Used**: Indicate whether you used any officer vehicles during the shift (Yes/No).
* **Officer Equipment Used**: Indicate the officer equipment used during the shift.
* **Officer Comments**: Enter any comments or notes about the shift.
* **Officer Status**: Select your current officer status (Active/Inactive).
* **Officer Vehicles Status**: Select your officer vehicle status (Active/Inactive).
* **Officer Attendance**: Select whether you attended the shift (Yes/No).
* **Officer Attendance Status**: Select your attendance status (Active/Inactive).
* **Incident Location Status**: Select the location status (Active/Inactive).
* **Officer Vehicles Count**: Enter the number of officer vehicles used.
* **Officer Comments Status**: Select the status of your comments (Active/Inactive).
* **Incident Status**: Select the status of the incident (Active/Inactive).
* **Incident Vehicles Status**: Select the status of the incident vehicles (Active/Inactive).
* **Incident Comments**: Enter any comments or notes about the incident.
* **Officer Attendance**: Select whether you attended the shift (Yes/No).
* **Officer Attendance Status**: Select your attendance status (Active/Inactive).
* **Incident Location Status**: Select the location status (Active/Inactive).
