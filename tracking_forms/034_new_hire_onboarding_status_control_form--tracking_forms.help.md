# New Hire Onboarding Status Control Form - Help Guide
## Purpose
This form is used to track the onboarding status of new hires in the company. It collects information about the new hire's details, hiring date, job title, department, status, notes, contact email, contact phone, manager comments, and onboarding status. This form helps managers keep track of new hires' progress and ensures that everyone is on the same page.

## How To Complete This Form
To complete this form, follow the steps below:

1. Click on the "Submit" button to start filling out the form.
2. Fill out the required fields, which include:
	* New Hire Details
	* Hire Date
	* Status (choose one or more from the dropdown list)
	* Manager Comments
	* Onboarding Status (choose a date)
3. You can leave the optional fields blank if not applicable, but be aware that they will not be visible on the form submission.
4. Review your form submission before clicking the "Submit" button to ensure all required fields are filled out.

## Field-by-Field Explanation
* **New Hire Details** (`new_hire_details`, text, required):
	+ This field is used to input the new hire's full name.
* **Hire Date** (`hire_date`, date, required):
	+ This field is used to input the new hire's hire date.
* **Job Title** (`job_title`, text, optional):
	+ This field is used to input the new hire's job title.
* **Department** (`department`, select_one, required):
	+ This field is used to select the new hire's department (Engineering, Finance, or HR).
* **Status** (`status`, select_multiple, required):
	+ This field is used to select the new hire's status (Pending, In Progress, or Completed).
* **New Hire Notes** (`new_hire_notes`, note, required):
	+ This field is used to input any additional notes about the new hire.
* **New Hire Contact Email** (`new_hire_contact_email`, email, optional):
	+ This field is used to input the new hire's contact email (if applicable).
* **New Hire Contact Phone** (`new_hire_contact_phone`, text, optional):
	+ This field is used to input the new hire's contact phone number (if applicable).
* **Manager Comments** (`manager_comments`, text, required):
	+ This field is used for the manager to input any comments or feedback about the new hire.
* **New Hire Comments** (`new_hire_comments`, text, optional):
	+ This field is used to input any additional comments or feedback about the new hire (if applicable).
* **Onboarding Status** (`onboarding_status`, date, required):
	+ This field is used to input the new hire's onboarding status date.

## Tips
* Make sure to review the form submission before clicking the "Submit" button to ensure all required fields are filled out.
* If the new hire's status is "Pending", ensure that the onboarding status date is a future date.
* If you need to add or update any additional information about the new hire, use the "New Hire Notes" field.
