# Vessel Daily Log Form - Help Guide
## Purpose
The Vessel Daily Log Form is used to track daily activities and events related to vessel operations, such as vessel maintenance, crew activities, and notable events. This form helps to gather information that can be used for analysis and improvement of vessel performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct vessel operation date from the calendar picker.
2. Enter the vessel name and type from the provided options.
3. Record the departure and arrival times, if applicable.
4. Select the crew size, which may be a numerical value.
5. Provide any relevant vessel remarks, up to 14 fields for comments.

## Field-by-Field Explanation
* **Vessel Operation Date** (`vessel_operation_date`): Enter the date of the operation, which should match the calendar date.
* **Vessel Name** (`vessel_name`): Select the name of the vessel from the provided options.
* **Location** (`location`): Enter the location of the operation, if applicable.
* **Departure Time** (`departure_time`): Enter the departure time of the vessel, if applicable.
* **Arrival Time** (`arrival_time`): Enter the arrival time of the vessel, if applicable.
* **Vessel Type** (`vessel_type`): Select the type of vessel from the provided options.
* **Crew Size** (`crew_size`): Enter the number of crew members on board.
* **Weather Conditions** (`weather_conditions`): Select the weather conditions from the provided options, if applicable.
* **Navigation Notes** (`navigation_notes`): Enter any navigation-related notes or comments.
* **Onboard Activity Log** (`onboard_activity_log`): Enter any onboard activity logs or comments.
* **Voyage Details** (`voyage_details`): Enter any voyage-specific details or comments.
* **Remarks 2-14** (`remarks_2`-`remarks_14`): Enter any additional remarks or comments related to the operation. 

These fields are intended to provide a comprehensive view of vessel operations and activities. Each field is designed to be used in conjunction with other fields to gather a complete picture of daily events and performance.
