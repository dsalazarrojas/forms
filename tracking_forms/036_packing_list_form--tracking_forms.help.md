# Packing List Form - Help Guide
## Purpose
The Packing List Form is designed to collect information from packers and track the packing process.

## How To Complete This Form
1. Fill out the form in multiple pages, starting with Page 1.
2. Enter your packing information on each page, making sure to fill out all required fields.
3. Review each page for accuracy before proceeding to the next.
4. Once you have completed all pages, submit the form to submit your packing information.

## Field-by-Field Explanation
- **Packer Name** (`packer_name`, text, required): Enter your name as the packer responsible for this item.
- **Item Name** (`item_name`, text, required): Enter the name of the item being packed.
- **Item Type** (`item_type`, select_one, required): Select the type of item being packed (Backpack, Pencil, etc.).
- **Item Quantity** (`item_quantity`, number, optional): Enter the quantity of the item being packed.
- **Item Size** (`item_size`, number, optional): Enter the size of the item being packed.
- **Packer Email** (`packer_email`, email, optional): Enter your email address as the packer responsible for this item.
- **Packer Phone** (`packer_phone`, text, optional): Enter your phone number as the packer responsible for this item.
- **Item Date Required** (`item_date_required`, date, optional): Enter the date by which the item is required to be packed.
- **Item Time Required** (`item_time_required`, time, optional): Enter the time by which the item is required to be packed.
- **Notes** (`notes`, note, optional): Add any additional comments or notes about the item.

## Tips
- Please fill out all required fields (Packer Name, Item Name, Item Type, and Item Date Required) before proceeding.
- If a field is not required, you may leave it blank if it is not applicable.
- Please review each page for accuracy before proceeding to the next.
- Once you have completed all pages, review the entire form for accuracy before submitting it.
