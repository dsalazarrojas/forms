# Work Session Evidence Submission - Help Guide
## Purpose
The Work Session Evidence Submission form is used to provide detailed information about a work session, including its start and end dates and times, location, and submitted evidence type.

## How To Complete This Form

1. Select the correct evidence type from the "Work Session Evidence Type" dropdown menu. You can choose from options like Session Summary, Session Notes, Session Images, Session Audio, Session Video, and Session Other.
2. Enter the start date and time of the work session in the "Work Session Start Date" and "Work Session Start Time" fields, respectively.
3. Enter the end date and time of the work session in the "Work Session End Date" and "Work Session End Time" fields, respectively.
4. Enter the session location in the "Session Location" field.
5. If necessary, provide additional session notes in the "Session Notes" or "Session Other Notes" fields.
6. Enter the incident number and session ID (if available) in the respective fields.
7. Select the person who submitted the evidence from the "Submitted By" dropdown menu.
8. Review your submission for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **Work Session Evidence Submission** (1, work_session_evidence_submission, required): This is the main field where you can enter a brief description of the evidence you are submitting.
* **Work Session Start Date** (2, work_session_start_date, required): Enter the start date of the work session in YYYY-MM-DD format.
* **Work Session Start Time** (3, work_session_start_time, required): Enter the start time of the work session in 24-hour format (HH:MM).
* **Work Session End Date** (4, work_session_end_date, required): Enter the end date of the work session in YYYY-MM-DD format.
* **Work Session End Time** (5, work_session_end_time, required): Enter the end time of the work session in 24-hour format (HH:MM).
* **Work Session Evidence Type** (6, work_session_evidence_type, required): Select the type of evidence you are submitting, which can be Session Summary, Session Notes, Session Images, Session Audio, Session Video, or Session Other.
* **Incident Number** (7, incident_number, required): Enter the incident number related to the work session.
* **Session Location** (8, session_location, required): Enter the location where the work session took place.
* **Session Notes** (9, session_notes, optional): Provide additional session notes if necessary.
* **Session Other Notes** (10, session_other_notes, optional): Provide any other notes related to the session.
* **Submitted By** (11, submitted_by, required): Select the person who submitted the evidence, which can be Administrator, Team Lead, or Team.
* **Session ID** (12, session_id, optional): Enter the session ID if available.
