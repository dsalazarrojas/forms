# Property Maintenance Weighbridge Log - Help Guide
## Purpose
This form is used to record and track information about property maintenance weighbridges. It helps to ensure that all relevant details are documented accurately and thoroughly.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the required and optional information as prompted. Note that some fields are not mandatory, so you can skip them if not applicable.
2. Fill in the `Vehicle Details` section with any relevant information about the vehicle.
3. Record the `Vehicle Weight`, if applicable.
4. Enter the `Vehicle Number Plate` if it is available.
5. Fill in the `Site ID` field with the relevant site identification number.
6. Enter the `Maintenance Date` and `Maintenance Time` of the activity.
7. Provide any comments from the supervisor in the `Supervisor Comment` field.
8. Add any additional comments from facilities personnel in the `Facilities Comment` field.
9. Select the vehicle type as `Yes` or `No`, depending on whether it is applicable.
10. Enter the `Driver Name` if it is relevant.

## Field-by-Field Explanation
* **Vehicle Details** (`vehicle_details`, text, required): Fill in any information about the vehicle, such as make, model, and any other relevant details.
* **Vehicle Weight** (`vehicle_weight`, number, optional): Record the weight of the vehicle if applicable.
* **Vehicle Number Plate** (`vehicle_number_plate`, text, optional): Enter the vehicle's number plate if available.
* **Site ID** (`site_id`, number, optional): Fill in the site identification number.
* **Maintenance Date** (`maintenance_date`, date, optional): Record the date of the maintenance activity.
* **Maintenance Time** (`maintenance_time`, time, optional): Record the time of the maintenance activity.
* **Supervisor Comment** (`supervisor_comment`, text, optional): Provide any comments from the supervisor.
* **Facilities Comment** (`facilities_comment`, text, optional): Add any comments from facilities personnel.
* **Vehicle Type** (`vehicle_type`, select_one, optional): Select `Yes` or `No` depending on if it is a vehicle type that requires maintenance.
* **Driver Name** (`driver_name`, text, optional): Enter the driver's name if it is relevant.

## Tips
* Double-check the entered information for accuracy before submitting the form.
* If you are unsure about any field, refer to the relevant personnel or consult the database.
* Ensure that all required fields are filled in before submitting the form.
