# Manufacturing Innovation Progress Report - Help Guide
## Purpose
The Manufacturing Innovation Progress Report form is used to track the progress of manufacturing projects and gather information on project status, milestones achieved, and challenges encountered. This report helps stakeholders make informed decisions about next steps.

## How To Complete This Form
- Fill in the project status in the first field, providing a brief description of the project's current state.
- For the `milestones_achieved` field, select the milestones that have been completed, separated by commas. For example, "Completed milestone 1, completed milestone 2".
- In the `challenges_encountered` field, type a brief description of any challenges or obstacles that the project team is facing.
- In the `project_manager_comments`, `engineering_comments`, `production_manager_comments`, and `quality_manager_comments` fields, select "Yes" if you have comments or input, and type your comments in the text field below.

## Field-by-Field Explanation
- **project_status**: A brief description of the project's current state (e.g., "On track for completion", "Delayed due to technical issues", etc.).
	+ Type: text
	+ Required: no
- **milestones_achieved**: Select completed milestones, separated by commas (e.g., "Milestone 1, milestone 2, milestone 3").
	+ Type: select_multiple
	+ Required: no
- **challenges_encountered**: A brief description of any challenges or obstacles the project team is facing.
	+ Type: text
	+ Required: no
- **next_steps**: Brief description of the next steps or actions planned for the project.
	+ Type: text
	+ Required: no
- **project_manager_comments**: Select "Yes" if you have comments or input.
	+ Type: select_multiple
	+ Required: no
- **engineering_comments**: Select "Yes" if you have comments or input, then type your comments.
	+ Type: text
	+ Required: no
- **production_manager_comments**: Select "Yes" if you have comments or input, then type your comments.
	+ Type: text
	+ Required: no
- **quality_manager_comments**: Select "Yes" if you have comments or input, then type your comments.
	+ Type: text
	+ Required: no
