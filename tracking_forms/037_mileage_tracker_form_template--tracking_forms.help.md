# mileage_tracker_form_template - Help Guide
## Purpose
The mileage_tracker_form_template is designed to track vehicle-related activities, such as mileage, fuel types, and locations. This form helps collect information about vehicle usage, enabling users to monitor and analyze their vehicle's performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Vehicle ID** in the first field. This is a unique identifier for your vehicle.
2. Select the **Date** of the vehicle's usage.
3. Enter the **Odometer Reading** of the vehicle at the start of the activity.
4. Enter the **Distance** traveled by the vehicle.
5. Select the **Purpose** of the vehicle's usage from the available options (Reimbursement, Tax Deduction, or Other).
6. Enter the **Start Location** where the vehicle's activity began.
7. Enter the **End Location** where the vehicle's activity ended.
8. Select the **Fuel Type** used by the vehicle from the available options (Gasoline, Diesel, Hybrid, or Other).
9. Enter the **Total Miles** traveled by the vehicle. Please note that this field is required.
10. Finally, add any additional **Notes** about the vehicle's usage.

## Field-by-Field Explanation
- **Vehicle ID** (text): Enter your vehicle's unique identifier.
- **Date** (date): Select the date of the vehicle's usage.
- **Odometer Reading** (text): Enter the vehicle's odometer reading at the start of the activity.
- **Distance** (number): Enter the distance traveled by the vehicle.
- **Purpose** (select multiple): Select the purpose of the vehicle's usage.
  • Reimbursement: Select this option for official vehicle expenses.
  • Tax Deduction: Select this option for tax-deductible vehicle expenses.
  • Other: Select this option for other vehicle usage purposes.
- **Start Location** (text): Enter the location where the vehicle's activity began.
- **End Location** (text): Enter the location where the vehicle's activity ended.
- **Fuel Type** (select one): Select the type of fuel used by the vehicle.
  • Gasoline: Select this option for vehicles using gasoline as fuel.
  • Diesel: Select this option for vehicles using diesel as fuel.
  • Hybrid: Select this option for hybrid vehicles.
  • Other: Select this option for other types of fuel.
- **Total Miles** (number): Enter the total distance traveled by the vehicle. This field is required.
- **Notes** (note): Add any additional comments or notes about the vehicle's usage.
