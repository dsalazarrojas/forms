# Project Timesheet Form - Help Guide
## Purpose
The Project Timesheet Form is designed for project managers and team members to track and record progress on non-standard business operations projects.

## How To Complete This Form

### Step 1: Select a Project
- Click on the "Select a project" button to choose a project from the list of available projects.

### Step 2: Fill out the Form
- Enter the project title in the "Project Title" field.
- Enter the start and end dates of the project in the "Start Date" and "End Date" fields.
- Enter a brief description of the task or project in the "Task Description" field.
- Enter the estimated and actual hours worked on the project in the "Estimated Hours" and "Actual Hours" fields.
- Select the tool used for the project from the "Assigned Tool" field.

## Field-by-Field Explanation

* **Project Title (text)**: Enter the title of the project.
* **Start Date (date)**: Enter the date the project started.
* **End Date (date)**: Enter the date the project is estimated to end.
* **Task Description (text)**: Enter a brief description of the task or project.
* **Estimated Hours (number)**: Enter the estimated hours required for the project.
* **Actual Hours (number)**: Enter the actual hours worked on the project.
* **Assigned Tool (text)**: Select the tool or resource used for the project.

## Tips

- Make sure to select the correct project from the list.
- Double-check the accuracy of the dates and hours entered.
- Use clear and concise language for the task or project description.
- Ensure that you are tracking non-standard business operations projects only.
- If a field is not relevant to your project, you can leave it blank.
