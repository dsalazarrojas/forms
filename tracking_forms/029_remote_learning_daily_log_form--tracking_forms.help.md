# remote_learning_daily_log_form - Help Guide
## Purpose
The remote learning daily log form is a tool to track and record student progress and experiences during remote learning sessions.

## How To Complete This Form
1. Select the page where you wish to input your data.
2. Fill in each field as required:
   - **Remote Learning Daily Log Form** (page 1): Enter your thoughts and observations about the session.
   - **Subject**: Enter the subject or topic being covered in the session.
   - **Notes**: Enter any additional notes or comments about the session.
   - **Progress** (page 2): Enter a progress number, indicating how well you have mastered or completed the material.
   - **Student ID**: Enter your student ID number (if required).
   - **Teacher ID**: Enter your teacher's ID number (if required).
   - **Date**: Select the date of the session.
   - **Time**: Select the time of the session.
   - **Form Data 1-15** (pages 3-15): Enter any additional data relevant to the session.
