# Daily Gardening Report - Help Guide
## Purpose
The purpose of this form is to collect information about your daily gardening activities, plant health, and site conditions. This will help us track your progress and provide valuable insights for garden management and decision-making.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (marked as required).
2. Select all that apply for the select_multiple fields.
3. Ensure all fields are filled in accurately and thoroughly.

## Field-by-Field Explanation

* **Daily Gardening Report** (1, text, required): Enter a brief description of your daily gardening activities.
* **Task Completed** (2, select_multiple, required): Check all tasks you completed today:
	+ Task 1
	+ Task 2
	+ Task 3
* **Notes (Task 1)** (3, text, required): Enter notes for Task 1.
* **Notes (Task 2)** (4, text, required): Enter notes for Task 2.
* **Plant Health** (5, select_one, required): Check the plant's health:
	+ Good
	+ Fair
	+ Bad
* **Watering Frequency** (6, select_one, required): How often have you watered the plants?
	+ Daily
	+ Weekly
	+ Monthly
* **Watering Amount** (7, number, required): Enter the amount of water used.
* **Site Details** (8, text, required): Enter any site details, such as weather conditions or observations.
* **Photo Taken** (9, select_one, required): Was a photo taken?
	+ True
	+ False
* **Site Notes** (10, select_multiple, required): Check any site notes:
	+ Good
	+ Bad
	+ Neutral
* **Weather Conditions** (11, select_one, required): What are the weather conditions?
	+ Clear
	+ Cloudy
	+ Rain
* **Temperature** (12, number, required): Enter the current temperature.
* **Humidity** (13, select_one, required): What is the humidity level?
	+ High
	+ Low
	+ Medium
* **Soil Moisture** (14, select_one, required): What is the soil moisture level?
	+ High
	+ Low
	+ Medium
* **Plant Type** (15, select_one, required): Is the plant type:
	+ Yes
	+ No
* **Task 1** (16, select_multiple, required): Check all tasks for Task 1:
	+ Option 1
	+ Option 2
	+ Option 3
* **Task 2** (17, select_multiple, required): Check all tasks for Task 2:
	+ Option 1
	+ Option 2
	+ Option 3
* **Task 3** (18, select_multiple, required): Check all tasks for Task 3:
	+ Option 1
	+ Option 2
	+ Option 3
* **Plant Status** (19, select_one, required): What is the plant status?
	+ Active
	+ Inactive
* **Comments** (20, text, required): Enter any comments.
* **Site Name** (21, text, required): Enter the site name.
* **Site Location** (22, text, required): Enter the site location.
* **Photo** (23, text, required): Enter a photo description.
* **Submitter** (24, text, required): Enter the submitter name.
* **Submitted By** (25, text, required): Enter the submitted by name.
