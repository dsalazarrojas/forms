# Movie Shot List Form - Help Guide

## Purpose
This form is used to collect and track information on individual shots for a movie production. It is intended to be completed for each shot, and its data is used to inform shot planning, coordination, and execution.

## How To Complete This Form

1. To start, fill in the **Shot Schedule** field with the desired schedule for the shot (e.g., morning, afternoon, or evening).
2. Enter the **Scene ID** in the corresponding field. This is a unique identifier for each scene in the production.
3. Provide information about the **Shot Type**, if applicable. If unsure, leave this field empty.
4. Record the **Shot Number**, which is the sequence number for the shot.
5. If applicable, enter the **Camera Angle** and **Camera Position** to detail the camera's settings.
6. Note the **Lighting Conditions** for the shot.
7. Enter the **Shot Duration**, if known.
8. Add a brief **Shot Description** to provide context about the shot.
9. Record the **Shot Location**, if known.
10. Add any relevant **Shot Notes** for further reference.
11. Select the **Shot Status**, if known.
12. Enter the **Shot Priority**, if applicable.
13. If the shot has been rehearsed, provide details on the **Rehearshal**, **Rehearshal Location**, and **Rehearshal Notes**.
14. Finally, enter the **Shot Schedule Time** and **Shot Schedule Time End**, if applicable.

## Field-by-Field Explanation

* **Shot Schedule** (morning, afternoon, evening): Select the desired schedule for the shot.
* **Scene ID**: A unique identifier for each scene in the production.
* **Shot Type**: A descriptive field for the type of shot (e.g., establishing shot, close-up, etc.).
* **Shot Number**: A sequence number for the shot.
* **Camera Angle**: The angle of the camera for the shot.
* **Camera Position**: The position of the camera for the shot.
* **Lighting Conditions**: Details on the lighting setup for the shot.
* **Shot Duration**: The length of time required for the shot.
* **Shot Description**: A brief description of the shot.
* **Shot Location**: The location where the shot will be taken.
* **Shot Notes**: Any additional notes or comments on the shot.
* **Shot Status**: The current status of the shot (e.g., ready, pending, etc.).
* **Shot Priority**: The priority level of the shot.
* **Rehearshal**: Details on rehearshal, if applicable.
* **Rehearshal Location**: The location where the shot was rehearsed.
* **Rehearshal Notes**: Any notes or comments on the rehearshal.
* **Rehearshal Location Map URL**: A link to the map location where the shot was rehearsed.
* **Rehearshal Notes**: Any additional notes on the rehearshal.
* **Shot Location Map URL**: A link to the map location where the shot will be taken.
* **Shot Location Map URL Notes**: Any notes or comments on the map location.
* **Shot Location Map URL Link**: A link to view the map location.
* **Shot Location Map URL Label**: A label for the map location link.
* **Shot Location Map URL Alt Text**: An alternative text for the map location link.
* **Shot Schedule Time**: The planned start time for the shot.
* **Shot Schedule Time End**: The planned end time for the shot.
* **Shot Status Notes**: Any additional notes on the shot status.

Note: The **Rehearshal** section may seem redundant with other fields, but it likely refers to a different aspect of shot planning or rehearshal, which is not entirely clear without additional context.
