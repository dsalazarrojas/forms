# late_paperwork_submission_form - Help Guide

## Purpose
This form is used to track paper work submissions for employees, including overdue documents, their due dates, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form purpose and ensure it is relevant to your needs.
2. Determine if you have overdue documents to report.
3. Select all overdue documents from the "Overdue Documents" dropdown list.
4. Enter the due date of the overdue document(s).
5. Enter the employee's ID number.
6. Select the type of document (e.g., Late, Overdue, Missing).
7. Provide a description of the document and its status.
8. Enter the submitted date and time if applicable.
9. Add any additional notes about the submission.
10. Select the department assigned to handle the document (if applicable).

## Field-by-Field Explanation

* **Overdue Documents** (Overdue Documents, select_multiple, not required):
	+ This field allows you to select all overdue documents that need to be reported. Choose all relevant documents from the dropdown list.
* **Due Date** (Due Date, date, not required):
	+ Enter the due date of the overdue document(s). If left blank, the form will assume the document is overdue.
* **Employee ID** (Employee ID, number, not required):
	+ Enter the employee's ID number associated with the document(s).
* **Document Type** (Document Type, select_one, not required):
	+ Select the type of document being reported (e.g., Late, Overdue, Missing).
* **Description** (Description, text, not required):
	+ Provide a brief description of the document and its status.
* **Status** (Status, select_multiple, not required):
	+ Select the status of the document (e.g., Active, Inactive).
* **Submitted By** (Submitted By, email, not required):
	+ Enter the email address of the person who submitted the document.
* **Submitted Date** (Submitted Date, date, not required):
	+ Enter the date the document was submitted, if applicable.
* **Submitted Time** (Submitted Time, time, not required):
	+ Enter the time the document was submitted, if applicable.
* **Notes** (Notes, note, not required):
	+ Add any additional information about the submission.
* **Assigned To** (Assigned To, select_one, not required):
	+ Select whether the document is assigned to someone (e.g., 'Yes', 'No').
* **Department** (Department, select_one, not required):
	+ Select the department responsible for handling the document (e.g., Finance, HR, Operations).
