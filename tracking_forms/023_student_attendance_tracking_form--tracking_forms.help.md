# Student Attendance Tracking Form - Help Guide

## Purpose
This form is designed to track student attendance for events, workshops, or classes. It allows users to record the attendance status of students, which can be helpful for tracking attendance rates, identifying patterns, or generating reports.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the date of the event.
2. Enter the start time of the event.
3. Enter the student's name.
4. Enter the student's ID (if applicable).
5. Select the student's attendance status (present, absent, or late).

## Field-by-Field Explanation

* **form_group** (Text, Optional): Enter a brief description of the event or group name.
* **start_date** (Date, Optional): Date of the event. Enter in the format mm/dd/yyyy.
* **start_time** (Time, Optional): Start time of the event. Enter in the format 12:00 AM/PM.
* **student_name** (Text, Optional): Student's name.
* **student_id** (Number, Optional): Student's ID number (if applicable).
* **attendance** (Select Multiple, Optional): Select one or more of the following options to indicate the student's attendance status:
	+ **Present**: The student was present during the event.
	+ **Absent**: The student was not present during the event.
	+ **Late**: The student arrived late to the event.

## Tips

* Be as specific as possible when entering the student's name and student ID.
* If the student's attendance status is "late", try to include a reason for their tardiness.
* If the student has multiple attendance status (e.g., present and late), select all applicable options.
* Review the form carefully before submitting to ensure accuracy.
* If you are unsure about any field, please contact your administrator for guidance.
