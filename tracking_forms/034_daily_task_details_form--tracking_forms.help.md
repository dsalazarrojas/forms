# Daily Task Details Form - Help Guide

## Purpose
The Daily Task Details Form is designed to collect detailed information about daily tasks, including client and task-specific details. Its primary purpose is to provide a structured way to document and track tasks, making it easier to manage tasks and clients efficiently.

## How To Complete This Form

1.  Fill out the form with the necessary information, making sure to provide accurate details about each field.
2.  Use the available options or input fields as needed for each field.
3.  Review and submit the form once you have completed all the required and optional fields.

## Field-by-Field Explanation

*   **Daily Task Details** (Page 1, daily_task_details): This field is a text input where you can enter a brief description of the task.
    *   **Client Name** (Page 1, client_name): Enter the name of the client associated with this task.
    *   **Task Name** (Page 1, task_name): Enter the name of the task.
    *   **Task Date** (Page 1, task_date): Enter the date of the task in date format (e.g., 2023-02-20).
    *   **Task Start Time** (Page 1, task_start_time): Enter the start time of the task in 24-hour format (e.g., 08:00).
    *   **Task End Time** (Page 1, task_end_time): Enter the end time of the task in 24-hour format (e.g., 17:00).
    *   **Task Duration** (Page 1, task_duration): Enter the duration of the task in hours (e.g., 3).
    *   **Task Priority** (Page 1, task_priority): Select the priority level of the task from the options: 'Yes' or 'No'.
    *   **Task Notes** (Page 1, task_notes): Enter any relevant notes about the task.
    *   **Task Tags** (Page 1, task_tags): Select relevant tags for the task from the options: 'Yes' or 'No'.
    *   **Task Status** (Page 1, task_status): Select the status of the task from the options: Active or Inactive.
    *   **Client Status** (Page 1, client_status): Select the client's status from the options: Active or Inactive.
    *   **Task Location** (Page 1, task_location): Enter the location of the task.
    *   **Form Submitted By** (Page 1, form_submitted_by): Enter your email address for tracking purposes.
    *   **Form Submitted On** (Page 1, form_submitted_on): Select the date the form was submitted.

Note: All fields are optional except for **Form Submitted By** and **Form Submitted On**, which are required for tracking purposes.
