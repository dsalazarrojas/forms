# Tool Life Tracking Report Request Form - Help Guide

## Purpose
The Tool Life Tracking Report Request Form is designed to collect information about tools that need to be tracked. It is used to request a tool life tracking report, which will help analyze and monitor the usage of tools across the organization.

## How To Complete This Form
To complete this form, simply fill in the required information below.

## Field-by-Field Explanation
* **Tool Name (text)**: Enter the name of the tool that you would like to track.
* **Tool ID (number)**: Enter the ID of the tool that you would like to track (if applicable).
* **Tool Type (select_one)**: Select the type of tool that you would like to track from the list below:
	+ Tool 1
	+ Tool 2
	+ Tool 3
* **Date Used (date)**: Enter the date the tool was used (if available).
* **Time Used (time)**: Enter the time the tool was used (if available).
* **Usage Hours (number)**: Enter the number of hours the tool was used.
* **Usage Comments (text)**: Enter any additional comments about the tool's usage.
* **Attachment URL (text)**: Enter the URL of any attachment related to the tool (if applicable).
* **Attachment File (text)**: Enter the file related to the tool (if applicable).
* **Assigned To (select_one)**: Select who the tool was assigned to from the list below:
	+ ChatJ
	+ Other
* **Assigned Date (date)**: Enter the date the tool was assigned (if applicable).
* **Follow Up Date (date)**: Enter the date to follow up on the tool's status (if applicable).
* **Status (select_one)**: Select the current status of the tool from the list below:
	+ New
	+ In Progress
	+ Done
* **Notes (text)**: Enter any additional notes about the tool's status.

## Tips
* Please ensure that you have entered all the required information for the form to be processed correctly.
* If a field is not applicable, simply leave it blank or select "Not Applicable" from the options list.
* If you need help with this form, please contact the system administrator.
