# Initial Margin Monitoring Log - Help Guide

## Purpose
The Initial Margin Monitoring Log is used to record and track the status of margin checks for accounts. This form helps in maintaining accurate and up-to-date records of margin checks, including the date, time, and status of each check. It also provides a way to flag issues and record comments for each check.

## How To Complete This Form

1.  Ensure you have all necessary information required for the form before starting.
2.  Fill in the Margin Check Date field with the date of the margin check.
3.  Enter the Margin Check ID, which is a unique identifier for each margin check.
4.  Select the Account Code from the dropdown list to specify the account being checked.
5.  Enter the Margin Check Amount, which should be a numerical value.
6.  If issues were flagged, select the Flag option to mark the check as flagged.
7.  Enter a brief explanation for the flag, if necessary.
8.  Select the Margin Check Status to update the status of the check.
9.  Enter any comments related to the margin check status.
10. Enter the Margin Check User ID, which is typically the ID of the person performing the margin check.
11. Enter the Margin Check User Name, if available.
12. Enter the Margin Check Date Time, which is the timestamp of the margin check.
13. Select the Margin Check Time Zone, if applicable.
14. Enter the Margin Check Time Zone ID and Name, if applicable.
14. Enter any Margin Check Status Comments, if necessary.
15. Enter the Margin Check Status ID, if available.
15. Enter the Margin Check Status Name, if available.
16. Enter the Margin Check Status Time, if applicable.
17. Enter the Margin Check Status Time Zone, if applicable.
17. Enter any Margin Check Status Comments, if necessary.
18. Enter the Margin Check Flagged By, typically the ID of the person who flagged the issue.
19. Enter the Margin Check Flagged By, a brief description of the person who flagged the issue.
20. Enter the Margin Check Flagged Time, if applicable.

## Field-by-Field Explanation

* **Margin Check Date** (`margin_check_date`, date, optional): Enter the date of the margin check.
* **Margin Check ID** (`margin_check_id`, number, required): A unique identifier for each margin check.
* **Account Code** (`account_code`, select_one, required): Select the account being checked.
* **Margin Check Amount** (`margin_check_amount`, number, required): Enter the numerical value of the margin check.
* **Flag** (`flag`, select_multiple, required): Select the flag option to mark the check as flagged.
* **Flag Reason** (`flag_reason`, text, optional): Enter a brief explanation for the flag.
* **Margin Check Status** (`margin_check_status`, select_one, required): Update the status of the margin check.
* **Margin Check Comments** (`margin_check_comments`, text, optional): Enter any comments related to the margin check status.
* **Margin Check User ID** (`margin_check_user_id`, number, required): Enter the ID of the person performing the margin check.
* **Margin Check User Name** (`margin_check_user_name`, text, optional): Enter the name of the person performing the margin check.
* **Margin Check Date Time** (`margin_check_date_time`, time, required): Enter the timestamp of the margin check.
* **Margin Check Time Zone** (`margin_check_time_zone`, text, optional): Select the time zone for the margin check.
* **Margin Check Time Zone ID** (`margin_check_time_zone_id`, number, optional): Enter the ID of the time zone.
* **Margin Check Time Zone Name** (`margin_check_time_zone_name`, text, optional): Enter the name of the time zone.
* **Margin Check Status Comments** (`margin_check_status_comments`, text, optional): Enter comments related to the margin check status.
* **Margin Check Status ID** (`margin_check_status_id`, number, optional): Enter the ID of the margin check status.
* **Margin Check Status Name** (`margin_check_status_name`, text, optional): Enter the name of the margin check status.
* **Margin Check Status Time** (`margin_check_status_time`, time, optional): Enter the timestamp of the margin check status.
* **Margin Check Status Time Zone** (`margin_check_status_time_zone`, text, optional): Select the time zone for the margin check status.
* **Margin Check Status Comments** (`margin_check_status_comments`, text, optional): Enter comments related to the margin check status.
* **Margin Check Flagged By** (`margin_check_flagged_by`, text, optional): Enter the ID of the person who flagged the issue.
* **Margin Check Flagged By** (`margin_check_flagged_by`, text, optional): Enter a brief description of the person who flagged the issue.
* **Margin Check Flagged Time** (`margin_check_flagged_time`, time, optional): Enter the timestamp of the margin check flagged.
* **Margin Check Flagged Time** (`margin_check_flagged_time`, time, optional): Enter the timestamp of the margin check flagged.
