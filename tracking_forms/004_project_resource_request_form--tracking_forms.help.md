# Project Resource Request Form - Help Guide

## Purpose
The Project Resource Request Form is used to track and record requests for project resources. Project teams and resource requesters can use this form to request resources for specific projects, providing essential information about the project, the requesting unit, and the resource requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `project_id` field with the corresponding project ID number.
2. Enter the `Project Title` in the `title` field.
3. Select the project type from the list of options in the `project_type` field.
4. Provide the project date in the `Project Date` field.
5. Choose the project status from the list of options in the `project_status` field.
6. Enter a brief description of the project in the `Project Description` field.
7. Indicate the resource requesting unit in the `Resource Requesting Unit` field.
8. Select the date of the resource request in the `Request Date` field.
9. Choose the priority of the resource request from the list of options in the `Priority` field.
10. Select the tool to be assigned to the project in the `Assigned Tool` field.

## Field-by-Field Explanation
* **project_id**: Enter the project's unique ID number. If you are unsure, consult the project's project management system or ask your department for assistance.
* **Project Title**: Briefly describe the project title, making sure it's clear and concise.
* **Project Type**: Select either 'Yes' or 'No' to indicate the project type.
* **Project Date**: Enter the project start or completion date in the format `YYYY-MM-DD`.
* **Project Status**: Choose between 'Active' and 'Inactive' to indicate the project's status.
* **Project Description**: Provide a brief description of the project, including its purpose and objectives.
* **Resource Requesting Unit**: Enter the department or team name responsible for the resource request.
* **Request Date**: Enter the date of the resource request in the format `YYYY-MM-DD`.
* **Priority**: Select 'Yes' or 'No' to indicate the priority level of the resource request.
* **Assigned Tool**: Choose between 'chatjimmy' and 'Other' to indicate the tool assigned to the project.

## Tips
* Make sure to double-check the project details before submitting the form.
* If you are requesting a resource for an ongoing project, ensure the `project_status` field is set to 'Active'.
* If you need assistance with the project ID or other project details, consult the project's project management system or your department.
