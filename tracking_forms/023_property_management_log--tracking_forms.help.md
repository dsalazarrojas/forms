# Property Management Log - Help Guide

## Purpose
This form is used to track property management activities and maintenance tasks.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the property name in the `property_name` field.
* Enter the date of the activity in the `activity_date` field.
* Select the type of activity from the `activity_type` dropdown menu.
* Provide a brief description of the activity in the `activity_description` field.
* If applicable, select the tenant's ID from the `tenant_id` dropdown menu.
* Provide details about the maintenance activity in the `maintenance_description` field.
* Select the type of maintenance from the `maintenance_type` dropdown menu (multiple selections allowed).
* Assign a person to handle the task by selecting from the `assigned_to` dropdown menu.
* Set the priority of the task by selecting from the `priority` dropdown menu.
* Set the status of the task by selecting from the `status` dropdown menu.
* Provide any additional comments about the task in the `comments` field.
* Enter the contact number for further information in the `contact_number` field.

## Field-by-Field Explanation

* **property_name** (`text`, required/optional): Enter the name of the property being managed.
* **activity_date** (`date`, required/optional): Enter the date of the activity or maintenance task.
* **activity_type** (`select_one`, required/optional): Select the type of activity or maintenance task.
* **activity_description** (`text`, required/optional): Provide a brief description of the activity or maintenance task.
* **tenant_id** (`select_one`, required/optional): If applicable, select the ID of the tenant associated with the property.
* **maintenance_description** (`text`, required/optional): Provide details about the maintenance activity.
* **maintenance_type** (`select_multiple`, required/optional): Select the type(s) of maintenance performed.
* **assigned_to** (`select_one`, required/optional): Select the person assigned to handle the task.
* **priority** (`select_one`, required/optional): Set the priority of the task by selecting from the dropdown menu.
* **status** (`select_one`, required/optional): Set the status of the task by selecting from the dropdown menu.
* **comments** (`text`, required/optional): Provide any additional comments or notes about the task.
* **contact_number** (`text`, required/optional): Enter the contact number for further information.
