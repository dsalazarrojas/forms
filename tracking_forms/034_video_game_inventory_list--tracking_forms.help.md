# Video Game Inventory List - Help Guide
## Purpose
This form is designed to record and track video games in your inventory. It gathers essential details about each game, including its title, platform, and release year, to help you keep a comprehensive and organized collection.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the "Game Title" in the first field, which is the name of the video game you're adding to your inventory.
2. If applicable, select the platform on which the game is played from the drop-down options (e.g., PlayStation, Nintendo, Xbox, PC, Other).
3. Enter the release year of the game in the "Release Year" field.
4. Describe the condition of the game you're tracking, if known.
5. Enter the price you've purchased the game for in the "Game Price" field.
6. Provide the location where you bought the game.
7. If you have a purchase date, you can choose it using the provided date fields.
8. Use the "Notes" field to add any additional remarks or comments about the game that might be helpful in the future.
9. Add your email address to the "Email" field if you've purchased it from a vendor or seller that you want to contact for more details or updates.
10. Enter your phone number for any direct communication.
11. If you bought the game from a private seller, enter their name and contact information in the "Seller Name" and "Seller Contact" fields.
12. Finally, you can upload a Game Image and/or a Game Video to the form, using the respective fields to provide visual aids for tracking and reference.

## Field-by-Field Explanation

* **Game Title** (`game_title`, text, optional): Enter the title of the video game you're tracking.
* **Platform** (`platform`, select_one, optional): Select the platform the game is originally designed for.
* **Release Year** (`release_year`, number, optional): Enter the year the game was released.
* **Condition** (`condition`, text, optional): Describe the condition of the game (e.g., New, Used, Refurbished, etc.).
* **Game Price** (`game_price`, number, optional): Enter the price you paid for the game.
* **Purchase Location** (`purchase_location`, text, optional): Indicate where you bought the game.
* **Purchase Date** (`purchase_date`, date, optional): If you have a specific date for the purchase, use this field.
* **Notes** (`notes`, note, optional): Add any additional comments about the game.
* **Email** (`email`, email, optional): Enter your or the seller's email address.
* **Phone** (`phone`, text, optional): Enter your or the seller’s phone number.
* **Seller Name** (`seller_name`, text, optional): Enter the seller's name.
* **Seller Contact** (`seller_contact`, text, optional): Enter the seller's contact information.
* **Game Image** (`game_image`, select_multiple, optional): Upload a URL to an image related to the game or select from options like "URL" or "Base64" for different types of image uploads.
* **Game Video** (`game_video`, select_multiple, optional): Upload a URL to a video related to the game or select from options like "URL" or "Base64" for different types of video uploads.

## Tips

- Always ensure you are filling out the form for the correct game in your inventory to maintain accurate records.
- If a field is not applicable to the game you're listing, you can leave it blank or select "None" or "N/A" as appropriate.
- For fields like "Game Image" and "Game Video," remember that you can either upload an existing URL or upload a new image/video directly into the form, depending on your preference and the options provided.
- For fields with "select_multiple" type, such as "Game Image" and "Game Video," use the options to guide you on how to input data effectively.
