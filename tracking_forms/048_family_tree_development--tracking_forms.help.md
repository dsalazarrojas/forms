# Family Tree Development - Help Guide
## Purpose
This form is used to collect information about individuals in a family tree. It ensures that the family tree is up-to-date and accurate, reducing the risk of duplication and errors.

## How To Complete This Form
1. Select the individual you want to add to the family tree.
2. Fill in the required fields: First name, Last name, Birthdate, Gender, and Relationship.
3. Provide an optional Email and Phone number if available.
4. Add any additional notes about the individual.

## Field-by-Field Explanation
* **First name** (`first_name`, text, required): Enter the individual's first name.
* **Last name** (`last_name`, text, required): Enter the individual's last name.
* **Birthdate** (`birthdate`, date, required): Enter the individual's birthdate in the format MM/DD/YYYY.
* **Gender** (`gender`, select_one, required): Select the individual's gender (Male, Female, or Other).
* **Relationship** (`relationship`, select_multiple, required): Select all applicable relationships for the individual (Spouse, Parent, Child, or Other).
* **Email** (`email`, email, optional): Enter the individual's email address (if available).
* **Phone** (`phone`, text, optional): Enter the individual's phone number (if available).
* **Note** (`note`, note, optional): Add any additional notes or comments about the individual.

## Tips
* Make sure to provide accurate and up-to-date information to avoid duplication and errors.
* If an individual has multiple relationships (e.g., Spouse and Parent), select all applicable options.
* Use the correct format for the Birthdate field (MM/DD/YYYY).
