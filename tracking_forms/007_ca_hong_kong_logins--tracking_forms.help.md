# Ca Hong Kong Logins - Help Guide

## Purpose
This form is for tracking login activity, specifically for recording the details of a user accessing a system or resource. The form helps ensure accuracy and accountability in monitoring and managing user access and session duration. It's a critical component of internal processes, such as security audits and compliance checks.

## How To Complete This Form

### To complete the form, follow these steps:

1. Ensure you have all necessary information before proceeding.
2. Fill out the form with the required fields:
	* Enter the **Technician's Name**, the person performing the action.
	* Select the **Entry Date** and **Entry Time** of when the action occurred.
	* Specify the **System Name**, identifying the resource being accessed.
	* Enter the **System ID**, the unique identifier for the resource.
	* Select the **Login Type** of the access, such as Initial Login or Password Reset.
	* Choose the **Access Level**, indicating the scope of the access granted.
	* Input the **Username** used for the login.
	* Optionally, input the **Workstation ID**, if the access was made from a specific computer or terminal.
	* Optionally, input the **IP Address**, if applicable.
	* Select the **Reason for Access**, such as for System update or User support.
	* If applicable, describe any **Changes Made** during the session.
	* If applicable, report any **Issues Encountered** during the session.
	* Optionally, estimate the **Session Duration**.
	* If applicable, specify the **Logout Time**.
	* Decide if **Supervisor Notification** is required for this session.
	* Add any **Additional Notes** about the session.

## Field-by-Field Explanation

* **Technician Name**: The person making this entry.
	+ Type: text, required
	+ Purpose: Identify the technician making the login entry.
* **Entry Date**: The date of this login session.
	+ Type: date, required
	+ Purpose: Record the date of the access event.
* **Entry Time**: The time of this login session.
	+ Type: time, required
	+ Purpose: Record the time of the access event.
* **System Name**: Name of the system or resource being accessed.
	+ Type: text, required
	+ Purpose: Identify the resource being accessed.
* **System ID**: Unique identifier for the system or resource.
	+ Type: text, required
	+ Purpose: Record the ID of the resource.
* **Login Type**: Type of access made to the system or resource.
	+ Type: select_one, required
	+ Purpose: Indicate the purpose or type of login made.
* **Access Level**: Level of access granted to the resource.
	+ Type: select_one, required
	+ Purpose: Record the scope of access granted.
* **Username**: Account username used for the login.
	+ Type: text, required
	+ Purpose: Identify the username used for access.
* **Workstation ID**: Computer or terminal identifier (optional).
	+ Type: text, optional
	+ Purpose: Record the computer or terminal used, if applicable.
* **IP Address**: Source IP address, if applicable.
	+ Type: text, optional
	+ Purpose: Record the source IP address, if applicable.
* **Reason for Access**: Purpose of this login session.
	+ Type: select_one, required
	+ Purpose: Describe the reason for the access.
* **Changes Made**: Describe any changes performed during the session.
	+ Type: text, optional
	+ Purpose: Record any modifications or actions taken.
* **Issues Encountered**: Report any problems or anomalies observed.
	+ Type: text, optional
	+ Purpose: Document any issues or problems encountered.
* **Session Duration**: Approximate length of the login session.
	+ Type: select_one, optional
	+ Purpose: Estimate the duration of the session.
* **Logout Time**: Time when the session ended.
	+ Type: time, optional
	+ Purpose: Record the end time of the access event.
* **Supervisor Notification**: Notification requirement for the supervisor.
	+ Type: select_one, optional
	+ Purpose: Determine if the supervisor needs to be notified.
* **Additional Notes**: Any other relevant information.
	+ Type: text, optional
	+ Purpose: Add any additional comments or details about the session.

## Tips

* Ensure accuracy and thoroughness when filling out the form.
* Use the correct login type and access level for each session.
* Record all relevant details for security and audit purposes.
* If unsure about any field, consult with the relevant team or supervisor.
* Review and update the form regularly to maintain consistency and integrity.
