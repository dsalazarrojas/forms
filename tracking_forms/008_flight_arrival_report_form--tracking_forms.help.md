# Flight Arrival Report Form - Help Guide
## Purpose
The Flight Arrival Report Form is used to collect and report on flight arrival details for ground handling and coordination purposes.

## How To Complete This Form

1. To complete this form, fill in each field with the required information for the reported flight. Ensure that you provide accurate and detailed information as the form will be used for coordination and communication with relevant personnel.
2. The form is split into multiple pages, each covering a different aspect of flight arrival details. Navigate through the pages to input information as needed.
3. Use the provided field types (text, time, select, select multiple) as guidance for inputting your answers. Some fields are optional, but ensure that all required fields are completed.

## Field-by-Field Explanation

* **flight_arrival_details**: Enter a brief description or note about the flight, its purpose, or any additional details that need to be known.
* **Arrive Time**: Report the time the flight arrived.
* **aircraft_code**: Select the type of aircraft that landed.
* **flight_number**: Choose the flight number that the report is for.
* **flight_status**: Choose the status of the flight (On Schedule, Delayed, or Cancelled).
* **ground_handling_status**: If applicable, report the ground handling status of the flight (Grounded or Ungrounded).
* **flight_arrival_report**: Enter a detailed report or note about the flight's arrival.
* **flight_departure_time**: Report the time the flight was expected to depart.
* **flight_arrival_gate**: Enter the gate number or terminal where the flight landed.
* **flight_arrival_airport**: Choose the airport where the flight arrived (e.g., JFK, LAX, SFO).
* **ground_handling**: Enter any notes or comments about ground handling for the flight.
* **comments**: Add any additional comments or notes.
* **assigned_to**: Choose the personnel or group to which the report will be assigned.
* **remarks**: Enter any additional remarks or comments.

**Tips**: 

* Double-check all fields for accuracy before submission.
* Ensure all required fields are completed before finalizing the report.
* If unsure about any field, consult with relevant personnel or refer to the flight's documentation.
