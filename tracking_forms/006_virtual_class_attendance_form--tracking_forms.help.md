# Virtual Class Attendance Form - Help Guide
## Purpose

The Virtual Class Attendance Form is designed to track the attendance of students and instructors in virtual classes. This form helps instructors and administrators to maintain accurate records and facilitate communication between students and instructors.

## How To Complete This Form

1.  Select the correct attendance date from the calendar input field.
2.  Enter the instructor's name in the Instructor Name field.
3.  Enter the class name in the Class Name field.
4.  Select the correct class ID from the options provided.
5.  Enter the number of students who attended in the Students Attended field.
6.  Enter the number of students who were absent in the Students Absent field.
7.  Enter any student comments in the Student Comments field.
8.  Enter any instructor comments in the Instructor Comments field.
9.  Select the attendance status from the Attendance Status field.
10.  Select the instructor's attendance status from the Instructor Attendance field.
11.  Select the student attendance status from the Student Attendance field.
12.  Select the attendance status for each of the six options in the Attendance Status 1-3 fields.
13.  Enter any additional comments from students to the instructor in the Students - Instructor Comment field.
14.  Enter any additional comments from students in the Students - Instructor Comments field.
15.  Enter the student attendance ID for each student in the Student Attendance ID fields.
16.  Select whether each student attended or not in the Student Attendance ID 1-8 fields.

## Field-by-Field Explanation

* **Attendance Date** ( attendance_date ): The date of the virtual class.
* **Instructor Name** ( instructor_name ): The name of the instructor who led the virtual class.
* **Class Name** ( class_name ): The name of the virtual class.
* **Class ID** ( class_id ): The unique identifier for the virtual class.
* **Students Attended** ( students_attended ): The number of students who attended the virtual class.
* **Students Absent** ( students_absent ): The number of students who were absent from the virtual class.
* **Student Comments** ( student_comments ): Any comments from students about the virtual class.
* **Instructor Comments** ( instructor_comments ): Any comments from the instructor about the virtual class.
* **Attendance Status** ( attendance_status ): The attendance status of the virtual class.
* **Instructor Attendance** ( instructor_attendance ): The attendance status of the instructor.
* **Student Attendance** ( student_attendance ): The attendance status of the students.
* **Attendance Status 1-3** ( attendance_status_1-3 ): The attendance status for each of the three options.
* **Instructor** ( instructor ): The name of the instructor who led the virtual class.
* **Students - Instructor Comment** ( students_instructor_comment ): Any comments from students to the instructor.
* **Students - Instructor Comments** ( students_instructor_comments ): Any comments from students to the instructor.
* **Student Attendance ID** ( student_attendance_id ): The unique identifier for each student's attendance.
* **Student Attendance ID 1-8** ( student_attendance_ids_1-8 ): Select whether each student attended or not.
