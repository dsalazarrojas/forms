# Observation And Media Log - Help Guide
## Purpose
This form is used to record and track observations, including media types and related notes. It's intended for use by fieldworkers to document their findings and experiences during observations, which can be audio, video, text, or other types of media. This form is not meant to be used for duplicate observations, so please make sure to complete a new entry each time you perform a new observation.

## How To Complete This Form
1. Select the type of media you observed (e.g., text, audio, video, image, or other).
2. Enter the URL of the media file (if applicable).
3. Enter the date and time of the observation (using the date and time fields).
4. Enter the duration of the media file (if applicable).
5. Enter any relevant notes about the observation.
6. Enter the date and time of the second observation (if applicable).
7. Enter any additional notes about the second observation (if applicable).

## Field-by-Field Explanation
* **Media Type** (`Media Type`, select_multiple, required/optional): Please select the type of media that was observed. This can be text, audio, video, image, or other. Multiple types may be selected.
* **Media URL** (`Media URL`, text, required/optional): If the observation is a media file, enter the URL where it can be accessed. This field is optional, but it's helpful for reference.
* **Observation Date** (`Observation Date`, date, required/optional): Enter the date of the observation. If you have multiple observations, make sure to fill this field for each observation.
* **Observation Time** (`Observation Time`, time, required/optional): Enter the time of the observation. Like the date field, this should be filled for each observation.
* **Media Duration** (`Media Duration`, number, required/optional): If the media file has a duration, enter its length in seconds. This field is optional, but it helps to provide more context.
* **Observation Notes** (`Observation Notes`, note, required/optional): Enter any relevant notes or comments about the observation. This field is optional, but it's a great place to add context.
* **Observation Date 2** (`Observation Date 2`, date, required/optional): This field is intended for recording a second observation, if necessary. Fill it in if you have a follow-up observation.
* **Observation Time 2** (`Observation Time 2`, time, required/optional): This field is for recording the time of the second observation.
* **Observation Notes 2** (`Observation Notes 2`, note, required/optional): These notes are for any additional context or comments about the second observation.
