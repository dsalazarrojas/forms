# Received Inventory Form - Help Guide
## Purpose
This form is used to track inventory received from vendors. It is essential to fill out this form accurately to ensure that the inventory is properly recorded and tracked.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the title of the inventory reception event.
2. Fill in the vendor name where the inventory was received from.
3. Enter the date the inventory was received.
4. Enter the quantity of the received inventory.
5. Provide a brief description of the vendor's item.
6. Mention who received the inventory if applicable.
7. Specify the purpose for which the inventory was received if applicable.
8. Fill in any additional remarks related to the inventory reception event.

## Field-by-Field Explanation
* **Received Inventory** (received_inventory, text, required/optional): This is the title of the inventory reception event.
* **Vendor Name (vendor name, text, required/optional): Enter the name of the vendor from whom the inventory was received.
* **Receipt Date (receipt date, date, required/optional): Enter the date the inventory was received, using the standard date format (e.g., 2022-01-01).
* **Quantity Received (quantity received, number, required/optional): Enter the exact number of items received.
* **Vendor Item Description (vendor item description, text, required/optional): Provide a brief description of the vendor's item.
* **Received From (received from, text, required/optional): If applicable, mention who received the inventory, e.g., "John Doe."
* **Received By (received by, text, required/optional): If applicable, specify who received the inventory on behalf of the organization or team.
* **Received For (received for, text, required/optional): If applicable, specify the purpose for which the inventory was received.
* **Remarks 1 (remarks, text, required/optional): Provide any additional comments or remarks related to the inventory reception event.
* **Remarks 2 (remarks 2, text, required/optional): Enter any additional comments or remarks for reference.
* **Remarks 3 (remarks 3, text, required/optional): Enter any additional comments or remarks for further reference.
* **Remarks 4 (remarks 4, text, required/optional): Enter any final comments or remarks related to the inventory reception event.
