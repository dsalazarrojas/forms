# Standard Work Log Template - Help Guide
## Purpose
The Standard Work Log Template is a form used for tracking work hours and activities performed on a project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **IT work log** field with a brief description of the work performed. This field is a text area where you can type in as much information as needed.
2. Enter the **date of work** in the corresponding field. This date should match the date you performed the work.
3. Enter the number of **hours worked** on the project.
4. In the **work description** field, provide a detailed description of the work performed.
5. If applicable, enter the **task number** related to the work done.
6. Enter the **project name** and **client name** for the project/client you worked on.
7. If you need to, you can provide additional information about the **client contact** person or team.
8. Finally, type in any **notes** you have about the project or work performed.

## Field-by-Field Explanation

* **IT work log**: A text area where you can type in a description of the work performed.
* **date_of_work**: Enter the date you performed the work.
* **hours_worked**: Enter the number of hours you spent working on the project.
* **work_description**: A more detailed description of the work performed.
* **task_number**: If applicable, enter the task number associated with the work.
* **project_name**: The name of the project you worked on.
* **client_name**: The name of the client you worked for.
* **client_contact**: Additional information about the client contact.
* **notes**: Any additional notes about the project or work performed.

## Tips
* Be as detailed as possible when filling out the fields, especially the **work description** field.
* If you're unsure about any field, refer to the project manager or team lead for guidance.
* Remember to save your progress as you fill out the form, as it will help with tracking and recording work hours.
