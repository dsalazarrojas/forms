# Doula Service Timesheet - Help Guide
## Purpose
The Doula Service Timesheet form is designed to help Doulas track the details of their services, including service hours, visit details, client sessions, service provider, agency, service type, start and end time, location, notes, date, and time.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to understand the required and optional fields.
2. Fill in the required fields:
	* Service Hours: The number of hours spent on the service.
	* Date: The date of the service.
3. Select the relevant visit details (Yes/No) for the service provided.
4. Choose the correct client sessions (Yes/No) for the service provided.
5. Select the correct service provider (Yes/No) for the service provided.
6. Select the agency (Yes/No) for the service provided.
7. Select the service type (Yes/No) for the service provided.
8. Input the start and end time of the service.
9. Specify the location of the service.
10. Input any additional notes about the service.
11. Optionally, select a time for the service.

## Field-by-Field Explanation
* **Service Hours**:
	+ A number indicating the hours spent on the service.
* **Visit Details**:
	+ Select "Yes" if this is a visit, "No" otherwise.
* **Client Sessions**:
	+ Select "Yes" if this is a client session, "No" otherwise.
* **Service Provider**:
	+ Select "Yes" if this is a service provided by the user, "No" otherwise.
* **Agency**:
	+ Select "Yes" if this is a service provided by the agency, "No" otherwise.
* **Service Type**:
	+ Select "Yes" if this is a specific type of service, "No" otherwise.
* **Start Time**:
	+ The start time of the service.
* **End Time**:
	+ The end time of the service.
* **Location**:
	+ The location where the service was provided.
* **Notes**:
	+ Additional information about the service.
* **Date**:
	+ The date of the service.
* **Time**:
	+ The time of the service.

## Tips
* Review the form carefully before submitting it to ensure accuracy.
* Make sure to select the correct options for each field.
* Double-check the start and end times for correctness.
* Enter notes and location details thoroughly.
* Ensure that the date and time are correct.
