# Visitor Log Form - Help Guide
## Purpose
The Visitor Log Form is used to track the details of visitors who arrive at the facility. This information can be used to verify the identity of visitors, keep a record of their visit, and potentially for follow-up actions or invitations for future visits.

## How To Complete This Form
To complete the form, follow these steps:
1. Fill out the form with the visitor's details.
2. Enter the visitor's name in the "name" field.
3. If you have the visitor's email address, enter it in the "email" field.
4. If you have the visitor's phone number, enter it in the "phone" field.
5. Enter the date of the visit using the "date" field.
6. Enter the time the visitor arrived using the "in_time" field.
7. Enter the time the visitor departed using the "out_time" field.
8. You can add any additional notes about the visit in the "notes" field, if desired.

## Field-by-Field Explanation

* **Visitor Log Form Label** (`visitor_log_form_label`, title, optional): This field is for the title of the form, which should be filled out if you want to include a title on the form.
* **Visitor Name** (`name`, text, optional): Enter the visitor's full name.
* **Visitor Email** (`email`, email, optional): Enter the visitor's email address if provided.
* **Visitor Phone** (`phone`, text, optional): Enter the visitor's phone number if provided.
* **Date** (`date`, date, optional): Enter the date of the visit using the standard date format (MM/DD/YYYY).
* **Time of Arrival** (`in_time`, time, optional): Enter the time the visitor arrived, using the 24-hour time format (HH:MM).
* **Time of Departure** (`out_time`, time, optional): Enter the time the visitor left, using the 24-hour time format (HH:MM).
* **Notes** (`notes`, text, optional): This field is for any additional notes about the visitor.

## Tips
- Make sure to enter the form with accurate information.
- Each visitor should only be logged once.
- If you are unsure about any information, you can leave it blank.
