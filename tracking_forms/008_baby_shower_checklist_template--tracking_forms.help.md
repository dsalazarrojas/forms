# Baby Shower Checklist Template - Help Guide
## Purpose
The Baby Shower Checklist Template is a comprehensive form designed to help you track the progress of your baby shower planning process. It ensures that all essential tasks, categories, and details are managed efficiently.

## How To Complete This Form

To complete the Baby Shower Checklist Template, follow these steps:

* Click on the form and start by selecting a category from the "Category" field (id: 3).
* For each category, enter a specific task in the "Planning Task" field (id: 2).
* Assign the task to a person responsible in the "Person Responsible" field (id: 4), if desired.
* Set a target completion date for the task in the "Target Completion Date" field (id: 5), if desired.
* Estimate the cost of the task in the "Estimated Budget" field (id: 6), if desired.
* Select the current status of the task in the "Current Status" field (id: 7).
* If necessary, set a priority level for the task in the "Priority" field (id: 8).
* Finally, add any additional details or vendor contact information in the "Additional Details or Vendor Contact Info" field (id: 9), if needed.
* Add any shopping list items for the task in the "Shopping List Items for this Task" field (id: 10), if desired.

## Field-by-Field Explanation

* **Category** (id: 3): Choose from the available categories to categorize the task, such as "Venue and Date" or "Invitations and RSVP."
* **Planning Task** (id: 2): Enter a specific task or activity that needs to be done for the baby shower, such as sending out invitations or preparing decorations.
* **Person Responsible** (id: 4): If applicable, assign the task to a person who will handle it.
* **Target Completion Date** (id: 5): Set a specific date when the task should be completed, if desired.
* **Estimated Budget** (id: 6): Enter an estimated budget for the task, such as the cost of invitations or decorations.
* **Current Status** (id: 7): Select the current status of the task, which can be "Not Started", "In Progress", "On Hold", or "Completed."
* **Priority** (id: 8): If necessary, set a priority level for the task, which can be "High", "Medium", or "Low."
* **Additional Details or Vendor Contact Info** (id: 9): Add any additional details or vendor contact information related to the task, such as a vendor's name and phone number.
* **Shopping List Items for this Task** (id: 10): Add any shopping list items required for the task, such as food or decorations.
