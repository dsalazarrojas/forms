# Rainfall Measurement Form - Help Guide

## Purpose
The Rainfall Measurement Form is used to track rainfall measurements for specific locations and time periods. Users can submit multiple sets of measurements, each with its own fields for location, measurement unit, measurement value, duration, frequency, and date/time.

## How To Complete This Form

1. Select the location where the rainfall measurement was taken.
2. Choose the measurement unit (e.g., millimeters).
3. Enter the measurement value (e.g., 10 mm).
4. Select the duration of the measurement period (e.g., Rainy Days, Storm, Drought).
5. Enter the date and time of the measurement.
6. Add any additional notes about the measurement.
7. Select the Submit option to save the measurement.

## Field-by-Field Explanation

* **Location** (`location_2`, text, optional): Enter the location where the rainfall measurement was taken.
* **Measurement Unit** (`measurement_2`, text, optional): Choose the unit of measurement (e.g., millimeters).
* **Measurement** (`measurement_2`, number, optional): Enter the actual measurement value (e.g., 10 mm).
* **Duration** (`duration_2`, number, optional): Select the duration of the measurement period (e.g., Rainy Days, Storm, Drought).
* **Date** (`date_2`, date, optional): Enter the date and time of the measurement.
* **Time** (`time_2`, time, optional): Enter the time of the measurement.
* **Notes** (`notes_2`, note, optional): Add any additional notes about the measurement.
* **Submit** (`submit_2`, select_multiple, optional): Select the Submit option to save the measurement.
* **Email** (`email_2`, email, optional): Enter the email address for contact.
* **Phone** (`phone_2`, text, optional): Enter the phone number for contact.
* **Location 2** (`location_3`, text, optional): Enter the location for the second measurement (if applicable).
* **Submit 2** (`submit_3`, select_multiple, optional): Select the Submit option to save the second measurement.

Note: Some fields are optional, and users should only fill out the necessary fields for each measurement.
