# Time Tracker Form - Help Guide
## Purpose

The Time Tracker Form is a tool used to track time spent on specific tasks and projects. This form is intended for recording actual work hours spent on tasks or projects, and should not be used for tracking other activities or non-work-related time.

## How To Complete This Form

To complete the Time Tracker Form, follow these steps:

1. Enter the time spent on the task or project in the `time_spent` field, using numeric values.
2. Select the task that the time was spent on from the `task` field.
3. Enter the time spent on the task in the `time_spent_on_task_description` field, using text format.
4. Select the project that the time was spent on from the `project` field.
5. Enter the time spent on the project in the `time_spent_on_project_time_spent` field, using time format.
6. Add any additional notes or comments in the `notes` field.

## Field-by-Field Explanation

* **Time Tracker Form** (`time_tracker_form`): This is the title of the form.
* **Time Spent** (`time_spent`): Enter the time spent on the task or project, using numeric values.
* **Task** (`task`): Select the task that the time was spent on from the available options.
* **Time Spent on Task Description** (`time_spent_on_task_description`): Enter the time spent on the task, using text format.
* **Time Spent on Task Time Spent** (`time_spent_on_task_time_spent`): Enter the time spent on the task, using time format.
* **Project** (`project`): Select the project that the time was spent on from the available options.
* **Time Spent on Project Description** (`time_spent_on_project_description`): Enter the time spent on the project, using text format.
* **Time Spent on Project Time Spent** (`time_spent_on_project_time_spent`): Enter the time spent on the project, using time format.
* **Notes** (`notes`): Add any additional notes or comments about the task or project.

Note: The form fields marked with an asterisk (\*) are required fields and must be filled out before submitting the form.
