# medication_reconciliation_form - Help Guide
## Purpose
The medication_reconciliation_form is used to track medications for healthcare patients.

## How To Complete This Form
1. Review the form carefully and fill out each field accurately.
2. Ensure that all required fields are completed before submission.
3. Select the correct options for each field according to the patient's actual condition.

* **medications** (Meds, Select Multiple, Required/Optional): Check if the patient has any medications. Select 'Yes' if they do, 'No' if they do not.
