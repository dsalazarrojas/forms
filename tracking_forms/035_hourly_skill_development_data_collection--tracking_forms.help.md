# Hourly Skill Development Data Collection - Help Guide
## Purpose
This form is designed to gather information on learners' skills development, enabling trainers and instructors to track progress, identify areas of improvement, and make data-driven decisions to optimize the learning process.

## How To Complete This Form
To complete the Hourly Skill Development Data Collection form, follow these steps:

1. Enter the Team ID of the team or group the learner belongs to.
2. Enter the Learner ID of the learner being tracked.
3. Select the Learning Activity that was performed during the session.
4. Enter the Start Time of the session.
5. Enter the End Time of the session.
6. Enter the duration of the session.
7. Select the outcomes achieved during the session (e.g., "Outcome 1", "Outcome 2", etc.).
8. Choose the level of Progress made during the session (e.g., "High", "Medium", etc.).
9. Optionally, add any additional Notes about the session.

## Field-by-Field Explanation
- **Team ID** (`team_id`, number, optional): Enter the unique ID of the team or group the learner belongs to.
- **Learner ID** (`learner_id`, number, optional): Enter the unique ID of the learner being tracked.
- **Learning Activity** (`learning_activity`, text, optional): Select the activity or task the learner performed during the session.
- **Start Time** (`start_time`, time, optional): Enter the start time of the session.
- **End Time** (`end_time`, time, optional): Enter the end time of the session.
- **Duration** (`duration`, number, optional): Enter the duration of the session.
- **Outcomes** (`outcomes`, select_multiple, optional): Select all relevant outcomes achieved during the session (e.g., "Outcome 1", "Outcome 2", etc.).
  Example: Select all relevant outcomes using a comma-separated list (e.g., "Outcome 1, Outcome 2, Outcome 3").
- **Progress** (`progress`, select_one, optional): Choose the level of Progress made during the session (e.g., "High", "Medium", etc.).
- **Notes** (`notes`, note, optional): Add any additional comments or notes about the session.

## Tips
- Please ensure that each entry represents a distinct skill development session.
- Use the same format for all entries to maintain consistency.
- Select only relevant outcomes and progress levels to accurately reflect the learner's development.
