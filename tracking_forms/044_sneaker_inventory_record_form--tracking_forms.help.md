# Sneaker Inventory Record Form - Help Guide
## Purpose
The Sneaker Inventory Record Form is used to create and manage records for individual sneakers in the inventory.

## How To Complete This Form
To complete this form, follow the steps below:

1. **Select the correct options for "Location"** - This is the place where you bought or obtained this sneaker. Be as specific as possible.
2. **Enter "Year Purchased" (optional)** - If applicable, please enter the year you purchased this sneaker.
3. **Enter "Date Purchased"** - This is the date you purchased this sneaker. Please use the correct format (MM/DD/YYYY).
4. **Enter "Sneaker Brand"** - This is the brand of the sneaker. For example, "Nike", "Adidas", etc.
5. **Enter "Shoe Name"** - This is the name of the sneaker model. For example, "Air Jordan 1", "Yeezy 700", etc.
6. **Enter "Shoe Model"** - This is the model number of the sneaker. For example, "1", "2", "3", etc.
7. **Enter "Shoe Color"** - This is the color of the sneaker. Please select the color you see the sneaker as.
8. **Enter "Box Condition" (optional)** - If you purchased the sneaker in its box, check the condition of the box. Please select "New" if the box is in perfect condition, "Used" if it's been opened or used, or "Damaged" if the box is broken or severely used.
9. **Select "Colorways"** - This is the colorway of the sneaker. Please select the correct colorway from the options provided.
10. **Select "Sizes and Colorways"** - This is a list of the sneaker's sizes and colorways. Please select the correct sizes and colorways from the options provided.
11. **Select "Material Type" (optional)** - If applicable, please select the material type of the sneaker (Leather or Synthetic).
12. **Enter "Year Released" (optional)** - If applicable, please enter the year the sneaker was released.
13. **Enter "Year Acquired" (optional)** - If applicable, please enter the year you acquired this sneaker.
14. **Enter "Price Point" (optional)** - If applicable, please enter the price you paid for this sneaker as a decimal number.
15. **Enter "Notes" (optional)** - This is a text field for any additional information about the sneaker.
