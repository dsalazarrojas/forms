# Progress Note Form - Help Guide
## Purpose
The Progress Note Form is used to document and track project progress, updates, and next steps. It is intended for use by project managers, team members, or other stakeholders to ensure that all necessary information is captured and communicated effectively.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the project update in the "Project update" field.
2. Provide feedback from the employer in the "Employer feedback" field, if applicable.
3. Enter any updates from the employee in the "Employee update" field, if applicable.
4. Enter the date and time of the progress update in the "Date" and "Time" fields.
5. Enter any additional comments or notes from the employer in the "Employer update" field, if applicable.
6. Enter any comments or notes from the employee in the "Employee notes" field, if applicable.
7. Specify the next steps to be taken in the "Next steps" field.
8. Enter the employer's contact information in the "Employer contact" field.
9. Enter the employee's contact information in the "Employee contact" field.
10. If applicable, select the project status in the "Project status" field.
11. If applicable, select one or more project priorities from the "Project priority" field.
12. If applicable, select the project type from the "Project type" field.

## Field-by-Field Explanation

* **Project update (Project update)**: Enter a brief description of the project's current status or changes.
* **Employer feedback (Employer feedback)**: If applicable, enter any feedback or updates from the employer.
* **Employee update (Employee update)**: If applicable, enter any updates or comments from the employee.
* **Date (Date)**: Enter the date of the progress update.
* **Time (Time)**: Enter the time of the progress update.
* **Employer update (Employer update)**: If applicable, enter any additional comments or updates from the employer.
* **Employee notes (Employee notes)**: If applicable, enter any comments or notes from the employee.
* **Next steps (Next steps)**: Describe the next steps to be taken in the project.
* **Employer contact (Employer contact)**: Enter the employer's contact information.
* **Employee contact (Employee contact)**: Enter the employee's contact information.
* **Project status (Project status)**: If applicable, select the current project status.
	+ Active: The project is actively being worked on and progressing well.
	+ In progress: The project is in progress, but has experienced some delays or issues.
	+ Delayed: The project has experienced significant delays or setbacks.
	+ Completed: The project has been completed and is now closed.
* **Project priority (Project priority)**: If applicable, select one or more project priorities.
	+ High: The project has high priority and requires immediate attention.
	+ Medium: The project has medium priority and should be addressed soon.
	+ Low: The project has low priority and can be addressed at a later time.
* **Project type (Project type)**: If applicable, select the type of project.
	+ Software Development: The project involves software development and coding.
	+ IT: The project involves IT-related tasks or issues.
	+ Marketing: The project involves marketing-related tasks or campaigns.
	+ Design: The project involves design-related tasks or projects.
