# Inventory And Meter Readings Form - Help Guide
## Purpose
This form is designed for tracking and recording inventory and meter readings to monitor and manage assets or equipment.

## How To Complete This Form
1. Fill out the form with the required fields (those marked as required).
2. Enter accurate and relevant information in each field.
3. Make sure to review your entries before submitting the form.

## Field-by-Field Explanation

* **Inventory And Meter Readings Form** (Form Title, text): This is the title of the form, which should be filled out as a descriptive name for the form.
* **Location** (Location, text): Enter the location related to the issue or reading.
* **Issue Description** (Issue Description, text): Describe the issue or problem that occurred.
* **Issue Date** (Issue Date, date): Enter the date the issue occurred.
* **Issue Time** (Issue Time, time): Enter the time the issue occurred.
* **Reading Type** (Reading Type, select_one):
	+ 'Yes' : Select this if the reading is affirmative.
	+ 'No' : Select this if the reading is negative.
* **Reading Value** (Reading Value, number): Enter the value of the reading.
* **Meter ID** (Meter ID, text): Enter the ID of the meter or device.
* **Meter Reading** (Meter Reading, text): Enter the reading taken from the meter.
* **Meter Reading Date** (Meter Reading Date, date): Enter the date the meter reading was taken.
* **Inventory Item ID** (Inventory Item ID, text): Enter the ID of the inventory item.
* **Inventory Item Name** (Inventory Item Name, text): Enter the name of the inventory item.
* **Inventory Item Description** (Inventory Item Description, text): Enter a description of the inventory item.
* **Inventory Item Quantity** (Inventory Item Quantity, number): Enter the quantity of the inventory item.
* **Inventory Item Location** (Inventory Item Location, text): Enter the location of the inventory item.
* **Issue Status** (Issue Status, select_one):
	+ Active : Select this if the issue is active.
	+ Inactive : Select this if the issue is inactive.
* **Issue Category** (Issue Category, select_one):
	+ 'Yes' : Select this if the issue is affirmative.
	+ 'No' : Select this if the issue is negative.
* **Issue Priority** (Issue Priority, select_one):
	+ 'Yes' : Select this if the priority is high.
	+ 'No' : Select this if the priority is low.
* **Issue Type** (Issue Type, select_one):
	+ 'Yes' : Select this if the issue is affirmative.
	+ 'No' : Select this if the issue is negative.
* **Issue Details** (Issue Details, text): Enter detailed information about the issue.
* **Issue Comments** (Issue Comments, text): Enter any comments or notes about the issue.
* **Inventory Item Serial Number** (Inventory Item Serial Number, text): Enter the serial number of the inventory item.
* **Inventory Item Serial Number Notes** (Inventory Item Serial Number Notes, text): Enter any notes about the serial number.
* **Issue Resolution** (Issue Resolution, text): Enter information about resolving the issue.
* **Issue Closure Date** (Issue Closure Date, date): Enter the date the issue was closed, if applicable.
* **Meter ID** and other fields with 'required: false' are not necessary to fill out.
