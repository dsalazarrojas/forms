# Agricultural Spray Records Checklist - Help Guide
## Purpose
This form is designed to gather accurate and detailed information about agricultural spray activities, ensuring compliance with regulations and best practices.

## How To Complete This Form
To complete this form, start by filling in the required fields, including Operator Name, Farm Name, Spray Date, and Spray Time. Then, enter the Field Name or ID, and select the Crop Being Treated from the drop-down menu. Next, enter the Field Size in acres, and select the Target Pest or Weed from the list. After that, enter the details for each product used, including Product Name, EPA Number, and Amount Used. Be sure to select the correct Unit of Measurement for each product. If additional products were used, enter their details in the corresponding fields. Finally, enter the Total Water Used, Application Rate, and Equipment Used, and complete the sections for Wind Speed, Wind Direction, Temperature, Relative Humidity, Re-entry Interval, Pre-harvest Interval, Personal Protective Equipment, Buffer Zones Observed, Drift Precautions, Container Disposal, and Incidents or Spills. 

## Field-by-Field Explanation
* **Operator Name**: Enter the name of the operator who conducted the spray.
* **Farm Name**: Enter the name of the farm on which the spray was performed.
* **Spray Date**: Enter the date on which the spray was performed. Use the "mm/dd/yyyy" format.
* **Spray Time**: Enter the start time of the spray, in 24-hour clock format (HH:MM AM/PM).
* **Field Name or ID**: Enter the name or ID of the field on which the spray was performed.
* **Field Size (acres)**: Enter the size of the field in acres.
* **Crop Being Treated**: Select the type of crop being treated from the list.
* **Crop Growth Stage**: Select the current growth stage of the crop from the list.
* **Target Pest or Weed**: Select the pest or weed being controlled from the list.
* **Product Name 1**: Enter the name of the first product used.
* **EPA Number 1**: Enter the EPA registration number for the first product.
* **Amount Used 1**: Enter the amount of the first product used.
* **Unit 1**: Select the unit of measurement for the first product.
* **Product Name 2**: If applicable, enter the name of the second product used (if any).
* **EPA Number 2**: If applicable, enter the EPA registration number for the second product (if any).
* **Amount Used 2**: If applicable, enter the amount of the second product used (if any).
* **Unit 2**: If applicable, select the unit of measurement for the second product (if any).
* **Total Water Used (gallons)**: Enter the total volume of water used for the entire spray.
* **Application Rate (gallons per acre)**: Enter the application rate for the entire spray.
* **Equipment Used**: Select the type of spray equipment used from the list.
* **Equipment ID Number**: If applicable, enter the ID number of the equipment used (if any).
* **Wind Speed (mph)**: Enter the wind speed during the application.
* **Wind Direction**: Select the direction in which the wind was blowing from the list.
* **Temperature (Fahrenheit)**: Enter the air temperature during the application.
* **Relative Humidity (%)**: Enter the relative humidity during the application.
* **Re-entry Interval (hours)**: Enter the re-entry interval for the area treated.
* **Pre-harvest Interval (days)**: Enter the pre-harvest interval for the area treated.
* **Personal Protective Equipment Used**: Select all personal protective equipment worn during the application.
* **Buffer Zones Observed**: Select if buffer zones were maintained.
* **Drift Precautions Taken**: Select all precautions taken to prevent drift.
* **Container Disposal Method**: Select the method used to dispose of containers.
* **Incidents or Spills**: Select if any incidents or spills occurred during the application.
* **Incident Description**: Enter a description of any incidents or spills that occurred (if applicable).
* **Supervisor Signature**: Enter the digital signature of the supervisor.
* **Checklist Completed**: Select if the checklist is complete, or indicate if there are items pending.

Note: The required fields are marked as "required: true" in the YAML file.
