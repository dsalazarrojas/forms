# Project Planning Form - Help Guide
## Purpose
This form is used to collect and track information for project planning and management.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (if any):
   * If you are the project manager, make sure to fill in the "Project Status" and "Project Manager" fields.
   * If you are a team member, ensure you are listed correctly under "Team Members".
2. Provide a clear and concise project description in the "Project Description" field.
3. Enter the project start and end dates in the "Project Start Date" and "Project End Date" fields.
4. Select the correct team members who are working on the project under "Team Members".
5. Choose the correct project status and submission details.

## Field-by-Field Explanation
### 1. Project Name
* **Project Name (text)**: This field is used to input the name of the project. Enter a brief and descriptive title that accurately represents the project.

### 2. Project Start Date
* **Project Start Date (date)**: Enter the start date of the project, which marks the beginning of the project timeline.

### 3. Project End Date
* **Project End Date (date)**: Enter the end date of the project, which indicates the completion date.

### 4. Project Status
* **Project Status (multiple selection)**: Select the current status of the project from the provided options: Active or Inactive.

### 5. Project Manager
* **Project Manager (single selection)**: Identify the person responsible for leading the project from the given options: John, Jane, or Jim.

### 6. Team Members
* **Team Members (multiple selection)**: List all team members working on the project from the given options: John, Jane, or Jim.

### 7. Project Description
* **Project Description (text)**: Provide a clear and detailed description of the project, explaining its goals, objectives, and requirements.

### 8. Form Submission Date
* **Form Submission Date (date)**: Automatically populated with the date the form is submitted.

### 9. Submitted By
* **Submitted By (single selection)**: Identify the person submitting the form from the given options: Jim or John.

### 10. Submitted Time
* **Submitted Time (time)**: The timestamp when the form is submitted.

### 11. Form ID
* **Form ID (number)**: A unique identifier for the form submission, automatically generated.

### 12. Project Header (Note)
* **Project Header (note)**: An optional header for the project, which can be used for a brief introduction or description.

This guide is intended to be user-friendly and clear, providing a step-by-step process for completing the form and explaining each field's purpose. The fields are categorized to help users understand their relevance and the expected input.
