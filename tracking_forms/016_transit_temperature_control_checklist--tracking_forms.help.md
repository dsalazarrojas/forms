# Transit Temperature Control Checklist - Help Guide
## Purpose
The purpose of this form is to document and track temperature control checks for shipments, ensuring the goods are transported safely and efficiently.

## How To Complete This Form

1. Select the options for "In Transit Temperature Checks" to indicate if the temperature checks were performed.
2. Choose "Document Inspections" to indicate if document inspections were conducted.
3. Choose "Corrective Actions" to indicate if corrective actions were taken.
4. Fill in the "Shipment Details" text field with relevant information about the shipment, such as the shipment number or description.
5. Enter the "Date And Time Of Check" if the temperature check was performed.
6. Enter the "Temperature Range" if applicable.
7. Enter the "Temperature Limit" if applicable.
8. Add any "Notes" about the temperature check.
9. Check the "Email Notification" box to send an email notification if desired.
10. Enter the "Phone Number" of the person performing the temperature check.
11. Enter the "Responsible Person" name.
12. Check the "Corrective Action Taken" box to indicate if corrective action was taken.
13. Select the "Corrective Action Status" to indicate if the corrective action is Active or Inactive.
14. Select the "Shipment Status" to indicate if the shipment is Active or Inactive.
15. Enter the "Shipment Status Description" if applicable.
16. Add any "Shipment Status Note" about the shipment.
17. Add your "Signature" to the form.
18. Enter the "Document Number" if applicable.
19. Enter the "Document Version" if applicable.
20. Enter the "Last Updated By" name.
21. Enter the "Last Updated On" date.
22. Enter the "Last Updated At" time.
23. Enter the "Created By" name.
24. Enter the "Created On" date.
25. Enter the "Created At" time.

## Field-by-Field Explanation

* **In Transit Temperature Checks**: 
  Select "Yes" if temperature checks were performed during the shipment, "No" if not.
* **Document Inspections**: 
  Select "Yes" if document inspections were conducted, "No" if not.
* **Corrective Actions**: 
  Select "Yes" if corrective actions were taken, "No" if not.
* **Shipment Details**: 
  Enter any relevant information about the shipment.
* **Date And Time Of Check**: 
  Enter the date and time the temperature check was performed.
* **Temperature Range**: 
  Enter the temperature range if applicable.
* **Temperature Limit**: 
  Enter the temperature limit if applicable.
* **Notes**: 
  Add any additional notes about the temperature check.
* **Email Notification**: 
  Check the box to send an email notification if desired.
* **Phone Number**: 
  Enter the phone number of the person performing the temperature check.
* **Responsible Person**: 
  Enter the name of the person responsible for the shipment.
* **Corrective Action Taken**: 
  Check the box to indicate if corrective action was taken.
* **Corrective Action Status**: 
  Select "Active" or "Inactive" to indicate the status of the corrective action.
* **Shipment Status**: 
  Select "Active" or "Inactive" to indicate the status of the shipment.
* **Shipment Status Description**: 
  Enter any additional information about the shipment status.
* **Shipment Status Note**: 
  Add any additional notes about the shipment status.
* **Signature**: 
  Add your signature to the form.
* **Document Number**: 
  Enter the document number if applicable.
* **Document Version**: 
  Enter the document version if applicable.
* **Last Updated By**: 
  Enter the name of the person who last updated the form.
* **Last Updated On**: 
  Enter the date the form was last updated.
* **Last Updated At**: 
  Enter the time the form was last updated.
* **Created By**: 
  Enter the name of the person who created the form.
* **Created On**: 
  Enter the date the form was created.
* **Created At**: 
  Enter the time the form was created.
