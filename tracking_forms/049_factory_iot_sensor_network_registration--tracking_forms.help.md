# Factory IoT Sensor Network Registration - Help Guide

## Purpose
The Factory IoT Sensor Network Registration form is used to create or update a factory's IoT sensor network information.

## How To Complete This Form
1. Enter the factory location where the sensor network is installed.
2. Input the network ID, which is a unique identifier for the network.
3. Choose whether the factory has a sensor or not.
4. Select the date of installation for the sensor network.
5. Enter the total number of sensors installed.
6. Provide a list of serial numbers for the sensors.
7. Input a location map for the sensor placement.
8. Specify the type of installation (e.g., manual, automated).
9. Enter the date of installation.
10. Provide the name and details of the person who installed the sensor network.

## Field-by-Field Explanation
* **Factory Location** (factory_location, text, optional): Enter the factory location where the sensor network is installed.
* **Network ID** (network_id, text, optional): Input the unique identifier for the network.
* **Sensor Type** (sensor_type, select, optional): Choose whether the factory has a sensor ('Yes', 'No').
* **Installation Date** (installation_date, date, optional): Select the date of installation for the sensor network.
* **Sensor Count** (sensor_count, number, optional): Enter the total number of sensors installed.
* **Serial Numbers** (serial_numbers, text, optional): Provide a list of serial numbers for the sensors.
* **Sensor Location Map** (sensor_location_map, text, optional): Input a location map for the sensor placement.
* **Installation Type** (installation_type, text, optional): Specify the type of installation (e.g., manual, automated).
* **Installation Date** (installation_date, date, optional): Select the date of installation.
* **Installed By** (installed_by, text, optional): Provide the name and details of the person who installed the sensor network.

## Tips
* Ensure that you have the correct permissions to access and update sensor network information within the factory.
* Double-check the accuracy of your input data to avoid errors.
* If you're unsure about any field, refer to your factory's IoT sensor network documentation or contact the relevant personnel for assistance.
