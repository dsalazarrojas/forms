# Equipment Release Form - Help Guide
## Purpose
The purpose of this Equipment Release Form is to request permission to borrow specific pieces of equipment. This form should only be filled out if you are requesting equipment that belongs to your department.

## How To Complete This Form
1. Select the **employee** who would be using the equipment.
2. Choose which **equipment** you would like to borrow.
3. Enter your **reason** for borrowing the equipment (e.g., "I need a laptop for a project meeting").
4. Provide the **start date** and **return date** when you would like to begin and end using the equipment.
5. Add any additional **comment** about your request.
6. Select the **manager** who will be responsible for the equipment while it is borrowed.
7. Choose the **department** where the equipment will be used.

## Field-by-Field Explanation
* **employee** (`employee`, select_one, required): Select the employee who will be using the equipment.
* **equipment** (`equipment`, select_multiple, required): Choose which equipment you would like to borrow. You can select multiple equipment items.
* **reason** (`reason`, text, required): Enter your reason for borrowing the equipment (e.g., "I need a laptop for a project meeting").
* **start_date** (`start_date`, date, required): Enter the date when you would like to start using the equipment.
* **return_date** (`return_date`, date, required): Enter the date when you would like to return the equipment.
* **comment** (`comment`, text, required): Add any additional comment about your request.
* **manager** (`manager`, select_one, required): Select the manager who will be responsible for the equipment while it is borrowed.
* **department** (`department`, select_one, required): Choose the department where the equipment will be used.
