# Store Opening Form - Help Guide
## Purpose
The Store Opening Form is designed to collect information about new or modified stores. This form is used to track store details such as name, location, hours, manager's name, store type, address, city, state, country, opening date, and opening time. Completing this form accurately ensures that store information is updated correctly in our system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **store_name** field with the name of the store you are opening or modifying.
2. Enter the **location** where the store is located.
3. Provide the **store_hours** of operation for the store.
4. Enter the **manager_name** of the store.
5. Select the correct **store_type** from the options provided (New Store or Existing Store).
6. Enter the **store_address** of the store.
7. Enter the **store_city** where the store is located.
8. Select the correct **store_state** from the options provided.
9. Select the correct **store_country** from the options provided (USA or Other).
10. If applicable, select the **store_opening_date** and **store_opening_time** for the store.

## Field-by-Field Explanation
* **store_name**: Enter the name of the store (e.g., "ABC Supermarket").
* **location**: Enter the location of the store (e.g., "123 Main St, Anytown, USA").
* **store_hours**: Enter the hours of operation for the store (e.g., "Mon-Sat 9am-6pm, Sun 10am-5pm").
* **manager_name**: Enter the name of the store manager (e.g., "John Doe").
* **store_type**: Select "New Store" if this is a new store, or "Existing Store" if this is a modification to an existing store.
* **store_address**: Enter the address of the store (e.g., "123 Main St, Anytown, USA").
* **store_city**: Enter the city where the store is located (e.g., "Anytown").
* **store_state**: Select the state where the store is located from the options provided (e.g., "CA").
* **store_country**: Select the country where the store is located from the options provided (e.g., "USA").
* **store_opening_date**: Enter the date the store is opening (if applicable, e.g., "2022-01-01").
* **store_opening_time**: Enter the opening time of the store (if applicable, e.g., "09:00").
