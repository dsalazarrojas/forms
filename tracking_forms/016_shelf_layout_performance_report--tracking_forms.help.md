# Shelf Layout Performance Report - Help Guide

## Purpose
The Shelf Layout Performance Report is designed to track and analyze performance data for stores. This report helps store managers monitor their store's layout and make informed decisions to improve customer experience and sales.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the store name in the **store_name** field.
2. Provide the section ID for the store in the **section_id** field.
3. Enter the shelf ID for the store in the **shelf_id** field.
4. Rate the store's performance using the **ratings** field. Select one of the following options:
	* 1
	* 2
	* 3
	* 4
	* 5
5. Enter any comments or feedback in the **comments** field.
6. Optionally, upload up to 18 images of the store's layout using the **store_image**, **store_image2**, **store_image3**, ..., **store_image18** fields.
7. Enter a phone number for the store in the **phone_number** field.

## Field-by-Field Explanation
- **store_name**: Enter the name of the store being reviewed.
- **section_id**: Enter the ID number for the store section being reviewed.
- **shelf_id**: Enter the ID number for the store shelf being reviewed.
- **ratings**: Rate the store's performance using a scale of 1-5, where 1 is the lowest and 5 is the highest.
- **comments**: Enter any additional comments or feedback about the store's performance.
- **store_image**: Upload an image of the store's layout.
- **store_image2**, **store_image3**, ..., **store_image18**: Upload up to 17 additional images of the store's layout.
- **phone_number**: Enter the store's phone number.

Note: Some fields are optional and not all fields are required.
