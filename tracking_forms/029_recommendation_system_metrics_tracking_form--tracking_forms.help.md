# Recommendation System Metrics Tracking Form - Help Guide
## Purpose
This form is used to track metrics and performance of a recommendation system. It is intended for internal use within an organization, possibly for quality assurance or research purposes.

## How To Complete This Form
1. Select the "metric_type" field and choose a relevant metric type from the options provided.
2. Enter the "metric_value" field with the actual metric value.
3. Select the "data_source" field and choose whether the data is from an internal or external source.
4. Enter the evaluation date and time in the "evaluation_date" and "evaluation_time" fields.
5. Add any additional comments or notes about the metric in the "notes" field.
6. Optionally, enter the email address and phone number for contact purposes.

## Field-by-Field Explanation
* **metric_type** (Metric Type, required): Select the type of metric you are tracking, such as "accuracy" or "completeness".
* **metric_value** (Metric Value, optional): Enter the actual value of the metric.
* **data_source** (Data Source, required): Choose whether the data is from an internal or external source.
* **project_id** (Project ID, optional): Enter the ID of the project associated with the metric.
* **evaluation_id** (Evaluation ID, optional): Enter the ID of the evaluation associated with the metric.
* **metric_name** (Metric Name, optional): Enter a name for the metric.
* **metric_target** (Metric Target, optional): Enter the target value for the metric.
* **evaluation_date** (Evaluation Date, optional): Enter the date of the evaluation.
* **evaluation_time** (Evaluation Time, optional): Enter the time of the evaluation.
* **notes** (Notes, optional): Add any additional comments or notes about the metric.
* **email_address** (Email Address, optional): Enter an email address for contact purposes.
* **phone_number** (Phone Number, optional): Enter a phone number for contact purposes.

## Tips
* Make sure to fill out all required fields.
* If you are unsure about any field, refer to the project or evaluation documentation for guidance.
