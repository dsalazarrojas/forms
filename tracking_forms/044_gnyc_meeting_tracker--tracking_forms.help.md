# Gnyc Meeting Tracker - Help Guide
## Purpose
The Gnyc Meeting Tracker form is used to record and track meetings for the Gnyc organization. This form helps to ensure that all relevant information is captured and recorded for future reference and decision-making.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the meeting date using the date picker field at the top of the form.
2. Choose the meeting time using the time selector field next to the date field.
3. Enter the participant(s) involved in the meeting using the text field.
4. Select the level of stakeholder engagement using the numerical scale provided.
5. Add any additional notes or comments regarding the meeting using the text area field at the bottom.

## Field-by-Field Explanation
* **Meeting Date** (`meeting_date`, `date`, required: false): Enter the date of the meeting, using the date picker field to select the desired date.
* **Meeting Time** (`meeting_time`, `time`, required: false): Choose the time of the meeting using the time selector field.
* **Participant** (`participant`, `text`, required: false): Enter the name(s) of the participant(s) involved in the meeting.
* **Stakeholder Engagement** (`stakeholder_engagement`, `number`, required: false): Select a numerical value to indicate the level of stakeholder engagement, with higher values indicating greater engagement.
* **Notes** (`notes`, `note`, required: false): Add any additional notes or comments regarding the meeting in the text area provided.
