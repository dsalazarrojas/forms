# Storage Location Assignment Survey - Help Guide
## Purpose
This form is used to provide information about storage locations you are currently using or wish to use for storing items.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and ensure you understand the purpose and the fields that need to be filled out.
2. Fill out the form with the required information.

## Field-by-Field Explanation

* **Storage Location Assignment** (`storage_location_assignment_survey`, text, optional): Provide a brief description of the storage location you are assigning the item to.
* **Assigned To** (`assigned_to`, select_one, optional): Select who the storage location is assigned to.
	+ Note: This field is optional, but if selected, it will help the administrator track and manage storage assignments more efficiently.
* **Storage Area** (`storage_area`, select_multiple, optional): Select all areas where the storage location is used or will be used.
	+ Note: This field is optional and allows for multiple selections.
* **Access Level** (`access_level`, select_one, optional): Select the access level of the storage location.
	+ Note: This field is optional and will help in managing access control to storage locations.
* **Notes** (`notes`, note, optional): Add any additional comments or notes about this storage location.

## Tips
- Be concise and accurate when filling out this form.
- Use the "Storage Location Assignment" field for a brief description.
- Use the "Assigned To" field to select a valid option.
- Use the "Storage Area" field to select all relevant areas.
- Use the "Access Level" field to select the correct access level.
- Use the "Notes" field for additional comments.
