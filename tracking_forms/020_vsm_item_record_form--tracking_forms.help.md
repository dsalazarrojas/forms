# VSM Item Record Form - Help Guide
## Purpose
This form is used to record and track VSM (Visual System Management) items, allowing users to capture and store various details about each item.
## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the fields according to your needs, starting with the "record_items" field.
2. Select the relevant items from the list provided in the "record_items" field.
3. Enter the item's details in the "item_number", "item_description", "item_status", "priority", "start_date", and "end_date" fields.
4. Add any additional notes or comments in the "notes" field.
## Field-by-Field Explanation
* **VSM Item Form**: This is the main form title, indicating that this is a VSM item record form.
* **record_items**: Select the relevant items from the list provided to associate with this VSM item.
* **item_number**: Enter a numerical value to identify and distinguish this item from others.
* **item_description**: Enter a brief description of the item being recorded.
* **item_status**: Choose whether the item is currently Active or Inactive.
* **priority**: Enter a numerical value indicating the item's priority level.
* **start_date**: Enter the date when the item started or became active.
* **end_date**: Enter the date when the item is expected to end or completed.
* **notes**: Add any additional comments or notes about the item.
## Tips
* Make sure to select the correct items in the "record_items" field that relate to the item being recorded.
* Enter accurate and relevant information in the numerical fields.
* Double-check the dates entered for the "start_date" and "end_date" fields.
* Use the "notes" field to capture any additional context or details about the item.
