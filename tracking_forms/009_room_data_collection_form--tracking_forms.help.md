# Room Data Collection Form - Help Guide
## Purpose
The Room Data Collection Form is designed to gather information about a specific room, including its occupancy details, features, and status. This form helps to ensure that accurate and consistent data is collected and stored for reference.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the title of the room (room_data_collection).
2. Provide the occupancy details about the room.
3. Upload room photos to help with visualization (optional).
4. Select the features of the room (Building, Classroom, Office, or Other).
5. Select the status of the room (Active, Inactive, or Vacant).
6. Enter the name of the room.
7. Write a brief description of the room.
8. Enter the room's number.
9. Enter the building's ID.
10. Enter the floor level of the room.
11. Enter the room's size in square feet.
12. Add any additional comments or notes about the room's status.

## Field-by-Field Explanation

* **Room Data Collection**: This is the title of the form, which should be completed with the name of the room.
* **Occupancy Details**: This field is for providing additional information about the room's occupancy, such as the number of occupants or their schedules.
* **Room Photos**: This field is for uploading photos of the room to help with visualization. You can add multiple photos if needed.
* **Room Features**: Choose the features that apply to the room, such as Building, Classroom, Office, or Other. Select all that apply for an accurate representation.
* **Room Status**: Select the current status of the room, which can be Active, Inactive, or Vacant.
* **Room Name**: Enter the name of the room, which should be distinct and descriptive.
* **Room Description**: Write a brief description of the room to help with identification and context.
* **Room Number**: Enter the number of the room, which should match the building's floor plan.
* **Building ID**: Enter the ID of the building where the room is located.
* **Floor Level**: Enter the floor level of the room, which should match the building's floor plan.
* **Room Size SQFT**: Enter the size of the room in square feet.
* **Room Status Comments**: This field is for adding any additional comments or notes about the room's status, which can be useful for reference.

## Tips

* Be accurate and consistent with your input to ensure that the data is reliable and usable.
* Use the room photos to help with visualization and identification.
* Make sure to select all features that apply to the room.
* Enter the room's size and number correctly for reference and mapping purposes.
* Use the room status comments to add any additional context or notes that may be helpful for others.
