# Drug And Alcohol Testing Log - Help Guide
## Purpose
This form is used to track and record the results of drug and alcohol testing for employees. It is intended to provide a centralized log for management and HR to monitor and manage testing results, ensuring compliance with company policies and procedures.

## How To Complete This Form
To complete this form, follow these steps:
1. Ensure you have a valid Employee ID.
2. Enter the Employee ID in the designated field.
3. Select a date from the calendar or enter it in the correct format (YYYY-MM-DD).
4. Choose the location where the test was conducted.
5. Select the type of test administered.
6. Enter the shift ID associated with the test.
7. Select all relevant test result options that apply.
8. Provide a brief explanation for the test result.
9. If necessary, enter the date and time of the test.

## Field-by-Field Explanation
* **Employee ID (1)**: Enter the unique identifier assigned to the employee undergoing the test. This field is mandatory.
* **Date Tested (2)**: Select the date the test was administered or enter it manually in the correct format (YYYY-MM-DD). Although not required, it helps in tracking historical data and trend analysis.
* **Testing Location (3)**: Provide the location where the test was conducted. This can be a facility, lab, or testing site.
* **Testing Type (4)**: Select the type of test administered, which can be one of the following options:
	+ Option 1
	+ Option 2
	+ Option 3
* **Shift ID (5)**: Enter the unique identifier associated with the shift or work period during which the test was conducted. This field is mandatory.
* **Test Result (6)**: Select all relevant options that apply to the test result.
	+ Option 1
	+ Option 2
	+ Option 3
* **Test Date/Time (7)**: If applicable, enter the date and time the test was administered. This field is not required.
* **Result Explanation (8)**: Provide a brief explanation for the test result, which helps clarify the outcome and reasoning behind the test result. This field is optional.
