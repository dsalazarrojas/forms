# simple_time_sheet_form - Help Guide
## Purpose
The simple time sheet form is used to track the time an employee works and takes breaks. It is used to record the start and end times of work and breaks, and to calculate the total hours worked.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the hours worked in the "Employee Hours" field.
2. Describe the work task or project in the "Work Description" field.
3. Enter the start time of your work in the "Work Start Time" field.
4. Enter the end time of your work in the "Work End Time" field.
5. Enter the start time of your break in the "Break Start Time" field, if applicable.
6. Enter the end time of your break in the "Break End Time" field, if applicable.
7. The "Total Hours" field will automatically calculate the total hours worked based on the input data.

## Field-by-Field Explanation
* **Employee Hours** (Number, required: false): Enter the number of hours worked on the task.
* **Work Description** (Text, required: false): Briefly describe the work task or project.
* **Work Start Time** (Time, required: false): Enter the start time of work in 24-hour format (HH:MM).
* **Work End Time** (Time, required: false): Enter the end time of work in 24-hour format (HH:MM).
* **Break Start Time** (Time, required: false): Enter the start time of break in 24-hour format (HH:MM).
* **Break End Time** (Time, required: false): Enter the end time of break in 24-hour format (HH:MM).
* **Total Hours** (Number, required: false): The automatic calculation of total hours worked based on the input data.

## Tips
* Make sure to enter the correct times in 24-hour format (HH:MM) for work and break start and end times.
* If a break is taken, please enter the break start and end times.
* Ensure to enter an accurate number of hours worked in the "Employee Hours" field.
* Use the "Work Description" field to briefly describe the work task or project.

Note: This help guide assumes the user has a basic understanding of time formats and can follow the instructions accurately. If additional information or clarification is needed, please reach out to support.
