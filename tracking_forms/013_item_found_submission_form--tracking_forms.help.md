# Item Found Submission Form - Help Guide
## Purpose
This form is used to report items that have been found in the workplace or school environment.

## How To Complete This Form

1. Fill out the form completely, providing all the necessary information for your item found submission.
2. Answer each question truthfully and thoroughly.
3. Make sure to complete the form only when the item has been actually found.

## Field-by-Field Explanation

* **Found On** (1, `date`):
	+ A date field where you can select the date when the item was found.
* **Location** (2, `text`):
	+ A text field where you can describe the location where the item was found.
* **Description** (3, `text`):
	+ A text field where you can provide a detailed description of the item.
* **Category** (4, `select_multiple`):
	+ A dropdown menu where you can select the category of the item (e.g., 'Yes', 'No').
* **Found By** (5, `email`):
	+ An email field where you can enter the email address of the person who found the item.

## Tips

* Make sure to complete this form with all the necessary information.
* If unsure about a category, choose the most relevant one or select 'No' if it's not applicable. 
* Be as detailed as possible in your location and description of the item. 

Note: The form can be completed in multiple languages, so the language of the form will be based on the user's default settings.
