# Production Worksheet Form - Help Guide
## Purpose
The Production Worksheet Form is a document used to record and track production details for a specific product. It captures information about the product, its supplier, quantity, price, and status among other fields.

## How To Complete This Form
1. Fill out the required fields (if any) and provide as much detail as possible in the optional fields.
2. Ensure that the "Production Status" field is accurate and up-to-date.
3. Use the "Notes" field to add any additional comments or context related to the production process.
4. Review the form for any errors or inconsistencies before submitting.

## Field-by-Field Explanation
- **Product Name** (Product Name, text, required): Enter the name of the product being produced.
- **Supplier ID** (supplier_id, number, required): Enter the ID of the supplier providing the product.
- **Product Code** (product_code, text, required): Enter the product code for the item being produced.
- **Quantity** (quantity, number, required): Enter the quantity of the product being produced.
- **Unit Price** (unit_price, number, required): Enter the unit price of the product.
- **Total Value** (total_value, number, required): The total value of the product, calculated from the unit price and quantity.
- **Production Status** (production_status, select_one, required): Select the current production status (Pending, In Progress, Complete, Cancelled).
- **Production Date** (production_date, date, required): Enter the date when the production started.
- **Production Time** (production_time, time, required): Enter the time when the production started.
- **Email** (email, email, required): Enter the contact email of the person responsible for the production.
- **Phone** (phone, text, required): Enter the contact phone number of the person responsible for the production.
- **Production Location** (production_location, text, required): Enter the location where the production took place.
- **Production Manager** (production_manager, text, required): Enter the name of the production manager responsible for the task.
- **Production Schedule** (production_schedule, select_multiple, required): Select the days on which the production occurred or will occur (Monday to Sunday).
- **Production Type** (production_type, select_one, required): Select the type of production (Type A, Type B, Type C, Type D).
- **Production Code** (production_code, text, required): Enter the production code for the item.
- **Product Category** (product_category, text, required): Enter the category of the product being produced.
- **Production Plan** (production_plan, text, required): Enter the production plan or notes related to the production process.
- **Tracking Status** (tracking_status, select_one, required): Select the tracking status of the production (Tracked, Not Tracked).
- **Tracking Status Code** (tracking_status_code, text, required): Enter the tracking status code.
- **Tracking Notes** (tracking_notes, text, required): Enter any tracking notes or comments.
- **Production Status Code** (production_status_code, text, required): Enter the production status code.
- **Tracking Notes Code** (tracking_notes_code, text, required): Enter the tracking notes code.
- **Production Notes** (production_notes, select_multiple, required): Select the notes related to the production process.
- **Supplier Name** (supplier_name, text, required): Enter the name of the supplier providing the product.
