# Action Items Details Form - Help Guide

## Purpose

The Action Items Details Form is used to collect and track detailed information about action items. This form is essential for ensuring that action items are properly assigned, prioritized, and completed.

## How To Complete This Form

To complete this form, follow these steps:

1. **Enter the action item title**: Type a brief but descriptive title for the action item in the "Action Item Title" field.
2. **Provide a detailed description**: Write a detailed description of what needs to be done in the "Action Item Description" field.
3. **Assign the action item**: Identify the person responsible for completing the action item in the "Assigned To" field.
4. **Associate the action item with a project**: Enter the name of the project that this action item belongs to in the "Project Name" field.
5. **Specify the priority level**: Choose the priority level of the action item from the options (Low, Medium, High, or Critical) in the "Priority Level" field.
6. **Set a due date**: Enter the date by which the action item needs to be completed in the "Due Date" field.
7. **Set the status**: Select the current status of the action item from the options (Not Started, In Progress, Review, Completed, On Hold, or Cancelled) in the "Status" field.
8. **Choose a category**: Select the type of action item from the options (Task, Meeting, Follow-up, Research, Development, or Other) in the "Category" field.
9. **Optional: estimate time to complete**: If applicable, estimate the time required to complete the action item in the "Estimated Time to Complete" field.
10. **Optional: dependencies**: If this action item depends on completion of other items, list them in the "Dependencies" field.
11. **Optional: required resources**: If specific resources are needed to complete this action item, list them in the "Required Resources" field.
12. **Optional: success criteria**: Define what constitutes successful completion of this action item in the "Success Criteria" field.
13. **Optional: related documents**: List any documents or files related to this action item in the "Related Documents" field.

## Field-by-Field Explanation

* **Action Item Title** (required): Brief title for the action item.
* **Action Item Description** (required): Detailed description of what needs to be done.
* **Assigned To** (required): Name of the person responsible for completing the action item.
* **Project Name** (required): Name of the project this action item belongs to.
* **Priority Level** (required): How urgent this action item is (Low, Medium, High, or Critical).
* **Due Date** (required): Date by which the action item needs to be completed.
* **Status** (required): Current status of the action item (Not Started, In Progress, Review, Completed, On Hold, or Cancelled).
* **Category** (required): Type of action item (Task, Meeting, Follow-up, Research, Development, or Other).
* **Estimated Time to Complete** (optional): Estimated time required to complete the action item (in hours).
* **Dependencies** (optional): List of action items this one depends on.
* **Required Resources** (optional): Resources needed to complete this action item.
* **Success Criteria** (optional): Definition of successful completion of this action item.
* **Related Documents** (optional): List of documents or files related to this action item.
