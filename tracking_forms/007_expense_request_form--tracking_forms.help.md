# Expense Request Form - Help Guide
## Purpose
This form is for tracking employee expenses. It helps the company record and manage employee expenses for financial purposes.

## How To Complete This Form
1.  Fill out the form with the required information.
2.  Select an expense type from the list.
3.  Choose one or more categories for the expense.
4.  Optionally select a date and time for the expense.
5.  Enter a description of the expense.
6.  Enter the amount of the expense.
7.  Click "Submit" to send the form, or "Cancel" to discard it.

## Field-by-Field Explanation
- **Expense Type** (expense_type_label): Select the type of expense from the list to categorize the expense.
- **Expense Date** (expense_date_label): Enter the date of the expense (if applicable).
- **Expense Description** (expense_description_label): Give a brief description of the expense.
- **Expense Amount** (amount_label): Enter the cost of the expense.
- **Submit/Cancel** (submit_label): Select "Submit" to send the form, or "Cancel" to discard it.
- **Category** (category_label): Select one or more categories for the expense.
- **Time** (time_label): Enter the time of the expense (if applicable).
