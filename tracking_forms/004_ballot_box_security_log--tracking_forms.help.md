# Ballot Box Security Log - Help Guide
## Purpose
The Ballot Box Security Log is a form designed for tracking and recording security checks, inspections, and incidents related to ballot boxes. It helps ensure the integrity and security of the ballot box by capturing relevant information about the location and equipment details, seal verification, chain of custody, and any security incidents or discrepancies that may occur.

## How To Complete This Form

1. **Start by filling out the location and equipment details**:
	* Enter the name or ID of the polling station (`polling_location`) to identify the location where the ballot box is being secured.
	* Enter the unique Ballot Box ID number (`ballot_box_id`) on the physical box to track individual box information.
2. **Verify the seal on the ballot box**:
	* Select the reason for the log entry (`check_type`) to specify the purpose of the check or inspection.
	* Record the number on the main security seal (`seal_number_primary`) and secondary seal (if applicable) (`seal_number_secondary`) to track seal information.
	* Indicate whether the seal is intact and untampered (`seal_integrity`).
3. **Document the chain of custody**:
	* Fill out the names of the first and second officials witnessing the security check (`officer_1_name` and `officer_2_name`) for dual custody.
4. **Record the inspection date and time**:
	* Enter the date (`check_date`) and time (`check_time`) of the security inspection.
5. **Report any incidents or discrepancies**:
	* Select whether any security incidents or discrepancies were observed (`incident_reported`) and provide detailed description if necessary (`incident_details`).

## Field-by-Field Explanation

- **Polling Location Name**: Enter the name or ID of the polling station to identify the location.
- **Ballot Box ID Number**: Enter the unique identifier on the physical box.
- **Type of Security Check**: Select the reason for the log entry to specify the purpose of the check or inspection.
- **Primary Seal Number**: Record the number on the main security seal.
- **Secondary Seal Number**: Record the number on the secondary seal (if applicable).
- **Seal Intact and Untampered**: Indicate whether the seal is intact and untampered.
- **Election Officer 1 Name**: Fill out the name of the first official witnessing the check.
- **Election Officer 2 Name**: Fill out the name of the second official witnessing the check (required for dual custody).
- **Date of Inspection**: Enter the date of the security inspection.
- **Time of Inspection**: Enter the time of the security inspection.
- **Incident Reported**: Select whether any security incidents or discrepancies were observed.
- **Detailed Incident Description**: Provide detailed description of any security incidents or discrepancies that occurred.
- **Inspection Date**: Enter the date of the security inspection.
- **Inspection Time**: Enter the time of the security inspection.
