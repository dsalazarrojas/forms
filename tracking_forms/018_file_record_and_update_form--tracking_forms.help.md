# File Record And Update Form - Help Guide
## Purpose
This form is designed to track and update file records, allowing users to input and manage various metadata associated with files. It is likely used in a workgroup or organizational setting where multiple users are involved in updating and tracking file versions.

## How To Complete This Form
1. Fill in the required fields, which are marked as "required" in the form.
2. For date fields, enter the date in the standard format (e.g., YYYY-MM-DD).
3. For select fields, choose one option from the dropdown list.
4. Enter any additional comments or details in the text fields.

## Field-by-Field Explanation
### 1. **File Record And Update Form** (`file_record_and_update_form`, text, required)
This is the title of the form, indicating its purpose.

### 2. **File Version** (`file_version`, text, optional)
Enter the version of the file being tracked.

### 3. **File Date Modified** (`file_date_modified`, date, optional)
Enter the date the file was last modified.

### 4. **File Update Date** (`file_update_date`, date, optional)
Enter the date the file was last updated.

### 5. **File Update Status** (`file_update_status`, select_one, required)
Choose the current status of the file update:
* Approved
* Draft
* Rejected

### 6. **File Change Details** (`file_change_details`, text, required)
Enter any details about changes made to the file.

### 7. **File Update Reason** (`file_update_reason`, text, optional)
Enter the reason for the file update.

### 8. **File Last Updated By** (`file_last_updated_by`, text, optional)
Enter the name of the user who last updated the file.

### 9. **File Last Update Date** (`file_last_update_date`, date, optional)
Enter the date the file was last updated.

### 10. **File Last Updated At** (`file_last_updated_at`, time, optional)
Enter the time the file was last updated.

### 11. **File Last Updated By 2** (`file_last_updated_by_2`, text, optional)
Enter the name of the user who last updated the file.

### 12. **File Update Comment** (`file_update_comment`, text, optional)
Enter any comments about the file update.

### 13. **File Last Update User** (`file_last_update_user`, text, optional)
Enter the name of the user who last updated the file.

### 14. **File Update Status Updated** (`file_update_status_updated`, select_multiple, optional)
Choose the updated status of the file update:
* Approved
* Draft
* Rejected

### 15. **File User** (`file_user`, text, optional)
Enter the name of the user associated with the file.

### 16. **File User 1** (`user_1`, text, optional)
Enter an additional user name.

### 17. **Last Update User** (`last_update_user`, text, optional)
Enter the name of the user who last updated the file.

### 18. **File Update Comment 2** (`file_update_comment_2`, text, optional)
Enter additional comments about the file update.

### 19. **File User 2** (`user_2`, text, optional)
Enter an additional user name.

### 20. **File Last Updated By 3** (`file_last_updated_by_3`, text, optional)
Enter the name of the user who last updated the file.
