# Facility Waste Reduction Plan Request Form - Help Guide
## Purpose

The Facility Waste Reduction Plan Request Form is used by facilities to submit information about their waste reduction projects. This form is used to track and manage waste reduction projects, including project details, progress, and goals.

## How To Complete This Form

1. **Facility Waste Reduction** (`text`, required): Enter a brief description of the waste reduction project.
2. **Facility ID** (`number`, optional): Enter your facility's ID number, if applicable.
3. **Project Title** (`text`, optional): Enter a title for the project.
4. **Project Description** (`text`, required): Enter a detailed description of the project.
5. **Project Start Date** (`date`, optional): Enter the start date of the project.
6. **Project End Date** (`date`, optional): Enter the end date of the project.
7. **Facility Email** (`email`, optional): Enter your facility's email address, if applicable.
8. **Facility Phone** (`text`, optional): Enter your facility's phone number, if applicable.
9. **Project Lead** (`text`, optional): Enter the name of the project lead, if applicable.
10. **Project Status** (`select_one`, required): Select the current status of the project:
	* **Active**: The project is currently active.
	* **Inactive**: The project is currently inactive.
	* **Completed**: The project has been completed.
11. **Project Notes** (`note`, required): Enter any relevant notes about the project.
12. **Facility Location** (`text`, optional): Enter the location of the facility, if applicable.
13. **Facility Waste Reduction Goal** (`number`, required): Enter the percentage of waste reduction goal for the project.
14. **Facility Waste Reductions** (`number`, required): Enter the number of waste reductions implemented as part of the project.
15. **Facility Waste Reduction Percentage** (`number`, required): Enter the percentage of waste reduction achieved as part of the project.
16. **Facility Waste Reduction Target** (`text`, optional): Enter any additional information about the waste reduction target.
17. **Facility Waste Reduction Action** (`text`, optional): Enter any relevant actions taken as part of the project.
18. **Facility Waste Reduction Comments** (`text`, optional): Enter any additional comments about the project.
19. **Facility Waste Reduction Notes** (`note`, optional): Enter any additional notes about the project.
20. **Facility Waste Reduction File** (`text`, optional): Upload any relevant file related to the project.
21. **Facility Waste Reduction Submit** (`select_multiple`, required): Select the submit option:
	* **Submit**: Submit the form for review.
	* **Decline**: Decline to submit the form.
	* **Hold**: Hold the submission for further review.

## Tips

* Ensure all required fields are completed before submitting the form.
* If you're updating an existing project, make sure to review and update the existing submission before completing this form.
* If you have any questions or concerns, contact the relevant facility or project lead.
