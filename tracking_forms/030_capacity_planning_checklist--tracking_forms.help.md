# Capacity Planning Checklist - Help Guide
## Purpose
This form is designed to help organizations assess and document their capacity planning and backup strategy. It's used to gather information about the organization's infrastructure, backup systems, and disaster recovery procedures.

## How To Complete This Form

1. Fill out the form completely, providing all required information.
2. Review each section carefully to ensure accuracy.
3. Select the correct options from the drop-down menus.
4. Enter numerical values in the correct format (e.g., numbers, percentages).
5. Describe any improvements or recommendations in the "Recommendations for Improvement" field.

## Field-by-Field Explanation

* **Organization Name** (4): Enter your organization's name as it should be displayed on the report.
* **Department or Division** (5): Enter the department or division name associated with this assessment.
* **Assessment Date** (6): Enter the date this assessment was completed.
* **Assessor Name** (7): Enter your name as the assessor completing this form.
* **Assessor Email** (8): Enter your email address for contact purposes.
* **Current Storage Capacity (TB)** (10): Enter the total storage capacity in terabytes (TB).
* **Current Storage Utilization (%)** (11): Enter the current storage utilization as a percentage.
* **Estimated Monthly Data Growth (%)** (12): Enter the estimated monthly data growth rate as a percentage.
* **Number of Servers** (14): Enter the total number of servers.
* **Average Server Age (years)** (15): Enter the average age of the servers in years.
* **Hardware Refresh Needed Soon?** (16): Select one of the options:
	+ Yes, critical
	+ Yes, planned
	+ Maybe in 6 months
	+ No, current
* **Current Backup System in Place?** (18): Select one of the options:
	+ Yes, comprehensive
	+ Yes, partial
	+ Basic backup
	+ No
* **Backup Frequency** (19): Select one of the options:
	+ Real-time
	+ Hourly
	+ Daily
	+ Weekly
	+ Monthly
	+ No regular backups
* **Backup Storage Location** (20): Select all applicable options:
	+ On-site
	+ Off-site
	+ Cloud storage
	+ Multiple locations
	+ Other
* **Backup Testing Schedule** (21): Select one of the options:
	+ Monthly tests
	+ Quarterly tests
	+ Annual tests
	+ No regular testing
* **Disaster Recovery Plan in Place?** (23): Select one of the options:
	+ Yes, documented
	+ Yes, informal
	+ Partial plan
	+ No
* **Recovery Time Objective (RTO) Defined?** (24): Select one of the options:
	+ Yes, minutes
	+ Yes, hours
	+ Yes, days
	+ No
* **Recovery Point Objective (RPO) Defined?** (25): Select one of the options:
	+ Yes, minutes
	+ Yes, hours
	+ Yes, days
	+ No
* **Is Data Properly Classified by Criticality?** (27): Select one of the options:
	+ Yes, fully classified
	+ Partially classified
	+ Not classified
* **Critical Systems Identified?** (28): Select one of the options:
	+ Yes, documented
	+ Yes, informally
	+ Not identified
* **System Redundancy in Place?** (30): Select one of the options:
	+ Yes, full redundancy
	+ Yes, partial redundancy
	+ No redundancy
* **Failover Testing Completed?** (31): Select one of the options:
	+ Yes, regularly
	+ Yes, once
	+ Planned
	+ No
* **Recommendations for Improvement** (32): Describe any needed improvements or recommendations.
