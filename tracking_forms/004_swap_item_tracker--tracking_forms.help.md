# Swap Item Tracker - Help Guide

## Purpose
This form is designed to help you track and manage your swaps, including their status, dates, photos, and notes.

## How To Complete This Form
To fill out this form, follow these steps:

1. Review the form carefully to understand each field's purpose.
2. Fill out the relevant fields for each swap you want to track.
3. Enter the swap status (Active, Lost, Completed, or Cancelled) for each swap.
4. Select the date for each swap using the date picker.
5. Add any relevant photos for each swap.
6. Enter any additional notes for each swap.
7. Repeat the process for each swap you want to track.

## Field-by-Field Explanation
* **Swap Status (swap_status)**: Select the status of the swap (Active, Lost, Completed, or Cancelled).
* **Swap Date (swap_date)**: Select the date for the swap using the date picker.
* **Photo URL (photo_url)**: Enter a URL of the photo related to the swap (optional).
* **Notes (notes)**: Add any additional notes about the swap (optional).
* **User ID (user_id)**: Enter the ID of the user involved in the swap (optional).
* **Item Name (item_name)**: Enter the name of the item being swapped (optional).
* **Swap Status 1-3 (swap_status_1-3)**: Select the status of each swap (Active, Lost, Completed, or Cancelled).
* **Swap Date 1-3 (swap_date_1-3)**: Select the date for each swap using the date picker.
* **Photo URL 1-3 (photo_url_1-3)**: Enter a URL of the photo related to each swap (optional).
* **Notes 1-3 (notes_1-3)**: Add any additional notes about each swap (optional).
* **User ID 1-3 (user_id_1-3)**: Enter the ID of the user involved in each swap (optional).
* **Item Name 1-3 (item_name_1-3)**: Enter the name of the item being swapped for each swap (optional).

## Tips
* Make sure to review each field carefully to avoid any mistakes or misinterpretation.
* Repeat the process for each swap you want to track.
* Use the date picker to select the correct date for each swap.
* Enter any relevant photos and notes for each swap.
