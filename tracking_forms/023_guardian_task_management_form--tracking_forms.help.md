# Guardian Task Management Form - Help Guide
## Purpose
The Guardian Task Management Form is a tool used to collect and track information about tasks assigned to guardians of children or vulnerable individuals.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each page carefully to understand the required and optional fields.
2. Fill in the required fields as prompted.
3. For fields with multiple options, select the most suitable choice for your task.
4. Use the text areas (Notes 1, 2, and 3) to provide any additional information that may be helpful in understanding the task.
5. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

* **General Info**: This is a text field where you can provide any general information about the task.
* **Due Date 1**: Enter the date by which the task is due.
* **Due Date 2**: Enter the date by which the second task is due.
* **Status 1**: Select the status of the task, either "Active" or "Inactive".
* **Status 2**: Select the status of the second task, either "Active" or "Inactive".
* **Notes 1**: Use this text area to provide any additional information about the task, such as details about the task or any relevant notes.
* **Notes 2**: Similar to Notes 1, use this text area to provide any additional information about the task.
* **Notes 3**: Use this text area to provide any further details about the task, if needed.

## Tips

* Please fill out all required fields before submitting the form.
* Use clear and concise language in the text areas to help ensure that the task information is easily understood.
* If you are unsure about any field, refer back to this help guide for clarification.
