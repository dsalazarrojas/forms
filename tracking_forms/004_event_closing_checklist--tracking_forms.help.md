# Event Closing Checklist - Help Guide
## Purpose
The Event Closing Checklist is a form used to track the completion of events and ensure that all necessary tasks and checks are performed before closing an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields for each section, including event details and descriptions.
2. Select the relevant options for each checklist, based on the actual completion of the tasks.

## Tips
- Make sure to select 'No' for tasks that were not completed.
- Use the event_closing_checklist_1_checklist field to track completion of tasks for this event.
- If an event has multiple sections (e.g. event_closing_checklist_2_checklist), make sure to select 'Yes' for each relevant section.
- If an event has no sections, leave the corresponding checklist fields blank.
- This form is used to track the completion of events, so make sure to fill out all relevant sections accurately.
- If you are unsure about the completion of a task, select 'No' and note the reason in the description field.
