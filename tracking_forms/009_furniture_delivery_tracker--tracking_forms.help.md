# Furniture Delivery Tracker - Help Guide
## Purpose
The Furniture Delivery Tracker form helps you track the status of furniture deliveries. It allows you to input key information about each delivery, including the delivery date, store confirmation, and delivery confirmation.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the relevant fields that pertain to your delivery.
2.  Fill in the required fields with the necessary information.
3.  Select your choices for the select fields.

## Field-by-Field Explanation
* **Delivery Date** (`delivery_date`, date, required/optional): Enter the date the delivery is scheduled to take place.
* **Store Name** (`store_name`, text, optional): Enter the name of the store where the delivery is taking place.
* **Customer Name** (`customer_name`, text, optional): Enter the name of the customer for the delivery.
* **Delivery Status** (`delivery_status`, select_one, optional): Select 'Active' if the delivery is still active or 'Inactive' if it's completed or cancelled.
* **Confirmation Status** (`confirmation_status`, select_one, optional): Select 'Yes' if you have confirmed the delivery with the customer or 'No' otherwise.
* **Store Confirmation** (`store_confirmation`, select_multiple, optional): Select 'Yes' if you have confirmed the delivery with the store or 'No' otherwise.
* **Delivery Confirmation** (`delivery_confirmation`, select_multiple, optional): Select 'Yes' if you have confirmed the delivery with the customer or 'No' otherwise.
* **Delivery Notes** (`delivery_notes`, note, optional): Enter any additional information about the delivery.
* **Warehouse Confirmation** (`warehouse_confirmation`, select_multiple, optional): Select 'Yes' if you have confirmed the delivery with the warehouse or 'No' otherwise.
