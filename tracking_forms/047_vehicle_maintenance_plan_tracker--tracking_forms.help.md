# Vehicle Maintenance Plan Tracker - Help Guide

## Purpose
The Vehicle Maintenance Plan Tracker form helps users track and manage vehicle maintenance plans, including service history, upcoming maintenance, and costs associated with vehicle ownership.

## How To Complete This Form
1. Fill out each field carefully, making sure to provide accurate information for each section.
2. Start by entering the vehicle details, such as vehicle number, make, model, year, and color.
3. Record the vehicle's maintenance history, including any past maintenance events, service dates, and costs.
4. List any upcoming scheduled maintenance, if applicable.
5. Enter the cost and details of the last service performed.
6. Provide additional notes about the service, if necessary.
7. Select the type of service performed (e.g., oil change, tire change, etc.).
8. Enter the date of the last service, if known.
9. Enter the location where the last service was performed.
10. Enter the mileage at which the last service was performed.
11. Enter any additional notes about the vehicle, if necessary.
12. Determine the vehicle's status (active or inactive).
13. Enter the vehicle type.
14. Enter the date of the next service, if scheduled.
15. Enter the mileage at which the next service is due.
16. Enter the location of the next service, if scheduled.
17. Enter the estimated cost of the next service.
18. Enter any additional notes about the next service, if necessary.

## Field-by-Field Explanation

* **Vehicle Number** (`vehicle_number`, text, optional): Enter the vehicle's unique identification number.
* **Vehicle Make** (`vehicle_make`, text, optional): Enter the vehicle's make.
* **Vehicle Model** (`vehicle_model`, text, optional): Enter the vehicle's model.
* **Vehicle Year** (`vehicle_year`, text, optional): Enter the vehicle's year.
* **Vehicle Color** (`vehicle_color`, text, optional): Enter the vehicle's color.
* **Vehicle Status** (`vehicle_status`, select_one, required): Select the current status of the vehicle (active or inactive).
* **Vehicle Type** (`vehicle_type`, text, optional): Enter the type of vehicle (e.g., car, truck, motorcycle, etc.).
* **Last Service Date** (`last_service_date`, date, optional): Enter the date of the last service, if known.
* **Last Service Location** (`service_location`, text, optional): Enter the location where the last service was performed.
* **Last Service Mileage** (`service_mileage`, number, optional): Enter the mileage at which the last service was performed.
* **Last Service Notes** (`service_notes`, text, optional): Enter any additional notes about the last service.
* **Last Service Type** (`service_type`, select_one, optional): Select the type of service performed (e.g., oil change, tire change, etc.).
* **Last Service Cost** (`service_cost`, number, optional): Enter the cost of the last service.
* **Upcoming Maintenance** (`upcoming_maintenance`, select_multiple, optional): List any upcoming scheduled maintenance, if applicable.
* **Next Service Date** (`next_service_date`, date, optional): Enter the date of the next service, if scheduled.
* **Next Service Location** (`next_service_location`, text, optional): Enter the location of the next service, if scheduled.
* **Next Service Distance** (`next_service_distance`, number, optional): Enter the mileage at which the next service is due.
* **Next Service Cost** (`next_service_cost`, number, optional): Enter the estimated cost of the next service.
* **Next Service Type** (`service_type`, select_one, optional): Select the type of service scheduled for the next service (e.g., oil change, tire change, etc.).
* **Additional Notes** (`notes`, text, optional): Enter any additional notes about the vehicle, if necessary.)
