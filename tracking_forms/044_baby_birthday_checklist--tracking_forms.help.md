# Baby Birthday Checklist - Help Guide
## Purpose
The purpose of this form is to help plan and track various aspects of a baby's birthday party, including the party date, expected number of guests, and preparations for food, entertainment, and decorations.

## How To Complete This Form
To complete this form, simply fill out each field as follows:

* Fill in the baby's name
* Select a date for the party
* Enter the name of the party organizer
* Choose the location for the party
* Enter the expected number of guests
* Indicate if invitations have been sent
* Set a deadline for RSVPs
* Check off preparations for balloons, streamers, and banners
* Check off preparations for table setup and linens
* Indicate if cake has been ordered
* Choose a flavor for the cake (if ordered)
* Plan out the food menu
* Check off preparations for drinks
* Plan out activities and entertainment
* Check off if a photographer has been arranged
* Select party supplies that apply
* Add any additional notes or reminders

## Field-by-Field Explanation

* **Baby Name** (`baby_name`, text, required): Fill in the baby's name
* **Party Date** (`party_date`, date, required): Select a date for the party (e.g., 2024-02-22)
* **Party Organizer Name** (`party_organizer`, text, required): Enter the name of the person planning the party
* **Party Location** (`party_location`, text, required): Choose the location of the party (e.g., home, venue, park)
* **Expected Number of Guests** (`expected_guests`, number, required): Enter the expected number of guests
* **-- Invitations --** (`section_invitations`, note, optional): A section for tracking invitations (e.g., sent, not sent, progress)
* **Invitations Sent?** (`invitations_sent`, select_one, required): Check off if invitations have been sent, or select "in progress" or "not yet" if not
* **RSVP Deadline** (`rsvp_deadline`, date, optional): Set a deadline for RSVPs
* **-- Decorations --** (`section_decorations`, note, optional): A section for tracking decoration preparations
* **Balloons Purchased?** (`balloons_purchased`, select_one, optional): Check off if balloons have been purchased, or select "in progress" or "not yet" if not
* **Streamers and Banners?** (`streamers_banners`, select_one, optional): Check off if streamers and banners have been purchased, or select "in progress" or "not yet" if not
* **Table Setup and Linens?** (`table_setup`, select_one, optional): Check off if table setup and linens have been prepared, or select "in progress" or "not yet" if not
* **Cake Ordered?** (`cake_ordered`, select_one, required): Check off if cake has been ordered, or select "in progress" or "false" if not
* **Cake Flavor** (`cake_flavor`, text, optional): Choose the flavor of the cake (if ordered)
* **-- Food and Drinks --** (`section_food`, note, optional): A section for tracking food and drink preparations
* **Food Menu Planned?** (`food_menu_planned`, select_one, optional): Check off if a food menu has been planned, or select "in progress" or "false" if not
* **Drinks Prepared?** (`drinks_prepared`, select_one, optional): Check off if drinks have been prepared, or select "in progress" or "not yet" if not
* **-- Entertainment --** (`section_entertainment`, note, optional): A section for tracking entertainment preparations
* **Activities Planned?** (`activities_planned`, select_one, optional): Check off if activities have been planned, or select "in progress" or "false" if not
* **Entertainment or DJ Booked?** (`entertainment_booked`, select_one, optional): Check off if entertainment or a DJ has been booked, or select "in progress" or "false" if not
* **-- Party Favors --** (`section_favors`, note, optional): A section for tracking party favor preparations
* **Party Favors Purchased?** (`favors_purchased`, select_one, optional): Check off if party favors have been purchased, or select "in progress" or "not yet" if not
* **Photographer Arranged?** (`photographer`, select_one, optional): Check off if a photographer has been arranged, or select "in progress" or "false" if not
* **Party Supplies Checklist** (`supplies_checklist`, select_multiple, optional): Select all party supplies that apply (e.g., plates, cups, centerpieces, etc.)
* **Additional Notes or Reminders** (`notes`, text, optional): Add any additional notes or reminders for the party.
