# Daily Case Notes Form - Help Guide
## Purpose
The Daily Case Notes Form is a tool used to track and document daily case notes, ensuring that all relevant information is captured and recorded accurately. This form is used to provide a clear and organized record of each case.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form fields to ensure you have all the necessary information.
2. Enter the required information accurately and thoroughly.
3. Use the available options for select fields to choose the most relevant information.
4. Save your progress before moving on to other tasks.

## Field-by-Field Explanation

### Session Details
* **Session Details** (`session_details`, text, optional): Enter a brief description of the session, including any relevant context or information.

### Case Updates
* **Case Updates** (`case_updates`, text, optional): Record any updates or changes that occurred during the session, including any new information or developments.

### Session Duration
* **Session Duration** (`session_duration`, number, optional): Enter the duration of the session, including the start and end times.

### Session Goals
* **Session Goals** (`session_goals`, select_multiple, optional): Indicate whether the session had the following goals:
	+ Yes
	+ No

### Action Plans
* **Action Plans** (`action_plans`, select_multiple, optional): Indicate whether the following action plans were discussed or agreed upon:
	+ Yes
	+ No

### Next Steps
* **Next Steps** (`next_steps`, select_multiple, optional): Indicate whether the following next steps were agreed upon:
	+ Yes
	+ No

### Follow Up Date
* **Follow Up Date** (`follow_up_date`, date, optional): Enter the date for the follow-up, if applicable.

### Follow Up Time
* **Follow Up Time** (`follow_up_time`, time, optional): Enter the time for the follow-up, if applicable.

### Follow Up Notes
* **Follow Up Notes** (`follow_up_notes`, text, optional): Enter any additional notes or information for the follow-up.

Note: The required fields are optional by default, but it's recommended to fill them out for a more comprehensive and accurate record.
