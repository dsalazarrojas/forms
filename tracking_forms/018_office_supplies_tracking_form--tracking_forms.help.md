# Office Supplies Tracking Form - Help Guide
## Purpose
The Office Supplies Tracking Form is a tool used to monitor and manage office supplies. This form provides an overview of the current stock, supply type, replenishment status, and other relevant information to ensure efficient tracking and ordering of office supplies.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Form Title**, a brief description of the office or location being tracked.
2. Select the **Supply Type** (e.g., Paper, Pens, Pencils, etc.) to indicate the type of office supplies being tracked.
3. Enter the **Current Stock** quantity of the selected supply type.
4. Select the **Last Replenishment Date** and **Last Replenished By** to record the previous replenishment details.
5. Set the **Next Replenishment Due** date for the selected supply type.
6. Choose the **Replenishment Frequency** (e.g., Daily, Weekly, Monthly).
7. Select the **Replenishment Status** (e.g., Completed, Pending).
8. Set the **Reorder Threshold** to trigger the next replenishment action.

## Field-by-Field Explanation

* **Form Title**: A brief description of the office or location being tracked.
* **Supply Type**: Select one or more types of office supplies being tracked, such as Paper, Pens, Pencils, etc.
	+ Note: This field allows for multiple selection, so you can track multiple supply types at once.
* **Current Stock**: Enter the current quantity of the selected supply type.
* **Last Replenishment Date**: Record the date of the last replenishment of the selected supply type.
* **Last Replenished By**: Record the person or team responsible for the last replenishment.
* **Next Replenishment Due**: Set the date for the next replenishment of the selected supply type.
* **Last Replenishment Date**: Record the date of the last replenishment of the selected supply type. (Note: This field is intended to track the date of the last replenishment event.)
* **Last Replenished By**: Record the person or team responsible for the last replenishment event.
* **Replenishment Frequency**: Choose how often you want to replenish the selected supply type (e.g., Daily, Weekly, Monthly).
* **Replenishment Status**: Select the status of the next replenishment (e.g., Completed, Pending).
* **Reorder Threshold**: Set the quantity below which the supply type should be reordered.
