# Daily Portion Tracker Form - Help Guide
## Purpose
This form is designed to track your daily food and snack intake, providing detailed information about what you ate at different meals and whether you had any additional snacks.

## How To Complete This Form
1. Select your food item for each meal from the provided options.
2. Enter the number of servings for each meal.
3. Select whether you ate any snacks between meals.
4. If you ate snacks, select all that apply and enter the number of servings.
5. Repeat the process for all three meals and snack sections.
6. Finally, add any additional comments or questions in the "Additional comments or questions" field.

## Field-by-Field Explanation
* **What was the first thing you had for breakfast?** (`first_page`): Select the food item you had for breakfast from the provided options. This will help us track your breakfast intake.
* **How many servings?** (`first_page_servings`): Enter the number of servings of the selected food item for breakfast.
* **Did you eat any snacks?** (`did_you_eat_snacks`): Select 'True' if you had any snacks between breakfast and lunch.
* **What snacks did you have?** (`snacks`): If you selected 'True' for the previous question, select all the snacks you had.
* **How many servings of snacks?** (`first_page_servings_snacks`): Enter the number of servings for the selected snacks.
* **What was the main course for lunch?** (`second_page`): Select the food item you had for lunch from the provided options.
* **Second Page Servings** (`second_page_servings`): Enter the number of servings for the selected food item for lunch.
* **Did you eat any additional snacks?** (`did_you_eat_snacks_2`): Select 'True' if you had any additional snacks between lunch and dinner.
* **What snacks did you have?** (`additional_snacks`): If you selected 'True' for the previous question, select all the additional snacks you had.
* **How many servings of additional snacks?** (`second_page_servings_snacks`): Enter the number of servings for the selected snacks.
* **What was the main course for dinner?** (`third_page`): Select the food item you had for dinner from the provided options.
* **Third Page Servings** (`third_page_servings`): Enter the number of servings for the selected food item for dinner.
* **Did You Eat Snacks 3** (`did_you_eat_snacks_3`): Select 'True' if you had any snacks between dinner and bedtime.
* **Additional Snacks 2** (`additional_snacks_2`): If you selected 'True' for the previous question, select all the additional snacks you had.
* **Third Page Servings Snacks** (`third_page_servings_snacks`): Enter the number of servings for the selected snacks.
* **Additional comments or questions** (`fourth_page`): Enter any additional comments or questions you may have. This is an optional field.
