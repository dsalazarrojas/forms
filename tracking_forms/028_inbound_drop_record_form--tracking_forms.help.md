# Inbound Drop Record Form - Help Guide
## Purpose
The Inbound Drop Record Form is designed for tracking inbound deliveries, ensuring accurate and timely information.

## How To Complete This Form
To complete this form, follow these steps:
- Fill in the delivery date using the calendar input field.
- Select the delivery time using the time input field.
- Enter any additional delivery note in the text area.
- Select the delivery type from the options provided.
- Choose the correct slip option for the delivery.
- Enter the warehouse information for the delivery.
- Type in the office name associated with the delivery.
- Enter the name of the person responsible for the logistics team.
- Enter the contact number of the contact person.

## Field-by-Field Explanation
- **Delivery Date** (`delivery_date`, date, required/optional): Enter the date of the delivery.
  - Please use the calendar input field to select the date of the delivery.
- **Delivery Time** (`delivery_time`, time, required/optional): Select the time of the delivery.
  - Choose the time of the delivery using the time input field.
- **Delivery Note** (`delivery_note`, note, required/optional): Enter any additional notes about the delivery.
  - Type any comments or remarks about the delivery in this text area.
- **Delivery Type** (`delivery_type`, select_multiple, required/optional): Select the type of delivery.
  - Choose one or multiple options that best describe the delivery type.
- **Delivery Slip** (`delivery_slip`, select_one, required/optional): Select the correct slip option for the delivery.
  - Choose the slip option that corresponds to the delivery.
- **Warehouse** (`warehouse`, text, required/optional): Enter the warehouse information for the delivery.
  - Type in the warehouse name or location where the delivery is being sent.
- **Office** (`office`, text, required/optional): Enter the office name associated with the delivery.
  - Type in the office name or location where the delivery is being sent.
- **Logistics Team** (`logistics_team`, text, required/optional): Enter the name of the person responsible for the logistics team.
  - Type in the name of the person or team handling the delivery.
- **Contact Person** (`contact_person`, text, required/optional): Enter the name of the contact person.
  - Type in the name of the person to contact for the delivery.
- **Contact Number** (`contact_number`, text, required/optional): Enter the contact number of the contact person.
  - Type in the contact number of the person to contact for the delivery.
