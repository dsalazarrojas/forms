# Serial Number Generator - Help Guide
## Purpose
This form generates a serial number based on the input parameters provided. It allows you to define a specific date range and time period, prefix, suffix, and padding characteristics to generate unique serial numbers.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Start Date for the serial number range.
2. Enter the Start Time for the serial number range.
3. Enter the End Date for the serial number range.
4. Enter the End Time for the serial number range.
5. Set the Length of the serial number.
6. Define the Prefix for the serial number.
7. Optionally, set the Suffix for the serial number.
8. Optionally, set the Prefix Length.
9. Optionally, set the Pad To option to control the padding behavior.
10. Optionally, set the Start Pad and End Pad options to control the padding behavior at the start and end of the serial number.
11. Optionally, set the Pad Char to control the character used for padding.
12. Optionally, set the Prefix Type and Suffix Type options to control the type of prefix and suffix.
13. Optionally, set the Pad Type to control the type of padding.
14. Optionally, set the Char Pad Type to control the type of character used for padding.
