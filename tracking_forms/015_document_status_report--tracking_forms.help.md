# Document Status Report - Help Guide
## Purpose
The Document Status Report form is a tool used to track and manage documents, providing real-time information on current status, updates, and progress.

## How To Complete This Form
1. Start by selecting the current status of the document from the options provided.
2. If necessary, update the owner of the document by selecting their email address from the options.
3. Set a deadline for the document, if applicable.
4. Provide a due date for the document, if necessary.
5. Enter a progress report, if you have any updates on the document's status.
6. Add any comments about the document, if necessary.
7. Fill in the tracking number, if provided.
8. Finally, select the submitter and team lead from the options provided.

## Field-by-Field Explanation

* **Current Status** (`current_status`, select_one, required/optional): Select the current status of the document from the provided options to accurately reflect its progress.
* **Update Owner** (`update_owner`, email, optional): If the document's owner needs to be updated, enter their email address to ensure they receive notifications.
* **Deadline** (`deadline`, date, optional): Set a deadline for the document to help stakeholders stay on track with its completion.
* **Due Date** (`due_date`, date, optional): Enter a due date for the document, if necessary, to help with scheduling and planning.
* **Progress Report** (`progress_report`, text, optional): Provide an update on the document's progress, including any relevant details or comments.
* **Comments** (`comments`, note, optional): Add any additional comments or notes about the document, if necessary.
* **Tracking Number** (`tracking_number`, number, optional): Enter the tracking number for the document, if provided.
* **Submitter** (`submitter`, select_one, optional): Select the person who submitted the document, if necessary.
* **Team Lead** (`team_lead`, select_one, optional): Select the team lead responsible for the document, if necessary.

## Tips
- Make sure to select the correct options for the current status, submitter, and team lead to ensure accurate reporting.
- Enter the email address of the document's owner correctly to ensure they receive updates.
- Be concise and clear in the progress report to keep stakeholders informed.
- Use the comments field for any additional information that doesn't fit in the other fields.
