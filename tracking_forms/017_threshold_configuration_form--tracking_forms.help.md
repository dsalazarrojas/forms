# Threshold Configuration Form - Help Guide
## Purpose
This form is for defining and configuring threshold settings for various metrics. It helps you determine when to trigger specific actions based on certain conditions.

## How To Complete This Form
- Select the conditions that should be checked.
- Choose the threshold value for the selected condition.
- Determine the method for sending notifications and performing actions when the condition is met.
- Optionally select additional methods for sending notifications and performing actions when the condition is met for multiple thresholds.

## Field-by-Field Explanation

* **Conditions** (`conditions`, select_multiple): Choose one or more conditions to be checked. This could be "Yes" or "No".
* **Threshold** (`threshold`, select_one): Select "Yes" or "No" to activate threshold monitoring. 
* **Notification Method** (`notification_method`, select_multiple): Choose the method for sending notifications when the condition is met. 
* **Action** (`action`, select_multiple): Select one or more actions to be performed when the condition is met. 
* **Notification Method Name** (`notification_method_name`, text): Provide a name for the notification method. 
* **Threshold Value** (`threshold_value`, number): Enter the value of the threshold. 
* **Action Name** (`action_name`, text): Provide a name for the action. 
* **Action Method** (`action_method`, select_one): Select "Yes" or "No" to activate the action. 
* **Notification Recipients** (`notification_recipients`, text): Enter the recipients to receive the notification. 
* **Condition** (`condition`, text): Briefly describe the condition for which this threshold is being set. 
* **Threshold Unit** (`threshold_unit`, select_one): Select the unit for the threshold value. 
* **Frequency** (`frequency`, select_one): Select whether the threshold should be checked frequently or not. 
* **Notification Method 2** (`notification_method_2`, select_one): Choose an alternative method for sending notifications when the condition is met. 
* **Action 2** (`action_2`, select_multiple): Select one or more actions to be performed when the condition is met. 
* **Notification Recipients 2** (`notification_recipients_2`, text): Provide recipients for the second notification. 
* **Action Name 2** (`action_name_2`, text): Give a name to the second action. 
* **Threshold Value 2** (`threshold_value_2`, number): Set the threshold value for the second condition. 
* **Threshold Unit 2** (`threshold_unit_2`, select_one): Set the unit for the second threshold value. 
* **Frequency 2** (`frequency_2`, select_one): Select whether the second threshold should be checked frequently or not. 
* **Notification Method 3** (`notification_method_3`, select_one): Choose an alternative method for sending notifications when the condition is met. 
* **Action 3** (`action_3`, select_multiple): Select one or more actions to be performed when the condition is met. 
* **Action Name 3** (`action_name_3`, text): Provide a name for the third action. 
* **Threshold Value 3** (`threshold_value_3`, number): Set the threshold value for the third condition. 
* **Threshold Unit 3** (`threshold_unit_3`, select_one): Set the unit for the third threshold value. 
* **Frequency 3** (`frequency_3`, select_one): Select whether the third threshold should be checked frequently or not.
