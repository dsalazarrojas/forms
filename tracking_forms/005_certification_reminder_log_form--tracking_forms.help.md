# Certification Reminder Log Form - Help Guide
## Purpose
The Certification Reminder Log Form is designed to track certifications and their associated details, ensuring timely reminders and updates on renewal status.
## How To Complete This Form
To fill out the form correctly, follow these steps:
  1. Select the relevant certification category from the options provided.
  2. Enter the full name of the certification and its unique code or ID.
  3. Choose the issuing organization responsible for granting this certification.
  4. Select the department responsible for managing this certification.
  5. Set the current expiration date for the certification.
  6. Select the frequency at which reminders should be sent.
  7. Enter the date of the last reminder sent for this certification.
  8. If applicable, enter the estimated renewal fee and the total CEU hours required for renewal.
  9. Update the current renewal status and any relevant notes.
  10. Enter the current date as the date of the last log entry.
## Field-by-Field Explanation
* **Certification Name** (id: 2, label: Certification Name, type: text, required: true): Enter the full name of the certification to be logged.
* **Certification Code or ID** (id: 3, label: Certification Code or ID, type: text, required: true): Enter the unique code associated with this certification.
* **Certification Category** (id: 4, label: Certification Category, type: select_one, required: true): Select the category of the certification from the provided options.
* **Issuing Organization** (id: 5, label: Issuing Organization, type: text, required: true): Enter the body that grants this certification.
* **Renewal Owner Name** (id: 7, label: Renewal Owner Name, type: text, required: true): Enter the person responsible for managing the renewal process.
* **Owner Email Address** (id: 8, label: Owner Email Address, type: email, required: true): Enter the email address for reminder notifications.
* **Department Responsible** (id: 9, label: Department Responsible, type: select_one, required: true): Select the department this certification belongs to from the options provided.
* **Current Expiration Date** (id: 11, label: Current Expiration Date, type: date, required: true): Set the date the current certification expires.
* **Reminder Frequency** (id: 12, label: Reminder Frequency, type: select_one, required: true): Select the frequency at which reminders should be sent from the options provided.
* **Last Reminder Sent Date** (id: 13, label: Last Reminder Sent Date, type: date, required: false): Enter the date of the last reminder sent for this certification, if applicable.
* **Estimated Renewal Fee** (id: 15, label: Estimated Renewal Fee, type: number, required: false): If applicable, enter the cost associated with the renewal process.
* **Continuing Education Required?** (id: 16, label: Continuing Education Required?, type: select_one, required: true): Select if this certification requires CEUs for renewal.
* **Total CEU Hours Needed** (id: 17, label: Total CEU Hours Needed, type: number, required: false): Enter the number of hours required if continuing education is necessary.
* **Current Renewal Status** (id: 18, label: Current Renewal Status, type: select_one, required: true): Select the status of the renewal process for this cycle.
* **Tracking Log Notes** (id: 19, label: Tracking Log Notes, type: text, required: false): Enter any additional information or issues encountered while tracking this certification.
* **Date of Last Log Entry** (id: 20, label: Date of Last Entry, type: date, required: true): Enter the current date as the date of the last log entry.
