# Inventory Depletion Report Log - Help Guide
## Purpose
This form is used to log and track inventory depletion reports for the purpose of maintaining accurate inventory records and facilitating better decision-making.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "write_off_date_1" field to enter the date of the inventory depletion event.
2. Choose the "stock_item_1" field to select the stock item that was depleted.
3. Enter the "quantity_1" field with the exact quantity of the stock item that was depleted.
4. Select the "reason_1" field to specify the reason for the inventory depletion.
5. Choose the "location_1" field to select the location where the inventory depletion occurred.
6. Enter any additional notes about the event in the "notes_1" field.

## Field-by-Field Explanation
* **write_off_date_1**: Select the date on which the inventory depletion event occurred. (Type: date)
* **stock_item_1**: Choose the stock item that was depleted from the dropdown menu. (Type: select_one)
* **quantity_1**: Enter the exact quantity of the stock item that was depleted. (Type: number)
* **reason_1**: Select all applicable reasons for the inventory depletion from the dropdown menu. (Type: select_multiple)
* **location_1**: Choose the location where the inventory depletion occurred from the dropdown menu. (Type: select_one)
* **notes_1**: Enter any additional notes or comments about the inventory depletion event. (Type: note)
* **assigned_tool_1**: Enter any tools or equipment used during the inventory depletion event. (Type: text)
* **created_by_1**: Enter the name of the person responsible for completing this form. (Type: text)
