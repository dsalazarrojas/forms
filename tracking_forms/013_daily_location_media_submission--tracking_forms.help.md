# daily_location_media_submission - Help Guide
## Purpose
The purpose of this form is to collect daily data on media presence in a specific location, allowing users to track changes over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date you are submitting data for using the "media_date" field.
2. Enter the location where you observed media presence using the "location" field.
3. Indicate whether media presence was observed (yes/no) using the "media_type" field.
4. Provide the URL of any media you observed using the "media_url" field (if applicable).
5. Enter any additional observations or notes you have about the media presence using the "observation" field.

## Field-by-Field Explanation
* **media_date** (`media_date`, date, required: false): Enter the date of your observation in the format "YYYY-MM-DD" (e.g. 2022-01-01).
* **location** (`location`, text, required: false): Type in the name of the location where you observed media presence.
* **media_type** (`media_type`, select_one, required: false): Choose "Yes" if media presence was observed, "No" if not.
* **media_url** (`media_url`, text, required: false): If the media presence you observed has a URL, enter it here.
* **observation** (`observation`, text, required: false): Enter any additional comments or notes about the media presence you observed.

## Tips
* Make sure to submit data for the correct date to ensure accurate tracking of changes over time.
* If you're unsure about any of the fields, feel free to reach out to your supervisor or project lead for guidance.
