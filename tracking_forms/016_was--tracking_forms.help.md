# WAS - Help Guide
## Purpose
The WAS form is used to track the progress and comments of teams. It captures team names, start dates for weeks, director comments, team comments, team name labels, and week numbers.

## How To Complete This Form
1. Ensure you have all the necessary information for the team and week you are tracking.
2. If the team is already being tracked, confirm you want to add the new team information.
3. Complete each field as described below.

## Field-by-Field Explanation
* **Team name**: Enter the name of the team you are tracking. This is a required field.
* **Week start date**: Enter the start date of the week you are tracking. If left blank, the current date will be assumed. This field is optional.
* **Director comments**: Enter any comments or notes from the director. This field is required.
* **Team comments**: Enter any comments or notes from the team. This field is optional.
* **Team name label**: If you want to label the team name, enter a short description here. This field is optional.
* **Week number**: Enter the week number you are tracking. This field is optional.

## Tips
* Please ensure to complete all required fields before submitting the form.
* Use the correct format for each field (e.g., date format for week start date).
* If you are unsure about any field, consult with your team or the system administrator.
