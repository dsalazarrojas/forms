## Facility Access Log - Help Guide

## Purpose
This form is used to track access records of personnel within facilities. It helps facility administrators to maintain accurate records of who accessed or exited the facility and at what time.

## How To Complete This Form
1. Select whether this is an entry or exit (Step 1: Entry or Exit).
2. Choose whether you have high or low access level (Step 2: Access Level).
3. Select all applicable options from the "First Page" dropdown (Step 1: First Page).
4. Enter the facility name or ID (Step 2: Facility Details).
5. Type in the personnel's name (Step 5: Personnel Name).
6. Type in the department name (Step 6: Department).
7. Choose a date for the access event (Step 7: Date).
8. Type in the time the person entered the facility (Step 8: Time in).
9. Type in the time the person exited the facility (Step 9: Time out).
10. Add any comments about the access event (Step 10: Comments).
11. Enter a unique Facility Access Log ID (Step 11: Facility Access Log ID).
12. Enter a unique Facility ID (Step 12: Facility ID).
13. Enter a unique User ID (Step 13: User ID).

## Field-by-Field Explanation

* **First Page** (`Step 1: First Page`, select_multiple, required): This field allows you to choose the access event details from a list of options.
* **facility_details** (`Step 2: Facility Details`, text, required): Enter the name or ID of the facility where the access event occurred.
* **Entry or Exit** (`Step 2: Entry or Exit`, select_one, required): Choose whether this is an entry or exit event.
* **access_level** (`Step 3: Access Level`, select_multiple, required): Select all applicable access levels for this access event (High or Low).
* **Personnel Name** (`Step 5: Personnel Name`, text, required): Type in the name of the person who accessed or exited the facility.
* **Department** (`Step 6: Department`, text, required): Enter the department name of the person who accessed or exited the facility.
* **Date** (`Step 7: Date`, date, required): Choose the date of the access event.
* **Time in** (`Step 8: Time in`, time, required): Type in the time the person entered the facility.
* **Time out** (`Step 9: Time out`, time, required): Type in the time the person exited the facility.
* **Comments** (`Step 10: Comments`, text, required): Add any comments about the access event.
* **Facility Access Log ID** (`Step 11: Facility Access Log ID`, text, required): Enter a unique ID for this access event.
* **Facility ID** (`Step 12: Facility ID`, text, required): Enter the ID of the facility where the access event occurred.
* **User ID** (`Step 13: User ID`, text, required): Enter the ID of the user who accessed or exited the facility.

Note: All fields with a required status of "true" are marked with an asterisk (*) for emphasis.
