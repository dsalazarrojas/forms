# First Notice Of Loss Form - Help Guide
## Purpose
The "First Notice Of Loss Form" is a template for reporting a loss event to an insurance company or insurer. This form is used to gather information about the loss event, including date, time, location, and details about the insured and insurer.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the notice date and time fields to report when the loss occurred.
2. Provide a detailed description of what happened in the description field.
3. Select the type of loss from the options provided.
4. Enter the loss date and time if different from the notice date and time.
5. Enter the name and contact information of the insured and insurer as required.
6. Fill in the loss amount field with the actual amount of the loss.
7. Enter the location of the loss, if applicable.
8. Select the type of insured and enter any relevant details.
9. Enter the contact information for the insurer.
10. Provide any additional remarks or notes as needed.

## Field-by-Field Explanation

* **Notice Date** (`notice_date`, date, required false): Enter the date when the loss occurred.
* **Notice Time** (`notice_time`, time, required false): Enter the time when the loss occurred.
* **Notice Location** (`notice_location`, text, required false): Enter the location where the loss occurred, if applicable.
* **Description** (`notice_description`, text, required false): Provide a detailed description of the loss event.
* **Notice Loss Type** (`notice_loss_type`, select_one, required true): Select the type of loss from the provided options.
* **Loss Date** (`notice_loss_date`, date, required false): Enter the date of the loss, if different from the notice date.
* **Loss Time** (`notice_loss_time`, time, required false): Enter the time of the loss, if different from the notice time.
* **Insured** (`notice_insured`, text, required false): Enter the name of the insured.
* **Insurer** (`notice_insurer`, text, required false): Enter the name of the insurer.
* **Loss Amount** (`notice_loss_amount`, number, required false): Enter the actual amount of the loss.
* **Loss Location** (`notice_loss_location`, text, required false): Enter the location of the loss, if applicable.
* **Insured Type** (`notice_insured_type`, text, required false): Select or enter the type of insured.
* **Insurer Phone** (`notice_insurer_phone`, text, required false): Enter the phone number of the insurer.
* **Insurer Email** (`notice_insurer_email`, email, required false): Enter the email of the insurer.
* **Insurer Address** (`notice_insurer_address`, text, required false): Enter the address of the insurer.
* **Insured Address** (`notice_insured_address`, text, required false): Enter the address of the insured.
* **Insurer Website** (`notice_insurer_website`, text, required false): Enter the website of the insurer.
* **Insured Website** (`notice_insured_website`, text, required false): Enter the website of the insured.
* **Insurer Remarks** (`notice_insurer_remarks`, text, required false): Enter any remarks about the insurer.
* **Insured Remarks** (`notice_insured_remarks`, text, required false): Enter any remarks about the insured.
* **Notes** (`notice_insurer_notes`, text, required false): Enter any additional notes about the insurer.
