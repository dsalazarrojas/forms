# Budget Limit Settings - Help Guide

## Purpose

This form is used to create and manage budget limits for various departments or categories. It helps to establish monetary limits for specific periods, such as monthly, quarterly, or annual, and captures relevant details like setting names, departments, and approvers.

## How To Complete This Form

1. To begin, select the "Setting name" field to enter a unique identifier for this budget limit.
2. In the "Department" field, select the department this budget limit applies to.
3. Enter the monetary "Limit amount" in the specified format.
4. Choose the "Period" for this budget limit from the available options (Monthly, Quarterly, or Annual).
5. Select the "Approver" who is authorized to approve exceptions to this budget limit.
6. Optionally, specify the "Notification threshold" as a percentage to trigger notifications.
7. Provide additional "Notes" about this setting if necessary.
8. If required, describe the "Override procedure" to request an exception.

## Field-by-Field Explanation

* **Setting name** (Text, required): Enter a unique identifier for this budget limit.
* **Department** (Text, required): Select the department this budget limit applies to.
* **Limit amount** (Number, required): Enter the monetary limit value for this budget period.
* **Period** (Select One, required): Choose the period this budget limit covers (Monthly, Quarterly, or Annual).
* **Approver** (Text, required): Select the person authorized to approve exceptions to this budget limit.
* **Notification threshold** (Number, optional): Set the percentage threshold to trigger notifications.
* **Override procedure** (Text, optional): Describe the steps to request an exception to this budget limit.
* **Notes** (Text, optional): Add any additional details about this setting.
