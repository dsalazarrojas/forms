# Shipping Load Report Form - Help Guide

## Purpose
The Shipping Load Report Form is designed for tracking and reporting shipment details, allowing users to input various information about shipments, including dates, IDs, locations, and other relevant data.

## How To Complete This Form

1. Select the applicable fields from the form.
2. Enter or select the required information for each field.
3. Ensure that you fill out all the fields as required or as necessary for your report.

## Field-by-Field Explanation

* **Pickup Date (1)**: Enter the date the shipment was picked up.
* **Shipment ID (2)**: Enter the unique ID of the shipment.
* **Trailer Number (3)**: Enter the number of the trailer used for the shipment.
* **Prophet (4)**: Select one or more prophets who were part of the shipment.
* **Delivery Date (5)**: Enter the date the shipment was delivered.
* **Warehouse Location (6)**: Select the location where the shipment was stored.
* **Carrier ID (7)**: Enter the ID of the carrier used for the shipment.
* **Shipment Weight (8)**: Enter the weight of the shipment.
* **Shipment Status (9)**: Select the current status of the shipment (In Transit, Delivered, Picked Up).
* **Notes (10)**: Add any additional notes or comments about the shipment.
* **Phone (11)**: Enter the contact phone number for the shipment.
* **Email (12)**: Enter the contact email address for the shipment.
* **Assigned Tool (13)**: Indicate if the shipment was assigned a specific tool.
* **Assigned User (14)**: Indicate if the shipment was assigned a specific user.
* **More Notes (15)**: Add any additional notes about the shipment.
* **Delivery Method (16)**: Indicate if the shipment was delivered via a specific method.
* **Shipment Type (17)**: Indicate the type of shipment.
* **Shipment Date Range (18)**: Select the dates range for which the shipment occurred.
* **Another Prophet (19)**: Select one or more additional prophets who were part of the shipment.

## Tips
* Ensure that you fill out all the required fields accurately and completely.
* Use the form for tracking and reporting shipment details.
* Refer to the shipment status and weight fields for real-time updates.
* Review the form regularly for accuracy and completeness of data.
