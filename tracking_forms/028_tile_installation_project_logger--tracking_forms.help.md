# Tile Installation Project Logger - Help Guide
## Purpose
The Tile Installation Project Logger form is designed to track and manage tile installation projects, providing a centralized platform for recording and updating project details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (*) symbol, with the relevant information for each project.
2. Enter the project status as "Active", "Inactive", or "Completed" to reflect the current project state.
3. Select the job type from the available options (Wall, Floor, Ceiling, or Other).
4. Choose the tile type from the options (Porcelain, Ceramic, Marble, Granite).
5. If necessary, enter multiple tile types separated by commas in the Tile Type field.
6. Enter the job number and client name as required.
7. Record the installation date and time if applicable.
8. Enter the job cost.
9. Provide detailed notes about the project.
10. Enter the contact person's name, phone number, email, and address.
11. Optionally, enter the tile color and size if applicable.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the tile installation project.
* **Job Start Date** (`job_start_date`, date, optional): Enter the date the project started, if applicable.
* **Job Start Time** (`job_start_time`, time, optional): Enter the time the project started, if applicable.
* **Job End Date** (`job_end_date`, date, required): Enter the date the project was completed.
* **Job End Time** (`job_end_time`, time, optional): Enter the time the project was completed, if applicable.
* **Project Status** (`project_status`, select_one, required): Choose the current project status (Active, Inactive, Completed).
* **Client Name** (`client_name`, text, required): Enter the client's name.
* **Job Number** (`job_number`, text, optional): Enter the job number, if applicable.
* **Job Type** (`job_type`, select_one, required): Select the job type (Wall, Floor, Ceiling, Other).
* **Tile Type** (`tile_type`, select_multiple, required): Choose the tile type(s) (Porcelain, Ceramic, Marble, Granite).
* **Installation Date** (`installation_date`, date, optional): Enter the installation date, if applicable.
* **Installation Time** (`installation_time`, time, optional): Enter the installation time, if applicable.
* **Job Cost** (`job_cost`, number, required): Enter the job cost.
* **Notes** (`notes`, note, required): Provide detailed notes about the project.
* **Contact Name** (`contact_name`, text, required): Enter the contact person's name.
* **Contact Phone** (`contact_phone`, text, required): Enter the contact person's phone number.
* **Contact Email** (`contact_email`, email, required): Enter the contact person's email address.
* **Contact Address** (`contact_address`, text, required): Enter the contact person's address.
* **Tile Color** (`tile_color`, text, optional): Enter the tile color, if applicable.
* **Tile Size** (`tile_size`, text, optional): Enter the tile size, if applicable.
