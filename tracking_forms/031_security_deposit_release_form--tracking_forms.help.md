# Security Deposit Release Form - Help Guide
## Purpose
The Security Deposit Release Form is used to document the release of a security deposit from a tenant to a landlord. 

## How To Complete This Form
To complete the form, simply fill in the required information in each field. 

## Field-by-Field Explanation
* **Tenant Submission** (`tenant_submission`, text, required: false): This field is used for the tenant to submit their information, including their name and any other relevant details.
* **Landlord Return** (`landlord_return`, text, required: false): This field is for the landlord to confirm receipt of the security deposit release.
* **Date Returned** (`date_returned`, date, required: false): This field is used to record the date the security deposit was returned to the tenant. 

## Tips
* Ensure that the tenant's signature is provided for verification. 
* Make sure to keep a copy of the completed form for record-keeping purposes.
