# Mabc Rmlp Placement Tracking Form - Help Guide

## Purpose
The Mabc Rmlp Placement Tracking Form is a tool used to track and record information about MABC RMLP placements. This form is designed to gather data on the status of placements, locations, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct options for each field as requested.
2. Enter the required dates and times in the correct format (dd/mm/yyyy for dates, HH:MM for times).
3. Select multiple options for fields that allow multiple selections.

## Field-by-Field Explanation
### 1. **placement tracking form 1** (`mabc_rmlp_placement_tracking_form_1`, select_one, required)
This field is a dropdown menu with two options: "Yes" and "No". Select the correct option to indicate the status of the placement.

### 2. **locum name** (`locum_name`, text, required)
Enter the locum name as it appears on the relevant medical record.

### 3. **start date** (`start_date`, date, required)
Enter the start date of the placement in the format dd/mm/yyyy.

### 4. **start time** (`start_time`, time, required)
