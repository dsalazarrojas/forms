# Inventory Import Issue Contact Form - Help Guide

## Purpose
This form is used to report any issues or discrepancies encountered during the inventory import process. Please fill out the form below to help us identify and address the problem efficiently.

## How To Complete This Form
To report an issue, simply follow these steps:

1. Fill out the required fields, marked with an asterisk (*).
2. Select the relevant option from the 'sku' field to specify the specific stock keeping unit affected by the issue.
3. Choose a date to report when the issue occurred.
4. If necessary, include any supporting documents or explanations in the 'attachment' field.
5. Click the 'Submit' button to send your report to our team for review.

## Field-by-Field Explanation

* **form_1_label (text)**: * This is the title of the form, which should not be filled out as it is a system-generated label.
* **sku (select_one)**: * Choose the specific stock keeping unit (SKU) affected by the issue. This will help us to locate the specific product with the problem. Options:
	+ Option 1
	+ Option 2
	+ Option 3
* **date (date)**: * Report the date when the issue occurred.
* **attachment (text)**: * If you have any supporting documents or explanations, upload them here. This can be a screenshot, log file, or any other relevant file. 
* **(no label, as no label provided in YAML)**: * Please enter any additional information or comments related to the issue.
