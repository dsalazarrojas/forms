# User Story Template - Help Guide

## Purpose
This form is for creating, editing, or searching User Stories, which are essential in Agile project management for capturing and tracking feature or requirement descriptions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title and description of your User Story in the respective fields.
2. Select relevant tags for your User Story from the list of provided options.
3. Choose the priority level of your User Story from the available options.
4. Select the users assigned to the User Story from the list.
5. Choose the start date and time of your User Story.
6. Set the duration of your User Story.
7. Select the status of your User Story from the available options.
8. Provide any comments for the User Story.
9. Decide on the export options for your User Story, including file type and name.

## Field-by-Field Explanation

* **story_title** (Text, Required/Optional): Enter a brief title for your User Story.
* **story_description** (Text, Required/Optional): Write a detailed description of your User Story.
* **story_points** (Text, Required/Optional): Add any relevant points related to your User Story.
* **story_tags** (Select One, Required/Optional): Choose relevant tags for your User Story from the provided options.
* **story_priority** (Number, Required/Optional): Select a priority level for your User Story from the available options.
* **story_priority_value** (Text, Required/Optional): Enter a value for your User Story priority.
* **assigned_to** (Select Multiple, Required/Optional): Select the users assigned to your User Story from the list.
* **story_start_date** (Date, Required/Optional): Set the start date of your User Story.
* **story_start_time** (Time, Required/Optional): Set the start time of your User Story.
* **story_duration** (Time, Required/Optional): Set the duration of your User Story.
* **story_status** (Select One, Required/Optional): Choose the status of your User Story from the available options.
* **story_status_value** (Text, Required/Optional): Enter a value for your User Story status.
* **story_comments** (Text, Required/Optional): Provide any additional comments for your User Story.
* **story_export** (Note, Required/Optional): Decide on the export options for your User Story, including file type and name.
* **story_export_filename** (Text, Required/Optional): Enter a name for your exported User Story file.
* **story_export_filetype** (Select One, Required/Optional): Choose the file type for your exported User Story file.

## Tips
* Make sure to fill in all the required fields before submitting the form.
* Use the provided tags for accurate filtering and searching of User Stories.
* Double-check the priority and status of your User Story to ensure it meets the project requirements.
