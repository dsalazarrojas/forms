# Friendsgiving Event Survey - Help Guide
## Purpose
This form is designed to gather information about a Friendsgiving event, a social gathering where friends come together to celebrate the holiday season.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the following questions about the Friendsgiving event you attended.
2. For each field, select the correct options or enter the requested information.
3. Provide as much detail as possible in the open fields (Event Date, Event Time, Location, Organizer, Friends Invited, Food Served, and Suggestions).
4. Review your answers carefully and submit the form.

## Field-by-Field Explanation
* **Friendsgiving Event** (`friendsgiving_event_survey`, text, optional): This field is an open text input where you can describe the Friendsgiving event you attended.
* **Event Type** (`event_type`, select one, optional): Select the type of event that best describes the Friendsgiving event you attended. Options include:
	+ Friendsgiving
	+ Halloween
	+ Christmas
* **Date** (`event_date`, date, optional): Enter the date when the Friendsgiving event was held.
* **Time** (`event_time`, time, optional): Enter the start time of the event.
* **Location** (`event_location`, text, optional): Describe the location where the Friendsgiving event was held.
* **Organizer** (`event_organizer`, text, optional): Enter the name or description of the person who hosted the event.
* **Friends Invited** (`friends_invited`, select multiple, optional): Select the types of friends who attended the event. Options include:
	+ You
	+ Family
	+ Friends
	+ Coworkers
	+ Neighbors
	+ Others
* **Food Served** (`food_served`, select multiple, optional): Select the types of food that were served during the event. Options include:
	+ Turkey
	+ Mashed Potatoes
	+ Stuffing
	+ Vegetarian
	+ Vegan
	+ Others
* **Favorite Part** (`favorite_part`, text, optional): Describe your favorite part of the event.
* **Suggestions** (`suggestions`, text, optional): Provide any suggestions you have for future events.

## Tips
* Please answer the questions as accurately as possible.
* Provide as much detail as possible in the open fields.
* If you're unsure about any field, you can ask the event organizer for clarification.
* Submit the form carefully, as it will be used to gather insights about the event.
