# Thanksgiving Song Request - Help Guide
## Purpose
The Thanksgiving Song Request form is designed to collect information from attendees to create a custom playlist for the Thanksgiving event.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the "What is your favorite Thanksgiving song?" field with your personal preference.
2. If you would like to request a song to be played during the event, fill out the "What song would you like to hear on Thanksgiving?" field.
3. If you have a special request for this event, you can indicate this in the "Is there a special request for this event?" field.
4. Select the song you would like to hear on the event from the "Thanksgiving Song Request" dropdown menu.
5. If you need to contact the event organizer, fill out the "Contact Email" and "Contact Phone" fields.
6. If the event organizer has assigned you a playlist, indicate the assigned playlist in the "Assigned To" field.
7. If you are the event organizer, indicate who assigned you the playlist in the "Assigned By" field.
8. Finally, the "Created At" and "Updated At" fields are automatically populated and should not be edited.

## Field-by-Field Explanation
* **What is your favorite Thanksgiving song?** (`title`, `text`, required/optional): This field is where you can share your favorite song to be played during the Thanksgiving event.
* **Favorite singer?** (`favorite_singer`, `select_multiple`, required/optional): Select the singers you would like to hear during the event.
* **What song would you like to hear on Thanksgiving?** (`song_request`, `text`, required/optional): This field is where you can request a specific song to be played during the event.
* **Is there a special request for this event?** (`special_request`, `note`, required/optional): Indicate if you have a special request for the event.
* **Thanksgiving Song Request** (`thanksgiving_song_request`, `select_one`, required/optional): Choose a song you would like to hear on the event.
* **Contact Email** (`contact_email`, `email`, required/optional): If you need to contact the event organizer, provide your email address.
* **Contact Phone** (`contact_phone`, `text`, required/optional): If you need to contact the event organizer, provide your phone number.
* **Assigned To** (`assigned_to`, `text`, required/optional): If the event organizer has assigned you a playlist, indicate the name of the playlist.
* **Assigned By** (`assigned_by`, `text`, required/optional): If you are the event organizer, indicate who assigned you the playlist.
* **Created At** (`created_at`, `time`, required/optional): This field is automatically populated and should not be edited.
* **Updated At** (`updated_at`, `time`, required/optional): This field is automatically populated and should not be edited.
* **Assigned Tool** (`assigned_tool`, `text`, required/optional): This field is not intended to be used and should be left blank.
