# thanksgiving-buffet-dining-reservation - Help Guide

## Purpose
This form is designed to allow users to make reservations for a Thanksgiving buffet dinner. The form collects information about the holiday, start and end times, number of guests, reservation date, guest name, and guest email. This form will help the event organizers prepare for the event and ensure accurate headcount.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select a date for the event (Holiday) by choosing a date from the calendar.
2.  Choose a start time for the event by selecting a time of day.
3.  Choose an end time for the event by selecting a time of day.
4.  Enter the number of guests attending the event.
5.  Choose the date for the reservation.
6.  Enter the name of the guest making the reservation.
7.  Enter the email of the guest making the reservation.

## Field-by-Field Explanation
* **Holiday** (`holiday_datetime`, date, optional): Select a date for the event.
* **Start Time** (`reservation_start_time`, time, optional): Choose a start time for the event.
* **End Time** (`reservations_end_time`, time, optional): Choose an end time for the event.
* **Number of Guests** (`guests_count`, number, optional): Enter the number of guests attending the event.
* **Reservation Date** (`reservation_date`, date, optional): Choose the date for the reservation.
* **Guest Name** (`guest_name`, text, optional): Enter the name of the guest making the reservation.
* **Guest E-mail** (`guest_email`, email, optional): Enter the email of the guest making the reservation.

Note: All fields are optional, but providing accurate information will help the event organizers prepare for the event and ensure an accurate headcount.
