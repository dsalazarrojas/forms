# Club Event Souvenir Production Order Form - Help Guide
## Purpose
This form is used to place an order for souvenirs to be produced for a specific event. It collects essential details such as order date, contact information, event details, souvenir type, quantity, unit cost, and payment method to ensure accurate production and timely delivery.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Review each field carefully to ensure accuracy before submitting.
3. Double-check the event date against the actual event schedule to avoid errors.
4. Select the correct souvenir item type from the options provided.
5. Enter the total quantity needed accurately.
6. Verify the unit cost per item with the event organizers.
7. Calculate the total order cost correctly (quantity × unit cost).
8. If applicable, provide size options and quantity breakdown.
9. Clearly indicate if custom design is required.
10. Ensure the production deadline is realistic and allows sufficient time for processing and production.
11. Select the agreed-upon payment method.

## Field-by-Field Explanation
### Order Date
**Order Date** (id: 1): <date> 
Enter the date the order is placed.

### Name of Person Placing Order
**Name of Person Placing Order** (id: 2): <text>
Enter the name of the person placing the order.

### Email Address
**Email Address** (id: 3): <email> 
Enter the email address of the person placing the order.

### Phone Number
**Phone Number** (id: 4): <text>
Enter the phone number of the person placing the order.

### Event Name
**Event Name** (id: 5): <text> 
Enter the name of the event these souvenirs are for.

### Event Date
**Event Date** (id: 6): <date> 
Enter the date of the event.

### Souvenir Item Type
**Souvenir Item Type** (id: 7): <select_one> 
Select the type of souvenir item from the options provided.

### Detailed Description
**Detailed Description** (id: 8): <text>
Enter a detailed description of the souvenir item, including color and design.

### Total Quantity Needed
**Total Quantity Needed** (id: 9): <number> 
Enter the total number of items needed.

### Unit Cost per Item
**Unit Cost per Item** (id: 10): <number> 
Enter the price per individual item.

### Total Order Cost
**Total Order Cost** (id: 11): <number> 
Calculate the total cost by multiplying the quantity by the unit cost.

### Size Options Needed
**Size Options Needed** (id: 12): <select_multiple> 
Select all sizes needed for the souvenir item.

### Size Breakdown
**Size Breakdown** (id: 13): <text>
Enter the quantity needed for each size selected.

### Custom Design Required
**Custom Design Required** (id: 14): <select_one> 
Indicate if custom design is required.

### Production Deadline
**Production Deadline** (id: 15): <date> 
Enter the date when the items are needed.

### Payment Method
**Payment Method** (id: 16): <select_one> 
Select the agreed-upon payment method.
