# Fundraiser For Elementary School PTA - Help Guide

## Purpose
The purpose of this form is to collect information about fundraisers for an Elementary School PTA, enabling the organization to track and manage fundraising events effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter the title of the fundraiser**: In the `Fundraiser For Elementary School PTA` field, type the name of the fundraiser.
2. **Select the category**: Choose one or more categories for the fundraiser from the dropdown menu.
3. **Describe the fundraiser**: Provide a brief description of the fundraiser in the `description` field.
4. **Choose the type of fundraiser**: Select one or more types for the fundraiser from the dropdown menu.
5. **Upload output file**: You can optionally upload a file related to the fundraiser.

## Field-by-Field Explanation

* **Fundraiser For Elementary School PTA** (text, required): Enter the title of the fundraiser, which should be a brief and descriptive name.
* **category** (select multiple, optional): Choose one or more categories for the fundraiser, which will help in organizing and tracking the types of events.
* **description** (text, optional): Provide a concise and clear description of the fundraiser, including its purpose, goals, and any relevant details.
* **fundraiser_type** (select multiple, optional): Select one or more types for the fundraiser, which will aid in further categorization and analysis.
* **output_file** (text, optional): Upload a file related to the fundraiser, if applicable.

## Tips

* Be concise and clear in your descriptions, as this will aid in better tracking and management.
* Use relevant categories and types to ensure that the fundraiser is easily identifiable.
* Upload files only when necessary, as this can save storage space and improve loading times.
