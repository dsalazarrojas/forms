# Fundraising Package Delivery Form - Help Guide

## Purpose

This form is used to track and manage the delivery of packages related to fundraising events or campaigns. It helps to ensure that packages are delivered correctly and efficiently.

## How To Complete This Form

1. Please fill out the form accurately and completely with the relevant information for the package being delivered.
2. Ensure that you are using the correct form for the specific package.

## Field-by-Field Explanation

* **User First Name** (`user_first_name`, `text`, optional): Enter the first name of the person receiving the package.
* **User Last Name** (`user_last_name`, `text`, optional): Enter the last name of the person receiving the package.
* **Email** (`email`, `email`, optional): Enter the email address of the person receiving the package, if applicable.
* **Order Date** (`order_date`, `date`, optional): Select the date the package was ordered.
* **Delivery Location** (`delivery_location`, `text`, optional): Enter the location where the package is to be delivered.
* **Delivery Time** (`delivery_time`, `time`, optional): Enter the time the package is scheduled to be delivered.
* **Package Details** (`package_details`, `text`, optional): Enter a brief description or details about the package being delivered.
* **Quantity Ordered** (`quantity_ordered`, `number`, optional): Enter the number of packages being delivered.
* **Delivery Status** (`delivery_status`, `select_one`, required): Select the current status of the package delivery from the options: Available, Not Available, or Pending.
* **Delivery Note** (`delivery_note`, `note`, optional): Enter any additional comments or notes about the package delivery.

## Tips

* Double-check that you're using the correct form for the specific package being delivered.
* Ensure that all required fields are completed before submitting the form.
* Use the "Delivery Status" field to keep track of the current status of the package delivery.
* Use the "Delivery Note" field for any additional comments or notes that may be helpful for the delivery team.
