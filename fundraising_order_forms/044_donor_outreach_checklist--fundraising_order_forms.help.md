# Donor Outreach Checklist - Help Guide
## Purpose
This form is used to gather information about donors, their contact details, and follow-up schedules to ensure effective communication and relationship building.

## How To Complete This Form
1. Review the donor's registration in the system to ensure they are already registered and have a clear outreach strategy.
2. Select the donor's contact information from the options provided.
3. Choose the frequency of follow-up communications (e.g., daily, weekly, monthly).
4. Choose the style of follow-up communications (e.g., call, email, mail).
5. Select the follow-up schedule date and time.
6. Add any necessary notes and follow-up notes for the donor.
7. Review and update the donor's segment and relationship status.

## Field-by-Field Explanation

* **Donor Outreach Form** (`donor_outreach_form`, text, optional): Enter a brief description of the donor outreach strategy.
* **Contact Information** (`contact_info`, select multiple, optional):
	+ **Phone**: Enter the donor's phone number.
	+ **Email**: Enter the donor's email address.
	+ **Address**: Enter the donor's mailing address.
	+ **Fax**: Enter the donor's fax number.
* **Donation Frequency** (`donation_frequency`, select one, optional):
	+ **One-time**: The donation is a one-time gift.
	+ **Repeating**: The donation is a recurring gift.
	+ **Annual**: The donation is annual.
* **Outreach Methods** (`outreach_methods`, select multiple, optional):
	+ **Mail**: Send mail communications to the donor.
	+ **Email**: Send email communications to the donor.
	+ **Phone**: Make phone calls to the donor.
	+ **In-person**: Meet with the donor in person.
* **Communication Channels** (`communication_channels`, select multiple, optional):
	+ **Facebook**: Send messages to the donor on Facebook.
	+ **Twitter**: Send messages to the donor on Twitter.
	+ **Email**: Send email communications to the donor.
	+ **Phone**: Make phone calls to the donor.
	+ **In-person**: Meet with the donor in person.
* **Donor Segment** (`donor_segment`, select one, optional):
	+ **Individual**: The donor is an individual.
	+ **Family**: The donor is a family.
	+ **Organization**: The donor is an organization.
* **Donor Relationship** (`donor_relationship`, select multiple, optional):
	+ **Friend**: The donor is a friend of the organization.
	+ **Volunteer**: The donor has volunteered with the organization.
	+ **Family Friend**: The donor is a family friend of the organization.
	+ **Donor**: The donor is a donor of the organization.
	+ **Board Member**: The donor is a board member of the organization.
* **Follow Up Methods** (`follow_up_methods`, select multiple, optional):
	+ **Mail**: Send mail communications to the donor.
	+ **Email**: Send email communications to the donor.
	+ **Phone**: Make phone calls to the donor.
	+ **In-person**: Meet with the donor in person.
* **Communication Style** (`communication_style`, select one, optional):
	+ **Formal**: The communication style is formal.
	+ **Informal**: The communication style is informal.
	+ **Casual**: The communication style is casual.
* **Communication Frequency** (`communication_frequency`, number, optional): Enter the frequency of follow-up communications (e.g., 1, 2, 3).
* **Follow Up Frequency** (`follow_up_frequency`, select one, optional):
	+ **Daily**: Follow up daily.
	+ **Weekly**: Follow up weekly.
	+ **Monthly**: Follow up monthly.
* **Follow Up Style** (`follow_up_style`, select one, optional):
	+ **Call**: Follow up with a call.
	+ **Email**: Follow up with an email.
	+ **Mail**: Follow up with mail.
* **Follow Up Note** (`follow_up_note`, note, optional): Add any follow-up notes for the donor.
* **Follow Up Status** (`follow_up_status`, select multiple, optional):
	+ **Pending**: The follow-up is pending.
	+ **Ongoing**: The follow-up is ongoing.
	+ **Completed**: The follow-up is completed.
* **Follow Up Date** (`follow_up_date`, date, optional): Enter the follow-up date.
* **Follow Up Time** (`follow_up_time`, time, optional): Enter the follow-up time.
* **Donor Segmentation** (`donor_segmentation`, select multiple, optional):
	+ **Individual**: The donor is an individual.
	+ **Family**: The donor is a family.
	+ **Organization**: The donor is an organization.
* **Relationship Status** (`relationship_status`, select multiple, optional):
	+ **Active**: The donor is active.
	+ **Inactive**: The donor is inactive.
	+ **Unknown**: The donor's relationship status is unknown.
* **Relationship Notes** (`relationship_notes`, note, optional): Add any relationship notes for the donor.
* **Follow Up Notes** (`follow_up_notes`, note, optional): Add any follow-up notes for the donor.
* **Notes** (`notes`, note, optional): Add any general notes for the donor.
* **Communication Notes** (`communication_notes`, note, optional): Add any communication notes for the donor.
* **Follow Up Schedules** (`follow_up_schedules`, select multiple, optional):
	+ **Daily**: The follow-up schedule is daily.
	+ **Weekly**: The follow-up schedule is weekly.
	+ **Monthly**: The follow-up schedule is monthly.
* **Follow Up Schedule Date** (`follow_up_schedule_date`, date, optional): Enter the follow-up schedule date.
* **Follow Up Schedule Time** (`follow_up_schedule_time`, time, optional): Enter the follow-up schedule time.

## Tips
* Make sure to review the donor's registration in the system before filling out this form.
* Ensure that the donor has a clear outreach strategy in place.
* Use the follow-up notes section to add any additional information about the donor.
* The follow-up schedule date and time should be set according to the donor's availability.
