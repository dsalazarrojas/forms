# Zoom Appointment Form - Help Guide
## Purpose
The Zoom Appointment Form is a tool used to collect information about a Zoom meeting or appointment.

## How To Complete This Form

### Page 1: Basic Information

* **Zoom Appointment Form**: Enter a title for the appointment. This is a required field.
* **Category**: Select the category for the appointment from the given options (e.g., Telecommuting Forms, Other). This field is optional.
* **Description**: Provide a brief description of the appointment. This field is optional.
* **Assigned Tool**: Enter the tool assigned for the appointment. This field is optional.
* **Form ID**: Enter a unique ID for the form. This field is optional.
