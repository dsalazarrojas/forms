# remote_work_ergonomic_assessment - Help Guide
## Purpose
The remote_work_ergonomic_assessment form helps you identify potential ergonomic risks in your workspace and provides insights for improvement.

## How To Complete This Form
To complete this form, follow these steps:
1. Review each field carefully and answer honestly.
2. Select the options that best describe your current work setup.
3. Fill out the form completely and accurately.

## Field-by-Field Explanation
* **Work From Home** (`work_from_home`, select_one, optional): This question helps us understand if you work from home. Select "Yes" if you work from home, and "No" if you don't.
* **Ergonomic Setup** (`ergonomic_setup`, select_multiple, optional): This question is to identify if you have a well-set up ergonomic equipment in your workspace. Select all the options that apply to you.
* **Monitor Distance** (`monitor_distance`, number, optional): This question helps you measure the distance between your eyes and the monitor, which is recommended to be between 20-25 inches. Enter the actual distance in inches.
* **Keyboard Use** (`keyboard_use`, select_one, optional): This question is to determine if you use a keyboard during work. Select "Yes" if you use a keyboard, and "No" if you don't.
* **Chair Adjustment** (`chair_adjustment`, select_one, optional): This question is to check if your chair is adjusted to a comfortable height. Select "Yes" if it is, and "No" if it's not.
* **Standing Desk Height** (`standing_desk_height`, number, optional): This question is to measure the height of your standing desk, if you have one. Enter the actual height in inches.
* **Monitor Angle** (`monitor_angle`, select_one, optional): This question is to determine if your monitor is at the recommended angle. Select "Yes" if it is, and "No" if it's not.
* **Keyboard Distance** (`keyboard_distance`, number, optional): This question is to measure the distance between your eyes and the keyboard, which is recommended to be between 20-25 inches. Enter the actual distance in inches.

## Tips
- Make sure to provide accurate information to get the most out of this form.
- If you're unsure about any field, refer to the recommended ergonomic guidelines.
- Take the results seriously and make adjustments to your workspace to minimize risks and improve productivity.
