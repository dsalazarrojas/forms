# Recruiting Activity Report Form - Help Guide

## Purpose
This form is designed to collect weekly recruiting data from field representatives. It's used to track and analyze the number of weekly recruitments, recruiting dials (phone or in-person meetings), and persons interviewed for each location. Please ensure that you only submit one report per week and do not duplicate any data.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant location from the provided options.
2. Enter the number of weekly recruitments for the selected location.
3. Enter the number of recruiting dials for the selected location.
4. Enter the number of persons interviewed for the selected location.

## Field-by-Field Explanation
* **Weekly Recruitments**: Enter the total number of new recruitments for the selected location for the week.
* **Recruiting Dials**: Enter the total number of phone or in-person meetings (dials) made by the field representative for the selected location for the week.
* **Persons Interviewed**: Enter the total number of persons interviewed by the field representative for the selected location for the week.

## Tips
- Please ensure that the data entered is accurate and up-to-date.
- If you have any issues with the form or data submission, contact your supervisor.
- If you have any feedback or suggestions for this form, please reach out to the development team.
- Only submit one report per week for each location to maintain data integrity.
