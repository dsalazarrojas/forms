# employee_equipment_issue_form - Help Guide
## Purpose
The employee_equipment_issue_form is used to report equipment issues that affect employees in the company.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the Issue Title field to provide a brief description of the issue.
2.  In the Describe Issue field, provide a detailed explanation of the issue.
3.  Select the type of equipment involved from the Equipment Type dropdown menu.
4.  Enter the equipment's ID, if available.
5.  Enter the employee's ID, if applicable.
6.  Choose the priority of the issue (Low, Medium, or High).
7.  Select the current status of the issue (New, In Progress, or Resolved).
8.  If applicable, select the assigned tool.

## Field-by-Field Explanation
*   **Issue Title**: A brief description of the issue being reported.
*   **Describe Issue**: A detailed explanation of the issue, including any relevant details that can help the IT department troubleshoot the problem.
*   **Equipment Type**: Select the type of equipment that is affected by the issue (e.g., Computer, Phone, or Printer).
*   **Equipment ID**: The specific ID of the equipment involved, if known.
*   **Employee ID**: The ID of the employee experiencing the issue, if applicable.
*   **Issue Priority**: Choose the priority of the issue based on its severity and impact (Low, Medium, or High).
*   **Issue Status**: Select the current status of the issue (New, In Progress, or Resolved).
*   **Assigned Tool**: If applicable, select the tool that has been assigned to resolve the issue.
