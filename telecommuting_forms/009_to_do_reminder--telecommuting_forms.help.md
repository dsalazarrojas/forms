# To Do Reminder - Help Guide
## Purpose
The "To Do Reminder" form is a tool for creating and managing tasks with deadlines and personal notes. It is designed to help users quickly generate a reminder template with the option to select multiple tasks, create a list of tasks, add personal notes, and set a deadline date.

## How To Complete This Form
1. Select the tasks you want to include in your reminder template by choosing the "Yes" option for each relevant task.
2. Type in a list of tasks in the "to_do_list" field, including any additional tasks not listed in the select options.
3. Add personal notes about each task in the "personal_notes" field.
4. Set a deadline date for each task in the "deadline_date" field, if applicable.

## Field-by-Field Explanation
* **Reminder Template** (`reminder_form`, `select_multiple`): Select the tasks you want to include in your reminder template.
* **List of Tasks** (`to_do_list`, `text`): Type in a list of tasks that are not included in the select options.
* **Personal Notes** (`personal_notes`, `note`): Add personal notes about each task to help you remember important details.
* **Deadline** (`deadline_date`, `date`): Set a deadline date for each task to stay on track.

## Tips
* Use the select options to quickly add commonly used tasks to your reminder template.
* Use the text field to add tasks that are not included in the select options or provide additional context.
* Use personal notes to keep important details about each task.
* Use the deadline date field to stay on track and ensure you don't miss important deadlines.
