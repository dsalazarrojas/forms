# IT Service Ticket Form - Help Guide
## Purpose
This form is for employees to report issues or problems experienced while working remotely or telecommuting. Report details about the issue, and the IT department will address it accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your Employee ID number or username.
2. Choose the category of the issue (e.g., IT, Other).
3. Select the person to whom the issue will be assigned (e.g., chatjimmy, other).
4. Choose the status of the issue (e.g., Open, In Progress, Closed).
5. Fill in any comments if necessary.
6. Optionally, provide a date the issue occurs or was noticed.
7. Fill out a brief description of the problem.
8. Optionally, provide a solution, if known.

## Field-by-Field Explanation

* **Employee ID**: Enter your Employee ID number or username for identification and access control.
* **Issue Date**: The date when the issue occurs or when the employee noticed it. If you don't know the exact date, enter the best approximation.
* **Issue Time**: The time when the issue occurs or when the employee noticed it. If you don't know the exact time, enter the best approximation.
* **Issue Details**: A detailed description of the problem you are experiencing.
* **Solution**: A brief description of any solution you may have found to the issue.
* **Category**: Choose the type of issue reported (e.g., IT, Other).
* **Assigned To**: Select who the issue will be assigned to from the provided list.
* **Status**: Choose the current status of the issue (e.g., Open, In Progress, Closed).
* **Comments**: Any additional comments or explanations to help the IT department understand the issue.
* **Submit Date**: The date the issue was submitted. This will be auto-filled by the system.

## Tips
* Please be as detailed as possible in the Issue Details field.
* Choose the correct Category and Assigned To options to ensure the issue is directed to the right person or team.
* Use the Status field to keep track of the issue's progress.
* If you have already found a solution, please include it in the Solution field.
* If you need help, don't hesitate to add comments to provide more context. 

Note: This guide is based on the provided form schema and is intended to be a general explanation. Adjustments may be necessary based on actual form functionality and requirements.
