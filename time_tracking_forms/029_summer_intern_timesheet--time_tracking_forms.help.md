# Summer Intern Timesheet - Help Guide
## Purpose
The Summer Intern Timesheet is a form used to track the time spent by summer interns on various projects and activities during their internship.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your start and finish times to track the hours you worked on a project.
2. Enter the name of the project you worked on.
3. Select the activities you performed during the project (e.g., "Task A", "Task B", etc.).
4. Enter your goals and any comments about your work.
5. List the tasks you completed during your project.
6. Enter the number of hours spent on the project.
7. Calculate the total project hours by entering the number of hours spent on the project.

## Field-by-Field Explanation
* **Start Time**: Enter the time you started working on a project. Please use 24-hour clock format (e.g., 09:00 for 9:00 AM).
* **Finish Time**: Enter the time you finished working on a project. Please use 24-hour clock format (e.g., 17:00 for 5:00 PM).
* **Lunch Break**: Enter the total time you took for lunch, if any. If you didn't take a lunch break, enter "0".
* **Project Name**: Enter the name of the project you worked on. This will help us track which projects you're working on.
* **Activities**: Select the activities you performed during the project (e.g., "Task A", "Task B", etc.). You can select multiple activities.
* **Goals**: Enter any goals or objectives you achieved during the project.
* **Tasks**: List the tasks you completed during the project.
* **Time Spent**: Enter the total number of hours you spent on the project.
* **Total Project Hours**: If prompted, enter the total hours spent on the project (calculated from the start and finish times).

# Tips
* Make sure to track your time accurately to ensure accurate reporting.
* Use the 24-hour clock format for start and finish times.
* If you have any questions or need assistance, please reach out to your supervisor or the project lead.
