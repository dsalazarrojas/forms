# Session Summary Tracking Log Form - Help Guide
## Purpose
The Session Summary Tracking Log Form is a tool used to track and monitor session-related information, including session dates, times, duration, attendees, topics, and notes.

## How To Complete This Form
1. Select the date of the session you are tracking.
2. Enter the start and end times of the session.
3. Choose the duration of the session start and end (in minutes).
4. Select the type of session (e.g., meeting, training, etc.).
5. Enter the number of attendees for the session.
6. Choose the topics covered during the session (select multiple as needed).
7. Add any additional notes about the session.

## Field-by-Field Explanation

* **Session Date** (`session_date`, `date`, required: false): Enter the date of the session you are tracking. This field is not required, but it's recommended to ensure accurate reporting.
* **Session Start Time** (`session_start_time`, `time`, required: false): Enter the start time of the session.
* **Session End Time** (`session_end_time`, `time`, required: false): Enter the end time of the session.
* **Session Start Duration** (`session_start_duration`, `number`, required: false): Enter the duration of the session start in minutes. This field is optional, but it's recommended for accurate reporting.
* **Session End Duration** (`session_end_duration`, `number`, required: false): Enter the duration of the session end in minutes. This field is optional, but it's recommended for accurate reporting.
* **Session Type** (`session_type`, `select_one`, required: false): Choose the type of session (e.g., meeting, training, etc.) from the provided options.
* **Session Attendee Count** (`session_attendee_count`, `number`, required: false): Enter the number of attendees for the session.
* **Session Topic** (`session_topic`, `select_multiple`, required: false): Choose multiple topics covered during the session from the provided options.
* **Session Notes** (`session_notes`, `note`, required: false): Add any additional notes about the session.

## Tips
* Be as accurate as possible when filling out the form to ensure reliable data.
* Use the form only for new sessions or updates to existing sessions to avoid duplication.
* If you're unsure about any field, refer to the form's purpose and field explanations above.
