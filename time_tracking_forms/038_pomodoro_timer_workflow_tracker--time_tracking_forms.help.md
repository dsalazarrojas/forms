# pomodoro_timer_workflow_tracker - Help Guide
## Purpose
This form is used to track and log individual Pomodoro timer sessions. It helps users to analyze their productivity and time management.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the session name to identify the session.
2. Enter the duration of the session in the session duration field.
3. Specify the focused work time in minutes for the session.
4. Enter the break time in minutes for the session.
5. Record the number of sessions completed.
6. Input the start and end time of the session.
7. Add any additional notes about the session.
8. Provide an email address and phone number for future contact (optional).

## Field-by-Field Explanation
* **Session name** (`session_name`, text, optional): Enter a name for the session to identify it.
* **Session duration** (`session_duration`, number, optional): Enter the total duration of the session in minutes.
* **Focused work time** (`focused_work_time`, number, optional): Enter the time spent working on focused work during the session in minutes.
* **Break time** (`break_time`, number, optional): Enter the break time taken during the session in minutes.
* **Sessions completed** (`sessions_completed`, number, optional): Record the total number of sessions completed.
* **Session start time** (`start_time`, date, optional): Input the start date and time of the session.
* **Session end time** (`end_time`, time, optional): Input the end date and time of the session.
* **Session notes** (`session_notes`, note, optional): Add any notes about the session for future reference.
* **Email** (`email`, email, optional): Provide an email address for future contact (if applicable).
* **Phone** (`phone`, text, optional): Provide a phone number for future contact (if applicable).
