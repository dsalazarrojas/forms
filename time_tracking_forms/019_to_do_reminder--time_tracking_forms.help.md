# To Do Reminder - Help Guide
## Purpose
The "To Do Reminder" form is designed to help you track and organize tasks with their respective deadlines. It's a simple, user-friendly way to keep track of tasks and stay on top of your work.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the form (optional but recommended for reference).
2. Choose a deadline date for the task(s) you want to track.
3. Select a deadline time for the task(s) you want to track.
4. List the tasks you need to complete by choosing from the available options (Task 1, Task 2, Task 3).

## Field-by-Field Explanation
### **To Do Reminder (1)**
 * A brief description or title of the task you want to track (optional, but recommended for reference).

### **Deadline Date (2)**
 * The date by which you need to complete or have completed the task(s).

### **Deadline Time (3)**
 * The time of day by which you need to complete or have completed the task(s).

### **Task List (4)**
 * A list of tasks you need to complete. Select multiple tasks as needed from the options provided (Task 1, Task 2, Task 3).
