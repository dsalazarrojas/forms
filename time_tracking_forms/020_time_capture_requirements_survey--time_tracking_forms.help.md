# Time Capture Requirements Survey - Help Guide
## Purpose
The Time Capture Requirements Survey is designed to collect information required for efficient time tracking and reporting.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill out each field accurately and completely.
2. Make sure to read the field explanation below each label to understand its purpose.
3. If you are unsure about any field, refer back to this guide for clarification.
4. Double-check your entries for accuracy before submitting the form.

## Field-by-Field Explanation

* **Project Name** (Project Lead, 1, **Required**)
Enter the name of the project you are working on.

* **Project Description** (Project Description, 2, **Required**)
Provide a brief description of the project.

* **Project Lead** (Project Lead, 3, **Required**)
Enter the email address of the project lead.

* **Project Manager** (Project Manager, 4, **Required**)
Select the project manager from the list below:
	+ Project Lead
	+ Project Manager

* **Team Lead** (Team Lead, 5, **Required**)
Select all relevant team leads from the list below:
	+ Team Lead
	+ Project Manager

* **Time Capture System Name** (Time Capture System Name, 6, **Required**)
Enter the name of the time capture system you are using.

* **Time Format** (Time Format, 7, **Required**)
Select the time format you are using:
	+ 24 hour format
	+ 12 hour format
	+ AM/PM format

* **Time Capture Period** (Time Capture Period, 8, **Required**)
Select the period for time capture:
	+ Daily
	+ Weekly
	+ Monthly

* **Time Entry Duration** (Time Entry Duration, 9, **Required**)
Enter the duration of time entries in minutes.

* **Time Entry Frequency** (Time Entry Frequency, 10, **Required**)
Select the frequency of time entries:
	+ Daily
	+ Weekly
	+ Monthly

* **Time Entry Time Zone** (Time Entry Time Zone, 11, **Required**)
Select the time zone for time entries:
	+ UTC-5
	+ UTC-8
	+ UTC-9
	+ UTC-10
	+ UTC-11
	+ UTC-12
	+ UTC-13
	+ UTC-14
	+ UTC-15

* **Time Entry Time Zone Offset** (Time Entry Time Zone Offset, 12, **Optional**)
Enter the time zone offset in minutes.

* **Time Entry Start Date** (Time Entry Start Date, 13, **Required**)
Enter the start date of the time entry.

* **Time Entry Start Time** (Time Entry Start Time, 14, **Required**)
Enter the start time of the time entry.

* **Time Entry End Date** (Time Entry End Date, 15, **Required**)
Enter the end date of the time entry.

* **Time Entry End Time** (Time Entry End Time, 16, **Required**)
Enter the end time of the time entry.

* **Time Entry Notes** (Time Entry Notes, 17, **Required**)
Provide any additional notes for the time entry.

* **Time Entry Tags** (Time Entry Tags, 18, **Required**)
Select all relevant tags for the time entry:
	+ Yes
	+ No

* **Time Entry Attachments** (Time Entry Attachments, 19, **Optional**)
Enter any attachments for the time entry.

* **Time Entry Comments** (Time Entry Comments, 20, **Optional**)
Provide any comments for the time entry.

* **Time Entry Private** (Time Entry Private, 21, **Optional**)
Enter a value for making a time entry private.

* **Time Entry Read Only** (Time Entry Read Only, 22, **Optional**)
Enter a value for making a time entry read-only.

* **Time Entry Require Comments** (Time Entry Require Comments, 23, **Optional**)
Enter a value for requiring comments on a time entry.

* **Time Entry Require Attachments** (Time Entry Require Attachments, 24, **Optional**)
Enter a value for requiring attachments on a time entry.

* **Reporting Frequency** (Reporting Frequency, 25, **Required**)
Select the frequency of reporting:
	+ Daily
	+ Weekly
	+ Monthly
