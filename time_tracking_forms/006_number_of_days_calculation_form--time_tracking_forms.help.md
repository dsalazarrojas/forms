# Number of Days Calculation Form - Help Guide
## Purpose
This form is designed to calculate the number of days between two dates. The user inputs the start and end dates, and the form outputs the result of the calculation.

## How To Complete This Form
1. Click on the "Start Date" field and select the start date from the calendar.
2. Click on the "End Date" field and select the end date from the calendar.
3. Select the desired "Period" and "Period Type" from the respective dropdown menus.
4. Click the "Submit" button to calculate and display the result.

## Field-by-Field Explanation

* **Start Date** (`start_date_input`, `date`, required): The start date for the calculation. Enter the date from which you want to calculate.
* **End Date** (`end_date_input`, `date`, required): The end date for the calculation. Enter the date to which you want to calculate.
* **Result** (`result`, `text`, optional): The result of the calculation.
* **Days Calculated** (`days_calculated`, `text`, optional): The number of days calculated.
* **Period** (`period`, `select_one`, optional): Select the desired time period (e.g., One Day, Two Days).
* **Period Type** (`period_type`, `select_one`, optional): Select the type of period (e.g., Business Days, Calendar Days).

## Tips
* Make sure to input the correct start and end dates to get an accurate calculation.
* Choose the correct period and period type to match your specific needs.
