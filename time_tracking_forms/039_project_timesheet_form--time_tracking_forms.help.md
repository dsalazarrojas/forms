# Project Timesheet Form - Help Guide
## Purpose
The Project Timesheet Form is a simple tool used to track and manage projects. It gathers information about project titles, descriptions, estimated and actual start and end dates, project status, and categories.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the project title and description in the corresponding fields.
2. Provide the estimated start and end dates for the project.
3. Enter the actual start and end dates for the project (if applicable).
4. Update the project status and category.

## Field-by-Field Explanation
* **Project Title** (`project_title`, text, optional): Enter a brief title for your project.
* **Task Description** (`task_description`, text, optional): Describe the project in a few words.
* **Estimated Start Date** (`estimated_start_date`, date, optional): Enter the estimated start date of the project.
* **Estimated End Date** (`estimated_end_date`, date, optional): Enter the estimated end date of the project.
* **Actual Start Date** (`actual_start_date`, date, optional): Enter the actual start date of the project (if the project has already started).
* **Actual End Date** (`actual_end_date`, date, optional): Enter the actual end date of the project (if the project has already been completed).
* **Project Status** (`project_status`, text, optional): Enter the current status of the project (e.g. "In Progress", "Completed", etc.).
* **Project Category** (`project_category`, text, optional): Choose a category for your project (e.g. "Software Development", "Marketing Campaign", etc.).

## Tips
* Make sure to provide accurate and up-to-date information about your project.
* Use the estimated dates to plan and schedule project timelines.
* Update the actual dates as soon as the project starts and finishes.
* Use the project status to track progress and completion.
* Choose a relevant category to help with project organization and filtering.
