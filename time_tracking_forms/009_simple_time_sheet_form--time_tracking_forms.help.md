# simple_time_sheet_form - Help Guide
## Purpose
The purpose of this form is to track employee time worked on various projects and tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's name in the `Employee Name` field.
2. Enter the hours worked by the employee in the `Hours Worked` field.
3. Select the date of work by using the calendar icon next to the `Work Date` field.
4. Enter the work time in the `Work Time` field.
5. Enter the employee's job title in the `Job Title` field.
6. Enter the work location in the `Work Location` field.
7. Enter the project name in the `Project` field.
8. Enter a brief description of the work done in the `Work Description` field.
9. (Optional) Enter the task name in the `Task` field.
10. Enter any additional comments about the work done in the `Comments` field.

## Field-by-Field Explanation
* **Employee Name (text)**: Enter the name of the employee as per company records.
* **Hours Worked (number)**: Enter the total hours worked by the employee for the day.
* **Work Date (date)**: Select the date of the workday using the calendar icon.
* **Work Time (time)**: Enter the time of work, in 24-hour format (e.g., 09:00 - 17:00).
* **Job Title (text)**: Enter the employee's job title or designation.
* **Work Location (text)**: Enter the location where the work was done (e.g., office, field, etc.).
* **Project (text)**: Enter the name of the project the employee was working on.
* **Work Description (text)**: Enter a brief description of the work done (e.g., tasks completed, meetings attended, etc.).
* **Task (text)**: Enter the task name if applicable.
* **Comments (text)**: Enter any additional comments about the work done.
