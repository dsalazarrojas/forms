# Volunteer Fire Department Run Log - Help Guide
## Purpose
This form is designed to record and document incidents responded to by the volunteer fire department. It captures key information about each incident, including the incident date, time, location, and outcome.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields as needed.
2. Enter the incident date in the `Incident Date` field. This is the date the incident occurred.
3. Enter the incident time in the `Incident Time` field. This is the time the incident occurred.
4. In the `Fire Department` field, select the correct fire department that responded to the incident.
5. In the `Incident Description` field, provide a brief description of the incident.
6. In the `Incident Outcome` field, select whether the incident was resolved or not.
7. In the `Incident Number` field, enter the unique number assigned to the incident.
8. In the `Incident Type` field, select the type of incident (e.g., fire, medical, etc.).
9. Review and submit the form to save the information.

## Field-by-Field Explanation

* **Incident Response**: This field is not applicable as it does not exist in the form schema.
* **Incident Details**: This field is a text area for additional information about the incident.
* **Fire Department**: Select the fire department that responded to the incident. This helps to identify the responding agency.
* **Incident Date**: Enter the date the incident occurred. Use the date format `YYYY-MM-DD`.
* **Incident Time**: Enter the time the incident occurred. Use the 24-hour format `HH:MM:SS`.
* **Incident Location**: Enter the location of the incident. This can be a street address, city, or other geographical location.
* **Incident Description**: Provide a brief description of the incident.
* **Incident Outcome**: Select whether the incident was resolved or not.
* **Fire Station Number**: Enter the number of the fire station that responded to the incident.
* **Response Date**: Enter the date the response was made.
* **Response Time**: Enter the time the response was made.
* **Response Location**: Enter the location where the response was made.
* **Incident Number**: Enter the unique number assigned to the incident.
* **Incident Type**: Select the type of incident (e.g., fire, medical, etc.).

## Tips
* Please ensure that all required fields are completed accurately and completely.
* Use the correct date and time formats when entering information in the `Incident Date` and `Incident Time` fields.
* Select the correct fire department and incident type from the options.
* Enter the correct incident number to avoid duplicates.
