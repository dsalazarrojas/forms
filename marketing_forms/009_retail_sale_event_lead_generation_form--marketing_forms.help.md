# Retail Sale Event Lead Generation Form - Help Guide

## Purpose
The Retail Sale Event Lead Generation Form is designed to help the sales team collect information about potential retail sale events and generate leads for these events.

## How To Complete This Form

- Fill out this form only for the purpose of generating leads for a specific event.
- Verify that the event is not already listed on the sales team's current lead generation projects.
- Provide accurate and detailed information about the event.
- Select "Customer", "Non-Customer", or "Both" for "Interested Parties" based on the event's target audience.

## Field-by-Field Explanation
### Event Date (id: 1)

*   **Event Date**: A calendar date on which the event is scheduled. Please provide the date in the format of MM/DD/YYYY.

### Event Time (id: 2)

*   **Event Time**: A time of day when the event will start. Please use 24-hour time format (HH:MM).

### Event Duration (id: 3)

*   **Event Duration**: A duration of the event in hours. For example, if the event will last for 4 hours, enter 4. If the event will last until a specific time, enter the total duration in hours.

### Store Name (id: 4)

*   **Store Name**: The name of the store where the event will take place.

### Event Location (id: 5)

*   **Event Location**: A detailed address or description of the event location. This could include the store address, a mall location, or a specific venue.

### Event Description (id: 6)

*   **prophets**: This field appears to be a placeholder or an error. Please enter a detailed description of the event.

### Event Category (id: 7)

*   **Event Category**: A category that best describes the type of event (e.g., "In-Store Event", "Pop-up", "Seasonal Sale").

### Interested Parties (id: 8)

*   **Interested Parties**: Select the type of customers or non-customers that this event is targeting ("Customer", "Non-Customer", "Both").
