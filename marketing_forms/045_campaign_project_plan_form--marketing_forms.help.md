# Campaign Project Plan Form - Help Guide

## Purpose
The Campaign Project Plan Form is a standardized form that collects essential information about a campaign project. This information is used to track and monitor project progress, and to ensure that projects are well-planned and executed.

## How To Complete This Form
1. To complete this form, fill out the required information for each field.
2. Enter the project's name in the "Project Name" field.
3. Identify the person responsible for delivering the project in the "Project Manager" field.
4. Outline the primary goals of the project in the "Objectives" field.
5. List major milestones and target dates in the "Key Milestones" field.
6. If required, specify the staff, budget, and tools needed for the project in the "Resources Required" field.
7. List the primary stakeholders involved in the project in the "Stakeholders" field.
8. Describe the key risks and mitigation plans for the project in the "Risk Assessment" field.
9. Define how success will be measured and achieved in the "Success Criteria" field.
10. If applicable, estimate the budget for the project in the "Budget Estimate" field.
11. Add any additional information about the project in the "Additional Notes" field.

## Field-by-Field Explanation
* **Project Name** (`project_name`, `text`, required): Enter the name of the campaign project.
* **Project Manager** (`project_manager`, `text`, required): Identify the person responsible for delivering the project.
* **Objectives** (`objectives`, `text`, required): Outline the primary goals of the project.
* **Key Milestones** (`key_milestones`, `text`, required): List major milestones and target dates.
* **Resources Required** (`resources_required`, `text`, optional): If required, specify the staff, budget, and tools needed for the project.
* **Stakeholders** (`stakeholders`, `text`, optional): List the primary stakeholders involved in the project.
* **Risk Assessment** (`risk_assessment`, `text`, optional): Describe the key risks and mitigation plans for the project.
* **Success Criteria** (`success_criteria`, `text`, required): Define how success will be measured and achieved in the project.
* **Budget Estimate** (`budget_estimate`, `number`, optional): If applicable, estimate the budget for the project.
* **Additional Notes** (`additional_notes`, `text`, optional): Add any additional information about the project.
