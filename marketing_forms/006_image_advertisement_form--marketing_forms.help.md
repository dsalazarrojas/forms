# Image Advertisement Form - Help Guide

## Purpose
The Image Advertisement Form is designed to create and manage image advertisements for marketing campaigns.

## How To Complete This Form
To complete this form, follow these steps:

1. Upload an image by filling in the "Upload Image" field.
2. Select an image from the "Select Image" field.
3. Enter a description in the "Description" field.
4. Add tags in the "Tags" field.
5. Set the start and end dates using the "Start Date" and "End Date" fields.
6. Set the budget using the "Budget" field and select the budget type from the "Select Budget Type" field.
7. Select the priority using the "Priority" field.
8. Select the status using the "Status" field.
9. Add comments in the "Comments" field.
10. Enter a URL in the "URL" field.
11. Set the height and width of the image using the "Height" and "Width" fields.
12. Select the image ratio using the "Select Image Ratio" field.
13. Select the image count using the "Select Image Count" field.
14. Select the target audience using the "Select Audience" field.
15. Select the language using the "Select Language" field.
16. Select the device using the "Select Device" field.
17. Select the budget type using the "Select Budget Type" field.
18. Select the device type using the "Select Device Type" field.

## Field-by-Field Explanation

* **Upload Image** (1, text, optional): Upload an image file to use for the advertisement.
* **Select Image** (3, select_one, optional): Choose an image from the provided options.
* **Description** (5, text, optional): Enter a brief description of the advertisement.
* **Tags** (6, text, optional): Add relevant tags to the advertisement.
* **Start Date** (7, date, optional): Set the start date of the advertisement.
* **End Date** (8, date, optional): Set the end date of the advertisement.
* **Budget** (9, number, optional): Enter the budget for the advertisement.
* **Select Budget Type** (10, select_multiple, optional): Choose the type of budget.
* **Priority** (11, text, optional): Set the priority of the advertisement.
* **Status** (12, select_one, optional): Choose the status of the advertisement.
* **Comments** (13, text, optional): Add comments to the advertisement.
* **URL** (14, text, optional): Enter the URL of the advertisement.
* **Height** (15, number, optional): Set the height of the image.
* **Width** (16, number, optional): Set the width of the image.
* **Select Image Ratio** (17, select_one, optional): Choose the image ratio.
* **Select Image Count** (18, select_one, optional): Choose the image count.
* **Select Audience** (19, select_multiple, optional): Choose the target audience.
* **Select Language** (20, select_multiple, optional): Choose the language of the advertisement.
* **Select Device** (21, select_multiple, optional): Choose the type of device to target.
* **Select Budget Type** (22, select_multiple, optional): Choose the budget type.
* **Select Device Type** (23, select_multiple, optional): Choose the device type.

**Tips**
