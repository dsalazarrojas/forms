# Fashion Buyer Preview RSVP Form - Help Guide
## Purpose
This form is designed to help fashion buyers preview an event by providing their name, event date and time, and other necessary details.

## How To Complete This Form
1. Please fill in the required fields to the best of your ability. Note that no field is marked as required, so you can choose what information you want to provide.
2. If you need help with a specific field, click on the label for an explanation.
3. Review your submission before submitting it.

## Field-by-Field Explanation
* **Event Name**: This field is for the name of the event you want to preview. Type in the name of the event as it appears on the promotional materials or website.
* **Event Date**: This field is for the date of the event you want to preview. Type in the date in the format mm/dd/yyyy, for example, 01/15/2022.
* **Event Time**: This field is for the time of the event you want to preview. Type in the time in the format 12:00 AM or 10:30 PM.
 
## Tips
- Double-check the event name, date, and time to ensure accuracy.
- Use the correct date and time format for the fields mentioned.
- If you're unsure about any field, feel free to ask for clarification.
