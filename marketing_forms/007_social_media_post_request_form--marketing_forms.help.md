# Social Media Post Request Form - Help Guide
## Purpose
This form is used to submit a request for a social media post that will be created based on the information provided. It will help our marketing team to create a relevant and engaging social media post for our social media marketing campaigns.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the Coworker Name field with the name of the person responsible for the social media post.
2. Select the Department field with the department that the coworker belongs to.
3. Enter the Post Request field with a brief description of the social media post request.
4. Choose the Social Media Platform field with the platform where the post will be published.
5. Enter the Post Text field with the text of the social media post.
6. If you want to add an image or video report, fill in the Image field with the file path or upload the file, and the Video Report field with the date of the report.
7. Fill in the Social Media Post Request ID field with the ID of the existing social media post request if you have it.
8. Fill in the Post ID field with the ID of the post if you already have one.
9. Select the Departmentalized Department field with the departments that the post will be shared with.
10. Enter the Social Media Request field with any additional information about the request.

## Field-by-Field Explanation
* **Coworker Name**: This field is required and should be filled with the name of the person responsible for the social media post.
* **Department**: This field is a dropdown menu where you can select the department that the coworker belongs to.
* **Post Request**: This field is a text field where you can enter a brief description of the social media post request.
* **Social Media Platform**: This field is a dropdown menu where you can select the social media platform where the post will be published.
* **Post Text**: This field is a text field where you can enter the text of the social media post.
* **Image**: This field is optional and can be filled with the file path or uploaded file of the image.
* **Video Report**: This field is optional and can be filled with the date of the video report if required.
* **Social Media Post Request ID**: This field is optional and can be filled with the ID of the existing social media post request if you already have one.
* **Post ID**: This field is optional and can be filled with the ID of the post if you already have one.
* **Departmentalized Department**: This field is a dropdown menu where you can select the departments that the post will be shared with.
* **Social Media Request**: This field is a text field where you can enter any additional information about the request.

## Tips
* Please make sure to fill in all required fields to ensure that your request is processed correctly.
* If you already have an existing social media post request ID, please fill it in to avoid duplicating the request.
* If you already have a social media post ID, please fill it in to avoid confusion.
* If you have a video report, please fill in the Video Report field with the correct date.
* If you have any additional information about the request, please enter it in the Social Media Request field.
