# Media Coverage Quarterly Metrics Report Form - Help Guide

## Purpose
This form is designed to collect data on media coverage for a specific quarter. It helps track the performance of media impressions, engagement, and value across various social media channels.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields:
	* Media Metrics: Provide a brief description of the media coverage for the quarter.
	* Number of Earned Media Impressions (Current Quarter) and Number of Earned Media Impressions (Last Quarter): Enter the number of media impressions for the current and previous quarter.
	* Earned Media Value (Last Quarter): Enter the total value of media impressions for the last quarter.
	* Date of Publication: Enter the date when the media coverage was published.
	* Time of Publication: Enter the time when the media coverage was published.
	* Media Reach (Earned Media Impressions) (Last Quarter): Enter the total number of people reached by media impressions for the last quarter.
	* Media Reach (Earned Media Impressions) (Current Quarter) Percentage: Enter the percentage growth of media reach for the current quarter compared to the last quarter.
	* Media Reach (Earned Media Impressions) Growth: Select the growth rate of media reach for the current quarter.
	* Social Media Channels: Select the social media channels where the media coverage was published (e.g. YouTube, Facebook, Twitter, Instagram).
	* Social Media Engagement: Select the level of engagement on social media for the quarter (e.g. high, medium, low).
2. For social media channels, select the channels where the media coverage was published:
	* Earned Media Impressions YouTube, Earned Media Impressions Facebook, Earned Media Impressions Twitter, Earned Media Impressions Instagram, Earned Media Impressions Other.

## Field-by-Field Explanation

* **Media Metrics**: A brief description of the media coverage for the quarter.
* **Number of Earned Media Impressions (Current Quarter)**: The total number of media impressions for the current quarter.
	+ Please note that this is a required field.
* **Number of Earned Media Impressions (Last Quarter)**: The total number of media impressions for the previous quarter.
	+ This field helps to calculate the growth rate of media reach.
	+ Please note that this is a required field.
* **Number of Earned Media Impressions (Last Quarter) Percentage**: The percentage growth rate of media impressions for the last quarter.
* **Earned Media Value (Last Quarter)**: The total value of media impressions for the last quarter.
	+ Please note that this is a required field.
* **Date of Publication**: The date when the media coverage was published.
	+ Please use the format `YYYY-MM-DD`.
* **Time of Publication**: The time when the media coverage was published.
* **Earned Media Impressions (YouTube)**: The total number of media impressions on YouTube for the quarter.
* **Earned Media Impressions (Facebook)**: The total number of media impressions on Facebook for the quarter.
* **Earned Media Impressions (Twitter)**: The total number of media impressions on Twitter for the quarter.
* **Earned Media Impressions (Instagram)**: The total number of media impressions on Instagram for the quarter.
* **Earned Media Impressions (Other)**: The total number of media impressions on other channels for the quarter.
* **Media Reach (Earned Media Impressions) (Last Quarter)**: The total number of people reached by media impressions for the last quarter.
* **Media Reach (Earned Media Impressions) (Current Quarter) Percentage**: The percentage growth rate of media reach for the current quarter compared to the last quarter.
* **Media Reach (Earned Media Impressions) Growth**: The growth rate of media reach for the current quarter.
* **Social Media Channels**: Select the social media channels where the media coverage was published.
* **Earned Media Impressions (Facebook 2)**: The total number of media impressions on Facebook for the quarter.
* **Earned Media Impressions (Twitter 2)**: The total number of media impressions on Twitter for the quarter.
* **Earned Media Impressions (Instagram 2)**: The total number of media impressions on Instagram for the quarter.
* **Earned Media Impressions (Other 2)**: The total number of media impressions on other channels for the quarter.
* **Earned Media Value (Last Quarter)**: The total value of media impressions for the last quarter.
	+ Please note that this is a required field.
* **Media Reach (Earned Media Impressions) (Current Quarter) Percentage**: The percentage growth rate of media reach for the current quarter compared to the last quarter.
* **Social Media Engagement**: Select the level of engagement on social media for the quarter (e.g. high, medium, low).
* **Social Media Channels 1**: Select the social media channels where the media coverage was published.
* **Earned Media Impressions Facebook 2**: The total number of media impressions on Facebook for the quarter.
* **Earned Media Impressions Twitter 2**: The total number of media impressions on Twitter for the quarter.
* **Earned Media Impressions Instagram 2**: The total number of media impressions on Instagram for the quarter.
* **Earned Media Impressions Other 2**: The total number of media impressions on other channels for the quarter.

## Tips
- Make sure to complete all required fields.
- If you are unsure about any field, please contact the relevant authority for guidance.
- This form is designed to help track media coverage for a specific quarter, so please ensure that the data is accurate and up-to-date.
