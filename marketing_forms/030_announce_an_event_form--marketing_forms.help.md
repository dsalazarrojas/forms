# Announce An Event Form - Help Guide
## Purpose
The "Announce An Event Form" is designed for event organizers to submit information about their events, including event title, description, date, time, location, and ticketing details. The form is used to announce upcoming events to a specific audience.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the organizer's name and organization name in the respective fields.
2. Provide a valid email address for event confirmation.
3. Enter a phone number for contact purposes.
4. Enter a website URL for the organization (if applicable).
5. Provide the event title and description.
6. Choose the event category from the provided options.
7. Select the event start and end dates and times.
8. Choose the event location type (in-person, virtual, or hybrid).
9. Enter the venue name and address (if applicable).
10. Select the admission type (e.g., free admission, paid tickets required, donation-based).
11. Enter the ticket price (if applicable).
