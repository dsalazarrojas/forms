# Email Campaign Plan Form Template - Help Guide
## Purpose
This template is used to create a detailed plan for a marketing email campaign. It includes fields to define the campaign's goals, target audience, key message points, and communication channels.

## How To Complete This Form
1. Fill in the campaign's goals in the **Email Campaign Goals** field.
2. Select the target audience for the campaign from the **target_audience** field.
3. Choose one or multiple target segments from the **target_segments** field.
4. Enter the key message points for the campaign in the **Key Message Points** field.
5. Add additional key message points in the **Key Message Point 2** and **Key Message Point 3** fields.
6. Define the target audience location in the **Target Audience Location**, **Target Audience 2**, and **Target Audience 3** fields.
7. Set the campaign date, time, and duration in the **Date**, **Time**, and **Duration** fields.
8. Select the email channels to use for the campaign from the **Email Channels**, **Email Channels 2**, and **Email Channels 3** fields.
9. Choose the social media channels to use for the campaign from the **Social Media Channels**, **Social Media Channels 2**, and **Social Media Channels 3** fields.
10. Select the marketing channels to use for the campaign from the **Marketing Channels**, **Marketing Channels 2**, and **Marketing Channels 3** fields.
11. Enter the email lists to be used for the campaign in the **Email List**, **Email List 2**, **Email List 3**, and other **Email List** fields.
