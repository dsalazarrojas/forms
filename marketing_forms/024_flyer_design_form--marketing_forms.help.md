# Flyer Design Form - Help Guide
## Purpose
The Flyer Design Form is a tool designed to guide users through the process of creating a visually appealing and functional flyer. This form will help users input various parameters to create a well-designed flyer that effectively communicates their message.

## How To Complete This Form
1. Click on the "Start Designing" button to begin the flyer design process.
2. Fill out the required fields:
	* **Main Information** (`main_info`): Enter a brief description of the flyer, including its purpose and any relevant details.
3. Select the **Color Scheme** (`color_scheme`):
	* Choose from options: 'Yes' to apply a color scheme, 'No' not to apply.
4. Choose the background for the flyer (`background`):
	* Select from: red, blue, or green.
5. Determine the text style for the flyer (`text_style`):
	* Choose from: 'Yes' to apply a text style, 'No' not to apply.
6. Input the font size for the flyer (`font_size`):
	* Enter a numeric value (e.g., 10, 12, 14).
7. Select the font family for the flyer (`font_family`):
	* Choose from: 'Yes' to apply a font family, 'No' not to apply.
8. Determine the font weight for the flyer (`font_weight`):
	* Choose from: 'Yes' to apply a font weight, 'No' not to apply.
9. Choose the font type for the flyer (`font_type`):
	* Select from: 'Yes' to apply a font type, 'No' not to apply.
10. Select the content area for the flyer (`content_area`):
	* Choose from: 'Yes' to apply a content area, 'No' not to apply.
11. Input the content for the flyer (`content`):
	* Enter the text you want to display on the flyer.
12. Choose the colors for the flyer (`color_1`, `color_2`, `color_3`):
	* Select from: 'Yes' to apply each color, 'No' not to apply.
