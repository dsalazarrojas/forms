# Webinar Attendance Benchmark Report Request Form - Help Guide
## Purpose
This form is designed to collect information from users who want to receive a webinar attendance benchmark report. The report will help analyze and compare the attendance of different webinars, allowing users to gain insights and improve their future webinars.

## How To Complete This Form
To complete this form, follow these steps:

1. Read through the form carefully to ensure you understand what type of report you are requesting.
2. Decide whether you want to receive a webinar attendance benchmark report and select 'Yes' in the corresponding field.
3. If you select 'Yes', provide the necessary details for the report, such as the types of events the report should cover (e.g., Virtual events, Education events, Marketing events).
4. Choose the date and time of the webinar for which you want the report.
5. Submit the form to request the report.

## Field-by-Field Explanation
- **1. Webinar attendance benchmark report request form page 1**: This is the first page of the form and serves as a placeholder.
- **2. Request benchmark report**: Select 'Yes' to request a webinar attendance benchmark report. This report will help you compare the attendance of different webinars.
- **3. Benchmark report details**: If you selected 'Yes' for the previous field, enter the details for the report, such as which types of events you want the report to cover. You can select multiple options.
  * **Virtual events**: Select 'Yes' if you want the report to include virtual events.
  * **Education events**: Select 'Yes' if you want the report to include education events.
  * **Marketing events**: Select 'Yes' if you want the report to include marketing events.
- **4. Virtual events**: Select 'Yes' if the webinar is a virtual event.
- **5. Education events**: Select 'Yes' if the webinar is an education event.
- **6. Marketing events**: Select 'Yes' if the webinar is a marketing event.
- **7. Benchmark report request**: Select 'Yes' to confirm your request for the benchmark report.
- **8. Date and time of the webinar**: Enter the date and time of the webinar for which you want the report.
