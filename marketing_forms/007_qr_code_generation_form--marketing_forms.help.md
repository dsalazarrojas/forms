# QR Code Generation Form - Help Guide
## Purpose
The QR Code Generation Form is a tool used to create a QR code for events that you are hosting or will host. This form will guide you through the process of generating a QR code that you can use for promotional purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose whether you want to generate a QR code or not.
2. Fill out the relevant fields with your event details:
	* If yes, select one of the event details categories to fill out the required fields.
	* If no, click the "Submit" button without filling out any fields.

## Field-by-Field Explanation
* **QR code type**: Choose whether to generate a QR code ('Yes') or not ('No').
	* Please select 'Yes' if you want to generate a QR code.
	* Please select 'No' if you do not want to generate a QR code.
* **Event details**: Enter a short text about your event.
	* Please fill this field if you selected 'Yes' for QR code type.
* **Product info**: Enter a short text about the product related to your event.
	* This field is optional, but please fill it up if you want to provide more information about the product.
* **Event registration**: Enter a short text about event registration.
	* This field is optional, but please fill it up if you want to provide more information about event registration.
* **Customer info**: Enter a short text about your customer.
	* This field is optional, but please fill it up if you want to provide more information about your customer.
* **Event name**: Enter the name of your event.
	* Please fill this field to provide the name of your event.
* **Event start date**: Select the start date of your event.
	* Please select the start date of your event.
* **Event end date**: Select the end date of your event.
	* Please select the end date of your event.
* **Event time**: Select the time of your event.
	* Please select the time of your event.
* **Event location**: Enter the location of your event.
	* Please fill this field to provide the location of your event.
* **Event registration link**: Enter the link where your customers can register for your event.
	* This field is optional, but please fill it up if you want to provide more information about event registration.

## Tips
* Please make sure to fill out all the required fields to ensure a successful QR code generation.
* If you are having trouble with a particular field, please contact our support team for assistance.
* The generated QR code will be displayed after you submit the form.
