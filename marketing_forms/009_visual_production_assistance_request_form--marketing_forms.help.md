# Visual Production Assistance Request Form - Help Guide
## Purpose
The Visual Production Assistance Request Form is used to gather project details for visual production, facilitating effective communication between stakeholders and production teams.

## How To Complete This Form

1. Enter a detailed description of your request in the **Request Details** field.
2. Provide information about the project, including **Project Details**, **Creative Details**, and **Production Requirements**.
3. Specify the production assistance type needed, such as **Type 1**, **Type 2**, or **Type 3**.
4. Set the requested **Request Priority** as **Low**, **Medium**, or **High**.
5. Enter your name and role as **Requested By**.
6. Choose relevant **Production Start Date**, **Production End Date**, and **Production Duration** for the project.
7. Enter the **Project Manager** and **Production Company** names.
8. Provide the **Production Contact** details, including name, email, and phone number.
9. Select the relevant **Production Address** from the available options.
10. Add any additional **Production Notes** if necessary.
11. Update the **Project Status** as needed.

## Field-by-Field Explanation

* **Request Details** (`request_details`, text, optional): A brief description of your request.
* **Project Details** (`project_details`, text, optional): Project information, such as title, description, and project manager.
* **Creative Details** (`creative_details`, text, optional): Creative brief details, such as art direction and style guidelines.
* **Production Requirements** (`production_requirements`, text, optional): List of required production specifications, such as equipment and software.
* **Production Assistance Type** (`production_assistance_type`, select_one, optional): Type of production assistance needed, such as 3D animation, video production, or photography.
* **Request Priority** (`request_priority`, select_one, optional): Level of priority for the request, such as Low, Medium, or High.
* **Requested By** (`requested_by`, text, optional): Name and role of the person requesting production support.
* **Production Start Date** (`production_start_date`, date, optional): Scheduled start date for production.
* **Production End Date** (`production_end_date`, date, optional): Scheduled end date for production.
* **Production Start Time** (`production_start_time`, time, optional): Scheduled start time for production.
* **Production End Time** (`production_end_time`, time, optional): Scheduled end time for production.
* **Production Duration** (`production_duration`, number, optional): Estimated duration for production.
* **Total Budget** (`total_budget`, number, optional): Total budget allocated for the project.
* **Project Manager** (`project_manager`, text, optional): Name of the project manager.
* **Production Company** (`production_company`, text, optional): Name of the production company.
* **Production Contact** (`production_contact`, text, optional): Name, email, and phone number of the production contact.
* **Production Email** (`production_email`, email, optional): Production contact's email address.
* **Production Phone** (`production_phone`, text, optional): Production contact's phone number.
* **Production Address** (`production_address`, select_multiple, optional): Production company's address.
* **Production Notes** (`production_notes`, note, optional): Additional information about the production.
* **Project Status Update** (`project_status_update`, select_multiple, optional): Update on the project status.
