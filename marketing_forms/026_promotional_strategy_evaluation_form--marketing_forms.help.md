# promotional_strategy_evaluation_form - Help Guide
## Purpose
This form is used to evaluate a promotional strategy by gathering information about campaign performance and effectiveness across various channels. It helps in understanding what worked well and what didn't, providing valuable insights to improve future marketing efforts.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the campaign performance and effectiveness across all channels.
2. Select all the channels that were used for the campaign.
3. Provide feedback on how each channel performed.
4. Enter any additional comments or insights about the campaign.
5. Enter the email address and phone number (if applicable) associated with the campaign.
6. Select the date the campaign was run.
7. Select the time of the campaign.
8. Select the recommended channels for future campaigns.

## Field-by-Field Explanation
* **promotional strategy** (`promotional strategy`, `note`, required: false): This is the main strategy used for the campaign. Briefly describe the promotional strategy employed.
* **campaign performance** (`campaign performance`, `text`, required: false): Enter a brief description of the campaign's performance. Was it successful or not?
* **channel effectiveness** (`channel effectiveness`, `select_multiple`, required: false): Select all the channels used for the campaign. This will help in evaluating their effectiveness.
* **feedback** (`feedback`, `text`, required: false): Provide any feedback or comments about the campaign's performance.
* **email** (`email`, `email`, required: false): Enter the email address associated with the campaign.
* **phone** (`phone`, `text`, required: false): Enter the phone number associated with the campaign.
* **date** (`date`, `date`, required: false): Select the date the campaign was run.
* **time** (`time`, `time`, required: false): Select the time of the campaign.
* **comments** (`comments`, `text`, required: false): Enter any additional comments or insights about the campaign.
* **recommended channels** (`recommended channels`, `select_one`, required: false): Select the recommended channels for future campaigns based on the performance of the current campaign.
* **channel_a** (`channel_a`, `select_multiple`, required: false): Select all the channels from A that were used for the campaign.
* ... (All other channel fields, e.g., channel_b, channel_c, channel_d, etc.)
* **channel_m** (`channel_m`, `select_multiple`, required: false): Select all the channels from M that were used for the campaign.
* **channel_n** (`channel_n`, `select_multiple`, required: false): Select all the channels from N that were used for the campaign.
* **channel_o** (`channel_o`, `select_multiple`, required: false): Select all the channels from O that were used for the campaign.
* **channel_p** (`channel_p`, `select_multiple`, required: false): Select all the channels from P that were used for the campaign.

## Tips
* Make sure to select all the channels that were used for the campaign.
* Provide clear and concise answers for each field.
* If you're unsure about any of the fields, feel free to ask for assistance.
