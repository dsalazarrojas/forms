# Brand Guideline Compliance Checklist - Help Guide
## Purpose
This form is a Brand Guideline Compliance Checklist designed to help project managers and reviewers evaluate the compliance of marketing materials and content with the brand guidelines.

## How To Complete This Form
1. Fill out the form with the relevant information for the specific project being reviewed.
2. Select one of the three options for each field: compliant, non-compliant, or not applicable.
3. Provide a brief description of any issues found in the issues description field.
4. Enter your name and signature in the reviewer name and signature fields.
5. Review and submit the form to get the overall compliance status.

## Field-by-Field Explanation
* **Project Name** (Project Name, text, required): Enter the name of the project being reviewed.
* **Project Manager Name** (Project Manager Name, text, required): Enter the name of the person responsible for the project.
* **Department** (Department, select_one, required): Select your department from the options provided.
* **Review Date** (Review Date, date, required): Enter the date of the review.
* **Material Type** (Material Type, select_one, required): Select the type of material being reviewed from the options provided.
* **Logo Usage** (Logo Usage, select_one, required): Select whether the logo is used correctly per guidelines.
* **Logo Spacing and Clear Space** (Logo Spacing and Clear Space, select_one, required): Select whether proper logo spacing is maintained.
* **Color Accuracy** (Color Accuracy, select_one, required): Select whether brand colors are used correctly.
* **Typography Compliance** (Typography Compliance, select_one, required): Select whether brand fonts are used correctly.
* **Tone of Voice** (Tone of Voice, select_one, required): Select whether content matches brand voice guidelines.
* **Imagery Style** (Imagery Style, select_one, required): Select whether images match brand style.
* **Messaging Consistency** (Messaging Consistency, select_one, required): Select whether messaging is consistent with brand values.
* **Legal Disclaimers** (Legal Disclaimers, select_one, required): Select whether required disclaimers are included.
* **Accessibility Check** (Accessibility Check, select_one, required): Select whether material meets accessibility standards.
* **Overall Compliance Status** (Overall Compliance Status, select_one, required): Select the final compliance status.
* **Issues Description** (Issues Description, text, optional): Describe any compliance issues found.
* **Reviewer Name** (Reviewer Name, text, required): Enter your name as the reviewer.
* **Reviewer Signature** (Reviewer Signature, text, required): Type your name as signature.

## Tips
* Please ensure that you are familiar with the brand guidelines before completing this form.
* If you are unsure about any field, refer to the brand guidelines document for guidance.
* This form is designed to be used by project managers and reviewers to evaluate compliance of marketing materials and content.
* The overall compliance status will provide a clear indication of whether the material is compliant with brand guidelines.
* The issues description field is for recording any issues found during the review.
