# Product Video Localization Request Form - Help Guide
## Purpose
The Product Video Localization Request Form is used to request product video localization for adaptation to a specific language or target market. This form should be filled out once for each product video that needs to be translated or adapted.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Video Details** section with the name of the product video you'd like to localize.
2. Select the **Target Language** that the video should be localized to.
3. If necessary, provide any **Video Requirements** for the localization process, such as specific formatting or editing needs.
4. Set a **Deadline** for when the localized video is needed.
5. Upload the **File** associated with the product video.
6. Confirm that you've submitted the form and attached the file correctly.
7. Select the confirmation option that best matches your submission experience.

## Field-by-Field Explanation
* **Video Details**: Enter the name of the product video you'd like to localize.
* **Target Language**: Select the language that the video should be localized to from the dropdown list.
* **Video Requirements**: If there are specific requirements for the localization process, such as specific formatting or editing needs, enter them here.
* **Deadline**: Set a deadline for when the localized video is needed. If there's no specific deadline, leave this field blank.
* **File Upload**: Upload the file associated with the product video. The file should be in a format that is easily viewable, such as .mp4 or .mpg. Ensure that you've attached the correct file.
* **Submission Confirmation**: Confirm that you've submitted the form and attached the correct file by selecting "File uploaded successfully".
* **Submission Confirmation 2**: Select "Submission Confirmation 2" to confirm that you've successfully submitted the form with the correct file attached. 
* **Submission Confirmation 3**: This field is for final confirmation of form submission. Please select "Form submitted successfully" to confirm that the form has been successfully submitted with all required fields filled out.

## Tips
* Fill out the form only once for each product video to be localized.
* Ensure that you've attached the correct file with the product video.
* Double-check that you've selected the correct target language and deadline.
* If there are specific requirements for the localization process, make sure to include them in the **Video Requirements** field.
