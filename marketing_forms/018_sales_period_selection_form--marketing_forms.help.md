# Sales Period Selection Form - Help Guide
## Purpose
The Sales Period Selection Form is used to configure sales periods for sales activities, such as sales campaigns, reporting, and other sales-related settings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the **Select Period Type** field to choose the sales period type that suits your needs (Week, Month, Quarter, Season, or Year).
2. In the **Sales Period** field, select the specific periods you want to include (First, Second, Third, Last, or any combination).
3. If required, choose the **Start Date** and **End Date** for your sales period.
4. Select the **Sales Period Frequency** field to specify how often you want to run the sales period (Daily, Weekly, Monthly, Quarterly, or Yearly).
5. In the **Sales Period Start Date** and **Sales Period End Date** fields, select the dates for your sales period if required.
6. If needed, choose the **Sales Period Start Date Format**, **Sales Period End Date Format**, and **Sales Period Unit** fields to customize the date format and unit for your sales period.

## Field-by-Field Explanation
* **Sales Periods**: Select the specific sales periods you want to include in your sales activities. You can choose one or more periods from the list.
* **Select Period Type**: Choose the type of sales period that suits your needs.
* **Select Period Frequency**: Select how often you want to run the sales period.
* **Sales Period Start Date**: Select the start date of the sales period if required.
* **Sales Period End Date**: Select the end date of the sales period if required.
* **Sales Period Start Time**: Select the start time of the sales period if required.
* **Sales Period End Time**: Select the end time of the sales period if required.
* **Sales Period Start Date Format**: Choose the format for the start date of the sales period.
* **Sales Period End Date Format**: Choose the format for the end date of the sales period.
* **Sales Period Unit**: Select the unit for the sales period frequency (Days, Weeks, Months, Quarters, or Years).

## Tips
* Make sure to select the correct period type and frequency for your sales activities.
* Double-check the start and end dates for correct configuration.
* Customizing the date formats can be helpful for specific sales activities that require different date representations.
