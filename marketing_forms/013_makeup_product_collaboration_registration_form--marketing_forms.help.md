# Makeup Product Collaboration Registration Form - Help Guide
## Purpose
This form is used to register and collaborate on makeup products. It gathers information about the product, submission date and time, location, and contact details of the collaborators.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form carefully to ensure you're not duplicating any existing collaboration or submitting information already registered.
2.  Fill out each page of the form according to the instructions below.
3.  Ensure that all required fields are completed.

## Field-by-Field Explanation
### Page One
- **Page One** (`page_one`, `text`, required: false): This is the first page of the form. Please review and ensure that you're not duplicating any existing collaboration or submitting information already registered.
### Page Two
- **Page Two** (`page_two`, `text`, required: false): Please describe your collaboration. This will help in organizing and tracking collaborations.
### Additional Comments
- **Additional Comments** (`page_three`, `text`, required: false): If you have any additional comments or information related to the collaboration, please provide them here.
### Collaborator Details
- **Collaborator Details** (`page_four`, `select_one`, required: false): Select one of the options to indicate how you want to collaborate:
  • Name: This option is for providing the name of the collaborator.
  • Email: This option is for providing the email of the collaborator.
  • Phone: This option is for providing the phone number of the collaborator.
  • Description: This option is for providing a description of the collaborator.
### Collaborator Contact
- **Collaborator Contact** (`page_five`, `select_multiple`, required: false): Select multiple options to provide contact information of the collaborator:
  • Phone: This option is for providing the phone number of the collaborator.
  • Email: This option is for providing the email of the collaborator.
  • Description: This option is for providing a description of the collaborator.
### Collaborator Social Media
- **Collaborator Social Media** (`page_six`, `select_multiple`, required: false): Select multiple options to provide social media information of the collaborator:
  • Facebook: This option is for providing the Facebook profile of the collaborator.
  • Instagram: This option is for providing the Instagram profile of the collaborator.
  • LinkedIn: This option is for providing the LinkedIn profile of the collaborator.
  • Twitter: This option is for providing the Twitter profile of the collaborator.
