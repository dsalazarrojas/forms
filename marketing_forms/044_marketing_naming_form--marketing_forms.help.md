# marketing_naming_form - Help Guide
## Purpose
This form is designed to help the marketing team propose new project names according to our internal naming conventions. It guides you in selecting the most suitable name based on the project category, subcategory, and other relevant details.

## How To Complete This Form
1. Select the category of the project from the options provided.
2. Choose a subcategory (if applicable).
3. Enter a brief description of the project.
4. Suggest a name for the project.
5. Select the tool assigned to the project from the available options.
6. Enter the project ID (if applicable).
7. Choose an output file name (if applicable).

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, optional): Enter a name for the project that reflects its purpose and goals.
* **Category** (`category`, select_multiple, optional): Select the category that best describes the project. This will help us understand the project's context and suggest a name accordingly.
* **Subcategory** (`subcategory`, text, optional): If you have a specific subcategory for the project, enter it here. This will further refine the name suggestion.
* **Name Suggestion** (`name_suggestion`, text, optional): Provide a specific name for the project that you think fits well. This is a good opportunity to be creative and suggest something that you think is unique and memorable.
* **Description** (`description`, text, optional): Briefly describe the project to help us understand its purpose and context.
* **Assigned Tool** (`assigned_tool`, select_one, required): Choose the tool that will be used for the project from the available options. This will help us suggest a name that is relevant to the tool and its use case.
* **Project ID** (`project_id`, text, optional): If you have a specific project ID, enter it here. This is useful for tracking and identification purposes.
* **Output File** (`output_file`, text, optional): If you need to generate an output file for the project, enter the name for it here.

## Tips
* Be as specific as possible when providing descriptions and name suggestions.
* If you're unsure about a category or subcategory, feel free to ask for guidance.
* The more information you provide, the better the name suggestion will be.
