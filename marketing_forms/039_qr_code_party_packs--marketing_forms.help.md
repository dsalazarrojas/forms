# qr_code_party_packs - Help Guide
## Purpose
The "qr_code_party_packs" form is used to create and manage QR code packs for marketing campaigns. This form helps you to configure and customize QR code packs according to your marketing needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of your QR code pack (Marketing Forms or Other).
2. Enter a brief description of your QR code pack.
3. Choose the output file format for your QR code pack.
4. Assign the tool used for this QR code pack.
5. Enter the form IDs for this QR code pack.

## Field-by-Field Explanation
* **QR Code Packs** (`qr_code_packs`, text, optional): Enter a brief name for your QR code pack.
* **Category** (`category`, select_one, optional): Choose the category for your QR code pack (Marketing Forms or Other).
* **Description** (`description`, text, optional): Describe your QR code pack in a few words.
* **Output File** (`output_file`, text, optional): Select the format for your output file.
* **Assigned Tool** (`assigned_tool`, text, optional): Assign the tool used for this QR code pack.
* **Form IDs** (`form_ids`, number, optional): Enter the form IDs for this QR code pack.
