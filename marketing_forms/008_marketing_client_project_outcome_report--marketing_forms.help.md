# Marketing Client Project Outcome Report - Help Guide
## Purpose
This form is used to report on the outcome of a marketing project, providing a summary of its success or failure, and its performance and client feedback.

## How To Complete This Form
1. Enter the project ID to select the project you want to report on.
2. Choose the marketing outcome (Excellent, Good, Fair, or Poor) that best describes the project's success or failure.
3. Enter any performance insights that you think are important for the report.
4. Write down any feedback from the client regarding the project.
5. Select the current status of the project (Active, Closed, or Paused).
6. Enter the date of the project's outcome.
7. Enter the name, contact information, and title of the project manager who handled the project.
8. Enter a brief description of the project's outcome.
9. Enter the email address of the project manager.
10. If applicable, enter any additional phone number and address details for the project manager.
11. If applicable, enter the company of the project manager.
12. If you want to report on multiple projects at once, you can do so by filling out this form multiple times, each with a different project ID.

## Field-by-Field Explanation
* **project_id**: Enter the unique ID of the marketing project you want to report on. This is required.
* **marketing_outcome**: Choose the marketing outcome that best describes the project's success or failure (Excellent, Good, Fair, or Poor). This is required.
* **performance_insights**: Enter any additional insights or information about the project's performance. This is required.
* **client_feedback**: Enter any feedback from the client regarding the project. This is required.
* **project_status**: Select the current status of the project (Active, Closed, or Paused). This is required.
* **outcome_date**: Enter the date of the project's outcome. This is required.
* **project_manager**: Enter the name of the project manager who handled the project. This is required.
* **outcome_description**: Enter a brief description of the project's outcome. This is required.
* **project_manager_email**: Enter the email address of the project manager. This is required.
* **project_manager_phone**: Enter the phone number of the project manager (optional).
* **project_manager_address**: Enter the address of the project manager (optional).
* **project_manager_company**: Enter the company of the project manager (optional).
* **project_manager_title**: Enter the title of the project manager (optional).
* **marketing_outcome_date**: Enter the date of the marketing outcome (optional).
* **marketing_outcome_time**: Enter the time of the marketing outcome (optional).
* **outcome_rating**: Choose the rating that best describes the project's marketing outcome (Excellent, Good, Fair, or Poor, optional).
* **outcome_comment**: Enter a brief comment on the project's outcome. This is required.
* **outcome_rating**: This field is marked as "outcome_rating" but it seems it was meant to be "outcome_comment". If so, this field should be renamed to "outcome_comment" to match the others and to avoid confusion.
