# Daily WLA Form Template - Help Guide
## Purpose
The Daily WLA Form Template is a tool used to track and analyze resource allocation and management within the organization. It is used to monitor the availability and utilization of resources, including their location, type, and status.

## How To Complete This Form

1. Review the form carefully and ensure that the information is accurate and up-to-date.
2. Fill in the required fields with the correct information for each resource.
3. Select the correct options for the resource type, status, and availability.
4. Enter the correct values for work start time, duration, and cost.
5. Select the correct urgency and priority level for each resource.
6. Fill in the comments section with any additional information or notes.

## Field-by-Field Explanation

* **Resource Allocation** (id: 1): Select the resources that are currently allocated, by choosing from the options "Yes" or "No".
* **Work Start Time** (id: 2): Enter the start time of the work session in date format (e.g., 2024-02-20).
* **Work Duration** (id: 3): Enter the duration of the work session in minutes.
* **Time Off** (id: 4): Enter the time off in time format (e.g., 12:00 PM).
* **Resource Availability** (id: 5): Select the resource availability from the options "Available", "Unavailable", "Partially Available", etc.
* **Resource Utilization** (id: 6): Select the resource utilization from the options "Low", "Medium", "High", etc.
* **Comments** (id: 7): Enter any additional comments or notes about the resource.
* **Resource ID** (id: 8): Enter a unique identifier for the resource.
* **Resource Name** (id: 9): Enter the name of the resource.
* **Resource Description** (id: 10): Enter a brief description of the resource.
* **Resource Type** (id: 11): Enter the type of the resource.
* **Resource Status** (id: 12): Select the resource status from the options "Available", "On Leave", "On Vacation", etc.
* **Location** (id: 13): Select the location of the resource from the options "USA", "Canada", "Mexico", etc.
* **Cost** (id: 14): Enter the cost associated with the resource.
* **Capacity** (id: 15): Enter the capacity of the resource.
* **Urgency** (id: 16): Select the urgency level of the resource from the options "Low", "Medium", "High", etc.
* **Priority** (id: 17): Select the priority level of the resource from the options "Low", "Medium", "High", etc.
* **Comments** (id: 18): Enter any additional comments or notes about the resource.
* **Resource ID 2** (id: 19): Enter a unique identifier for the resource.
* **Resource Name 2** (id: 20): Enter the name of the resource.
* **Resource Description 2** (id: 21): Enter a brief description of the resource.
* **Resource Type 2** (id: 22): Enter the type of the resource.
* **Resource Status 2** (id: 23): Select the resource status from the options "Available", "On Leave", "On Vacation", etc.
* **Location 2** (id: 24): Select the location of the resource from the options "USA", "Canada", "Mexico", etc.
* **Cost 2** (id: 25): Enter the cost associated with the resource.
* **Assigned Tool** (id: 26): Select the assigned tool from the options "chatjimmy" or "other".

## Tips

* Make sure to review and update the form regularly to reflect changes in resource allocation and management.
* Ensure that the information is accurate and up-to-date.
* Use the form to identify trends and patterns in resource utilization and allocation.
* Use the form to inform decision-making and resource planning.
