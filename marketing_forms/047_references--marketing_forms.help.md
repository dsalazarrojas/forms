# References - Help Guide

## Purpose
This form is used to provide a list of references to be filled in by a user. The purpose of this form is to allow users to easily create and manage their references.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the required information in the text fields (reference1, reference2, reference3).
2. Optionally, select the "created-by" field from the dropdown menu.

## Field-by-Field Explanation
- **reference1** (`reference1`, text, required/optional): Enter a reference value for the first reference.
- **reference2** (`reference2`, text, required/optional): Enter a reference value for the second reference.
- **reference3** (`reference3`, text, required/optional): Enter a reference value for the third reference.
- **created-by** (`user_created_by`, select_one, required/optional): Select the option that best describes who created the reference. You can choose from the following options: Option 1, Option 2, or Option 3.

## Tips
* Make sure to enter accurate and relevant information in the text fields.
* Select a valid option from the "created-by" dropdown menu.
* If you are unsure about the purpose of this form, please contact your administrator for further assistance.
