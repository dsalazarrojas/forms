# Website Analytics Filter Form - Help Guide
## Purpose
The Website Analytics Filter Form is used to filter website analytics data based on various criteria such as date range, time zone, and analytics type. This form helps users to extract specific insights from the vast amount of data collected by the website.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the desired **Filter Type** from the options provided:
	* **Analytics**: Filter data related to website analytics metrics.
	* **Conversion**: Filter data related to conversion metrics.
	* **Engagement**: Filter data related to engagement metrics.
2. Choose the **Date Range** for which you want to view data. Select a start and end date to get data within the specified period.
3. Set the **Time Range** (optional): If you want to filter by a specific time period, select the start and end time.
4. Choose your **Time Zone**:
	* Select a single time zone from the options (PST, EST, CST, MST)
5. Optionally, select multiple time zones from the options (PST, EST, CST, MST)

## Field-by-Field Explanation
* **Website Analytics Filter Form 1**: This field is used to enter a custom filter query. It is not required.
* **Filter Type**: This field is used to select the type of analytics data to filter. Choose from **Analytics**, **Conversion**, or **Engagement**.
* **Date Range**: This field is used to select a date range for which to filter data. Select a start and end date to get data within the specified period.
* **Start Date**: This field is used to enter the start date of the date range.
* **End Date**: This field is used to enter the end date of the date range.
* **Time Range**: This field is used to select a time range for which to filter data. Select a start and end time to get data within the specified period.
* **Time Zone**: This field is used to select a single time zone for which to filter data. Choose from (PST, EST, CST, MST).
* **Time Zone**: This field is used to select multiple time zones for which to filter data. Choose from (PST, EST, CST, MST).
* **Time Zone Offset**: This field is used to enter a time zone offset in numeric format.
* **Time Zone Offset Minutes**: This field is used to enter a time zone offset in minutes.
* **PST**: Select this option to filter data for the Pacific Standard Time zone.
* **EST**: Select this option to filter data for the Eastern Standard Time zone.
* **CST**: Select this option to filter data for the Central Standard Time zone.
* **MST**: Select this option to filter data for the Mountain Standard Time zone.

## Tips
* Make sure to select a specific filter type to get accurate results.
* Ensure to enter a valid date and time range to get accurate data.
* If you are unsure about any field, try selecting the default options to see how it affects the results.
