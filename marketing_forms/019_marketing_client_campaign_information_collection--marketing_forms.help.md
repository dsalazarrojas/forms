# Marketing Client Campaign Information Collection - Help Guide
## Purpose
This form is designed to collect all necessary information about a marketing client campaign. It is essential to fill out this form accurately and thoroughly to ensure the successful execution and evaluation of the campaign.

## How To Complete This Form
1. Select the correct page for each section of the campaign information.
2. Fill out each field according to the provided instructions and hints.
3. Ensure that all required fields are completed before proceeding to the next page.
4. Review each page for accuracy and completeness before submitting the form.

## Field-by-Field Explanation

* **Campaign Name** (`campaign_name`, text, required): Enter the name of the campaign.
* **Client Name** (`client_name`, text, required): Enter the name of the client.
* **Marketing Agency** (`marketing_agency`, text, required): Enter the name of the marketing agency.
* **Project Budget** (`project_budget`, number, required): Enter the project budget.
* **Campaign Timeline** (`campaign_timeline`, date, required): Enter the campaign timeline.
* **Marketing Objectives** (`marketing_objectives`, text, required): Enter marketing objectives.
* **Target Audience** (`target_audience`, text, required): Enter target audience.
* **Marketing Channels** (`marketing_channels`, select_multiple, required): Select marketing channels (e.g., Online Ads, Social Media, Print Media, Email Marketing, Events).
* **Marketing Budget** (`marketing_budget`, number, required): Enter marketing budget.
* **Campaign Sponsors** (`campaign_sponsors`, text, required): Enter campaign sponsors.
* **Marketing Objectives** (`marketing_objectives`, text, required): Enter marketing objectives.
* **Marketing Strategy** (`marketing_strategy`, text, required): Enter marketing strategy.
* **Marketing Tactics** (`marketing_tactics`, text, required): Enter marketing tactics.
* **Evaluation Metrics** (`evaluation_metrics`, text, required): Enter evaluation metrics.
* **Campaign Status** (`campaign_status`, select_one, required): Select campaign status (e.g., Active, Inactive, Pending).
* **Campaign Notes** (`campaign_notes`, text, optional): Enter campaign notes.
* **Marketing Media Types** (`marketing_media_types`, select_multiple, required): Select marketing media types (e.g., TV, Radio, Print, Digital, Outdoor, Event).
* **Marketing Mediums** (`marketing_mediums`, select_multiple, required): Select marketing mediums (e.g., Online, Offline, Direct Mail, Phone).
* **Target Location** (`target_location`, text, required): Enter target location.
* **Project Goals** (`project_goals`, text, required): Enter project goals.
* **Project Outcomes** (`project_outcomes`, text, required): Enter project outcomes.
* **Marketing Teams** (`marketing_teams`, select_multiple, required): Select marketing teams (e.g., Creative, Digital, Media, Event, Public Relations, Content).
* **Campaign Start Date** (`campaign_start_date`, date, required): Enter campaign start date.
* **Campaign End Date** (`campaign_end_date`, date, required): Enter campaign end date.
* **Campaign Duration** (`campaign_duration`, text, required): Enter campaign duration.
