# YouTube SEO Form - Help Guide
## Purpose
This form is designed to help users optimize their YouTube video titles and descriptions for better search engine optimization (SEO). It's a collection of various fields that gather information about the video, such as its title, URL, social media links, image license, and music license. The form also includes fields for posting on social media platforms, creating a blog post, and connecting to external services like Airtable and Zapier. By filling out this form, users can ensure their YouTube videos are properly configured for visibility and engagement.

## How To Complete This Form
To fill out this form, follow these steps:

*   Fill in the video's title in the `Video Title` field.
*   Enter the video's URL in the `Video URL` field.
*   If you have a Twitter profile, link to it in the `Twitter` field.
*   If you have a Facebook profile, link to it in the `Facebook` field.
*   If you have an Instagram profile, link to it in the `Instagram` field.
*   If you have a blog post related to the video, link to it in the `Blog Link` field.
*   Specify the license of the image used in the video in the `Image License` field.
*   Specify the license of the music used in the video in the `Music License` field.
*   If you'd like to post the video on Twitter, select `Yes` in the `Zapier Post to Twitter` field.
*   If you'd like to post the video on Pinterest, select `Yes` in the `Zapier Post to Pinterest` field.
*   If you'd like to create a new blog post about the video, select `Yes` in the `Zapier Create Blog Post` field.
*   If you'd like to connect to Airtable, select `Yes` in the `Connect to Airtable` field.
*   Finally, click the "Submit" button to complete the form.

## Field-by-Field Explanation

*   **Video Title** (`video_title`, text, optional): This field is for entering the title of the video. This title will be used for search engine optimization and will be displayed on the video's page.
*   **Video URL** (`video_url`, text, optional): This field is for entering the URL of the video. This URL will be used to link to the video.
*   **Twitter** (`social_media_twitter`, text, optional): This field is for linking to your Twitter profile.
*   **Facebook** (`social_media_facebook`, text, optional): This field is for linking to your Facebook profile.
*   **Instagram** (`social_media_instagram`, text, optional): This field is for linking to your Instagram profile.
*   **Blog Link** (`blog_link`, text, optional): This field is for linking to a blog post related to the video.
*   **Image License** (`image_license`, text, optional): This field is for specifying the license of the image used in the video.
*   **Music License** (`music_license`, text, optional): This field is for specifying the license of the music used in the video.
*   **Zapier Post to Twitter** (`zapiery_post_twitter`, select_one, required): This field is for selecting whether you'd like to post the video on Twitter.
*   **Zapier Post to Pinterest** (`zapiery_post_pinterest`, select_one, required): This field is for selecting whether you'd like to post the video on Pinterest.
*   **Zapier Create Blog Post** (`zapiery_create_blog_post`, select_one, required): This field is for selecting whether you'd like to create a new blog post about the video.
*   **Connect to Airtable** (`zapiery_connect_airtable`, select_one, required): This field is for selecting whether you'd like to connect to Airtable.
*   **Zapier App ID** (`zapiery_app_id`, text, optional): This field is not used in this form and can be ignored.
*   **Zapier API Token** (`zapiery_api_token`, text, optional): This field is not used in this form and can be ignored.
*   **Zapier Webhook URL** (`zapiery_webhook_url`, text, optional): This field is not used in this form and can be ignored.
*   **Zapier Webhook Key** (`zapiery_webhook_key`, text, optional): This field is not used in this form and can be ignored.
*   **Zapier Webhook Secret** (`zapiery_webhook_secret`, text, optional): This field is not used in this form and can be ignored.
