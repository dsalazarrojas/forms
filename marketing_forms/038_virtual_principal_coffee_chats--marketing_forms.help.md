# Virtual Principal Coffee Chats - Help Guide
## Purpose

This form is used to collect data for Virtual Principal Coffee Chats, a series of virtual events or meetings for educational or information purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the principal coffee chats you would like to participate in from the list provided.
2. Choose the category for the data collection (Marketing, Social Media, or Email).
3. Enter a brief description of the event or meeting.
4. Select the tool assigned to the Virtual Principal Coffee Chats (ChatJimmy or Other).
5. Choose the output file format (YAML, JSON, or CSV).
6. Enter the name of the output file.
7. Write a description of the form for further reference.
8. Optionally, select the category and form ID for the form.

## Field-by-Field Explanation

* **Virtual Principal Coffee Chats** (Select Multiple): Choose the principal coffee chats you would like to participate in.
* **Category** (Select One): Select the category for the data collection (Marketing, Social Media, or Email).
* **Description** (Text): Enter a brief description of the event or meeting.
* **Assigned Tool** (Select One): Select the tool assigned to the Virtual Principal Coffee Chats (ChatJimmy or Other).
* **Form ID** (Number): Enter the form ID (a unique identifier for the form).
* **Output File** (Select One): Choose the output file format (YAML, JSON, or CSV).
* **Output File Extension** (Select One): Choose the file extension for the output file (YAML, JSON, or CSV).
* **Output File Name** (Text): Enter the name of the output file.
* **Form Description** (Text): Write a description of the form for further reference.
* **Form Category** (Text): Optionally, select the category for the form.
* **Form ID** (Number): Optionally, enter a unique identifier for the form.
* **Description Field** (Text): Enter a description for the field.
* **Output Dir** (Select One): Choose the directory for the output file (output, data, or public).
