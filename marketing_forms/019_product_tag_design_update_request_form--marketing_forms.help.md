# Product Tag Design Update Request Form - Help Guide
## Purpose
The form is used to request changes to product tags, ensuring that the updates are accurate and timely.

## How To Complete This Form
1. Fill in the product tag change request.
2. Provide a description of the change.
3. Select the priority level of the update (e.g. high, medium, low).
4. Choose the deadline for the update.
5. Choose a relevant collection (e.g. product group).
6. Select any relevant files associated with the update.
7. Add any additional notes about the update.
8. Enter your email address.

## Field-by-Field Explanation
- **Product Tag Change Request**: Enter the specific tag that needs to be updated (required).
  * This is the tag that needs to be changed.
- **Description**: Enter a brief description of the change (required).
  * This will help us understand the context of the update.
- **Priority**: Select the priority level (required).
  * High for urgent updates, medium for regular updates, low for non-urgent updates.
- **Deadline**: Enter the date and time for the update (required).
  * This will help us schedule the update in time.
- **Collection**: Select a relevant collection (required).
  * Choose the collection that the tag belongs to.
- **Files**: Select any relevant files associated with the update (optional).
  * These files will be used for the update.
- **Notes**: Add any additional notes about the update (optional).
  * This is a free text field for any additional information.
- **Email**: Enter your email address (required).
  * This will help us contact you about the update.
- **Phone**: Enter your phone number (required).
  * This will help us contact you about the update.
- **Files**: Select any additional files associated with the update (optional).
  * These files will be used for the update.
