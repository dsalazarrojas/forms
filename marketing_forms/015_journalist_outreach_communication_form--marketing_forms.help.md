# Journalist Outreach Communication Form - Help Guide
## Purpose
The Journalist Outreach Communication Form is used to facilitate communication and outreach between the organization and journalist contacts for various purposes such as scheduling interviews, sending press releases, or sending information requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Organization Name in the first field.
2. In the next field, input the Journalist Name, who is being contacted.
3. Enter the contact Email address in the Email field.
4. If necessary, add the Contact Number for the journalist.
5. Select the preferred communication channels from the list.
6. Choose the Target Audience the message should be directed to.
7. Provide a brief Description of the message to be sent.
8. Select the Assigned Tool or Platform used to send the message.
9. Select the Output File type for the message.
10. Choose the Category of the message.
11. Enter any additional information in the Form IDs field.
12. Finally, enter the Assigned Tool ID if necessary.

## Field-by-Field Explanation
* **Organization Name**: Enter the name of the organization or company you represent.
* **Journalist Name**: The name of the journalist or media contact.
* **Email**: Enter the email address of the journalist or media contact.
* **Contact Number**: Provide a contact number for the journalist or media contact.
* **Preferred Communication Channels**: Select the communication channels you wish to use, such as phone, email, or messaging apps.
* **Target Audience**: Choose the target audience for the message, such as general public, press, or industry experts.
* **Description**: Write a brief description of the message or purpose of the outreach.
* **Assigned Tool**: Select the platform or tool used to send the message, such as social media, email, or phone.
* **Output File**: Choose the type of file to be outputted, such as PDF or Word document.
* **Category**: Select the category of the message or purpose of the outreach.
* **Form IDs**: Provide additional information or IDs related to the form.
* **Assigned Tool ID**: Enter the ID of the tool or platform assigned to the message.
* **Tips**: Make sure to review the form carefully before submission to ensure all fields are completed as required and relevant to the purpose of the form.
