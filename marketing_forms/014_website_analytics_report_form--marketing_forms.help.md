# Website Analytics Report Form - Help Guide
## Purpose
This form is designed to collect information for website analytics reports.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Enter the title of the report you want to create.
2. Choose whether you want the report to be weekly, monthly, or another frequency.
3. Select the start and end dates for the report period.
4. Specify the target URL for the report.
5. Choose the source of the website traffic.
6. Select the goal for the analytics report.
7. Enter the frequency of the report in the number of times per <string> (e.g., per week).
8. Select the time zone for the report.
9. Enter your email address for contact information.
10. Provide any additional information for the report.
11. Enter the frequency of the report in the time interval (e.g., hours, minutes).

## Field-by-Field Explanation
- **Report Title** (`title`, text, required): Enter the title of the report you want to create.
  This will be the name of the report that appears in the analytics reports.
- **Report Frequency** (`report_frequency`, select_one, required): Choose whether you want the report to be weekly, monthly, or another frequency.
  This will determine how often the report is generated.
- **Report Start Date** (`report_start_date`, date, required): Select the start date for the report period.
  This will mark the beginning of the report period.
- **Report End Date** (`report_end_date`, date, required): Select the end date for the report period.
  This will mark the end of the report period.
- **Target URL** (`target_url`, text, required): Enter the URL you want to report on.
  This will be the focus of the report.
- **Website Traffic Source** (`website_traffic`, select_multiple, required): Choose the source of the website traffic you want to report on.
  This will help filter the traffic data.
- **Analytics Goal** (`analytics_goal`, select_one, required): Select the goal of the analytics report.
  This will guide the analysis of the data.
- **Report Frequency Interval** (`report_frequency_period`, number, required): Enter the report frequency interval.
  This will define how often the report is generated.
- **Time Zone** (`timezone`, select_one, required): Select the time zone for the report.
  This will help with date and time calculations.
- **Email** (`email`, email, required): Enter your email address for contact information.
  This will be used for contact and notifications.
- **Additional Information** (`additional_info`, note, required): Enter any additional information for the report.
  This is a free text field for comments.
- **Time Zone Offset** (`timezone_offset`, time, required): Enter the time zone offset.
  This will help with date and time calculations.
- **Phone** (`phone`, text, required): Enter your phone number for contact information.
  This will be used for contact and notifications.
 
Please note that this form requires completion for all the fields. Make sure you have all necessary information before proceeding.
