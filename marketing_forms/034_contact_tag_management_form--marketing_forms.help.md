# Contact Tag Management Form - Help Guide
## Purpose
The Contact Tag Management Form is a request for the management of contact tags, allowing users to add, modify, or remove tags.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your name and department.
2. Enter a valid email address.
3. Select the type of request: Add New Tag, Modify Existing Tag, Remove Tag, or Bulk Tag Update.
4. Choose the contact segment: Leads, Customers, Prospects, Partners, or All Contacts.
5. Enter a proposed tag name and its classification.
6. Provide a description and criteria for the tag.
7. Select if the tag should be applied automatically or manually.
8. Choose the systems affected by the tag.
9. Set the request priority: Low, Medium, High, or Critical.
10. (Optional) Enter a desired implementation date.
11. (Optional) Add any other stakeholders.
12. (Optional) Provide additional notes.

## Field-by-Field Explanation

* **Requester Name** (1, text, required): Enter your name to identify yourself.
* **Department** (3, select_one, required): Select your department from the provided options (Marketing, Sales, Customer Support, Operations, IT, or Other).
* **Email Address** (4, email, required): Enter a valid email address to contact you.
* **Request Date** (5, date, required): Enter the current date to help with tracking and planning.
* **Type of Request** (6, select_one, required): Choose from the options: Add New Tag, Modify Existing Tag, Remove Tag, Bulk Tag Update, or Tag Audit Request.
* **Contact Segment** (7, select_one, required): Select which segment to apply the tag (Leads, Customers, Prospects, Partners, or All Contacts).
* **Tag Name** (8, text, required): Enter a proposed tag name.
* **Tag Category** (9, select_one, required): Classify the tag into one of the provided categories (Demographic, Behavioral, Engagement, Purchase History, Campaign, or Custom).
* **Tag Description** (10, text, required): Provide a description of the tag's purpose.
* **Tagging Criteria** (11, text, required): Define when the tag should be applied.
* **Automation** (12, select_one, required): Decide if the tag should be applied automatically or manually.
* **Affected Systems** (13, select_multiple, required): Choose the systems where the tag should sync (CRM, Email Platform, Marketing Automation, Analytics, Customer Support, or E-commerce).
* **Request Priority** (14, select_one, required): Set the request priority: Low, Medium, High, or Critical.
* **Desired Implementation Date** (15, date, optional): Enter the date when the implementation is needed.
* **Other Stakeholders** (16, text, optional): Identify any other stakeholders involved.
* **Additional Notes** (17, text, optional): Provide any additional information that might be helpful.

Note: Ensure you complete all required fields to ensure accurate and complete tag management.
