# San Antonio Rodeo - Help Guide
## Purpose
This form is designed to collect information about upcoming rodeo events.

## How To Complete This Form
- Fill in the form with the required fields to provide accurate information about your event.
- Make sure to double-check your input data for any errors.
- If you're unsure about any field, please review the field explanation provided below.

## Field-by-Field Explanation
### Event Name
* **Event Name** (`title`, text, optional): Enter the name of your rodeo event, e.g., "Texas Stampede Rodeo".

### Start Date
* **Start Date** (`start_date`, date, optional): Select the date you want the event to start. Please use the date format: MM/dd/yyyy.

### End Date
* **End Date** (`end_date`, date, optional): Choose the date you want the event to end. Please use the date format: MM/dd/yyyy.

### Event Location
* **Event Location** (`event_location`, text, optional): Enter the name of the location where the event will take place, e.g., "San Antonio Arena".

### Attendees List
* **Attendees List** (`attendees_list`, select multiple, optional): Select all relevant cities that you expect to have attendees from, such as "San Antonio" and "Austin".

### Ticket Price
* **Ticket Price** (`ticket_price`, number, optional): Enter the price of one ticket.

### Ticket Quantity
* **Ticket Quantity** (`ticket_quantity`, number, optional): Enter the total number of tickets you plan to sell.

### Contact Info
* **Contact Info** (`contact_info`, text, optional): Enter your contact information, e.g., "rodeo@santaroinfo.com" and "123-456-7890".

### Notes
* **Notes** (`notes`, note, optional): Add any additional notes about your event that might be helpful to event organizers.

## Tips
- Please ensure that all fields are filled out accurately and thoroughly.
- If you're unsure about any field, review this guide again or contact the system administrator.
- Make sure to use the correct date format for the start and end dates.
