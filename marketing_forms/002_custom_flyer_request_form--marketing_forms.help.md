# Custom Flyer Request Form - Help Guide
## Purpose
This form is designed to gather information for creating custom flyers, brochures, or posters for marketing purposes. Please fill out the form with your requirements to create high-quality marketing materials.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the form title and provide your name and company name.
2. Enter your email address and phone number (optional).
3. Specify the date and time required for the project completion.
4. Select the location where the design should be delivered.
5. Choose the type of form (Flyer, Brochure, or Poster).
6. Select the color scheme, font style, and paper size for the design.
7. Determine the design type (Digital or Print).
8. Provide any additional design notes.
9. Specify any review or submission notes.

## Field-by-Field Explanation

* **Form Information** (Form Information, text, required: false): This field is for any additional information about the form.
* **Name** (Name, text, required: true): Enter your name to be associated with the request.
* **Company Name** (Company Name, text, required: true): Enter your company name to be associated with the request.
* **Email** (Email, email, required: true): Enter a valid email address to receive updates and notifications.
* **Phone** (Phone, text, required: false): Enter your phone number for contact purposes (optional).
* **Date Required** (Date Required, date, required: true): Specify the date by which the project should be completed.
* **Time Required** (Time Required, time, required: true): Specify the time by which the project should be completed.
* **Location** (Location, text, required: true): Specify the location where the design should be delivered.
* **Message** (Message, note, required: true): Enter any additional information or message for the design team.
* **Form Type** (Form Type, select_one, required: true): Choose the type of form (Flyer, Brochure, or Poster).
* **Color Scheme** (Color Scheme, select_multiple, required: true): Select the desired color scheme for the design.
* **Font Style** (Font Style, select_one, required: true): Select the desired font style for the design.
* **Paper Size** (Paper Size, select_multiple, required: true): Select the desired paper size for the design.
* **Design Type** (Design Type, select_one, required: true): Determine if the design is for digital or print purposes.
* **Design Notes** (Design Notes, note, required: true): Enter any additional information or notes for the design team.
* **Review Notes** (Review Notes, note, required: true): Enter any review notes or comments for the design team.
* **Submission Notes** (Submission Notes, note, required: true): Enter any submission notes or comments for the design team.

## Tips

* Please ensure that you provide accurate and relevant information to create a high-quality custom design.
* Review the form carefully before submitting to ensure all fields are filled out correctly.
* If you have any questions or need further clarification, please contact the design team.
