# festival_publicity_collaboration_request_form - Help Guide
## Purpose
The festival publicity collaboration request form is a tool used to collect information from external entities interested in collaborating with the festival. It is used to track and follow up on collaboration opportunities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required fields marked as "true" (indicated by a star).
2. Select the correct options for each field, if applicable.
3. Review your responses for accuracy and completeness.
4. Submit the form once you have finished.

## Field-by-Field Explanation
* **Publicity Request** (`publicity_request`, text, true): This field is used to describe the publicity request from the collaborating entity. Please provide a brief description of what you would like to achieve through collaboration.
* **Collaboration Request** (`collaboration_request`, text, true): This field is used to describe the specific collaboration opportunity being requested. Please be specific and detailed in your response.
* **Media Type** (`media_type`, select_one, true): This field is used to select the type of media you are requesting for publicity. Select one of the options from the dropdown list.
* **Media Outlets** (`media_outlets`, select_multiple, true): This field is used to select the specific media outlets you are interested in working with. Select all that apply from the dropdown list.
* **Collaboration Details** (`collaboration_details`, text, true): This field is used to provide additional details about the collaboration opportunity. Please be thorough and include any relevant information.
* **Publicity Request Status** (`publicity_request_status`, select_one, true): This field is used to report the current status of the publicity request. Select one of the options from the dropdown list.
* **Publicity Request Notes** (`publicity_request_notes`, note, false): This field is used to add any additional information about the publicity request. Please use this field for any additional details or notes.
* **Collaboration Request Notes** (`collaboration_request_notes`, note, false): This field is used to add any additional information about the collaboration request. Please use this field for any additional details or notes.
* **Email** (`email`, email, true): This field is used to enter the email address of the contact person. Please enter a valid email address.
* **Phone** (`phone`, text, true): This field is used to enter the phone number of the contact person. Please enter a valid phone number.
* **Contact Person** (`contact_person`, text, true): This field is used to enter the name of the contact person. Please enter the name of the person responsible for this collaboration opportunity.
* **Contact Number** (`contact_number`, text, true): This field is used to enter the phone number of the contact person. Please enter a valid phone number.
* **Contact Information** (`contact_information`, text, true): This field is used to enter any additional contact information. Please be thorough and include any relevant details.
* **Publicity Request Deadline** (`publicity_request_deadline`, date, false): This field is used to enter the expected deadline for the publicity request. Please select a valid date if applicable.
* **Publicity Request Time** (`publicity_request_time`, time, false): This field is used to enter the expected time for the publicity request. Please select a valid time if applicable.
* **Publicity Request Date** (`publicity_request_date`, date, false): This field is used to enter the expected date for the publicity request. Please select a valid date if applicable.
* **Additional Comments** (`additional_comments`, text, false): This field is used to add any additional comments or information about the collaboration opportunity. Please be thorough and include any relevant details.
* **Collaboration Request Date** (`collaboration_request_date`, date, false): This field is used to enter the expected date for the collaboration request. Please select a valid date if applicable.
* **Publicity Request Time** (`publicity_request_time`, time, false): This field is used to enter the expected time for the publicity request. Please select a valid time if applicable.

## Tips
* Please be thorough in your responses, as this information will be used to track and follow up on the collaboration opportunity.
* If you are unsure about any of the fields, please reach out to festival staff for clarification.
