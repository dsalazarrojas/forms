# sfdc_campaign_request_form - Help Guide
## Purpose
This form is designed to be used by marketing teams to request and manage Salesforce campaigns. It captures essential information about the campaign, including title, client details, and expected return on investment.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and detailed information.
2. Review the field explanations below for more specific guidance on each field.

## Field-by-Field Explanation
* **Campaign Title** (`campaign_title`, text, required): Enter a brief and descriptive title for the campaign.
* **Client Name** (`client_name`, text, required): Enter the name of the client or company associated with the campaign.
* **Campaign Requirements** (`campaign_requirements`, text, required): Describe the specific requirements for the campaign, including the target audience and expected outcome.
* **Media Used** (`media_used`, text, required): Specify the media channels that will be used for the campaign (e.g., Facebook, Google Adwords, etc.).
* **Target Audience** (`target_audience`, text, required): Describe the target audience for the campaign, including demographics and interests.
* **Budget** (`budget`, number, required): Enter the allocated budget for the campaign.
* **Expected Return** (`expected_return`, select_one, optional): Select one of the options (Facebook, Google Adwords, Bing Ads) for expected return on investment.
* **Platform** (`platform`, select_multiple, optional): Choose multiple platforms for the campaign (Facebook, Google Adwords, Bing Ads).
* **Expected Return 2** (`expected_return_2`, select_one, optional): Select one of the options (Facebook, Google Adwords, Bing Ads) for expected return on investment.
* **Payment** (`payment`, number, required): Enter the payment amount for the campaign.
* **Payment Terms** (`payment_terms`, text, required): Specify the payment terms, including any additional conditions or agreements.
* **Client Email** (`client_email`, email, required): Enter the client's email address.
* **Client Phone** (`client_phone`, text, required): Enter the client's phone number.
* **Date** (`date`, date, required): Enter the desired campaign start date.
* **Time** (`time`, time, required): Enter the desired campaign start time.
* **Note** (`note`, note, required): Enter any additional notes or comments about the campaign.
* **Additional Info** (`additional_info`, text, required): Provide any additional information about the campaign.
* **Assigned To** (`assigned_to`, select_one, optional): Select the team member assigned to handle the campaign.
* **Notes** (`notes`, text, required): Enter any additional notes or comments about the campaign.
* **Expected Return 3** (`expected_return_3`, select_one, optional): Select one of the options (Facebook, Google Adwords, Bing Ads) for expected return on investment.
* **Platform 2** (`platform_2`, select_multiple, optional): Choose multiple platforms for the campaign (Facebook, Google Adwords, Bing Ads).
* **Payment Terms 3** (`payment_terms_3`, text, required): Specify the payment terms, including any additional conditions or agreements.
* **Payment Terms 4** (`payment_terms_4`, text, optional): Provide any additional payment terms or conditions.
* **Payment Terms 5** (`payment_terms_5`, text, optional): Enter any additional payment terms or conditions.
