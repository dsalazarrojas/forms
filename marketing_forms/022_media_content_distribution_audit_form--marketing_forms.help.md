# Media Content Distribution Audit Form - Help Guide

## Purpose
This form is designed to collect information about media content distribution, specifically for auditing purposes.

## How To Complete This Form
To complete this form, please fill out all the required fields carefully:

## Field-by-Field Explanation

* **Channel ID** (`channel_id`, `number`, required/optional: true): This is the unique identifier for the channel. Please enter the channel ID of the media content.
* **Channel Type** (`channel_type`, `select_one`, required/optional: false): Select the type of channel where the media content was distributed, such as Email, Fax, Phone, or Web.
* **Published At** (`published_at`, `date`, required/optional: false): This is the date when the media content was first published.
* **Effective At** (`effective_at`, `date`, required/optional: false): This is the date when the media content became effective or started being distributed.
* **Channel Name** (`channel_name`, `text`, required/optional: true): This is the name of the channel where the media content was distributed.
* **Message** (`message`, `note`, required/optional: true): This is a brief description of the media content.
* **User ID** (`user_id`, `number`, required/optional: true): This is the unique identifier for the user who distributed the media content.
* **User Name** (`user_name`, `text`, required/optional: false): This is the name of the user who distributed the media content.
* **Email** (`email`, `email`, required/optional: true): This is the contact email of the user who distributed the media content.
* **Phone** (`phone`, `text`, required/optional: true): This is the contact phone number of the user who distributed the media content.
* **Created At** (`created_at`, `date`, required/optional: true): This is the date when the media content was created.
* **Updated At** (`updated_at`, `date`, required/optional: false): This is the date when the media content was last updated.
* **Other** (`channel_type`, `select_one`, required/optional: false): This is another type of channel where the media content was distributed.

Note: The "Other" field is used for non-standard or custom channel types. Please use this field if your channel type is not listed in the "Channel Type" dropdown menu.

## Tips
Please ensure that all required fields are filled out carefully and thoroughly. If you're unsure about any field, please consult with the relevant team members or administrators.
