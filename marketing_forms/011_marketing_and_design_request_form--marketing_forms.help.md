# marketing_and_design_request_form - Help Guide
## Purpose
This form is used to collect marketing and design requests from end-users.

## How To Complete This Form
To complete this form, simply fill out the fields as requested. You can save and continue later if you need to.

## Field-by-Field Explanation
* **marketing_request**:
  * Type: Text
  * Required: Not required
  * Description: Enter a brief summary of your marketing request.
* **design_request**: 
  * Type: Text
  * Required: Not required
  * Description: Enter a brief summary of your design request.
* **request_description**:
  * Type: Text
  * Required: Not required
  * Description: Enter a detailed description of your marketing and design request.
* **assigned_designer**:
  * Type: Text
  * Required: Not required
  * Description: If applicable, enter the name of the person you would like to be assigned to your request.
* **Notes**:
  * Type: None (Not a field)
  * Required: Not required
  * Description: This field is not part of the form, but you may include additional comments or notes if needed.
