# Nick_Carpenter_Sales_Funnel_1 - Help Guide
## Purpose
This form is used to collect sales-related information for lead tracking and analysis.

## How To Complete This Form
1. Fill in the required and optional fields as needed. The form is divided into the following sections:
2. Enter general information about the user: user_info, home_info, and contact_info.
3. Provide details about the lead source.
4. Select the user type and lead type.
5. Add any additional information if necessary, such as phone number, email, date, and time.

## Field-by-Field Explanation
* **User Info (1)**: Enter the user's name and other relevant details.
* **Home Info (2)**: Enter the user's home address or relevant residential information.
* **Contact Info (3)**: Enter the user's contact information, including name and address if applicable.
* **Lead Source (4)**: Describe the source of the lead, e.g., "Social Media", "Referral", etc.
* **User Type (5)**: Select all applicable user types (Yes/No) to categorize the user.
* **Lead Type (6)**: Select all applicable lead types (Option 1/Option 2) to categorize the lead.
* **Phone (7)**: Enter the user's phone number, if applicable.
* **Email (8)**: Enter the user's email address, if applicable.
* **Date (9)**: Enter the date for the lead, if necessary.
* **Time (10)**: Enter the time for the lead, if necessary.
