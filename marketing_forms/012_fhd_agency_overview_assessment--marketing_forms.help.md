# FHD Agency Overview Assessment - Help Guide
## Purpose
The FHD Agency Overview Assessment form is designed to collect essential information about agencies. This form helps gather details such as contact information, services offered, and other relevant data required for agency management.
## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the agency's contact information, including address, phone number, and email.
2. Choose the services offered by the agency from the select_one field.
3. Enter the agency's license number.
4. Assess the agency's rating by selecting one or more rating options.
5. Select the agency's current status.
6. Add any additional notes about the agency.
7. Set the date of the last update.

## Field-by-Field Explanation

* **Agency Overview Form** (`1`, text, optional): Enter a brief description of the agency. This field is meant to provide a short summary of the agency's profile.
* **Contact Info** (`2`, text, optional): Enter the agency's contact information, including name, address, phone number, and email.
* **Agency Details** (`3`, text, optional): Provide a detailed description of the agency, including any necessary background information.
* **Services Offered** (`4`, select_one, optional): Select all the services offered by the agency from the options provided. This field is meant to show the types of services the agency provides.
* **Agency Address** (`5`, text, optional): Enter the agency's physical address.
* **Agency Phone** (`6`, text, optional): Enter the agency's phone number.
* **Agency Email** (`7`, email, optional): Enter the agency's email address.
* **Agency Website** (`8`, text, optional): Enter the agency's website URL.
* **Agency License** (`9`, select_one, optional): Select the agency's license number from the options provided.
* **Agency Rating** (`10`, select_multiple, optional): Assess the agency's rating by selecting one or more rating options. This field helps evaluate the agency's performance.
* **Agency Status** (`11`, select_one, optional): Select the agency's current status from the options provided.
* **Notes** (`12`, text, optional): Add any additional notes or comments about the agency.
* **Date Last Updated** (`13`, date, optional): Set the date of the last update to the agency's information.

Please note that all fields are optional, but it's recommended to fill them out as much as possible for a more comprehensive agency overview.
