# exclusive_sale_signup_form - Help Guide
## Purpose
This form is designed to collect information on exclusive sales events. It is intended for users to provide their details, including contact information, and options for specific events or conditions.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in your First Name.
2. Provide a valid Email address.
3. Confirm your Email address.
4. Enter your Phone number.
5. (Optional) Enter a Date and/or Time.
6. (Optional) Enter a Note if desired.
7. Select one of the options provided (e.g. 'Yes' or 'No').
8. (Optional) Select multiple options if applicable (e.g. 'Yes' or 'No' for multiple conditions).
9. (Optional) Enter an Alias for your First Name, Email, Date, or Phone number if you have a different name/address/number for this event.
10. Confirm your selection for the "Select One" field.
11. Enter a Phone number for the second instance (if necessary).
12. (Optional) Enter a second Date.
13. (Optional) Enter an Email 2 for the second instance.
14. (Optional) Enter a Note 2 for the second instance.
15. (Optional) Select multiple options for the second instance.
16. Confirm your selection for the "Select Multiple" field.
17. Enter a second Phone number.
18. (Optional) Enter a second Date.
19. (Optional) Enter a third Phone number (if necessary).

## Field-by-Field Explanation
- **First Name** (First Name, text, required): Enter your first name.
- **Email** (Email, email, required): Enter a valid Email address.
- **Email Confirmation** (Email Confirmation, text, not required): Confirm your Email address.
- **Phone** (Phone, text, required): Enter your Phone number.
- **Date** (Date, date, not required): Enter a Date if necessary.
- **Time** (Time, time, not required): Enter a Time if necessary.
- **Note** (Note, note, not required): Enter a Note if desired.
- **Select One** (Select One, select_one, required): Select one of the options provided.
- **Select Multiple** (Select Multiple, select_multiple, required): Select multiple options if applicable.
- **First Name (Alias)** (First Name (Alias), text, not required): Enter an Alias for your First Name if you have a different name for this event.
- **Email (Alias)** (Email (Alias), text, not required): Enter an Alias for your Email if you have a different address for this event.
- **Date (Alias)** (Date (Alias), date, not required): Enter an Alias for your Date if you have a different date for this event.
- **Time (Alias)** (Time (Alias), time, not required): Enter an Alias for your Time if you have a different Time for this event.
- **Phone (Alias)** (Phone (Alias), text, not required): Enter an Alias for your Phone number if you have a different number for this event.
- **Email 2** (Email 2, email, not required): Enter an Email 2 for this event.
- **Note (Alias)** (Note (Alias), note, not required): Enter an Alias for your Note if you have a different Note for this event.
- **Select Multiple (Alias)** (Select Multiple (Alias), select_multiple, not required): Select multiple options for this event.
- **Select One (Alias)** (Select One (Alias), select_one, required): Confirm your selection for the "Select One" field.
- **Phone 2** (Phone 2, text, required): Enter a Phone number for the second instance.
- **Date 2** (Date 2, date, not required): Enter a second Date.
- **Email 2** (Email 2, email, not required): Enter an Email 2 for this event.
- **Note 2** (Note 2, note, not required): Enter a second Note if desired.
- **Select Multiple 2** (Select Multiple 2, select_multiple, not required): Select multiple options for the second instance.
- **Phone 3** (Phone 3, text, required): Enter a Phone number for the third instance (if necessary).
- **Select One** (Select One, select_one, required): Enter your selection for the second "Select One" field.
