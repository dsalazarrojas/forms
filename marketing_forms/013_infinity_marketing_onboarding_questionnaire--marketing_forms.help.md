# Infinity Marketing Onboarding Questionnaire - Help Guide

## Purpose
This form is designed to collect information about a new marketing client, including their contact details, onboarding preferences, and marketing budget. This data will help you understand their needs and create a tailored marketing strategy that meets their requirements.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the client's new contact information in the **New Client Information** section.
2. Enter the client's **Client Name**, **Client Email**, and **Client Contact Number**.
3. Select the **Client Role** and **Marketing Agency** to indicate whether the client is a new or existing agency, and whether they require marketing services.
4. Set the **Onboarding Date** and **Onboarding Time** according to your availability.
5. If applicable, provide **Onboarding Notes** and **Next Steps**.
6. Select the **Team Members** responsible for the project.
7. Choose the client's **Client Status** (Active or Inactive).
8. Optionally, select the **Project Start Date** and **Project End Date** if applicable.
9. Enter the **Project Notes** if any.
10. Set the **Marketing Budget** and provide a brief description in the **Marketing Budget Note** field.
11. Select whether the client requires **Social Media** updates.
12. Choose the **Email Frequency** (Yes or No).
13. Optionally, enter the **Email Frequency Note** if needed.
14. Select whether the client requires **Content Creation** (Yes or No).
15. Enter any details in the **Content Creation Note** field.
16. Choose whether the client requires **Lead Generation** (Yes or No).
17. Enter any details in the **Lead Generation Note** field.
18. Select whether the client requires **Lead Conversion** (Yes or No).

## Field-by-Field Explanation
* **New Client Information**: Enter the client's name, email, and contact number to ensure we have a clear point of contact.
* **Client Name**: Enter the name of the client.
* **Client Email**: Enter the client's email address.
* **Client Contact Number**: Enter the client's contact number.
* **Client Role**: Select whether the client is new or an existing agency, and whether they require marketing services.
* **Marketing Agency**: Select whether the client has a marketing agency.
* **Onboarding Date**: Set the date of onboarding according to your availability.
* **Onboarding Time**: Set the time of onboarding according to your availability.
* **Onboarding Notes**: Provide any additional information about the onboarding process.
* **Next Steps**: List any next steps or follow-up tasks.
* **Team Members**: Select the team members responsible for the project.
* **Client Status**: Choose whether the client is Active or Inactive.
* **Project Start Date**: Set the start date of the project if applicable.
* **Project End Date**: Set the end date of the project if applicable.
* **Project Notes**: Enter any additional project details.
* **Marketing Budget**: Enter the marketing budget.
* **Marketing Budget Note**: Enter a brief description of the marketing budget.
* **Social Media**: Select whether the client requires social media updates.
* **Email Frequency**: Choose whether the client requires email updates (Yes or No).
* **Email Frequency Note**: Enter a brief description of the email frequency.
* **Content Creation**: Select whether the client requires content creation (Yes or No).
* **Content Creation Note**: Enter any details about content creation.
* **Lead Generation**: Select whether the client requires lead generation (Yes or No).
* **Lead Generation Note**: Enter any details about lead generation.
* **Lead Conversion**: Select whether the client requires lead conversion (Yes or No).

Note: This form requires filling out 9 required fields and 8 optional fields to provide complete information about the new marketing client.
