# Moodboard Creation Survey - Help Guide
## Purpose
This form is designed to gather feedback on the effectiveness and relevance of moodboards in a given context.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the questions carefully and provide honest and accurate feedback.
2. For each question, provide a response in the text field provided.
3. If you need to select an option, choose the best fit from the provided options.
4. Upload any relevant files by clicking on the "Moodboard File Upload" field.

## Field-by-Field Explanation

* **Submit** (form_submit, select_one, required: false):
	+ This is a final check to ensure you have completed the form and are ready to submit your feedback.
* **Moodboard creation says** (form_text_response_1, text, required: false):
	+ Please share your overall impression of the moodboard creation process.
* **What is the main theme or insight?** (form_text_response_3, text, required: true):
	+ Identify the most important idea or theme that came up during the moodboard creation process.
* **What is the second theme or insight?** (form_text_response_4, text, required: false):
	+ Provide any additional ideas or themes that emerged during the moodboard creation process.
* **Moodboard says best match** (form_select_response_1, select_multiple, required: false):
	+ Select all the options that best describe the moodboard.
* **Moodboard says match** (form_select_response_2, select_one, required: true):
	+ Select the option that best describes the moodboard.
* **Moodboard says don't match** (form_text_response_5, text, required: false):
	+ Explain why the options do not match the moodboard.
* **What is the reason for mismatch?** (form_text_response_6, text, required: false):
	+ Elaborate on why the options do not match the moodboard.
* **What is the suggestion?** (form_text_response_10, text, required: false):
	+ Provide any suggestions for improvement.
* **What should we improve on?** (form_text_response_11, text, required: false):
	+ Identify areas that need improvement.
* **How might we improve it?** (form_text_response_12, text, required: false):
	+ Offer specific ideas for improvement.
* **Next steps** (form_text_response_13, text, required: false):
	+ Describe the next steps for further improvement.
* **Moodboard file upload** (form_file_upload_1, text, required: false):
	+ Upload any relevant files related to the moodboard.
* **Moodboard says important** (form_text_response_15, text, required: false):

* **Moodboard says very important** (form_text_response_16, text, required: false):

* **Moodboard says unimportant** (form_text_response_17, text, required: false):

* **Moodboard says don't know** (form_text_response_18, text, required: false):

* **Moodboard says very don't know** (form_text_response_19, text, required: false):
