# Community Outreach Request Form - Help Guide
## Purpose
The Community Outreach Request Form is designed to collect relevant information from organizations requiring support for their events or projects. By providing a comprehensive understanding of the requested support, the community can effectively assist these organizations, ensuring a positive experience for all parties involved.

## How To Complete This Form
1. Fill out all required fields. Required fields are marked with an asterisk (\*).
2. Ensure accuracy and completeness of the information provided.
3. Select all applicable skills from the "Specific Skills Required" dropdown menu.
4. If this is a recurring event or project, select "True" in the "Is this a recurring event or project?" dropdown menu.
5. Verify the provided information is accurate by signing the "Verification Statement" at the end of the form.

## Field-by-Field Explanation

* **-- Outreach Request Form --**: This is the header of the form. Read the hint for an overview of the request.
* **Name of Requesting Organization**:* This is the name of the organization making the request.
* **Primary Contact Person**:* This is the name of the primary contact person for the requesting organization.
* **Contact Email Address**:* This is the email address of the primary contact person.
* **Contact Phone Number**:* This is the phone number of the primary contact person.
* **Event or Project Title**:* This is the title of the event or project being requested support for.
* **Proposed Event Date**:* Enter the date when the event or project is expected to occur.
* **Event Start Time**:* Enter the time when the event or project is expected to start.
* **Event End Time**:* Enter the time when the event or project is expected to end.
* **Event Location or Address**:* Enter the address of where the event or project will take place.
* **Purpose of Outreach Request**:* Briefly describe the goal of the event or project.
* **Estimated Number of Volunteers Needed**:* Enter the number of volunteers required for the event or project.
* **Specific Skills Required**:* Select all relevant skills required for the event or project. Choose from:
	+ General Labor
	+ Social Media Support
	+ Event Planning
	+ Marketing
	+ Fundraising
	+ First Aid
	+ Other
* **Is this a recurring event or project?**: Select "True" if the event or project is recurring.
* **Description of Volunteer Tasks**:* Provide a detailed description of what volunteers will be doing.
* **Special Requirements**:* List any special requirements, such as background checks, age restrictions, or dress code.
* **-- Verification Statement --**: This is a certification that the provided information is accurate.
	+ By submitting, you certify that the information provided is accurate.
	+ If this form is being submitted for a recurring event or project, the information provided will be updated accordingly.
	+ Inaccurate or misleading information may lead to a misallocation of resources.
	+ Misallocated resources can cause confusion, disappointment, or harm to the community or requesting organization.
