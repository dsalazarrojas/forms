# seo_content_details_form - Help Guide
## Purpose
This form is used to collect and store metadata details for SEO optimization of website content.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the "Content Type" to indicate the type of content being optimized (e.g., article, blog, product).
2. Input "Seo Keywords" to list the relevant keywords associated with the content.
3. Enter the "URL" of the content being optimized.
4. Input "Meta Title", "Meta Description", "Meta Keywords", and other relevant metadata for social media platforms.

## Field-by-Field Explanation

* **Content Details** (`content_details`): A text field to input a brief description of the content.
* **Seo Keywords** (`seo_keywords`): A text field to input a list of relevant keywords associated with the content.
* **Content Type** (`content_type`): Select the type of content (e.g., article, blog, product).
* **URL** (`url`): Enter the URL of the content being optimized.
* **Meta Title** (`meta_title`): Input the title to be used as meta title for social media platforms.
* **Meta Description** (`meta_description`): Input the description to be used as meta description for social media platforms.
* **Meta Keywords** (`meta_keywords`): Input a list of keywords to be used as meta keywords for social media platforms.
* **Meta Image URL** (`meta_image_url`): Input the URL of the image to be used as meta image for social media platforms.
* **Meta Video URL** (`meta_video_url`): Input the URL of the video to be used as meta video for social media platforms.
* **Meta Facebook Image** (`meta_facebook_image`): Input the URL of the Facebook image to be used as meta image for Facebook.
* **Meta Twitter Image** (`meta_twitter_image`): Input the URL of the Twitter image to be used as meta image for Twitter.
* **Meta Open Graph Image** (`meta_open_graph_image`): Input the URL of the Open Graph image to be used as meta image for Open Graph.
* **Meta Twitter Card** (`meta_twitter_card`): Input the Twitter card to be used as meta card for Twitter.
* **Meta Facebook Title** (`meta_facebook_title`): Input the Facebook title to be used as meta title for Facebook.
* **Meta Facebook Description** (`meta_facebook_description`): Input the Facebook description to be used as meta description for Facebook.
* **Meta Facebook Description Length** (`meta_facebook_description_length`): Input the length of the Facebook description.
* **Meta Twitter Description Length** (`meta_twitter_description_length`): Input the length of the Twitter description.
* **Meta Facebook Keywords** (`meta_facebook_keywords`): Input a list of Facebook keywords to be used as meta keywords for Facebook.
* **Meta Twitter Keywords** (`meta_twitter_keywords`): Input a list of Twitter keywords to be used as meta keywords for Twitter.
* **Meta Facebook Video URL** (`meta_facebook_video_url`): Input the URL of the Facebook video to be used as meta video for Facebook.
* **Meta Facebook URL** (`meta_facebook_url`): Input the URL of the Facebook page to be used as meta URL for Facebook.
* **Meta Facebook Image URL** (`meta_facebook_image_url`): Input the URL of the Facebook image to be used as meta image for Facebook.
* **Meta Open Graph Title** (`meta_open_graph_title`): Input the Open Graph title to be used as meta title for Open Graph.
* **Meta Open Graph Description** (`meta_open_graph_description`): Input the Open Graph description to be used as meta description for Open Graph.
* **Meta Open Graph URL** (`meta_open_graph_url`): Input the URL of the Open Graph page to be used as meta URL for Open Graph.

## Tips
* Make sure to input accurate and relevant metadata details for each platform.
* Double-check the length of meta descriptions for Facebook and Twitter to ensure they are within the recommended limits.
* Use the correct image URLs for each platform to ensure proper image display.
* Test and review the content after filling out this form to ensure everything is correctly optimized.
