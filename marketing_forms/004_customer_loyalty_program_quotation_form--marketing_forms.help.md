# Customer Loyalty Program Quotation Form - Help Guide

## Purpose
The purpose of this form is to collect information from customers regarding their participation in a customer loyalty program. This form helps to create a quotation for the customer's loyalty program, which may include details such as the program type, quoted price, terms and conditions, and other relevant information.

## How To Complete This Form
1. Start by filling in your customer's first and last name in the respective fields.
2. Select the type of program you want to offer the customer from the "Program Type" field.
3. Enter the customer's email address in the "Email" field.
4. Enter the customer's phone number in the "Phone" field.
5. If you have any additional notes about the customer, enter them in the "Customer Notes" field.
6. Select the customer's preferred program details from the "Customer Program Preferences" field.
7. Enter the quoted price for the loyalty program in the "Quotation Quoted Price" field.
8. Enter the terms and conditions for the loyalty program in the "Quotation Terms and Conditions" field.
9. If you have any additional business notes, enter them in the "Business Notes" field.
10. Select the sales person responsible for the customer from the "Sales Person" field.
11. Select the start and end dates for the customer's program from the "Customer Program Start Date" and "Customer Program End Date" fields, respectively.

## Field-by-Field Explanation

* **Customer First Name (customer_first_name)**: Enter the customer's first name.
* **Customer Last Name (customer_last_name)**: Enter the customer's last name.
* **Program Type (program_type)**: Select the type of program you want to offer the customer.
* **Email (email)**: Enter the customer's email address.
* **Phone (phone)**: Enter the customer's phone number.
* **Customer Notes (customer_notes)**: Enter any additional notes about the customer.
* **Customer Program Preferences (customer_program_preferences)**: Select the customer's preferred program details.
* **Quotation Quoted Price (quotation_quoted_price)**: Enter the quoted price for the loyalty program.
* **Quotation Terms and Conditions (quotation_terms_and_conditions)**: Enter the terms and conditions for the loyalty program.
* **Business Notes (business_notes)**: Enter any additional business notes.
* **Sales Person (sales_person)**: Select the sales person responsible for the customer.
* **Customer Program Start Date (customer_program_start_date)**: Select the start date for the customer's program.
* **Customer Program End Date (customer_program_end_date)**: Select the end date for the customer's program.

## Tips
* Please ensure that all required fields are completed accurately to avoid any errors or miscommunication.
* If you have any doubts or queries regarding the form, please reach out to the sales person responsible for the customer.
* The form is a critical component of the customer loyalty program process, so please complete it carefully and accurately.
