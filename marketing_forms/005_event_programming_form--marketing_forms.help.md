# Event Programming Form - Help Guide

## Purpose
This form is used for creating or managing events. It allows event organizers or managers to assign events to specific teams or individuals and track their progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the "Event Name" field.
2. Fill in the "Start Date", "End Date", and "Location" fields, if required.
3. Enter the event description and any additional comments or notes.
4. Assign the event to a team or individual by selecting from the "Assignee" dropdown.
5. Confirm you have reviewed the "Terms and Conditions" by selecting the correct options.
6. Optionally, upload any relevant files.
7. Finally, submit the form by selecting "Yes" from the "Submit" dropdown.

## Field-by-Field Explanation

* **Event Name** (`event_programming_form_1_name`, text, **optional**): Enter the name of the event.
* **Start Date** (`event_programming_form_2_start_date`, date, **optional**): Enter the start date of the event.
* **End Date** (`event_programming_form_3_end_date`, date, **optional**): Enter the end date of the event.
* **Description** (`event_programming_form_4_description`, text, **optional**): Enter a brief description of the event.
* **Location** (`event_programming_form_5_location`, text, **optional**): Enter the location of the event.
* **Start Time** (`event_programming_form_6_start_time`, time, **optional**): Enter the start time of the event.
* **End Time** (`event_programming_form_7_end_time`, time, **optional**): Enter the end time of the event.
* **Email** (`event_programming_form_8_email`, email, **optional**): Enter contact email for the event.
* **Phone** (`event_programming_form_9_phone`, text, **optional**): Enter contact phone number for the event.
* **Website** (`event_programming_form_10_website`, text, **optional**): Enter the event website.
* **Tags** (`event_programming_form_11_tags`, select multiple, **required**): Select relevant tags for the event.
* **Assignee** (`event_programming_form_13_assignee`, select one, **required**): Select the team or individual assigned to the event.
* **Submit** (`event_programming_form_14_submit`, select one, **required**): Confirm that you have submitted the form.
* **Terms** (`event_programming_form_15_terms`, select multiple, **required**): Confirm that you have reviewed the terms and conditions.
* **Comments** (`event_programming_form_16_comments`, text, **optional**): Add any additional comments about the event.
* **File** (`event_programming_form_17_file`, text, **optional**): Upload a relevant file for the event.
* **File 2** (`event_programming_form_18_file2`, text, **optional**): Upload another relevant file for the event.
* **Notes** (`event_programming_form_20_notes`, text, **optional**): Enter any additional notes about the event.
* **Event Description** (`event_programming_form_21_description`, text, **optional**): Enter a brief description of the event.
* **Start Date 2** (`event_programming_form_22_start_date`, date, **optional**): Enter the start date of the event.
* **End Date 2** (`event_programming_form_23_end_date`, date, **optional**): Enter the end date of the event.
* **Email 2** (`event_programming_form_24_email`, email, **optional**): Enter contact email for the event.
* **Phone 2** (`event_programming_form_25_phone`, text, **optional**): Enter contact phone number for the event.

## Tips

* Make sure to fill in all required fields.
* Double-check the event details before submitting.
* Review the terms and conditions carefully.
* Use the "Submit" field to confirm that you have submitted the form.
