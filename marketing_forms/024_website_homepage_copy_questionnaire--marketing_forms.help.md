# Website Homepage Copy Questionnaire - Help Guide
## Purpose

The Website Homepage Copy Questionnaire is designed to gather essential information about a website's homepage, including its title, category, description, and assigned tool. This form ensures that the website's content is up-to-date and accurate, providing a smooth user experience.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the **Website Title** field with a concise and descriptive title for the website.
2. Choose the correct **Category** for the website from the list of options provided.
3. Provide a **Description** of the website in the provided field.
4. Indicate if the website is to be assigned a **Tool** from the options available.
5. Enter a file name for the **Output File** in the specified format.
6. Enter the **Form ID**, which should match the ID of the related form.
7. Provide a brief **Description 2** (optional).
8. Choose the correct **Category 2** from the available options.
9. Indicate if the website is to be assigned a **Tool 2** from the options provided.
10. Click the **Submit** button to save your changes.

## Field-by-Field Explanation

* **Website Title** (text, required): Enter a short and descriptive title for the website.
* **Category** (select_one, required): Choose the category that best fits the website's content.
* **Description** (text, required): Provide a brief description of the website.
* **Assigned Tool** (select_one, required): Select the tool that will be used to manage the website.
* **Output File** (text, required): Enter a file name for the website in the specified format.
* **Form ID** (number, required): Enter the ID of the related form.
* **Description 2** (text, optional): Provide an optional description for additional context.
* **Category 2** (select_one, optional): Choose an additional category for the website (if needed).
* **Assigned Tool 2** (select_one, required): Select the tool that will be used for the website's secondary management.
* **Form ID 2** (number, not applicable): This field is not applicable for this form.
* **Tool 2** (select_one, not applicable): This field is not applicable for this form.
