# Event Attendee Interest Survey - Help Guide
## Purpose
This form is designed to collect data about event attendees and their interest in attending an event. The goal is to gather information that can be used to plan and execute the event in an effective and engaging way.

## How To Complete This Form

1. Complete each page in order, from start to finish.
2. Make sure to enter accurate and complete information in each field.
3. Review and submit the form once you have completed all pages.

## Field-by-Field Explanation

* **Event Name**: Enter the name of the event that you are interested in attending, if applicable.
  * Type: text
  * Required: no
* **Attendee Email**: Enter your email address so that we can contact you about the event.
  * Type: email
  * Required: no
* **Attendee Phone**: Enter your phone number so that we can contact you about the event.
  * Type: text
  * Required: no
* **Event Interest**: Indicate whether you are interested in attending the event (yes/no).
  * Type: select_multiple
  * Required: no
  * Options: yes/no
* **Event Description**: Enter a brief description of the event, if applicable.
  * Type: text
  * Required: no
* **Event Date**: Enter the date of the event.
  * Type: date
  * Required: no
* **Event Time**: Enter the time of the event.
  * Type: time
  * Required: no
* **Event Location**: Enter the location of the event, if applicable.
  * Type: text
  * Required: no
* **Event Interest Level**: Indicate the level of interest you have in the event (high/medium/low).
  * Type: select_one
  * Required: no
  * Options: high/medium/low
