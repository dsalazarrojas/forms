# Marketing Reach Evaluation Form - Help Guide
## Purpose
The "Marketing Reach Evaluation Form" is a tool used to assess the performance of marketing channels. It allows users to evaluate the reach and effectiveness of different marketing channels, providing valuable insights for marketing strategy and decision-making.

## How To Complete This Form
To complete the form, follow these steps:

1. Select one or more marketing channels to evaluate (page 1).
2. Choose the performance metric for each selected channel (page 2).
3. Enter the performance metric value (page 3).
4. Indicate the audience reach for each channel (page 4).
5. Select the analysis frequency for each channel (page 5).
6. Identify any growth challenges or issues with each channel (page 6).
7. Indicate whether ongoing marketing analysis is performed for each channel (page 7).
8. Select any additional channels for evaluation (pages 8-12).

## Field-by-Field Explanation
* **Marketing Channel** (`marketing_channel`, select_multiple, optional): Select one or more marketing channels to evaluate.
* **Channel ID** (`channel_id`, select_one, optional): Choose the ID for the selected marketing channel.
* **Channel Performance Metric** (`channel_performance_metric`, text, optional): Enter the performance metric value for the selected channel.
* **Audience Reach** (`audience_reach`, number, optional): Indicate the audience reach for each channel.
* **Analysis Frequency** (`analysis_frequency`, select_one, optional): Select the analysis frequency for each channel.
* **Growth Challenge** (`growth_challenge`, text, optional): Identify any growth challenges or issues with each channel.
* **Ongoing Marketing Analysis** (`ongoing_marketing_analysis`, select_one, optional): Indicate whether ongoing marketing analysis is performed for each channel.
* **Channel ID 2-13** (`channel_id_2-13`, select_one, optional): Select any additional channels for evaluation.
