# Fundraiser Ticket Form - Help Guide
## Purpose

The Fundraiser Ticket Form is used to gather essential information about a fundraising event. This information helps us organize and promote the event effectively.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the name of the event you are promoting or holding.
2. Input the date of the event in the format mm/dd/yyyy or dd/mm/yyyy.
3. Select the start and end time for the event.
4. Provide the exact address of the location where the event will be held.
5. If tickets are being sold, input the price of each ticket.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter a clear and concise name of the event.
* **Event Date** (`event_date`, date, required): Input the date of the event in the format mm/dd/yyyy or dd/mm/yyyy.
* **Event Time** (`event_time`, time, required): Choose the start and end time for the event.
* **Event Address** (`event_address`, text, required): Enter the exact address of the event location.
* **Ticket Price** (`ticket_price`, number, optional): If applicable, input the price of each ticket sold for the event.

## Tips

* Be as specific as possible when entering the event name to avoid confusion.
* Double-check the date and time to ensure accuracy.
* Enter the correct address to provide clear directions to the venue.
* If tickets are being sold, ensure you input the price correctly to reflect the actual cost of the ticket.
