# Creative Project Request Form - Help Guide
## Purpose
This form is designed to collect information about creative projects, including contact details, project manager information, project type, description, budget, and deadline. It will be used to initiate a new project and to facilitate communication between the project team and the client.

## How To Complete This Form
To complete this form, please fill in the following information:

1. **Contact Information**:
	* First and Last name of the contact person
	* Email address of the contact person
	* Phone number of the contact person
2. **Project Manager Information**:
	* First name of the project manager
	* Last name of the project manager
	* Title of the project manager
3. **Project Details**:
	* Type of project (select from the options provided)
	* Description of the project
	* Any additional research or information related to the project
	* Project budget (if applicable)
	* Project deadline (if applicable)

## Field-by-Field Explanation

* **Contact Information** (`contact_first_name`, `contact_last_name`, `email`, `contact_phone`):
	* First and last name of the contact person.
	* Please enter the first and last name of the contact person who is submitting the form.

	* Email address of the contact person.
	* Please enter the email address of the contact person.

	* Phone number of the contact person.
	* Please enter the phone number of the contact person.
* **Project Manager Information** (`project_manager_first_name`, `project_manager_last_name`, `project_manager_title`):
	* First name, last name, and title of the project manager.
	* Please enter the first name, last name, and title of the project manager.
* **Type of Project** (`project_type`):
	* Select the type of project from the options provided.
* **Project Description** (`project_description`):
	* Brief description of the project.

* **Project Research** (`project_research`):
	* Any additional research or information related to the project.

	* Project budget (if applicable).
* **Project Deadline** (`project_deadline`):
	* Project deadline (if applicable).

## Tips

* Please ensure that you fill in the form accurately and completely.
* Please do not submit duplicate form entries.
* If you have any questions or concerns, please don't hesitate to contact us.
