# Content Generation Planning Form - Help Guide

## Purpose
This form is a planning tool used to create, manage, and distribute content effectively. It captures necessary details about a content project, enabling teams to focus on content creation while ensuring that it meets project requirements and goals.

## How To Complete This Form

To fill out this form, simply follow the steps below:

1.  Fill in the project overview section with general information about the content piece.
2.  Enter a working title for the content piece, which can be a placeholder or a suggested title.
3.  Select the type of content (e.g., Blog Post, Whitepaper).
4.  Identify the target audience for the content piece.
5.  Determine the primary goal of the content (e.g., Brand Awareness, Lead Generation).
6.  In the strategic details section, you can jot down key points about SEO and distribution planning, as needed.
7.  Provide focus keywords for the content piece.
8.  Specify the key takeaways the reader should remember.
9.  In the production schedule section, you can note down deadlines and responsibilities, as applicable.
10. Enter the deadline for the first draft.
11.  Plan the target publication date for the content.
12.  Name the person assigned to write the content.
13.  If applicable, estimate the budget for the content piece.
14.  Click submit to complete the form and start the content generation process.

## Field-by-Field Explanation

*   **-- Project Overview --** (`project_overview_header`, `note`, required: false): 
    *   This is a general information section for the content piece. Enter any relevant details about the content that doesn’t fit into other sections.
*   **Working Title** (`content_title_working`, `text`, required: true): 
    *   A placeholder or suggested title for the content piece.
*   **Content Type** (`content_type`, `select_one`, required: true): 
    *   What format will this content take (e.g., Blog Post, Whitepaper).
*   **Target Audience** (`target_audience`, `text`, required: true): 
    *   Who is this content specifically for.
*   **Primary Goal** (`primary_goal`, `select_one`, required: true): 
    *   What is the main objective of this content (e.g., Brand Awareness, Lead Generation).
*   **-- Strategic Details --** (`strategic_details_header`, `note`, required: false): 
    *   Key points about SEO and distribution planning.
*   **Focus Keywords** (`focus_keywords`, `text`, required: false): 
    *   Primary and secondary keywords for SEO.
*   **Key Takeaways** (`key_takeaways`, `text`, required: true): 
    *   What 3 things the reader should remember.
*   **Distribution Channels** (`distribution_channels`, `select_multiple`, required: true): 
    *   Where will this be published (e.g., Company Website, LinkedIn, Twitter).
*   **-- Production Schedule --** (`production_schedule_header`, `note`, required: false): 
    *   Deadlines and responsibilities for content creation and publication.
*   **Draft Deadline** (`draft_deadline`, `date`, required: true): 
    *   When the first draft should be ready.
*   **Target Publication Date** (`publication_date`, `date`, required: true): 
    *   Planned date for going live.
*   **Assigned Writer** (`assigned_writer`, `text`, required: false): 
    *   Name of the person responsible for the draft.
*   **Estimated Budget** (`budget_allocation`, `number`, required: false): 
    *   If applicable, enter total budget for this content piece.
