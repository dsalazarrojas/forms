# Street Sheet - Help Guide
## Purpose
The Street Sheet form is used to collect information about a street or location.

## How To Complete This Form
- Fill in the Street Address field with the exact address of the street.
- Select either 'Yes' or 'No' in the Data Type field, indicating the type of data related to the street. 
  * If you select 'Yes', we will ask for more detailed information on subsequent forms or pages.
  * If you select 'No', the form will proceed without further questions.
- Enter the start and end dates of the activity or event in the corresponding fields, using the date format (YYYY-MM-DD).
- If applicable, fill in the Start Time field with the start time of the activity or event, using the time format (HH:MM AM/PM).

## Field-by-Field Explanation

* **Street Address** (street_address, text, required/optional): Enter the exact address of the street, including any relevant details such as house numbers or street names.
* **Data Type** (data_type, select_one, required/optional): Select 'Yes' if the street has data or activity related to it, such as events or construction. Select 'No' otherwise.
* **Start Date** (start_date, date, required/optional): Enter the start date of the activity or event, using the date format (YYYY-MM-DD). This field is optional.
* **End Date** (end_date, date, required/optional): Enter the end date of the activity or event, using the date format (YYYY-MM-DD). This field is optional.
* **Start Time** (start_time, time, required/optional): Enter the start time of the activity or event, using the time format (HH:MM AM/PM). This field is optional.

## Tips
- Be accurate when filling out the Street Address field to ensure the correct location is represented.
- Select 'Yes' in the Data Type field only if there is activity or data related to the street.
- Enter the start and end dates and start time fields only if the activity or event has a specific start and end time.
