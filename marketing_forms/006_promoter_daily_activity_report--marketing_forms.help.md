# Promoter Daily Activity Report - Help Guide
## Purpose
The Promoter Daily Activity Report is a form used to track and record daily activities of promoters. It is meant to be completed by promoters and is a crucial tool for tracking their progress.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your User ID to identify yourself as the promoter.
2. Enter the date when the form is being completed.
3. Check off 'Yes' or 'No' to indicate whether you were actively promoting or not.
4. Add any additional notes or comments in the Notes field.
5. Enter your contact information in the Email and Phone fields.
6. Select whether you are Active or Inactive in the Status field.
7. Check off whether you have been assigned to a specific user in the Assigned User field.
8. Enter the tool used for promotion in the Assigned Tool field.
9. Enter any additional information about the tool used for promotion in the Assigned Tool Id field.
