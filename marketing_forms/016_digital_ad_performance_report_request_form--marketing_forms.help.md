# Digital Ad Performance Report Request Form - Help Guide
## Purpose
This form is used to request a report on the performance of digital ads.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of campaign you are requesting a report for (e.g. Facebook Ads, Google Ads, Instagram Ads, or Other).
2. Enter the campaign details, including the campaign name, start date, and end date.
3. Select the performance metrics you would like to see in the report.
4. Enter any additional information about the campaign, such as the target audience.

## Field-by-Field Explanation
* **Campaign Details** (`campaign_details`, `text`, required: false):
  * Enter a brief description of the campaign you are requesting a report on.
* **Date Range** (`date_range`, `text`, required: false):
  * Enter the date range for which you would like to see the report.
* **Performance Metrics** (`performance_metrics`, `text`, required: false):
  * Select up to five performance metrics you would like to see in the report.
* **Campaign Duration** (`campaign_duration`, `number`, required: false):
  * Enter the duration of the campaign in days.
* **Campaign Start Date** (`campaign_start_date`, `date`, required: false):
  * Enter the start date of the campaign.
* **Campaign End Date** (`campaign_end_date`, `date`, required: false):
  * Enter the end date of the campaign.
* **Campaign Type** (`campaign_type`, `select_one`, required: false):
  * Select the type of campaign (e.g. Facebook Ads, Google Ads, Instagram Ads, or Other).
* **Campaign Budget** (`campaign_budget`, `number`, required: false):
  * Enter the budget for the campaign.
* **Target Audience** (`target_audience`, `select_multiple`, required: false):
  * Select whether the target audience was reached.
* **Ad Campaign ID** (`ad_campaign_id`, `text`, required: false):

## Tips
* Please make sure to fill out the form as completely as possible to ensure the report is accurate and meets your needs.
* If you are unsure about any of the fields, feel free to contact the support team for assistance.
* If you would like to request a report on multiple campaigns, you will need to submit multiple forms.
