# Marketing Campaign Asset Upload Form - Help Guide
## Purpose
The Marketing Campaign Asset Upload Form is used to upload and collect metadata for marketing campaign assets.

## How To Complete This Form
1. Please complete each page of the form according to the explanations below.
2. Review your answers for accuracy and completeness before submitting the form.

## Field-by-Field Explanation

* **Page 1: Upload your assets**:
  This page is a general instructions page, and no specific information is required.
  You can proceed to the next page.
* **Page 2: File Upload**:
  * **File Upload**: Upload a file to be used as an asset.
  Please select the file to be uploaded from your local computer or device.
* **Page 3: File Description**:
  * **File Description**: Provide a brief description of the file.
  This description will be used to help identify the file for the campaign.
  Please keep the description concise and relevant to the file.
* **Page 4: Prophets**:
  * **Prophets**: Select the type of prophet for the campaign.
  Please choose one of the provided options.
* **Page 5: File URL**:
  * **File URL**: Enter the URL of the file if it is stored online.
  This will help track the file's original location.
  Please ensure the URL is correct and up-to-date.
* **Page 6: File Type**:
  * **File Type**: Select the type of file (e.g., image, video, or text).
  Please choose one of the provided options.
* **Page 7: File Size**:
  * **File Size**: Enter the file size in bytes.
  This is optional, but it will help with data tracking.
  Please enter a valid number.
* **Page 8: Email**:
  * **Email**: Enter a valid email address.
  This will be used for contact and communication purposes.
  Please ensure the email is correct and up-to-date.
* **Page 9: Phone**:
  * **Phone**: Enter a valid phone number.
  This will be used for emergency contact purposes.
  Please ensure the number is correct and up-to-date.
* **Page 10: Campaign Name**:
  * **Campaign Name**: Enter a unique name for the campaign.
  Please choose a descriptive name for easy identification.
* **Page 11: Campaign Description**:
  * **Campaign Description**: Provide a brief description of the campaign.
  This will help with tracking and reporting.
  Please keep the description concise and relevant.
* **Page 12: Campaign URL**:
  * **Campaign URL**: Enter the URL of the campaign if it is stored online.
  This will help track the campaign's original location.
  Please ensure the URL is correct and up-to-date.
* **Page 13: Campaign File Upload**:
  * **Campaign File Upload**: Upload a file containing campaign information.
  Please select the file to be uploaded from your local computer or device.
  Ensure the file is in the correct format and is not too large.

Note: The fields and pages in this form are subject to change as per business needs. This guide is a snapshot of the form as of the current date. Always refer to your internal documentation or support team for any updates.
