# Web Banner Creation Request Form - Help Guide
## Purpose
The purpose of this form is to collect and document web banner creation requests from internal stakeholders. Please fill out this form to provide detailed information about the banner you want to create.

## How To Complete This Form
- Read the form instructions and explanations carefully.
- Provide accurate and complete information for each field.
- Click the submit button to send the form.

## Field-by-Field Explanation
* **Web Banner Creation Request**: (`web_banner_creation_request_form`, text, optional) This field is a brief description of the web banner creation request. Please provide a short description of the banner you want to create.
* **Banner Description**: (`banner_description`, text, optional) This field is a detailed description of the banner design and requirements. Please provide as much information as possible about the banner's content, size, and color scheme.
* **Web Designer**: (`web_designer`, select_one, optional) This field is a list of available web designers. Please select the designer you would like to work on your banner project.
* **Web Designer Email**: (`web_designer_email`, email, optional) This field is the email address of the selected web designer. Please ensure you have the correct email address.
* **Web Designer Phone**: (`web_designer_phone`, text, optional) This field is the phone number of the selected web designer. Please provide the correct phone number.
* **Web Banner Image**: (`web_banner_image`, text, optional) This field is the URL or path to the banner image file. Please provide the complete path or URL.
* **Banner Due Date**: (`banner_due_date`, date, optional) This field is the due date for the banner creation. Please select a date and time for the banner completion.
* **Banner Due Time**: (`banner_due_time`, time, optional) This field is the due time for the banner completion. Please select a time for the banner completion.
* **Web Designer Note**: (`web_designer_note`, text, optional) This field is for any additional notes or comments to the web designer. Please provide any specific requirements or instructions for the banner.
