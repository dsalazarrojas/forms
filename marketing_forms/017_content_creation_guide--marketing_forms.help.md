# Content Creation Guide - Help Guide
## Purpose
This form helps teams and individuals create high-quality content for various marketing purposes. It ensures that all necessary information is gathered to produce well-informed and effective content.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project details:
	* Project Name: Enter the name of the content project.
	* Project Manager: Enter the name of the person managing this project.
	* Content Creator: Enter the name of the person creating the content.
2. Set up the project scope:
	* Request Date: Enter the date of this content request.
	* Content Type: Select the type of content needed (e.g., Blog Post, Social Media Post, etc.).
3. Define the project objectives and target audience:
	* Content Objective: Select the main goal of this content (e.g., Lead Generation, Brand Awareness, etc.).
	* Target Audience: Enter the details of the audience this content is for.
	* Key Message: Enter the main message to convey.
4. Determine the content specifics:
	* Tone of Voice: Choose the tone for the content (e.g., Professional, Casual, etc.).
	* Brand Guidelines: Check if there are specific brand guidelines to follow.
	* Word Count: Select the desired length of the content.
5. Finalize the project:
	* Distribution Channels: Choose where the content will be published.
	* Review Process: Specify who needs to review the content before publication.
	* Budget: Enter the budget for this content piece.
	* Success Metrics: Enter how success will be measured.
	* Additional Notes: Add any other important information.

## Field-by-Field Explanation
### **Project Name (1)** (`Project Name`, text, required)
The Project Name field is where you enter the name of the content project. This will help identify and organize the project.

### **Project Manager (2)** (`Project Manager`, text, required)
The Project Manager field is where you enter the name of the person managing this project. This ensures that the person responsible is aware of the project details.

### **Content Creator (3)** (`Content Creator`, text, required)
The Content Creator field is where you enter the name of the person creating the content. This ensures that the content creator is aware of their role and responsibilities.

### **Request Date (4)** (date, required)
The Request Date field is where you enter the date of this content request. This helps track the project timeline.

### **Content Type (5)** (select_one, required)
The Content Type field is where you select the type of content needed (e.g., Blog Post, Social Media Post, etc.). This ensures that the content creation process is tailored to the content type.

### **Content Objective (6)** (select_one, required)
The Content Objective field is where you select the main goal of this content (e.g., Lead Generation, Brand Awareness, etc.). This guides the content creation process to achieve the desired outcome.

### **Target Audience (7)** (text, required)
The Target Audience field is where you enter the details of the audience this content is for. This helps create content relevant to the target audience's needs and interests.

### **Audience Demographics (8)** (text, optional)
The Audience Demographics field is where you enter the age, gender, location, and interests of the target audience. This information is helpful for tailoring the content to the specific audience.

### **Key Message (9)** (text, required)
The Key Message field is where you enter the main message to convey. This ensures that the content effectively communicates the intended message.

### **Tone of Voice (10)** (select_one, required)
The Tone of Voice field is where you choose the tone for the content (e.g., Professional, Casual, etc.). This determines the language and style of the content.

### **Brand Guidelines (11)** (select_one, required)
The Brand Guidelines field is where you check if there are specific brand guidelines to follow. This ensures that the content adheres to the brand's voice and style.

### **Target Word Count (12)** (select_one, required)
The Target Word Count field is where you select the desired length of the content. This guides the content creation process to ensure it meets the required word count.

### **SEO Keywords (13)** (text, optional)
The SEO Keywords field is where you enter keywords to include for SEO purposes. This optimizes the content for search engines.

### **Call to Action (14)** (text, required)
The Call to Action field is where you enter the action readers should take. This drives engagement and conversions.

### **Reference Materials (15)** (text, optional)
The Reference Materials field is where you link or document materials for reference. This provides additional context and information.

### **Competitor Examples (16)** (text, optional)
The Competitor Examples field is where you link to competitor content for reference. This helps create content that stands out from the competition.

### **Distribution Channels (17)** (select_multiple, required)
The Distribution Channels field is where you choose where the content will be published (e.g., Company Website, Facebook, etc.). This ensures that the content reaches the intended audience.

### **Content Deadline (18)** (date, required)
The Content Deadline field is where you enter the date the content is due. This tracks the project timeline.

### **Review Process (19)** (text, required)
The Review Process field is where you specify who needs to review the content before publication. This ensures that the content meets the required standards.

### **Budget (20)** (select_one, optional)
The Budget field is where you enter the budget for this content piece. This tracks the financial resources allocated for the project.

### **Success Metrics (21)** (text, optional)
The Success Metrics field is where you enter how success will be measured. This evaluates the project's outcome and effectiveness.

### **Additional Notes (22)** (text, optional)
The Additional Notes field is where you enter any other important information. This provides context and clarity to the project.

Please refer back to the form for any field that may have additional options or instructions. If you have any questions or concerns, please don't hesitate to reach out to form@gic.mx.
