# Brownies Order Form - Help Guide
## Purpose
The Brownies Order Form is a simple form designed to collect customer information for order purposes. It is meant to be used by customers to place an order with the bakery for brownies.

## How To Complete This Form
To complete this form, simply fill in the required fields with your details and preferences.

## Field-by-Field Explanation
* **Customer name** (`customer_name`, text, required): Enter your full name as you would like it to appear on the order receipt.
* **Contact email** (`contact_email`, email, required): Enter the email address you would like to use for order confirmation and updates.
* **Phone number** (`phone_number`, text, optional): If you have a preferred phone number to contact you, enter it here. This is not required for order processing.
* **Brownie flavor** (`brownie_flavor`, select_one, required): Choose the type of brownie you would like to order from the available flavors. Options include Classic chocolate, Salted caramel, and Peanut butter.
* **Quantity** (`quantity`, number, required): Enter the number of brownies or boxes you would like to order.
* **Pickup or delivery** (`pickup_or_delivery`, select_one, required): Choose how you would like to receive your order. Options include Pickup or Delivery.
* **Delivery address** (`delivery_address`, text, optional): If you have selected delivery, enter the address where you would like to receive your order. This field is not required if you have chosen Pickup.
* **Special instructions** (`special_instructions`, text, optional): If you have any special requests or allergies, or would like to add a gift note, enter it here. This field is not required for order processing.
