# Cake Pop Order Form Template - Help Guide
## Purpose
This form is designed to collect information for a custom cake pop order. The form is divided into several sections, each with specific fields that help us understand your order requirements. Please fill out the form carefully to ensure that we can create the perfect cake pops for your event or occasion.

## How To Complete This Form
1. Click on each page (or section) to navigate through the form.
2. Fill out the required fields marked with an asterisk (*) as you work through each section.
3. Make sure to enter accurate and complete information for each field.

## Field-by-Field Explanation
### Page 1: Customer Information
* **Your Name** (Your Name, text, required): Enter your full name as you would like it to be printed on the cake pops.
* **Email Address** (Email Address, email, required): Enter a valid email address where we can contact you for questions or updates.
* **Phone Number** (Phone Number, text, required): Enter your phone number in case we need to contact you for more information.
* **Event Date** (Event Date, date, required): Enter the date of the event or occasion where you plan to enjoy the cake pops.

### Page 2: Cake Pop Order Details
* **Cake Pop Flavor** (Cake Pop Flavor, select_one, required): Choose the flavor of cake pop you would like (e.g., Chocolate, Vanilla, Red Velvet, etc.).
* **Chocolate Coating Type** (Chocolate Coating Type, select_one, required): Select the type of chocolate coating you prefer (e.g., Dark Chocolate, Milk Chocolate, etc.).
* **Quantity of Cake Pops** (Quantity of Cake Pops, number, required): Enter the number of cake pops you would like to order.
* **Decoration Options** (Decoration Options, select_multiple, optional): Choose any additional decoration options you would like (e.g., Sprinkles, Pearl beads, etc.).
* **Custom Design Request?** (Custom Design Request?, select_one, required): Select yes if you have a custom design in mind.
* **Design Details** (Design Details, text, optional): Enter details about your custom design if you selected yes in the previous question.
* **Dietary Information** (Allergies or Dietary Restrictions, text, optional): If you have any dietary restrictions or allergies, list them here.

### Page 3: Delivery/Pickup
* **Delivery or Pickup?** (Delivery or Pickup?, select_one, required): Choose whether you would like to pick up your order or have it delivered.
* **Delivery Address** (Delivery Address, text, optional): If you selected delivery, enter your delivery address.
* **Delivery/Pickup** (Delivery/Pickup, note, required): This is just a page header, not a field to fill.

### Page 4: Payment Information
* **Estimated Total Cost** (Estimated Total Cost, number, optional): This field will be calculated based on your order.
* **Preferred Payment Method** (Preferred Payment Method, select_one, required): Select how you would like to pay for your order (e.g., Credit Card, Debit Card, etc.).
* **Special Requests** (Special Requests, text, optional): If you have any special requests or notes, enter them here.
* **Payment Information** (Payment Information, note, required): This is just a page header, not a field to fill.

Please note that some fields are optional and can be skipped if not applicable. If you have any questions or need further clarification, don't hesitate to reach out to us.
