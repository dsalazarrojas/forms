# easter_brunch_order_form - Help Guide
## Purpose
This form is designed to collect information from users for an Easter brunch order. It will help you gather details about the number of guests, their preferences, and additional requests. 

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the number of guests attending the Easter brunch.
2. Choose whether the guests will have a brunch time preference.
3. Provide any special requests or notes for the order.
4. Answer questions about Easter baskets, eggs, cake, and other items.
5. Specify the number of items you would like to order.
6. Enter the order total.
7. Provide your name.
8. Answer questions about Easter desserts, coffee, and other items.
9. Select the number of Easter presents and other items you would like.
10. Enter any additional details or notes.

## Field-by-Field Explanation
* **Easter Brunch Guests** (`easter_brunch_guests`, select_one, required: false): This field asks if guests are attending the Easter brunch.
* **Brunch Time** (`brunch_time`, select_one, required: false): Choose if the guests have a brunch time preference.
* **Special Request** (`special_request`, note, required: false): Enter any special notes or requests for the order.
* **Order Details** (`order_details`, select_multiple, required: false): Select any additional details or requests about the order.
* **Easter Eggs** (`easter_eggs`, number, required: false): Specify the number of Easter eggs you would like to order.
* **What Time** (`brunch_time_2`, time, required: false): Enter the time for the Easter brunch.
* **Easter Baskets** (`easter_baskets`, select_multiple, required: false): Select the type of Easter baskets you would like to order.
* **Easter Cake** (`easter_cake`, select_one, required: false): Choose if you would like to order an Easter cake.
* **Special Request 2** (`special_request_2`, select_multiple, required: false): Enter any additional special requests.
* **Easter Egg Hunt** (`easter_egg_hunt`, note, required: false): This is a note field for any additional information.
* **Order Total** (`order_total`, number, required: false): Enter the total order amount.
* **Name** (`name`, text, required: false): Enter your name.
* **Number of Attendees** (`easter_brunch_attendees`, number, required: false): Specify the number of people attending.
* **Easter Desserts** (`easter_desserts`, select_multiple, required: false): Select the types of Easter desserts you would like to order.
* **Easter Coffee** (`easter_coffee`, select_one, required: false): Choose if you would like to order Easter coffee.
* **Easter Presents** (`easter_presents`, select_multiple, required: false): Select the types of Easter presents you would like to order.
* **Easter Presents 2** (`easter_presents_2`, select_one, required: false): Choose if you would like to order Easter presents.
* **Easter Fruit** (`easter_fruit`, select_multiple, required: false): Select the types of Easter fruit you would like to order.
* **Easter Chocolate** (`easter_choclate`, select_one, required: false): Choose if you would like to order Easter chocolate.
* **Easter Flowers** (`easter_flowers`, select_one, required: false): Choose if you would like to order Easter flowers.
* **Easter Favors** (`easter_favors`, select_multiple, required: false): Select the types of Easter favors you would like to order.
* **Easter Cards** (`easter_cards`, select_multiple, required: false): Select the types of Easter cards you would like to order.
* **Easter Cake 2** (`easter_cake_2`, select_one, required: false): Choose if you would like to order Easter cake 2.
