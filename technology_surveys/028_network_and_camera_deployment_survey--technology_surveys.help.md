# Network And Camera Deployment Survey - Help Guide
## Purpose
This form is designed to collect information about a site's network and camera deployment.

## How To Complete This Form

1. Please select "Next" to progress through the form.
2. For each field, provide the requested information or select an option from the list.
3. If a field has a "required" label, ensure that you enter information in that field.
4. If a field has a "select_multiple" or "select_one" type, select one or more options from the list.
5. If you encounter any issues or have questions, refer to the Field-by-Field Explanation section for more information.
