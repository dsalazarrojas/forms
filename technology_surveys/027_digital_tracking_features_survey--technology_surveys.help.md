# digital_tracking_features_survey - Help Guide

## Purpose
This form is designed to collect feedback on digital tracking features from end users. It will help us understand your preferences and experiences with these features.

## How To Complete This Form
1. Select all the options that apply to you.
2. Be as honest as possible when providing your feedback.

## Field-by-Field Explanation

Select all the features that you have used or would like to use for tracking:
