# tech_gadget_consumer_preference_poll - Help Guide
## Purpose
This form aims to collect information on consumers' preferences and behaviors regarding technology gadgets, specifically their device ownership, priorities when choosing a new phone, buying plans, and features of their current phone.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer "Do you own a smartphone?" on **Page 1: device_ownership**.
	* Select 'True' if you own a smartphone, or 'False' if you do not.
2. On **Page 2: priority_1**, select all priorities that are important to you when choosing a new phone.
	* Priorities include Price, Camera, Battery, Storage, and Performance.
3. On **Page 3: buying_intents**, select all plans where you would buy a new phone.
	* Plans include Online, Retail, and Other.
4. On **Page 4: features**, select all features that your current phone has.
	* Features include GPS, Touch Screen, Camera, Headphone Jack, and Microphone.
5. Add any additional information or comments in **Page 5: notes**.

## Field-by-Field Explanation
* **Do you own a smartphone?** (`device_ownership`, `select_one`, **Required: False**):
	+ This question helps us understand how many consumers own smartphones, which is essential for our research.
* **What is your priority for a new phone?** (`priority_1`, `select_multiple`, **Required: False**):
	+ This question gauges the importance of different features when choosing a new phone.
* **What do you plan to buy next?** (`buying_intents`, `select_multiple`, **Required: False**):
	+ This question helps us understand the preferred channels for purchasing new phones.
* **Which of the following features does your current phone have?** (`features`, `select_multiple`, **Required: True**):
	+ This question helps us understand the current phone market landscape and features offered by various phones.
* **Additional notes** (`notes`, `note`, **Required: False**):
	+ This field is for any additional information or comments you'd like to provide.

## Tips
- Please answer all questions truthfully to ensure accurate data.
- Ensure all required fields are completed before submitting the form.
- If you have any questions or concerns, feel free to contact us.
