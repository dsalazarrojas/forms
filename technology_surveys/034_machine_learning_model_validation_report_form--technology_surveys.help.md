## Field-by-Field Explanation

*   **General Information (Page 1)** (`title`, `string`, required): Fill in the title of the report.
*   **Model Info (Page 2)** (`model_info`, `string`, required): Enter the details of the model being evaluated.
*   **ML Evaluation (Page 3)** (`ml_evaluation`, `string`, optional): Enter any additional information about the model evaluation.
*   **Evaluation Info (Page 4)** (`evaluation_info`, `string`, optional): Enter any extra information related to the evaluation.
*   **Performance Metrics (Page 5)** (`performance_metrics`, `string`, optional): Enter the performance metrics of the model.
*   **Evaluation Criteria (Page 6)** (`evaluation_criteria`, `select_multiple`, required): Select the evaluation criteria that was used.
*   **Evaluation Outcome (Page 7)** (`evaluation_outcome`, `string`, optional): Enter the outcome of the evaluation.
*   **Evaluation Comments (Page 8)** (`evaluation_comments`, `string`, optional): Enter any comments about the evaluation.
*   **Performance Score (Page 9)** (`performance_score`, `number`, required): Enter the score of the model's performance.
*   **Model Name (Page 10)** (`model_name`, `string`, required): Enter the name of the model.
*   **Model Type (Page 11)** (`model_type`, `string`, required): Enter the type of the model.
*   **Model Version (Page 12)** (`model_version`, `string`, required): Enter the version of the model.
*   **Model Description (Page 13)** (`model_description`, `string`, required): Enter a description of the model.
*   **Model Evaluations (Page 14)** (`model_evaluations`, `string`, optional): Enter any additional evaluations of the model.
*   **Team Name (Page 15)** (`team_name`, `string`, required): Enter the name of the team that evaluated the model.
*   **Team Members (Page 16)** (`team_members`, `select_multiple`, required): Select the team members involved in the evaluation.
*   **Evaluation Date (Page 17)** (`evaluation_date`, `date`, required): Enter the date of the evaluation.
*   **Evaluation Time (Page 18)** (`evaluation_time`, `time`, optional): Enter the time of the evaluation.
*   **Evaluation Timezone (Page 19)** (`evaluation_timezone`, `string`, optional): Enter the timezone of the evaluation.

*   **Submission Useragent (Page 25)** (`submission_useragent`, `string`, optional): Enter the user agent of the submission.
