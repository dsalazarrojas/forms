# vlan_knowledge_assessment - Help Guide
## Purpose
This form is used to gauge your knowledge about virtual LAN (VLAN) settings. Please answer the questions truthfully to provide an accurate assessment of your knowledge level.

## How To Complete This Form
To complete this form, simply select the correct answer for each question. You can select one or multiple options depending on the field type.

## Field-by-Field Explanation

* **vlan_config** (`vlan_config`, select_one, optional): Select one of the following options:
	+ Yes
	+ No
* **vlan_id** (`vlan_id`, select_multiple, optional): Select all that apply:
	+ Yes
	+ No
* **vlan_name** (`vlan_name`, text, optional): Enter your answer in the text field.
* **vlan_status** (`vlan_status`, select_one, optional): Select one of the following options:
	+ Active
	+ Inactive
* **vlan_type** (`vlan_type`, select_multiple, optional): Select all that apply:
	+ Yes
	+ No
* **vlan_ports** (`vlan_ports`, select_multiple, optional): Select all that apply:
	+ Yes
	+ No
* **vlan_trunking** (`vlan_trunking`, select_multiple, optional): Select all that apply:
	+ Yes
	+ No
* **vlan_ports_config** (`vlan_ports_config`, select_one, optional): Select one of the following options:
	+ Yes
	+ No
* **vlan_trunking_config** (`vlan_trunking_config`, select_multiple, optional): Select all that apply:
	+ Yes
	+ No
* **vlan_trunking_status** (`vlan_trunking_status`, select_one, optional): Select one of the following options:
	+ Active
