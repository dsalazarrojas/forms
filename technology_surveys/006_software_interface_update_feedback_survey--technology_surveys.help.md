# Software Interface Update Feedback Survey - Help Guide
## Purpose
This form is used to collect feedback on the software interface updates.

## How To Complete This Form
To complete this form, simply fill out the fields as follows:

*   Fill out the fields as you see fit, providing a brief description or comment on the fields that apply to you.
*   Be honest and thorough in your feedback, it will help us improve the software interface.

## Field-by-Field Explanation
*   **Software Interface Update Feedback**: This field is for you to type in your comments or suggestions on the software interface. Please be detailed and specific about your issue or suggestion.
*   **Overall Satisfaction**: Please select a number between 1 (very dissatisfied) and 5 (very satisfied) to rate your overall satisfaction with the software interface.
*   **Usability issues**: If you have encountered any usability issues, please describe them here.
*   **Feedback**: This field is for you to provide any additional comments or feedback on the software interface.
*   **Comments**: This field is for you to provide any additional comments or feedback.
*   **Email**: Please enter your email address so we can contact you if we need more information.
*   **Phone**: Please enter your phone number so we can contact you if we need more information.
*   **Category**: Please select which category best fits your feedback: Team, User, Administrator, or Other.
*   **Role**: If you are a Team Member, Team Administrator, Other (e.g. Customer Support), please select which role best fits your feedback.
*   **Date**: If you are providing feedback on a specific date, please enter it here.
*   **Time**: If you are providing feedback on a specific time, please enter it here.
*   **Assigned Tool**: Please select which tool you are using to submit this form: Google Forms, Jotform, or Other.
*   **Output File**: Please select which file format you would like the output to be in: pdf, excel, csv, or other.
*   **Comments**: This field is for you to provide any additional comments or feedback.

## Tips
*   Be honest and thorough in your feedback.
*   Only fill out this form if you have a specific issue or suggestion for improvement.
*   If you have any further questions or concerns, please contact us at [insert contact information].
