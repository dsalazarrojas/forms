# Network Cost Assessment Survey - Help Guide
## Purpose
This form is designed to gather information about the cost implications of a network infrastructure or service. It is intended for use in assessing the current costs associated with your network and identifying potential opportunities for cost optimization. Please ensure that you are taking this survey if it aligns with your current situation and responsibilities.

## How To Complete This Form
- **Read each page carefully**: Each page will cover a different topic.
- **Answer each question**: Respond to each page's questions as accurately as possible.
- **Be honest and thorough**: Provide truthful information about your current costs and challenges.

## Field-by-Field Explanation
- **Network Cost Assessment Survey (Page 1)**: This page allows you to indicate whether you are currently assessing or optimizing costs. If "No" is chosen, you can move on to the next page.
  **cost_category (Page 2)**: Select one option for each category that best describes your current cost assessment situation: 
  - **Yes** - You are currently assessing or optimizing costs in this category.
  - **No** - This category does not apply to your current cost assessment situation.
- **cost_frequency (Page 3)**: Select all applicable options that best describe when you are currently assessing or optimizing costs:
  - **Yes** - Daily
  - **No** - Weekly, Monthly, Quarterly, Yearly
  - **No** - Other (Provide explanation in cost_optimization_opportunities)
  - **No** - Never
- **cost_value (Page 4)**: Enter a numeric value (e.g., dollar amount) for your current costs.
- **comment (Page 5)**: Add any additional comments or explanations about your cost assessment situation.
- **email (Page 6)**: Enter your contact email address for follow-up.
- **phone (Page 7)**: Enter your contact phone number for follow-up.
- **cost_optimization_opportunities (Page 8)**: If none of the provided options for cost_frequency apply, or if you have any additional comments, provide a description of your cost optimization opportunities.

Note: Some fields are not required, but it's essential to answer them for a more accurate assessment.
