# FinOps Tool Evaluation Survey - Help Guide
## Purpose

This form is designed to gather your feedback on the FinOps tools you've used. Your input will help us improve these tools and provide better support for the community.

## How To Complete This Form

1. Please select the tool you're evaluating and fill out the required fields.
2. Rate the tool based on your experience.
3. Provide your name, title, and company (if applicable).

## Field-by-Field Explanation

* **Tool Name** (`finops_tool_name`): Enter the name of the tool you're evaluating.
* **Tool URL** (`tool_url`): If the tool has a public URL, please provide it.
* **Category** (`tool_category`): Select the category that best describes the tool's purpose.
* **Rate this tool** (`tool_rating`): Rate the tool based on its effectiveness and usability.
* **Ease of Use** (`tool_ease_of_use`): Rate the tool's ease of use.
* **Value For Money** (`tool_value_for_money`): Rate the tool's value for money.
* **Support** (`tool_support`): Rate the tool's support.
* **Roadmap** (`tool_roadmap`): Rate the tool's roadmap.
* **User Feedback** (`user_feedback`): If you have any additional comments or feedback about the tool, please provide it.
* **Would you recommend this tool?** (`user_recommendation`): If you would recommend the tool, please select 'Yes', otherwise select 'No'.
* **Tool Type** (`tool_type`): Select the type of tool (e.g., Cost Management, Performance Management, etc.).
* **Tool Provider** (`tool_provider`): If you have any information about the tool provider, please provide it.
* **Tool Version** (`tool_version`): If you have information about the tool version, please provide it.
* **Purchase Year** (`tool_purchase_year`): If you can provide the year you purchased the tool, please do so.
* **Cost** (`tool_cost`): If you can provide the cost of the tool, please do so.
* **Your Name** (`user_name`): Please enter your name.
* **Your Title** (`user_title`): Please enter your title.
* **Company** (`company`): If you're from a company, please enter it.

Note: This form is for evaluating specific tools, not general concepts or non-FinOps related topics. If you're unsure, ask for clarification.
