# Source Configuration Survey - Help Guide
## Purpose
This form is used to collect information about your team's source configuration to help us understand your team's setup and make informed decisions.

## How To Complete This Form
1. Choose the correct option for the "Team Size" page.
2. Enter the name of the Team Lead and their title if applicable.
3. Choose the configuration frequency for your team (if other, specify below).
4. Select all areas where you face challenges.
5. If you chose "Other (specify)" for configuration frequency, describe the reason in the text box.
6. If there are challenges in the "Challenges" section, select the specific areas where you face challenges.
7. Choose the area to prioritize for improvement.
8. If "Prioritize" was selected, select the direction (Increase/Decrease).
9. Enter any additional feedback comments or notes.
10. If you have any additional feedback, enter your email address and phone number.
11. Add any additional notes about your team configuration.
12. Finally, enter the current version number of your team configuration.

## Field-by-Field Explanation
* **Team Size** (`team_size`, select_multiple, required): Choose the number of members in your team.
* **Team Lead** (`team_lead`, text, optional): Enter the name of the Team Lead.
* **Lead Title** (`lead_title`, text, optional): Enter the title of the Team Lead.
* **Configuration Frequency** (`config_frequency`, select_one, required): Choose how often you configure your team.
* **Other (specify)** (`config_frequency_other`, text, optional): Describe your team's configuration frequency.
* **Configuration Challenges** (`config_challenges`, select_multiple, optional): Check areas where you face challenges.
* **Inadequate Training** (`config_challenges_1`, select_multiple, optional): Check if you face Inadequate Training challenges.
* **Lack of Clear Processes** (`config_challenges_2`, select_multiple, optional): Check if you face Lack of Clear Processes challenges.
* **Lack of Tools** (`config_challenges_3`, select_multiple, optional): Check if you face Lack of Tools challenges.
* **Configuration Improvements** (`config_improvements`, select_one, optional): Choose an area to prioritize for improvement.
* **Prioritize** (`config_improvements_1`, select_one, optional): If "Prioritize" was selected, choose the direction (Increase/Decrease).
* **Improve** (`config_improvements_2`, select_one, optional): Check if improvement is needed.
* **Provide** (`config_improvements_3`, select_one, optional): Check if tools need to be provided.
* **Additional Feedback Comments** (`feedback_comments`, text, optional): Enter any additional feedback comments.
* **Email** (`feedback_email`, text, optional): Enter your email address for feedback.
* **Phone** (`feedback_phone`, text, optional): Enter your phone number for feedback.
* **Notes** (`feedback_notes`, text, optional): Enter any additional notes about your team configuration.
* **Version** (`config_version`, select_one, optional): Check the current version number of your team configuration.
* **1** (`config_version_1`, select_one, optional): Check if this version is correct.
* **2** (`config_version_2`, select_one, optional): Check if this version is correct.
* **3** (`config_version_3`, select_one, optional): Check if this version is correct.
* **Other** (`config_version_other`, text, optional): Describe your team's current version number.
* **Last Updated** (`config_last_updated`, date, optional): Enter the date of the last update.
* **Time** (`config_last_updated_time`, time, optional): Enter the time of the last update.
* **Date** (`config_last_updated_date`, date, optional): Enter the date of the last update.

Note: Some fields have specific instructions for the type of input required. Ensure you follow the format specified for each field. If you're unsure, please contact the form administrators for clarification.
