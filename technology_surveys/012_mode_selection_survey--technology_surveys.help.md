# mode_selection_survey - Help Guide
## Purpose
This form is designed to collect feedback from you on your preferred mode of communication. We want to understand which mode you use the most and how satisfied you are with each mode.

## How To Complete This Form
1. Please select all the modes you use from the list below. You can select one or multiple modes.
2. For each mode you select, please rate your usage frequency and satisfaction level accordingly.
3. If you have any suggestions or comments about our modes, please type them in the text boxes provided.

## Field-by-Field Explanation

* **preferred_mode** (select_multiple, required): Select all the modes you use. You can choose one or multiple modes from the list below. 
  - Internet: This refers to using the Internet for communication, such as email, messaging, or browsing the web.
  - Mobile: This refers to using a mobile device for communication, such as texting or mobile apps.
  - Email: This refers to using email as a mode of communication.
* **usage_frequency** (number, required): Rate your usage frequency of each mode you selected. 
  - This field will only appear for the modes you select above.
* **satisfaction_level** (select_one, required): Rate your satisfaction level with each mode you selected. 
  - very satisfied: You are very satisfied with this mode.
  - somewhat satisfied: You are somewhat satisfied with this mode.
  - neutral: You are neutral about this mode.
  - somewhat unsatisfied: You are somewhat unsatisfied with this mode.
  - very unhappy: You are very unhappy with this mode.
* **suggestion** (text, optional): If you have any suggestions or comments about our modes, please type them here.
* **mode_suggestion** (text, optional): If you have any additional suggestions or comments, please type them here.
* **mode_suggestion_2** (text, optional): If you have any further suggestions or comments, please type them here.
* **mode_suggestion_3** (text, optional): If you have any more suggestions or comments, please type them here.

## Tips
- Please be honest when rating your frequency and satisfaction level of each mode. 
- If you don't see a mode in the list, please contact us and let us know so we can make it available in the future. 
- You can skip the text boxes if you don't have any suggestions or comments.
