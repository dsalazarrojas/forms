# Solar Panel Troubleshooting Survey - Help Guide
## Purpose
This form is designed to collect information from customers who have experienced issues with their solar panels. The form aims to gather details about the problem, the brand of the panel, and the steps taken to resolve the issue.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Answer all the questions as accurately as possible.
2. For select multiple fields, choose the applicable options from the drop-down menu.
3. For text fields, enter your comments or description in the box provided.
4. If any of the select options are required, you must select one of the given options.
5. Once you have completed all the fields, click the submit button to send the form.

## Field-by-Field Explanation

* **what_brands_of_panel_do_you_own**:
	+ This field asks you about the brands of solar panels you own.
	+ Please select all the brands that apply from the drop-down menu.
* **what_problem_are_youd_experience**:
	+ This field asks you about the problem you are experiencing with your solar panels.
	+ Please select all the problems that apply from the drop-down menu.
* **what_is_the_nature_of_the_issue**:
	+ This field is for a brief description of the problem you are experiencing.
	+ Please enter your comments in the text box.
* **what_are_the_photos_of_the_issue**:
	+ This field asks you to confirm if you have photos of the issue.
	+ Please select "Yes" if you have photos and "No" otherwise.
* **contact_details**:
	+ This field asks you to confirm if you want us to contact you.
	+ Please select "Yes" if you want to be contacted and "No" otherwise.
* **what_is_your_preferred_contact_method**:
	+ This field asks you about your preferred contact method.
	+ Please select all the methods that apply from the drop-down menu.
* **is_this_service_reimbursed**:
	+ This field asks if the service is reimbursed.
	+ Please select "Yes" if yes and "No" otherwise.
* **additional_comments**:
	+ This field is for any additional comments or description.
	+ Please enter your comments in the text box.
* **photos**:
	+ This field is for uploading photos of the issue.
	+ Please note that this field is a text field for uploading photos.
* **issue_description**:
	+ This field is for a detailed description of the issue.
	+ Please enter your description in the text box.
* **technician_notes**:
	+ This field is for the technician's notes.
	+ Please enter your comments in the text box.
* **issue_date**:
	+ This field asks for the date of the issue.
	+ Please enter the date in the format YYYY-MM-DD.
* **issue_time**:
	+ This field asks for the time of the issue.
	+ Please enter the time in the format HH:MM.
* **technician_name**:
	+ This field asks for the technician's name.
	+ Please enter the name in the text box.
* **technician_company**:
	+ This field asks for the technician's company.
	+ Please enter the company name in the text box.
* **technician_phone_number**:
	+ This field asks for the technician's phone number.
	+ Please enter the phone number in the text box.
* **technician_email**:
	+ This field asks for the technician's email.
	+ Please enter the email in the text box.
* **technician_address**:
	+ This field asks for the technician's address.
	+ Please enter the address in the text box.
* **is_the_issue_resolved**:
	+ This field asks if the issue is resolved.
	+ Please select "Yes" if yes and "No" otherwise.
* **resolution_date**:
	+ This field asks for the resolution date.
	+ Please enter the date in the format YYYY-MM-DD.
* **resolution_time**:
	+ This field asks for the resolution time.
	+ Please enter the time in the format HH:MM.
* **follow_up_status**:
	+ This field asks for the follow-up status.
	+ Please select the status as "Active" or "Inactive".
* **is_follow_up_required**:
	+ This field asks if follow-up is required.
	+ Please select "Yes" if yes and "No" otherwise.
* **follow_up_date**:
	+ This field asks for the follow-up date.
	+ Please enter the date in the format YYYY-MM-DD.
* **follow_up_time**:
	+ This field asks for the follow-up time.
	+ Please enter the time in the format HH:MM.
