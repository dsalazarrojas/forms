# Veterinary Cybersecurity Readiness Survey - Help Guide
## Purpose
This guide will help you complete the Veterinary Cybersecurity Readiness Survey form, which assesses your practice's current state of cybersecurity.

## How To Complete This Form
1. Review each question carefully and answer truthfully.
2. For multiple-choice questions, select the answer that best describes your practice's current state.
3. For text fields, provide a detailed description of your practice's current state.
4. If you have an 'Other' option selected, provide a brief description of your practice's current state in the 'Other (please specify)' field.

## Field-by-Field Explanation

* **Introduction**: A brief description of your practice.
* **Practice Location**: Enter your practice location (e.g., street address, city, state, zip).
* **Number of Practices**: Enter the number of employees in your practice.
* **Cybersecurity Lead Person**: Select 'Yes' if you have a designated cybersecurity lead person, or 'No' if you do not.
* **Email Domain**: Enter your practice's email domain (e.g., @example.com).
* **Security Concerns**: Select 'Yes' if your practice has security concerns, or 'No' if not. If 'Yes', you may choose 'Other' and provide a brief description of the concerns.
* **Other Security Concerns (if 'Yes')**: If you selected 'Yes' for security concerns, describe the concerns here.
* **Cybersecurity Measures**: Select 'Yes' if your practice has implemented certain cybersecurity measures, such as backups, firewalls, etc., or 'No' if not.
* **Measures Other (if 'Yes')**: If you selected 'Yes' for cybersecurity measures, describe the measures your practice has implemented.
* **Training**: Select 'Yes' if your practice offers cybersecurity training, or 'No' if not.
* **Training Other (if 'Yes')**: If you selected 'Yes' for training, describe the training program.
* **Incident Response**: Select 'Yes' if your practice has an incident response plan, or 'No' if not.
* **Incident Response Other (if 'Yes')**: If you selected 'Yes' for incident response, describe the plan.
* **Incident Reporting**: Select 'Yes' if your practice reports incidents, or 'No' if not.
* **Incident Reporting Other (if 'Yes')**: If you selected 'Yes' for incident reporting, describe the reporting process.
* **Incident Response Plan**: Select 'Yes' if your practice has an incident response plan, or 'No' if not. If 'Yes', you may choose 'Other' and provide a brief description of the plan.
* **Incident Response Plan Other (if 'Yes')**: If you selected 'Yes' for incident response plan, describe the plan here.
* **Data Backup**: Select 'Yes' if your practice has data backups, or 'No' if not.
* **Data Backup Other (if 'Yes')**: If you selected 'Yes' for data backup, describe the backup process.
* **Data Backup Policy**: Enter the date of the last data backup or the date of the last backup policy review.
