# Civic Technology Awareness Survey - Help Guide
## Purpose
This form is designed to gather information about your awareness, experience, and opinions on civic technology tools.

## How To Complete This Form
To complete this form, please follow these steps:

* Answer each question honestly and accurately.
* Select your response from the provided options for questions with multiple-choice answers.
* For open-ended questions, provide as much detail as possible.
* If you have any additional feedback or comments, use the "Additional feedback or comments" field.

## Field-by-Field Explanation

### 1. Respondent Information
* **Name** (`name`, `text`, required/optional): This is your name. Please provide your name if you wish to participate in the survey.
* **Email Address** (`email`, `email`, required/true): This is your email address. Please provide a valid email address if you wish to participate in the survey.

### 2. Age Group
* **Age Group** (`age_group`, `select_one`, required/true): This question asks for your age group. Please select one of the provided options.

### 3. Technology Proficiency Level
* **Technology Proficiency Level** (`tech_proficiency`, `select_one`, required/true): This question asks for your level of proficiency with technology. Please select one of the provided options.

### 4. Awareness of Civic Technology Tools
* **Are you aware of civic technology tools and platforms?** (`aware_of_civic_tech`, `select_one`, required/true): This question asks if you are aware of civic technology tools and platforms. Please select one of the provided options.

### 5. Civic Technology Tools You Have Heard of
* **Civic technology tools you have heard of - select all** (`heard_of_tools`, `select_multiple`, required/false): This question asks if you have heard of any civic technology tools. Please select all that apply.

### 6. Have You Used Any Civic Technology Tools
* **Have you used any civic technology tools** (`used_civic_tech`, `select_one`, required/true): This question asks if you have used any civic technology tools. Please select one of the provided options.

### 7. Which Civic Technology Tools Have You Used
* **Which civic technology tools have you used** (`specific_tools_used`, `text`, required/false): This question asks for specific civic technology tools you have used. Please provide a detailed answer if you have used any civic technology tools.

### 8. Experience and Effectiveness
* **How would you rate your experience with civic tech tools** (`experience_quality`, `select_one`, required/false): This question asks for your rating of your experience with civic tech tools. Please select one of the provided options.
* **Do civic technology tools effectively help citizens participate?** (`effectiveness`, `select_one`, required/true): This question asks if you believe that civic technology tools effectively help citizens participate. Please select one of the provided options.

### 9. Barriers to Use
* **Barriers to using civic technology - select all** (`barriers`, `select_multiple`, required/false): This question asks for potential barriers to using civic technology tools. Please select all that apply.

### 10. Suggestions for Improvement
* **How could civic technology tools be improved** (`improvements`, `text`, required/false): This question asks for suggestions on how civic technology tools can be improved. Please provide your ideas.

### 11. Desired Features
* **Features you would like to see in civic tech tools** (`desired_features`, `text`, required/false): This question asks for features that would be beneficial in civic technology tools. Please provide your thoughts.

### 12. Future Use
* **Likelihood to use civic technology tools in the future** (`future_use`, `select_one`, required/true): This question asks if you are likely to use civic technology tools in the future. Please select one of the provided options.

### 13. Additional Feedback or Comments
* **Additional feedback or comments** (`additional_feedback`, `text`, required/false): This question asks for any additional feedback or comments. Please provide your thoughts.
