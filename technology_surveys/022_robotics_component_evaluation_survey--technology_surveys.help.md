# Robotics Component Evaluation Survey - Help Guide
## Purpose
The Robotics Component Evaluation Survey is a form used to evaluate and compare different robotics components. This form helps collect information about a specific component's performance and characteristics.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of component you are evaluating (motor, gear, or sensor).
2.  Type the name of the component.
3.  Rate the performance of the component from 1 to 5.
4.  Optionally, provide any additional comments about the component.

## Field-by-Field Explanation

* **component_type** (`component_type`, select_one, required): Select the type of robotics component you are evaluating (e.g., motor, gear, or sensor).
* **component_name** (`component_name`, text, required): Type the name of the component you are evaluating.
* **performance_rating** (`performance_rating`, number, required): Rate the performance of the component from 1 to 5, where 1 is low and 5 is high.
* **comments** (`comments`, note, optional): Provide any additional comments about the component.

## Tips
* Please select the correct component type to ensure accurate evaluation results.
* Use the provided scale to rate the component's performance accurately.
* Be as descriptive as possible in the "comments" field to provide valuable information.
