# Software Features And Functions Survey - Help Guide
## Purpose
This form is designed to gather your opinions and feedback on the software's features and functions. Your input will help us improve the product to better meet your needs.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by reading the introductory page.
2. Select all that apply from the list of SaaS teams on page 2.
3. Choose how you feel about the usability of the feature on page 3.
4. Rate the performance of the feature on page 4.
5. Select up to three features that you'd like to see improved on page 5.
6. If you have any other suggestions, please type them in the "Additional Features" field on page 6.
7. Enter your email address and name on page 7.

## Field-by-Field Explanation
### Intro (Page 1)
* **Intro** (`intro`, `note`, not required): This page is a brief introduction to the survey. Please read it to understand the purpose and scope of the survey.

### SaaS Teams (Page 2)
* **SaaS teams** (`saas_teams`, `select_multiple`, not required): Select all the SaaS teams that you belong to, as this will help us tailor our feedback to specific teams.

### How do you feel about the usability of this feature? (Page 3)
* **How do you feel about the usability of this feature?** (`feedback_usability`, `select_one`, not required): Choose how you feel about the usability of the feature. Options range from "Not very satisfied" to "Very satisfied".

### How would you rate the performance of this feature? (Page 4)
* **How would you rate the performance of this feature?** (`feature_performance`, `number`, required): Rate the performance of the feature on a scale from 1 to 10, where 1 is "Poor" and 10 is "Excellent".

### What feature would you like to see improved? (Page 5)
* **What feature would you like to see improved?** (`feature_improvement`, `select_multiple`, not required): Select up to three features that you think need improvement. Options include "User interface", "Usability", "Performance", "Functionality", and "Other".

### Is there anything else you'd like to see us add? (Page 6)
* **Is there anything else you'd like to see us add?** (`additional_features`, `text`, not required): Type any additional features or suggestions you have for improvement.

### Your Email (Page 7)
* **Your Email** (`email`, `email`, required): Enter your email address so we can contact you for further discussion or to provide updates.

### Your Name (Page 7)
* **Your Name** (`name`, `text`, required): Enter your name so we can associate it with your feedback.
