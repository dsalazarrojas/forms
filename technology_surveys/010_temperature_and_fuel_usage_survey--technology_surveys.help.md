# Temperature And Fuel Usage Survey - Help Guide

## Purpose
This form is designed to gather information about temperature and fuel usage for a specific location or building. It aims to collect data on heating habits, energy-saving practices, and fuel consumption.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the questions carefully and ensure you are answering based on your knowledge of the location's temperature and fuel usage.
2. For select_one or select_multiple questions, choose the relevant options that best describe your situation.
3. Enter numerical values accurately, as they will be used for further analysis.
4. Submit the form once you have answered all questions honestly and accurately.

## Field-by-Field Explanation
### 1. Heating type 
**Heating type** (select_one): This question asks about the type of heating system used in the location. Please choose 'Yes' if the location has a heating system, 'No' otherwise.
### 2. Thermostat set point 
**Thermostat set point** (number): This question asks for the temperature set point of the thermostat, which is the temperature at which the heating system turns off.
### 3. Hours per day used for heating 
**Hours per day used for heating** (number): This question asks about the number of hours the heating system is used per day.
### 4. Energy type 
**Energy type** (select_multiple): This question asks about the types of energy used for heating. Please choose all that apply, as it may be multiple types.
### 5. Heating fuel type 
**Heating fuel type** (select_one): This question asks about the type of fuel used for the heating system. Please choose 'Yes' if it is applicable.
### 6. Hours usage per day 
**Hours usage per day** (number): This question asks for the number of hours the heating system is used per day.
### 7. Days used per month 
**Days used per month** (number): This question asks for the number of days the heating system is used per month.
### 8. Energy saving habits 
**Energy saving habits** (select_multiple): This question asks about energy-saving practices used. Please choose all that apply.
### 9. Heating fuel consumption 
**Heating fuel consumption** (number): This question asks for the consumption of heating fuel in a unit of measurement (e.g., liters, kilograms, etc.).
### 10. Electricity usage 
**Electricity usage** (number): This question asks for the usage of electricity for heating in a unit of measurement (e.g., kilowatt-hours, megawatt-hours, etc.).
### 11. Gas usage 
**Gas usage** (number): This question asks for the usage of gas for heating in a unit of measurement (e.g., kilowatt-hours, megawatt-hours, etc.).
### 12. Oil usage 
**Oil usage** (number): This question asks for the usage of oil for heating in a unit of measurement (e.g., liters, kilograms, etc.).
### 13. Coal usage 
**Coal usage** (number): This question asks for the usage of coal for heating in a unit of measurement (e.g., kilograms, tons, etc.).

## Tips
- Ensure accuracy when entering numerical values.
- Choose the correct options for select_one, select_multiple, and select_one questions based on actual circumstances.
- If unsure about any question, consult the relevant authorities or experts.
