# Device Keyboard Haptic Feedback Settings Request Form - Help Guide

## Purpose
The purpose of this form is to request changes to haptic feedback settings on your device keyboard.

## How To Complete This Form
1. Select the type of device you are using:
	* Haptic Feedback Settings Form is available on multiple device types:
		+ Phone
		+ Laptop
		+ Tablet
		+ Watch
		+ Other (please specify)
2. Choose the type of haptic feedback you prefer:
	* Vibration
		+ Light
		+ Medium
		+ Strong
3. Select your device model:
	* Enter the number of your device model (e.g. 1234, 5678, etc.)
4. Describe your haptic feedback experience:
	* Enter a brief description of your haptic feedback experience, including any details you'd like to share about the settings you are requesting.
5. Select a date and time for submission:
	* Enter the date and time you are submitting this request.
6. (Optional) Add any additional comments:
	* If you have any additional comments or details you'd like to include, please provide them here.
7. Enter your email address:
	* Enter your email address so we can contact you to discuss your request.
8. Enter your phone number:
	* Enter your phone number, or leave this field blank if you do not have one.
9. Select the tool you would like to use for your haptic feedback:
	* Default: This is the default tool that will be used for your haptic feedback.
	* Custom: This is a custom tool that you have set up for your haptic feedback.
10. Add any additional comments:
	* If you have any additional comments or details you'd like to include, please provide them here.
