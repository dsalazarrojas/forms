# Website Development Pre Screening Survey - Help Guide
## Purpose
This form is a questionnaire designed to gather information about website development projects that need pre-screening. It's essential to fill it out accurately to ensure that all necessary details are captured.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Title** field with a brief description of the project.
2. Select the **Category** that best fits the project.
3. In the **Description** field, provide a detailed description of the project.
4. Choose the **Goals** for the project by selecting one or more options from the list.
5. Enter the **Budget** for the project, if applicable.
6. Set the **Timeline** for the project's completion.
7. Select the **Priority** for the project, if applicable.
8. Choose the **Lead Capture Methods**, **Lead Capture Sources**, and **Lead Qualify Methods**, **Project Capture Methods**, and **Project Prioritize Methods** by selecting one or more options from the lists.
