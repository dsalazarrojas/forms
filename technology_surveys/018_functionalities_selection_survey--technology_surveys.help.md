# Functionalities Selection Survey - Help Guide

## Purpose
This form is designed to gather your feedback on the functionalities of our product. Please take a few minutes to answer the questions and let us know what you would like to see improved in the next release.

## How To Complete This Form

1. Select the main features you would like to see prioritized in the next release on the "Main Page" section.
2. Rate the importance of each feature in the "How Important Are the Following Features?" section.
3. Enter any comments or improvement ideas you have for the product in the "Improvement Ideas" section.
4. Provide your contact information if you would like to be contacted for further feedback.
5. Finally, rate your satisfaction with the product and provide any additional comments or ideas.

## Field-by-Field Explanation

* **Main Page** (`main_page`, `text`, required: false): On this page, you will be asked to select the main features you would like to see prioritized in the next release.
* **What are the main features that you would like to see prioritized in the next release?** (`main_page_features`, `select_multiple`, required: false): Select all features you would like to see prioritized in the next release.
* **What are the main features?** (`main_page_features_features`, `text`, required: false): Enter any comments or ideas you have for the main features.
* **How important are the following features?** (`feature_ratings`, `select_one`, required: false): Rate the importance of each feature from 1 to 3.
* **How satisfied are you with this product?** (`satisfaction`, `select_one`, required: false): Rate your satisfaction with the product from 1 to 3.
* **What features would you like to see improved?** (`improvements`, `note`, required: false): Enter any comments or improvement ideas you have for the product.
* **What features would you like to see prioritized in the next release?** (`next_release`, `select_multiple`, required: false): Select all features you would like to see prioritized in the next release.
* **What features would you like to see in the future?** (`main_page_future_ideas`, `select_multiple`, required: false): Select all features you would like to see in the future.
* **How satisfied are you with this product in the future?** (`main_page_satisfaction_future`, `select_one`, required: false): Rate your satisfaction with the product in the future from 1 to 3.
* **Next Release Ideas 2** (`next_release_ideas_2`, `select_multiple`, required: false): Select all features you would like to see prioritized in the next release.
* **Next Release Comments 2** (`next_release_comments_2`, `note`, required: false): Enter any comments or ideas you have for the next release.
