# data_analytics_utilization_survey - Help Guide
## Purpose
This form is designed to collect data on the utilization of data and analytics tools in your organization. The goal is to understand which tools are being used, the challenges faced while using them, and the benefits gained from using data and analytics.

## How To Complete This Form

1. **Introduction**: Please start by reading this introduction, which explains the purpose of the form and the benefits of completing it.
2. Click on each page to navigate through the form.
3. For each field, read the label and description carefully before entering your information.

## Field-by-Field Explanation

* **Challenges** (2): Describe the biggest challenges you are facing while using data and analytics in your work.
* **Tools** (3): Select all the data and analytics tools you are currently using. You can choose multiple tools from the list.
	+ Tableau
	+ Power BI
	+ Qlik
	+ Google BigQuery
	+ Amazon Redshift
	+ Other
* **Benefits** (4): Please describe the benefits you have seen or heard about using data and analytics in your work.
* **Submissions** (5): Select all the submission platforms you are currently using. You can choose multiple platforms from the list.
	+ Google
	+ Jotform
	+ Other
* **Assigned Tool** (7): Specify the tool assigned to you for data and analytics tasks. You can choose from the available options or select "Other".
* **Output File** (8): Enter the name of the file you will output from your data and analytics work.
* **Category** (9): Select the category that best describes the type of work you do in relation to data and analytics. You can choose from the available options or select "Other".
* **Description** (10): Enter a brief description of your work in data and analytics.
* **Description 2** (11): Enter another brief description of your work in data and analytics.
* **Assigned Tool 2** (12): Specify the tool assigned to you for data and analytics tasks. You can choose from the available options or select "Other".
* **Submission ID** (13-17, 19-25): These fields are not used in this form and can be ignored.
* **Submission ID 2** (18): This field is not used in this form and can be ignored.
