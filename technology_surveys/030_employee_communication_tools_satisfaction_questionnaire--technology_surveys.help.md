# Employee Communication Tools Satisfaction Questionnaire - Help Guide
## Purpose
This form is used to gather feedback on employee satisfaction with company-provided communication tools. Please answer the questions honestly, and provide as much detail as possible.

## How To Complete This Form
1. Review the form carefully and answer each question based on your honest assessment of your experiences with communication tools provided by the company.
2. For question 8, select all applicable communication tools that you use.
3. For question 9, if you selected "Other (please specify)" in question 8, provide a brief description of the tool you use.

## Field-by-Field Explanation
* **Employee Communication Tools Satisfaction Questionnaire** (`employee_communication_tools_satisfaction_questionnaire_page_1`, text, required/optional):
    This is the main heading of the form and introduction to the survey questions.
* **General Information** (`general_information`, text, optional):
    Please provide any additional context or information about your role, department, or company that you think would be relevant to answering this form.
* **What is your email?** (`email_1`, email, optional):
    Please enter your company email address or alias.
* **Phone Number** (`phone_number_1`, text, optional):
    Please enter your work phone number.
* **Company** (`company_1`, text, optional):
    Please provide the name of your company.
* **Department** (`department_1`, text, optional):
    Please provide the name of your department.
* **Job Title** (`job_title_1`, text, optional):
    Please provide your job title.
* **Which of these communication tools do you use?** (`communication_methods_1`, select_multiple, optional):
    Please select all communication tools that you regularly use for work-related activities.
    Options: 
    - Email
    - Phone
    - Instant Messaging
    - Video conferencing
    - Collaboration software
    - Text messaging
    - Other (please specify)
* **Other (please specify)** (`communication_methods_2`, text, optional):
    If you selected "Other" in the previous question, please provide a brief description of the tool you use.
* **How often do you use this communication tool?** (`communication_tools_1`, select_one, optional):
    Please select how often you use the communication tool selected in question 8.
    Options: 
    - Daily
    - Several times a week
    - Rarely
    - Never
