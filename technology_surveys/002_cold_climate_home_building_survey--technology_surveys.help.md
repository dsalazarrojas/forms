# Cold Climate Home Building Survey - Help Guide
## Purpose
This form is designed to gather information from homeowners, builders, and other professionals about their experiences and challenges with building and designing homes in cold climate regions. The survey aims to understand the various factors that influence building in such regions, including insulation types, heating systems, window specifications, air sealing methods, ventilation systems, foundation types, and roof design considerations. The collected data will help to identify best practices and areas for improvement in cold climate home building.

## How To Complete This Form

1. Please select the correct options for each question, taking into account your real-world experience or knowledge.
2. For questions where you have to choose between multiple options (e.g., `respondent_type`), pick the one that best represents your role.
3. For questions where you have to select a specific value (e.g., `insulation_r_value`), provide the recommended or actual value used in your building project.
4. If you have any additional comments or recommendations, please use the `additional_comments` field to share them.

## Field-by-Field Explanation

* **Respondent Full Name** (`respondent_name`): Your name or organization name, which will be used to identify your responses.
* **Respondent Type** (`respondent_type`): Select your role in the building process:
	+ Home Builder
	+ Architect
	+ Designer
	+ Homeowner
	+ Engineer
	+ Contractor
	+ Other
* **Organization Name** (`organization_name`): If you are representing a company or organization, enter its name.
* **Email Address** (`email`): Your contact email for follow-up questions or information sharing.
* **Building Location Region** (`building_location`): Select the geographic area where the building is located:
	+ Northern Canada
	+ Alaska
	+ Scandinavia
	+ Northern Europe
	+ Russia
	+ Mountain Regions
	+ Other Cold Climate
* **Type of Home Being Built** (`home_type`): Select the type of home you are building:
	+ Single Family Detached
	+ Townhouse
	+ Duplex
	+ Modular Home
	+ Log Home
	+ Custom Design
* **Primary Insulation Type Used** (`insulation_type`): Select the main insulation material used for the building envelope:
	+ Spray Foam
	+ Fiberglass Batt
	+ Cellulose
	+ Rigid Foam Board
	+ Mineral Wool
	+ Structural Insulated Panels
	+ Other
* **Target R-Value for Walls** (`insulation_r_value`): Enter the recommended or actual R-value for wall insulation.
* **Primary Heating System** (`heating_system`): Select the main heating system used:
	+ Forced Air Furnace
	+ Radiant Floor Heating
	+ Heat Pump
	+ Boiler System
	+ Wood Stove
	+ Electric Baseboard
	+ Geothermal
* **Heating Fuel Type** (`heating_fuel`): Select the primary fuel source for heating:
	+ Natural Gas
	+ Propane
	+ Electricity
	+ Heating Oil
	+ Wood
	+ Pellets
	+ Geothermal
* **Window Type Selected** (`window_type`): Select the window specifications for cold climate:
	+ Triple-Pane
	+ Double-Pane Low-E
	+ Quadruple-Pane
	+ Double-Pane Standard
* **Air Sealing Methods Used** (`air_sealing_methods`): Select all the air sealing methods applied:
	+ Spray Foam Sealing
	+ Caulking
	+ Weather Stripping
	+ House Wrap
	+ Vapor Barrier
	+ Tape and Membrane
	+ Gaskets
* **Ventilation System Type** (`ventilation_system`): Select the mechanical ventilation approach:
	+ HRV - Heat Recovery Ventilator
	+ ERV - Energy Recovery Ventilator
	+ Exhaust Only
	+ Supply Only
	+ Natural Ventilation
	+ None
* **Foundation Type** (`foundation_type`): Select the foundation design for cold climate:
	+ Frost-Protected Shallow Foundation
	+ Full Basement
	+ Slab on Grade
	+ Crawl Space
	+ Piling
* **Roof Design Considerations** (`roof_design`): Select all special roof features for snow and ice:
	+ Ice and Water Shield
	+ Snow Guards
	+ Heated Gutters
	+ Steep Pitch
	+ Metal Roofing
	+ Green Roof
	+ Solar Panels
* **Biggest Challenge in Cold Climate** (`biggest_challenge`): Describe the main challenge faced in building or designing in cold climate.
* **Energy Efficiency Priority Level** (`energy_efficiency_priority`): Select the priority level for energy efficiency:
	+ Highest Priority
	+ High Priority
	+ Moderate Priority
	+ Low Priority
	+ Not a Priority
* **Construction Budget Range** (`budget_range`): Select the budget category:
	+ Under $200,000
	+ $200,000 - $400,000
	+ $400,000 - $600,000
	+ $600,000 - $800,000
	+ $800,000 - $1,000,000
	+ Over $1,000,000
* **Additional Comments or Recommendations** (`additional_comments`): Share any other insights or recommendations for cold climate building.

Note: The form is designed to be completed by respondents with real-world experience or knowledge in building or designing homes in cold climate regions. The collected data will be used to improve the understanding of best practices and areas for improvement in cold climate home building.
