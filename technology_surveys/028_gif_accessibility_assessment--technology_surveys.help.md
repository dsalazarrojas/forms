# GIF Accessibility Assessment - Help Guide
## Purpose

This form is designed to guide users through a comprehensive assessment of a GIF file's accessibility. It ensures that all necessary information is collected and documented in a structured manner.

## How To Complete This Form

1. **Upload GIF**: Please upload the GIF file you want to assess. You can either upload the file from your computer or select it from a predefined list of uploaded GIFs.
2. Follow the form instructions and answer each question carefully.
3. Review and submit the form when you have completed all fields.

## Field-by-Field Explanation

* **GIF File (1)**: Upload the GIF file that you want to assess for accessibility.
* **Alt Text (2)**: Enter a brief text describing the GIF file's content, including its primary and secondary images or objects, to help screen reader users understand its content.
* **Motion Risks (3)**: Indicate whether the GIF may cause motion sickness.
	+ Select 'Yes' if the GIF's rapid sequence of images may cause motion sickness.
	+ Select 'No' if the GIF does not cause motion sickness.
* **Flashing Risks (4)**: Indicate whether the GIF includes flashing content.
	+ Select 'Yes' if the GIF includes flashing or flickering images.
	+ Select 'No' if the GIF does not include flashing content.
* **Improvement Suggestions (5)**: Enter any additional feedback or suggestions on how to improve the GIF's accessibility.
* **Accessibility Decisions (6)**: Note any decisions you made or recommendations for improvements to the GIF's accessibility.
* **Email Address (7)**: Provide your email address for any follow-up communication.
* **Phone Number (8)**: Enter your phone number (optional).
* **Date Recorded (9)**: Enter the date the GIF was recorded (optional).
* **Time Recorded (10)**: Enter the time the GIF was recorded (optional).
* **Comments (11)**: Enter any additional comments or observations about the GIF's accessibility.

## Tips

* Be as specific as possible when providing feedback and suggestions.
* Ensure your answers are accurate and consistent throughout the form.
* This form is an essential tool for assessing GIFs for accessibility; use it to ensure that all GIFs are accessible and usable for all users.
