# Smart Building Dashboard Experience Survey - Help Guide
## Purpose
The Smart Building Dashboard Experience Survey is designed to collect feedback from users on their experience with the dashboard. This feedback will help us understand the strengths and weaknesses of the dashboard and make improvements accordingly.

## How To Complete This Form
To complete this form, simply fill out the fields below and submit it when finished.

## Field-by-Field Explanation

* **Dashboard Usage (1)** (`dashboard_usage`, text, optional): This field asks about your overall experience with the dashboard. Please provide a brief description of how you use the dashboard.
* **Satisfaction** (`satisfaction`, select_one, optional): Please select one of the following options to express your level of satisfaction with the dashboard:
	+ Very satisfied
	+ Somewhat satisfied
	+ Neutral
	+ Somewhat dissatisfied
	+ Very dissatisfied
* **Issues** (`issues`, note, optional): If you have any issues or concerns with the dashboard, please describe them in this field.
* **Feature Requests** (`feature_requests`, select_multiple, optional): Select all the features you would like to request or see added to the dashboard:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Option 4
	+ Option 5
* **Email** (`email`, email, optional): Please provide your email address for any follow-up contact or communication.
* **Phone** (`phone`, text, optional): This field is for your phone number (if you want to provide it).
* **Date** (`date`, date, optional): Select the date you used the dashboard (if applicable).
* **Time** (`time`, time, optional): Select the time you used the dashboard (if applicable).
* **Dashboard Usage (1)** (`dashboard_usage_1`, number, optional): Enter the number of times you've used the dashboard so far.
* **Feature Request (1)** (`feature_requests_1`, select_one, optional): Please select one of the following options for your feature request:
	+ Option 1
	+ Option 2
	+ Option 3

## Tips
* Please fill out as many or as few fields as you see fit, depending on your experience with the dashboard. We value your feedback, no matter how brief or detailed it is.
* If you have any questions or concerns, feel free to contact us for assistance.
