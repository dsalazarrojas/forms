# Facility Technology Adoption Survey - Help Guide
## Purpose
This form is designed to gather information about facility technology adoption. It is intended for facilities teams to provide a snapshot of their current technology use. Please answer all questions to the best of your ability.

## How To Complete This Form
1. Start by completing the form in sections, working through each page until you have finished.
2. For each field, follow the instructions provided below.

## Field-by-Field Explanation
* **Introduction** (`1`, `note`, required: `false`): This is an introductory page providing background information about the form purpose and instructions.
* **Current Technology Adoption** (`2`, `select_multiple`, required: `false`):
	+ Select all the technologies you currently use, such as mobile devices, computers, software, or other technologies.
	+ If none are used, select "No technology adoption".
* **Technologies Used** (`3`, `select_multiple`, required: `false`):
	+ Select all the technologies you currently use, such as mobile devices, computers, software, or other technologies.
	+ If none are used, select "None".
* **Facility Count** (`4`, `number`, required: `true`):
	+ Enter the number of facilities in your organization that use each selected technology.
* **Facility Purpose** (`5`, `text`, required: `false`): Enter a brief description of the purpose of each facility.
* **Current Maintenance State** (`6`, `select_one`, required: `false`):
	+ Select the current maintenance state of each technology.
	+ Options are "True", "False", or "Not applicable".
* **Technology Types Used** (`7`, `text`, required: `false`): Enter a list of technology types used in each facility.
