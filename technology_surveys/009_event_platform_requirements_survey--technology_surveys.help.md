# Event Platform Requirements Survey - Help Guide
## Purpose
This form is designed to collect information about the event platform requirements from the end-users to get a comprehensive understanding of the event platform needs.

## How To Complete This Form
1. Please select the type of event platform you are interested in (Event Management Platforms, Event Marketing Platforms, Web and Video Conferencing, etc.)
2. Choose the vendors you are interested in (Zoom, Eventbrite, B2Begenda, etc.)
3. Prioritize the features you need for your event platform (High, Medium, Low)
4. Select the integrations you need (User Management, Content Management, Payment Management, etc.)
5. Choose the data retention and security options (Local, Cloud, Synchronized, Public, Private, Secure, etc.)
6. Select the support options (24/7, Business Hours, No Support)
7. Specify the cost and limits of your event platform (Number of users, Number of events, etc.)
8. Provide your geographical location (City, State, Country, etc.)

## Field-by-Field Explanation

* **event_platform**: This field is to select the type of event platform you are interested in.
	+ Event Management Platforms
	+ Event Marketing Platforms
	+ Web and Video Conferencing
	+ Event and Meeting Management
	+ Registration and Ticketing
	+ Mobile Apps and Event Apps
	+ Content Management and Distribution
	+ Analytics and Reporting
	+ Payment and Invoicing
* **category**: This field is to select the category of event platform you are interested in.
* **vendor**: This field is to select the vendor you are interested in.
* **priority**: This field is to prioritize the features you need for your event platform.
	+ High
	+ Medium
	+ Low
* **integration**: This field is to select the integrations you need for your event platform.
	+ User Management
	+ Content Management
	+ Payment Management
	+ Reporting and Analytics
	+ Integration
* **event_type**: This field is to select the type of events you are interested in hosting.
	+ Online
	+ In-person
	+ Hybrid
	+ Virtual
	+ Physical
* **platform_features**: This field is to select the features you need for your event platform.
	+ User Management
	+ Content Management
	+ Payment Management
	+ Reporting and Analytics
	+ Integration
* **data_retention**: This field is to select the data retention options you need for your event platform.
	+ Local
	+ Cloud
	+ Synchronized
* **data_security**: This field is to select the data security options you need for your event platform.
	+ Public
	+ Private
	+ Secure
* **vendor_support**: This field is to select the support options you need for your event platform.
	+ 24/7
	+ Business Hours
	+ No Support
* **cost**: This field is to specify the cost of your event platform.
* **user_limit**: This field is to specify the user limit of your event platform.
* **event_limit**: This field is to specify the event limit of your event platform.
* **user_limit_unit**: This field is to specify the unit of user limit (Number of users, Number of events, etc.)
* **event_limit_unit**: This field is to specify the unit of event limit (Per event, Per month, Per year, etc.)
* **event_capacity**: This field is to specify the event capacity.
* **time_zone**: This field is to select the time zone of your event platform.
* **geo_location**: This field is to select the geographical location of your event platform.
* **geo_location_country**: This field is to select the country of your event platform.
* **geo_location_city**: This field is to select the city of your event platform.
* **geo_location_state**: This field is to select the state of your event platform.
* **geo_location_zip**: This field is to specify the zip code of your event platform.
* **geo_location_lat**: This field is to specify the latitude of your event platform.
* **geo_location_lon**: This field is to specify the longitude of your event platform.
* **geo_location_accuracy**: This field is to specify the geographical location accuracy (10 meters, 100 meters, 1 kilometer, etc.)

## Tips
- Please ensure that the information provided is accurate and up-to-date.
- If you have any questions or need further clarification on any field, feel free to contact us.
- If you have already filled this form out in the past, please do not fill it out again.
- Please provide the most up-to-date information about your event platform requirements.
