# System Diagnostic Survey - Help Guide
## Purpose
This form is designed to gather information about system performance and issues. It will help with system diagnosis and troubleshooting by providing a comprehensive view of your system's condition.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose how you would rate your system's performance.
2. Indicate if you are experiencing a system issue.
3. If you are experiencing an issue, describe the problem in the text field.
4. Select the area where the issue is happening (Performance, Security, Reliability, Usability, Support).
5. Rate the severity of the issue (Critical, High, Medium, Low, None).
6. Enter the number of times your system has crashed recently.
7. Indicate if your system has crashed recently.
8. Enter the average system uptime (in hours).
9. Enter the time your system has been up for the last time you checked (in hours).
10. Enter the time your system was down (in hours).

## Field-by-Field Explanation

* **System Performance (1)** (`system_performance`, required/optional): Rate your system's performance. Select from High, Medium, Low, or System Performance.
* **System Issue (2)** (`system_issue`, required/optional): Indicate if you are experiencing a system issue. Select True or False.
* **System Issue Description (3)** (`system_issue_description`): If you are experiencing an issue, describe the problem in detail.
* **System Problem Area (4)** (`system_problem_area`, required/optional): Select the area where the issue is happening. Select from Performance, Security, Reliability, Usability, Support.
* **System Issue Severity (5)** (`system_issue_severity`, required/optional): Rate the severity of the issue. Select from Critical, High, Medium, Low, None.
* **System Reboot (6)** (`system_reboot`, required/optional): Enter the number of times your system has crashed recently.
* **System Crash (7)** (`system_crash`, required/optional): Indicate if your system has crashed recently. Select True or False.
* **System Average Uptime (8)** (`system_average_uptime`, required/optional): Enter the average system uptime in hours.
* **System Last Uptime (9)** (`system_last_uptime`, required/optional): Enter the time your system has been up for the last time you checked in hours.
* **System Downtime (10)** (`system_downtime`, required/optional): Enter the time your system was down in hours.

## Tips
- Be as detailed as possible when describing system issues.
- If you're unsure about any of the options, select the option that best fits your situation.
- If you need help or have questions, contact the support team.
