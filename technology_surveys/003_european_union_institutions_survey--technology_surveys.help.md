# European Union Institutions Survey - Help Guide
## Purpose
The European Union Institutions Survey is a tool designed to collect feedback from users about their experience with EU institutions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select one or more of the European Union institutions you work with from the dropdown menu. 
   - Please ensure that you select all institutions that apply to your work. 
2. If you have experience with technology, select your satisfaction level from the options provided. 
   If you don't have experience with technology, you can skip this question.
3. If you have any additional comments or suggestions, please provide them in the text field.
4. Enter your email address for follow-up or additional information.
5. Select one of the predefined categories that best suits your work or interest.
6. If you have a phone number or additional description about your experience, you can provide it in the text fields.

## Field-by-Field Explanation
- **European Union Institutions Survey** (`user_input`): A text field that explains the form's purpose.
- **eu_bodies_organisation** (`eu_bodies_organisation`): Select one or more of the European Union institutions you work with.
  • Please ensure that you select all institutions that apply to your work.
- **technology_survey** (`technology_survey`): Select your satisfaction level with technology. 
  • Please select "Very satisfied" if you are extremely happy with the technology.
  • Please select "Somewhat satisfied" if you are somewhat happy with the technology.
  • Please select "Neutral" if you are neutral about the technology.
  • Please select "Somewhat dissatisfied" if you are somewhat unhappy with the technology.
  • Please select "Very dissatisfied" if you are extremely unhappy with the technology.
- **feedback** (`feedback`): Please provide any additional comments or suggestions you may have.
- **email_input** (`email_input`): Enter your email address for follow-up or additional information.
- **category_input** (`category_input`): Select one of the predefined categories that best suits your work or interest. 
- **phone_input** (`phone_input`): If you have a phone number, please provide it. 
  • This field is optional. 
  • Please ensure that you enter the correct format (e.g., +1 202-123-4567). 
- **description_input** (`description_input`): If you have any additional description about your experience, please provide it. 
  • This field is optional.
