# Digital Tools For Work Management Survey - Help Guide

## Purpose
The purpose of this form is to collect information about digital tools used for work management.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select all that apply by checking the boxes for the digital tools you use for work management.
2. Choose a category for the survey to help us better understand your response.
3. Optionally, provide a brief description of the tool(s) you use.
4. Enter the ID(s) assigned to the tool(s) you use.
5. If you have any additional comments or notes about your tool(s), enter them in the text field labeled "output_file".

## Field-by-Field Explanation

* **digital_tools_for_work_management_survey**: This is a multiple-choice question where you select all the digital tools you use for work management. Please check the boxes for each tool that applies to you.
* **category**: This field allows you to choose a category for the survey. Select the option that best fits your response.
* **description**: If you'd like to provide more information about the tools you use, you can enter a brief description here.
* **assigned_tool**: If a tool has been assigned to you, enter the ID number assigned to it.
* **form_ids**: This is where you would enter any additional information or ID numbers related to the form, if applicable.
* **output_file**: This field is for any additional comments or notes about the tool(s) you use.
