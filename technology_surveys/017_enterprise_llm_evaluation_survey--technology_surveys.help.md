# Enterprise LLM Evaluation Survey - Help Guide
## Purpose
This form is designed to collect feedback and evaluations from users about their experiences with Enterprise LLM providers. It aims to gather information on the provider's performance, adoption, and overall satisfaction.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select your answer from the available options for each field.
2. For fields that are not relevant to your experience with the provider, you can leave them blank.

## Field-by-Field Explanation

### Survey Header (Page 1)
* **Survey Header** (`1`, text, required): This is a title page for the survey. Please do not change this value as it is not relevant to your answers.

### Select a Provider (Page 2)
* **Select a Provider** (`2`, select_one, required): Choose the provider you are evaluating from the list. This is the provider you have interacted with.

### Selected Provider (Page 3)
* **Selected Provider** (`3`, text, required): Please confirm the provider you selected in the previous question. This helps us ensure accuracy.

### Performance Rating (Page 4)
* **Performance Rating** (`4`, select_one, required): Rate the provider's performance as Good, Fair, or Poor.

### Adoption Rating (Page 5)
* **Adoption Rating** (`5`, select_one, required): Rate how likely you are to adopt the provider's solution as Good, Fair, or Poor.

### Satisfaction Rating (Page 6)
* **Satisfaction Rating** (`6`, select_one, required): Rate your overall satisfaction with the provider as Satisfied, Dissatisfied, or Neutral.

### Would Recommend (Page 7)
* **Would Recommend** (`7`, select_one, required): Would you recommend the provider's solution to others? Yes or No.

### Comments (Page 8)
* **Comments** (`8`, text, optional): Share any additional comments or feedback you have about the provider.

### Date Created (Page 9)
* **Date Created** (`9`, date, optional): Please do not fill out this field. This is for internal tracking purposes only.

### Date Completed (Page 10)
* **Date Completed** (`10`, date, optional): Please do not fill out this field. This is for internal tracking purposes only.

### Form ID (Page 11)
* **Form ID** (`11`, number, required): This is an internal tracking number. Please do not change this value.

### Assigned Tool (Page 12)
* **Assigned Tool** (`12`, text, required): Please enter the tool you were assigned to evaluate. This helps us track which tool you're referring to.

### Category (Page 13)
* **Category** (`13`, text, required): This is the category of the tool you evaluated. Enter the category name.

### Description (Page 14)
* **Description** (`14`, text, required): Please provide a brief description of the tool you evaluated. This helps us understand your experience better.

### Title (Page 15)
* **Title** (`15`, text, required): Enter the title of the tool you evaluated.

### Category Selection (Page 16)

### Description Selection (Page 17)
* **Description Selection** (`17`, select_multiple, optional): Select all descriptions that apply to the tool. This helps us understand the tool's features better. (Yes/No)

### Tool Selection (Page 18)
