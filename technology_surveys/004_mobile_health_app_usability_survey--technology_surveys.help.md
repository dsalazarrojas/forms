# Mobile Health App Usability Survey - Help Guide
## Purpose
This form is for gathering user feedback on the usability of a mobile health app. Your input will help us improve the app's user experience.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Select the answer that best represents your experience with the app for each question.
2. For the "issues" and "Issues2" questions, please type in any specific problems you have encountered while using the app.
3. For the "feature_requests" and "Feature Requests2" questions, select all the features you would like to see added to the app.
4. If you have any additional comments or suggestions, please use the "Any additional comments or suggestions?" field.
5. Finally, provide your contact information (email and phone number) so we can follow up with you if needed.

## Field-by-Field Explanation
- **How often do you navigate the app?** (`navigation`, `select_multiple`): This question helps us understand how often you interact with the app. Please select the answer that best reflects your experience.
	* Frequently: You use the app daily.
	* Occasionally: You use the app a few times a week.
	* Rarely: You use the app less than once a week.
	* Never: You have never used the app.
- **What do you think of the app overall?** (`satisfaction`, `select_one`): This question gauges your overall satisfaction with the app. Please select the answer that best reflects your feelings.
	+ Love it: You are extremely satisfied with the app.
	+ Like it: You are somewhat satisfied with the app.
	+ Neutral: You are neither satisfied nor dissatisfied with the app.
	+ Dislike it: You are somewhat dissatisfied with the app.
	+ Hate it: You are extremely dissatisfied with the app.
- **What issues do you experience while using the app?** (`issues`, `text`): If you have any problems while using the app, type them in here.
- **What feature would you like to see in our app?** (`feature_requests`, `select_multiple`): Select all the features you would like to see added to the app.
	+ Feature 1
	+ Feature 2
	+ Feature 3
	+ Feature 4
	+ Feature 5
- **How satisfied are you with the app?** (`satisfaction2`, `select_one`): This question assesses your satisfaction with the app. Please select the answer that best reflects your feelings.
	+ Very satisfied
	+ Satisfied
	+ Neutral
	+ Dissatisfied
	+ Very Dissatisfied
- **Navigation2** (`navigation2`, `select_multiple`): This question is similar to the "How often do you navigate the app?" question.
- **Issues2** (`issues2`, `text`): Similar to the "What issues do you experience while using the app?" question.
- **Feature Requests2** (`feature_requests2`, `select_multiple`): Similar to the "What feature would you like to see in our app?" question.
- **Satisfaction3** (`satisfaction3`, `select_one`): Similar to the "How satisfied are you with the app?" question.
- **Any additional comments or suggestions?** (`notes`, `note`): If you have any additional thoughts or suggestions, please share them here.
- **Contact Information (Email)** (`email`, `email`): Please provide your email address so we can follow up with you if needed.
- **Contact Information (Phone)** (`phone`, `text`): Please provide your phone number so we can follow up with you if needed.
- **Email2** (`email2`, `email`): Similar to the "Contact Information (Email)" question.
- **Phone2** (`phone2`, `text`): Similar to the "Contact Information (Phone)" question.
