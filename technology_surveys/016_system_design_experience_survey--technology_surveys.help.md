# System Design Experience Survey - Help Guide
## Purpose
This form is designed to gather feedback from users on their system design experience. Your input will help us improve our design practices and better serve you and other users in the future.

## How To Complete This Form
To fill out this form, simply follow these steps:

1. Review each page and answer the questions accordingly.
2. For each question, select the correct answer from the provided options or provide a free-text response.
3. Ensure that you are filling out the form based on your actual experience and not hypothetical or idealized scenarios.

## Field-by-Field Explanation

* **Technical Skills** (page_2, select_multiple, optional)
	+ This question asks about your technical skills, and you can select all that apply.
	+ Options:
		- Yes
		- No
* **Experience Levels** (page_3, select_one, optional)
	+ This question asks about your level of experience with system design.
	+ Options:
		- Low
		- Medium
		- High
* **Challenges** (page_4, select_multiple, optional)
	+ This question asks about the challenges you face when designing systems.
	+ Options:
		- Yes
		- No
* **first_page_2** (page_5, text, optional)
	+ This is a free-text field where you can provide any additional comments or insights.
* **first_page_3** (page_6, time, optional)
	+ This field is for you to provide a rough estimate of the time you spend on system design activities.
* **first_page_4** (page_7, number, optional)
	+ This field is for you to provide a rough estimate of the number of systems you have designed in the past.
* **first_page_5** (page_8, number, optional)
	+ This field is for you to provide a rough estimate of the number of team members you work with on system design projects.
* **first_page_6** (page_9, date, optional)
	+ This field is for you to provide a rough estimate of the time in years you have been working on system design activities.
* **System Design Experience** (page_10, select_one, optional)
	+ This question asks about your overall experience with system design.
	+ Options:
		- first page 7 low
		- first page 7 high
		- first page 7 medium
