# Emergency Evacuation Route Audit Application Form - Help Guide
## Purpose
The Emergency Evacuation Route Audit Application Form is a tool for building inspectors to collect and report data on evacuation routes in a building.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the applicable options for the evacuation routes.
2. Choose a building inspector from the list of options.
3. Provide a brief description of the form's purpose and the building inspector's role.
4. Select the relevant building inspector forms from the list of options.
5. Enter any additional text relevant to the evacuation route audit.
6. Enter the name of the building being audited.
7. Select the building inspector forms that are relevant to the audit.
8. Provide any additional text information that is relevant to the audit.

## Field-by-Field Explanation
* **Evacuation Routes** (`emergency_evacuation_route_audit_application_form_1`, select_multiple): Select all the applicable evacuation routes in the building.
* **Building Inspector** (`building_inspector_forms_2`, text): Enter the name of the building inspector who is performing the audit.
* **Form Purpose** (`emergency_evacuation_route_audit_application_form_3`, note): Provide a brief description of the form's purpose and the building inspector's role.
* **Building Inspector Forms** (`building_inspector_forms_4`, select_one): Select the relevant building inspector forms from the list of options.
* **Building Inspector Forms** (`building_inspector_forms_5`, text): Enter any additional text relevant to the building inspector forms.
* **The Form is Designed for** (`emergency_evacuation_route_audit_application_form_6`, text): Enter any additional text that is relevant to the form's design.
* **Building** (`building_inspector_forms_7`, text): Enter the name of the building being audited.
* **Inspector Forms** (`building_inspector_forms_8`, select_one): Select whether the building inspector forms are relevant to the audit.
* **The** (`emergency_evacuation_route_audit_application_form_9`, text): Enter any additional text that is relevant to the audit.
* **Emergency Evacuation Route Audit Application Form** (`building_inspector_forms_10`, text): Enter any additional text that is relevant to the form.
