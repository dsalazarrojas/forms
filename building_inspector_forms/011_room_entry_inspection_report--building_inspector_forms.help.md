# Room Entry Inspection Report - Help Guide

## Purpose
This form is used to document room inspections, collecting information about the room's condition, photos, and inspection details.

## How To Complete This Form
1. Start by filling out the "Room Details" page with any relevant information about the room, such as its address or location.
2. Move on to the "Room Condition" page and select the current condition of the room from the provided options (Excellent, Good, Fair, Needs Work, or Unsatisfactory).
3. If you've taken photos during the inspection, upload them to the "Photos" field. You can add multiple photos if necessary.
4. Use the "Notes" field to document any additional comments or observations about the room's condition.
5. Provide your name and role in the "Inspector Name" and "Inspector Role" fields, respectively.
6. If the facility manager is present during the inspection, fill in their name and contact information in the "Facility Manager Name" and "Facility Manager Contact Info" fields.
7. Finally, select the completion date for the inspection in the "Completion Date" field.

## Field-by-Field Explanation

* **Room Details** (room_details, text, required: false): This field is used to collect any additional information about the room, such as its address or location.
* **Room Condition** (room_condition, select_one, required: false): This field helps assess the room's current condition, using the options (Excellent, Good, Fair, Needs Work, or Unsatisfactory).
* **Photos** (photo_urls, text, required: false): Upload photos taken during the inspection to provide visual evidence of the room's condition.
* **Notes** (notes, text, required: false): Add any additional comments or observations about the room's condition.
* **Inspector Name** (inspector_name, text, required: false): Enter your name as the inspector.
* **Inspector Role** (inspector_role, text, required: false): Describe your role as the inspector.
* **Facility Manager Name** (facility_manager_name, text, required: false): If the facility manager is present during the inspection, enter their name.
* **Facility Manager Contact Info** (facility_manager_contact_info, text, required: false): If the facility manager is present, enter their contact information.
* **Completion Date** (completion_date, date, required: false): Select the date the inspection was completed.
