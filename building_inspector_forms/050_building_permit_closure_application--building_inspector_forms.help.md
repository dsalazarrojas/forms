# Building Permit Closure Application - Help Guide
## Purpose
The building permit closure application form is used to finalize a building permit once all construction or renovation work is complete and all necessary documents and inspections have been completed or scheduled.

## How To Complete This Form
1. Ensure all work is complete and all necessary documents and inspections have been completed or scheduled.
2. Fill out all required fields with accurate and honest information.
3. Review and confirm all information before submitting the form.

## Field-by-Field Explanation

* **Building Permit Number**: Enter the number of the building permit for which you are seeking closure.
* **Permit Issue Date**: Enter the date the building permit was originally issued.
* **Applicant or Property Owner Name**: Enter the name of the property owner or the name of the individual or company authorized to request permit closure.
* **Email Address**: Enter the email address of the applicant or property owner.
* **Phone Number**: Enter the phone number of the applicant or property owner.
* **Company or Contractor Name (if applicable)**: Enter the name of the company or contractor responsible for the construction or renovation work.
* **Contractor License Number**: Enter the license number of the contractor, if applicable.
* **Property Address**: Enter the address of the property for which the permit was issued.
* **Parcel or Lot Number**: Enter the number of the parcel or lot for which the permit was issued.
* **Current Property Owner**: If the property owner is different from the applicant, enter the current property owner's name.
* **Original Scope of Work**: Enter a brief description of the original scope of work for which the permit was issued.
* **Work Completed as Described**: Select "Yes" if the work was completed as described in the original scope of work. If not, select "No" and provide a brief description of any modifications made.
* **Description of Modifications (if any)**: If any modifications were made, provide a brief description of the modifications.
* **Date of Substantial Completion**: Enter the date the majority of the work was completed.
* **Date of Final Completion**: Enter the date the work was fully completed.
* **Final Inspections**: Select "Yes" if the final inspection has been completed and passed. If not, select one of the other options and provide a brief explanation.
* **Final Inspection Date**: Enter the date the final inspection was completed, if applicable.
* **Inspector Name**: Enter the name of the inspector who completed the final inspection.
* **Inspection Result**: Select the outcome of the final inspection, if applicable.
* **Required Corrections**: If any corrections were required, provide a brief description of the corrections.
* **Electrical Final Inspection**: Select "Completed and approved" if the electrical final inspection was completed and passed. If not, select one of the other options.
* **Plumbing Final Inspection**: Select "Completed and approved" if the plumbing final inspection was completed and passed. If not, select one of the other options.
* **Mechanical Final Inspection**: Select "Completed and approved" if the mechanical final inspection was completed and passed. If not, select one of the other options.
* **All Required Systems Passed Inspection**: Select "Yes" if all required systems passed inspection.
* **All Required Documents Submitted**: Select "Yes" if all required documents have been submitted.
* **As-Built Plans Submitted**: Select "Yes" if the as-built plans have been submitted.
* **Building Permit Compliance Verified**: Select "Yes" if the building permit compliance has been verified.
* **Certificate of Occupancy Requested**: Select "Yes" if a certificate of occupancy has been requested.
* **Performance Bonds Released**: Select "Yes" if the performance bonds have been released.
* **All Permit Fees Paid**: Select "Yes" if all permit fees have been paid.
* **Authorized to Request Permit Closure**: Select "Yes" if you are authorized to request permit closure.
* **All Work Properly and Safely Completed**: Select "Yes" if all work was properly and safely completed per plans.
* **Additional Information or Comments**: If any additional information or comments are necessary, provide them here.
