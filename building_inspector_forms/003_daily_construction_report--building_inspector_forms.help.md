# Daily Construction Report - Help Guide

## Purpose
The Daily Construction Report is a form used for daily reporting of construction projects. It is essential to complete this form accurately and thoroughly to ensure that all relevant information is recorded for tracking and monitoring of the project's progress.

## How To Complete This Form
1. Ensure that you are authorized to complete this form.
2. Review the form carefully to understand its purpose and requirements.
3. Enter the following information:
	* Project Name: Enter the name of the project being reported on.
	* Site Address: Enter the address of the site where the project is located.
	* Date Completed: Enter the date on which the project was completed.
	* Time Completed: If applicable, enter the time on which the project was completed.
	* Work Order Number: If applicable, enter the work order number associated with the project.
	* Inspector Name: Enter your name as the inspector.
	* Inspector Signature: Sign your name as the inspector, confirming that you have completed the report accurately.
	* Inspector Phone Number: Enter your phone number.
	* Inspector Email: Enter your email address.
	* Notes: Enter any additional notes or comments about the project.
	* Photos: If applicable, select "Yes" if you took photos during the inspection, otherwise select "No".

## Field-by-Field Explanation

* **Project Name** (`project_name`, `text`, required): Enter the name of the project being reported on.
* **Site Address** (`site_address`, `text`, required): Enter the address of the site where the project is located.
* **Date Completed** (`date_completed`, `date`, required): Enter the date on which the project was completed.
* **Time Completed** (`time_completed`, `time`, optional): If applicable, enter the time on which the project was completed.
* **Work Order Number** (`work_order_number`, `text`, optional): If applicable, enter the work order number associated with the project.
* **Inspector Name** (`inspector_name`, `text`, optional): Enter your name as the inspector.
* **Inspector Signature** (`inspector_signature`, `text`, required): Sign your name as the inspector, confirming that you have completed the report accurately.
* **Inspector Phone Number** (`inspector_phone_number`, `text`, required): Enter your phone number.
* **Inspector Email** (`inspector_email`, `text`, required): Enter your email address.
* **Notes** (`notes`, `text`, optional): Enter any additional notes or comments about the project.
* **Photos** (`photos`, `select_multiple`, optional): If applicable, select "Yes" if you took photos during the inspection, otherwise select "No".
