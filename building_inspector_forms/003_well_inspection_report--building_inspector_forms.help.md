# Well Inspecton Report - Help Guide
## Purpose
The Well Inspecton Report form is used to document the condition and inspection details of a well, including any recommendations for maintenance or repair.

## How To Complete This Form
1. Select the "Well Condition" page and enter a brief description of the well's condition.
2. On the "Recommendations" page, select all the recommendations that apply to the well's condition.
3. On the "Photos or Files" page, select "Yes" if you have attached any photos or files to support your inspection report.
4. In the "Additional Notes" field, enter any relevant comments or observations about the well.
5. For each of the "Recommendations" fields, select "Yes" if the recommendation is applicable and "No" otherwise.
6. Enter the "Date of Inspection" and "Time of Inspection" fields with the date and time of the inspection.
7. In the "Attach Files" field, select "Yes" if you have attached any files to support your report.
8. Enter the "Attached Photos" field with the number of photos attached.
9. Enter the "Location" field with the location of the well.
10. Enter the "Well Name" field with the name of the well.
11. For each of the "Recommendations" fields, select "Yes" or "No" based on the recommendation's applicability.

## Field-by-Field Explanation
* **Well Condition (Text)**: Enter a brief description of the well's condition.
* **Recommendations (Select multiple)**: Select all the recommendations that apply to the well's condition.
* **Photos or Files (Select multiple)**: Select "Yes" if you have attached any photos or files to support your inspection report.
* **Additional Notes (Text)**: Enter any relevant comments or observations about the well.
* **Notes on Recommendations (Text)**: Enter any additional comments or observations about the recommendations.
* **Date of Inspection (Date)**: Enter the date of the inspection.
* **Time of Inspection (Time)**: Enter the time of the inspection.
* **Attach Files (Select multiple)**: Select "Yes" if you have attached any files to support your report.
* **Attached Photos (Select multiple)**: Enter the number of photos attached.
* **Location (Text)**: Enter the location of the well.
* **Well Name (Text)**: Enter the name of the well.
* **Recommendation 1-14 (Select One)**: Select "Yes" or "No" based on the recommendation's applicability.
