# Uniform Inspection Checklist - Help Guide
## Purpose
The Uniform Inspection Checklist is a standard form designed to help building inspectors evaluate and report on the quality and condition of uniforms and equipment used in the inspection process. This form ensures that all inspectors follow a consistent process, reducing subjective judgments and promoting fairness.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for each field:
	* For "Building Inspector Forms", select all relevant forms from the list of available options.
	* For "Uniform Type", select the type of uniform being inspected (e.g., Army, Navy, Marine Corps, Airforce).
	* For "Is Worn Properly", "Is In Proper Condition", "Is In Proper Fitting", "Is Properly Cleaned", "Is Maintained Properly", and "Is Worn With Proper Emblem", select "Yes" or "No" based on your observations.
	* For "Comments", provide any additional comments or notes about the uniform or equipment.
	* For "Assigned Tool", enter the tool or equipment being inspected.
	* For "Form ID", enter a unique identifier for the form, if required.
	* For "Date", enter the date of the inspection.

## Field-by-Field Explanation
* **Building Inspector Forms**: Select all relevant forms from the list of available options. This field is used to identify which forms were used during the inspection.
* **Uniform Type**: Select the type of uniform being inspected (e.g., Army, Navy, Marine Corps, Airforce). This field helps ensure that the correct type of uniform is being inspected.
* **Is Worn Properly**: Select "Yes" if the uniform is worn properly, and "No" if it is not. This field checks if the uniform is worn in accordance with regulations.
* **Is In Proper Condition**: Select "Yes" if the uniform is in proper condition, and "No" if it is not. This field checks if the uniform is clean, pressed, and free from tears or other damage.
* **Is In Proper Fitting**: Select "Yes" if the uniform is in proper fitting, and "No" if it is not. This field checks if the uniform fits properly and is not too loose or too tight.
* **Is Properly Cleaned**: Select "Yes" if the uniform is properly cleaned, and "No" if it is not. This field checks if the uniform is clean and free from stains or odors.
* **Is Maintained Properly**: Select "Yes" if the uniform is properly maintained, and "No" if it is not. This field checks if the uniform is well-maintained and free from excessive wear and tear.
* **Is Worn With Proper Emblem**: Select "Yes" if the uniform is worn with proper emblem, and "No" if it is not. This field checks if the correct emblem is properly displayed on the uniform.
* **Comments**: Provide any additional comments or notes about the uniform or equipment being inspected. This field is useful for providing more information or context about the inspection results.
* **Assigned Tool**: Enter the tool or equipment being inspected. This field is used to record the specific tool or equipment being inspected.
* **Form ID**: Enter a unique identifier for the form, if required. This field is used to track the form's progress and status.
* **Date**: Enter the date of the inspection. This field records the date of the inspection and helps in tracking the progress and status of the inspection.
