# Building Observation Report - Help Guide
## Purpose
The Building Observation Report form is designed to gather data on a building's condition, including its exterior and interior aspects. It's a crucial tool for inspectors to document their findings and provide a comprehensive report.

## How To Complete This Form
1. Start by filling out the "Report Date" field, which requires the date of the observation.
2. Enter the "Property Address" in the corresponding field, providing the exact location of the building.
3. Fill in the "Inspector Name" field with the name and title of the person conducting the inspection.
4. For the "Time of Observation" field, provide the start time of the inspection (if necessary).
5. In the "Weather Conditions" field, select the current weather at the time of the inspection.
6. Evaluate the building's exterior condition using the "Exterior Building Assessment" field and select from the provided options.
7. Describe any exterior observations or issues in the "Exterior Observations" field.
8. Provide detailed information about the roof condition in the "Roof Condition Observations" field.
9. Describe the foundation condition in the "Foundation Observations" field.
10. In "Windows and Doors Observations," describe any issues with windows and doors.
11. Assess the building's interior condition using the "Interior Building Assessment" field and select from the provided options.
12. Write down any interior observations or issues in the "Interior Observations" field.
13. Describe the condition of walls, ceilings, and floors in the "Walls, Ceilings, and Floors" field.
14. Document any visible issues with the plumbing system in the "Plumbing System Observations" field.
15. Describe any issues with the electrical system in the "Electrical System Observations" field.
16. Note any Heating, Ventilation, and Air Conditioning (HVAC) system issues in the "HVAC System Observations" field.
17. In "Safety Issues Identified," select all observed hazards.
18. Describe any safety hazards or issues in the "Details of Safety Issues" field.
19. List any maintenance items needed in the "Maintenance Items Needed" field.
20. Evaluate the urgency of needed repairs using the "Urgency of Repairs" field and select from the provided options.
21. Provide any suggested improvements or recommendations in the "Inspector Recommendations" field.
22. Finally, rate the building's overall condition using the "Overall Condition Rating" field and select from the provided options.
