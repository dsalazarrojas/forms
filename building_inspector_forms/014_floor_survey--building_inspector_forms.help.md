# Floor Survey - Help Guide
## Purpose
The Floor Survey form is used to collect information about the floor of a building for inspection purposes. This data will be used to identify and track the building and its various components.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of building (residential, commercial, or industrial).
2. Enter the location ID (a unique identifier for the building's location).
3. Enter the location name.
4. Enter the building name.
5. Enter the floor number.
6. Enter the room number.
7. Provide a description of the floor.
8. Enter the building inspector's name.
9. Enter the building inspector's license number.
10. Enter the building inspector's phone number.
11. Enter the building inspector's email.
12. Enter any additional notes from the building inspector.
13. Select the building inspector's assigned tool (Chatbot or Chatjimmy).

## Field-by-Field Explanation
* **building_type**: Select the type of building (residential, commercial, or industrial).
	+ This field is optional and helps identify the building's purpose or usage.
* **location_id**: Enter a unique identifier for the building's location.
	+ This field is optional and helps track the building's location.
* **location_name**: Enter the name of the building's location.
	+ This field is optional and helps describe the building's location.
* **building_name**: Enter the name of the building.
	+ This field is optional and helps identify the building.
* **floor_number**: Enter the number of the floor being inspected.
	+ This field is optional and helps track the floor's location.
* **room_number**: Enter the number of the room being inspected.
	+ This field is optional and helps track the room's location.
* **description**: Provide a brief description of the floor being inspected.
	+ This field is optional and helps describe the floor's features or conditions.
* **building_inspector_name**: Enter the name of the building inspector.
	+ This field is optional and helps identify the building inspector.
* **building_inspector_license_number**: Enter the building inspector's license number.
	+ This field is optional and helps verify the inspector's qualifications.
* **building_inspector_phone**: Enter the building inspector's phone number.
	+ This field is optional and helps contact the inspector.
* **building_inspector_email**: Enter the building inspector's email address.
	+ This field is optional and helps contact the inspector.
* **building_inspector_notes**: Enter any additional notes from the building inspector.
	+ This field is optional and helps provide extra information about the inspection.
* **building_inspector_assigned_tool**: Select the building inspector's assigned tool (Chatbot or Chatjimmy).
	+ This field is optional and helps identify the tool used for inspection.

## Tips
* Ensure that all fields are accurate and complete before submitting the form.
* If unsure about any field, refer to the explanations above or contact the relevant authorities.
* Use a clear and concise description for the floor being inspected.
* Use a valid and up-to-date email address for the building inspector.
* Use a valid phone number and license number for the building inspector.
