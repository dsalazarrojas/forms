# Building Renovation Approval Request Form - Help Guide

## Purpose
The purpose of this form is to collect information about a building renovation project, including property details, project scope, timeline, cost, and contractor's information, to facilitate the approval process.

## How To Complete This Form

1. **Property Address**: Enter the complete street address of the property, including the unit number if applicable.
2. **Property Owner Name**: Enter the full legal name of the property owner.
3. **Property Owner Phone Number**: Enter the contact phone number for the property owner.
4. **Property Owner Email**: Enter a valid email address for the property owner.
5. **Type of Renovation**: Select the primary category of the renovation work (e.g., Interior Remodeling, Exterior Work, etc.).
6. **Scope of Work Description**: Provide a detailed description of all proposed work.
7. **Estimated Project Cost**: Enter the total estimated cost of the project in USD.
8. **Proposed Start Date**: Enter the date when you plan to begin work.
9. **Estimated Duration**: Enter the estimated duration of the project in weeks.
10. **Contractor Company Name**: Enter the name of the licensed contractor company.
11. **Contractor License Number**: Enter the state license number of the contractor.
12. **Contractor Phone**: Enter the contact phone number for the contractor.
13. **Contractor Email**: Enter the email address for the contractor.
14. **Are Permits Required**: Select 'True' if the project requires building permits.
15. **Permits Already Obtained**: Select 'True' if necessary permits have been acquired.
16. **Engineering Plans Submitted**: Select 'True' if engineering plans have been prepared.
17. **Asbestos Inspection Completed**: Select 'True' if an asbestos survey has been conducted (if the building was constructed before 1980).
18. **Insurance Coverage Details**: Enter the type of insurance coverage for the project.
19. **Additional Comments or Notes**: Enter any additional information about the renovation project.
