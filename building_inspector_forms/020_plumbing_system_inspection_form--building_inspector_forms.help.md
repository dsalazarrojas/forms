# Plumbing System Inspection Form - Help Guide
## Purpose
The Plumbing System Inspection Form is designed to inspect and evaluate the condition of the plumbing system. This includes assessing the status, quality, and condition of the fixtures and pipes to identify any potential issues or concerns.

## How To Complete This Form

1. Fill in the Inspection Date to record the date of the inspection.
2. Enter the Inspector's Name to identify who conducted the inspection.
3. For System Condition, select one of the three options: good, fair, or poor.
4. Describe the Leak Location if there are any issues with the system.
5. Evaluate the Fixture Condition by selecting one of the three options: excellent, fair, or poor.
6. Identify the Pipe Material using one of the three options: Copper, PEX, or PVC.
7. Enter the Pipe Size if necessary.
8. Select the Pipe Condition by choosing one of the three options: good, fair, or poor.
9. Choose the Water Quality by selecting one of the four options: excellent, good, fair, or poor.
10. Specify the Fixture Type using text, e.g., "water heater" or "faucet".
11. Enter the Fixture Type Location if necessary.
12. Evaluate the Fixture Condition by selecting one of the three options: excellent, fair, or poor.
13. Identify the Water Quality Location using text, e.g., "kitchen" or "bathroom".
14. Enter the Pipe Location using text, e.g., "under the sink" or "behind the wall".
15. Add any Other Notes about the inspection.
16. Evaluate the System Status by selecting one of the two options: active or inactive.
17. Enter the System Status Location using text, e.g., "main floor" or "basement".
18. Enter any Other System Status using text, e.g., "under construction" or "waiting for repair".
19. Add System Notes about the inspection.
20. Enter the Water Temperature if necessary.
21. Enter the Pipe Diameter if necessary.
22. Enter the Pipe Depth if necessary.
23. Enter the Fixture Depth if necessary.
24. Evaluate the System Rating by selecting multiple options: excellent, good, fair, or poor.
25. Enter the System Rating Location using text, e.g., "kitchen" or "bathroom".

## Field-by-Field Explanation

* **Inspection Date (1)**: The date of the inspection.
* **Inspector Name (2)**: The name of the person who conducted the inspection.
* **System Condition (3)**: The overall condition of the system, rated as good, fair, or poor.
* **Leak Location (4)**: A description of where the leak was found.
* **Fixture Condition (5)**: The condition of the fixtures, rated as excellent, fair, or poor.
* **Pipe Material (6)**: The type of material used for the pipes, e.g., Copper, PEX, or PVC.
* **Pipe Size (7)**: The size of the pipes, if necessary.
* **Pipe Condition (8)**: The condition of the pipes, rated as good, fair, or poor.
* **Water Quality (9)**: The quality of the water, rated as excellent, good, fair, or poor.
* **Fixture Type (10)**: A description of the type of fixture, e.g., "water heater" or "faucet".
* **Fixture Type Location (11)**: A description of where the fixture is located.
* **Fixture Condition (12)**: The condition of the fixtures, rated as excellent, fair, or poor.
* **Water Quality Location (13)**: A description of where the water quality issues were found.
* **Pipe Location (14)**: A description of where the pipes are located.
* **Other Notes (15)**: Additional comments or notes about the inspection.
* **System Status (16)**: The status of the system, rated as active or inactive.
* **System Status Location (17)**: A description of where the system status was found.
* **Other System Status (18)**: Additional comments or notes about the system status.
* **System Notes (19)**: Additional comments or notes about the system.
* **Water Temperature (20)**: The temperature of the water, if necessary.
* **Pipe Diameter (21)**: The diameter of the pipes, if necessary.
* **Pipe Depth (22)**: The depth of the pipes, if necessary.
* **Fixture Depth (23)**: The depth of the fixtures, if necessary.
* **System Rating (24)**: A rating of the system, selected from multiple options.
* **System Rating Location (25)**: A description of where the system was rated.

## Tips

* Make sure to complete the form thoroughly and accurately to ensure that the inspection results are reliable and useful.
* If you are unsure about any aspect of the form, consult with a colleague or supervisor.
* Remember to include any additional comments or notes that may be helpful for future reference.
* Ensure that the form is completed before leaving the inspection site to prevent loss of information.
* Review the form carefully before submitting it to ensure that all required fields are filled in.
