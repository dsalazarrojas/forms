# Chimney Inspection Form - Help Guide

## Purpose

The Chimney Inspection Form is designed to gather information about a chimney's condition and provide an assessment of its overall condition, safety, and any recommended repairs or services.

## How To Complete This Form

1.  Complete each section of the form in order from top to bottom.
2.  Be thorough and accurate when filling out each field.
3.  Use the provided hints for help and guidance.
4.  Refer to the inspection notes for additional context and details.

## Field-by-Field Explanation

*  **Inspection Information**: Enter a brief description of the inspection performed.
    *   **Date of Inspection**: Enter the date of the inspection in MM/DD/YY format.
    *   **Time of Inspection**: Enter the time of the inspection in HH:MM format.
    *   **Inspector Name**: Enter the name of the inspector performing the inspection.
    *   **Inspector Company**: Enter the name of the company the inspector works for.
    *   **Inspector License**: Enter the inspector's license number or certification number.
*  **Customer Information**: Enter the details about the property owner or customer.
*  **Chimney Information**: Enter a brief description of the chimney, including its type, location, and height.
*  **Connected Appliances**: Select all the appliances connected to the chimney that were inspected.
*  **Exterior Inspection**: Enter a brief description of the chimney's exterior condition.
*  **Chimney Cap Condition**: Select the condition of the chimney cap.
*  **Flashing Condition**: Select the condition of the flashing surrounding the chimney.
*  **Masonry Condition**: Select the condition of the masonry materials used in the chimney.
*  **Chimney Crown Condition**: Select the condition of the chimney's crown.
*  **Interior Inspection**: Enter a brief description of the interior condition of the chimney.
*  **Flue Condition**: Select the condition of the flue.
*  **Flue Liner Type**: Select the type of flue liner used.
*  **Creosote Buildup Level**: Select the level of creosote build up on the chimney.
*  **Obstructions**: Select any obstructions found in the chimney.
*  **Smoke Chamber Condition**: Select the condition of the smoke chamber.
*  **Firebox Condition**: Select the condition of the firebox.
*  **Damper Operation**: Select the operation of the damper.
*  **Safety Issues**: Enter any safety issues or concerns.
*  **Safety Hazards Identified**: Select all safety hazards found during the inspection.
*  **Water Intrusion**: Select the level of water intrusion found during the inspection.
*  **Recommendations**: Enter any recommended repairs or maintenance actions.
*  **Inspection Level**: Select the level of inspection performed.
*  **Overall Chimney Condition**: Select the overall condition of the chimney.
*  **Immediate Repairs Needed**: Select any immediate repairs needed for the chimney.
*  **Recommended Services**: Select all recommended services for the chimney.
*  **Inspector Notes**: Enter any additional notes or comments about the inspection.
*  **Estimate Provided**: Select whether an estimate was provided for repairs.
*  **Customer Signature**: Enter the customer's signature acknowledging the inspection.
*  **Inspector Signature**: Enter the inspector's signature verifying the inspection.

By following these instructions and completing each field accurately, the inspector can gather comprehensive data about the chimney's condition and provide a thorough assessment of its overall condition, safety, and any recommended repairs or services.
