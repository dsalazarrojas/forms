# Building Condition Assessment Survey - Help Guide

## Purpose
The Building Condition Assessment Survey is a standardized form used by building inspectors to gather data on the condition of a building's structure, systems, and other factors that impact its overall quality and value. This form helps inspectors identify potential issues and prioritize necessary repairs to prevent safety hazards and maintain the building's condition.

## How To Complete This Form

1. Select the "Assessment Date" field and enter the date of the inspection.
2. Enter the "Property Address" of the building being inspected.
3. Enter the "Property ID" reference number (if available).
4. For "Building Age," enter the number of years since the building's construction.
5. Assess the condition of the "Foundation Condition", "Roof Condition", "Exterior Walls Condition", "Windows and Doors", "Plumbing System", "Electrical System", "HVAC System", and "Interior Walls and Finishes" using the following scale:
	* Excellent
	* Good
	* Fair
	* Poor
	* Critical
6. Indicate if there are "Signs of Moisture or Water Damage" (None Visible, Minor Spots, Moderate Damage, Extensive Damage).
7. Identify any "Safety Hazards" (None Found, Electrical, Gas, Structural, Asbestos, Lead Paint, Other).
8. Enter any "Immediate Maintenance Needs" in the text field.
9. Optional: Enter "Long-Term Repairs Recommended" if you have suggestions for future improvements.
10. Assess the "Overall Building Condition" using the same scale as above.
11. Enter your "Inspector Name" and "Inspector License Number" for record-keeping purposes.

## Field-by-Field Explanation

* **Assessment Date (assessment_date)**: Date of inspection when you visited the building.
* **Property Address (property_address)**: Building location, including street address and unit number.
* **Property ID (property_id)**: Reference number for the building (optional).
* **Building Age (building_age)**: Number of years since the building's construction.
* **Foundation Condition (foundation_condition)**: Assess the structural foundation's condition using the provided scale.
* **Roof Condition (roof_condition)**: Evaluate the roof's structural integrity using the provided scale.
* **Exterior Walls Condition (exterior_walls)**: Assess the condition of the building's exterior walls using the provided scale.
* **Windows and Doors (windows_doors)**: Evaluate the condition and functionality of the windows and doors using the provided scale.
* **Plumbing System (plumbing_system)**: Assess the plumbing system's condition using the provided scale.
* **Electrical System (electrical_system)**: Evaluate the electrical system's condition using the provided scale.
* **HVAC System (hvac_system)**: Assess the HVAC system's condition using the provided scale.
* **Interior Walls and Finishes (interior_walls)**: Evaluate the condition and finish of the interior walls using the provided scale.
* **Signs of Moisture or Water Damage (moisture_damage)**: Identify any signs of moisture or water damage using the provided options.
* **Safety Hazards (safety_hazards)**: Identify any safety hazards using the provided options.
* **Immediate Maintenance Needs (maintenance_needs)**: Enter any maintenance needs that require immediate attention.
* **Long-Term Repairs Recommended (long_term_repairs)**: Suggest long-term repairs or improvements (optional).
* **Overall Building Condition (overall_rating)**: Assess the building's overall condition using the provided scale.
* **Inspector Name (inspector_name)**: Enter your full name for record-keeping purposes.
* **Inspector License Number (inspector_license)**: Enter your professional license number (optional).
