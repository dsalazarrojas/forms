# Building Approval Form - Help Guide
## Purpose
The Building Approval Form is a document used to collect project details for building inspections and approval.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project name, address, and type.
2. Provide estimated project cost.
3. Enter applicant information (name, role, contact information, and phone number).
4. Provide contractor information (name, license number, and license expiration date).
5. Confirm whether the contractor has liability insurance.
6. Indicate the scope of work and complete plans submission status.
7. Provide proposed start and completion dates.
8. Identify inspections required for the project.
9. Confirm site safety plan and demolition or debris removal plan.
10. Make a recommendation on building inspector approval status, including any conditions for approval.

## Field-by-Field Explanation

* **Project name** (`project_name`, text, required): Enter the name of the project.
* **Project address** (`project_address`, text, required): Enter the address of the project location.
* **Project type** (`project_type`, select_one, required): Select the type of project (e.g., new construction, renovation, expansion, etc.).
* **Scope of work** (`project_scope`, text, required): Describe the scope of work for the project.
* **Estimated project cost** (`estimated_cost`, number, required): Enter the estimated cost of the project.
* **Applicant name** (`applicant_name`, text, required): Enter the name of the applicant.
* **Applicant role** (`applicant_role`, select_one, required): Select the role of the applicant (e.g., owner, contractor, architect, etc.).
* **Contact information** (`applicant_contact`, email, required): Enter the contact information of the applicant.
* **Phone number** (`applicant_phone`, text, required): Enter the phone number of the applicant.
* **Contractor name** (`contractor_name`, text, required): Enter the name of the contractor.
* **Contractor license number** (`license_number`, text, required): Enter the contractor's license number.
* **License expiration date** (`license_expiration`, date, required): Enter the expiration date of the contractor's license.
* **Contractor has liability insurance** (`contractor_insurance`, select_one, required): Confirm whether the contractor has liability insurance.
* **Architect name** (`architect_name`, text, optional): Enter the name of the architect (if applicable).
* **Engineer name** (`engineer_name`, text, optional): Enter the name of the engineer (if applicable).
* **Complete plans submitted** (`plans_submitted`, select_one, required): Confirm whether complete plans have been submitted.
* **Plans reviewed for code compliance** (`code_compliance`, select_one, optional): Confirm whether plans were reviewed for code compliance.
* **Proposed start date** (`start_date`, date, required): Enter the proposed start date of the project.
* **Proposed completion date** (`completion_date`, date, required): Enter the proposed completion date of the project.
* **Inspections required** (`inspection_schedule`, select_multiple, required): Select the inspections required for the project.
* **Site safety plan** (`site_safety_plan`, select_one, required): Confirm whether a site safety plan is in place.
* **Demolition or debris removal plan** (`demolition_plan`, select_one, optional): Confirm whether a demolition or debris removal plan is in place.
* **Building inspector approval recommendation** (`approval_recommendation`, select_one, optional): Make a recommendation on the building inspector's approval status.
* **Conditions for approval** (`approval_conditions`, text, optional): Provide conditions for approval (if any).
* **Inspection schedule** (`inspection_schedule`, select_multiple, optional): Select additional inspections required (if not listed elsewhere).
* **Safety measures** (`safety_measures`, note, optional): Describe any safety measures taken or planned for the project.
* **Final inspection** (`final_inspection`, select_one, optional): Confirm whether final inspection has been completed.
* **Approval status** (`approval_status`, note, optional): Enter the current status of the project's approval.
* **Other inspections** (`other_inspections`, note, optional): Describe any other inspections required or completed.
* **Notes** (`notes`, note, optional): Add any additional notes or comments for the building inspector.
* **Approval conditions** (`approval_conditions`, text, optional): Describe any conditions for approval.
* **Other** (`other`, note, optional): Provide any other information relevant to the project.
