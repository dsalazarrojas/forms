# Fire Door Inspection Form - Help Guide
## Purpose
This form is designed to inspect fire doors and associated safety systems in a building. It will help ensure that fire doors are functioning correctly and meet relevant safety standards.

## How To Complete This Form
1. Review each page of the form carefully.
2. Select the relevant options for each field based on your inspection findings.
3. Ensure all required fields are completed.
4. Use the notes field to provide any additional information that may be relevant to the inspection.

## Field-by-Field Explanation
* **Fire Door Inspection** (`fire_door_inspection`, text, required/optional): Briefly describe the condition of the fire door.
* **Door Condition** (`door_condition`, select_one, required/optional): Select the condition of the fire door from the provided options: Good, Needs Repair, or Needs Replacement.
* **Door Clearance** (`door_clearance`, number, required/optional): Measure the door's clearance in centimeters.
* **Fire Exit Sign** (`fire_exit_sign`, select_one, required/optional): Check if the fire exit sign is working or not working, or select N/A if it's not applicable.
* **Fire Exit Alarms** (`fire_exit_alarms`, select_multiple, required/optional): Check if the fire exit alarms are working or not working.
* **Exit Sign Color** (`exit_sign_color`, select_one, required/optional): Select the color of the exit sign from the provided options: Black, White, Red, Yellow, or Green.
* **Fire Exit Alarms Prophets** (`fire_exit_alarms_prophets`, select_one, required/optional): Check if the fire exit alarms are working or not working.
* **Fire Exit Doors Wet Location** (`fire_exit_doors_wet_location`, note, required/optional): Take notes on the location of fire exit doors that are wet.
* **Fire Exit Doors Drains** (`fire_exit_doors_drains`, select_multiple, required/optional): Check if the fire exit doors have drains that are working or not working.
* **Emergency Exit Sign** (`emergency_exit_sign`, select_one, required/optional): Check if there is an emergency exit sign present.
* **Fire Alarms** (`fire_alarms`, select_multiple, required/optional): Check if the fire alarms are working or not working.
* **Fire Doors** (`fire_doors`, select_multiple, required/optional): Check if the fire doors are working or not working.
* **Smoke Alarms** (`smoke_alarms`, select_multiple, required/optional): Check if the smoke alarms are working or not working.
* **Electrical Equipment** (`electrical_equipment`, select_multiple, required/optional): Check if the electrical equipment is working or not working.
* **Water Main Pipe** (`water_main_pipe`, select_one, required/optional): Check if the water main pipe is working or not working.
* **Fire Hose** (`fire_hose`, select_one, required/optional): Check if the fire hose is working or not working.
* **Fire Exit Goals** (`fire_exit_goals`, select_one, required/optional): Select the color of the fire exit goals from the provided options: Black, White, Red, Yellow, or Green.
* **Emergency Exit** (`emergency_exit`, select_one, required/optional): Select the color of the emergency exit from the provided options: Black, White, Red, Yellow, or Green.
* **Fire Exit Doors Location** (`fire_exit_doors_location`, select_multiple, required/optional): Take notes on the location of fire exit doors.
* **Fire Exit Doors Drains** (`fire_exit_doors_drains`, select_multiple, required/optional): Check if the fire exit doors have drains that are working or not working.
* **Fire Exit Doors Electrical** (`fire_exit_doors_electrical`, select_multiple, required/optional): Check if the fire exit doors' electrical components are working or not working.

Note: Please refer to the form's introduction for further instructions on how to use this form.
