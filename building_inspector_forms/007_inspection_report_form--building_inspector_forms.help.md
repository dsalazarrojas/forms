# Inspection Report Form - Help Guide
## Purpose
This form is designed to help building inspectors collect and document information about buildings and structures during inspections. The information gathered will be used to track and report findings, issues, and other relevant details.

## How To Complete This Form
1. Please fill out each section of the form completely and accurately.
2. Use the provided options when selecting answers, if applicable.
3. Be thorough in your descriptions and observations.
4. If you need to add additional information, use the "Notes" field provided in each section.

## Field-by-Field Explanation

* **Section 1: Section 1** (`page_1`, text, optional): This is the first section of the form where you can add any general information about the building/structure being inspected.
* **Section 2: Section 2** (`page_2`, select_one, optional): In this section, you will select one option from the provided list to indicate the condition of the building/structure.
* **Section 3: Section 3** (`page_3`, time, optional): This section is for recording the inspection time.
* **Section 4: Section 4** (`page_4`, number, optional): You can use this section to record numerical data, such as measurements or quantities.
* **Section 5: Section 5** (`page_5`, note, optional): This is a text area for adding notes and comments about the building/structure.
* **Section 6: Section 6** (`page_6`, date, optional): Record the date of the inspection in this section.
* **Section 7: Section 7** (`page_7`, email, optional): Enter your email address if you would like to be contacted about this inspection report.
* **Section 8: Section 8** (`page_8`, text, optional): This section is for adding any additional information about the building/structure.
* **Section 9: Section 9** (`page_9`, number, optional): Enter numerical data, such as quantities or measurements.
* **Section 10: Section 10** (`page_10`, text, optional): Add any final comments or observations about the building/structure.
* **Section 11: Section 11** (`page_11`, select_multiple, optional): In this section, select all applicable options to indicate multiple findings or issues with the building/structure.
* **Section 12: Section 12** (`page_12`, select_one, optional): Select one option from the provided list to indicate a specific finding or issue.
* **Section 13: Section 13** (`page_13`, note, optional): Add any additional notes or comments about the building/structure.
* **Section 14: Section 14** (`page_14`, text, optional): Add any final comments or observations about the building/structure.
* **Section 15: Section 15** (`page_15`, select_multiple, optional): Select all applicable options to indicate multiple findings or issues with the building/structure.
