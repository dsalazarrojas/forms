# Locomotive Inspection Checklist - Help Guide
## Purpose
This form is designed to provide a detailed inspection checklist for locomotives. It helps the inspector to ensure that all critical aspects of the locomotive are checked and recorded.

## How To Complete This Form
1. Select the relevant information for each field and submit the form.
2. Review and verify the correctness of the information entered.

## Field-by-Field Explanation
- **Locomotive Inspection Checklist** (`locomotive_inspection_checklist`, Text, Optional):
  Enter a brief description or remarks about the locomotive inspection. This field is a general notes section for any comments or observations made during the inspection.

- **Inspector Name** (`inspector_name`, Text, Optional):
  Enter the name of the person conducting the inspection. This field is not required but is useful for tracking who performed the inspection.

- **Inspector Role** (`inspector_role`, Select One, Optional):
  Select whether the inspector is a qualified personnel or not. This field helps to categorize the level of expertise of the inspector.

- **Locomotive Type** (`locomotive_type`, Select One, Optional):
  Select the type of locomotive being inspected. This field is useful for tracking specific types of locomotives.

- **Locomotive Status** (`locomotive_status`, Select Multiple, Optional):
  Select the current status of the locomotive. This field can be used to track whether the locomotive is Active or Inactive.

- **Locomotive Location** (`locomotive_location`, Text, Optional):
  Enter the location of the locomotive. This field helps to track where the locomotive was inspected.

- **Notes** (`notes`, Notes, Optional):
  Enter any additional comments or explanations that were not captured by the other fields. 

## Tips
- Double-check the accuracy of the information entered.
- Complete all required fields before submitting the form.
- Enter any relevant comments or explanations to ensure a complete understanding of the inspection. 

Please make sure to submit the form once you have completed it. 

This guide provides an overview of each field and how it can be used to ensure the inspection checklist is completed accurately and thoroughly. By following this guide, you should be able to complete the form effectively.
