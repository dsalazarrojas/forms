# Grooming Parlour Inspection Checklist - Help Guide
## Purpose
This form is designed to inspect a grooming parlour to ensure it meets the necessary standards and regulations for safety, hygiene, and overall quality.
## How To Complete This Form
1. Review the form carefully and answer each question according to the given options or your observations.
2. For select-all-that-apply questions, select all the applicable options that apply to the parlour.
3. For free-text fields, provide a clear and concise description of your observations.
4. Make sure to answer all questions accurately and thoroughly to ensure a comprehensive assessment of the parlour.

## Field-by-Field Explanation

* **Introduction** (`1`, `note`, optional): This section is an introduction to the form and provides a brief overview of the inspection process.
* **Facilities** (`2`, `select_multiple`, optional): Select all the facilities that are available in the parlour, such as the parlour's name, address, and contact information.
* **Facilities and Equipment** (`3`, `select_one`, optional): Check if the following facilities and equipment are available and in proper working condition: Faucets, Sinks, and Toilets.
* **Facilities and Equipment (other)** (`4`, `text`, optional): If not listed above, provide the name and description of the other facilities and equipment available in the parlour.
* **Facilities and Adequacy** (`5`, `select_multiple`, optional): Check if the facilities meet the required minimum standards for safety and hygiene, such as if the parlour is licensed and if there is a proper hand-washing facility.
* **Facilities and Adequacy (other)** (`6`, `text`, optional): If not listed above, provide a description of any other facilities and adequacy issues.
* **Staff** (`7`, `select_multiple`, optional): Check if the following staff are available during the inspection: the parlour owner, the parlour manager, and other staff members.
* **Staff (other)** (`8`, `text`, optional): If not listed above, provide the name and description of other staff members.
* **Facilities Cleanliness** (`9`, `select_multiple`, optional): Check if the facilities are clean and free from odours and pests, such as if the parlour is clean and if there is a strong odour.
* **Facilities Cleanliness (other)** (`10`, `text`, optional): If not listed above, provide a description of any other cleanliness issues.
* **Animal Handling** (`11`, `select_multiple`, optional): Check if animal handling practices are safe and humane, such as if animal handling is safe and if animal handling is humane.
* **Animal Handling (other)** (`12`, `text`, optional): If not listed above, provide a description of any other animal handling issues.
* **Facilities Waste** (`13`, `select_multiple`, optional): Check if waste is disposed of properly, such as if waste is disposed of properly and if there is a waste management plan.
* **Facilities Waste (other)** (`14`, `text`, optional): If not listed above, provide a description of any other waste management issues.
* **Facilities Fire Safety** (`15`, `select_multiple`, optional): Check if the facilities meet the required safety standards, such as if the parlour is fire safety compliant and if the fire alarm is working.
* **Facilities Fire Safety (other)** (`16`, `text`, optional): If not listed above, provide a description of any other fire safety issues.
* **Facilities Electricity** (`17`, `select_multiple`, optional): Check if the facilities meet the required electrical standards, such as if the electrical system is working properly and if there is a fire alarm in each room.
* **Facilities Electricity (other)** (`18`, `text`, optional): If not listed above, provide a description of any other electrical issues.
* **Facilities Plumbing** (`19`, `select_multiple`, optional): Check if the facilities meet the required plumbing standards, such as if the plumbing system is working properly and if there is a hot water supply.
* **Facilities Plumbing (other)** (`20`, `text`, optional): If not listed above, provide a description of any other plumbing issues.
* **Facilities Structural** (`21`, `select_multiple`, optional): Check if the facilities meet the required structural standards, such as if the building is in good condition and if the structural integrity is good.
* **Facilities Structural (other)** (`22`, `text`, optional): If not listed above, provide a description of any other structural issues.
* **Facilities Parking** (`23`, `select_multiple`, optional): Check if the facilities meet the required parking standards, such as if the parking area is available and if the parking area is well-maintained.
* **Facilities Parking (other)** (`24`, `text`, optional): If not listed above, provide a description of any other parking issues.
* **Other Findings** (`25`, `text`, optional): Enter any other issues or observations during the inspection that are not listed above.

## Tips

* Make sure to answer all questions accurately and thoroughly to ensure a comprehensive assessment of the parlour.
* If you're unsure about any question, provide a description of your observations or any other relevant information.
* This form is designed to help identify areas of improvement for the parlour; use it as a tool to help them better themselves.
