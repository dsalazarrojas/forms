# Water Leak Inspection Checklist - Help Guide
## Purpose
The Water Leak Inspection Checklist is a form used by building inspectors to document and report on the presence and condition of a building's plumbing system.

## How To Complete This Form
1. Fill out the form for each section, indicating whether the specified item is "Yes" or "No" as applicable.
	* Start with the "Introduction" section, providing a brief overview of the inspection.
	* Record the location of the inspection in the "Inspection Location" section.
	* In the "Pipes and Fittings" section, select "Yes" if all pipes and fittings are in good condition.
	* In the "Pipe Insulation" section, select "Yes" if all pipes are properly insulated.
	* In the "Water Meter" section, select "Yes" if the water meter is present and functioning correctly.
	* In the "Leaks Found" section, select "Yes" if any leaks are detected during the inspection.
	* In the "Notes" section, add any additional comments or observations about the inspection.
	* In the "Email" section, provide your email address for contact.
	* In the "Phone" section, provide your phone number for contact.
	* In the "Building Inspector Form" section, select "Yes" if this is a building inspector's form.
	* In the "Plumber Form" section, select "Yes" if this is a plumber's form.

## Field-by-Field Explanation
* **Introduction (text):** A brief overview of the inspection, including any relevant background information or comments.
* **Inspection Location (text):** The location where the inspection took place, including the address or building name.
* **Pipes and Fittings (select_multiple):** Check "Yes" if all pipes and fittings are in good condition, or "No" if any are found to be damaged or malfunctioning.
* **Pipe Insulation (select_multiple):** Check "Yes" if all pipes are properly insulated, or "No" if any are not.
* **Water Meter (select_one):** Check "Yes" if the water meter is present and functioning correctly, or "No" if it is missing or malfunctioning.
* **Leaks Found (select_one):** Check "Yes" if any leaks are detected during the inspection, or "No" if none are found.
* **Notes (note):** Add any additional comments or observations about the inspection, including any issues or concerns.
* **Email (email):** Your email address for contact.
* **Phone (text):** Your phone number for contact.
* **Building Inspector Form (select_one):** Check "Yes" if this is a building inspector's form, or "No" if it is not.
* **Plumber Form (select_one):** Check "Yes" if this is a plumber's form, or "No" if it is not.
