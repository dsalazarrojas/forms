# Flooring Inspection Checklist - Help Guide
## Purpose
The purpose of this form is to document the results of a flooring inspection. It helps building inspectors to identify the type of flooring, its condition, and any potential issues or defects. This information is crucial for ensuring that the flooring meets the required standards and safety regulations.

## How To Complete This Form
To complete this form, follow these steps:

1.  **Enter the inspection date**: Enter the date of the inspection in the "Inspection Date" field.
2.  **Enter the buyer's name**: Enter the name of the buyer or owner of the building in the "Buyer Name" field.
3.  **Select the floor type**: Select the type of flooring in the "Floor Type" field. This can be carpet, hard wood, laminate, tile, vinyl, or wood engineered.
4.  **Assess the flooring condition**: Choose the condition of the flooring in the "Flooring Condition" field. This can be excellent, good, fair, or poor.
5.  **Check for damage**: Check the "Damage Present" field to indicate if any damage is present. If yes, describe the damage in the "Damage Description" field.
6.  **Enter the inspector's details**: Enter your details as the inspector, including your name, company name, address, phone number, email, and notes.
7.  **Check for final inspection results**: Choose the final inspection result in the "Final Inspection Result" field. This can be pass or fail.

## Field-by-Field Explanation
- **Inspection Date (1)**: Enter the date of the inspection in dd/mm/yyyy format. This is a required field for tracking inspection dates.
- **Buyer Name (2)**: Enter the name of the buyer or owner of the building. This is an optional field, but it's helpful for record-keeping.
- **Floor Type (4)**: Select the type of flooring from the list provided. This field is required to document the type of flooring inspected.
- **Flooring Condition (5)**: Choose the condition of the flooring. This field is required to document the flooring's quality.
- **Damage Present (6)**: Check if any damage is present. If yes, describe the damage in the "Damage Description" field.
- **Damage Description (7)**: If damage is present, enter a detailed description of the damage. This is an optional field.
- **Comments (8)**: Enter any additional comments or observations about the inspection. This is an optional field.
- **Additional Comments (9)**: Enter any other comments or observations. This is an optional field.
- **Inspection Completed (10)**: Check if the inspection is completed. This is a required field to indicate completion status.
- **Completed By (11)**: Enter your name as the inspector. This is a required field for record-keeping.
- **Completed Date (12)**: Enter the date when the inspection was completed. This is a required field for tracking completion dates.
- **Inspector Signature (13)**: Sign your name as the inspector. This is a required field for authenticity.
- **Inspector Company (14)**: Enter your company name. This is a required field for record-keeping.
- **Inspector Address (16)**: Enter your company address. This is a required field for contact information.
- **Inspector Phone (17)**: Enter your phone number. This is a required field for contact information.
- **Inspector Email (18)**: Enter your email. This is a required field for contact information.
- **Inspector Notes (19)**: Enter any additional notes or comments about the inspection. This is an optional field.
- **Buyer Signature (20)**: If applicable, enter the buyer's signature. This is an optional field.
- **Buyer Address (21)**: If applicable, enter the buyer's address. This is an optional field.
- **Buyer Phone (22)**: If applicable, enter the buyer's phone number. This is an optional field.
- **Buyer Email (23)**: If applicable, enter the buyer's email. This is an optional field.
- **Buyer Notes (24)**: If applicable, enter any additional notes or comments from the buyer. This is an optional field.
- **Final Inspection Result (25)**: Choose the final inspection result. This can be pass or fail, which is a required field for determining the inspection outcome.
