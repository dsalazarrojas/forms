# Wedding Hair And Makeup Questionnaire - Help Guide

## Purpose
This form is used to collect information about the couple's preferences for hair and makeup on their wedding day. This will allow you to provide personalized and tailored services that meet their expectations.

## How To Complete This Form
- Please answer each field according to your personal preferences and expectations.
- You can select multiple options for fields that allow selection of multiple values.
- If a field is marked as optional, feel free to skip it if it's not relevant.
- If you have any special requests or additional information, please use the "Special Requests" field.

## Field-by-Field Explanation

* **Wedding Hair And Makeup Questionnaire** (1):
  This is the title of the form, simply for your reference.

* **Hair Style** (2):
  Choose whether the couple would like to have a specific hair style on their wedding day. Select "Yes" if they have a preference, and "No" otherwise.

* **Hair Style Other** (3):
  If the couple has a hair style that is not listed, please describe it in this field.

* **Makeup Style** (4):
  Choose whether the couple would like to have a specific makeup style on their wedding day. Select "Yes" if they have a preference, and "No" otherwise.

* **Makeup Style Other** (5):
  If the couple has a makeup style that is not listed, please describe it in this field.

* **Hair Length** (6):
  Select the couple's hair length. Please note that "afro" typically refers to a short, natural style.

* **Hair Color** (7):
  Choose the couple's hair color.

* **Makeup Color** (8):
  Select the couple's makeup color preference.

* **Hair Type** (9):
  Select all the hair types that apply to the couple. You can select multiple options.

* **Makeup Type** (10):
  Select all the makeup types that apply to the couple. You can select multiple options.

* **Special Requests** (11):
  If the couple has any special requests or requirements for their hair or makeup, please list them here.

* **Special Requests Other** (12):
  If the couple has any other special requests that are not listed, please describe them here.

* **Wedding Date** (13):
  Enter the date of the wedding.

* **Time of Day** (14):
  Enter the time of day for the wedding.

* **Wedding Location** (15):
  Enter the location of the wedding.

* **Wedding Location Other** (16):
  If the location is not listed, please describe it here.
