# Software Deployment Check In Form - Help Guide
## Purpose
This form is used to track and record information about software deployments, including the software status, deployment details, and relevant notes and comments. The form is primarily intended for IT teams to check in on software deployments, ensuring that all necessary updates and information are accurately recorded.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current status of the software deployment from the provided options.
2. Choose who was responsible for deploying the software (e.g., IT Team, Dev Team, or Other).
3. Enter the date the software was deployed.
4. Enter the time the software was deployed.
5. Enter any relevant notes or comments about the deployment.
6. Enter the name of the software being deployed.
7. Enter the version of the software being deployed.
8. Enter the name of the environment where the software is deployed.
9. Enter the version of the environment where the software is deployed.
10. Enter your name and email address.
11. Enter your phone number (optional).
12. Enter any additional comments about the deployment.

## Field-by-Field Explanation
* **Software Deployment Status**: This field allows you to select the current status of the software deployment. You can choose from the following options:
	+ Deployed
	+ Not Deployed
	+ Not Applicable
* **Deployed By**: Choose who was responsible for deploying the software. This field is used to track who was involved in the deployment process.
	+ IT Team
	+ Dev Team
	+ Other
* **Deployed Date**: Enter the date the software was deployed. This field should be in a standard date format (mm/dd/yyyy).
* **Deployed Time**: Enter the time the software was deployed. This field should be in 24-hour format (HH:MM).
* **Deployed Notes**: Enter any additional notes or comments about the deployment. This field is optional.
* **Software Name**: Enter the name of the software being deployed.
* **Software Version**: Enter the version of the software being deployed.
* **Environment Name**: Enter the name of the environment where the software is deployed.
* **Environment Version**: Enter the version of the environment where the software is deployed.
* **User Name**: Enter your name.
* **User Email**: Enter your email address.
* **User Phone**: Enter your phone number (optional).
* **Comments**: Enter any additional comments about the deployment. This field is optional.

Note: The fields marked as optional are not required to be filled out, but it's recommended to provide as much information as possible to ensure accurate tracking and record-keeping.
