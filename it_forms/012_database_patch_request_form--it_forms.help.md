# Database Patch Request Form - Help Guide
## Purpose
The Database Patch Request Form is used to submit updates to the database. Please use this form for legitimate requests that are not already being addressed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for the fields below to provide a detailed description of the requested patch.
2. Make sure to fill out all required fields before submitting the form.
3. Submit the form once you have filled out all the relevant fields.

## Field-by-Field Explanation
* **File Upload** (1, text, optional): This field allows you to upload a file that contains the patch details. This could be a zip or a text file with relevant patch information.
* **Description** (2, text, optional): Provide a detailed description of the patch you are requesting. This will help the development team understand the changes being requested.
* ** Fixes** (3, text, optional): Describe all the fixes or changes that will be included in the patch.
* **Category** (4, select, optional): Choose the category that best describes the type of patch being requested.
* **Priority** (5, select, optional): Select the priority of the patch, indicating its level of importance.
* **Status** (6, select, optional): Choose the status of the patch, indicating whether it is active or inactive.
* **Due Date** (7, date, optional): If the patch has a specific due date, select it here. Otherwise, leave blank.
* **Due Time** (8, time, optional): If the patch has a specific due time, select it here. Otherwise, leave blank.
* **Assigned To** (9, select, optional): If the patch is assigned to a specific team member or person, choose them here.

## Tips

* Please only fill out this form for legitimate and not already addressed patches.
* If you are unsure which category best describes the patch, choose 'Other' and describe the category in the description field.
* The development team will review the form and provide feedback or start working on the patch once it is submitted.
