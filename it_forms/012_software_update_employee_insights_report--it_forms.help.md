# Software Update Employee Insights Report - Help Guide
## Purpose
The Software Update Employee Insights Report is a form designed to gather feedback from employees on the performance of software updates. This feedback is used to identify areas for improvement and make data-driven decisions about future updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the number that corresponds to the software update you are reporting on in the "software_update" field.
2. Enter your name in the "employee_name" field.
3. Rate your experience with the software update in the "experience_score" field, on a scale of 1-10.
4. Select all issues you encountered with the software update in the "issues_encountered" field. You can choose one or more of the options: "bugs", "glitches", "performance issues".
5. If you have any suggestions for improvement, enter them in the "suggestions_for_improvement" field. This is optional.

## Field-by-Field Explanation

* **software_update** (`1`, `number`, required): Enter the number that corresponds to the software update you are reporting on. This will help us track which updates are being reported on.
* **employee_name** (`2`, `text`, required): Enter your name as you would like it to be displayed in the report.
* **experience_score** (`3`, `number`, required): Rate your experience with the software update on a scale of 1-10. A higher score indicates a more positive experience.
* **issues_encountered** (`4`, `select_multiple`, required): Select all issues you encountered with the software update. You can choose one or more of the options: "bugs", "glitches", "performance issues".
* **suggestions_for_improvement** (`5`, `note`, optional): If you have any suggestions for improvement, enter them here. This is an opportunity to provide specific feedback on how we can improve the software update process.

## Tips
* Please be honest and specific when providing feedback. Your input is invaluable to us!
* If you have any concerns or questions, please don't hesitate to reach out to your supervisor or IT department.
* If you're unsure whether you should fill out this form, ask someone from your team or supervisor for guidance.
