# Network And Camera Deployment Survey - Help Guide
## Purpose

The purpose of this form is to collect information about a site's network and camera deployment to ensure a comprehensive site survey.

## How To Complete This Form

1. Please answer each field carefully and accurately.
2. Ensure you complete all required fields.
3. If any of the fields do not apply to your site, please mark them as "N/A" (Not Applicable).

## Field-by-Field Explanation

* **Location Details** (`location_details`, `text`, required: false): Enter a brief description of the site's location.
* **Network Requirements** (`network_requirements`, `select_multiple`, required: false): Select all the network requirements that apply to your site from the options provided:
	+ Option A
	+ Option B
	+ Option C
* **Camera Requirements** (`camera_requirements`, `select_multiple`, required: false): Select all the camera requirements that apply to your site from the options provided:
	+ Option D
	+ Option E
* **Camera Placement** (`camera_placement`, `select_one`, required: false): Choose the correct placement of cameras for your site from the options provided:
	+ Option F
	+ Option G
* **Notes** (`notes`, `note`, required: false): Enter any additional notes about the site.
* **Contact** (`site_contact`, `email`, required: false): Enter the contact person's email address.
* **Phone** (`site_phone`, `text`, required: false): Enter the contact person's phone number.
* **Notes 2** (`site_notes`, `note`, required: false): Enter any additional notes about the site.
* **Location ID** (`location_id`, `number`, required: false): Enter the location's ID number.
* **Facility ID** (`facility_id`, `number`, required: false): Enter the facility's ID number.
* **Camera Count** (`camera_count`, `number`, required: false): Enter the number of cameras on the site.
* **Network Count** (`network_count`, `number`, required: false): Enter the number of networks on the site.
* **Site Survey Date** (`site_survey_date`, `date`, required: false): Enter the date of the site survey.
* **Site Survey Time** (`site_survey_time`, `time`, required: false): Enter the time of the site survey.
* **Network Status** (`network_status`, `select_one`, required: false): Choose the status of the network from the options provided:
	+ Option H
	+ Option I
	+ Option J
* **Network Type** (`network_type`, `select_multiple`, required: false): Select all the network types that apply to your site from the options provided:
	+ Option K
	+ Option L
* **Camera Type** (`camera_type`, `select_multiple`, required: false): Select all the camera types that apply to your site from the options provided:
	+ Option M
	+ Option N
	+ Option O
* **Camera Location** (`camera_location`, `select_multiple`, required: false): Select all the camera locations that apply to your site from the options provided:
	+ Option P
	+ Option Q
	+ Option R
* **Additional Info** (`additional_info`, `text`, required: false): Enter any additional information about the site.
* **Notes 3** (`notes_3`, `note`, required: false): Enter any additional notes about the site.
* **Site Surveyor** (`site_surveyor`, `text`, required: false): Enter the name of the site surveyor.
* **Site Survey** (`site_survey`, `date`, required: false): Enter the date of the site survey.
* **Site Survey Status** (`site_survey_status`, `select_one`, required: false): Choose the status of the site survey from the options provided:
	+ Option S
	+ Option T
* **Site Survey Date/Time** (`site_survey_date_time`, `date`, required: false): Enter the date and time of the site survey.
* **Site Notes 2** (`site_notes_2`, `note`, required: false): Enter any additional notes about the site.
