## Application Support Request Form - Help Guide
### Purpose
This form is designed to collect information from users to help the support team understand the nature of their request and provide effective assistance.

### How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the issue you are experiencing (e.g., Login Problem, Performance Issue).
2. Choose the priority level of your issue (e.g., Critical - System Down, High - Major Impact).
3. Provide a detailed description of the issue.
4. If applicable, specify steps to reproduce the issue and any error messages you see.
5. Indicate how many users are affected by the issue.
6. Specify the browser, operating system, and frequency of the issue.
7. If you have attempted any workarounds, indicate if they worked or not.
8. Describe the business impact of the issue.
9. If you have any additional comments or attachments, provide them in the text box.

### Field-by-Field Explanation
#### 1. Request Date
* **Request Date** (`request_date`, date, required): The date when you are requesting support for this issue.
#### 2. Request Time
* **Request Time** (`request_time`, time, optional): The time when the issue occurred.
#### 3. Requester Name
* **Requester Name** (`requester_name`, text, required): Your full name.
#### 4. Requester Email
* **Requester Email** (`requester_email`, email, required): Your email address.
#### 5. Requester Phone
* **Requester Phone** (`requester_phone`, text, optional): Your contact phone number.
#### 6. Department
* **Department** (`department`, text, required): The department or team you belong to.
#### 7. Application Name
* **Application Name** (`application_name`, text, required): The name of the application you are experiencing issues with.
#### 8. Application Version
* **Application Version** (`application_version`, text, optional): The version number of the application (if known).
#### 9. Issue Category
* **Issue Category** (`issue_category`, select_one, required): The category of the issue you are experiencing (e.g., Login Problem, Performance Issue).
#### 10. Issue Priority
* **Issue Priority** (`issue_priority`, select_one, required): The priority level of your issue (e.g., Critical - System Down, High - Major Impact).
#### 11. Issue Description
* **Issue Description** (`issue_description`, text, required): A detailed description of the issue.
#### 12. Steps to Reproduce
* **Steps to Reproduce** (`steps_to_reproduce`, text, optional): Steps that lead to the issue.
#### 13. Error Message
* **Error Message** (`error_message`, text, optional): Exact error message if any.
#### 14. Affected Users
* **Affected Users** (`affected_users`, select_one, required): How many users are affected by the issue.
#### 15. Browser Used
* **Browser Used** (`browser_used`, select_one, optional): The web browser you are using.
#### 16. Operating System
* **Operating System** (`operating_system`, select_one, optional): The operating system you are using.
#### 17. Issue Frequency
* **Issue Frequency** (`issue_frequency`, select_one, required): How often the issue occurs (e.g., Always, Frequently, Occasionally).
#### 18. Workaround Attempted
* **Workaround Attempted** (`workaround_attempted`, select_one, required): If you have attempted any workarounds, indicate if they worked or not.
#### 19. Workaround Details
* **Workaround Details** (`workaround_details`, text, optional): Describe any workaround attempts.
#### 20. Business Impact
* **Business Impact** (`business_impact`, text, required): Describe how the issue impacts your work.
#### 21. Requested Resolution Date
* **Requested Resolution Date** (`requested_resolution_date`, date, optional): The date by when you need the issue resolved.
#### 22. Attachments
* **Attachments** (`attachments`, text, optional): Any screenshots or documents to attach for reference.
#### 23. Additional Comments
* **Additional Comments** (`additional_comments`, text, optional): Any other relevant information.

### Tips
* Be as detailed as possible when describing the issue and its impact.
* If you are unsure about any field, please ask for clarification.
* Attach any relevant screenshots or documents to help the support team understand the issue better.
