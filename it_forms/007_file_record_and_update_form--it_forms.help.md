The purpose of this form is to record and update file information. This form allows users to enter the name of the file, its type, the date and time it was updated, who made the update, and any comments or change details associated with the update. This form is intended for users who need to track changes to files over time.

# file_record_and_update_form - Help Guide

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the name of the file in the "File Name" field.
2. Select the type of file from the "File Type" dropdown menu.
3. If you are making an update, enter the date and time the file was last updated in the "Date Updated" field.
4. If you are making an update, enter the username or name of the person making the update in the "Updated By" field.
5. Enter any comments or change details in the "Change Details" field.
6. If you are making an update, enter the current version of the file in the "Version" field.
7. If you are making an update, enter the updated version of the file in the "Updated Version" field.
8. Enter any comments about the update in the "Comments" field.
9. Click the "Submit" button to save your changes.

## Field-by-Field Explanation

* **File Name** (text, required/optional): Enter the name of the file being updated.
* **File Type** (select_one, required): Choose the type of file from the dropdown menu.
* **Date Updated** (date, optional): Enter the date and time the file was last updated. This field is only needed if you are making an update.
* **Updated By** (text, optional): Enter the username or name of the person making the update.
* **Change Details** (text, optional): Enter any comments or change details about the update.
* **Updated At** (time, optional): Enter the current date and time of the update.
* **Updated At** (time, duplicate label, optional): Enter the date and time of the update. This field is a duplicate of "Updated At" above.
* **Comments** (note, optional): Enter any comments about the update.
* **Version** (number, optional): Enter the current version of the file.
* **Updated Version** (number, optional): Enter the updated version of the file.
* **Version** (number, duplicate label, optional): Enter the updated version of the file. This field is a duplicate of "Version" above.

## Tips

* Make sure to fill in all required fields before submitting the form.
* If you are making an update, ensure that you enter the correct date and time of the update.
* Double-check your input for errors before submitting the form.
* If you have any further questions or need assistance, contact your administrator.
