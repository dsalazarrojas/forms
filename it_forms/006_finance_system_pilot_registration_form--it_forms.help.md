# Finance System Pilot Registration Form - Help Guide
## Purpose
This form is used to collect information from finance system pilots during the registration process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the finance system pilot details.
2. Specify your objective(s) for registering the pilot.
3. Indicate whether participants will be involved in the pilot.
4. Provide details about the pilot's start and end dates and times.
5. Add any additional notes if necessary.
6. Provide financial details about the pilot.
7. Specify the system's version.

## Field-by-Field Explanation

* **Finance System Pilot Details** (`finance_system_pilot_details`): Enter a brief description of the pilot.
* **Objective** (`objective`): Enter a clear and concise statement of the pilot's purpose or goal.
* **Objectives** (`objectives`): Select all applicable objectives that apply to the pilot. Options: `Yes` or `No`.
* **Consent** (`consent`): This field is currently not applicable. 
* **Finance System Pilot Registration Form Participants Details** (`finance_system_pilot_registration_form_participants_details`): Enter a brief description of the participants involved in the pilot.
* **Participants** (`participants`): Select all applicable participant(s). Options: `Yes` or `No`.
* **Finance System Pilot Registration Form Participants Objectives** (`finance_system_pilot_registration_form_participants_objectives`): Select all applicable participant objectives. Options: `Yes` or `No`.
* **Finance System Pilot Registration Form Participants Consent** (`finance_system_pilot_registration_form_participants_consent`): Select all applicable participant consents. Options: `Yes` or `No`.
* **Finance System Pilot Registration Form Participants Notes** (`finance_system_pilot_registration_form_participants_notes`): Enter any additional notes about the participants.
* **System Version** (`system_version`): Enter the version of the finance system being used.
* **Pilot Start Date** (`pilot_start_date`): Enter the start date of the pilot.
* **Pilot Start Time** (`pilot_start_time`): Enter the start time of the pilot.
* **Pilot End Date** (`pilot_end_date`): Enter the end date of the pilot.
* **Pilot End Time** (`pilot_end_time`): Enter the end time of the pilot.
* **Notes** (`notes`): Enter any additional notes about the pilot.
