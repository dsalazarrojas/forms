# Identity Privilege Monitoring Log Form - Help Guide
## Purpose

The Identity Privilege Monitoring Log Form is used to record when and how users perform privileged actions, including logging the user's identity and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the **User Name** of the person performing the privileged action.
2. Select the **Date** and **Time** of the action.
3. Choose whether the action was performed with **Privileged Action** ('Yes' or 'No').
4. Enter the **User ID** of the person performing the action.
5. Enter the **IP Address** if applicable.
6. Enter the **Device ID** if applicable.
7. Add any additional **Notes** about the action.

## Field-by-Field Explanation

* **User Name**: Enter the name of the user performing the action. This is a required field.
* **Date**: Enter the date the action was performed. This field is not required.
* **Time**: Enter the time the action was performed. This field is not required.
* **Privileged Action**: Check 'Yes' if the action was performed with elevated privileges. This field is not required.
* **User ID**: Enter the unique ID of the user performing the action. This is a required field.
* **IP Address**: Enter the IP address of the device performing the action. This field is not required.
* **Device ID**: Enter the ID of the device performing the action. This field is not required.
* **Notes**: Add any additional notes about the action. This field is not required.

## Tips

* Make sure to complete all required fields, especially **User Name** and **User ID**.
* Be thorough when entering **Notes** to provide as much detail as possible.
* Use the **Privileged Action** field to indicate whether the action was performed with elevated privileges.
