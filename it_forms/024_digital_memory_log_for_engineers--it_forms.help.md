# Digital Memory Log For Engineers - Help Guide
## Purpose
The "Digital Memory Log For Engineers" form is designed to collect and organize digital memory-related projects or assets. This form is used to categorize and store information about these projects/assets for easy reference and retrieval.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose a project or asset title that accurately describes the memory-related work.
2. Select a category for the project or asset from the options provided.
3. Provide a description of the project or asset if necessary.
4. Select output files or other relevant files related to the project or asset.
5. Choose an assigned tool from the options provided.
6. Enter a form ID and tool name if applicable.
7. Select categories 2 and 3, which provide additional classification and grouping.
8. Finally, provide the project name and select the assigned tool 2 and category 3.

## Field-by-Field Explanation
### Project/Asset Title (project_title)
* Project/Asset Title (`project_title`, text, required): Enter a brief title that accurately describes the project or asset.

### Category (category)
* Category (`category`, select_one, required): Choose a category for the project or asset from the options provided. This helps in grouping and sorting projects/assets in the digital memory log.

### Description (description)
* Description (`description`, text, optional): Provide a detailed description of the project or asset if needed.

### Output Files (output_files)
* Output Files (`output_files`, text, optional): Attach relevant files related to the project or asset.

### Assigned Tool (assigned_tool)
* Assigned Tool (`assigned_tool`, select_one, optional): Select a tool assigned to the project or asset from the options provided.

### Form ID (form_id)
* Form ID (`form_id`, text, required): Enter a unique ID for the project or asset.

### Tool Name (tool_name)
* Tool Name (`tool_name`, text, optional): Enter the name of the tool used for the project or asset.

### Category 2 (category_2)
* Category 2 (`category_2`, select_multiple, optional): Select additional categories for the project or asset from the options provided.

### Description 2 (description_2)
* Description 2 (`description_2`, text, optional): Provide an extended description of the project or asset if needed.

### Project Name (project_name)
* Project Name (`project_name`, text, optional): Enter the name of the project or asset.

### Assigned Tool 2 (assigned_tool_2)
* Assigned Tool 2 (`assigned_tool_2`, select_one, optional): Choose an additional tool assigned to the project or asset from the options provided.

### Category 3 (category_3)
* Category 3 (`category_3`, select_one, optional): Select the third category for the project or asset from the options provided.

## Tips

* Make sure to accurately categorize projects/assets for easy retrieval and sorting.
* Use relevant files for the project or asset to enhance understanding.
* Assign tools and names correctly to maintain consistency and organization.
