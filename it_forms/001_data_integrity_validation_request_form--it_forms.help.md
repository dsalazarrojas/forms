# Data_Integrity_Validation_Request_Form - Help Guide
## Purpose
The Data Integrity Validation Request Form is used to collect information for internal validation requests. It helps ensure that the provided data is accurate and consistent by collecting necessary details such as names, email, request date, and description.

## How To Complete This Form
1. Click on the "Submit" button to start the form.
2. Provide your first and last name in the corresponding fields. The "First Name" field is required, while the "Last Name" field is optional.
3. Enter a valid email address in the "Email" field. This field is required to ensure correct contact information.
4. (Optional) Provide a phone number if you have one. This will help in case further communication is needed.
5. Select the request date from the calendar picker or enter it manually. This field is required to track the validation request date.
6. Write a clear and detailed description of the request in the "Description" field. This field is required to understand the purpose of the request.
7. If applicable, provide the tool or resource associated with the validation request in the "Assigned Tool" field.

## Field-by-Field Explanation
* **First Name** (first_name, text, required)
	+ Enter your first name in this field. This will be used to identify you in the validation process.
* **Last Name** (last_name, text, optional)
	+ Enter your last name if you wish to include it in the validation process.
* **Email** (email, email, required)
	+ Enter a valid email address that can be used for contact purposes.
* **Phone** (phone, text, optional)
	+ If you have a phone number, please enter it. This will help in case further contact is needed.
* **Request Date** (request_date, date, required)
	+ Select the date when the integrity validation request was made using the calendar picker or enter it manually.
* **Description** (description, text, required)
	+ Provide a clear description of the request to help understand its purpose.
* **Assigned Tool** (assigned_tool, text, optional)
	+ If applicable, enter the tool or resource associated with the validation request.
