# it_support_check_in_form - Help Guide
## Purpose
The it_support_check_in_form is used to report problems or request help with tasks, allowing support teams to track and respond to support requests efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your user information in the "user_info" field, including any relevant details such as your name and role.
2. Provide a clear and concise "issue_title" that describes the problem you are experiencing.
3. Select the "category" of the issue, choosing from "Yes" or "No" to indicate whether the issue is related to a specific category.
4. Enter a detailed "description" of the issue in the text field.
5. If applicable, select "assigned_to" to indicate whether the issue is assigned to someone.
6. Choose "priority" to indicate the level of priority for the issue, selecting from "Yes" or "No" to indicate whether it is a high-priority issue.
7. Select the "status" of the issue, choosing from "Active" or "Inactive" to indicate the current status.
8. Enter the "due_date" and "start_time" and "end_time" fields to provide more information about the issue's timeline.
9. Add any relevant "tags" or "notes" to provide additional context.
10. Enter your "email" and "phone" contact information so that support teams can reach out to you.
11. If applicable, select "category_label" to indicate whether the issue is related to a specific category.
12. Choose "assigned_tool" to indicate whether the issue is assigned to a tool.
13. Enter the "form_id" and "user_id" fields to provide more information about the issue.
14. Finally, select the "created_at" field to indicate when the issue was created.

## Field-by-Field Explanation
* **User Info (`user_info`, text, required: false)**: Enter your user information, including your name and role.
* **Issue Title (`issue_title`, text, required: false)**: Provide a clear and concise title for the issue you are experiencing.
* **Category (`category`, select_multiple, required: false)**: Choose the category related to the issue.
* **Description (`description`, text, required: false)**: Enter a detailed description of the issue.
* **Assigned to (`assigned_to`, select_one, required: false)**: Indicate whether the issue is assigned to someone.
* **Priority (`priority`, select_one, required: false)**: Choose the priority level for the issue.
* **Status (`status`, select_one, required: false)**: Select the current status of the issue.
* **Due Date (`due_date`, date, required: false)**: Enter the due date for the issue.
* **Start Time (`start_time`, time, required: false)**: Enter the start time for the issue.
* **End Time (`end_time`, time, required: false)**: Enter the end time for the issue.
* **Tags (`tags`, text, required: false)**: Add any relevant tags or notes for the issue.
* **Notes (`notes`, note, required: false)**: Enter any additional notes about the issue.
* **Email (`email`, email, required: false)**: Enter your email contact information.
* **Phone (`phone`, text, required: false)**: Enter your phone contact information.
* **Category Label (`category_label`, select_one, required: false)**: Indicate whether the issue is related to a specific category.
* **Assigned Tool (`assigned_tool`, select_one, required: false)**: Choose whether the issue is assigned to a tool.
* **Form ID (`form_id`, text, required: false)**: Enter the form ID for the issue.
* **User ID (`user_id`, text, required: false)**: Enter the user ID for the issue.
* **Created At (`created_at`, time, required: false)**: Select the creation time for the issue.

## Tips
* Please provide as much detail as possible when filling out this form.
* Make sure to select the correct category and priority for the issue.
* Use the "tags" field to provide additional context.
* Enter your contact information so that support teams can reach out to you.
* Double-check your answers before submitting the form.
