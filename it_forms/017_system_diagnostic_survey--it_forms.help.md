# System Diagnostic Survey - Help Guide
## Purpose
The System Diagnostic Survey is a form designed to collect information about the system's status. It helps us identify potential issues and areas for improvement.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Review each page and select the correct options for each field.
2. Answer each question based on your experience with the system.
3. Make sure you have permission from the system owners before filling out this form.
