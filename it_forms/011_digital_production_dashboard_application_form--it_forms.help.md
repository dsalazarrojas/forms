# Digital Production Dashboard Application Form - Help Guide
## Purpose
This form is used to provide information about projects in the Digital Production Dashboard Application. It helps project managers and stakeholders to get an accurate picture of project status and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project details such as project title, project lead, dashboard owner, technical requirements, supporting files, and other required fields.
2. Select the status of the project (Active or Inactive).
3. Indicate whether the project has priority (Yes or No).
4. Provide information on technical and non-technical issues, if any.
5. Optionally, add any comments.
6. Select the tool assigned to the project.
7. Add any additional notes about the project.

## Field-by-Field Explanation

* **Project Details (Project Details)** (`project_details`, `text`, required)
	+ This field is used to enter the title of the project.
* **Project Lead (Project Lead)** (`project_lead`, `text`, required)
	+ This field is used to enter the name of the project lead.
* **Dashboard Owner (Dashboard Owner)** (`dashboard_owner`, `text`, required)
	+ This field is used to enter the name of the dashboard owner.
* **Technical Requirements (Technical Requirements)** (`technical_requirements`, `text`, required)
	+ This field is used to enter technical requirements or specifications of the project.
* **Supporting Files (Supporting Files)** (`supporting_files`, `text`, required)
	+ This field is used to enter supporting files or documents relevant to the project.
* **Project Manager (Project Manager)** (`project_manager`, `text`, required)
	+ This field is used to enter the name of the project manager.
* **Business Manager (Business Manager)** (`business_manager`, `text`, required)
	+ This field is used to enter the name of the business manager.
* **Start Date (Start Date)** (`start_date`, `date`, required)
	+ This field is used to enter the start date of the project.
* **End Date (End Date)** (`end_date`, `date`, required)
	+ This field is used to enter the end date of the project.
* **Status (Status)** (`status`, `select_one`, required)
	+ This field is used to select the status of the project (Active or Inactive).
* **Priority (Priority)** (`priority`, `select_one`, required)
	+ This field is used to indicate whether the project has priority (Yes or No).
* **Technical Issues (Technical Issues)** (`technical_issues`, `text`, required)
	+ This field is used to enter any technical issues related to the project.
* **Non-Technical Issues (Non-Technical Issues)** (`non_technical_issues`, `text`, required)
	+ This field is used to enter any non-technical issues related to the project.
* **Comments (Comments)** (`comments`, `text`, optional)
	+ This field is used to add any comments about the project.
* **Assigned Tool (Assigned Tool)** (`assigned_tool`, `text`, required)
	+ This field is used to select the tool assigned to the project.
* **Notes (Notes)** (`notes`, `text`, optional)
	+ This field is used to add any additional notes about the project.

Note: Ensure that all required fields are completed before submitting the form.
