# Editing Tools Assessment - Help Guide
## Purpose
The purpose of this form is to assess the editing tools used in your daily work, their satisfaction with these tools, and any feature needs or training needs related to these tools. This form helps identify potential areas where tools can be improved to better support your work.

## How To Complete This Form
1. Select the options for each field that best fit your answers.
2. Fill in any text fields with your thoughts or comments.
3. Make sure to review your answers before submitting the form.

## Field-by-Field Explanation
* **Editing software usage**: Select how frequently you use editing software. This field is used to gauge your tool usage habits.
	+ Select "Yes" if you frequently use editing software.
	+ Select "No" if you do not use editing software.
* **Editing software satisfaction**: Indicate your level of satisfaction with the editing software.
	+ Select "Satisfied" if you are satisfied with the editing software.
	+ Select "Dissatisfied" if you are not satisfied with the editing software.
* **Feature needs**: Specify which features you feel are lacking from the tools in your department.
	+ Select "Yes" for each feature you feel is missing.
* **Training needs**: Provide any training needs you have related to the editing tools.
* **Tool decisions**: Enter any specific reasons why you decided on the tools you are using.
* **Assigned tool**: Indicate if a tool has been assigned to you by a manager or team lead.
* **Department**: Select if the tool is used across departments.
* **User role**: Indicate if the tool is used by all or some users in your role.
* **User ID**: Enter your user ID, if applicable.
* **Assigned user**: Indicate if the tool is assigned to a specific user.
* **Comments**: Provide any additional comments or feedback about the tools.
* **Email**: Enter your email address, if you want to be contacted about the results of this assessment.
