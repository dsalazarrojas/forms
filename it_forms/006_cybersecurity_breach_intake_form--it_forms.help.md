# Cybersecurity Breach Intake Form - Help Guide
## Purpose
The Cybersecurity Breach Intake Form is used to gather information about security incidents that may have occurred within the organization. The form is designed to collect relevant details about the incident, such as the date, time, and description, as well as the severity and impact of the incident. This information will be used to assess and respond to the incident appropriately.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Incident Summary field with a brief description of what happened.
2. Enter the Incident Date and Incident Time using the date and time pickers.
3. Provide a detailed Incident Description of what occurred.
4. Select the Incident Impact and Incident Severity from the dropdown menus.
5. Choose the Incident Type from the list of options.
6. Enter the Incident Reporter's information in the Contact Information field.
7. Enter the Organization Name, if applicable.

## Field-by-Field Explanation
### Incident Summary (<type> text, required: false)
A brief description of what happened. Please provide a concise summary of the incident.

*   **Incident Summary**: This field is a text input where you can type in a brief description of the incident. You can enter any relevant details about what happened, such as what systems or data were affected.

### Incident Date (<type> date, required: false)
The date the incident occurred.

*   **Incident Date**: This field is a date picker where you can select the date the incident occurred. Please use the calendar to select the correct date.

### Incident Time (<type> time, required: false)
The time the incident occurred.

*   **Incident Time**: This field is a time picker where you can select the time the incident occurred. Please use the clock to select the correct time.

### Incident Description (<type> note, required: false)
A detailed description of what happened.

*   **Incident Description**: This field is a free text input where you can provide a detailed description of the incident. Please include any relevant details, such as what systems or data were affected.

### Incident Impact (<type> select_one, options: [Low, Medium, High], required: false)
The impact of the incident on the organization.

*   **Incident Impact**: This field is a dropdown menu where you can select the impact of the incident. Please choose one of the following options:
    *   Low: The incident had a minimal impact on the organization.
    *   Medium: The incident had a moderate impact on the organization.
    *   High: The incident had a significant impact on the organization.

### Incident Severity (<type> select_multiple, options: [Low, Medium, High], required: false)
The severity of the incident.

*   **Incident Severity**: This field is a dropdown menu where you can select the severity of the incident. Please choose one or more of the following options:
    *   Low: The incident is considered low-severity.
    *   Medium: The incident is considered medium-severity.
    *   High: The incident is considered high-severity.

### Incident Type (<type> select_one, options: [Phishing, Malware, Ransomware], required: false)
The type of incident that occurred.

*   **Incident Type**: This field is a dropdown menu where you can select the type of incident. Please choose one of the following options:
    *   Phishing: A type of social engineering attack.
    *   Malware: Malicious software that is designed to harm the organization.
    *   Ransomware: Malicious software that demands payment from the victim.

### Incident Reporter (<type> text, required: false)
The person who reported the incident.

*   **Incident Reporter**: This field is a text input where you can enter the name of the person who reported the incident.

### Contact Information (<type> text, required: false)
Additional information about the person who reported the incident.

*   **Contact Information**: This field is a text input where you can enter any additional information about the person who reported the incident.

### Organization Name (<type> text, required: false)
The name of the organization affected by the incident.

*   **Organization Name**: This field is a text input where you can enter the name of the organization affected by the incident.

## Tips
*   Make sure to provide as much detail as possible when filling out this form.
*   If you are unsure about any of the fields, please ask your supervisor or IT department for assistance.
*   Please fill out this form as soon as possible after the incident has occurred.
