# Scam Link Report Form - Help Guide
## Purpose
The Scam Link Report Form is a tool used to report suspected scam links to relevant authorities or organizations. It helps in gathering information about the link, its context, and other relevant details to aid in its investigation and potential removal.

## How To Complete This Form
To fill in this form, follow these steps:

1. Fill in the required fields with accurate and detailed information about the reported link.
2. Provide a brief description of the link in the "Description" field.
3. Select the type of report you wish to submit (e.g., Scam, Suspicious, Other).
4. Choose the report status (e.g., Pending, Reviewing, Resolved, Closed).
5. Enter your name and email (if you wish to be contacted).
6. Choose whether the link has been reported by someone else or not.
7. Fill in the reported time and date of the link.
8. Optionally, add any supporting evidence or files related to the report.
9. Click on the "Submit" button to send the report.

## Field-by-Field Explanation

* **Link URL** (`link_url`, text, required): Enter the URL of the reported link.
* **Description** (`link_description`, text, required): Provide a brief description of the link.
* **Supporting Evidence** (`supporting_evidence`, text, optional): Upload any supporting evidence or files related to the report.
* **Incident Context** (`incident_context`, text, optional): Provide more context about the incident.
* **Report Type** (`report_type`, select_one, required): Choose the type of report (e.g., Scam, Suspicious, Other).
* **Report Status** (`report_status`, select_one, required): Choose the report status (e.g., Pending, Reviewing, Resolved, Closed).
* **Reporter Name** (`reporter_name`, text, optional): Enter your name (if you wish to be contacted).
* **Reporter Email** (`reporter_email`, email, optional): Enter your email (if you wish to be contacted).
* **Reported By** (`reported_by`, select_one, required): Choose whether the link has been reported by someone else or not.
* **Reported Time** (`reported_time`, time, required): Enter the time the link was reported.
* **Reported Date** (`reported_date`, date, required): Enter the date the link was reported.
* **Submit Date** (`submit_date`, date, required): Enter the date the report was submitted.
* **Submit Time** (`submit_time`, time, required): Enter the time the report was submitted.
* **Submit Status** (`submit_status`, select_one, required): Choose the submit status (e.g., Approved, Rejected).
* **Comments** (`comments`, text, optional): Add any additional comments about the report.
* **Additional Info** (`additional_info`, text, optional): Add any additional information about the report.
* **Submitter** (`submitter`, text, optional): Enter your name or identity.
* **Reporting Team** (`reporting_team`, text, optional): Enter the name of the reporting team.
* **Incident ID** (`incident_id`, text, optional): Enter the incident ID (if known).
* **Report ID** (`report_id`, text, optional): Enter the report ID (if known).
* **Report Date** (`report_date`, date, optional): Enter the date the report was received.
* **Submitted By** (`submitted_by`, text, optional): Enter the name or identity of the person who submitted the report.
