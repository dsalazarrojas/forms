# Student Software Subscription Verification Form - Help Guide
## Purpose
This form is used to verify student software subscriptions. It is designed to be completed by students or administrators to confirm the student's software subscriptions.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select "Submit Request" to indicate if you are submitting a request for software subscription verification.
2. Choose "Yes" or "No" for "Student Information" to confirm if the student's information is correct.
3. Choose "Yes" or "No" for "Software Information" to confirm if the software information is accurate.
4. Select "Submit Form" to confirm that you have reviewed the form.

## Field-by-Field Explanation
- **Submit Request**: Select this option to indicate that you are submitting a request for software subscription verification. This will help the administrators to identify your request.
  - **Student Information**: This field is used to confirm if the student's information is correct. If you choose "Yes", it means that the student's information is accurate. If you choose "No", it means that the student's information is incorrect or needs to be updated.
  - **Software Information**: This field is used to confirm if the software information is accurate. If you choose "Yes", it means that the software information is correct. If you choose "No", it means that the software information is incorrect or needs to be updated.
  - **Submit Form**: This field is used to confirm that you have reviewed the form. This is a required field to submit the form. 

## Tips
- Please complete the form carefully, as the information you provide will be used for software subscription verification.
- If you are unsure about any of the fields, please contact the administrator for clarification.
- The form can be submitted multiple times, but please be aware that each submission will need to be verified individually.
