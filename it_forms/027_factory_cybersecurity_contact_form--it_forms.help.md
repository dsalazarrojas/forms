# Factory Cybersecurity Contact Form - Help Guide
## Purpose
The Factory Cybersecurity Contact Form is designed to gather information about security incidents reported by employees. This form helps to collect data about security incidents in a structured manner, allowing for efficient and effective handling of such incidents.

## How To Complete This Form
To fill out this form, follow these steps:

1. **Report Security Issue**: In this text field, please describe the security issue you are reporting. Be as detailed as possible, including any relevant details such as dates, times, and locations.
2. **Incident Details (Date)**: If available, please provide the date and time of the incident.
3. **Share File**: If relevant to the incident, please share any supporting files (e.g., images, documents).
4. **Select One Issue Type**: Choose the type of issue that best describes the incident from the options provided: Security Incident, Compliance Issue, Data Protection, or Other.
5. **Select Multiple Issue Categories** (optional): If applicable, choose any relevant categories from the options provided: Security, Compliance, Data Protection, or Other.
6. **Share Phone Number** (optional): If you'd like to be contacted for further information, please provide your phone number.
7. **Share Email** (optional): If you'd like to be contacted via email, please provide your email address.

## Tips
* Please fill out as many fields as possible to ensure that your report is thorough and effective.

* If you're reporting a sensitive or critical incident, please contact your supervisor or security team immediately after submitting this form.
