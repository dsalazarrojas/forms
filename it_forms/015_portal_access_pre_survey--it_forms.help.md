# portal_access_pre_survey - Help Guide

The purpose of this form is to determine why a user needs access to the portal, how they plan to use it, and to obtain confirmation that they have read and agreed to the relevant policies and have or do not have existing user credentials. This form helps to ensure that users have a clear understanding of their intended use and that they have the necessary permissions to access the portal.

### How To Complete This Form

To complete this form, follow these steps:

1.  **why_do_you_need_access**: This section asks you to describe why you need access to the portal. Please enter a brief description of your intended purpose.
2.  **what_will_you_use_access_for**: In this section, describe how you plan to use the portal. Provide as much detail as possible about your intended use.
3.  **have_you_read_and_agreed_to_policy**: In this section, confirm that you have read and agreed to the relevant policies. Select "True" if you have read and agreed to the policies, or "False" if you have not.
4.  **do_you_already_have_user_credentials**: In this section, confirm whether you already have existing user credentials. Select "True" if you have existing credentials, or "False" if you do not.
5.  **describe_your_intended_use**: In this section, provide a detailed description of your intended use of the portal.

## Field-by-Field Explanation

* **why_do_you_need_access** (why_do_you_need_access, text, optional): A text field where you can describe why you need access to the portal.
* **what_will_you_use_access_for** (what_will_you_use_access_for, text, optional): A text field where you can describe how you plan to use the portal.
* **have_you_read_and_agreed_to_policy** (policy_acknowledgement, select_one, required): A select field where you confirm that you have read and agreed to the policies. Select "True" to confirm.
*   **do_you_already_have_user_credentials** (user_credentials, select_one, required): A select field where you confirm whether you have existing user credentials. Select "True" to confirm.
* **describe_your_intended_use** (intended_use, text, optional): A text field where you can provide a detailed description of your intended use of the portal.

## Tips

*   Be sure to provide clear and detailed answers to each question, as this will help us understand your needs and ensure that you have access to the portal.
