# Security System Recalibration Request Form - Help Guide
## Purpose
This form is used to request a recalculation of a user's security system access levels.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the contact details section with your name, email address, and phone number.
2. Select your preferred schedule for the recalculation, including the date and time.
3. Choose whether you have access to certain systems and select the relevant options.
4. Select who should be assigned to handle your recalculation request.
5. If you have any additional comments, please provide them here.
6. Finally, confirm your security clearance level and access levels.

## Field-by-Field Explanation

* **Contact Details (Required)**: Please fill out your name, email address, and phone number to ensure we can contact you with any questions or concerns.
* **Location**: If you have a preferred location for the recalculation, please select it here. This is not required, but it can help us better understand your needs.
* **Access Info (Optional)**: Select whether you have access to certain systems. This will help us determine your current access levels.
* **Select Access Info (Optional)**: Select multiple options for which systems you have access to. This is similar to the previous field, but allows for multiple selections.
* **Preferred Schedule (Required)**: Select a date and time that works best for you to have your security system accessed recalculated.
* **Schedule Time (Optional)**: If you have a preferred time for the recalculation, please select it here. This is not required, but it can help us better fit you into the schedule.
* **Additional Comments**: If you have any additional comments or questions, please provide them here. This is not required, but it can help us better understand your needs.
* **Email (Required)**: Please ensure that your email address is accurate so we can contact you with any questions or concerns.
* **Phone (Optional)**: If you have a preferred phone number for us to contact you, please provide it here.
* **Assigned To (Required)**: Select who you would like to be assigned to handle your recalculation request.
* **Comments (Optional)**: If you have any additional comments or questions, please provide them here.
* **Security Clearance Level (Required)**: Select your current security clearance level.
* **Access Level (Optional)**: Select your access level for certain systems.
* **Select Access Level (Optional)**: Select multiple access levels for certain systems.
* **Select Access Level 2 (Optional)**: Select multiple access levels for certain systems.
* **Security Clearance Level 2 (Required)**: Select your current security clearance level.
* **Access Level 2 (Optional)**: Select your access level for certain systems.
* **Security Clearance Level 3 (Required)**: Select your current security clearance level.
* **Access Level 3 (Optional)**: Select your access level for certain systems.
* **Security Clearance Level 4 (Required)**: Select your current security clearance level.
* **Access Level 3 (Optional)**: Select your access level for certain systems.
* **Security Clearance Level 5 (Required)**: Select your current security clearance level.
* **Access Level 4 (Optional)**: Select your access level for certain systems.
* **Comments**: If you have any additional comments or questions, please provide them here.

Note: Some fields may seem redundant, but please fill out both fields if you have multiple access levels or clearance levels.
