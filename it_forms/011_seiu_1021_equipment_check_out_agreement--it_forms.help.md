# seiu 1021 equipment check out agreement - Help Guide
## Purpose
The seiu 1021 equipment check out agreement form is a template used to track and monitor the usage and status of equipment within an organization. It captures user information, equipment details, and status updates to ensure that equipment is used and returned in an organized and accountable manner.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your user information, including your name and email address.
2. Select the equipment for which you are checking out.
3. Enter the dates you plan to use the equipment, including both the check-out and check-in dates.
4. Provide any comments or remarks about the equipment.
5. Select the condition of the equipment before it is checked out.
6. Choose the assigned tool or user, if applicable.
7. Update the status of the equipment once it has been checked back in.

## Field-by-Field Explanation

* **User Name**: The user's name who is checking out the equipment.
	+ Required: No (but recommended)
	+ Type: Text input field
* **User Email**: The user's email address.
	+ Required: No (but recommended)
	+ Type: Email input field
* **Equipment Name**: The name of the equipment being checked out.
	+ Required: No (but recommended)
	+ Type: Text input field
* **Check Out Date**: The date when the equipment is checked out.
	+ Required: No
	+ Type: Date input field
* **Check In Date**: The date when the equipment is checked in.
	+ Required: No
	+ Type: Date input field
* **Comments**: Any additional comments or remarks about the equipment.
	+ Required: No (but recommended)
	+ Type: Text area for free-form input
* **Assigned Tool**: The tool or equipment that is assigned to the user.
	+ Required: No
	+ Type: Select one from a list of options
* **Assigned User**: The user who is assigned to use the equipment.
	+ Required: No
	+ Type: Select one from a list of options
* **Equipment Condition**: The condition of the equipment before it is checked out.
	+ Required: No
	+ Type: Select multiple from a list of options
* **Checked By**: The person who checks the equipment back in.
	+ Required: No
	+ Type: Select one from a list of options
* **Checked Date**: The date when the equipment is checked back in.
	+ Required: No
	+ Type: Date input field
* **Remarks**: Any additional comments or remarks about the equipment.
	+ Required: No (but recommended)
	+ Type: Text area for free-form input
* **Status**: The status of the equipment.
	+ Required: No
	+ Type: Select one from a list of options
