# Cross Origin Access Issue Report Form - Help Guide
## Purpose
This form is intended for users to report Cross-Origin Access Issues that occur when accessing a website.

## How To Complete This Form
To complete this form, follow these steps:
1. Choose the browser type you are using to access the site in question.
2. Provide a detailed description of the issue you are experiencing.
3. Outline the steps to reproduce the issue.
4. Provide additional details about the issue.
5. Specify your browser version.
6. Indicate the impact of the issue (high, medium, or low).
7. Enter the date and time the issue occurred.
8. Confirm whether the issue is reproducible.
9. Mention the frequency of the issue (if applicable).

## Field-by-Field Explanation
* **Browser Type (1)** (`browser_type`, `select_one`, required): Choose the browser you are using (e.g., chrome, firefox, safari, edge, internet explorer).
* **Issue Description (2)** (`issue_description`, `text`, required): Provide a detailed description of the issue you are experiencing.
* **Issue Steps (3)** (`issue_steps`, `text`, required): Outline the steps to reproduce the issue.
* **Issue Details (4)** (`issue_details`, `text`, required): Provide additional details about the issue.
* **Browser Version (5)** (`browser_version`, `text`, required): Specify your browser version.
* **Issue Impact (6)** (`issue_impact`, `select_multiple`, required): Indicate the impact of the issue (high, medium, low).
* **Issue Date (7)** (`issue_date`, `date`, required): Enter the date the issue occurred.
* **Issue Time (8)** (`issue_time`, `time`, required): Enter the time the issue occurred.
* **Reproducible Issue (9)** (`issue_reproducible`, `text`, required): Confirm whether the issue is reproducible.
* **Issue Frequency (10)** (`issue_frequency`, `text`, required): Mention the frequency of the issue (if applicable).

## Tips
* Please ensure you have not already reported this issue, and that it is not a duplicate of an issue you have already reported.
* If you are unsure or need clarification, please refer to your organization's policies and procedures for handling Cross-Origin Access Issues.
* Provide as much detail as possible to help our team better understand and resolve the issue.
