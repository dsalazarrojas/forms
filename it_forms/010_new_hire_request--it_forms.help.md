The New Hire Request form is used to collect information from employees for new hires within the company. This form is typically completed by HR or management staff when a new employee is joining the team, and it ensures that the relevant department manager is notified and any necessary equipment is allocated for the new hire. The form is also used to track and manage employee requests for equipment and software, ensuring that the necessary resources are available for them to start work effectively.

# New Hire Request - Help Guide
## Purpose

## How To Complete This Form

To complete this form, follow these steps:

1. **New Hire Request**: Enter a brief description of the new hire request.
2. **Employee Name**: Enter the name of the new employee.
3. **Start Date**: Enter the date the new employee is expected to start work.
4. **Department**: Select the department the new employee will be working in.
5. **Employment Period**: Enter the length of time the new employee will be working for (e.g., full-time, part-time, etc.).
6. **Additional Requests**: Select any additional equipment or software the new employee will need for their role.
7. **Computer Requests**: Select the type of computer the new employee will need (if any).
8. **Software Requests**: Select any software the new employee will need for their role.
9. **Department Manager Requests**: If the department manager will be responsible for allocating resources, select "Yes" to notify them.

## Field-by-Field Explanation

* **New Hire Request**: Enter a brief description of the new hire request.
* **Employee Name**: Enter the full name of the new employee (including first and last names).
* **Start Date**: Enter the date the new employee is expected to start work in the format `YYYY-MM-DD` (e.g., 2023-02-15).
* **Department**: Select the department the new employee will be working in from the list of available options.
* **Employment Period**: Enter the length of time the new employee will be working for (e.g., full-time, part-time).
* **Additional Requests**: Select any additional equipment or software the new employee will need for their role, such as:
	+ Computer: Check if the new employee will need a computer for their role.
	+ Software: Check if the new employee will need any specific software for their role.
	+ Peripherals: Check if the new employee will need any additional peripherals (e.g., a headset, scanner, etc.).
* **Computer Requests**: Select the type of computer the new employee will need (if any):
	+ Laptop: Select if the new employee will need a laptop.
	+ Desktop: Select if the new employee will need a desktop computer.
	+ Mobile: Select if the new employee will need a mobile device.
* **Software Requests**: Select any software the new employee will need for their role, such as:
	+ Microsoft Office: Check if the new employee will need Microsoft Office for their role.
	+ Adobe Creative Cloud: Check if the new employee will need Adobe Creative Cloud for their role.
	+ Browser Extensions: Check if the new employee will need any browser extensions.
* **Department Manager Requests**: If the department manager will be responsible for allocating resources, select "Yes" to notify them.

## Tips

* Make sure to complete all required fields (marked as *) to ensure that the form is submitted correctly.
* Review the form carefully to ensure that all necessary information is provided.
* If you are unsure about any field, refer to your supervisor or HR representative for guidance.
