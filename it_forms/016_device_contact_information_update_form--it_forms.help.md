# Device Contact Information Update Form - Help Guide
## Purpose
The Device Contact Information Update Form is used to gather and update information about devices in your inventory. This form is essential for maintaining accurate and up-to-date records of your devices.

## How To Complete This Form
1. Select the correct contact information for your device.
2. Choose the contact person responsible for the device.
3. Enter the contact email and phone number (if applicable).
4. Select the contact address (street, city, state, and zip).
5. Select the type of device you have (laptop, desktop, phone, or printer).
6. Enter the serial number of the device.
7. Enter the MAC address of the device.
8. Select the status of the device (available, unavailable, or maintenance).
9. Indicate whether the device is assigned to a tool (yes or no).
10. Select the type of tool assigned to the device (laptop, desktop, phone, or tablet).
11. Add any additional notes for the device.

## Field-by-Field Explanation

* **Contact Information**: This field allows you to select whether you have contact information for the device. Select "Yes" if you have contact information.
* **Contact Person**: This field is used to select the person to contact regarding the device. This is a required field.
* **Contact E-mail**: This field is used to enter the contact email address for the device. This field is optional and only required if you selected "Yes" in the contact information field.
* **Contact Phone**: This field is used to enter the contact phone number for the device. This field is optional and only required if you selected "Yes" in the contact information field.
* **Contact Address**: This field allows you to select the contact address for the device. This includes selecting the street, city, state, and zip code. This field is optional.
* **Device Type**: This field is used to select the type of device you have (laptop, desktop, phone, or printer). This is a required field.
* **Serial Number**: This field is used to enter the serial number of the device. This is a required field.
* **MAC Address**: This field is used to enter the MAC address of the device. This is a required field, and you must select one of the options provided.
* **Device Status**: This field is used to select the status of the device (available, unavailable, or maintenance). This is a required field.
* **Assigned Tool**: This field is used to indicate whether the device is assigned to a tool (yes or no). This is a required field.
* **Tool Type**: This field is used to select the type of tool assigned to the device (laptop, desktop, phone, or tablet). This is a required field.
* **Notes**: This field is used to enter any additional notes about the device. This field is optional.
* **Notes 2**: This field is used to enter any additional notes about the device. This field is optional.
