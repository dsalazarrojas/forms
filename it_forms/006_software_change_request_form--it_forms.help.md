# Software Change Request Form - Help Guide
## Purpose
The Software Change Request Form is a tool used to submit and document formal requests for changes to software applications or features. This form helps track and manage software changes efficiently.

## How To Complete This Form

1.  **Software Change Request Form**:
    This is the main section of the form where you can enter your software change request.
2.  **Description**:
    Enter a brief description of the software change you are requesting.
3.  **Software Version**:
    Please specify the current version of the software that requires the change.
4.  **Request Type**:
    Indicate whether this is a 'Yes' or 'No' request type.
5.  **Change Description**:
    Provide a detailed description of the change you are requesting.
6.  **Impact Level**:
    Select 'High', 'Low', or 'High' as the impact level of the change.
7.  **Impact Frequency**:
    Choose 'Yes' or 'No' to indicate if the impact of the change is frequent.
8.  **Priority**:
    Select 'Yes' or 'No' to indicate the priority level of the change.
9.  **Assigned To**:
    Select the person or team responsible for the change.
10. **Due Date**:
    Enter the due date for the change.
11.  **Status**:
    Select 'Active' or 'Inactive' to indicate the status of the change request.
12.  **Created At**:
    This field will display the date and time the form was created.
13.  **Updated At**:
    This field will display the last updated time for the form.
14.  **Created By**:
    Select the person who created the form.
15.  **Updated By**:
    Select the person who last updated the form.
16.  **Tags**:
    Enter any additional information or keywords related to the change request.
17.  **Custom Field 1**:
    Enter any additional information related to the first custom field.
18.  **Custom Field 2**:
    Enter any additional information related to the second custom field.
19.  **Custom Field 3**:
