# Network Connection Request Form - Help Guide
## Purpose
This form is used to request network access for yourself or others in your organization. Fill out this form to provide necessary information about your request.
## How To Complete This Form
To complete this form, simply fill out each field with the requested information.
## Field-by-Field Explanation
* **User Info** (`user_info`, text, optional): Enter your name and any relevant contact information.
* **Network Access** (`network_access`, text, optional): Briefly describe the network access you are requesting.
* **Network Devices** (`network_devices`, select_one, optional): Select which type of network device you need access to (e.g., Router, Switch, Server).
* **IP Address** (`ip_address`, text, optional): Enter the IP address you are requesting access to.
* **MAC Address** (`mac_address`, text, optional): Enter the MAC address you are requesting access to.
* **Network Type** (`network_type`, text, optional): Describe the type of network you are requesting access to (e.g., LAN, WAN, wireless).
* **Purpose of Request** (`purpose_of_request`, text, optional): Describe the reason for your network access request.
* **Comments** (`comments`, text, optional): Add any additional comments or details about your request.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the specific tool you are requesting access to. 

Note: All fields are optional, but filling out all relevant fields will help the request process and ensure your request is processed efficiently.
