## CrowdStrike Fix Request Form - Help Guide

## Purpose
The purpose of this form is for customers to report issues and provide information for the CrowdStrike team to resolve.

## How To Complete This Form
To complete this form, follow the steps above.

## Field-by-Field Explanation
* **Customer Information** (`customer_info`, `text`, required): Enter the customer's name, email, and other relevant information.
* **Issue Description** (`issue_details`, `text`, required): Describe the problem that needs to be addressed.
* **Fix Information** (`fix_info`, `text`, optional): Provide additional context or information about the fix.
* **Issue Attachment** (`issue_attachment`, `text`, optional): Attach a file related to the issue, if necessary.
* **Comments** (`comments`, `note`, optional): Add any additional comments about the issue.
* **Fix Status** (`fix_status`, `select_one`, optional): If known, select the status of the fix (Pending, In Progress, or Fixed).
* **Additional Comments** (`comments_2`, `note`, optional): Add any further comments or details about the issue.
* **Attachment** (`attachment`, `text`, optional): Attach another file related to the issue, if necessary.
