# Screen Share Session Registration - Help Guide
## Purpose
The Screen Share Session Registration form is used to register screen share sessions for meetings. Users are required to provide information about the session, including the topic, schedule, and other relevant details. This form helps to ensure that the session is properly registered and communicated to the relevant parties.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the purpose of the form and ensure that you have all the necessary information.
2. Enter your name in the `Name` field.
3. Describe the `Session Topic` in a brief statement.
4. Select the `Schedule Session` using one of the provided time slots.
5. Set a specific time for the `Session Time` (in 24-hour format, e.g., 14:00).
6. Capture a brief description for `Capture Screen` and `Capture Session`.
7. Enter the `Meeting ID` and `Meeting Type` if applicable.
8. Provide any additional `Meeting Details`.

## Field-by-Field Explanation
* **Name (Name)**: Enter your name as it should be displayed for the session.
* **Session Topic (Session Topic)**: Briefly describe the topic of the screen share session.
* **Schedule Session (Schedule Session)**: Select the time slot for the session from the provided options.
* **Session Time (Session Time)**: Enter the specific time for the session (24-hour format, e.g., 14:00).
* **Capture Screen (Capture Screen)**: Provide a brief description for capturing the screen during the session.
* **Capture Session (Capture Session)**: Provide a brief description for capturing the session (e.g., what to show, what not to show).
* **Meeting ID (Meeting ID)**: Enter the meeting ID if applicable (e.g., for integration with other systems).
* **Meeting Type (Meeting Type)**: Select the type of meeting (e.g., client, internal, etc.).
* **Meeting Details (Meeting Details)**: Provide any additional information about the meeting (e.g., participants, expected outcomes, etc.).

## Tips
* Ensure that all required fields are filled in accurately and completely.
* Double-check the form before submission to ensure all fields are correct.
* If unsure about any field, refer back to the form's purpose and instructions.
