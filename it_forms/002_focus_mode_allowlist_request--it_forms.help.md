# Focus Mode Allowlist Request - Help Guide

## Purpose
This form is designed to facilitate the request process for users seeking to be included in the focus mode allowlist.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your user information in the "user" field.
2. Provide the URL of the site where you will be working on focus mode.
3. Enter a brief reason for your inclusion in the focus mode allowlist.
4. Select 'Yes' or 'No' for the approval of a manager.
5. If approved, provide comments from the manager.
6. Optionally, you can add any additional comments.
7. Click the "submit" button to send your request.

## Field-by-Field Explanation

* **user** (`user`, text, required): Enter your user information.
* **site url** (`site_url_1`, text, required): Enter the URL of the site where you will be working on focus mode.
* **reason** (`reason_1`, text, required): Enter a brief reason for your inclusion in the focus mode allowlist.
* **approval** (`approval_1`, select_one, required): Select 'Yes' or 'No' to indicate manager approval.
* **frequency** (`frequency_1`, text, optional): Optionally, enter the frequency of your focus mode usage.
* **comment** (`comment_1`, text, optional): Add any additional comments.
* **manager approval** (`manager_approval_1`, select_one, optional): Select 'Yes' or 'No' to indicate manager approval.
* **manager comments** (`manager_comments_1`, text, optional): If approved, provide comments from the manager.
* **submit** (`submit_1`, text, optional): Click to send your request.
