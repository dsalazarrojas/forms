# Software User Issue Inquiry Form - Help Guide
## Purpose
The Software User Issue Inquiry Form is a tool for software users to report any issues they encounter with the software. This form is designed to collect relevant information from users to help our team identify and resolve issues effectively.

## How To Complete This Form

1. To report an issue, please fill out this form with the required fields.
2. Provide a detailed description of the issue in the "Description" field.
3. Select the category of the issue from the "Category" dropdown menu.
4. Choose the priority of the issue from the "Priority" dropdown menu.
5. Select the status of the issue from the "Status" dropdown menu.
6. Choose the tool assigned to the issue from the "Assigned Tool" dropdown menu.
7. If applicable, fill out the "Date" and "Time" fields with the date and time the issue was reported.
8. If applicable, fill out the "Version" field with the version of the software the issue is related to.
9. If applicable, fill out the "Email" and "Phone" fields with the contact information of the reporter.
10. If the issue is related to IMEI, fill out the "IMEI" fields with the relevant details.

## Field-by-Field Explanation

* **Description** (`software_user_issue_description`, `text`, required): Provide a clear and concise description of the issue you're experiencing.
* **Category** (`software_user_issue_category`, `select_one`, required): Choose the category related to the issue you're experiencing (e.g., IT Forms).
* **Priority** (`software_user_issue_priority`, `select_one`, required): Choose the priority level of the issue (e.g., High, Medium, Low).
* **Status** (`software_user_issue_status`, `select_one`, required): Choose the status of the issue (e.g., Open, Resolved, Closed).
* **Assigned Tool** (`software_user_issue_assigned_tool`, `select_one`, required): Choose the tool assigned to the issue (e.g., chatjimmy).
* **Date** (`software_user_issue_date`, `date`, optional): Provide the date the issue was reported (if applicable).
* **Time** (`software_user_issue_time`, `time`, optional): Provide the time the issue was reported (if applicable).
* **Version** (`software_user_issue_version`, `text`, optional): Provide the version of the software the issue is related to (if applicable).
* **Email** (`software_user_issue_email`, `email`, optional): Provide your email address for contact purposes (if applicable).
* **Phone** (`software_user_issue_phone`, `text`, optional): Provide your phone number for contact purposes (if applicable).
* **Reporter** (`software_user_issue_reporter`, `text`, optional): Provide your name as the reporter of the issue (if applicable).
* **IMEI 1-12** (`software_user_issue_imei1`, `software_user_issue_imei2`, `software_user_issue_imei3`, `software_user_issue_imei4`, `software_user_issue_imei5`, `software_user_issue_imei6`, `software_user_issue_imei7`, `software_user_issue_imei8`, `software_user_issue_imei9`, `software_user_issue_imei10`, `software_user_issue_imei11`, `software_user_issue_imei12`, `text`, optional): Provide the IMEI details related to the issue (if applicable).
