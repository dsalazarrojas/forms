# Cybersecurity Monitoring Authorization Form - Help Guide

## Purpose
This form is used for both monitoring purposes and administrative tasks. It's used to authorize monitoring tasks, assign tools, and track the status of monitoring tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* "Name"
	* "Email"
	* "Phone"
	* "Form Authorized" (select "Yes")
	* "Form Status" (select "Active")
	* "Form Version 2"
2. Optionally, fill in the following fields:
	* "Organization"
	* "Address"
	* "Services" (select "Yes" or "No")
	* "Description"
	* "Form Title"
	* "Form Tags"
	* "Form Notes"
	* "Form Category 2" (select "Yes" or "No")
	* "Form Subcategory" (select "Yes" or "No")
3. If you are an administrator, you may also want to add "Form Category", "Form Version", "Form Tags", "Form Notes", and "Form Title" fields.

## Tips
* Please fill in all required fields.
* If you are unsure about any field, please consult with your supervisor or administrator.
* Please select "Yes" for "Form Authorized" only if you are authorized to do so.
* Please select "Active" for "Form Status" only if the form is currently active.
* Please enter "Form Version 2" with the correct version of the form.
* Please select "Yes" for "Form Category 2" and "Form Subcategory" only if they are applicable.
