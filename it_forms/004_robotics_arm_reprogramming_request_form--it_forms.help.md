# Robotics Arm Reprogramming Request Form - Help Guide
## Purpose
This form is intended to facilitate the reprogramming of robotics arms in our organization. It will help us track requests, assign tasks, and ensure that the necessary adjustments are made efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Request Details** section with a brief description of the reprogramming request.
2. Select the type of robot that needs to be reprogrammed from the **Robot Type** dropdown menu.
3. Provide the reason for the reprogramming request in the **Reason for Request** field.
4. If applicable, specify the new software version that needs to be installed or updated in the **New Software Version** field.
5. Enter the current software version of the robot in the **Current Software Version** field.
6. If there are any hardware changes required, describe them in the **Hardware Changes** field.
7. Enter any test results or notes in the **Test Results** field.
8. In the **Comments** field, add any additional information that may be helpful for the assigned technician.
9. Select one or more technicians to be assigned to the task from the **Assigned Technician** dropdown menu.
10. Repeat step 8 for the second assigned technician.
11. Select the person submitting the request from the **Submitter** dropdown menu.
12. Choose the date and time the request was made in the **Date Requested** and **Time Requested** fields.
13. Select the priority level of the request from the **Priority** dropdown menu.
14. Choose the department involved in the request from the **Department** dropdown menu.
15. Select one or more groups to be assigned to the task from the **Assigned Group** dropdown menu.

## Field-by-Field Explanation
* **Request Details**: A brief description of the reprogramming request.
* **Robot Type**: Select the type of robot that needs to be reprogrammed.
* **Reason for Request**: Enter the reason for the reprogramming request.
* **New Software Version**: If applicable, specify the new software version that needs to be installed or updated.
* **Current Software Version**: Enter the current software version of the robot.
* **Hardware Changes**: If applicable, describe any hardware changes required.
* **Test Results**: Enter any test results or notes.
* **Comments**: Add any additional information that may be helpful for the assigned technician.
* **Assigned Technician**: Select one or more technicians to be assigned to the task.
* **Assigned Technician 2**: Select one or more technicians to be assigned to the task (if applicable).
* **Submitter**: Select the person submitting the request.
* **Date Requested**: Choose the date the request was made.
* **Time Requested**: Choose the time the request was made.
* **Priority**: Select the priority level of the request.
* **Department**: Choose the department involved in the request.
* **Assigned Group**: Select one or more groups to be assigned to the task.

Note: This form is designed to be completed by authorized personnel only. If you are not authorized to submit this form, please contact your supervisor for guidance.
