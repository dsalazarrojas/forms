# Cybersecurity Audit Quote Request - Help Guide
## Purpose
This form is for customers who want to request a quote for a cybersecurity audit service. It helps us understand their project details, required services, and submission schedule.

## How To Complete This Form
1. Please fill out this form carefully, providing as much detail as possible.
2. Select the relevant information for each field.
3. Ensure you provide your email address and a valid phone number for follow-up.

## Field-by-Field Explanation
* **Which IT provider** (`it_provider`, select_one, required):
	+ Please select the IT provider that is relevant to your project.
* **Customer Info** (`customer_info`, note, required):
	+ Please provide a brief description of your company or organization.
* **Project Info** (`project_info`, text, required):
	+ Please provide a brief description of your project.
* **Services** (`services`, select_multiple, required):
	+ Select the services you are interested in for the cybersecurity audit.
* **Submission Date** (`submission_date`, date, required):
	+ Please select the date you want to submit your information for a quote.
* **Submission Time** (`submission_time`, time, required):
	+ Select the time you want to submit your information for a quote.
* **Follow-up Date** (`follow_up_date`, date, required):
	+ Select the date you would like to have follow-up information.
* **Follow-up Time** (`follow-up_time`, time):
	+ Select the time you would like to have follow-up information.
* **Assigned Tool** (`assigned_tool`, text, required):
	+ Please select the tool you would like to be assigned for the audit.
* **Notes** (`notes`, text, required):
	+ Please provide any additional information about your project that will help us understand your needs.
* **Project Details** (`project_details`, text, required):
	+ Please provide a brief description of your project details.
