# Language Resource Management Form - Help Guide
## Purpose
The Language Resource Management Form is designed to collect information about language resources, which helps in effective management and organization of these resources.

## How To Complete This Form
1. Select the relevant options for each field as per your understanding and requirements.
2. Fill in the required fields, which are marked as required in the form.
3. Ensure that you provide accurate and relevant information for each field.

## Field-by-Field Explanation
* **Multilingual Materials** (id: 1, type: select_multiple, required: false): This field allows you to indicate whether the language resource is available in multiple languages. Select "Yes" if it is available in more than one language.
* **Ownership** (id: 2, type: text, required: false): Provide details about the ownership of the language resource, such as the name of the owner, organization, or institution.
* **Access Details** (id: 3, type: time, required: false): Enter the access details for the language resource, such as the last updated date or access restrictions.
* **Usage Rules** (id: 4, type: text, required: false): Describe the usage rules for the language resource, like usage restrictions or access permissions.
* **Language Codes** (id: 5, type: select_one, required: false): Select "Yes" if the language resource uses language codes.
* **Material Status** (id: 6, type: select_multiple, required: false): Indicate whether the language resource is Active or Inactive.
* **Material Access** (id: 7, type: text, required: false): Provide details about the material access, such as access permissions or restrictions.
* **Access Restrictions** (id: 8, type: text, required: false): Describe the access restrictions for the language resource.
* **Searchable** (id: 9, type: select_one, required: false): Select "Yes" if the language resource is searchable.
* **Assigned Tool** (id: 10, type: text, required: false): Enter the tool assigned to the language resource.
* **Assigned Tool ID** (id: 11, type: number, required: false): Enter the ID of the assigned tool.
* **Output File** (id: 12, type: text, required: false): Provide the output file related to the language resource.
* **Language** (id: 13, type: select_multiple, required: false): Select "Yes" if the language resource uses a specific language.
* **Category** (id: 14, type: select_one, required: false): Select "Yes" if the language resource is categorized.
* **Description** (id: 15, type: text, required: false): Briefly describe the language resource.
* **Form IDs** (id: 16, type: number, required: false): Enter the IDs of the forms associated with the language resource.
* **Form ID** (id: 17, type: number, required: false): Enter the ID of the form.
* **Category** (id: 18, type: select_one, required: false): Select "Yes" if the language resource is categorized.
* **Category ID** (id: 19, type: number, required: false): Enter the ID of the category.

## Tips
* Please ensure that you provide accurate and relevant information in each field.
* Review your answers carefully before submission.
* If you are unsure about any field, contact your administrator for guidance.
