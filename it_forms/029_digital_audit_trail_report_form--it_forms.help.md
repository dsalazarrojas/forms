# Digital Audit Trail Report Form - Help Guide
## Purpose
The Digital Audit Trail Report Form is used to report on the status of digital objects, such as files or documents, and the tools or resources assigned to them. This form helps track changes made to these objects and ensures that all information is properly documented.

## How To Complete This Form
To complete this form, simply fill in the required fields as follows:
* For each field, select the correct option from the dropdown list or enter the relevant information in the text box.
* Make sure to fill in all required fields (indicated by the "required" label in the field description).
* Review your entries carefully before submitting the form.

## Field-by-Field Explanation
* **digital_audit_trail_report_form** (Text): This field is where you enter the title of the digital object being reported on.
* **category** (Select One): Please select "Yes" if the digital object falls under the category "Yes" or "No" if it does not.
* **description** (Text): This field is optional and provides additional context for the digital object being reported on.
* **assigned_tool** (Select Multiple): Select all tools or resources that have been assigned to the digital object.
* **category_0** (Select Multiple): Please select "Yes" if the digital object falls under the category "Yes" or "No" if it does not. This field is repeated from the "category" field to allow for multiple categories to be selected.
* **assigned_tool_0** (Select One): Select "Yes" if the digital object has been assigned to tool 0 or "No" if not.
* **assigned_tool_1** (Select One): Select "Yes" if the digital object has been assigned to tool 1 or "No" if not.
* **category_1** (Select Multiple): Please select "Yes" if the digital object falls under the category 1 or "No" if it does not.
* **assigned_tool_2** (Select One): Select "Yes" if the digital object has been assigned to tool 2 or "No" if not.

## Tips
* Make sure to fill in all required fields to ensure accurate reporting.
* If you are unsure about any field, please consult with the relevant authorities.
* If you have any questions or concerns, please contact the support team.
