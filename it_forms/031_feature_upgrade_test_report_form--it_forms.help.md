# Feature Upgrade Test Report Form - Help Guide
## Purpose
The Feature Upgrade Test Report Form is a tool used to collect data on the outcome of feature upgrade tests. This form is used by the development team to gather information on the category, description, test outcome, and any issues or notes regarding the test.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the Category field by selecting the category that the feature belongs to.
* In the Description field, provide a brief description of the feature.
* Select the Test Outcome from the dropdown menu.
* Enter any Issue Summary that occurred during the test.
* Enter any additional Notes about the test.

## Field-by-Field Explanation
* **Category** (`Category`, select_one, required: false): Select the category that the feature belongs to.
* **Description** (`Description`, text, required: false): Enter a brief description of the feature.
* **Test Outcome** (`Test Outcome`, select_one, required: false): Select the outcome of the test, which is either Passed, Failed, or Skipped.
* **Issue Summary** (`Issue Summary`, note, required: false): Enter any issues that occurred during the test.
* **Notes** (`Notes`, note, required: false): Enter any additional notes about the test.

## Tips
* Please make sure to select the correct category for the feature.
* Be as detailed as possible when providing the description of the feature.
* Enter only relevant information in the Test Outcome field.
* Enter only necessary information in the Issue Summary and Notes fields.
