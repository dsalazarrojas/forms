# Remote Access Security Assessment - Help Guide
## Purpose
The Remote Access Security Assessment form is used to gather information about remote access practices, duration, location, frequency, risk evaluation, status, and other details to identify and mitigate potential security risks.

## How To Complete This Form
1. Review the form carefully and fill out all required fields.
2. For fields with options, select the relevant option from the provided choices.
3. For text fields, enter your answer clearly and concisely.

## Field-by-Field Explanation
* **Remote Access Practices** (remote_access_practices, text, optional): Enter your remote access practices, such as VPN, remote desktop, etc.
* **Remote Access Duration** (remote_access_duration, number, optional): Enter the duration of remote access in minutes or hours.
* **Remote Access Location** (remote_access_location, text, optional): Enter the location of remote access, such as office, home, etc.
* **Remote Access Frequency** (remote_access_frequency, select_multiple, optional): Select how often you access the remote location.
	+ Options: Every day, Every 2 days, Every 3 days, Every week, Every 2 weeks, Every month, Every 2 months, Every 3 months, Every 4 months, Every 5 months, Every 6 months, Every 7 months, Every 8 months, Every 9 months, Every 10 months, Every 11 months, Every 12 months
* **Risk Evaluation** (risk_evaluation, select_one, optional): Evaluate the risk level of remote access.
	+ Options: Low, Moderate, High
* **Risk Assessment Status** (risk_assessment_status, select_multiple, optional): Select the status of risk assessment.
	+ Options: No risk assessed, Risk assessed, Risk not assessed
* **Comments** (comments, note, optional): Add any additional comments about the remote access.
* **Reviewer Notes** (reviewer_notes, note, optional): Add any notes from the reviewer.
* **Reviewer** (reviewer, text, optional): Enter the reviewer's name or title.
* **Email** (email, email, optional): Enter the reviewer's email address.

# Tips
* Please fill out all required fields as specified.
* Use clear and concise language when entering text fields.
* Select relevant options for fields with options.
* Review the form carefully before submitting.
* If you are unsure about any field, please refer to this help guide for clarification.
