# Program Survey - Help Guide

## Purpose
The Program Survey form is used to collect information about a program or service offered by an organization. It helps to gather feedback and satisfaction ratings from users to improve the program or service.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" for "Category".
2. Enter a brief description of the program or service in the "Description" field.
3. Choose the assigned tool from the dropdown list in the "Assigned Tool" field.
4. Enter the name of the output file in the "Output File" field.
5. Enter a brief description of the program or services offered in the "Program and Services Offered" field.
6. Select "Yes" or "No" for "Data Collection Method".
7. Select "Satisfied" or "Dissatisfied" for "Program Satisfaction".
8. Select "Satisfied" or "Dissatisfied" for "Program and Services Satisfaction".

## Field-by-Field Explanation

* **Category** (`category`, select_one, required/optional): Select "Yes" if the program or service is applicable, otherwise, select "No".
* **Description** (`description`, text, optional): Enter a brief description of the program or service being surveyed.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Choose the tool assigned to the program or service from the dropdown list.
* **Output File** (`output_file`, text, optional): Enter the name of the output file related to the program or service.
* **Program and Services Offered** (`program_services_offered`, text, optional): Enter a brief description of the program or services offered.
* **Data Collection Method** (`data_collection_method`, select_one, optional): Select "Yes" if data collection method is used for this program or service, otherwise, select "No".
* **Program Satisfaction** (`program_satisfaction`, select_one, optional): Select "Satisfied" if the program or service is satisfactory, otherwise, select "Dissatisfied".
* **Program and Services Satisfaction** (`program_services_satisfaction`, select_one, optional): Select "Satisfied" if the program or services offered are satisfactory, otherwise, select "Dissatisfied".

## Tips
* Be accurate and honest when answering the questions to help us better understand your program or service.
