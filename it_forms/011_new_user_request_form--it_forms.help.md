# New User Request Form - Help Guide
## Purpose
The New User Request Form is designed for requesting new user accounts. It helps us process new user requests in a structured and efficient way.

## How To Complete This Form
- Fill out the required fields: `name`, `email`, and `new_user_request_form_page_11`, as well as `new_user_request_form_page_6` and `new_user_request_form_page_9`.
- If you have any additional comments or notes, you can add them in the "new_user_request_form_page_4" field.
- Choose your department and schedule from the respective dropdown menus.
- Select your availability for training from `new_user_request_form_page_16`, `new_user_request_form_page_17`, `new_user_request_form_page_20`, and `new_user_request_form_page_24`.

## Field-by-Field Explanation
* **name**: This is a text field where you can enter your name.
* **email**: This is an email field where you can enter your email address. This will be the primary contact method for the system.
* **new_user_request_form_page_11**: Please select "option 7 1" or "option 7 2" from this dropdown menu.
* **new_user_request_form_page_6**: Select "option 6 1" or "option 6 2" from this dropdown menu. This will determine the level of access you need for the new user account.
* **new_user_request_form_page_9**: Enter any additional comments or notes about your new user request.
* **new_user_request_form_page_4**: This is a text field for any additional comments or notes.
* **department**: This is a text field for selecting your department. Please enter the name of your department.
* **new_user_request_form_page_16**: Select "option 16 1", "option 16 2", or "option 16 3" from this dropdown menu.
* **new_user_request_form_page_17**: Select "option 17 1" or "option 17 2" from this dropdown menu.
* **new_user_request_form_page_20**: Select "option 19 1", "option 19 2", or "option 19 3" from this dropdown menu.
* **new_user_request_form_page_22**: Select "option 22 1", "option 22 2", or "option 22 3" from this dropdown menu.
* **new_user_request_form_page_24**: Select "option 24 1" or "option 24 2" from this dropdown menu.

## Tips
- Make sure to fill out all required fields before submitting the form.
- Double-check your selections in the dropdown menus to ensure you have selected the correct options.
- If you have any questions or concerns, please contact the support team.
