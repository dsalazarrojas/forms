# Cybersecurity Client Security Inquiry Form - Help Guide
## Purpose
This form is used by clients to submit their security inquiries to the organization's cybersecurity team. Please fill out this form to provide the necessary information to help us assess and mitigate potential security risks.

## How To Complete This Form
1. Select the correct "security_discovery" answer based on your current security situation.
2. Choose whether you have a "qualification" for a security inquiry.
3. Select a "risk_assessment" date for your security inquiry.
4. Provide your "submission_date" and "phone" number.
5. Enter your company name in the "what_is_your_company" field.
6. Enter your email address in the "email" field (optional, but recommended for follow-up communication).

## Field-by-Field Explanation

* **security_inquiry** (`security_inquiry`, number, required): This field is used to determine the level of security awareness you have about your current security situation. Please select "Yes" if you are aware of potential security risks, and "No" if you are not aware.
* **what_is_your_company** (`what_is_your_company`, text, required): This field is for your company name.
* **email** (`email`, email, optional): This field is for your email address. This is an optional field, but it's recommended for follow-up communication.
* **phone** (`phone`, text, optional): This field is for your phone number.
* **security_discovery** (`security_discovery`, select multiple, optional): Please select "Yes" if you have already discovered potential security risks, and "No" otherwise.
* **qualification** (`qualification`, select one, required): Please select "Yes" if you have a qualification for a security inquiry, and "No" otherwise.
* **risk_assessment** (`risk_assessment`, date, required): This field is used to select a date for the risk assessment.
* **submission_date** (`submission_date`, time, required): This field is used to select a submission date and time.
* **phone** (`phone`, text, optional): This field is for your company's phone number.
* **qualification** (`qualification`, select one, required): This field is used to determine if you have a qualification for a security inquiry.
* **risk_assessment** (`risk_assessment`, date, required): This field is used to select a date for the risk assessment.
* **submission_date** (`submission_date`, time, required): This field is used to select a submission date and time.

## Tips
* Please fill out this form carefully, as it will help the cybersecurity team understand your security situation.
* If you are unsure about any of the fields, please contact the cybersecurity team for guidance.
* If you have already submitted a similar inquiry, please do not submit this form again.
