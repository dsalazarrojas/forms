# ประกIT Service Request Form 2 - Help Guide
## Purpose
This form is for requesting IT services from the IT department. It is used to submit a formal request for assistance with an issue or problem. Fill out this form to ensure that your request is documented and reviewed for prompt resolution.

## How To Complete This Form
1. Fill in your name and contact information (Customer Name, Email, and Phone).
2. Select the correct category (Yes/No).
3. Provide a detailed description of the issue.
4. Add any further explanation or context about the issue.
5. Leave comments if you have any additional information or requests.
6. If applicable, attach relevant files to support your request.

## Field-by-Field Explanation
* **Customer Name** (Customer Name, text, required): Please enter your name to identify yourself for the purpose of this request.
* **Email** (Email, email, required): Enter your work or personal email address where you can be reached for further communication.
* **Phone** (Phone, text, required): Enter your phone number for us to contact you if needed.
* **Category** (Category, select_one, required): Select one of the two options (Yes/No) to help us determine the type of service you need.
* **Issue Description** (Issue Description, text, required): Clearly describe the issue you are experiencing and provide as much detail as possible.
* **Further Explanation** (Further Explanation, text, optional): If there is any additional context or information about the issue, please provide it here.
* **Comments** (Comments, text, optional): Add any additional comments or requests that you may have.
* **Repair Request** (Repair Request, text, required): Specify the exact repair or service you are requesting.
* **Issue Attachment** (Issue Attachment, text, optional): Attach a file or document to support your request (e.g. a screenshot, log file, or video).
* **Issue Attachment 2** (Issue Attachment 2, text, optional): Attach another file or document to support your request.
* **Issue Attachment 3** (Issue Attachment 3, text, optional): Attach another file or document to support your request.
* **Issue Attachment 4** (Issue Attachment 4, text, optional): Attach another file or document to support your request.
* **Issue Attachment 5** (Issue Attachment 5, text, optional): Attach another file or document to support your request.
