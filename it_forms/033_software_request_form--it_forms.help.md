# Software Request Form - Help Guide
## Purpose
The Software Request Form is designed to gather information for software requests, ensuring that your needs are met and your expectations are understood. Fill out this form to help us better understand your software requirements and provide the necessary support.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill in the required fields with the requested information.
2.  Choose the correct software category and sub-category for your request.
3.  Provide a brief description of the software you are requesting.
4.  Specify the software version you are looking for.
5.  Enter your contact information so we can reach out to you.
6.  Select the department responsible for your software request.
7.  Indicate if this is an urgent matter or not.
8.  Choose a date for when you would like the software to be implemented.
9.  Select the primary user involved in this request.
10.  If necessary, add any additional information about your request.
11.  Decide if you want to be notified when the software is ready to use.

## Field-by-Field Explanation

*   **What is the software you are requesting?** (`software_request_1`): Enter the title of the software you are looking for.
*   **Software Category** (`software_category_1`): Choose the general category of the software from the available options (General, IT, Security, Network, Database, Operating System, Other).
*   **Software Sub Category** (`software_sub_category_1`): Select all relevant sub-categories for your software request.
*   **Brief Description** (`software_description_1`): Provide a brief description of the software you are requesting.
*   **Software Version** (`software_version_1`): Enter the software version you are looking for.
*   **Contact Information** (`contact_information_1`): Enter your name, phone number, and email so we can contact you.
*   **Department** (`department_1`): Choose the department responsible for your software request from the available options (IT, Security, Finance, Marketing, Other).
*   **Is this software request an urgent matter?** (`is_urgent_1`): Check if your software request is urgent.
*   **Expected Timeline** (`software_timeline_1`): Enter a date for when you would like the software to be implemented.
*   **Primary User** (`primary_user_1`): Choose who will be the primary user for this software request from the available options (Me, Another User, Team).
*   **Additional Information (if needed)** (`software_note_1`): If necessary, add any extra details about your software request.
*   **Would you like to be notified when the software is ready to use?** (`notification_1`): Decide if you want to be notified when the software is ready to use.
