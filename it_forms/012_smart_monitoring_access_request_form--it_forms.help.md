# Smart Monitoring Access Request Form - Help Guide

## Purpose
The Smart Monitoring Access Request Form is used by administrators to request access for a user to our smart monitoring systems. This form should be submitted only once for each user to avoid duplicating access.

## How To Complete This Form
- To complete this form, please follow the instructions below:
 1. Enter your User ID
 2. Enter the date you are requesting access
 3. Select the Access Level you are requesting (Monitoring, Access, or Control)
 4. Choose the Monitoring System you need access to (System A, System B, or System C)
 5. Select the Monitoring User responsible for your access (User A, User B, or User C)
 6. Choose the Reason for your request (Reason A, Reason B, or Reason C)
 7. Select the Approver for your request (John, Jane, or Joe)
 8. Add any additional Notes (optional)

## Field-by-Field Explanation

* **User ID** (`user_id`, `number`, required: false): Enter your User ID to identify yourself.
* **Request Date** (`request_date`, `date`, required: false): Enter the date you are requesting access.
* **Access Level** (`access_level`, `select_multiple`, required: false): Select the level of access you need (Monitoring, Access, or Control).
* **Monitoring System** (`monitoring_system`, `select_one`, required: false): Choose the system you need access to (System A, System B, or System C).
* **Monitoring User** (`monitoring_user`, `select_one`, required: false): Select the user responsible for your access (User A, User B, or User C).
* **Reason** (`reason`, `select_one`, required: false): Choose the reason for your request (Reason A, Reason B, or Reason C).
* **Approved By** (`approved_by`, `select_one`, required: false): Select the person approving your request (John, Jane, or Joe).
* **Notes** (`notes`, `note`, required: false): Add any additional notes about your request.

## Tips
- Please submit only one form per user to avoid duplicating access.
- Only the approved users will have access to the systems and they will be informed about it via email.
- Please select a valid reason for your request.
- If you have any questions or concerns, feel free to contact our support team.
