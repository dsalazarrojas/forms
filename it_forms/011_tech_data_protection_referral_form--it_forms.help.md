# tech_data_protection_referral_form - Help Guide
## Purpose
The tech_data_protection_referral_form is used to report and manage a technology data protection referral.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct team responsible for handling the referral from the "IT Team" dropdown menu.
2. Provide a brief description of the incident in the "Incident Details" text field.
3. Indicate the priority level of the referral by selecting one or more options from the "Priority" dropdown menu (High, Medium, Low).
4. Check all types of data involved in the referral by selecting all applicable options from the "Data Types" dropdown menu (Personal Data, Technical Data, Business Data, Special Category Data).
5. Choose all applicable classification of data by selecting all applicable options from the "Data Classification" dropdown menu (Confidential, Public, Restricted, Private).
6. Provide a detailed description of the resolution status in the "Incident Description" text field.
7. Finally, select the resolution status of the referral from the "Resolution" dropdown menu (Resolved, Not Resolved).

## Field-by-Field Explanation

* **IT Team** (`it_team_contact`): Select the team responsible for handling this referral from the provided options (IT Team 1, Security Team, Privacy Team, Other).
* **Incident Details** (`incident_details`): Provide a brief description of the incident in this text field.
* **Priority** (`priority`): Select one or more priority levels for this referral (High, Medium, Low). 
* **Data Types** (`data_types`): Check all types of data involved in this referral (Personal Data, Technical Data, Business Data, Special Category Data).
* **Data Classification** (`data_classification`): Choose all classification of data involved in this referral (Confidential, Public, Restricted, Private).
* **Incident Description** (`incident_description`): Provide a detailed description of the referral in this text field.
* **Resolution** (`resolution`): Select the resolution status of this referral from the provided options (Resolved, Not Resolved).
