# Fulfillment Automation Integration Application - Help Guide
## Purpose

The Fulfillment Automation Integration Application form is used to manage integration requests for fulfillment automation.

## How To Complete This Form

To complete this form, follow the instructions in the "How to Complete This Form" section.

## Field-by-Field Explanation

* **Integration Request** (1, `number`, required): This field is used to select the type of integration request.
* **Vendor Info** (2, `text`, required): Enter the vendor information.
* **Ecommerce Brand** (3, `text`, required): Enter the ecommerce brand.
* **Logistics Details** (4, `text`, required): Enter the logistics details.
* **Type** (5, `text`, required): Select the integration request type.
* **URL** (6, `text`, required): Enter the integration URL.
* **Username** (7, `text`, required): Enter the username for the integration.
* **Password** (8, `text`, required): Enter the password for the integration.
* **API Keys** (9, `text`, required): Enter the API keys.
* **API Credentials** (10, `select_multiple`, required): Select the API credentials type.
* **API Credentials 2** (11, `select_multiple`, required): Select the API credentials type 2.
* **API Credentials 3** (12, `select_multiple`, required): Select the API credentials type 3.
* **Status** (13, `select_one`, required): Select the integration status.
* **Notes** (14, `note`, required): Enter any additional comments or notes.
* **Description** (15, `text`, required): Enter a description of the integration request.
* **Comments** (16, `text`, required): Enter any comments about the integration request.
* **Request ID** (17, `text`, required): Enter the request ID.
* **Request Date** (18, `date`, required): Enter the request date.
* **Request Time** (19, `time`, required): Enter the request time.
* **Assigned To** (20, `text`, required): Select the assigned user.
* **Priority** (21, `select_one`, required): Select the priority of the integration request.
* **Due Date** (22, `date`, required): Enter the due date for the integration request.
* **Comments** (23, `text`, required): Enter any additional comments about the integration request.
* **Status** (24, `select_one`, required): Select the status of the integration request.
