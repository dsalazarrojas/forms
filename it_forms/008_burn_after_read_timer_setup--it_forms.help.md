# Burn After Read Timer Setup - Help Guide

## Purpose
The Burn After Read Timer Setup form is designed to configure settings for a secure message that automatically self-destructs after a set time period. This form helps you set up the recipient's information, timer settings, and other security options to ensure that the message is delivered and accessed securely.

## How To Complete This Form
To complete this form, follow these steps:

1. **Sender Information**: Provide your name and email address. This information will be used to identify you as the sender.
2. **Department**: Select your department from the list to categorize your message.
3. **Message Configuration**: Enter the subject and content of your message.
4. **Recipient Information**: Enter the recipient's email address and select the verification method (e.g., email verification only or two-factor authentication).
5. **Access Control**: Choose who can access the message (e.g., only the recipient or others with specific permissions).
6. **Timer Settings**: Set the time period until the message self-destructs.
7. **Additional Options**: Select notification preferences and other advanced options.

## Field-by-Field Explanation

* **Sender Name**: Enter your name to identify yourself as the sender.
* **Sender Email**: Enter your email address to associate with the message.
* **Department**: Select your department to categorize your message.
* **Message Subject**: Enter the subject line of your message.
* **Message Content**: Enter the content of your secure message.
* **Sensitivity Level**: Select the sensitivity level of your message (e.g., confidential, internal use only, or top secret).
* **Timer Settings**: Set the time period until the message self-destructs (e.g., 1 hour, 6 hours, or 24 hours).
* **Read Receipt Required**: Choose whether the sender should be notified when the message is read.
* **Access Control**: Choose who can access the message.
* **Recipient Email**: Enter the recipient's email address.
* **Recipient Verification**: Select the verification method (e.g., email verification only or two-factor authentication).
* **Maximum Access Attempts**: Set the number of failed access attempts before the message is locked out.
* **Forwarding Allowed**: Choose whether the recipient can forward the message.
* **Printing Allowed**: Choose whether the recipient can print the message.
* **Security Options**: Additional security measures (e.g., encryption level or audit trail).
* **Encryption Level**: Select the encryption strength (e.g., standard, enhanced, or military-grade).
* **Audit Trail**: Choose whether access to the message should be logged.
* **Additional Password**: Optional extra password protection for the message.
* **Notification Preferences**: Choose when you should be notified (e.g., when the message is delivered, read, or destroyed).
* **Notification Preferences Options**: Select multiple notification preferences (e.g., when the message is delivered, read, or destroyed).
