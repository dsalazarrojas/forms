# Software Project Outcome Report Form - Help Guide
## Purpose
This form is used to gather information about the outcomes of software project management activities, providing a comprehensive report that captures key details about the project's status, categorization, and outcomes.

## How To Complete This Form
1. Start by selecting the project's category from the options provided.
2. Enter the project ID, if applicable.
3. Select the project status from the text field.
4. Enter the project start and end dates, if applicable.
5. Enter the project manager's name, email, and phone number, if applicable.
6. List the stakeholder names and their emails, if applicable.
7. Provide comments and outcomes from stakeholders, if applicable.
8. Enter any comments from the project manager, if applicable.
9. Describe the overall outcome of the project.
10. Enter any recommendations for future projects.

## Field-by-Field Explanation

* **Project Status** (`project_status`, text, required: false): Enter the current status of the project, e.g., 'On-going', 'Completed', or 'Cancelled'.

* **Project ID** (`project_id`, number, required: false): Enter the project ID number, if applicable.

* **Category** (`outcome_category`, select_one, required: false): Choose the category of the project, e.g., 'Software Project' or 'IT Project'.

* **Project Manager Name** (`project_manager_name`, text, required: false): Enter the name of the project manager.

* **Project Start Date** (`project_start_date`, date, required: false): Enter the start date of the project, if applicable.

* **Project End Date** (`project_end_date`, date, required: false): Enter the end date of the project, if applicable.

* **Project Manager Email** (`project_manager_email`, email, required: false): Enter the email address of the project manager, if applicable.

* **Project Manager Phone** (`project_manager_phone`, text, required: false): Enter the phone number of the project manager, if applicable.

* **Stakeholder Names** (`stakeholder_names`, text, required: false): List the names of stakeholders involved in the project, separated by commas.

* **Stakeholder Emails** (`stakeholder_emails`, text, required: false): List the email addresses of stakeholders involved in the project, separated by commas.

* **Stakeholder Comments** (`stakeholder_comments`, note, required: false): Provide any comments from stakeholders, if applicable.

* **Project Manager Comments** (`project_manager_comments`, note, required: false): Provide any comments from the project manager, if applicable.

* **Project Outcomes** (`project_outcomes`, text, required: false): Describe the outcomes of the project.

* **Overall Outcome** (`overall_outcome`, text, required: false): Enter the overall outcome of the project, if applicable.

* **Recommendation** (`recommendation`, text, required: false): Enter any recommendations for future projects, if applicable.
