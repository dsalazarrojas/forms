# Security Plan Deviation Request Form - Help Guide

## Purpose
This form is used to request a deviation from the security plan. It helps in handling exceptions or changes to the standard security processes.

## How To Complete This Form

1. To fill out this form, select the "Requester" field and enter your name.
2. In the "Requester's Email" field, enter your email address.
3. For "Requester's Phone", enter your contact number.
4. In the "Risk Context" field, provide a brief description of the reason for the deviation request.
5. Select the "Reviewer" who will review the deviation request from the following options: IT, Operations, or Management.
6. In the "Review Date" field, select the date when the review is expected to be completed.
7. If the review is expected to be completed within a specific time, enter the "Review Time" in 24-hour format.
8. In the "Comments" field, provide any additional comments regarding the deviation request.
9. In the "Submitted By" field, enter your name.
10. In the "Submitted On" field, select the date when the form was submitted.

## Field-by-Field Explanation

* **Requester**: This is where you enter your name.
* **Requester's Email**: This field is used to enter your email address.
* **Requester's Phone**: This field is used to enter your contact number.
* **Risk Context**: This is a field to provide a brief description of the reason for the deviation request.
* **Reviewer**: This field is used to select the person who will review the deviation request.
	+ Select one of the following options: IT, Operations, or Management.
* **Review Date**: This field is used to select the date when the review is expected to be completed.
* **Review Time**: This field is used to enter the review time in 24-hour format.
* **Comments**: This field is used to provide any additional comments regarding the deviation request.
* **Submitted By**: This field is used to enter your name.
* **Submitted On**: This field is used to select the date when the form was submitted.

Note: The fields marked as "required" are mandatory and must be filled out.
