**Collaborator Data Set Upload Form - Help Guide**

## Purpose

This form is designed to collect information about a collaborator's dataset, including contributor details, dataset metadata, and usage agreements. It is used to ensure that all collaborating parties have a clear understanding of the data's scope, access, and usage. This form should be filled out for every dataset uploaded to our platform.

## How To Complete This Form

1.  Fill out the form completely, ensuring that all fields are accurate and relevant to the dataset you are uploading.
2.  Ensure that you are authorized to upload the dataset and have the necessary permissions and agreements in place.
3.  Attach any supporting documentation and files as required.
4.  Review the form carefully before submitting to ensure that all information is correct and complete.

## Field-by-Field Explanation

*   **Contributor Full Name**: Enter the name of the contributor, first and last.
*   **Email Address**: Enter the contact email of the contributor.
*   **Phone Number**: Enter the contact phone number of the contributor (optional).
*   **Institution/ Organization**: Enter the name of the institution or organization affiliated with the contributor.
*   **Department**: Enter the department or unit within the institution (optional).
*   **Your Role**: Select the role of the contributor in the research project (e.g., Principal Investigator, Co-Investigator, Research Assistant, etc.).
*   **Research Project Name**: Enter the name of the research project the dataset is associated with.
*   **Project ID Number**: Enter the ID number associated with the project (optional).
*   **Dataset Title**: Enter a brief title for the dataset.
*   **Dataset Description**: Provide a brief description of the dataset.
*   **Type of Data**: Select all types of data included in the dataset (e.g., numerical, text, images, etc.).
*   **Data Format**: Select the format of the data (e.g., CSV, Excel, JSON, etc.).
*   **Upload Data Files**: Attach the data files associated with the dataset.
*   **Total File Size**: Enter the total size of the dataset in MB or GB.
*   **Number of Files**: Enter the number of files in the dataset.
*   **Data Collection Method**: Describe how the data was collected.
*   **Data Collection Dates**: Enter the dates when the data was collected.
*   **Data Collection Location**: Enter the location where the data was collected (optional).
*   **Sample Size**: Enter the number of records or subjects in the dataset.
*   **Number of Variables**: Enter the number of variables or fields in the dataset (optional).
*   **Data Quality Checks**: Describe any quality checks performed on the data.
*   **Missing Data Handling**: Describe how missing values were handled in the dataset.
*   **Contains Sensitive Data**: Select "True" if the dataset contains PII or confidential information.
*   **Data Use Agreement Required**: Select "True" if an agreement is required for use of the dataset.
*   **Access Level**: Select who can access the dataset (e.g., public, project team, institution, etc.).
*   **Embaro Date**: Enter the date when the dataset can be shared (optional).
*   **Documentation Included**: Select whether a README or codebook is included with the dataset.
*   **Upload Documentation**: Attach any documentation files (optional).
*   **Codebook Available**: Select whether a codebook is available with the dataset.
*   **Related Publications**: List any publications related to the dataset (optional).
*   **Funding Source**: Enter any funding information associated with the dataset (optional).
*   **Data License Preference**: Select the license preference for the dataset (e.g., public domain, attribution, etc.).
*   **Citation Preference**: Enter how the dataset should be cited (optional).
*   **Additional Notes**: Add any additional information about the dataset.

Note: Please ensure that all required fields are filled out accurately and completely to avoid delays in processing the dataset.
