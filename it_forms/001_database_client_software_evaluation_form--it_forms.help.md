# Database Client Software Evaluation Form - Help Guide
## Purpose
This form is used to evaluate and compare database client software based on your specific needs and preferences.
## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the provided fields with your thoughts and opinions about the database client software you are evaluating.
2. Choose the category that best describes your software evaluation.
3. Describe your experience and needs related to the database client software.
4. Share any helpful documentation or recommendations for the software.
5. Indicate if the software supports purchasing or standardization decisions.

## Field-by-Field Explanation
* **Category** (`category`, select_one, required: false): Select the category that best describes your software evaluation.
	+ IT Forms (e.g., database management, data analysis)
	+ Other (e.g., web development, project management)
* **Description** (`description`, text, required: false): Describe your experience and needs related to the database client software.
* **Helps IT and Engineering Teams** (`helps_it_and_engineering_teams`, text, required: false): This field is intended to help you describe how the software provides support for IT and engineering teams.
* **Collects Consistent Feedback** (`collects_consistent_feedback`, text, required: false): This field is intended to help you describe how the software collects consistent feedback from users.
* **Compare Database Client Tools** (`compararate_database_client_tools`, text, required: false): This field is intended to compare database client tools and describe their differences.
* **Document Recommendations** (`document_recommendations`, text, required: false): Share any helpful documentation or recommendations related to the database client software.
* **Supports Purchasing or Standardization Decisions** (`support_purchasing_or_standardization_decisions`, text, required: false): This field is intended to indicate if the software supports purchasing or standardization decisions.
