# Retail App Error Notification Contact Form - Help Guide
## Purpose
This form is designed to report errors experienced with our retail application. Please provide as much detail as possible so we can better assist you.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the title field with a brief description of the issue.
2. Select the type of device you are using.
3. Enter the app version you are currently using.
4. Provide a step-by-step explanation of how to reproduce the error.
5. Enter a detailed error message.
6. If necessary, attach any files related to the issue.
7. Select any additional attachments that are relevant to the error report.
8. Click "Submit" to send your report.

## Field-by-Field Explanation
* **Retail App Error Notification Contact Form** (`form_title`): A brief description of the issue you are experiencing. 
* **device_type** (`device_type`): Select the type of device (Android, iOS, or Other).
* **App Version** (`app_version`): Enter the app version you are currently using.
* **Steps to Reproduce** (`steps_to_reproduce`): Provide a step-by-step explanation of how to reproduce the error.
* **Error Message** (`error_message`): Enter a detailed error message related to the issue.
* **Attachment** (`attachment`): Select your file to attach, if relevant to the error report.
* **Attachments** (`attachment_uploads`): Select any additional attachments related to the issue (max 2 files).
* **Submit** (`submit`): Click to send your completed report to our team.

## Tips
* Be sure to attach any relevant files to support your error report.
* Try to provide detailed, step-by-step instructions on how to reproduce the error.
* If you are unsure about any field, feel free to ask for clarification.
