# Software Development Statement Of Work SOW - Help Guide
## Purpose
The Software Development Statement Of Work SOW form is used to document the scope, deliverables, and requirements of a software development project. It provides a centralized location for capturing project details, which helps project stakeholders to understand the project's objectives, timelines, and payment terms.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form's purpose and fields to understand what information is required.
2. Start by filling in the "Project Scope" field with a brief description of the project's objectives and deliverables.
3. In the "Deliverables" field, select the relevant items that apply to your project.
4. For the "Timelines" field, enter the project start and end dates.
5. In the "Payment Terms" field, enter the payment terms and conditions for the project.
6. Provide information about the client, project, internal, and freelancer details in the respective fields.
7. Add any review notes in the "Review Notes" field.
8. Set the project status as "Active" or "Inactive" in the "Status" field.
9. Finally, enter any comments about the project in the "Comments" field.

## Field-by-Field Explanation
* **Project Scope** (Page 1): A brief description of the project's objectives and deliverables. Enter a text description of the project's scope in this field.
* **Deliverables** (Page 1): Select all the deliverables that apply to your project. You can select one or multiple deliverables from the provided options.
* **Timelines** (Page 1): Enter the project start and end dates in the format MM/DD/YYYY HH:MM:SS.
* **Payment Terms** (Page 2): Enter the payment terms and conditions for the project, including any payment schedules or deadlines.
* **Client Info** (Page 2): Enter any relevant information about the client, such as their contact details or project manager's email.
* **Project Info** (Page 2): Enter any information about the project, such as its title, description, or version.
* **Agency Info** (Page 2): Enter any information about the agency or organization handling the project.
* **Internal Info** (Page 2): Enter any internal information about the project, such as meeting minutes or project documents.
* **Freelancer Info** (Page 2): Enter any information about the freelancer or external team members working on the project.
* **Review Notes** (Page 3): Add any review notes or comments about the project in this field.
* **Approval Date** (Page 3): Enter the date when the project was approved.
* **Approval Time** (Page 3): Enter the time when the project was approved.
* **Status** (Page 3): Set the project status as "Active" or "Inactive".
* **Comments** (Page 3): Enter any comments or feedback about the project.
