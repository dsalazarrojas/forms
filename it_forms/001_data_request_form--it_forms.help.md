# Data Request Form - Help Guide
## Purpose
The Data Request Form is designed to collect information about a client's data request, including client details, contact preferences, and request specifics. This form is used to manage client data requests and ensure that the request is processed correctly.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Fill out the required fields, including Client Information, Contact, and Data Request.
2.  Select the correct options for Contact and Data Request Status to reflect the client's preferences.
3.  Fill out the Date and Time fields accordingly.
4.  Add any additional notes or comments in the Note field.
5.  Enter the client's Email address.
6.  Enter the client's Phone number.
7.  Choose who the request is assigned to.
8.  Choose who updated the request.

## Field-by-Field Explanation

*   **Client Information** (`client_information`, text, required/optional): This field is used to enter the client's name and any other relevant details.
*   **Contact** (`contact_details`, select_multiple, required/optional): This field allows you to select whether the client prefers contact by "Yes" or "No".
*   **Data Request** (`data_request`, text, required/optional): This field is used to enter the specific data request details.
*   **Date** (`data_request_date`, date, required/optional): This field is used to enter the date of the data request.
*   **Time** (`data_request_time`, time, required/optional): This field is used to enter the time of the data request.
*   **Status** (`data_request_status`, select_one, required/optional): This field is used to select the status of the data request as "Active" or "Inactive".
*   **Note** (`data_request_note`, note, required/optional): This field is used to add any additional notes or comments about the request.
*   **Email** (`email`, email, required/optional): This field is used to enter the client's Email address.
*   **Phone** (`phone`, text, required/optional): This field is used to enter the client's Phone number.
*   **Assigned To** (`assigned_to`, select_multiple, required/optional): This field is used to choose who the request is assigned to.
*   **Updated By** (`updated_by`, select_multiple, required/optional): This field is used to choose who updated the request.

## Tips
*   Be sure to fill out all required fields accurately to avoid errors and ensure that the request is processed correctly.
*   Use the correct formatting for dates and times to ensure that they are read correctly.
*   Use the correct options for Contact and Data Request Status to reflect the client's preferences.
*   Keep the Note field concise and to the point, as it's used to add any additional notes or comments about the request.
*   Double-check the client's Email and Phone number to ensure they are entered correctly.
