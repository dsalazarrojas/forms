# data_center_inspection_form - Help Guide
## Purpose
The data_center_inspection_form is used to inspect and report on the status of various systems and equipment within a data center.

## How To Complete This Form
1. Fill out the form for each page, providing information for each field as requested.
2. For each field, select the applicable options from the dropdown menus or enter your notes in the text boxes.
3. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **user_data**: A text field for the user to enter their name or other identifying information.
* **is_data_center_running**: A dropdown menu to select whether the data center is currently running (online) or not running (offline).
* **safety_equipment_checked**: A dropdown menu to select which safety equipment is checked (e.g. fire safety system, emergency exit signs, fire extinguishers, etc.).
* **safety_equipment_notes**: A text field for notes about the safety equipment.
* **electrical_equipment_checked**: A dropdown menu to select which electrical equipment is checked (e.g. circuit breakers, electrical panel boxes, power distribution units, etc.).
* **electrical_equipment_notes**: A text field for notes about the electrical equipment.
* **cooling_system_checked**: A dropdown menu to select which cooling system is checked (e.g. cooling towers, chillers, cooling systems, etc.).
* **cooling_system_notes**: A text field for notes about the cooling system.
* **structural_equipment_checked**: A dropdown menu to select which structural equipment is checked (e.g. structural support, structural foundation, structural walls, etc.).
* **structural_equipment_notes**: A text field for notes about the structural equipment.
* **environmental_equipment_checked**: A dropdown menu to select which environmental equipment is checked (e.g. air quality monitors, temperature monitors, humidity monitors, etc.).
* **environmental_equipment_notes**: A text field for notes about the environmental equipment.
* **security_equipment_checked**: A dropdown menu to select which security equipment is checked (e.g. cameras, alarms, emergency exit signs, etc.).
* **security_equipment_notes**: A text field for notes about the security equipment.
* **general_equipment_checked**: A dropdown menu to select which general equipment is checked (e.g. floor plates, racking system, data center equipment, etc.).
* **general_equipment_notes**: A text field for notes about the general equipment.
* **fire_safety_equipment_checked**: A dropdown menu to select which fire safety equipment is checked (e.g. fire sprinkler system, fire safety equipment, smoke detector, etc.).
* **fire_safety_equipment_notes**: A text field for notes about the fire safety equipment.
* **electrical_equipment_status**: A dropdown menu to select the status of the electrical equipment (e.g. online or offline).
* **environmental_equipment_status**: A dropdown menu to select the status of the environmental equipment (e.g. online or offline).
* **security_equipment_status**: A dropdown menu to select the status of the security equipment (e.g. online or offline).
* **general_equipment_status**: A dropdown menu to select the status of the general equipment (e.g. online or offline).
* **cooling_system_status**: A dropdown menu to select the status of the cooling system (e.g. online or offline).
* **structural_equipment_status**: A dropdown menu to select the status of the structural equipment (e.g. online or offline).

## Tips
* Double-check all fields before submitting the form to ensure that all required information is provided.
* Use the notes fields to provide any additional information that may not fit in the standard fields.
* If you are unsure about any field, contact your supervisor or the data center administrator for guidance.
