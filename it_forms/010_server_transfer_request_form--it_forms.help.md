# Server Transfer Request Form - Help Guide
## Purpose
The Server Transfer Request Form is designed to collect information about server transfers within your organization. This form will guide you through the required fields and ensure that you provide accurate and complete information for the transfer process.

## How To Complete This Form
- Please select the "Source" server by entering its name or ID.
- Choose the "Destination" server by entering its name or ID.
- Enter the desired "Timing" for the transfer, using the date format (YYYY-MM-DD).
- Provide a brief "Reason" for the transfer.

## Field-by-Field Explanation
- **Source** (server_transfer_request_form_1): Enter the name or ID of the server you wish to transfer data from.
- **Destination** (server_transfer_request_form_2): Enter the name or ID of the server you wish to transfer data to.
- **Timing** (server_transfer_request_form_3): Select the date and time when the transfer is expected to take place.
- **Reason** (server_transfer_request_form_4): Briefly describe the purpose or reason for the server transfer.

## Tips
- Please ensure that you have the necessary permissions and approvals before initiating a server transfer.
- Double-check the accuracy of your input before submitting the form.
- If you experience any issues or have further questions, please contact [form@gic.mx](mailto:form@gic.mx).
