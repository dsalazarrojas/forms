# SSH Audit Log Form - Help Guide

## Purpose
The SSH Audit Log Form is used to collect information on the details of an SSH audit log entry.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **User Id** field with the ID of the user who accessed the system.
2. Fill in the **User Name** field with the name of the user who accessed the system.
3. Fill in the **User Email** field with the email of the user who accessed the system.
4. Fill in the **User Department** field with the department of the user who accessed the system.
5. Fill in the **Start Date** field with the date when the user started their SSH session.
6. Fill in the **End Date** field with the date when the user ended their SSH session.

## Field-by-Field Explanation
* **User Id (1)** (`User Id`, `number`, optional): A unique identifier for the user who accessed the system. 
* **User Name (2)** (`User Name`, `text`, optional): The name of the user who accessed the system.
* **User Email (3)** (`User Email`, `email`, optional): The email of the user who accessed the system.
* **User Department (4)** (`User Department`, `text`, optional): The department of the user who accessed the system.
* **Start Date (5)** (`Start Date`, `date`, optional): The date when the user started their SSH session.
* **End Date (6)** (`End Date`, `date`, optional): The date when the user ended their SSH session.

## Tips
- Make sure to fill in all the required fields.
- Double-check the information provided before submitting the form.
- If you are unsure about any of the fields, please contact your supervisor for clarification.
