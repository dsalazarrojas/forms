# Device Verification Form - Help Guide
## Purpose
The Device Verification Form is designed to collect details about devices to verify their authenticity and ensure they meet our quality and safety standards.

## How To Complete This Form
1. Fill in the device's **device_name** field with the exact model name of the device, as stated on its label or packaging.
2. Enter the **device_serial_number** if available, which can be found on the device's packaging, documentation, or from the manufacturer.
3. Select the **device_type** from the available options or type in a different type if not listed.

## Field-by-Field Explanation

* **device_name**: Enter the exact model name of the device.
* **device_serial_number**: The serial number of the device, if available. This helps us verify the device's origin and production date.
* **device_type**: Select the correct type of device from the options provided, or type in a different type if not listed. This ensures we accurately categorize and manage the device.

## Tips
- Double-check the device's packaging or documentation for accurate information.
- Ensure you have the necessary permissions to complete this form.
- If you're unsure about any field, please ask our support team for assistance.
