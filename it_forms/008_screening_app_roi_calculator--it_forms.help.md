## Purpose
The Screening App ROI Calculator is a tool designed to help users estimate the return on investment (ROI) of different scenarios related to a screening application.

## How To Complete This Form
1.  Select the "Compare Scenarios" option to choose which scenarios you want to compare.
2.  Select the scenarios you want to compare.
3.  Enter time savings, cost savings, implementation expenses, and ROI timeline for each scenario.
4.  Review and compare your results.
