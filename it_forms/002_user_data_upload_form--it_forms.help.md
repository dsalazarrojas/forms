# User Data Upload Form - Help Guide
## Purpose
The User Data Upload Form is designed for users to upload and manage files, team leaders, and follow-ups. This form is used to collect context and additional information about uploaded files and team leaders.

## How To Complete This Form
To complete this form, follow these steps:
1. Click on the "Upload Files" section to upload your files.
2. Select the context and team leaders for the uploaded files in the corresponding sections.
3. Choose the follow-up options that apply to each file.
4. Fill in the file size fields if necessary.
5. Review your selections before submitting the form.

## Field-by-Field Explanation
* **Upload Files** (`id: 1`, `type: text`, required: false): Upload your files by selecting the "Upload Files" section and clicking on the "Upload" button.
* **Collect Context** (`id: 2`, `type: text`, required: false): Select the context that applies to the uploaded files.
* **Additional Files** (`id: 3`, `type: text`, required: false): Select additional files that are related to the main upload.
* **Follow-ups** (`id: 4`, `type: select_multiple`, required: false): Select follow-up options that apply to the uploaded files.
* **Essential Context** (`id: 5`, `type: text`, required: false): Fill in the essential context for the uploaded files.
* **Team Leader** (`id: 6`, `type: select_one`, required: false): Select the team leader who is responsible for the uploaded files.
* **File Size** (`id: 7`, `type: number`, required: false): Enter the size of the uploaded file.
