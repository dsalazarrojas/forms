# crowdstrike_cyber_attack_report_form - Help Guide
## Purpose
The Cyber Attack Report Form is used to collect information about cyber attacks or incidents that have occurred within an organization.

## How To Complete This Form
To complete this form, simply fill out each field with the requested information. All required fields are marked as such and should be filled out accurately. Optional fields can provide additional context and information that can be helpful in understanding the incident.

## Field-by-Field Explanation
- **Impact** (Impact, text, required): Describe the impact of the incident on the organization, including any financial, reputational, or operational effects.
- **Attack Vector** (Attack Vector, text, optional): If known, provide information about the vector used by the attacker (e.g. phishing, ransomware, etc.).
- **Response** (Response, text, required): Describe the response taken by the organization to the incident, including any actions taken to mitigate the damage.
- **Resolution** (Resolution, text, required): Describe the resolution of the incident, including any steps taken to prevent future occurrences.
- **Impact Date** (Impact Date, date, required): Provide the date on which the incident occurred.
- **Impact Time** (Impact Time, time, required): Provide the time on which the incident occurred.
- **Response Time** (Response Time, time, required): Provide the time at which the response was initiated.
- **Attacker IP** (Attacker IP, text, optional): If known, provide the IP address of the attacker.
- **Response Method** (Response Method, text, optional): If known, provide the method used by the organization to respond to the incident (e.g. patching, containment, etc.).
- **Attacker Domain** (Attacker Domain, text, optional): If known, provide the domain associated with the attacker's IP address.
- **Resolution Method** (Resolution Method, text, optional): If known, provide the method used by the organization to resolve the incident (e.g. patching, containment, etc.).
- **Impact Type** (Impact Type, select one, required): Select the type of impact experienced by the organization (network, system, user, application).
- **Response Type** (Response Type, select one, required): Select the type of response taken by the organization (immediate, delayed, none).
- **Attacker Location** (Attacker Location, text, required): Provide the location of the attacker.
- **Resolution Status** (Resolution Status, text, required): Describe the current status of the resolution process.
- **Attacker Email** (Attacker Email, email, optional): If known, provide the email address associated with the attacker.
- **Attacker Phone** (Attacker Phone, text, optional): If known, provide the phone number associated with the attacker.
- **Comments** (Comments, note, optional): Provide any additional comments or context about the incident.

Note: This help guide is meant to be a general guide and is not meant to be a comprehensive guide to every possible scenario. If you have any questions or need further clarification, please reach out to the relevant team or contact person.
