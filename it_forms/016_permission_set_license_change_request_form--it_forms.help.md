# permission_set_license_change_request_form - Help Guide
## Purpose
This form is used to request changes to an existing license or permission set.

## How To Complete This Form
1. Select the relevant category and form type from the drop-down menus.
2. Enter any additional description if necessary.
3. Choose the assigned tool for the requested change.
4. Provide the form IDs if necessary.
5. Enter any additional file outputs or descriptions if required.

## Field-by-Field Explanation
* **category** (`category`, select_one, required: false): Select the category for the permission set license change request.
* **description** (`description`, text, required: false): Enter any additional description for the request.
* **assigned_tool** (`assigned_tool`, select_one, required: false): Choose the tool associated with the permission set license change request.
* **form_ids** (`form_ids`, number, required: false): Enter any relevant form IDs.
* **output_file** (`output_file`, text, required: false): Enter any additional file outputs or descriptions.
* **description2** (`description2`, text, required: false): Enter any additional description if necessary.
* **description3** (`description3`, text, required: false): Enter any additional description if necessary.

## Tips
* Be sure to select the correct category and form type to ensure accurate processing of your request.
* If required, enter the relevant form IDs to facilitate tracking and management.
* Double-check your descriptions for accuracy and completeness.
* This form is for internal IT management or administrative purposes, so be clear and concise in your entries.
