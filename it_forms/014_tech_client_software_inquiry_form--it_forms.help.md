# tech_client_software_inquiry_form - Help Guide
## Purpose
This form is used to gather information about software inquiries from clients. It is intended to be filled out by clients or project managers to provide details about software requests, project status, and follow-up methods.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Software Inquiry** field with a brief description of the software request.
2. Provide the **Client Info** field with relevant information about the client.
3. Enter the **Project Info** field with details about the project.
4. Choose your **Preferred Contact Method** (Email, Phone, or Chat) and select your preferred method for follow-up.
5. Select the current **Project Status** (Active, Inactive, or Unknown).
6. Enter the **Project Manager** name and **Project Manager Email** and **Project Manager Phone** fields with relevant information.
7. Choose the follow-up methods (Email, Phone, or Chat) and **Follow-up Status** (Completed, In Progress, or Not Started) for each follow-up.
8. Enter the **Follow-up Date** and **Follow-up Time** fields with relevant information.
9. Enter any additional notes in the **Project Manager Note** fields.

## Field-by-Field Explanation
* **Software Inquiry**: A brief description of the software request.
	+ Type: Text
	+ Required: No
* **Client Info**: Relevant information about the client.
	+ Type: Text
	+ Required: No
* **Project Info**: Details about the project.
	+ Type: Text
	+ Required: No
* **Preferred Contact Method**: The method you prefer to use for follow-up (Email, Phone, or Chat).
	+ Type: Select One
	+ Required: Yes
* **Email**: The email of the project manager.
	+ Type: Email
	+ Required: No
* **Phone**: The phone number of the project manager.
	+ Type: Text
	+ Required: No
* **Project Status**: The current status of the project (Active, Inactive, or Unknown).
	+ Type: Select One
	+ Required: Yes
* **Project Manager**: The name of the project manager.
	+ Type: Text
	+ Required: No
* **Project Manager Email**: The email of the project manager.
	+ Type: Email
	+ Required: No
* **Project Manager Phone**: The phone number of the project manager.
	+ Type: Text
	+ Required: No
* **Follow-up Method**: The method to use for follow-up (Email, Phone, or Chat).
	+ Type: Select Multiple
	+ Required: Yes
* **Follow-up Status**: The status of the follow-up (Completed, In Progress, or Not Started).
	+ Type: Select One
	+ Required: Yes
* **Follow-up Date**: The date of the follow-up.
	+ Type: Date
	+ Required: No
* **Follow-up Time**: The time of the follow-up.
	+ Type: Time
	+ Required: No
* **Project Manager Note**: Additional notes from the project manager.
	+ Type: Note
	+ Required: No
