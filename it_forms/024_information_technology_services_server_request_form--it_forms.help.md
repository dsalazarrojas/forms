# Information Technology Services Server Request Form - Help Guide
## Purpose
This form is used to capture and document server-related requests for Information Technology services. It is intended to ensure that all necessary information is captured correctly and consistently for the IT services team to fulfill the requests efficiently.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill out the first page with your personal details.
2. Select the relevant server type from the dropdown menu.
3. Choose the status of the server from the dropdown menu.
4. Enter the date and time that the request should be opened.
5. Enter any additional comments or description if necessary.
6. Submit the form to complete the request.

## Field-by-Field Explanation
* **First Name** (Text, Required): Enter your first name.
* **Last Name** (Text, Required): Enter your last name.
* **Email** (Email, Required): Enter your email address.
* **Phone** (Text, Optional): Enter your phone number for contact purposes.
* **Server Type** (Select One, Optional): Choose the type of server you are requesting (e.g. Rack, Tower, Blade, Virtual).
* **Server Status** (Select Multiple, Optional): Choose the status of the server (e.g. Active, Inactive, Scheduled).
* **Server Request** (Text, Required): Enter a detailed description of your server request.
* **Comment** (Text, Optional): Add any additional comments or description if necessary.
* **Category** (Text, Optional): Enter the category of the request (if applicable).
* **Priority** (Select One, Optional): Choose the priority of the request (e.g. High, Medium, Low).
* **Date Opened** (Date, Required): Enter the date the request should be opened.
* **Time Opened** (Time, Required): Enter the time the request should be opened.
* **Description** (Note, Optional): Add any additional details or description if necessary.

## Tips
* Ensure that all required fields are filled out correctly before submitting the form.
* Enter accurate and up-to-date information to ensure the IT services team can fulfill the request efficiently.
* If you have any questions or concerns, please contact the IT services team.
