# Security Incident Response Log - Help Guide
## Purpose
The Security Incident Response Log is a form designed to collect and document information about security incidents that occur within an organization. This form helps ensure that incident details are accurately recorded, making it easier to investigate and respond to incidents in a timely and effective manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing a clear and concise description of the incident in the "Incident Description" field.
2. Select the type of incident from the dropdown menu in the "Incident Type" field.
3. Review and complete all fields as relevant to the incident you are reporting.

## Field-by-Field Explanation
### Initial Reporting
* **Initial Reporting** (`initial_reporting`, text, optional): This field is for you to enter any preliminary information about the incident, such as the date and time it occurred, or any initial steps you've taken to address it.

### Incident Type
* **Incident Type** (`incident_type`, select_one, optional): Choose the type of incident you are reporting. The options provided are: Incident Type 1, Incident Type 2, and Incident Type 3. Please select the one that best describes the incident you are reporting.

### Incident Description
* **Incident Description** (`incident_description`, text, optional): Provide a clear and detailed description of the security event you are reporting. This should include as much information as possible, such as the circumstances leading up to the incident, its progression, and any actions taken to address it.

### Tips
* Be as thorough as possible when documenting the incident.
* Review and update the form regularly to reflect new information or changes in the incident's status.
* Consult your organization's security incident response policy for specific guidance on reporting and responding to security incidents.
