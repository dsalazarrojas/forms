# IT Software Project Performance Assessment - Help Guide
## Purpose
The IT Software Project Performance Assessment form is a tool used to evaluate and track the performance of IT software projects. It provides a comprehensive overview of project attributes, including title, description, performance criteria, status, team size, location, budget, scope, risk level, team experience, project phases, team members, total hours estimated, actual hours logged, total hours variance, project status change, team performance, manager suggestions, and notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project title in the first field.
2. Provide a brief description of the project in the second field.
3. Select the relevant performance criteria that apply to the project in the third field.
4. Choose the current project status from the options provided in the fourth field.
5. Enter the project start and end dates in the fifth and sixth fields, respectively.
6. Enter the team size, project location, and project budget in the seventh, eighth, and ninth fields, respectively.
7. Select the project scope, risk level, and team experience in the 10th, 11th, and 12th fields, respectively.
8. Choose the project phases that apply to the project in the 13th field.
9. Enter the team members, total hours estimated, actual hours logged, total hours variance, project status change, team performance, manager suggestions, and notes in the 14th, 15th, 16th, 17th, 18th, 19th, 20th, and 21st fields, respectively.

## Field-by-Field Explanation
* **Project Title** (`project_title`, text, required): Enter a brief title of the project that accurately represents its nature and scope.
* **Project Description** (`project_description`, text, optional): Provide a brief description of the project, including its goals, objectives, and key features.
* **Performance Criteria** (`performance_criteria`, select_multiple, optional): Select the performance criteria that apply to the project, such as quality, cost, time, and team performance.
* **Project Status** (`project_status`, select_one, optional): Choose the current status of the project from the options provided, such as In Progress, On Track, At Risk, or Delayed.
* **Project Start Date** (`project_start_date`, date, optional): Enter the date when the project started.
* **Project End Date** (`project_end_date`, date, optional): Enter the date when the project is expected to end.
* **Team Size** (`team_size`, number, optional): Enter the total number of team members working on the project.
* **Project Location** (`project_location`, text, optional): Enter the location where the project is being executed.
* **Project Budget** (`project_budget`, number, optional): Enter the total budget allocated for the project.
* **Project Scope** (`project_scope`, text, optional): Enter the scope of the project, including its objectives and key features.
* **Project Risk Level** (`project_risk_level`, select_one, optional): Choose the risk level of the project from the options provided, such as Low, Medium, or High.
* **Team Experience** (`team_experience`, number, optional): Enter the experience level of the team, including their average years of experience.
* **Project Phases** (`project_phases`, select_multiple, optional): Select the project phases that apply to the project, such as Phase 1, Phase 2, Phase 3, and so on.
* **Team Members** (`team_members`, text, optional): Enter the names and details of the team members working on the project.
* **Total Hours Estimated** (`total_hours_estimated`, number, optional): Enter the total number of hours estimated for the project.
* **Actual Hours Logged** (`actual_hours_logged`, number, optional): Enter the actual number of hours logged for the project.
* **Total Hours Variance** (`total_hours_variance`, number, optional): Calculate the total hours variance, which is the difference between the total hours estimated and actual hours logged.
* **Project Status Change** (`project_status_change`, text, optional): Enter any status changes that occurred during the project.
* **Team Performance** (`team_performance`, text, optional): Enter an assessment of the team's performance, including strengths and weaknesses.
* **Manager Suggestions** (`manager_suggestions`, text, optional): Enter any suggestions or recommendations from the project manager.
* **Notes** (`notes`, text, optional): Enter any additional notes or comments about the project.
