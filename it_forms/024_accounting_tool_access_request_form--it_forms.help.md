# Accounting Tool Access Request Form - Help Guide
## Purpose
This form is used to request access to accounting tools by employees. To ensure the process is completed correctly, please only submit one request per form. If you need to request access to multiple tools, please submit a new form for each tool.


## How To Complete This Form

### Step 1: Enter Your Information
1. Enter your name in the "Requester name" field.
2. Enter your corporate email address in the "Requester email" field.
3. Enter the name of the accounting tool you are requesting access to in the "Tool name" field.
4. Select the access level you require from the "Access level requested" dropdown menu.
5. Enter a brief explanation of why access is required in the "Business justification" field.

### Step 2: Manager Approval
1. If your manager has already approved your access request, select "False" from the "Manager approval required" dropdown menu.
2. If your manager has not approved your request, select "True" and enter your manager's name in the "Manager name" field.
3. Enter the date when you would like access to begin in the "Requested start date" field (optional).
4. If you are requesting integrations with other systems, enter the names of those systems in the "Systems to integrate" field (optional).
5. Check the box indicating if you have completed required training for the tool (if applicable).
6. Enter any additional notes or details relevant to your request in the "Additional notes" field (optional).

## Field-by-Field Explanation

* **Requester name** (text, required): Enter the name of the employee requesting access.
* **Requester email** (email, required): Enter the corporate email address of the employee requesting access.
* **Tool name** (text, required): Enter the name of the accounting tool being requested.
* **Access level requested** (select_one, required): Select the access level required from the dropdown menu:
	+ Read only
	+ Edit
	+ Approve
	+ Admin
* **Business justification** (text, required): Provide a brief explanation of why access is required.
* **Manager approval required** (select_one, required): Select "True" if your manager has not approved your request or "False" if your manager has already approved your request.
* **Manager name** (text, optional): Enter the name of your manager if you selected "True" for "Manager approval required".
* **Requested start date** (date, optional): Enter the date when you would like access to begin.
* **Systems to integrate** (text, optional): Enter the names of any systems that need to be integrated with the tool.
* **Training completed** (select_one, required): Check the box indicating if you have completed required training for the tool.
* **Additional notes** (text, optional): Enter any additional details or notes relevant to your request.

## Tips
* Please ensure you have completed required training for the tool before submitting this form.
* Only request access to one tool per form.
* Your request will be reviewed and approved by your manager and the accounting team.
