# weekly_audio_visual_checklist - Help Guide
## Purpose
The "weekly_audio_visual_checklist" is a form used to collect information on the status of rooms with audio-visual equipment in an institution. It helps in monitoring and updating the status of these rooms for better management and maintenance.

## How To Complete This Form
1. Select all the rooms you'd like to check on the "Check Rooms" page.
2. Provide the current status of the room's issue tracker, if any, in the "Issue Tracker" field.
3. Select the current status of the room's audio-visual equipment, either "Active" or "Inactive", in the "Rooms Status" field.
4. Briefly describe any issues or problems with the room's audio-visual equipment in the "Issue Description" field.
5. Indicate if the room's sign-offs are complete, either "Yes" or "No", in the "Sign Offs" field.

## Field-by-Field Explanation

* **Check Rooms (select_multiple)**: Select all the rooms with audio-visual equipment you'd like to check.
* **Issue Tracker (date)**: Enter the current date when issues or problems were encountered with the room's audio-visual equipment.
* **Rooms Status (select_one)**: Choose the current status of the room's audio-visual equipment, either "Active" if it's operational or "Inactive" if not.
* **Issue Description (text)**: Provide a brief description of any issues or problems with the room's audio-visual equipment.
* **Sign Offs (select_multiple)**: Indicate if the sign-offs for the room's audio-visual equipment are complete, either "Yes" if done or "No" otherwise.

## Tips
* Make sure to select only the rooms with audio-visual equipment that you'd like to check.
* Enter the exact date for issues or problems encountered with the room's audio-visual equipment.
* Be concise while describing any issues or problems with the room's audio-visual equipment.
* Indicate the completion status of sign-offs clearly.
