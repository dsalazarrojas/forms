1. **Start by filling out the form title** (`form-title`, text, optional): Enter a brief title for your form, if desired.

4. **Enter Total Dependent Securities (TDS)** (`form-tds`, text, optional): Input the total TDS value, if applicable.
5. **Enter PAN Card Number** (`form-pancard`, text, optional): Enter your PAN card number, if required.
6. **Bank Reconciliation** (`form-bank-reconciliation`, text, optional): Enter bank reconciliation details, if necessary.
7. **Debtors/Creditors** (`form-debtors-creditortors`, text, optional): Input debtors/creditors information, if required.
8. **GST** (`form-gst`, text, optional): Enter GST details, if applicable.
9. **Input Tax Registration** (`form-itr`, text, optional): Enter input tax registration details, if needed.
10. **TDS Filing** (`form-tds-filing`, text, optional): Enter TDS filing information, if required.
11. **Maintain Day Book** (`form-maintain-day-book`, text, optional): Input day book maintenance details, if necessary.
