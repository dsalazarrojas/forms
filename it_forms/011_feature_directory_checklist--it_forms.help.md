# feature_directory_checklist - Help Guide
## Purpose
This form is used to track and assess the status of a specific feature in a software or project context.

## How To Complete This Form
To complete this form, simply select the correct status and completion details for your feature. You can choose one directory option for "Directory" and select multiple status options for "Status".

## Field-by-Field Explanation
### Directory (<id: 1>, <name: directory>)
* **Directory**: Select the correct directory for your feature. Options are "Yes" and "No".

### Status (<id: 2>, <name: status>)
* **Status**: Select one or multiple status options for your feature. Options are "Active" and "Inactive".

### Notes (<id: 3, <name: notes>)
* **Notes**: Enter any additional notes or comments about your feature. This is a free-text field for any information you want to keep track of.

### Progress (<id: 4, <name: progress>)
* **Progress**: Enter the current progress percentage of your feature, if applicable.

### Date Completed (<id: 5, <name: date_completed>)
* **Date Completed**: If your feature has been completed, select the date it was completed.

### Date Started (<id: 6, <name: date_started>)
* **Date Started**: Enter the date when your feature started.

### Time Completed (<id: 7, <name: time_completed>)
* **Time Completed**: If your feature has been completed, enter the time it was completed.

### Time Started (<id: 8, <name: time_started>)
* **Time Started**: Enter the time when your feature started.

## Tips
* Make sure to only create a new entry for a new feature.
* If you're unsure about any field, contact the relevant team members or the project lead for clarification.
* Keep your entries up-to-date and accurate to ensure easy tracking and comparison of progress.
