# Application Schema Submission Form - Help Guide
## Purpose
This form is designed to collect application schema information from submitters, which will be used to support the development and implementation of data systems. Please ensure you have the necessary permissions and authority to submit this schema information on behalf of your team or department.

## How To Complete This Form
1. **Submitter Information**: Fill in your contact details, including your name, email address, and team or department. Please ensure your information is accurate and up-to-date.
2. **Schema Details**: Provide a brief description of the schema you are submitting, including its name, version, and purpose. Be as concise as possible while still providing enough information for the review process.
3. **Schema Specifications**: If applicable, attach any relevant schema specifications, such as a SQL DDL or entity-relationship diagram.
4. **Submission Details**: Answer the questions regarding submission format, documentation attachment, test data inclusion, and consent to schema review and feedback.
5. **Review and Submit**: Review your information for accuracy, then submit the form.

## Field-by-Field Explanation

### 1. **Submitter Information** (`id: 2`):
• `Submitter Name`: Enter your full name as you would like to be displayed in the review process.
• `Email Address`: Enter your valid email address for any subsequent communications regarding this schema.
• `Team or Department`: Specify the team or department that owns this schema submission.

### 2. **Schema Details** (`id: 6`):
• `Schema Name`: Provide a brief and descriptive name for this schema submission.
• `Schema Version`: Enter the version number of the schema if applicable.
• `Purpose of Schema`: Describe the purpose of this schema in a concise manner.

### 3. **Schema Specifications** (`id: 11`):
• Attach any relevant schema specifications if not already provided as part of the submission.

### 4. **Submission Details** (`id: 17`):
• `Schema Format`: Select the format of the schema you are submitting (e.g., SQL DDL, JSON Schema, YAML, etc.).
• `Is documentation attached?`: Indicate if documentation is attached to this submission.
• `Test data included?`: Indicate if test data is included with this submission.
• `I consent to schema review and feedback`: Confirm your consent for schema review and feedback.

### 5. **Schema Submission** (`id: 14`, `id: 15`):
• `Describe key relationships and constraints`: Provide a description of the schema's relationships and constraints.
• `Performance Requirements`: Describe any performance requirements of the schema.

### 6. **Schema Size and Data Volume** (`id: 12`, `id: 13`):
• `Number of Tables/Collections`: Enter the number of tables or collections in this schema.
• `Estimated Data Volume`: Select the estimated data volume of the schema.
