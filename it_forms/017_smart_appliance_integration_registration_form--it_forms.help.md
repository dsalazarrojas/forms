# Smart Appliance Integration Registration Form - Help Guide
## Purpose
This form is used to register smart appliance integrations. It collects information about the device being integrated, the user, and other relevant details to manage and configure the integration.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: smart_appliance_device, user_email, device_type, device_password, user_phone, smart_appliance_integration_type, and form_completion_date, form_completion_time, submitted_by, submitted_at, and submitted_time.
2. Select the correct options for device type and submitted_by fields.
3. Enter any additional notes if necessary.
4. Review and agree to the terms and conditions by selecting "Yes, I agree to the terms" in the smart_appliance_integration_agreement field.

## Field-by-Field Explanation
* **Smart Appliance Integration Registration** (1, text, required): Enter a brief description of the integration.
* **Smart Appliance Device** (2, text, required): Enter the name of the smart appliance device being integrated.
* **User Email** (3, email, required): Enter your email address.
* **Device Type** (4, select_one, required): Select the type of device being integrated (e.g., Smart Speaker, Smart TV, etc.).
* **Device IP Address** (5, text, optional): Enter the IP address of the device (if applicable).
* **Device Password** (6, text, required): Enter the password for the device.
* **Smart Appliance Model** (7, text, optional): Enter the model number of the smart appliance device (if applicable).
* **User Phone** (8, text, required): Enter your phone number.
* **Smart Appliance Serial Number** (9, number, optional): Enter the serial number of the smart appliance device (if applicable).
* **Smart Appliance Integration Type** (10, text, required): Select the type of integration being done (e.g., smart home, smart office, etc.).
* **Smart Appliance Integration Notes** (11, note, optional): Enter any additional notes about the integration.
* **Smart Appliance Integration Agreement** (12, select_multiple, required): Select "Yes, I agree to the terms" to agree to the terms and conditions.
* **Smart Appliance Integration Comments** (13, note, optional): Enter any additional comments about the integration.
* **Assigned User** (14, select_one, optional): Select the user who will be assigned to manage the integration (e.g., chatjimmy, etc.).
* **Assigned User Email** (15, email, optional): Enter the email address of the assigned user (if applicable).
* **Assigned User Phone** (16, text, optional): Enter the phone number of the assigned user (if applicable).
* **Assigned User Notes** (17, note, optional): Enter any additional notes about the assigned user.
* **Assigned User Comments** (18, note, optional): Enter any additional comments about the assigned user.
* **Form Completion Date** (19, date, required): Enter the date of form submission.
* **Form Completion Time** (20, time, required): Enter the time of form submission.
* **Submitted By** (21, select_one, required): Select the person submitting the form (e.g., chatjimmy, etc.).
* **Submitted At** (22, date, required): Enter the date of submission.
* **Submitted Time** (23, time, required): Enter the time of submission.
* **Submitted By** (24, email, optional): Enter the email address of the person submitting the form (if applicable).
* **Submitted At** (25, date, optional): Enter the date of submission (if applicable).
