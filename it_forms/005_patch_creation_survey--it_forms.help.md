# patch creation survey - Help Guide
## Purpose
The patch creation survey is designed to collect user input on their experience with patch creation, including workflow information, communication details, tooling information, feedback, and patch information.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Answer the questions in each section of the form, providing as much detail as possible.
2.  Make sure to fill out all the required fields, marked with an asterisk (\*).
3.  If you have any questions or concerns, please contact us at form@gic.mx.

## Field-by-Field Explanation

* **Workflow Information (\*)** (Workflow Information, text, required):
    This field is for providing details about the workflow related to the patch creation process.
* **Communication Information (\*)** (Communication Information, text, required):
    This field is for providing communication details related to the patch creation process.
* **Tooling Information (\*)** (Tooling Information, text, required):
    This field is for providing tooling information related to the patch creation process.
* **Feedback** (Feedback, text, optional):
    This field is for providing feedback or comments on the patch creation process.
* **Patch Information** (Patch Information, text, optional):
    This field is for providing patch information related to the patch creation process.
* **Submit (\*)** (Submit, date, required):
    This field is for submitting the form, and you will be able to see the date and time of submission.
