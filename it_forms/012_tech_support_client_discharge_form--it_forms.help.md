# Tech Support Client Discharge Form - Help Guide
## Purpose

This form is used to document the resolution of a client's tech support ticket.

## How To Complete This Form

1.  Fill in the required fields for Client Ticket Number, Client Name, Date Ticket Started, Ticket Status, Client Satisfaction, Service Provider, and Tech Support Team.
2.  Select the status of the ticket from the options provided.
3.  Choose how the client has been satisfied with the support received.
4.  Select whether to follow up with the client or not.
5.  Check if an email has been sent to the client.
6.  Mark the form as completed.
7.  Add any additional comments if necessary.

## Field-by-Field Explanation
### Client Ticket Number
*   This field requires the client's unique ticket number, which can be found in the ticketing system.

### Client Name
*   This field is used to record the name of the client.

### Date Ticket Started
*   This field records the date the client's issue began.

### Ticket Status
*   This field must be selected from the following options:
    *   Resolved
    *   Unresolved
    *   In Progress

### Client Satisfaction
*   This field is used to gather feedback from the client, and must be selected from the following options:
    *   Satisfied
    *   Somewhat Satisfied
    *   Neutral
    *   Dissatisfied
    *   Not Satisfied

### Service Provider
*   This field requires the name of the service provider who supported the client.

### Tech Support Team
*   This field requires the name of the tech support team that supported the client.

### Next Steps
*   This field allows you to choose how to follow up with the client, and must be selected from the following options:
    *   Follow up call
    *   No follow up call
    *   Follow up call and send email

### Follow Up Call
*   This field allows you to add additional comments about the follow up call, if applicable.

### Email Sent
*   This field is used to mark whether an email has been sent to the client.

### Tech Support Client Discharge Form
*   This field is used to mark the form as completed.

### Tech Support Client Discharge Form Comments
*   This field is used to add additional comments about the client's issue.

### Other Comments
*   This field is used to add any additional comments, if necessary.

Note: This form will only be used for tickets that have been fully resolved. If a ticket is not fully resolved, please do not complete this form.
