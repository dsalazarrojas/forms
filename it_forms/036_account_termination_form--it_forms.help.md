# Account Termination Form - Help Guide
## Purpose
This form is used to document the termination of an account. It captures information about the account holder, account details, and termination reasons. The form is used to ensure a smooth and secure account closure process.

## How To Complete This Form
To complete the form, please follow these steps:

1.  Enter the account holder's information:
    *   Account Holder Full Name: Enter the name of the person associated with the account.
    *   Email Address: Enter the email address associated with the account.
    *   Phone Number: Enter the phone number associated with the account.
    *   Employee ID (if internal account): Enter the employee ID if the account is internal.
    *   Department: Enter the department associated with the account (if applicable).
2.  Enter account details:
    *   Account Username or ID: Enter the account username or ID.
    *   Account Type: Select the type of account (e.g., Email account, System or application login, VPN access, etc.).
    *   Platform or System Name: Enter the name of the platform or system associated with the account.
3.  Provide termination details:
    *   Reason for Termination: Select the reason for terminating the account (e.g., Employee resignation, Employee termination, Role change, etc.).
    *   Last Day of Access: Enter the last day of access for the account.
    *   Data Backup Required: Select whether data needs to be backed up before termination (e.g., Yes - Please back up all data, Yes - Back up selected data only, etc.).
    *   Transfer Data To (if applicable): Enter the name or email of the person to receive backed-up data.
4.  Approve the termination:
    *   Requested By: Enter the name of the person submitting this termination request.
    *   Manager Approval: Select the status of the termination request (e.g., Approved, Pending, Denied).

## Field-by-Field Explanation

*   **Account Holder Full Name** (`account_holder_name`, text, required): Enter the name of the person associated with the account.
*   **Email Address Associated with the Account** (`email`, email, required): Enter the email address associated with the account.
*   **Phone Number** (`phone_number`, text, required): Enter the phone number associated with the account.
*   **Employee ID (if internal account)** (`employee_id`, text, optional): Enter the employee ID if the account is internal.
*   **Department** (`department`, text, optional): Enter the department associated with the account (if applicable).
*   **Account Username or ID** (`account_username`, text, required): Enter the account username or ID.
*   **Account Type** (`account_type`, select_one, required): Select the type of account (e.g., Email account, System or application login, VPN access, etc.).
*   **Platform or System Name** (`platform_or_system`, text, required): Enter the name of the platform or system associated with the account.
*   **Reason for Termination** (`reason_for_termination`, select_one, required): Select the reason for terminating the account (e.g., Employee resignation, Employee termination, Role change, etc.).
*   **Last Day of Access** (`last_day_of_access`, date, required): Enter the last day of access for the account.
*   **Is Data Backup Required Before Termination** (`data_backup_required`, select_one, required): Select whether data needs to be backed up before termination (e.g., Yes - Please back up all data, Yes - Back up selected data only, etc.).
*   **Transfer Data To (if applicable)** (`data_transfer_to`, text, optional): Enter the name or email of the person to receive backed-up data.
*   **Requested By** (`requestor_name`, text, required): Enter the name of the person submitting this termination request.
*   **Manager Approval** (`manager_approval`, select_one, required): Select the status of the termination request (e.g., Approved, Pending, Denied).

## Tips

*   Please ensure that all required fields are completed accurately and thoroughly.
*   If you are unsure about any field, please reach out to the relevant authorities or your supervisor for clarification.
*   Be sure to review the form carefully before submitting it to ensure it is complete and accurate.
