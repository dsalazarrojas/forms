# WhatsApp Message Sending Form - Help Guide
## Purpose
This form is designed to create and send WhatsApp messages to a recipient. It allows users to input their message request, schedule outreach, select a date and time for the outreach, and choose a message type. The form is used to streamline and facilitate communication with recipients through WhatsApp.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your message request in the "Message" field.
2. If you have a specific schedule for the outreach, select the corresponding option from the "Schedule Outreach" dropdown menu.
3. Choose a date for the outreach from the "Outreach Date" field.
4. Select a time for the outreach from the "Outreach Time" field.
5. Choose the type of message to be sent from the "Message Type" dropdown menu.
6. Enter the recipient's phone number in the "Recipient Phone" field.
7. Enter your phone number in the "Sender Phone" field.
8. Finally, enter the message body in the "Message Body" field.

## Field-by-Field Explanation
* **Message** (`message_request`, text, optional): Enter a brief message request to be sent to the recipient.
* **Schedule Outreach** (`schedule_outreach`, select_one, optional): Select a schedule for the outreach, if applicable.
* **Outreach Date** (`outreach_date`, date, optional): Choose a date for the outreach.
* **Outreach Time** (`outreach_time`, time, optional): Select a time for the outreach.
* **Message Type** (`message_type`, select_one, optional): Choose the type of message to be sent to the recipient.
* **Recipient Phone** (`recipient_phone`, text, optional): Enter the phone number of the recipient to whom the message will be sent.
* **Sender Phone** (`sender_phone`, text, optional): Enter your phone number to be used as the sender's number for the message.
* **Message Body** (`message_body`, text, optional): Enter the content of the message to be sent to the recipient.
