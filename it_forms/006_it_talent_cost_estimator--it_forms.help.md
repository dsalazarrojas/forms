# IT Talent Cost Estimator - Help Guide
## Purpose
The IT Talent Cost Estimator form is a tool used to estimate the cost of hiring and managing IT talent. It helps IT teams and project managers to quickly calculate the cost of various roles, locations, and duration of projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the role type(s) that you want to estimate the cost for.
2. Enter the location where the talent will be working.
3. Enter the duration of the project in number of days or months.

## Field-by-Field Explanation
* **Role Type** (Role Type, Select Multiple, Required: False):
	+ This field allows you to choose one or multiple roles for which you want to estimate the cost.
	+ Choose from the options: Software Engineer, Data Scientist, and Product Manager.
* **Location** (Location, Text, Required: False):
	+ Enter the location where the talent will be working.
	+ This field is used to adjust the cost estimate based on location-specific factors.
* **Duration** (Duration, Number, Required: False):
	+ Enter the duration of the project in number of days or months.
	+ This field will impact the estimated cost based on project length.
