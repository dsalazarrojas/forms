# personal_cyber_security_checklist - Help Guide
## Purpose
The personal cyber security checklist is a self-assessment tool designed to help users identify potential vulnerabilities in their personal cyber security habits and provide guidance on how to improve them.

## How To Complete This Form
To complete this form, please answer each question honestly and thoroughly. For each field, select the most accurate response based on your current habits and practices. If you're unsure about any question, please choose the option that best describes your situation.

## Field-by-Field Explanation

* **Password Strength** (Password Strength): Enter your password strength, with "Very Strong" indicating a password that is at least 12 characters long, contains special characters, and is not reused.
* **Two Factor Auth** (Two Factor Auth): Select "Yes" if you use two-factor authentication (2FA) for any accounts, including Google Authenticator, SMS, or a security app.
* **Sensitive Info** (Sensitive Info): Enter any sensitive information you store online, such as financial information or personal identifiable data.
* **Backup Important Data** (Backup Important Data): Select "Very Important" if you regularly back up important data, such as financial records or personal documents.
* **Secure Devices** (Secure Devices): Select "Yes" if you have secure devices, such as password-protected devices or encrypted storage.
* **Secure Your Network** (Secure Your Network): Select "Yes" if you secure your network with a firewall, VPN, or strong password.
* **Account Security** (Account Security): Select "Yes" if you have strong account security measures in place, such as two-factor authentication or a strong password.
* **Password** (Password): Select "Yes" if you use unique and complex passwords for all accounts.
* **Update Software** (Update Software): Select "Yes" if you keep your software up to date, including operating systems, browsers, and security software.
* **User Account** (User Account): Select "Yes" if you have a strong understanding of your user account settings and permissions.
* **Device Locks** (Device Locks): Select "Yes" if you enable device locks, such as screen locks or biometric authentication.
* **Password Manager** (Password Manager): Enter your password manager, if you use one.
* **Secure Notes** (Secure Notes): Enter any secure notes or reminders you have in place, such as a password vault or secure note-taking app.
* **Reuse Passwords** (Reuse Passwords): Select "Yes" if you reuse passwords across multiple accounts.
