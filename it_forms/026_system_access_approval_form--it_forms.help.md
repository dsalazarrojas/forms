# System Access Approval Form - Help Guide

## Purpose
The System Access Approval Form is used to request and track access to company systems, applications, and other resources. It is designed to ensure that all necessary information and approvals are documented, improving the efficiency and transparency of the approval process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (*). These fields are:
	* Requester (id: 2)
	* Requester Department (id: 3)
	* Requester Job Title (id: 4)
	* Requester Email (id: 5)
	* Requester Phone (id: 6)
	* Request Date (id: 7)
	* Request Status (id: 9)
	* Approving Manager (id: 21)
	* Approving Manager Department (id: 23)
	* Approving Manager Email (id: 22)
	* Approving Manager Phone (id: 24)
2. Fill in the optional fields, such as Requesting Manager Notes (id: 19) and Approver Notes (id: 16), if needed.
3. Select the Request Status (id: 9) to indicate the current status of the request.
4. Select the Approver (id: 12) and Approver Department (id: 13) from the available options, if applicable.
5. Enter the Approval Date (id: 17), Expiration Date (id: 18) and Reviewd By (id: 25), which are date fields.
6. Review and update the form as necessary, making sure all required fields are filled and the request status is accurate.

## Field-by-Field Explanation

* **Requester (id: 2)**: The person making the request for system access.
* **Requester Department (id: 3)**: The department of the person making the request.
* **Requester Job Title (id: 4)**: The job title of the person making the request.
* **Requester Email (id: 5)**: The email address of the person making the request.
* **Requester Phone (id: 6)**: The phone number of the person making the request.
* **Access Request Date (id: 7)**: The date the request was made.
* **Request Status (id: 9)**: The current status of the request, which can be Pending, Approved, Denied, Expired, or Completed.
* **Approver (id: 12)**: The person approving the system access.
* **Approver Department (id: 13)**: The department of the person approving the system access.
* **Approver Phone (id: 14)**: The phone number of the person approving the system access.
* **Approver Email (id: 15)**: The email address of the person approving the system access.
* **Approver Notes (id: 16)**: Optional notes for the approver.
* **Approval Date (id: 17)**: The date the approval was made.
* **Expiration Date (id: 18)**: The date the system access will expire.
* **Requesting Manager Notes (id: 19)**: Optional notes from the manager of the person making the request.
* **Approving Manager Notes (id: 20)**: Optional notes from the manager of the person approving the system access.
* **Requesting Manager (id: 21)**: The manager of the person making the request.
* **Requesting Manager Department (id: 23)**: The department of the person approving the system access.
* **Requesting Manager (id: 22)**: The email address of the manager of the person making the request.
* **Requesting Manager Phone (id: 24)**: The phone number of the manager of the person making the request.
* **Reviewed By (id: 25)**: The person reviewing the access request.

This form is used to ensure that access to company systems and resources is properly documented and approved. The fields are designed to provide all necessary information for the approval process and the tracking of access requests.
