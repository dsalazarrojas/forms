# Guest Access Restriction Request Form - Help Guide

## Purpose

This form is used to request restriction of guest access for a specific period. Please fill out the form with accurate and complete information to help us process your request efficiently.

## How To Complete This Form

1. Fill out the form with the requested information, ensuring that all required fields are completed.
2. Select the appropriate restriction type from the options provided.
3. Choose the start and end dates for the restriction period.
4. Provide a valid reason for the restriction request.
5. Enter the ID of the person approving the request.

## Field-by-Field Explanation

* **guest_access_restriction_request_form** (text, optional): Enter a brief description of the reason for the restriction request.
* **name** (text, optional): Enter the name of the person or group for which access is being restricted.
* **restriction_type** (select_one, optional): Choose the type of restriction you are requesting (e.g., type1, type2, type3).
* **start_date** (date, optional): Enter the date from which the restriction should start.
* **end_date** (date, optional): Enter the date until which the restriction should be in place.
* **reason** (note, optional): Provide a detailed explanation for the restriction request.
* **approver_id** (number, optional): Enter the ID of the person approving the request.

## Tips

* Please ensure that all required fields are filled out to avoid delays in processing your request.
* If you have any questions or concerns about the form or the process, contact our support team for assistance.
* We review each request carefully; incomplete or inaccurate information may result in delays or requests being declined.
* Do not submit multiple requests for the same purpose; each request will be reviewed on a case-by-case basis.
