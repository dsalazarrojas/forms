# IT Helpdesk Resolution Verification Form - Help Guide
## Purpose
This form is used to verify the resolution of IT issues reported to the helpdesk. It helps ensure that issues are properly addressed and closed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the resolved issues you have reviewed.
2. Choose the relevant issue category.
3. Confirm if the resolution satisfied you.
4. Provide a brief description of the resolution.
5. Add any additional comments about the resolution.
6. Choose the outcome of the issue.

## Field-by-Field Explanation
### 1. Resolved Issues (`submitted_resolution_form`, select_multiple)
Select all the resolved issues you have reviewed.
- This field allows you to choose which issues are resolved.

### 2. Issue Category (`issue_category`, select_one)
Choose the relevant issue category for the issue you are verifying.
- This field categorizes the issue to help track its type.

### 3. Resolution Satisfied (`resolution_satisfied`, select_one)
Confirm if the resolution satisfied you.
- This field ensures that you are satisfied with the resolution.

### 4. Resolution Description (`resolution_description`, text)
Provide a brief description of the resolution.
- This field is for adding any notes or details about the resolution.

### 5. Resolution Comments (`resolution_comments`, text)
Add any additional comments about the resolution.
- This field is for providing any further information about the resolution.

### 6. Resolution Outcome (`resolution_outcome`, select_one)
Choose the outcome of the issue.
- This field indicates the status of the issue, whether it was resolved, unresolved, or pending.
