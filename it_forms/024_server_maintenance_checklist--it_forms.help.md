# Server Maintenance Checklist - Help Guide
## Purpose
This form is designed for IT teams to perform routine server maintenance checks to identify potential issues or maintenance needs.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each section carefully and answer all questions honestly.
2. For "check_all_systems" (Page 1), select all the systems that require maintenance or checks.
3. For the remaining pages, enter any comments or notes about the status of each system.
