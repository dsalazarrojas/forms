# it_infrastructure_audit_verification_form - Help Guide
## Purpose
This form is used to collect information about the current state of an organization's IT infrastructure.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each field based on your current situation. You can choose multiple options for fields that allow multiple selections.
2. Be as accurate as possible. Incomplete or incorrect information can lead to incorrect results.
3. Save and submit your responses when you are finished.

## Field-by-Field Explanation
* **it_infrastructure_audit_status**: This is a text field where you can briefly describe the current status of your IT infrastructure.
* **servers_used**: This field asks about the type of servers used in your infrastructure. Select all that apply from the options.
	+ AWS: This is a cloud-based server platform.
	+ Azure: This is another cloud-based server platform.
	+ Google Cloud Platform: This is a cloud-based server platform.
	+ On-premises: This refers to servers located within the organization's physical premises.
	+ Other: This is for any other type of server not listed above.
* **network_segments**: This is a note field where you can provide any relevant information about network segments.
* **firewalls**: This field is currently a text field, but it seems to be intended for a select_multiple or select_one field. If you are certain about the intent, please provide the correct type. If not, please provide a brief description instead.
* **virtualization**: This field asks about the type of virtualization used in your infrastructure. Select one option from the list.
	+ Virtual: This is used for virtualization technologies such as VMware, Hyper-V, or KVM.
	+ Physical: This refers to non-virtualized servers.
	+ No Virtualization: This is for infrastructure that does not use virtualization.
* **backup**: This field is a date field, likely for the last backup date.
* **disaster_recovery**: This field asks about the disaster recovery process in place. Select one option from the list.
	+ True: This indicates that a disaster recovery process is in place.
	+ False: This indicates that no disaster recovery process is in place.
* **monitoring**: This field is a text field where you can describe the monitoring process used in your infrastructure.
* **compliance**: This field asks about compliance with industry standards and regulations. Select all that apply from the list.
	+ Compliance 1: This is for compliance with specific regulations or standards.
	+ Compliance 2: This is for another specific regulation or standard.
	+ Compliance 3: This is for yet another specific regulation or standard.
	+ Compliance 4: This is for another specific regulation or standard.
* **remediation**: This is a note field where you can provide any information about remediation processes.
* **it_infrastructure_changes**: This field is a text field where you can describe any changes made to the infrastructure.
* **it_infrastructure_security**: This field asks about the security level of the infrastructure. Select one option from the list.
	+ True: This indicates that the infrastructure has high security.
	+ False: This indicates that the infrastructure does not have high security.
* **it_infrastructure_compliance**: This field asks about compliance with industry standards and regulations. Select all that apply from the list.
	+ Compliance 1: This is for compliance with specific regulations or standards.
	+ Compliance 2: This is for another specific regulation or standard.
	+ Compliance 3: This is for yet another specific regulation or standard.
	+ Compliance 4: This is for another specific regulation or standard.
* **it_infrastructure_backup**: This field asks about the backup process. Select all that apply from the list.
	+ Backup 1: This is for backup of specific data or systems.
	+ Backup 2: This is for another specific data or system backup.
	+ Backup 3: This is for yet another specific data or system backup.
* **it_infrastructure_disaster_recovery**: This field asks about the disaster recovery process. Select one option from the list.
	+ True: This indicates that a disaster recovery process is in place.
	+ False: This indicates that no disaster recovery process is in place.
* **it_infrastructure_monitoring**: This field asks about the monitoring process. Select one option from the list.
	+ True: This indicates that monitoring is in place.
	+ False: This indicates that monitoring is not in place.
* **it_infrastructure_security_patches**: This field is a text field where you can describe any security patches applied to the infrastructure.
* **it_infrastructure_security_updates**: This field is a text field where you can describe any security updates applied to the infrastructure.
* **it_infrastructure_patches**: This field is a text field where you can describe any infrastructure patches applied.
* **it_infrastructure_updates**: This field is a text field where you can describe any infrastructure updates applied.
* **it_infrastructure_decommissioning**: This field asks about the decommissioning process. Select one option from the list.
	+ True: This indicates that infrastructure is being decommissioned.
	+ False: This indicates that infrastructure is not being decommissioned.
* **it_infrastructure_remediation**: This is a note field where you can provide any information about remediation processes.
* **it_infrastructure_changes**: This field is a text field where you can describe any changes made to the infrastructure.
* **comments**: This field is a text field where you can provide any additional comments or feedback.
* **submit**: This is the submit button to finalize your responses.
