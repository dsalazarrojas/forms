# Faculty Engagement Data Access Request - Help Guide
## Purpose
This form is used to request access to faculty engagement data. The faculty engagement data includes information such as start and end dates, duration, and policy acknowledgment for a specific time period.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the "Faculty Request" field with a clear and concise description of the purpose of your request.
2. Select the start date of the period for which you are requesting data.
3. Select the end date of the period for which you are requesting data.
4. Specify the duration of the data you are requesting.
5. Confirm that you have read and understood the policy acknowledgment by checking the box.

## Field-by-Field Explanation
* **Faculty Request (<font size="small">text</font>)** (`faculty_request`, text, required): A brief and clear description of the purpose of your request.
* **Purpose (<font size="small">text</font>)** (`purpose`, text, required): A description of the purpose of your request.
* **Start Date (<font size="small">date</font>)** (`start_date`, date, required): The start date of the period for which you are requesting data.
* **End Date (<font size="small">date</font>)** (`end_date`, date, required): The end date of the period for which you are requesting data.
* **Duration (<font size="small">number</font>)** (`duration`, number, required): The duration of the data you are requesting.
* **Policy Acknowledgment (<font size="small">text</font>)** (`policy_acknowledgment`, text, required): Confirm that you have read and understood the policy acknowledgment.

## Tips
* Make sure to provide a clear description of your request to help the data team process it efficiently.
* Only request data for specific instances and not for routine or recurring requests.
* Review the policy acknowledgment carefully to ensure you understand your responsibilities and obligations.
