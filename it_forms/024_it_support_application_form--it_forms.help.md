# it_support_application_form - Help Guide
## Purpose
This form is used to capture information from customers or users who are requesting support for an "it" related issue. It's intended to gather details about the issue and contact information of the person submitting the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the issue in the "Issue Description" field (page 3).
2. Select "Yes" or "No" to indicate if you have already contacted us about this issue (page 4).
3. Choose how you would like to be contacted (page 5).
4. Enter your email address (page 6) and phone number (page 7).
5. Add any additional notes or comments about your issue (page 8).
6. Select the date and time you are submitting this request (page 9).
7. Finally, click the submit button to send your support request.

## Field-by-Field Explanation

* **Issue Description** (`issue_description`, text, required): A brief description of the issue you are experiencing.
* **Contact Method** (`contact_method`, select_one, required): How would you like to be contacted (e.g., "Yes" for phone call, "No" for email).
* **Contact Email** (`contact_email`, email, required): Enter your email address so we can get in touch with you.
* **Contact Phone** (`contact_phone`, text, required): Enter your phone number so we can call you.
* **Contact Note** (`contact_note`, note, required): Add any additional notes or comments about your issue.
* **Date** (`date`, date, required): The date you are submitting this request.
* **Time** (`time`, time, required): The time you are submitting this request.
* **Submitted By** (`submitted_by`, text, required): Your name or identifier so we can track this request.

## Tips
- Make sure to provide a clear and concise description of your issue.
- Ensure your contact information is accurate and up-to-date.
- If you have any additional information or attachments related to your issue, feel free to add them to the "Contact Note" field.
