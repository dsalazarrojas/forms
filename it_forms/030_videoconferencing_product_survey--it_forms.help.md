# Videoconferencing Product Survey - Help Guide
## Purpose
This form is designed to gather feedback and suggestions from customers about their videoconferencing experience and preferences. Your responses will help us improve our product and services.

## How To Complete This Form
To complete this form, simply select the appropriate options and answer the required fields. For fields with a dropdown menu, choose one option per selection. You can also add additional comments below if you have more to say.

## Field-by-Field Explanation
* **Product Survey** (`product_survey`, Note, Optional): This field is for any comments or thoughts you may have about our product.
* **Videoconferencing Features** (`videoconferencing_features`, Select One, Optional): Please select the feature that best describes your videoconferencing experience:
	+ Option 1: Excellent
	+ Option 2: Average
	+ Option 3: Poor
* **Survey Questions** (`survey_questions`, Select Multiple, Optional): Select all that apply:
	+ Option 4: Yes
	+ Option 5: No
* **Feedback** (`feedback`, Text, Optional): Share any thoughts or comments about your videoconferencing experience.
* **Email** (`email`, Email, Optional): Enter your email address for us to reach out if we need more information about your response.
* **Phone** (`phone`, Text, Optional): If you'd like to provide a phone number for us to contact you.
* **Videoconferencing Issues** (`videoconferencing_issues`, Select One, Optional): Please select the issue you experienced:
	+ Option 6: Option 6
	+ Option 7: Option 7
* **Product Improvement** (`product_improvement`, Note, Optional): Any suggestions for improvement.
* **Product Roadmap** (`product_roadmap`, Select Multiple, Optional): Select all that apply:
	+ Option 8: Option 8
	+ Option 9: Option 9
* **Additional Comments** (`additional_comments`, Text, Optional): Add any additional comments or thoughts.
