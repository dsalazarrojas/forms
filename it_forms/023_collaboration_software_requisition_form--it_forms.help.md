# Collaboration Software Requisition Form - Help Guide
## Purpose
The purpose of this form is to gather necessary information for a software requisition within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name as the requester.
2. Select the department making the software request.
3. Enter the name of the software or tool being requested.
4. Choose the license type needed (Single user, Team, or Enterprise).
5. Provide a business case for why the software is needed.
6. If applicable, enter the preferred vendor.
7. If applicable, enter the cost center or budget line (budget code).
8. If applicable, enter the date by which the software is required.
9. If necessary, list the approvers required for approval.

## Field-by-Field Explanation
### Requester Name (Required)
* **Requester name**: Enter the full name of the person submitting the software requisition.

### Department (Required)
* **Department**: Select the team making the software request.

### Software Name (Required)
* **Software name**: Enter the name of the software or tool being requested.

### License Type (Required)
* **License type needed**: Choose the license type that best fits the request (Single user, Team, or Enterprise).

### Justification (Required)
* **Business case for the tool**: Provide a brief explanation of why the software is needed within the organization.

### Preferred Vendor (Optional)
* **Vendor name**: If applicable, enter the name of the preferred vendor.

### Budget Code (Optional)
* **Cost center or budget line**: If applicable, enter the cost center or budget line.

### Required By Date (Optional)
* **Required by date**: If applicable, enter the date by which the software is required.

### Approvals Needed (Optional)
* **List approvers required**: If necessary, list the approvers required for approval.

## Tips
* Please ensure that all required fields are filled out.
* If you are unsure about the license type or any other field, do not hesitate to ask the IT department for guidance.
* This form will be reviewed and approved by the IT department before proceeding with the software requisition.
