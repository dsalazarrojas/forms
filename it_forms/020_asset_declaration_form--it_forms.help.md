# Asset Declaration Form - Help Guide
## Purpose
This form is used to collect information about your financial assets, including real estate, vehicles, bank accounts, investments, and other valuable items. Please fill out this form accurately and honestly to ensure compliance with company policies and tax reporting requirements.

## How To Complete This Form
1. Fill out the form in a quiet and comfortable setting with all the necessary information and resources available to you.
2. Be honest and accurate in your responses to each question.
3. Do not leave any fields blank if you are unsure of an answer.
4. Use the provided options for each field and select the correct answer.
5. Review and verify the form before submission.

## Field-by-Field Explanation
* **Employee Name**:
	+ A text field to input your full legal name.
* **Employee ID**:
	+ A text field to input your staff identification number.
* **Department**:
	+ A text field to input your work department.
* **Position Title**:
	+ A text field to input your job title.
* **Declaration Date**:
	+ A date field to input the date of this declaration.
* **Declaration Type**:
	+ Select the type of declaration (Initial Declaration, Annual Update, Change in Status, or Termination Declaration).
* **Do You Own Real Estate**:
	+ Select 'Yes' if you own real estate, 'No' if you do not.
* **Real Estate Details**:
	+ A text field to describe your real estate properties.
* **Number of Vehicles Owned**:
	+ A number field to input the number of vehicles you own.
* **Vehicle Details**:
	+ A text field to describe your vehicle properties.
* **Number of Bank Accounts**:
	+ A number field to input the number of bank accounts you have.
* **Total Bank Balance**:
	+ A number field to input your combined bank balance.
* **Do You Have Investment Accounts**:
	+ Select 'Yes' if you have investment accounts, 'No' if you do not.
* **Total Investment Value**:
	+ A number field to input the approximate value of your investments.
* **Retirement Accounts**:
	+ Select all types of retirement accounts you have (401k, 403b, IRA, Roth IRA, Pension Plan, or None).
* **Do You Have Business Interests**:
	+ Select 'Yes' if you have business interests, 'No' if you do not.
* **Business Interest Details**:
	+ A text field to describe your business interests.
* **Valuable Personal Property**:
	+ Select 'Yes - Over $10,000', 'Yes - Under $10,000' or 'No' to indicate the value of your valuable personal property.
* **Do You Own Intellectual Property**:
	+ Select 'Yes' if you own intellectual property, 'No' if you do not.
* **Intellectual Property Details**:
	+ A text field to describe your intellectual property assets.
* **Do You Have Outstanding Loans**:
	+ Select 'Yes' if you have outstanding loans, 'No' if you do not.
* **Loan Details**:
	+ A text field to describe your outstanding debts.
* **Credit Card Debt Range**:
	+ Select the approximate range of your credit card debt.
* **Other Assets**:
	+ A text field to list any other assets not mentioned.
* **I Certify This Declaration Is Accurate**:
	+ Select 'Yes I Certify' to confirm the accuracy of this declaration.
* **Employee Signature**:
	+ A text field to input your name for signing.
* **Witness Name**:
	+ A text field to input the witness's name (if required).
* **Witness Signature**:
	+ A text field to input the witness's signature (if required).

# Tips
* Please review this form carefully before submission.
* Answer each question honestly and accurately.
* If you are unsure of an answer, do not leave it blank.
* If you need help or have questions, contact your HR representative.
* This form is subject to change based on company policies and tax reporting requirements.
