# it third party maintenance service request - Help Guide
## Purpose
This form is designed to collect information from vendors to request maintenance services. It is intended for internal use by your organization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the necessary information about the vendor and their contact details.
2. Provide a brief description of the maintenance request.
3. Select the priority and status of the request.
4. Choose the type of maintenance requested (if applicable).
5. Choose the assigned tool for maintenance.
6. Fill in the description of the required maintenance work.
7. Set the priority date for the maintenance request.

## Field-by-Field Explanation

- **Vendor Information (vendor_information)** 
    - A text field to fill in the name or contact information of the vendor.
    - This field is optional.

- **Contact Information (contact_information)** 
    - A text field to fill in the contact information of the person making the request.
    - This field is optional.

- **Contact Details (contact_details)** 
    - A text field to fill in any additional contact details.
    - This field is optional.

- **Maintenance Request Details (maintenance_request_details)** 
    - A text field to fill in the details of the maintenance request.
    - This field is optional.

- **Schedule Details (schedule_details)** 
    - A text field to fill in any schedule details.
    - This field is optional.

- **Priority (priority)** 
    - A dropdown menu to select the priority of the request (Critical, High, Medium, Low).
    - This field is optional.

- **Request Status (request_status)** 
    - A dropdown menu to select the current status of the request (New, In Progress, On Hold, Done).
    - This field is required.

- **Request Type (request_type)** 
    - A dropdown menu to select the type of request (Hardware, Software, Other).
    - This field is optional.

- **Assigned Tool (assigned_tool)** 
    - A dropdown menu to select the tool assigned for the maintenance (chatjimmy, other).
    - This field is required.

- **Description (description)** 
    - A text field to fill in the description of the required maintenance work.
    - This field is required.

- **Priority Date (priority_date)** 
    - A date field to select the date when the maintenance request becomes a priority.
    - This field is optional.
