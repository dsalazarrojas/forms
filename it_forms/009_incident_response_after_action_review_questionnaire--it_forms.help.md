# Incident Response After Action Review Questionnaire - Help Guide
## Purpose
The Incident Response After Action Review Questionnaire is a form used to collect information after an incident has been resolved. The purpose of this form is to support the collection of information about the incident, including its type, description, date, and outcome, to review, evaluate, and improve the response effort.

## How To Complete This Form
To complete this form, follow these steps:
- Answer each field according to your knowledge and best judgment.
- If you're unsure about any field, you can leave it blank or contact your team leader for guidance.
- Be as detailed as possible but also concise and avoid repeating information already provided in other fields.
- If you have any questions or concerns about the response effort, use the "Review Questions" field to note them.

## Field-by-Field Explanation

* **IncidentType** (Select One):
	+ Select the type of incident that occurred. Choose from the available options: None, IT incident, Network issue, Other, Security incident.
* **IncidentName** (Text, Optional):
	+ Enter a brief description of the incident. This will help to quickly identify the incident and its context.
* **IncidentDate** (Date, Optional):
	+ Enter the date of the incident. Use the format YYYY-MM-DD.
* **IncidentTime** (Time, Optional):
	+ Enter the time of the incident. Use the format HH:MM AM/PM.
* **IncidentDetails** (Text, Optional):
	+ Provide detailed description of the incident. Be as detailed as possible, but also concise.
* **TeamLeader** (Text, Optional):
	+ Enter the name of the team leader involved in the response effort.
* **TeamMembers** (Text, Optional):
	+ Enter the team members who were involved in the response effort.
* **ReviewQuestions** (Text, Optional):
	+ Enter any questions or concerns you have about the response effort. This will help to identify areas for improvement.
* **IncidentOutcome** (Select Multiple, Required):
	+ Select the outcome of the incident. Choose from the available options: Success, Partial success, Failure.
* **LessonsLearned** (Text, Optional):
	+ Enter any lessons learned from the response effort. This will help to improve future responses.
