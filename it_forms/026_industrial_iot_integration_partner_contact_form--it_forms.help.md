# industrial_iot_integration_partner_contact_form - Help Guide
## Purpose
The purpose of this form is to gather information from potential partners about their industrial IoT integration solutions. It will be used by our internal team to review and follow up with the partner accordingly.

## How To Complete This Form

To complete this form, please fill out each field accurately and thoroughly. Make sure to review all the information before submitting the form.

## Field-by-Field Explanation
- **First Name** (`first_name`, text, optional): This is your first name that will be used for communication purposes.
- **Last Name** (`last_name`, text, optional): This is your last name that will be used for communication purposes.
- **Organization** (`organization`, text, optional): This is the name of your organization that will be used to identify your company.
- **Job Title** (`job_title`, text, optional): This is your job title that will be used to understand your role in the organization.
- **Contact Email** (`contact_email`, email, optional): This is your email address that will be used for communication purposes.
- **Contact Phone** (`contact_phone`, text, optional): This is your phone number that will be used for communication purposes.
- **Partner Inquiry** (`partner_inquiry`, text, optional): This field is for any specific questions or inquiries you may have about the integration process.
- **Technical Capabilities** (`technical_capable`, text, optional): This field is for any technical capabilities or features you would like to highlight about your integration solution.
- **Industrial Automation** (`industrial_automation`, text, optional): This field is for any industrial automation related information or features of your integration solution.
- **Collaboration Lead** (`collaboration_lead`, select_one, required): Please select one of the options for collaboration lead type.
- **Lead Source** (`lead_source`, text, optional): This is the source of the lead that you would like to highlight.
- **Integration Request** (`integration_request`, text, optional): This field is for any specific integration requests you may have.
- **Lead Status** (`lead_status`, select_multiple, required): Please select all relevant lead status options.
- **Lead Date** (`lead_date`, date, optional): This is the date when you would like to start the integration process.
- **Lead Time** (`lead_time`, time, optional): This is the time when you would like to start the integration process.
- **Additional Notes** (`notes`, note, optional): This field is for any additional information you would like to share.
- **Lead Owner** (`lead_owner`, text, optional): This is the name of the lead owner that will be responsible for the partnership.
- **Lead Time** (`lead_time`, text, optional): This field is for any specific lead time requirements.
- **Lead Source** (`lead_source`, text, optional): This is the source of the lead that you would like to highlight.

## Tips
- Please make sure to fill out all required fields (Collaboration Lead and Lead Status) to ensure that we can review your form correctly.
- Make sure to be as detailed as possible when filling out the form to ensure that we can follow up with you correctly.
- If you have any specific questions or concerns, please don't hesitate to reach out to us through the partner inquiry field.
