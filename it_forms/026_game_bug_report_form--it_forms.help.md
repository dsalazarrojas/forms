# Game Bug Report Form - Help Guide
## Purpose
The Game Bug Report Form is a tool designed to help developers identify and fix issues within the game. It allows users to report bugs or problems they encounter while playing the game, providing essential information to aid in the development process.

## How To Complete This Form
To complete the Game Bug Report Form, follow these steps:
1.  Select the game mode you were experiencing the issue with.
2.  Choose the version of the game that was running when the issue occurred.
3.  Describe the issue in detail in the "Description" field.
4.  If applicable, enter any error codes related to the bug.
5.  Specify the frequency of the issue, if it's a recurring problem.
6.  Upload any relevant screenshots or videos to help developers better understand the issue.
7.  Add any additional comments that may be helpful for developers to replicate the bug.
8.  Finally, submit the form to send the report to the development team.

## Field-by-Field Explanation

*   **Game Mode**: Select the game mode that you were playing when the issue occurred. For example, "Game Mode 1" or "Game Mode 2".
*   **Version**: Choose the version of the game that was running when the issue occurred, such as "Version 1" or "Version 2".
*   **Description**: Provide a detailed description of the issue. Describe what was happening when the bug occurred.
*   **Error Code**: If applicable, enter any error codes you've received related to the bug. This can be a numeric code or a specific code phrase given to you by support.
*   **Frequency**: If the issue is recurring, indicate how often it happens.
*   **Screenshot**: If possible, upload screenshots or images that illustrate the issue you're reporting.
*   **Video**: If applicable, upload a video of the issue to help developers better understand what's happening.
*   **Comments**: Add any additional comments that may be helpful for developers to replicate the bug.
*   **Submit**: Click this button to send the report to the development team.

Note: The fields marked as "required: false" are not mandatory and you can skip them if you don't have the necessary information.
