# Fundraiser Referal Form - Help Guide
## Purpose
The Fundraiser Referal Form is used to collect information about a fundraiser, the person making the referral, and the referred individual. This form is used to create a referral document that can be used to follow up with the referred individual.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **First Name**, **Last Name**, and **Email** fields with the information about the person making the referral.
2. Fill out the **Referral Name** and **Referral Email** fields with the information about the person being referred.
3. Provide a **Description** of the referral, including any relevant details about the person being referred.
4. Select the **Category** of the referral.
5. If necessary, fill out the **Assigned Tool** field with the name of the tool assigned to the referral.
6. Optionally, you can fill out the **Form ID** field with the ID of the form used to create this referral.
7. Click "Submit" to create the referral document.

## Field-by-Field Explanation
* **First Name**: Enter the first name of the person making the referral.
* **Last Name**: Enter the last name of the person making the referral.
* **Email**: Enter the email address of the person making the referral.
* **Referral Name**: Enter the name of the person being referred.
* **Referral Email**: Enter the email address of the person being referred.
* **Description**: Provide a description of the referral, including any relevant details about the person being referred.
* **Category**: Select the category for the referral.
* **Assigned Tool**: If the referral requires a specific tool, enter the name of that tool.
* **Form ID**: If you want to track the ID of the form used to create this referral, enter it here.
* **Phone**: Enter the phone number of the person making the referral.
* **Category**: Select the category for the referral.
* **Output File**: This field is not currently used, and can be left blank.

## Tips
* Make sure to fill out all required fields.
* Double-check that the email addresses entered are correct before submitting the form.
* If you're unsure about any of the fields, ask your supervisor for clarification.
