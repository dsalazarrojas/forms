# Secure Web Access Error Report Form - Help Guide
## Purpose
The Secure Web Access Error Report Form is used to report errors when attempting to access the web application. Please provide details about the error to help IT identify and resolve the issue.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your User ID, which is your unique identifier for the web application.
2.  Describe the error details in the `Error Details` field.
3.  Select the `Error Type` that best describes the issue you experienced.
4.  If available, take a screenshot of the error and attach it to the `Screenshot` field.
5.  If applicable, provide the `Issue Date` and `Issue Time` of when you encountered the error.
6.  Indicate the `Browser Type` and `OS` you are using to access the web application.
7.  Enter the `IP Address` you were using when the error occurred.
8.  Enter the `Browser Version` if you know it.

## Field-by-Field Explanation
*   **User ID** (`user_id`, number, required: false): Enter your unique identifier for the web application.
*   **Error Details** (`error_details`, text, required: false): Describe the error you experienced in as much detail as possible.
*   **Issue Date** (`issue_date`, date, required: false): If you know the exact date of the issue, enter it here.
*   **Issue Time** (`issue_time`, time, required: false): If you know the exact time of the issue, enter it here.
*   **Error Type** (`error_type`, select_one, required: false): Select the error type that best describes the issue.
*   **Error Message** (`error_message`, text, required: false): Enter the error message you received.
*   **Screenshot** (`screenshot`, text, required: false): If available, attach a screenshot of the error.
*   **Browser Type** (`browser_type`, select_multiple, required: false): Select the browser type you are using to access the web application.
*   **OS** (`os`, select_one, required: false): Select the operating system you are using to access the web application.
*   **IP Address** (`ip_address`, text, required: false): Enter the IP address you were using when the error occurred.
*   **Browser Version** (`browser_version`, text, required: false): Enter the browser version you are using, if known.

## Tips
*   Only fill out this form if you are experiencing an error when attempting to access the web application.
*   If the issue has already been resolved, do not fill out this form.
*   Provide as much detail as possible in the `Error Details` field to help IT identify the issue.
*   If you are unable to attach a screenshot, you can describe the error in the `Error Details` field instead.
*   Make sure to provide the correct `Browser Type` and `OS` to help IT identify the issue.
*   If you are using a virtual private network (VPN), please note this in the `Error Details` field.
