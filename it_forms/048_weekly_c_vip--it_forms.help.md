# Weekly C-Vip - Help Guide
## Purpose
The purpose of this form is to collect user input for the weekly C-vip (Community Volunteer Incentive Program) activities.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter your information accurately and completely in each field.
*   Make sure to review each field and its corresponding label for any required fields.
*   Submit the form once you have filled out all necessary information.


## Field-by-Field Explanation

*   **User Input 1** (`user_input_1`, text, optional): This field allows you to enter any necessary information related to the weekly activity. Enter your answer in the text field provided.
*   **Another Input** (`user_input_2`, text, optional): This field provides an additional input option for any other relevant information. Enter your answer in the text field provided.
*   **Select 1** (`select_one_1`, select_one, optional): In this field, you can choose one option from the provided list. Select 'Yes' or 'No' as necessary.
*   **Select 2** (`select_one_2`, select_one, optional): This field is similar to Select 1, where you can choose one option from the list. Select 'Yes' or 'No' as necessary.
*   **Select 2** (`select_multiple_2`, select_multiple, optional): In this field, you can select one or multiple options from the list. Select 'Yes' or 'No' as necessary.
*   **Date** (`date_1`, date, optional): Enter the date for the activity in this field.
*   **Time** (`time_1`, time, optional): Enter the time for the activity in this field.
*   **Decimal** (`decimal_1`, number, optional): Enter a decimal value as necessary for the activity. Please ensure it's a number.
*   **Note** (`note_1`, note, optional): This field is for any additional comments or notes related to the activity.
*   **Email** (`email_1`, email, optional): Enter your email address for contact or communication purposes.
*   **Phone** (`phone_1`, text, optional): Enter your phone number for contact or communication purposes.

## Tips

*   If you need help or have any issues with the form, contact the support team.
*   Make sure to review the form carefully before submission to avoid any missing information.
*   If required fields are marked as required, be sure to fill them out before submitting the form.
