# Factory Iot Sensor Network Registration - Help Guide
## Purpose
The Factory Iot Sensor Network Registration form is designed to add a new sensor to the factory environment's IoT sensor network. This form collects relevant information about the deployed sensors to ensure accurate tracking and monitoring.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **sensor deployment details** in the `Sensor Deployment` field.
2.  Specify the **location** where the sensor is installed.
3.  Provide the **Network Identifier** to associate the sensor with the correct network.
4.  Select the **sensor type** being deployed.
5.  Fill in the **Installation Date** when the sensor was installed.
6.  Enter the **Sensor Serial** number for identification.
7.  Add a **Description** of the sensor to help with identification and categorization.

## Field-by-Field Explanation
### Sensor Deployment
*   **Sensor Deployment** (`Sensor Deployment`, `text`, required/optional): Enter a brief description of the sensor deployment, including its purpose and any relevant details about the deployment process.

### Location
*   **Location** (`Location`, `text`, required/optional): Type in the location where the sensor is installed, such as the factory floor, warehouse, or specific room number.

### Network Identifier
*   **Network Identifier** (`Network Identifier`, `text`, required/optional): Enter the network identifier associated with the sensor to connect it to the correct network within the factory.

### Sensor Type
*   **Sensor Type** (`Sensor Type`, `text`, required/optional): Select the type of sensor being deployed, such as temperature, pressure, or humidity sensor.

### Installation Date
*   **Installation Date** (`Installation Date`, `date`, required/optional): Fill in the date when the sensor was installed, including the day, month, and year.

### Sensor Serial
*   **Sensor Serial** (`Sensor Serial`, `text`, required/optional): Enter the unique serial number of the sensor for identification purposes.

### Description
*   **Description** (`Description`, `text`, required/optional): Provide a brief description of the sensor, including its purpose and any relevant details for its correct categorization.

## Tips
*   Make sure to fill in accurate and complete information to ensure correct registration and tracking of the sensor within the factory environment.
*   If you're unsure about any field, refer to your factory's sensor network guidelines or contact your supervisor for clarification.
*   This form is for registering new sensors only; for editing or updating existing sensors, use the respective edit functions.
