# New Server Request Form - Help Guide

## Purpose
This form is used to request new server resources with specific operating systems, hardware, and software products. Please fill out the following fields carefully to ensure accurate information is provided.

## How To Complete This Form
To fill out this form, follow these steps:

1. Fill in the **New Server Request Form Title** field with a brief title for the server request.
2. Enter your **Full Name** in the **Full Name** field.
3. Enter your **Email** in the **Email** field. Ensure it's a valid email address.
4. Select the **Operating System** for the new server from the available options.
5. Select the **Hardware Product** for the new server from the available options.
6. Choose the software and other products required for the server from the **Software Product** field, which allows multiple selections.
7. Describe the **Operating Environment** of the server, if applicable.
8. Add a brief description of the server request in the **Description** field.
9. Choose a date for the server request using the **Date** field.
10. Select a time for the server request using the **Time** field.
11. Rate the **Operating System Versions** of the servers, if applicable.
12. Enter the **URL** of any related resource, if applicable.
13. Add any additional **Notes** about the server request.
14. Enter any assigned **Tool** for the server request.
15. Enter the **Form ID** (optional and not used for form submission).

## Field-by-Field Explanation
* **New Server Request Form Title** (Text, Required: False): Enter a brief title for the server request.
* **Full Name** (Text, Required: False): Enter your full name for contact purposes.
* **Email** (Email, Required: False): Enter a valid email address for communication.
* **Operating System** (Select One, Required: True): Choose the operating system for the new server.
* **Hardware Product** (Select One, Required: True): Select the hardware product for the new server.
* **Software Product** (Select Multiple, Required: False): Choose the software products required for the server.
* **Operating Environment** (Text, Required: False): Describe the operating environment, if applicable.
* **Description** (Text, Required: False): Add a brief description of the server request.
* **Date** (Date, Required: False): Choose a date for the server request.
* **Time** (Time, Required: False): Select a time for the server request.
* **Operating System Versions** (Select Multiple, Required: False): Rate the operating system versions.
* **URL** (Text, Required: False): Enter the URL of any related resource.
* **Notes** (Note, Required: False): Add any additional notes about the server request.
* **Assigned Tool** (Text, Required: False): Enter any assigned tool for the server request.
* **Form ID** (Text, Required: False): Enter the form ID (optional and not used for form submission).
