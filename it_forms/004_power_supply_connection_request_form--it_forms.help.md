# Power Supply Connection Request Form - Help Guide
## Purpose
The Power Supply Connection Request Form is used by authorized personnel to request power supply connections for their work sites. This form helps to streamline the process of requesting power supply connections, ensuring that the necessary information is collected and that the request is processed efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (indicated by an asterisk \*).
2. Choose the correct options for the "Power Source" and "Connection Type" fields.
3. Select the "Yes" or "No" option for the "Power Supply" field.
4. Enter the site information in the "Site Name", "Site Code", "Site Type", and "Site Location" fields.
5. Enter the connection information in the "Connection Rating" field.
6. Choose the connection size from the available options.

## Field-by-Field Explanation

* **Power Supply Connection Request\**: *Enter a brief description of the power supply request.*
* **Power Source**: *Choose the power source that the site is connected to (e.g. "Grid", "Generator", etc.).*
* **Connection Type**: *Choose the type of connection that is required (e.g. "Direct", "Metered", etc.).*
* **Site Name**: *Enter the name of the site where the power supply connection is required.*
* **Site Code**: *Enter the code assigned to the site where the power supply connection is required.*
* **Site Type**: *Choose the type of site (e.g. "Office", "Factory", etc.).*
* **Site Location**: *Enter the physical location of the site where the power supply connection is required.*
* **Connection Rating**: *Enter the connection rating of the site (e.g. 100A, 200A, etc.).*
* **Power Supply**: *Select "Yes" if the site requires a power supply, "No" otherwise.*
* **Connection Size**: *Choose the connection size that is required (e.g. "Large", "Small", etc.).*
* **Connection Date**: *Enter the date of the connection.*

Note: The connection date is optional, but if you know the date of the connection, it will help in processing the request more efficiently.
