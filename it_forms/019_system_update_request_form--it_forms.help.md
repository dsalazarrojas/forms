# System Update Request Form - Help Guide

## Purpose

The System Update Request Form is used to submit updates and requests for both software and hardware upgrades, as well as to specify the category, description, and submitter's information. It is meant to be filled out by users when they have a need for an update, whether it be for a piece of software or hardware, and to provide a clear and concise way for the submitter to provide context and details about their request.

## How To Complete This Form

To complete the System Update Request Form, follow these steps:

* Fill out the form completely, providing as much detail as possible in each field.
* If you are requesting software or hardware updates, choose the corresponding option in the `Category` field.
* Select the submitter of the request from the `Submitter` field.
* Fill out the `Date of submission` field with the date on which you are submitting the request.
* Fill out the `Time of submission` field with the time on which you are submitting the request.
* If you have any additional comments or information about your request, enter them in the `Comments` field.
* Enter your email address in the `Email` field so that we can contact you to follow up on your request.
* Enter your phone number in the `Phone` field so that we can contact you if necessary.
* Finally, click the `Submit` button to send the form.

## Field-by-Field Explanation

### Software updates

* **Software updates** (`software_updates`, text, optional): Describe the software update you are requesting.
* **Hardware updates** (`hardware_updates`, text, optional): Describe the hardware update you are requesting.
* **Category** (`category`, select_multiple, optional): Select the category of the update (Software or Hardware).
* **Description** (`description`, text, optional): Provide a detailed description of the update you are requesting.
* **Submitter** (`submitter`, select_one, optional): Select the person submitting the request (John, Jane, or Jim).
* **Date of submission** (`date_of_submission`, date, optional): Enter the date on which you are submitting the request.
* **Time of submission** (`time_of_submission`, time, optional): Enter the time on which you are submitting the request.
* **Comments** (`comments`, note, optional): Enter any additional comments or information about your request.
* **Email** (`email`, email, optional): Enter your email address so that we can contact you to follow up on your request.
* **Phone** (`phone`, text, optional): Enter your phone number so that we can contact you if necessary.
* **Submit** (`submit`, text, optional): Click this button to submit the form.

Note: All fields are optional, but it is recommended to fill out as much information as possible to ensure that your request is processed efficiently.
