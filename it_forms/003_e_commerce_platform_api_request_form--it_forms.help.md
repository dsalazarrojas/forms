# e_commerce_platform_api_request_form - Help Guide
## Purpose
This form is used to request API access for external partners. Please fill out the following sections to provide necessary information for the review process.
## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the Integration Details page with any necessary information about the integration.
2. Select the Endpoints page to choose the API endpoints you need access to.
3. Choose the Consent page to determine the level of consent you need.
4. Select the API Access page to choose the type of access you need.
5. Fill in the Product Info page with any relevant product information.
6. Provide the date for the IT Teams Review on the next available date.
7. Choose the Partnership Teams Review page to determine the review date.
8. Select the Review Status page to indicate the status of your request.
9. Fill in the Notes page with any additional comments.
10. Provide your Email and Phone number.

## Field-by-Field Explanation
* **Integration Details (1)** (text, optional): This is a text field for providing any necessary details about the integration.
* **Endpoints (2)** (select_multiple, optional): Choose the API endpoints you need access to.
	+ Yes: Select to access the API
	+ No: Do not select to indicate that you do not need access to the API
* **Consent (3)** (select_one, optional): Choose the level of consent you need:
	+ option 1
	+ option 2
	+ option 3
* **API Access (4)** (number, optional): Choose the type of API access you need.
* **Product Info (5)** (note, optional): This is a text area for providing any relevant product information.
* **IT Teams Review (6)** (date, optional): Provide the date for the IT Teams review.
* **Partnership Teams Review (7)** (date, optional): Choose the date for the Partnership Teams review.
* **Review Status (8)** (select_one, optional): Select the status of your review:
	+ option 1
	+ option 2
	+ option 3
* **Notes (9)** (text, optional): Provide any additional comments or notes about your request.
* **Email (10)** (email, optional): Provide your email address.
* **Phone (11)** (text, optional): Provide your phone number.
