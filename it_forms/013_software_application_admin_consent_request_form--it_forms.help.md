# Software Application Admin Consent Request Form - Help Guide

## Purpose
The Software Application Admin Consent Request Form is used to request administrative access to software applications. This form is intended for users who need to access specific software tools for administrative purposes. The form helps the IT department evaluate and grant or deny access requests.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the correct response to the Software Tool Request question, indicating if you are requesting access to a software tool.
2. Provide details about the software application you are requesting access to in the Software Application Details field.
3. Describe the specific permissions you need to access the software tool in the Administrative Access Request field.
4. Select the date for which you are requesting consent in the Consent Date field.
5. Choose the time of day for which you are requesting consent in the Consent Time field.
6. Choose the type of consent you are requesting, either Admin or User.
7. Enter the name of the software tool you are requesting access to in the Software Tool field.
8. Provide a reason for your request in the Reason for Request field.
9. You may also add any additional comments about your request in the Software Application Admin Consent Request Form Comments field.

## Field-by-Field Explanation

* **Software Tool Request**: Select "Yes" to indicate you are requesting access to a software tool.
* **Software Application Details**: Provide a brief description of the software application you are requesting access to.
* **Administrative Access Request**: Describe the specific permissions you need to access the software tool.
* **Consent Date**: Select the date for which you are requesting consent.
* **Consent Time**: Choose the time of day for which you are requesting consent.
* **Consent**: Select "Admin" for administrative access or "User" for user-level access.
* **Software Tool**: Enter the name of the software tool you are requesting access to.
* **Reason for Request**: Provide a brief reason for your request.
* **Review and Acknowledge**: This field is for internal comments and review.
* **Software Application Admin Consent Request**: Enter your email address for communication purposes.
* **IT Department**: Enter the department responsible for software tool access.
* **Requester**: Enter your name or username for identification purposes.
* **Software Application Admin Consent Request Form Comments**: Add any additional comments about your request.
* **Software Application Admin Consent Request Form Review Comments**: Add any comments for the IT department to review your request.
* **Software Application Admin Consent Request Form**: This field is for internal use and does not require input.
