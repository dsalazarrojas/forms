## Field-by-Field Explanation

*   **Monitored User**:
    *   `<name>: Employee Internet Usage Monitoring Log`
    *   `<type>: select_one`
    *   `required/optional: required`
    *   Select the employee whose internet usage you are monitoring. This field is required and should be filled in with one of the following options: option 1, option 2, option 3.
*   **start_date**:
    *   `<name>: start_date`
    *   `<type>: date`
    *   `required/optional: required`
    *   Enter the start date of the monitored period in the format MM/DD/YYYY.
*   **end_date**:
    *   `<name>: end_date`
    *   `<type>: date`
    *   `required/optional: required`
    *   Enter the end date of the monitored period in the format MM/DD/YYYY.
*   **Monitored By**:
    *   `<name>: Monitored By`
    *   `<type>: select_multiple`
    *   `required/optional: required`
    *   Select all the individuals who monitored the employee's internet usage during the monitored period. This field should be filled in with one or more of the following options: option 1, option 2.
*   **Internet Usage Category**:
    *   `<name>: Internet Usage Category`
    *   `<type>: select_multiple`
    *   `required/optional: required`
    *   Select one or more categories of internet usage that were monitored during the period. This field is required and should be filled in with one or more of the following options: option 1, option 2, option 3.
*   **Time Spent On Internet**:
    *   `<name>: Time Spent On Internet`
    *   `<type>: number`
    *   `required/optional: required`
    *   Enter the total amount of time the employee spent on the internet during the monitored period.
*   **Time Spent On Workplace Internet**:
    *   `<name>: Time Spent On Workplace Internet`
    *   `<type>: number`
    *   `required/optional: required`
    *   Enter the amount of time the employee spent on the workplace internet during the monitored period.
*   **Devices Used**:
    *   `<name>: Devices Used`
    *   `<type>: select_multiple`
    *   `required/optional: required`
    *   List all the devices used by the employee during the monitored period. This field should be filled in with one or more of the following options: option 1, option 2.
*   **Internet Usage Notes**:
    *   `<name>: Internet Usage Notes`
    *   `<type>: note`
    *   `required/optional: required`
    *   Enter any additional notes or comments about the employee's internet usage during the monitored period.
