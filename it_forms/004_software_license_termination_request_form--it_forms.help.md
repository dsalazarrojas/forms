# Software License Termination Request Form - Help Guide

## Purpose
The Software License Termination Request Form is used to formally initiate the process of terminating a software license. This form is essential to ensure that all necessary steps are taken to properly end a software license, which may be due to non-compliance, technical issues, or other reasons.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the reason for termination from the available options.
2. Enter the date of the termination request.
3. Provide the software ID number.
4. Choose the department responsible for the software (e.g., IT Department, Accounting Department, HR Department, Sales Department).
5. Enter the name of the software being terminated.
6. Enter your name as the requestor.
7. Enter your email address.
8. Enter your phone number.
9. Optionally, add any additional comments or notes regarding the software termination.
10. If approved, enter the date and name of the person who approved the termination.
11. Select the status of the termination request (Approved, Pending, Denied).
12. Optionally, add comments for the requestor or approver.

## Field-by-Field Explanation

* **Software License Request** (`software_license_termination_request_form`, select_one, required): Select the reason for termination from the available options (e.g., License Requested, License Cancelled).
* **Request Date** (`request_date`, date, required): Enter the date of the termination request.
* **Software ID** (`software_id`, text, required): Enter the software ID number.
* **Reason for Termination** (`reason_for_termination`, text, required): Provide a brief explanation of the reason for termination.
* **Department ID** (`department_id`, select_multiple, required): Choose the department responsible for the software (e.g., IT Department, Accounting Department, HR Department, Sales Department).
* **Software Name** (`software_name`, text, required): Enter the name of the software being terminated.
* **Requestor Name** (`requestor_name`, text, required): Enter your name as the requestor.
* **Email** (`email`, email, required): Enter your email address.
* **Phone Number** (`phone`, text, required): Enter your phone number.
* **Comment** (`comment`, text, optional): Add any additional comments or notes regarding this software termination (not required but recommended).
* **Termination Date** (`termination_date`, date, optional): Enter the date of the termination, if known.
* **Approved by** (`approved_by`, text, optional): Enter the name of the person who approved the termination.
* **Approved Date** (`approved_date`, date, optional): Enter the date the termination was approved.
* **Status** (`status`, select_one, required): Select the status of the termination request (Approved, Pending, Denied).
* **Comments** (`comments`, text, optional): Add any comments for the requestor or approver.
