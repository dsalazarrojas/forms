# Server Downtime Incident Form - Help Guide
## Purpose
The Server Downtime Incident Form is used to report and track server downtime incidents. Please fill out this form to report any server-related issues that are currently affecting or have affected the server. This form is meant to be completed only once per incident, and it will help us to better understand and respond to the incident.

## How To Complete This Form

1.  Fill out all the required fields, marked with an asterisk (\*).
2.  For fields not marked as required, you can leave them blank if you don't have the information.

## Field-by-Field Explanation
- **incident_details** (text): Describe the incident in a few words, including any relevant details.
- **incident_type** (select one): Choose the type of incident from the options: Server Crash, Server Maintenance, or Network Outage.
  - This field helps us to understand the nature of the incident and plan accordingly.
- **server_name** (text): If the incident is related to a specific server, please enter the server name.
  - This field is used to track the affected server.
- **start_time** (time): Enter the start time of the incident.
  - This field is used to track the start of the incident.
- **end_time** (time): Enter the end time of the incident.
  - This field is used to track the end of the incident.
- **cause** (text): Describe the cause of the incident in detail.
  - This field helps us to identify the root cause of the incident.
- **affected_services** (text): List the services affected by the incident.
  - This field is used to identify which services are impacted by the incident.
- **description** (text): Provide a more detailed explanation of the incident.
  - This field helps to provide a better understanding of what happened.
- **incident_status** (select one): Choose the status of the incident from the options: Open, Closed, or In Progress.
  - This field tracks the status of the incident, helping us to stay on top of it.

## Tips
- Please fill out the form as thoroughly and accurately as possible.
- If you have any attachments or additional information, you can attach them to the form.
- If you have any questions or concerns, please contact the IT department.
