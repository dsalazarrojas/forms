# software_testing_device_order_request_form - Help Guide
## Purpose
The software testing device order request form is used to submit a request for a software testing device.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Select the shipping method and status from the available options.
3. Ensure that you have filled in all required fields.

## Field-by-Field Explanation
- **software_testing_device** (`software_testing_device_order_request_form_form_1`, text, required/optional): Please fill in the name of the software testing device you are requesting.
- **testing_device_description** (`software_testing_device_order_request_form_form_2`, text, optional): Provide a brief description of the device.
- **testing_device_requester** (`software_testing_device_order_request_form_form_3`, text, optional): Enter the name of the person requesting the device.
- **testing_device_requester_email** (`software_testing_device_order_request_form_form_4`, email, optional): Enter the email address of the person requesting the device.
- **testing_device_requester_department** (`software_testing_device_order_request_form_form_5`, text, optional): Enter the department of the person requesting the device.
- **testing_device_requester_phone** (`software_testing_device_order_request_form_form_6`, text, optional): Enter the phone number of the person requesting the device.
- **testing_device_requester_notes** (`software_testing_device_order_request_form_form_7`, note, optional): Add any additional notes about the request.
- **testing_device_requester_agreed** (`software_testing_device_order_request_form_form_8`, select_one, required): Select 'Agreed' to confirm that you have read and understood the terms and conditions.
- **shipping_method** (`software_testing_device_order_request_form_form_9`, select_multiple, required): Select the shipping method from the available options.
- **shipping_notes** (`software_testing_device_order_request_form_form_10`, text, optional): Add any additional notes about the shipping.
- **shipping_status** (`software_testing_device_order_request_form_form_11`, select_one, required): Select the shipping status from the available options.
- **shipping_status_notes** (`software_testing_device_order_request_form_form_12`, note, optional): Add any additional notes about the shipping status.
- **shipping_date** (`software_testing_device_order_request_form_form_13`, date, optional): Enter the date when the device is expected to be shipped.
- **shipping_time** (`software_testing_device_order_request_form_form_14`, time, optional): Enter the time when the device is expected to be shipped.
- **testing_device_order_requester** (`software_testing_device_order_request_form_form_15`, text, optional): Enter a name for the testing device order requester.
- **testing_device_order_requester_title** (`software_testing_device_order_request_form_form_16`, text, optional): Enter a title for the testing device order requester.
- **testing_device_order_requester_company** (`software_testing_device_order_request_form_form_17`, text, optional): Enter the company name of the testing device order requester.
- **testing_device_order_requester_country** (`software_testing_device_order_request_form_form_18`, text, optional): Enter the country of the testing device order requester.
- **testing_device_order_requester_state** (`software_testing_device_order_request_form_form_19`, text, optional): Enter the state of the testing device order requester.
- **testing_device_order_requester_city** (`software_testing_device_order_request_form_form_20`, text, optional): Enter the city of the testing device order requester.
- **testing_device_order_requester_zip** (`software_testing_device_order_request_form_form_21`, text, optional): Enter the zip code of the testing device order requester.
- **testing_device_order_requester_address** (`software_testing_device_order_request_form_form_22`, text, optional): Enter the address of the testing device order requester.
- **testing_device_order_requester_phone** (`software_testing_device_order_request_form_form_23`, text, optional): Enter the phone number of the testing device order requester.
- **testing_device_order_requester_notes** (`software_testing_device_order_request_form_form_24`, note, optional): Add any additional notes about the testing device order requester.
- **testing_device_order_requester_signature** (`software_testing_device_order_request_form_form_25`, text, optional): Enter a signature for the testing device order requester.

## Tips
- Please ensure that you fill in all required fields.
- Double-check your information before submitting the form.
