# CrowdStrike Incident Response Form - Help Guide

## Purpose
This form is designed to collect information about an incident reported by users. It helps in gathering details about the incident, such as its type, date, location, and impact, as well as the response and status of the incident.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide details about the incident, including its type, date, and location.
2. Indicate whether any affected assets are online or offline.
3. Describe the impact of the incident.
4. Report the asset affected by the incident.
5. Specify the category and priority of the incident.
6. Provide notes about the incident.
7. Add a list of assets affected by the incident.
8. Identify the type of assets affected by the incident.
9. Specify the status of the assets affected by the incident.

## Field-by-Field Explanation
- **Incident Details** (`incident_details`):
    - A free-text field to provide a brief description of the incident.
- **Incident Type** (`incident_type`):
    - Select one of the following incident types: Phishing, Malware, Ransomware, or DDOS.
- **Date** (`incident_date`):
    - The date when the incident occurred. Please use the format `YYYY-MM-DD`.
- **Time** (`incident_time`):
    - The time when the incident occurred. Please use the format `HH:MM:SS`.
- **Location** (`incident_location`):
    - A text field to specify the location of the incident.
- **Description** (`incident_description`):
    - A text field to provide a detailed description of the incident.
- **Affected Assets** (`affected_assets`):
    - Indicate whether any assets were affected by the incident. Select 'Yes' or 'No'.
- **Status** (`incident_status`):
    - Select one of the following incident statuses: Open, In Progress, or Resolved.
- **Category** (`incident_category`):
    - Select one of the following categories: Security, Network, System, or Unknown.
- **Priority** (`incident_priority`):
    - Select one of the following priority levels: Low, Medium, or High.
- **Impact** (`incident_impact`):
    - A text field to specify the impact of the incident.
- **Reported By** (`incident_reported_by`):
    - A text field to specify the person or team that reported the incident.
- **Reported Date** (`incident_reported_date`):
    - The date when the incident was reported. Please use the format `YYYY-MM-DD`.
- **Response** (`incident_response`):
    - A text field to specify the response to the incident.
- **Notes** (`incident_notes`):
    - A text field to provide additional notes about the incident.
- **Assets** (`incident_assets`):
    - A text field to specify the assets affected by the incident.
- **Asset List** (`incident_assets_list`):
    - A text field to specify the list of assets affected by the incident.
- **Asset Type** (`incident_assets_type`):
    - Select one of the following asset types: Server, Laptop, Desktop, or Mobile.
- **Asset Status** (`incident_assets_status`):
    - Select one of the following asset statuses: Online, Offline, or Unknown.
