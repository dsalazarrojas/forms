# Digital_Infrastructure_Development_Application - Help Guide
## Purpose
This form is used to provide information about digital infrastructure development projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form for the project you are managing.
2. Enter project details in the "Project Details" field. This field is for general information about the project.
3. In the "Technical Requirements" field, describe the technical aspects of the project.
4. Enter "Timelines" in the "Timelines" field, selecting a date for the expected project completion date.
5. Upload any relevant documents in the "Documents" field.
6. If applicable, select the "Project Manager" from the dropdown menu.
7. Check the "Project Lead" field, selecting either "Yes" or "No" to indicate whether the project lead is involved.
8. Enter the current project status in the "Status" field.
9. Finally, select the "Expected Completion Date" for the project.

## Field-by-Field Explanation
### Project Details (id: 1)
* **Project Details** (`<name>`, `text`, false): This is a field for general information about the project.

### Technical Requirements (id: 2)
* **Technical Requirements** (`<name>`, `text`, false): This field is for describing the technical aspects of the project.

### Timelines (id: 3)
* **Timelines** (`<name>`, `date`, false): Enter a date for the expected project completion date.

### Documents (id: 4)
* **Documents** (`<name>`, `note`, false): Upload any relevant documents for the project.

### Project Manager (id: 5)
* **Project Manager** (`<name>`, `select_multiple`, false): Select one or more project managers from the dropdown menu.

### Project Lead (id: 6)
* **Project Lead** (`<name>`, `select_one`, false): Select either "Yes" or "No" to indicate whether the project lead is involved.

### Status (id: 7)
* **Status** (`<name>`, `text`, false): Enter the current project status.

### Expected Completion Date (id: 8)
* **Expected Completion Date** (`<name>`, `date`, false): Select a date for the expected project completion.

## Tips
- Please ensure that you are filling out the form for the correct project.
- If a field is not required, you can leave it blank.
- Make sure to select the correct project manager(s) and project lead.
- Keep in mind that this form is for internal use, so provide honest and accurate information.
