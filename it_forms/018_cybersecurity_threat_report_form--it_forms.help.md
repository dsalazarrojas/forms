# Cybersecurity Threat Report Form - Help Guide
## Purpose
The Cybersecurity Threat Report Form is a tool used to report and document potential or actual cybersecurity threats to the IT security team.

## How To Complete This Form
1. Start by filling out the threat description field (Field 1) with a detailed account of the threat.
2. Indicate whether the threat is a type of threat you've encountered (Field 2) by selecting either 'Yes' or 'No' from the dropdown menu.
3. Choose all applicable threat severity levels (Field 3) by selecting multiple options that best describe the severity of the threat.
4. Select all relevant threat frequency (Field 4) levels by choosing multiple options from the dropdown menu.
5. Enter the source of the threat (Field 5) in the text field, providing as much detail as possible.
6. Summarize the threat (Field 6) in a concise and clear manner.
7. If you have a recommended course of action (Field 7), enter it in the text field.
8. If you have any additional comments or context about the threat (Field 8), enter them in the text field.

## Field-by-Field Explanation
* **threat_description** (Text, required): A detailed description of the cybersecurity threat you are reporting.
* **threat_type** (Select One, required): Indicate whether this is a type of threat you've encountered.
* **threat_severity** (Select Multiple, required): Choose all applicable threat severity levels.
* **threat_frequency** (Select Multiple, required): Select all relevant threat frequency levels.
* **threat_source** (Text, required): Enter the source of the threat.
* **threat_summary** (Text, required): Summarize the threat in a concise and clear manner.
* **threat_recommendation** (Text, required): Enter a recommended course of action.
* **threat_comments** (Text, optional): Enter any additional comments or context about the threat.

Note: Fields marked as 'required' must be filled out.
