# Security Surveillance Review Request - Help Guide
## Purpose
The "Security Surveillance Review Request" form is designed to gather information about incidents that require security review. This form is used to provide details about the incident and request a review from the security team.

## How To Complete This Form
1. Fill out this form carefully and thoroughly.
2. Provide accurate information about the incident, including details about what happened and any relevant dates and times.
3. Attach supporting files or evidence related to the incident, if possible.
4. Select the correct security contacts who will be involved in reviewing the incident.
5. Choose the type of review you are requesting (Video, File, or Both).

## Field-by-Field Explanation

* **Request Details** (`request_details`, `text`, required: false): This field is where you can provide a brief description of the incident. Please use this space to explain what happened and any relevant context.
* **Incident Details** (`incident_details`, `text`, required: false): In this field, you can provide more detailed information about the incident, such as what occurred, how it affected you, and any other relevant details.
* **Incident Date** (`incident_date`, `date`, required: false): Enter the date of the incident in the correct date format (e.g., mm/dd/yyyy).
* **Incident Time** (`incident_time`, `time`, required: false): Enter the time of the incident in the correct 24-hour format (e.g., 14:30).
* **Location** (`location`, `text`, required: false): Provide the location where the incident occurred.
* **Supporting Files** (`supporting_files`, `note`, required: false): If you have any files or evidence related to the incident, please attach them here. This will help the security team understand the incident better.
* **Security Contacts** (`security_contacts`, `select_one`, required: false): Select the correct security team members who will be reviewing the incident. Choose from the available options (North, South, or West).
* **Review Request** (`review_request`, `select_multiple`, required: false): Specify the type of review you are requesting. Choose from the options (Video, File, or Both).
