# Application Cloud - Help Guide
## Purpose
This form is for reporting issues with cloud applications, such as cloud services or products. The information collected will help our engineering team understand and resolve the issues you're experiencing.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and title of the cloud service or product experiencing issues.
2. Choose the environment where the issue occurred (Production, Staging, Development, or Other).
3. Select the severity level of the issue (Low, Medium, High, or Critical).
4. Describe the steps you took to reproduce the issue (if applicable).
5. Describe the expected behavior of the cloud application.
6. Describe what actually happened when the issue occurred.
7. Indicate if you've attached any logs or screenshots (filename).
8. Enter the contact email for engineering follow-up.

## Field-by-Field Explanation
* **Respondent name** (1): This field is optional, but your name will help us know who submitted the report.
* **Cloud service or product** (2): Enter the name of the cloud application experiencing issues.
* **Environment** (3): Select the environment where the issue occurred: 
  + Production: Issues with live, production-grade applications.
  + Staging: Issues with application in a testing or pre-production environment.
  + Development: Issues with code in development or testing stages.
  + Other: Select this if your environment is not listed.
* **Issues reported** (4): Briefly describe the problems you've encountered with the cloud application.
* **Severity** (5): Choose the impact level of the issue:
  + Low: Minor issues with minimal impact.
  + Medium: Issues affecting performance but not causing a major disruption.
  + High: Issues causing significant problems but no data loss.
  + Critical: Issues causing major data loss or severe performance issues.
* **Steps to reproduce** (6): If applicable, describe the steps you took to reproduce the issue.
* **Expected behavior** (7): Describe the desired behavior of the cloud application.
* **Actual behavior** (8): Describe what actually happened when the issue occurred.
* **Attachment filename** (9): If you've attached logs or screenshots, indicate the filename (e.g., "error_log.txt").
* **Contact email** (10): Enter the email address where you'd like engineering to follow up with you.
