# External Drive Unlock Request Form - Help Guide
## Purpose
This form is used to request the unlock of an external drive. It is intended for team members to submit requests to unlock external drives.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the form with the required information, which includes:
	* Category (IT Forms, Security Forms, or Other)
	* Description of the external drive
	* Urgency (High, Medium, or Low)
	* Priority (High, Medium, or Low)
	* Assigned To (team member's name)
	* Drive ID
	* Drive Type (Windows, Mac, or Linux)
	* Status (Open, Closed, or Pending)
	* Email
	* Phone number
	* Location (Remote, Office, or Other)
	* Date of submission
	* Time of submission
	* Submitted By (team member's name)
	* Date of submission
	* Time of submission
	* External Drive Unlock Request ID
	* External Drive Unlock Request Date
	* External Drive Unlock Request Status
	* External Drive Unlock Request Priority (optional)
	* External Drive Unlock Request Comments (optional)
	* External Drive Unlock Request Assigned To (optional)

## Field-by-Field Explanation
* **External Drive Unlock Request**: 
	* A text field for the description of the external drive to be unlocked.
* **Category**: 
	* Select the category for the request, which can be IT Forms, Security Forms, or Other.
* **Description**: 
	* A text field for any additional comments or details about the external drive.
* **Urgency**: 
	* Select the level of urgency for the request, which can be High, Medium, or Low.
* **Priority**: 
	* Select the priority level for the request, which can be High, Medium, or Low.
* **Comments**: 
	* An optional text field for any additional comments or details about the external drive.
* **Assigned To**: 
	* Select the team member to whom the request is assigned.
* **Drive ID**: 
	* A field to input the ID of the external drive to be unlocked.
* **Drive Type**: 
	* Select the type of external drive, which can be Windows, Mac, or Linux.
* **Status**: 
	* Select the status of the request, which can be Open, Closed, or Pending.
* **Email**: 
	* A field to input the email of the team member who submitted the request.
* **Phone**: 
	* A field to input the phone number of the team member who submitted the request.
* **Location**: 
	* Select the location where the external drive is located, which can be Remote, Office, or Other.
* **Date**: 
	* A field to input the date of submission.
* **Time**: 
	* A field to input the time of submission.
* **Submitted By**: 
	* Select the team member who submitted the request, which can be John Doe, Jane Doe, or Jim Doe.
* **Submitted On**: 
	* A field to input the date of submission.
* **Submitted At**: 
	* A field to input the time of submission.
* **External Drive Unlock Request ID**: 
	* A text field for the ID of the external drive unlock request.
* **External Drive Unlock Request Date**: 
	* A field to input the date of the external drive unlock request.
* **External Drive Unlock Request Status**: 
	* Select the status of the external drive unlock request, which can be New, Open, or Closed.
* **External Drive Unlock Request Priority** (Optional): 
	* Select the priority level for the request, which can be Low, Medium, or High.
* **External Drive Unlock Request Comments** (Optional): 
	* An optional text field for any additional comments or details about the external drive.
* **External Drive Unlock Request Assigned To** (Optional): 
	* Select the team member to whom the request is assigned, which can be chatjimmy or Other.
