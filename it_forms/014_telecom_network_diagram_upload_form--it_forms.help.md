# Telecom Network Diagram Upload Form - Help Guide
## Purpose
This form is designed for uploading telecom network diagrams for documentation and reference purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Upload File" page to upload a file containing your telecom network diagram.
2. Choose the type of diagram you are uploading (e.g., Drawing, Model, or Other).
3. Provide a brief description of the uploaded diagram.
4. Enter the name of the project related to the uploaded diagram.
5. (Optional) Enter the name of the vendor associated with the project.
6. (Optional) Add any additional notes about the uploaded diagram.
7. (Optional) Enter a URL for the diagram, if it's publicly accessible.

## Field-by-Field Explanation
* **Upload File** (`upload_file`, text, required): Upload a file containing your telecom network diagram.
* **Diagram Type** (`diagram_type`, select_one, required): Choose the type of diagram you are uploading (e.g., Drawing, Model, or Other).
* **Description** (`description`, text, required): Provide a brief description of the uploaded diagram.
* **Project Name** (`project_name`, text, required): Enter the name of the project related to the uploaded diagram.
* **Vendor** (`vendor_name`, text, optional): Enter the name of the vendor associated with the project.
* **Notes** (`notes`, text, optional): Add any additional notes about the uploaded diagram.
* **File URL** (`file_url`, text, optional): Enter a URL for the diagram, if it's publicly accessible.
