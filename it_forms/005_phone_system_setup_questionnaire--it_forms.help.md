# Phone System Setup Questionnaire - Help Guide
## Purpose
The purpose of this form is to collect information about phone system setup from end users.

## How To Complete This Form

1.  Enter the **Business Name** of the phone system being set up.
2.  Provide the **Contact Person** responsible for the phone system.
3.  If available, enter the **Contact Email** of the contact person.
4.  Select **Yes** or **No** to indicate whether the phone system is set up or not.
5.  Choose the **Phone System Type** from the available options.
6.  Enter a brief **Description** of the phone system.
7.  Select the **Features** of the phone system from the available options.
8.  Choose the **System Capacity** from the available options.
9.  Enter the **System Location** where the phone system is set up.

## Field-by-Field Explanation
* **Business Name** (`business_name`, text, required): Enter the name of the business that owns or operates the phone system.
* **Contact Person** (`contact_person`, text, required): Enter the name and title of the contact person responsible for the phone system.
* **Contact Email** (`contact_email`, email, optional): If available, enter the email address of the contact person.
* **Phone System** (`phone_system`, select_multiple, optional): Select **Yes** to indicate that the phone system is set up, or **No** otherwise.
* **Phone System Type** (`phone_system_type`, select_one, optional): Choose the type of phone system being set up from the available options.
* **Description** (`system_description`, text, required): Enter a brief description of the phone system.
* **System Features** (`system_features`, select_multiple, optional): Select the features of the phone system from the available options.
* **System Capacity** (`system_capacity`, select_one, optional): Choose the capacity of the phone system from the available options.
* **System Location** (`system_location`, text, optional): Enter the location where the phone system is set up.

## Tips
- Please be as accurate and detailed as possible when filling out the form.
- If you are unsure about any field, contact the administrator for clarification.
- This form is intended for internal record-keeping and troubleshooting purposes only.
