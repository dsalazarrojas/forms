# Signal Configuration Survey - Help Guide
## Purpose
The Signal Configuration Survey form is used to collect information about the configuration of signals in a system, helping to inform decisions about signal processing and alerting.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question carefully and accurately, as it will help to inform decisions about signal processing and alerting.
2. Select the correct options for each field, paying attention to the available options for each question.
3. Make sure to complete all fields, especially those marked as "required" to ensure that the data is accurate and complete.

## Field-by-Field Explanation
### 1. Signal Configuration Survey

This is the title of the form, indicating the purpose and topic of the form.

### 2. Signal Types

* **Signal Types** (Yes, No): This field asks whether signals should be sent. Select "Yes" to send signals, or "No" to not send signals.
	+ Required: No

### 3. Signal Frequency

* **Signal Frequency** (Every minute, Every 5 minutes, Every 10 minutes, Every 15 minutes, Every 30 minutes, Every 60 minutes): This field asks how often signals should be sent. Select the frequency at which signals should be sent.
	+ Required: No

### 4. Device Type

* **Device Type** (Device 1, Device 2, Device 3, Device 4, Device 5): This field asks which type of device is sending the signal. Select the device type from the available options.
	+ Required: No

### 5. Signal Status

* **Signal Status** (Active, Inactive, Pending): This field asks the status of the signal. Select the current status of the signal from the available options.
	+ Required: No

### 6. Signal Priority

* **Signal Priority** (High, Medium, Low): This field asks the priority of the signal. Select the priority level of the signal from the available options.
	+ Required: No

## Tips
* Make sure to complete all required fields to ensure accurate and complete data collection.
* Select the correct options for each field, based on the available options.
* If you're unsure about any field, please ask for clarification or guidance.
