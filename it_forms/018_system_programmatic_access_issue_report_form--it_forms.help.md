# System Programmatic Access Issue Report Form - Help Guide

## Purpose
This form is used to report issues with system programmatic access. It is a crucial tool for the system administrators to understand and resolve technical issues that users may be experiencing when accessing the system programmatically.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `System Programmatic Access Issue Report Form` section with a short title that summarizes the issue you are reporting.
2. Select the correct category for the issue you are reporting, either `IT Forms` or `Other`.
3. Provide a detailed description of the issue you are experiencing.
4. Choose the priority of the issue as `Low`, `Medium`, or `High`.
5. Enter your name and email address so that we can contact you for further information.
6. Provide your phone number so that we can reach out to you if necessary.
7. Add any additional comments or information about the issue in the `Additional Comments` section.
8. If applicable, attach any relevant files or screenshots that can help to diagnose the issue.

## Field-by-Field Explanation

* **System Programmatic Access Issue Report Form** (`form_title`, text, required: false): This is the title of the issue you are reporting. Please enter a short and descriptive title that summarizes the issue.
* **Category** (`category`, select_one, required: false): Choose the correct category for the issue you are reporting, either `IT Forms` or `Other`.
* **Description** (`description`, text, required: false): Please provide a detailed description of the issue you are experiencing. Be as specific as possible about the steps you took to encounter the issue and what you were doing when the issue occurred.
* **Priority** (`form_priority`, select_one, required: false): Choose the priority of the issue as `Low`, `Medium`, or `High`.
* **Submitter** (`form_submitter`, text, required: false): Enter your name so that we can contact you for further information.
* **Email** (`form_submitter_email`, email, required: false): Enter your email address so that we can reach out to you if necessary.
* **Phone** (`form_submitter_phone`, text, required: false): Provide your phone number so that we can reach out to you if necessary.
* **Comments** (`form_comments`, text, required: false): Add any additional comments or information about the issue in this section.
* **Attachment** (`form_attachment`, note, required: false): If applicable, attach any relevant files or screenshots that can help to diagnose the issue.
* **Additional Comments** (`form_comments`, text, required: false): Add any additional comments or information about the issue in this section.
