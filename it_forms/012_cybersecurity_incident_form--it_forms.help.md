# Cybersecurity Incident Form - Help Guide
## Purpose
The Cybersecurity Incident Form is used to report cybersecurity incidents to the organization's security team.

## How To Complete This Form
To report a cybersecurity incident, please follow the instructions in the "Instructions" section above.

## Field-by-Field Explanation
* **Incident Type**: This field is used to select the type of incident that occurred. Please choose one of the options in the dropdown menu.
* **Incident Date**: This field is used to enter the date of the incident in the format yyyy-mm-dd. Please use the correct date format to ensure accurate processing.
* **Incident Time**: This field is used to enter the time of the incident in the format hh:mm am/pm. Ensure that the format is correct to avoid delays in response.
