# Tech Software Bug Report Form - Help Guide
## Purpose
This form is designed for tech software developers to report bugs or issues they encounter while using or testing software. The form is intended to collect essential details to help developers identify and resolve problems.

## How To Complete This Form
1. Please fill out this form if you have encountered a bug or issue with the software.
2. Enter your name or username associated with your account (if available).
3. Provide a clear and concise description of the bug or issue.
4. Describe the steps to reproduce the bug or issue.
5. Indicate whether the expected behavior was to browse or view the software in a certain way.
6. Report if the bug is reproducible (Yes/No).
7. Select if the bug was reported by someone else (Yes/No).
8. Select all applicable product versions that are affected by the bug.
9. Select all applicable product versions that have the bug fixed (if known).

## Field-by-Field Explanation
* **bug_reporter**: Enter your name or username associated with your account (if available). This field helps developers know who submitted the report.
* **bug_description**: Provide a clear and concise description of the bug or issue. Be as detailed as possible to help developers diagnose the problem.
* **bug_steps**: Describe the steps to reproduce the bug or issue. This helps developers understand how to replicate the problem.
* **expected_browse**: Indicate whether the expected behavior was to browse or view the software in a certain way. For example, "I expected to see a button on the screen."
* **expected_view**: Similar to **expected_browse**, but for views.
* **category**: Indicate whether the bug is reproducible (Yes/No).
* **reported_by**: Select if the bug was reported by someone else (Yes/No).
* **product_versions_1**: Select all applicable product versions that are affected by the bug.
* **product_versions_2**: Select all applicable product versions that have the bug fixed (if known).

## Tips
- If you have already submitted a bug report, do not resubmit the same issue.
- If you are reporting a feature request, do not use this form.
- Be as descriptive as possible when reporting the bug or issue.
