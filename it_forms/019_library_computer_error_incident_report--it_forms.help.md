# Library Computer Error Incident Report - Help Guide

## Purpose
The Library Computer Error Incident Report form is used to report and track computer errors that occur in the library environment. This form helps the library staff to gather and document the necessary information about the incident, enabling the library management to identify the cause, assign priority, and allocate resources for resolution.


## How To Complete This Form
1. Start by selecting the **Category** of the error from the provided options (Option 1, Option 2, or Option 3).
2. In the **Description** field, provide a clear and concise description of the error or incident.
3. Enter the **Date** of the incident using the format MM/DD/YYYY.
4. Enter the **Time** of the incident using the format HH:MM:SS.
5. Select the **Library Technology Affected** from the provided options (Option 1, Option 2, or Option 3).
6. List the **Staff Involved** who were impacted by or witnessed the error, using the provided options (Option 1, Option 2, or Option 3).
7. Select the **Location** where the error occurred from the provided options (Option 1, Option 2, or Option 3).
8. Provide additional **Incident Details** that will help in resolving the issue.
9. Assign a **Priority** to the error from the provided options (Option 1, Option 2, or Option 3).
10. Select the **Follow-up Status** from the provided options (Option 1, Option 2, or Option 3).
11. If applicable, enter the **Follow-up Date** using the format MM/DD/YYYY.
12. If applicable, enter the **Follow-up Time** using the format HH:MM:SS.
12. Provide any **Follow-up Details** that may be useful in the resolution process.

## Field-by-Field Explanation

* **Category**: Select the category under which the error falls (e.g., hardware, software, network).
	+ Required field.
* **Description**: A brief description of the error or incident that occurred.
	+ Required field.
* **Date**: The date when the error occurred, in the format MM/DD/YYYY.
	+ Required field.
* **Time**: The time when the error occurred, in the format HH:MM:SS.
	+ Required field.
* **Library Technology Affected**: The specific technology or system affected by the error (e.g., computer, printer, network).
	+ Required field.
* **Staff Involved**: The library staff members who were impacted by or witnessed the error.
	+ Required field.
* **Location**: The location where the error occurred (e.g., public computer, staff room, library floor).
	+ Required field.
* **Incident Details**: Additional details about the incident that may be useful in resolving the issue.
	+ Required field.
* **Priority**: The level of priority assigned to the error (e.g., high, medium, low).
	+ Required field.
* **Follow-up Status**: The status of the follow-up action taken on the error (e.g., resolved, pending, escalated).
	+ Required field.
* **Follow-up Date**: The date when the follow-up action was taken, in the format MM/DD/YYYY.
	+ Optional field.
* **Follow-up Time**: The time when the follow-up action was taken, in the format HH:MM:SS.
	+ Optional field.
* **Follow-up Details**: Additional details about the follow-up action taken on the error.
	+ Optional field.
