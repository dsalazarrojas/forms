# Open Source Learning Tool Request Form - Help Guide
## Purpose
This form is designed to collect requests for open-source learning tools. It's a simple, user-friendly form intended for developers, researchers, and educators to share and collaborate on open-source tools for learning and education.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and email address in the "Your Name" and "Email" fields, respectively.
2. Enter the name of the learning tool you're requesting in the "Tool Name" field.
3. Add a brief description of the tool in the "Tool Description" field.
4. If the tool is publicly available online, provide the URL in the "Tool URL" field.
5. Click the submit button to send your request.

## Field-by-Field Explanation
* **Your Name** (Text, Optional): Enter your name as it appears on your identification documents.
* **Email** (Email, Required): Enter your email address for contact and communication purposes.
* **Tool Name** (Text, Optional): Enter the name of the open-source learning tool you're requesting.
* **Tool Description** (Text, Optional): Give a brief description of the tool, including its purpose and functionality.
* **Tool URL** (Text, Optional): If the tool is publicly available, enter the URL where it can be accessed.

## Tips
* Make sure to fill out the form accurately and completely to ensure that your request is processed correctly.
* If you're requesting a tool that's already available online, please provide the URL to the tool's website or repository.
* If you have any questions or need help, contact us at form@gic.mx.
