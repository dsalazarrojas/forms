# Cybersecurity Investigation Report Form - Help Guide
## Purpose
The Cybersecurity Investigation Report Form is used to gather information about cybersecurity incidents. It helps us to quickly report and document incidents, which enables the team to identify, assess, and respond to these incidents effectively.

## How To Complete This Form

1.  Fill out the form completely, paying attention to the required fields.
2.  Use the space provided to provide detailed descriptions and explanations.
3.  Ensure that you select the correct options for fields like Threat Level and Status.
4.  If you're unsure about any field, please refer to the explanation below.

## Field-by-Field Explanation

- **Incident ID** (incident_id, number, required): Please enter the unique ID for this incident. This is a required field that helps us track and identify the incident.
- **Incident Date** (incident_date, date, required): Enter the date of the incident. This will help us understand when the incident occurred.
- **Incident Time** (incident_time, time, required): Enter the time of the incident. This is used in conjunction with the incident date to identify the timing of the incident.
- **Date and Time** (incident_date_time, date, required): Enter the full date and time of the incident. This field is a combination of the incident date and time.
- **Location** (incident_location, text, optional): If the incident occurred at a specific location, please enter it here. This field is not required, but it can be helpful in understanding the context of the incident.
- **Threat Level** (threat_level, select_one, required): Choose the threat level of the incident: Low, Medium, or High. This helps us understand the severity of the incident.
- **Incident Type** (incident_type, text, optional): Enter the type of the incident, e.g., Malware, Ransomware, etc. This field is not required, but it can provide more context to the incident.
- **Description** (description, text, required): Describe the nature of the incident in detail. This is a required field that helps us understand what happened.
- **Remediation Plan** (remediation_plan, text, optional): If you have a plan to resolve the incident, please enter it here. This field is not required, but it can be helpful for follow-up actions.
- **Status** (incident_status, select_multiple, required): Choose the status of the incident: Open, Closed, or In Progress. This helps us understand the current state of the incident.

## Tips

- Ensure that you fill out all required fields.
- If you're unsure about any field, please refer to the explanations above.
- If you have any questions or concerns, please reach out to the IT department for assistance.
