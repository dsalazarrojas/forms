# Food Delivery App Project Intake Form - Help Guide
## Purpose
This form is designed to collect and manage project information for food delivery projects. It is a crucial tool for setting up and tracking the progress of these projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the project requirements in the "Project Requirements" field. This section is mandatory and should include all the details about the project.
2. Enter a budget estimation for the project in the "Budget Estimation" field. This will help us determine the scope of the project.
3. Set the expected timeline for the project in the "Expected Timeline" field. This will help us schedule the project's start and end dates.
4. Select the project team lead from the dropdown menu in the "Project Team Lead" field. This is a critical field as it helps us determine who will be responsible for the project's progress.
5. Enter any additional information about the project in the "Additional Info" field. This field is optional, but it's a good idea to include any important details that might be helpful for the project.
6. Select the current project status from the dropdown menu in the "Project Status" field. This helps us track the project's progress.
7. Enter the date when the budget was approved in the "Budget Approved" field, if applicable.
8. Enter the project deadline in the "Project Deadline" field, if applicable.
9. Enter the team size for the project in the "Team Size" field. This is an essential field as it helps us determine the scope of the project.
10. Enter the email address of the project lead in the "Project Lead Email" field. This is a critical field as it helps us contact the lead for updates and progress.
11. Enter the phone number of the project lead in the "Project Lead Phone" field. This is also a critical field as it helps us contact the lead for updates and progress.
12. Enter the name of the project lead in the "Project Lead Name" field. This is a mandatory field.
13. Enter the title of the project lead in the "Project Lead Title" field. This is a mandatory field.
14. Select the status of the project lead from the dropdown menu in the "Project Lead Status" field. This helps us determine if the lead is active, inactive, or on vacation.
15. Enter the company name of the project lead in the "Project Lead Company" field, if applicable.
16. Enter the position of the project lead in the "Project Lead Position" field, if applicable.
17. Enter the address of the project lead in the "Project Lead Address" field, if applicable.
18. Enter any notes about the project lead in the "Project Lead Notes" field.
19. Enter any additional information about the project lead in the "Project Lead Additional Info" field.
20. Enter any notes about the project in the "Project Notes" field.
21. Enter any comments about the project in the "Project Comments" field.
22. Enter the date of submission in the "Submission Date" field. This is a mandatory field.
23. Enter the last updated date and time in the "Last Updated" field, if applicable.
