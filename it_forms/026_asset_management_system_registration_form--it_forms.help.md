# Asset Management System Registration Form - Help Guide
## Purpose
The Asset Management System Registration Form is designed to gather essential information from organizations interested in using our asset management system. This form helps us understand your organization's needs, preferences, and requirements to tailor the system's configuration and setup for a smooth implementation.

## How To Complete This Form

To complete this form, please follow these steps:

1. Ensure you have all the necessary information and approvals to complete the form accurately.
2. Read each section carefully and answer the questions accordingly.
3. Fill out the form in sections, using the provided options for select fields.
4. If you're unsure about any aspect of the form, please reach out to your internal contacts or the asset management system team for clarification.

## Field-by-Field Explanation

* **Organization Name**: Enter the legal name of your organization.
* **Organization Type**: Select the type of organization you belong to (e.g., Business, School or University, Non-Profit, etc.).
* **Primary Contact Person**: Enter the name of the primary contact person for your organization.
* **Contact Title**: Enter the job title of the primary contact person.
* **Email Address**: Enter the email address associated with the primary contact person's account.
* **Phone Number**: Enter the contact phone number for the primary contact person.
* **Organization Address**: Enter the full mailing address of your organization.
* **Number of Employees**: Select the approximate number of employees in your organization.
* **Estimated Number of Assets**: Select the estimated number of assets to be tracked by the system.
* **Asset Categories to Track**: Select all the asset categories that your organization needs to track (e.g., IT Equipment, Office Furniture, Vehicles, etc.).
* **Current Tracking Method**: Select the current method used to track assets (e.g., Spreadsheets, Paper Records, Legacy Software, etc.).
* **Primary Use Case**: Select the main reason for using the asset management system (e.g., Financial Reporting, Maintenance Tracking, Compliance and Audits, etc.).
* **Integration Needs**: Select the systems that you would like to integrate with the asset management system (e.g., Accounting Software, ERP System, etc.). Note that this is not required but can be filled out for future reference.
* **Barcode Scanning Needed**: Select whether barcode scanning is needed for asset tracking.
* **QR Code Needed**: Select whether QR code support is needed for mobile scanning.
* **RFID Needed**: Select whether RFID support is needed for advanced tracking.
* **Number of System Users**: Enter the approximate number of users who will access the system.
* **Deployment Preference**: Select where you would like the system to be hosted (e.g., Cloud Based, On Premises, Hybrid).
* **Budget Range**: Select the approximate annual budget for the system.
* **Desired Implementation Timeline**: Select the desired implementation timeline (e.g., Immediate, Within 1 Month, Within 3 Months, etc.).
* **Training Needed**: Select whether you need full or basic training to use the system effectively.
* **Data Migration Needed**: Select whether you need to transfer existing data to the new system.
* **Special Requirements**: Enter any specific needs or requirements that are not covered in the previous fields.
* **How Did You Hear About Us**: Select how you found out about the asset management system (e.g., Online Search, Referral, Advertisement, etc.). This is not required but can be helpful for marketing and improvement purposes.
* **Registration Date**: Date of registration, will be filled in automatically when you submit the form.

Please fill out the form carefully, and don't hesitate to contact us if you have any questions or concerns.
