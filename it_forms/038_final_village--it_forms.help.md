# Final Village - Help Guide
## Purpose
The Final Village form is used for internal purposes to collect user information for management and tracking.

## How To Complete This Form
To complete the Final Village form, follow these steps:

1. Fill in your **First Name**, **Last Name**, **Email**, and **Phone** fields with the corresponding information.
2. Choose a date for **Date** and **Created At** fields using the calendar picker.
3. Select one of the options for the **Select One** field.
4. Select multiple options for the **Select Multiple** field.
5. If applicable, add a note for **Note** field.
6. Enter a decimal value for the **Decimal** field.
7. Enter an integer value for the **Integer** field.
8. Optionally, enter a Form ID for the **Form ID** field.
9. Ensure the **Updated At** and **Deleted At** fields are left blank.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Enter your first name.
* **Last Name** (`last_name`, text, optional): Enter your last name.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Date** (`date`, date, optional): Choose a date from the calendar picker.
* **Time** (`time`, time, optional): Select a time from the time picker.
* **Select One** (`select_one`, select_one, optional): Choose one option from the list.
* **Select Multiple** (`select_multiple`, select_multiple, optional): Select multiple options from the list.
* **Note** (`note`, note, optional): Add any additional information.
* **Decimal** (`decimal`, number, optional): Enter a decimal value.
* **Integer** (`integer`, number, optional): Enter an integer value.
* **Form ID** (`form_id`, number, optional): Optionally enter a Form ID.
* **Created At** (`created_at`, date, optional): This field is auto-populated and should not be edited.
* **Updated At** (`updated_at`, date, optional): This field is auto-populated and should not be edited.
* **Deleted At** (`deleted_at`, date, optional): This field is used for internal purposes and should not be edited.
