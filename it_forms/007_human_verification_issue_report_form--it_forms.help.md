# Human Verification Issue Report Form - Help Guide
## Purpose
This form is used to report and track human verification issues that require attention.

## How To Complete This Form

To complete this form, follow these steps:

1. Provide a detailed description of the issue in the `Issue Description` field.
2. Select the type of issue (e.g., Low, Medium, High) in the `Issue Type` field.
3. Enter the date when the issue occurred in the `Issue Date` field.
4. Enter the number of prophets or people affected by the issue in the `Issue Prophets` field.
5. Select the severity of the issue (e.g., Low, Medium, High) in the `Issue Severity` field.
6. Select the status of the issue (e.g., New, In Progress, Resolved) in the `Issue Status` field.
7. Enter any additional context about the issue in the `Issue Context` field.
8. Describe the issue steps in the `Issue Steps` field.
9. Attach a screenshot or image related to the issue in the `Issue Screenshot` field.
10. Upload any attachment related to the issue in the `Issue Attachment` field.
11. Enter any additional note or comment about the issue in the `Issue Note` field.
12. Enter a solution to the issue in the `Issue Solution` field.
13. Enter any additional comment about the issue in the `Issue Comment` field.
14. Select any relevant tags for the issue in the `Issue Tags` field.

## Field-by-Field Explanation

* **Issue Description** (1, text, required/optional): A detailed description of the issue.
* **Issue Type** (2, select_one, required/optional): The type of issue (e.g., Low, Medium, High).
* **Issue Date** (3, date, required/optional): The date when the issue occurred.
* **Issue Prophets** (4, number, required): The number of prophets or people affected by the issue.
* **Issue Severity** (5, select_one, required/optional): The severity of the issue (e.g., Low, Medium, High).
* **Issue Status** (6, select_one, required/optional): The status of the issue (e.g., New, In Progress, Resolved).
* **Issue Context** (7, note, required/optional): Additional context about the issue.
* **Issue Steps** (8, text, required/optional): A description of the issue steps.
* **Issue Screenshot** (9, note, required/optional): A screenshot or image related to the issue.
* **Issue Attachment** (10, text, required/optional): An attachment related to the issue.
* **Issue Note** (11, text, required/optional): Additional note or comment about the issue.
* **Issue Solution** (12, text, required): A solution to the issue.
* **Issue Comment** (13, text, required/optional): Additional comment about the issue.
* **Issue Tags** (14, select_multiple, required/optional): Relevant tags for the issue (e.g., tag1, tag2, tag3).

## Tips

* Make sure to provide accurate and detailed information about the issue to help in its resolution.
* Attach any relevant images or attachments to support your report.
* Select the correct issue type and severity to help in prioritizing and resolving the issue.
* Enter any additional context or steps related to the issue to help in understanding it better.
* Enter any additional comment or solution to the issue to help in its resolution.
