# Shelf Optimization Software Access Application Form - Help Guide
## Purpose
This form is used for requesting and managing software access. It provides a standardized way of collecting and tracking information related to software access.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the required fields with your information.
2. Select the correct options for each field.
3. Provide any additional comments or notes if necessary.

## Field-by-Field Explanation
### User Info
**User Info (1)** (`User Info`, `text`, not required): This field is for general information about the user.

*Please enter your name and any other relevant details in this field.*

### Software Access Info
**Software Access Info (2)** (`Software Access Info`, `text`, required): This field is for the software access information.

*Please enter the software title and version if you are requesting access to the software.*

### User Notes
**User Notes (3)** (`User Notes`, `note`, not required): This field is for any additional notes or comments from the user.

*You can enter any additional comments or notes about the software access request.*

### Email
**Email (4)** (`Email`, `email`, required): This field is for the user's email address.

*Please enter your email address.*

### Phone
**Phone (5)** (`Phone`, `text`, not required): This field is for the user's phone number.

*Please enter your phone number if you have one.*

### Software Access Manager
**Software Access Manager (6)** (`Software Access Manager`, `select_one`, required): This field is for selecting the software access manager.

*Please select the software access manager from the list.*

### Software Title
**Software Title (7)** (`Software Title`, `text`, required): This field is for the software title.

*Please enter the software title.*

### Software Version
**Software Version (8)** (`Software Version`, `text`, not required): This field is for the software version.

*Please enter the software version if it's available.*

### Software Features
**Software Features (9)** (`Software Features`, `select_multiple`, not required): This field is for selecting the software features.

*Please select the software features that you need access to.*

### Date of Access Requested
**Date of Access Requested (10)** (`Date of Access Requested`, `date`, required): This field is for the date the software access was requested.

*Please select the date of access requested.*

### Time of Access Requested
**Time of Access Requested (11)** (`Time of Access Requested`, `time`, required): This field is for the time the software access was requested.

*Please select the time of access requested.*

### Date of Access Granted
**Date of Access Granted (12)** (`Date of Access Granted`, `date`, not required): This field is for the date the software access was granted.

*Please select the date the software access was granted if available.*

### Time of Access Granted
**Time of Access Granted (13)** (`Time of Access Granted`, `time`, not required): This field is for the time the software access was granted.

*Please select the time the software access was granted if available.*

### User Acknowledgement
**User Acknowledgement (14)** (`User Acknowledgement`, `select_one`, required): This field is for user acknowledgement.

*Please select acknowledge or decline.*

### Reason for Decline
**Reason for Decline (15)** (`Reason for Decline`, `text`, not required): This field is for reason for decline.

*Please enter the reason for decline if you selected decline.*

### Software Access Level
**Software Access Level (16)** (`Software Access Level`, `select_one`, required): This field is for software access level.

*Please select the software access level.*

### Comments
**Comments (17)** (`Comments`, `note`, not required): This field is for any additional comments.

*You can enter any additional comments about the software access request.*

### Software Access Status
**Software Access Status (18)** (`Software Access Status`, `select_one`, required): This field is for software access status.

*Please select active or inactive.*

### Software Access End Date
**Software Access End Date (19)** (`Software Access End Date`, `date`, not required): This field is for software access end date.

*Please select the software access end date if available.*

### Software Access End Time
**Software Access End Time (20)** (`Software Access End Time`, `time`, not required): This field is for software access end time.

*Please select the software access end time if available.*

### Software Access Duration
**Software Access Duration (21)** (`Software Access Duration`, `time`, not required): This field is for software access duration.

*Please select the software access duration if available.*

### Software Access Last Access
**Software Access Last Access (22)** (`Software Access Last Access`, `time`, not required): This field is for software access last access.

*Please select the software access last access if available.*

### Software Access Last Access By
**Software Access Last Access By (23)** (`Software Access Last Access By`, `select_one`, not required): This field is for software access last access by.

*Please select the software access last access by from the list.*

### User Last Updated By
**User Last Updated By (24)** (`User Last Updated By`, `select_one`, required): This field is for user last updated by.

*Please select the user last updated by from the list.*

### Comments
**Comments (25)** (`Comments`, `note`, not required): This field is for any additional comments.

*You can enter any additional comments about the software access request.*
