# Data Porting Intake Form - Help Guide
## Purpose
The Data Porting Intake Form is used to collect information about the data porting request, ensuring that the request is handled correctly and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the issue field to describe the problem or concern with the data.
2. Provide a detailed description of the issue in the issue description field.
3. If applicable, select the type of data involved (e.g., "Yes" or "No").
4. If relevant, attach a file related to the issue.
5. Specify the date and time the request was made.
6. Enter the name of the person or entity making the request.
7. Indicate the preferred contact method (e.g., Email, Phone, or Chat).

## Field-by-Field Explanation

* **What is the issue** (text): Describe the problem or concern with the data.
* **Issue description** (text): Provide a detailed description of the issue.
* **Data type** (select_one): Select "Yes" or "No" if the issue involves data.
* **Attach file** (text): Attach any relevant files related to the issue.
* **Date requested** (date): Enter the date the request was made.
* **Time requested** (time): Enter the time the request was made.
* **Requestor** (text): Enter the name of the person or entity making the request.
* **Contact method** (select_multiple): Select the preferred contact method (e.g., Email, Phone, or Chat).
