# Security Alarm Reconfiguration Request Form - Help Guide
## Purpose
This form is for customers to request reconfiguration of their existing security alarms. Please ensure that you have been in contact with the security team previously and have been authorized to submit this form.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and contact information (Customer Name, Contact Number, and Contact Email) to help us contact you regarding your request.
2. Select the correct Security Level and Alarm Type to describe the alarm you want to reconfigure.
3. Specify the Alarm Location and Alarm Status to help us locate and verify the alarm.
4. Choose whether the alarm is currently Enabled, Disabled, or Pending.
5. Indicate if you want the alarm reconfigured (True or False).
6. Add any comments or notes about the reconfiguration request.
7. Select the security manager assigned to the reconfiguration request.
8. Add any comments or notes for the security manager.
