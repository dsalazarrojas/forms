# systems_support_log_form - Help Guide
## Purpose
The systems_support_log_form is used to document and track systems support interactions. This form is intended for use when reporting issues or requesting help from the systems support team.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the **Report Form** field with a detailed description of the issue or problem you are experiencing.
2.  Select the relevant **Category** from the provided options to categorize the issue.
3.  Enter the **Date** and **Time** of the incident or issue.
4.  Select the **Category** that best describes the issue, from the options provided.
5.  Enter a detailed **Description** of the problem or issue.
6.  If applicable, enter the **Solution** or resolution to the issue.
7.  Add any additional **Comments** about the issue or interaction.
8.  If applicable, select the **User ID** of the user who submitted the report.
9.  Choose who the issue is **Assigned To** from the provided options.
10.  Select the **Report Type** that best describes the nature of the report, from the options provided.
11.  Finally, set the **Priority** of the issue based on its severity or urgency.

## Field-by-Field Explanation

* **Report Form** (1, text, required/optional): This field is used to describe the issue or problem you are experiencing. Enter a detailed description of the problem.
* **Date** (2, date, required/optional): Enter the date of the incident or issue. This helps track progress and history.
* **Time** (3, time, required/optional): Enter the time of the incident or issue. This helps in scheduling follow-up actions.
* **Category** (4, select_one, required/optional): Choose the category that best describes the issue from the provided options.
* **Description** (5, text, required/optional): Enter a detailed description of the problem or issue.
* **Solution** (6, text, required/optional): If the issue has been resolved, enter the solution or resolution. This helps track progress and closure.
* **Comments** (7, text, required/optional): Add any additional comments or notes about the issue or interaction.
* **User ID** (8, number, required/optional): If applicable, enter the User ID of the user who submitted the report.
* **Assigned To** (9, select_one, required/optional): Choose who the issue is assigned to from the provided options.
* **Report Type** (10, select_multiple, required/optional): Select the report type that best describes the nature of the report from the provided options.
* **Priority** (11, select_one, required/optional): Set the priority of the issue based on its severity or urgency.
