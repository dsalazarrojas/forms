# Server Failure Report Form - Help Guide
## Purpose
The Server Failure Report Form is used to document and report server failures, helping the support team to diagnose and resolve issues efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the server failure (Critical, Non-Critical, or Unknown).
2. Enter the date and time the server failure occurred.
3. Provide the server's IP address and port number.
4. Describe the error message and type of failure in detail.
5. Choose the support person responsible for addressing the issue.
6. Enter any additional information relevant to the failure.
7. Indicate if the issue is reproducible.
8. Specify the resolution status of the issue (Resolved, Pending, or Unknown).
9. Enter the next steps for the support team to take.
10. (Optional) Enter the last updated date, time, and user information.

## Field-by-Field Explanation

* **server_failure_report**:
    * Name: server_failure_report
    * Description: Enter a brief description of the server failure.
* **server_category**:
    * Name: server_category
    * Description: Select the category of the server failure (Critical, Non-Critical, or Unknown).
* **server_date**:
    * Name: server_date
    * Description: Enter the date the server failure occurred.
* **server_time**:
    * Name: server_time
    * Description: Enter the time the server failure occurred.
* **server_ip**:
    * Name: server_ip
    * Description: Enter the IP address of the server that failed.
* **server_port**:
    * Name: server_port
    * Description: Enter the port number of the server that failed.
* **server_error_message**:
    * Name: server_error_message
    * Description: Describe the error message or issue encountered.
* **server_error_type**:
    * Name: server_error_type
    * Description: Select the type of failure (Hardware, Software, or Connection issue).
* **server_support_person**:
    * Name: server_support_person
    * Description: Select the support person responsible for addressing the issue.
* **server_support_contact**:
    * Name: server_support_contact
    * Description: Enter the contact information of the support person (optional).
* **server_support_phone**:
    * Name: server_support_phone
    * Description: Enter the phone number of the support person (optional).
* **server_support_notes**:
    * Name: server_support_notes
    * Description: Enter any additional notes or comments from the support person (optional).
* **server_additional_info**:
    * Name: server_additional_info
    * Description: Enter any additional information relevant to the failure (optional).
* **server_reproducible**:
    * Name: server_reproducible
    * Description: Indicate if the issue is reproducible.
* **server_resolution**:
    * Name: server_resolution
    * Description: Specify the resolution status of the issue (Resolved, Pending, or Unknown).
* **server_next_steps**:
    * Name: server_next_steps
    * Description: Enter the next steps for the support team to take.
* **server_last_updated**:
    * Name: server_last_updated

* **server_updated_by**:
    * Name: server_updated_by
