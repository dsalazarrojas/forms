# Unlock Request Form - Help Guide
## Purpose
The Unlock Request Form is used to request access to a locked resource. This form is designed to gather necessary information from users to facilitate the unlock process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the option that best describes your situation in the **User Input** field.
2. Provide a brief reason for requesting access to the locked resource in the **Reason** field.
3. Enter the date you need the resource unlocked on in the **Date** field.
4. Enter the time you need the resource unlocked on in the **Time** field.
5. If necessary, add any additional notes about your request in the **Notes** field.

## Field-by-Field Explanation

* **User Input**: (`select_multiple`, required: false) Select one or more options to describe your situation. This will help us understand your needs better.
* **Reason**: (`text`, required: false) Please provide a brief reason for requesting access to the locked resource.
* **Date**: (`date`, required: false) Enter the date you need the resource unlocked on. This should be a standard date format (YYYY-MM-DD).
* **Time**: (`time`, required: false) Enter the time you need the resource unlocked on. This should be in 24-hour format (HH:MM:SS).
* **Notes**: (`note`, required: false) Add any additional information about your request that may be helpful for us to consider.
