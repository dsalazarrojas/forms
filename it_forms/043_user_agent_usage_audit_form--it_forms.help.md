# User Agent Usage Audit Form - Help Guide
## Purpose

This form is used to collect information about a user's browser usage, including browser type, version, and plugins, as well as other details such as device type, geo location, and submission date. The form is intended to help IT teams audit and analyze user agent usage across different browsers and devices.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the required fields with accurate information about the user's browser usage.
2. Select the correct browser type and version from the options provided.
3. Choose the correct device type and geo location from the options provided.
4. Enter the user's IP address and device IP address.
5. Add any additional notes for the IT team and the submitter.

## Field-by-Field Explanation

* **User Agent Usage Audit Form** (`user_agent_usage_audit_form`): This is the title of the form, which helps identify the purpose of the form.
* **Browser Session Duration** (`browser_session_duration`): Enter the duration of the user's browser session in seconds.
* **Browser Type** (`browser_type`): Select the type of browser used by the user, such as Chrome, Firefox, Edge, or Safari.
* **Browser Version** (`browser_version`): Enter the version number of the browser being used.
* **Device Model** (`device_model`): This field is not required, but enter the model of the device used by the user, if applicable.
* **Device OS** (`device_os`): Select the operating system used by the device, such as Windows, Android, iOS, or Linux.
* **Device Type** (`device_type`): Choose the type of device used by the user, such as Desktop, Mobile, Tablet, or Watch.
* **Browser Language** (`browser_language`): Select the language used by the browser, such as English, Spanish, French, or Chinese.
* **Geo Location** (`geo_location`): This field is required, but you can select 'No' if the user's location is not available or 'Yes' if it is.
* **User Browser** (`user_browser`): Enter the user's browser, if different from the selected browser type.
* **User Device** (`user_device`): Enter the user's device, if different from the selected device type.
* **Notes** (`notes`): Add any additional comments or notes about the user's browser usage.
* **User Agent** (`user_agent`): Enter the user agent string from the browser.
* **Submitter** (`submitter`): Enter the name of the person submitting the form.
* **Submission Date** (`submission_date`): Enter the date the form was submitted.
* **Submitter Email** (`submitter_email`): Enter the email address of the submitter, if applicable.
* **Notes for Submitter** (`notes_for_submitter`): Add any additional comments or notes for the submitter.
* **Browser Plugins** (`browser_plugins`): Select whether the browser has plugins installed.
* **Geo Timezone** (`geo_timezone`): Select the time zone of the user's location.
* **Geo City** (`geo_city`): Enter the city of the user's location.
* **Geo Country** (`geo_country`): Select the country of the user's location.
* **User IP** (`user_ip`): Enter the user's IP address.
* **Device IP** (`device_ip`): Enter the device's IP address.
* **Notes for IT** (`notes_for_it`): Add any additional comments or notes for the IT team.
* **Notes for Submitter** (`submitter_notes`): Add any additional comments or notes for the submitter.

**Tips**

* Be accurate and thorough when filling out the form.
* Ensure you are submitting the form to the correct IT team or department.
* Use a clear and concise writing style when adding notes or comments.
* If you are unsure about any of the fields, ask your IT department for guidance.
* This form is intended to help IT teams identify and analyze user agent usage, so be detailed and honest in your submissions.
