# Software Beta Program Application - Help Guide
## Purpose
The "Software Beta Program Application" form is designed for users to apply to the beta program for testing and development purposes. The form collects information about the user's background, experience, and motivation for joining the beta program.
## How To Complete This Form
To complete this form, follow these steps:
1. Provide your user input, which includes your name or any other relevant information about yourself.
2. Choose the type of application you're interested in, which can be Testing, Beta Development, or Other.
3. If you have experience, please provide the number of years you've had it.
4. Explain why you want to join the beta program (optional).
5. Enter any additional information about yourself (optional).
6. Select whether you agree to participate in the beta program.
7. Finally, provide your company name (if applicable).

## Field-by-Field Explanation

* **User Input** (`user_input`, text, required): This field is where you'll enter your name or any other relevant information about yourself. Please make sure to provide accurate and complete information.
* **Application Type** (`application_type`, select_multiple, required): Choose the type of application you're interested in, such as Testing, Beta Development, or Other. Select all relevant options that apply.
* **Experience** (`experience`, number, optional): If you have experience, please provide the number of years you've had it. This will help us understand your qualifications for the beta program.
* **Motivation** (`motivation`, text, optional): Explain why you want to join the beta program. This will help us understand your interests and goals.
* **Tester Info** (`tester_info`, note, optional): This field is not required, but if you have any additional information about yourself, you can enter it here.
* **Contact Info** (`contact_info`, text, optional): Enter any additional contact information you'd like to provide (e.g., email, phone number, etc.).
* **Agree** (`agree`, select_one, required): Select whether you agree to participate in the beta program. You must agree to participate to be eligible.
