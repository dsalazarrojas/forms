# HR System Migration Application Form - Help Guide
## Purpose
This form is for collecting information from users for HR system migration. It is only to be used for this purpose and not for other tasks.

## How To Complete This Form
1. Start by providing your User Information, which includes your name and contact details.
2. In the next section, list your HR System Migration Requests, which should include any specific requirements or issues you need to be addressed during the migration.
3. Please provide your Objectives for the migration process, so we can understand your goals and expectations.
4. Next, specify your Timelines for completion, including deadlines and milestones.
5. Indicate if any IT Teams are involved in the migration process.
6. Similarly, indicate if any HR Teams are involved in the migration process.
7. Confirm if the HR System has specific System Requirements that need to be met during the migration.
8. Specify if you have a Migration Plan in place or if one needs to be created.
9. Provide any additional Notes about the migration process.
10. If you have any Attachments or supporting documents, please upload them here.
11. Finally, click the Submit button to complete the form, or click Cancel to exit without submitting.

## Field-by-Field Explanation
* **User Information** (`User Information`, `text`, required: false): Please provide your name and contact details so we can reach you for further clarification.
* **HR System Migration Requests** (`HR System Migration Requests`, `text`, required: false): List any specific requirements or issues you need to be addressed during the migration.
* **Objectives** (`Objectives`, `note`, required: false): Explain your goals and expectations for the migration process.
* **Timelines** (`Timelines`, `time`, required: false): Specify your deadlines and milestones for completion.
* **IT Teams Involved** (`IT Teams Involved`, `select_multiple`, required: false): Check 'Yes' if any IT teams are involved in the migration process.
* **HR Teams Involved** (`HR Teams Involved`, `select_multiple`, required: false): Check 'Yes' if any HR teams are involved in the migration process.
* **System Requirements** (`System Requirements`, `select_one`, required: false): Confirm if the HR System has specific requirements that need to be met during the migration.
* **Migration Plan** (`Migration Plan`, `select_multiple`, required: false): Specify if you have a migration plan in place or if one needs to be created.
* **Notes** (`Notes`, `note`, required: false): Provide any additional comments or details about the migration process.
* **Attachments** (`Attachments`, `text`, required: false): Upload any supporting documents or files related to the migration process.
* **Submit** (`Submit`, `text`, required: false): Click to complete and submit the form.
* **Cancel** (`Cancel`, `text`, required: false): Click to exit without submitting the form.
