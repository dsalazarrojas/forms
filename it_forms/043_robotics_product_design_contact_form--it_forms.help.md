# robotics_product_design_contact_form - Help Guide
## Purpose
This form collects information from users who want to submit a project proposal for a robotics product design project.

## How To Complete This Form
To complete this form, follow the steps below:

1. In the **Form Info** field, provide a brief description of your project proposal.
2. In the **Project Info** field, provide more details about your project.
3. Select the type of application you are submitting, from the options provided in **Application Type** field.
4. In the **Project Requirements** field, list the requirements of your project.
5. In the **Robot Type** field, select the type of robot you are proposing.
6. Enter the duration of your project in the **Project Duration** field.
7. Enter the deadline of your project in the **Project Deadline** field.
8. In the **Project Status** field, provide a brief status of your project.
9. In the **Robot Status** field, provide a brief status of your robot.

## Field-by-Field Explanation

* **Form Info** (Text, Optional): A brief description of your project proposal.
* **Project Info** (Text, Optional): More details about your project.
* **Application Type** (Select One, Optional): The type of application you are submitting.
*   * option 1: Select this option for project type 1.
*   * option 2: Select this option for project type 2.
*   * option 3: Select this option for project type 3.
* **Project Requirements** (Text, Optional): List the requirements of your project.
* **Robot Type** (Select Multiple, Optional): The type of robot you are proposing.
*   * option 1: Select this option for robot type 1.
*   * option 2: Select this option for robot type 2.
*   * option 3: Select this option for robot type 3.
* **Project Duration** (Number, Optional): Enter the duration of your project.
* **Project Deadline** (Date, Optional): Enter the deadline of your project.
* **Project Status** (Text, Optional): A brief status of your project.
* **Robot Status** (Text, Optional): A brief status of your robot.

## Tips

* Please ensure that the information you provide is accurate and relevant to your project proposal.
* If you have any questions or need help, do not hesitate to contact us.
* We will review your proposal and get back to you soon.
