# Crowdstrike Outage Report Form - Help Guide
## Purpose
The Crowdstrike Outage Report Form is used to report and track service outages, their causes, impacts, and corrective actions taken. This form is essential for IT teams to communicate and coordinate the status of service outages, ensure prompt resolution, and maintain up-to-date records.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if the service was affected by an outage ('True' or 'False').
2. Enter the date of the service outage ('MM/DD/YYYY').
3. Specify the time of the service outage.
4. Select the impact level of the outage (Low, Medium, or High).
5. Describe the cause of the outage.
6. Indicate if a corrective action was planned ('True' or 'False').
7. Describe the corrective action taken.
8. Select the IT proponent responsible for the outage (John Doe, Jane Doe, or Jimmy Doe).
9. Optionally, enter any additional notes about the outage.
10. Select the service name affected by the outage (Service A, Service B, or Service C).
11. Select the type of service affected (Network or System).
12. Select the location affected (Location 1, Location 2, or Location 3).
13. Enter the duration of the outage in minutes.
14. Specify if the outage was a one-time or recurring event (Once or Multiple).
15. Indicate if the outage was a scheduled or unplanned event (Scheduled or Unplanned).
16. Optionally, enter a description of the impact type (e.g., "System crashed").
17. Optionally, enter any additional notes about the outage.
18. Optionally, enter any additional notes about the outage.

## Field-by-Field Explanation

* **Service Outage**: This field determines if a service was affected by an outage ('True' or 'False').
* **Service Outage Date**: Enter the date of the service outage in 'MM/DD/YYYY' format.
* **Service Outage Time**: Specify the time of the service outage.
* **Impact**: Select the impact level of the outage (Low, Medium, or High).
* **Cause**: Describe the reason for the service outage.
* **Corrective Action Planned**: Indicate if a corrective action was planned ('True' or 'False').
* **Corrective Action Taken**: Describe the corrective action taken.
* **IT Proponent**: Select the person responsible for the outage (John Doe, Jane Doe, or Jimmy Doe).
* **Notes**: Optionally, enter any additional information about the outage.
* **IT Proponent 2**: This field is optional and allows you to enter a secondary IT proponent.
* **Notes 2**: This field is optional and allows you to enter any additional information about the outage from another perspective.
* **Service Name**: Select the service affected by the outage (Service A, Service B, or Service C).
* **Service Type**: Select the type of service affected (Network or System).
* **Location**: Select the location affected (Location 1, Location 2, or Location 3).
* **Duration**: Enter the duration of the outage in minutes.
* **Frequency**: Indicate if the outage was a one-time or recurring event (Once or Multiple).
* **Recurrence**: Indicate if the outage was a recurring event ('True' or 'False').
* **Impact Type**: Optionally, specify the type of impact (e.g., "System crashed").
* **Impact Description**: Optionally, enter a description of the impact type.
* **Notes 3**: Optionally, enter any additional information about the outage.

This guide should cover all the essential fields and provide users with a clear understanding of the form's purpose, how to complete it, and what each field entails.
