# telecom_network_reliability_inquiry_form - Help Guide
## Purpose
This form is used to collect information about telecom network reliability inquiries, helping telecom service providers or network administrators to gather data about issues affecting their network.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your location, if applicable.
2. Select the start and end times of the incident, if known.
3. Describe the issue you are experiencing.
4. If applicable, select the issue priority level, issue type, and issue category.
5. Specify the location and services affected.
6. Select the network services affected.
7. Update the incident status.

## Field-by-Field Explanation
* **What is your location** (location, text, optional): This field is for entering your location, which will help the team to better understand the issue and allocate resources accordingly.
* **Incident start time** (incident_start_time, time, optional): Enter the start time of the incident, if known.
* **Incident end time** (incident_end_time, time, optional): Enter the end time of the incident, if known.
* **Describe the issue** (issue_description, text, optional): Provide a detailed description of the issue you are experiencing.
* **Issue priority level** (issue_priority, select_one, optional): Select the priority level of the issue from the available options (High, Medium, Low).
* **Issue type** (issue_type, select_one, optional): Choose the type of issue from the available options (Network Outage, Equipment Issue, Customer Issue, Other).
* **Issue category** (issue_category, select_one, optional): Select the category of the issue from the available options (Power and Energy, Connectivity, Voice Services, Data Services).
* **Location of services affected** (location_services_affected, select_multiple, optional): Select the services affected from the available options (Mobile, Fixed, Data, Voice).
* **Network services affected** (network_services_affected, select_multiple, optional): Choose the network services affected from the available options (Mobile, Fixed, Data, Voice).
* **Incident status** (incident_status, select_one, optional): Select the status of the incident from the available options (Active, Resolved, Pending).

## Tips
* Be as specific as possible when describing the issue.
* If you are unsure about any of the options, please choose the one that best fits your situation.
* This form is designed to be completed by telecom network administrators or service providers to help identify and prioritize issues affecting their network.
