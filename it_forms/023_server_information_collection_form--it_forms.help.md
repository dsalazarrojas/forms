# Server Information Collection Form - Help Guide
## Purpose
The Server Information Collection Form is used to gather comprehensive information about servers, including their status, location, and technical specifications.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the Server Type field by selecting the type of server (Physical, Virtual, or Cloud) from the dropdown list.
2. Enter the Server Name as it appears in the inventory.
3. Provide the Server IP address.
4. Enter the Server OS version.
5. Enter the Server software version.
6. Fill in the Server Location.
7. Add any additional notes about the server (optional).
8. Enter the Server Phone number.
9. Enter the Server Email address.
10. Select the company that owns this server from the list.
11. Select the status of the server (Active or Inactive).
12. Enter the Server Model.
13. Enter the Server RAM in GB.
14. Enter the Server Storage in GB.
15. Enter the Server Cores.
16. Enter the Server CPU.
17. Enter the Server Date.
18. Enter the Server Time.
19. Enter the Server Vendor.

## Field-by-Field Explanation

* **Page 1** (`page_1`, text, optional): This page is the introduction to the form.
* **Server Details** (`page_2`, text, optional): This page contains fields for gathering server information.
	+ **Server Type** (`server_type_id`, select_one, optional): Select the type of server (Physical, Virtual, or Cloud).
	+ **Server Name** (`server_name`, text, optional): Enter the server name as it appears in the inventory.
	+ **Server IP** (`server_ip`, text, optional): Enter the server IP address.
	+ **Server OS** (`server_os`, text, optional): Enter the server OS version.
	+ **Server Version** (`server_version`, text, optional): Enter the server software version.
	+ **Server Location** (`server_location`, text, optional): Enter the server location.
	+ **Note** (`page_2_note`, note, optional): Add any additional notes about the server.
	+ **Phone** (`page_2_phone`, text, optional): Enter the server phone number.
	+ **Email** (`page_2_email`, email, optional): Enter the server email address.
	+ **Company** (`page_2_company`, select_multiple, optional): Select the company that owns this server.
	+ **Server Status** (`page_2_status`, select_multiple, optional): Select the status of the server (Active or Inactive).
* **Page 3** (`page_3`, text, optional): This page is for additional information.
* **Server Model** (`server_model`, text, optional): Enter the server model.
* **Server RAM** (`server_ram`, number, optional): Enter the server RAM in GB.
* **Server Storage** (`server_storage`, number, optional): Enter the server storage in GB.
* **Server Cores** (`server_cores`, number, optional): Enter the server cores.
* **Page 4** (`page_4`, text, optional): This page is for additional information.
* **Server CPU** (`server_cpu`, text, optional): Enter the server CPU.
* **Server Date** (`server_date`, date, optional): Enter the server date.
* **Server Time** (`server_time`, time, optional): Enter the server time.
* **Page 5** (`page_5`, text, optional): This page is for additional information.
* **Server Vendor** (`server_vendor`, text, optional): Enter the server vendor.
* **Submit** (`submit`, text, optional): Submit the form.
