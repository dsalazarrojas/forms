# Member Information Security Risk Assessment - Help Guide
## Purpose
This form is designed to help you assess the security risks associated with a member's online activities. It is meant to be completed by the member themselves, or by someone who has had a chance to speak with them. The assessment will help you understand their level of awareness about various security-related topics, their training readiness, and their concerns about online safety.

## How To Complete This Form
1. Please answer each question honestly and to the best of your ability.
2. If you are unsure about any of the questions, please ask for help from the person responsible for completing this form.
3. Please complete each field as instructed.

## Field-by-Field Explanation
* **Employee Insights** (`employee_insights`, text, optional): This field is for any additional insights or comments that can help us better understand the member's situation.
* **Security Awareness** (`security_awareness`, select_one, optional): Please select how likely you are to be aware of security risks associated with online activities. Choose one of the following options: Phishing and Email, Online Safety and Security, or Password Policy.
* **Training Readiness** (`training_readiness`, number, optional): Please enter a number that indicates how ready you are to receive security training. This will help us understand your level of knowledge and preparation.
* **Phishing Readiness** (`phishing_readiness`, select_one, optional): Please select how likely you are to be targeted by phishing attacks. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Security Knowledge** (`security_knowledge`, number, optional): Please enter a number that indicates how knowledgeable you are about security-related topics.
* **Security Concerns** (`security_concerns`, text, optional): This field is for any concerns you have about online safety.
* **Follow Up** (`follow_up`, select_multiple, optional): Please select how often you would like to be followed up on regarding your security awareness and training. Choose one of the following options: 3, 30, or 60.
* **Security Awareness Training** (`security_awareness_training`, select_multiple, optional): Please select how often you have received security awareness training. Choose one of the following options: 1, 2, or 3.
* **Phishing Training** (`phishing_training`, select_multiple, optional): Please select how often you have received phising training. Choose one of the following options: 1, 2, or 3.
* **Security Readiness** (`security_readiness`, select_multiple, optional): Please select how ready you are to receive security training. Choose one of the following options: 1, 2, or 3.
* **Security Concerns Frequency** (`security_concerns_frequency`, select_multiple, optional): Please select how often you have concerns about online safety. Choose one of the following options: 1, 2, or 3.
* **Follow Up Frequency** (`follow_up_frequency`, select_multiple, optional): Please select how often you would like to be followed up on regarding your security awareness and training. Choose one of the following options: 1, 2, or 3.
* **Security Awareness Frequency** (`security_awareness_frequency`, select_multiple, optional): Please select how often you are reminded about security awareness. Choose one of the following options: 1, 2, or 3.
* **Training Frequency** (`training_frequency`, select_multiple, optional): Please select how often you have received security training. Choose one of the following options: 1, 2, or 3.
* **Email Readiness** (`email_readiness`, select_one, optional): Please select how likely you are to be targeted by email-based attacks. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Online Safety** (`online_safety`, select_one, optional): Please select how likely you are to be aware of online safety risks. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Password Policy** (`password_policy`, select_one, optional): Please select how likely you are to follow password policies. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Password Security** (`password_security`, select_one, optional): Please select how secure you think your passwords are. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Security Standards** (`security_standards`, select_one, optional): Please select how likely you are to follow security standards. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Conduct** (`conduct`, select_one, optional): Please select how likely you are to follow security protocols. Choose one of the following options: Highly Likely, Somewhat Likely, or Not Likely.
* **Security Readiness Reasons** (`security_readiness_reasons`, text, optional): This field is for any reasons you might not be ready for security training.
* **Additional Comments** (`additional_comments`, text, optional): This field is for any additional comments or concerns you have.
* **Follow-Up Notes** (`follow_up_notes`, text, optional): This field is for any follow-up notes or comments.
* **Security Risks** (`security_risks`, text, optional): This field is for any additional security concerns or risks you have.
* **Follow Up Schedule** (`follow_up_schedule`, text, optional): This field is for any follow-up schedule or deadlines.

## Tips
* Please answer each question honestly and to the best of your ability.
* If you are unsure about any of the questions, please ask for help from the person responsible for completing this form.
* This form should be completed once for each member, and only once you have had a chance to speak with them.
* If you have already assessed the member's security risks, please do not use this form.
