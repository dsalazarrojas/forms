# server_health_checklist_form - Help Guide
## Purpose
The server health checklist form is used to collect information about a server's health status, performance, and resource utilization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the server you want to check the health status of.
2. Answer the questions about the server's performance, status, version, and resource utilization.
3. Fill in the relevant fields with accurate information.
4. Submit the form to save your input.

## Field-by-Field Explanation

* **server performance**: Enter a numerical value to rate the server's performance. A higher value indicates better performance.
* **server status**: Select the current status of the server, such as "active" or "inactive".
* **server version**: Enter the version of the server software or firmware.
* **server uptime**: Enter the time the server has been running.
* **memory usage**: Enter the percentage of memory used by the server.
* **cpu usage**: Enter the percentage of CPU used by the server.
* **network traffic**: Enter the amount of network traffic the server is generating.
* **disk space**: Enter the amount of disk space used by the server.
* **system logs**: Enter any relevant system logs for the server.
* **backup status**: Select the backup status, such as "complete" or "incomplete".
* **server reboot**: Select the reboot status, such as "rebooted" or "not rebooted".
* **server status 2**: Select the current status of the server 2. This field is similar to "server status".
* **server reboot 2**: Select the reboot status of server 2, such as "rebooted" or "not rebooted".
* **server uptime 2**: Enter the time server 2 has been running.
* **server version 2**: Enter the version of server 2 software or firmware.
* **server performance 2**: Enter a numerical value to rate the performance of server 2. A higher value indicates better performance.
* **memory usage 2**: Enter the percentage of memory used by server 2.
* **disk space 2**: Enter the amount of disk space used by server 2.
* **system logs 2**: Enter any relevant system logs for server 2.
