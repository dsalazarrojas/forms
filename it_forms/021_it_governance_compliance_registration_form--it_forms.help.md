# it-governance-compliance-registration-form - Help Guide
## Purpose
This form is used for the registration of IT governance compliance within an organization. It aims to collect information on an organization's current state of IT compliance, including areas of compliance, documentation, centralization, and involvement of IT forms and teams.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the registration form (Section 1)
2. Select the relevant compliance areas (Section 2)
3. Upload any relevant documentation (Section 4)
4. Specify whether data is centralized (Section 5)
5. Select the relevant IT forms (Section 6)
6. Select the relevant IT, Risk, and Audit teams (Section 7)

## Field-by-Field Explanation
### Registration (Section 1)
* **Registration**: Enter your organization's name or identifier.
* Type: text
* Required: false

### Compliance Areas (Section 2)
* **Compliance Areas**: Select one or more areas of compliance that apply to your organization.
* Type: select_multiple
* Options: IT, Risk, and Audit, Data Security, Cyber Security

### Organization (Section 3)
* **Organization**: Enter your organization's name.
* Type: text
* Required: false

### Upload Documentation (Section 4)
* **Upload Documentation**: Upload any relevant documentation or attachments.
* Type: note
* Required: false

### Centralize Data (Section 5)
* **Centralize Data**: Specify whether your organization's data is centralized.
* Type: text
* Required: false

### IT Forms (Section 6)
* **IT Forms**: Select one relevant IT form from the options.
* Type: select_one
* Options: IT, Risk, and Audit, Data Security, Cyber Security

### IT, Risk, and Audit Teams (Section 7)
* **IT, Risk, and Audit Teams**: Select one or more teams relevant to your organization.
* Type: select_multiple
* Options: IT, Risk, and Audit, Data Security, Cyber Security

## Tips
* Please fill out as much information as possible.
* Make sure to upload relevant documentation if required.
* Review and submit the form when complete.
