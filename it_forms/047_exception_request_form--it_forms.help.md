# Exception Request Form - Help Guide
## Purpose
This form is designed to collect information about exceptions that have occurred on-site. Exceptions are unusual events or issues that require immediate attention from the IT department. By filling out this form, you will be able to provide a clear and concise description of the problem, the job that was affected, and the solution or action taken to resolve the issue.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title of the exception request form.
2. Select a category for the exception from the drop-down menu (e.g., IT Forms, Support, etc.).
3. Enter a brief description of the job that was affected by the exception.
4. Indicate whether a solution was applied to the problem.
5. Enter the date and time the exception occurred.

## Field-by-Field Explanation
* **exception_request_form** (Title, text, optional): Enter a brief title for the exception request form.
* **category** (Select One, required): Select a category for the exception from the drop-down menu. This helps us understand the type of exception that occurred.
* **job_description** (Text, required): Provide a brief description of the job that was affected by the exception. This will help us understand the impact of the exception.
* **solution** (Select Multiple, required): Check all the boxes that apply to indicate whether a solution was applied to the problem.
* **date** (Date, required): Enter the date the exception occurred.
* **time** (Time, required): Enter the time the exception occurred.
* **problem** (Text, required): Describe the problem that occurred.
* **solution_details** (Text, required): If a solution was applied, provide a brief description of the steps taken to resolve the issue.

## Tips
* Please make sure to fill out all required fields.
* If you are unsure about a category or solution, select "Other" and describe the exception in the problem field.
* If you have any questions or need help with filling out this form, please contact your IT representative.
