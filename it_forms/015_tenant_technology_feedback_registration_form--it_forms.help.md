# Tenant Technology Feedback Registration Form - Help Guide
## Purpose
The Tenant Technology Feedback Registration Form is a tool for tenants to provide feedback about the technology used in their unit. The information gathered from this form will help identify areas of improvement and inform future development and maintenance of the technology.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question in as much detail as possible, using the text boxes provided for longer responses.
2. For yes/no questions, select the answer that best reflects your experience with the technology.
3. Make sure to check the required fields before submitting the form.

## Field-by-Field Explanation

* **Feedback** (page_1, text, required):
	+ This is the main feedback section. Please describe any issues, problems, or suggestions you have about the technology.
* **Technology** (page_2, select_one, required):
	+ Select "Yes" if you are currently using and satisfied with the technology.
	+ Select "No" if you are not using the technology or are not satisfied.
* **Building** (page_3, text, optional):
	+ Describe your building or unit, if applicable.
* **In Unit Technology** (page_4, number, optional):
	+ Enter a numerical value to indicate the number of technologies you have in your unit.
* **Property Manager** (page_5, select_multiple, required):
	+ Select "Yes" if you have a property manager who manages your unit's technology.
	+ Select "No" if you do not have a property manager.
* **Contact** (page_6, text, optional):
	+ Provide any additional contact information or comments.
* **Note** (page_7, note, optional):
	+ This is a free-form text field for any additional information or notes you'd like to add.
* **Date** (page_8, date, required):
	+ Enter the date you completed this form.
* **Time** (page_9, time, optional):
	+ Enter the time you completed this form, if you'd like to provide more detail.
* **Tenant Experience** (page_10, select_one, required):
	+ Select "Yes" if you have had a positive experience with the technology.
	+ Select "No" if you have not had a positive experience.
* **Suggestions** (page_11, text, optional):
	+ This is another free-form text field for any additional suggestions or ideas you have about the technology.

## Tips
- Make sure to answer all required fields before submitting the form.
- If you have any further questions or need clarification, please don't hesitate to contact us!
