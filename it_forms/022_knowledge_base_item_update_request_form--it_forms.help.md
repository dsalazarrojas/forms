# Knowledge Base Item Update Request Form - Help Guide

## Purpose

This form is used to update existing knowledge base items. It's intended for use when you need to make changes to an item's details, such as its title, content, or associated metadata. Please only use this form if you have a valid knowledge base item to update and have permission to do so.

## How To Complete This Form

To update a knowledge base item, follow these steps:

1. Select "Yes" or "No" from the "first_page_label" dropdown to indicate whether you've previously checked the knowledge base item.
2. Enter any additional text information in the "text_field_label" field.
3. Select a date for the update in the "date_field_label" field.
4. Enter a time for the update in the "time_field_label" field.
5. Enter an email address in the "email_field_label" field.
6. Enter a phone number in the "phone_field_label" field.

## Field-by-Field Explanation

* **first_page_label** (`first_page`, Select Multiple, Optional): Select "Yes" if you have previously checked the knowledge base item, "No" otherwise.
* **text_field_label** (`text_field`, Text, Optional): Enter any additional text information to update the knowledge base item.
* **date_field_label** (`date_field`, Date, Optional): Select a date for the update.
* **time_field_label** (`time_field`, Time, Optional): Select a time for the update.
* **email_field_label** (`email_field`, Email, Optional): Enter an email address associated with the update.
* **phone_field_label** (`phone_field`, Text, Optional): Enter a phone number associated with the update.

## Tips

* Make sure to fill out all required fields before submitting the form.
* Use the "first_page" field to indicate if you've previously checked the knowledge base item.
* Use the "date_field" field to select a specific date for the update, not just any date.
