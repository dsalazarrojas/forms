# Technical Project Work Order Form - Help Guide
## Purpose
The Technical Project Work Order Form is used by internal teams or departments to create, manage, and track technical projects.

## How To Complete This Form
To complete the form, follow these steps:

1. Ensure you have filled out all required fields and have the necessary permissions to submit the form.
2. Select the project's priority level (Low, Medium, or High).
3. Choose the start and end dates for the project.
4. Specify the project's status and tags.
5. Select the team members assigned to the project.
6. Provide any additional comments, contact information, and other relevant details.

## Field-by-Field Explanation

* **Form Header** (`form_header`, `text`, required): Enter a brief description of the project.
* **Owner** (`owner`, `select_one`, optional): Select the team member or department that will lead the project.
* **Requestor** (`requestor`, `select_one`, optional): Select the team member or department that requested the project.
* **Priority** (`priority`, `select_multiple`, optional): Select the project's priority level (Low, Medium, or High).
* **Deadline** (`deadline`, `date`, optional): Enter the project's deadline date.
* **Start Date** (`start_date`, `date`, optional): Enter the project's start date.
* **End Date** (`end_date`, `date`, optional): Enter the project's end date.
* **Assigned To** (`assigned_to`, `select_one`, optional): Select the team member(s) assigned to the project.
* **Comments** (`comments`, `text`, optional): Provide any additional comments or details about the project.
* **Tags** (`tags`, `select_multiple`, optional): Select relevant tags for the project (Tag 1, Tag 2, etc.).
* **Status** (`status`, `select_one`, optional): Select the current status of the project (Open, Closed, etc.).
* **Notes** (`notes`, `text`, optional): Enter any additional notes or details about the project.
* **Contact Info** (`contact_info`, `text`, optional): Provide the contact information for the project.
* **Contact Name** (`contact_name`, `text`, optional): Enter the name of the contact person or department.
* **Email** (`email`, `email`, optional): Enter the email address of the contact person or department.
* **Phone** (`phone`, `text`, optional): Enter the phone number of the contact person or department.
* **Location** (`location`, `text`, optional): Enter the location where the project will take place.
* **Work Order Number** (`work_order_number`, `text`, optional): Enter the work order number for the project.
* **Description** (`description`, `text`, optional): Enter a brief description of the project.
* **Assigned Tool** (`assigned_tool`, `text`, optional): Enter the tool assigned to the project.
* **Assigned Tool Version** (`assigned_tool_version`, `text`, optional): Enter the version of the tool assigned to the project.
* **Project Name** (`project_name`, `text`, optional): Enter the name of the project.
* **Project Number** (`project_number`, `text`, optional): Enter the project number.
* **Project Status** (`project_status`, `text`, optional): Enter the current status of the project.
* **Notes** (`notes`, `text`, optional): Enter any additional notes or details about the project.

## Tips

* Please ensure you have all necessary permissions before submitting the form.
* If you are unsure about any field, please ask your supervisor or project lead for clarification.
* Double-check your entries for accuracy and completeness before submitting the form.
* If you need to update the form, please use the most recent version of the form available.
