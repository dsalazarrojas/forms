# information_security_assessment_form - Help Guide
## Purpose
This form is used to collect security-related information from users or systems. The form consists of multiple pages, each focusing on a specific aspect of the assessment, such as user input, system input, and security input.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct page for the information you need to provide:
	* User Input Page (Page 1)
	* System Input Page (Page 2)
	* Security Input Page (Page 3)
2. Fill out the required fields on each page. These fields are marked with a "required: true" tag.
3. For fields with multiple options (e.g., "Attachments"), select one or more of the available options.
4. Add any additional comments or notes as needed.
5. Review and submit the form.

## Field-by-Field Explanation

* **User Input Page (Page 1)**
	+ **Minimalist Goal** (Text, required): Enter the goal or objective of the assessment.
	+ **Minimalist Objective** (Text, required): Enter the objective of the assessment.
	+ **Minimalist Success** (Text, required): Enter the success criteria for the assessment.
	+ **Minimalist Input** (Text, required): Enter any additional input relevant to the assessment.
* **System Input Page (Page 2)**
	+ **Minimalist Goal** (Text, required): Enter the goal or objective of the assessment.
	+ **Minimalist Objective** (Text, required): Enter the objective of the assessment.
	+ **Minimalist Success** (Text, required): Enter the success criteria for the assessment.
	+ **Minimalist Input** (Text, required): Enter any additional input relevant to the assessment.
* **Security Input Page (Page 3)**
	+ **Minimalist Goal** (Text, required): Enter the goal or objective of the assessment.
	+ **Minimalist Objective** (Text, required): Enter the objective of the assessment.
	+ **Minimalist Success** (Text, required): Enter the success criteria for the assessment.
	+ **Minimalist Input** (Text, required): Enter any additional input relevant to the assessment.
* **Date and Time** (Text, required): Enter the date and time of the assessment.
* **Comments** (Note, optional): Add any additional comments or notes about the assessment.
* **User Comments** (Note, optional): Add any comments or notes from the user.
* **System Comments** (Note, optional): Add any comments or notes from the system.
* **Security Comments** (Note, optional): Add any comments or notes about the security aspect of the assessment.
* **Attachments** (Select Multiple, optional): Attach any relevant files or documents to the assessment.
* **Notes** (Note, optional): Add any additional notes about the assessment.
* **Attachments** (Select Multiple, optional): Select whether attachments are allowed.
