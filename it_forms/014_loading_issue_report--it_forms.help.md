# Loading Issue Report - Help Guide
## Purpose
The purpose of this form is to report loading-related issues, such as delays, damage, or other problems, to help track and analyze these issues.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Issue Type" field to indicate the type of issue that occurred (e.g. Loading, Unloading, Delay, Damage, or Other).
2. Enter a brief description of the issue in the "Issue Description" field.
3. If applicable, upload any relevant images or documents to support your report in the "Image Upload" and "Document Upload" fields.
4. Provide any additional information related to the issue in the "Additional Info" field.
5. Enter the "Facility Id", "Carrier Id", and "Dock Id" fields with the relevant IDs.
6. Select the "Solution Status" field to indicate the current status of the solution (e.g. In Progress, Done, Not Required).
7. If the issue has been resolved, provide the date and time it was resolved in the "Solution Date" and "Solution Time" fields, respectively.
8. Optionally, provide any follow-up information in the "Follow-up" field.

## Field-by-Field Explanation
* **Loading Issue Report**: A description of the form, which is not a field you need to fill out.
* **Date**: The date the issue occurred.
* **Facility Id**: A unique identifier for the facility where the issue occurred.
* **Carrier Id**: A unique identifier for the carrier responsible for the issue.
* **Dock Id**: A unique identifier for the dock where the issue occurred.
* **Issue Type**: A field to select the type of issue that occurred (e.g. Loading, Unloading, Delay, Damage, or Other).
* **Issue Description**: A brief description of the issue.
* **Image Upload**: An optional field to upload images or photos related to the issue.
* **Document Upload**: An optional field to upload relevant documents related to the issue.
* **Additional Info**: A field to provide any additional information related to the issue.
* **Solution Status**: A field to indicate the current status of the solution (e.g. In Progress, Done, Not Required).
* **Solution Details**: An optional field to provide additional details about the solution.
* **Solution Date**: The date the solution was implemented, if applicable.
* **Solution Time**: The time the solution was implemented, if applicable.
* **Follow-up**: An optional field to provide any follow-up information.

Note: This form is designed to be completed in a timely manner to ensure that issues are addressed efficiently and effectively.
