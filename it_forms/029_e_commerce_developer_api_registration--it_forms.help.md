# E Commerce Developer API Registration - Help Guide
## Purpose
This form is designed to collect registration information from e-commerce developers who want to access the platform's API for various purposes such as accessing the platform's API, integrating it into their system, or subscribing to its services.

## How To Complete This Form
1. Fill out all the required fields to provide detailed information about yourself and your intended use of the API.
2. Select the relevant options for your intended use of the API from the "Intended API Use" field.
3. Enter your contact information including your name, email, and phone number for the platform's administrators to reach out to you.
4. If you have any API keys, enter them in the corresponding fields.
5. Confirm that you have accepted the terms and conditions of the platform.

## Field-by-Field Explanation

* **Platform Name** (`platform_name`, text, optional): Enter the name of your platform.
* **Intended API Use** (`intended_use`, select_multiple, optional): Select all the relevant options from the list:
	+ API Access
	+ API Integration
	+ API Subscription
* **API Keys** (`api_keys`, select_one, optional): Select the type of API keys you need:
	+ Public API Keys
	+ Private API Keys
* **API Version** (`api_version`, text, optional): Enter the API version you require.
* **API Usage Details** (`api_usage_details`, select_one, optional): Select the API usage details:
	+ API Usage 1
	+ API Usage 2
	+ API Usage 3
* **API Terms Agreement** (`api_agreement`, note, optional): This field is for you to acknowledge that you have read and accepted the terms and conditions of the platform.
* **Contact Name** (`contact_name`, text, optional): Enter your name for the platform's administrators to reach out to you.
* **Contact Email** (`contact_email`, email, optional): Enter your email address for the platform's administrators to reach out to you.
* **Contact Phone** (`contact_phone`, text, optional): Enter your phone number for the platform's administrators to reach out to you.
* **Contact Phone (Alt)** (`contact_phone_alternate`, select_one, optional): Select the type of phone number you have:
	+ Mobile
	+ Landline
	+ Fax
* **API Key 1** (`api_key_1`, text, optional): Enter your API key 1.
