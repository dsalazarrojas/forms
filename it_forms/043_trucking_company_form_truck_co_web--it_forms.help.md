# Trucking Company Form - Help Guide
## Purpose
This form is used to collect general information about a trucking company. It helps us to understand the company's details and generate reports or updates as needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Please ensure that you have authorization to complete this form.
2. Enter your first name in the **first name** field.
3. Enter your last name in the **last name** field.
4. Enter your email address in the **email** field.
5. Enter your phone number in the **phone number** field.
6. Select a category for the company from the **category** dropdown list.
7. If you need to add any additional notes, you can enter them in the **notes** field.
8. Optionally, you can enter the date and time you completed this form in the **created at** and **updated at** fields, respectively.

## Field-by-Field Explanation

### First Name (first_name)
* **First Name (first_name)**: Enter your first name.
* Type: text, required: false

### Last Name (last_name)
* **Last Name (last_name)**: Enter your last name.
* Type: text, required: false

### Email (email)
* **Email (email)**: Enter your email address.
* Type: email, required: false

### Phone Number (phone)
* **Phone Number (phone)**: Enter your phone number.
* Type: text, required: false

### Category (category)
* **Category (category)**: Select a category for the company.
* Type: select_one, required: true

### Notes (notes)
* **Notes (notes)**: Add any additional notes about the company.
* Type: note, required: false

### Created At (created_at)
* **Created At (created_at)**: Optionally, enter the date you completed this form.
* Type: date, required: false

### Updated At (updated_at)
* **Updated At (updated_at)**: Optionally, enter the time you updated this form.
* Type: time, required: false

## Tips

* Please ensure that all fields are filled in accurately and completely.
* If you have any doubts or questions, please contact us for assistance.
* Do not submit this form if you have already completed one with the same information.
