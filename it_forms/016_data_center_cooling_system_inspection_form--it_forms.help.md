# Data Center Cooling System Inspection Form - Help Guide
## Purpose
This form is designed to collect information about the data center cooling system's condition, performance, and reliability. This data will help maintain and improve the overall health of the data center.

## How To Complete This Form
1. Review each page carefully and select the relevant options for your inspection findings.
2. Use the "User Input" field to provide any additional information not covered in the other fields.
3. Answer each field accurately and truthfully based on your inspection results.

## Field-by-Field Explanation

* **User Input** (text, required: false): This is a free-text field where you can provide any relevant information not covered in the other fields.
* **Air Handler Info** (select_one, required: false): Check this field if the air handler is present and functioning correctly.
* **Cooling System Info** (select_multiple, required: false): Check all that apply if the cooling system is functioning correctly (e.g., cooling, heating, etc.).
* **Electrical Info** (select_multiple, required: false): Check all that apply if the electrical components are functioning correctly (e.g., power supply, distribution, etc.).
* **Water Info** (select_one, required: false): Check this field if water is involved in the cooling system (e.g., water-cooled systems).
* **Cooling System Condition** (select_one, required: false): Check this field to report the overall condition of the cooling system (e.g., good, fair, poor).
* **Cooling System Status** (select_one, required: false): Check this field to report the current status of the cooling system (e.g., active, inactive, maintenance mode).
* **Cooling System Reliability** (select_one, required: false): Check this field to report the reliability of the cooling system (e.g., yes, no).
* **Cooling System Performance** (select_one, required: false): Check this field to report the performance of the cooling system (e.g., good, fair, poor).
* **Cooling System Capacity** (number, required: false): Enter the rated capacity of the cooling system, if applicable.
* **Cooling System Rated Capacity** (number, required: false): Enter the rated capacity of the cooling system, if applicable.
* **Cooling System Design Capacity** (number, required: false): Enter the design capacity of the cooling system, if applicable.
* **Electrical Distribution** (select_one, required: false): Check this field to report if the electrical distribution is functioning correctly.
* **Electrical Cabinet Info** (select_one, required: false): Check this field to report if the electrical cabinet is present and functioning correctly.
* **Electrical Cable Type** (select_one, required: false): Check this field to report if the electrical cable type is correct.
* **Data Center Info** (select_multiple, required: false): Check all that apply if the data center information is correct (e.g., layout, capacity, etc.).
* **Cooling System Control** (select_one, required: false): Check this field to report if the cooling system control is functioning correctly.
* **Cooling System Control Info** (select_one, required: false): Check this field to report if the cooling system control information is correct.
* **Cooling System Alarm Info** (select_one, required: false): Check this field to report if the cooling system alarm is functioning correctly.
* **Data Center Equipment Info** (select_multiple, required: false): Check all that apply if the data center equipment is correct (e.g., servers, power supplies, etc.).
* **Cooling System Equipment Info** (select_multiple, required: false): Check all that apply if the cooling system equipment is correct (e.g., chillers, pumps, etc.).
* **Cooling System Monitoring** (select_one, required: false): Check this field to report if the cooling system monitoring is functioning correctly.
* **Cooling System Failure Info** (select_one, required: false): Check this field to report if the cooling system failure information is correct.
* **Notes** (note, required: false): Enter any additional notes about the inspection.
* **Comments** (note, required: false): Enter any additional comments about the inspection.
