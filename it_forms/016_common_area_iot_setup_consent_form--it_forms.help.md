# Common Area IoT Setup Consent Form - Help Guide
## Purpose
This form is used to collect information and consent from residents for the installation and operation of IoT devices in common areas of a property or complex.

## How To Complete This Form

1. Review the form carefully and ensure you have understood the purpose and implications of the IoT installation.
2. Fill out all required fields, marked with an asterisk (*).
3. Select all applicable options for each field, using the available choices.
4. Sign and date the form to confirm your consent.

## Field-by-Field Explanation

* **Consent Information**: This section provides details about the IoT installation project.
* **Property Name**: Please enter the name of the property or complex where the IoT devices will be installed.
* **Property Address**: Enter the full address of the property or complex.
* **Resident Information**: This section provides details about the consenting resident.
* **Resident Name**: Enter the full name of the resident.
* **Unit Number**: Enter the apartment or unit number of the resident.
* **Resident Email**: Enter the contact email address of the resident.
* **Resident Phone**: Enter the contact phone number of the resident.
* **IoT Installation Details**: This section provides information about the IoT devices to be installed.
* **Device Types**: Select all types of IoT devices that will be installed (e.g., Smart Thermostats, Motion Sensors, etc.).
* **Installation Locations**: Select all locations where the devices will be installed (e.g., Lobby, Hallways, etc.).
* **Installation Start Date**: Select the date when the installation will begin.
* **Expected Duration**: Select the estimated duration of the installation process.
* **Data Collection Consent**: Check if you agree to the data collection by IoT devices.
* **Data Types Collected**: Select all types of data that will be collected (e.g., Temperature Readings, Occupancy Data, etc.).
* **Data Usage Purpose**: Select all purposes for which the data will be used (e.g., Energy Efficiency, Building Optimization, etc.).
* **Data Sharing**: Check if you agree to share data with third parties.
* **Data Retention**: Select the duration for which data will be stored.
* **Privacy Concerns**: If you have any privacy concerns, enter them in this field.
* **Network Information**: This section provides information about the IoT network connectivity details.
* **Network Type**: Select the type of network that IoT devices will use (e.g., Wi-Fi, Zigbee, etc.).
* **Consent Declaration**: Check if you consent to the IoT installation.
* **Conditions**: If you have any conditions for your consent, enter them in this field.
* **Signature Date**: Date of consent signature.

Note: All fields marked with an asterisk (*) are required fields and must be filled out accurately.
