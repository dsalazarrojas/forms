# User Logon Activity Report - Help Guide

## Purpose
This form is designed to gather data about user logon activities to help organizations understand user behavior and identify trends.

## How to Complete This Form
To complete this form, please follow these steps:

1. Fill in your user details, including any relevant information.
2. Enter the time you logged on and off, if applicable.
3. Select the type of activity you performed (Login, Logout, Active, or Idle).
4. Choose the location from which you accessed the system (Office, Home, or Remote).
5. Provide any additional comments or notes about your activity.

## Field-by-Field Explanation

* **User details**: This section collects your basic user information. Please fill in your name, email, or any other relevant details as required.
* **Logon/Logoff time**: Enter the time you logged on or off, if applicable. This can be in 24-hour clock format (HH:MM).
* **Activity type**: Select the type of activity you performed during your logon time. Choose one of the following options:
	+ **Login**: When you first accessed the system.
	+ **Logout**: When you ended your session.
	+ **Active**: When you were actively using the system.
	+ **Idle**: When you were not actively using the system.
* **Device or location**: Select the location from which you accessed the system. Choose one of the following options:
	+ **Office**: When you accessed the system from a physical office location.
	+ **Home**: When you accessed the system from your home or personal space.
	+ **Remote**: When you accessed the system from outside the office or remotely.
* **Notes**: This field allows you to provide any additional comments or notes about your activity. You can type in any relevant information that will help us better understand your behavior.
