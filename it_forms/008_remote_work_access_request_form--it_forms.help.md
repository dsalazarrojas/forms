# Remote Work Access Request Form - Help Guide
## Purpose
The Remote Work Access Request Form is a system used by employees to request access to work remotely. This form helps ensure that all remote work requests are properly documented and approved.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name in the field labeled "employee_name."
2. Enter your email address in the field labeled "employee_email."
3. Enter your phone number in the field labeled "employee_phone" (optional).
4. Enter the location where you will be working remotely in the field labeled "remote_work_location."
5. Select the start date you will begin working remotely in the field labeled "start_date."
6. Select the end date you will stop working remotely in the field labeled "end_date."
7. Enter the number of days you will be working remotely in the field labeled "remote_access_duration."
8. Select the person who will be approving your request (i.e. "remote_access_approver").
9. You may select multiple approval status options by holding Ctrl + Click on each option.
10. If you have any additional comments, please enter them in the field labeled "comments."

## Field-by-Field Explanation
* **employee_name**: This is where you enter your name.
* **employee_email**: This is where you enter your email address.
* **employee_phone**: This is where you enter your phone number (if applicable).
* **remote_work_location**: This is where you enter the location where you will be working remotely.
* **start_date**: This is where you select the date you will begin working remotely.
* **end_date**: This is where you select the date you will stop working remotely.
* **remote_access_duration**: This is where you enter the number of days you will be working remotely.
* **remote_access_approver**: This is where you select the person who will be approving your request. Typically, this is your supervisor or manager.
* **approval_status**: This is where you select the current status of your request. Please select one of the following options: "approved," "pending," or "denied."
* **comments**: This is where you can enter any additional comments or questions you have about your request.
