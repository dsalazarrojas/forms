# NHA New Server Request Form - Help Guide
## Purpose
The NHA New Server Request Form is a form for requesting a new server from the network administration team.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **new_server_request** field with a detailed description of your server request.
2. In the **description** field, provide a brief explanation of your request.
3. Enter your **name** in the corresponding field.
4. Enter your email address in the **email** field.
5. If applicable, add your phone number in the **phone_number** field.
6. Fill in the **date_of_visit** and **time_of_visit** fields with the date and time of your visit.
7. In the **request_details** field, provide any additional details or context about your request.
8. Select the **request_status** field to indicate the current status of your request (Open, In Progress, or Closed).
9. Choose the **request_type** field to indicate the type of request you are making (Server Request, User Request, or Server and User Request).

## Field-by-Field Explanation
* **new_server_request**: Enter a detailed description of your server request, including any relevant information or context.
* **description**: Briefly explain your request, providing context and background.
* **name**: Enter your name as it appears on your identification or in our records.
* **email**: Enter your email address so that we can contact you regarding your request.
* **phone_number**: If you have a phone number, enter it so that we can contact you if needed.
* **date_of_visit**: Enter the date of your visit, following the standard format (YYYY-MM-DD).
* **time_of_visit**: Enter the time of your visit, following the standard format (HH:MM).
* **request_details**: Add any additional details or context about your request.
* **request_status**: Select the current status of your request (Open, In Progress, or Closed).
* **request_type**: Choose the type of request you are making (Server Request, User Request, or Server and User Request).
