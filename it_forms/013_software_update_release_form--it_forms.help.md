# software_update_release_form - Help Guide
## Purpose
This form is designed to collect information about planned software releases, enabling teams to coordinate and prepare for upcoming releases. It helps in tracking release details, team members' involvement, and release status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Planned Release Details in the first field.
2. Fill in the Release Name, Version, and Release Date in the following fields.
3. Provide a Release Description (optional).
4. Select the Team Members Involved from the list.
5. Choose the Release Status (Draft, Approved, or Declined).
6. Enter any Comments (optional).
7. Set the Release Date Review.
8. Choose the Release Type (Major, Minor, or Patch).

## Field-by-Field Explanation
* **Planned Release Details**: A field to enter any additional planned release details.
* **Release Name**: Enter the name of the software release.
* **Release Version**: Enter the version of the software release.
* **Release Date**: Enter the date when the software is expected to be released.
* **Release Description**: Provide a brief description of the software release (optional).
* **Team Members Involved**: Select all team members involved in the software release from the list (product team, IT team).
* **Release Status**: Choose the status of the software release (Draft, Approved, or Declined).
* **Comments**: Enter any additional comments related to the software release (optional).
* **Release Date Review**: Set the time when the release date will be reviewed.
* **Release Type**: Choose the type of software release (Major, Minor, or Patch).
