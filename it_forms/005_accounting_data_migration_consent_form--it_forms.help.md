# Accounting Data Migration Consent Form - Help Guide
## Purpose
This form is used to gather essential information for the accounting data migration process. It is intended to capture the details required for a successful migration, including client consent, contact information, and system details. The form is crucial for the project team to understand the client's needs and preferences for the migration process.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the form carefully to ensure all required fields are completed.
2.  Provide your client's name and contact information accurately.
3.  Specify the current and target accounting systems involved in the migration.
4.  Indicate the scope of data to be migrated.
5.  Confirm the backup status and any specific data privacy requirements.
6.  Sign and date the form to authorize the migration.

## Field-by-Field Explanation

*   **Client name** (`client_name`, `text`, required): Enter the legal or trading name of your client.
*   **Contact person** (`contact_person`, `text`, required): Provide the primary contact person's name for the migration.
*   **Contact email** (`contact_email`, `email`, required): Enter the email address for migration coordination and communication.
*   **Current accounting system** (`current_system`, `text`, required): Specify the accounting system data will be migrated from.
*   **Target accounting system** (`target_system`, `text`, required): Specify the accounting system data will be migrated to.
*   **Data scope to be migrated** (`data_scope`, `text`, required): Indicate the type of data to be migrated (e.g., transactions, charts of accounts, payroll records).
*   **Backup confirmed** (`backup_confirmed`, `select_one`, required): Confirm that a full backup of the current system has been taken.
*   **Data privacy requirements** (`data_privacy_requirements`, `text`, optional): List any specific data privacy or confidentiality requirements.
*   **Approval signature** (`approval_signature`, `text`, required): Type your full name as authorization.
*   **Approval date** (`approval_date`, `date`, required): Date the client approved the migration.
*   **Contact phone** (`contact_phone`, `text`, optional): Provide a phone number for rapid coordination.
*   **Additional instructions** (`additional_instructions`, `text`, optional): Provide any special instructions for the migration team.

Please note that required fields are marked as such in the form, and all fields are essential for a successful migration process.
