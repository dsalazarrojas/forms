# security_equipment_technician_contact_form - Help Guide
## Purpose
This form is for security equipment technicians to report or request assistance with security-related issues, such as Security System, System Alarm, Access Control, or Motion Detection issues.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out your user details, including any relevant contact information.
2. Describe the issue you are experiencing with your security equipment.
3. Specify the type of issue you are experiencing (e.g. Security System, System Alarm, etc.).
4. Indicate the priority of the issue (e.g. High, Medium, Low).
5. If follow-up is required, provide details on the follow-up required.
6. Add any additional notes about the issue.

## Field-by-Field Explanation

* **User Details** (`user_details`):
	+ A text field where you can input your name and any other relevant contact information.
* **Service Request** (`service_request`):
	+ A text field where you can describe what you are asking for or reporting.
* **Issue Description** (`issue_description`):
	+ A text field where you can provide a detailed description of the issue you are experiencing.
* **Contact Details** (`contact_details`):
	+ A text field where you can input any other contact information that may be relevant.
* **Issue Type** (`issue_type`):
	+ A select multiple field where you can choose from the following options:
		- Security System
		- System Alarm
		- Access Control
		- Motion Detection
		- Other
		- Unknown
* **Issue Priority** (`issue_priority`):
	+ A select one field where you can choose from the following options:
		- High
		- Medium
		- Low
* **Follow-up Required** (`follow_up_required`):
	+ A text field where you can indicate if follow-up is required and provide details.
* **Notes** (`notes`):
	+ A text field where you can add any additional information about the issue.
