# SharePoint Change Audit Log Tracker - Help Guide
## Purpose
The SharePoint Change Audit Log Tracker is a form designed to track and record changes made to the SharePoint system. This form helps track the type of change, the user who made the change, the date and time it occurred, and any other relevant details.

## How To Complete This Form

1. Start by selecting the type of change that was made (change_type). This field is used to categorize the type of change that was made.
2. Enter the details of the change (change_details) in the text box provided.
3. Select 'Yes' or 'No' to indicate if the change was related to a specific user (related_user).
4. Enter the name of the related user (related_user_name) if the change was made by a specific user.
5. Select 'Yes' or 'No' to indicate if the change was approved by a user (approver).
6. Enter the name of the approver (approver_name) if the change was approved by a user.
7. Enter the email of the approver (approver_email) if the approver has an email address.
8. Select the date and time of the change (change_date).
9. Select the time of the change (change_time).
10. Enter any comments related to the change (comments).
11. Select the status of the approval (approval_status).
12. Enter the name of the approval status (approval_status_name).
13. Select the date of approval (approval_date).
14. Select the time of approval (approval_time).
15. Enter any comments related to the approval (approval_comments).
16. Enter the version of the form (form_version).
17. Enter the URL of the related site (related_site_url).
18. Select 'Yes' or 'No' to indicate if the change was approved by a user (approval_user).
19. Enter the name of the user who approved the change (approval_user_name).
20. Enter the email of the user who approved the change (approval_user_email).
21. Enter the type of change request (change_request_type).
22. Enter the number of the change request (change_request_number).
23. Enter the number of the related ticket (related_ticket_number).
24. Enter any comments related to the change request (comments_for_change_request).

## Field-by-Field Explanation

* **form_title** (1, text, required: false): Enter a brief title for the change being tracked.
* **change_type** (2, select_one, required: false): Select the type of change made to the SharePoint system.
	+ 'Yes' or 'No': Indicates if the change was related to a specific user.
* **change_details** (3, text, required: true): Enter the details of the change made, including any relevant information.
* **related_user** (4, select_multiple, required: false): Select 'Yes' or 'No' to indicate if the change was related to a specific user.
* **related_user_name** (5, text, required: false): Enter the name of the user related to the change if 'Yes' was selected.
* **approver** (6, select_one, required: false): Select 'Yes' or 'No' to indicate if the change was approved by a user.
* **approver_name** (7, text, required: false): Enter the name of the approver if 'Yes' was selected.
* **approver_email** (8, email, required: false): Enter the email of the approver if 'Yes' was selected.
* **change_date** (9, date, required: true): Select the date the change occurred.
* **change_time** (10, time, required: false): Select the time the change occurred.
* **comments** (11, text, required: false): Enter any comments related to the change.
* **approval_status** (12, select_one, required: false): Select the status of the approval.
	+ 'Active' or 'Inactive': Indicates the status of the approval.
* **approval_status_name** (13, text, required: false): Enter the name of the approval status.
* **approval_date** (14, date, required: false): Select the date of approval.
* **approval_time** (15, time, required: false): Select the time of approval.
* **approval_comments** (16, text, required: false): Enter any comments related to the approval.
* **form_version** (17, text, required: false): Enter the version of the form.
* **related_site_url** (18, text, required: false): Enter the URL of the related site.
* **approval_user** (19, select_one, required: false): Select 'Yes' or 'No' to indicate if the change was approved by a user.
* **approval_user_name** (20, text, required: false): Enter the name of the user who approved the change if 'Yes' was selected.
* **approval_user_email** (21, email, required: false): Enter the email of the user who approved the change if 'Yes' was selected.
* **change_request_type** (22, text, required: false): Enter the type of change request.
* **change_request_number** (23, text, required: false): Enter the number of the change request.
* **related_ticket_number** (24, text, required: false): Enter the number of the related ticket.
* **comments_for_change_request** (25, text, required: false): Enter any comments related to the change request.

## Tips

* Make sure to enter accurate and detailed information for each field to ensure a clear audit log.
* Use the 'Yes' or 'No' options to indicate if the change was related to a specific user or approved by a user.
* Enter the correct date and time for each field.
* Use the fields to track and record changes made to the SharePoint system.
* Review and update the form as necessary to ensure accurate tracking and reporting.
