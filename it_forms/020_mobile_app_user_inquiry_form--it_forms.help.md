# mobile_app_user_inquiry_form - Help Guide
## Purpose
The "mobile_app_user_inquiry_form" is a tool for users to report bugs, provide feedback, or ask questions about a mobile app.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your App Name to indicate which app you are experiencing an issue with.
2. Provide a brief description of the bug or issue you are experiencing, including any relevant details.
3. Enter your contact information, including your Email Address and optional Contact Number.
4. Select the type of issue you are experiencing (Bug Report, Bug, or Feedback).
5. Indicate which App Version you are using.
6. Specify the Operating System (Android or iOS) and Device Model you are using.
7. Optionally, provide a Screen Capture to help the development team better understand the issue.

## Field-by-Field Explanation

* **App Name** (`app_name`, Text, Required): Enter the name of the app you are experiencing an issue with.
* **Bug Report** (`bug_report`, Text, Optional): Describe the issue you are experiencing with the app.
* **Issue Description** (`issue_description`, Text, Required): Provide a detailed description of the issue you are experiencing.
* **Feedback** (`feedback`, Text, Optional): Share your thoughts, suggestions, or ideas about the app.
* **Email Address** (`email_address`, Email, Required): Enter your email address so we can contact you with updates about your issue.
* **Contact Number** (`contact_number`, Text, Optional): Provide an optional contact number for us to reach out to you.
* **Issue Type** (`issue_type`, Select One, Required): Select the type of issue you are experiencing (Bug Report, Bug, or Feedback).
* **App Version** (`app_version`, Select Multiple, Required): Choose the version of the app you are using.
* **Operating System** (`operating_system`, Select One, Required): Select the Operating System (Android or iOS) you are using.
* **Device Model** (`device_model`, Text, Optional): Enter the model of your device (if applicable).
* **Screen Capture** (`screen_capture`, Note, Optional): Attach a screen capture to help us better understand the issue (if applicable).
