# it_modernization_advisory_request_form - Help Guide

## Purpose
The it_modernization_advisory_request_form is a tool for gathering information about modernization projects.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide project details
2. Choose the modernization initiatives applicable to your project
3. Select the level of project urgency
4. Enter any advisory requests
5. Describe the project goals
6. Specify the project status
7. Enter the completion date (if applicable)
8. Identify the assigned tool (if applicable)

## Field-by-Field Explanation
### 1. **Project Details** (project_details)
* A text field for providing a brief description of the project
### 2. **Modernization Initiatives** (modernization_initiatives)
* A multiple-choice field with three options to choose from:
	+ Option 1
	+ Option 2
	+ Option 3
### 3. **Project Urgency** (project_urgency)
* A single-choice field with three options to choose from:
	+ Option 4
	+ Option 5
	+ Option 6
### 4. **Advisory Requests** (advisory_requests)
* A text field for entering any additional requests
### 5. **Project Goals** (project_goals)
* A text field for describing the project goals
### 6. **Project Status** (project_status)
* A field for entering a specific date and time, e.g., "ongoing", "completed" etc.
### 7. **Completion Date** (completion_date)
* A date field for entering the expected completion date
### 8. **Assigned Tool** (assigned_tool)
* A text field for identifying the assigned tool
