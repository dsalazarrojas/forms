# Suspicious Activity Report Form - Help Guide
## Purpose
The Suspicious Activity Report Form is a tool used to report any financial-related activities that seem irregular or unusual. It's used to report any activities that raise concerns about fraudulent or illicit activities.

## How To Complete This Form

1.  Ensure you have a valid reason to fill out this form. Only use this form to report activities that you suspect as suspicious.
2.  Review each field to ensure you are providing accurate and relevant information.
3.  Fill out the form with the required information.
4.  Review the form before submitting to ensure all required fields are filled out.
5.  Submit the form to the relevant authorities.

## Field-by-Field Explanation

*   **Suspicious Activity Report Form** (`title`, text, required: false): Enter a brief title for your report.
*   **Reported by** (`reported_by`, select_one, required: false): Select the name of the person who reported the activity.
	+   First name
	+   Middle name
	+   Last name
	+   Organization
	+   Other
*   **Date of Report** (`date_of_report`, date, required: false): Enter the date when you reported the suspicious activity.
*   **Description of Suspicious Activity** (`description_of_suspicious_activity`, text, required: false): Provide details regarding the suspicious activity.
*   **Contact Phone** (`contact_phone`, text, required: false): Enter the phone number of the contact person.
*   **Email** (`email`, email, required: false): Enter the email of the contact person.
*   **Address** (`address`, text, required: false): Enter the address of the contact person.
*   **Location** (`location`, select_multiple, required: false): Select the location where the activity occurred.
	+   Bank
	+   Office
	+   Home
	+   Other
*   **Type of Suspicious Activity** (`suspicious_activity_type`, select_one, required: false): Select the type of suspicious activity from the options provided.
	+   Suspicious activity 1
	+   Suspicious activity 2
	+   Suspicious activity 3
	+   Suspicious activity 4
	+   Suspicious activity 5
*   **Description of Suspicious Activity 2** (`description_of_suspicious_activity_2`, text, required: false): Enter a description of the second suspicious activity.
*   **Other fields may be required based on the selected option**

## Tips
Please ensure all required fields are filled out before submitting the form. If unsure about any field, refer back to this help guide for guidance.
