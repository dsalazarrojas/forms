# Financial Insurance Application Request Form - Help Guide
## Purpose
This form collects information from customers seeking financial insurance. Please fill out the form completely and accurately to ensure proper processing of their request.

## How To Complete This Form
- Please select the "Customer Information" tab to begin filling out the form.
- Fill out the "Income" field with your annual income.
- Enter the loan amount you are interested in applying for in the "Loan Amount" field.
- If you have an existing credit score, enter it in the "Credit Score" field. If not, you can leave this field blank.
- Select your social security number from the dropdown options in the "Social Security Number" field.
- In the "Financial History" field, provide a brief description of your financial history.
- Choose the type of insurance you are interested in applying for from the dropdown options in the "Insurance Type" field.
- Select the loan term you are interested in from the dropdown options in the "Loan Term" field.

## Field-by-Field Explanation
- **Customer Information**: This is the first section of the form where you will enter your basic contact information.
  * This field is not required.
  * Please enter your name, address, and other relevant details.
* **Income**: Enter your annual income.
  * This field is not required.
  * Please enter a valid number value.
* **Loan Amount**: Enter the amount you are interested in applying for.
  * This field is not required.
  * Please enter a valid number value.
* **Credit Score**: If you have an existing credit score, enter it here.
  * This field is not required.
  * If you do not have a credit score, please leave this field blank.
* **Social Security Number**: Select your social security number from the dropdown options.
  * This field is not required.
  * Please select a valid social security number from the provided options.
* **Financial History**: Provide a brief description of your financial history.
  * This field is not required.
  * Please enter a short paragraph explaining your financial history.
* **Insurance Type**: Choose the type of insurance you are interested in applying for.
  * This field is not required.
  * Please select from the provided options: Health, Auto, or Life.
* **Loan Term**: Select the loan term you are interested in.
  * This field is not required.
  * Please select from the provided options.
