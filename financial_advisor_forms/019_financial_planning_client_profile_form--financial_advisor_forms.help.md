# Financial Planning Client Profile Form - Help Guide
## Purpose
The purpose of this form is to collect financial planning client profile information.

## How To Complete This Form
To complete this form, please go through each page and select the relevant information for your client. You can access the form through your account.

## Field-by-Field Explanation

### 1. Financial Planning
* **Financial Planning** (`Financial Planning`, select_one, required/optional): This field determines if the client is interested in financial planning.
  - Select "Yes" if the client is interested in financial planning.
  - Select "No" if the client is not interested in financial planning.

* **Contact Details** (`Contact Details`, select_multiple, required/optional): This field determines if the client has contact details.
  - Select "Yes" if the client has contact details.
  - Select "No" if the client does not have contact details.

* **Client Name** (`Client Name`, text, required/optional): This field is for the client's name.
  - Please enter the client's name as it appears on their identification documents.

* **Phone** (`Phone`, text, required/optional): This field is for the client's phone number.
  - Please enter the client's phone number.

* **Email** (`Email`, email, required/optional): This field is for the client's email address.
  - Please enter the client's email address.

* **Address** (`Address`, text, required/optional): This field is for the client's address.
  - Please enter the client's address.

* **Zip Code** (`Zip Code`, number, required/optional): This field is for the client's zip code.
  - Please enter the client's zip code.

* **Birth Date** (`Birth Date`, date, required/optional): This field is for the client's birth date.
  - Please enter the client's birth date.

* **Income** (`Income`, number, required/optional): This field is for the client's income.
  - Please enter the client's income.

* **Financial Goals** (`Financial Goals`, text, required/optional): This field is for the client's financial goals and expectations.
  - Please enter the client's financial goals and expectations.

* **Risk Tolerance** (`Risk Tolerance`, select_one, required/optional): This field determines if the client has a risk tolerance.
  - Select "Yes" if the client has a risk tolerance.
  - Select "No" if the client does not have a risk tolerance.

* **Financial Assets** (`Financial Assets`, select_multiple, required/optional): This field determines if the client has financial assets.
  - Select "Yes" if the client has financial assets.
  - Select "No" if the client does not have financial assets.

* **Liabilities** (`Liabilities`, select_multiple, required/optional): This field determines if the client has liabilities.
  - Select "Yes" if the client has liabilities.
  - Select "No" if the client does not have liabilities.

* **Financial Objectives** (`Financial Objectives`, text, required/optional): This field is for the client's financial objectives.
  - Please enter the client's financial objectives.

* **Risk Freezing** (`Risk Freezing`, select_multiple, required/optional): This field determines if the client has a risk freezing.
  - Select "Yes" if the client has a risk freezing.
  - Select "No" if the client does not have a risk freezing.

* **Financial Benchmarks** (`Financial Benchmarks`, select_multiple, required/optional): This field determines if the client has financial benchmarks.
  - Select "Yes" if the client has financial benchmarks.
  - Select "No" if the client does not have financial benchmarks.

* **Asset Allocation** (`Asset Allocation`, select_multiple, required/optional): This field determines if the client has asset allocation.
  - Select "Yes" if the client has asset allocation.
  - Select "No" if the client does not have asset allocation.

* **Investment Strategies** (`Investment Strategies`, select_multiple, required/optional): This field determines if the client has investment strategies.
  - Select "Good" if the client has investment strategies.
  - Select "Fair" if the client does not have investment strategies.

* **Financial Planner** (`Financial Planner`, text, required/optional): This field is for the client's financial planner.
  - Please enter the client's financial planner's name.

* **Financial Planner Contact Info** (`Financial Planner Contact Info`, text, required/optional): This field is for the financial planner's contact information.
  - Please enter the financial planner's contact information.

* **Additional Info** (`Additional Info`, text, required/optional): This field is for any additional information about the client.
  - Please enter any additional information about the client.

* **Financial Goals and Expectations** (`Financial Goals and Expectations`, text, required/optional): This field is for the client's financial goals and expectations.
  - Please enter the client's financial goals and expectations.

* **Financial Status** (`Financial Status`, text, required/optional): This field is for the client's financial status.
  - Please enter the client's financial status.

* **Notes** (`Notes`, note, required/optional): This field is for any notes about the client.
  - Please enter any notes about the client.

* **Financial Institutions** (`Financial Institutions`, text, required/optional): This field is for any financial institutions associated with the client.
  - Please enter any financial institutions associated with the client.
