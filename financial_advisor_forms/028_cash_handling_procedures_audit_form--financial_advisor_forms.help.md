# Cash Handling Procedures Audit Form - Help Guide
## Purpose
This form is intended to evaluate the adherence to cash handling procedures, policies, and regulations in an organization. The form assesses various aspects of cash handling, including documentation, access controls, safe security, counting procedures, reconciliation, and variance investigation. The goal is to identify areas of improvement and ensure that cash handling processes are followed correctly.

## How To Complete This Form
1.  Ensure you have all necessary information and documents before starting the audit.
2.  Read each question carefully and choose the most accurate response.
3.  Answer "Yes" if the procedure is followed as expected.
4.  Answer "No" if the procedure is not followed.
5.  Answer "Partial" or "Needs improvement" if the procedure is followed partially or requires improvement.
6.  Provide any additional comments or explanations in the "Audit Findings and Recommendations" field.

## Field-by-Field Explanation

*   **Audit Date** (`audit_date`, date, required): Enter the date of the audit in MM/DD/YYYY format.
*   **Auditor Name** (`auditor_name`, text, required): Enter your name as the auditor.
*   **Organization Name** (`organization_name`, text, required): Enter the name of the organization being audited.
*   **Location or Department Audited** (`location_audited`, text, required): Enter the location or department being audited.
*   **Is cash handling policy documented?** (`cash_handling_policy_documented`, select_one, required): Answer whether the organization has a documented cash handling policy.
    *   Select "Yes" if the policy is documented.
    *   Select "No" if the policy is not documented.
*   **Is cash handling training provided to staff?** (`training_provided`, select_one, required): Answer whether staff receives regular cash handling training.
    *   Select "Yes, regularly" if training is provided regularly.
    *   Select "Yes, sometimes" if training is provided occasionally.
    *   Select "No" if no training is provided.
*   **Is access to cash restricted to authorized personnel?** (`restricted_access`, select_one, required): Answer whether access to cash is restricted to authorized personnel.
    *   Select "Yes" if access is restricted.
    *   Select "No" if access is not restricted.
*   **Are access events logged or monitored?** (`access_logging`, select_one, required): Answer whether access events are logged or monitored.
    *   Select "Yes" if events are logged.
    *   Select "No" if events are not logged.
*   **Is a safe or secure storage available?** (`safe_available`, select_one, required): Answer whether a safe or secure storage is available.
    *   Select "Yes" if a safe or secure storage is available.
    *   Select "No" if no safe or secure storage is available.
*   **Condition of safe** (`safe_condition`, select_one, required): Answer the condition of the safe.
    *   Select "Excellent" if the safe is in excellent condition.
    *   Select "Good" if the safe is in good condition.
    *   Select "Fair" if the safe is in fair condition.
    *   Select "Poor" if the safe is in poor condition.
    *   Select "No safe present" if no safe is present.
*   **Are safe keys properly controlled?** (`key_access_controlled`, select_one, required): Answer whether safe keys are properly controlled.
    *   Select "Yes" if keys are properly controlled.
    *   Select "No" if keys are not properly controlled.
*   **How often is cash counted?** (`counting_frequency`, select_one, required): Answer how often cash is counted.
    *   Select "Daily" if cash is counted daily.
    *   Select "Weekly" if cash is counted weekly.
    *   Select "Monthly" if cash is counted monthly.
    *   Select "As needed" if cash is counted as needed.
    *   Select "Not regularly counted" if cash is not counted regularly.
*   **Is two-person verification rule followed?** (`two_person_rule`, select_one, required): Answer whether the two-person rule is followed.
    *   Select "Yes, always" if the rule is followed always.
    *   Select "Yes, usually" if the rule is followed usually.
    *   Select "Sometimes" if the rule is followed occasionally.
    *   Select "No" if no rule is followed.
*   **Are receipts issued for all cash transactions?** (`receipts_issued`, select_one, required): Answer whether receipts are issued for all cash transactions.
    *   Select "Yes" if receipts are issued.
    *   Select "No" if no receipts are issued.
*   **Are detailed cash handling records maintained?** (`records_maintained`, select_one, required): Answer whether detailed cash handling records are maintained.
    *   Select "Yes" if records are maintained.
    *   Select "No" if no records are maintained.
*   **Is daily reconciliation performed?** (`daily_reconciliation`, select_one, required): Answer whether daily reconciliation is performed.
    *   Select "Yes" if daily reconciliation is performed.
    *   Select "No" if no daily reconciliation is performed.
*   **Are cash variances investigated?** (`variance_investigation`, select_one, required): Answer whether cash variances are investigated.
    *   Select "Yes, thoroughly" if variances are investigated thoroughly.
    *   Select "Yes, sometimes" if variances are investigated occasionally.
    *   Select "No" if no variances are investigated.
*   **Audit Findings and Recommendations** (`audit_findings`, text, optional): Enter any additional comments or recommendations regarding the audit findings.
