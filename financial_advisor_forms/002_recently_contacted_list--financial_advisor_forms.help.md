# recently_contacted_list - Help Guide
## Purpose
The "recently_contacted_list" form is designed to record information about recent contacts made with clients or prospects.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the name of the person you last contacted.
2. Select all the methods you used to contact this person (e.g., Phone, Email, or Video call).
3. Enter the date when you last contacted this person.

## Field-by-Field Explanation
- **Last Contacted Person** (`last_contacted_person`, text, optional): Please enter the name of the person you last contacted. This field is optional, but it helps to track who was contacted.
- **Contact Method** (`contact_method`, select_multiple, **required**): Choose all the methods you used to contact this person. Select as many as apply (e.g., Phone, Email, or Video call). This field is required to ensure that all contacts are properly recorded.
  - Phone: The person was contacted via a phone call.
  - Email: The person was contacted via email.
  - Video call: The person was contacted via video call.
- **Contact Date** (`contact_date`, date, optional): Please enter the date when you last contacted this person. This field is optional, but it helps to track when the contact was made.

## Tips
- Make sure to select all contact methods that apply to ensure accurate recording.
- Enter the date of the last contact in the correct format (YYYY-MM-DD).
- If you make multiple contacts with the same person, fill out a new form for each contact.
