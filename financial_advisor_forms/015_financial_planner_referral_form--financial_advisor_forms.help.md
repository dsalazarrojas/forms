# Financial Planner Referral Form - Help Guide

## Purpose
This form is used to refer a client to a financial planner. It's a tool to help financial advisors connect their clients with other professionals in the industry.

## How To Complete This Form
1. Ensure that no other form for the same client is already in the system before filling out this form.
2. Fill out the form with the required information, which includes:
	* Client details (name, address, etc.)
	* How the client was referred (e.g., client request, social media, word of mouth)
	* Financial planner details (name, contact info)
	* Financial services offered
	* Additional comments (if any)

## Field-by-Field Explanation

* **Client Information (`client_info`, text, required: false):** Enter the client's name and any other relevant contact information.
* **Client Address (`client_address`, text, required: false):** Enter the client's address, including street address, city, state, zip, and country.
* **Financial Planner Details (`financial_planner_details`, text, required: false):** Enter the name and contact information of the financial planner being referred.
* **Client Financial Details (`client_financial_details`, text, required: false):** Enter any relevant financial information about the client, such as current assets, income, etc.
* **Referral Method (`referral_method`, select multiple, required: false):** Select how the client was referred, from the following options:
	+ Client Request
	+ Social Media
	+ Word of Mouth
	+ Google Search
	+ Referral from Another Financial Planner
	+ Other (Please specify)
* **Referral Fee (`financial_planner_referral_rate`, number, required: false):** Enter the referral fee for the financial planner (if any).
* **Other Financial Services (`other_financial_services`, select multiple, required: false):** Select the financial services offered by the financial planner, from the following options:
	+ Investment Management
	+ Tax Planning
	+ Financial Planning
	+ Financial Planning and Investment
	+ Trust and Estate Planning
	+ Retirement Planning
	+ Insurance Planning
	+ Other (Please specify)
* **Other Financial Services (Other) (`other_financial_services_other`, text, required: false):** Enter any other financial services offered by the financial planner that are not listed above.
* **Referral Fee (`referral_fee`, number, required: false):** Enter the referral fee for the financial planner (if any).
* **Additional Comments (`additional_comments`, text, required: false):** Enter any additional comments or notes about the referral.
