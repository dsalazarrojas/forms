# Mutual Fund Portfolio Addition - Help Guide
## Purpose
This form is used to add or maintain mutual fund portfolios for clients. Please fill out the required fields to create a new portfolio or update an existing one.

## How To Complete This Form
1. Select the "Portfolio Details" page and fill out the following fields:
   - **Portfolio Details**: Enter a brief description of the portfolio.
2. Proceed to the "Allocation Details" page and enter the allocation details for the portfolio.
3. Move on to the "Objectives and Risks" page and select the applicable objectives and risks for the portfolio.
4. Choose the "Add Fund" page and select the mutual fund to be added to the portfolio.
5. Enter the "Amount" of the investment in the selected fund.
6. Select the "Objectives" and "Risk Tolerance" that best match the portfolio's characteristics.
7. On the "Notes" page, enter any additional comments or explanations for the portfolio.
8. Finally, fill out the "Contact Information" fields to specify who the portfolio is assigned to and by.

## Field-by-Field Explanation
* **Portfolio Details**: A brief description of the portfolio.
* **Allocation Details**: Enter the allocation details for the portfolio.
* **Objectives and Risks**: Select the objectives and risks that best match the portfolio's characteristics.
* **Add Fund**: Select the mutual fund to be added to the portfolio.
* **Amount**: Enter the amount of investment in the selected fund.
* **Objectives**: Select the objectives that match the portfolio's characteristics.
* **Risk Tolerance**: Select the risk tolerance that best matches the portfolio's characteristics.
* **Notes**: Enter any additional comments or explanations for the portfolio.
* **Assigned To**: Specify who the portfolio is assigned to (e.g., client name).
* **Assigned By**: Specify who assigned the portfolio (e.g., financial advisor).
* **Date**: Enter the date the portfolio was created or updated.
* **Time**: Enter the time the portfolio was created or updated.
* **Contact Information**: Enter any contact information for the assigned person or entity.
* **Notes 1-11**: Additional comments or explanations for the portfolio (these can be used for internal notes).
