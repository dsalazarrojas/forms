# Debt Collection Form - Help Guide
## Purpose
The purpose of this form is to collect information about a debtor's details and the amount owed.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form fields with the debtor's information, ensuring that all required fields are completed.
2. Enter the debtor's name and employer name in the respective fields.
3. Enter the debtor's address, phone, and email if available.
4. Enter the date of last contact with the debtor.
5. Enter the amount owed, which is a required field.
6. Enter any additional notes about the debtor.
7. Review and submit the form once completed.

## Field-by-Field Explanation
* **Debtors Name (required)**: Enter the debtor's full name.
* **Debtors Address**: Enter the debtor's address, if available. This field is not required.
* **Debtors Phone**: Enter the debtor's phone number, if available. This field is not required.
* **Debtors Email**: Enter the debtor's email address, if available. This field is not required.
* **Date of Last Contact**: Enter the date of last contact with the debtor, if applicable.
* **Amount Owed (required)**: Enter the amount of money owed to the debtor. This field is a numerical value.
* **Employer Name (required)**: Enter the debtor's employer's name.
* **Employer Address**: Enter the debtor's employer's address, if available. This field is not required.
* **Employer Phone**: Enter the debtor's employer's phone number, if available. This field is not required.
* **Employer Email**: Enter the debtor's employer's email address, if available. This field is not required.
* **Notes**: Enter any additional notes about the debtor. This field is not required.

## Tips
* Please ensure that all required fields are completed before submitting the form.
* If the debtor's information is not available, please indicate this in the notes field.
* This form is not a substitute for a thorough debt collection process, which may involve multiple forms and procedures.
