# Tax Return Request Form - Help Guide
## Purpose
The Tax Return Request Form is used for requesting tax returns, gathering information about the taxpayer, and tracking the status of the request. This form is part of the "Financial Advisor Forms" category.

## How To Complete This Form
To fill out the Tax Return Request Form, follow these steps:

1. Fill in the required fields, marked as "required" in the form.
2. Provide your name and address to identify yourself as a taxpayer.
3. Enter your Taxpayer ID number.
4. Specify the tax year for which you are requesting the tax return.
5. Choose the status of your tax return (Pending, Filed, Approved, Denied, Rejected).
6. Optionally, select the Category and Description for your tax return request.
7. Choose the Tool assigned to process your tax return.
8. Fill in the Form ID and Output File fields if required.
9. Select "Yes" or "No" for Tax Return Request Form.
