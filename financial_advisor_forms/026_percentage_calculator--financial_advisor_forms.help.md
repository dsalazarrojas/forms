# percentage_calculator - Help Guide
## Purpose
The "percentage_calculator" form is a tool used to calculate a calculated value based on a given base value and a percentage.

## How To Complete This Form
To use the percentage calculator form, follow these steps:

1. Enter the base value in the "base_value" field. This is the value from which the percentage will be calculated.
2. Enter the percentage in the "percentage" field.
3. Click "Submit" to calculate the result.

## Field-by-Field Explanation
* **base_value** (number, required): Enter the base value from which the percentage will be calculated.
* **percentage** (number, required): Enter the percentage to be calculated.
* **result** (note, required): This field will display the calculated result after submitting the form.
* **base_value_hint** (note, required): A hint to remind the user to enter a base value.
* **percentage_hint** (note, required): A hint to remind the user to enter a percentage.
* **result_hint** (note, required): A hint to indicate that this field will display the calculated result.
* **percentage_decimal** (number, required): This field is not clearly defined, but based on the name and the provided fields, it's likely used for decimal representation of the percentage.
* **base_value_decimal** (number, required): This field might be used for decimal representation of the base value.
* **result_decimal** (number, required): This field might be used for displaying the calculated result in decimal format.
* **base_value_integer** (number, required): This field might be used to specify if the base value should be treated as an integer.
