# financial_health_check_form - Help Guide
## Purpose
The financial health check form is designed to gather information about a client's financial situation. It is essential to provide accurate and honest answers to help financial advisors offer tailored advice and guidance.

## How To Complete This Form
To complete the form, follow these steps:

1. Review the instructions and understand the purpose of each section.
2. Answer each question honestly and accurately.
3. Fill in all required fields marked as "required".
4. Use the available options for select fields to provide the correct information.
5. Submit the form once completed.

## Field-by-Field Explanation

* **financial_health_check_form_1** (`text`, required/optional): This is a note field for any additional comments or information about the client's financial situation.
* **financial_health_check_form_2** (`text`, required): Enter the client's income amount.
* **financial_health_check_form_3** (`number`, required/optional): Enter the client's current savings amount.
* **financial_health_check_form_4** (`number`, required/optional): Enter the client's current investments amount.
* **financial_health_check_form_5** (`select_one`, required): Select the client's primary financial concern from the options: income, expenses, savings, or investments.
* **financial_health_check_form_6** (`select_multiple`, optional): Select all applicable financial concerns from the options: Yes or No.
* **financial_health_check_form_7** (`date`, required/optional): Enter the client's last financial review date.
* **financial_health_check_form_8** (`time`, required/optional): Enter the client's preferred appointment time for a financial review.
* **financial_health_check_form_9** (`email`, required/optional): Enter the client's contact email for follow-up communications.
* **financial_health_check_form_10** (`text`, required/optional): Enter any additional comments or information about the client's financial situation.
