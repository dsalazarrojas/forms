# Financial Document Request Form - Help Guide

## Purpose
The Financial Document Request Form is designed to collect requests for financial documents from clients, such as tax returns, bank statements, or identification documents. This form is used to gather information about the document requested, including the type of document, date, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

1.  Select the type of financial document you are requesting (e.g., Tax Return, Bank Statement, or Identification Document).
2.  Enter the date the document is due or was issued.
3.  Provide the name of the document.
4.  Enter the client's name, email address, phone number, and any other relevant contact information.
5.  Upload the requested financial document, if applicable.
6.  Enter the financial institution associated with the document, if applicable.
7.  Select the person assigned to handle the document request.
8.  Optionally, provide a file description and file type.
9.  Enter the file size and upload date.
10.  Select the file status (Pending, Completed, or Failed).
11.  Enter any additional comments about the document request.
12.  Enter the name and email of the user requesting the document.
13.  Optionally, enter the user's phone number and comments.
14.  Select the person assigned to handle the document request.
