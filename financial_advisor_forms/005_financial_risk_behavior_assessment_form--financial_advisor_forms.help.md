# Financial Risk Behavior Assessment Form - Help Guide
## Purpose
This form is designed to help financial advisors understand clients' investment behavior, tolerance, and goals. The information collected helps advisors provide personalized guidance and recommendations.

## How To Complete This Form
To complete this form, please follow these steps:

1.  On the **Client Onboarding** page, enter a brief description of the client.
2.  On the **Portfolio Reviews** page, select all applicable investment reviews that apply to the client.
3.  On the **Risk Tolerance** page, enter a number between 1-10, indicating the client's risk tolerance level.
4.  On the **Investment Experience** page, select the best investment experience from the provided options.
5.  On the **Financial Goals** page, enter a brief description of the client's financial goals.
6.  On the **Investment Objects** page, select all applicable investment objects relevant to the client's investments.
7.  On the **Risk Attitude** page, enter the number of years the client has been actively investing.

## Field-by-Field Explanation

* **Client Onboarding (Required/Optional)**: Enter a brief description of the client.
* **Portfolio Reviews (Required/Optional)**: Select all applicable investment reviews that apply to the client (e.g., Option 1, Option 2, Option 3).
* **Risk Tolerance (Required)**: Enter a number between 1-10, indicating the client's risk tolerance level. A lower number indicates a lower risk tolerance.
* **Investment Experience (Required)**: Select the best investment experience from the provided options.
* **Financial Goals (Required/Optional)**: Enter a brief description of the client's financial goals.
* **Investment Objects (Required)**: Select all applicable investment objects relevant to the client's investments.
* **Risk Attitude (Required/Optional)**: Enter the number of years the client has been actively investing.
