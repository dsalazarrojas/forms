# financial_performance_benchmark_consent_form - Help Guide
## Purpose
The financial_performance_benchmark_consent_form is a form used to collect participant consent for financial data collection and sharing in financial benchmarking projects.

## How To Complete This Form
1. Fill out the form completely, including all required and optional fields.
2. Enter the participant's consent and provide their signature.

## Field-by-Field Explanation

* **Participant Consent** (`participant_consent`, `text`, required/optional): This is a text field where the participant can provide their consent to the collection and sharing of their financial data.
* **Financial Data Use** (`financial_data_use`, `select_multiple`, required/optional): This is a multiple-select field where the participant can choose how their financial data will be used. The options are:
	+ 'Yes'
	+ 'No'
* **Data Collection Start** (`data_collection_start`, `date`, required/optional): This is a date field where the participant can enter the start date of the data collection process.
* **Data Collection End** (`data_collection_end`, `date`, required/optional): This is a date field where the participant can enter the end date of the data collection process.
* **Benchmarking Project** (`benchmarking_project`, `text`, required/optional): This is a text field where the participant can enter the name of the benchmarking project.
* **Benchmarking Project Type** (`benchmarking_project_type`, `text`, required/optional): This is a text field where the participant can enter the type of benchmarking project.
* **Participant Information** (`participant_information`, `text`, required/optional): This is a text field where the participant can enter additional information about themselves.
* **Financial Data Sharing** (`financial_data_sharing`, `text`, required/optional): This is a text field where the participant can enter the details about data sharing.
* **Consent Date** (`consent_date`, `date`, required/optional): This is a date field where the participant can enter the date of their consent.
* **Participant Signature** (`participant_signature`, `text`, required/optional): This is a text field where the participant can sign their name.

## Tips
* Please ensure that all fields are filled out completely and accurately.
* If you are unsure about any field, please ask the project administrator for clarification.
* Please do not fill out this form if you are not authorized to do so.
