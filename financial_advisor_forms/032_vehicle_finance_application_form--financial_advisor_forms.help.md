# Vehicle Finance Application Form - Help Guide
## Purpose
The Vehicle Finance Application Form is designed to collect information from customers seeking vehicle finance for the purchase or refinancing of a vehicle. This form will help the financial advisor to evaluate and determine the eligibility for a vehicle loan.

## How To Complete This Form
To fill out this form, please follow these steps:

1. Fill in the main page with your personal details.
2. Provide information about the vehicle you are interested in financing.
3. Share your contact information so we can get back to you.
4. Answer questions about your employment status and income.
5. Select the desired loan terms and conditions.

## Field-by-Field Explanation

* **Vehicle Info (id: 2)**
	+ Type: text
	+ Purpose: Enter the details of the vehicle you are interested in financing.
* **Contact Info (id: 3)**
	+ Type: text
	+ Purpose: Enter your contact information so we can get back to you.
* **Employment Info (id: 4)**
	+ Type: text
	+ Purpose: Enter your employment status and occupation.
* **Income Info (id: 5)**
	+ Type: text
	+ Purpose: Enter your current income and other relevant financial information.
* **Employment Status (id: 6)**
	+ Type: select_one
	+ Purpose: Select your current employment status.
* **Income Frequency (id: 7)**
	+ Type: select_multiple
	+ Purpose: Select how frequently you receive income.
* **Income Amount (id: 8)**
	+ Type: number
	+ Purpose: Enter your current income amount.
* **Vehicle Make (id: 9)**
	+ Type: select_multiple
	+ Purpose: Select the make of the vehicle you are interested in financing.
* **Vehicle Year (id: 10)**
	+ Type: select_multiple
	+ Purpose: Select the year of the vehicle you are interested in financing.
* **Loan Amount (id: 11)**
	+ Type: number
	+ Purpose: Enter the loan amount you are seeking.
* **Loan Term (id: 12)**
	+ Type: select_multiple
	+ Purpose: Select the desired loan term.
* **Finance Provider (id: 13)**
	+ Type: select_one
	+ Purpose: Select your current finance provider.
* **Loan Type (id: 14)**
	+ Type: select_one
	+ Purpose: Select the type of loan you are seeking.
* **Payment Plan (id: 15)**
	+ Type: select_multiple
	+ Purpose: Select the payment plan you are interested in.
* **Payment Frequency (id: 16)**
	+ Type: select_multiple
	+ Purpose: Select how frequently you would like to make payments.
* **Loan Status (id: 17)**
	+ Type: select_one
	+ Purpose: Select the status of your current loan.

## Tips

* Please fill out this form accurately and honestly.
* Make sure to answer all required fields.
* If you have any questions or concerns, do not hesitate to contact us.
