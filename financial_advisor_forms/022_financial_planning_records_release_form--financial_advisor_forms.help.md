# Financial Planning Records Release Form - Help Guide
## Purpose
The Financial Planning Records Release Form is a document used to formally release and terminate financial planning records. It ensures that all parties involved in the planning process are aware of their roles and responsibilities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the client's name in the Client Authorization field.
2. Enter the financial institution's name in the Financial Institution field.
3. Enter the financial planner's name in the Financial Planner field.
4. Enter the start date of the client's authorization in the Authorization Start Date field.
5. Enter the end date of the client's authorization in the Authorization End Date field.
6. Select the trusted parties involved in the planning process from the Trusted Party options.
7. Select the reason for termination from the Authorization Termination options.
8. Sign the form with your signature in the Client Signature field.
9. Sign the form with the financial institution's signature in the Financial Institution Signature field.
10. Sign the form with the financial planner's signature in the Financial Planner Signature field.

## Field-by-Field Explanation
* **Client Authorization** (Client Authorization, text, required): Enter the client's name to confirm their authorization of the financial planning records.
* **Financial Institution** (Financial Institution, text, required): Enter the name of the financial institution involved in the planning process.
* **Financial Planner** (Financial Planner, text, required): Enter the name of the financial planner involved in the planning process.
* **Authorization Start Date** (Authorization Start Date, date, required): Enter the date the client's authorization began.
* **Authorization End Date** (Authorization End Date, date, required): Enter the date the client's authorization ended.
* **Trusted Party** (Trusted Party, select_multiple, required): Select all parties who will have access to the financial planning records. 
  - Option 1: First Option
  - Option 2: Second Option
  - Option 4: Fourth Option
  - Option 5: Fifth Option
* **Authorization Termination** (Authorization Termination, select_one, required): Select the reason for terminating the client's authorization.
  - Option 1: First Option
  - Option 2: Second Option
  - Option 3: Third Option
* **Client Signature** (Client Signature, note, required): Sign to confirm the client's authorization.
* **Financial Institution Signature** (Financial Institution Signature, note, required): Sign to confirm the financial institution's authorization.
* **Financial Planner Signature** (Financial Planner Signature, note, required): Sign to confirm the financial planner's authorization.
* **Financial Planner Note** (Financial Planner Note, note, optional): Enter any additional notes from the financial planner.
* **Trusted Party 2** (Trusted Party 2, select_multiple, optional): Select additional trusted parties with access to the financial planning records. 
  - Option 4: Fourth Option
  - Option 5: Fifth Option
* **Trusted Party 3** (Trusted Party 3, select_multiple, optional): Select additional trusted parties with access to the financial planning records.
