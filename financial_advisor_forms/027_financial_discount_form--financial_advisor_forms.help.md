# Financial Discount Form - Help Guide
## Purpose
The Financial Discount Form is used to capture information related to financial discounts, allowing customers or financial advisors to provide accurate and complete details for processing.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the store business where the discount will be applied.
2. Enter the discount code associated with the discount.
3. Select the type of discount (cash, gift card, or other).
4. Enter the discount percentage.
5. Enter the expiration date of the discount.
6. Enter the start date of the discount.
7. Enter the end date of the discount.
8. Enter the maximum use count for the discount.
9. Enter the minimum use count for the discount.
10. Enter the maximum use percentage.
11. Enter the minimum use percentage.
12. Enter a brief description of the discount.
13. Enter your name (the person submitting the form).
14. Enter your email address (the contact information for follow-up).
15. Enter your phone number (for further contact).
16. Select the type of phone number you're using (home, work, or cell).

## Field-by-Field Explanation
* **Store Business** (`store_business`, text, required): Enter the name of the store where the discount will be applied.
* **Discount Code** (`discount_code`, text, required): Enter the unique code associated with the discount.
* **Discount Type** (`discount_type`, select_one, required): Select the type of discount (cash, gift card, or other).
* **Discount Percent** (`discount_percent`, number, required): Enter the discount percentage.
* **Expiration Date** (`expiration_date`, date, required): Enter the date when the discount expires.
* **Start Date** (`start_date`, date, required): Enter the date when the discount starts.
* **End Date** (`end_date`, date, required): Enter the date when the discount ends.
* **Max Use Count** (`max_use_count`, number, required): Enter the maximum number of times the discount can be used.
* **Min Use Count** (`min_use_count`, number, required): Enter the minimum number of times the discount can be used.
* **Max Use Percent** (`max_use_percent`, number, required): Enter the maximum percentage of use for the discount.
* **Min Use Percent** (`min_use_percent`, number, required): Enter the minimum percentage of use for the discount.
* **Discount Description** (`discount_description`, text, required): Enter a brief description of the discount.
* **User Name** (`user_name`, text, required): Enter your name for reference.
* **User Email** (`user_email`, text, required): Enter your email address for contact.
* **User Phone** (`user_phone`, text, required): Enter your phone number for further contact.
* **User Phone Type** (`user_phone_type`, select_one, required): Select the type of phone number you're using (home, work, or cell).
