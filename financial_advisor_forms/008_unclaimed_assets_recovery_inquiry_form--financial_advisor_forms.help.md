# Unclaimed Assets Recovery Inquiry Form - Help Guide
## Purpose
The Unclaimed Assets Recovery Inquiry Form is used to submit an inquiry for the recovery of unclaimed assets. This form is designed to gather essential information about the asset recovery request, including details about the asset, the recovery team, and the contact information of the person submitting the request.

## How To Complete This Form
To complete this form, follow these steps:

1. **Fill out the required fields**: Ensure that all the required fields, marked as "Required", are filled out completely.
2. **Choose the correct recovery team**: Select the correct team from the Legal or Financial Team options.
3. **Specify the request status**: Choose the current status of the request from the Pending, Approved, or Denied options.
4. **Select the correct recovery method**: Enter the recovery method for the unclaimed asset.
5. **Enter contact details**: Provide a valid email address and any additional contact information if available.
6. **Verify asset details**: Double-check the asset type, value, and currency to ensure accuracy.

## Field-by-Field Explanation
* **Recovery Details** (Required)
	+ A brief description of the unclaimed asset being recovered.
* **Request Documentation** (Optional)
	+ Any supporting documentation for the asset recovery request.
* **Request Date** (Required)
	+ The date the asset recovery request was made.
* **Recovery Service Details** (Optional)
	+ Additional details about the recovery service.
* **Legal or Financial Team** (Required)
	+ Select the team handling the asset recovery request.
* **Request Status** (Required)
	+ Current status of the asset recovery request.
* **Recovery Agent** (Optional)
	+ The person or team handling the asset recovery.
* **Request Description** (Optional)
	+ A detailed description of the asset recovery request.
* **Unclaimed Property** (Required)
	+ List all unclaimed assets being recovered.
* **Notes** (Optional)
	+ Any additional notes about the asset recovery request.
* **Contact Details** (Optional)
	+ Contact information for the person making the request.
* **Email** (Required)
	+ A valid email address for the person making the request.
* **Phone** (Optional)
	+ Phone number for the person making the request.
* **Address** (Optional)
	+ Address for the person making the request.
* **Recovery Service** (Optional)
	+ The recovery service used for the asset.
* **Financial Institution** (Optional)
	+ The financial institution related to the asset.
* **Unclaimed Asset** (Optional)
	+ A brief description of the unclaimed asset.
* **Request Amount** (Required)
	+ The amount of the asset being recovered.
* **Recovery Method** (Optional)
	+ The method used to recover the asset.
* **Recovery Notes** (Optional)
	+ Additional notes about the asset recovery process.
* **Financial Institution** (Optional)
	+ The financial institution related to the asset.
* **Recovery Status** (Optional)
	+ Current status of the asset recovery request.
* **Asset Type** (Optional)
	+ The type of asset being recovered.
* **Asset Value** (Optional)
	+ The value of the asset.
* **Asset Value Currency** (Optional)
	+ The currency of the asset value.
