# financial_model_troubleshooting_guide - Help Guide
## Purpose
This form is designed to help users troubleshoot issues with a financial model. It is intended for internal use by financial model administrators or support teams and should only be used to report issues that directly relate to the financial model.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Financial Model Troubleshooting Guide" title field. This is the main title of the form and should clearly describe the issue you are experiencing.
2. Select the urgency of the issue (High, Medium, or Low) in the "Urgency" field. This will help the support team understand the priority level of the issue.
3. Enter a detailed description of the issue in the "Issue Description" field. This is an essential field as it will help the support team understand the root cause of the problem.
4. Identify the type of issue you are experiencing (Modeling Error, Data Error, or User Error) in the "Issue Type" field. This will help the support team narrow down the cause of the problem.
5. If relevant, select any supporting files that may help the support team diagnose the issue in the "Supporting Files" field.
6. Enter any additional details about the issue in the "Issue Details" field.
7. Add any comments or notes about the issue in the "Comments" field.
8. If applicable, select any additional supporting files in the "Supporting Files 2" field.
9. Enter the resolution time for the issue in the "Resolution Time" field.
10. Add any additional comments or notes about the resolution in the "Comments 2" field.
11. If applicable, select the resolution status of the issue (Open, Closed, or In Progress) in the "Resolution Status" field.
12. Enter the resolution time for the issue in the "Resolution Time 2" field.
