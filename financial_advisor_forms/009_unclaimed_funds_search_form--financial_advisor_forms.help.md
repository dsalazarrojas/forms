# Unclaimed Funds Search Form - Help Guide
## Purpose
The Unclaimed Funds Search Form is designed to search for unclaimed funds on behalf of account holders. This form helps users find and track unclaimed funds by gathering relevant information from the user.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information.
2. Review the form to ensure that you are not searching for the same account holder or unclaimed funds.

## Field-by-Field Explanation

* **account_holder** (required, text): Enter the name of the account holder you are searching for.
* **account_number** (text, optional): Enter the account number if available.
* **address** (text, optional): Enter the address of the account holder if known.
* **phone** (email, optional): Enter the phone number or email of the account holder if available.
* **authorization_number** (text, optional): Enter the authorization number if available.
* **account_type** (select_one, optional): Select the type of account.
* **search_details** (text, required): Enter a brief description of the search.
* **search_status** (select_multiple, optional): Select the status of the search.
* **followup_details** (text, required): Enter a brief description of the follow-up action.
* **followup_status** (select_multiple, optional): Select the status of the follow-up action.
* **account_name** (text, optional): Enter the name of the account if available.
* **account_number** (text, optional): Enter the account number if available.
* **search_notes** (note, optional): Add any additional search notes.
* **followup_notes** (note, optional): Add any additional follow-up notes.
* **search_date** (date, optional): Enter the date of the search if available.
* **followup_date** (date, optional): Enter the date of the follow-up action if available.
* **search_time** (time, optional): Enter the time of the search if available.
* **followup_time** (time, optional): Enter the time of the follow-up action if available.
* **search_by** (text, optional): Enter the person searching.
* **search_notes** (text, optional): Add any additional search notes.
* **followup_by** (text, optional): Enter the person doing the follow-up action.
* **account_holder_email** (email, optional): Enter the email of the account holder if available.
* **account_holder_phone** (text, optional): Enter the phone number of the account holder if available.
* **followup_notes** (note, optional): Add any additional follow-up notes.
* **followup_comments** (note, optional): Add any additional follow-up comments.

## Tips
- Be sure to fill in all required fields accurately and completely.
- Ensure that you are not searching for the same account holder or unclaimed funds.
- Use additional fields for any additional information that may be relevant to your search or follow-up action.
