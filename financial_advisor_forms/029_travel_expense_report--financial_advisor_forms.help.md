# travel-expense-report - Help Guide
## Purpose
The travel-expense-report form is a tool for users to report their travel expenses. This form is used to provide details about expenses related to travel, such as type, category, date, time, and other relevant information. The form is designed to help financial advisors track and analyze travel expenses.

## How To Complete This Form
1. Select the relevant options from the dropdown menu for "Expense Category" to indicate the type of expense.
2. Choose the correct "Expense Type" from the dropdown menu to further specify the category of expense.
3. Enter the date of the expense in the format "mm/dd/yy".
4. If applicable, input the time of the expense in the format "hh:mm".
5. Add any additional notes about the expense in the "Note" field.
6. Enter the email address (if applicable) and phone number (if applicable).
7. Review and submit the form.

## Field-by-Field Explanation

* **Expense Category** (`travel_expense_form_section_1_expense_category`): Choose the correct category for the expense, such as "lodging", "transportation", or "food-and-beverage".
* **Expense Type** (`travel_expense_form_section_1_expense_type`): Select the specific type of expense within the category chosen above, such as "lodging" or "transportation".
* **Date** (`travel_expense_form_section_1_expense_date`): Enter the date of the expense in the format "mm/dd/yy".
* **Time** (`travel_expense_form_section_1_expense_time`): If applicable, input the time of the expense in the format "hh:mm".
* **Note** (`travel_expense_form_section_1_expense_note`): Add any additional notes about the expense.
* **Email** (`travel_expense_form_section_1_expense_email`): Enter the email address associated with the expense, if applicable.
* **Phone Number** (`travel_expense_form_section_1_expense_phone`): Enter the phone number associated with the expense, if applicable.

## Tips
* Make sure to enter all required fields for accurate reporting.
* Use the correct format for dates and times.
* If you have any issues or questions, contact your financial advisor for assistance.
