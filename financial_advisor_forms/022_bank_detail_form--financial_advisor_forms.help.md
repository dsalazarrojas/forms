# Bank Detail Form - Transaction Checklist - Help Guide

## Purpose
This form is used to document and verify bank transactions for compliance and auditing purposes. It ensures that all necessary information is collected to accurately record and report on transactions, including financial advisor and employee information, transaction details, and compliance checks.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields:
	* **Financial Advisor / Employee Name**: Enter the name of the financial advisor or employee handling the transaction.
	* **Employee ID**: Enter the ID number of the employee who is processing the transaction.
	* **Date of Transaction**: Enter the date of the transaction.
	* **Batch or Reference Number**: Enter the batch or reference number associated with the transaction.
	* **Customer Account Name**: Enter the name of the customer's account.
	* **Customer Account Number**: Enter the account number of the customer's account.
	* **Total Cash Amount**: Enter the total amount of cash involved in the transaction.
	* **Number of Checks**: Enter the total number of checks involved in the transaction.
	* **Total Check Value**: Enter the total value of all checks involved in the transaction.
	* **Primary Transaction Type**: Select the type of transaction (e.g. Standard Deposit, Withdrawal Request, etc.)
	* **Is this transaction over $10,000?**: Select 'True' if the transaction amount is over $10,000.
	* **Declared Source of Funds**: Select the source of funds for the transaction (e.g. Employment Income, Sale of Asset, etc.)
	* **Does this require supervisor override?**: Select 'Yes' if the transaction requires a supervisor override due to limits being exceeded or out-of-state checks.

## Field-by-Field Explanation

* **Financial Advisor / Employee Name**: Enter the name of the financial advisor or employee handling the transaction.
* **Employee ID**: Enter the ID number of the employee who is processing the transaction.
* **Date of Transaction**: Enter the date of the transaction, in the format MM/DD/YY.
* **Batch or Reference Number**: Enter the batch or reference number associated with the transaction.
* **Customer Account Name**: Enter the name of the customer's account.
* **Customer Account Number**: Enter the account number of the customer's account.
* **Identity Verified**: Check if a government-issued ID was presented and verified for the customer.
* **Total Cash Amount**: Enter the total amount of cash involved in the transaction.
* **Number of Checks**: Enter the total count of physical checks being processed.
* **Total Check Value**: Enter the total value of all checks involved in the transaction.
* **Primary Transaction Type**: Select the type of transaction (e.g. Standard Deposit, Withdrawal Request, etc.)
* **Is this transaction over $10,000?**: Select 'True' if the transaction amount is over $10,000.
* **Declared Source of Funds**: Select the source of funds for the transaction (e.g. Employment Income, Sale of Asset, etc.)
* **Does this require supervisor override?**: Select 'Yes' if the transaction requires a supervisor override due to limits being exceeded or out-of-state checks.

## Tips

* Ensure all fields are filled in accurately and completely.
* Use this form for all transactions that need to be documented and verified.
* If a customer's identity is verified, select 'Yes - ID Verified' in the Identity Verified field.
* If a transaction requires a supervisor override, select 'Yes - Limits Exceeded' or 'Yes - Out-of-state check' in the Does this require supervisor override? field.
