# Personal Financial Statement Form - Help Guide
## Purpose
The Personal Financial Statement Form is a document used to report a user's financial status, including assets and liabilities. This form helps ensure accurate and up-to-date financial information for regulatory and internal reporting purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User Name.
2. Provide the Date of Last Update for the information provided in this form.
3. Enter your Account Number (if applicable).
4. Select the type of account you have (Checking, Savings, or Credit).
5. Report the value of each asset, up to 5.
6. For each asset, select the type from the list (Cash, Stock, Bond, Real Estate, or Business).
7. Enter the value of each asset.
8. For each liability, select the type from the list (Mortgage, Loan, Credit Card, Alimony, or Business).
9. Enter the value of each liability.
10. Enter any Other Asset Type and value, if applicable.
11. Enter any Other Liability Type and value, if applicable.
12. Enter your Income.
13. Enter your Net Worth.
14. Sign and date the form.

## Field-by-Field Explanation

* **User Name**: Enter your name as it appears on your identification documents.
* **Date of Last Update**: The date the information provided in this form was last updated.
* **Account Number**: The number of your account with the financial institution (if applicable).
* **Account Type**: The type of account you have (Checking, Savings, or Credit).
* **Asset 1 Type**: Select the type of asset from the list (Cash, Stock, Bond, Real Estate, or Business).
* **Asset 1 Value**: Enter the value of the asset.
* **Asset 2 Type**: Select the type of asset from the list (Cash, Stock, Bond, Real Estate, or Business).
* **Asset 2 Value**: Enter the value of the asset.
* **Asset 3 Type**: Select the type of asset from the list (Cash, Stock, Bond, Real Estate, or Business).
* **Asset 3 Value**: Enter the value of the asset.
* **Asset 4 Type**: Select the type of asset from the list (Cash, Stock, Bond, Real Estate, or Business).
* **Asset 4 Value**: Enter the value of the asset.
* **Asset 5 Type**: Select the type of asset from the list (Cash, Stock, Bond, Real Estate, or Business).
* **Asset 5 Value**: Enter the value of the asset.
* **Other Asset Type**: Enter any other type of asset not listed above.
* **Other Asset Value**: Enter the value of the asset.
* **Other Liability Type**: Enter any other type of liability not listed above.
* **Other Liability Value**: Enter the value of the liability.
* **Income**: Enter your monthly income.
* **Net Worth**: Enter your current net worth.
* **Signature**: Sign and date the form to confirm the accuracy of the information provided.
