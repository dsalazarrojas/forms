# Medical Simulation Training Evaluation Form - Help Guide
## Purpose
This form is designed to gather feedback and evaluations from users who have participated in a medical simulation training session. The information collected will help trainers and course administrators improve the training program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure you have all the necessary information required.
2. Answer all the questions to the best of your ability.
3. Ensure that all required fields are filled out correctly.

## Field-by-Field Explanation
### Session Number 
* Session Number (`session_number`, number, required: false)
  This field is used to record the number of the session you attended. Please enter the correct session number.

### Simulation Type 
* Simulation Type (`simulation_type`, select_one, required: false)
  This field asks if the simulation session included any type of simulation. Please select 'Yes' if it did, and 'No' if it did not.

### Training Session 
* Training Session (`training_session`, select_multiple, required: false)
  This field asks which type of training session you participated in. Please select all that apply. 

### Session Length 
* Session Length (`session_length`, number, required: false)
  This field is used to record the length of the session you attended. Please enter the correct session length in minutes.

### Simulation Start Time 
* Simulation Start Time (`simulation_start_time`, time, required: false)
  This field is used to record the start time of the simulation session. Please enter the correct start time in 24-hour format.

## Tips
* Please answer all questions to the best of your ability.
* If you are unsure about any of the fields, please contact the course administrator for clarification.
* Ensure that all required fields are filled out correctly.
