# Process Change Assessment Form - Help Guide
## Purpose
The Process Change Assessment Form is a tool used to track and document changes to processes within an organization. This form helps team members to assess and document changes, their impact, and the associated risk level, as well as the review and approval process.

## How To Complete This Form
1. Fill out the form for each process change you wish to document.
2. Choose the correct Change Type (e.g. Process Re-Design, Process Re-Definition, etc.).
3. Describe the impact of the change using the Description field.
4. Indicate the associated risk level using the Risk Level field.
5. Select the correct Change Status and Review Status using the provided options.
6. Enter the Reviewer Name and Reviewer Role, as well as the Review Date and Reviewer Name (if different from the Reviewer Name).
7. If applicable, indicate the Approval Date and Approved By.
8. Use the Review Comment field to note any relevant comments about the review process.
9. If necessary, fill out the fields for Team Member, Team Lead, Manager, Department, Process ID, Project ID, Project Leader, Process Leader, and Process Owner.

## Field-by-Field Explanation

* **New Project**: Enter a brief description of the new process.
* **Change Type**: Select one or more of the provided options to describe the nature of the change (e.g. Process Re-Design, Process Re-Definition, etc.).
* **Impact**: Describe the potential impact of the change.
* **Risk Level**: Select the associated risk level of the change (e.g. High, Medium, Low).
* **Change Date**: Enter the date the change was made.
* **Change Status**: Select one or more of the provided options to describe the status of the change (e.g. In Progress, Pending, Approved, Rejected).
* **Review Status**: Select one or more of the provided options to describe the status of the review (e.g. Approved, Rejected, Not Reviewd).
* **Reviewer Name**: Enter the name of the person reviewing the change.
* **Reviewer Role**: Enter the role of the reviewer.
* **Review Date**: Enter the date the review was completed.
* **Reviewer Name 2** (if applicable): Enter the name of the secondary reviewer.
* **Review Date 2** (if applicable): Enter the date the review was completed by the secondary reviewer.
* **Approved By**: Enter the name of the person who approved the change.
* **Review Comment**: Enter any comments about the review process.
* **Change Suggested By**: Enter the name of the person who suggested the change.
* **Team Member**: Enter the name of the team member responsible for the process.
* **Team Lead**: Enter the name of the team lead responsible for the process.
* **Manager**: Enter the name of the manager responsible for the process.
* **Department**: Enter the department responsible for the process.
* **Process ID**: Enter a unique identifier for the process.
* **Project ID**: Enter a unique identifier for the project.
* **Project Leader**: Enter the name of the project leader.
* **Process Leader**: Enter the name of the process leader.
* **Process Owner**: Enter the name of the process owner.
* **Reviewer Name 2**: Enter the name of the secondary reviewer.
* **Review Date 2**: Enter the date the review was completed by the secondary reviewer.

## Tips

* Make sure to fill out the form thoroughly and accurately to ensure accurate tracking of process changes.
* Use the provided options for Change Type, Risk Level, Change Status, and Review Status to ensure consistency across the organization.
* If you are unsure about any field, contact your department or process owner for guidance.
* Review and approve changes promptly to ensure timely and efficient process changes.
