# Long Acting Therapy Implementation Survey - Help Guide
## Purpose
This form is designed to gather feedback and experiences from end users about the implementation of long-acting therapies. Your input will help us understand how long-acting therapies are being used in real-world settings and what benefits and challenges users have faced.

## How To Complete This Form
1. Please fill out the form carefully, providing honest and detailed information about your experiences with long-acting therapies.
2. For each question, choose the answer that best describes your experiences.
3. Be as concise as possible when filling out the form, but please provide enough details to help us understand your answer.
4. If you have any questions or concerns, please don't hesitate to ask for clarification.
