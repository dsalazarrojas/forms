# Pedagogical Innovation Pilot Application Form - Help Guide
## Purpose
This form is designed to gather information about proposed pedagogical innovations for a pilot program. It is essential to provide accurate and detailed information to support the evaluation and approval process.

## How To Complete This Form
1. Fill out the personal details section with your first name, last name, email, phone number, and school name.
2. Provide a title and description for your project, including the start and end dates.
3. Select the pilot initiative and project lead.
4. Enter the project location.
5. Enter the budget for the project.
6. Add any additional notes about the project.
7. Select the status of the pilot initiative and project.
8. Choose the form submitter and submission date.
9. Select the user who last updated the form and the date it was updated.

## Field-by-Field Explanation

* **First Name** (`form_first_name`, `text`, required: false): Please enter your first name.
* **Last Name** (`form_last_name`, `text`, required: false): Please enter your last name.
* **Email** (`form_email`, `email`, required: false): Please enter your email address.
* **Phone** (`form_phone`, `text`, required: false): Please enter your phone number.
* **School Name** (`form_school_name`, `text`, required: false): Please enter the name of your school.
* **Proposal Title** (`form_proposal_title`, `text`, required: false): Please enter a title for your project proposal.
* **Project Description** (`form_project_description`, `note`, required: false): Please provide a detailed description of your project.
* **Project Start Date** (`form_project_start_date`, `date`, required: false): Please enter the start date of your project.
* **Project End Date** (`form_project_end_date`, `date`, required: false): Please enter the end date of your project.
* **Pilot Initiative** (`form_pilot_initiative`, `text`, required: false): Please select the pilot initiative that your project is part of.
* **Project Lead** (`form_project_lead`, `text`, required: false): Please enter the name of the project lead.
* **Location** (`form_location`, `text`, required: false): Please enter the location where the project will take place.
* **Budget** (`form_budget`, `number`, required: false): Please enter the budget for your project.
* **Additional Notes** (`form_additional_notes`, `note`, required: false): Please add any additional notes about your project.
* **Pilot Initiative Status** (`form_pilot_initiative_status`, `select_one`, required: false): Please select the status of your pilot initiative (Pending, Approved, or Rejected).
* **Project Status** (`form_project_status`, `select_one`, required: false): Please select the status of your project (Active, Archived, or Completed).
* **Form Submitted By** (`form_form_submitted_by`, `select_multiple`, required: false): Please select the user who submitted the form.
* **Form Submitted At** (`form_form_submitted_at`, `select_one`, required: false): Please select the date the form was submitted.
* **Form Updated By** (`form_form_updated_by`, `select_one`, required: false): Please select the user who last updated the form.
* **Form Updated At** (`form_form_updated_at`, `select_one`, required: false): Please select the date the form was last updated.

## Tips
- Please double-check the form fields for accuracy before submission.
- Ensure that you have the necessary permissions to submit the form.
- If you have any doubts or concerns, please contact the relevant authorities for assistance.
