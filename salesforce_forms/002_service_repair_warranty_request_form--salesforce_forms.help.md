# Service Repair Warranty Request Form - Help Guide
## Purpose
This form is used to request a service repair or warranty for a customer's product.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your contact information, including customer email and phone number.
2. Enter a detailed description of the issue with your product.
3. Select the priority level of the repair request.
4. Choose the type of request (Repair, Service, or Warranty).
5. Select the assigned team (Repair, Service, or Warranty).
6. Enter the date and time of the request.
7. Add any relevant customer notes.
8. Select the assigned technician.
9. Update the repair status.
10. Select who made the request (Customer or Internal).
11. Enter any additional customer signature.
12. Enter an internal signature.

## Field-by-Field Explanation

* **Service Repair Warranty Request** (`service_repair_warranty_form`): Enter a brief description of your service repair or warranty request.
* **Customer Details** (`customer_details`): Enter your name, address, and contact information.
* **Repair / Warranty Request** (`repair_warranty_request`): Enter a detailed description of the issue with your product.
* **Request Date** (`request_date`): Enter the date of the request.
* **Request Time** (`request_time`): Enter the time of the request.
* **Customer E-mail** (`customer_email`): Enter your email address.
* **Customer Phone** (`customer_phone`): Enter your phone number.
* **Service / Repair Description** (`service_repair_description`): Enter a detailed description of the issue with your product.
* **Repair / Request Status** (`repair_request_status`): Select the status of the request (Open, In Progress, or Done).
* **Service / Repair Priority** (`service_repair_priority`): Select the priority level of the request (High, Medium, or Low).
* **Service / Repair Type** (`service_repair_type`): Select the type of request (Repair, Service, or Warranty).
* **Assigned Team** (`assigned_team`): Select the team that will handle the request (Repair, Service, or Warranty).
* **Service / Repair Date** (`service_repair_date`): Enter the date of the service or repair.
* **Service / Repair Time** (`service_repair_time`): Enter the time of the service or repair.
* **Customer Notes** (`customer_notes`): Enter any additional notes from the customer.
* **Assigned Technician** (`assigned_technician`): Select the technician assigned to the request.
* **Service / Repair Status Update** (`service_repair_status_update`): Enter an update on the status of the request.
* **Service / Requester** (`service_repair_requester`): Select who made the request (Customer or Internal).
* **Customer Signature** (`customer_signature`): Enter your signature, if applicable.
* **Internal Signature** (`internal_signature`): Enter the internal signature, if applicable.
* **Service / Repair / Warranty Requester** (`service_repair_warranty_requester`): Select who made the request (Customer or Internal).
* **Request Date2** (`request_date2`): Enter an additional date, if applicable.
* **Request Time2** (`request_time2`): Enter an additional time, if applicable.
* **Internal Notes** (`internal_notes`): Enter any internal notes.
* **Service Repair Description2** (`service_repair_description2`): Enter an additional description, if applicable.

## Tips

* Make sure to fill in all required fields before submitting the form.
* Review each section carefully to ensure all information is accurate and complete.
* Use the drop-down menus to select options from the provided list.
* Do not hesitate to contact us if you need assistance or have any questions.
