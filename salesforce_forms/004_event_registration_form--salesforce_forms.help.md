# Event Registration Form - Help Guide
## Purpose
The Event Registration Form is a tool for registering and managing events. This form captures information about users and events, such as event start and end dates, user contact details, and event status.

## How To Complete This Form
1. To complete the form, follow the steps below:
	* Enter your user information, including your phone number and email address.
	* Provide details about the event, such as the start and end dates.
	* Specify the duration of the event (online, offline, or hybrid).
	* Add any additional notes or comments if needed.
2. Fill in the form with accurate and complete information to ensure that the event is registered correctly.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, required/optional): Enter your name or any other relevant information about yourself.
* **Event Info** (`event_info`, text, required/optional): Provide a brief description of the event.
* **User Phone** (`user_phone`, text, required/optional): Enter your phone number for contact purposes.
* **User Email** (`user_email`, email, required/optional): Enter your email address for communication.
* **Event Start Date** (`event_start_date`, date, required/optional): Choose the start date of the event.
* **User Time** (`user_time`, time, required/optional): Choose the time of day for the event.
* **Event End Date** (`event_end_date`, date, required/optional): Choose the end date of the event.
* **Event Duration** (`event_duration`, select one, required/optional): Select whether the event is online, offline, or hybrid.
* **Event Status** (`event_status`, select one, required/optional): Choose the status of the event (active or inactive).
* **Event Reg Type** (`event_reg_type`, select multiple, required/optional): Select the type of event registration (online, offline, or hybrid).
* **User Notes** (`user_notes`, note, required/optional): Add any additional comments or notes about the event.
* **Phone Label** (`user_phone_label`, text, required/optional): Enter a label for your phone number.

Note: Please ensure that all required fields are filled in to complete the form successfully.
