# Virtual Care Appointment Form - Help Guide
## Purpose
The Virtual Care Appointment Form is a critical tool for scheduling and managing virtual care appointments. This form helps patients and providers collect essential information for secure and efficient virtual care sessions.

## How To Complete This Form
1. Select the type of appointment you are scheduling. If you are a patient, select "Patient". If you are a provider, select "Virtual".
2. Enter your patient's name or the name of the patient you are scheduling the appointment for.
3. Choose a date for the appointment.
4. Select the start and end times for the appointment.
5. Enter the name of the provider who will be attending the virtual care session.
6. Enter the location of the appointment (optional).
7. Provide a reason for the appointment (optional).
8. Add any additional notes about the appointment.
9. Confirm HIPAA compliance.
10. If applicable, select the integration options for the appointment.
11. If applicable, select the embedded options for the appointment.
12. Enter any additional integration details.

## Field-by-Field Explanation

* **Appointment Type** (`Appointment Type`, `select_one`, required): This field determines the type of appointment you are scheduling. If you are a patient, select "Patient". If you are a provider, select "Virtual".
* **Patient Name** (`Patient Name`, `text`, required for "Patient" option): Enter your patient's name or the name of the patient you are scheduling the appointment for.
* **Date** (`Date`, `date`, required): Choose a date for the appointment.
* **Start Time** (`Start Time`, `time`, required): Select the start time for the appointment.
* **End Time** (`End Time`, `time`, required): Select the end time for the appointment.
* **Provider Name** (`Provider Name`, `text`, required): Enter the name of the provider who will be attending the virtual care session.
* **Location** (`Location`, `text`, optional): Enter the location of the appointment (if applicable).
* **Reason** (`Reason`, `text`, optional): Provide a reason for the appointment (if applicable).
* **Notes** (`Notes`, `note`, required): Add any additional notes about the appointment.
* **HIPAA Compliance** (`HIPAA Compliance`, `select_one`, required): Confirm that you understand and agree to the terms of HIPAA compliance.
* **Integration** (`Integration`, `select_multiple`, optional): Select the integration options for the appointment (if applicable).
* **Embedded** (`Embedded`, `select_one`, optional): Select the embedded options for the appointment (if applicable).
* **Embedded App** (`Embedded App`, `text`, optional): Enter any additional embedded details (if applicable).
* **Integration 1-10** (`Integration 1-10`, `text`, optional): Enter any additional integration details (if applicable).
* **Embedded Integration 1** (`Embedded Integration 1`, `text`, optional): Enter any additional embedded integration details (if applicable).

## Tips
* Ensure all required fields are completed before submitting the form.
* Verify the accuracy of all entered information before submitting.
* If you are unsure about any field or option, consult with your provider or patient coordinator.
* This form is designed for both patients and providers to ensure accurate and secure virtual care sessions.
