# Request For Proposal Form - Help Guide
## Purpose
This form is designed to collect information about project proposals, including project details, manager information, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Project Title" field with a brief description of the project.
2. Select "Yes" or "No" for "Project Manager" depending on whether the project has a manager.
3. Enter the name of the company associated with the project in the "Company" field.
4. Enter the name of the contact person for the project in the "Contact Person" field.
5. Enter the address of the project location in the "Address" field.
6. Enter the phone number of the contact person in the "Phone" field.
7. Enter the email address of the contact person in the "Email" field.
8. Enter a brief description of the project in the "Description" field.
9. Select the "Date Required" field if the project requires a specific date.
10. Select the "Date Received" field if the project has a specific date of receipt.
11. Enter the status of the project in the "Status" field.
12. Add any comments about the project in the "Comments" field.
13. Select "Yes" or "No" for "Project Type" depending on the type of project.

## Field-by-Field Explanation

* **Project Title** (text, required/optional): Enter a brief description of the project.
* **Project Manager** (select_one, required/optional): Select "Yes" if the project has a manager, otherwise select "No".
* **Company** (text, required/optional): Enter the name of the company associated with the project.
* **Contact Person** (text, required/optional): Enter the name of the contact person for the project.
* **Address** (text, required/optional): Enter the address of the project location.
* **Phone** (text, required/optional): Enter the phone number of the contact person.
* **Email** (email, required/optional): Enter the email address of the contact person.
* **Description** (text, required/optional): Enter a brief description of the project.
* **Date Required** (date, required/optional): Select the date when the project is required.
* **Date Received** (date, required/optional): Select the date when the project was received.
* **Status** (text, required/optional): Enter the status of the project.
* **Comments** (note, required/optional): Add any comments about the project.
* **Project Type** (select_one, required/optional): Select "Yes" if the project is of a certain type, otherwise select "No".
