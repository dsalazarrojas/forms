# Event Request Form - Help Guide
## Purpose
The Event Request Form is used to submit requests for events that need to be managed or organized. It allows users to provide details about the event, including its type, location, dates, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing a title for the event in the "Event Request" field.
2. Select the type of event you are requesting in the "Event Type" field. Choose from the options: conference, seminar, fair, or charity event.
3. Provide the location of the event in the "Event Location" field.
4. Enter the start and end dates of the event in the "Event Start Date" and "Event End Date" fields.
5. Select the start and end times of the event in the "Event Start Time" and "Event End Time" fields.
6. Enter a brief description of the event in the "Event Description" field.
7. Choose the current status of the event in the "Event Status" field. Options include: requested, confirmed, or cancelled.
8. Enter the name, phone number, and email of the contact person in the "Contact Name", "Contact Phone", and "Contact Email" fields.
9. If applicable, provide a URL for the event in the "Event URL" field.
10. Add any relevant attachments to the event in the "Event Attachments" field. Choose from the options: image or document.
11. Select the tool assigned to manage the event in the "Assigned Tool" field. Choose from the options: chatjimmy or Other.
12. Add any additional notes about the event in the "Event Status Notes" field.
13. Enter your name in the "Created By" field.
14. Enter the date and time you created the event in the "Created Date" and "Created Time" fields.
15. Enter the name of the person who last updated the event in the "Last Updated By" field.
16. Enter the date and time the event was last updated in the "Updated Date" and "Updated Time" fields.
