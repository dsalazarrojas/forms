# event_follow_up_survey - Help Guide
## Purpose
The event follow-up survey is used to gather information about past events, including event name, attendee name, event type, event date, event location, event description, event rating, and feedback.

## How To Complete This Form
To complete this form, simply fill out the fields as requested and follow the instructions below.

## Field-by-Field Explanation
* **Event Name** (1, text, optional): Enter the name of the event in question.
* **Attendee Name** (2, text, optional): Enter the name of the attendee, usually the person who participated in or hosted the event.
* **Event Type** (3, select_one, optional): Select the type of event that took place, such as "Yes" or "No".
* **Event Date** (4, date, optional): Enter the date the event took place.
* **Event Location** (5, text, optional): Enter the location where the event took place.
* **Event Description** (6, text, optional): Provide a brief description of the event.
* **Event Rating** (7, select_multiple, optional): Rate the event's quality, with options being "Good" and "Fair".
* **Feedback** (8, text, optional): Enter any comments or feedback about the event.
* **Comments** (9, text, optional): Enter any additional comments about the event.
