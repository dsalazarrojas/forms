# event_interest_form - Help Guide

## Purpose
This form is used to gather information about events of interest in a sales context.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the event type from the options provided.
2. Enter the date of the event in the date_of_event field. Note that this field is a date field, so it should be in the format MM/DD/YYYY.
3. Enter the time of the day for the event in the time_of_day field. Note that this field is a time field, so it should be in the format 12:00 PM or 13:00 for 1:00 PM.
4. Enter the location of the event in the location field.
5. Share any ideas or details about the event in the event_ideas field.

## Field-by-Field Explanation
* **Event Type** (`event_type`, select_one): Select the type of event from the options provided to help sales representatives identify the event type.
* **Date of Event** (`date_of_event`, date): Enter the date of the event in the format MM/DD/YYYY.
* **Time of Day** (`time_of_day`, time): Enter the time of the day for the event in the format 12:00 PM or 13:00 for 1:00 PM.
* **Location** (`location`, text): Enter the location of the event.
* **Event Ideas** (`event_ideas`, text): Share any ideas or details about the event.
