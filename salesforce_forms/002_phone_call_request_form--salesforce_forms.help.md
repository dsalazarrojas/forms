# phone_call_request_form - Help Guide
## Purpose
The phone call request form is a tool used to gather information from users to request a phone call for various reasons. This form captures contact details, reasons for the call, and other relevant information to ensure that the caller's needs are understood and met.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Contact Information** section with your name and contact details.
2. Select the **Reason for Call** and provide a brief explanation.
3. Choose the type of call you are requesting (landline or mobile).
4. Indicate whether this is a follow-up call or not.
5. Add any additional comments if needed.
6. Select the **Assigned Tool** that you would like to use for the call.
7. Upload the output file for this request (optional).
8. Enter the date and time you would like the call to take place.

## Field-by-Field Explanation

* **Contact Information**: Enter your full name and contact details to ensure we can reach out to you.
* **Reason for Call**: Select the reason for your phone call request (e.g., scheduling a meeting, answering questions, etc.).
* **Call Type**: Choose between landline or mobile to ensure the call is made to the correct number.
* **Follow Up**: Indicate whether this is a follow-up call or not.
* **Additional Comments**: Add any additional comments or details regarding the call.
* **Salesforce Form ID**: This is an internal field for Salesforce tracking purposes (do not fill this out).
* **Assigned Tool**: Select the tool that you would like to use for the call (e.g., chatjimmy).
* **Output File**: If you want to upload an output file, please select the relevant file for this request (optional).
* **Date**: Enter the date you would like the call to take place.
* **Time**: Enter the time you would like the call to take place.

Please note that the form is required to be filled in its entirety, and the date and time fields are mandatory for scheduling purposes.
