# Meal Reimbursement Form - Help Guide
## Purpose
The Meal Reimbursement Form is used by employees to submit claims for meal expenses incurred during work-related activities. This form captures essential information about the meal expense, including date, employee details, and expense categories.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the relevant date of the meal expense.
2. Choose your employee ID from the provided options.
3. Enter the amount claimed for the meal expense.
4. Select the category of the expense (e.g., Food, Transportation, Other).
5. Choose the type of expense (e.g., Breakfast, Lunch, Dinner).
6. Provide a brief description of the expense.
7. Enter the date the expense was claimed.

## Field-by-Field Explanation
### 1. Date of Meal 
* **Date of Meal (`date_of_meal`, `date`, required: false)**: This is the date on which the meal expense was incurred. Select the date from the calendar to ensure accuracy.
### 2. Employee ID 
* **Employee ID (`employee_id`, `select_one`, required: false)**: Select your employee ID from the provided options to authenticate your identity.
### 3. Amount Claimed 
* **Amount Claimed (`amount_claimed`, `number`, required: false)**: Enter the exact amount claimed for the meal expense.
### 4. Category 
* **Category (`category`, `select_multiple`, required: false)**: Choose the category of the expense from the provided options (e.g., Food, Transportation, Other).
### 5. Expense Type 
* **Expense Type (`expense_type`, `select_one`, required: false)**: Select the type of expense from the provided options (e.g., Breakfast, Lunch, Dinner).
### 6. Description 
* **Description (`description`, `note`, required: false)**: Provide a brief description of the expense to help facilitate processing.
### 7. Date Claimed 
* **Date Claimed (`date_claimed`, `date`, required: false)**: Enter the date the expense was claimed.

## Tips
* Ensure that the date of the meal expense is accurate to avoid discrepancies.
* Choose the correct category and expense type to ensure proper reimbursement processing.
* Provide a clear description to facilitate processing and approval.
