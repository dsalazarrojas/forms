# Swimming Competition Enrollment - Help Guide
## Purpose
This form is designed to collect information for a swimming competition event. Please fill it out carefully to ensure accurate registration.

## How To Complete This Form
1. Fill in your contestant's name in the "Contestant Name" field.
2. Enter your school's name in the "School Name" field (if applicable).
3. Select the date of the event using the "Event Date" field.
4. Choose the start time of the event using the "Event Time" field.
5. Enter the location of the event in the "Event Location" field.
6. Provide the swimmer's name in the "Swimmer Name" field.
7. Enter the swimmer's contact information in the "Swimmer Contact" field.
8. Choose the type of competition using the "Competition Type" field (e.g., Freestyle, Breaststroke, Backstroke).
9. Select the competition level (e.g., Local, Regional, National) from the "Competition Level" field.
10. Choose the swimmer's age group from the "Swimmer Age" field (e.g., 8-12, 13-15, 16-20).
11. Choose the swimmer's gender from the "Swimmer Gender" field (e.g., Male, Female, Other).
12. (Optional) Enter the start time of the event using the "Event Start Time" field.
13. (Optional) Enter the end time of the event using the "Event End Time" field.

## Field-by-Field Explanation
* **Contestant Name** (Text, Required): Enter the name of the swimmer registering for the event.
* **School Name** (Text, Optional): If the swimmer is affiliated with a school, enter the name here.
* **Event Date** (Date, Required): Choose the date of the event.
* **Event Time** (Time, Required): Choose the start time of the event.
* **Event Location** (Text, Optional): Enter the location of the event.
* **Swimmer Name** (Text, Required): Enter the name of the swimmer participating in the event.
* **Swimmer Contact** (Text, Optional): Enter the swimmer's contact information.
* **Competition Type** (Select One, Optional): Choose the type of competition (e.g., Freestyle, Breaststroke, Backstroke).
* **Competition Level** (Select Multiple, Required): Choose the competition level (e.g., Local, Regional, National).
* **Swimmer Age** (Select Multiple, Required): Choose the swimmer's age group (e.g., 8-12, 13-15, 16-20).
* **Swimmer Gender** (Select One, Required): Choose the swimmer's gender (e.g., Male, Female, Other).
* **Event Start Time** (Time, Optional): (Optional) Enter the start time of the event.
* **Event End Time** (Time, Optional): (Optional) Enter the end time of the event.
