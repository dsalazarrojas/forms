# enrollment_registration - Help Guide
## Purpose
This form is used for enrolling in a program and collecting demographic information from parents and youth. To use this form, the user should be enrolled in a program and be a parent or guardian of the youth.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the youth entry page (page 1) with the required information, including the youth's:
	* Entry number (a numerical value)
2. Move on to the parent registration page (page 2) and register the parent or guardian:
	* Enter the parent's registration number (a numerical value)
3. Review and agree to the consent section (page 3) by selecting one of the available options:
	* First name
	* Last name
	* Date of birth
4. On the program option page (page 4), select one program option for the youth:
	* Option 1, Option 2, or Option 3
5. On the program option 2 page (page 5), select multiple program options for the youth:
	* Option 1, Option 2, or Option 3
6. Enter the date (page 6) of the youth's:
	* Date of birth, using the standard date format (YYYY-MM-DD)
7. Enter the time (page 7) of the youth's:
	* Time, using the standard time format (HH:MM AM/PM)

## Field-by-Field Explanation

* **Youth entry** (`youth_entry`, `number`, **optional**): Enter the youth's entry number.
* **Parent registration** (`parent_registration`, `number`, **optional**): Enter the parent's registration number.
* **Consent** (`consent`, `select_one`, **optional**): Review and agree to the consent section by selecting one of the available options.
	+ First name: Enter the first name of the parent or guardian.
	+ Last name: Enter the last name of the parent or guardian.
	+ Date of birth: Enter the date of birth of the parent or guardian.
* **Program option 1** (`program_option_1`, `select_one`, **optional**): Select one program option for the youth.
	+ Option 1: Select this option for the youth.
	+ Option 2: Select this option for the youth.
	+ Option 3: Select this option for the youth.
* **Program option 2** (`program_option_2`, `select_multiple`, **optional**): Select multiple program options for the youth.
	+ Option 1: Select this option for the youth.
	+ Option 2: Select this option for the youth.
	+ Option 3: Select this option for the youth.
* **Date** (`date`, `date`, **optional**): Enter the date of birth of the youth, using the standard date format (YYYY-MM-DD).
* **Time** (`time`, `time`, **optional**): Enter the time of the youth, using the standard time format (HH:MM AM/PM).

## Tips
* Make sure to enter the correct information for the youth and parent or guardian.
* Review each page carefully before submitting the form.
* If you have already completed this form for a youth, do not attempt to complete it again.
