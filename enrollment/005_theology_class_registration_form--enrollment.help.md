# Theology Class Registration Form - Help Guide
## Purpose
This form is for students to register for a theology class. It will help us create a list of registered students for the class.

## How To Complete This Form

- First, review the form to make sure you understand each field and what information is required.
- If you're already registered, do not fill the form again.
- Fill out each field with the required information, and make sure to use a correct format for date fields.
- Once you've completed all fields, submit the form.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Please enter your first name as it is in your official documents.
* **Email** (`email`, email, optional): Enter your email address that you use to contact you. Please use the correct format `your_email@example.com`.
* **Course** (`course_name`, text, optional): Type the name of the course you want to register for.
* **Start Date** (`start_date`, date, optional): Enter the date you want to start the course. Please use the `MM/DD/YY` format, for example `06/02/2024`.
