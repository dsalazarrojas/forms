# woozworld_hot_spot_sign_up_sheet - Help Guide
## Purpose
The woozworld_hot_spot_sign_up_sheet form is designed to collect user information for internal purposes, such as creating user profiles and tracking user engagement.

## How To Complete This Form
1. Fill out the form fields as prompted, providing accurate and truthful information.
2. Review the fields and make sure you have provided all required information.
3. Submit the form to proceed.

* **User First Name** (`user_first_name`, text, optional): Enter your first name as it is commonly known.
* **User Last Name** (`user_last_name`, text, optional): Enter your last name as it is commonly known.
* **Email** (`email`, email, optional): Enter a valid email address associated with your account.
* **User Age** (`user_age`, number, optional): Enter your age for demographic purposes.
* **User Group** (`user_group`, select_one, optional): Select one of the following options:
	+ Yes
	+ No
* **User Email** (`user_email`, email, optional): Enter a valid email address associated with your account.
* **Phone** (`user_phone`, text, optional): Enter your phone number for contact purposes.
* **User Notes** (`user_notes`, note, optional): Enter any additional notes about yourself.
* **User Category** (`user_category`, select_multiple, optional): Select one or more of the following options:
	+ Yes
	+ No
* **User Country** (`user_country`, select_multiple, optional): Select one or more of the following options:
	+ Yes
	+ No
* **Region** (`user_region`, select_multiple, optional): Select one or more of the following options:
	+ Yes
	+ No
* **User Language** (`user_language`, select_multiple, optional): Select one or more of the following options:
	+ Yes
	+ No
* **User City** (`user_city`, select_multiple, optional): Select one or more of the following options:
	+ Yes
