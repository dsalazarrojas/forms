# Rideshare User Registration Form - Help Guide
## Purpose
This form collects registration information from users registering as either drivers or riders for rideshare services. Please fill out this form accurately and thoroughly for successful registration.

## How To Complete This Form
- Fill out the form in order from page 1 to page 27.
- Select "Submit" at the end of the form to complete registration.
