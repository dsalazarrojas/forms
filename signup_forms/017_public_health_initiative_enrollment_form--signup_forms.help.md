# Public Health Initiative Enrollment Form - Help Guide
## Purpose
This form is used to enroll individuals in a public health initiative. It captures essential information about the enrolee, enabling the initiative's team to track and manage their status effectively.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you are filling out the form for the correct person.
2. Fill out the form accurately and completely.
3. Review the form carefully before submitting.

## Field-by-Field Explanation

* **enrollment_details**: A text field where you can add any additional information about the enrolee.
  * Type: Text
  * Required: Optional
* **contact_details**: A text field for entering the enrolee's contact information.
  * Type: Text
  * Required: Optional
* **medical_conditions**: A select-one field where you can choose from the following options:
  * diabetes
  * hypertension
  * none
  * Type: Select One
  * Required: Optional
* **medications**: A select-multiple field where you can choose from the following options:
  * insulin
  * blood thinners
  * beta blockers
  * Type: Select Multiple
  * Required: Optional
* **follow_up_reminders**: A date field for setting follow-up reminders for the enrolee.
  * Type: Date
  * Required: Optional
* **phone_number**: A text field for entering the enrolee's phone number.
  * Type: Text
  * Required: Optional
* **email**: A text field for entering the enrolee's email address.
  * Type: Email
  * Required: Optional
* **follow_up_date**: A date field for setting the follow-up date for the enrolee.
  * Type: Date
  * Required: Optional
* **assigned_to**: A select-one field where you can choose who the enrolee will be assigned to.
  * chatjimmy
  * user2
  * user3
  * Type: Select One
  * Required: Optional
* **medical_notes**: A text field for adding any medical notes about the enrolee.
  * Type: Note
  * Required: Optional
* **follow_up_status**: A select-one field where you can track the enrolee's follow-up status.
  * pending
  * completed
  * missed
  * Type: Select One
  * Required: Optional

## Tips
Please fill out the form accurately and completely, and make sure to review it carefully before submitting. If you are unsure about any field, please ask your supervisor or the initiative's representative for guidance.
