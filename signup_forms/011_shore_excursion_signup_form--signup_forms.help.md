# shore_excursion_signup_form - Help Guide
## Purpose
The shore_excursion_signup_form is used to register participants for shore excursions. This form captures essential details about the tour, participants, and other relevant information to facilitate a smooth and enjoyable tour experience.

## How To Complete This Form
1. Ensure you have all the necessary information before starting the form.
2. Select the correct Tour Group for the excursion.
3. Enter the Tour Date and Tour Time for the excursion.
4. Choose the Port of Call for the excursion.
5. Select the Shore Excursion to be attended.
6. Enter the Participant Number.
7. Add any additional Tour Notes, if necessary.

## Field-by-Field Explanation
* **Tour Details**: Enter a brief description of the tour, including the name of the tour and any other relevant details.
* **Participant Details**: Enter the full name and any other relevant contact information for each participant.
* **Emergency Contact**: Enter the emergency contact information for each participant.
* **Tour Group**: Select the correct tour group for the excursion. This will help in organizing and managing the tour.
* **Tour Date**: Enter the date of the tour in the correct format (DD/MM/YYYY).
* **Tour Time**: Enter the time of the tour in the correct format (HH:MM).
* **Port of Call**: Select the port of call for the excursion. This will help in planning and logistics.
* **Shore Excursion**: Select the shore excursion to be attended. This will help in organizing and managing the tour.
* **Participant Number**: Enter the number of participants for the tour.
* **Tour Notes**: Enter any additional notes or comments about the tour, if necessary.
