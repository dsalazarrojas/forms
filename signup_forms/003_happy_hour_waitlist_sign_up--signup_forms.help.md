# happy_hour_waitlist_sign_up - Help Guide
## Purpose
This form is used to collect information from individuals interested in joining a happy hour waitlist. It helps the internal team determine suitability for the waitlist.

## How To Complete This Form
To complete this form, simply fill out the required fields and provide any additional information as requested.

## Field-by-Field Explanation
- **First name** (`First name`, text, required): Please enter your first name.
- **Last name** (`Last name`, text, required): Please enter your last name.
- **Email** (`Email`, email, optional): If you have an email address, please enter it so we can contact you about upcoming happy hour events.
- **Phone** (`Phone`, text, optional): If you have a phone number, please enter it so we can contact you about upcoming happy hour events.
- **Date of Birth** (`Date of Birth`, date, optional): Please enter your date of birth if you would like to be contacted about happy hour events for individuals with similar interests or demographics.
- **Time** (`Time`, time, optional): If you have a preferred time for happy hour events, please enter it.
- **Note** (`Note`, note, optional): If you have any additional information you'd like to share with us, please use this field.
- **Reservation Time** (`Reservation Time`, time, optional): If you have a preferred reservation time for happy hour events, please enter it.
- **Reservation Date** (`Reservation Date`, date, optional): If you have a preferred reservation date for happy hour events, please enter it.
- **Reservation Note** (`Reservation Note`, note, optional): If you have any additional information about your reservation preferences, please use this field.
- **Number of Guests** (`Number of Guests`, number, optional): If you know how many guests you will be bringing, please enter that number.
- **Special Request** (`Special Request`, text, optional): If you have any special requests or accommodations, please let us know.
- **Contact Name** (`Contact Name`, text, optional): If you'd like to be contacted by a specific person, please enter their name.
- **Contact Phone** (`Contact Phone`, text, optional): If you'd like to be contacted by phone, please enter the phone number of the contact person.
- **Contact Email** (`Contact Email`, email, optional): If you'd like to be contacted by email, please enter the email address of the contact person.

## Tips
* Please fill out the required fields (First name and Last name) to be considered for the happy hour waitlist.
* If you have any special requests or accommodations, please use the Special Request field.
* If you'd like to be contacted by a specific person, please enter their name in the Contact Name field.
* If you have any additional information you'd like to share, please use the Note field.
* This form is not a reservation, it is a waitlist sign-up form. You will be contacted when a happy hour event is scheduled.
