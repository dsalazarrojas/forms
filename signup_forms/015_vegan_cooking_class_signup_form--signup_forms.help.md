# vegan_cooking_class_signup_form - Help Guide
## Purpose
This form is used to sign up for a vegan cooking class. Fill out the form with your class details and preferences.

## How To Complete This Form
1. Fill in all the required fields with your class information and preferences.
2. Choose the class type (Vegan, Vegetarian, or Omnivore).
3. Provide a description of the class.
4. Select the location of the class.
5. Choose which admin to report to.
6. Set the participant count.
7. Select the payment method (Credit Card, Cash, or PayPal).

## Field-by-Field Explanation
* **Signup Form** (`signup_form`, text, required): Enter a brief description of your class.
* **Name** (`name`, text, required): Enter the name of the class.
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`phone`, text): Enter your phone number.
* **Address** (`address`, text): Enter the address of the class location.
* **Date** (`date`, date, required): Choose the date of the class.
* **Start Time** (`start time`, time, required): Choose the start time of the class.
* **End Time** (`end time`, time, required): Choose the end time of the class.
* **Class Duration** (`class duration`, number, required): Enter the duration of the class.
* **Class Type** (`class type`, select_one, required): Choose the type of class (Vegan, Vegetarian, or Omnivore).
* **Class Description** (`class description`, text, required): Enter a description of the class.
* **Class Location** (`class location`, text, required): Enter the location of the class.
* **Report To** (`report to`, select_multiple, required): Choose which admin will receive reports about the class.
* **Participant Count** (`participant count`, number, required): Enter the number of participants in the class.
* **Payment** (`payment`, select_one, required): Choose the payment method (Credit Card, Cash, or PayPal).

## Tips
* Be sure to fill out all required fields.
* If you are unsure about any field, refer back to this guide.
* If you are still having trouble, contact the form administrator.
