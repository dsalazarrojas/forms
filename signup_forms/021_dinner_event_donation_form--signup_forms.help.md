# Dinner Event Donation Form - Help Guide
## Purpose
The Dinner Event Donation Form is used to collect information about the dinner event and the donations to be made. Fill out this form to let us know what you would like to donate and in what quantity.

## How To Complete This Form
1. Select the items you would like to donate from the options provided on the "Donation Form" page.
2. Choose the quantity of each item you would like to donate using the "Donation Amount" field, if applicable.
3. Select the date and time of the dinner event using the "Event Date" and "Event Time" fields, if applicable.
4. Make your selection and submit the form once you have filled out all the required and optional fields.

## Field-by-Field Explanation
### **Signup Form** (Required)
Select "Yes" if you would like to participate in the dinner event.

### **Donation Form** (Optional)
Choose the items you would like to donate:
* Apples
* Bananas
* Grapes

### **Donation Amount** (Optional)
Enter the quantity of each item you would like to donate. This field is only visible if you select an item on the "Donation Form" page.

### **Event Date** (Optional)
Select the date of the dinner event.

### **Event Time** (Optional)
Select the time of the dinner event.
