# T Shirt Drop Off Sign Up Form - Help Guide

## Purpose
This form is used to sign up for a t-shirt drop off event. Please fill out the form accurately and completely to ensure that your information is recorded correctly.

## How To Complete This Form
Fill out this form completely and accurately. Make sure to enter your name, phone number, and event date correctly. If you are unsure about any of the questions, you can refer to the explanation below for field-by-field guidance.

## Field-by-Field Explanation

### First Name
**First Name** (`first_name`, `text`, required/true)
 Enter your first name here. This field is required, so please make sure to enter your correct name.

### Last Name
**Last Name** (`last_name`, `text`, required/true)
 Enter your last name here. This field is required, so please make sure to enter your correct name.

### Email
**Email** (`email`, `text`, required/false)
Enter your email address here if you have one. This field is not required but it's a good idea to enter it so that we can contact you with updates.

### Phone
**Phone** (`phone`, `text`, required/true)
Enter your phone number here. This field is required, so please make sure to enter your correct phone number.

### T Shirts
**T Shirts** (`tshirts`, `select_multiple`, required/true)
Select 'Yes' if you want a t-shirt, or 'No' if you do not.

### Size
**Size** (`size`, `select_one`, required/true)
Select the size you would like to wear, or choose 'No' if you don't want a custom size.

### Color
**Color** (`color`, `text`, required/false)
Enter the color you prefer. This field is not required, but it's helpful to know your favorite color.

### Date
**Date** (`date`, `date`, required/true)
Enter the date you can attend the event. Please select the date you can actually make it.

### T Shirt Type
**T Shirt Type** (`tshirt_type`, `select_one`, required/true)
Select the type of t-shirt you want: 'Yes' for a plain t-shirt or 'No' for a custom design.

### Quantity
**Quantity** (`quantity`, `number`, required/true)
Enter the number of t-shirts you want. Please be accurate so that we can prepare the correct number of shirts.

### Message
**Message** (`message`, `text`, required/false)
If you have any additional information or message for us, you can enter it here. This field is not required, so only enter what's necessary.

### Notes
**Notes** (`notes`, `text`, required/false)
If you have any additional notes or comments, you can enter them here. This field is not required, but it's helpful to know any extra information.

### Assigned To
**Assigned To** (`assigned_tool`, `select_one`, required/false)
Select 'Yes' if you are assigned a tool, or 'No' if you are not. This field is not required, but it's helpful to know who's assigned to you.

### Form ID
**Form ID** (`form_id`, `number`, required/true)
This field is automatically generated and should not be filled out. It's only used for internal tracking purposes.

### Category
**Category** (`category`, `select_one`, required/true)
Select the category you belong to. This field is required, so please make sure to select the correct category.

### Description
**Description** (`description`, `text`, required/false)
If you have a description for yourself, you can enter it here. This field is not required, so only enter what's necessary.

### Assigned Tool
**Assigned Tool** (`assigned_tool`, `select_one`, required/false)
Select 'Yes' if you are assigned a tool, or 'No' if you are not. This field is not required, so only enter it if it's necessary.

## Tips
Please make sure to fill out this form accurately and completely. If you have any questions or concerns, feel free to reach out to us for assistance.
