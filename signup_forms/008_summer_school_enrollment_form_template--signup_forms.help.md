# Summer School Enrollment Form Template - Help Guide
## Purpose
This form is used to collect and store information about students enrolling in summer programs at your school.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Child Name" field.
2. Enter the student's email address in the "Email" field.
3. Select the student's program preferences from the "Program Type" dropdown menu.
4. Enter the student's birthdate in the "Birthdate" field.
5. Enter the student's start and end dates in the "Start Date" and "End Date" fields, respectively.
6. Select the student's program status ("Active" or "Inactive") from the "Program Status" dropdown menu.
7. Enter the student's parent's name in the "Parent Name" field.
8. Enter the student's phone number in the "Phone" field.
9. Enter the student's address in the "Address" field.
10. Add any additional notes about the student in the "Note" field.
11. Select whether the student is enrolled in a program ("Yes" or "No") from the "Program" dropdown menu.
12. Select the payment method ("Yes" or "No") from the "Payment Method" dropdown menu.
13. Select the payment status ("Active" or "Inactive") from the "Payment Status" dropdown menu.
14. Enter the program fee in the "Program Fee" field.
15. Enter the total fees in the "Total Fee" field.
16. Enter the payment date in the "Payment Date" field.
17. Enter the enrollment date in the "Enrollment Date" field.
18. Enter any additional payment details in the "Payment Details" field.
19. Select the payment status update ("Active" or "Inactive") from the "Payment Status Update" dropdown menu.
20. Enter any notes about the payment status update in the "Payment Status Note" field.
21. Select the program status update from the "Program Status Update" field (text input).
22. Enter any notes about the program status update in the "Program Status Note" field.
23. Select whether the payment was refunded ("Yes" or "No") from the "Payment Refund" dropdown menu.

## Field-by-Field Explanation

* **Child Name (ID 1)**: Enter the student's name in this field.
* **Email (ID 2)**: Enter the student's email address in this field.
* **Program Type (ID 3)**: Select the type of program the student is enrolling in.
* **Program Duration (ID 4)**: Select the duration of the program the student is enrolling in.
* **Birthdate (ID 5)**: Enter the student's birthdate in this field.
* **Start Date (ID 6)**: Enter the start date of the program in this field.
* **End Date (ID 7)**: Enter the end date of the program in this field.
* **Program Status (ID 8)**: Select the status of the program the student is enrolling in.
* **Parent Name (ID 9)**: Enter the name of the parent or guardian of the student.
* **Phone (ID 10)**: Enter the student's phone number in this field.
* **Address (ID 11)**: Enter the student's address in this field.
* **Note (ID 12)**: Add any additional notes about the student in this field.
* **Program (ID 13)**: Select whether the student is enrolling in a program ("Yes" or "No").
* **Payment Method (ID 14)**: Select the payment method used by the student ("Yes" or "No").
* **Payment Status (ID 15)**: Select the status of the student's payment ("Active" or "Inactive").
* **Program Fee (ID 16)**: Enter the program fee in this field.
* **Total Fee (ID 17)**: Enter the total fees in this field.
* **Payment Date (ID 18)**: Enter the date of the payment in this field.
* **Enrollment Date (ID 19)**: Enter the date of the student's enrollment in this field.
* **Payment Details (ID 20)**: Add any additional payment details in this field.
* **Payment Status Update (ID 21)**: Select the updated status of the student's payment ("Active" or "Inactive").
* **Program Status Update (ID 22)**: Enter any notes about the program status update.
* **Payment Status Note (ID 23)**: Add any notes about the payment status update.
* **Payment Status Update Note (ID 24)**: Enter any notes about the payment status update.
* **Payment Refund (ID 25)**: Select whether the payment was refunded ("Yes" or "No").
