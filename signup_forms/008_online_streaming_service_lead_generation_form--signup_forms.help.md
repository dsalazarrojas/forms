# Online Streaming Service Lead Generation Form - Help Guide
## Purpose
The Online Streaming Service Lead Generation Form is designed to quickly collect data from website visitors and help streaming platforms and media brands follow up with them.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the online streaming service (field 1)
2. Select the category of the form (field 2)
3. Enter a brief description of how you want to capture and qualify prospects (field 3)
4. Enter the form ID (fields 4, 5, and 6)
5. Enter the name of the output file (field 7)
6. Select the assigned tool (field 8)
7. Enter a brief description of the category (field 9)
8. Enter a brief description of the form (field 10)
9. Select the output file (field 11)

## Field-by-Field Explanation
### Field 1: Online Streaming Service
* **Online Streaming Service** (text, required): Enter the name of the online streaming service you are promoting, such as "Netflix" or "Hulu".
*   This field is required and should be the name of the online streaming service you are promoting.

### Field 2: Category
*   **Category** (select_one, required): Select the category of the form you are filling out, such as "Signup Forms" or "Lead Generation Forms".
*   This field is required and should be selected carefully to ensure the form is filled out correctly.

### Field 3: Capture and qualify prospects
*   **Capture and qualify prospects** (text, required): Enter a brief description of how you want to capture and qualify prospects for your online streaming service.
*   This field is not required but is useful for providing more context.

### Field 4: Form ID
*   **Form ID** (number, required): Enter a unique ID for your form, such as 12345.
*   This field is required and should be a unique ID for your form.

### Field 5: Form Id 45993
*   **Form Id 45993** (number, required): Enter another unique ID for your form, such as 67890.
*   This field is required and should be a unique ID for your form.

### Field 6: Form Id 85711
*   **Form Id 85711** (number, required): Enter yet another unique ID for your form, such as 12345.
*   This field is required and should be a unique ID for your form.

### Field 7: Output File Name
*   **Output File Name** (text, required): Enter the name of the output file you want to create, such as "leads.csv".
*   This field is required and should be the name of the output file you want to create.

### Field 8: Assigned Tool
*   **Assigned Tool** (text, required): Select the tool you are using for your online streaming service, such as "Salesforce" or "Marketo".
*   This field is required and should be the tool you are using for your online streaming service.

### Field 9: Category (2)
*   **Category (2)** (text, required): Enter a brief description of the category, such as "streaming service".
*   This field is required and should be a brief description of the category.

### Field 10: Description
*   **Description** (text, required): Enter a brief description of the form, such as "Generate leads for online streaming service".
*   This field is required and should be a brief description of the form.

### Field 11: Output File
*   **Output File** (text, required): Enter the name of the output file you want to create, such as "leads.csv".
*   This field is required and should be the name of the output file you want to create.

## Tips

*   Make sure to fill out the form only once per prospect.
*   Enter accurate and clear information to ensure the form is filled out correctly.
*   If you are unsure about any field, refer back to this help guide for clarification.
