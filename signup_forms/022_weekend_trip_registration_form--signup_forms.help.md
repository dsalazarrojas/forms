# Weekend Trip Registration Form - Help Guide
## Purpose
This form is designed to collect participant information for a weekend trip. It aims to gather essential details about each participant, including contact information, preferences, and optional additional data.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the **Participant Name** field with the participant's name.
2.  Enter the participant's **Email** in the "Email" field.
3.  Enter the participant's **Phone Number** in the "Phone Number" field.
4.  Provide the participant's **Address** in the "Address" field.
5.  For **Participant Preferences**, select one of the available options from the dropdown menu (Participant 1, Participant 2, or Participant 3).
6.  Optionally, add any additional **Notes** or **Comments** about the participant.
7.  If required, upload a file or attach an image for the participant.
8.  Select one or more **Options** from the "Options" field.
9.  Choose one **Option** from the "Option" field.
10. Enter the participant's **Date** and **Time** for the trip.
11. Optionally, add any additional **Notes** or **Comments** about the participant.

## Field-by-Field Explanation

*   **Participant Name**: A text field to enter the participant's name.
*   **Email**: A text field to enter the participant's email address.
*   **Phone Number**: A text field to enter the participant's phone number.
*   **Address**: A text field to enter the participant's address.
*   **Participant Preferences**: A dropdown menu with three options (Participant 1, Participant 2, or Participant 3).
*   **Notes**: A text area for any additional notes or comments about the participant.
*   **Comments**: A text area for any additional comments about the participant.
*   **Participant Files**: A text field to upload files for the participant.
*   **Participant Image**: A note field to attach an image for the participant.
*   **Participant Audio**: A note field to attach an audio file for the participant.
*   **Participant Video**: A note field to attach a video file for the participant.
*   **Options**: A checkbox field to select one or more options for the participant.
*   **Option**: A dropdown menu with three options (Option 1, Option 2, or Option 3).
*   **Participant Date Range**: A date field to select a date range for the participant.
*   **Participant Time Range**: A time field to select a time range for the participant.
*   **Participant Datetime**: A date field to select a datetime for the participant.
*   **Participant Date Only**: A date field to select a date only for the participant.
*   **Participant Time Only**: A time field to select a time only for the participant.

Note: All fields marked as "Required" are mandatory and must be filled out.
