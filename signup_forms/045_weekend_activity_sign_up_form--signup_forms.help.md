# Weekend Activity Sign Up Form - Help Guide
## Purpose
This form is used to sign up for weekend activities such as hiking, movie nights, or other social events. Users can submit their information to participate in activities and get updates on assigned tools, dates, and locations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **User Information** (page 1) in the text field provided.
2. Select the **Activity Type** (page 2) that you would like to participate in. Options include Football, Hiking, and Movie Night.
3. Choose a **Date** (page 3) for the activity by selecting a date from the calendar.
4. Enter the **Time** (page 4) when you would like to participate in the activity.
5. Provide a brief **Location** (page 5) where the activity will take place.
6. Add a **Description** (page 6) of the activity to help others understand what it's about.
7. Enter your **Phone** (page 7) number so that organizers can contact you.
8. Enter your **Email** (page 8) address so that organizers can send you updates.
9. Add any additional **Note** (page 9) about the activity if needed.
10. Enter any **Activity Details** (page 10) such as specific equipment needed or other requirements.
11. Select the **Assigned Tool** (page 11) that you will be using for the activity.
12. Enter the **Assigned Date** (page 12) and **Assigned Time** (page 13) when you will be using the assigned tool.
13. Enter the **Assigned Location** (page 14) where you will be using the assigned tool.
14. Enter the **Assigned Email** (page 15) of the person you are coordinating with.
15. Select the **Activity Status** (page 16) of the activity such as Pending, In Progress, or Completed.
16. Enter the **Form ID** (page 17) to help track the activity.
17. Enter the **Assigned Tool ID** (page 18) of the assigned tool.

## Field-by-Field Explanation

* **User Information (page 1)**: Enter your name and any other relevant information about yourself.
* **Activity Type (page 2)**: Select the type of activity you would like to participate in.
* **Date (page 3)**: Choose a date for the activity.
* **Time (page 4)**: Enter the time when you would like to participate in the activity.
* **Location (page 5)**: Provide the location where the activity will take place.
* **Description (page 6)**: Add a brief description of the activity.
* **Phone (page 7)**: Enter your phone number so that organizers can contact you.
* **Email (page 8)**: Enter your email address so that organizers can send you updates.
* **Note (page 9)**: Add any additional notes about the activity if needed.
* **Activity Details (page 10)**: Enter any specific details about the activity.
* **Assigned Tool (page 11)**: Enter the tool that has been assigned to you for the activity.
* **Assigned Date (page 12)**: Enter the date when you will use the assigned tool.
* **Assigned Time (page 13)**: Enter the time when you will use the assigned tool.
* **Assigned Location (page 14)**: Enter the location where you will use the assigned tool.
* **Assigned Email (page 15)**: Enter the email of the person you are coordinating with.
* **Activity Status (page 16)**: Select the status of the activity.
* **Form ID (page 17)**: Enter the ID of the form to help track the activity.
* **Assigned Tool ID (page 18)**: Enter the ID of the assigned tool.

## Tips

* Make sure to enter accurate information about yourself and the activity.
* Double-check the details you enter to ensure they are correct.
* If you have any questions or need clarification, contact the organizers.
* If you need to cancel or modify your activity, update your form accordingly.
