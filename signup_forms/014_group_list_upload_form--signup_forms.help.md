# Group List Upload Form - Help Guide
## Purpose
The Group List Upload Form is a data collection tool used to upload and store information about groups, contacts, and events within an institutional setting, such as schools. Its primary function is to help authorized personnel manage and maintain accurate and up-to-date data for school groups, contacts, and events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Group List" page to input information related to groups.
2. Enter contact details using the "Contact Details" page.
3. Add group size, email, phone number, date, and time for each group on the corresponding pages.
4. Provide notes and event details on the "Notes" and "Event Details" pages.
5. Enter school-specific information, such as school name, address, phone number, website, email, and other relevant details on the corresponding pages.

## Field-by-Field Explanation

* **Group List (1)**: Enter a list of groups as text.
* **Contact Details (2)**: Select the contact information related to each group from the available options.
* **Group Size (3)**: Enter the size of each group.
* **Email (4)**: Enter the email address for each group.
* **Phone (5)**: Enter the phone number for each group.
* **Date (6)**: Select the date of the event or group meeting.
* **Time (7)**: Select the time of the event or group meeting.
* **Note (8)**: Add any additional notes or comments for each group.
* **Event Details (9)**: Enter the event or group meeting details.
* **School Event Name (10)**: Enter the name of the event or group meeting.
* **School Event Date (11)**: Select the date of the event or group meeting.
* **School Event Time (12)**: Select the time of the event or group meeting.
* **School Event Note (13)**: Add any additional notes or comments for the event or group meeting.
* **Event Details (14)**: Enter the event or group meeting details.
* **School Name (15)**: Enter the name of the school.
* **School Address (16)**: Enter the address of the school.
* **School Phone (17)**: Enter the phone number of the school.
* **School Website (18)**: Enter the website of the school.
* **School Email (19)**: Enter the email address of the school.
* **School Note (20)**: Add any additional notes or comments for the school.
* **School Group (21)**: Enter the name of the school group.
* **School Other Info (22)**: Enter any other relevant information about the school.
* **School Other Info 1 (23)**: Enter additional information about the school.
* **School Other Info 2 (24)**: Enter more information about the school.
* **School Other Info 3 (25)**: Enter the last piece of information about the school.
