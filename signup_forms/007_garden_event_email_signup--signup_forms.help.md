## Garden Event Email Signup - Help Guide

## How To Complete This Form
To complete this form, simply follow these steps:

1. Enter your first name in the "First name" field. This field is optional, so you can leave it blank if you don't feel comfortable sharing your first name.
2. Provide your email address in the "Email" field. This is the primary means of contact for communication about the event. Please make sure to enter a valid email address.
3. Indicate whether you plan to attend the event or not by selecting "Yes" or "No" in the "Event" field.
4. Enter the location of the event, if different from the main location, in the "Location" field.
5. Choose a date for the event from the available options.
6. Select a time for the event from the available options.
7. Add any comments or additional information about the event in the "Comments" field.
8. Confirm whether you would like to receive email updates about the event by selecting "Yes" or "No" in the "Confirm Email" field.

## Field-by-Field Explanation

* **First name (1)** (`text`, optional): Enter your first name if you feel comfortable sharing it.
* **Email (2)** (`email`, required): Enter a valid email address to receive event updates.
* **Event (3)** (`select_one`, optional): Select "Yes" if you plan to attend the event, "No" otherwise.
* **Location (4)** (`text`, optional): Enter the location of the event if it's different from the main location.
* **Date (5)** (`date`, optional): Select a date for the event.
* **Time (6)** (`time`, optional): Select a time for the event.
* **Comments (7)** (`note`, optional): Add any comments or additional information about the event.
* **Confirm Email (8)** (`select_one`, optional): Select "Yes" to receive email updates about the event, "No" otherwise.
