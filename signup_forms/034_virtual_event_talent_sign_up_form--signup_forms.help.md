# Virtual Event Talent Sign Up Form - Help Guide
## Purpose
The Virtual Event Talent Sign Up Form is designed for talent to provide their information and sign up for virtual events hosted by event organizers.

## How To Complete This Form

1.  To fill out this form, navigate to the "Virtual Event Talent Sign Up Form".
2.  Click on the "Sign up" button to start the registration process.
3.  Select the event you would like to sign up for from the list of available events.
4.  Fill out the form with the required information.
5.  Once you have completed the form, click on the "Submit" button to finish the registration process.

## Field-by-Field Explanation

* **talent_type**: This field is used to select the type of talent you are signing up as (e.g., musician, comedian, etc.).
* **length_of_act**: This field is used to specify the length of your act (e.g., 15 minutes, 1 hour, etc.).
* **details of the performance**: This field is used to provide a brief description of your performance.
* **show details**: This field is used to provide more details about your performance.
* **show details 2**: This field is used to provide additional details about your performance.
* **event_organizer_email**: This field is used to provide the email address of the event organizer.
* **event_organizer_name**: This field is used to provide the name of the event organizer.
* **event title**: This field is used to specify the title of the event.
* **contact_number**: This field is used to provide your contact number.
* **event date**: This field is used to specify the date of the event.
* **event time**: This field is used to specify the time of the event.
* **event duration**: This field is used to specify the duration of the event.
* **event capacity**: This field is used to specify the capacity of the event.
* **event type**: This field is used to select the type of event (e.g., concert, comedy night, etc.).
* **event organizer**: This field is used to select the event organizer.
* **event details**: This field is used to provide more details about the event.
* **contact details**: This field is used to provide contact details.
* **performance type**: This field is used to specify the type of performance (e.g., live, pre-recorded, etc.).
* **length of performance**: This field is used to specify the length of the performance.
* **show time**: This field is used to specify the time of the show.
* **show date**: This field is used to specify the date of the show.
* **show details**: This field is used to provide more details about the show.
* **talent details**: This field is used to provide more details about your talent.
* **show duration**: This field is used to specify the duration of the show.
* **contact name**: This field is used to provide your contact name.
