# Wardrobe Form - Help Guide
## Purpose
The Wardrobe Form is a tool that helps users find and purchase clothes that match their style.

## How To Complete This Form
To complete the Wardrobe Form, follow these steps:

1. Answer the questions on each page to provide as much information as possible.
2. Review each page to ensure that you have answered all the required questions.
3. If you need help, refer to the field explanations below.
