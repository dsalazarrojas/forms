# Daily Currency Exchange Rate Preferences - Help Guide
## Purpose
The purpose of this form is to collect user preferences for daily currency exchange rate updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the update frequency for your currency exchange rate updates from the options provided (Daily, Weekly, Monthly).
2. Select your preferred delivery method for the updates (Email, SMS, Push).
3. Choose the currencies for which you want to receive updates (USD, EUR, JPY, CNY).
4. Set the start and end dates for when you want to receive updates.
5. Select your timezone (UTC, EST, PST).
6. Set your timezone offset if applicable.
7. Choose the delivery frequency for your updates (Daily, Weekly, Monthly).

## Field-by-Field Explanation

* **Update frequency** (Select Multiple, required: false): Choose the frequency at which you want to receive currency exchange rate updates. Options: Daily, Weekly, Monthly.
* **Preferred update time** (Time, required: false): This field allows you to set the time of day when you want to receive updates.
* **Delivery method** (Select One, required: false): Choose how you want to receive your updates (Email, SMS, Push).
* **Preferred currencies** (Select Multiple, required: false): Choose the currencies for which you want to receive updates. Options: USD, EUR, JPY, CNY.
* **Start date** (Date, required: false): Set the start date for when you want to receive updates.
* **End date** (Date, required: false): Set the end date for when you want to stop receiving updates.
* **Timezone** (Select One, required: false): Choose your timezone (UTC, EST, PST).
* **Timezone offset** (Number, required: false): Set your timezone offset if applicable.
* **Delivery frequency** (Select Multiple, required: false): Choose the frequency at which you want to receive updates. Options: Daily, Weekly, Monthly.
* **Currency update time** (Time, required: false): This field is currently not used in the provided YAML and can be ignored.

## Tips
- Make sure to fill out all the fields that are relevant to your needs.
- If you have not already set up currency exchange rate updates, this form is a good way to get started.
- If you have any issues or questions, contact support.
- Review your preferences regularly to ensure they are accurate.
