# Customer Sign Up & Quote Request - Help Guide
## Purpose
This form is designed to collect customer details and quote requests for a project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (email and phone) correctly.
2. Provide a brief description of your project in the Project Details field.
3. Select your project type (Yes/No) and project status (Active/Inactive).
4. Fill in your contact details in the Contact field.
5. Enter any comments or special requests in the Comments field.
6. Select multiple options for Project Type and Project Status.
7. Fill in the quote terms and conditions if necessary.
8. Fill in the customer sign-up details in the Customer Sign Up 2 field.

## Field-by-Field Explanation

* **Email** (`email`, `email`, required): A valid email address is required.
* **Phone** (`phone`, `text`, required): A valid phone number is required.
* **Project Type** (`project_type`, `select_one`, required): Select Yes or No to indicate the type of project.
* **Project Type Options** (`project_type_options`, `select_multiple`, required): Select multiple options for your project type.
* **Project Duration** (`project_duration`, `number`, required): Enter the project duration in numbers.
* **Project Budget** (`project_budget`, `number`, required): Enter the project budget in numbers.
* **Project Status** (`project_status`, `select_one`, required): Select Active or Inactive to indicate the project status.
* **Project Status Options** (`project_status_options`, `select_multiple`, required): Select multiple options for project status.
* **Project Details** (`project_details`, `text`, required): A brief description of your project.
* **Quote Request** (`quote_request`, `text`, required): A brief description of your quote request.
* **Quote Terms** (`quote_terms`, `note`, required): A brief description of your quote terms.
* **Quote Terms Terms 2** (`quote_terms_terms_2`, `text`, required): A brief description of your quote terms.
* **Quote Terms Terms 2 2** (`quote_terms_terms_2_2`, `text`, required): A brief description of your quote terms.
* **Customer Sign Up** (`customer_sign_up`, `text`, required): A brief description of your customer sign up.
* **Customer Sign Up 2** (`customer_sign_up_2`, `text`, required): A brief description of your customer sign up 2.
* **Contact** (`contact`, `text`, required): A brief description of your contact details.
* **Comments** (`comments`, `text`, required): A brief description of any comments or special requests.
* **Date** (`date`, `date`, required): Enter a date in the format MM/DD/YY.
