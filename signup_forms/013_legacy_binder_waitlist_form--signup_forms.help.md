# Legacy Binder Waitlist Form - Help Guide
## Purpose
The Legacy Binder Waitlist Form is used to add a legacy binder to the waitlist. This form helps the user decide if a legacy binder is eligible to be included on the waitlist.

## How To Complete This Form
To complete this form, follow these steps:

1. Decide if the legacy binder should be included on the waitlist.
2. Select the option for the number of people waiting.
3. Enter the name and email of the person responsible for the legacy binder.
4. Add any additional notes about the legacy binder.

## Field-by-Field Explanation
* **Legacy Binder** (`waitlist_form`, select_multiple): Select "Yes" if the legacy binder is eligible to be included on the waitlist.
* **Name** (`name`, text): Enter the name of the person responsible for the legacy binder.
* **Email** (`email`, email): Enter the email address of the person responsible for the legacy binder.
* **Number of People Waiting** (`number_of_people`, select_one): Choose the number of people waiting for the legacy binder.
* **Notes** (`notes`, note): Add any additional notes about the legacy binder.

## Tips
* Make sure to enter the correct email address for the person responsible for the legacy binder.
* Double-check the number of people waiting to ensure it's accurate.
* Use the "Notes" field to provide any additional context or information about the legacy binder.
