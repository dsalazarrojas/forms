# Zoom Webinar Sign Up Form - Help Guide

## Purpose
This form is designed to collect necessary information from users who wish to attend a Zoom Webinar. It is a one-time event and should only be used for a single event.

## How To Complete This Form
To sign up for the Zoom Webinar, follow these steps:

1. Enter your registrant name in the "Registrant name" field.
2. Enter your email address in the "Email" field.
3. Select the correct time zone for you in the "Time zone" field.
4. If you have any messages or notes for the speaker, use the "Message" field.
5. If you need to add any guests, enter their names in the "Number of guests" field, but this field is optional.
6. Enter any additional information for each guest in the "Registrant Email", "Registrant Time", and "Registrant Timezone" fields, but these fields are only required if you are registering guests.

## Field-by-Field Explanation

* **Registrant name**: Enter the name of the person signing up.
* **Email**: Enter the email address of the person signing up.
	+ Note: This is not the email address of the guest(s) you are adding, but rather the email address of the person filling out this form.
* **Time**: Select the time you are planning to join the webinar.
* **Number of guests**: If you are adding any guests, enter the number of people attending with you. This field is optional.
* **Time zone**: Select the time zone you are in to ensure you are on the correct time.
* **Message**: If you have any questions or comments for the speaker, use this field.
* **Phone**: This field is not currently used for the webinar.
* **Registrant Email**: This field is only required if you are adding guests, and is the email address of the guest you are adding.
* **Registrant Number**: This field is not currently used for the webinar.
* **Registrant Time**: This field is not currently used for the webinar.
* **Registrant Timezone**: This field is only required if you are adding guests, and is the time zone of the guest you are adding.
* **Registrant Phone**: This field is not currently used for the webinar.
