# Standard Test Log Sheet - Help Guide
## Purpose
The Standard Test Log Sheet is a form used to record and document laboratory test results and associated data. This form helps to ensure that all relevant information is accurately and consistently recorded, making it easier to track and analyze test results over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the test date, which is the date the test was performed.
2. Enter the name of the technician or laboratory technician who performed the test.
3. Specify the equipment used to perform the test.
4. Enter the test result, which is the outcome of the test.
5. Add any additional notes about the test, if necessary.
6. Select the test type, which indicates whether the test was performed and its relevance to the patient or sample.
7. Select the test category, which indicates the type of test performed.
8. Enter the test frequency, which is how often the test is performed.
9. Select the test status, which indicates whether the test is active or inactive.
10. Enter any comments about the test result, if necessary.
11. Enter the name and phone number of the laboratory technician who performed the test.
12. Enter the location where the test was performed.
13. Enter the URL of a map or location where the test was performed, if available.

## Field-by-Field Explanation
- **Test Date** (`test_date`, date): Enter the date the test was performed.
- **Technician** (`technician`, text): Enter the name of the technician or laboratory technician who performed the test.
- **Equipment Used** (`equipment_used`, text): Specify the equipment used to perform the test.
- **Test Result** (`test_result`, text): Enter the outcome of the test.
- **Notes** (`notes`, note): Add any additional notes about the test, if necessary.
- **Test Type** (`test_type`, select_one): Select whether the test was performed and its relevance to the patient or sample.
- **Test Category** (`test_category`, select_one): Select the type of test performed.
- **Test Frequency** (`test_frequency`, text): Enter how often the test is performed.
- **Test Status** (`test_status`, select_one): Select whether the test is active or inactive.
- **Result Comments** (`result_comments`, text): Enter any comments about the test result, if necessary.
- **Lab Technician** (`lab_technician`, text): Enter the name of the laboratory technician who performed the test.
- **Lab Technician Phone** (`lab_technician_phone`, text): Enter the phone number of the laboratory technician who performed the test.
- **Test Location** (`test_location`, text): Enter the location where the test was performed.
- **Test Location Map URL** (`test_location_map_url`, text): Enter the URL of a map or location where the test was performed, if available.

## Tips
- Make sure to fill in all required fields before submitting the form.
- Enter as much detail as possible in the free-form fields to ensure accurate and consistent recording of test results.
- If a field is not relevant to the specific test, you can leave it blank.
