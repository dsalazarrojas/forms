# R&D Experiment Validation Report Form - Help Guide
## Purpose
The purpose of this form is to collect information about the validation of R&D experiments. It is used to report on the progress and outcomes of experiments and to record the validation status and decisions made on them.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the date completed field with the date the experiment was completed.
2. Enter the validation outcome by selecting one or more of the options (e.g., "Yes" or "No").
3. Enter any comments about the experiment in the comments field.
4. Select the validation status (Active or Inactive) in the validation status field.
5. Enter any validation decisions made on the experiment in the validation decision field.
6. Enter any validation rationale in the validation rationale field.
7. Enter any validation notes in the validation notes field.

## Field-by-Field Explanation

* **Experiment Validation Report Form** (`experiment_validation_report`, text, required): This is the main title of the form.
* **Date Completed** (`date_completed`, date, required): Enter the date the experiment was completed.
* **Date Verified** (`date_verified`, date, required): Enter the date the experiment was verified.
* **Validation Outcome** (`validation_outcome`, select_multiple, optional): Select one or more of the options to indicate the outcome of the experiment. (e.g., "Yes" or "No").
* **Comments** (`comments`, text, optional): Enter any comments about the experiment.
* **Validation Status** (`validation_status`, select_one, optional): Select the current status of the experiment (Active or Inactive).
* **Validation Decision** (`validation_decision`, select_multiple, optional): Select one or more of the options to record any validation decisions made on the experiment. (e.g., "Yes" or "No").
* **Validation Rationale** (`validation_rationale`, text, optional): Enter any reasoning or justification for any validation decisions made.
* **Validation Notes** (`validation_notes`, text, optional): Enter any additional notes about the experiment's validation.

## Tips

* Make sure to fill out all required fields (Date Completed, Date Verified, and Experiment Validation Report Form).
* Be as clear and concise as possible when entering information in the fields.
* If you are unsure about any field, refer to the instructions above or contact the relevant authorities for guidance.
