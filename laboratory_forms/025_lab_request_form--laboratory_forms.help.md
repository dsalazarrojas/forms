# Lab Request Form - Help Guide

## Purpose
The Lab Request Form is used to collect information about a patient's laboratory tests and results. This form is designed to be completed by laboratory professionals to request and track lab tests, their results, and other relevant information.

## How To Complete This Form
To complete the form, follow these steps:

1. Review the form carefully to ensure all required fields are filled in.
2. Select the options for each field as necessary.
3. Enter your information in the designated fields.
4. Submit the form once complete.

## Field-by-Field Explanation
### 1. **Lab Request Form** (`lab_request_form`)
This is the title of the form.
### 2. **Patient Info** (`patient_info`)
Select "Yes" or "No" to indicate if the patient has provided information about their lab requests.
### 3. **Sample Collection** (`sample_collection`)
Enter the sample collection information.
### 4. **Lab Tests** (`lab_tests`)
Select "Yes" or "No" to indicate if the lab tests have been completed.
### 5. **Sample Type** (`sample_type`)
Select "Yes" or "No" to indicate if the sample type is required.
### 6. **Test Results** (`test_results`)
Select "Yes" or "No" to indicate if the test results are available.
### 7. **Lab Info** (`lab_info`)
Enter any additional lab information.
### 8. **Lab Name** (`lab_name`)
Enter the lab's name.
### 9. **Test Code** (`test_code`)
Enter the test code.
### 10. **Test Name** (`test_name`)
Select "Yes" or "No" to indicate if the test name is required.
### 11. **Result Date** (`result_date`)
Enter the date of the test result.
### 12. **Result Time** (`result_time`)
Enter the time of the test result.
### 13. **Result Status** (`result_status`)
Select "Active" or "Inactive" to indicate the status of the test result.
### 14. **Note** (`note`)
Enter any additional notes about the lab request.
### 15. **Email** (`email`)
Enter the email of the person requesting the lab test.
### 16. **Phone** (`phone`)
Enter the phone number of the person requesting the lab test.
### 17. **Lab Phone** (`lab_phone`)
Enter the phone number of the lab.
### 18. **Lab Address** (`lab_address`)
Enter the address of the lab.
### 19. **Lab Contact** (`lab_contact`)
Enter the contact information of the lab.
### 20. **Lab Fax** (`lab_fax`)
Enter the fax number of the lab.
### 21. **Lab Notes** (`lab_notes`)
Enter any additional lab notes.
### 22. **Doctor Name** (`doctor_name`)
Enter the name of the doctor.
### 23. **Doctor Phone** (`doctor_phone`)
Enter the phone number of the doctor.
### 24. **Doctor Fax** (`doctor_fax`)
Enter the fax number of the doctor.
### 25. **Doctor Email** (`doctor_email`)
Enter the email of the doctor.

Note: This guide is based on the provided YAML fields and is designed to be a helpful reference for users completing the Lab Request Form. If you have any questions or need further clarification, please don't hesitate to ask.
