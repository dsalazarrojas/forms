# Embryonic Development Assessment - Help Guide
## Purpose
The Embryonic Development Assessment form is designed to collect information about a pregnant woman's health and lifestyle factors that may impact the development of her unborn child. This form helps healthcare professionals assess the risk factors associated with the pregnancy and provide personalized guidance and care.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each page carefully and ensure you have all necessary information before proceeding.
2. Enter the form title and number (embryo_id) to identify the patient's record.
3. Answer each question honestly and to the best of your ability.
4. Select the most accurate options for each question.
5. Submit the form once you have completed all pages.

## Field-by-Field Explanation

* **Form Title** (page 1, form_title): Enter a brief description of the patient's case or a unique identifier for the assessment.
* **Form Number** (page 1, embryo_id): Enter the patient's unique identifier for the assessment.
* **Maternal Age** (page 2, maternal_age): Enter the age of the mother in years.
* **Gestational Age** (page 2, gestational_age): Enter the gestational age of the pregnancy in weeks.
* **Maternal Weight** (page 2, maternal_weight): Enter the weight of the mother in kilograms.
* **Maternal Height** (page 2, maternal_height): Enter the height of the mother in centimeters.
* **Maternal Smoking Status** (page 3, maternal_smoking_status): Select the correct option for the mother's smoking status:
	+ Active: Mother currently smokes
	+ False: Mother does not smoke
	+ True: Mother previously smoked
* **Maternal Drinking Status** (page 3, maternal_drinking_status): Select the correct option for the mother's drinking status:
	+ True: Mother currently drinks alcohol
	+ False: Mother does not drink alcohol
* **Prophet's Smoking Status** (page 3, prophets_smoking_status): Select the correct option for the mother's smoking status:
	+ True: Mother's father or partner currently smokes
	+ False: Mother's father or partner does not smoke
* **Maternal Education** (page 4, maternal_education): Select the correct option for the mother's education level:
	+ Less than high school
	+ High school
	+ Some college
	+ College
	+ Postgraduate
	+ Other
* **Prophet's Income** (page 4, prophets_income): Select the correct option for the mother's income level:
	+ Low
	+ Medium
	+ High
	+ Very high
* **Maternal Occupation** (page 4, maternal_occupation): Select the correct option for the mother's occupation:
	+ Student
	+ Employee
	+ Unemployed
* **Embryo Quality** (page 5, embryo_quality): Select the correct option for the embryo's quality:
	+ Good
	+ Fair
	+ Poor
* **Maternal Insurance** (page 6, maternal_insurance): Select all applicable insurance options for the mother:
	+ Medicare
	+ Medicaid
	+ Private
	+ Other
* **Embryo Weight** (page 7, embryo_weight): Enter the weight of the embryo in grams.
* **Maternal Marital Status** (page 8, maternal_marital_status): Select the correct option for the mother's marital status:
	+ Single
	+ Married
	+ Divorced
	+ Widowed
* **Maternal Pregnancy Complications** (page 9, maternal_pregnancy_complications): Select the correct option for the mother's pregnancy complications:
	+ True: Mother has experienced pregnancy complications
	+ False: Mother has not experienced pregnancy complications
* **Maternal Heart Diseases** (page 10, maternal_heart_diseases): Select the correct option for the mother's heart diseases:
	+ True: Mother has heart disease
	+ False: Mother does not have heart disease
* **Maternal Diabetes** (page 10, maternal_diabetes): Select the correct option for the mother's diabetes status:
	+ True: Mother has diabetes
	+ False: Mother does not have diabetes
* **Maternal Hypertension** (page 10, maternal_hypertension): Select the correct option for the mother's hypertension status:
	+ True: Mother has hypertension
	+ False: Mother does not have hypertension
* **Maternal Preeclampsia** (page 11, maternal_preeclampsia): Select the correct option for the mother's preeclampsia status:
	+ True: Mother has preeclampsia
	+ False: Mother does not have preeclampsia
* **Maternal Obesity** (page 11, maternal_obesity): Select the correct option for the mother's obesity status:
	+ True: Mother is obese
	+ False: Mother is not obese
* **Maternal Allergy** (page 12, maternal_allergy): Select all applicable allergy options for the mother:
	+ Penicillin
	+ Latex
	+ Dust
	+ Other
* **Maternal Comments** (page 13, maternal_comments): Enter any additional comments or information about the mother's health or pregnancy.

## Tips

* Please ensure all required fields are completed before submitting the form.
* If you are unsure about any question, please consult with a healthcare professional.
* Please review the form carefully to ensure accurate and complete information.
* If you have any questions or concerns, please contact your healthcare provider or a relevant authority.
* This form is for informational purposes only and should not be used as a substitute for professional medical advice.
