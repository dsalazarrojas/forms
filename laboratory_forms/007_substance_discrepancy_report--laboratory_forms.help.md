# Substance Discrepancy Report - Help Guide
## Purpose
This form is designed to report discrepancies found in a laboratory setting. It allows users to document and track discrepancies in substances, providing essential information for review and resolution.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Reported By** field with the name of the person who reported the discrepancy.
2. Choose the **Date Discrepancy Found** field to select the date when the discrepancy was first identified.
3. Provide a detailed description of the **Discrepancy Description** in the text field.
4. Select the **Discrepancy Type** field to choose the type of discrepancy (e.g., Label 1, Label 2, etc.).
5. Select the **Discrepancy Category** field to choose one or more relevant categories (e.g., Select 1, Select 2, etc.).
6. Enter the **Department** field with the name of the department responsible for the discrepancy.
7. Choose the **Discrepancy Priority** field to select the priority level (e.g., Low, Medium, High).
8. If applicable, choose **Discrepancy Reopened** and **Discrepancy Closed** fields according to the status of the discrepancy.
9. If applicable, enter the **Discrepancy Closed On** and **Discrepancy Closed By** fields with the date and name of the person who closed the discrepancy.
10. If applicable, enter the **Discrepancy Verified On** and **Discrepancy Verified By** fields with the date and name of the person who verified the discrepancy.
11. Enter the **Submitted To** field with the name of the person or department who submitted the report.

## Field-by-Field Explanation
* **Reported By** (Required, Text): The name of the person who reported the discrepancy.
* **Date Discrepancy Found** (Required, Date): The date when the discrepancy was first identified.
* **Discrepancy Description** (Required, Text): A detailed description of the discrepancy.
* **Discrepancy Type** (Required, Select One): The type of discrepancy (e.g., Label 1, Label 2, etc.).
* **Discrepancy Category** (Required, Select Multiple): One or more relevant categories (e.g., Select 1, Select 2, etc.).
* **Discrepancy Notes** (Optional, Note): Additional notes about the discrepancy.
* **Discrepancy Status** (Required, Select One): The status of the discrepancy (e.g., Status 1, Status 2, etc.).
* **Discrepancy Comments** (Optional, Text): Additional comments about the discrepancy.
* **Submitted By** (Optional, Text): The name of the person who submitted the report.
* **Submitted On** (Optional, Date): The date when the report was submitted.
* **Reviewer** (Optional, Text): The name of the reviewer.
* **Review Date** (Optional, Date): The date of the review.
* **Discrepancy ID** (Required, Text): A unique ID for the discrepancy.
* **Lab Manager** (Optional, Text): The name of the lab manager.
* **Department** (Required, Text): The department responsible for the discrepancy.
* **Discrepancy Priority** (Required, Select Multiple): The priority level of the discrepancy (e.g., Low, Medium, High).
* **Discrepancy Reopened** (Optional, Select Multiple): Whether the discrepancy has been reopened.
* **Discrepancy Closed** (Optional, Select Multiple): Whether the discrepancy has been closed.
* **Discrepancy Closed On** (Optional, Date): The date when the discrepancy was closed.
* **Discrepancy Closed By** (Optional, Text): The name of the person who closed the discrepancy.
* **Discrepancy Verified On** (Optional, Date): The date when the discrepancy was verified.
* **Discrepancy Verified By** (Optional, Text): The name of the person who verified the discrepancy.
* **Submitted To** (Required, Text): The name of the person or department who submitted the report.
