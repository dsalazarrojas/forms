# Laboratory Result Form - Help Guide
## Purpose
The Laboratory Result Form is used to record and report the result of a laboratory test, including the test date and time, the status of the result, and any further details. The form is intended for use by medical staff or healthcare professionals.

## How To Complete This Form
To complete this form, please follow these steps:

* Enter the test result in the "Test Result" field.
* Provide additional details about the test result in the "Test Result Details" field.
* Enter the date and time of the test in the "Test Date" field.
* Enter the test time in the "Test Time" field.
* Select the test result status from the "Test Result Status" options.
* Enter any further status details in the "Test Result Status Details" field.
* Select any lab contact persons from the "Lab Contact Person" options.
* Enter the lab contact email address in the "Lab Contact Email" field.
* Enter the lab phone number in the "Lab Phone" field.
* Enter the test order number in the "Test Order Number" field.

## Field-by-Field Explanation
* **Test Result** (`Test Result`, text, required/optional): Enter the result of the test here.
* **Test Result Details** (`Test Result Details`, text, optional): Provide any additional details about the test result.
* **Test Date** (`Test Date`, date, required/optional): Enter the date of the test.
* **Test Time** (`Test Time`, time, required/optional): Enter the time of the test.
* **Test Result Status** (`Test Result Status`, select_one, optional): Select one of the following options:
	+ Positive
	+ Negative
	+ Abnormal
* **Test Result Status Details** (`Test Result Status Details`, text, optional): Enter any further details about the test result status.
* **Lab Contact Person** (`Lab Contact Person`, select_multiple, optional): Select one or more of the following lab contact persons:
	+ Dr. Smith
	+ Dr. Jones
	+ Dr. Johnson
* **Lab Contact Email** (`Lab Contact Email`, email, optional): Enter the lab contact email address.
* **Lab Phone** (`Lab Phone`, text, optional): Enter the lab phone number.
* **Test Order Number** (`Test Order Number`, number, optional): Enter the test order number.

## Tips
* Please enter the test result and details accurately and clearly.
* Make sure to select the correct test result status.
* Double-check the test date and time.
* Ensure that you have entered the correct lab contact information.
