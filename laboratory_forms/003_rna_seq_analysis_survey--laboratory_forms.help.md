# RNA Seq Analysis Survey - Help Guide
## Purpose
This form is designed to gather feedback and comments from users about the RNA sequence analysis workflow, which is a crucial process in genetic research and analysis.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields:
	+ **Lab Type**: Select one of the available options (Lab, Core Facility, or Biotech Team).
	+ **Analysis Type**: Choose one of the analysis types (Library Preparation, PCR, Sequencing, or Bioinformatics).
	+ **Sequencing Platform**: Select the sequencing platform used (Illumina, PacBio, or Ion Torrent).
	+ **Contact Name**: Enter the name of the contact person.
	+ **Contact Email**: Enter a valid email address of the contact person.
* The other fields are optional and can be filled in or left blank as per your preference.

## Field-by-Field Explanation

* **Workflow Name**: Please enter a descriptive name for the workflow.
* **Lab Type**: Please select the type of lab (Lab, Core Facility, or Biotech Team) that performed the analysis.
* **Analysis Type**: Please choose the type of analysis performed (Library Preparation, PCR, Sequencing, or Bioinformatics).
* **Sequencing Platform**: Please select the sequencing platform used (Illumina, PacBio, or Ion Torrent).
* **Instrument Used**: Select all the instruments used in the analysis (multiple options are available).
* **Workflow Steps**: This field is optional and can be used to describe specific steps of the workflow.
* **Feedback on Steps**: This field is optional and can be used to provide feedback on any particular steps of the analysis.
* **Feedback on Platform**: This field is optional and can be used to provide feedback on the sequencing platform used.
* **Feedback on Instrument**: This field is optional and can be used to provide feedback on the instrument used.
* **Additional Comments**: This field is optional and can be used for any additional comments or suggestions.
* **Contact Name**: Enter the name of the person who will be contacted for further information.
* **Contact Email**: Enter a valid email address of the contact person.
* **Contact Department**: This field is optional and can be used to specify the department of the contact person.
* **Contact Phone**: This field is optional and can be used to provide the contact person's phone number.
* **Additional Comments**: This field is optional and can be used for any additional comments or suggestions.
