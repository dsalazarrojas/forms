# shelf_life_extension_testing_request_form - Help Guide
## Purpose
The purpose of this form is to request shelf life extension of a product. This form is intended to gather information from the manufacturer or responsible person to support the request.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the manufacturer's name and product code or product name.
2. Select the product type from the provided options.
3. Enter a brief description of the product.
4. Enter the shelf life of the product.
5. Select the expiry date.
6. Provide a justification for the shelf life extension request.
7. Select any supporting documents required for the review process.
8. If necessary, upload any supporting documents as separate notes.

## Field-by-Field Explanation
* **Manufacturer** (1, text, required: false): Enter the name of the manufacturer of the product.
* **Product Code** (2, text, required: false): Enter the product code of the product being requested for shelf life extension.
* **Product Name** (3, text, required: false): Enter the name of the product being requested for shelf life extension.
* **Product Type** (4, select_one, required: false): Select the type of product from the options provided.
* **Product Description** (5, text, required: false): Enter a brief description of the product.
* **Shelf Life** (6, number, required: false): Enter the current shelf life of the product.
* **Expiry Date** (7, date, required: false): Select the current expiry date of the product.
* **Justification** (8, text, required: false): Provide a clear justification for requesting shelf life extension.
* **Supporting Documents** (9, select_multiple, required: true): Select the supporting documents required for the review process.
* **Document A** (10, note, required: false): If necessary, upload any supporting documents as separate notes.
* **Document B** (11, note, required: false): If necessary, upload any additional supporting documents as separate notes.
* **Document C** (12, note, required: false): If necessary, upload any further supporting documents as separate notes.

## Tips
* Please ensure that you have all necessary information and supporting documents before starting to fill out the form.
* Double-check your entries for accuracy and completeness.
* If you are unsure about any field, please contact the relevant authority for clarification.
* Supporting documents must be uploaded as separate notes for each field.
* Only select the relevant supporting documents required for the review process.
