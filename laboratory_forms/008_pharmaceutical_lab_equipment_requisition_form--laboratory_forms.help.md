# Pharmaceutical Lab Equipment Requisition Form - Help Guide
## Purpose
This form is designed to streamline the process of requesting and approving pharmaceutical lab equipment. It captures key information about the equipment, including its name, type, department, lab location, and other relevant details. This helps ensure that requests are properly documented and approved, reducing errors and delays in the procurement process.

## How To Complete This Form
1. Select the "Equipment Type" that best describes the type of equipment requested.
2. Choose the department and lab location where the equipment will be used.
3. Enter the "Purchase Request Date" for the equipment.
4. Choose the "Delivery Time Frame" for when the equipment is needed.
5. Select the "Priority" level of the request (High, Medium, or Low).
6. Specify who requested the equipment (Requested By).
7. Select the "Approval Status" (Approved or Not Approved).
8. Add any comments or notes about the request (Comments).
9. If approved, select the "Procurement Status" (Ordered or Not Ordered) and add any procurement notes.
10. Enter any additional equipment details.

## Field-by-Field Explanation

* **Equipment Name** (`equipment_name`, `text`, required): Enter the name of the requested equipment.
* **Equipment Type** (`equipment_type`, `select_multiple`, required): Select the type of equipment that best describes the request (e.g., Analytical Instrument, Centrifuge, Microscope).
* **Department** (`department`, `select_one`, required): Choose the department that will be using the equipment.
* **Lab Location** (`lab_location`, `select_one`, required): Select the lab location where the equipment will be used.
* **Purchase Request Date** (`purchase_request_date`, `date`, required): Enter the date when the equipment is requested.
* **Delivery Time Frame** (`delivery_timeframe`, `select_one`, required): Choose the delivery timeframe for when the equipment is needed.
* **Priority** (`priority`, `select_one`, required): Select the priority level of the request (High, Medium, or Low).
* **Requested By** (`requested_by`, `select_one`, required): Specify who requested the equipment.
* **Approval Status** (`approval_status`, `select_one`, required): Select the current approval status of the request (Approved or Not Approved).
* **Comments** (`comments`, `text`, optional): Add any comments or notes about the request.
* **Submitted By** (`submitted_by`, `text`, optional): Enter the person or group submitting the request.
* **Submission Date** (`submission_date`, `date`, optional): Enter the date when the request was submitted.
* **Approved By** (`approved_by`, `text`, optional): Enter the person or group who approved the request.
* **Approval Date** (`approval_date`, `date`, optional): Enter the date when the approval was made.
* **Equipment Status** (`equipment_status`, `select_one`, required): Select the current status of the equipment (Active or Inactive).
* **Notes** (`notes`, `text`, optional): Enter any additional notes about the equipment.
* **Departmental Approvals** (`departmental_approvals`, `select_multiple`, optional): Select the departmental approvals required for the equipment.
* **Departmental Comments** (`departmental_comments`, `text`, optional): Enter any departmental comments about the equipment.
* **Approval Comments** (`approval_comments`, `text`, optional): Enter any comments about the approval process.
* **Procurement Status** (`procurement_status`, `select_one`, required): Select the current procurement status (Ordered or Not Ordered).
* **Procurement Notes** (`procurement_notes`, `text`, optional): Enter any procurement notes about the equipment.
* **Equipment Details** (`equipment_details`, `text`, optional): Enter any additional equipment details.
* **Remarks** (`remarks`, `text`, optional): Enter any additional remarks about the equipment.
* **Remarks 2** (`remarks_2`, `text`, optional): Enter any additional remarks about the equipment.

## Tips
* Make sure to fill in all required fields to ensure a complete and accurate request.
* Double-check the "Equipment Type" and "Department" selections to ensure they align with the equipment's intended use.
* If a request is approved, ensure that the "Procurement Status" is updated to "Ordered".
* If a request is not approved, ensure that the "Procurement Status" is updated to "Not Ordered".
