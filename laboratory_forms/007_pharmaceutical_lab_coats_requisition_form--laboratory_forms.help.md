# pharmaceutical_lab_coats_requisition_form - Help Guide
## Purpose
The pharmaceutical_lab_coats_requisition_form is a tool for lab personnel to request lab coats for their team, providing necessary information for the lab coat's distribution.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information.
2. Make sure to provide accurate and complete answers for each field.
3. Review the form for errors before submitting it.

## Field-by-Field Explanation
### Form ID
* **Form ID** (`form_id`, `number`, optional): Unique identifier for this form submission. This is automatically generated by the system and is not required to be filled out.

### User Name
* **User Name** (`user_name`, `text`, optional): Your name as a lab personnel. If you're requesting a lab coat for someone else, enter their name here.

### Lab Group
* **Lab Group** (`lab_group`, `select_multiple`, optional): Select all the lab groups that this lab coat request is for. You can select multiple groups if necessary.

### Lab Location
* **Lab Location** (`lab_location`, `select_one`, optional): Select the location where you'll be using the lab coat. This will help determine which lab coat to provide.

### Lab Coat Size
* **Lab Coat Size** (`lab_coat_size`, `select_one`, optional): Select the size of the lab coat you need. Please be accurate as this will impact the fit and comfort of the coat.

### Lab Coat Type
* **Lab Coat Type** (`lab_coat_type`, `select_multiple`, optional): Select the type of lab coat you need, such as a full-length or waistcoat. You can select multiple types if necessary.

### Request Date
* **Request Date** (`request_date`, `date`, optional): The date you're requesting the lab coat. This will help determine the order of requests.

### Request Time
* **Request Time** (`request_time`, `time`, optional): The time you're requesting the lab coat. This will help ensure timely delivery.

### Department
* **Department** (`department`, `select_one`, optional): Select your department. This will help determine which lab coat stock to allocate.

### Team
* **Team** (`team`, `select_multiple`, optional): Select the team members you're requesting the lab coat for. You can select multiple team members if necessary.

### Request Status
* **Request Status** (`request_status`, `select_one`, optional): Select the status of this request, whether it's active or inactive.

### Notes
* **Notes** (`notes`, `note`, optional): Any additional information you'd like to provide about this lab coat request.

### Email
* **Email** (`email`, `email`, optional): Your email address for contact purposes.

### Phone
* **Phone** (`phone`, `text`, optional): Your phone number for contact purposes.
 

### Tips
* Make sure to fill out all required fields accurately and completely.
* Check the available options for each field to ensure you're selecting the correct information.
* If you're unsure about any field, contact your team lead or the lab coat request system administrator for guidance.
* Review the form for errors before submitting it to avoid delays in processing your request.
