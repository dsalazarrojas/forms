# Seedling Growth Assessment Form - Help Guide
## Purpose
This form is used to track the growth of seedlings over time. It is designed to help nursery staff assess the progress of seedlings from planting to harvesting.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant seedling growth assessment from the options provided.
2. Enter the date the seedling was planted.
3. Record the seedling's height.
4. Count the number of seedlings.
5. Record the seedling's growth in inches.
6. Record the number of days since planting.
7. Add any additional notes about the seedling.
8. Select the person responsible for submitting the assessment.
9. Select the tool used for the assessment.
10. Add any additional notes about the seedling.
