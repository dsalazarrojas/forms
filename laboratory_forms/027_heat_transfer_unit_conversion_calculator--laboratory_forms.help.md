# Heat Transfer Unit Conversion Calculator - Help Guide
## Purpose
This form is used to calculate the heat transfer between two different mediums. It supports three modes of heat transfer: conduction, convection, and radiation.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Enter the first heat transfer value in the first field.
2. Enter the second heat transfer value in the second field.
3. Select the mode of heat transfer for the first value from the first select field.
4. Select the mode of heat transfer for the second value from the second select field.
5. Click the "submit" button to perform the calculation and view the result.

## Field-by-Field Explanation
* **Heat Transfer Value 1**: Enter the heat transfer value for the first medium.
* **Heat Transfer Value 2**: Enter the heat transfer value for the second medium.
* **Transfer Mode**: Select the mode of heat transfer for the first medium. You can choose from Conduction, Convection, or Radiation.
* **Second Transfer Mode**: Select the mode of heat transfer for the second medium. You can choose from Conduction, Convection, or Radiation.
* **Result**: This is the calculated heat transfer between the two mediums in the selected modes.

## Tips
* Make sure to enter the correct units for the input values.
* If you're unsure about the mode of heat transfer, refer to the relevant scientific literature or consult with a subject matter expert.
