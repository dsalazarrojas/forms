# Lab Test Result Validation Form - Help Guide
## Purpose
The Lab Test Result Validation Form is designed to collect and verify lab test results for patients. This form ensures that lab test results are accurately documented and verified by authorized personnel.

## How To Complete This Form
1. Navigate through the pages to select the relevant information for each field.
2. Enter the required information for each field accurately and completely.
3. Review the completed form carefully before submitting it.

## Field-by-Field Explanation
* **Patient Info (Patient Info, text, optional)**: Enter the patient's name.
* **Lab Test Name (lab test name, select_one, optional)**: Select the name of the lab test from the dropdown menu.
* **Lab Result (lab result, select_one, optional)**: Select the result of the lab test.
* **Result Date (result date, date, optional)**: Enter the date of the lab test result.
* **Result Time (result time, time, optional)**: Enter the time of the lab test result.
* **Lab Result Notes (lab result notes, note, optional)**: Enter any additional notes about the lab test result.
* **Medical Provider (medical provider, select_one, optional)**: Select whether the medical provider is present or not.
* **Patient DOB (patient dob, date, optional)**: Enter the patient's date of birth.
* **Hospital Name (hospital name, text, optional)**: Enter the name of the hospital where the lab test was performed.
* **Lab Test Number (lab test number, number, optional)**: Enter the lab test number.
* **Test Result (test result, select_multiple, optional)**: Select the result(s) of the lab test.
* **Test Value (test value, number, optional)**: Enter the value of the lab test result.
* **Patient ID (patient id, text, optional)**: Enter the patient's ID.
* **Test Date (test date, date, optional)**: Enter the date of the lab test.
* **Medical Provider Name (medical provider name, text, optional)**: Enter the name of the medical provider.
* **Medical Department (medical department, text, optional)**: Enter the department of the medical provider.
* **Lab Order Number (lab order number, number, optional)**: Enter the lab order number.
* **Test Name (test name, text, optional)**: Enter the name of the test.
* **Test Code (test code, text, optional)**: Enter the code of the test.
* **Medical Specialty (medical specialty, text, optional)**: Enter the specialty of the medical provider.
* **Patient Phone (patient phone, text, optional)**: Enter the patient's phone number.
* **Medical Provider Phone (medical provider phone, text, optional)**: Enter the phone number of the medical provider.
* **Hospital Number (hospital number, text, optional)**: Enter the hospital number.
* **Medical Department Code (medical department code, text, optional)**: Enter the code of the medical department.
* **Patient Address (patient address, text, optional)**: Enter the patient's address.
